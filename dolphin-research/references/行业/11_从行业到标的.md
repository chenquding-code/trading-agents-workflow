# 第11章 从行业到标的

> **本章目的**：把行业判断映射成受益/受损标的，排序环节与公司，并给出估值和预期差框架。

**本章小节**：11.1 受益标的分层映射与核心资产池｜11.2 方案迭代与情景下的增减量映射｜11.3 环节排序、标的比较与选股准则｜11.4 估值方法与预期定价

---

## 11.1 受益标的分层映射与核心资产池

> 本节导读：本节解决“行业结论怎么落到具体公司”的问题。做法是先按产业角色、器件环节把参与者铺开并分级（谁是定义者、谁已兑现、谁只是期权），再用巨头的资本动作、龙头的采购模式、新增工艺步骤、垂直一体化程度做“可投资性过滤”，最后用逐家影响映射、政策映射、跨市场映射补全，并以核心资产表/股单收尾，形成后续跟踪池。环节价值量排序见 2.3，两套方案的供应链重合度与增减量映射见 11.2，环节排序与选股准则见 11.3，估值与预期定价见 11.4，事件发布后的预期差映射股价见 12.1。

### 11.1.1 按产业角色分层映射标的（定义者/推动者→落地制造→器件→组件→设备）

**方法要点**：从行业判断落到个股时，不把全链条公司平铺罗列，而是按产业角色分层，每一层写清“看什么”，再给出该层的弹性与风险判断，避免“全链条都买”。

**操作步骤 / 拆分口径**

1. 先找“定义者与推动者”：谁在定义新方案、谁的产品进展决定整条链的节奏。以 CPO 为例是英伟达、博通、Marvell、思科。重点密切跟踪它们的 CPO 产品进展——这既是它们主业超预期或不及预期的影响因素，也是上游机会的起点；再顺着它们的进展和上游合作关系往上游找机会。
2. 看“落地制造”：台积电、英特尔、日月光、Amkor；关注点是工艺卡点和外溢订单。
3. 看“上游器件”，即激光器：Lumentum、Coherent、AAOI。
4. 看“光纤组件”：康宁、安费诺、TE Connectivity。
5. 看“设备”：耦合设备看 ficonTEC/罗博特科、AIXEMTEC、Vanguard、MRSI、万润科技、猎奇智能；测试设备看 Teradyne、Advantest。
6. 每一层都给出弹性与风险判断（弹性的量化框架见 11.3.6，同环节横比见 11.3.5）。
7. 系列收尾把各层标的汇总成核心资产表，作为后续跟踪池（见 11.1.12）。

**变体**

- 变体 A（按产业角色分五层）：适用于一项新技术（如 CPO）从定义者到设备的纵向链条，即上述 1-5 步。
- 变体 B（按功能环节分四类）：DC 互联系列文章不按角色分层，而是按“光连接、交换、铜连接、PCB&ABF”四个环节映射标的，最后汇总成核心资产表，计划逐一跟踪。

**关键指标与数据来源**：标的所处环节、产品进展、客户绑定、弹性、风险敞口；来源为定义者的产品发布与路线图、上游合作关系、公司公告与产业链调研。

**判断标准**

- 每一层的关注点不同：定义者层看“产品进展”（它直接影响其主业是超预期还是不及预期），落地制造层看“工艺卡点与外溢订单”，器件、组件、设备层看“弹性与风险”。
- 推理链：定义者的进展 → 与上游的合作关系 → 上游机会；落到个股时，必须结合每层的弹性和估值取舍，而不是“每层都买”。
- 层与层之间的优先级由 11.3 的排序准则决定，本方法只负责把参与者放进正确的位置。

**海豚案例**

- CPO 行业《“‘铜’ 牛夫人” 不走！CPO》（2026-06-24）：给出完整的五层标的梳理——定义者与推动者（英伟达、博通、Marvell、思科）、落地制造（台积电、英特尔、日月光、Amkor）、激光器（Lumentum、Coherent、AAOI）、光纤组件（康宁、安费诺、TE Connectivity）、设备（耦合设备与测试设备），并对每一层给出弹性与风险判断。
- AMD/英伟达机架《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：按“光连接、交换、铜连接、PCB&ABF”四个环节梳理标的，并汇总出 AI DC 互联核心资产表。

**适用场景与注意事项**：适用于产业链长、参与者多的赛道。分层只是“铺图”，必须再结合每层的弹性和估值取舍，避免“全链条都买”；产品进展类信息变化快，层内名单需随定义者的路线更新。

### 11.1.2 跟踪平台巨头的战略投资与产能锁定，识别关键卡点与核心供应商

**方法要点**：巨头花钱锁定的环节，往往就是稀缺或瓶颈环节。把巨头的投资、收购、联盟动作当作“产业资本信号”，用来确认关键卡点、挑出核心供应商，并同时给被背书的标的做估值提示。

**操作步骤 / 拆分口径**

1. 持续跟踪三类动作：战略投资（含向上游供应商注资、向下游客户注资）、收购、标准/技术联盟。
2. 把动作还原成事实清单。以 CPO 为例：英伟达向 Lumentum 和 Coherent 各投资 20 亿美元，锁定激光器等关键部件产能；投资 Ayar Labs（CPO 互连方案，产品包括 SuperNova 外置光源芯片、TeraPHY 光学 I/O 芯粒）；向 Marvell 注资 20 亿美元；Marvell 收购主攻光互连的 Celestial AI；博通参与 OCI 联盟。
3. 据此做三件事：① 确认该部件（激光器）是关键增量部件；② 把“是否获英伟达注资、是否深度绑定”列为标的比较维度（见 11.3.5 的“客户/路线绑定”）；③ 提示被巨头背书的标的，市场预期已充分反映、估值偏高。
4. 顺着这些合作关系继续找上游投资机会。
5. 同时留意反向动作：巨头向下游客户输血（扶持新云），说明它在主动培育自己的需求端，是另一类产业资本信号。

**关键指标与数据来源**：巨头战略投资的金额与对象、收购事件、标准联盟成员；来源为公司公告、融资/并购新闻、联盟成员名单。

**判断标准**

- 推理链：巨头出资 → 锁定产能或补齐技术拼图 → 被锁定环节即稀缺/瓶颈环节 → 该环节的核心供应商进入候选池。
- 被巨头背书意味着“确定性”上升，但市场预期也会提前反映，估值往往偏高，所以“获注资”既是加分项，也是估值风险提示。
- 联盟成员与收购标的用来判断各定义者的技术路线站队，作为找上游机会的线索。

**海豚案例**

- CPO 行业《“‘铜’ 牛夫人” 不走！CPO》（2026-06-24）：英伟达投资 Lumentum、Coherent、Ayar Labs、Marvell；Marvell 收购 Celestial AI；博通参与 OCI 联盟；据此确认激光器是关键增量部件，并把“是否获英伟达注资”列为比较维度，同时提示 Lumentum、Coherent 估值已相对较高。
- 新云《CoreWeave、Nebius：算力涨价、干爹出手，英伟达 “干儿子” 能飒多久？》（2026-08-13）：英伟达牵头搭建 5000 亿美元融资平台扶持新云，属于反向扶持下游客户。

**适用场景与注意事项**：适用于巨头主导、供应链稀缺的赛道。被投标的的估值往往已提前反映，不能把“被巨头投资”直接等同于“值得买”；需要与 11.4 的估值判断配合。

### 11.1.3 按器件环节逐一映射供应商，并按“独家/主供/二级/白名单/送样/试制”分级

**方法要点**：对一个技术方案里每个外采器件，把全球和国内供应商逐一列出，并标注其所处的供应关系阶段，目的是区分“已经兑现的标的”和“期权型标的”。

**操作步骤 / 拆分口径**

1. 拆出方案中的外采器件清单（以谷歌 OCS 为例：MEMS 微镜阵列、分色分束器、光纤准直器阵列、透镜阵列）。
2. 每个器件下列出全球与国内的供应商。
3. 给每家标注所处阶段与客户覆盖：独家 / 主供 / 二级 / 白名单 / 送样 / 试制。
4. 最后整理成该客户链的核心资产表（谷歌链核心资产表）。

**分级映射示例（OCS 外采器件）**

| 器件 | 供应商与所处阶段 |
|---|---|
| MEMS 微镜阵列 | 赛微电子通过瑞典 Silex 为谷歌独家代工 MEMS-OCS 芯片；英唐智控旗下 6 寸 MEMS 晶圆厂（对标赛微的 8 寸线）具备生产能力 |
| 分色分束器 | 腾景科技产品通过谷歌白名单，并绑定谷歌的光模块供应商，客户覆盖 Lumentum、Coherent、光迅科技；东田微、海泰新光、水晶光电、福晶科技多处于送样或试制阶段 |
| 光纤准直器阵列 | 康宁是全球主供，太辰光、天孚通信是二级供应商，腾景科技是 Coherent 在准直阵列上的第三方采购来源 |
| 透镜阵列 | 炬光科技是 Lumentum 的核心供应商，同时在向 Coherent 送样 |

**关键指标与数据来源**：供应关系层级、认证阶段、客户覆盖；来源多为公司公告和调研。

**判断标准**

- 独家、主供、白名单且已有客户覆盖的，属于“已兑现”；处于送样、试制的，属于“期权型”，兑现取决于认证结果。
- 二级供应商与第三方采购来源，要看其对应主供的份额与扩产节奏，确定性介于两者之间。
- 判断链条：环节外采 → 供应关系分级 → 已兑现/期权分类 → 进入核心资产表时标明层级。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：对 OCS 每个外采器件列出全球和国内供应商，如上表，最后整理成谷歌链核心资产表。

**适用场景与注意事项**：适用于用 A 股、港股映射海外大厂供应链。信息多来自公司公告和调研，时效性强，认证阶段变化要及时更新；“送样/试制”不要按已兑现标的处理。

### 11.1.4 从龙头的采购模式（总成还是零部件）推断受益环节

**方法要点**：先判断龙头整机厂的供应链组织方式——采购总成，还是采购零部件自己组装——再据此推断价值量更高、受益更直接的环节。

**操作步骤 / 拆分口径**

1. 判断龙头的采购模式：特斯拉倾向把执行器总成交给供应商生产，而不是采购零部件自己组装；灵巧手同样是总成思路。
2. 由此推出：总成供应商的价值量更高、受益更直接，零部件供应商的受益通过总成商间接传导。
3. 再结合产业链反馈的合作进展排序：进展较快的有新剑传动（手部丝杠及手部总成）、浙江荣泰（手部丝杠及手部总成）；有潜力的是特斯拉现有总成供应商，如拓普集团、三花智控。

**关键指标与数据来源**：采购模式（总成或零部件）、供应商合作进展、单机价值量；来源为龙头的公开表述、既有研究报告的结论和产业链调研。

**判断标准**

- 采购模式决定“谁拿价值量”：总成模式下，总成商拿整环节价值量；零部件模式下，价值量分散到各零部件商。
- 排序分两档：已有合作进展的（进展较快），和凭现有总成供应商身份具备潜力的。

**海豚案例**

- 人形机器人《人形机器人：为何灵巧手是迈不过去的门槛？》（2026-01-20）：承接三花智控报告中的总成判断，映射新剑传动、浙江荣泰（进展较快）与拓普集团、三花智控（有潜力）。

**适用场景与注意事项**：适用于由单一龙头主导的供应链映射。依赖产业链调研信息，量产定点前不确定性较高，需随定点与量产订单更新（供应链收敛风险见 11.2.7）。

### 11.1.5 从新增工艺步骤反推上游设备与材料受益方

**方法要点**：把新架构所需的新增或强化工艺步骤逐项列出，反推到对应的设备与材料供应商，找到向上游“卖水人”的受益映射，并同时标出受损或中性环节。

**操作步骤 / 拆分口径**

1. 对比新旧架构，列出新增或强化的工艺步骤。以长鑫的 4F² 垂直晶体管架构为例：大量新增选择性外延、原子层沉积（ALD）、快速热处理（RTP）、高深宽比刻蚀，以及混合键合等工艺步骤。
2. 把工艺步骤映射到设备商：潜在受益方包括应用材料、东京电子、泛林、ASMI、Eugene Tech。
3. 把新材料映射到材料商：钼、钌等新字线材料供应商（如默克）。
4. 指出受损或中性环节：首代 4F² 对光刻需求有所稀释，但后续节点仍需更小制程与尖端光刻。

**关键指标与数据来源**：工艺步骤数与类型、设备品类、新材料；来源为技术路线与工艺流程的拆解（存储赛道技术背景见 16.1）。

**判断标准**

- 新增/强化的工艺步骤越多、越集中在某一设备或材料品类，该品类的受益越直接。
- 要同时给出“谁被稀释”：首代对光刻需求稀释但并非终局，后续节点仍需尖端光刻，结论要分阶段。

**海豚案例**

- 半导体设备/材料《长鑫把晶体管「竖起来」：绕开 EUV 的追赶路，会撼动存储三巨头吗？》（2026-10-16）：4F² 需要的新增工艺步骤映射到应用材料、东京电子、泛林、ASMI、Eugene Tech 及钼、钌材料供应商（如默克）；光刻需求在首代被稀释，后续节点仍需要尖端光刻。

**适用场景与注意事项**：适用于任何架构或工艺变革向上游卖水人的映射（GAA、背面供电、HBM、3D DRAM 等）。设备商对不同存储类型的暴露差异另见 11.3.7。

### 11.1.6 上游供应链映射：剔除龙头垂直一体化内化的环节，寻找真正外采的可投资环节

**方法要点**：价值量大不等于可投资。找上游机会时，先看龙头的垂直一体化程度，把被内化的环节剔除，只在真正外采的环节里找标的；同时关注技术路线切换可能把内化环节变成外购环节。

**操作步骤 / 拆分口径**

1. 判断龙头的垂直一体化程度：SpaceX 高度垂直一体化；Blue Origin 发动机、箭体结构自研自产；Rocket Lab 把发动机、箭体、GNC 相关部件甚至部分复材都内化。
2. 逐环节判断“自制还是外购”，只保留外购环节：
   - 火箭环节：外部采购主要是大宗材料和芯片等部分电子器件。
   - 卫星端太阳翼：SpaceX、Rocket Lab 均自研自产；但若技术路线切换为硅基光伏电池，不排除外购。
   - 卫星端热管理部件：SpaceX 需外购材料和部件。
   - 卫星端激光通信：SpaceX 自研终端，但芯片、传感器、模组依赖外部供应商。
3. 给出可投资环节：大宗材料、电子器件、热管理材料与部件、激光通信的芯片/传感器/模组等。
4. 对内化环节设置“切换监测”：技术路线变化可能改变自制/外购属性。

**关键指标与数据来源**：各环节自制/外购属性、技术路线变化；来源为龙头公开披露、产业链调研与技术路线跟踪。

**判断标准**

- 被内化的环节没有外部受益者，不论其价值量多大都不构成投资标的。
- 路线切换会改变属性：自制环节在技术路线切换后可能变成外购环节（如太阳翼切到硅基光伏电池）。
- 结论形态：外采环节 = 可投资环节，内化环节 = 剔除，路线可能切换的环节 = 观察池。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：上游供应链“三类机会”的筛选就是按此法进行——火箭端外采以大宗材料和芯片等电子器件为主，卫星端按太阳翼、热管理、激光通信逐项判断自制或外购。

**适用场景与注意事项**：适用于龙头高度垂直一体化的行业（特斯拉、SpaceX、苹果自研芯片等）。自制/外购属性随龙头战略变化，需定期复核；映射后标的的稀缺性与跨市场落地见 11.1.9。

### 11.1.7 逐家影响映射：追赶者、领先者、第二名、落后者分别受何影响

**方法要点**：同一事件对处于不同位置的玩家影响不同，不能笼统写成“利好/利空行业”，而要按竞争位置逐家判断，作为个股相对强弱排序的依据。

**操作步骤 / 拆分口径**

1. 先把事件所涉的玩家按位置分类：追赶者、领先者、第二名、落后者。
2. 对每家分别回答：事件改变了它哪项能力（技术节点、良率、产品定位、成本密度）？短期和中期的影响是否不同？
3. 对中期影响单独设置跟踪条件（例如“某家修复执行后，领先幅度是否收窄”）。
4. 汇总成相对强弱排序，并按各家利润结构（HBM 还是常规 DDR）校准敏感度。

**映射示例（长鑫 4F² 事件）**

| 玩家 | 位置 | 影响判断 |
|---|---|---|
| 长鑫 | 追赶者 | 最大意义是找到绕开 EUV 的追赶路径，DUV 条件下获得接近对手的密度，叠加持续扩产与切入服务器 DDR5，常规 DRAM 竞争加剧 |
| 三星 | 制程与 4F² 相对领先 | 近几代 DRAM 良率问题拖累 HBM，但在制程与 4F² 上相对领先，可能“弯道超车” |
| SK 海力士 | 第二名 | 4F² 晚一个节点，但当前优势建立在 HBM 产品与客户上，短期影响不大；中期需关注三星借 4F² 修复 DRAM 与 HBM 执行后，海力士 HBM 领先幅度收窄 |
| 美光 | 落后者 | 此前侧重 3D DRAM，4F² 最晚（约 2030H2）；若三星与长鑫先跑通，将面临成本与密度相对劣势窗口 |

**关键指标与数据来源**：各厂技术节点、HBM 地位、良率、产品定位。

**判断标准**

- 影响方向由“事件改变了哪项优势、该优势在谁的利润结构里占比最大”决定，而不是由“是不是存储股”决定。
- 区分时间维度：短期（如海力士受 HBM 优势保护）与中期（三星执行修复后的追赶）可能给出不同结论。
- 推理链：事件 → 逐家能力变化 → 逐家利润结构敏感度 → 相对强弱。

**海豚案例**

- 存储《长鑫把晶体管「竖起来」：绕开 EUV 的追赶路，会撼动存储三巨头吗？》（2026-10-16）：逐家判断长鑫、三星、SK 海力士、美光的影响，如上表。

**适用场景与注意事项**：适用于行业技术变革下的个股相对强弱排序；应结合各家利润结构（HBM vs DDR）判断敏感度。竞争位置本身的定性见 8.2，追赶者能否追平的评估见 8.7。

### 11.1.8 按行业属性把政策变化映射到受益/受损板块

**方法要点**：政策冲击后，先用“行业属性”这一把尺子快速分出受益与受损板块，再用组合层面的股价表现验证，最后落到个股。

**操作步骤 / 拆分口径**

1. 识别政策的结构性变化：以关税为例，是“普遍关税受限”与“行业性关税加码”并存。
2. 设定分类标准：该行业是否关系到高端制造回流和战略产业。
3. 分类映射：
   - 一般性行业（玩具、纺服、出海电商平台、消费品）：受益，关税下降可以喘口气；
   - 战略与关键行业（高端制造等）：受损，232/301 行业性关税会更紧。
4. 用组合层面的股价表现验证：当周涨幅靠前的，是此前回落较多、又受益于关税削减的个股。
5. 进一步落到个股层面：美国收入占比和供应链转移能力。

**关键指标与数据来源**：行业对美出口依赖度、是否被列入 232/301 清单、个股周涨跌幅。

**判断标准**

- 受益/受损的分界由“行业是否属于战略与关键行业”决定：战略行业面临的是行业性关税继续收紧，一般性行业才是普遍关税削减的净受益者。
- 股价验证的逻辑：涨幅靠前的不是单纯的受益股，而是“前期回落多 + 受益于政策”的叠加。
- 板块映射只是第一步，个股的敞口要看美国收入占比和供应链转移能力。

**海豚案例**

- 中概/关税《特朗普关税“被废”、中国模型齐飞，中概能有狂欢吗？》（2026-02-23）：出海电商、消费品受益；Alpha Dolphin 组合当周领涨的是前期回落多、受益关税削减的标的。

**适用场景与注意事项**：适用于宏观政策冲击后快速筛选受益和受损标的。需进一步落到个股的美国收入占比和供应链转移能力；政策条款拆解与敞口排序的完整方法见 10.1，关税测算见 10.2。

### 11.1.9 可投资标的稀缺性判断与跨市场映射（美股稀缺转向 A 股/港股）

**方法要点**：映射完上游环节后，要检查标的“买不买得到”。如果主战场市场里独立上市的标的稀缺，就把映射转向另一市场里参与同一环节的上市公司。

**操作步骤 / 拆分口径**

1. 完成上游环节映射后，逐环节检查标的可得性：美欧相关供应环节的公司多在巨头旗下，或已私有化、尚未上市，独立上市公司较少。
2. 归因：过去几十年美欧制造业整合，专业制造公司已经不多，格局以巨型跨国企业为主。
3. 把仍可得的美股相关公司列表（图表呈现）。
4. 转向中国市场：多家上市公司参与上游部件和零件生产，可关注其港股上市机会，并附长桥股单链接。
5. 核实标的纯度（业务占比），避免把“沾边”当“主业”。

**关键指标与数据来源**：上市标的数量、业务纯度；来源为公司业务结构披露与上市进展。

**判断标准**

- 若独立上市的纯标的稀缺，主题的可投资性不在原市场，而在能参与上游部件/零件的跨市场公司。
- 标的纯度（业务占比）决定映射的有效性，需另行核实。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：给出上游供应链的美股公司表，同时指出中国市场有多家上市公司参与上游部件和零件生产、可关注其港股上市机会，并附长桥股单链接。

**适用场景与注意事项**：适用于主题投资的标的落地。标的纯度（业务占比）需另行核实；本方法回答“能不能买到”，不回答“值不值得买”，后者见 11.3 与 11.4。

### 11.1.10 行业判断 → 受益方向清单 → 股单（长桥 APP）映射

**方法要点**：行业分析的落点是一张“受益方向清单”，再链接到海豚君发布的股单。固定写法是：先产业逻辑，后标的表格，标的细节放在股单里持续更新。

**操作步骤 / 拆分口径**

1. 完成行业逻辑推导（如缺电）。
2. 把逻辑收敛成若干受益方向。以缺电为例的五大方向：
   1. 燃气发电、核电、SOFC 等高可靠电源建设；
   2. 电网侧和用户侧储能；
   3. 电网工程设备；
   4. 数据中心电源升级（HVDC/SST）；
   5. 液冷升级。
3. 文中给汇总图；具体公司与逻辑引向《AI 电力与能源股单》。
4. 下篇结尾再给“AIDC 发电，能源和设备股总结”表；商业航天篇同样以股单链接收尾。
5. 标的细节留在股单中持续更新，文章本身只保留产业逻辑和方向清单。

**关键指标与数据来源**：受益方向、对应公司、投资逻辑。

**判断标准**

- 方向清单要由前文的产业逻辑自然推出，不是先有股票再找理由。
- 文章负责“为什么是这些方向”，股单负责“具体是哪些公司、逻辑是什么、何时调整”。

**海豚案例**

- AI 电力《AI 终极瓶颈…》（2026-04-09）：五大受益方向 + 《AI 电力与能源股单》。
- AI 电力《AI 电荒突围》（2026-04-14）：文末“AIDC 发电，能源和设备股总结”表。
- 商业航天《SpaceX 的挑战者们》（2026-04-08）：文末股单链接。

**适用场景与注意事项**：适用于所有行业文。股单是动态的，需结合个股估值另行判断；方向清单不等于推荐清单。

### 11.1.11 文末核心标的汇总表 + 股单/附录，并链接前序深度

**方法要点**：系列文章的每一篇结尾都用统一表格整理核心标的，指向股单，已有深度的环节只链接不重复展开，补充数据放附录。从行业判断到个股的路径被固化为“环节价值量排序 → 确定性 → 环节内格局 → 标的表”。

**操作步骤 / 拆分口径**

1. 路径：先做环节价值量排序，再判断确定性，再看环节内格局（龙头和份额），最后落成标的表。
2. 表格字段：按环节、公司、市场、逻辑整理核心标的。
3. 指向“海豚君连接股单”；光模块、CPO、PCB 等其他环节的标的链接到之前的深度，避免重复。
4. 附录放补充数据表。

**关键指标与数据来源**：环节、公司代码、供应关系。

**判断标准**

- 表中每个标的必须能回答“它在哪个环节、该环节为什么排在前面、它在环节内的位置是什么”。
- 已有深度覆盖的环节直接链接，保证系列内部不重复、不矛盾。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：整理谷歌链核心资产。
- AWS《AWS 图省事…》（2026-10-12）：文末核心标的表、连接股单和附录。

**适用场景与注意事项**：适用于产业链系列研究的投资落地。环节价值量排序和确定性评估的具体方法见 11.3.2。

### 11.1.12 每个系列收尾汇总“核心资产表”，作为后续逐一跟踪的标的池

**方法要点**：各环节分析完之后，把入选标的汇总成核心资产表，并明确它是“后续逐一跟踪的标的池”，把行业研究平滑过渡到个股跟踪。

**操作步骤 / 拆分口径**

1. 先完成各环节分析，并与同类方案对比（如对比谷歌、AWS、华为的组网方案）。
2. 在此基础上，从产业链中挑出核心资产，汇总成核心资产表（图）。
3. 入选标准大致是四类：
   - 价值量高；
   - 定价权强（高端芯片、品牌交换机）；
   - 掌握供给瓶颈（预制棒、ABF 膜、HVLP 铜箔）；
   - 受益于技术迭代（PCB 高层板、光连接）。
4. 表中的标的作为跟踪池，后续逐一展开研究。

**关键指标与数据来源**：无单一指标，属研究组织方法；入选依据来自前文的价值量、定价权、供给瓶颈和技术迭代分析。

**判断标准**

- 入选的四类特征分别对应“量”（价值量）、“价”（定价权）、“稀缺”（供给瓶颈）、“趋势”（技术迭代）；满足的维度越多，越应排在跟踪池前列。
- 核心资产表不是买入清单，而是研究任务清单。

**海豚案例**

- AMD/英伟达机架《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：文末汇总 AI DC 互联核心资产表，并说明在对比谷歌、AWS、华为的组网方案之后，再从产业链中挑出核心资产逐一跟踪。

**适用场景与注意事项**：用于从行业研究过渡到个股跟踪池；后续跟踪的验证指标设计见 13.1、13.2。

**本节速查清单**

- [ ] 是否按产业角色（定义者→落地制造→器件→组件→设备）或功能环节把参与者分层，并为每一层写出关注点与弹性、风险判断？
- [ ] 是否跟踪了巨头的战略投资、收购、联盟，并把“是否获注资/深度绑定”列为比较维度，同时提示被背书标的估值已较高？
- [ ] 每个外采器件是否列出了全球与国内供应商，并标注独家/主供/二级/白名单/送样/试制，区分“已兑现”与“期权型”？
- [ ] 是否判断了龙头的采购模式（总成 vs 零部件）和垂直一体化程度，并剔除了被内化、无外部受益者的环节？
- [ ] 对架构/工艺变革，是否逐项列出新增工艺步骤并映射到设备与材料，同时标出受损或中性环节？
- [ ] 同一事件是否按追赶者、领先者、第二名、落后者逐家判断，并区分短期与中期影响？
- [ ] 政策变化是否按行业属性（战略 vs 一般性行业）映射受益/受损板块，并落到美国收入占比等个股敞口？
- [ ] 是否检查了标的的可得性与业务纯度，必要时做跨市场映射？
- [ ] 收尾是否给出方向清单、核心资产表/标的汇总表和股单链接，并说明入选标准与后续跟踪安排？

## 11.2 方案迭代与情景下的增减量映射

> 本节导读：本节解决“同一赛道里方案在变，标的会怎么分化”的问题。先比较两套竞争方案的供应链重合度——只有差异环节才会出现标的分化；再按方案迭代列出增量与减量环节，对同时有新旧业务敞口的公司测算净效应；客户下一代路径不确定时，用分支情景映射供应商归属，并按 SKU 出货结构判断“量”到底依赖谁；最后用设计取舍的二阶效应前瞻增量环节，并提示验证期到量产期的供应链收敛风险。基础的标的分层映射见 11.1，环节排序与选股准则见 11.3，技术路线比较见第 6 章（6.1、6.6），事件冲击与预期差见 12.1、12.3。

### 11.2.1 分析供应链重合度：找出两套方案的共用环节和差异环节，只有差异环节才会出现标的分化

**方法要点**：比较两套竞争方案时，先看它们的供应链有多少是重合的。共用环节受益于两家的总出货，不随单一方案成败分化；只有差异环节才会因某一方案胜负而产生标的分化。

**操作步骤 / 拆分口径**

1. 把两套方案的硬件规格并排对比。例子中两家机架的规格已经接近：都是 3.6TB/s、200G SerDes、铜缆背板加多层 PCB。
2. 按环节列出两边的供应商名单，标出高度重合的共用环节：基板、PCB、液冷、电源。
3. 找出差异环节：① 交换芯片，AMD 用博通；② 整机组装，英伟达用鸿海、广达，AMD 用 Sanmina、Celestica、HPE 等偏美链的组装厂。
4. 分别处理：共用环节按“两家总出货”的逻辑选标的，选股的重点是看环节格局；差异环节才作为单一方案成败的押注。

**关键指标与数据来源**：各环节供应商名单、重合度；来源为两套方案的规格披露和供应链调研。

**判断标准**

- 共用环节：受益逻辑与“谁赢”无关，只与整体组网规模和环节自身格局有关。
- 差异环节：标的表现与单一方案的成败高度相关，是方案分化的押注点。
- 推理链：规格趋同 → 供应链重合 → 分化只发生在少数差异环节。

**海豚案例**

- AMD/英伟达机架《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：两套机架方案的供应链重合度分析——基板、PCB、液冷、电源高度重合，差异在交换芯片与整机组装。

**适用场景与注意事项**：适用于从竞争方案映射供应链标的。重合度越高，越不应把“押某一方案”的逻辑套到共用环节标的身上。

### 11.2.2 按方案迭代映射增量与减量：AMD 链新增交换托盘，英伟达链“铜退、PCB 与光进”

**方法要点**：以方案变化为线索梳理价值转移，逐条写出“哪个环节增量、哪个环节减量、谁是直接受益标的、谁是长期替代者”。

**操作步骤 / 拆分口径**

1. 描述方案变化：AMD 的 Helios 让 AMD 从单板 8 卡走到跨板 72 卡；英伟达取消计算托盘与交换托盘之间的飞线。
2. AMD 链的增减量：
   - 增量：交换托盘和 Scale-up 层是最直接的增量。
   - 直接受益标的：博通（供应以太网 Retimer 和交换芯片）、安费诺（提供从连接器到铜缆的整体方案）。
   - 长期替代风险：UALink 原生芯片将由 Marvell、Astera Labs 供应，构成对博通交换芯片的替代；谷歌的 OCS 在设计之初也是博通 Spine 交换机的替代。
3. 英伟达链的增减量：
   - 取消计算托盘与交换托盘之间的飞线，PCB 的面积和强度提升，即“铜退、PCB 与光进”。
   - PCB 的量价齐升逻辑：量来自组网规模扩大带动机架数量增长，价来自层数和材料升级。
   - 更长期：Kyber 机架用 PCB 中板替代柜内铜缆，继续利好 PCB、利空柜内铜连接。
4. 用一句话概括价值转移，便于后续跟踪，例如“柜内模块化，板代线；柜外 GPU 加量，光代铜”。

**关键指标与数据来源**：各环节增减量、ASP 变化。

**判断标准**

- 增量环节：接口数、面积、层数、规格上升的环节；减量环节：被取消、被替代的环节。
- 量价分拆：增量必须说明“量”从哪来、“价”从哪来（如 PCB 的量来自机架数、价来自层数和材料升级）。
- 近端受益与远期替代要分开写：同一环节可能近期是直接受益、远期却面临替代（如博通交换芯片）。

**海豚案例**

- AMD/英伟达机架《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：“柜内模块化，板代线；柜外 GPU 加量，光代铜”的产业链梳理，覆盖 AMD 链交换托盘与 Scale-up 增量、英伟达链铜退、PCB 与光进。

**适用场景与注意事项**：适用于产品迭代驱动的供应链研究。同一公司多空交错时，用 11.2.3 测算净效应；环节价值量排序见 2.3。

### 11.2.3 识别新路线对同一公司现有主业的反向冲击，并测算多空交错的净效应

**方法要点**：映射受益标的的同时，要检查同一家公司是否也是被替代的对象。做法是列出“增量项”和“减量项”，判断净值为正、为负还是中性。

**操作步骤 / 拆分口径**

1. 对每个受益标的，列出它在新路线中的增量项（新产品、ASP、接口数）。
2. 同时列出它在旧路线中的主业，并检验新路线是否会替代这部分主业（减量项）。
3. 量化各增减项的相对大小：收入敞口、ASP 变化、接口数量变化。
4. 给出净效应：正、负或中性，并写出长期变化。

**示例：安费诺和 TE Connectivity**

| 场景 | 增量项 | 减量项 / 风险 | 净效应 |
|---|---|---|---|
| CPO | 能供应 MPO、Fiber Shuffle 等 | 主战场是英伟达 Scale-up 环节的铜互连；若未来 Scale-up 也切到 CPO，反而利空其主业空间 | 需持续关注 Scale-up 是否切光 |
| Helios 篇（Vera Rubin 对照） | 计算托盘内连接器 ASP 更高、接口数明显增加；背板铜缆方案（含连接器）仍由安费诺主供 | Vera Rubin 取消飞线（无源铜缆），利空安费诺 | 多空交错，整体偏中性 |
| 更长期 | Kyber 机架用 PCB 中板替代柜内铜缆：利好 PCB | 利空柜内铜连接 | 铜连接长期承压 |

**关键指标与数据来源**：公司在新旧路线下的收入敞口、ASP 变化、接口数量变化。

**判断标准**

- 不能只看增量：新路线让公司获得新产品并不等于净受益，要和被替代的主业收入对冲后再下结论。
- 对冲关系：如“取消飞线”的减量被“连接器 ASP 更高、接口数增加”部分对冲，背板铜缆方案主供不变，故整体偏中性。
- 关键是量化各增减项的相对大小，否则“多空交错”无法落成结论。

**海豚案例**

- CPO 行业《“‘铜’ 牛夫人” 不走！CPO》（2026-06-24）：提示安费诺、TE 的 Scale-up 铜互连风险——它们在 CPO 里能供应 MPO、Fiber Shuffle 等，但主战场的铜互连可能被 CPO 侵蚀。
- AMD/英伟达机架《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：安费诺多空交错，整体中性。

**适用场景与注意事项**：适用于在技术迭代中同时有新旧业务敞口的公司。结论取决于对增减项相对大小的量化，数据不足时应只给“方向性”判断并标注不确定性。

### 11.2.4 按下一代技术路径分支，映射交换芯片供应商的归属（情景映射）

**方法要点**：当供应商份额高度依赖客户的设计选择时，把客户下一代可能的技术路径逐条列出，并把每条分支对应的受益方和受损方写清楚，事件一发生就能快速更新判断。

**操作步骤 / 拆分口径**

1. 确认当前代的供应结构：Trn3 生命周期内以采购标品为主，交换芯片核心供应商是 Astera Labs；下一代交换托盘芯片可能转向高通（另有点评）。
2. 列出下一代（Trn4）的分支路径，并为每条分支写出对应的供应商归属：
   - 若走 NVLink Fusion：交换芯片可能依赖英伟达的 NVSwitch；
   - 若走 UALink：可能让位于 AMD 体系（芯片由 Marvell 和 ALAB 共同研发）。
3. 对每条分支写出受益方与受损方，形成“路径 → 受益/受损”对照表。
4. 事件（客户宣布路线、芯片发布）出现后，直接选中对应分支并更新判断。

**关键指标与数据来源**：各技术路径的可能性、各分支对应的供应商。

**判断标准**

- 分支映射不预测“哪条路径一定发生”，而是提前准备好“发生后谁受益、谁受损”。
- 当前代与下一代的供应商可能不同，不能把当前代的主供外推到下一代。

**海豚案例**

- AWS《AWS 组网靠「买」…》（2026-10-13）：Trn3 以采购标品为主、交换芯片核心供应商 Astera Labs；Trn4 按 NVLink Fusion、UALink 两条分支映射交换芯片供应商归属。

**适用场景与注意事项**：适用于供应商份额高度依赖客户设计选择的环节。若要检验各环节“不论走哪条路都受益”的确定性，参见 11.3.2。

### 11.2.5 从客户方案迭代推演供应链变化，并按训练/推理出货结构判断链条风险

**方法要点**：从客户自己的方案演进推导对供应链的影响，再结合负载结构（训练 vs 推理）判断“量”依赖哪个 SKU，从而识别链条风险。

**操作步骤 / 拆分口径**

1. 推导方案演进对供应链的影响：
   - 计算托盘里最核心的下一代 TPU ASIC 将引入联发科；
   - v8t 延续 v7 拓扑，预计产业链变化不大；
   - v8i 为推理优化，硬件升级带来单位价值量提升，但 Boardfly 拓扑的互连器件用量普遍更少。
2. 结合负载结构判断风险：
   - v8t 折到单位算力，网络成本高于 Vera Rubin，并不是性价比之选；
   - 推理已占 AI 加速器周期 70% 以上，TPU 从训推一体走向分化后，如果 8t 出货不及预期，对谷歌链（尤其是光模块这类配比高的环节）是利空。
3. 核心动作：分析“量”依赖哪个 SKU，再回到每芯片器件用量，判断各环节受影响的程度。

**关键指标与数据来源**：SKU 出货结构（训练 vs 推理）、每芯片器件用量、单位价值量。

**判断标准**

- 单位价值量上升不等于总需求上升：还要看对应 SKU 的出货量和每芯片器件用量（如 v8i 价值量提升但互连器件用量更少）。
- 配比高的环节（如光模块）对训练 SKU 出货更敏感，该 SKU 不及预期就是链条风险点。
- 性价比判断（单位算力网络成本）影响客户 SKU 的出货预期，是出货结构判断的输入。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：按 v8t/v8i 的拓扑、价值量与用量差异推演供应链变化，并据推理占比与 8t 出货风险判断谷歌链的风险。

**适用场景与注意事项**：适用于客户产品线分化时判断供应商需求。需要持续跟踪各 SKU 的出货量。

### 11.2.6 设计取舍的二阶效应推导：方案缺陷 → 可能的修正 → 零部件受益或受损

**方法要点**：不只分析当前方案，而是分析当前方案的副作用，推演整机厂可能的修正方向，再判断这些修正对各环节的受益与受损，从而前瞻地发现增量环节。

**操作步骤 / 拆分口径**

1. 描述当前设计取舍的收益：特斯拉把大量执行器集中在手臂，可以缩小手部体积、增加自由度。
2. 列出副作用：结构复杂、控制延迟、热积聚。
3. 推演可能的修正，并映射到零部件：
   - 暂时牺牲部分手指自由度：对部分执行器零件不利；
   - 增加热管理配置：对热管理模块供应商有利。
4. 归纳硬件迭代的六个方向：
   1. 继续降本；
   2. 感知足够灵敏精确，这是大模型算法有效的前提；
   3. 集成度与性能兼顾，整个动力传导结构仍不确定；
   4. 材料兼顾柔性、准确性、寿命；
   5. 热管理可能成为增量环节；
   6. 关注环节之间的相互补偿（如腱绳误差可以靠算法纠错或增加位置传感器反馈来弥补）。

**关键指标与数据来源**：自由度、延迟、发热、成本、位置传感器数量。

**判断标准**

- 修正方向要从副作用出发，而不是凭空想象：每个副作用对应一个可能的修正，每个修正对应一批受益/受损零部件。
- 要看环节间的相互补偿：一个环节的缺陷可能被另一环节补上，决定哪个环节才是真正的增量。
- 海豚君的原则：只有知道了是什么和为什么，才能前瞻地判断未来可能的变化。

**海豚案例**

- 人形机器人《人形机器人：为何灵巧手是迈不过去的门槛？》（2026-01-20）：从执行器集中在手臂的副作用推出牺牲手指自由度、增加热管理的修正，总结硬件迭代六个方向，并指出“只有知道了是什么和为什么，才能前瞻地判断未来可能的变化”。

**适用场景与注意事项**：适用于技术路线未收敛的赛道。用于前瞻发现增量环节（如热管理），也用于规避被替代的环节。

### 11.2.7 供应链收敛风险：从验证期的多家参与到量产期每环节 2-3 家

**方法要点**：研发验证阶段每个硬件环节都有多家公司参与，进入量产后，整机厂在每个环节的实际供应商只有 2-3 家，没进入供应链的企业将面临预期落空；因此“量产节点”本身就是预期分化的风险点。

**操作步骤 / 拆分口径**

1. 统计各环节参与验证的供应商数量，对比量产期整机厂的实际供应商数量（经验上 2-3 家）。
2. 标记谁拿到了定点和量产订单，谁仍停留在验证阶段。
3. 检查硬件公司的估值溢价：主机厂大多未上市，部分上市硬件公司成了市场流动性的“蓄水池”，估值里包含了大量预期。
4. 对照整机厂的量产规划：按特斯拉的规划，2026 年产业进入量产阶段，恰恰是供应链收敛、预期分化的风险点。

**关键指标与数据来源**：各环节供应商数量、定点和量产订单、硬件公司估值溢价。

**判断标准**

- 验证期的“参与”不等于量产期的“进入”：没有定点或量产订单的公司，其估值里的预期存在落空风险。
- 估值越是依赖“蓄水池”效应（预期而非订单），收敛期的下行风险越大。
- 量产定点是关键验证节点。

**海豚案例**

- 人形机器人《人形机器人：为何灵巧手是迈不过去的门槛？》（2026-01-20）：提示 2026 年量产带来供应链收敛风险。

**适用场景与注意事项**：适用于主题炒作期的零部件股。量产定点是关键验证节点；与 11.1.4 的采购模式推断配合使用。

**本节速查清单**

- [ ] 两套方案的规格是否已趋同？共用环节与差异环节是否分开处理，只在差异环节押注单一方案成败？
- [ ] 方案迭代带来的增量环节与减量环节是否逐条列出，增量是否拆成“量”和“价”？
- [ ] 同一家公司在新旧路线下是否同时列出增量项与减量项，并量化相对大小、给出正/负/中性的净效应？
- [ ] 客户下一代技术路径不确定时，是否为每条分支写出对应的受益方与受损方？
- [ ] 是否分析了“量”依赖哪个 SKU（训练 vs 推理），并检查了单位价值量与每芯片器件用量的变化？

## 11.3 环节排序、标的比较与选股准则

> 本节导读：本节解决“映射出一堆环节和公司之后，怎么取舍”的问题，分三组：环节之间怎么排序（成长性准则、价值量×确定性、最紧缺环节、发射>运营>上游）；同一环节内的标的怎么比（六维横比、新业务占体量的弹性、设备商对不同产品的暴露、周期行业选一体化龙头）；周期位置与资金偏好下怎么选（增量 vs 存量驱动、错配期优选先建大厂、按 AI 回报轨迹给巨头排序、从巨头注意力推导中小企业机会）。环节价值量的测算见 2.3，供需与周期位置见第 5 章，标的分层映射见 11.1，估值是否已反映见 11.4，竞争格局与壁垒见第 8 章。

### 11.3.1 成长性排序准则：新增环节优于存量升级环节，格局松动环节优于传统巨头把持的环节

**方法要点**：在多个受益环节之间排序时，海豚君用两条准则——是否为新增环节、格局是否给新玩家留出空间——判断各环节的成长性优先级；高度集中的环节则被归入“定价权”而非“成长弹性”。

**操作步骤 / 拆分口径**

1. 准则①：这是新增环节还是存量升级环节？新增的瓶颈环节成长性强于仅仅升级的环节。
2. 准则②：格局是否给新玩家留出空间？由传统巨头把持的环节成长性弱于格局松动、有新进入者机会的环节。
3. 对格局高度集中的环节，换用“定价权”口径，而不是“成长弹性”口径。
4. 结合估值使用（排序只回答“哪个环节更优先”，不回答“贵不贵”）。

**排序示例（CPO 与交换芯片）**

| 环节 | 是否新增 / 价格变化 | 格局 | 判断 |
|---|---|---|---|
| 耦合设备 | CPO 新增的瓶颈环节 | — | 成长性强于测试设备 |
| 测试设备 | 只是升级 | — | 成长性弱于耦合设备 |
| 激光器 | 单价大增 | CW 路线给了新进入者机会 | 成长性较强 |
| 光纤组件 | — | 优势企业仍是康宁、安费诺、TE 等传统巨头 | 成长性可能弱于激光器板块 |
| 交换芯片 | — | 格局高度集中（博通约 70%） | 受益方式是定价权，而不是成长弹性 |

**关键指标与数据来源**：环节是否为新增、份额集中度、新进入者订单。

**判断标准**

- 新增环节 > 存量升级环节；格局松动环节 > 传统巨头把持环节。
- 集中度极高的环节不靠“放量成长”，而靠“定价权”获利，评价维度要换。
- 单价是否大增、路线是否给新玩家入口，是判断“格局是否松动”的具体观察点。

**海豚案例**

- CPO 行业《“‘铜’ 牛夫人” 不走！CPO》（2026-06-24）：对设备和光纤组件环节的成长性评价——耦合设备（新增瓶颈）优于测试设备（升级）；光纤组件由传统巨头把持，成长性可能弱于激光器板块。
- AMD/英伟达机架《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：交换芯片格局高度集中（博通约 70%），受益方式是定价权而非成长弹性。

**适用场景与注意事项**：用于赛道内细分环节的优先级排序，需结合估值使用。集中度与格局的口径见 8.1、8.4。

### 11.3.2 供应链多元时按“价值量 × 确定性”二维评估环节，确定性用下一代多路径情景检验

**方法要点**：当供应链高度多元（如客户以采购标品为主）时，单看哪个环节“有价值量”不够，要用“价值量 × 确定性”二维评估，并用下一代多路径情景去检验确定性，最后选“不论走哪条路都赢”的环节。

**操作步骤 / 拆分口径**

1. 第一步排单柜价值量：铜连接最大，PCIe Retimer 最小。
2. 第二步从方案迭代角度评估确定性：列出下一代（Trn4）的几条可能路径——继续 PCIe Gen7、NVLink Fusion、UALink。
3. 检验每个环节在各路径下是否都受益。
4. 按“所有路径都受益 → 部分路径受益 → 可能被替换/优化掉”给出排序。

**检验结果（AWS 下一代）**

| 排序 | 环节 | 确定性依据 |
|---|---|---|
| 1 | PCB | 确定性最强：走 PCIe 则 Gen7 对板材压力更大；走 NVLink 或 UALink 则 200G 需要 M9 及以上材料，板材升级是刚性的 |
| 2 | 光连接 | 大规模组网下，Scale-Out 让光的确定性和价值量双升 |
| 2 | 铜连接 | 以柜内为主，AWS 是 AEC 的忠实用户，但不能排除跨柜改走光 |
| 3 | 交换 | 供应商可能更换 |
| 4 | PCIe Retimer | 价值量不高，可被板材替代；当前必需，但可能被优化掉 |

**关键指标与数据来源**：单柜价值量、各路径下的需求变化方向。

**判断标准**

- 价值量决定“能不能赚到钱”，确定性决定“赚钱的前提是否稳固”，两者相乘才是环节优先级。
- 确定性的检验方式是“逐路径过一遍”：每个环节在每条路径下需求是否都上升；刚性需求（如板材升级）排在最前。
- 价值量小且可被替代的环节排在最后。

**海豚案例**

- AWS《AWS 图省事…》（2026-10-12）、《AWS 组网靠「买」…》（2026-10-13）：AWS 采购标品既压低成本，也意味着供应链高度多元，故按“单柜价值量 + Trn4 多路径确定性”排序，结论为 PCB > 光连接/铜连接 > 交换 > PCIe Retimer。

**适用场景与注意事项**：适用于技术路线未定时做产业链配置，思路是选“不论走哪条路都赢”的环节。路径可能性的情景映射见 11.2.4。

### 11.3.3 电网侧受益链：按“最紧缺环节”排序设备超级周期

**方法要点**：在受益链里找交付周期最长、供给最刚性的环节，把它作为弹性最大的投资方向。

**操作步骤 / 拆分口径**

1. 从需求根因出发，推导设备需求。逻辑链：并网拥堵（部分区域等 7 年）→ 根因是电网老旧和不通 → 输电扩容 → 设备需求 → 找最紧缺设备。
2. 列出直接拉动的设备：电力变压器（电网心脏）、高压开关/断路器、铜铝线缆。
3. 在这些设备里找交付瓶颈最严重的环节：变压器，判定为“产业链最紧缺的一环”。
4. 以此作为弹性最大的方向，推出“设备超级周期”。

**关键指标与数据来源**：并网排队时长、变压器交付周期、电网资本开支。

**判断标准**

- 电网扩容和改造是长期必选项；受益链里交付周期最长、供给最刚性的环节弹性最大。
- “最紧缺”由交期和积压数据证明，不是凭印象判断。

**海豚案例**

- AI 电力《AI 终极瓶颈…》（2026-04-09）：电网侧推导出变压器、高压开关、铜铝线缆的“超级周期”，变压器为最紧缺环节。

**适用场景与注意事项**：适用于基建和设备类产业链。前提是能拿到交期或积压数据。本文对电网侧只做定性映射，没有展开测算；供给瓶颈的量化方法见 4.4。

### 11.3.4 赛道内环节排序（发射 > 运营 > 上游）与“龙头 + 追赶者”并行配置的论证

**方法要点**：在新兴赛道里，先把环节按“机会如何看”分成几类并排序，再对排第一的环节论证“龙头 + 追赶者”并行配置，要求正反两面论证龙头壁垒和追赶者空间。

**操作步骤 / 拆分口径**

1. 环节排序一：火箭发射公司优先。
   - 可回收大幅降低成本、加速需求，完全可回收“只是时间问题”。
   - 行业难以独家垄断：SpaceX 趟出可行路线，后来者参考后研发周期缩短；贝索斯虽慢也取得阶段性成功；需求方不接受一家独大，会扶持竞对。
   - 但 SpaceX 仍明显领先：Starship 若完全可回收，发射成本会再次断代领先；Starlink 的网络效应也维持先发壁垒。
   - 结论：同时关注 SpaceX 和追赶者；追赶者首选 Rocket Lab（技术领先性、快速迭代、政府军事卡位），催化剂是 Neutron 首发进展。
2. 环节排序二：星座运营公司排在发射之后。LEO 运营商在 SpaceX、Blue Origin 压顶下，核心观察点是价格、性能、服务上的差异化；传统 GEO 运营商面临 LEO 全面挑战，看转型进展；附美股上市卫星运营公司表。
3. 环节排序三：上游供应链，按 11.1.6 的“剔除内化环节”方法筛选。

**关键指标与数据来源**：技术领先度、网络效应、政府订单卡位、关键催化剂（Neutron 首发）。

**判断标准**

- 排序依据：谁决定成本曲线（发射）> 谁依赖成本曲线（运营）> 谁给前两者供货（上游，且大部分被内化）。
- “龙头 + 追赶者”并行的论证要同时满足：龙头为什么仍然领先（技术断代、网络效应）、追赶者为什么仍有空间（路线已被验证、需求方扶持竞对）。
- 追赶者需有明确的催化剂节点（如 Neutron 首发）来验证。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：第三章“机会如何看”，按发射 > 运营 > 上游排序，并论证 SpaceX 与追赶者 Rocket Lab 并行关注。

**适用场景与注意事项**：适用于蓝海行业的标的选择。要正反两面论证龙头壁垒和追赶者空间；追赶者的追平判断见 8.7，商业航天赛道要点见 16.7。

### 11.3.5 同环节标的六维横比：技术积累、产能扩张、业务纯度、客户/路线绑定、进入者位置、估值反映

**方法要点**：对同一环节的多个标的，从六个固定维度做横向比较，把“谁弹性更大、谁更确定、谁已被定价”放在同一张表里对照。

**操作步骤 / 拆分口径**

1. 技术与产能积累：各家在核心技术路线上的积累与能力边界。
2. 产能扩张：产能规划与扩充比例。
3. 业务纯度：核心业务占比，是专注型还是综合型。
4. 客户与路线绑定：是否获巨头注资、是否是关键路线的核心供应商、是否绑定大客户。
5. 进入者位置：是龙头、追赶者还是后进者，收入兑现程度。
6. 估值反映：巨头注资与公司乐观指引后，市场是否已充分反映空间与弹性。

**六维对照（Lumentum / Coherent / AAOI）**

| 维度 | Lumentum | Coherent | AAOI |
|---|---|---|---|
| ① 技术与产能积累 | EML 路线的 InP 激光器芯片积累深厚，也能做 CW | 同左 | — |
| ② 产能扩张 | 2026 年规划产能扩充 50% | — | — |
| ③ 业务纯度 | 更专注光通信，弹性更大 | 从材料、器件到系统一体化，还有半导体和工业等传统业务；凭 VCSEL 和硅光积累有机会参与 CPO 方案设计 | — |
| ④ 客户与路线绑定 | 获英伟达注资；谷歌 OCS 的核心供应商，看好 OCS 路线的话也是重要标的 | 获英伟达注资 | 与微软等大客户绑定 |
| ⑤ 进入者位置 | — | — | 传统主业是有线电视宽带设备，后进者，竞争力和客户上都处劣势，收入尚未充分兑现，但弹性大 |
| ⑥ 估值反映 | 英伟达注资加公司乐观指引，市场已充分反映空间与弹性，整体估值偏高 | 同左 | — |

**关键指标与数据来源**：InP 晶圆产能、产能扩充比例、光通信收入占比、核心客户、获巨头注资情况、估值水平。

**判断标准**

- 前五维决定“质地与弹性”，第六维决定“还有没有赔率”；高质地但已被充分定价的标的，不能直接给出买入结论。
- 业务纯度越高，弹性越大（如 Lumentum 优于综合化的 Coherent）；后进者弹性大但兑现度低（AAOI）。
- 路线绑定要和路线本身的判断一致：看好 OCS 路线时，Lumentum 才是重要标的。

**海豚案例**

- CPO 行业《“‘铜’ 牛夫人” 不走！CPO：真机会 or 镜中花？》（2026-06-24）：Lumentum、Coherent、AAOI 三家按六维比较，结论是 Lumentum、Coherent 空间与弹性已被市场充分反映、整体估值偏高，AAOI 弹性大但处于后进者位置。

**适用场景与注意事项**：适用于同一细分环节内的选股。要形成买卖决策，还需补充估值倍数和一致预期（见 11.4）。

### 11.3.6 按新业务占公司体量判断弹性：大平台看“护城河加固”，中小公司看“业绩弹性”

**方法要点**：同样受益于一项新技术，各公司的弹性取决于新业务相对公司体量有多大。大平台关注的是新技术对主业的防守价值，而不是业绩弹性。

**操作步骤 / 拆分口径**

1. 估算新业务（增量价值量）相对公司现有收入的比例，并评估盈利质量。
2. 公式：弹性 ≈ 增量收入占现有收入的比例 × 盈利质量。
3. 对大平台，改看防守价值：新技术是主业的潜在障碍（量产失败可能拖累整体 Capex 节奏），还是护城河的加固工具。
4. 逐家判断并给出排序（如下）。

**逐家判断（CPO 为例）**

| 公司类型 | 公司 | 判断 |
|---|---|---|
| 定义者 | 英伟达 | CPO 单环节价值量相对其整体太小，对它更多是生态竞争力和供应链保障，而不是弹性来源 |
| 定义者 | 博通、Marvell | 弹性大于英伟达 |
| 晶圆制造 | 台积电 | CPO 难以成为独立业务，弹性有限，但能进一步加固从晶圆制造到先进封装的护城河 |
| 封测 | 日月光、Amkor | 若能承接 CPO 后端工序，能提供一定弹性 |
| 激光器 | Lumentum | 比综合化的 Coherent 更专注光通信，弹性更大 |
| 激光器 | AAOI | 作为后进者劣势明显，但弹性也大 |

**关键指标与数据来源**：新业务收入占比、业务纯度、增量价值量与公司收入之比。

**判断标准**

- 体量越小、新业务占比越高，业绩弹性越大；体量越大，新业务越应被视为“防守或加固”而非“弹性”。
- 大平台分析的关键问题是：新技术量产失败会不会拖累整体 Capex 节奏？还是在加固护城河？
- 弹性高不等于值得买，要结合估值是否已反映（如 Lumentum、Coherent 估值已相对较高）。

**海豚案例**

- CPO 行业《“‘铜’ 牛夫人” 不走！CPO：真机会 or 镜中花？》（2026-06-24）：逐一判断英伟达、博通/Marvell、台积电、日月光/Amkor、Lumentum/Coherent/AAOI 的弹性。

**适用场景与注意事项**：用于选股阶段给标的排序。要结合估值是否已反映，例如文中提到 Lumentum、Coherent 的估值已相对较高。

### 11.3.7 映射设备商对不同存储类型的暴露，比较周期弹性

**方法要点**：把各家设备商的优势工艺对应到不同产品类型（存储类型），据此判断在不同扩产场景下哪家弹性更大、哪家更稳健。

**操作步骤 / 拆分口径**

1. 梳理产品类型对工艺的依赖：DRAM/HBM 更依赖沉积、CMP、先进封装；3D NAND 依赖高深宽比刻蚀，堆叠层数增加时刻蚀投入是非线性增长。
2. 梳理各家设备商的优势工艺与份额，以及在各存储类型上的收入占比。
3. 设想扩产场景：是 DRAM 扩产还是 NAND 扩产？
4. 得出弹性与稳健性判断：看谁的优势工艺对应当期扩产的品类。

**关键指标与数据来源**：设备商在各工艺的份额、存储类型收入占比、NAND 层数。

**判断标准**

- DRAM 扩产场景：存储收入主要来自 DRAM 的设备商增长更稳健（AMAT）。
- NAND 扩产场景：在高深宽比刻蚀上垄断的设备商弹性更大，层数从 232 层升到 300 层以上，刻蚀投入非线性增长（拉姆研究）。
- 推理链：产品类型 → 依赖的工艺 → 设备商的优势工艺 → 扩产品类决定弹性。

**海豚案例**

- AMAT（2026-02-13）：AMAT 的存储收入主要来自 DRAM，增长更稳健；拉姆研究在 3D NAND 高深宽比刻蚀上绝对垄断，层数从 232 层升到 300 层以上，刻蚀投入非线性增长，NAND 扩产时弹性更大。

**适用场景与注意事项**：半导体设备行业比较；与 11.1.5（新增工艺步骤→设备映射）配合使用，存储赛道背景见 16.1。

### 11.3.8 技术壁垒“有一些但不强”的周期行业：选拥有上游瓶颈自有产能或全产业链一体化的龙头

**方法要点**：对壁垒中等、新玩家能够进入的周期行业，选股准则是看垂直一体化能力——到产能出清阶段，拥有上游瓶颈自有产能或全链条整合的龙头，能凭议价能力和成本优势胜出。

**操作步骤 / 拆分口径**

1. 判断行业壁垒：技术壁垒“有一些但不强”，新玩家能够进入。
2. 判断周期阶段：涨价阶段大家都受益；供给增加、价格回落时，利润要靠成本与议价能力留住。
3. 筛选一体化龙头：看是否拥有预制棒自有产能或全链条整合。
4. 具体建议关注：长飞光纤、康宁、亨通光电。

**关键指标与数据来源**：上游自有产能比例、成本曲线位置、一体化程度。

**判断标准**

- 逻辑：涨价阶段大家都受益 → 供给增加、价格回落 → 只有掌握最上游瓶颈且有成本优势的公司才能留住利润。
- “自有产能”和“成本曲线位置”是核心判据，一体化程度越高，周期下行阶段越有安全边际。

**海豚案例**

- AMD/英伟达机架《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：光纤环节建议关注长飞光纤、康宁、亨通光电。

**适用场景与注意事项**：适用于周期性制造业的选股，需结合成本曲线数据。周期位置与拐点识别见 5.4，价格持续性见 5.3。

### 11.3.9 区分增量驱动与存量驱动：Capex 见顶对上游硬件是收入下滑，对云厂只是增速放缓

**方法要点**：从行业判断推到投资偏好时，先区分标的收入是由“增量建设”驱动还是由“存量资产”驱动——同样的 Capex 见顶，对上游硬件和对云厂的含义完全不同。

**操作步骤 / 拆分口径**

1. 区分收入驱动：上游硬件商的收入取决于算力建设的增量，云厂收入基于算力存量。
2. 推出含义：Capex 见顶对硬件商意味着收入同比下滑，对云厂只意味着增速放缓。
3. 对上游硬件，论证“双重利空”：
   - 议价权下降：云厂自研芯片的绝对性能已追上旗舰 GPU、相对能效可能已反超，对外部芯片的依赖下降，芯片商为留住客户必须让利；
   - Capex 可能在 2027 年见顶。
4. 对云厂，论证“有好有坏”：
   - 大幅降 Capex、恢复现金流的利好，可能比收入增速下降的利空更受市场重视；
   - 算力阶段性过剩时竞争格局恶化，表现会分化，能强绑定 AI Lab 的云厂收入增速甚至可能上调；
   - 整体议价权走低，云租价大概率从溢价转为折价，拖累利润率（部分被芯片效率提升对冲）。
5. 提醒：硬件内部要区分，存储目前仍是主要瓶颈。

**关键指标与数据来源**：Capex 增速、云收入增速、自由现金流、云租价溢价/折价、自研芯片性能对比。

**判断标准**

- 增量驱动型：Capex 见顶 = 收入下滑 + 议价权下降（双重利空）；存量驱动型：Capex 见顶 = 增速放缓，同时可能带来现金流改善（好坏参半）。
- 对云厂的评估取决于是否强绑定 AI Lab（决定收入能否上调）、云租价由溢价转折价的幅度（决定利润率）。
- 硬件内部不能一刀切：存在瓶颈的细分（存储）逻辑不同。

**海豚案例**

- AI 算力《AI 算力：从盛宴到 “剩宴”？》（2026-07-13）：小结部分推出“上游硬件双重利空、云厂有好有坏”。

**适用场景与注意事项**：适用于任何资本开支周期中“设备供应商 vs 资产运营商”的比较（半导体设备、电力设备等）。Capex 锚与可持续性见 3.1，周期顶部的估值错觉见 11.4.4。

### 11.3.10 在确定性的错配期，优选 Capex 投建早、规模大的厂商，以安全边际为先

**方法要点**：在判断供需错配是阶段性的前提下，出于安全考虑，优先选择 Capex 投得早、规模大的大厂，因为在确定性的错配期，只有已经投产的产能才能实实在在拿到收入。

**操作步骤 / 拆分口径**

1. 先确认前提：当前的供需错配是阶段性的、且价格高涨。
2. 判断收入的决定因素：收入取决于能交付多少产能，而不是价格有多高。
3. 比较交付能力：新云股价弹性虽大，但产能交付受厂房、供电、设备交付周期和资金约束；亚马逊、微软这类先建先投的大厂已投产规模大，确定性最高。
4. 选择：错配期首选 Capex 投建早、规模大的厂商。

**关键指标与数据来源**：已投产算力规模、Capex 投建时点、积压订单与交付能力。

**判断标准**

- 逻辑链：价格高涨 → 收入取决于能交付多少产能 → 已投产规模大的公司确定性最高。
- 弹性与确定性的取舍：新云弹性大但交付受多重约束，错配期以安全边际为先。
- 前提一旦改变（进入供给集中投放期），需要切换逻辑。

**海豚案例**

- 新云《CoreWeave、Nebius》（2026-08-13）：错配期首选亚马逊、微软这类先建先投的大厂。

**适用场景与注意事项**：适用于供不应求阶段的选股。进入供给集中投放期后，需要切换逻辑；供给释放节奏见第 4 章，供需缺口判断见 5.1。

### 11.3.11 按 AI 投资回报轨迹的确定性给科技巨头排序

**方法要点**：从资金视角看软科技巨头的“版本答案”，按“AI 投入是否受控、AI 是否直接变现、主业是否放缓”分档排序：轨迹清晰的给估值，还在讲故事的估值持续打折。

**操作步骤 / 拆分口径**

1. 为每家巨头收集四项：AI 直接收入、Backlog（代表未来收入）、Capex、主业增速。
2. 按轨迹分三档：
   - 第一档：投入受控、AI 直接变现保持或实现更高增长（当期收入加代表未来收入的 Backlog），如微软；
   - 第二档：功过相抵，AI 直接变现超预期但投入也在加大，如谷歌；
   - 第三档：投入不减、主业放缓、AI 变现还在路上，如 Meta。
3. 对照估值：轨迹清晰的资金愿意给估值，还在讲故事的估值会持续打折。

**关键指标与数据来源**：AI 直接收入；Backlog；Capex；主业增速。

**判断标准**

- 核心判据是“所投有所得”是否已被自证：同样是收入强劲下提高资本开支，已有直接变现证据的与尚未自证的，资金反馈相反。
- 估值便宜不等于有吸引力：Meta 估值已低于同行和自身历史中枢，资金仍不热衷捡便宜。
- AI 对尚未变现的公司仍是被动防守的成本项。

**海豚案例**

- Meta《尴尬的 Meta》（2026-07-30）：Meta 属第三档，尽管估值已低于同行和自身历史中枢，资金仍不热衷捡便宜。
- Meta（2026-04-30）：与谷歌同样是收入强劲下提高资本开支，资金反馈却明显相反，关键在 Meta 还没完成“所投有所得”的自证；AI 对 Meta 仍是被动防守的成本项。

**适用场景与注意事项**：美股科技巨头的横向估值比较。传统互联网公司的类似考核标准见 11.4.6。

### 11.3.12 从巨头注意力的分布推导中小企业的机会：偏离巨头焦点、更垂直的领域

**方法要点**：先判断巨头的主战场，再推导被它们忽视的细分领域，中小企业的机会在偏离巨头注意力、而且更垂直的领域。

**操作步骤 / 拆分口径**

1. 判断巨头的主战场：巨头更聚焦在底层入口的比拼，这场比拼更惨烈，会牵扯它们更多的资源和注意力。
2. 认清生态优势：在垂类场景上，巨头相对中小企业的生态优势非常大，中小企业不能与巨头正面竞争。
3. 推导机会：找偏离巨头注意力、而且更垂直的领域。

**关键指标与数据来源**：巨头的资源投向、细分领域的垂直程度。

**判断标准**

- 条件需同时满足：（a）不在巨头主战场，（b）足够垂直。
- 巨头越是为入口之争消耗资源，越可能给垂直细分领域留出空白。

**海豚案例**

- 中国 AI 互联网《火拼 AI 互联网…》（2026-01-09）：根据巨头聚焦底层入口比拼的注意力分布，推导出中小企业的机会在偏离巨头焦点、更垂直的领域。

**适用场景与注意事项**：适用于筛选中小市值的 AI 应用标的。入口与生态竞争的框架见 9.5。

**本节速查清单**

- [ ] 环节排序是否同时检验了“是否新增环节”“格局是否留出空间”，并对高度集中的环节换用“定价权”口径？
- [ ] 供应链多元时，是否排出了单柜/单机价值量，并用下一代多路径情景逐一检验各环节的确定性，优先选“不论走哪条路都赢”的环节？
- [ ] 受益链里是否找出了交期最长、供给最刚性的“最紧缺环节”，并用交期/积压数据证明？
- [ ] 新兴赛道是否对环节排序，并正反两面论证龙头壁垒与追赶者空间，给追赶者设置了催化剂节点？
- [ ] 同环节标的是否按技术积累、产能扩张、业务纯度、客户/路线绑定、进入者位置、估值反映六维横比？
- [ ] 弹性是否用“新业务占公司体量”衡量，大平台是否改看防守价值？
- [ ] 设备商是否按优势工艺映射到产品类型，并比较了不同扩产场景下的弹性？
- [ ] 周期行业是否检查了上游瓶颈自有产能、成本曲线位置与一体化程度？
- [ ] 是否区分了增量驱动与存量驱动，并在错配期优先考虑已投产规模大的厂商？
- [ ] 巨头是否按 AI 回报轨迹的清晰度排序，中小企业机会是否从巨头注意力分布反推？

## 11.4 估值方法与预期定价

> 本节导读：本节解决“标的值不值、市场预期定在哪”的问题。先用三种“锚”做粗估——远期 TAM 对标市值、市值天花板反推、P/ARR 跨市场可比；再处理 AI 板块里特有的估值逻辑——AI ROI 到 Capex 斜率再到产业链估值（周期顶部低估值是错觉）、监测估值能否持续的三项外部条件、资金对传统互联网 AI 转型的考核指标、模型“交错领先”带来的多空机会；最后讨论传统低利润产品切入高附加值下游的价值重估。这些方法给出的是预期定价的判断，而非目标价；事件发布后的预期差映射股价见 12.1，TAM 的自下而上测算见 7.2，周期位置见 5.4，标的取舍见 11.3。

### 11.4.1 远期 TAM 对标市值：市值 vs 基本盘市场远期规模

**方法要点**：估算公司核心市场（基本盘）的远期 TAM，与当前市值比较；如果市值还没反映基本盘 TAM，就说明海外、机器人等期权尚未定价，中长期弹性较好。

**操作步骤 / 拆分口径**

1. 确定基本盘市场（如国内乘用车 ADAS 激光雷达），测算其远期 TAM（如 2030 年规模）。
2. 取当前市值，与基本盘 TAM 比较。
3. 若市值低于甚至尚未覆盖基本盘 TAM，则判断海外、机器人等期权尚未被定价。
4. 同时检查市场为什么不愿定价：找出压低估值的担忧（竞争加剧、单价下行等），判断其是否充分。

**关键指标与数据来源**：远期 TAM（2030 年）、当前市值；TAM 的详细测算参见深度《禾赛：特斯拉“弃子”？挡不住激光雷达的“华丽逆袭”》。

**判断标准**

- 市值还没反映基本盘 TAM：说明基本盘之外的期权（海外、机器人等）尚未被定价，中长期弹性较好。
- 要把“为什么估值偏低”的原因写清楚：禾赛 2026 年 8 月的情形是市场担忧 2026 年竞争加剧、单价加速下行。
- 它只是一个粗略的锚，不能替代现金流估值。

**海豚案例**

- 禾赛（2026-03-24、2026-05-19）：保守估计 2030 年国内乘用车 ADAS 市场达 400 亿规模，当前约 256 亿市值只反映了基本盘。
- 禾赛（2026-08-19）：约 180 亿市值“甚至还未能反映国内乘用车 ADAS 市场的基本盘估值”，原因是市场担忧 2026 年竞争加剧、单价加速下行。

**适用场景与注意事项**：适用于渗透率早中期的赛道龙头。TAM 市值对比是粗略的锚，不能替代现金流估值；TAM 的外部锚定与合理性检验见 7.1，自下而上测算见 7.2。

### 11.4.2 市值天花板反推：现有龙头市值合计占目标公司市值的比例

**方法要点**：检验高估值公司的新业务叙事时，先问“如果新业务只是现有市场的‘替代’，即使目标公司复制龙头地位，能贡献多少市值？”做法是把现有行业龙头的市值加总，和目标公司当前市值比较。

**操作步骤 / 拆分口径**

1. 假设新业务仅替代现有市场，目标公司最多复制现有龙头的地位。
2. 把现有行业龙头的市值加总，作为“市值天花板”。
3. 计算天花板占目标公司当前市值的比例。
4. 若占比很低，说明仅靠替代不足以支撑估值，新业务必须扩大可服务市场；研究问题随之转向“这个行业为什么有天花板、新业务能否打破它”。

**计算示例（特斯拉 Robotaxi）**：Uber 加滴滴市值合计约 2000 亿美元（且 Uber 还含外卖估值），只占特斯拉约 1.5 万亿美元市值的 14%（2000 亿 / 1.5 万亿）。因此 Robotaxi 必须扩大可服务市场（替代私家车出行），才能支撑估值，研究问题转向“网约车为什么有天花板”以及“Robotaxi 能否打破它”。

**关键指标与数据来源**：现有龙头市值合计、目标公司市值、两者之比。

**判断标准**

- 比值越低，“替代型叙事”越撑不起估值，必须论证新业务有“增量型”的可服务市场。
- 比值本身不是结论，而是把研究问题转向“天花板为什么存在、能否被打破”。

**海豚案例**

- 特斯拉/网约车《Robotaxi出行帝国，能再造特斯拉？》（2026-01-07）：2000 亿 / 1.5 万亿 ≈ 14%，据此提出 Robotaxi 需扩大可服务市场才能支撑估值。

**适用场景与注意事项**：适用于检验高估值公司的新业务叙事。现有龙头可能含其他业务（如 Uber 含外卖），需要剔除；市场空间的测算与情景见 7.2。

### 11.4.3 大模型公司 P/ARR 跨市场可比估值（中 vs 美、一级 vs 二级）

**方法要点**：对高增长、未盈利的大模型公司，用“市值 / 年底 ARR”做跨市场比较——中国二级市场对标北美一、二级市场——并把倍数差异归因到毛利率和资金环境，最后对照中国未上市大模型的一级市场估值。

**操作步骤 / 拆分口径**

1. 统一 ARR 口径，按“公司指引 → 最新上调 → 头部机构预期”梳理：
   - 智谱：财报指引 24 亿美元，9 月中旬上调至 30 亿，机构约 33 亿；
   - MiniMax：年初指引 10 亿未更新，机构给 12 亿。
2. 计算 P/ARR = 市值 / 年底 ARR：
   - 智谱跌 8% 后市值约 400 亿美元，约 12x（与机构约 33 亿美元的 ARR 口径相符）；
   - MiniMax 跌 12% 后约 95 亿美元，不足 8x（与机构 12 亿美元的 ARR 口径相符）。
3. 北美对标：
   - Anthropic：约 9x-20x（5 月融资估值 0.97 万亿至近 2 万亿 IPO 估值，对应 1000 亿 ARR）；
   - OpenAI：官方只给今年 300 亿收入指引，第三方估当下 ARR 500-700 亿，假设年底 600-800 亿，9 月底融资估值 1.4 万亿，约 20x。
4. 差异归因：毛利率差（约 30% vs 60%）+ 港股资金交易环境。
5. 对照中国未上市大模型的一级市场估值。
6. 结论：智谱、MiniMax 估值显著偏低。

**对照表**

| 公司 | 市场 | ARR 口径 | 估值 | P/ARR |
|---|---|---|---|---|
| 智谱 | 港股（二级） | 指引 24 亿美元 → 上调 30 亿 → 机构约 33 亿 | 跌 8% 后市值约 400 亿美元 | 约 12x |
| MiniMax | 港股（二级） | 年初指引 10 亿未更新 → 机构 12 亿 | 跌 12% 后约 95 亿美元 | 不足 8x |
| Anthropic | 北美（一级融资至 IPO 估值） | 对应 1000 亿 ARR | 5 月融资估值 0.97 万亿至近 2 万亿 IPO 估值 | 约 9x-20x |
| OpenAI | 北美（一级融资） | 第三方估当下 500-700 亿，假设年底 600-800 亿 | 9 月底融资估值 1.4 万亿 | 约 20x |

**关键指标与数据来源**：ARR（公司指引 / 机构预期）、市值、P/ARR、毛利率、一级市场融资估值。

**判断标准**

- 倍数要结合毛利率解读：毛利率差（约 30% vs 60%）与港股资金交易环境，是倍数差异的两项归因，比较时应把毛利率差异反映到倍数上。
- 对照国内未上市大模型的一级市场估值，用来检查二级市场相对一级是否折价。
- 结论依据三方面合起来看：与北美倍数的差距（智谱约 12x、MiniMax 不足 8x，对比 Anthropic 约 9x-20x、OpenAI 约 20x）、毛利率差与资金环境的解释力、国内一级市场估值的对照；海豚君据此判断智谱、MiniMax 估值显著偏低。

**海豚案例**

- 智谱/MiniMax/Anthropic/OpenAI《(短评)Anthropic发布Claude Haiku 5.5》（2026-10-08）：按上述步骤比较 P/ARR，结论智谱、MiniMax 估值显著偏低。

**适用场景与注意事项**：适用于高增长未盈利的 AI 公司；ARR 口径（毛/净、年化方式）需统一，毛利率差异应反映到倍数上；分子（估值）和分母（ARR）必须同币种相除。

### 11.4.4 AI ROI → Capex 增速斜率 → 产业链估值：“周期顶部低估值只是计算错觉”

**方法要点**：把龙头模型厂的商业化进展与全行业军备竞赛联系起来，用“AI ROI → 巨头 Capex 斜率 → 产业链盈利与估值”的传导链判断硬件链风险，并识别周期顶部估值看似便宜的“计算错觉”。

**操作步骤 / 拆分口径**

1. 确认背景：AI 的颠覆性让科技巨头不敢离开战场；但 AI ROI 的变化趋势决定巨头是否暂时放慢投入。
2. 判断产业链预期位置：在预期已经打满的情况下，Capex 哪怕只是降低增长斜率，也会导致市场短期出现崩盘迹象。
3. 识别估值错觉：在周期顶部，盈利处于高点，市盈率看似便宜，低估值只是计算错觉。
4. 选前瞻指标：追踪 Anthropic 等龙头的 ARR 与经营利润转正，作为判断全产业链 Capex 斜率的前瞻指标。
5. 顶部 PE 失真时，改用周期平均盈利来看估值。

**关键指标与数据来源**：龙头 ARR 与盈利拐点、科技巨头 Capex 增速（斜率）、产业链估值与盈利位置。

**判断标准**

- 传导链：龙头模型厂 ARR 与利润 → AI ROI → 巨头 Capex 增速斜率 → 上游产业链（存储、光模块、服务器）的盈利与估值。
- 关键是“斜率”而非“绝对水平”：预期打满时，增速放缓即可引发调整。
- 周期顶部的 PE 低不代表便宜，需用周期平均盈利校正。

**海豚案例**

- AI 产业链《Kimi K3 时刻：中美 AI 产业链叙事要变天？》（2026-07-22）：把龙头模型厂的商业化进展（ARR、经营利润转正）与科技巨头 Capex 斜率及产业链估值联系起来，提示周期顶部低估值只是计算错觉。

**适用场景与注意事项**：适用于强周期 AI 硬件链（存储、光模块、服务器）的估值风险判断；顶部 PE 失真时应参考周期平均盈利。与 11.3.9（增量 vs 存量驱动）配合，周期位置见 5.4，Capex 锚见 3.1。

### 11.4.5 用三项外部条件监测 AI 模型板块估值能否持续

**方法要点**：对中国 AI 原生和模型股的估值能否持续，不做绝对估值，而是设三个外部条件监测，本质是“锚定海外映射 + 产业景气”的相对估值支撑判断。

**操作步骤 / 拆分口径**

1. 条件①：美国 SOTA 模型商的融资估值继续创新高（一级市场的定价锚）。
2. 条件②：云巨头资本开支仍在高增（产业投入）。
3. 条件③：模型商的新模型仍在大幅迭代（技术进步）。
4. 三者同时成立，模型板块估值就有持续机会；任何一项转弱都是风险信号。

**关键指标与数据来源**：海外头部模型公司的融资估值、谷歌/微软/亚马逊/Meta 资本开支增速、模型能力对标（如编程能力对标 Claude Opus）。

**判断标准**

- 三项为“与”关系：缺一不可；任一转弱即风险信号。
- 三项分别对应定价锚（海外估值）、产业投入（Capex）和技术进步（模型迭代），共同支撑相对估值。
- 局限：属于情绪和资金面判断，给不出目标价。

**海豚案例**

- 中国 AI 模型板块《特朗普关税“被废”、中国模型齐飞，中概能有狂欢吗？》（2026-02-23）：春节模型发布潮后，据此三条件判断模型板块估值仍有持续机会。

**适用场景与注意事项**：适用于缺少盈利支撑的主题和成长板块（AI 模型、AI 应用）。局限是情绪和资金面判断，给不出目标价；需要时与 11.4.3 的 P/ARR 配合给出相对估值水平。

### 11.4.6 资金对传统互联网 AI 转型的两条“考核指标”

**方法要点**：结合百度、腾讯、快手财报后的资金反应，总结出资金对传统互联网转型 AI 的考核标准。两条都满足，估值倍数才不会因投入削弱经营杠杆而被下调；主业不能兜底时，低估值可能只是假象。

**操作步骤 / 拆分口径**

1. 考核一：AI 投入后要看到直接变现，要算 ROI——跟踪 AI 收入（ARR、季度收入）与 AI 相关 Capex 和费用。
2. 考核二：传统主业要能兜底——既不能被 AI 直接替代，也不能持续被竞争对手截流；跟踪主业增速和流量趋势。
3. 两条都满足：估值倍数才不会因投入削弱经营杠杆而被下调。
4. 主业不能兜底：低估值可能只是假象，即使倍数看起来很低。

**关键指标与数据来源**：AI 收入（ARR、季度收入）、AI 相关 Capex 和费用、主业增速和流量趋势、估值倍数变化。

**判断标准**

- 资金是否认可“投入对经营杠杆的削弱”，取决于是否带来更高的业务增速或成长想象力。
- 主业兜底性比估值倍数更重要：流量持续下滑、主业无法兜底时，即便倍数不高也不是便宜。
- 推理链：AI 投入 → 经营杠杆被削弱 → 若有直接变现（ROI）且主业兜底，估值不下调；否则估值被下调或低估值是假象。

**海豚案例**

- 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：结合百度和腾讯财报后的资金态度，提出这两条考核指标；快手生态流量近两年持续下滑，主业无法兜底，即便估值 9x+ 也可能是“低估值假象”。
- 快手《快手：一场向死而生的暴跌，能换来 AI 重生吗？》（2026-03-25）：资金是否认可投入对经营杠杆的削弱，取决于是否带来更高的业务增速或成长想象力。

**适用场景与注意事项**：适用于 AI 转型期的互联网公司估值判断。AI 巨头按投资回报轨迹的排序见 11.3.11。

### 11.4.7 模型竞争“交错领先”框架：识别市场线性外推带来的多空机会

**方法要点**：观察中国模型一哥“轮流坐庄”的规律——模型竞争是交错领先，不是单一模型持续 SOTA，也不是一落后就结构性掉队。市场把阶段性领先或落后线性外推来定价时，就是多空机会。

**操作步骤 / 拆分口径**

1. 跟踪模型排名变化与发布节奏，确认当前谁领先、谁落后、下一次发布窗口在何时。
2. 对比市场定价：市场是否把阶段性领先或落后线性外推（领先者按“长期 SOTA”定价、落后者按“结构性掉队”定价）。
3. 对领先者提示守擂失败的风险；对落后者寻找边际向上的催化。
4. 监测股价和估值对排名变化的反应，验证线性外推是否正在被修正。

**关键指标与数据来源**：模型排名变化、发布节奏、股价/估值。

**判断标准**

- 交错领先是常态：持续 SOTA 与结构性掉队都是少数情形。
- 市场按线性外推定价的偏差越大，反向机会越大：领先者的守擂失败风险（空头机会），落后者的边际催化（多头机会）。
- 催化剂是对手的新基座或新模型发布，它会改变排名与股价。

**海豚案例**

- MiniMax（2026-08-26）：Bottom Line——用“结构性掉队”思维线性定价资产时，就是投资的多空机会。
- 智谱（2026-08-31）：26 年是智谱年，27 年是大问号，线性外推风险较大；Kimi K3 发布后智谱股价快速回落。
- MiniMax（2026-03-02）：DeepSeek 新基座即将发布，错位领跑下有回调压力。

**适用场景与注意事项**：适用于技术快速迭代、领先地位容易易手的行业（AI 模型、游戏、消费电子）。竞争位置和梯队判断见 8.2，竞争烈度见 8.4。

### 11.4.8 传统低利润产品切入高附加值新下游带来的重估逻辑（中速机）

**方法要点**：同一产品切换到支付能力更强的下游，会带来量和利润率的双重提升，从而触发价值重估；判断角度是“下游变了没有”，而不是“产品变了没有”。

**操作步骤 / 拆分口径**

1. 梳理传统下游与盈利特征：中速机传统上用于船舶动力、调峰电厂、分布式电网、工业热电联产，市场份额分散、利润空间有限。
2. 识别新下游与切入理由：凭高效率（48%-50%）和更优 LCOE，切入北美 AIDC 主电源这一高壁垒、高附加值市场。
3. 判断量与利润率的双重提升：新下游支付能力更强。
4. 梳理初步竞争格局：先发者（瓦锡兰已获 GW 级订单）和全产品线巨头（卡特彼勒、康明斯凭客户关系入场）。
5. 验证新下游订单的持续性。

**关键指标与数据来源**：下游结构变化、订单规模（GW）、利润率。

**判断标准**

- 下游支付能力与壁垒越高，重估幅度越大；需要产品性能（效率、LCOE）能满足新下游的门槛。
- 先发者的订单规模（GW 级）是验证新下游需求真实性的第一信号。
- 重估要看订单是否持续，一次性订单不构成重估。

**海豚案例**

- 燃气/中速机《AI 电荒突围》（2026-04-14）：中速机凭高效率与更优 LCOE 切入北美 AIDC 主电源，瓦锡兰获 GW 级订单，卡特彼勒（CAT）、康明斯（CMI）入场。

**适用场景与注意事项**：适用于传统工业品因新下游获得重估的情形。需验证新下游订单的持续性；新下游的需求与可持续性测算见第 3 章。
