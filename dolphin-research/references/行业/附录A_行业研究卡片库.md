### AI大模型商业化与Token经济（含OpenAI、Anthropic）
**核心变量与核心问题**：（板块：AI/大模型）
1. Token为何成为AI时代的计价锚？
2. AI商业化的钱从哪来——C端Chatbot还是B端Agent？
3. 模型厂收入（合计ARR加速度）能否支撑AI基建的逐级加杠杆？
4. 闭源模型降价，是需求不及预期，还是效率提升与产品矩阵策略？

**分析框架与关键判断**：
- 拆解路径：以Token作为AI时代的计价与用量锚 → 把商业化收入拆成C端Chatbot与B端Agent两条来源 → 以OpenAI与Anthropic合计ARR的加速度检验AI基建“逐级加杠杆”的根基 → 区分闭源模型降价究竟是需求不及预期，还是效率提升与产品矩阵策略。
- 预期基准与比较基期：第三方估算（Yipit Data、Tickertrends）作为ARR预期基线；ChatGPT付费率约5%作为C端付费对标；前期收入结构（4月B端占40%）作为比较基期。

**追踪数据与指标**：
- 日均Token使用量及份额
- 模型厂ARR（毛/净口径）及其增速与加速度
- B端/C端收入占比
- Agent使用率与每日使用率
- 广告CPM、广告ARR、广告主数量
- 推理单位成本降幅
- token单价与单任务成本
- 数据来源：Stack Overflow开发者调研、Yipit Data、Tickertrends、OpenRouter、媒体报道（The Information等）

**涉及标的与映射逻辑**：
- 估值方法（P/ARR）：Anthropic约9x-20x（0.97万亿融资估值至近2万亿IPO估值，对应1000亿ARR）；OpenAI约20x（1.4万亿融资估值/年底ARR 600-800亿美元）。
- 标的：OpenAI、Anthropic（模型厂）；模型厂ARR加速度向上游AI基建（光模块、存储等）传导，见「AI基建链（光模块/存储）对模型厂收入的敏感度」。

### 大模型 / AI Lab 行业
**核心变量与核心问题**：（板块：AI-基础模型；以Kimi K3为触发事件）
1. 中国开源模型（Kimi K3）首次大幅缩小与顶尖闭源差距（6-12个月→3个月），是否意味着纯大模型商业模式边际恶化的拐点。
2. 短期竞争影响：单价低不等于性价比高（单任务成本仅便宜10%），算力受限。
3. 架构效率路线（MoE稀疏度、KDA减KV 75%）与对硬件需求的影响（单位需求vs总需求）。
4. 中美成本结构差异与补贴。
5. 商业模式=持续融资竞赛，上市潮。
6. 价值链议价权从模型厂回流CSP。
7. AI ROI决定Capex斜率，周期顶部低估值是错觉。

**分析框架与关键判断**：
- 中美模型差距由6-12个月缩小到约3个月，是判断纯大模型商业模式边际恶化的核心变量。
- 单价低≠性价比高：单任务成本仅便宜约10%，且算力受限。
- 效率路线要区分“单位硬件需求”与“总需求”两个口径（MoE稀疏度、KDA减KV Cache 75%）。
- 模型商业模式本质是持续融资竞赛；价值链议价权从模型厂回流CSP；AI ROI决定Capex斜率，周期顶部的低估值是错觉。
- 预期基准：公司年度目标（Anthropic 260亿收入）、市场预期（年底1000亿ARR）、增速斜率是否已priced in；智能性×单任务成本矩阵中的「绿色」优势区。

**追踪数据与指标**：
- AA智能评分、Arena排名、中美差距月数
- ARR与月环比（Anthropic 25Q4 9%→1-2月25%→3-6月30%+）
- OpenRouter Token份额与Token单价
- 单价、单任务成本、Token效率、输出速度
- 总参数、专家数、激活率
- KV Cache削减比例
- 部署权重TB与最低硬件门槛
- 毛利率（A&O约60%、智谱<30%）
- 训练成本
- 企业AI采用率（北美约20%，+3ppt）
- 分行业渗透
- 数据来源：Artificial Analysis、LMArena、OpenRouter、Yipit（含辟谣）、公司披露、渠道调研与亲测（Kimi套餐）、海豚君智谱&MiniMax深度报告

**涉及标的与映射逻辑**：
- 估值：未做显性估值；以ARR增速斜率（隐含年化增速约70%）判断上市估值弹性。
- 映射：Kimi（K3）、Anthropic、OpenAI（A&O）、智谱、MiniMax；价值链议价权回流CSP，Capex斜率取决于AI ROI。

### 大模型行业（独立模型商商业模式）
**核心变量与核心问题**：（板块：AI-大模型）
1. 大模型要什么样的投入要素和密度（数据、算法即人才、算力）。
2. 算力扮演什么角色：训练算力占总支出50%以上，贡献一半以上的亏损。
3. 模型经济学怎么算才能平衡：收入对上一年训练算力的覆盖率持续下降，代际训练成本3—5倍。
4. 最终是什么生意：把资产负债表业务摊在利润表上，缩放定律失效后才可能变成“长江电力”式模式。
5. 终局前是融资耐力的竞赛和淘汰赛。
6. 模型大宗商品化，Agent OS调度削弱规模效应。

**分析框架与关键判断**：
- 以“投入要素与密度 → 算力角色 → 模型经济学平衡 → 生意本质 → 终局”的链条拆解独立模型商。
- 训练算力占总支出50%以上，贡献一半以上亏损；收入/上一年训练算力覆盖率持续下降；代际训练成本3—5倍。
- 生意本质是把资产负债表业务摊在利润表上；缩放定律失效后才可能变成“长江电力”式模式；终局前是融资耐力的竞赛和淘汰赛。
- 模型大宗商品化，Agent OS调度削弱规模效应。
- 预期基准与类比：OpenAI自建数据中心模式 vs 中国模型商第三方云的轻资产模式；云服务寡头格局作为终局类比；蔚来作为“融资即生存能力”的类比。

**追踪数据与指标**：
- 支出/收入倍数
- 毛利率（to B vs to C）
- 人数和研发占比、单人薪酬
- 训练算力（研发费用）与推理算力（营业成本）
- 训练算力/总支出
- 收入/上一年训练算力覆盖率
- 单代训练成本及代际倍数
- 融资额/收入（3—5倍）
- 存活玩家数
- 榜单排名
- ARR增速
- 数据来源：MiniMax、智谱招股书/财报；媒体报道的行业格局

**涉及标的与映射逻辑**：
- 估值：行业层面不估值；个股用P/ARR对标头部闭源公司。
- 标的：MiniMax、智谱（来源文章标的）；对标OpenAI、Anthropic等头部闭源公司；类比标的：蔚来（融资耐力）。

**来源文章**：《深扒 Minimax 与智谱：大模型，算力强度与融资耐力的绝杀？》（2026-01-27，ID 38121039）；《疯狂高估值背后，MiniMax 是泡沫还是摸到了未来？》（2026-03-31，ID 39635158）。

### AI算力资本开支链
**核心变量与核心问题**：（板块：AI基础设施）
1. CSP资本开支（五大CSP在2026年超过8000亿、+82%）能否持续。
2. 资本开支上调是来自涨价还是真实需求。
3. AI实验室（Anthropic、OpenAI）的ARR斜率与融资能力（循环融资、零残值）。
4. 资本开支向芯片（GPU、ASIC）、代工与CoWoS、设备、存储的逐级传导。
5. 市场风格从成长转向确定性时，各环节估值如何分化。

**分析框架与关键判断**：
- 传导链：CSP资本开支 → AI实验室ARR与融资能力 → 芯片（GPU、ASIC）→ 代工与CoWoS → 设备 → 存储。
- 估值分化规律：确定性越高（台积电、ASML）回调越小；竞争加剧（博通）或周期性强（海力士）的环节估值受压；高估值（ARM）需要超强业绩。
- 预期基准：机构对CSP资本开支的预期；英伟达和博通的多年AI收入指引；台积电全年增速指引。

**追踪数据与指标**：
- 五大CSP资本开支及上调幅度
- Anthropic和OpenAI的ARR斜率
- GW规模与单GW收入
- ASIC和GPU收入
- CoWoS产能
- 晶圆厂资本开支
- 存储价格
- 美债利率与AI融资成本

### AI数据中心组网架构（Scale-Up/Scale-Out互连）
**核心变量与核心问题**：（板块：AI硬件/数据中心网络）

- 好坏标准：按同等算力折算后成本更低、性能可以接受，才算有竞争力；单卡便宜但折算后不便宜，就不算竞争力。

### HBM（高带宽内存）
**核心变量与核心问题**：
1. HBM供需：2026年供给41.9亿GB vs 需求42.1亿GB，紧平衡而不是最紧（capex集中投向HBM）；
2. HBM为什么脱颖而出：垂直堆叠突破DRAM制程极限；1-2千位的超宽位宽需要硅中介层与GPU共封装；
3. 技术难点与竞争优势：TSV；MR-MUF vs TC-NCF（海力士的护城河）；混合键合是对手弯道超车的机会；
4. Base Die定制化与代工化，削弱内存厂话语权；
5. 层数会继续堆高还是“降层多颗”（Rubin Ultra传闻），HBF能否分流容量需求；
6. 毛利率悖论：HBM约60% vs 常规DRAM 80%+。

### DRAM/HBM 存储行业
**核心变量与核心问题**：
- AI时代DRAM（含HBM）供需缺口是扩大还是收窄；
- 2026年是否为供需比顶点、2027-28年DDR转松而HBM转紧；
- 补库存是否让2026年紧缺有“水分”、2027年是否去库存；
- 长协能否熨平周期、提升估值中枢；
- HBM格局是否从一家独大走向三分天下；
- 中国厂商DDR扩产是否带来反转风险。

**分析框架与关键判断**：
- 拆解方式：自下而上建立供需平衡表——需求侧（常规终端出货×单机容量、通用服务器出货×单机DDR、XPU颗数×单颗HBM及主机DDR）、供给侧（晶圆月产能、HBM可用晶圆、单片bit产出、CoWoS良率），得到DDR与HBM各自的供需比，再叠加客户补库存、capex与长协。
- 判断标准：供需比>1为紧、<1为松，并据此映射价格方向；XPU出货±10%对HBM供需比±0.1。
- 关键判断（卡片未标注各数值对应年份，以下按序列推断）：DDR供需比先升后降（1.07→1.14→0.98→0.92），即2026年为供需比顶点、2027-28年DDR转松；HBM供需比1.04→1.06-1.07，转紧；客户补库存约400亿Gb，对应“2026年紧缺有水分、2027年去库存”的问题；中国厂商DDR晶圆占比23%→32%，构成反转风险；长协（预付款比例、底价折让、覆盖率）能否熨平周期、提升估值中枢，是估值判断的关键。
