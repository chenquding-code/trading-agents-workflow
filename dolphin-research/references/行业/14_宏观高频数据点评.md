# 第14章 宏观高频数据点评

> **本章目的**：点评社零、楼市、就业等宏观高频数据，校正季节与口径，拆出结构与扩散，并映射到行业与平台个股。

**本章小节**：14.1 季节、基数与大促校正｜14.2 结构拆分、量价拆分与口径倒算｜14.3 扩散判断、前瞻跟踪与平台映射

---

## 14.1 季节、基数与大促校正

> 本节导读：宏观高频数据（社零、线上零售等）的单月同比，常被春节错位、去年同期的政策与事件基数、大促时点所扭曲，直接读单月数字很容易误判景气。本节给出四个“先校正、再下结论”的工具：用跨春节多月加权平均作可比基准；把当前增速放进剔除特殊年份的长周期里定位；用去年同期的政策与事件时间轴预判同比拐点；用大促时点与补贴强度判断线上增速反弹的成色。校正之后的结构拆分与口径倒算见 14.2，扩散判断与平台映射见 14.3；跨指标的景气交叉验证见 13.1，产业需求侧的季节波动与透支见 3.5。

### 14.1.1 春节错位校正：用跨春节多月加权平均作为可比基准

**方法要点**：春节偏晚时，消费会后置，导致春节前后的单月同比失真；把跨春节的几个月合并成一个加权平均增速，当作“可比的增长中枢”，再选春节扰动基本消失的月份去判断真实景气。

**操作步骤 / 拆分口径**

1. 先判断春节位置：春节时间偏晚，消费后置，12月和1-2月的单月同比都不可直接比较。
2. 把跨春节的12月到2月合并，计算三个月的加权平均增速，作为可比的增长中枢。实操上可按各月规模加权，也就是把三个月合计后再求同比。
3. 选春节扰动基本消失的月份（如3月）作为“更准确的景气度判断月份”。
4. 把该月增速与12-2月加权平均比较，判断边际是增强还是走弱。
5. 分项复用同一做法：商品零售、餐饮、线上实物等分项，同样用12月到2月的加权平均作为基准。

**关键指标与数据来源**：社零月度同比、12月到2月加权平均增速、分项（商品零售、餐饮、线上实物）加权平均增速；数据来自国家统计局月度社零。

**判断标准与推理链条**

- 推理链：春节偏晚，消费后置；12月偏低、1-2月偏高，二者各自失真；合并12-2月得到中枢；3月春节扰动消失，若3月增速低于该中枢，则景气度确实偏弱且边际走弱。
- 单月值低于加权中枢：边际走弱；高于加权中枢：边际改善。
- 分项同理：线上实物以12-2月加权平均作基准（6.5%），后续月份持续沿用同一基准做比较。

**变体**

- 变体 A（总量）：社零总额。12月社零同比0.9%，1-2月2.8%，12-2月加权2.1%，3月1.7%。
- 变体 B（分项）：商品零售、餐饮、线上实物，各自计算12-2月加权平均作为基准。线上实物的相关数据为：1-2月10.3%，12-2月加权6.5%，一季度7.5%，3月2.5%。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：春节偏晚，12月社零只增0.9%，1-2月增2.8%；把12-2月合并后加权平均为2.1%，选春节扰动消失的3月来判断；3月增速1.7%，对比加权2.1%，判断景气度确实偏弱且边际走弱。线上实物同样以12-2月加权6.5%为基准（1-2月10.3%、一季度7.5%、3月2.5%）。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：继续用12-2月加权6.5%作为线上实物的基准，判断4月线上实物增速的位置。

**适用场景与注意事项**

- 适用于所有受春节、节假日错位影响的中国月度数据，如社零、出口、CPI、出行。
- 春节偏早时方向相反（消费前置），同样用跨月合并的办法处理。
- 必须等到春节扰动消失的月份出数后才能下结论；基准一旦确定，后续各月沿用同一口径，保持前后可比。
- 加权平均只是“可比中枢”，不替代对结构、基数的进一步分析（见 14.1.3、14.2）。

### 14.1.2 历史长周期位置比较：剔除特殊年份后的分位判断

**方法要点**：不只看环比和同比，而是把当前增速放到长周期里定位，并剔除极端年份，用“自某时点以来最差”“某年以后最差”“首次转负”这类表述，给读者一个直观的严重程度锚点。

**操作步骤 / 拆分口径**

1. 取该指标（如社零同比）的历史月度序列。
2. 剔除受极端冲击的特殊年份（疫情期的2020年和2022年），避免把非常态当作比较对象。
3. 找当前值在剩余序列中的位置，写成定位句式：
   - “自去年11月以来，社零增长是除2020年和2022年两个特殊时期外最差的”；
   - “4月是2022年以后最差的一月”；
   - “5月社零在后疫情时代首次跌到负数”。
4. 再用重大政策拐点作参照：5月的负增长“即便在2024年9月‘大反转’之前也没这么差”，说明压力超过政策转向前的低谷。
5. 与环比、同比边际变化、结构拆分配合使用，不单凭位置下结论。

**关键指标与数据来源**：社零同比的历史序列、剔除疫情年份后的历史低点；数据来自国家统计局。

**判断标准与推理链条**

- 剔除特殊年份后仍处于历史低位，说明压力不是常态波动，而是严重的下行；“首次转负”说明进入新的更差区间。
- 定位句式的层级由轻到重：近几个月最差 → 除特殊年份外最差 → 某年以后最差 → 后疫情首次为负。
- 先给严重程度的定性，再回到结构、基数、政策去解释原因。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：指出自去年11月以来，社零增长是除2020年和2022年两个特殊时期外最差的，用来界定“倒春寒”的严重程度。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：4月社零增速0.2%，是2022年以后最差的一月。
- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）：5月社零同比-0.6%，后疫情时代首次跌到负数，即便在2024年9月“大反转”之前也没这么差。

**适用场景与注意事项**

- 适用于所有宏观月度数据点评，尤其是需要给读者一个直观严重程度的场合。
- 剔除哪些年份、为什么剔除，要在文中交代清楚（疫情年份属非常态）；序列要足够长，才有“位置”可言。
- 位置比较只回答“多严重”，不回答“为什么”，需与 14.1.1、14.1.3 及 14.2 配合。

### 14.1.3 基数效应加政策与事件时间轴，推断同比拐点

**方法要点**：把去年同期的政策和事件按时间轴标出来，预判今年同比压力最大的月份和触底时点，再用实际数据持续修正。

**操作步骤 / 拆分口径**

1. 梳理去年同期的政策和事件时间轴，并标出对应的基数（去年同期社零和分项增速）。
2. 判断每个阶段基数的高低，推断今年同比压力最大的月份和触底时点。
3. 对照实际数据修正判断，必要时下调回暖力度并把反弹时点后移。
4. 同时看环比：基数低只意味着同比容易修复，不等于需求好转。

**时间轴示例（海豚君的梳理）**

| 去年时点 | 政策与事件 | 对基数的含义 | 对今年的推断 |
|---|---|---|---|
| 3-5月 | 国补利好最明显，社零增速处于高峰 | 基数高 | 今年二季度同比压力最大 |
| 6月后 | 国补利好明显消退；餐饮因外卖大战在6月后增速跳水 | 商品和餐饮基数都明显下降 | 今年6月起社零可能触底修复，下半年基数走低 |

**关键指标与数据来源**：去年同期社零和分项增速（基数）、国补发放时间、外卖补贴大战时间。

**判断标准与推理链条**

- 推理链：去年3-5月国补集中释放，基数高 → 今年二季度同比承压最重；去年6月后国补退潮、外卖大战拖累餐饮，基数下沉 → 今年6月起同比有望触底修复，下半年基数更低。
- 滚动修正规则：实际数据弱于预期，就下调回暖力度，并把更明显的反弹后移。例如7月社零再度走弱，三季度回暖力度的预期下调，更明显的反弹推迟到四季度，但仍维持二季度为电商增速最低点的判断。
- 基数低不等于需求好转：同比修复要用环比、结构（见 14.2）加以确认。

**海豚案例**

- 社零《4月社零点评：消费怎么办？》（2026-05-18）：预判二季度同比压力最大，下半年基数下降后触底。
- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）：指出6月后商品和餐饮的基数都会明显下滑，为后续同比修复提供条件。
- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：7月数据再度走弱，下调三季度回暖力度预期，维持二季度为电商增速最低点的判断，更明显的反弹推迟到四季度。

**适用场景与注意事项**

- 适用于所有同比口径数据的前瞻判断。
- 时间轴要事先标出政策与事件的发生月份，否则容易把“基数变化”误读为“需求变化”。
- 基数效应只决定同比的“难易程度”，必须同时看环比；预判与实际的偏差要及时回头修正（见 14.3.2）。

### 14.1.4 大促时点与补贴强度校正，判断增速反弹的成色

**方法要点**：线上增速出现反弹时，先排除促销日历和补贴扰动，再判断反弹是大促前置造成的，还是真实触底。

**操作步骤 / 拆分口径**

1. 核对今年618大促的活动时间，与去年相比是否提前或拉长；提前或拉长会造成线上增速“前高后低”。
2. 核对平台是否有高调的补贴宣传；监管重视反内卷，平台补贴相对克制。
3. 如果两者都没有明显变化，则增速反弹不是大促前置造成的，更可能是真实触底。
4. 事后复核：促销季结束后增速回落，说明此前的反弹多少受618推动；再看环比跌幅，若不大，说明景气度没有断崖式下降。

**关键指标与数据来源**：大促起止时间、平台补贴力度、线上实物零售增速。

**判断标准与推理链条**

- 大促时间无变化 + 补贴力度克制 → 排除大促前置，反弹成色较足，视为真实触底。
- 大促提前或拉长、补贴高调 → 反弹成色存疑，预期促销季后增速回落。
- 事后增速回落但环比跌幅不大 → 反弹多少受大促推动，但景气度没有断崖式下降。

**海豚案例**

- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）：核对618活动时间和平台补贴宣传后，判断5月线上实物增速反弹到2.6%不是大促前置造成的，更可能是真实触底。
- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：线上实物增速从6月3.9%降到7月3.3%，确认6月的反弹多少受618推动，但环比跌幅不大，说明景气度没有断崖式下降。

**适用场景与注意事项**

- 适用于电商数据（社零线上、平台GMV）的月度解读，以及双11、618等大促前后。
- 补贴力度要结合监管环境判断（反内卷下补贴克制），不能想当然套用往年。
- 同类判断需配合 14.2.4 的线上渗透率，核对线上相对整体的景气度。

**本节速查清单**

- [ ] 春节是否错位？是否已用12月到2月加权平均作为可比基准，并选了春节扰动消失的月份（如3月）来判断？
- [ ] 分项（商品零售、餐饮、线上实物）是否也各自做了跨春节加权，并沿用同一基准？
- [ ] 当前增速在历史长周期中的位置如何？是否已剔除2020年、2022年等特殊年份，并说明剔除理由？
- [ ] 去年同期的政策与事件时间轴（国补发放、外卖大战等）是否已标出，据此推断了压力最大月份和触底时点？
- [ ] 基数低的月份，是否同时看了环比，没有把“基数低”当成“需求好转”？
- [ ] 线上增速反弹时，是否核对了大促（618、双11）的起止时间与补贴宣传，排除了前置因素？
- [ ] 促销季后是否做了事后复核：增速回落幅度与环比跌幅如何？
- [ ] 预判与实际数据的偏差是否已记录并据此修正判断强度？

## 14.2 结构拆分、量价拆分与口径倒算

> 本节导读：同一个社零总数，拆开之后常常讲的是完全不同的故事。本节解决“怎样把总量拆到能解释景气与政策影响的颗粒度，并处理好口径变化”：先把社零拆成商品零售与餐饮、识别统计口径变更并倒算线上服务与线下商品零售、用线上渗透率衡量线上相对景气度，再剔除汽车后按政策属性分品类，用第三方量数据做量价拆分，最后把“量×价→额”的思路用到楼市高频数据。时间扰动的校正放在 14.1；拆出的结构再交给 14.3 做扩散判断与平台映射；产业层面的价格驱动归因见 5.3，收入口径与利润率测算见 9.3。

### 14.2.1 商品零售与餐饮收入拆分，以餐饮作为“更真实”的景气指标

**方法要点**：把社零拆成商品零售和餐饮收入，分别看增速与环比变化幅度，并识别哪一个更能反映真实需求：商品零售受政策与价格扰动大，餐饮更“干净”，因此以餐饮作为更真实的景气度指标。

**操作步骤 / 拆分口径**

1. 将社零拆为商品零售和餐饮收入两类，分别记录同比。
2. 看两者相对前期（如前三个月）的环比变化幅度，而不只看绝对增速。
3. 识别扰动源：商品零售受国补退坡、电子产品涨价等结构性因素扰动大；餐饮不太受国补退坡和电子产品普涨影响，更能“真实”反映消费景气度。
4. 叠加季节性因素：节后餐饮短期受冲击；暑期“带娃消费”支撑餐饮和酒旅。
5. 餐饮同样要结合基数看（外卖补贴大战等会造成基数扰动，见 14.1.3）。

**关键指标与数据来源**：商品零售同比、餐饮收入同比、两者相对前期的环比变化幅度；数据来自国家统计局。

**判断标准与推理链条**

- 餐饮走弱：说明总体景气确实走弱，因为餐饮几乎不受国补和电子产品涨价扰动。
- 商品零售走弱：若主要来自少数品类（国补退坡、手机涨价等），属于结构性拖累，需要继续拆到品类（见 14.2.5）；若拖累扩散到各品类，则转向“全面性”判断（见 14.3.1）。
- 对照“商品”与“餐饮”的边际变化幅度：二者同步回落，景气判断更扎实。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：商品零售增速1.5%，对比前三月1.9%；餐饮2.9%，对比3.9%，两者均回落，餐饮降幅更明显。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：商品0.2%、餐饮2.2%，判断4月景气确有走弱。
- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）：商品-0.7%、餐饮0.6%，两者同步走低。
- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：商品0.9%、餐饮1.4%，低位企稳；暑期“带娃消费”对餐饮和酒旅有支撑。

**适用场景与注意事项**

- 适用于中国消费景气度判断。
- 餐饮也会受外卖补贴大战等基数扰动，必须结合基数一起看。
- 季节性（节后冲击、暑期支撑）要单独标注，避免把短期扰动当成趋势。

### 14.2.2 识别统计口径变更：线上实物可比，并倒算线上服务的隐含增速

**方法要点**：先确认统计口径是否发生变化，再只用口径不变、历史可比的序列做比较，并用“总口径减去实物”倒算被扩大的那一块（线上服务）的隐含增速。

**操作步骤 / 拆分口径**

1. 确认口径变化：2026年起统计局把线上零售总口径从“网上零售额”改为“网上商品和服务零售额”，大幅扩大了网上服务型零售的统计范围；网上实物商品零售口径不变，和历史可比。
2. 电商分析只用线上实物零售同比做历史比较。
3. 倒算线上服务型销售的隐含增速：隐含额 = 网上商品和服务零售额 − 网上实物商品零售额；隐含同比 = 本期隐含额 ÷ 去年同期隐含额 − 1（去年同期的两项数额，可由统计局披露的同比增速反推）。
4. 推断隐含增速背后的内容：酒旅、文娱影视等服务型消费。
5. 每篇点评都加注口径说明，防止读者误读。

**关键指标与数据来源**：网上实物商品零售额同比、网上商品和服务零售额、线上服务隐含增速；数据来自国家统计局。

**判断标准与推理链条**

- 口径不可比的序列不用于历史比较；口径可比的“线上实物”才是电商景气度的基准。
- 总口径增速若明显高于实物增速，差额来自线上服务；用倒算值（3月约12%、4月约6.8%）观察服务型消费的边际变化。
- 线上服务隐含增速从3月约12%降到4月约6.8%，与线上实物（2.5% → 0.2%）同步回落，说明线上两块都在走弱。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：线上实物3月2.5%，1-2月为10.3%，12-2月加权6.5%，一季度7.5%；倒算线上服务隐含增速约12%，并推断其隐含内容包括酒旅、文娱影视等。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：线上实物0.2%，倒算线上服务隐含增速约6.8%。
- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）、《7月社零点评：回暖“昙花一现”？》（2026-08-17）：均加注口径说明，提示线上总口径与线上实物口径的差异。

**适用场景与注意事项**

- 适用于任何口径变更年份的宏观数据点评：先核对口径，再比较，避免数据陷阱。
- 倒算值是推算而非官方披露，历史数据可能修订，结论只作参考。
- 平台GMV对比时也只用线上实物口径（见 14.3.3）。

### 14.2.3 倒算线下商品零售增速（社零商品零售减线上实物）

**方法要点**：统计局不直接披露线下商品零售，用“商品零售总额减网上实物商品零售额”推算线下商品零售及其同比，判断渠道分化。

**操作步骤 / 拆分口径**

1. 取商品零售总额和网上实物商品零售额。
2. 线下商品零售额 = 商品零售总额 − 网上实物商品零售额；线下同比 = 本期线下额 ÷ 去年同期线下额 − 1（去年同期的两项数额，可由披露的同比增速反推）。
3. 对比线上实物同比与推算的线下同比，以及线下同比相对上月的变化。
4. 注明历史数据会修订，算出的增速仅作参考。

**关键指标与数据来源**：商品零售额、网上实物商品零售额、推算的线下商品零售同比；数据来自国家统计局。

**判断标准与推理链条**

- 线上反弹而线下继续下滑 → 整体社零走弱主要来自线下，线上更先触底。
- 线下降幅相对上月扩大（-1.2% → -4.5%）→ 线下仍在走弱，没有见底迹象。

**海豚案例**

- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）：5月线上实物反弹到2.6%，而推算的线下商品零售同比为-4.5%（上月-1.2%），结论是线上触底反弹、线下继续走弱，整体社零走弱主要来自线下。

**适用场景与注意事项**

- 适用于渠道结构分析（电商与线下零售）。
- 存在数据修订和口径误差，要用“推算”的措辞，结论保持谨慎。
- 与 14.2.4 的线上渗透率互为补充：一个看线下绝对走势，一个看线上相对份额。

### 14.2.4 线上渗透率同比变化，衡量线上的相对景气度

**方法要点**：线上增速下降不等于线上景气变差；用线上实物零售占社零（或商品零售）的渗透率及其同比变化，衡量线上相对整体的景气度。

**操作步骤 / 拆分口径**

1. 计算渗透率 = 线上实物零售额 ÷ 社零总额（或商品零售额）。
2. 计算渗透率同比变化（pct），并看变化幅度较上期是扩大还是收窄。
3. 与线上增速的变化对照：增速下降但渗透率同比继续提升，说明线上相对整体更有韧性。

**关键指标与数据来源**：线上实物零售渗透率、渗透率同比变化（pct）；数据来自国家统计局。

**判断标准与推理链条**

- 即使线上增速下降，只要渗透率同比继续提升，而且提升幅度扩大，就说明线上相对整体的景气度在改善，线上受到的压力比线下小。
- 渗透率同比提升幅度收窄甚至转负，说明线上也在失去相对优势。

**海豚案例**

- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：线上实物增速从6月3.9%降到7月3.3%，但渗透率同比仍提高约0.2pct，且幅度高于6月，判断线上更有韧性。

**适用场景与注意事项**

- 适用于电商平台的行业Beta判断。
- 渗透率受统计口径和大促时点影响，比较时需保持口径一致，并与 14.1.4 的大促校正配合。

### 14.2.5 剔汽车社零加限额以上分品类，按政策属性分组（国补、非国补可选、必选）

**方法要点**：先剔除汽车这个最大单项，看其他商品的真实表现，再把限额以上品类按政策属性分组，找出最差和最坚韧的品类，并解释个别异常。

**操作步骤 / 拆分口径**

1. 先看汽车同比，并使用统计局披露的“剔除汽车后的社零增速”，判断其他商品的真实表现（与上期对比看放缓幅度）。
2. 用限额以上分品类数据，按政策属性分三组：

| 分组 | 品类 |
|---|---|
| 国补品类 | 家电、家具、通讯器材、3C |
| 非国补可选品类 | 服装鞋帽、化妆品、金银珠宝、烟酒 |
| 必选品类 | 粮油食品、日用品、饮料 |

3. 每组看绝对增速和环比边际变化，找出最差和最坚韧的品类。
4. 解释个别异常：
   - 烟酒（送礼）、服装（过年新衣）的回落受春节影响；
   - 金银珠宝受金价影响；
   - 通讯受内存涨价和新机周期影响（量价拆分见 14.2.6）。

**关键指标与数据来源**：汽车零售同比、剔汽车社零同比、限额以上各品类同比与环比变化；数据来自国家统计局。

**判断标准与推理链条**

- 汽车拖累很大但剔汽车后放缓不多，说明其他商品没有同步恶化（如3月汽车跌超10%，剔汽车后3.2%，对比1-2月3.7%）。
- 国补品类走弱是政策退坡所致，属结构性；非国补可选品与必选品的环比下滑，才是需求面扩散的信号（见 14.3.1）。
- 分组后某一组突然改善（家电跌幅收窄、通讯强劲），要继续追问是需求还是价格（见 14.2.6）。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：汽车跌超10%，剔汽车后增速3.2%（1-2月3.7%），放缓不多；家电-5%、家具-9%，通讯强劲。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：汽车近-20%，剔汽车2.2%；家电-15%、家具-10%，金银珠宝约-20%，服饰和化妆品环比降3-4pct。
- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：汽车近-17%，剔汽车2.5%；家电跌幅收窄到不到-2%，通讯超20%。

**适用场景与注意事项**

- 适用于政策（补贴退坡）对消费结构影响的追踪。
- 分组方式可随政策变化调整（例如新增或取消补贴品类）。
- 异常品类的归因要单独说明（春节、金价、内存涨价、新机周期），避免把一次性扰动当成趋势。

### 14.2.6 量价拆分：销售额与出货量背离时识别涨价驱动

**方法要点**：某品类销售额增速异常时，引入第三方的量数据交叉验证，判断是量增还是价增；销售额高增而出货量走低，说明是涨价驱动，不代表需求强。

**操作步骤 / 拆分口径**

1. 发现销售额增速异常的品类（如限额以上通讯器材销售额7月增速超20%）。
2. 找第三方量数据（如IDC的国内手机出货量同比）交叉验证；销售额增速 ≈ 量增速 + 价格增速（同比的乘积关系：(1+量同比)×(1+价同比)−1）。
3. 若销售额高增而出货量同比走低，则高增来自价格上涨（内存等元器件大幅涨价，推动手机售价上调）。
4. 检查上游价格线索：内存价格、金价等。
5. 反向使用：用终端销售额与出货量的背离，验证上游涨价向终端的传导。

**关键指标与数据来源**：品类销售额同比、IDC手机出货量同比、内存价格、金价。

**判断标准与推理链条**

- 销售额高增 + 出货量走低 → 涨价驱动，不代表需求强。
- 内存涨价对手机需求的压制，4月开始显现；金银珠宝消费跳水，可能因为金价见顶回落。
- 推理链：上游元器件涨价 → 终端售价上调 → 销售额被推高 → 但销量受压制 → 销售额的高增并不代表需求强。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：初步猜测通讯增长来自内存涨价和新机周期。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：内存涨价压制需求开始显现；金银珠宝约-20%，可能与金价见顶回落有关。
- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：通讯超20%，但对照IDC的手机出货量同比走低，确认为涨价驱动，不代表需求强。

**适用场景与注意事项**

- 适用于消费电子、珠宝等受上游价格影响大的品类；也可以反过来，作为上游涨价向终端传导的验证。
- 第三方量数据（出货量）与统计局的限额以上口径不完全一致，只用于判断方向，不做精确拆分。
- 价格驱动的归因与持续性，在产业层面见 5.3。

### 14.2.7 楼市高频数据：成交量同比 + 成交均价 → 成交额（量价拆分）

**方法要点**：在财报之外，用月度或周度楼市高频数据前瞻下一季度的业绩：把成交量同比、核心城市均价、新房成交额合起来推算GTV趋势，判断下季压力大小。

**操作步骤 / 拆分口径**

1. 看主要城市二手房成交量同比：从高点近40%回落到个位数，说明政策脉冲的效果在消退。
2. 看核心城市（北京、上海）二手房均价较年初的变化：企稳反弹会支撑成交额。
3. 看新房成交额同比。
4. 量价合起来推算GTV趋势：成交额同比 ≈ (1+量同比)×(1+均价同比)−1，判断下季压力大小。
5. 再结合调研校正（如4月成交环比回落但同比仍为正）。

**关键指标与数据来源**：主要城市二手房成交量同比、北京和上海二手房均价（较年初）、新房成交额同比、月度调研。

**判断标准与推理链条**

- 成交量同比从高点回落到个位数：说明政策带来的是脉冲而非持续修复，量的支撑在减弱。
- 核心城市均价较年初企稳上涨：价格对成交额形成支撑，可部分抵消量的回落。
- 新房成交额仍同比大幅下滑：新房端压力未解除。
- 环比回落但同比仍为正：当季压力不大。

**海豚案例**

- 贝壳《“跪太久”贝壳》（2026-05-20）：4月主要城市二手房交易环比3月回落，但同比仍正增长，结合调研，判断Q2压力不大。
- 贝壳《一线再松绑》（2026-08-21）：存量房成交量增速从近40%降到个位数，依赖政策脉冲；北京、上海均价较年初上涨低个位数，成交额获得支撑；新房成交额仍同比下滑10%以上。

**适用场景与注意事项**

- 适合地产链公司（中介、平台等）。
- 高频数据样本城市有限，不能代表全国，需要与调研和公司口径交叉验证。
- 与财报口径的GTV并非一一对应，只作趋势和压力大小的判断。

**本节速查清单**

- [ ] 是否把社零拆成商品零售与餐饮收入，并以餐饮（受政策与涨价扰动小）作为景气度的“真实”参照？
- [ ] 统计口径是否有变更（如线上总口径改为“网上商品和服务零售额”）？比较时是否只用口径可比的序列（线上实物），并在文中加注口径说明？
- [ ] 是否倒算了线上服务的隐含增速与线下商品零售增速，并注明数据会修订、结果仅作参考？

## 14.3 扩散判断、前瞻跟踪与平台映射

> 本节导读：宏观数据点评的落脚点，是回答“这对行业、对平台个股意味着什么”。本节包含三组动作：判断疲软是结构性还是全面性并给各品类定阶段，用线上数据做前瞻并滚动修正预判（14.3.1、14.3.2）；把社零线上实物和分品类数据当作基准，衡量平台GMV是跑赢还是向大盘收敛、增速修复是否广泛，并用公司指引与业绩沟通互相印证（14.3.3 至 14.3.5）；最后把“宏观高频数据→公司需求”的思路延伸到就业与招聘领域（14.3.6）。本节依赖 14.1 的时间校正和 14.2 的结构拆分；估值与预期定价见 11.4，交叉验证与景气跟踪见 13.1。

### 14.3.1 “结构性→全面性”扩散判断，并定位各品类所处阶段

**方法要点**：连续几个月跟踪疲软从哪些品类开始、向哪些品类扩散，判断问题是“结构性”还是“全面性”，并给每类品类定位所处的周期阶段。

**操作步骤 / 拆分口径**

1. 找出疲软的起点品类：早期是汽车和国补品类（家电、家具）拖累，属于结构性问题。
2. 持续观察非国补可选品（服装、化妆品、烟酒）和必选品（粮油食品、日用品）是否也环比明显下滑；若是，则判断“从结构性转向全面性”。
3. 统计恶化品类的数量和各品类限额以上同比的环比变化，确认扩散范围。
4. 给每类品类定位周期阶段（见下表）。
5. 至少积累3个月数据后才确认趋势。

**品类阶段定位（海豚君的判断）**

| 品类 | 阶段定位 | 依据 |
|---|---|---|
| 家电、家具 | 受国补冲击已有达峰迹象，后续有边际改善苗头 | 国补冲击已出现达峰迹象 |
| 手机数码 | 仍在走向增长低点的路上 | 内存涨价；去年国补时点较晚 |
| 服装、食品饮料、日用品 | 处于扩散影响的早中期，绝对冲击不大，但触底改善的时间点偏后 | 属于扩散而来的影响 |

**关键指标与数据来源**：各品类限额以上同比的环比变化、恶化品类数量；数据来自国家统计局分品类零售数据。

**判断标准与推理链条**

- 只有汽车和国补品类拖累：结构性问题。
- 非国补可选品和必选品也环比明显下滑：转向全面性。
- 家电和通讯改善、而其他必选和可选全面下滑：从结构性扩散为普遍性，改善只来自政策或价格因素（见 14.2.6）。
- 阶段定位决定轮动顺序：先见底的品类（家电、家具）先出现边际改善，后扩散的品类（服装、食品饮料、日用品）触底更晚。

**海豚案例**

- 社零《4月社零点评：消费怎么办？》（2026-05-18）：首次指出疲软有扩散迹象。
- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）：判断扩散到近乎全品类，并给出各品类的阶段定位（家电、家具有达峰迹象，手机数码仍在走向低点，服装、食品饮料、日用品处于扩散早中期）。
- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：确认疲软从结构性扩散为普遍性，家电和通讯改善，而其他必选和可选品类全面下滑。

**适用场景与注意事项**

- 适用于消费周期研判和消费股的轮动顺序判断。
- 需要至少3个月的数据才能确认趋势，单月变化不足以下“全面性”结论。
- 分组与异常解释依赖 14.2.5，量价归因依赖 14.2.6。

### 14.3.2 线上作为前瞻指标，并对预判做滚动跟踪和修正

**方法要点**：把反应更灵活的线上零售当作整体消费的前瞻指标，每期对照上期预判做回溯，并据最新数据调整判断强度。

**操作步骤 / 拆分口径**

1. 以线上实物增速作为前瞻指标：整体社零继续走弱时，如果线上实物已触底反弹，说明“最差的时间可能就是现在”。
2. 每期对照上期预判做回溯，坦诚记录偏差（如“不幸言中”“甚至比预期更差”）。
3. 据最新数据调整判断强度：7月数据后，下调三季度回暖力度的预期，更明显的反弹推迟到四季度，但维持二季度为电商增速最低点的判断。
4. 给文章标题设置悬念式判断（倒春寒、黎明前的黑暗、昙花一现），对应所处的景气阶段。

**关键指标与数据来源**：线上实物增速拐点、前期预判与实际值的偏差。

**判断标准与推理链条**

- 推理链：线上反应灵活 → 先于整体触底；整体仍弱而线上已反弹 → 整体最差时点可能就是当前。
- 线上反弹需先经过 14.1.4 的大促与补贴校正，排除前置因素，再作为前瞻信号使用。
- 预判与实际的偏差，是调整判断强度的依据：不及预期则下调回暖力度、后移反弹时点。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：预判二三季度压力更大。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：回溯上期预判，数据不意外。
- 社零《5月社零点评：黎明前的黑暗？》（2026-06-16）：以线上触底作为前瞻，提出“黎明前的黑暗”。
- 社零《7月社零点评：回暖“昙花一现”？》（2026-08-17）：下调三季度回暖预期，更明显的反弹推迟到四季度，维持二季度为电商增速最低点的判断。

**适用场景与注意事项**

- 适用于连续性的宏观数据系列点评，能积累判断的可信度。
- 要坦诚记录预判偏差；标题的悬念式判断要对应真实的景气阶段，不为吸引眼球而改变结论。
- 基数低的月份要同时看环比（见 14.1.3）。

### 14.3.3 以社零线上实物增速作为电商大盘基准，判断平台GMV跑赢还是收敛

**方法要点**：把国家统计局社零“线上实物商品零售额”增速当作电商大盘增速，与平台GMV增速（或一致预期）对比，判断平台是跑赢大盘还是向大盘收敛。

**操作步骤 / 拆分口径**

1. 取社零线上实物商品零售额同比（月度和季度）作为大盘基准。
2. 取平台GMV增速或一致预期（如彭博一致预期的平台主站GMV增速）。
3. 计算领先幅度 = 平台GMV增速 − 大盘增速，逐季追踪。
4. 判断：领先幅度逐季缩窄，说明平台“向大盘收敛”，成长溢价应当下降，估值只能参考行业平均。
5. 前瞻：月度社零（如4月数据）加上同行指引，可以提前判断下一季度行业景气是否恶化。

**关键指标与数据来源**：社零线上实物商品零售额同比（月度和季度）、彭博一致预期的平台主站GMV增速、同行下季指引。

**判断标准与推理链条**

- 领先幅度持续缩窄 → 平台向大盘收敛 → 成长溢价下降 → 估值参考行业平均。
- 月度社零弱 + 同行指引弱 → 下一季度行业景气恶化，且可能成为市场新共识。

**海豚案例**

- 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：彭博一致预期拼多多主站2Q GMV增速4.5%，社零线上大盘2.6%，领先约1.9pct；领先幅度逐季缩窄，判断主站增长向大盘收敛的趋势没变，估值只能参考行业平均。
- 唯品会《唯品会：不增收也能增利，只是怕2Q坎难过》（2026-05-21）：从4月社零数据和唯品会及其他电商的指引可以看出，2Q电商景气迅速恶化已成新共识。

**适用场景与注意事项**

- 适用于中国电商平台的跟踪。
- 社零线上口径与平台GMV口径（含退货、虚拟商品等）不完全一致，只能看趋势和相对强弱，不宜做精确对比。
- 只使用线上实物口径作比较（见 14.2.2）。

### 14.3.4 社零分品类数据判断平台增速修复的广度

**方法要点**：用最新月度社零分品类增速判断改善的“广度”：若只有受补贴影响的品类改善，则以这些品类为主的平台反弹更明显，其他平台反弹有限。

**操作步骤 / 拆分口径**

1. 取最新月度社零分品类增速。
2. 判断改善是广泛的还是局限于少数品类：只有受补贴影响的品类（家电、手机）改善，而大部分品类仍在下滑。
3. 对应平台的品类结构：以这些品类为主的平台（京东）反弹更明显，其他平台反弹有限。
4. 结合去年同期基数，判断更明显的反弹会在哪个季度体现。

**关键指标与数据来源**：社零线上实物零售增速、分品类社零增速、去年同期基数。

**判断标准与推理链条**

- 推理链：补贴品类改善（家电、手机）+ 其他绝大多数品类增速仍下滑 → 修复不广 → 品类集中于补贴品类的平台（京东）受益更明显，其余平台反弹可能不明显。
- 去年三季度基数不低 → 更明显的反弹要到四季度才能体现（基数逻辑见 14.1.3）。

**海豚案例**

- 阿里《阿里狂投》（2026-08-21）：7月社零中家电和手机等国补影响大的品类在改善，其他绝大多数品类增速仍在下滑，因此除京东外的平台反弹可能不明显；去年三季度基数不低，更明显的反弹要到四季度。

**适用场景与注意事项**

- 适合电商和零售平台的季度前瞻。
- 需要对平台的品类结构有清楚的认识；品类分组方式见 14.2.5，量价归因见 14.2.6，避免把涨价驱动的“改善”当作需求修复。

### 14.3.5 用公司指引和业绩沟通交叉验证宏观数据，并映射到平台个股

**方法要点**：把宏观数据和头部公司管理层的表态互相印证，再反过来用宏观数据判断对个股的影响。

**操作步骤 / 拆分口径**

1. 取头部公司业绩沟通和指引（电商GMV和收入指引、品类结构），与同期宏观数据对照。
2. 互相印证：
   - 阿里一季度业绩沟通称3月电商增长走弱，与3月线上实物增速跳水吻合；
   - 京东指引电商营收增速从一季度约+5%恶化到二季度约-5%，与4月线上实物仅0.2%吻合，说明头部平台也认为二季度线上压力很大。
3. 反过来映射到个股：
   - 线上实物在一季度高、二三季度承压，会影响各电商平台对之后增长的判断；
   - 家电国补退坡，对以家电为主的平台（京东）是利空。
4. 注意公司口径与统计局口径的差异。

**关键指标与数据来源**：线上实物零售增速、平台电商GMV和收入指引、品类结构。

**判断标准与推理链条**

- 宏观数据与公司指引方向一致 → 判断更可信，可提升对行业景气的把握。
- 品类结构决定映射方向：国补退坡 → 家电占比高的平台承压更大。
- 宏观数据领先于公司披露：可用于前瞻性地调整对平台之后增长的判断。

**海豚案例**

- 社零《3月社零点评：消费倒春寒？问题有多大》（2026-04-16）：与阿里一季度业绩沟通中3月电商增长走弱相互印证。
- 社零《4月社零点评：消费怎么办？》（2026-05-18）：与京东二季度电商营收约-5%的指引相互印证。

**适用场景与注意事项**

- 适用于宏观点评落到个股（电商、家电、汽车）。
- 公司口径（GMV、收入、含退货或虚拟商品）与统计局口径存在差异，只作方向印证，不做数值对等。
- 映射到估值与预期定价的方法见 11.4。

### 14.3.6 用宏观就业指标和第三方招聘帖数据验证行业需求，并识别细分分化

**方法要点**：先用多个劳动力市场指标判断整体就业强弱，再用第三方招聘帖数据看企业招聘需求，识别细分行业分化，用来解释公司在宏观承压下为什么还能增长。

**操作步骤 / 拆分口径**

1. 看多个劳动力市场指标：失业率、新增就业、居民失业预期，判断整体就业强弱。
2. 用第三方招聘帖数据（中信自行采集，不含Boss直聘）看企业的招聘需求，比较同比变化。
3. 识别细分行业分化：AI新兴行业、蓝领制造业的需求仍有增加。
4. 把宏观与细分结合，解释公司在宏观承压下的表现：结构性需求加份额提升。

**关键指标与数据来源**：失业率、新增就业、失业预期、招聘帖数量同比（中信自行采集的第三方招聘帖口径）。

**判断标准与推理链条**

- 推理链：整体就业弱（宏观指标）+ 企业招聘需求同比仍小幅增加（招聘帖口径）→ 劳动力供需在不同行业之间错位 → 结构性需求（AI新兴行业、蓝领制造业）支撑招聘平台的需求 → 再叠加份额提升，公司能在宏观承压下继续增长。
- 招聘帖数据不含Boss直聘，用它判断行业需求时，应说明该口径限制。

**海豚案例**

- Boss直聘（2026-05-20）：今年初就业市场整体比去年弱，但企业招聘需求（中信招聘帖口径）同比仍小幅增加，劳动力供需在不同行业之间错位，用结构性需求加份额提升解释公司的增长。

**适用场景与注意事项**

- 适用于招聘、人力资源、灵活用工类公司。
- 招聘帖数据是第三方采集，样本与口径有限；不含Boss直聘，要避免把行业口径与公司自身数据混为一谈。
