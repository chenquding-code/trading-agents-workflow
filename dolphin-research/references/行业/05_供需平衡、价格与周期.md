## 5.1 供需平衡表与缺口判断

> 本节导读：本节解决“这个行业到底缺不缺、缺多少、缺到什么时候、这个缺口是真的还是被放大了”的问题，是把第3章的需求测算和第4章的供给测算合成一张平衡表并下结论的一步。研究存储、锂电、酒店等周期品，或算力、电力这类基础设施“短缺”议题时，每次更新需求或供给假设后都要回到这里重算缺口。缺口判断出来后，接 5.2（用价格验证）、5.3（解释价格为何变动、能否持续）和 5.4（判断周期位置与拐点）；需求与供给本身怎么测，见第3章和第4章。

### 5.1.1 供需缺口双视角：相对增速与绝对缺口

**方法要点**：判断涨价能否持续，同时用“需求增速是否持续快于供给增速”（相对视角）和“供给相对需求还差多少、供给充足度是否已低于正常水位”（绝对视角）两套口径互相校验，再据此给各品类的确定性排序。

**操作步骤 / 拆分口径 / 公式**

1. 视角一，相对增速（大行常用）：按品类列出未来两三年的需求同比增速与供给同比增速并排比较。只要需求增速持续快于供给增速，缺口和涨价就会持续。
2. 视角二，绝对量（海豚君补充）：缺口 =（需求 − 供给）/ 供给，需求与供给用同一物理量（GB、EB）；同时看供给充足度或库存水位是否已低于正常水位。即使缺口在数据里还没有明显体现，水位下移也是紧张的先兆。
3. 把两个视角叠加：相对视角回答“方向和持续性”，绝对视角回答“缺口有多大”，合在一起得出“供不应求能拉到哪一年”，并给各品类缺口的严重程度排序，即“确定性排序”。

相对增速视角的数据（需求增速 vs 供给增速）：

| 品类 | 2026年 | 2027年 |
|---|---|---|
| DRAM | 需求+25% > 供给+18% | 需求+23% > 供给+18.5% |
| NAND | 需求+18% > 供给+16% | 需求+21% > 供给+20% |
| HDD | 需求+33% > 供给+29% | 需求+23% > 供给+19% |

绝对缺口视角的数据：DRAM 2026年缺口尚未明显体现，但供应充足度已低于正常水位，2027年缺口可能扩大到约2%；NAND 2026-2027年缺口维持在5-6%。

**关键指标与数据来源**：需求量与供给量（GB/EB）、需求增速、供给增速、缺口 =（需求 − 供给）/ 供给、供给充足度或库存水位。增速预测取自大行常用口径，绝对缺口为海豚君自行测算。

**判断标准**

- 相对视角：需求增速 > 供给增速即缺口和涨价持续。三类产品在2026、2027年全部满足这一条件（增速差分别为DRAM约7和4.5个百分点、NAND约2和1个百分点、HDD约4和4个百分点）；一旦需求增速降到供给增速以下，缺口开始收窄，转入 5.4 的拐点判断。
- 绝对视角：缺口为正且在扩大，或供给充足度低于正常水位，说明紧张在加剧。
- 推理链条：相对视角只告诉你“剪刀差”的方向，绝对视角补上“水位和缺口大小”。两者同时指向紧缺的品类，确定性最高。NAND的2027年增速差只剩约1个百分点，但海豚君的绝对视角仍判断缺口维持在5-6%，说明已存在的缺口不会因为增速差收窄就立刻消失，要看累计缺口。
- 本案例的结论：a）供不应求要拉到2027年；b）DRAM 2027年缺口更严峻，NAND缺口5-6%；并据此给各品类的确定性排序。

**海豚案例**

- 存储行业（DRAM、NAND、HDD）《99%计算闲置？推理时代，存力比算力香！》（2026-01-14）：先引用大行的相对增速视角（DRAM 2026年需求+25%>供给+18%、2027年+23%>+18.5%；NAND 2026年+18%>+16%、2027年+21%>+20%；HDD 2026年+33%>+29%、2027年+23%>+19%），再补充绝对量视角（DRAM 2027年缺口可能扩大到约2%，NAND 2026-2027年缺口5-6%），得出“供不应求拉到2027年”“DRAM 2027年缺口更严峻”的核心判断。

**适用场景与注意事项**：适用于所有周期品。相对增速视角忽略起点库存，绝对缺口对基数假设敏感，最好结合库存数据一起看（见 5.1.3、5.4.6）；缺口大小要与价格走势互相验证（见 5.2.1）。

### 5.1.2 分产品年度供需比表→价格方向映射与二阶反馈

**方法要点**：用“需求/供给”的供需比衡量紧张度，按产品做年度时间序列表，把每个产品的供需比轨迹映射成价格方向，再叠加“价格反过来改变供需”的二阶反馈，避免把供需表直接当成价格预测。

**操作步骤 / 拆分口径 / 公式**

1. 建表：行为产品（全行业DRAM含HBM、常规DDR、HBM含客户备货），列为年份，值为供需比 = 需求 / 供给；同时给出缺口或过剩的绝对量（Gb）。
2. 找峰值与穿越点：供需比大于1为缺口，小于1为过剩；找出每个产品供需比见顶的年份，以及穿越1的年份。
3. 映射价格方向：供需比抬升并处于峰值的年份涨价最猛；仍大于1但回落，涨价放缓；穿越1进入过剩，回落压力加大。结构上要分产品映射，因为产品之间此消彼长。
4. 叠加二阶反馈：价格回落会让被压制的终端需求反弹，价格差会让厂商把产能从一个产品转向另一个，两者都会反过来修正供需比。
5. 回头修正表格：把二阶反馈带来的需求回补和产能转产写进下一版平衡表。

供需比表：

| 产品 | 2025 | 2026 | 2027 | 2028 |
|---|---|---|---|---|
| 全行业DRAM（含HBM） | — | 见顶，需求比供给多约13% | 大体平衡 | 略微过剩 |
| 常规DDR | 1.07 | 1.14 | 0.98 | 0.92 |
| HBM（含客户备货） | — | 约1.04 | 约1.06-1.07 | 约1.06-1.07 |

绝对量：常规DDR 2026年缺口约490亿Gb，2028年过剩约410亿Gb。

**关键指标与数据来源**：供需比、缺口或过剩量（Gb）、HBM单GB价格（市场预期从约15美元升至20-30美元）。

**判断标准**

- 价格映射：常规DRAM涨价2026年最猛、2027年放缓、2028年回落压力加大；HBM（含客户备货）供需比2027-28年仍在1.06-1.07，因此2027-28年仍有涨价支撑（市场预期单GB从约15美元升至20-30美元）。
- 二阶反馈：DDR价格回落，被压制的终端需求反弹，同时厂商加快DDR向HBM转产，结果是DDR稍紧、HBM稍松，即上面的供需比会向中间收敛一些。
- 推理链条：全行业供需比2026年见顶，意味着最猛的涨价阶段是2026年；市场对价格拐点的定价会提前于供需比穿越1。

**海豚案例**

- 海力士《海力士：超级AI加持，存储神话还能牛多久？》（2026-10-08，第2.3节）：给出上表全部供需比，即全行业DRAM（含HBM）2026年见顶、2027年大体平衡、2028年略微过剩；常规DDR 1.07→1.14→0.98→0.92（2026年缺口约490亿Gb，2028年过剩约410亿Gb）；HBM约1.04→1.06-1.07；据此映射常规DRAM价格和HBM价格，并补充二阶反馈（DDR回落→需求反弹+转产HBM，DDR稍紧、HBM稍松）。

**适用场景与注意事项**：适用于周期品的价格预测和多产品并存的行业（常规产品与新品此消彼长）。供需比表只是静态推演，必须与库存调整（见 5.1.3）和反馈机制结合；价格的实际追踪与验证见 5.2.1；供需比对周期位置的含义见 5.4。

### 5.1.3 剔除渠道补库存后的“真实缺口”与次年去库存风险

**方法要点**：涨价周期里下游会提前备货甚至重复下单，库存放大了供需波动，需要把客户补库存从名义缺口里扣掉，看“真实缺口”有多大，并推演次年去库存对价格的冲击。

**操作步骤 / 拆分口径 / 公式**

1. 取名义缺口（如常规DDR 2026年缺口约490亿Gb，见 5.1.2）。
2. 取客户补库存量（UBS测算：2026年客户补库存约400亿Gb，约占DDR总需求的10%），计算补库存占缺口比例 = 补库存 / 名义缺口，真实缺口 = 名义缺口 − 补库存。
3. 结论：若测算准确，2026年DDR缺口约八成实际来自补库存，紧缺有“水分”。
4. 推演次年风险：补库存是否延续取决于下游对此后供需紧张度的预测；若转为去库存，叠加2027年常规DDR已基本平衡，会出现比平衡表更显著的供过于求。
5. 把价格拐点前移：常规DRAM的跌价压力从原本判断的2028年提前到2027年。

**关键指标与数据来源**：客户补库存量（Gb）、占需求比例、供需比。数据来源为UBS测算；渠道库存数据可得时更可靠。

**判断标准**

- 补库存占名义缺口的比例越高，缺口的“水分”越大，价格对下游预期转向越敏感。
- 推理链条：缺口大部分来自补库存 → 补库存依赖下游对未来紧张度的判断 → 一旦预期转向（去库存）就是需求与库存的双重收缩 → 价格拐点前移。
- 这一步不是否定缺口，而是修正缺口的质量：缺口的持续性要看终端真实消耗，而不是客户下单量。

**海豚案例**

- 海力士《海力士：超级AI加持，存储神话还能牛多久？》（2026-10-08，第2.3c节）：引用UBS测算2026年客户补库存约400亿Gb（约占DDR总需求10%），指出2026年DDR缺口约八成来自补库存；若2027年去库存，叠加常规DDR已基本平衡，常规DRAM跌价压力可能从2028年提前到2027年。

**适用场景与注意事项**：适用于涨价周期中的需求真实性检验；渠道库存数据可得时更可靠，否则补库存数只能依赖第三方估算，要注明来源。库存周数与跌价预期的自我强化机制见 5.4.6。

### 5.1.4 把需求与供给统一折算成同一口径（GW）再比较

**方法要点**：需求端的驱动是AI模型公司的ARR，供给端是云厂商的Capex，量纲不同，直接比较看不出未来是持续供不应求还是会供过于求；把两端都折算成同一个算力规模单位（GW）后再比较。

**操作步骤 / 拆分口径 / 公式**

1. 需求侧：把AI Lab的ARR（收入）折算为所需算力规模（GW）。
2. 供给侧：把云厂商的Capex折算为新增可供给的算力规模（GW）。
3. 统一口径后逐年比较，时间跨度上预测做到2030年，但重点只看到2028年，再往后可见性太低，基本没有意义。
4. 分两个视角使用：①行业层面的供需，决定未来竞争格局和产业链议价权如何变化；②单个云厂层面，看其云收入预期是否充分反映了它分到的AI算力需求，以及它的算力供应是否足以支撑收入释放。

**关键指标与数据来源**：需求与供给的GW规模、ARR、Capex。

**判断标准**

- 统一口径之后，比较“需求GW”与“可供给GW”的相对大小，得到供需比（见 5.1.5）。
- 行业层面：持续供不应求则议价权在供给方（云厂、芯片厂），转为供过于求则议价权向需求方转移。
- 单家云厂层面：收入预期是否已反映它分到的算力需求；供应是否足以支撑收入释放。
- 推理链条：换算系数（单GW对应的收入、不同芯片功耗）对结果影响很大，因此结论要同时给出系数的假设并做敏感性。

**海豚案例**

- AI算力行业《AI 算力：从盛宴到 “剩宴”？》（2026-07-13）：第三部分把需求（AI Lab ARR）与供给（云厂Capex）统一折成GW口径后再比较，预测做到2030年、重点看到2028年，分行业与单个云厂两个视角。

**适用场景与注意事项**：适用于AI基建周期判断。GW换算系数（单GW收入、不同芯片功耗）对结果影响很大，必须交代假设。需求与供给各自如何测算，见 3.3 与 4.3；统一口径之后如何解读，见 5.1.5。

### 5.1.5 用供需比时间序列检验市场隐含预期（而非做预测）

**方法要点**：计算供需比的时间序列，不是为了预测“将会过剩”，而是反推“按当前假设，市场需要相信什么才能支撑现在的Capex外推”，再评估这种信念是否合理。

**操作步骤 / 拆分口径 / 公式**

1. 沿用 5.1.4 的GW口径，计算供需比 = 需求 / 供给，并按年排成序列。
2. 读序列形状：2024到2026年从87%升到93%（供需趋紧），2027年回到2024年水平，2028年起明显供过于求且缺口越来越大（2028年需求约53GW，可外租供给73GW，按此换算需求约为供给的73%）。
3. 把序列与“市场对新增算力和Capex在2028年及以后仍维持高位的线性外推”对照：按当前假设的AI收入预期（2030年两大AI Lab合计约5000亿美元年收入），撑不起这一外推。
4. 反推隐含假设：市场已提前计入了一块“现在看不见、但相信一定存在”的增量需求，用情景测算得出“要维持当前Capex需要多少隐含AI收入”。
5. 评估这种信念合理与否，并给出推论：如果未来1到2年AI发展没那么快，算力建设和云厂Capex可能在2027年见顶，即便之后发现新场景再重新抬升。

**关键指标与数据来源**：需求/供给比、GW缺口、维持当前Capex所需的隐含AI收入。

**判断标准**

- 供需比的绝对数值不重要（测算本身预测不准），重要的是它暴露的隐含假设：序列显示2028年起过剩，而Capex预期仍在外推，说明价格里已包含不可见增量。
- 若隐含假设需要的需求明显高于可见收入预期，则顶部风险上升；若可见需求能覆盖，则外推合理。
- 推理链条：供需比序列 → 对比Capex线性外推 → 差额就是“需要相信的增量” → 判断这块增量是否可信 → 推出Capex见顶时点的风险。

**海豚案例**

- AI算力行业《AI 算力：从盛宴到 “剩宴”？》（2026-07-13）：供需比从2024年87%升到2026年93%，2027年回到2024年水平，2028年需求约53GW对可外租供给73GW、缺口扩大；强调有价值的信息不是“将会过剩”，而是市场已提前计价一块不可见增量，若AI发展不及预期，Capex可能在2027年见顶。

**适用场景与注意事项**：适用于判断周期顶部风险和检验市场预期。测算本身预测不准，价值在于把隐含假设暴露出来；解读时不要把序列当作确定性预测。与 5.4.11（软件需求非线性对物理供给线性）、5.4.12（回本期）配合，用来判断集中投放期与Capex见顶。

### 5.1.6 次年行业供需平衡：需求（渗透率/销量/装机）vs 有效产能增速 + 政策供给约束

**方法要点**：当年业绩已被股价定价后，争论焦点转向次年；需求端拆下游渗透率、销量和装机，供给端测算行业有效产能增速并加入政策对供给的约束，与上一轮过剩周期对比，判断利润率回落的幅度。

**操作步骤 / 拆分口径 / 公式**

1. 需求端分拆：新能源车（渗透率已高、增速放缓是共识）；储能（政策调整风险、第三方机构预测；储能出货领先安装约6个月）。
2. 供给端：测算行业有效产能增速（有效产能而非名义产能）。
3. 加入政策对供给的约束：扩产审批收归中央，新增产能自2027H2起收紧。
4. 与上一轮过剩周期（2023-2024年价格战）对比，判断利润率回落的幅度和是否重演价格冲击。

**关键指标与数据来源**：新能源车渗透率与销量增速、储能需求增速（JPM预测）、行业有效产能增速、全球锂电需求增速。

**判断标准**

- 需求增速放缓至中高位而有效产能增速偏高时，利润率有回落压力；回落幅度取决于新增产能被约束的程度。
- 推理链条：车端渗透率已高、销量增速放缓是共识 → 储能是边际增量但有政策调整风险，出货领先安装约6个月，出货放缓最早可能在2027H2出现 → 供给端有效产能或增长约40%，但新增产能自2027H2起收紧 → 不太可能重演2023-24年的价格冲击。
- 对比上一轮：以2023-2024价格战作为基准，判断本轮是“回落”还是“再次过剩”。

**海豚案例**

- 宁德（2026-07-25）：国内新能源车渗透率2026年59%、2027年64%，销量增速11%/8%；JPM预测国内储能需求增速2027年约25%、2028年约4%，出货放缓最早可能在2027H2出现；2027年行业有效产能或增长约40%；全球锂电需求增速2027年超20%（乐观25%）vs 2026年45%；新增产能自2027H2起收紧，不太可能重演2023-24年的价格冲击。

**适用场景与注意事项**：适用于周期行业的年度展望。要同时交代需求预测来源（如JPM）和口径差异（有效产能 vs 名义产能）；产能扩张与审批约束的追踪见 4.2、4.5；政策本身的拆解见第10章。

### 5.1.7 供给增速对比正常中枢，加需求恢复度横向比较

**方法要点**：把行业矛盾定位为“供给释放太快、价格体系被冲散”而非需求不足，用供给增速对比正常中枢判断降温程度，再用需求恢复度与其他可选消费横向比较，判断价格战是否缓和、谁先受益。

**操作步骤 / 拆分口径 / 公式**

1. 供给端：取全国酒店房间数同比增速，看它从高点回落的轨迹，并对比3%-5%的正常水平，判断降温程度。
2. 需求端：取文旅部人均出游次数同比、旅游恢复至2019年的比例。
3. 横向比较：把旅游恢复度与餐饮、零售等其他可选消费的恢复度对比，判断需求是否真的偏弱。
4. 推理链条落到公司层：供给降温 + 需求修复 → 价格战缓和 → 中高端占比高、会员强、收益管理成熟的头部先受益。

**关键指标与数据来源**：全国酒店房间数同比增速、文旅部人均出游次数、恢复至2019年的百分比、餐饮与零售恢复度。

**判断标准**

- 供给增速高于正常中枢（3%-5%）越多，价格体系越容易被冲散；增速持续回落向中枢靠拢，说明降温。
- 需求恢复度高于其他可选消费，说明问题不在需求，而在供给。
- 推理链条：矛盾在供给侧 → 供给增速回落 + 需求修复 → 价格战缓和 → 头部先受益。

**海豚案例**

- 华住（2026-05-15）：全国酒店房间数增速由2025年11月的9%回落到约6.5%（正常水平3%-5%）；Q1人均出游3.2次、+41%；1-4月旅游恢复至2019年的128%，高于餐饮115%、零售108%。

**适用场景与注意事项**：适用于酒店、出行、景区等供给周期显著的行业；统计口径需稳定。供给增速要对比“正常中枢”而不只看绝对值；需求恢复度基准年选取（如2019年）要一致。

### 5.1.8 储备裕度法测算可靠性缺口

**方法要点**：用储备裕度这一行业基准，把“新增峰值负荷”和“新增有效容量”的差距倒算成可靠性缺口，用于电力等需要冗余的基础设施。

**操作步骤 / 拆分口径 / 公式**

- 公式：储备裕度 =（有效总容量 − 峰值负荷）/ 峰值负荷。行业基准线通常为15%，用来保证机组故障、预测误差、极端气候等最差情景下仍有足够缓冲。
- 步骤：
  1. 假设未来系统备用率与2024年持平（15%）。
  2. 需求端设三档情景：新增峰值负荷105、140、180GW。
  3. 供给端取新增有效容量约28GW。
  4. 在保持15%裕度的前提下，倒算2030年美国电力系统的可靠性缺口。
- 结果：低、中、高需求情景下缺口分别约109GW、149GW、195GW。

**关键指标与数据来源**：有效总容量、峰值负荷、储备裕度（15%基准）、缺口（GW）。

**判断标准**

- 缺口为正说明在15%的备用率约束下，有效供给追不上负荷增长；缺口越大，需要的新增有效容量越多。
- 三档缺口之间的差额约等于峰值增量乘以1.15（35GW×1.15≈40GW，40GW×1.15≈46GW），说明裕度要求使每1GW新增负荷需要约1.15GW有效容量；因此需求情景的高低对缺口的影响，比供给新增的不确定性更大。
- 要用有效容量（而不是铭牌容量）：风光等只能做电量替代，有效容量折扣大（见 5.1.9）。

**海豚案例**

- 北美电力《AI竞赛终局：电力说了算？》（2026-02-09）：假设备用率与2024年持平为15%，需求端新增峰值105、140、180GW，供给端新增有效容量约28GW，倒算2030年美国电力系统可靠性缺口分别约109GW、149GW、195GW。

**适用场景与注意事项**：适用于电力及其他需要冗余的基础设施的供需缺口测算。结果对“基准裕度”“有效容量折算”和“需求情景”三类假设敏感，使用时要三档情景并列给出。

### 5.1.9 缺电成因“需求端—供给端—电网侧”三端结构性拆解

**方法要点**：对基础设施“短缺”议题，先定性是结构性矛盾还是周期性失衡，再从需求端、供给端、电网侧三端分别拆原因，汇总后才进入“如何破解”和“谁是解法”。

**操作步骤 / 拆分口径 / 公式**

1. 先定性质：在系列首篇就把“缺电”定性为结构性矛盾，而不是周期性的短期失衡；后续每篇开头复述这一定性，作为全系列的逻辑锚点。
2. 需求端：看两股驱动叠加，即制造业回流和AI数据中心的刚性负荷，判断需求进入加速增长通道、峰值负荷压力陡增。
3. 供给端：看传统高可靠基荷电源持续退役，以及风光只能做“电量替代”、补不上“容量缺口”，结论是有效供电能力不足。
4. 电网侧：看设施老化、投资缺位、关键设备短缺，以及建设周期与需求错配。
5. 三端结论汇总，然后再进入“如何破解”和“谁是解法”。分析顺序：先定性质（结构性或周期性），再拆三端，最后推对策。

| 端 | 拆什么 | 结论 |
|---|---|---|
| 需求端 | 制造业回流 + AI数据中心刚性负荷 | 需求加速增长，峰值负荷压力陡增 |
| 供给端 | 基荷电源持续退役；风光只能电量替代、补不上容量缺口 | 有效供电能力不足 |
| 电网侧 | 设施老化、投资缺位、关键设备短缺，建设周期与需求错配（并网排队3-7年） | 瓶颈在输送与并网 |

**关键指标与数据来源**：电力需求增速、峰值负荷、基荷电源退役量、风光装机及有效容量、并网排队时长（3-7年）、电网投资。

**判断标准**

- 结构性短缺：三端同时存在长期原因，并且建设周期远长于需求增长，对应长周期投资机会；周期性短缺：某一端的临时失衡，更多是价格交易机会。
- 推理链条：三端各自指向“不够”，且彼此叠加（需求加速、有效供给不足、电网输送跟不上）→ 定性为结构性矛盾 → 解法也必须来自长周期的供给与电网建设。

**海豚案例**

- AIDC电力《AI 终极瓶颈：算力狂奔遇“超级电荒”，燃气轮机成幕后大 Boss？》（2026-04-09）：以复述上篇《AI 竞赛终局：电力说了算？》的三端结论开篇。
- AIDC电力《AI 电荒突围：谁能替代重燃？》（2026-04-14）：开头再次复述“非短期供需失衡而是结构性矛盾”。

**适用场景与注意事项**：适用于电力、资源品等基础设施类“短缺”议题。前提是能区分结构性和周期性。局限：三端都是定性描述，缺少统一的量化缺口测算，需要与 5.1.8（储备裕度法）搭配把缺口量化；也可用 5.1.10 的三类外部证据佐证严重性。

### 5.1.10 价格信号 + 资本行为 + 政策时间线，佐证供需矛盾的严重性

**方法要点**：不依赖单一测算，用三类外部证据交叉定性供需紧张的程度——价格信号、资本行为、政策时间线，再引用产业领袖与第三方预测加固。

**操作步骤 / 拆分口径 / 公式**

1. 价格信号：找最能反映稀缺定价的价格。美国最大区域电网PJM的容量拍卖价格从28.92美元/MW-day暴涨到269.92美元/MW-day，约9倍，说明定价从“风险溢价”转向“生存恐慌”。
2. 资本行为：看供给方和需求方怎么花钱。燃气轮机订单爆发，卡特彼勒、三菱重工激进扩产；本质是科技巨头“弃网自保”，用自备电源绕开公共电网。
3. 政策时间线：按时间排政策动作。2025年1月白宫宣布能源紧急状态；4月强制电网动用一切可用能源（煤电、气电重回一线）；9月能源部启动电力加速计划缩短审批。
4. 引用产业领袖表态：纳德拉称供电能力是比芯片更大的瓶颈；黄仁勋称电力可用性将决定AI扩展的规模和速度。
5. 引用第三方预测：高盛预测2027年AI服务器单机架功率密度是五年前普通云服务器的50倍。

**关键指标与数据来源**：PJM容量拍卖价格、燃气轮机订单、设备厂扩产、政策事件、机架功率密度。

**判断标准**

- 价格信号最领先，政策和资本行为用来确认；三类证据同向才能下“供需矛盾严重”的结论。
- 价格从“风险溢价”到“生存恐慌”是定价逻辑的质变，而不只是涨幅大；资本行为从“采购”到“自建”说明买方已不再信任公共供给；政策从“鼓励”到“紧急状态”说明问题已上升到国家层面。

**海豚案例**

- 北美电力《AI竞赛终局：电力说了算？》（2026-02-09）：以PJM容量拍卖价格9倍跳涨（28.92→269.92美元/MW-day）、燃气轮机订单爆发（卡特彼勒、三菱重工扩产）、2025年1月/4月/9月的政策时间线，加上纳德拉、黄仁勋的表态和高盛的机架功率密度预测，论证缺电的严重性。

**适用场景与注意事项**：适用于判断任何资源品或基础设施的紧缺程度。三类证据的时点要对齐，避免用后发的政策去解释先发的价格；严重性判断之后的量化缺口见 5.1.8，价格变动的归因见 5.3。

**本节速查清单**

- [ ] 同时用了相对增速（需求增速 vs 供给增速）和绝对缺口（缺口比例、供给充足度）两个视角，并分品类给出确定性排序
- [ ] 供需比表按产品拆分（常规产品与新品、全行业与分结构），并把供需比轨迹映射成价格方向，同时检查二阶反馈（需求回补、转产）
- [ ] 名义缺口里是否含渠道补库存，剔除后的真实缺口是多少，次年去库存会不会让价格拐点前移
- [ ] 需求与供给是否折成同一口径（如GW）再比较，换算系数的假设是否交代并做了敏感性
- [ ] 供需比序列是用来暴露“市场隐含预期”（需要相信的增量需求），而不是当作确定性预测
- [ ] 次年平衡表是否同时放入需求端渗透率/销量/装机、有效产能增速和政策供给约束，并与上一轮过剩周期对比
- [ ] 供给增速是否对比了正常中枢，需求恢复度是否与其他可选消费横向比较
- [ ] 基础设施缺口是否用储备裕度（基准15%）三档情景倒算，并区分结构性与周期性短缺
- [ ] 严重性是否有价格信号、资本行为、政策时间线三类证据互相验证

## 5.2 价格追踪与价格信号

> 本节导读：本节解决“用什么价格、怎么追、读出什么信号”的问题：价格是验证供需判断的最终指标，也是最领先的信号。研究存储、成熟制程、云算力、模型Token等任何价格驱动的行业时，先在本节建立“代表性规格 + 现货/合约/长协 + 第三方预测”的价格仪表盘。价格为什么涨、能不能持续，见 5.3；价格所处的周期位置，见 5.4；缺口本身的测算，见 5.1。AI模型API/订阅的定价策略不在本节，见 9.4。

### 5.2.1 代表性规格的现货价与合约价追踪，并与股价对照

**方法要点**：选代表性规格，同时追踪现货价和合约价，量化涨幅倍数，把价格作为供需判断的最终验证指标，再与相关公司股价对照，看市场是否已经定价。

**操作步骤 / 拆分口径 / 公式**

1. 选代表性规格：如DDR5（16Gb 2Gx8，4800/5600Mbps）、NAND Flash（32Gb 4Gx8 MLC），统一规格才能前后可比。
2. 追踪现货价：记录起点和当前点，计算涨幅倍数。
3. 追踪合约价：引用TrendForce最新合约价，统一成单GB价格（$/GB），便于不同品类比较，并对比同容量售价差。
4. 追踪新品合约价预期：如HBM合约价。
5. 阶段复盘：定期回头复算涨幅倍数（如9月复盘半年涨幅）。
6. 与股价对照：把价格涨幅与美光、海力士等股价涨幅放在一起，判断价格-股价是否同步。

数据点：

| 项目 | 起点 | 当前 | 涨幅 |
|---|---|---|---|
| DDR5现货（16Gb 2Gx8，4800/5600Mbps） | 2025年9月初约6美元 | 31美元 | 5倍以上；9月复盘半年涨约7-9倍 |
| NAND Flash现货（32Gb 4Gx8 MLC） | 2025年初2.3美元 | 4.27美元 | +85%；9月复盘涨4-5倍 |
| DDR5合约价（TrendForce） | — | 单GB约16美元 | — |
| NAND（MLC）合约价（TrendForce） | — | 单GB约1.9美元 | 同容量售价差DDR5与NAND在8倍以上 |
| HBM合约价 | 15-17美元/GB | 据报道有望上调到20-30美元/GB | — |

股价：美光、海力士半年一度涨约10倍。

**关键指标与数据来源**：DDR5与NAND现货价、合约价（$/GB）、HBM合约价、涨幅倍数、相关股价涨幅。合约价来自TrendForce，现货价来自行业报价。

**判断标准**

- 价格是验证供需判断的最终指标：缺口判断（5.1）应能在价格上看到兑现，价格不跟说明缺口判断有问题。
- 现货价领先合约价、波动更大，二者要区分：现货价先动代表边际紧张，合约价体现真实成交与长协。
- 价格与股价对照：股价半年涨约10倍而价格涨约7-9倍（DDR5）、4-5倍（NAND），说明市场已经把大量涨价预期提前计入，此后要看价格斜率而非高度（见 5.4.1）。

**海豚案例**

- 存储行业《99%计算闲置？推理时代，存力比算力香！》（2026-01-14）：DDR5现货从2025年9月初6美元涨到31美元（5倍以上），NAND Flash（32Gb 4Gx8 MLC）从2025年初2.3美元涨到4.27美元（+85%），用价格验证“供不应求”判断。
- 存储行业《存力接棒算力，HBM为什么“脱颖而出”？》（2026-09-17）：9月复盘，DDR5半年涨约7-9倍、NAND涨4-5倍，HBM合约价据报道有望从15-17美元/GB上调到20-30美元/GB，美光、海力士半年一度涨约10倍。
- 英伟达与存储《从HBM限高到NAND加量，英伟达vs存力到底谁拿捏谁？》（2026-09-29）：引用TrendForce最新合约价，DDR5单GB约16美元、NAND（MLC）单GB约1.9美元，同容量售价差8倍以上。

**适用场景与注意事项**：适用于存储等大宗型半导体。现货价领先合约价、波动更大，二者要区分；单一规格不能代表整体ASP，要说明所选规格的代表性。

### 5.2.2 第三方价格预测与机构共识/分歧梳理（按时间段划分共识区和分歧区）

**方法要点**：引用第三方价格机构对下季合约价的预测，把主流机构观点按时间段划分为“共识区”和“分歧区”，再给出自己对分歧区的边界判断。

**操作步骤 / 拆分口径 / 公式**

1. 引用第三方机构（如TrendForce）对下季合约价的预测：DRAM、NAND四季度仍为两位数环增。
2. 把主流机构对各年份价格的判断按时间段分类：共识区（“本轮存储价格到2027年下半年仍上涨”）与分歧区（2028年后的价格判断有明显分歧）。
3. 给出自己的边界判断：在Agent AI等增量需求和5年期长约地板价的保障下，即使相对悲观的预期也不会出现2028年“崩盘式下滑”。
4. 把管理层表态（2027、2028年更紧）作为对分歧区的“定心丸”。

**关键指标与数据来源**：TrendForce合约价环比预测；机构对各年份价格的共识与分歧；长约地板价；管理层对未来年份供需的表态。

**判断标准**

- 共识区的信息已被定价，边际信息主要在分歧区；因此要明确“分歧从哪一年开始”。
- 边界判断的推理链条：有增量需求（Agent AI）+ 有长约地板价 → 分歧区的悲观情形也有下限 → 排除“崩盘式下滑”。
- 管理层表态只作为辅助证据，用来佐证对分歧区的判断，不能替代供需测算。

**海豚案例**

- 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：引用TrendForce对下季合约价的预测（DRAM、NAND四季度仍为两位数环增）；把机构观点按时间划分，“到2027年下半年仍上涨”为共识，2028年后分歧明显；自己的边界判断是在Agent AI增量需求和5年期长约地板价保障下不会出现2028年崩盘式下滑，并把管理层“2027、2028年更紧”的表态视为分歧区的定心丸。

**适用场景与注意事项**：适用于有第三方价格机构的商品型行业（存储、面板、锂电材料）。长约条款的实际保护力度见 5.3.3；机构共识本身是否已被股价吸收，需结合周期位置判断（见 5.4）。

### 5.2.3 成熟制程涨价的扩散追踪：品类、尺寸、同行幅度

**方法要点**：沿“品类、尺寸、同行”三条线追踪涨价从哪里开始、扩散到哪里，再结合供给端变化判断成因，用毛利率指引确认涨价是否已经兑现。

**操作步骤 / 拆分口径 / 公式**

1. 品类线：从功率BCD、模拟、电源管理、存储，到市场期待的更多产品线。
2. 尺寸线：从8寸成熟制程到12寸。
3. 同行线：同行的涨价公告，包括幅度和启动时间。
4. 结合供给端变化判断成因：一线代工厂把产能转向AI、台积电收缩成熟制程。
5. 用公司毛利率指引确认涨价是否已经兑现。

**关键指标与数据来源**：涨价品类、8寸/12寸涨幅、同行涨价公告（幅度与时间）、一线厂产能转移、毛利率指引。

**判断标准**

- 品类越多、尺寸从8寸扩散到12寸、同行跟进的幅度越大，说明涨价越有“面”而不是单点。
- 推理链条：先在需求回升的品类（如功率类）涨价 → 一线厂把产能转向AI、台积电收缩成熟制程 → 外溢需求流向中芯等成熟制程代工厂 → 同行公告涨价确认行业共识 → 毛利率指引验证兑现。
- 同行的措辞也是信号：格芯只说“选择性涨价”，说明并非全线提价。

**海豚案例**

- 中芯（2026-08-13）：涨价集中在BCD、模拟、电源管理、存储等；8寸先涨，市场预计下半年扩散到12寸；联电8寸涨25-40%、部分12寸涨10-20%，下半年启动、2027年全面涨价；格芯只说“选择性涨价”；中芯成熟制程部分提价10%以上；一线厂把产能转向AI，中芯承接外溢需求。
- 中芯（2026-05-14）：功率类需求回升，推动成熟制程涨价；台积电主动收缩成熟制程产能，联电宣布下半年涨价。

**适用场景与注意事项**：适用于晶圆代工及上下游。涨价公告不等于兑现，要以毛利率指引确认；供给侧的产能转移与扩产追踪见 4.2、4.5。

### 5.2.4 长协价与拍卖/现货价的价差，以及定价方式反转，判断卖方市场

**方法要点**：用合同结构而不是单一价格判断供需：长协价与零售/拍卖价差多大、成交方式是谁去竞标谁，两个信号一起说明是不是卖方市场。

**操作步骤 / 拆分口径 / 公式**

1. 取长协价（1-3年中长单）与零售/拍卖价，计算价差倍数。
2. 看交易方式：是供给方竞标客户项目，还是客户来竞价、价高者得。
3. 记录合同期限和定价方式，区分长协与实时价；测算时要分开处理，AI Lab与云厂一般签长协，实际租价未必随实时价走高。

**关键指标与数据来源**：长协价（$/GW）、拍卖/零售价、价差倍数、合同期限、定价方式。

**判断标准**

- 信号一：长协价与零售价相差约2倍（Nebius长协每GW 200-250亿美元，拍卖定价可达每GW 500亿美元）。
- 信号二：交易方式反转，过去是云厂去竞标企业项目，现在是客户来竞价；两个信号叠加，说明AI云已是严重的卖方市场。
- 对收入测算的含义：长协价不随实时价同步，估算云厂收入时必须区分两者。

**海豚案例**

- Nebius《CoreWeave、Nebius：算力涨价、干爹出手，英伟达 “干儿子” 能飒多久？》（2026-08-13）：1-3年中长单每GW 200-250亿美元，公司特意留出部分零售产能采用拍卖，客户竞价、价高者得，定价可达每GW 500亿美元；价差约2倍，且过去是云厂竞标企业项目、现在是客户竞价。
- AI算力行业《AI 算力：从盛宴到 “剩宴”？》（2026-07-13）：提示AI Lab与云厂一般签长协，实际租价未必随实时价走高，测算时要区分两者。

**适用场景与注意事项**：适用于长协与现货双轨定价的行业（算力、存储、光纤、锂盐等）。价差只说明紧张程度，不等于全部合同都按高价结算；长协的价格机制与保护力度见 5.3.3。

### 5.2.5 按代际追踪云GPU按需租赁价（新卡、主流旧卡、老旧卡三档），以老卡逆势涨价作为供不应求的证据

**方法要点**：从多个渠道整理云算力的on-demand实时标准价，按GPU代际分三档追踪，用“已上市3-5年的老卡不降反涨”验证算力严重供不应求，并推断云厂议价权和资产残值。

**操作步骤 / 拆分口径 / 公式**

1. 渠道：从多个渠道整理云算力的on-demand实时标准价，以$/GPU时计。
2. 分三档追踪涨跌幅：
   - ①最新GPU（B200及更新）：自2025年底至今上涨约1/4到1/2。
   - ②市场实际主流的H200及更早产品：上涨约15%到20%。
   - ③比A100更老旧的芯片：平均租价自2024年底下降约1/3，但仍能以低价继续贡献收入。
3. 逻辑推断：老芯片本应随迭代降价，已上市3到5年的老芯片却逆势涨价，一方面验证算力严重供不应求，另一方面说明云厂议价权和利润率在提升，即便裸金属IaaS的毛利率也应改善。
4. 残值与折旧：老芯片不会因为新卡更强就变成闲置资产，对折旧年限和残值假设很有意义。

**关键指标与数据来源**：各代GPU按需租赁价（$/GPU时）、涨跌幅、观察区间（2025年底至今）。

**判断标准**

- 最新卡涨价说明需求抢先；主流旧卡涨价15%-20%说明供不应求已传导到“并非最新”的产品；只有比A100更老的卡才继续降价，且仍能贡献收入。
- 老卡逆势涨价是最强的供不应求证据，因为按正常规律老卡应随迭代降价。
- 推理链条：老卡涨价 → 供不应求 + 云厂议价权/利润率提升 → 裸金属IaaS毛利率改善 → 老卡仍是有效资产 → 折旧年限和残值假设可以更长。
- 英伟达敢为GPU残值担保，也说明它有信心拉长老一代GPU的服役周期。

**海豚案例**

- AI算力行业《AI 算力：从盛宴到 “剩宴”？》（2026-07-13）：分代际的云租价变化——最新GPU自2025年底至今上涨约1/4到1/2、H200及更早产品上涨约15%-20%、比A100更老旧的芯片平均租价自2024年底下降约1/3，并据此判断算力供不应求、云厂议价权和利润率在提升。
- CoreWeave、Nebius《CoreWeave、Nebius：算力涨价、干爹出手，英伟达 “干儿子” 能飒多久？》（2026-08-13）：英伟达敢为GPU残值担保，说明它有信心拉长老一代GPU的服役周期。

**适用场景与注意事项**：适用于云、算力租赁和GPU周期判断。注意实时价与长协价存在差异（见 5.2.4），实时价只代表边际成交；折旧与残值的使用要结合资产服役周期的其他证据。

### 5.2.6 算力即期价格、单GW部署成本、存储涨价作为供需紧张信号并传导至Capex

**方法要点**：用价格数据判断算力供需缺口，再把这些价格反向用于修正Capex预测里的单位成本参数，把“价格”和“Capex指引”连成一条因果链。

**操作步骤 / 拆分口径 / 公式**

1. 追踪算力短租价与长协价的倍数。
2. 追踪单GW部署成本的变化。
3. 追踪存储等模组涨价导致的Capex指引上调额。
4. 判断：供需错配越大，云厂商提价空间越大、利润率可维持；反之窗口期结束。
5. 修正参数：用这些价格修正Capex预测中的单位成本参数。

**关键指标与数据来源**：算力短租价/长协价、单GW部署成本、存储价格、Capex指引调整额。

**判断标准**

- 短租价是长协价的数倍，说明即期紧张；单GW部署成本上升，说明供应链涨价正在抬高资本开支。
- 要区分Capex上调的来源：是真实需求扩张，还是单位成本（存储涨价）抬升；后者不增加算力供给，见 3.1.2。
- 推理链条：存储涨价 → 云厂Capex指引上调 → 同样的Capex买到更少的算力 → 对算力供给的测算要下调。

**海豚案例**

- 谷歌（2026-07-27）：xAI短期租赁价格是长期合同的3-4倍，CoreWeave算力成本从300亿/GW涨到350亿/GW。
- 谷歌（2026-07-23）：全年Capex指引从1800-1900亿上调至1950-2050亿，资金因存储涨价预期提高50-100亿。
- 亚马逊（2026-07-31）：全年Capex因存储涨价从2000亿拉到2200亿。

**适用场景与注意事项**：适用于AI基础设施链、存储/半导体周期分析。短租价只代表边际成交，不能直接外推整体收入（见 5.2.4）；Capex指引调整里的涨价成分要拆出来。

### 5.2.7 追踪模型Token价格：剔除订阅制，用官方定价加第三方混合Token价格指数

**方法要点**：观察模型价格是否随能力迭代而变化时，只看按量计费、剔除订阅模式，同时用官方定价和第三方机构的混合Token价格指数两套数据，判断模型价格是通胀、通缩还是横盘，进而判断头部模型把技术红利留给自己还是让给用户。

**操作步骤 / 拆分口径 / 公式**

1. 只看按量计费（API按Token计价），剔除订阅制。
2. 取两套数据：Anthropic官方定价；第三方机构统计的真实Token价格指数（由多种等级模型的Input、Output、Cache-hit价格混合而成）。
3. 对比两套数据的趋势：是否随模型迭代呈趋势性走高或走低。
4. 结论：AI模型价格既不通胀也不通缩，没有随模型迭代呈趋势性走高，而是区间震荡甚至走平；头部模型没有把芯片性能提升的好处让给终端用户，而是留作了自己的利润。
5. 后续情景测算再补一个判断：模型商维持单位Token不降价难以长期持续，终会进入量增价减阶段。

**关键指标与数据来源**：官方API价格、第三方Token价格指数（Input/Output/Cache-hit混合）。

**判断标准**

- 价格横盘 + 成本下降（芯片性能提升）= 利润留在模型商手里；若价格开始趋势性下降，说明竞争或让利启动。
- 单位Token不降价不可长期持续，终局是量增价减，所以情景测算里不能假设永远不降价。
- 价格为什么这样是供需问题还是策略问题，策略层面见 9.4。

**海豚案例**

- AI算力行业《AI 算力：从盛宴到 “剩宴”？》（2026-07-13）：用Anthropic官方定价与第三方混合Token价格指数两套数据，得出模型价格横盘（不通胀也不通缩）的结论，并在后续情景测算中补充“量增价减”的判断。

**适用场景与注意事项**：适用于AI应用和模型公司的收入与毛利分析。订阅制收入需另行处理；模型API与订阅的定价策略见 9.4。

**本节速查清单**

- [ ] 价格是否取了代表性规格并统一口径（如16Gb 2Gx8 DDR5、32Gb MLC NAND、$/GB），现货价与合约价是否分开记录
- [ ] 价格涨幅是否与相关公司股价涨幅对照，判断预期是否已被定价
- [ ] 第三方价格预测是否按时间段划分了“共识区”和“分歧区”，并写出自己对分歧区的边界判断
- [ ] 涨价扩散是否沿品类、尺寸、同行三条线追踪，并用毛利率指引确认兑现
- [ ] 长协价与拍卖/零售价的价差倍数、成交方式（谁在竞价）是否记录，测算时是否区分长协与实时价
- [ ] 云GPU租价是否按新卡、主流旧卡、老旧卡分三档追踪，老卡是否逆势涨价
- [ ] 算力短租价/长协价、单GW部署成本、存储涨价引起的Capex上调是否被拆出并回填到Capex单位成本参数
- [ ] Token价格是否剔除订阅制，并用官方定价加第三方混合指数两套数据交叉

## 5.3 价格驱动归因、持续性与合约结构

> 本节导读：本节解决“价格为什么涨（或跌）、涨的这轮能持续多久、合同结构会不会改变价格路径”的问题。价格追踪（5.2）只告诉你价格在哪，本节回答它背后的驱动是供给收缩、需求扩张还是技术降本，涨价能否持续取决于瓶颈在哪、新产能何时落地、合同是否锁量锁价。研究周期品涨价、原材料成本对下游的传导、硬件ASP走势、长协条款时使用；归因结论直接喂给 5.4 的周期位置判断。

### 5.3.1 涨价分阶段归因：区分供给收缩驱动与需求驱动

**方法要点**：把一轮涨价按时间拆成不同阶段，分别判断每个阶段是供给侧事件还是需求侧事件，因为两类驱动的持续性完全不同：供给收缩驱动的涨价可能被复产逆转，需求驱动的涨价要看下游Capex。

**操作步骤 / 拆分口径 / 公式**

1. 按时间切分涨价阶段，并标注各阶段发生的事件和时点。
2. 每个阶段分供给端和需求端两栏列事件，判断主导因素。
3. NAND（2025年）：
   - 阶段一（上半年）：三星、海力士等为应对周期下行主动减产，供给收缩；同时中国国补刺激需求，价格止跌回升。
   - 阶段二（下半年）：AI Capex高增，AI服务器中单个AI芯片的SSD配比超量增加，导致供不应求。
4. DRAM同样拆两端：
   - 供给端：原厂把产能转向HBM，挤压传统DDR。
   - 需求端：训练转推理，增加CPU侧和“外挂内存”需求；服务器DDR均价高，厂商优先满足，“此消彼长”打破了原有平衡。
5. 用归因结果判断持续性：供给收缩驱动的涨价，要看复产的可能；需求驱动的涨价，要看下游Capex能否持续。

**关键指标与数据来源**：厂商减产与稼动率、政策补贴、AI Capex、单芯片SSD/DDR配比、价格曲线。

**判断标准**

- 供给收缩驱动（阶段一类型）：价格止跌回升更多是“修复”，复产后可能逆转，持续性弱。
- 需求驱动（阶段二类型）：由结构性需求变化（单AI芯片SSD配比提升、训练转推理）带来，持续性取决于下游Capex。
- 推理链条：拆阶段 → 分供给/需求 → 找各自的触发事件与时点 → 对应不同的持续性判断。要分清供给侧与需求侧事件各自发生的时点，不可混为一谈。

**海豚案例**

- NAND、DRAM《99%计算闲置？推理时代，存力比算力香！》（2026-01-14）：NAND 2025年涨价分两个阶段（上半年减产+国补，下半年AI Capex高增、SSD配比超量）；DRAM供给端原厂转产HBM挤压传统DDR，需求端训练转推理增加CPU侧和“外挂内存”需求，“此消彼长”打破原有平衡。

**适用场景与注意事项**：适用于任何周期品的价格驱动拆解。要分清供给侧与需求侧事件各自发生的时点；归因后的持续性判断可继续用 5.3.2 的瓶颈、扩产周期和新进入者框架。

### 5.3.2 涨价持续性判断：技术驱动 vs 供需错配驱动，定位瓶颈环节、扩产周期、新进入者产能与现货价

**方法要点**：对一次涨价，先定性来源（技术驱动还是供需错配），再定位供给瓶颈环节，看存量玩家扩产节奏和新进入者产能，用现货价边际变化验证动能，并检查是否有新技术干扰，综合判断涨价能否持续。

**操作步骤 / 拆分口径 / 公式**

1. 定性涨价来源：并非技术驱动，而是供需错配。需求侧是AI集群扩张带来的结构性量升。
2. 定位供给瓶颈环节：在最上游的光纤预制棒（超高纯石英玻璃实心棒，决定光纤的“光学DNA”，贡献产业链近70%的利润，设备和工艺要求最高）。
3. 判断供给刚性：成熟产能由康宁、藤仓、长飞等头部厂商主导，且大部分不外售；存量玩家扩产谨慎，扩产周期18到24个月，缺口沿产业链向下传导，推动近一年整体涨价。
4. 检验持续性存疑的证据：
   - 新进入者激进扩产：大族激光扩产2000吨、合盛硅业扩产3200吨，预计2027年下半年落地；
   - 调研显示国内竞争已经加剧；
   - 现货价动能：截至6月，G.657.A现货价环比微升，G.652.D环比持平，涨价动能减弱。
5. 评估新技术干扰：空心光纤HCF（长飞领先）仍处商业化早期，累计交付约占全年光纤需求的0.02%；与CPO这种确定性极强的技术相比，它推动产业更新的逻辑更弱、涉及的环节也更少。

**关键指标与数据来源**：预制棒利润占比（约70%）、扩产周期（18-24个月）、新进入者扩产吨数与落地时间、现货价环比（G.657.A、G.652.D）、新技术渗透率（0.02%）。

**判断标准**

- 供需错配型涨价的持续性取决于：瓶颈环节的扩产周期（18-24个月）与新进入者产能落地的时间差。存量玩家谨慎扩产、新进入者要到2027年下半年才落地，意味着在此之前供给仍难放量，而新增产能落地之后才是持续性的主要风险。
- 现货价是动能的实时指标：环比转平或微升，说明涨价动能减弱，即使合同价还在涨。
- 新技术是否会改变供需：渗透率只有0.02%，对当前供需影响很小，但要持续跟踪。
- 推理链条：定性（供需错配）→ 定位瓶颈（预制棒）→ 看存量刚性（扩产周期长、不外售）→ 看增量冲击（新进入者2027H2）→ 用现货价验证动能 → 排除或纳入新技术干扰 → 得出“持续性存疑”的判断。

**海豚案例**

- 光纤光缆产业链《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：光纤光缆涨价为供需错配（AI集群带来结构性量升）；瓶颈在光纤预制棒（约占产业链近70%利润）；康宁、藤仓、长飞主导成熟产能且大部分不外售，扩产周期18-24个月；新进入者大族激光（2000吨）、合盛硅业（3200吨）预计2027年下半年落地；截至6月G.657.A现货价环比微升、G.652.D环比持平；空心光纤HCF累计交付仅约占全年光纤需求0.02%。

**适用场景与注意事项**：适用于任何周期性涨价品种（光纤、存储、化工、锂电材料等）的持续性判断。要把“瓶颈环节”找准，否则扩产周期会被下游环节的短周期误导；新进入者的落地时间往往是判断拐点的关键；技术路线商业化进度见 6.5。

### 5.3.3 新旧长协（LTA）三维对比：违约成本、价格机制、交易对手信用，“抬底不消周期”

**方法要点**：回应“长协改变周期属性、提升估值中枢”的市场叙事，把新一轮长协与旧式长协在违约成本、价格机制、交易对手信用三个维度逐项对比，评估它到底锁住了多少量和价格，结论是“抬高业绩底部但不消除周期”。

**操作步骤 / 拆分口径 / 公式**

1. 旧式长协的定位：更多保护买方，是量的松散约定；行情好时优先拿货，行情差时照样砍单，卖方据此扩产反担库存与闲置风险。
2. 新一轮长协逐维度对比：
   - ①违约成本前置：普遍要求预付保证金、预付款或第三方担保，砍单可没收（美光称长协可见度支撑其上调FY27 Capex）；但预付款只覆盖合同底价价值的一小部分（美光约16%-21%）。
   - ②从随行就市到价格区间：美光约3/4长协采用“底价+上限”；但据Bernstein推算底价较当前价低约50%，厂商仍承担相当跌价风险。
   - ③交易对手信用：对手从PC厂、模组商、渠道商变为英伟达与云巨头，无力履约风险明显下降，风险转向“云厂商Capex会不会掉头”。
3. 得出结论：长协锁定部分“量+价格区间”，抬高业绩底部但不消除周期，保护力度取决于量的覆盖程度与价格上下限。

| 维度 | 旧式长协 | 新一轮长协 | 保护力度的限制 |
|---|---|---|---|
| 违约成本 | 松散，砍单无代价 | 预付款/保证金/担保，砍单可没收 | 预付款仅覆盖合同底价价值约16%-21% |
| 价格机制 | 随行就市 | “底价+上限”（美光约3/4长协） | 底价较当前价低约50%（Bernstein），跌价风险仍在 |
| 交易对手信用 | PC厂、模组商、渠道商，履约风险高 | 英伟达与云巨头，履约风险低 | 风险转向云厂商Capex会不会掉头 |

**关键指标与数据来源**：预付款占合同价值比例、底价较现价折让、长协覆盖率、交易对手资信、价格上限设定。来源：公司披露、Bernstein、UBS、韩媒。

**判断标准**

- 预付款占比越高、底价越接近现价、覆盖量越大，长协对业绩底部的保护越强；本案例的预付款比例仅16%-21%、底价较现价低约50%，保护有限。
- 交易对手升级降低了“无力履约”风险，但把周期风险转移到了对手方的Capex决策上，需要与 3.1 的Capex锚结合判断。
- 推理链条：旧长协保护买方 → 新长协把违约成本前置、价格区间化、对手信用升级 → 锁定一部分量和价格区间 → 抬高底部，但底价仍远低于现价、预付款只覆盖一小部分，所以不消除周期。

**海豚案例**

- SK海力士《SK 海力士：长协能熨平周期？估值到哪一步》（2026-10-09，第3.2节）：用三维对比拆解新旧长协，引用美光（预付款覆盖约16%-21%、约3/4长协为“底价+上限”）、Bernstein（底价较当前价低约50%）、UBS及韩媒的信息，得出“抬底不消周期”的结论。

**适用场景与注意事项**：适用于周期品长协、照付不议、预付款合同的评估（存储、锂、LNG、航运）。要把“合同名义覆盖”与“有约束力的覆盖”区分开；长协对回落形态的影响见 5.3.4，对估值的影响见 11.4。

### 5.3.4 用价格见顶时点和长协结构判断原材料价格回落形态，推导对下游的影响

**方法要点**：研判上游成本对下游的影响时，先汇总主流机构对价格见顶时点的预期，再结合供需合同结构，推断回落是“高位缓降”还是“闪崩”，从而判断下游需求压力是“有所缓解”还是“消失”。

**操作步骤 / 拆分口径 / 公式**

1. 汇总主流机构对价格见顶时点的预期：存储2027H1见顶、H2回落。
2. 看供需合同结构：大厂多签LTA长协。
3. 推断回落形态：高位缓降而非闪崩。
4. 推导对下游的影响：对PC需求的压力是“有所缓解”而不是“消失”。

**关键指标与数据来源**：DRAM/NAND合约价预测、见顶时点、LTA签约情况、PC出货量。

**判断标准**

- 回落形态决定下游成本压力的退坡速度：缓降意味着下游仍需长期承受高成本，只是边际压力缓解；闪崩才意味着成本压力迅速消失。
- 推理链条：见顶时点（2027H1）+ 回落时点（2027H2）→ 长协锁住部分量价 → 不会价格闪崩 → 下游压力有所缓解而非消失。

**海豚案例**

- 戴尔（2026-09-02）：主流机构预期存储价格2027年上半年见顶、下半年回落；存储大厂多签LTA，即便回落也不会“价格闪崩”，对PC市场的压力是“有所缓解”而非“消失”。

**适用场景与注意事项**：适用于原材料或核心零部件成本占比高的下游公司（PC、手机、汽车、服务器）。长协的保护力度有限（见 5.3.3），“缓降”的判断要同时看长协覆盖比例与底价；上游成本传导到下游的更多方法见 2.5。

### 5.3.5 ASP从“快速通缩”切换到“汽车零部件年降模式”的拐点判断

**方法要点**：判断硬件价格何时从快速下探切换到稳态年降，区分降价的驱动（技术降本还是竞争），看高端产品占比的结构对冲，并判断产品属性是否已从“新兴科技品”变成“标准化汽车零部件”，据此预测未来几年ASP降幅。

**操作步骤 / 拆分口径 / 公式**

1. 区分降价驱动：技术降本驱动的降价（自研芯片化红利释放完毕后会放缓）与竞争驱动的降价。
2. 看高端产品占比提升带来的结构对冲。
3. 判断产品属性切换：从“新兴科技品”变成“标准化汽车零部件”，定价转向传统年降模式（每年约5%-10%）。
4. 据此预测未来几年ASP降幅。

**关键指标与数据来源**：历年ASP降幅、技术降本节奏、高端产品占比、行业年降惯例。

**判断标准**

- 技术降本红利基本释放完毕 → 降幅收窄；之后进入每年约5%-10%的年降模式。
- 若价格下降主要是竞争驱动，则不会随技术红利释放而放缓，拐点会推迟。
- 推理链条：ASP降幅（过去两年超50%）→ 拆出技术降本占比 → 红利释放完毕 → 2027年降幅收窄至约10%（2026年约31%）→ 此后年降5%-10%。

**海豚案例**

- 禾赛（2026-08-19）：过去两年ASP降幅超50%，很大程度由自研芯片化技术降本驱动，这一轮红利已基本释放；预计2027年综合ASP降幅收窄到约10%（2026年约31%），之后每年5%-10%；激光雷达的定价模式从快速下探抢渗透率过渡到年降模式。

**适用场景与注意事项**：适用于渗透率进入中后期的科技硬件（激光雷达、摄像头模组、动力电池）。如果出现新的价格战，拐点会推迟；降本空间与技术路线成本比较见 6.4，定价权见 9.4。

### 5.3.6 商品价格对比边际生产成本，判断底部支撑与供给收缩

**方法要点**：对有生产成本曲线的商品，把现价与边际生产者的成本区间比较；价格低于边际成本时，上游供给会在成本压力下放缓，形成底部支撑，这是大宗商品成本曲线底部逻辑的应用。

**操作步骤 / 拆分口径 / 公式**

1. 确定边际生产成本区间（如BTC矿工边际生产成本）。
2. 取商品现价，与成本区间比较：价格 < 边际成本 → 供给在成本压力下放缓。
3. 判断底部支撑：价格低于成本区间越多，供给收缩压力越大，底部支撑越强。
4. 在股价与该商品价格强绑定时，先判断商品价格底部，再看公司。

**关键指标与数据来源**：BTC现价、边际生产成本区间。

**判断标准**

- 价格低于边际成本并持续，意味着高成本供给方亏损、被迫减产或退出，价格出现底部。
- 需求端崩塌时成本支撑可能失效：成本曲线只约束供给，不能保证需求。
- 推理链条：股价短期绑定加密货币行情 → 先判断BTC价格底部 → 现价低于边际生产成本 → 供给放缓形成底部支撑。

**海豚案例**

- Coinbase《烂行情+烂业绩…》（2026-02-13）：BTC 6.7万美元，低于边际生产成本7.7-8.7万美元，似乎可以看到底部支撑。

**适用场景与注意事项**：适用于有生产成本曲线的商品（BTC、原油、金属、面板等）。需求端崩塌时成本支撑可能失效；成本区间要说明口径（是否含折旧、电价假设）。

**本节速查清单**

- [ ] 涨价是否按时间切分阶段，每个阶段分别归因到供给收缩还是需求驱动，并判断各自的持续性
- [ ] 是否定性了涨价来源（技术驱动 vs 供需错配），并定位到具体的瓶颈环节
- [ ] 存量玩家的扩产周期、新进入者的产能规模与落地时间、现货价环比动能是否都已核对
- [ ] 新技术对现有供需的干扰是否已量化（渗透率、涉及环节）
- [ ] 长协是否用违约成本、价格机制、交易对手信用三个维度逐项评估，并核对预付款占比、底价折让、覆盖率
- [ ] 价格见顶时点预期与合同结构是否已合成回落形态判断（缓降或闪崩），并推导对下游需求的影响
- [ ] 硬件ASP是否区分技术降本与竞争降价，高端占比的结构对冲是否纳入，何时切换到年降模式
- [ ] 商品价格是否与边际生产成本比较，是否检查需求端崩塌导致成本支撑失效的风险

## 5.4 周期位置与拐点识别

> 本节导读：本节解决“现在处在周期的哪一段、拐点有哪些可观察的先行信号”的问题，各行业的周期判断框架统一归在这里：存储、硅周期、面板、锂电、AI算力、燃机等。做法是把价格、库存、毛利率、Capex、下游行为、集中度等指标组合成一套“周期仪表盘”，并且看持续性而不是高度。周期位置的结论要建立在 5.1 的缺口、5.2 的价格和 5.3 的驱动归因之上；周期股的估值方法不在本节，见 11.4；供给侧行为与纪律见 4.5。

### 5.4.1 用价格“二阶导”判断周期阶段

**方法要点**：周期品不能只看价格是涨是跌（一阶），更要看涨幅本身的变化（二阶导）；价格还在涨但涨幅收窄，就说明暴涨阶段已经结束，市场会提前交易周期下行，估值随之承压。

**操作步骤 / 拆分口径 / 公式**

1. 取第三方合约价的季度环比（如TrendForce存储合约价）。
2. 画出环比序列的斜率：一阶是价格变化，二阶是环比增速的变化。
3. 判断：价格仍在涨但环比涨幅逐季收窄 = 二阶导为负 = 暴涨阶段结束。
4. 同一逻辑用于需求侧的ARR增速：ARR仍在增长，但斜率放缓。
5. 把斜率变化与市场关注点联系起来：暴涨阶段结束后，市场更在意公司获取长协（LTA）的能力。

| 季度 | 存储均价环比 |
|---|---|
| Q1 | +90%以上 |
| Q2 | +50%以上 |
| Q3（市场预期） | 约+15% |

**关键指标与数据来源**：TrendForce存储合约价季度环比；ARR增速斜率。

**判断标准**

- 环比序列“90%→50%→15%”的斜率下滑，说明二阶导持续为负：价格虽仍上涨，但暴涨阶段已经结束。
- 推理链条：二阶导转负 → 市场提前交易周期下行 → 估值承压 → 关注点从价格涨幅转向价格的可持续性（LTA能力，见 5.3.3）。
- 斜率下滑“已成共识”意味着市场已提前定价，此时的增量信息是斜率之后的路径（见 5.4.2、5.4.3）。

**海豚案例**

- 海力士（2026-07-29）：TrendForce数据显示存储均价Q1环比+90%以上、Q2+50%以上，市场对Q3的预期只有+15%左右；“90%→50%→15%”的斜率下滑已成共识，海豚君据此认为存储的暴涨阶段已经过去，市场更在意公司获取LTA的能力；同篇提到Anthropic ARR仍在增长，但斜率已在放缓。

**适用场景与注意事项**：适用于存储、面板、大宗商品等价格驱动的周期股；也适用于用户数、ARR等增速指标。二阶导依赖连续、可比的环比数据；要区分季节性波动与真实斜率变化。

### 5.4.2 存储周期判断框架：价格二阶导、原厂资本开支、下游抵触、利润分配、长协

**方法要点**：判断存储周期同时看六个维度，每个维度对应一个可观察的拐点信号，综合判断周期位置。

**操作步骤 / 拆分口径 / 公式**

| 维度 | 看什么 | 拐点含义 |
|---|---|---|
| ①价格二阶导 | 合约价环比斜率（见 5.4.1） | 涨幅收窄 = 暴涨阶段结束 |
| ②原厂资本开支 | 三大原厂Capex扩张 | 产能会提前释放，加速下行 |
| ③下游抵触 | 下游对涨价的抵触，如手机厂拒绝涨价 | 需求弹性显现，涨价受阻 |
| ④产业链利润分配 | 存储毛利率是否健康；超过80%本身不可持续 | 利润分配失衡会引发下游反制和上游扩产 |
| ⑤长协 | 长协覆盖与条款 | 能平滑周期、延缓下行，但没有锁住更多产能 |
| ⑥机构共识与估值 | 主流机构对价格见顶时点的共识，当前估值是否已反映 | 共识 + 估值已反映 = 利好出尽 |

**关键指标与数据来源**：合约价环比、三大原厂资本开支、存储毛利率、下游议价行为、LTA覆盖率、机构对见顶时点的预期。

**判断标准**

- 六个维度越多指向转弱，周期越接近顶部：二阶导为负、Capex大幅扩张、下游开始抵触、毛利率逼近或超过80%、机构预期见顶、估值已反映。
- 长协维度要两面看：它能延缓下行（回落形态偏缓），但没有锁住更多产能，所以只能弱化而不能消除周期（见 5.3.3）。
- 推理链条：Capex扩张 → 产能提前释放 → 下行加速；利润过高 → 下游抵触 + 上游扩产 → 利润分配回归；价格见顶共识 → 估值提前反映。

**海豚案例**

- 海力士（2026-07-29）：海豚君预计2026年三大原厂在存储上的资本开支超过950亿美元，同比+30%以上；OPPO、Vivo等已开始拒绝涨价；主流机构预期存储价格在2027年下半年开始下滑；乐观观点认为LTA可以弱化周期；存储增速斜率下降已是共识。

**适用场景与注意事项**：适用于存储及其他强周期电子元器件。六个维度要组合使用，单一维度（如Capex）容易误判；持续性视角见 5.4.3，毛利率与价格的三重验证见 5.4.5；存储赛道的其他要点见 16.1。

### 5.4.3 存储周期中看持续性而非高度：长协、需求满足度、来年需求展望

**方法要点**：存储涨价周期中，短期业绩爆表已被价格数据定价，更应关注持续性：长协订单比例、客户需求满足度、下一年的需求展望，并把指引毛利率当作下季涨价幅度的信号。

**操作步骤 / 拆分口径 / 公式**

1. 先用指引与市场预期对比，判断短期“高度”是否超预期：下季收入指引、毛利率指引与买方预期。
2. 把指引毛利率当作下季涨价幅度的信号：指引毛利率高于买方预期，意味着下季继续大幅提价。
3. 转向持续性：长协订单比例、客户需求满足度、下一年的需求展望。
4. 判断更多客户是否愿意签长协锁量，这才能让公司赚钱更久。

**关键指标与数据来源**：指引毛利率；存储合约价；长协比例；客户需求满足度；来年需求展望。

**判断标准**

- 短期高度（收入和毛利率远超预期）已被价格数据定价，边际变化在持续性。
- 更多客户愿意签长协锁量 = 持续性提升的证据。
- 推理链条：指引毛利率高于买方预期 → 下季再次大幅提价 → 但“相比业绩的高度，市场更在意持续性” → 看长协占比、需求满足度和来年展望。

**海豚案例**

- 美光（2026-03-19）：下季收入指引335亿±7.5亿 vs 预期268亿，毛利率约81% vs 买方76%，意味着下季再次大幅提价；“相比业绩的高度，市场更在意持续性”，更多客户愿意签长协锁量，才能让公司赚钱更久。

**适用场景与注意事项**：适用于存储及其他强周期品。指引毛利率接近历史新高时，也是接近周期高位的提示（见 5.4.5）；长协条款的保护力度要逐项评估（见 5.3.3）。

### 5.4.4 “硅周期”循环链条刻画，以及打破周期的判定条件

**方法要点**：先刻画旧周期的需求特征和闭环链条，再给出“能否打破周期”的判定标准：只要产品仍是“外围零件”就打不破，唯一出路是出现价格脱敏、与GPU算力部署直接绑定的新需求。

**操作步骤 / 拆分口径 / 公式**

1. 刻画旧周期的需求特征：AI之前，手机、PC、传统服务器等“话事”下游增长平稳可预期；需求增长来自三大动能（单机容量升级、新兴市场渗透、SSD对HDD存量替代），缺乏爆发变量。
2. 因此周期大起大落由供给端无序扩产与急剧收缩主导。
3. 把周期写成闭环链条：供过于求、价格暴跌 → 原厂减产，低价同时刺激单机容量升级 → 供需再平衡、价格回升 → 原厂高利润下追高扩产 → 再次过剩。
4. 判定能否打破周期：产品仍是“外围零件”就打不破；唯一出路是出现一个不太看价格、且与GPU算力部署直接绑定的新场景。
5. 以此作为论证AI推理是“破局者”的逻辑起点。

**关键指标与数据来源**：下游需求结构、需求增长动能（单机容量、渗透、SSD替代HDD）、价格、减产/扩产节奏。

**判断标准**

- 需求端三大动能平稳、没有爆发变量 → 周期由供给端主导（无序扩产/急剧收缩）。
- 打破周期的条件：新需求方 ①对价格不敏感（价格脱敏）；②与GPU算力部署直接绑定（需求有刚性）。缺一则仍在硅周期内。
- 关键是找出需求方的价格敏感度与需求刚性是否发生结构变化。

**海豚案例**

- NAND《从绿叶到鲜花，AI 推理如何为 NAND「逆天改命」？》（2026-09-30）：把NAND定义为被困在硅周期的大宗品，提出AI推理（价格脱敏的云厂商，且与GPU绑定）是打破死循环的条件。

**适用场景与注意事项**：适用于所有强周期半导体/大宗型硬件（存储、面板、被动元件等）的周期位置判断。“能否打破周期”是一个条件判断，不是结论；需持续检验价格脱敏与刚性是否真实存在。

### 5.4.5 用龙头毛利率指引是否创历史新高判断周期烈度，做价格-利润率-股价三重验证

**方法要点**：判断存储周期强度的第一个锚点，是龙头厂商的毛利率指引是否创历史新高，再配合产品价格涨幅和股价涨幅，形成“价格-利润率-股价”三重验证，后续再跟踪毛利率提升是否放缓。

**操作步骤 / 拆分口径 / 公式**

1. 取龙头毛利率指引及其历史分位：指引是否创历史新高。
2. 取产品价格涨幅（如DDR5现货价涨幅）。
3. 取相关股价涨幅。
4. 三重验证：价格、利润率、股价三者是否同向且同量级。
5. 后续跟踪：毛利率提升是否放缓。

**关键指标与数据来源**：龙头毛利率指引及其历史分位、产品价格涨幅、股价涨幅。

**判断标准**

- 毛利率指引创历史新高 → 本轮周期比以往更猛烈。
- 三重验证同向 → 周期强度确认；任何一重背离（如股价涨幅远高于价格和利润率）都提示预期过度。
- 毛利率提升放缓是边际转弱信号；毛利率高点往往接近周期顶部，需结合供需缺口的持续性判断（见 5.1、5.4.3）。

**海豚案例**

- 美光《存储猛拉，AI存力超级周期到底有多神？》（2026-01-06）：下季度毛利率指引66-68%，创历史新高，说明本轮周期比以往更猛烈；配合DDR5现货从6美元涨到31美元（5倍以上）和股价涨幅，形成三重验证；后续跟踪毛利率提升是否放缓（美光纪要：毛利率继续提升，但幅度会放缓）。
- 美光、海力士《存力接棒算力，HBM为什么“脱颖而出”？》（2026-09-17）：复盘，DDR5半年涨约7-9倍，NAND涨4-5倍，美光与海力士股价半年一度涨约10倍。

**适用场景与注意事项**：适用于周期行业（存储、面板、化工）判断周期位置。毛利率高点往往接近周期顶部，需结合供需缺口的持续性判断；价格追踪的取数方法见 5.2.1。

### 5.4.6 库存周数 + 跌价预期自我强化（牛鞭效应）机制分析

**方法要点**：跟踪原厂库存周数，并刻画“预期继续跌价→推迟采购→订单萎缩→价格加速下跌→预期被验证”的反身性循环，解释为什么终端需求只是小幅放缓，订单却剧烈波动；涨价周期里同一逻辑反过来用。

**操作步骤 / 拆分口径 / 公式**

1. 跟踪原厂库存周数（如从6周升到16周）。
2. 描述反身性循环：客户预期继续跌价 → 推迟采购、按需下单 → 订单萎缩 → 价格加速下跌 → 预期被验证。
3. 对比终端与订单：终端需求只是放缓到6%~8%，存储订单却剧烈波动，说明波动被牛鞭效应放大。
4. 判断拐点时看库存周数和客户采购行为（长协/现货、提前备货/去库），不能只看终端出货。
5. 涨价周期里反向使用：云厂商一般多备约10%库存，需求测算因此乘1.1作库存缓冲。

**关键指标与数据来源**：原厂库存周数、客户订单模式、现货与合约价走势、CSP库存缓冲比例。需要渠道调研或原厂披露的库存数据。

**判断标准**

- 库存周数快速上升（6周→16周）且三大终端同时去库，是下行周期的典型特征。
- 客户由“提前备货”转向“按需下单/去库”是拐点的先行信号，早于终端出货变化。
- 推理链条：终端需求小幅放缓 → 库存周数上升 + 跌价预期 → 客户去库、订单被放大 → 价格加速下跌 → 预期被验证；涨价周期则相反（见 5.1.3）。

**海豚案例**

- 闪迪《NAND 天性“多产”…》（2026-09-18）：原厂库存6→16周，三大终端同时去库；用该机制解释终端需求只放缓到6%~8%而存储订单剧烈波动。
- 闪迪《AI 改不了“DNA”，闪迪还能牛多久？》（2026-10-06）：2026年起AI NAND需求×(1+10%)库存缓冲（云厂商一般多备约10%库存），在涨价周期里反向使用同一逻辑。

**适用场景与注意事项**：适用于存储、面板、被动元件等库存驱动型周期品；需要渠道调研或原厂披露的库存数据。涨价周期里补库存会放大缺口（见 5.1.3）；供给纪律见 4.5。

### 5.4.7 面板周期：区分供给侧调节与需求端真实好转，并看集中度

**方法要点**：面板价格的上涨要先归因——是厂商主动控产（供给侧）还是需求真的好转；控产推价会因厂商恢复盈利、提升稼动率而停滞，只有需求改善才是周期上行的核心；中长期看集中度提升使周期淡化。

**操作步骤 / 拆分口径 / 公式**

链条（变体 B 的五步）：

1. 供给侧：双寡头在需求低迷时按需生产，主动控产稳价，而非被动亏损后的救火式减产。
2. 价格上涨若主要靠控产而非需求，一旦厂商盈利就会提升稼动率，供需回到平衡，涨价停滞。
3. 只有需求端真正好转才是周期上行的重要指标。
4. 关注需求催化（世界杯、春节减产）与需求抑制因素（存储涨价削弱终端购买力，抑制TV需求）。
5. 集中度提升后行业周期性淡化，龙头业绩更平稳，规模效应使其抗亏损能力更强。

变体 A（价格归因与终端需求）：
- 先归因：控产带来的涨价不可持续（厂商恢复盈利后提升利用率，价格回到供需平衡）。
- 需求端看电视、电脑等终端，受国补、存储涨价等因素影响。
- 中长期看行业集中度：前三大厂份额超过6成、龙头继续并购，周期性有望弱化。

**关键指标与数据来源**：面板价格走势、出货量、厂商产能利用率（稼动率）、全球LCD份额（前三大份额）、并购、终端TV需求、存储价格、龙头盈利率。

**判断标准**

- 控产驱动的价格上涨：持续性弱，终点是稼动率回升后的价格停滞；需求驱动：才是周期上行。
- 需求端的“催化”（世界杯、春节减产）是短期事件，抑制因素（存储涨价、国补收紧）是对冲项，要同时算。
- 集中度判断：前三大份额超过6成、双寡头（京东方+TCL华星）占全球LCD超50% → 供给纪律更强，周期弱化，龙头业绩更平稳。
- 推理链条：控产推价 → 盈利 → 稼动率回升 → 价格停滞；需求改善才是上行核心；集中度提升使周期淡化。

**海豚案例**

- 变体 A，京东方（2026-03-31）：4Q25收入500亿，同比-8.4%，面板价格同比约-1%，出货下滑是主因；供给收缩带动价格涨到2024年中，供需重回均衡后近一年价格平稳；2026年2月起价格有回升迹象，但国补收紧、存储涨价压制电视和电脑需求；前三大厂出货份额超过6成，京东方2025年收购彩虹光电30%股权。
- 变体 B，京东方《京东方：主动控产撞上世界杯…》（2026-04-30）：双寡头（京东方+TCL华星占全球LCD超50%）春节减产主动收窄供应，加上世界杯，打破此前均衡，2月起面板价格温和上涨；警惕存储持续涨价抑制TV需求；随着集中度提高，京东方业绩将更平稳。

**适用场景与注意事项**：适用于寡头化的周期性制造业（面板、光伏、化工、存储）。涨价归因的通用方法见 5.3.1；供给纪律与控产行为见 4.5；存储涨价对终端需求的抑制属于跨行业联动。

### 5.4.8 锂电周期指标：出货GWh、单价、单Wh净利、产能利用率、Capex

**方法要点**：用一组固定指标跟踪锂电周期：收入拆成出货量×单价，出货环比与下游销量环比对比，用毛利率验证成本能否传导，用产能利用率和Capex判断扩产周期，用单Wh净利衡量盈利水平。

**操作步骤 / 拆分口径 / 公式**

1. 收入 = 出货量（GWh）× 单价。
2. 动力电池出货环比增速 vs 新能源车销量环比增速：差值反映车企备货和单车带电量变化。
3. 毛利率：验证成本（如碳酸锂）能否传导给下游。
4. 产能利用率和Capex：判断扩产周期（利用率过满+Capex上升 → 新一轮扩产）。
5. 单Wh净利：衡量盈利水平。
6. 关注研发和减值对净利率的影响。

**关键指标与数据来源**：出货GWh；单价；单Wh净利；产能利用率；Capex；毛利率；研发；碳酸锂均价。

**判断标准**

- 出货环比明显高于新能源车销量环比，说明有车企备货和单车带电量提升的贡献，需拆开看。
- 毛利率好于预期，说明成本向下游传导顺畅；单Wh净利下降则提示盈利摊薄（需看研发与减值）。
- 产能利用率超过100%（下半年102.6%）+ Capex环比上升，是扩产周期启动的信号。

**海豚案例**

- 宁德时代（2026-03-09）：Q4收入1406亿 vs 预期1253亿；出货226GWh（+56%） vs 市场176GWh、偏乐观的大行200GWh；动力电池出货192GWh、环比+48%，而新能源车销量环比只+23%（车企备货加单车带电量提升）；毛利率28.2% vs 预期25.4%，验证了成本可以传导给下游；全年产能利用率96.9%（下半年102.6%）；Capex 123亿，环比+24亿；研发71亿 vs 预期58亿，单Wh净利从0.11元降到0.10元。
- 宁德时代（2026-04-15）：1Q26收入1291亿 vs 预期1142亿，碳酸锂均价约18万元/吨，毛利率24.8%，净利207亿。

**适用场景与注意事项**：适用于动力和储能电池。出货与销量的错位要拆开原因（备货、带电量）；次年供需平衡判断见 5.1.6。

### 5.4.9 “供给为王”阶段判定：供需缺口何时弥合，决定选股逻辑切换

**方法要点**：在国产替代等短缺型行业，先判断当前处在“供给为王”还是“需求为主”阶段，用缺口何时弥合作为选股逻辑切换的时点，据此把公司分析分为短期（产能锁定能力）与长期（产品力）。

**操作步骤 / 拆分口径 / 公式**

1. 判断供需错配的成因：英伟达在中国GPU市场从近100%市占率光速清空，Agent时代需求进一步引爆。
2. 粗略核算缺口比例：2026年缺口约40%-50%。
3. 判断弥合时点：2028-2029年逐步弥合，2029年后进入“需求为主”时代。
4. 阶段性评价标准切换：“供给为王”阶段，谁能规模出货谁拿到云Capex预算（看产能锁定能力）；“需求为主”阶段比拼产品力。
5. 公司分析分为短期（产能锁定能力）与长期（产品力）两条线。

**关键指标与数据来源**：AI芯片需求颗数、供给颗数、缺口比例、弥合年份。

**判断标准**

- 缺口仍大（40%-50%）→ 业绩逻辑是“供给为王”，出货规模和产能锁定决定份额。
- 缺口弥合（2028-2029年）→ 逻辑切换为“需求为主”，评价标准转向产品力。
- 阶段切换时必须同步切换评价标准，否则会用短期逻辑给长期价值定价。

**海豚案例**

- 壁仞科技《壁仞：国产 “英伟达”，到底 “几斤几两”？》（2026-06-18，第2节）：2026年需求约420万颗 vs 供给约260万颗，缺口约40%-50%，2028-2029年才逐步弥合；因此短期看产能锁定能力，长期看产品力。

**适用场景与注意事项**：适用于国产替代、短缺型行业；阶段切换时需同步切换评价标准。缺口比例要标明分母口径（占需求还是占供给），避免与供需比混用；国产替代的评估见 8.8。

### 5.4.10 新增装机CAGR加速 + 历史周期类比定位景气周期

**方法要点**：用设备类行业的年度新增装机时间序列判断景气拐点（CAGR是否加速、同比增速是否陡峭上行），再与历史周期高点类比，定性本轮周期的性质，并借历史上周期见顶的条件提示风险。

**操作步骤 / 拆分口径 / 公式**

1. 取全球年度新增装机规模的时间序列，计算CAGR和最新年份同比增速。
2. 判断增速斜率：从平稳增长转为陡峭上行 = 景气拐点。
3. 历史类比：找到上一轮周期的历史高点，看本轮是否正在逼近。
4. 类比需求驱动：上一轮是什么驱动（2001年互联网爆发带来的电力需求），这轮是什么（AI）。
5. 提示风险：上一轮周期因气价上涨和建设过热而回落，需持续跟踪这些条件。

**关键指标与数据来源**：全球燃机年新增装机（GW）、CAGR、同比增速、历史周期峰值。

**判断标准**

- 2019-2024年新增装机从40GW增至58.4GW（CAGR约8%）；2025年预计飙升到70.84GW，同比增长21%：增速陡峭上行，拐点确认。
- 2025年新增装机正快速逼近上一轮周期（2001年）的历史高点：定性为“AI复刻互联网周期”，开启新一轮超级周期。
- 风险条件：气价上涨、建设过热（上一轮的见顶原因），需要持续跟踪。

**海豚案例**

- AIDC电力《AI 终极瓶颈：算力狂奔遇“超级电荒”，燃气轮机成幕后大 Boss？》（2026-04-09）：全球燃机新增装机2019-2024年40→58.4GW（CAGR约8%）、2025E 70.84GW（+21%）；与2001年互联网周期高点类比，定性为“AI复刻互联网周期”、开启新一轮超级周期，并暗含上一轮因气价和过度建设见顶的风险提示。

**适用场景与注意事项**：适用于设备行业的周期定位。历史类比可用来提示见顶的条件（气价、过度建设），应持续跟踪这些条件；类比不是等同，需求驱动方和供给弹性要对比。

### 5.4.11 软件需求非线性 vs 物理供给线性（1.5-2年建设期）：解释错配，判断集中投放期

**方法要点**：用“需求由软件能力驱动、可以非线性推进，供给由物理建设和制造决定、只能线性推进”解释算力错配的本质，并用大厂GW投产计划判断阶段性集中投放期。

**操作步骤 / 拆分口径 / 公式**

1. 需求端：模型训练属于软件工程能力，可以非线性推进，一次约6个月的大迭代就能把Token需求拉高10倍。
2. 供给端：算力产能是物理世界的建设和制造，从开建到投产是线性的1.5到2年。
3. 虚拟世界飞速推进、物理世界受硬约束 → 大幅错配。
4. 由此推出三点：①眼下手握已投产产能的云厂，都应获得市场奖励；②不敢用2026年的算力定价线性外推后两年；③跟踪大厂的投产计划，判断阶段性集中投放期。
5. 跟踪投产计划：Meta和SpaceX 2027年目标都是6-8GW，判断2027年会进入阶段性的集中投放期。

**关键指标与数据来源**：模型迭代周期与Token需求倍数、建设周期、各厂GW投产计划。

**判断标准**

- 需求能“一次迭代放大10倍”而供给“1.5-2年才能投产”：当下错配严重，已投产产能稀缺。
- 集中投放期（2027年6-8GW级别的计划）意味着错配将在供给释放后缓解，价格不能线性外推。
- 推理链条：软件非线性 vs 物理线性 → 当下大幅错配 → 已投产产能被奖励 → 但2027年投产集中释放 → 供需关系回落，2028年起过剩（与 5.1.5 的结论互相印证）。

**海豚案例**

- CoreWeave、Nebius《CoreWeave、Nebius：算力涨价、干爹出手，英伟达 “干儿子” 能飒多久？》（2026-08-13）：用虚实两个世界的速度差解释供需错配，并以Meta和SpaceX 2027年6-8GW的投产目标判断集中投放期。
- 与《AI 算力：从盛宴到 “剩宴”？》（2026-07-13）中“2027年供需关系回落、2028年起过剩”的结论相互印证。

**适用场景与注意事项**：适用于需求由软件或技术驱动、供给受物理约束的行业周期判断。供给建设周期与扩产节奏的追踪见 4.2、4.4。

### 5.4.12 用单GW年租金估算回本期，解释扩产冲动，并提示不能线性外推当年价格

**方法要点**：按当年定价算回本期，用来解释各方为何疯狂扩产；同时提示这是当年价格的线性外推，不能拿2026年的定价去外推2027、2028年。

**操作步骤 / 拆分口径 / 公式**

1. 取单GW年租金（每GW 250-500亿美元）与单GW Capex，计算回本年限 = 单GW Capex / 单GW年租金；单GW部署成本的追踪见 5.2.6。
2. 结论：云厂1到2年内就能回本，之后的租金和设备退役后的残值都是额外收益。
3. 用回本期解释各方的扩产行为。
4. 提醒：不能用2026年的定价线性外推2027、2028年。

**关键指标与数据来源**：单GW年租金、单GW Capex、回本年限、残值。

**判断标准**

- 回本期1-2年的租金水平，会诱发过度投入；回本期过短往往引发过度供给，是拐点的伏笔。
- 推理链条：高租金 → 回本期短 → 疯狂扩产 → 2027年集中投放 → 租金回落 → 回本期拉长；因此不能线性外推。
- 当年价格是错配期的价格，不是稳态价格。

**海豚案例**

- CoreWeave、Nebius《CoreWeave、Nebius：算力涨价、干爹出手，英伟达 “干儿子” 能飒多久？》（2026-08-13）：用1-2年回本期解释SpaceX、Meta的扩产行为——SpaceX以2026年不到500亿美元的收入支撑约2000亿美元的资本开支（按其目标算力产能增量倒算）；Meta在自身模型不够强的情况下继续大举投入，从自建自用转向对外出租；同时提醒不能拿2026年的定价线性外推2027、2028年。

**适用场景与注意事项**：适用于重资产租赁型商业模式（云、IDC、船舶租赁）。回本期过短往往会诱发过度供给；与 5.4.11（集中投放期）和 5.1.5（供需比检验隐含预期）配合使用。

**本节速查清单**

- [ ] 价格是否做了“二阶导”分析（环比序列的斜率），而不只是看涨跌
- [ ] 存储周期六个维度（二阶导、原厂Capex、下游抵触、利润分配、长协、机构共识与估值）是否逐项核对
- [ ] 是否把“持续性”（长协占比、需求满足度、来年展望）与“高度”（当季业绩、毛利率）区分开
- [ ] 龙头毛利率指引是否创历史新高，价格-利润率-股价三重验证是否同向，毛利率提升是否放缓
- [ ] 是否核对库存周数、客户采购行为（长协/现货、备货/去库），并识别跌价预期自我强化的反身性循环
- [ ] 对价格上涨是否区分供给侧调节与需求端真实好转，集中度是否提升使周期淡化
- [ ] 周期行业的专属指标（锂电：出货、单价、单Wh净利、产能利用率、Capex）是否齐备
- [ ] 短缺型行业是否判定了所处阶段（供给为王还是需求为主）及缺口弥合年份，并同步切换评价标准
- [ ] 设备类行业是否用新增装机CAGR和历史周期类比定位景气，并跟踪历史上见顶的条件
- [ ] 软件需求与物理供给的错配、集中投放期、回本期是否已核对，是否避免用当年价格线性外推
