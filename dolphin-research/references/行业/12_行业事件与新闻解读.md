# 第12章 行业事件与新闻解读

> **本章目的**：面对突发事件、新品发布、传闻与市场异动时，快速给出结构化解读、量化冲击并判断影响期限。

**本章小节**：12.1 事件点评路径与拐点信号｜12.2 信息甄别与传闻处理｜12.3 事件冲击量化、归因与影响期限

---

## 12.1 事件点评路径与拐点信号

> 本节导读：本节回答“事件刚发生，第一步拆什么、按什么顺序写”。先给出事件点评的通用路径（12.1.1），再按事件类型给出专用模板：爆款产品（12.1.2）、技术突破（12.1.3）、新品发布的预期差（12.1.4）、技术代际回溯与真实触发点（12.1.5）；随后用大客户订单与融资用途（12.1.6）、巨头交易与立法提案（12.1.7）判断一个趋势是否“真实发生”，最后处理时间早已确定的大事件（12.1.8）。传闻真伪与事件强度的甄别见 12.2，冲击量化、归因与影响期限见 12.3；需求、供给、供需缺口的底层测算分别见第3、4、5章，事件映射到标的与估值见 11.2、11.4。

### 12.1.1 事件点评的标准路径：股价异动→业绩/电话会→行业供需→逻辑扩散→叠加事件→稳健选股

**方法要点**：以股价异动为入口，先用业绩与电话会确认“为什么涨/跌”，再上升到行业供需问“错配能持续多久”，随后做逻辑扩散、解读叠加事件对格局的影响，最后落到相对稳健的选股建议，把一次异动写成结构完整、每步都有硬证据的事件点评。

**操作步骤**

1. 切入：从股价异动切入（如新云公司股价暴涨），明确“市场在交易什么”。
2. 确认原因：结合业绩和电话会核实。结论必须有硬证据支撑，例如AI云需求明确供不应求，并拿出Nebius拍卖定价这类可观察的定价数据，而不是只复述叙事。
3. 上升到行业层面：提出“错配能持续多久”这个核心问题，用物理供给周期、各厂投产计划作答（供需缺口与周期的系统方法见 5.1、5.4）。
4. 逻辑扩散：把已确认的逻辑外推到同类公司——凡手握已投产产能的云厂，都应受到奖励；SpaceX、Meta转向对外出租算力就是扩散的例证。
5. 解读叠加事件：把同期出现的另一事件（英伟达5000亿美元融资平台）单独拆开，说明其机制，并推演对竞争格局的影响。
6. 选股与跟踪：给出相对稳健的选股建议（Capex早、规模大的大厂），同时列出尚未披露、需要继续跟踪的条款。

**关键指标与数据来源**：股价表现、业绩会与电话会的关键表述、定价数据（如拍卖价）、叠加事件的条款（融资平台规模、机制、未披露部分）、各厂投产计划。

**判断标准**

- 原因确认：有明确的“供不应求”表述且有定价数据印证，才能把股价异动归为基本面驱动；只有叙事没有定价证据时，应在文中降低结论强度。
- 行业层面：判断的重心是时间，即错配靠物理供给周期和投产节奏能撑多久，而不是只看当期需求有多热。
- 逻辑扩散：判断标准是“有没有已投产产能”。有已投产产能的厂商是逻辑的直接受益者，没有的则暂不扩散。
- 选股：在逻辑已被验证、但个股间差异难以逐一判断时，选Capex早、规模大的大厂作为相对稳健的选择。
- 推理链条：股价异动 → 业绩/电话会证实需求 → 行业层面供给刚性决定持续性 → 同类公司受益 → 叠加事件改变竞争格局 → 选更稳健的标的。

**海豚案例**

- CoreWeave、Nebius《CoreWeave、Nebius：算力涨价、干爹出手，英伟达 “干儿子” 能飒多久？》（2026-08-13）：按上述路径完成一篇事件点评——从新云股价暴涨切入，用业绩与电话会确认AI云供不应求，并以Nebius拍卖定价作硬证据；再从物理供给周期、各厂投产计划回答“错配能持续多久”；逻辑扩散到SpaceX、Meta转向对外出租；解读英伟达5000亿美元融资平台的机制及对竞争格局的影响；最后给出稳健选股（Capex早、规模大的大厂）并列出待跟踪的未披露条款。

**适用场景与注意事项**：适用于短评或事件点评类文章。节奏快，务必在文中标注假设与待验证点；叠加事件的未披露条款要列成跟踪清单，不要用推测替代事实。

### 12.1.2 爆款产品事件的分层解读：公司层另文点评，本文只讲上游传导

**方法要点**：爆款产品出现时，把事件拆成两层——产品端与对公司逻辑的影响放在另一篇点评里，本文只讲上游产业链的变化，并用一个问句式主线（“会是某品类的ChatGPT时刻吗”）把全文串起来，最后用股价涨幅判断是否已经price in。

**操作步骤**

1. 事件还原：记录发布时间与市场反应（如Meta在9月8日发布Muse，一度登顶美国移动端下载榜，Meta股价两位数上涨，CPU链公司也大涨）。
2. 分层：产品端与对发布公司的影响另文处理；本文限定为“对上游产业链的传导”，避免一篇文章同时回答两类问题。
3. 立主线：用一个可检验的问句作为全文主线，例如“Muse会是CPU版的ChatGPT时刻吗”。
4. 沿传导路径展开：产品形态差异 → 算力调用链差异 → 新增需求品类 → 需求量化 → 市场规模 → 公司收入和估值弹性。
5. 与股价对照：把推算出的增量与股价涨幅放在一起，判断是否已经price in。
6. 增量归因：对需求增量再做“既有趋势 vs 事件纯增量”的拆分，详见 12.3.2。

**关键指标与数据来源**：下载榜排名、股价涨幅（发布公司与上游链条公司）、需求测算结果（新增品类的需求量、市场规模、收入和估值弹性）。

**判断标准**

- 主线问句的答案取决于“新增需求品类”是否真实存在，以及量化后的市场规模是否足以支撑股价涨幅。
- 若测算出的收入与估值弹性小于或接近股价已反映的涨幅，则判断为已price in；若远大于涨幅，才有继续上修的空间。
- 推理链条：爆款 → 形态不同导致算力调用链不同 → 出现新增需求品类 → 量化需求与市场规模 → 折算成公司收入与估值 → 与股价对照。

**海豚案例**

- Muse与CPU链《Muse“爆火”，CPU 迎来自己的 ChatGPT 时刻？》（2026-09-28）：全文以“Muse会是CPU版的ChatGPT时刻吗”为主线，只谈上游CPU产业链；产品端和对Meta逻辑的影响放在另一篇点评；沿“产品形态差异→算力调用链差异→新增需求品类→需求量化→市场规模→公司收入和估值弹性→对照股价”展开。其中头节点CPU增量的因子拆解见 12.3.2。

**适用场景与注意事项**：适用于分析AI应用爆款事件对上游硬件的传导。要警惕把下载榜热度直接当成需求，必须过算力调用链这一步；事件对发布公司本身的影响不在本文范围，需另行点评。

### 12.1.3 技术突破事件解读四问法

**方法要点**：面对技术突破引发板块波动的事件，先把“市场到底在担忧什么”精确化，再用四个递进问题（技术基础→改变了什么→难点与是否独有→对行业影响）展开，坚持“先讲清技术本身，再谈影响”，避免情绪化解读。

**操作步骤**

1. 精确化市场担忧点：以“长鑫宣布4F²/VSG突破、海外三大存储厂股价下跌”为例，担忧被拆成两层——一项技术壁垒被中国厂商突破后量产速度快；4F²又直接提升单位产出。两者叠加意味着国内DRAM有效供给可能比预期增长更快。
2. 列出四个递进问题：
   - 问题一，技术基础：DRAM存储单元与阵列如何构成，主流6F²长什么样。
   - 问题二，改变了什么：从水平晶体管到垂直环绕、从6F²到4F²改变了什么。
   - 问题三，难点与是否独有：4F²难在哪里，是否长鑫独有。
   - 问题四，行业影响：对内存行业与三大厂影响多大。
3. 严格按顺序回答：先问题一到三讲清技术，再进入问题四谈影响。
4. 配合 12.2.3（措辞辨析）与 12.3.4（短期与中长期影响）完成对影响强度与期限的判断。

**关键指标与数据来源**：股价反应、技术参数（单元面积、晶体管结构）、量产时间表。

**判断标准**

- 担忧点是否被精确化：必须能用一句话说出“市场担心的传导链”（突破→量产快→有效供给增长快于预期）。
- 对行业影响的判断依赖前三问的结论：难度越高、越非独有，对行业格局的冲击越需要单独论证。
- 推理链条：先讲清技术，再谈影响，用“技术事实”约束“情绪判断”。

**海豚案例**

- 长鑫科技《长鑫把晶体管「竖起来」：绕开 EUV 的追赶路，会撼动存储三巨头吗？》（2026-10-16）：四问结构贯穿全文；市场担忧被表述为“壁垒被突破、量产速度快”与“4F²直接提升单位产出”叠加，使国内DRAM有效供给增长可能快于预期。

**适用场景与注意事项**：适用于所有技术或产品发布引发板块波动的事件点评（新架构、新模型、新工艺）。四问是顺序结构，不要在讲清技术之前就先下影响结论。

### 12.1.4 新品发布的“预期差”解读：逐品类对标预期，量化增量与缺口，再映射股价

**方法要点**：大客户发布新平台或新品时，不笼统说“利好”，而是逐个品类对标市场原有预期，判断“符合/略好/最超预期”，再量化需求增量及其对供需缺口的影响，最后映射到股价，验证“超预期幅度与股价弹性是否匹配”。

**操作步骤**

1. 建立预期基准：事先写清市场对各品类的原有预期（是前提，没有基准就无法谈“预期差”）。
2. 逐品类三档判断：把发布的规格与预期逐一对标，分为“符合预期 / 略好于预期 / 最超预期”。
3. 量化需求增量：按单GPU、单CPU、单柜的存储含量，算出相对市场预期的增量。
4. 量化缺口变化：把需求增量除以全球供应量，得到缺口扩大的百分比（需求增量占全球供应比例）。
5. 映射股价：按受益程度排序各公司，对照事件日股价涨幅，检验预期差大小与股价弹性是否匹配。

**逐品类对标（黄仁勋在CES2026发布Rubin后的三档判断）**

| 品类 | 发布内容 | 相对预期 | 需求增量与缺口 |
|---|---|---|---|
| HBM | 升级到HBM4，单GPU容量仍是288GB，增长来自GPU出货 | 符合预期 | HBM需求预期不变 |
| DDR | 单CPU DDR提升到3倍，2026年每GPU约0.5TB | 略好于预期 | 需求增加约1EB，对应供需缺口扩大约1% |
| NAND | 新增ICMS平台，每GPU扩展16TB | 最超预期 | 需求增加约45EB（44.8EB），相当于2025年全球NAND供应的4-5%，缺口扩大4-5% |

**股价映射**：NAND最受益，闪迪+27%，铠侠涨幅也更明显；美光+10%；海力士、三星表现相对弱。

**关键指标与数据来源**：单GPU/单CPU/单柜存储含量、相对市场预期的增量、需求增量占全球供应比例、事件日股价涨幅；规格来自发布会披露。

**判断标准**

- 以“相对预期的增量”而不是“绝对规格”判断利好大小：HBM升级到HBM4听起来是升级，但单GPU容量不变，仍属符合预期。
- 缺口扩大幅度越大，对应品类的弹性越大：DDR缺口扩大约1%，NAND缺口扩大4-5%，因此NAND最受益。
- 验证标准：超预期幅度排序（NAND > DDR > HBM）应与股价涨幅排序一致；本案中闪迪+27%、美光+10%、海力士和三星相对弱，与之匹配。
- 推理链条：发布规格 → 对标预期得出预期差 → 折算需求增量 → 占全球供应比例即缺口变化 → 受益程度排序 → 股价弹性。

**海豚案例**

- 英伟达、闪迪、美光、铠侠、海力士、三星《老黄解锁Rubin，AI存储又添“一把火”》（2026-01-07）：CES2026发布Rubin后，按HBM符合预期、DDR略好于预期、NAND最超预期给出三档判断；量化DDR需求增加约1EB、缺口扩大约1%，NAND需求增加约45EB、缺口扩大4-5%；映射到闪迪+27%、铠侠涨幅更明显、美光+10%、海力士和三星相对弱。

**适用场景与注意事项**：适用于大客户新平台或新品发布对供应链的冲击评估。要求事先对市场原有预期有清晰基准；发布的规格之后可能调整，需持续跟踪规格变化。需求底层公式见 3.2，供需缺口的完整口径见 5.1。

### 12.1.5 技术代际参数回溯与事件真实触发点识别

**方法要点**：对技术类事件，先回溯技术各代的关键参数判断进步速度，再识别区别于同类技术的核心能力，最后找出真正引爆市场的触发点——往往不是技术发布本身，而是“从实验室走到用户可直接使用”的那一刻。

**操作步骤**

1. 回溯各代关键参数，判断进步速度（见下表）。
2. 识别区别于同类技术的关键能力：可交互、能预测交互后的空间变化、长时间一致性（区别于视频生成）。
3. 找真正的触发点：技术早已发布，引发巨震的是上线渠道与用户实操，而不是论文或预告。
4. 对影响的量级做落地判断：参数已达到什么水平，能支撑什么级别的产出。

**Genie各代参数回溯**

| 代际 | 时间 | 关键参数 |
|---|---|---|
| 初代 | 2024年2月 | 分辨率低、交互单一、一致性只有几秒、物理只有简单碰撞 |
| 二代 | 2024年12月 | 分辨率提升，引入3D交互，一致性和物理反馈改善 |
| 三代 | 2025年8月预告 | 720P、20-24FPS实时交互，一致性最长3-5分钟，公众版最多生成60秒 |

**触发点**：1月30日上线Google AI Ultra（250美元/月，前三月半价），用户直接上手后发现效果超预期。技术早已发布，但从内部研究走到用户实操，冲击力完全不同。

**关键指标与数据来源**：分辨率、帧率、一致性时长、可生成时长、上线渠道与定价。

**判断标准**

- 进步速度：逐代比较分辨率、交互维度、一致性时长与物理反馈，三代之间一致性从“几秒”提升到“3-5分钟”，说明迭代很快。
- 与同类技术的区分：可交互、预测交互后的空间变化、长时间一致性，是区别于视频生成的核心。
- 触发点判断：若技术早已公开，而股价巨震发生在“用户可用”的节点，则冲击来自可用性与体验超预期，而不是技术新闻本身。
- 影响量级：Genie 3已能支撑做一个小关卡或一段沉浸式探索场景，据此评估对游戏行业的影响。

**海豚案例**

- 谷歌Genie与游戏行业《血洗游戏股，谷歌打出「灭霸」响指？》（2026-02-02）：回溯Genie三代参数；识别可交互、预测空间变化、长时间一致性三项区别于视频生成的能力；指出真正触发点是1月30日上线Google AI Ultra，用户直接上手后效果超预期；判断Genie 3已能支撑做一个小关卡或一段沉浸式探索场景。

**适用场景与注意事项**：适用于AI模型发布事件的影响判断。注意演示效果与稳定量产之间的差距：公众版最多生成60秒，与最长3-5分钟的一致性之间存在落差。技术路线图方法见 6.2。

### 12.1.6 用大客户订单与融资用途验证技术取舍的商业吸引力

**方法要点**：技术分析之后，用客户行为（订单、融资用途、交付需求）验证一条技术路线是否具备商业吸引力，判断其商业化进度。

**操作步骤**

1. 先完成技术分析，得出路线的技术特点。
2. 收集锚定客户的订单：芯片数量、签约时间。
3. 收集融资用途：融资额及其与某平台挂钩的比例。
4. 据此判断商业化阶段：是否从自用转向对外商业化，是否成为外部前沿实验室可规模采用的选项。
5. 用锚定客户的交付需求，反向解释厂商的技术选择。

**关键数据**：Anthropic在2025年7月与谷歌签下近100万颗TPU的订单；近期2,000亿美元融资计划中超过75%与TPU挂钩。

**判断标准**

- 订单规模与融资挂钩比例越高，说明技术路线的商业吸引力越强。
- 推理链条：近100万颗TPU订单 + 融资中超过75%挂钩TPU → TPU正从谷歌内部自用转向TPU-aaS商业化，成为外部前沿实验室可以规模采用的算力选项 → 很可能成为英伟达的竞争对手。
- 变体：用锚定客户的交付需求解释厂商取舍——AWS篇用锚定客户（Anthropic）的交付需求来解释AWS为什么选PCIe。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：以Anthropic近100万颗TPU订单与2,000亿美元融资中超75%与TPU挂钩，判断TPU转向TPU-aaS商业化。
- AWS《AWS 图省事…》（2026-10-12）：以锚定客户（Anthropic）的交付需求解释AWS选择PCIe的取舍。

**适用场景与注意事项**：适用于判断一条技术路线的商业化进度。要注意订单口径（意向还是已确认）和实际落地节奏。商业化障碍与产业化进度的系统方法见 6.5，融资结构见 9.6。

### 12.1.7 用巨头“离网自建”交易和立法提案作为趋势拐点信号

**方法要点**：判断“离网自建”这类新商业模式是否已成为主流策略，不靠逻辑推演，而是收集行为、资本、制度三类硬证据，互相印证后确认“从向电网要电到自产电力”的根本转变。

**操作步骤**

1. 找产业龙头的实际采购（行为证据）：xAI绕开电网，直接向韩国斗山采购5台单机380MW的重型燃机，组成1.9GW独立微电网（5台×380MW≈1.9GW）。
2. 找以溢价并购“购买时间”的交易（资本证据）：谷歌为拿到已锁定的电网连接许可，溢价47.5亿美元收购Intersect Power。
3. 找政策与法律可能性（制度证据）：议员Tom Cotton提出《DATA Act of 2026》，允许数据中心以“物理隔离”换取FERC监管豁免。
4. 三类证据对照：行为、资本、制度互相印证，才得出趋势拐点结论。
5. 并购解读的重点：溢价买的是什么（时间、并网许可），而不是资产本身。
6. 用面上数据补足个案：结合渗透率调研数据（如Bloom调研）。

| 证据类型 | 事实 | 说明 |
|---|---|---|
| 行为 | xAI向斗山采购5台单机380MW重型燃机，组成1.9GW独立微电网 | 龙头已实际绕开电网 |
| 资本 | 谷歌溢价47.5亿美元收购Intersect Power | 买的是已锁定的电网连接许可，即“时间” |
| 制度 | 《DATA Act of 2026》允许数据中心以“物理隔离”换FERC监管豁免 | 政策层面出现松绑路径 |

**关键指标与数据来源**：单笔采购规模（台数×单机MW）、并购对价、立法进展。

**判断标准**

- 单一证据只能算个案，三类证据同向才能确认拐点。
- 并购溢价越高，说明“时间”越稀缺，也越能说明电网排队已成为硬约束。
- 推理链条：行为（龙头采购燃机）+ 资本（溢价买时间）+ 制度（立法松绑）→ 数据中心从向电网要电转向自产电力。

**海豚案例**

- AI电力《AI 终极瓶颈…》（2026-04-09）：以xAI的1.9GW微电网、谷歌47.5亿美元收购Intersect Power、DATA Act of 2026三类证据判断离网自建成为趋势。
- AI电力《AI 电荒突围》（2026-04-14）：引用马斯克所述，xAI因电网延期12-18个月转购燃机，并发现燃机订单排到2030年。

**适用场景与注意事项**：适用于判断新商业模式或新需求是否“真实发生”。要注意个案的代表性，需结合渗透率调研数据（如Bloom调研）补足面上数据。供给瓶颈的约束切换见 4.4，电力赛道专属要点见 16.4。

### 12.1.8 确定性大事件的景气前置判断与“利好接力”观察

**方法要点**：对时间早已确定的事件（体育赛事、选举、大促），判断其对行业景气的季度级影响，同时意识到资金会提前布局、估值修复也会提前完成，因此关键不在事件本身，而在事件过后是否有新利好接力。

**操作步骤**

1. 列出确定性事件的时间表：北美世界杯、冬奥会、美国中期选举、Prime Day。
2. 判断受益行业：酒旅、品牌广告、搜索广告的季度级利好，属于确定性事件。
3. 判断是否已被定价：资金提前布局，业绩“并不意外”，估值修复也提前完成。
4. 用同业龙头验证景气：以Booking的业绩与股价作为行业景气的参照。
5. 事件过后观察是否有新利好接力。
6. 反例复盘：对事件期待过高导致误判。

**关键指标与数据来源**：事件时间表、同业业绩与股价、广告预算。

**判断标准**

- 确定性事件的利好是季度级的，但因为“早已确定”，业绩超预期的空间有限，估值修复也往往提前完成。
- 关键看“接力”：事件过后若没有新的利好，景气与股价可能回落。
- 同业龙头的业绩与股价是检验行业景气是否到位的标尺。
- 防误判：不对事件抱过高期待，避免把确定性事件当成超预期来源。

**海豚案例**

- Airbnb（2026-08-07）：世界杯横跨美加墨，加上中东冲突缓解；Booking同样走势，印证酒旅景气。
- 谷歌（2026-02-05）：世界杯、冬奥会、中期选举有望带动品牌广告反弹。
- 谷歌（2026-04-30）：冬奥会推动品宣，6月世界杯与Q3中期选举对冲美伊摩擦。
- 谷歌（2026-07-23）：YouTube回暖与世界杯有关，Temu、Shein北美投放回归。
- 分众（2026-08-21）：上季对消费政策、世界杯期待过高而误判（反例）。

**适用场景与注意事项**：适用于周期性或事件敏感行业。要先判断事件是否已被价格消化，再看接力；事件日历的管理见 15.4，景气跟踪指标见 13.1。

**本节速查清单**

- [ ] 事件点评是否按“股价异动→业绩/电话会→行业供需→逻辑扩散→叠加事件→选股”的顺序展开，且每一步都有硬证据（定价数据、业绩会表述）。
- [ ] 是否把公司层影响与上游传导分开，并用一个问句式主线贯穿全文。
- [ ] 技术突破类事件是否先精确化市场担忧点，再按“技术基础→改变了什么→难点与是否独有→行业影响”四问展开，且先讲技术后谈影响。
- [ ] 新品发布是否先写出市场原有预期基准，逐品类给出“符合/略好/最超预期”，并量化需求增量占全球供应的比例。
- [ ] 股价弹性是否与预期差排序一致，是否已经price in。
- [ ] 技术类事件是否回溯了各代关键参数，并区分“技术发布”与“用户可用”两个时点。
- [ ] 趋势是否“真实发生”：有没有客户订单、融资用途，或行为、资本、制度三类证据互相印证。
- [ ] 确定性大事件是否已被提前定价，事件过后是否有新利好接力，同业龙头是否验证了景气。

## 12.2 信息甄别与传闻处理

> 本节导读：本节解决“消息来了，先别急着推演影响，先判断它是真是假、有多强”。供应链传闻先标注未证实、再列合理性、最后推演影响（12.2.1）；政策类传闻回到法规与公告原文，拆税种、核税档、查公告（12.2.2）；公司表态做字面级辨析，缺规格、良率、出货信息时下调事件强度（12.2.3）。三者共同的动作，是把“事实层面的未证实或乌龙”与“逻辑层面的风险外推”分开。甄别之后的冲击量化与影响期限见 12.3；一手信息源的取证见 1.3；分歧处理与叙事纠偏见 13.3。

### 12.2.1 供应链传闻解读：先标注未证实，再列合理性，最后推演瓶颈迁移

**方法要点**：面对第三方机构报道的产业链传闻，先明确“这是未证实的信息、只代表厂商在考虑不同选项”，再列出该变动若为真的合理性，最后推演它会把瓶颈推向哪里，而不是直接把传闻当作事实或直接否定。

**操作步骤**

1. 还原传闻内容并标注来源与可信度：SemiAnalysis报道，Rubin Ultra每个计算核心配4颗HBM，层数从16层降到12层，又可能降到8层，单GPU HBM容量从768GB砍到192GB。同时明确，以上变动均未经英伟达官方确认，只代表其在考虑不同选项。
2. 列出变动的合理性，逐条独立论证：
   - ①堆高本身工艺难、成本高。
   - ②DRAM晶圆产能有限：同等GB容量下，HBM消耗的DRAM晶圆是常规DRAM的3-4倍，层数越高损耗越大；据投行预测，DRAM新增产能在2024-2026年有限，2027年才较多释放，这是主要卡点。
   - ③Scale-up互联扩大，系统总容量不降反升，因此单GPU HBM容量下降不等于总容量下降。
3. 推演新问题：假设传闻为真，瓶颈从HBM层数和DRAM晶圆转向Base Die和共同封装产能，关键变成能从台积电（以及三星、Intel）锁定多少产能；对互联和内存池化的要求也随之拉高。

**关键指标与数据来源**：HBM层数与颗数、单GPU HBM容量、HBM对DRAM晶圆的消耗倍数、DRAM晶圆产能增速、CoWoS产能；传闻来源为SemiAnalysis报道，产能预测来自投行。

**判断标准**

- 标签优先：全文贯穿“未证实”标注，所有结论采用“如果为真”的条件句。
- 合理性检验：从工艺成本、晶圆产能、系统总容量三个独立角度各自成立，才能说传闻有合理性；合理性只代表可能，不等于确认。
- 推理链条：层数降低 → 单GPU HBM容量下降 → 节省DRAM晶圆（HBM消耗为常规DRAM的3-4倍）→ 缓解2024-2026年DRAM新增产能有限的主要卡点 → 瓶颈迁移到Base Die与共同封装产能，并抬高对互联与内存池化的要求。
- 关注“瓶颈迁移”而非“某一环节减量”：一个环节的约束放松，必然要问下一个被卡住的环节在哪里（供给瓶颈的切换方法见 4.4）。

**海豚案例**

- 英伟达Rubin Ultra《从HBM限高到NAND加量，英伟达vs存力到底谁拿捏谁？》（2026-09-29）：解读SemiAnalysis关于HBM降层的报道——先声明未经英伟达官方确认；再列出工艺难度与成本、DRAM晶圆消耗3-4倍与2027年才较多释放的新增产能、Scale-up扩大使系统总容量不降反升三条合理性；最后推演瓶颈转向Base Die和共同封装产能，关键是从台积电（以及三星、Intel）锁定产能。

**适用场景与注意事项**：适用于产业链传闻事件。要先标明来源和可信度，再按“如果为真，有何合理性、有何影响”推演；规格最终以官方披露为准，传闻阶段的任何数字都可能调整。

### 12.2.2 税收传闻甄别：拆税种、核税档、查公告，识别“税率不变调篮子”

**方法要点**：对“某行业要加税”这类传闻，不凭印象判断，而是按三步回到法律与公告原文，找出真实变化与传闻错在哪里；甄别后再单独识别市场真正担心的“逻辑外推风险”，把可证伪的“事实乌龙”与需要持续跟踪的“风险外推”分开。

**增值税三档对照（核对基准）**

| 档位 | 对应范围 |
|---|---|
| 6% | 现代服务、增值服务 |
| 9% | 基础服务 |
| 13% | 主要对应自营卖货 |

**操作步骤**

1. 对照法律，确认税率档位有没有变：《增值税法》仍是上表三档，没有变化。
2. 查财政部和税务总局2026年2月初的公告，找真实变化：税率没改，而是把部分类目从6%的篮子挪进9%的篮子（调篮子）。
3. 找出传闻错在哪：把增值税、所得税和游戏行业税率等不同税种混为一谈。
4. 识别市场真正担心什么：三大电信运营商的流量、宽带接入、短信从“增值电信服务”（6%）划到“基础电信服务”（9%），市场担心这条逻辑顺延到搭在其上的互联网服务。
5. 分层结论：事实层面的乌龙（可以证伪）与逻辑层面的风险外推（需要持续跟踪）分别处理。

**关键指标与数据来源**：增值税三档税率（6%/9%/13%）及适用类目、财政部与税务总局公告、企业所得税率、行业专项税。

**判断标准**

- 是否有变化：以法律与公告原文为准，税率档位没变就不是“加税”；只是类目归属从一个篮子调到另一个篮子，则属于“调篮子”。
- 传闻错在哪：不同税种（增值税、所得税、行业专项税）被混为一谈，是最常见的错误。
- 真正的风险：运营商业务划转到基础电信服务，暗含“类目重新归类”的方向，市场交易的是向互联网服务外推的可能性。
- 推理链条：拆税种 → 核税档 → 查公告 → 确认真实变化只有类目调整 → 区分“已证伪的乌龙”与“仍需跟踪的外推风险”。

**海豚案例**

- 腾讯、阿里《中概：加税传闻，“乌龙”背后的道理》（2026-02-03）：确认互联网行业没有调整，提高所得税率、游戏税30%+属无中生有；真实变化只有三大电信运营商的流量、宽带、短信从6%调至9%；并识别市场担心这条逻辑顺延到搭在其上的互联网服务。这一变化对运营商业绩的逐项归因见 12.3.6（中国移动 2026-03-26）。

**适用场景与注意事项**：适用于政策传闻导致的急跌。前提是能查到原始法规或公告。注意：市场交易的是“外推风险”，传闻被证伪后，估值折价也可能继续存在，不要因为“乌龙”被证实就直接推导股价会完全修复。财税与关税测算的系统方法见 10.2。

### 12.2.3 公司措辞辨析：「推出」≠「量产」，缺规格、良率、出货信息时下调事件强度

**方法要点**：对官方表述做字面级辨析，把“发布、送样、小批量、量产爬坡”这些阶段区分清楚；当规格、良率、出货规模等关键信息缺失时，下调事件强度，从而为“短期影响有限”提供依据。

**操作步骤**

1. 摘录官方原话，逐字核对用词：长鑫总裁称首代4F²产品“年底推出”，用词是“推出”而非“量产”。
2. 检查关键披露项是否齐备：产品规格、良率、出货规模。
3. 缺项则降级：年底产品更可能是发布、送样或小批量验证，而不是产能释放。
4. 给事件定位：从“要不要做”进入“能做”的阶段，而非产能已释放。
5. 把定位转化为影响判断：为“短期影响有限”提供依据，并交给 12.3.4 判断影响期限。

**阶段阶梯**：发布 → 送样 → 小批量 → 量产爬坡。判断事件落在哪一级，决定事件强度。

**关键指标与数据来源**：官方措辞、规格/良率/出货规模是否披露。

**判断标准**

- 词汇决定阶段：“推出”只代表产品面世，不代表具备量产能力。
- 信息完整度决定强度：规格、良率、出货规模三项都没有，事件强度应下调；三项都有披露，才能按产能释放评估。
- 推理链条：官方措辞为“推出”→ 缺规格、良率、出货规模 → 更可能是发布、送样或小批量验证 → 事件定位为“从要不要做进入能做” → 短期影响有限。

**海豚案例**

- 长鑫科技《长鑫把晶体管「竖起来」：绕开 EUV 的追赶路，会撼动存储三巨头吗？》（2026-10-16）：长鑫总裁称首代4F²产品“年底推出”，海豚君据措辞与缺少规格、良率、出货规模判断年底产品更可能是发布、送样或小批量验证，把事件定位为“从要不要做进入能做的阶段”，作为“短期影响有限”的依据。

**适用场景与注意事项**：适用于所有新品或技术发布类事件，尤其中国厂商发布会与媒体报道；关键是区分发布、送样、小批量、量产爬坡。措辞辨析只决定事件强度，影响期限的判断见 12.3.4，追赶者评估见 8.7。

**本节速查清单**

- [ ] 传闻是否标注了来源与可信度（“未经官方确认”），结论是否采用“如果为真”的条件句。
- [ ] 是否从工艺成本、产能、系统层面等多个独立角度检验了传闻的合理性。
- [ ] 是否推演了瓶颈会迁移到哪个环节（如Base Die、共同封装产能），而不是只看被减量的环节。
- [ ] 政策传闻是否回到法律与公告原文，核对了税档，并区分增值税、所得税与行业专项税。
- [ ] 是否区分了“事实乌龙”（可证伪）与“逻辑外推风险”（需持续跟踪），并考虑证伪后估值折价可能仍在。
- [ ] 公司措辞是“推出”还是“量产”，规格、良率、出货规模是否披露。
- [ ] 事件落在“发布、送样、小批量、量产爬坡”中的哪一级，强度是否据此调整。

## 12.3 事件冲击量化、归因与影响期限

> 本节导读：本节解决“事件到底影响多大、归因给谁、能持续多久”。先看量化：突发供给事件用“份额×停产时长×恢复时间”（12.3.1），事件相关增量拆成多个因子以剥离既有趋势（12.3.2），并购事件做三维解读（12.3.3）；再看期限与归因：影响分短期与中长期、区分担忧与基本面（12.3.4），市场大跌拆分流动性与产业叙事（12.3.5），业绩波动逐项归因到具体政策或外部冲击（12.3.6）；最后是地缘/能源冲击对远期技术路线价值的重估（12.3.7）。事件真伪与强度的前置甄别见 12.2，事件解读路径见 12.1；供需缺口与周期位置的系统方法见第5章，政策条款的拆解见第10章。

### 12.3.1 突发供给事件量化：份额 × 停产时长 × 恢复时间

**方法要点**：对罢工、停电、地震等突发事件，用三个参数框定供给冲击的量级——事件主体的市场份额、停产时长、恢复时间，并推到业绩与毛利率的影响。

**操作步骤 / 公式**

1. 识别突发事件类型（罢工、停电、地震等）及事件主体。
2. 取三个参数：
   - 事件主体的市场份额：三星在DRAM市场近4成。
   - 停产时长：工会投票决定5月21日起罢工18天。
   - 恢复时间：一旦停工，重启产线可能需要长达两个月。
3. 联合判断量级：冲击量级由“份额 × 停产时长 × 恢复时间”共同决定。需要补充的一点是，实际影响窗口是停产期加产线恢复期，而不仅是停产天数——本例中停产18天，但恢复可能长达两个月，影响期远长于停工期。
4. 核实事件是否真正发生，以及是否有库存缓冲（缓冲会稀释短期冲击）。
5. 传导到同业业绩：判断对竞争对手出货、价格、毛利率的影响。

**关键指标与数据来源**：事件主体市场份额；停产天数；产线重启时间；工会投票结果、公司公告与新闻报道。

**判断标准**

- 份额越高，恢复时间越长，事件对供给的冲击越大；份额近4成的寡头停工，足以改变短期供需。
- 与停产时长相比，恢复时间决定影响的“尾巴”：一旦停工，重启产线可能需要长达两个月。
- 推理链条：三星份额近4成 + 罢工18天 + 重启需长达两个月 → 同业短期供给更紧 → 业绩有望持续超预期，下季毛利率有机会再超指引。

**海豚案例**

- 美光《美光 MU：AI 带动存储“疯涨”，能破周期“紧箍咒”吗？》（2026-03-19）：分析三星罢工事件，用份额近4成、停产18天（5月21日起）、重启需长达两个月三个参数量化冲击，结论是美光短期业绩有望持续超预期，下季毛利率有机会再超指引。

**适用场景与注意事项**：适用于寡头供给行业。需要确认事件是否真正发生，以及是否有库存缓冲。供给瓶颈与刚性见 4.4，供需缺口判断见 5.1。

### 12.3.2 把事件相关增量拆成多个因子：区分既有趋势与事件带来的纯增量

**方法要点**：把市场归功于某个事件的增量，拆成“本来就在发生的”和“事件带来的”两部分，只有后者才是新信息。以头节点CPU增量为例，拆成配比、单CPU核数、DPU三个因子。

**操作步骤 / 拆分口径**

1. 取总增量：近年每GPU对应的头节点核数涨了约3.75倍。
2. 拆成三个来源：

| 因子 | 变化 | 说明 |
|---|---|---|
| GPU与CPU配比 | 从传统HGX的4:1提高到NVL72的2:1 | 翻倍 |
| 单颗CPU核数 | 增加22% | 单颗核数提升 |
| DPU | NVL72里新增DPU贡献36% | 新增部件 |

3. 判断每个因子的驱动力：这部分是纯经济性驱动，即“投入CPU来榨干GPU的每一分钱”（头节点带宽不够 → GPU等数据 → 利用率下降）。
4. 与事件对照：这些增量不是Muse的Agentic AI直接拉动的；而且下一代还看不到再次大幅提升的迹象。
5. 结论：Agentic对头节点的带动不大。

**关键指标与数据来源**：GPU:CPU配比、单CPU核数、每GPU核数（36→60）、DPU数量。

**判断标准**

- 既有趋势 vs 纯增量：因子在事件之前就已经在发生、且由经济性驱动的，不应归功于事件。
- 前瞻检验：下一代是否还有再次大幅提升的迹象；没有，则事件对需求的拉动更弱。
- 推理链条：总增量3.75倍 → 拆成配比翻倍、单CPU核数+22%、DPU贡献36% → 均为提升GPU利用率的经济性驱动 → 与Muse无关 → Agentic对头节点的带动不大。
- 口径提示：各因子与总倍数并非简单连乘关系，不同基准代际或是否含DPU都会使数字有差异，使用时要统一基准和口径。

**海豚案例**

- Muse与CPU《Muse“爆火”…》（2026-09-28）：把头节点CPU增量拆成配比（4:1→2:1，翻倍）、单CPU核数（+22%）、DPU（新增贡献36%）三因子，判断为纯经济性驱动而非Muse的Agentic AI直接拉动，下一代也看不到再次大幅提升的迹象，得出Agentic对头节点带动不大的结论。事件分层与主线见 12.1.2。

**适用场景与注意事项**：适用于任何由事件驱动的需求上修判断，防止把存量趋势当成新增量。

### 12.3.3 并购事件三维解读：人才收购、IP获取、防御性收购

**方法要点**：对科技行业并购，不停留在“收购了谁”，而是拆交易实质——人才、IP、战略意图（含防御性收购），再推演对产业路线和竞争格局的影响。

**操作步骤 / 拆分口径**

1. 拆交易实质：
   - 人才：创始人Jonathan Ross（谷歌TPU创始成员）和约90%核心工程团队加入英伟达，Groq由新CEO接任。
   - IP：获得LPU架构、TSP微架构、编译器技术等全部核心IP以及硬件资产使用权。
   - 战略意图：一方面融合SRAM技术提升推理能力，另一方面属于防御性收购，避免技术落入竞争对手手中。
2. 推演对产业的影响：这笔交易推高了“SRAM替代HBM”的讨论。
3. 给出期限判断：短期两者仍是互补。

**关键指标与数据来源**：交易结构（人才/IP/资产）、被收购方的技术定位、对推理能力的贡献。

**判断标准**

- 三维分别回答：买到了谁（人才）、买到了什么（IP）、为什么买（进攻性融合还是防御性阻断）。
- 防御性收购的判断依据：核心团队与核心IP被整体买走，使技术无法流向竞争对手。
- 产业影响的判断：讨论度升高不等于路线替代，短期仍按互补处理。
- 推理链条：创始人和约90%核心团队加入 + 获得全部核心IP与硬件资产使用权 → 既融合SRAM、又防止落入对手 → 人才收购加防御性收购 → Rubin有望融入Groq的3D SRAM技术。

**海豚案例**

- 英伟达/Groq《存储猛拉，AI存力超级周期到底有多神？》（2026-01-06）：按人才、IP、战略意图三维拆解，结论是人才收购加防御性收购，Rubin有望融入Groq的3D SRAM技术；对产业的影响是推高“SRAM替代HBM”的讨论，但判断短期两者仍是互补。

**适用场景与注意事项**：适用于科技行业并购（尤其是“收人才+IP授权”型交易）。需关注监管和整合风险。并购溢价买“时间”的另一类解读见 12.1.7；替代与互补关系见 6.6。

### 12.3.4 事件影响分短期与中长期：以“市场可见供需期限”判断，区分股价反映的是担忧还是基本面

**方法要点**：把事件影响拆成短期与中长期两段，以“市场可见供需期限”为尺子——冲击是否落在市场定价的可见期内，决定了股价下跌反映的是担忧还是基本面。

**操作步骤**

1. 确定事件冲击的真实起点：产品何时能放量（量产时间表、爬坡节奏）。
2. 确定市场可见期：市场目前可见的供需预测到哪一年（本例至2028年）。
3. 判断冲击是否落在可见期内：
   - 落在可见期之外：对当前供需影响有限，短期股价变动更多是情绪。
   - 落在可见期内：影响已体现在基本面预期中，需上修或下修供需预测。
4. 区分股价反映的是什么：担忧（如对追赶速度的担忧）还是基本面即时变化。
5. 单独写中长期：量化产出增幅，评估供给增速的上行风险。

**短期与中长期对照**

| 期限 | 判断 | 依据 |
|---|---|---|
| 短期（2026-2027） | 影响有限 | 长鑫只是预告，首代产品规格、良率、规模未知；新架构从首发到成为产能主力需较长爬坡期；结合三大厂4F²量产计划，4F²产品更可能在2028年末才大量释放，而市场目前可见的供需格局只到2028年。近期三大厂股价走弱更多反映对长鑫追赶速度的担忧，而非基本面即时变化 |
| 中长期（2028年后） | 供给增速有上行风险 | 4F²相当于一次性兑现约两代制程的密度提升，晶圆产量不变下bit产出+30-50% |

**关键指标与数据来源**：量产时间表、市场预测可见期（至2028年）、bit产出增幅（30-50%）、股价反应。

**判断标准**

- 核心框架：事件冲击是否落在市场定价的可见期内。
- 新架构的路径：首发 → 爬坡 → 成为产能主力，每一步都要时间；首代规格、良率、规模未知，意味着短期无法折算成有效供给。
- 中长期的量级：一次性兑现约两代制程的密度提升，bit产出+30-50%。
- 推理链条：4F²大量释放在2028年末 → 超出市场可见期（至2028年）→ 当前供需影响有限 → 股价下跌更多反映对追赶速度的担忧 → 2028年后供给增速有上行风险。

**海豚案例**

- 长鑫科技/DRAM行业《长鑫把晶体管「竖起来」：绕开 EUV 的追赶路，会撼动存储三巨头吗？》（2026-10-16）：短期（2026-2027）影响有限，三大厂股价走弱主要反映担忧；中长期（2028年后）bit产出+30-50%，供给增速有上行风险。四问法见 12.1.3，措辞辨析见 12.2.3。

**适用场景与注意事项**：适用于新闻冲击型下跌的买点判断：若冲击落在可见期之外，短期股价下跌更多是情绪。仍要保留中长期风险，不能因为短期有限就否定长期影响。

### 12.3.5 市场大跌归因拆分：流动性去杠杆 vs 产业叙事事件

**方法要点**：在点评引发市场波动的产业事件前，先拆分下跌原因，把“情绪与流动性”和“基本面”分开，避免把下跌全部归于单一新闻，再对产业事件本身做独立评估。

**操作步骤**

1. 拆分下跌原因：
   - 流动性去杠杆：韩国加息、地缘问题。
   - 产业叙事事件：市场相对一致归因的K3大模型发布及“中美竞争”叙事。
   - 噪声：真假小作文趁机传播，需单独识别。
2. 对产业事件本身做独立评估：短期影响有限但意义重大。
3. 把流动性因素的影响从产业事件中剥离，避免用叙事替代流动性解释。

**关键指标与数据来源**：利率事件（韩国加息）、地缘事件、市场传闻、产业事件。

**判断标准**

- 同一时间窗口出现多个潜在原因时，不能把全部跌幅归因于市场最一致的那一条叙事。
- 产业事件需要脱离市场情绪独立评估：短期影响与长期意义可以不一致（短期有限、意义重大）。
- 推理链条：全球市场大跌 → 流动性去杠杆（韩国加息、地缘）与产业叙事（K3发布、中美竞争）并存，加上小作文 → 分别评估 → 产业事件短期影响有限但意义重大。

**海豚案例**

- Kimi/大模型《Kimi K3 时刻：中美 AI 产业链叙事要变天？》（2026-07-22）：上周全球市场大跌，既有韩国加息、地缘问题导致的流动性去杠杆，也有市场相对一致归因的K3大模型发布及“中美竞争”叙事，真假小作文趁机传播；海豚君先拆分，再对K3事件独立评估为短期影响有限但意义重大。

**适用场景与注意事项**：适用于任何事件驱动型大跌后的复盘；关键是不让叙事替代流动性解释。流动性与利率层面的分析见 15.1，传闻甄别见 12.2。

### 12.3.6 业绩波动逐项归因到具体政策或外部冲击

**方法要点**：把公司业绩的波动逐项归因到具体的政策或外部冲击，并区分短期阵痛与长期影响，避免把政策变量笼统归为“需求不好”或“经营变化”。

**操作步骤**

1. 列出可能影响业绩的政策与外部冲击清单：国补退坡、关税、IRA补贴退坡、购置税退坡、增值税调整、外卖补贴减弱等。
2. 逐项标注政策的时间点和影响金额。
3. 区分短期阵痛与长期影响：例如公司通过海外布局产能来消化关税，则属于阵痛期。
4. 注意同一政策对不同公司的方向可能相反：国补退坡对拼多多反而是边际利好。
5. 把归因结果写进业绩预期与指引的判断中。

**关键指标与数据来源**：政策的时间点；影响金额；公告与法规原文。

**海豚案例**

| 政策或冲击 | 涉及公司与日期 | 归因要点 |
|---|---|---|
| 国补退坡 | 京东（2026-03-05）、阿里、拼多多 | 对拼多多反而是边际利好 |
| 国补与关税 | 苹果（2026-01-30） | iPhone17 256G可享国补；中国区关税从20%降到10% |
| 美国加征关税 | 三花（2026-03-23） | 美国6月起对“钢铁衍生产品”加征关税；公司在墨西哥、泰国和美国本土布局产能，属阵痛期 |
| IRA补贴退坡 | Rivian、特斯拉 | 业绩波动归因于IRA补贴退坡 |
| 购置税退坡 | 蔚来、理想 | 业绩波动归因于购置税退坡 |
| 增值税调整 | 中国移动（2026-03-26） | 流量、短信、彩信从增值电信服务改为基础电信服务，增值税从6%升到9% |
| 增值税传闻 | 网易 | 游戏增值税传闻（甄别方法见 12.2.2） |
| 外卖补贴减弱 | 瑞幸、蜜雪 | 业绩波动归因于外卖补贴减弱 |
| 关税 | 阳光电源 | 关税共担约5亿 |
| 关税 | Lululemon | 业绩波动归因于关税 |

**判断标准**

- 先问“这是政策/外部冲击，还是经营层面的变化”：能追溯到具体政策的，按政策时间点和影响金额量化。
- 短期阵痛 vs 长期影响：公司已在多地布局产能（三花在墨西哥、泰国和美国本土）、关税承担方式（阳光电源关税共担约5亿）等，决定冲击是一次性还是持续。
- 同一政策对不同公司方向不一：国补退坡对拼多多反而是边际利好，与京东、阿里所受影响的方向不同。
- 推理链条：政策时间点 → 影响金额 → 归入当期业绩 → 判断阵痛或长期 → 调整预期。

**适用场景与注意事项**：普遍适用。归因时要避免把所有波动都推给政策，应保留经营层面的变化；政策条款拆解与敞口排序见 10.1，财税、关税与补贴测算见 10.2。

### 12.3.7 地缘/能源冲击对远期技术路线价值的重估

**方法要点**：在已经排除某技术路线短期作用之后，再额外叠加一层事件冲击的判断：把“短期渗透逻辑”和“长期估值逻辑”分开处理，同一技术短期不进入需求测算，但估值上可因地缘事件获得期权价值。

**操作步骤**

1. 先判断短期渗透：核电/SMR作为短期主电源存在交付错配，短期无实质渗透，因此不进入需求测算。
2. 叠加事件冲击：美伊冲突导致全球传统能源风险持续。
3. 重估远期价值：能源安全溢价使核电、SMR的远期价值可能得到再次重估。
4. 分开处理两套逻辑：短期看渗透与交付，长期看估值与期权价值。
5. 单独跟踪事件冲击的持续性。

**关键指标与数据来源**：能源价格波动、地缘风险事件、核电/SMR项目进度。

**判断标准**

- 短期：交付错配，无实质渗透，不进入需求测算。
- 长期：地缘事件带来的能源安全溢价，使远期价值可能被再次重估，体现为估值层面的期权价值，而不是近期需求。
- 推理链条：短期交付错配 → 不进需求 → 美伊冲突使传统能源风险持续 → 能源安全溢价 → 远期价值可能再次重估。

**海豚案例**

- AI电力《AI 终极瓶颈…》（2026-04-09）：“美伊冲突导致的全球传统能源风险持续下，全球核电、SMR 的远期价值可能得到再次重估”；同时短期不把核电/SMR作为主电源纳入需求测算。

**适用场景与注意事项**：适用于能源、军工等受地缘影响的赛道。事件冲击的持续性需要单独跟踪。出口管制与地缘风险的专门方法见 10.3，电力赛道要点见 16.4。
