## 8.1 份额追踪与市占率口径

> 本节导读：本节解决“份额数字从哪来、口径对不对、变化说明了什么”的问题。份额是竞争格局分析的起点，但同一个“份额”可能是出货量、收入、订单、月活、Token，也可能被垂直一体化巨头、战略收缩或产能虚高扭曲，所以研究一个行业、或每次财报更新竞争格局时，先在这一步把口径钉死。口径确定后接 8.2（梯队与定性）、8.3（竞争力对比）、8.4（竞争烈度）；份额背后的壁垒解释见 8.5，追赶者份额能否继续上行见 8.7，入口与生态层面的竞争见 9.5。

### 8.1.1 份额与供应位次的逐篇更新（CPU、HBM、光刻、代工、AI PC）

**方法要点**：每篇财报都把所在行业的“谁第几、份额多少、认证到哪一步、技术指标差多少”更新一遍，把寡头格局写成可逐季比较的几行结论，用位次与份额的变化解释估值溢价和客户的备选动作。

**操作步骤 / 拆分口径 / 公式**

1. 按细分市场建立“份额与供应位次”清单，每次财报后更新，不要只在行业深度篇里谈格局：
   - CPU：英特尔整体仍领先；AMD在桌面级反超；服务器CPU中英特尔出货被挤压到8成以下；AMD凭“CPU+GPU”组合蚕食份额。
   - HBM：海力士领先；美光是英伟达二供、进度落后海力士；三星HBM3E通过英伟达认证后，三家又回到同一起跑线；下一步看HBM4（Rubin和MI400都搭载）。
   - 光刻：ASML是全球唯一EUV提供商，垄断性用来解释其估值溢价。
   - 代工：台积电产能紧张，高通、微软等寻求备选；英特尔18A在晶体管密度上仍落后台积电。
   - AI PC：高通骁龙X2（NPU 80 TOPS，上代为45）份额仍低。
2. 每个细分市场同时记录三类信息：份额（注明出货口径还是收入口径）、供应商认证状态、关键技术指标（晶体管密度、TOPS等）。
3. 与上一次的表述逐项对照，判断位次、认证状态或技术差距有没有变化；变化才是需要写进结论的信号。

**关键指标与数据来源**：细分市场份额；供应商认证状态；技术指标（晶体管密度、TOPS）。份额数据多来自第三方（如Mercury Research），要标注来源。

**判断标准**

- 位次与份额要分开看：英特尔整体仍领先，但服务器CPU出货份额已被压到8成以下，说明“位次未变、份额在被蚕食”，趋势比静态位次更重要。
- 认证状态是格局的离散拐点：三星HBM3E通过英伟达认证，就从“落后”变成“与美光、海力士同一起跑线”，下一个比较点自动换成HBM4（认证机制见 8.1.4）。
- 垄断地位直接对应估值：ASML是唯一EUV提供商，这一事实被用来解释其估值溢价；反过来，客户在寻求备选（台积电产能紧张时的高通、微软）本身就是供给方议价权的体现，但备选方的技术指标（如英特尔18A晶体管密度）是否追平，决定备选是否现实。
- 产品指标代际变化要带上“上一代”做对照（骁龙X2 NPU 80 TOPS对上代45），再结合份额是否同步提升来判断“指标领先是否转化为份额”。

**海豚案例**

- 英特尔（2026-01-23、2026-04-24、2026-07-24）：连续三次财报都更新CPU格局——整体仍领先，AMD桌面级反超，服务器CPU中英特尔出货份额低于8成，AMD以“CPU+GPU”组合蚕食份额；英特尔18A晶体管密度仍落后台积电。
- 美光（2026-03-19）：HBM格局——美光是英伟达二供、进度落后海力士，三星HBM3E通过英伟达认证后三家回到同一起跑线，下一步看HBM4。
- 阿斯麦（2026-01-28与2026-04-15）：两次财报均强调ASML是全球唯一EUV提供商，以垄断性解释估值溢价。
- 高通（2026-02-05）：骁龙X2（NPU 80 TOPS，上代45）AI PC份额仍低；台积电产能紧张背景下，高通、微软等寻求代工备选。

**适用场景与注意事项**：适用于寡头格局的科技行业，尤其是财报季需要持续更新格局的半导体链条。第三方份额口径（出货或收入）和统计机构必须注明；认证、良率类信息往往来自产业链传闻，需要交叉验证（见 8.1.4）。

### 8.1.2 第三方份额加均价估算：量价齐升的拆解与管理层指引验证

**方法要点**：在供需紧张阶段，用第三方份额数据判断“量”的趋势、用估算的均价同比判断“价”的贡献，再用管理层对未来几个季度增速的指引验证景气是否持续，从而把收入增长拆成份额、出货与价格几个来源。

**操作步骤 / 拆分口径 / 公式**

1. 用第三方数据追踪服务器CPU份额、整体CPU（PC加服务器）份额，以及桌面级份额是否反超竞品，看份额在哪个子市场发生变化。
2. 在供需紧张阶段估算均价同比涨幅，区分量与价对收入的贡献。拆分口径：（1+收入同比）≈（1+出货量同比）×（1+均价同比）；份额变化解释“量”，均价变化解释“价”。
3. 记录管理层对服务器CPU同比增速的指引（下季、下半年、明年），逐季对照实际兑现情况，作为景气持续性的验证。

**关键指标与数据来源**：服务器CPU出货份额、整体CPU份额、桌面级份额、服务器CPU均价同比、管理层增速指引。份额来自第三方统计，均价为海豚君估算，指引来自管理层。

**判断标准**

- 份额层面：服务器CPU出货份额升至两成以上、桌面级反超竞品，说明份额增长既在高端（服务器）也在大众市场发生。
- 量价层面：均价同比上行（本例约10%-20%）说明增长不是只靠出货堆量，而是处于供需紧张下的“量价齐升”；这种增长的持续性取决于供需紧张是否延续。
- 指引层面：管理层指引的增速（下季+70%并延续到下半年；下半年超80%、2027年超70%）如果连续被抬高，说明景气持续性得到验证；指引口径若与第三方份额数据方向相反，需要重新核对口径。

**海豚案例**

- AMD《CPU“狂飙”》（2026-05-06）：第三方数据显示服务器CPU出货份额升至两成以上，桌面级市场已反超英特尔；管理层指引下季服务器CPU同比+70%，并延续到下半年。
- AMD《AMD：狂抢“AI大单”》（2026-08-05）：服务器CPU量价齐升，均价同比估计提升约10%-20%；管理层指引下半年服务器CPU同比超80%，2027年超70%。

**适用场景与注意事项**：适合寡头竞争的芯片品类，且处于供需偏紧、有涨价可能的阶段。均价为估算值，误差较大，应注明假设；第三方份额口径（出货量还是收入）要写清楚，否则“份额升”与“收入增”会被混用。需求与价格本身的追踪见 5.2。

### 8.1.3 AI芯片份额矩阵与训练/推理分阶段的替代分析

**方法要点**：先把各家数据中心AI芯片收入放在一张表里算出份额，再把市场按“训练”和“推理”两个阶段拆开，判断在哪个阶段份额会被替代、被谁替代，并跟踪关键竞争事件对份额与毛利率的影响。

**操作步骤 / 拆分口径 / 公式**

1. 份额矩阵：汇总各家数据中心AI芯片收入，计算份额。本例格局：英伟达7成以上；英伟达、谷歌+博通、AMD三方合计90%以上；谷歌Gemini+博通接近一成。
2. 分阶段分析：
   - 训练阶段：英伟达GPU优势明显；
   - 推理阶段：反复执行相同计算，更看重token吞吐、延迟和成本，性价比更高的定制ASIC、TPU、AMD可以替代。
3. 跟踪关键竞争事件：AMD与Meta 6GW协议加5年认股权证（首批1GW于2026H2交付）、AMD MI450X Helios机架，评估对份额和毛利率的下行风险。
4. 每次相关发布后更新：这类产品主要针对哪个阶段（训练还是推理）。

**关键指标与数据来源**：AI芯片市场份额、各家数据中心收入、合作协议GW规模、产品发布节奏。份额多为估算，需多来源校验。

**判断标准**

- 份额层面：集中度已很高（三方合计90%以上），格局变化主要来自“头部内部”的此消彼长，而不是新进入者。
- 推理逻辑：训练是一次性大规模计算，GPU通用性强；推理是反复执行相同计算，决定胜负的是token吞吐、延迟和成本，这正是各大厂自研芯片想替代的领域，所以推理占比上升对应份额与毛利率的下行风险。
- 竞争事件的评估方法：按“针对训练还是推理、规模多少GW、何时交付、是否带有绑定条款（认股权证）”四点衡量冲击，而不是只看发布会声量。

**海豚案例**

- 英伟达（2026-02-26）：英伟达份额7成以上，谷歌+博通近一成；AMD与Meta签6GW协议，首批1GW于2026H2交付。
- 英伟达（2026-05-21）：训练与推理分阶段——推理阶段“这也是各家大厂自研芯片想要替代的领域”。
- 英伟达（2026-08-27）：AMD MI450X Helios与各家定制ASIC都主要针对推理市场。

**适用场景与注意事项**：适用于技术迭代快、存在客户自研替代的硬件市场。份额为估算，需多来源校验；训练与推理的划分需随模型架构和负载变化动态更新。系统级方案（互连、组网）的竞争力对比见 8.3.3 至 8.3.5。

### 8.1.4 产能≠出货：用良率与客户认证校正份额

**方法要点**：判断厂商份额不能只看产能，而要用“产能×利用率”估算，其中利用率取决于良率和客户认证，因此认证进展这类离散事件才是份额的拐点。

**操作步骤 / 拆分口径 / 公式**

1. 公式：出货份额 ≈ 产能 × 利用率；利用率 ≈ f（良率、客户认证状态）。
2. 先列各厂的产能、良率、客户认证状态，再对照实际出货份额，找出“产能份额”与“出货份额”的偏离。
3. 把客户认证进展（尤其是对头部客户）当作需要重点盯的离散事件，设定时间点：认证通过后，产能利用率和出货份额才会回升。
4. 认证信息多来自产业链传闻，需交叉验证。

**关键指标与数据来源**：各厂HBM产能、良率、客户认证状态、出货份额。

**判断标准**

- 产能高但良率低、迟迟没通过认证，则实际出货份额会显著低于产能份额：三星HBM产能较高，但HBM3E良率偏低、迟迟未通过英伟达认证，出货份额降到3成以下；海力士占近一半份额，美光与三星接近。
- 认证是份额拐点：三星HBM3E在四季度通过英伟达认证后，产能利用率和出货份额有望回升，并可能反超美光。
- 推理链条：产能是上限，良率决定能产出多少合格品，客户认证决定合格品能不能卖给最大的买家；三者缺一，份额都不会兑现。

**海豚案例**

- 三星、海力士、美光《存储猛拉，AI存力超级周期到底有多神？》（2026-01-06）：三星HBM产能较高但良率偏低、迟迟未通过英伟达认证，实际出货份额降到3成以下；海力士近一半份额，美光与三星接近；三星HBM3E四季度通过英伟达认证后，产能利用率和出货份额有望回升，并可能反超美光。后续格局更新见 8.1.1（美光 2026-03-19：三星HBM3E通过认证后三家回到同一起跑线）。

**适用场景与注意事项**：适用于需要客户认证的高端半导体和零部件（HBM、先进封装、车规芯片）。认证信息多来自产业链传闻，需要交叉验证；产能追踪与扩产周期本身见 4.2。

### 8.1.5 寡头格局量化：订单份额与细分市占率双口径

**方法要点**：用两个口径同时描述寡头格局——整体订单份额和细分品类市占率，并在不同细分里分别给份额，避免用一个数字概括整个行业。

**操作步骤 / 拆分口径 / 公式**

1. 先给整体口径：三大主机厂合计的订单份额（CR3）。
2. 再给细分口径：在最核心的细分品类（重型燃机）里的市占率。
3. 先把格局定性（“三足鼎立、极其稳固的寡头垄断”），再用壁垒分析解释为什么能长期维持（见 8.5）。
4. 下篇对每个细分市场逐个给份额，并注明统计期。

**关键指标与数据来源**：订单份额、细分市占率（CR3/CR2）、统计期间（年度还是近五年累计）。

**判断标准**

- 整体订单份额与细分市占率相互印证：2024年GEV、西门子能源、三菱重工三大主机厂合计拿下全球约85%的订单份额，在重型燃机细分领域市占率高达约90%，这是“稳固寡头”的量化依据。
- 细分市场格局可能截然不同：航改机近五年GEV+BKR合计63%，西门子10%，俄罗斯联合发动机8%，三菱5%；轻型燃机2024年Solar（卡特彼勒）48%，西门子25%，曼恩10%。
- 数字使用前要先看口径：订单份额不等于收入份额；年度份额与五年累计份额不能放在一起比较。

**海豚案例**

- 《AI 终极瓶颈…》（2026-04-09）：三大主机厂2024年合计约85%订单份额、重型燃机细分市占率约90%，定性为“三足鼎立”的寡头垄断，再用壁垒解释稳固性。
- 《AI 电荒突围》（2026-04-14）：细分市场份额——航改机近五年GEV+BKR合计63%、西门子10%、俄罗斯联合发动机8%、三菱5%；轻型燃机2024年Solar（卡特彼勒）48%、西门子25%、曼恩10%。

**适用场景与注意事项**：适用于集中度高的装备行业。注意订单份额与收入份额的差异，以及统计期口径（单年与多年）；壁垒与终局推演见 8.5、8.6。

### 8.1.6 市占率口径调整：剔除软硬一体打包的厂商，只看独立第三方份额

**方法要点**：计算份额之前先识别“口径失真的玩家”——不在同一个市场里竞争的垂直一体化厂商，把它们剔出去后，在真正竞争的独立第三方市场里比较份额和与第二名的差距。

**操作步骤 / 拆分口径 / 公式**

1. 识别失真玩家：华为激光雷达以软硬一体打包出货，价格较高，主要服务于自家生态（智选车和HI模式），不和独立供应商在同一个市场里竞争。
2. 剔除后，在独立第三方Tier1市场（禾赛、速腾聚创、图达通）里比较份额，并计算与第二名的份额差距。
3. 加三类佐证：第三方定点排名、细分市场（Robotaxi）份额、独家供应关系。
4. 对口径调整写清依据，避免选择性剔除。

**关键指标与数据来源**：乘用车激光雷达市占率（第三方统计）、与龙二的份额差、高工智能（GGI）定点排名、Robotaxi份额。

**判断标准**

- 剔除一体化玩家后的“独立第三方份额”才是衡量公司与同类供应商竞争力的口径：禾赛四季度乘用车激光雷达市占率31.3%，比龙二速腾高近13个百分点。
- 多口径互相印证：全球Robotaxi份额60%-70%；GGI Robovan激光雷达定点排名第一，是新石器和DoorDash的独家供应商。
- 份额是动态的：速腾EMX从去年四季度加速出货，海豚君预计2026年禾赛短期份额受侵蚀，即使领先差距仍大，也要跟踪龙二的产品放量节奏。

**海豚案例**

- 禾赛（2026-03-24）：剔除华为后，四季度乘用车激光雷达市占率31.3%，比龙二速腾高近13个百分点；全球Robotaxi份额60%-70%；GGI Robovan激光雷达定点排名第一，是新石器和DoorDash的独家供应商。
- 禾赛（2026-05-19、2026-08-19）：速腾EMX从去年四季度加速出货，预计2026年禾赛短期份额受侵蚀。

**适用场景与注意事项**：适用于存在垂直一体化巨头的零部件市场（激光雷达、智驾芯片、座舱）。口径调整必须说明依据，避免选择性剔除；一体化玩家虽然不在同一市场竞争，但其生态内的出货会间接压缩独立供应商的可触及市场，这点要在市场空间判断中体现。

### 8.1.7 出货增速对比全球装机，市占率拆成海外/国内/全球三层

**方法要点**：先用公司出货增速对比行业总量增速，判断跑赢还是跑输行业，再把市占率拆成海外、国内、全球综合三层，识别份额变化来自哪个市场，以及是主动放弃还是被动丢失。

**操作步骤 / 拆分口径 / 公式**

1. 总量对比：公司全年出货增速 vs 行业（全球装机）增速；增速低于行业意味着全球份额下降。份额 = 公司出货 / 全球装机。
2. 三层拆分：分别计算海外市占率、国内市占率、全球综合市占率及其同比变化（ppt）。
3. 归因：份额变化来自海外还是国内？伴随的是毛利率更高的业务扩张，还是低毛利业务的收缩？
4. 结合国内业务毛利率与盈利情况，区分“战略收缩”与“竞争失利”。

**关键指标与数据来源**：公司出货量及增速、全球装机量（GWh）及增速、海外/国内/全球市占率及ppt变化、国内业务毛利率。

**判断标准**

- 海外份额升、国内份额大降 = 战略性收缩（主动放弃低毛利业务），而不是单纯的被动丢份额。
- 判断是否“主动”要看盈利：国内业务毛利仅约10%且净利为负，放弃的是不赚钱的份额。
- 方向正确，但核心前提是守住海外份额和单价/毛利；如果海外份额也开始下滑，“战略收缩”的叙事就不成立。

**海豚案例**

- 阳光电源《平地起惊雷》（2026-04-01）：储能2025年出货43GWh（+52%；国内7GWh、-26%，海外36GWh、+92%），低于全球装机约317GWh的74%增速；海外市占率+3.6ppt至26%，国内-5.8ppt至3.9%，全球-2ppt至13.6%；国内业务毛利仅约10%且净利为负，判断为战略性收缩。逆变器全年143GW（-3%），国内63GW（-17%），国内份额-7.3ppt至19.9%，海外+1ppt至40.8%，全球-4.2ppt至27.9%。

**适用场景与注意事项**：适用于有清晰行业总量数据的制造业（储能、光伏、汽车、手机等）。需要区分份额变化是主动的盈利导向还是被动的竞争失利；全球装机口径与出货口径存在时点差，需注明。

### 8.1.8 按月活看通用AI入口份额结构，并跟踪追赶者的增速与营销动作

**方法要点**：对新兴互联网入口，用月活算份额结构，与成熟互联网行业的典型结构对照，再跟踪追赶者的增长速度和营销动作，判断竞争是否已有定论。

**操作步骤 / 拆分口径 / 公式**

1. 按月活算份额结构：独立通用AI市场中，豆包约占60%，DeepSeek约30%，剩下10%里打头的是元宝（月活只有豆包的1/6，也排到全国第三）；整体呈现与成熟互联网行业类似的6:3:1结构。
2. 对照领先者与先发者：豆包已超越先发的文小言，并在过去两年不断扩大领先。
3. 追赶者增速：第三方数据滞后时（本例数据只到10月）需补充官方口径；千问11月才真正发力，据官方数据上线23天月活冲到3,000万，一个多月用户增长近10倍。
4. 梳理各家竞争动作：豆包拿下春晚赞助；千问处在大力推广期；元宝产品持续迭代并在年底掀起抢人大战。
5. 综合结论：竞争仍然焦灼，现在论输赢还早。

**关键指标与数据来源**：月活、份额、月活增速、营销动作（春晚、买量、抢人）。来源为QuestMobile等第三方和官方披露。

**判断标准**

- 结构判断：6:3:1与成熟行业结构类似，说明头部格局已初步形成，但追赶者的增速仍可能改写。
- 追赶者的判断不看绝对份额而看增速与资源投入：23天3,000万月活、一个多月近10倍的增长，说明追赶者的爆发力强，不能用第三方滞后数据下结论。
- 营销动作（春晚赞助、买量、抢人）是资金与战略意图的外部信号，与月活走势合看。

**海豚案例**

- 中国AI互联网《火拼 AI 互联网…》（2026-01-09）：按月活得出豆包约60%、DeepSeek约30%、元宝居第三（月活为豆包1/6）的6:3:1结构；豆包超越先发的文小言；千问11月才发力，上线23天月活3,000万、一个多月用户增长近10倍；综合各家营销动作判断竞争仍焦灼。

**适用场景与注意事项**：适用于跟踪互联网新入口的竞争格局。第三方数据有滞后，必须补充官方口径；入口与生态层面的竞争见 9.5，追赶者能否追平的判断见 8.7。

### 8.1.9 用子平台DAU/MAU粘性换算集团DAU，量化对比竞对

**方法要点**：当公司不披露某个关键指标（如DAU）时，借用可得的子平台粘性（DAU/MAU）乘以集团MAU做估算，把与竞对的用户规模差距量化，并逐季跟踪竞对是否超过自己的子产品。

**操作步骤 / 拆分口径 / 公式**

1. 估算公式：集团DAU ≈ 子平台DAU/MAU × 集团MAU。本例：QQ音乐DAU/MAU（28%）× 集团MAU 5.6亿 ≈ 1.6亿DAU。
2. 与竞对对比：汽水音乐近5000万DAU（MAU 1.4亿，抖音导流贡献80%+），得出TME约为汽水3倍。
3. 逐季跟踪追赶者DAU是否超过自家子平台单体（酷狗、QQ音乐）：Q1汽水DAU已超0.5亿并超过两者。
4. 把“是否超过”当作竞争拐点是否到来的判断标准。

**关键指标与数据来源**：MAU、DAU、DAU/MAU（粘性比）。

**判断标准**

- 整体规模仍占优（约3倍），但“超过单体产品”是拐点信号，因此竞争判断不能只看集团口径，还要看子产品口径。
- 导流来源占比（抖音导流贡献80%+）是评估追赶者用户质量与可持续性的补充变量。
- 结论取决于粘性比假设：QQ音乐的28%能否代表集团整体，需要合理性判断。

**海豚案例**

- 腾讯音乐《汽水猛攻》（2026-03-17）、《收编喜马拉雅》（2026-05-12）：TME不披露DAU，用QQ音乐DAU/MAU（28%）×集团MAU 5.6亿估算约1.6亿DAU，对比汽水近5000万DAU，判断TME约为汽水3倍；并逐季跟踪汽水DAU，Q1已超0.5亿并超过酷狗、QQ音乐单体。

**适用场景与注意事项**：适用于用户规模竞争分析。粘性比假设需合理，子平台粘性与集团整体可能不同；用户重合度与冲击对象的判断见 8.4.4。

### 8.1.10 Token用量与份额：AI竞争的高频指标

**方法要点**：把Token用量当作AI时代的“流量/GMV”，追踪全市场日均Token、单一厂商份额和单产品日均处理量，并在模型发布事件中用第三方路由平台（OpenRouter）的中美模型Token份额验证竞争胜负。

**操作步骤 / 拆分口径 / 公式**

1. 用量口径：全市场日均Token、单一厂商份额（%）、单产品日均Token处理量（trn/tn）。
2. 用份额判断生态主导者（谁的调用量最大，谁就是生态主导方）。
3. 模型发布事件中，用OpenRouter上中美模型Token份额作为胜负验证，并设定具体观察窗口（如新品发布后10-11月份额是否被反超）。

**关键指标与数据来源**：日均Token（trn/tn）、厂商份额（%）、OpenRouter中美模型Token份额。

**判断标准**

- 份额领先 = 生态主导：字节份额49%、豆包日均50tn，用份额直接论证“Token才是未来”的观点。
- 事件验证用具体窗口与阈值：6月起中国模型在OpenRouter领先；观察Haiku 5.5与GPT 6 Luna发布后10-11月是否被反超，若份额被反超，说明这轮领先尚未固化；若守住，则领先得到验证。
- OpenRouter样本偏开发者与长尾，不代表大客户直签和C端，不能把它外推为整体市场份额。

**海豚案例**

- 字节《(短评)Byte已老Token才是未来》（2026-01-13，文章 id 37768629）：追踪全市场日均Token，字节份额49%、豆包日均50tn，用Token份额判断生态主导者。
- 智谱/MiniMax《(短评)Anthropic发布Claude Haiku 5.5》（2026-10-08，文章 id 44232221）：用OpenRouter上中美模型Token份额作验证指标——6月起中国模型领先，观察Haiku 5.5与GPT 6 Luna发布后10-11月份额是否被反超。

**适用场景与注意事项**：适合大模型/AI应用竞争格局的高频追踪。OpenRouter样本偏开发者与长尾，需结合大客户直签、C端口径；模型能力层面的竞争见 8.3.15、8.3.16。

### 8.1.11 行业门店数据验证马太效应：能选择少开店本身是能力

**方法要点**：用第三方行业门店数据判断竞争格局（头部是否吃掉全部增量、中小品牌是否在收缩），并据此重新解读公司的开店放缓——在洗牌行业里，能主动少开店、保住加盟商赚钱能力本身就是能力。

**操作步骤 / 拆分口径 / 公式**

1. 取第三方行业门店数据（如茶咖观察），计算头部前10品牌对门店增长的贡献占比，以及中小品牌门店增减。
2. 统计样本品牌中门店数收缩或停滞的比例。
3. 把行业数据放回公司：行业里大部分品牌想开而开不了，则公司下调开店指引需要和行业背景一起读。
4. 反驳逻辑：“下调开店指引 = 成长故事结束”并不成立，要看公司是被动开不了还是主动选择少开。

**关键指标与数据来源**：头部品牌门店增长贡献占比、行业品牌门店增减比例（茶咖观察等）。

**判断标准**

- 马太效应成立的信号：头部前10品牌贡献90%以上门店增长，大部分中小品牌门店负增长。
- 行业洗牌的信号：上半年112家连锁茶饮品牌中62%门店数收缩或停滞。
- 解读：在这种行业里“能开店”本身已经稀缺，公司选择少开店以保住加盟商盈利，是能力而非衰退；市场把下调开店指引解读为成长结束而暴跌，海豚君认为不妥。

**海豚案例**

- 古茗《古茗：补贴退坡，茶饮界Costco依然稳健！》（2026-03-26）：据茶咖观察，H2头部前10品牌贡献90%以上门店增长，大部分中小品牌门店负增长，验证马太效应。
- 古茗《古茗：补贴退坡，咖啡接力…》（2026-08-27）：上半年112家连锁茶饮品牌中62%门店数收缩或停滞；市场把下调开店指引解读为成长结束而暴跌，海豚君认为不妥。

**适用场景与注意事项**：适用于连锁餐饮、茶饮、零售行业。第三方样本覆盖范围需说明；“少开店是能力”的前提是单店盈利与加盟商回报确实被保住，需用同店、加盟商盈利数据验证；竞争对手的价格与开店动态见 8.4.16。

**本节速查清单**

- [ ] 份额口径是否写清：出货量、收入、订单、月活还是Token？统计期是单年还是累计？数据来自哪个第三方？

## 8.2 梯队划分与竞争者定性

> 本节导读：本节解决“把一堆玩家分成几组、每个玩家是什么性格、为什么这么选”的问题，是从份额数字（8.1）进入多维竞争力对比（8.3）之前的“分组与定调”。写行业综述、对多厂商方案做对比、或判断某家公司在行业里的位置与战略意图时使用。本节先给分析框架（格局如何、竞争要素在哪一环），再给分梯队、分阵营、一句话定性、管理层口径追踪、新旧玩家比较五类工具；打分式的多维对比表见 8.3，竞争烈度见 8.4。

### 8.2.1 竞争格局“双问题”框架：格局如何，以及竞争要素对应哪些产业链环节

**方法要点**：开篇就把分析框架摆出来，只回答两个问题——行业竞争格局如何；不同参与者在技术路线和模式上有何差异，由此提炼主要竞争要素以及这些要素涉及哪些产业链环节，把竞争分析和产业链投资连起来。

**操作步骤 / 拆分口径 / 公式**

1. 梳理核心参与者清单（如可回收火箭的主要参与者）。
2. 第一问：行业竞争格局如何（份额、梯队、位次，见 8.1 与 8.2.2）。
3. 第二问：比较参与者的技术路线和模式，找出分化点，提炼主要竞争要素，并标出每个要素涉及的产业链环节。
4. 价值与瓶颈的定位：参与者在哪些技术点上分化，哪些环节就是价值和瓶颈所在（如发动机、箭体材料、GNC、3D打印）。
5. 在“机会如何看”中分三类落地：发射公司、星座运营公司、上游供应链。

**关键指标与数据来源**：参与者清单、技术路线差异点、对应产业链环节。

**判断标准**

- 一个技术点只有当不同参与者在这里选择不同路线（分化），它才是竞争要素；所有人做法一致的环节，不构成区分。
- 竞争要素所对应的产业链环节，就是价值和瓶颈所在，也是后续标的映射（第11章）的入口。
- 推理链条：参与者清单 → 技术路线分化点 → 竞争要素 → 产业链环节 → 三类落地标的。

**海豚案例**

- 商业航天《SpaceX 的挑战者们：贝索斯和中国军团们追得上吗？》（2026-04-08）：全文以此框架组织——梳理可回收火箭的主要参与者，回答“格局如何”和“竞争要素及涉及的产业链环节”两个问题（发动机、箭体材料、GNC、3D打印），最后在“机会如何看”中分发射公司、星座运营公司、上游供应链三类落地。

**适用场景与注意事项**：适用于技术快速迭代、参与者路线分化的新兴行业（商业航天、机器人、自动驾驶）。该框架与两强比较（8.3.13）、追赶者评估（8.7）、受益标的映射（11.1）配合使用。

### 8.2.2 按技术节点和规模划分行业梯队，并定位公司

**方法要点**：按技术节点和规模把行业分成梯队，确定公司在梯队中的位置，以及它冲击上一梯队的意愿，用来解释估值与战略差异，并持续跟踪全球排名。

**操作步骤 / 拆分口径 / 公式**

1. 按技术节点和营收规模划分梯队（代工：第一梯队台积电，第二梯队中芯、联电、格芯）。
2. 定位公司：它在梯队里排第几，是否还在冲击上一梯队。
3. 对比同梯队玩家的战略取舍：联电在14nm止步，中芯继续冲击等效7nm。
4. 用梯队位置解释估值和战略差异，并更新全球排名。
5. 在产业链位置上补充：公司在本国产业链里是否是不可替代的一环。

**关键指标与数据来源**：制程节点、营收规模、全球排名、梯队定位。

**判断标准**

- 同一梯队内，“是否还在冲击上一梯队”是区分玩家的核心变量：联电止步14nm，中芯是第二梯队里唯一还在冲击第一梯队的公司，因此估值与战略空间不同。
- 全球排名要放进梯队语境：中芯稳居第二梯队，是全球晶圆代工第三。
- 产业链位置带来的稀缺性：中芯是国产AI产业链晶圆制造的“独供”一环。

**海豚案例**

- 中芯（2026-02-10、2026-05-14、2026-08-13）：三次财报连续跟踪——中芯稳居第二梯队，是全球晶圆代工第三，也是第二梯队里唯一还在冲击第一梯队的公司；联电在14nm停下了脚步；中芯是国产AI产业链晶圆制造的“独供”一环。

**适用场景与注意事项**：适用于技术分层明显的制造业。梯队的划分标准（节点、规模）要先说明；位次的数据口径见 8.1.1，国产替代层面的判断见 8.8。

### 8.2.3 按性能设计和实际量产份额划分梯队，找出梯队内的关键差异变量

**方法要点**：不按纸面参数划梯队，而按“性能设计”与“实际量产出货份额”两个维度划分，因为纸面参数已不构成绝对壁垒，真正的差距在产能兑现；再在梯队内部找关键差异变量（如代工来源）。

**操作步骤 / 拆分口径 / 公式**

1. 先按性能设计（单卡性能、组网效率、模型适配）和实际量产出货份额分成三个梯队。
2. 判断壁垒落在哪：纸面参数已趋同，关键差距在产能兑现（先进制程配额、代工来源）。
3. 在梯队内找关键差异变量：代工来源（境外代工还是国产代工）、融资状态（是否已上市解决研发资金）。
4. 每个梯队内比较时，标明谁相对有优势、谁的短板是什么。

**关键指标与数据来源**：性能参数；出货份额；代工来源；上市融资状态。

**判断标准**

- 一梯队的特征不只是性能，还包括组网效率、已适配头部大模型、先进制程的优先配额。
- 二梯队内部的分化变量是代工：寒武纪、海光、平头哥已从境外代工切到国产代工，昆仑芯主力P800仍依赖三星。
- 三梯队内部以相对优势排序，并用融资状态判断研发资金风险：除燧原外都已上市解决研发资金。

**海豚案例**

- 百度（2026-09-07）：国产AI芯片分三梯队——一梯队华为昇腾，胜在单卡性能、组网效率、已适配头部大模型，还有先进制程的优先配额；二梯队寒武纪、海光、平头哥、昆仑芯，前三家已从境外代工切到国产代工，昆仑芯主力P800仍依赖三星；三梯队沐曦、摩尔、壁仞、天数智芯、燧原，沐曦相对有优势，除燧原外都已上市解决研发资金。

**适用场景与注意事项**：适用于格局分散、受产能约束的硬科技行业。梯队内差异变量要选“产能与供给”类的硬变量，而非停留在参数表；国产替代的整体评估见 8.8，追赶者能否追平见 8.7。

### 8.2.4 按技术路线把巨头划分阵营，并拆解各家的战略动机

**方法要点**：不只看“谁在做”，更看“为什么这么做”——按技术路线把巨头分成阵营，再逐个拆解战略动机（垂直整合、标准化生态、降本自研、折中妥协），据此预判后续的定价与开放策略。

**操作步骤 / 拆分口径 / 公式**

1. 列出各巨头的产品路线、投资与联盟动作，按路线分阵营。
2. 拆每个阵营的动机：
   - 垂直整合型：构建全栈壁垒，让产品嵌入自家算力生态；
   - 标准化生态型：提供标准化方案，推动量产和市场扩大、延伸能力边界、拿更高的价值占比，同时巩固自己作为供应商的竞争力；
   - 降本自研型：为降本用替代方案；
   - 折中型：在两条路线之间选中间态。
3. 衡量生态绑定程度与开放程度，如封闭、半开放、联盟。
4. 推出行业层面的结论：该技术是独立产品还是整体方案的一部分，产业化需要什么条件。

**关键指标与数据来源**：各巨头的产品路线、投资与联盟动作、生态绑定程度、开放程度。

**判断标准**

- CPO三大阵营：
  - ①英伟达和博通押注CPO。英伟达走垂直整合、构建全栈壁垒，CPO交换机深度嵌入其算力生态，本质是在谷歌等CSP全面自研的趋势下，延续自家芯片和系统的生命力；博通提供标准化的CPO芯片和设计方案，扮演生态构建者。
  - ②以谷歌为首的CSP为降本，用OCS替代部分光电交换，进度快于CPO、已经量产，但适用场景有限。
  - ③阿里、华为选NPO折中。
- 推论：CPO不是独立产品，而是数据中心整体方案的一部分，产业化既需要巨头引领，也需要完整生态。
- 互联协议层面：NVLink封闭生态加NVLink Fusion半开放，对比AMD牵头的UALink联盟“抱团取暖”，由开放程度推断各方的生态策略。

**海豚案例**

- 《“‘铜’ 牛夫人” 不走！CPO：真机会 or 镜中花？》（2026-06-24）：把CPO三大阵营（英伟达+博通押注CPO、谷歌等CSP用OCS降本、阿里华为选NPO折中）逐一拆解战略动机，得出“CPO不是独立产品，而是整体方案的一部分”的结论。
- 《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：NVLink封闭生态加NVLink Fusion半开放，对比AMD牵头的UALink联盟“抱团取暖”。

**适用场景与注意事项**：适用于平台型巨头主导的技术赛道。动机分析有助于预判巨头后续的定价与开放策略；动机是推断而非披露，要用产品路线和投资动作来佐证。协议生态的细致比较见 8.3.4，联盟实力评估见 8.3.5。

### 8.2.5 一句话定性各竞争者：行业基准 / 效仿但隔代 / 另起炉灶 / 先上市再补课

**方法要点**：在多厂商综述的开头，对每家有系统级方案的厂商各做一句话定位，让读者快速掌握格局，并为全文结论提供参照系。

**操作步骤 / 拆分口径 / 公式**

1. 选定定性维度：自研程度、代际对标、域规模、性能。
2. 对每家玩家给出一个标签加一句理由：
   - 行业基准：硬件、协议、软件全栈自研，软硬协同带来最佳性能，方案迭代快、跨度大，产业链逻辑也随之快速切换（英伟达）；
   - 效仿但隔代竞争：架构照搬、带宽对标下一代，但关键硬件外采，整体性能和成本仍落后（AMD：Helios照搬GB300 NVL72的组网架构，带宽却对标Vera Rubin，交换芯片等外采）；
   - 另起炉灶：自选技术路线，在特定规模下有性价比（谷歌：3D torus加OCS串起近万卡）；
   - 先上市再补课：能买不做、择廉而用，全网最不自研（AWS）。
3. 把定性与后文数据一一对应，让文末结论回扣开头的参照系。

**关键指标与数据来源**：自研程度、代际对标、域规模、性能。

**判断标准**

- 一句话定性必须有后文数据撑着，标签才不是空话。
- 标签的组合构成结论的参照系：文末结论“AWS既没有英伟达的性能，也没有谷歌的规模”直接用到了开头对英伟达（基准）和谷歌（规模）的定性。
- “隔代竞争”这类标签要具体到对标的代际（Helios对GB300架构、对Vera Rubin带宽）。

**海豚案例**

- AWS《AWS 图省事…》（2026-10-12）：开头对英伟达、AMD、谷歌、AWS四家各做一句话定位——英伟达是行业基准，AMD效仿英伟达但隔代竞争，谷歌另起炉灶，AWS先上市再补课、能买不做、择廉而用。
- 谷歌《叫板英伟达霸权…》（2026-09-21）：开头对AMD的定性（效仿英伟达但隔代竞争）。

**适用场景与注意事项**：适用于多厂商格局综述。定性要有前文数据撑着，否则容易变成标签化；各厂商的详细竞争力对比见 8.3.8。

### 8.2.6 追踪管理层战略目标口径的前后变化，推断战略定位并放入行业定位矩阵

**方法要点**：对比管理层在不同时间点对目标的表述，识别战略转向，再把公司放进行业战略定位矩阵，评估这个选择在当前竞争阶段是否合时宜。

**操作步骤 / 拆分口径 / 公式**

1. 收集管理层在不同时点（如3月、5月、最新分析师交流日）关于目标、产品定位的表述，逐条对比。
2. 识别口径变化：目标是升级、降级还是转向（如从“能力达到Opus级别、跻身全球一梯队”转为“追求成本效率而非SOTA”）。
3. 把公司放进行业战略定位矩阵，说明各家占据的位置。
4. 评估该选择是否符合当前竞争阶段（Scaling Law没失效时，智能水平仍是最关键的竞争力）。
5. 对同一话题的措辞升级也算口径变化（如把“侵蚀毛利率”升级为“缺货”）。

**关键指标与数据来源**：管理层各时点口径、产品目标、行业定位矩阵。

**判断标准**

- 目标口径从“冲SOTA”转向“成本效率”，意味着公司在资源和能力约束下主动降低追赶目标。
- 评估定位是否合时宜，要看行业所处阶段：Scaling Law没失效时，智能水平仍是最关键的竞争力，过早转向成本效率或多模态会影响模型智力研发。
- 管理层措辞的升级（问题→严重问题）是供给紧张或风险上升的信号。

**海豚案例**

- MiniMax（2026-08-26）：M3pro目标从3月/5月的Opus级别转为成本效率优先；定位矩阵为Anthropic做文本单模态SOTA、OpenAI做多模态SOTA、DeepSeek做文本极致性价比，MiniMax转向多模态相对领先的极致性价比；海豚君质疑过早选择多模态加自建算力，影响了模型智力研发。
- 高通（2026-04-30）：管理层上季提到的存储问题，从“侵蚀毛利率”升级为“缺货”。

**适用场景与注意事项**：适用于管理层沟通频繁、战略多变的公司。要记录每个表述的时间点和原文措辞，避免凭印象比较；定位矩阵里的各家定位要有公开证据；模型能力对标见 8.3.15。

### 8.2.7 新云与传统云巨头的长期确定性比较

**方法要点**：给AI基础设施赛道内的两类标的分层——新云（高增长、低确定性）和传统云巨头（能穿越叙事和技术演变），用于决定适合中短线博弈还是长期持有。

**操作步骤 / 拆分口径 / 公式**

1. 比较维度：
   - ①全栈技术和自研芯片带来的能效比优势；
   - ②客户群体规模与分散度；
   - ③作为模型分发渠道的产业链占位：无论大模型终局如何，只要不是被少数闭源垄断，都能分一杯羹；
   - ④差异化竞争优势。
2. 结合客户集中度、自研芯片、云业务体量等指标逐项打分或定性。
3. 得出结论：新云增长势头和空间更大，但长期确定性偏低，更适合中短线博弈；云巨头能穿越叙事和技术演变，值得长拿。

**关键指标与数据来源**：客户集中度、自研芯片、云业务体量。

**判断标准**

- 新云若缺少独特的差异化优势、在产业链中的必要性和占位不强，则长期确定性偏低。
- 云巨头的确定性来源于全栈技术、自研芯片带来的能效比优势、更大更分散的客户群和模型分发占位。
- 推理链条：增长空间大不等于确定性高；“长期确定性”看的是在叙事或技术变化后仍然不可或缺的程度。

**海豚案例**

- 甲骨文（2026-09-11）：Oracle缺乏独特的差异化优势，在产业链中的必要性和占位不强；云巨头凭全栈技术和自研芯片在能效比上有优势。结论为新云更适合中短线博弈、云巨头值得长拿。

**适用场景与注意事项**：适用于AI基础设施赛道内的标的分层。融资成本、多云部署、产能交付等更多维度的对比见 8.3.2，三要素评估见 8.3.1，资本竞赛见 9.6。

## 8.3 竞争力评估框架与多维对比

> 本节导读：本节解决“怎样系统地比较竞争力，才能既不被单一指标带偏，也不陷入标签化”的问题。海豚君的做法是：先选对比框架（三要素、软硬实力、技术-成本-商业模式、理念-模式-技术），再把每个维度落到可比的数据上（带宽、延迟、域规模、层数、Token、评分），对不可比项明确写成“路线取舍”，并追问厂商为何如此选择。适用于对多个厂商方案、模型、平台做同口径比较，或要判断一家公司能否与龙头同台。“是否追平”的判断见 8.7，入口与生态布局对比见 9.5，份额与梯队见 8.1、8.2。

### 8.3.1 AI时代核心竞争力三要素框架：大模型、云、芯片

**方法要点**：评估科技巨头或云厂商的AI竞争位次时，按“大模型、云、自研芯片（ASIC）”三项核心能力逐项判断，并把“与最强AI Lab的合作”视为同时增强三项的杠杆。

**操作步骤 / 拆分口径 / 公式**

变体 A：科技巨头AI竞争位次（以亚马逊为例）

1. 按大模型、云、芯片逐项判断公司的位置。
2. 评估与最强AI Lab的合作（算力合同、分销模型、芯片基石用户）：这类合作是“一石多鸟”——同时带来算力合同、增强自身AI能力、搭建ASIC生态。
3. 判断“量变到质变”：几个季度的向好迹象不断累积，并有业绩印证（增速提速、RPO跳升）。
4. 关注条款变化对分销权的影响（如独家销售条款取消）。

变体 B：AI云厂商综合竞争力排序与估值折价

1. 用三项核心能力评估云厂商：大模型、云、自研芯片（ASIC）。
2. 逐家排位：谷歌三项俱全；亚马逊有云和芯片；微软失去对OpenAI的独占后，模型和ASIC都缺乏优势，反而是竞争力最差，因此自研紧迫性高。
3. 把竞争力排序反映到相对估值（缺项则折价）。
4. 对新云额外比较能效比和客户分散度（见 8.3.2）。

**关键指标与数据来源**：合作合同金额；芯片GW承诺；RPO；云收入增速；自研模型排名、ASIC进展、云份额。

**判断标准**

- 三项全有（谷歌）> 两项领先加AI Lab合作（亚马逊）> 两项缺失（微软）。缺项本身带来自研紧迫性和相对估值折价。
- “量变到质变”的证据要同时具备：持续累积的合作和订单信号，加上财务指标（增速提速、RPO跳升）的确认。
- 独占条款的变化直接改变竞争位次：微软独家销售OAI API的条款取消后，AWS也能分销OpenAI的模型和工具。

**海豚案例**

- 亚马逊（2026-04-30）：判断亚马逊在云和芯片两项已行业领先，借OpenAI与Anthropic的合作提升了竞争位次；微软独家销售OAI API的条款取消后，AWS也能分销OpenAI的模型和工具。
- 微软（2026-05-01、2026-07-30）：模型和芯片未补足，竞争力最差，估值折价到22-23x PE。
- 甲骨文（2026-09-11）：云巨头凭全栈技术和自研芯片在能效比上有优势。

**适用场景与注意事项**：适用于大型科技公司和AI云、AI基础设施行业的横向比较。新云与云大厂的细致对比见 8.3.2，长期确定性比较见 8.2.7，估值方法见 11.4。

### 8.3.2 新云与云大厂的多维比较：芯片成本、多云部署、融资成本、产能交付

**方法要点**：对同一行业里两种商业模式的玩家，按成本结构、部署方式、融资成本和交付能力四个维度逐项比较，并判断某一事件（如融资平台）究竟改善了哪个维度、没有改善哪个维度。

**操作步骤 / 拆分口径 / 公式**

1. 云大厂的优势清单：自研ASIC带来的成本优势、跨国多云部署的优势、低融资成本。
2. 新云的状态：没有自研ASIC，几乎全用英伟达GPU和网络设备；表内杠杆已经很高；手握大量积压订单却做不出产能。
3. 拆解“做不出产能”的两层原因：一是厂房、供电、设备交付的物理周期；二是钱不到位、买不来设备。
4. 评估事件冲击：5000亿美元融资平台把杠杆挪到表外，减轻资产负债表和股权稀释压力，缩小了两大阵营的融资成本差距，新云可以把更多精力放在项目落地和执行上。
5. 分清“被改善的”与“没被改善的”：融资成本差距缩小；ASIC与GPU的成本差距、老云的多云部署优势仍然存在。

**关键指标与数据来源**：积压订单、可交付产能、杠杆率、融资成本、单位算力成本。

**判断标准**

- 事件对新云“是实打实的利好”，因为解决了资金与杠杆约束；但“改变不了其成本结构上的劣势”，因为成本结构取决于是否有自研ASIC与多云部署。
- 推理链条：积压订单多但交付不出 → 原因分为物理周期与资金两类 → 融资平台只解决资金这一类 → 物理周期与成本劣势不变。

**海豚案例**

- 《CoreWeave、Nebius》（2026-08-13）：评估5000亿美元融资平台对新老云竞争格局的影响——融资成本差距缩小、杠杆移到表外，但ASIC与GPU成本差距、多云部署优势依旧，结论为新云实打实的利好但改变不了成本结构劣势。

**适用场景与注意事项**：适用于同一行业内不同商业模式玩家的竞争力对比。事件影响要分拆到具体维度，避免“利好=格局改变”的笼统结论；融资结构与资本竞赛见 9.6。

### 8.3.3 系统级竞争力的两个维度：软实力（协议生态位）与硬实力（组网方案的部署规模与用户接受度）

**方法要点**：评估平台型硬件厂商能否与龙头同台较量时，不只比单芯片，而把“系统级方案”拆成软实力（协议生态位）和硬实力（组网方案的部署规模与客户接受度）两个维度。

**操作步骤 / 拆分口径 / 公式**

1. 先回顾历史：MI300时代AMD缺少系统级方案（核心是互连方案），几乎没吃到AI算力红利。
2. 软实力，即协议生态位：
   - Scale-up层：NVLink（封闭、性能一流、与CUDA和NCCL深度绑定，2025年推出NVLink Fusion转为半开放）对UALink联盟；
   - Scale-out层：InfiniBand对以太网，天平已明显偏向以太网，AMD是超以太网联盟UEC成员。
3. 硬实力，即硬件按协议组网后的部署规模和用户接受度：拿Helios对比GB300 NVL72和Vera Rubin。
4. 综合判断，并给出一句话结论。

**关键指标与数据来源**：协议性能、生态成员、方案部署规模、客户订单。

**判断标准**

- 系统级竞争力 = 软实力（谁的协议被生态接受）× 硬实力（方案实际部署多少、客户是否接受），两项都要有，缺一不可。
- 本例结论：带宽等核心指标基本追平，但“理论上了牌桌、实际万年备胎”——指标追平不等于竞争力追平，部署规模与客户订单才是验证。
- 以太网在Scale-out已占优，说明开放标准在某些层是确定的趋势，而Scale-up层仍是封闭与联盟的对垒。

**海豚案例**

- 《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：按“软实力之争”和“组网方案”两部分展开——软实力比较NVLink（含NVLink Fusion）与UALink、InfiniBand与以太网；硬实力以Helios对比GB300 NVL72和Vera Rubin；结论“理论上了牌桌、实际万年备胎”。

**适用场景与注意事项**：适用于评估平台型硬件厂商之间的竞争。协议层的分层比较见 8.3.4，开放联盟的实力评估见 8.3.5，是否追平的判断见 8.7。

### 8.3.4 协议生态竞争分析：分层比较带宽与延迟，用接受度和硬件份额衡量强弱

**方法要点**：把协议看作指导基础设施运转的规则（规定通信语义和可扩展的节点上限），按层级整理性能表，再用“同行与上下游的接受度”和“该协议下的硬件销量份额”判断协议强弱。

**操作步骤 / 拆分口径 / 公式**

1. 按Scale-up、Scale-out、DCI分层整理各协议的性能表，重点看带宽和延迟（及可扩展节点数）。
2. 判断各层格局：
   - Scale-up是产业演进的核心，厂商都想当话事人，NVLink、UALink、华为UB等多种专有协议并存；
   - Scale-out主要是英伟达主导的InfiniBand与开放的以太网之争。
3. 判断协议强弱：看标准被同行和上下游接受的程度，以及该协议下的硬件销量市占率。
4. 落到客户决策：CSP最终在业务需求、预算和自主可控之间取舍，这也是UALink、博通SUE等开放阵营能成形的原因。
5. 对龙头做总结：单看协议性能，英伟达能做到封闭和开放两套方案并行，仍是行业标杆。

**关键指标与数据来源**：协议带宽、延迟、可扩展节点数、联盟成员、该协议下硬件出货份额。

**判断标准**

- 协议性能只是门槛，协议“强不强”取决于生态接受度和硬件份额，而不是纸面指标。
- 客户（CSP）的取舍变量是业务需求、预算、自主可控，这决定了开放阵营有存在的土壤。
- 能同时运行封闭与开放两套方案的玩家，在协议层拥有更大的主动权（英伟达）。

**海豚案例**

- 《AI 时代 DC 互联》（2026-09-08）：按Scale-up、Scale-out、DCI分层整理各协议性能对比表，判断各层格局。
- 《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：NVLink与UALink、InfiniBand与以太网的具体对比。

**适用场景与注意事项**：适用于有标准之争的科技赛道（互联协议、通信标准、充电标准等）。协议比较要分层，不同层的玩家与竞争逻辑不同；与 8.3.3（软硬实力）、8.3.5（开放联盟）配合。

### 8.3.5 评估开放联盟的实力：看原生硬件是否落地，并用协议底层结构推断未披露的指标

**方法要点**：判断标准联盟的实力，看原生硬件的落地进度而不是联盟成员数量和声量；对未披露的指标，从协议栈结构做逻辑推断。

**操作步骤 / 拆分口径 / 公式**

1. 核查联盟标准的硬件落地进度：成员众多（AMD、Astera Labs、AWS、谷歌、Meta等）不等于有硬件；原生UALink交换芯片仍在Astera Labs与Marvell处研发和量产推进中。
2. 识别过渡方案：Helios的Scale-up实际走的是UALoE（架在以太网上的UALink）。
3. 对已披露指标做对比：UALoE带宽已与NVLink 6持平。
4. 对未披露指标（延迟）从协议栈推断：底层仍是以太网，数据要在两套标准之间反复封装、解封，还要叠加以太网本身的转发开销，所以延迟难以匹敌NVLink。
5. 得出结论：联盟声量大，缺硬件很尴尬。

**关键指标与数据来源**：原生芯片量产时间、带宽、延迟（推断）、联盟成员。

**判断标准**

- 联盟实力 = 原生硬件落地进度，而不是成员数量。
- 过渡方案出现，说明原生硬件尚未就绪。
- 未披露指标的推断逻辑：看底层协议是否多一层封装/解封与转发，结构上多一层就意味着延迟劣势。

**海豚案例**

- 《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：UALink联盟成员众多，但原生UALink交换芯片仍在Astera Labs与Marvell研发量产中，Helios实际走UALoE；带宽与NVLink 6持平，延迟未披露但推断难以匹敌，判断“联盟声量大，缺硬件很尴尬”。

**适用场景与注意事项**：适用于评估开放标准联盟对封闭龙头的挑战。延迟为推断而非实测，需要后续数据验证；与 8.3.9（第三方实测）配合。

### 8.3.6 把可维护性与组装效率纳入竞争力：飞线（易耗品）到模块化加PCB中板盲插

**方法要点**：除了带宽，把工程上的可维护性、组装效率也视为关键差异，并沿着“方案变化→对材料与工艺的新要求”推出产业链结论。

**操作步骤 / 拆分口径 / 公式**

1. 找出方案里的易耗、易故障环节：飞线是易耗品，容易坏、修起来麻烦；GB300中从NIC网卡到OSFP出柜接口的这段飞线最容易出故障。
2. 看下一代的解法：Vera Rubin的板卡模块化——CPU和GPU组成计算模块，CX-9网卡紧挨OSFP出口组成独立的网络通信模块Orchid；各模块与一块竖在中间的PCB中板通过板对板连接器盲插对接，全程走PCB。
3. 评估收益：易维护、便于组装、缩短组装时间。
4. 评估代价：PCB上长距离传输比飞线更容易衰减，所以英伟达除了配备高速SerDes，还同步升级了PCB的材料、层数和面积。
5. 推出产业链结论：PCB量价齐升。

**关键指标与数据来源**：飞线数量、组装时间、故障率、PCB层数与材料。

**判断标准**

- 可维护性影响客户的总拥有成本和部署速度，因此是竞争力的一部分，而不只是工程细节。
- 每一个方案收益都对应一个代价，代价所在的环节（PCB材料、层数、面积）就是增量环节。
- 推理链条：飞线易故障 → 改为模块化+中板盲插 → 全程走PCB → 传输衰减 → PCB材料/层数/面积升级 → PCB量价齐升。

**海豚案例**

- 《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：Vera Rubin如何取消飞线——计算模块与Orchid网络模块经PCB中板盲插，并推出PCB量价齐升的产业链结论。

**适用场景与注意事项**：适用于数据中心硬件方案比较。可维护性往往影响客户的TCO和部署速度；对应的制造能力评估见 8.3.7，价值量拆分见 2.3。

### 8.3.7 用技术规格能力对照下一代需求门槛，衡量制造端竞争力（PCB量产层数与储备层数）

**方法要点**：先确定下一代产品的规格门槛，再用厂商当前的量产规格和技术储备规格对照门槛，筛选能力达标的龙头。

**操作步骤 / 拆分口径 / 公式**

1. 确定下一代规格门槛：市场普遍预期下一代Rubin Ultra的背板会达到78层以上。
2. 把厂商的“量产层数”和“技术储备层数”作为两个能力指标列出。
3. 对照门槛筛选：当前已量产或技术储备已达标的厂商。
4. 给出结论并说明依据。

**关键指标与数据来源**：量产层数、储备层数、下一代规格要求（78层以上）。

**判断标准**

- 胜宏科技已具备70层以上量产能力、100层以上技术储备；深南电路量产68层、储备120层。
- 结论：关注具备高层板量产能力的龙头胜宏科技和深南电路。
- 注意区分“量产”与“储备”：两家当前量产层数仍低于78层门槛，储备层数高于门槛，所以判断的关键是储备向量产转化的进度。

**海豚案例**

- 《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：以78层以上为下一代门槛，对比胜宏科技（70层以上量产、100层以上储备）与深南电路（68层量产、120层储备）。

**适用场景与注意事项**：适用于规格驱动的制造环节（PCB、先进封装、光模块速率等）。“储备”不等于“可量产”，需要持续跟踪认证和良率；映射到标的的方法见 11.1。

### 8.3.8 竞争力对比表：可比项上色，不可比项归为“路线取舍”

**方法要点**：对技术路线差异大的方案，只给“可比维度”标注领先或落后，把“不可比维度”明确写成路线之间的取舍，用“代价-收益”句式下结论，避免用单一指标判强弱。

**操作步骤 / 拆分口径 / 公式**

1. 列出对比维度：单卡带宽、域规模、跳数、交换芯片数、组网成本。
2. 先厘清哪些指标在同一口径下可比，只给可比项加底色：绿色代表领先、红色代表落后。
3. 其余维度明确写成路线取舍，分成几组：
   - 第一组，牺牲单卡带宽换域规模：ICI的2,400GB/s落后NVLink 6和UALoE的3,600GB/s，但域规模是9,600颗对72颗；集群一旦超出单机柜（比如千卡），英伟达和AMD必须走Scale-Out，存在带宽落差（单卡Scale-Out带宽降到200GB/s）和协议转换开销，谷歌在这个规模下还在Scale-Up域内。
   - 第二组，牺牲跳数换掉交换芯片。
4. 用“代价-收益”句式下结论：单卡带宽落后约三分之一、多跳延迟不如单跳，是谷歌自选的代价；换来的是近万卡的域和每芯片约一半的组网成本。

**关键指标与数据来源**：单卡带宽、域规模、跳数、交换芯片数、组网成本。

**判断标准**

- 可比项才分高下；不可比项只说取舍，不简单判强弱。
- “代价”对应“收益”：落后的指标是自选的代价，换来的是规模和成本。
- 评估基准是“在目标场景下哪个代价更值”，而不是单项指标最优。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：对比表中只对可比项上色，ICI 2,400GB/s对NVLink 6与UALoE 3,600GB/s，域规模9,600颗对72颗，超出单机柜后英伟达与AMD的单卡Scale-Out带宽降至200GB/s；结论为谷歌用约三分之一的单卡带宽差距和多跳延迟，换来近万卡的域和每芯片约一半的组网成本。

**适用场景与注意事项**：适用于技术路线差异大的方案比较，避免拿单一指标下结论。前提是先厘清哪些指标在同一口径下可比；实测验证见 8.3.9。

### 8.3.9 引用第三方实测，区分原始性能与每芯片小时成本

**方法要点**：在理论测算之外，引用第三方实测来验证结论，并明确判断竞争力看“单位成本产出”而不是峰值性能。

**操作步骤 / 拆分口径 / 公式**

1. 找第三方实测数据（如InferenceX），区分两类曲线：原始性能曲线（吞吐/延迟）和每芯片小时成本。
2. 把实测结果与理论推断做对照，看是否互相印证。
3. 竞争力判断落在单位成本产出上，而非峰值性能。
4. 留意第三方测试的配置和软件版本。

**关键指标与数据来源**：原始性能曲线（吞吐/延迟）、每芯片小时成本。

**判断标准**

- Ironwood在原始性能曲线的大部分区间跑不赢GB系列，但在每芯片小时成本上胜出，印证了“性能落后、成本占优”的组网取舍。
- 判断竞争力看单位成本产出，而不是峰值性能。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：引用第三方InferenceX实测，Ironwood在原始性能曲线的大部分区间不及GB系列，但每芯片小时成本胜出，用以验证 8.3.8 中的路线取舍。

**适用场景与注意事项**：适用于评估加速器竞争力。要留意第三方测试的配置和软件版本；评分/榜单类指标的可刷性见 8.3.16。

### 8.3.10 从客户交付压力与成本动机解读厂商技术选择：“可交付优先于竞争力”

**方法要点**：当一家厂商的技术选择看起来不是最优时，不急于评价优劣，而是回到它的约束条件（成本动机、交付压力、锚定客户）去解释“为什么这么选”，并据此预判其路线的寿命。

**操作步骤 / 拆分口径 / 公式**

1. 先陈述疑问：为什么选一个“两头都堵”的方案（本例：PCIe）。
2. 回到厂商约束：
   - 一方面要摆脱英伟达溢价，必须自研；
   - 另一方面要尽快满足锚定客户Anthropic的算力交付。
3. 找出方案如何同时满足这两点：协议层跟着标准走，省掉了交换芯片的研发周期。
4. 得出结论：竞争力不是首要考虑，能交付才是。
5. 用这个动机去解释后续的路线行为（Trn2到Trn3的路线切换、Trn3生命周期内多次更换交换芯片），并给出中长期判断。

**关键指标与数据来源**：研发周期、交付时间、锚定客户需求。

**判断标准**

- 在交付时间紧迫、有锚定客户等刚性约束时，“可交付”优先于“有竞争力”。
- 动机推断的验证：它必须能解释厂商后续的多次路线变更，否则不成立。
- 结论：这类以交付为先的方案“中长期会被取代”。

**海豚案例**

- AWS《AWS 图省事…》（2026-10-12）、《AWS 组网靠「买」…》（2026-10-13）：用“摆脱英伟达溢价+尽快满足Anthropic交付”解释AWS为何选PCIe，并以此解释Trn2到Trn3的路线切换、Trn3生命周期内多次更换交换芯片等行为，推断出“中长期会被取代”。

**适用场景与注意事项**：适用于解释看起来不是最优的技术决策。需要结合客户结构和时间线；与一句话定性（8.2.5）和竞争力对比表（8.3.8）配合。

### 8.3.11 三维对比：技术、成本、商业模式（Robotaxi三大阵营）

**方法要点**：对多阵营竞争的新兴行业，先判断行业阶段，再从“技术—成本—商业模式”三个维度逐个列出各阵营的底牌，最后区分短期与长期的胜负手。

**操作步骤 / 拆分口径 / 公式**

1. 判断行业阶段：中小玩家退场，收敛为三大阵营（特斯拉、Waymo、英伟达+Uber联盟）。
2. 技术维度，看数据来源与路线：
   - 特斯拉海量真实数据，端到端上限最高；
   - Waymo走多传感器路线；
   - 英伟达联盟依赖合成数据（模型约相当FSD V12），长尾场景难破。
3. 成本维度，看车型成本与每英里定价：
   - Waymo车8万美元、定价>2美元/英里；
   - 特斯拉2.5-3万美元、动态定价1.3美元/英里；
   - 英伟达联盟有供应链溢价。
4. 商业模式维度：
   - Waymo重资产自营；
   - 特斯拉自建生态+轻资产扩张（开放车主车辆接入，边际成本近零）；
   - 英伟达联盟=技术授权+Uber流量+主机厂生产，协同难。
5. 区分短期胜负手（运营经验、车队规模）与长期胜负手（成本与规模化）。

**关键指标与数据来源**：车队规模（Waymo 2500辆）、城市份额（旧金山>25%）、车型成本、定价（美元/英里）、模型版本对标。

**判断标准**

- 技术上限由数据来源决定（真实数据 vs 合成数据）；成本由车型成本和定价共同决定；商业模式决定扩张的边际成本和协同效率。
- 短期看运营经验和车队规模（Waymo 2500辆、旧金山份额>25%）；长期看成本与规模化（特斯拉2.5-3万美元车型与轻资产扩张）。
- 联盟型阵营的弱点在“协同难”——技术授权、流量、生产分属不同主体。

**海豚案例**

- 特斯拉/Waymo/英伟达+Uber《(短评)美国Robotaxi三大阵营》（2026-01-16，文章 id 37873100）：按技术-成本-商业模式三维列出三大阵营，并区分短期与长期胜负手。

**适用场景与注意事项**：适用于技术路线分化、多阵营竞争的新兴行业（自动驾驶、AI芯片、大模型）；需持续用订单、里程、事故率等运营数据更新。更多汽车与智驾赛道要点见 16.6。

### 8.3.12 头部玩家打法的同维度对比：结论落在“都围绕自身原有优势”

**方法要点**：对竞争中的头部玩家，用同一组维度（产品形态、核心卖点、依托的资源）列表对比，得出各家打法都是围绕自身原有优势展开，并指出每家“仓促”上线的短板，判断各自风险。

**操作步骤 / 拆分口径 / 公式**

1. 选同一组维度：产品形态、核心卖点、依托的资源（生态资源）。
2. 逐家填表，得出“打法本质上是围绕自身原有优势展开”的结论。
3. 指出每家“仓促”上线的短板，据此判断各自风险。
4. 用不同时间点的对比表交叉验证（同一格局从不同公司视角看是否一致）。

**关键指标与数据来源**：产品形态；核心卖点；生态资源。

**判断标准**

- 同维度对比后，各家的打法与其原有资源高度吻合，说明竞争短期内沿着各自优势展开，而非互相复制。
- 短板往往在“资源无法覆盖的环节”：豆包手机没解决垂类App封API和手机厂商抵制的问题；千问只能顺畅完成特定品牌品类的外卖订单。

**海豚案例**

- 腾讯（2026-01-26）：豆包是体验最好的Chatbot，高度拟人化、主打情绪价值，依靠抖音流量和内容；千问是第一个真正的商业服务Agent，依靠领先的基础模型和丰富的商业生态；元宝做AI社交，依靠微信社交网络、群聊和公众号数据。短板：豆包手机没解决垂类App封API和手机厂商抵制的问题；千问只能顺畅完成特定品牌品类的外卖订单。
- 阿里（2026-01-16）：豆包强在聊天和泛娱乐，元宝强在高质量信息分发，千问是生活助手。

**适用场景与注意事项**：适用于寡头竞争的新赛道。与入口份额追踪（8.1.8）和入口生态竞争（9.5）配合；对比维度要在不同玩家间保持一致，才有可比性。

### 8.3.13 “理念→模式→技术路线”三层递进比较竞对

**方法要点**：比较两强时由抽象到具体分三层——理念、模式、技术路线，并让每个技术点的比较都回扣模式差异，形成一条解释链。

**操作步骤 / 拆分口径 / 公式**

1. 理念层：两家公司的使命与叙事（SpaceX要让人类成为多行星物种；Blue Origin要把重工业迁往太空、让地球更宜居）。叙事不同，但本质都基于地球的脆弱性和资源有限性。
2. 模式层：研发与组织方式（SpaceX是“快速试错、敏捷开发”；Blue Origin偏传统、长期主义、循序渐进）。
3. 技术路线层：由理念和模式推导出具体技术选择差异（发动机、箭体材料、GNC）：Blue Origin一步到位选“先进但稳妥”的方案，SpaceX激进降本。
4. 每个技术点的比较都回扣到模式差异（“这里同样体现两家公司的模式差异”），形成解释链。

**关键指标与数据来源**：愿景叙事、研发组织方式、技术选择。

**判断标准**

- 好的比较不是并列罗列，而是“理念→模式→技术”的因果链：技术差异能被模式差异解释，模式差异能被理念解释。
- 需警惕“理念决定一切”的过度解释，要用里程碑数据校验。

**海豚案例**

- 《SpaceX 的挑战者们》（2026-04-08）：SpaceX vs Blue Origin——理念、模式、技术路线（发动机、箭体材料、GNC）三层递进，并逐个技术点回扣模式差异。

**适用场景与注意事项**：适用于两强对比。要用里程碑数据校验叙事，避免叙事偏差；与双问题框架（8.2.1）配合，其中“技术路线分化点”就是这里的第三层。

### 8.3.14 创始人背景与组织文化分析：执行力与纠错能力

**方法要点**：对未上市或新兴公司，用创始人背景解释执行力与纠错能力，说明为什么这家公司能在众多竞争者中跑出来。

**操作步骤 / 拆分口径 / 公式**

1. 梳理创始人及联合创始人履历（金融背景、航天系统背景、工程经验等）。
2. 找执行力的量化体现：开发投入与速度（Rocket Lab只花约1亿美元就开发出Electron，并快速建成跨半球的发射、制造、研发基地）。
3. 找纠错案例：决策能否及时修正（Peter Beck早年断言不做回收，SpaceX成功后迅速转向）。
4. 把背景与组织风格联系：务实、技术介入度高。

**关键指标与数据来源**：创始人履历、开发投入（1亿美元）、决策纠错案例。

**判断标准**

- 蓝箭：创始人张昌武有金融背景（曾任职汇丰），联合创始人王建蒙有航天系统背景（曾任职卫星发射测控系统部），金融资源与航天体系经验互补。
- Rocket Lab：创始人Peter Beck没有大学学历，年轻时痴迷制造，做过游艇、家电制造，工程经验丰富；务实、技术介入度高、能及时纠错。
- 执行力的衡量不靠形容词，靠投入产出（约1亿美元开发Electron）与决策调整速度。

**海豚案例**

- 《SpaceX 的挑战者们》（2026-04-08）：蓝箭创始团队（张昌武、王建蒙）与Rocket Lab创始人Peter Beck的背景，用于解释执行力与纠错能力。

**适用场景与注意事项**：适用于创始人驱动的早期公司，需与客观里程碑结合，避免叙事偏差。

### 8.3.15 模型能力横向对标：总参/激活参数、智能指数排名、发布节奏、语料结构

**方法要点**：横向对比各家旗舰模型的参数规模、第三方智能指数排名、发布间隔与迭代速度、训练语料结构，以解释模型厂商的阶段性领先或掉队，以及对应的股价表现。

**操作步骤 / 拆分口径 / 公式**

1. 参数规模：对比总参数和激活参数。
2. 第三方智能指数排名（Artificial Analysis智能指数榜）。
3. 发布节奏：发布间隔和迭代速度。
4. 训练语料结构：纯文本占比。
5. 用这几项解释阶段性领先或掉队，并联系股价表现。

**关键指标与数据来源**：总参数/激活参数、智能指数排名、发布时间间隔、语料构成。纯文本语料占比来自海豚君调研。

**判断标准**

- 参数对比（总参/激活）：M3总参4280亿/激活230亿，对比GLM-5.2的7440亿/400亿、DeepSeek V4的1.6万亿/490亿、Kimi/Qwen均大于2T，M3处于较小规模；M3pro将升至2.7万亿/600亿。

- 参数迭代信号：GLM-5参数由355B/32B扩至744B/40B；GLM 6.0传为3T参数，说明头部厂商仍在大幅放大规模。

**海豚案例**

**适用场景与注意事项**：适用于大模型行业研究，也可迁移到芯片（性能参数对标）。传闻参数要标注为传闻；榜单类指标的局限见 8.3.16。

### 8.3.16 前沿模型竞争格局追踪：发布频次、第三方智能评分与中美差距以“月”计

**方法要点**：用多维第三方数据追踪大模型竞争，并把中美技术差距量化为“领先月数”，使“差距是在缩小还是扩大”可以被直接读出。

**操作步骤 / 拆分口径 / 公式**

1. 头部Lab前沿模型的发布频次：北美Anthropic与OpenAI为主力，xAI、Meta、Google紧随；中国生态百家争鸣。
2. 第三方评分对比：Artificial Analysis智能评分与Arena投票榜单（如GPT-5.6-Sol与Fable 5差距已很小；K3 AA评分仅次于Fable、Sol，Arena被投成榜一）。
3. 绘制各Lab最前沿模型的AA评分时间序列（虚线北美、实线中国），把中美差距量化为“领先月数”。
4. 读出趋势：二季度以来智谱、Kimi先后进入TOP5，与Anthropic差距从6-12个月缩短到3个月。

**关键指标与数据来源**：AA智能评分、Arena排名、模型发布频次、中美差距（月）；来源：Artificial Analysis、LMArena。

**判断标准**

- 差距“以月计”：把评分曲线上两条线的水平时间差当作领先月数，比绝对分数更直观。
- 趋势判断：中国模型进入TOP5、差距由6-12个月缩至3个月，说明追赶速度在加快。
- 榜单评分可被刷榜，需结合实际使用成本与商业数据；与 8.1.10（Token份额）等调用数据配合。

**海豚案例**

- 大模型行业《Kimi K3 时刻：中美 AI 产业链叙事要变天？》（2026-07-22）：K3的AA评分仅次于Fable、Sol，Arena被投成榜一；绘制各Lab最前沿模型AA评分时间序列，中美差距由6-12个月缩至3个月。

**适用场景与注意事项**：适用于AI模型层竞争格局的持续追踪。评分可被刷榜，需结合实际使用成本与商业数据；模型对标的更多维度见 8.3.15；中美差距作为追平判断的输入见 8.7。

### 8.3.17 视频生成模型竞争评估：技术壁垒、生态壁垒、定价策略、模型发布与人才流动

**方法要点**：评估AI视频模型业务的竞争力，从技术壁垒、生态壁垒、产品定位、竞争动态、核心人才五个方面看，并把结果用于动态调整增长预期和估值倍数。

**操作步骤 / 拆分口径 / 公式**

1. 技术壁垒：视频生成门槛低于文本LLM，技术突破有上限，绝对壁垒不高。
2. 生态壁垒：数据（大量低成本视频数据，多年降噪清洗积累）、通过电商和投流业务触达企业客户。
3. 产品定位：高定价专精路线（企业级、120秒长视频、多模态编辑）还是高性价比路线；ELO分数不能完全反映差异。
4. 竞争动态：
   - 竞品的价格动作（涨价、取消折扣说明竞争边际放缓）；
   - 新模型发布（定价更低、处于同一梯队）。
5. 核心研发人员流动。
6. 以上因素用来动态调整增长预期和估值倍数。

**关键指标与数据来源**：ELO评分、竞品梯队（T0/T1）、竞品定价变化、产品版本迭代、核心人员动态、B端和C端结构。

**判断标准**

- 技术壁垒低意味着真正的壁垒是生态和先发优势，而不是模型本身。
- 竞品涨价/取消折扣 = 竞争边际放缓，有利于自身变现；竞品新模型“更低价格+同梯队” = 竞争加剧。
- 核心骨干离职是增长预期下调的风险点。

**海豚案例**

- 快手《失望指引致暴跌，250亿美金的快手能“捞”吗？》（2026-03-26）：Seedance借助抖音和豆包在C端势头凶猛；视频模型壁垒低于文本LLM，真正壁垒是生态和先发优势；可灵3.0走高价专精路线。
- 快手《快手：老铁翻身，就靠“可灵”了》（2026-05-27）：竞争对手包括Seedance、阿里HappyHorse、Google Veo；Seedance从3月起多次涨价，竞争边际放缓，有利于可灵变现。
- 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：MiniMax H3于8月发布，达到T1水平且价格更低，Seedance保持T0；可灵核心骨干王鑫涛离职（传闻加入腾讯）；海豚君对下半年竞争不乐观。

**适用场景与注意事项**：适用于AI模型和应用赛道。技术迭代快，判断需要高频更新；传闻（如人员去向）要标注；ELO评分不能完全反映产品差异。

### 8.3.18 上下文优势多维排序：入口流量、客户质量、行业know-how、FDE交付、产品化模块

**方法要点**：以“上下文＝用户使用数据资产”为核心要素，用入口流量、客户质量、行业know-how、FDE交付、产品化模块等多个维度对几家平台做排序。

**操作步骤 / 拆分口径 / 公式**

1. 定义要素：上下文是用户使用数据资产，获取方式有两种——靠生态内高频入口导流积累轨迹；靠行业know-how储备或接入行业方案。
2. 分维度比较并排序：入口流量与客户规模、客户质量、行业know-how、FDE交付团队规模、产品化模块与连接器数量。
3. 逐家写清“优势—局限”：
   - 阿里（最优）：钉钉服务2600万+组织，传统行业、政府、教育渗透最深，审批流、组织架构、考勤规则天然是企业上下文；千问办公产品化为25项企业模块、20多个连接器，加MuleRun专家网络与Skill市场；局限是客户中小企业多、行业分散、know-how集中在通用流程。
   - 字节（居中）：飞书客户集中在互联网、新能源车、新消费、先进制造等“管理先进”企业，沉淀高价值可复制最佳实践；FDE团队60-70人投入最大；已形成智驾、AI模型公司、AI教育、AI制药、AI for Science等行业方案；局限是飞书月活仅钉钉约1/7、行业覆盖窄、跨生态打折。
   - 腾讯：企业微信偏对外沟通与客户管理，嵌入内部流程浅，业内评“企业专属模块最弱、生态最中立”。
4. 综合排序：阿里>字节>=腾讯。

**关键指标与数据来源**：组织数（钉钉2600万+）、MAU比（飞书约为钉钉1/7）、企业模块与连接器数量、FDE团队规模、行业方案数量；来源：调研。

**判断标准**

- 排序要看“嵌入企业内部流程的深度”，而不是名义用户量；企业微信“偏对外”所以嵌入浅。
- 要区分客户数量与客户质量：阿里客户多但分散，字节客户少但“管理先进”、可复制最佳实践价值高。
- 局限同样要写：阿里的中小企业占比高，字节月活仅钉钉约1/7。

**海豚案例**

- 阿里/字节/腾讯《腾讯、阿里、字节：谁能坐稳 AI 办公的「工头位」？》（2026-10-14）：以上下文为核心要素，从入口流量、客户质量、行业know-how、FDE交付、产品化模块多维度排序，结论阿里>字节>=腾讯。

**适用场景与注意事项**：适用于企业级AI平台竞争力比较；需区分客户数量与客户质量。入口与生态布局的对比见 9.5。

**本节速查清单**

## 8.4 竞争烈度、边际变化与竞争博弈

> 本节导读：本节解决“竞争现在有多激烈、是在加剧还是缓和、谁受冲击最大、各方会怎么博弈”的问题。海豚君的核心做法是不靠定性描述判断烈度，而是看可观测的动作——同业毛利率、对手佣金/服务费调整、营销费用增速、竞对资本开支转向、一次性资金、价格带与开店动态，再按用户重合度、收入结构等标准把冲击分到具体对象上。适用于平台、消费、出行、硬科技等有明显博弈的行业，每次财报季都要更新。份额口径见 8.1，竞争力对比见 8.3，壁垒与终局见 8.5、8.6，单位经济（UE）模型见 9.2，定价策略见 9.4，融资与资本竞赛见 9.6。

### 8.4.1 用同业毛利率趋势衡量竞争烈度，并识别公司主动退出的内卷环节

**方法要点**：判断一个细分环节值不值得做，先画出同业毛利率的变化，再看公司自己的进退选择——公司主动退出某环节，本身就是该环节盈利性差的证据，也说明管理层有能力边界意识。

**操作步骤 / 拆分口径 / 公式**

1. 列出主要参与者及国别（储能温控以中国企业为主：英维克、同飞股份、高澜股份、申菱环境）。
2. 画同业毛利率时间序列图：毛利率整体下降说明竞争激烈；需求改善时部分企业盈利回升（2025年随下游需求改善部分企业盈利回升）。
3. 观察公司在该环节的进退：公司曾尝试进入某环节、后因竞争过于内卷而退出，转而专注供应零部件。
4. 把“公司主动退出”作为竞争烈度的独立证据。

**关键指标与数据来源**：同业毛利率时间序列；参与者数量和国别；公司在该环节的进退。

**判断标准**

- 同业毛利率整体下降 = 竞争激烈，盈利性差。
- 需求端改善带来的毛利率回升要与结构性改善区分开：2025年随下游需求改善部分企业盈利回升，不等于竞争缓和。
- 公司主动退出：公司都选择退出的环节，盈利性必然较差；同时它也说明管理层识别自身能力边界、不做内卷生意的意识。

**海豚案例**

- 三花智控《三花：AI 机器人时代…》（2026-01-08，第一部分第二节第2点）：展示国内头部温控企业（英维克、同飞股份、高澜股份、申菱环境）盈利水平变化，行业毛利率整体下降，三花曾尝试储能温控系统集成但因竞争过于内卷而退出，转为专注供应零部件。

**适用场景与注意事项**：适用于判断任何细分赛道的竞争格局。要注意同业产品不限于该细分领域，毛利率口径可能混杂其他业务；毛利率与成本结构的测算见 9.3。

### 8.4.2 通过竞争对手的佣金/服务费调整和营销费用增速，判断竞争是否边际缓和

**方法要点**：竞争强度判断不靠定性描述，而是看可观测的动作——对手是否连续提高变现率、各家综合佣金率的横向位置、自身营销费用增速与GMV/收入增速的关系、调研的份额。

**操作步骤 / 拆分口径 / 公式**

1. 追踪对手是否连续提高变现率（每单服务费、分价格带佣金曲线）：从激进投入抢份额转向更看重利润，即竞争边际趋缓。
2. 横向比较各家综合佣金率：谁偏低、谁在抢份额。
3. 看自身营销费用增速是否低于GMV和收入增速（营销费用增速 < GMV增速 = 竞争没有明显加剧）。
4. 调研各家市场份额，交叉验证。
5. 提醒：格局演变还取决于其他重要对手，不能简单认为竞争一定减轻。

**关键指标与数据来源**：对手佣金率/服务费调整（bps、R$）、各平台综合佣金率、市场份额（调研）、营销费用增速vs GMV。

**判断标准**

- 对手连续提价（服务费或佣金率） = 对手更看重利润，竞争边际趋缓。
- 自身营销费用增速低于GMV和收入增速 = 竞争未明显加剧。
- 佣金率横向比较：综合佣金率偏低者（如Amazon）在抢份额；调整后与自己相当则说明对手不再靠价格差抢份额。
- 提醒：还要看其他重要对手的动作，否则结论容易偏乐观。

**海豚案例**

- MercadoLibre（2026-02-25）：Shopee巴西个人卖家每单服务费从R$5调至R$7（+40%），企业卖家R$80-300价格带佣金率上调，调整后综合佣金率与MELI相当，Amazon偏低；调研份额MELI约40%、Shopee约15%、另三家各约10%。
- Sea（2026-03-03）：Shopee 2025年在东南亚各市场提升变现率100-300bps，2026年至今又在印尼、越南、马来、新加坡宣布提升100-200bps；TikTok 2月11日在印尼提升200bps，与Shopee大体持平；电商营销费用增速约22%，低于GMV和收入增速，说明竞争未明显加剧。

**适用场景与注意事项**：适用于平台型行业（电商、外卖、出行、支付）竞争格局跟踪。对手动作要看“连续性”而非单次；佣金率口径（综合 vs 分价格带）要对齐；补贴类博弈见 8.4.12。

### 8.4.3 先判断“对谁明确是坏消息”，再看份额和营销强度

**方法要点**：竞争结局还不确定时，先确定这件事对谁明确不利，再用份额和营销投入强度判断竞争压力的大小，避免在不确定中直接预测胜负。

**操作步骤 / 拆分口径 / 公式**

1. 先问：这件事（新进入者、新产品、新技术）对谁一定是坏消息，哪怕结局未知。
2. 再看份额：竞争是否已经改变份额。
3. 再看营销投入强度：对手的投入力度，判断压力大小。
4. 区分压力的类型：有的是份额冲击，有的是引流成本上升，有的是长期替代风险。

**关键指标与数据来源**：份额；营销投入强度。

**判断标准**

- 对谁明确是坏消息，不依赖于最终谁赢：阿里做闪购最终能否增厚阿里利润还无法判断，但对美团无论如何是坏消息。
- 压力分层：京东、飞猪发力，不至于显著影响携程的份额，但增加了引流压力。
- 替代风险的表述：自动驾驶的替代风险是“高悬的利剑”（Uber）。
- 冲击的对象要具体到业务线：Unity中Genie的冲击主要针对Create引擎业务；AppLovin担心Meta重返iOS in-app广告。

**海豚案例**

- 阿里（2026-01-08）：做闪购最终能否增厚阿里利润还无法判断，但对美团无论如何是坏消息。
- 携程（2026-02-26）：京东、飞猪发力，不至于显著影响携程的份额，但增加了引流压力。
- Uber（2026-02-04）：自动驾驶的替代风险是“高悬的利剑”。
- AppLovin（2026-02-12）：担心Meta重返iOS in-app广告。
- Unity（2026-02-11）：Genie的冲击主要针对Create引擎业务。

**适用场景与注意事项**：适用于竞争激烈、结局不确定的行业。该方法给的是方向而非定量；定量要接 8.4.2（边际变化）、8.4.4（冲击排序）、8.4.5（收入结构分层）。

### 8.4.4 新品/新玩家对同业的冲击排序：按变现模式重合度与用户重合度判断谁首当其冲

**方法要点**：评估新品或新玩家的冲击对象时，不笼统说“竞争加剧”，而按用户场景、变现模式、用户重合度排序，找到首当其冲的对象，并顺带评估并购的协同空间。

**操作步骤 / 拆分口径 / 公式**

变体 A：按变现模式重合度排序（新产品对同行的外溢）

1. 看新品的用户场景与变现模式，和谁重合最多。
2. 排序冲击对象：Meta Muse若借社交优势分发裂变，首当其冲的是OpenAI的ToC业务（同为免费用户场景，OpenAI也指望广告和佣金变现）；其次是谷歌主动搜索的转化价值。
3. 再比较广告商业基建的成熟度：Meta广告基建完善，比OpenAI更容易吸引广告主做预算测试性迁移（海豚君此前对OpenAI广告商业化持怀疑态度）。

变体 B：按用户重合度判断冲击对象与并购协同

1. 用第三方用户重合度（QM）：汽水与QQ音乐重合度13%，汽水崛起期QQ音乐稳定，冲击主要落在同为性价比风格的酷狗。
2. 并购协同：喜马拉雅与TME核心用户重合度10-15%，合并后若以捆绑包销售（现有会员加1-2元溢价），付费转化不难。
3. 事后核对：冲击是否按预判落在重合度最高的对象上。

**关键指标与数据来源**：用户重叠/重合度（QM等第三方）、变现模式（广告/佣金/订阅）、广告基建成熟度。

**判断标准**

- 重合度越高冲击越大：重合度低（13%）的QQ音乐相对稳定，冲击落在风格相近的酷狗。
- 变现模式重合：同为免费用户场景、同靠广告和佣金变现的业务，最先受冲击。
- 重合度低的两个平台合并更容易做增量（核心用户重合度10-15%，捆绑包销售），因为用户是互补的。
- 事后核对：酷狗下滑最大，喜马拉雅初步合并未能延缓侵蚀，说明对并购协同要保守看待。

**海豚案例**

- Meta/OpenAI/谷歌《(短评)Meta Muse发布》（2026-09-10，文章 id 43844051）：按用户场景和变现模式的重合度排序，首当其冲是OpenAI的ToC业务，其次是谷歌主动搜索的转化价值；Meta广告基建更成熟，更容易吸引广告主做预算测试性迁移。
- 腾讯音乐《汽水猛攻》（2026-03-17）、《收编喜马拉雅》（2026-05-12）、《慷慨回购》（2026-08-11）：用QM用户重合度判断冲击与协同——汽水与QQ音乐重合度13%，汽水崛起期QQ音乐稳定，冲击主要落在同为性价比风格的酷狗；喜马拉雅与TME核心用户重合度10-15%，合并后若以捆绑包销售（现有会员加1-2元溢价）付费转化不难；事后核对：酷狗下滑最大，喜马拉雅初步合并未能延缓侵蚀。

**适用场景与注意事项**：变体 A 适合平台竞争的外溢分析；变体 B 适用于竞争冲击与并购协同分析。重合度是估算，不同来源口径可能不同；用户规模对比见 8.1.9。

### 8.4.5 按龙头收入结构分层评估竞争冲击：商业订单 vs 政府/军方订单

**方法要点**：评估新进入者对龙头的威胁时，不笼统说“抢份额”，而按龙头的客户结构分层，计算竞对能触及哪一层、这一层在龙头收入中有多重要。

**操作步骤 / 拆分口径 / 公式**

1. 拆龙头的收入结构：商业订单、政府订单、军方订单。
2. 判断竞对能触及哪些客户层：按地缘与安全监管，不同国家的追赶者能进入的市场不同。
3. 公式：冲击程度 = 竞对可触及的客户分层 × 该分层在龙头收入中的重要性。
4. 分别评估不同来源的追赶者：中国追赶者与美国本土追赶者。

**关键指标与数据来源**：龙头收入结构（商业/政府/军方）、竞对可触及市场。

**判断标准**

- 中国可回收火箭成熟后，最先抢的是SpaceX的商业订单，而商业订单对SpaceX相对不重要。
- 政府和军方订单才是SpaceX的核心，这块的竞争者是Blue Origin和Rocket Lab等美国本土公司。
- 因此：中国追赶者冲击大、但冲击在“不重要”的层；美国追赶者冲击在“核心”层，影响更实质。

**海豚案例**

- 《SpaceX 的挑战者们》（2026-04-08）：按SpaceX的客户结构分层，对比中国追赶者与美国本土追赶者对其影响的差异——前者主要冲击商业订单，后者才触及政府和军方这一核心。

**适用场景与注意事项**：适用于受地缘/安全监管分割的市场。前提是有龙头的收入结构数据；追赶者能否追平见 8.7，地缘与出口管制见 10.3。

### 8.4.6 从资金来源和盈利压力推导竞争的全面性

**方法要点**：判断一个竞对是否会与龙头在所有业务线上全面竞争，从“谁出钱、何时要回报”出发，推导竞争会延伸到哪些业务线。

**操作步骤 / 拆分口径 / 公式**

1. 看竞对的资金来源与规模：耐心资本（如创始人每年出售约10亿美元股票）还是需要尽快盈利的资本。
2. 看业务的盈利特征：终极目标是否是不可能短期盈利的大工程。
3. 推导：即使有耐心资本，也仍需探索可持续盈利的商业模式，于是会承接政府和军方项目、商业项目，并做自己的同类业务（如自己的“Starlink”）。
4. 得出竞争的全面性：推出两者必然在全业务线直接竞争。

**关键指标与数据来源**：资本来源与规模（约10亿美元/年）、盈利路径。

**判断标准**

- 两者的终极目标都是不可能短期盈利的大工程；Blue Origin虽有贝索斯每年出售约10亿美元Amazon股票提供的耐心资本，仍需探索可持续盈利的商业模式。
- 因此承接政府和军方项目、商业项目，以及做自己的“Starlink”（Project Kuiper），都是顺理成章的事。
- 推理链条：谁出钱、何时要回报 → 盈利模式需要什么业务 → 业务线与龙头重合的范围 → 竞争的全面性。

**海豚案例**

- 《SpaceX 的挑战者们》（2026-04-08）：Blue Origin的资金（贝索斯每年约10亿美元）与业务布局（政府与军方项目、商业项目、Project Kuiper），推出两者必然全业务线直接竞争。

**适用场景与注意事项**：适用于非上市或长周期投入型竞对的行为预判。资金来源与融资能力对竞争的约束见 9.6。

### 8.4.7 竞对资本开支转向（AI虹吸）对本行业竞争烈度的传导

**方法要点**：当多业务巨头大幅上调AI Capex时，它会回笼非AI业务投入、转向减亏或提升变现，从而降低本行业的竞争烈度；要区分这个信号的强弱。

**操作步骤 / 拆分口径 / 公式**

1. 跟踪竞对AI Capex：阿里、抖音动辄单季大几百亿。
2. 判断传导：竞对回笼非AI业务投入、转向减亏或提升变现，降低美团外卖与到店的竞争烈度，给美团修复主业窗口。
3. 区分信号强弱：
   - 强信号：阿里闪购单季亏百亿以上，有强紧迫性减亏；
   - 弱信号：抖音到店亏损不大，减投紧迫性弱，仅“据传提升部分品类变现率”。
4. 与竞对业务亏损规模、变现率变化配合验证。

**关键指标与数据来源**：竞对Capex、竞对业务亏损、变现率。

**判断标准**

- 竞对的AI Capex越高，对非AI业务的资源挤占越明显，竞争烈度边际下降的可能性越大。
- 信号强弱取决于竞对该业务的亏损规模：亏损越大（阿里闪购单季百亿以上），减亏紧迫性越强；亏损不大（抖音到店），减投信号弱。
- “据传”类信息只算弱信号，需要公告或实际动作验证。

**海豚案例**

- 美团《AI分走战火》（2026-06-01）、《阿里、抖音熄火？治不住美团的焦虑症》（2026-08-28）：阿里、抖音大幅上调AI Capex，回笼非AI业务投入，降低美团外卖与到店的竞争烈度，给美团修复主业窗口；并区分信号强弱——阿里闪购单季亏百亿以上，减亏紧迫性强；抖音到店亏损不大，仅“据传提升部分品类变现率”，属弱信号。

**适用场景与注意事项**：适用于多业务巨头之间的跨业务资源竞争。AI投入趋缓后竞对可能重新加补，要跟踪反转风险（见 8.4.12）；单位经济模型见 9.2。

### 8.4.8 巨头以主品牌入局或复制打法的信号解读：竞争性质是否变化

**方法要点**：判断新进入者是否改变了竞争性质——以往竞争对手各有短板，而具备全国渠道能力和大众心智的巨头以主品牌入局，会削弱原有玩家靠高性价比加快速铺货建立的先发优势。

**操作步骤 / 拆分口径 / 公式**

变体 A：具备渠道与心智的巨头以主品牌入局

1. 识别新进入者的品牌层级（主品牌 vs 子品牌）、渠道能力、大众心智。
2. 评估原有玩家的先发优势是否被削弱（靠性价比和快速铺货建立的优势最易被侵蚀）。
3. 推出增速判断：原有玩家增速高位回落是大概率事件。

变体 B：会员店自有品牌低价对标爆品

1. 看自有品牌的定价与口味对标对象。
2. 看客群重叠度：重叠度高则份额被蚕食的概率高。

变体 C：海外竞品把已验证的打法复制到新市场

1. 识别打法（社媒营销加快时尚）。
2. 用开店首日数据判断需求强度（首分钟销售额、SKU数）。

**关键指标与数据来源**：新进入者品牌层级、定价、客群重叠度、开业首日数据。

**判断标准**

- 巨头以主品牌入局 > 小玩家入局：全国渠道和大众心智让原有先发优势被削弱，增速回落概率大。
- 价格对标且客群重叠，份额蚕食概率高。
- 打法复制的强度看首日数据：开店首日、首分钟销售额是需求强度的早期信号。

**海豚案例**

- 东鹏饮料（2026-04-30）：农夫山泉以主品牌推出电解质水（低糖、日常补水），补水啦先发优势被削弱，增速高位回落是大概率事件（Q1仅+13.2%）。
- Monster（2026-05-08）：Costco的Kirkland能量饮料24罐16.99美元，口味对标Celsius，客群高度重叠。
- Lululemon（2026-09-04）：Alo把北美打法搬到中国，8月12日天猫旗舰店开业，300多个SKU，首分钟销售额破千万元。

**适用场景与注意事项**：适用于消费品行业竞争格局研究。主品牌入局的影响需要用后续销量增速验证；与价格带竞争（8.4.15）配合；定价策略见 9.4。

### 8.4.9 跨行业新进入者的进入路径判断：自建、MVNO、收购与渠道博弈

**方法要点**：判断新进入者（如卫星直连）切入传统行业（移动通信）的可行性，从进入路径、技术短板、Capex规模与替代方案、在位者态度四个方面综合评估短期扩张难度。

**操作步骤 / 拆分口径 / 公式**

1. 路径选择：自建、MVNO合作、收购。
2. 技术短板：本例中城区频谱不能复用，需要地面基站补盲。
3. Capex规模与替代方案：长期可达数千亿美元；替代方案如femto cell附加在屋顶天线上。
4. 在位者态度：三大运营商拒绝批发转售。
5. 综合判断短期的扩张难度，并给出需要跟踪的变量。

**关键指标与数据来源**：频谱资源、地面基站Capex、在位者合作态度、单星容量。

**判断标准**

- 在位者不愿批发转售（MVNO路径受阻） + 地面基站落地不明 + Capex规模巨大 = 短期大规模扩张难度高。
- 要看的变量：地面基站落地方案、在位者态度变化，以及技术迭代节点（如V3部署，关联单星容量）。

**海豚案例**

- SpaceX《豪赌AI》（2026-08-05）：SpaceX有意成为美国第四大移动运营商，但AT&T、Verizon、T-Mobile明确不愿批发转售，地面基站落地不明，判断DTC大规模扩张难度高，短期重点关注V3部署。

**适用场景与注意事项**：适用于跨界颠覆者分析，属于行业或个股深度框架。路径判断以公开信息为主，需要跟踪在位者态度的后续变化。

### 8.4.10 新市场进入的竞争对标：份额、独家协议、城市与商户覆盖、用户与骑手、投入额

**方法要点**：评估平台进入海外新市场或新品类的胜算时，建立对标表，把现有龙头、准入壁垒、新进入者的存量生态、核心差距和投入计划放在同一张表里，并参考成熟的“双飞轮”打法。

**操作步骤 / 拆分口径 / 公式**

1. 现有龙头份额与第二名份额。
2. 准入壁垒：独家协议规则及当地监管限制。
3. 新进入者的存量生态：网约车用户、司机和骑手数量。
4. 核心差距：城市覆盖、商户数。
5. 投入计划：投资额、城市扩张目标。
6. 参考同类成功模式（Uber“网约车+外卖”双飞轮）。
7. 结论：对手体量是否相近，并非以卵击石。

**关键指标与数据来源**：市场份额、独家协议规则（30家门店以上不得独家，独家GMV不超过25%）、覆盖城市数、商户数、用户数、骑手数、投资额。

**判断标准**

- 龙头份额很高但监管限制其独家协议：2023年巴西监管限制iFood的独家协议，降低了龙头的排他壁垒。
- 新进入者的存量生态（150万以上司机、70万摩的骑手、5000万以上用户，骑手数70万对iFood的48万）是切入的底气；差距在城市（不到20个对1500个以上）和商户（4.5万对46万），这是追赶要补的短板。
- 结论落在“体量相近的对手，并非以卵击石”。

**海豚案例**

- 滴滴《外卖大战卷到巴西，滴滴也惨了！》（2026-03-13）：iFood份额近70%，Rappi个位数；滴滴巴西有150万以上司机、70万摩的骑手、5000万以上用户，骑手数70万对iFood的48万；差距在城市（不到20个对1500个以上）和商户（4.5万对46万）；2023年巴西监管限制iFood的独家协议；滴滴计划到2026年年中覆盖100个城市，99 Food投资80亿雷亚尔（约100亿元人民币）；美团Keeta可能收缩（传闻）。

**适用场景与注意事项**：适用于平台出海或进入新品类的竞争评估。海外数据多来自新闻报道，需要标注可信度（如“传闻”）；单位经济与盈利路径见 9.2。

### 8.4.11 行业抱团整合对龙头的竞争影响判断

**方法要点**：行业逆风下的并购抱团虽然提升集中度，但三、四名合并会形成实力大增的第三名，反而可能加剧对龙头的对抗；再结合外部替代竞争判断龙头涨价能力与估值中枢。

**操作步骤 / 拆分口径 / 公式**

1. 识别行业内的并购与资产整合事件，计算合并后的份额与位次。
2. 判断合并后的格局：三、四名抱团 → “实力大增的第三名”，而不是削弱竞争。
3. 叠加外部竞争（短视频、短剧、AI漫剧）：外部替代加剧时，龙头涨价能力受限。
4. 推到估值：竞争加剧直接削弱涨价能力，导致估值中枢下移。
5. 区分情绪放大与真实威胁（远期产业威胁论被情绪放大）。

**关键指标与数据来源**：市场份额、并购事件、涨价幅度与用户反应。

**判断标准**

- 整合提升集中度不等于龙头竞争环境改善：“三、四名的抱团，最终会变成一个实力大增的第三名”，龙头需持续超预期才能走出行业beta。
- 涨价逻辑是龙头估值的关键变量：竞争加剧 → 涨价能力下降 → 估值中枢下移。
- 远期产业威胁论（短视频、AI漫剧）会被情绪放大，需区分短期基本面与远期叙事。

**海豚案例**

- 迪士尼（2026-08-05）：“三、四名的抱团，最终会变成一个实力大增的第三名”，迪士尼需持续超预期才能走出行业beta。
- 奈飞（2026-04-17）：同行资产整合与短视频短剧竞争直接影响涨价逻辑和长期估值中枢。
- 奈飞（2026-07-17）：情绪放大远期产业威胁论（短视频、AI漫剧）。

**适用场景与注意事项**：适用于集中度变化中的行业。涨价能力要用涨价幅度与用户反应验证；估值方法见 11.4。

### 8.4.12 补贴战博弈分析：共识与争议、参与方动机、监管介入概率、市占率

**方法要点**：对寡头补贴战，把问题拆成“共识（没有分歧的）”和“争议（真正需要判断的）”，再逐个梳理参与方动机、监管介入概率，最后落到市占率这个关键跟踪指标上。

**操作步骤 / 拆分口径 / 公式**

1. 区分共识与争议：
   - 共识：各方减亏无疑问；
   - 争议：减亏方式、速度、稳态UE（单位经济）均衡点。
2. 各方态度与动机：
   - 阿里：曾目标市占第一，给出29财年即时零售盈亏平衡目标，重规模；
   - 美团：应战方，结束主动权在阿里。
3. 监管介入概率：
   - 收敛恶性补贴（1分钱、强迫商户补贴）概率高；
   - 叫停平台自愿补贴概率低，最多加速退补。
4. 阿里持续投入的动机：攻守兼备防近场电商被侵蚀；沉没成本与已有份额；远近场、到家到店、AI Agent履约协同。
5. 关键跟踪指标是市占率：美团份额持续提升才意味稳态UE与投资逻辑拐点，否则UE随对手补贴动态波动。

**关键指标与数据来源**：市占率、UE、竞对亏损、监管表态。

**判断标准**

- 把时间花在“争议”上，不在“共识”上反复论证。
- 监管影响的分层：打击恶性补贴对补贴力度有约束，但不会从根本上叫停竞争。
- 稳态UE与投资逻辑的拐点，取决于份额是否持续改善，而不是单季亏损收窄。
- 竞对的投入动机（防守、沉没成本、协同）越强，退出概率越低；因此阿里不太可能完全放弃外卖，AI投入趋缓后不排除再加补。

**海豚案例**

- 美团《三山压顶》（2026-03-26）、《AI分走战火》（2026-06-01）：用共识/争议、各方动机、监管概率、市占率框架梳理补贴战——各方减亏无疑问，争议在减亏方式、速度和稳态UE均衡点；监管收敛恶性补贴概率高、叫停自愿补贴概率低；阿里持续投入的动机（攻守兼备、沉没成本、协同）；以市占率作为关键跟踪指标；并结合竞对AI Capex上调对补贴战烈度的影响（见 8.4.7）。
- 美团《阿里、抖音熄火？治不住美团的焦虑症》（2026-08-28）：阿里不太可能完全放弃外卖，AI投入趋缓后不排除再加补。

**适用场景与注意事项**：适用于寡头补贴竞争行业（外卖、出行、社区团购、即时零售）。监管概率为判断而非确定，需要跟踪监管表态；均衡的稳定性判断见 8.4.13，单位经济模型见 9.2。

### 8.4.13 补贴战均衡判断：份额稳定是“携手减亏”的前提

**方法要点**：对双寡头补贴战，判断均衡是否稳定——只要各方份额保持大体稳定，各家UE会同步改善、亏损携手下降；一旦任何一方试图显著夺取份额，补贴和亏损就会再度抬头。

**操作步骤 / 拆分口径 / 公式**

1. 命题：份额稳定 → 各家降补贴、订单结构优化、效率提升 → UE同步改善 → 亏损携手下降。
2. 前提检查：没有任何一方试图显著夺取份额，否则补贴和亏损会再度抬头。
3. 用管理层的态度表述（目标做到市场规模第一）和调研数据（单量份额小幅下滑）判断均衡的稳定性。
4. 评估减亏的代价：休战期的单量/份额损失是否值得。

**关键指标与数据来源**：单量份额（调研）、单均亏损、管理层目标表述、补贴力度。

**判断标准**

- 均衡成立的条件：份额大体稳定且无人试图显著夺份额。
- 警示信号：管理层仍把“做到市场规模第一”作为目标，说明份额竞争没有结束；调研显示单量份额小幅下滑，说明均衡已有代价。
- 代价是否值得：即时零售进入休战期，代价是单量份额略有下滑，但在现金流吃紧时利大于弊。

**海豚案例**

- 阿里《阿里：电商再沦陷》（2026-03-19）：管理层称即时零售的目标是做到市场规模第一，外卖大战的竞争和补贴退坡不会在短时间内结束。
- 阿里《阿里：电商退位，AI上位》（2026-05-14）：阿里和美团会在相当时间内保持单量和份额上的竞争，携手减亏的前提是份额稳定。
- 阿里《阿里狂投》（2026-08-21）：即时零售进入休战期，代价是单量份额略有下滑，但在现金流吃紧时利大于弊。

**适用场景与注意事项**：适合寡头补贴竞争行业（外卖、网约车、社区团购）。均衡是动态的，需要逐季用单量份额和管理层措辞更新；与 8.4.12 配合。

### 8.4.14 价格战：一次性资金发动加调研竞争对手是否跟进

**方法要点**：分析龙头发动价格战的资金来源与对手反应——如果降价用的是账外一次性资金，等于不动用当期盈利发动价格战，对手没有对应资金，可能不会跟进，从而形成扩大价格差的窗口。

**操作步骤 / 拆分口径 / 公式**

1. 列出行业份额格局。
2. 识别降价资金来源：账外一次性资金（关税退税）而非当期盈利。
3. 评估对手反应：对手无对应资金来源，调研反馈不会跟进。
4. 评估窗口期获取份额的性价比。
5. 设定验证信号：客流改善、食杂份额走高。

**关键指标与数据来源**：行业份额、降价SKU数与幅度、竞争对手反应（调研）。

**判断标准**

- 资金来源决定可持续性与对手的跟进意愿：一次性资金不侵蚀当期盈利；对手若不跟进，价格差窗口就会扩大。
- 窗口价值要用验证信号检验：客流改善、食杂份额走高；没有出现则降价的性价比下降。

**海豚案例**

- 沃尔玛（2026-08-21）：美国食杂份额沃尔玛24%、Kroger 10%、Costco 9%、Albertsons 6%、Publix 5%；7月6日起用关税退税这笔账外一次性资金对250多个单品降价最高25%，传统食杂商表示不跟进，形成扩大价格差的窗口。

**适用场景与注意事项**：适用于零售、平台等价格竞争行业。对手“不跟进”来自调研，需要用实际价格追踪验证；定价策略见 9.4。

### 8.4.15 主流价格带竞争分析：在基本盘价格带里识别“贴身肉搏”的对手和政策约束

**方法要点**：按价格带切分市场，识别公司基本盘价格带里的主要对手，以及政策对各价格带的不同影响，并判断龙头在监管下能不能再用降价抢份额，用于设定销量情景和判断公司策略。

**操作步骤 / 拆分口径 / 公式**

1. 按价格带切分市场，确定公司基本盘价格带（如10-20万）。
2. 识别基本盘里的主要对手：吉利银河靠高配置加性价比、零跑、长安、长城。
3. 看政策对各价格带的不同影响（国补倾斜16.7万以上）。
4. 判断龙头在反内卷监管下能不能再用降价抢份额。
5. 把结论用于设定国内销量情景，并判断公司是“保利润”还是“抢份额”。

**关键指标与数据来源**：各价格带份额、竞品系列销量增速、龙头定价策略、政策价格门槛。

**判断标准**

- 基本盘内对手增速（吉利银河系列销量接近翻倍）与自身份额变化（插混份额勉强维持在36%左右）一起看，判断“贴身肉搏”的强度。
- 结合新品定价判断公司策略：比亚迪推出秦PLUS 128km长续航版，结合发布会定价，判断在20万以下主力车型上转向“保利润、稳基盘”，没有再打价格战。
- 对手份额继续抬升是压力的延续：吉利新能源份额1Q26继续环比+2.8pct到13.4%。

**海豚案例**

- 比亚迪《王座失守…》（2026-03-28）：吉利银河系列销量接近翻倍，比亚迪推出秦PLUS 128km长续航版，勉强把插混份额维持在36%左右；结合发布会定价，判断比亚迪在20万以下主力车型上转向“保利润、稳基盘”，没有再打价格战。
- 比亚迪《宇宙车厂…》（2026-04-28）：吉利新能源份额1Q26继续环比+2.8pct到13.4%。

**适用场景与注意事项**：适用于价格带分层明显的消费品行业。需要分价格带的销量数据；政策门槛（如国补）会改变各价格带的相对竞争力；反内卷监管对降价手段的约束见 10.1。

### 8.4.16 多方竞争者动态追踪：价格策略、开店策略、跨界入局与价格锚点风险

**方法要点**：每季更新竞争者矩阵，把价格策略、开店策略、跨界入局、股权/战略变化和中小品牌出清放在一起看，并评估公司的防御动作与“价格锚点”长期风险。

**操作步骤 / 拆分口径 / 公式**

1. 每季更新竞争者矩阵：
   - 库迪的价格策略（退出全场9.9不限量，常规产品回到11.9-16.9元）、叫停省会以上城市加盟；
   - 幸运咖开店农村包围城市；
   - 星巴克中国合资（博裕60%/星巴克40%），转向本土化、下沉扩张；
   - 茶饮跨界咖啡（古茗咖啡占交易额约15%、低价促销，茶百道试点，沪上阿姨战略化）；
   - 中小品牌出清。
2. 判断影响：短期分流有限；中长期持续低价引流会强化消费者的价格锚点，压缩结构性提价空间。
3. 评估公司防御动作：瓶装即饮6-7元堵住低价下探空间；蓝瓶咖啡切入25-30元高端价格带；形成三层价格带布局。

**关键指标与数据来源**：竞品价格带、竞品开店/关店、跨界品牌咖啡占比、合资股权结构、公司新业务定价。

**判断标准**

- 短期看分流：竞品开店与价格动作对公司销量的分流有限。
- 中长期看价格锚点：低价引流持续存在会在消费者心中固化低价参照，压缩公司结构性提价空间，这是海豚君最担心的风险。
- 竞争者的战略变化（库迪退出9.9不限量、星巴克合资转向本土化）是对手阶段性策略的信号，需逐季更新。
- 公司的防御是否有效，看价格带覆盖是否完整：低价带（瓶装即饮6-7元，经销商毛利约10%）、中价带、高价带（蓝瓶25-30元）。

**海豚案例**

- 瑞幸《瑞幸咖啡：增收不增利…》（2026-04-29）：星巴克中国合资交割，中期或对瑞幸高线产品与品牌升级构成压力；蓝瓶咖啡（大钲收购）与瓶装即饮（6-7元）形成全价格带布局。
- 瑞幸《瑞幸咖啡：走出外卖后遗症…》（2026-08-03）：库迪2月退出9.9不限量；古茗咖啡占交易约15%，最低8.9元、美式4.9元；海豚君最担心价格锚点被强化；瓶装即饮由统实代工，经销商毛利约10%。

**适用场景与注意事项**：适用于竞争激烈的消费赛道。矩阵要每季更新；价格锚点是长期变量，不会在单季财报里体现；定价策略与性价比见 9.4，行业门店格局见 8.1.11。

### 8.4.17 到店竞争量化：GTV增速差、规模比、商家端与新App指标

**方法要点**：对两条业务线的竞争，用GTV增速差、规模比、商家端指标和新App的用户指标做量化对比，并区分对盈利的冲击与对份额、市场地位的冲击。

**操作步骤 / 拆分口径 / 公式**

1. 对比双方到店GTV增速：抖音GTV增速（Q4约60%，Q1约20-40%，核销前口径）vs 美团（指引<15%，外资预期高个位数）。
2. 规模比：抖音/美团到店酒旅GTV比例从25年约70%出头提升到26年近100%。
3. 商家端指标：QM商家月活，抖音已超美团。
4. 新App指标：独立App抖省省上线约2个月DAU近千万，进攻美团图文搜索/货架式优势腹地。
5. 结论：到店战对盈利冲击小于外卖战，但对份额和市场地位压力可能更大。

**关键指标与数据来源**：双方到店GTV增速、GTV比例、商家月活、独立App DAU。

**判断标准**

- 增速差：对手增速（20-40%）显著高于美团指引（<15%）= 对手在抢份额。
- 规模比趋近100% = 规模差距基本消失。
- 商家端月活反超：商家侧流量被分走，美团的供给侧优势被削弱。
- 新App攻击对手优势腹地（图文搜索/货架式）：竞争不是对称的，要看进攻的路径。
- 区分冲击类型：对盈利冲击小，但对份额与市场地位的压力可能更大。

**海豚案例**

- 美团《三山压顶》（2026-03-26）、《AI分走战火》（2026-06-01）：对比抖音与美团到店——抖音到店GTV增速Q4约60%、Q1约20-40%（核销前口径），美团指引<15%、外资预期高个位数；抖音/美团到店酒旅GTV比例从25年约70%出头提升到26年近100%；QM商家月活抖音已超美团；独立App抖省省上线约2个月DAU近千万，进攻美团图文搜索/货架式优势腹地；结论到店战对盈利冲击小于外卖战，但对份额和市场地位压力可能更大。

**适用场景与注意事项**：适用于本地生活竞争分析；注意GTV口径（核销前/后）。与补贴战（8.4.12）分开评估：盈利冲击与份额冲击是两件事。

## 8.5 竞争壁垒、关键成功要素与客户锁定

> 本节导读：本节回答“护城河到底由什么构成、有多厚、能不能被击穿、客户为什么走不掉”。做法是先把壁垒拆开来看（要素清单、四维、核心部件三层、技术同源性、服务与渠道、封闭供应链），再看软硬件与数据层面的锁定（配置期确定性、Agent 分层、数据飞轮、大客户反向替代），最后看稀缺资源带来的先到先得与窗口期，并把下游环节的竞争归因到上游瓶颈。份额口径见 8.1，梯队与竞争者定性见 8.2，多维竞争力对比见 8.3，竞争烈度见 8.4；壁垒结论用于判断追赶者能否追上时转入 8.7，用于国产替代可行性时转入 8.8；整机加长期服务协议的商业模式锁定见 9.1，AI 与流量入口的终局见 9.5。

### 8.5.1 列出壁垒要素清单，比较相邻赛道的竞争格局（储能 vs 光伏）

**方法要点**：不凭印象说“格局好/不好”，而是把一个环节里“除价格之外让客户愿意选你、让新人进不来”的要素逐条列出，再与相邻赛道的清单对照，判断护城河的厚度，以及它会不会被高毛利吸引来的新进入者击穿。

**操作步骤 / 拆分口径**

1. 列出目标环节的非价格壁垒清单。储能集成的清单为：安全要求、收益保证、地方合规、电量衰减、全周期服务、技术创新能力。
2. 用同样口径列出相邻赛道（光伏）的壁垒，逐项对照有无、强弱。
3. 判断格局差异：壁垒项更多、更难复制的一方格局更好。
4. 检查“可击穿性”：看行业毛利率是否高到足以吸引新进入者，新玩家涌入后毛利是否已经开始下行。
5. 对海外市场叠加检验：“技术领先 + 品牌溢价”的双重护城河是否面临被击穿的风险。

**关键指标与数据来源**：壁垒要素清单、行业毛利率（储能此前约 40%）、新进入者数量与动向。

**判断标准**

- 清单越长、每一项越难靠资本在短期内补齐，护城河越厚。
- 结论分两层：相对判断是储能格局好于光伏；绝对判断是“好格局不等于稳格局”，高毛利本身就是吸引新进入者的信号。
- 推理链条：壁垒清单 → 相对格局判断 → 毛利率水平 → 新进入者涌入 → 竞争加剧、毛利下行；海外护城河由“技术领先 + 品牌溢价”支撑，一旦被击穿则溢价同步消失。

**海豚案例**

- 阳光电源《收入倒春寒》（2026-04-28）：认为储能格局比光伏好，但此前约 40% 的高毛利吸引大量新玩家，竞争加剧推动毛利下行；海外“技术领先 + 品牌溢价”双重护城河面临被击穿的风险（相关判断见《平地起惊雷》（2026-04-01））。

**适用场景与注意事项**：适用于比较同一产业链不同环节、或相邻赛道的竞争格局。清单要用同一口径列给两边，否则对照无意义；壁垒清单只给出“厚度”，“可击穿性”必须再叠加毛利率与新进入者数据。

### 8.5.2 壁垒四维拆解：技术 / 资本与规模 / 供应链与认证 / 生态与服务

**方法要点**：解释寡头格局为什么稳固时，不停留在“技术好”，而是把“装备制造业皇冠上的明珠”拆成四个维度，每一维都给出可验证的事实或数字，再据此评估追赶者（含国产替代）的可行性与格局稳定性。

**操作步骤 / 拆分口径**

1. 技术维：列出工况参数（温度、压力、转速、寿命）、核心工艺与材料、整机研发周期与投入、控制算法所依赖的运行数据积累。
2. 资本与规模维：估算全链条产能所需的固定资产规模，判断新玩家在份额不足时是否会陷入“不规模 - 不盈利 - 难扩张”的负循环。
3. 供应链与认证维：找关键材料与关键部件的集中度，以及客户对新供应商的认证周期。
4. 生态与服务维：看长期服务协议（LTSA）带来的转换成本，该维度的商业模式锁定详见 9.1。
5. 四维各给出事实或数字后，再合成对“追赶者要补多少课”的结论。

**以燃气轮机为例的四维内容**

| 维度 | 事实与数字 |
|---|---|
| 技术 | 1400℃ 以上（高于镍基合金熔点）、高压高转速下数万小时可靠运行；叶片承受自重上万倍的离心力，依赖单晶高温合金、精密铸造、气冷通道、热障涂层；整机研发周期 10-15 年、耗资数十亿美元；燃烧室控制算法建立在几十年运行数据之上 |
| 资本与规模 | 全链条产能需百亿级人民币固定资产；新玩家份额不足会陷入“不规模 - 不盈利 - 难扩张”的负循环 |
| 供应链与认证 | 关键材料（铼、铪）和叶片集中，叶片约 70% 产能在 PCC / Howmet；电力公司对新供应商需数万小时实地考核 |
| 生态与服务 | LTSA 带来的客户锁定（详见 9.1） |

**关键指标与数据来源**：研发周期与投入、工况参数、供应链集中度、认证周期、转换成本。

**判断标准**

- 每一维都要有“可验证的事实或数字”，没有数字的壁垒只能算定性印象。
- 四维叠加而非择一：单维被攻破（如某家做出了样机）不等于壁垒被击穿，因为资本、认证、服务三维仍需逐一跨过。
- 推理链条：四维壁垒共同决定新进入者的时间成本与资金成本，因此寡头格局稳定；评估追赶者时按维度打分，找出最短板。

**海豚案例**

- 燃气轮机行业《AI 终极瓶颈…》（2026-04-09）：把燃机的壁垒拆成技术、资本与规模、供应链与认证、生态与服务四维，每一维给出温度、研发周期、产能占比、认证时长等事实。
- 燃气轮机行业《AI 电荒突围》（2026-04-14）：对涡轮叶片再做材料、工艺、认证三层壁垒的细化（见 8.5.3）。

**适用场景与注意事项**：适用于评估追赶者（含国产替代）可行性、判断格局稳定性，尤其是高端装备、重资产、长认证周期行业。各维度的数字需引用原始出处并区分口径。

### 8.5.3 核心部件三层壁垒：材料极限、制造工艺（良率）、试错认证周期

**方法要点**：对格局里最关键的单个核心部件（如燃机热端涡轮叶片），把壁垒细化为“知不知道、做不做得出、让不让用”三层，用来评估新进入者的追赶难度。

**操作步骤 / 拆分口径**

1. 材料层（知不知道）：需要什么材料体系、依赖哪些稀有元素、掌握核心技术且有有效产能的企业有几家。
2. 工艺层（做不做得出）：列出工序数、公差精度、一致性要求、良率难点，以及哪些环节依赖高级技工而难以快速复制。
3. 认证层（让不让用）：从材料研发到通过主机厂挂网测试需要多长时间，周期以年计还是以月计。
4. 三层逐层问“新进入者能否跨过”，并把最慢的一层作为追赶时间的下限。

**以涡轮叶片为例的三层内容**

| 层级 | 对应问题 | 内容 |
|---|---|---|
| 材料 | 知不知道 | 需用单晶高温合金，精准添加铼、铪等稀有元素提升耐温和抗蠕变；掌握单晶高温部件核心技术且有有效产能的企业屈指可数 |
| 工艺 | 做不做得出 | 真空熔炼、单晶定向凝固、空心冷却气道精密成型、气膜孔激光加工、热障涂层喷涂等十余道高难度工序；尺寸公差和一致性要求达微米级，良率控制是巨大挑战；蜡模制造和组装阶段仍高度依赖高级技工，难以快速复制 |
| 认证 | 让不让用 | 从材料研发到通过主机厂数万小时挂网测试，周期以年计 |

**关键指标与数据来源**：工序数、公差精度、良率、认证时长、稀有元素依赖。原文配合工艺流程图展示。

**判断标准**

- 三层是串联关系：任一层不过，整个部件就不可用，因此追赶时间由最慢一层决定。
- 材料层靠资源与配方积累，工艺层靠良率与技工经验，认证层靠时间，三者都无法单靠资金迅速堆出来。
- 推理链条：稀有元素 + 微米级工艺 + 数万小时认证 → 具备单晶高温部件有效产能的企业屈指可数 → 新进入者追赶难度极大。

**海豚案例**

- 燃气轮机行业《AI 电荒突围》（2026-04-14）：对热端涡轮叶片做材料、工艺、认证三层壁垒拆解，并配工艺流程图。

**适用场景与注意事项**：适用于高端材料和精密制造部件，也适用于国产替代可行性评估（与 8.8 配合）。三层框架适合“部件级”分析，整机级壁垒请与 8.5.2 四维配合使用。

### 8.5.4 细分市场份额 + 技术同源性：解释近乎垄断

**方法要点**：当某个细分产品线上两家公司合计份额极高时，不止报份额，还要追问“为什么是它们”，用技术同源性（母技术领先者在衍生品里占优）、专利壁垒、产品线覆盖和下游场景来解释近乎垄断。

**操作步骤 / 拆分口径**

1. 取近五年累计份额，列出细分产品线的全部玩家及其份额。
2. 追溯产品的技术来源，判断是否属于“跨界衍生品”，以及头部玩家是否掌握母技术。
3. 把技术同源性转化为专利壁垒的论据。
4. 补产品线覆盖（功率或规格区间是否覆盖、是否兼具不同产品线的优势）。
5. 补下游应用场景，说明需求面为什么偏向这些玩家。

**关键指标与数据来源**：近五年累计份额、产品功率覆盖范围、技术来源。

**判断标准**

- 份额高度集中且头部玩家都有母技术背景，可判定为“技术同源型垄断”。
- 推理链条：航改型燃机由航空发动机衍生 → GE 的 LM 系列、贝克休斯的 LM/LMS 系列（技术源自原 GE 航空）有深厚航发底蕴 → 技术同源与专利壁垒 → 再叠加产品线覆盖与下游场景，双寡头格局稳固。

**海豚案例**

- 燃气轮机行业《AI 电荒突围》（2026-04-14）：航改型燃机（单机 30-60MW）近五年 GEV 与贝克休斯合计份额 63%，其余为西门子能源 10%、俄罗斯联合发动机 8%、三菱 5%；解释关键是技术同源性（航发底蕴 + 专利壁垒）；再补贝克休斯产品线 12.5-132MW，兼具航改机效率与 Frame 系列工业燃机的成熟性，以及油气田发电、区域供能、调峰等下游场景。

**适用场景与注意事项**：适用于判断“跨界衍生”产品的竞争格局，母技术领先者往往在衍生品中占优。注意区分累计份额与单年份额，口径要写明。

### 8.5.5 “一超多强”格局的粘性来源：可靠性、全球服务网络、渠道协同

**方法要点**：对成熟工业设备的龙头，护城河不一定在技术，而在可靠性、服务网络和母公司渠道带来的客户粘性；用份额加三点来源说明“一超”为什么稳。

**操作步骤 / 拆分口径**

1. 取最新年度份额，确认“一超多强”的结构（龙头份额、第二梯队份额、第三梯队份额）。
2. 归因龙头地位，逐点检验：①行业深耕年限与应用场景是否贴合；②可靠性与全球化服务网络；③母公司渠道协同带来的客户粘性。
3. 判断护城河的类型：技术型还是服务与渠道型，后者的击穿方式与前者不同。

**关键指标与数据来源**：份额、服务网络覆盖、母公司渠道协同。

**判断标准**

- 若龙头优势主要来自服务网络和渠道，追赶者仅靠技术追平并不够，还要补服务覆盖与渠道。
- 推理链条：轻型燃机是油气田、管道增压等工业驱动的核心设备 → 龙头在油气领域深耕数十年 → 极高的可靠性与全球服务网络 → 与母公司渠道协同带来客户粘性 → 份额稳定在高位。

**海豚案例**

- 燃气轮机行业《AI 电荒突围》（2026-04-14）：轻型燃机（5-50MW）2024 年 Solar（卡特彼勒子公司）份额高达 48%，西门子能源 25%，曼恩能源解决方案 10%；龙头地位来自油气领域数十年深耕、极高可靠性与全球化服务网络、与卡特彼勒渠道的协同；结论是这类龙头的护城河主要在服务网络和渠道，不只在技术。

**适用场景与注意事项**：适用于成熟工业设备细分市场。与 8.5.4 配合使用：技术同源性解释“为什么做得出”，服务与渠道解释“为什么换不掉”。

### 8.5.6 龙头客户封闭供应链体系决定产业链区域格局

**方法要点**：当需求端由单一巨头主导时，供应商的区域分布由巨头的供应链政策决定；用四步判断一家公司在这条链上的位置，也可以反过来找开放生态带来的替代机会。

**操作步骤 / 拆分口径**

1. 谁是需求端的绝对领导者。
2. 它的供应链是开放还是封闭（是否有严苛标准、严格认证、单一供应商独供）。
3. 现有一级供应商的名单与地区分布。
4. 公司与该领导者有无合作基础、合作历史。
5. 反向使用：同一框架可用来寻找开放生态（Google ASIC、国产算力）带来的替代机会。

**关键指标与数据来源**：一级供应商名单和地区分布；认证体系严格程度；单一供应商独供情况；公司与龙头客户的合作历史。

**判断标准**

- 领导者的供应链越封闭、认证越严、独供越多，新供应商越难进入，区域格局越固化。
- 推理链条：英伟达是机柜的绝对领导者 → 为保证性能和供应链安全，一开始就用严苛标准和严格认证体系建立封闭的核心供应商体系，部分零部件由单一供应商独供 → 供应商集中在美国和中国台湾（如系统级液冷模块核心供应商维谛技术）→ 中国大陆除英维克等少数企业跻身一级供应商外，能做的很有限，主要做上游零部件或代工。

**海豚案例**

- 三花智控《三花：AI 机器人时代…》（2026-01-08）第一部分第一节第 3 点：数据中心热管理竞争格局与英伟达封闭供应链分析；解释热管理一级供应商为何集中在美国和中国台湾。

**适用场景与注意事项**：适用于由单一巨头主导的硬件产业链（AI 服务器、苹果链等）。同一框架可反过来找开放生态（Google ASIC、国产算力）带来的替代机会；评估国产替代时再转入 8.8。

### 8.5.7 “把智能从交换芯片搬到配置期”：确定性换灵活性，判断客户锁定与可复制性

**方法要点**：把一条硬件路线的本质归结为“软件栈优势”，看它的运行时是否还有设备在做决策、前提是否由软件在任务开始前定好，再用“软件与基础设施前提”判断这条路线能不能被别人复制、客户能不能迁走。

**操作步骤 / 拆分口径**

1. 看运行时：网络里是否有设备在运行时做转发决策。谷歌直连 torus 省掉了交换芯片，网络里没有设备在运行时做转发决策。
2. 看前提：拓扑与路径是否在任务开始前由软件（编译器）定好。Cube 是自环还是拼接、切片多大，都是 OCS 的配置。
3. 对客户讲清交换：用灵活性换确定性——路径固定、不存在运行时的拥塞绕行，性能在任务开跑前就能算出来；代价是跑起来后没有临场补救的余地。
4. 看锁定：只有谷歌的编译器知道芯片怎么连，客户必须留在谷歌编译器体系内；从 CUDA 迁移也是问题。
5. 反推可复制性：用同一逻辑检验他人。谷歌的 3D torus 建立在 OCS 基础设施和软件栈之上，AWS 缺这些条件，只能转向交换式。

**关键指标与数据来源**：运行时是否有转发设备、编译器生态、客户迁移成本。

**判断标准**

- 确定性换灵活性：适合负载可预知、任务可预先规划的场景；不适合需要运行时动态调整的场景。
- 客户锁定判断：路线由软件定义、且软件只对自家硬件开放，则迁移成本高；若路线靠通用硬件即可复制，则锁定弱。
- 可复制性判断：一条硬件路线能否被他人复制，取决于对方有没有对应的软件和基础设施前提，而不是有没有同款硬件。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：把谷歌组网的本质归结为软件栈优势，直连 torus 省掉交换芯片，路径由编译器和 OCS 配置预先确定，客户需留在谷歌编译器体系内。
- AWS《AWS 图省事…》（2026-10-12）：Trn2 缺 OCS 和软件栈，补课的地方太多又急着投用，所以转向交换式。

**适用场景与注意事项**：适用于评估软硬一体方案的可复制性和生态锁定，也可用来判断 TPU 对外商业化时客户的迁移门槛。技术路线本身的比较见 6.1，追赶者“抄答案 vs 换解题思路”的评估见 8.7.2。

### 8.5.8 Agent = LLM + Harness 分层拆解，逐层检验技术壁垒

**方法要点**：把 AI Agent 拆成“大模型负责思考决策、Harness 负责稳定安全执行与验收”两层，逐层检验有没有真正的技术壁垒，结论是“真正壁垒不在模型也不在 Harness”。

**操作步骤 / 拆分口径**

1. 按 Agent 完成工作的 5 个关键步骤拆技术栈，区分哪些步骤由大模型承担、哪些由 Harness 承担。
2. 检验 Harness 层壁垒——本质是技术套壳：
   - 日志、权限、沙箱、存档、界面等运行基础设施成熟通用；
   - 连接协议 MCP、Skills 成为开放标准；
   - OpenAI 开源 Codex Harness（Dots 跑在其上）；开源 OpenClaw 成为微软 Autopilot 与 Meta Muse 的灵感来源；
   - 模型在吃掉 Harness 功能：Kimi K2.5 起的 Agent Swarm 把子 Agent 调度训练进模型，上下文向 1M 看齐，规划与自我纠错内化；但主流路线仍是 Harness 调度、模型学会用“拆分子任务”工具。
3. 检验模型层壁垒——领先期收敛：前沿模型领先优势普遍只有 3-6 个月，开源追近、闭源降价甚至推出小模型打擂台；在“能做事”的及格线上差距收敛；追赶者可通过完善训练环境（有效反馈验证的数据回流）做后训练提升。
4. 得出结论：技术壁垒在两层都不稳固，需要转向数据、生态、入口等要素（见 8.5.10、8.5.11、8.6.6）。

**关键指标与数据来源**：模型领先窗口（3-6 个月）、开放协议（MCP / Skills）、开源 Harness、上下文窗口。

**判断标准**

- Harness 层：基础设施通用化、协议开放化、有开源实现 → 技术套壳，难以形成壁垒。
- 模型层：领先期缩短到 3-6 个月、追赶者可通过数据回流补课 → 技术优势难以长期保持。
- 两层都弱，说明竞争的决定因素在别处（上下文与用户数据、生态、商业模式）。

**海豚案例**

- AI 办公 / Agent 行业《AI 入口大战 2.0：腾讯、阿里、字节，谁是 AI 办公的隐形冠军？》（2026-10-13）：以 Agent = LLM + Harness 分层，论证 Harness 通用开源化、模型吃掉 Harness 功能、前沿模型领先期收敛，得出“真正壁垒不在模型也不在 Harness”。

**适用场景与注意事项**：适用于 AI 应用层护城河判断；模型能力代际跃迁可能重塑结论，应定期复检“领先窗口”这一参数。

### 8.5.9 “大客户反向替代”案例，反证纯模型层客户锁定弱

**方法要点**：不靠推断，而是用真实发生的“大客户转为竞对”事件检验供应商的客户粘性；若原有大客户可以反过来替换供应商，则纯模型层锁定弱，闭源模型即便降价也挡不住。

**操作步骤 / 拆分口径**

1. 收集行业里“客户自研替代、采购切换、路由降本”事件。
2. 逐例归类：自研替换、采购路由切换、弃用并推自家产品。
3. 判断事件是否具有共性：多个大客户走同一路径，则说明锁定机制本身薄弱。
4. 得出结论并映射到客户集中度与锁定风险。

**关键指标与数据来源**：客户自研替代事件、路由策略、模型采购切换。

**判断标准**

- 三类事件同时出现，说明“纯模型层”缺少让客户留下的硬约束。
- 推理链条：大客户有能力自研或切换 → 供应商原来的大客户可能反过来成为竞对 → 闭源模型即便降价也挡不住 → 纯模型层锁定弱。

**海豚案例**

- Anthropic / Meta / 微软 / 阿里《AI 入口大战 2.0：腾讯、阿里、字节，谁是 AI 办公的隐形冠军？》（2026-10-13）：
  - Meta 先用 Claude Code 开发 Muse，再用自研 Muse Code 替换 Claude Code；
  - 微软让 Copilot 自动路由默认走更便宜的 OpenAI 模型；
  - 阿里 7 月弃用 Claude Code，改推自家 Qoder。

**适用场景与注意事项**：适用于评估 To B 供应商（模型 API、云服务）的客户集中度与锁定风险。三个案例都发生在头部大客户身上，对中小客户的结论需另行验证。

### 8.5.10 数据飞轮之一：按 Agent 流程各环节，比较模型层与 Harness 层对用户使用轨迹数据的触达

**方法要点**：解释“为什么用户觉得 Codex、Claude Code 更聪明”：本质是上下文能力，即快速理解意图并把过往经验用于下次交付；再按 Agent 运作流程标出模型层与 Harness 层各自能触达哪些用户数据，尤其是“人工确认与交付”环节，判断数据壁垒归谁。

**操作步骤 / 拆分口径**

1. 列出上下文数据的类型：聊天信息、文件、邮件、权限、行业 Know-how、企业内部规范、组织架构、业务流程记录；其中最有价值的是用户每次纠错、批准、拒绝的执行轨迹，可回流做后训练强化学习。
2. 按 Agent 运作流程画图，逐环节标注模型层与 Harness 层能看到的用户数据。
3. 对照差异：Harness 层看到的用户数据明显更多；模型层几乎看不到“人工确认与交付”环节的用户验证与反馈，丧失最佳后训练原料。
4. 推出三种组合下的数据回流结论（见判断标准）。

**关键指标与数据来源**：用户轨迹数据类型与规模、反馈数据触达环节。

**判断标准**

- 若模型与 Harness 入口不属于同一家，数据回流对模型优化打折。
- 提供 Harness 入口的平台，即便用第三方模型，也能用轨迹数据快速优化自家落后的模型。
- 最佳形态是两者同属一家，形成“越用越聪明”的飞轮。

**海豚案例**

- AI 办公 / Agent 行业《AI 入口大战 2.0：腾讯、阿里、字节，谁是 AI 办公的隐形冠军？》（2026-10-13）：按 Agent 运作流程画图，标出模型层与 Harness 层的数据触达差异，结论是“人工确认与交付”环节的数据只有 Harness 层看得到。

**适用场景与注意事项**：适用于判断 AI 应用与模型垂直整合的价值；数据合规与隐私限制会影响数据的可用性。

### 8.5.11 数据飞轮之二：数据回流规模取决于用户量，自有生态是起跑线优势

**方法要点**：数据回流规模取决于用户量，因此把用户获取拆成两条路径，判断谁赢在起跑线：产品功能吸引，还是高频入口导流。

**操作步骤 / 拆分口径**

1. 路径一：产品功能吸引——底层模型性能、技能生态丰富度。
2. 路径二：其他高频入口导流，分两块：外接工具规模（MCP / API 接入或 Computer use 可操作的应用）、外部分发入口（IM、操作系统、浏览器等）。
3. 判断壁垒：外接工具与分发入口都要与传统互联网打交道，在巨头生态各自为政的现实下，拥有更多自有生态与巨额流量 IM 入口的公司赢在起跑线上。
4. 对比：入口与生态对 Agent 的分发作用，比靠技术硬实力的先发优势更轻松。

**关键指标与数据来源**：入口流量（IM / 系统 / 浏览器）、可接入工具数量、技能生态规模。

**判断标准**

- 用户获取的“两条路径”里，路径二（入口导流）在巨头生态割据的环境下更容易规模化。
- 谁拥有更多自有生态与流量入口，谁在数据回流规模上先赢一步。

**海豚案例**

- AI 办公 / 腾讯 / 阿里 / 字节《AI 入口大战 2.0：腾讯、阿里、字节，谁是 AI 办公的隐形冠军？》（2026-10-13）：把用户获取拆为产品功能吸引与高频入口导流，指出拥有自有生态与巨额流量 IM 入口的公司赢在起跑线上。

**适用场景与注意事项**：适用于平台型巨头在 AI 应用竞争中的优势评估；需关注监管对生态封闭的约束。入口与生态竞争的专项框架见 9.5。

### 8.5.12 稀缺资源的战略属性：用军事与国家安全属性判断竞争紧迫性（“太空圈地”）

**方法要点**：识别行业里有限且不可再生的资源（频谱、轨道），再看这些资源除商业价值外是否还有战略或军事价值；一旦关乎国家安全，资源争夺就不只是企业竞争，而是国家竞争，具有紧迫性，这决定了行业增长的确定性与政府支持力度。

**操作步骤 / 拆分口径**

1. 列出行业里有限且不可再生的资源（频谱资源、轨道资源）。
2. 检验是否先到先得：资源有限、先到先得，后来者进入难度拉满。
3. 检验战略属性：是否有军事用途、军方合同、地缘事件验证（如俄乌冲突中 Starlink 展现的军事价值）。
4. 用“资源 + 国家安全”解读各家动作：
   - SpaceX 加速发射 Starlink V2——提升带宽、解决盈利，更重要是占轨道；
   - 贝索斯与中国航天企业加速星座布局；
   - SpaceX 上市融资部分是为了加快资源卡位。
5. 得出结论：商业航天的竞争焦点不只是火箭技术与卫星布局，而是轨道与频谱两类稀缺资源。

**关键指标与数据来源**：频谱资源、轨道资源、军方合同、地缘事件；在轨卫星数、星座规划规模、频谱授权、发射频次。

**判断标准**

- 资源稀缺且不可再生 + 关乎国家安全 = 竞争具有紧迫性，行业增长确定性更高，政府支持力度更大。
- 推理链条：频谱和轨道资源有限 → 先到先得 → Starlink 在俄乌冲突中展现巨大军事价值 → 资源争夺关系各国国家安全 → 太空资源的抢夺和占位赋予行业增长的确定性。

**海豚案例**

- SpaceX《马斯克再甩“王炸”…》（2026-02-24）：频谱和轨道资源有限，Starlink 在俄乌冲突中展现巨大军事价值，资源争夺关系各国国家安全，具有紧迫性；总结认为太空资源的抢夺和占位赋予了行业增长的确定性。
- SpaceX / 亚马逊《(短评) 商业航天核心是轨道和频谱》（2026-03-09）：把商业航天竞争焦点从火箭技术、卫星布局转到近地轨道优质位置和卫星通信频谱；据此解读 SpaceX 加速发射 Starlink V2、贝索斯与中国航天企业加速星座布局、SpaceX 上市融资部分为加快资源卡位。

**适用场景与注意事项**：适用于航天、半导体、能源等具有国家战略属性的行业，以及卫星通信、低轨星座的竞争格局分析。资源价值难以量化，需结合监管分配规则（见 8.5.13）。

### 8.5.13 稀缺资源总量 + 监管时间表：测算窗口期的紧迫性（ITU 频轨规则、LEO 容量约 6 万颗）

**方法要点**：论证“当前是重要窗口期”时，把资源总量、监管时间表、申报动态、国家安全四条证据连起来，并由规则推出可测算的发射需求时间表。

**操作步骤 / 拆分口径**

1. 资源总量：近地轨道理论容量约 6 万颗卫星；Starlink 在轨已近 1 万颗；各国向 ITU 的申报量已达几十万颗，供需严重失衡。
2. 规则：频谱和轨道资源先到先得；按 ITU 规定，申报后第 7 年须发射首颗卫星并成功入轨、正常运行 90 天；第 9 年完成申报总数的 10%；第 12 年 50%；第 14 年 100%。
3. 申报动态：2025 年底中国向 ITU 一次性提交 GW、千帆等 14 个星座、合计 20.3 万颗卫星的申请，远超 Starlink 在轨量；中国星网、上海垣信已获卫星互联网牌照。
4. 国家安全：俄乌冲突中 Starlink 维持乌克兰全国网络、支撑无人机侦察和远程协同，频轨争夺关乎通信权和国家安全。
5. 推出结论：2026 年会有更多可回收火箭进入实际发射试验，发射需求有刚性时间表支撑。

**关键指标与数据来源**：LEO 理论容量、在轨卫星数、ITU 申报量、ITU 部署里程碑（第 7 / 9 / 12 / 14 年）。

**判断标准**

- 申报量远大于理论容量，说明资源争夺是零和的；规则有明确里程碑，说明发射需求有刚性时间表，不会无限推迟。
- 推理链条：资源有限 + 规则里程碑 + 国家层面的大规模申报 + 国家安全属性 → 窗口期紧迫 → 2026 年更多可回收火箭进入发射试验 → 发射需求刚性。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：以 LEO 容量约 6 万颗、Starlink 在轨近 1 万颗、各国 ITU 申报几十万颗、中国 14 个星座 20.3 万颗申请、ITU 第 7 / 9 / 12 / 14 年里程碑，论证频谱和轨道资源争夺的紧迫性与发射需求的刚性时间表。

**适用场景与注意事项**：适用于牌照、频谱、轨道等稀缺资源驱动的行业；ITU 规则提供可测算的发射需求时间表，可与发射端供给测算（第 4 章）配合使用。

### 8.5.14 把下游环节的竞争归因到上游瓶颈环节（星座运营的关键在火箭回收）

**方法要点**：产业链上下游壁垒差异显著时，不在下游环节平均用力，而是找出“决定性环节”，把下游的竞争格局归因到上游瓶颈，并据此调整投资排序。

**操作步骤 / 拆分口径**

1. 逐个判断下游环节有没有颠覆式门槛：卫星及其通信技术虽有技术和制造能力的竞争，但没有颠覆式门槛。
2. 据此判断下游玩家的直接威胁有限：星座运营公司对 SpaceX 的直接威胁有限。
3. 找出真正的变量：Blue Origin 等的火箭技术趋于成熟，卫星运营公司有了更多高性价比的发射选择，这才是核心竞争要素。
4. 得出归因：下游格局由上游发射成本决定，“关键还是看火箭回收赛道的比拼”。
5. 反映到排序：投资排序上把火箭发射放在星座运营之前。

**关键指标与数据来源**：发射成本、可选发射供应商数量。

**判断标准**

- 下游环节无颠覆式门槛、而上游环节存在瓶颈 → 竞争归因到上游。
- 上游可选供应商增多、成本下降 → 下游玩家的成本与选择权改善，下游格局随之改变。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：星座运营竞争格局小结——卫星无颠覆式门槛，核心竞争要素在火箭回收，投资排序上火箭发射先于星座运营。

**适用场景与注意事项**：适用于上下游环节壁垒差异显著的产业链，用来找出“决定性环节”。环节排序与标的选择见 11.3；上游瓶颈与约束切换见 4.4。

**本节速查清单**

- [ ] 是否列出了目标环节的非价格壁垒清单，并与相邻赛道用同一口径对照
- [ ] 四维壁垒（技术 / 资本与规模 / 供应链与认证 / 生态与服务）是否每一维都有可验证的事实或数字

## 8.6 竞争阶段与格局终局推演

> 本节导读：本节回答“竞争现在处在哪个阶段、什么时候爆发、最后会收敛成什么格局、终局下谁拿多少份额”。顺序是先定阶段（头部产品渗透、催化时点、格局收敛、品牌化窗口），再从竞对战略定位和先发优势能否持久看动机与壁垒，最后落到终局推演（模型商业化后规模效应削弱、寡头 vs 多玩家二分、多情景份额区间）。配合 8.1-8.4 的份额、梯队、竞争力对比和竞争烈度数据使用；终局推演得到的份额区间可直接作为 11.4 估值与 11.2 情景映射的输入；AI 与流量入口的终局另见 9.5。

### 8.6.1 用头部产品的 DAU 和渗透率判断竞争处在哪个阶段

**方法要点**：不凭热度判断“谁赢了”，而是看头部产品离国民级应用还有多远：还远，就仍在早期的“心智占领期”，此时考验产品迭代速度和差异化打法，还没到分输赢的时候，后进者仍有机会。

**操作步骤 / 拆分口径**

1. 取头部产品的 DAU 与渗透率，对照“国民级应用”的量级判断阶段。
2. 若头部产品尚远离国民级，定性为早期“心智占领期”，把考察重点放在产品迭代速度与差异化打法上。
3. 判断竞争是否同质化：各家路线是否相同，是否会像电商或外卖那样完全同质化竞争。
4. 判断下半场是否会互相渗透：各家从不同入口出发，最终是否会进入对方的地盘。

**关键指标与数据来源**：头部产品 DAU；渗透率；产品迭代速度。

**判断标准**

- 头部产品离国民级应用还远 → 仍在心智占领期 → 后进者有机会，不下“输赢已定”的结论。
- 各家路线不同 → 暂不会完全同质化；但长期看下半场相互渗透难以避免，需提前评估渗透后的交叉竞争。

**海豚案例**

- 腾讯（2026-01-26）：头部 AI App 只有 1 亿 DAU，竞争还在心智占领期，元宝仍有掰手腕的机会。
- 阿里（2026-01-16）：各家路线不同，暂时不会像电商或外卖那样完全同质化竞争，但下半场相互渗透难以避免。

**适用场景与注意事项**：适用于新兴赛道的竞争阶段定位。阶段判断是动态的，应随头部产品渗透率更新；AI 入口竞争的终局归 9.5 讨论。

### 8.6.2 列出“技术 / 芯片 / 海外样板”三类催化，判断竞争爆发的时点

**方法要点**：判断“竞争什么时候会爆发”，用方法而不是感觉：找出过去的瓶颈 → 判断瓶颈是否已解除 → 找可参照的样板和历史类比。

**操作步骤 / 拆分口径**

1. 找出此前限制行业爆发的瓶颈，归为三类催化：技术、芯片（算力）、海外样板。
2. 技术催化：国内头部模型（千问、DeepSeek、Kimi、豆包）在全球模型榜上都已很能打。
3. 芯片催化：进入推理阶段后“卡脖子”程度下降，国产算力卡也能用，H200 也能进口了，缺卡压力减轻。
4. 海外样板：海外已有 ChatGPT 做出通用 to C AI 的样板。
5. 历史类比：把 DeepSeek 打响的“算力平权”第一枪，类比为 2015 年移动互联网在政策引导下流量显著降本、行业加速繁荣。
6. 三类催化同时具备，则判断竞争一触即发。

**关键指标与数据来源**：模型榜排名、算力供给（国产卡、H200 进口）、海外样板。

**判断标准**

- 瓶颈全部（或主要）解除，叠加有可参照的海外样板，则竞争爆发的时点已到。
- 推理链条：技术追近全球第一梯队 + 芯片约束减轻 + 海外样板验证商业可行 → 2026 年中国 AI App 巨头乱战一触即发。

**海豚案例**

- 中国 AI 互联网《火拼 AI 互联网…》（2026-01-09）：以技术、芯片、海外样板三条依据，判断 2026 年中国 AI App 巨头乱战一触即发；并把 DeepSeek 打响“算力平权”第一枪，类比为 2015 年移动互联网在政策引导下流量降本、行业加速繁荣。

**适用场景与注意事项**：适用于判断行业拐点或竞争加剧的时点。历史类比只作参照，需交叉检验各催化是否真已兑现，避免把“预期解除”当成“已经解除”。

### 8.6.3 识别竞争格局收敛：玩家出清后聚焦少数阵营

**方法要点**：先判断行业处于哪个竞争阶段，若进入分化洗牌期、玩家出清，就把竞争收敛为少数几个阵营，并给每个阵营贴一个角色标签，后续的技术、成本、商业模式比较都在这几方之间展开。

**操作步骤 / 拆分口径**

1. 判断阶段：是否已进入分化洗牌期，列出退出或收缩的玩家名单。
2. 识别收敛后的阵营数量（如三大阵营）。
3. 给每个阵营贴角色标签并写清其依据（先发优势、技术或成本优势、生态赋能）。
4. 记录各阵营关键量化指标（车队规模、联盟成员）。
5. 后续比较（技术、成本、商业模式）限定在这几个阵营之内。
6. 动态更新：联盟变化会改变阵营划分。

**关键指标与数据来源**：退出或收缩的玩家名单；各阵营车队规模；联盟成员。

**判断标准**

- 玩家或元气大伤或进展缓慢 → 市场进入分化洗牌期 → 竞争收敛为少数阵营。
- 阵营标签要对应可检验的特征，而不是品牌印象。

**海豚案例**

- 特斯拉《从造车到造梦：1.5 万亿 AI 特斯拉真的贵了吗？》（2026-01-12）第一部分第 1 点：美国 Robotaxi 市场已进入分化洗牌期，Cruise、Motional、Zoox 等玩家或元气大伤或进展缓慢，竞争收敛为三大阵营——
  - 行业元老 Waymo：先发优势和成熟商业化，车队 2500 辆以上；
  - 激进挑战者特斯拉：端到端技术加成本优势；
  - 生态赋能者英伟达：联合主机厂和 Uber 组成开源联盟，可能改变战局。

**适用场景与注意事项**：适用于早期新兴赛道的格局判断。阵营划分会随联盟变化而变化，需要动态更新；阵营内的多维度对比见 8.3。

### 8.6.4 用传统产品参数同质化 + CR5，判断“无明星产品”的品牌化窗口

**方法要点**：识别行业惯用的产品参数（如支数、克重）是否只是便于产线统一控制的基础品质指标；若参数同质化严重、集中度极低（CR5 个位数）、无明星产品，说明存在以解决真实痛点的产品创新重塑品类、建立品牌的窗口。

**操作步骤 / 拆分口径**

1. 列出行业内主流产品的核心参数，判断它们是在描述消费者痛点，还是在描述产线控制所需的基础品质。
2. 取行业 CR5，判断集中度是否极低（个位数）。
3. 看是否存在明星产品。
4. 三者同时满足 → 存在“以痛点导向的产品创新重塑品类”的品牌化窗口。
5. 补充渠道能力检验，避免把“低集中度”当成“品牌溢价易建”。

**关键指标与数据来源**：行业 CR5、主流产品参数。

**判断标准**

- 参数同质化 + CR5 个位数 + 无明星产品 = 品类尚未被品牌占领，创新者有突破口。
- 推理链条：行业参数只是产线控制指标 → 消费者痛点没有被参数表达 → 以痛点切入的新品类（如深睡枕）有机会建立品牌。

**海豚案例**

- 亚朵《亚朵：酒店界“海底捞”…》（2026-01-13）：传统家纺枕头以支数、克重为主要参数，同质化严重，CR5 常年在 5% 以下，没有明星产品，为深睡枕提供突破口。

**适用场景与注意事项**：适用于分散的消费品赛道；低集中度也可能意味着品牌溢价难建立，需结合渠道能力。

### 8.6.5 从竞对在其集团内的战略定位与 KPI，推断竞争终局

**方法要点**：不只看竞对的产品，还看它在母集团内扮演什么角色、考核什么 KPI；角色与 KPI 决定了它的资源投入方式、内容采购倾向和目标用户，从而推断竞争最终是你死我活还是共存。

**操作步骤 / 拆分口径**

1. 确认竞对在集团内的战略定位（辅助主业生态、加强流量闭环，或独立业务）。
2. 确认 KPI 约束（是否需要自负盈亏）。
3. 由定位与 KPI 推断其资源倾向：版权或内容采购方向、成本水平、目标用户。
4. 把竞对的目标客群与自家核心客群作对比，判断是否重叠、是否被导流。
5. 综合给出终局：共存、替代或收敛。
6. 同一思路可用于分析竞对的组织调整（按商家月 GMV 分层，分别配置打法与入口）。

**关键指标与数据来源**：竞对组织架构、KPI、内容 / 客群。

**判断标准**

- 推理链条（汽水音乐 vs 腾讯音乐）：汽水音乐在字节内是辅助抖音生态、加强流量闭环的角色 → KPI 需自负盈亏 → 版权倾向成本不高的抖音神曲与新兴歌手 → 核心用户是价格敏感的抖音用户、碎片化背景音需求；TME 头部版权库服务一二线固定音乐消费用户，视频号对 TME 同样导流 → 终局大概率是“共存格局”。
- 定位与 KPI 越是“辅助生态、自负盈亏”，越不会无底线烧钱去全面替代对手。

**海豚案例**

- 腾讯音乐《汽水猛攻》（2026-03-17）：汽水音乐在字节集团内定位辅助抖音生态与流量闭环、需自负盈亏，版权倾向低成本神曲与新兴歌手，目标用户与 TME 的一二线固定音乐消费用户不同；叠加视频号对 TME 同样导流，推断终局为共存。
- 美团《AI 分走战火》（2026-06-01）：同理分析抖音到店组织调整，按商家月 GMV 5 万分层，小商家转线下地推并配以抖省省 LBS 入口。

**适用场景与注意事项**：适用于竞争格局与终局判断，尤其是对手为大集团内的一条业务线时。组织与 KPI 信息多为外部观察，需标注推断属性。

### 8.6.6 区分短期先发优势与长期持续壁垒：用户数领先不等于赢家，以数据资产与企业深度捆绑为终局判据

**方法要点**：竞争早期不以用户数定输赢；用“核心要素”（上下文、生态、商业模式）检验先发优势能否转化为持续壁垒，并以“谁能积累更多工作流程经验等数据资产”作为终局标准。

**操作步骤 / 拆分口径**

1. 列出当前先发者的优势（用户规模）。
2. 用核心要素逐项检验：上下文、生态、商业模式，找出需要补的短板（如模型性能与行业 know-how）。
3. 检验追赶者的追赶潜力：其优势不在用户数，而在与企业的深度捆绑。
4. 以数据资产作为终局判据：谁能积累更多工作流程经验等数据资产，谁才有持续性壁垒。
5. 判断竞争强度与打法：AI 办公是巨头把囤积算力有效变现的方向，竞争比年初 Chatbot 入口争夺更激烈且持续；巨头会减少纯撒币获客，转向利用生态位与渠道 + 产品迭代速度，最快触达用户、实现高留存、积累数据资产，形成强者恒强飞轮。
6. 结论：当下谈终局赢家尚早。

**关键指标与数据来源**：用户规模、留存、企业捆绑深度、数据资产积累。

**判断标准**

- 先发优势（用户规模）是短期变量，持续壁垒来自上下文、生态、商业模式与数据资产的积累。
- 推理链条：Workbuddy 拥有用户规模先发优势，但需补模型性能与行业 know-how 以延缓被追赶 → 千问办公、豆包工作体现的追赶力在于与企业的深度捆绑 → 数据资产积累决定谁有持续壁垒。

**海豚案例**

- 腾讯 / 阿里 / 字节《AI 入口大战 2.0：腾讯、阿里、字节，谁是 AI 办公的隐形冠军？》（2026-10-13）：现阶段 Workbuddy 拥有先发优势（用户规模），千问办公、豆包工作具备追赶甚至超越能力；终局标准是谁能积累更多工作流程经验等数据资产；竞争会比年初 Chatbot 入口争夺更激烈且持续，当下谈终局赢家尚早。

**适用场景与注意事项**：适用于平台竞争早期的赢面判断，避免以短期用户数定输赢。数据飞轮的来源见 8.5.10、8.5.11，技术层壁垒检验见 8.5.8。

### 8.6.7 模型大宗商品化 + Agent OS 调度对规模效应的削弱

**方法要点**：观察模型层的竞争动态，判断它是否具备互联网式规模效应；若不具备，终局前的估值驱动应是迭代速度与场景渗透率，而不是终局利润。

**操作步骤 / 拆分口径**

1. 观察闭源头部模型的榜单更替频率：是否轮流坐庄，性价比梯队坐庄是否换得更快。
2. 推演趋势：前台的 Agent OS 可以按用户需求自动调度模型，削弱互联网式规模效应。
3. 定性商业模式：本质是重资产模式下的成本与性能比拼。
4. 得出估值含义：终局之前，AI 迭代速度和场景渗透率才是核心估值驱动，成本控制和运营效率同样重要。
5. 估值方法选择：看 ARR 增长斜率，而不是终局利润。

**关键指标与数据来源**：榜单头部更替频率、调用量迁移、价格战。

**判断标准**

- 头部更替越快、调用量迁移越容易、价格战越激烈，说明模型商品化越深，规模效应越弱。
- 推理链条：闭源头部轮流坐庄 → 前台 Agent OS 按需调度模型 → 规模效应被削弱 → 重资产成本与性能比拼 → 估值看 ARR 增长斜率而非终局利润。

**海豚案例**

- MiniMax《疯狂高估值背后…》（2026-03-31）“开源头部 MiniMax：闭源头部示范效应下亦步亦趋的价值跟随”一节：以头部更替、性价比梯队轮替和 Agent OS 调度，判断模型商能否获得持续超额利润，并据此选用 ARR 增长斜率作为估值依据。

**适用场景与注意事项**：适用于判断模型商能否获得持续超额利润。估值方法的细化见 11.4；纯模型层客户锁定弱的实证见 8.5.9。

### 8.6.8 终局二分法：寡头垄断 vs 多玩家 / 通用技术，并跟踪 1P/3P 模式与份额

**方法要点**：面对颠覆性技术（无人网约车）对平台的威胁，把分歧归结为一个二分问题：终局是少数寡头垄断（连需求入口一起革命，平台价值受损、份额被抢甚至被挤出），还是多玩家市场或通用技术（只革命运力供给，平台凭供需两端的整合规模保住份额，成本下降还会做大行业）；再用可跟踪的项目持续检验，不草率下结论。

**操作步骤 / 拆分口径**

变体 A：阵营进展与威胁显现窗口（平台视角）

1. 把分歧归结为终局是寡头垄断（Waymo、Tesla 独大，平台价值受损）还是多玩家市场（众多技术提供方，聚合平台成为合作伙伴）。
2. 跟踪双方阵营的进展：平台方签约的合作方（Zoox、英伟达），以及潜在寡头的单量爬坡与城市扩张。
3. 判断威胁在报表上显现的时间窗口。

变体 B：1P/3P 模式追踪与份额测算

1. 头部玩家运营模式：Waymo 新城市中 1P 与 1P + 3P 的比例；Tesla 坚持 1P。
2. 覆盖计划：Tesla 2026 年底覆盖美国 1/4 到 1/2 地区；Waymo 2027 年中覆盖 40% 人口。
3. 单量份额测算：Waymo 2026 年底周均 100 万单，仅占美国 1-2%；Wells Fargo 预计 2028 年约 6%。
4. 平台合作生态：Uber 与 7 家自动驾驶技术方合作。
5. 新进入的技术供应方：英伟达。
6. 持续跟踪迹象，不草率下结论。

**关键指标与数据来源**：合作协议数量和对象；潜在寡头的单量和城市扩张；运营城市模式；覆盖人口比例；周单量；份额；合作方数量；威胁显现的时间窗口。

**判断标准**

- 寡头垄断情景：技术被少数寡头垄断，连需求入口一起革命，平台份额被抢甚至被挤出。
- 通用技术情景：技术成为谁都能用的通用技术，只革命运力供给，平台凭供需两端整合规模保住份额，成本下降还会做大行业。
- 迹象判据：新城市采用 1P 的比例越高、合作终止越多，越偏向寡头垄断；平台合作方越多、新技术供应方越多，越偏向多玩家。
- 时间窗口判断：即使是坏情景，在 2027 年前也难以在报表上明显体现。

**海豚案例**

- Uber《Uber：业绩都在线，只是 Robotaxi 威胁难散》（2026-05-07）：Uber 押注多玩家市场，近期与 Zoox、英伟达签约；Waymo 周均单量 50 万，年底目标 100 万；目前很难判断终局，即使是坏情景，在 2027 年前也难以在报表上明显体现。
- Uber《好业绩也暴跌，真会被特斯拉“抄家”？》（2026-02-05）：2025 年 6 月以来 Waymo 新明确运营模式的 5 个城市中，只有 1 个采用 1P + 3P（与 Lyft 合作）；Uber 在 Austin、Atlanta 引入无人车后，首次用户增长加速 9pct；股价自 2025 年 11 月高点回调近 20%。
- Uber（2026-08-06）：Waymo 考虑在 Austin、Atlanta 终止与 Uber 合作；Uber 与 Nvidia 共建无人驾驶生态，竞争更多元也更排他；海豚君偏谨慎。

**适用场景与注意事项**：适合平台型公司面对上游技术颠覆的情形，以及面临技术颠覆的平台型行业（出行、搜索、内容等）。终局判断要“持续跟踪迹象”而不是一次性下结论；份额区间的情景化见 8.6.9。

### 8.6.9 多情景终局 + 市占率区间推演（苹果 vs 安卓类比）

**方法要点**：在多维对比基础上，给出若干种终局情景并赋予份额区间，写明各玩家在情景中的约束；作用是把竞争判断转成可输入估值模型的份额假设。

**操作步骤 / 拆分口径**

1. 先完成各阵营的多维对比（技术、成本、商业模式等，见 8.3）。
2. 设计三种终局情景，并为每种赋予份额区间：
   - 红海混战：技术与成本差距不大、多方割据，特斯拉市占约 30%，聚合平台 Uber 成最大赢家；
   - 双寡头共治：特斯拉 55-65% vs 英伟达联盟 30-40%，复刻“苹果（垂直一体）vs 安卓（开放授权）”；
   - 一家独大：特斯拉凭技术 + 成本垄断 70-80%。
3. 写明各家在情景中的约束：Waymo 重资产高成本、技术泛化性弱；英伟达联盟协同与数据短板。
4. 为每种情景标注触发条件。
5. 把份额区间输入估值模型（见 11.2、11.4）。

**关键指标与数据来源**：终局市占率区间、受益方（平台方 vs 车辆方）。

**判断标准**

- 不同情景对应不同的受益方：红海混战利好聚合平台，双寡头利好垂直一体与开放联盟，一家独大利好技术与成本领先者。
- 用成熟的行业类比（苹果 vs 安卓）为双寡头情景提供形态参照。

**海豚案例**

- 特斯拉《(短评) 美国 Robotaxi 三大阵营》（2026-01-16）：给出三种终局，份额情景分别为 30% / 55-65% / 70-80%，并写明 Waymo 与英伟达联盟的约束。

**适用场景与注意事项**：适合为远期估值提供份额输入；需标注各情景的触发条件，避免主观概率。

**本节速查清单**

- [ ] 头部产品 DAU 与渗透率处于什么量级，是否仍是“心智占领期”，各家路线是否同质化、是否会互相渗透
- [ ] 是否列出技术、芯片、海外样板三类催化，并逐一判断瓶颈是否已解除
- [ ] 是否识别了玩家出清、阵营收敛，并给每个阵营贴上角色标签、标明联盟变化
- [ ] 分散的消费品赛道是否检验了参数同质化、CR5、明星产品缺位与渠道能力
- [ ] 是否分析了竞对在其集团内的战略定位与 KPI，据此推断共存还是替代
- [ ] 先发优势是否用上下文、生态、商业模式、数据资产检验过，是否避免以用户数定输赢
- [ ] 模型商业化的规模效应是否被 Agent OS 调度削弱，估值是否改看 ARR 增长斜率
- [ ] 终局二分法（寡头 vs 通用技术）的跟踪项（运营模式、覆盖计划、份额、合作生态、新进入者）是否齐备
- [ ] 多情景终局是否给出份额区间、各玩家约束与触发条件，并输入估值模型

## 8.7 追赶者评估与追平判断

> 本节导读：本节回答“后来者能不能追上、差在哪、还要多久”。方法分四组：框架型（可行性三问、抄答案 vs 换解题思路、代际错位比较、理论追平 vs 实际追平），定量对标型（核心参数横向对标、竞品追赶对龙头溢价的影响、里程碑与研发周期对标、是否独有检验、成本潜力），定性反证型（用龙头的理性选择反证竞对方案），以及后来者成功要素与商业模式差异（突围三要素、重资产整机 vs 轻资产 IP 授权）。壁垒的构成见 8.5，竞争力多维对比见 8.3，技术路线本身的比较见 6.1 与 6.5；国产替代专项评估见 8.8。

### 8.7.1 追赶者可行性三问：技术积累、一体化生产与生态壁垒、配套主业竞争力

**方法要点**：评估一个“早早布局但进展慢”的老牌玩家能否突围，不被“先发”印象误导，用三个问题检验：技术是否先发、量产与生态壁垒能否跨过、有没有配套主业来牵引。

**操作步骤 / 拆分口径**

1. 技术是否先发：布局时长、全栈能力、原型机进度。
2. 量产与生态壁垒能否跨过：客户绑定、制造一体化（前端晶圆制造与后端先进封装是否深度集成、龙头是否与制造龙头深度绑定）。
3. 有没有配套主业牵引：是否有自家主业产品（如交换机 ASIC）为新技术提供需求与规模。
4. 三问并列作答，得出“资本市场预期”与“长期可能性”两层结论。

**关键指标与数据来源**：技术积累时长、原型机进度、客户绑定、配套主业份额。

**判断标准**

- 三问中“技术先发”只是入场券，后两问才决定能否放量。
- 推理链条（英特尔 CPO）：最早布局硅光之一、有全栈能力、早已推出 CPO 原型机 → 但 CPO 需要把前端晶圆制造和后端先进封装深度集成，英伟达与台积电深度绑定，形成一体化生产壁垒 → 英特尔在交换机 ASIC 上竞争力有限，缺少自家交换芯片的牵引 → 资本市场对其 CPO 业务预期不高，但不排除未来能占一席之地。
- 同一框架用于 AMD Helios，结论是“理论上了牌桌、实际万年备胎”。

**海豚案例**

- 光互连行业《“‘铜’ 牛夫人” 不走！CPO》（2026-06-24）：评估英特尔的 CPO 前景，按三问得出“预期不高但不排除未来占一席”。
- AI 组网《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：用同一框架评估 AMD 的组网方案，结论“理论上了牌桌、实际万年备胎”。

**适用场景与注意事项**：适用于评估老牌企业或追赶者在新技术周期中的机会，以定性为主。三问要配合 8.7.4 的“理论追平 vs 实际追平”区分，避免只看原型机或带宽参数。

### 8.7.2 跟随者策略评估：在领先者框架内追赶（抄答案）vs 换解题思路

**方法要点**：用“抄答案还是换解题思路”区分挑战者的打法，并用三条标准判断跟随者能否成功。

**操作步骤 / 拆分口径**

1. 把每个挑战者归入一类：
   - 抄答案：照搬领先者架构，如 AMD 照搬 GB300 架构、外采交换芯片，带宽追平了，但出货时对手已经换代（拿前朝剑斩本朝官），工程设计落后；
   - 换解题思路：不在领先者的互连框架里硬拼，发挥自己的软件栈优势，用组网取舍换竞争力，如谷歌；
   - 先上市再补课：不求竞争力，只求能交付，如 AWS。
2. 解释为什么不在领先者框架内硬拼：在那个框架内，跟随者无论在产业链整合、方案迭代速度还是软硬件协同上都很难追上。
3. 用三条标准判断跟随者能否成功：①关键硬件是否依赖外采（有没有自主权）；②是否与领先者隔代竞争；③有没有别人复制不了的差异化能力（如软件栈）。

**关键指标与数据来源**：自研 / 外采比例、代际对标关系、差异化能力。

**判断标准**

- 依赖外采、与领先者隔代竞争、无独有差异化能力 = 追赶难度大，最多“迈过及格线”。
- 有别人复制不了的差异化能力（如软件栈）+ 换解题思路 = 有可能在特定路线上形成自己的竞争力。
- AMD 靠抄答案迈过及格线，谷歌完全换了解题思路，AWS 是全网最不自研的一家。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：AMD 靠抄答案迈过及格线，谷歌完全换了解题思路，发挥软件栈优势，用组网取舍换竞争力。
- AWS《AWS 图省事…》（2026-10-12）：AWS 是全网最不自研的一家，先上市再补课，不求竞争力，只求能交付。

**适用场景与注意事项**：适用于“一超多强”格局下的挑战者评估，如 AI 芯片、国产替代。软件栈锁定逻辑见 8.5.7，代际错位的具体对比方法见 8.7.3。

### 8.7.3 代际错位比较法：先与所对标的那一代比，再看竞品下一代迭代了什么

**方法要点**：追赶者的产品往往“参照上一代、上市时对手已换代”；比较时分两步：先和被模仿的那一代逐项对比，看抄了什么、抄得像不像；再分析对手新一代更新了什么，最后确定追赶者相对真实竞品的位置，并前瞻对手再下一代，判断差距会不会扩大。

**操作步骤 / 拆分口径**

1. 定位追赶者产品所参照的那一代（AMD Helios 基本参照 GB300 NVL72）。
2. 找出追赶者上市时真正的竞品（英伟达换代方案 Vera Rubin）。
3. 第一步：Helios 与 GB300 逐项对比，看抄了什么、抄得像不像。
4. 第二步：分析 Vera Rubin 更新的地方——取消飞线、模块化、36 颗 NVLink 6 交换芯片、C2C 带宽翻倍。
5. 第三步：确定 Helios 相对真实竞品 Vera Rubin 的位置。
6. 前瞻：再看英伟达下一代 Rubin Ultra（Kyber 与 Oberon 两种机架），判断差距是否会扩大。

**关键指标与数据来源**：代际时间线、各代关键参数。

**判断标准**

- 追赶者的真实对手是“上市时点的最新一代”，而非其模仿的那一代。
- 若对手迭代节奏快于追赶者追平速度，差距会随代际拉大。
- 用“用竞对上一代的架构，打对方下一代的产品”概括错位。

**海豚案例**

- AI 组网《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：Helios 先对 GB300、再对 Vera Rubin、最后前瞻 Rubin Ultra。

**适用场景与注意事项**：适用于追赶者与龙头的产品对比（芯片、手机、汽车等）。比错代际会让结论偏乐观；需要把各家发布与上市时间线放在同一张图上。

### 8.7.4 区分“理论指标追平”与“实际竞争力追平”：工程实现、自研全栈、成本和迭代速度才是差距所在

**方法要点**：做小结时先承认对手已达到的部分，再指出“单一参数追平”不等于“实际竞争力追平”，差距往往藏在工程实现、自研全栈、成本和迭代速度里，避免被一个亮眼指标误导。

**操作步骤 / 拆分口径**

1. 先列对手已追平的核心指标：在 Scale-up 与 Scale-out 两侧都已基本追平英伟达的机架方案。
   - Scale-up：单 GPU 双向 3.6TB/s 带宽，与 Vera Rubin 相当；
   - Scale-out：同样是 800G 网卡。
   - 对下游客户来说，AMD 已经具备成为替代方案的基本资格。
2. 再指出理论带宽追平并不是全部，差距集中在：
   - 工程实现与自研全栈：沿用 GB 机架的落后设计直接推高单机架物料成本；
   - 生态与协议：原生 UALink 还要走很长的路；
   - 迭代速度：英伟达的机架方案仍在快速迭代，下一代物理形态还可能改变。
3. 对 Scale-out 侧整理整机差异对比表，用浅红底色标出 AMD 落后的项目，结论是该层没有核心差异。
4. 给出定性：“理论上了牌桌，实际万年备胎”。

**关键指标与数据来源**：带宽、延迟、单机架成本、迭代节奏、差异对比表（标出落后项）。

**判断标准**

- 带宽等“理论指标”追平只意味着有资格成为替代方案，不意味着有竞争力。
- 判断实际竞争力要加上成本（单机架物料成本）、自研程度（工程实现）、生态成熟度（UALink）、迭代速度四项。
- 对比表中落后项集中、且无独有优势 → “没有核心差异”。

**海豚案例**

- AI 组网《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）第三部分小结：先承认 Helios 在 Scale-up 与 Scale-out 的带宽追平，再从工程实现、自研全栈、成本、迭代速度指出差距，最终定性“理论上了牌桌，实际万年备胎”。

**适用场景与注意事项**：适用于追赶者评估，避免被单一参数追平误导。与 8.7.3（比对代际）、8.7.2（打法分类）联合使用。

### 8.7.5 核心技术参数横向对标，判断“技术代差”护城河是否被追平

**方法要点**：把公司的核心技术参数与主要竞品并排比较，判断原有的技术代差是否已被“平替”；若被追平，再结合价格带与政策约束，判断份额流失是否会持续，同时追踪公司下一代技术的发布与下放时间，看能不能重建代差。

**操作步骤 / 拆分口径**

1. 选定可横向比较的核心技术参数：
   - 插混：馈电油耗、热效率、纯电续航；
   - 快充：倍率、补能时间、电压平台；
   - 智驾：芯片算力（TOPS）、城市 NOA 下沉价格带。
2. 并排对比主要竞品，判断是否已“平替”。
3. 看技术下放的价格带：先进技术只用在高价车型，还是已下放到走量车型。
4. 若代差被追平，再结合价格带和政策约束，判断份额流失是否持续。
5. 追踪公司下一代技术（DM6.0、二代刀片）的发布和下放时间，评估能否重建代差。

**关键指标与数据来源**：馈电油耗（L/100km）、热效率、纯电续航、充电倍率 / 补能时间、电压平台、智驾芯片 TOPS、技术下放的价格带；产业链调研和发布会数据。

**判断标准**

- 参数只有转化为终端销量才有意义：看份额是否仍在流失，技术下放是否覆盖走量价格带。
- 推理链条：代差被追平 → 价格带上高端技术未下放到走量车型 → 份额加速流失；重建代差需要下一代技术发布并下放。

**海豚案例**

- 比亚迪《王座失守…》（2026-03-28）：
  - 2025 年把 DM 馈电油耗降到 2.6L，但吉利雷神、奇瑞 C-DM 在能耗和动力上已实现平替；
  - 超级 E 平台（1500V、5 分钟续航 400 公里）只用在 20 万以上的汉 L、唐 L，没有下放到走量车型，纯电份额加速流失；
  - DM6.0 热效率有望超过 48%，馈电油耗 1.8-2.79L（DM5.0 为 2.9L），但大概率下半年才发布。
- 比亚迪《国内卷单价…》（2026-08-29）：6C 闪充下放到 15-20 万主力车型，直接对标吉利、小鹏的 800V 下沉；自研 4nm 智驾芯片璇玑 A3 单颗 700TOPS。

**适用场景与注意事项**：适用于技术驱动的制造业（汽车、消费电子、半导体）。参数要结合产业链调研和发布会数据，并且要看这些参数能不能转化成终端销量。

### 8.7.6 竞品技术路线追赶程度 → 龙头定价溢价能否维持

**方法要点**：跟踪竞品的技术路线变化，判断技术代差是否已消失；代差一旦消失，龙头过去高于同行的溢价就难以维持，只能“以价换量、守住份额”，这是 ASP 超预期下降的根因。

**操作步骤 / 拆分口径**

1. 跟踪竞品技术路线变化（如速腾从早期 MEMS 转向转镜路线）。
2. 确认竞品产品力与龙头的差距是否收窄，以及量产与出货时点。
3. 判断技术代差是否消失。
4. 代差消失 → 龙头过去高于同行的溢价（10%-20%）难以维持。
5. 推演龙头的应对：主动牺牲溢价，“以价换量、守住份额”；据此解释 ASP 超预期下降。

**关键指标与数据来源**：竞品技术路线、竞品量产和出货时点、龙头溢价幅度。

**判断标准**

- 竞品产品力差距收窄 + 大规模出货 = 技术代差消失，龙头溢价下滑成为大概率事件。
- 推理链条：竞品路线转变 → 产品力差距收窄 → 代差消失 → 龙头溢价（10%-20%）难以维持 → 以价换量 → ASP 超预期下降。

**海豚案例**

- 禾赛（2026-05-19、2026-08-19）：速腾 EMX 产品力与禾赛差距收窄，2025 年四季度大规模出货，技术代差基本消失；禾赛主动牺牲溢价，2026 年被定性为“以价换量之年”。

**适用场景与注意事项**：适用于技术驱动的硬件行业竞争分析。需要产业调研确认竞品的性能和量产情况。

### 8.7.7 关键里程碑与核心性能参数对标（回收成功、运力）

**方法要点**：用可验证的里程碑和性能参数来评估追赶者，把“有没有做到”和“做到什么程度”分开：是否回收成功、运力吨位是两个硬指标，用来定位追赶者所处的代际，以及对龙头构成什么程度的压力。

**操作步骤 / 拆分口径**

1. 列出赛道的硬指标：一级回收成功与否、LEO 运力（吨）、商业任务启动时间。
2. 逐项核对追赶者的完成情况与时点。
3. 与龙头的各代产品对比，定位追赶者所处代际，并判断压力大小。

**关键指标与数据来源**：一级回收成功与否、LEO 运力（吨）、商业任务启动时间。

**判断标准**

- 是否回收成功是“有没有入场资格”的硬指标，运力吨位是“能打哪个市场”的硬指标。
- 推理链条：New Glenn 2025 年成功首飞并完成一级回收 → 是全球第二个实现垂直回收的轨道级火箭，且直接在海上无人驳船着陆 → 2026 年 4 月开始执行商业任务 → LEO 运力达 45 吨，远高于 Falcon 9，接近 Falcon Heavy → 对龙头构成较大压力。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：New Glenn 与 Falcon 9 / Heavy 对比——2025 年首飞成功并完成一级回收，海上无人驳船着陆，2026 年 4 月开始执行商业任务，LEO 运力 45 吨。

**适用场景与注意事项**：适用于航天、半导体制程等有明确里程碑的赛道。里程碑要结合时间差使用（见 8.7.8），单一里程碑不等于规模化能力。

### 8.7.8 研发周期与里程碑时间差对标：立项 → 入轨 → 回收关键技术节点

**方法要点**：用“从立项到某里程碑所花时间”对比追赶速度，并把失败事件区分为工程细节问题还是原理性问题，判断后来者是否因先行者的示范而显著缩短研发周期。

**操作步骤 / 拆分口径**

1. 取追赶者的立项时间、入轨时间、回收关键节点。
2. 取龙头同阶段的时间作参照。
3. 计算“立项 → 里程碑”时长，并把回收环节拆成关键技术节点（高空调姿、再入点火、超音速气动滑行、高精度制导、最后阶段刹车等）。
4. 对比不同追赶者的进度与技术路线（回收方案）。
5. 分析失败事件：是工程细节问题（可通过迭代解决）还是原理性问题。

**关键指标与数据来源**：立项至入轨时长、关键回收技术节点、落点偏差（米）、回收方案。

**判断标准**

- 同一里程碑上，后来者所需时间显著短于龙头，说明有先行者参考，追赶速度更快。
- 落点偏差很小、失败发生在最后环节，往往属于工程细节问题。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：
  - 蓝箭朱雀三号：2023 年立项，2025 年 12 月发射入轨，约 2 年多；Falcon 9 从立项（2005）到首飞成功（2010）用了 5 年；
  - 回收环节：朱雀三号 2025 年 12 月发射后的回收中实现高空调姿、再入点火、超音速气动滑行、高精度制导，最后阶段刹车失败坠毁，但落点偏差仅约 40 米；Falcon 9 达到这些进展是 2012-2014 年，距立项已 7-9 年；
  - 航天八院长征十二号甲（2021 立项、液氧甲烷）2025 年 12 月入轨但回收失败，进度慢于朱雀三号；
  - 航天一院长征十号甲 2026 年 2 月“一箭双试”成功，一级受控海上溅落，采用网系回收（栅格舵调姿 + 末端反推 + 网器捕获），可能在工程可靠性和成本上具有优势；
  - 结论：后来者有先行者参考，研发周期显著缩短。

**适用场景与注意事项**：适用于判断追赶者的技术进度（航天、半导体、大模型）。失败事件需区分是工程细节问题还是原理性问题；不同路线的可靠性和成本优势仍需后续数据验证。

### 8.7.9 “是否独有”检验：行业共识梳理 + 各厂节点时间表对比 + 用上一代节点进度差推断下一代进度

**方法要点**：先判断一项技术是不是某家独有，再逐家列时间表，并用上一代节点的进度差去推断下一代进度；把“技术是否独家、谁快谁慢”转成可比较的时间表。

**操作步骤 / 拆分口径**

1. 判断技术是否独家：该技术是否已被行业研究多年、早期为何搁置、现在为何重新成为共识（垂直沟道晶体管业内研究多年，早期搁置是因为阵列与外围逻辑绑在同一工艺、改架构投入产出比低；随 6F² 微缩难度加大、混合键合成熟，4F² 重新成为行业公认下一代路线）。
2. 逐家列出时间表：
   - 三星：进度最快但路线摇摆；10a 原计划转 4F²，3 月已用 10a 工艺产出可工作芯片，计划年内完成开发、2027 年质量测试、2028 年转入量产线；
   - SK 海力士：0a 沿用 6F²，0b 才导入 4F²，晚一个节点；
   - 美光：未公开；2025 年韩媒称可能跳到 3D DRAM，UBS 1 月调研称已重新放回路线图、0a 转 4F²、约 2030H2 量产；
   - 长鑫：首代 4F² 产品定位 DDR5 RDIMM，年底推出，早于三大厂。
3. 用上一代节点的进度差推断下一代：海力士 1d 开发完成比三星晚约 3 个月、量产准备晚约半年，所以 4F² 迁移也偏慢。
4. 形成时间表对比图。

**关键指标与数据来源**：各厂 4F² 导入节点、开发完成 / 质量测试 / 量产时间、前代节点进度差；来源：The Bell、The Elec、UBS 产业调研。

**判断标准**

- 若多家都在走同一技术路线，则该技术不是独家，竞争落在“谁先量产、谁良率高”的时间表上。
- 用上一代的节点进度差外推下一代，是对未公开时间表的一种合理估计，但需交叉验证。

**海豚案例**

- 长鑫科技 / DRAM 三大厂《长鑫把晶体管「竖起来」：绕开 EUV 的追赶路，会撼动存储三巨头吗？》（2026-10-16）：梳理垂直沟道晶体管的行业共识，逐家列出三星、SK 海力士、美光、长鑫的 4F² 时间表，用 1d 节点的进度差推断海力士 4F² 迁移偏慢，并制成时间表对比图。

**适用场景与注意事项**：适用于技术节点竞赛型行业（存储、晶圆代工、先进封装）的格局判断；韩媒信息需交叉验证。EUV 依赖的换算见 8.8.4。

### 8.7.10 追赶者成本潜力评估：当前成本无量级差异 + 中国制造供应链的类比

**方法要点**：评估追赶者对龙头的威胁，先比较当前单位成本，再用跨行业类比看“模仿者路径”下成本能降到什么水平，最后定性追赶者的模式。

**操作步骤 / 拆分口径**

1. 对比发射成本：中国尚未实现可回收，但发射成本与 Falcon 9 无量级差异；一旦实现可回收，成本上可能有优势。
2. 跨行业类比：马斯克在特斯拉汽车和 Optimus 上都经历过尝试完全垂直一体化、最终把制造交给中国供应链的过程；SpaceX 能在美国本土制造，依靠的是发射模式的颠覆，一旦中国掌握可回收，SpaceX 受到的影响可能不小。
3. 定性中国模式：在可回收技术上处于跟随状态，但“模仿者”路径契合中国的工程能力和规模化优势。

**关键指标与数据来源**：单位发射成本（美元 / kg）、技术代差。

**判断标准**

- 当前成本无量级差异 + 技术追上后潜在降本空间 = 追赶者有成本优势潜力。
- 推理链条：成本无量级差异 → 可回收一旦实现，中国制造供应链的规模与工程能力可能带来成本优势 → 对 SpaceX 的影响可能不小。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：对比中国火箭与 Falcon 9 的发射成本，并用特斯拉 / Optimus 的供应链经历作类比。

**适用场景与注意事项**：适用于国产替代或追赶者分析。跨行业类比需谨慎，航天还受出口管制、军工属性约束。

### 8.7.11 竞对技术方案的“反证法”评估：若方案更优，龙头早已采用

**方法要点**：评估一个“以巧破力”型挑战者时，不直接争论技术优劣，而是用龙头的理性选择反证：如果对方方案真的更优，龙头完全可以采用类似方案或折中方案；龙头没有采用，说明对方方案有局限；再叠加资本背书作为修正项。

**操作步骤 / 拆分口径**

1. 规模对比：挑战者的规模与龙头的差距（AST 只用几十颗卫星，声称以巨型相控阵天线弥补数量不足；Starlink 有几万颗卫星）。
2. 反证：“否则 Starlink 完全可以考虑类似方案，或采用折中方案”，用龙头的理性选择反证对手方案的局限。
3. 资本背书修正：AST 背后有 Google 等巨头支持，不排除对 SpaceX 产生一定压力；美国另有多个 D2D 项目在推进。

**关键指标与数据来源**：星座规模（几十颗 vs 几万颗）、天线方案、战略投资方。

**判断标准**

- 框架：规模对比 → 反证 → 资本背书修正。
- 龙头未采用对方方案 → 说明方案在规模、成本或体验上有局限；但若有强资本背书，结论需向有压力的一侧修正。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：AST SpaceMobile vs Starlink 的 D2D 威胁评估。

**适用场景与注意事项**：适用于对“以巧破力”型挑战者的初步评估。反证法有局限：龙头可能受路径依赖所困，因此只作初步筛查，不能替代后续的技术与量产核验。

### 8.7.12 后来者突围三要素：差异化定位、客户“二供 / 三供”扶持、垂直一体化与极致降本

**方法要点**：拆解后来者（Rocket Lab）为什么能在寡头市场中跑出来，抽象出三条成功要素，用来评估寡头市场中二线公司的前景。

**操作步骤 / 拆分口径**

1. 差异化定位：Falcon 9 一次可发射多颗卫星，经济性好但灵活性差（卫星要迁就整体任务）；Electron 为小卫星提供专属轨道部署，用类比“Falcon 9 是公交车，Electron 是出租车”，填补市场空白。
2. 客户安全需求：政府和军方需要高频、高可靠的发射能力，也不可能让一家独大，必须扶持二供、三供，所以 Rocket Lab 创业不久就和美国国防部 / DARPA 合作。
3. 工程师文化 + 高度垂直一体化 + 极致降本：
   - 不只造火箭，还造卫星、搭卫星平台、提供交钥匙方案；
   - 卫星核心子系统和零部件（星象追踪器、反作用轮、通信、分离、光伏、太空软件）自研自产并对外销售；
   - 一体化能力大量通过并购获得：收购 Geost 获光电 / 红外能力，收购 SolAero 获抗辐射光伏电池及阵列。

**关键指标与数据来源**：定位差异、政府合同、自研子系统清单、并购标的。

**判断标准**

- 三要素缺一不可：没有差异化定位就是“小号龙头”；没有客户扶持就没有订单入口；没有垂直一体化与降本就难以盈利。
- 需求方扶持二供的逻辑，使二线公司在龙头之外有“制度性的生存空间”。

**海豚案例**

- 商业航天《SpaceX 的挑战者们》（2026-04-08）：Rocket Lab 的三大成功要素——差异化定位（公交车 vs 出租车）、国防客户对二供三供的需要、垂直一体化与并购整合。

**适用场景与注意事项**：适用于寡头市场中二线公司的评估。“需求方扶持二供”的逻辑也适用于国防、半导体设备等行业。

### 8.7.13 重资产整机龙头 vs 轻资产 IP 授权追赶者：跟踪授权伙伴的产能进度

**方法要点**：当赛道里并存“一体化整机龙头”与“轻资产 IP 授权追赶者”两种商业模式时，评估追赶者的关键不在技术先进性，而在授权伙伴的量产时间表，因此要逐个跟踪伙伴的产能落地。

**操作步骤 / 拆分口径**

1. 描述格局：SOFC 为“一超多强”，BE 份额 60%-80%，优势来自技术与系统集成壁垒、量产能力、90-120 天交付速度和客户生态。
2. 分析追赶者模式差异：英国 Ceres Power 凭第三代 MSC 技术走“轻资产 IP 授权”，自己不建大型整机厂，把 SteelCell 授权给全球制造巨头，形成制造网络。
3. 逐个跟踪授权伙伴的产能落地：
   - 斗山：已建成 50MW 年化产能，2025 年 7 月启动量产；
   - 台达：投资生产基地，2026 年底投产；
   - 潍柴动力：持股约 20%，获电堆制造许可，是国内产业化最快的企业；
   - 电装、Thermax 等也已获授权。
4. 评估追赶者的关键：授权方的量产时间表，而不只是技术先进性。
5. 补市场规模：用 IDTechEx 数据，2024 年全球 SOFC 约 10 亿美元，基数小但处在爆发前夜。

**关键指标与数据来源**：份额、授权伙伴年化产能（MW）、投产时间、持股比例、市场规模（IDTechEx）。

**判断标准**

- 授权伙伴产能落地越快、数量越多，追赶者的制造网络越成型。
- 授权模式的风险在于伙伴执行力和收入确认滞后。

**海豚案例**

- 燃料电池 / 燃气发电《AI 电荒突围》（2026-04-14）：BE vs Ceres 授权网络（斗山、台达、潍柴、电装、Thermax），逐个核对伙伴产能与投产时间。

**适用场景与注意事项**：适用于技术授权模式与一体化模式并存的赛道。授权模式的风险在于伙伴执行力和收入确认滞后；商业模式的收入口径见 9.1、9.3。

**本节速查清单**

- [ ] 追赶者是否通过“技术是否先发、量产与生态壁垒能否跨过、有无配套主业牵引”三问
- [ ] 追赶者是在领先者框架内“抄答案”，还是“换解题思路”；关键硬件是否外采、是否隔代竞争、有无不可复制的差异化能力
- [ ] 比较的代际是否正确（先比所对标的那一代，再看竞品下一代并前瞻再下一代），理论指标追平之外是否核查了工程实现、自研全栈、成本、迭代速度
- [ ] 核心参数是否横向并排，技术是否已下放到走量价格带，份额是否仍在流失；竞品是否已追平代差、龙头溢价（ASP）能否维持
- [ ] 里程碑、研发周期和时间差是否已对标，失败事件是否区分了工程细节与原理性问题
- [ ] 技术是否“独有”，各厂时间表是否列齐，并用上一代进度差外推下一代，信息源是否交叉验证
- [ ] 追赶者的成本潜力与跨行业类比是否考虑了出口管制等约束
- [ ] 是否用龙头的理性选择反证过竞对方案，并叠加了资本背书修正
- [ ] 后来者是否具备差异化定位、客户二供 / 三供扶持、垂直一体化与降本三要素

## 8.8 国产替代、自研与供应商可替代性

> 本节导读：本节回答两类问题。一类是“国产链能不能替代海外方案”：从成本（同等算力 TCO）、上游卡点（EDA-光刻-代工）、区域供应链约束下的妥协路线、架构创新对 EUV 依赖的换算，到细分行业的国产厂商排名与集中度；另一类是“关键供应商能不能被客户替换”：从客户在其他部件上的多供应商行为、供应商路线图、大客户整机自产与外采计划来判断供应商份额风险与替补机会。壁垒的构成与可击穿性见 8.5，追赶者评估见 8.7（本节只处理国产与自研 / 外采专项）；政策与管制风险见 10.3，选股落地见 11.3。

### 8.8.1 按同等算力的总拥有成本（TCO）比较国产与海外芯片

**方法要点**：比较国产与海外芯片不看单卡价格，而看“实现同等算力的总成本”，把需要更多芯片带来的功耗、机柜、配套网络设备都算进去，据此判断国产芯片在需求端的真实竞争力。

**操作步骤 / 拆分口径**

1. 设定目标算力，分别算出国产与海外方案所需芯片数（国产单卡较弱，需要更多颗）。
2. 逐项计入额外成本：
   - 电力功耗；
   - 机柜占用；
   - 配套的服务器机头、路由、交换机。
3. 公式示意：同等算力 TCO = 芯片采购成本 + 配套设备（服务器机头、路由、交换机）+ 机柜占用 + 电力功耗；其中芯片数 = 目标算力 ÷ 单卡有效算力。
4. 考察国产侧的改善：单卡算力提升，大规模组网弥补单卡短板，总成本开始具备优势。
5. 叠加外卡采购的合规风险，判断客户是否开始切换。

**关键指标与数据来源**：同等算力所需芯片数；功耗；机柜；网络配套成本。

**判断标准**

- 以总成本而非单卡价为准：国产总成本低于或接近海外方案，即具备相对成本优势。
- 推理链条：同等算力需更多国产芯片，带来额外电力、机柜、机头 / 路由 / 交换机成本 → 随国产单卡算力提升、大规模组网弥补单卡短板，总成本开始具备优势 → 叠加外卡采购的合规风险，中国云厂已开始切换一部分算力采购 → 至少在推理端，国产芯片已有相对成本优势，从需求角度给了国产芯片较大的出货空间。

**海豚案例**

- 百度（2026-09-07）：不看单卡价格，按实现同等算力的总成本比较国产与海外芯片，结论是至少在推理端国产芯片已有相对成本优势，需求角度给了国产芯片较大的出货空间。

**适用场景与注意事项**：适用于替代品的成本比较（芯片、设备、能源）。TCO 口径要写明（是否含网络、机柜、电力），推理与训练场景需分别评估。

### 8.8.2 上游“卡脖子”清单逐项评估：EDA - 光刻 - 代工

**方法要点**：评估国产算力产业链的约束，先给共识（性能落后与弥补手段），再沿“设计工具 - 光刻设备 - 制造产能”逐项列出上游限制及其国产化程度，找到最关键的卡点。

**操作步骤 / 拆分口径**

1. 先给共识：国产 GPU 单核性能普遍落后 NVIDIA / AMD 一至两代，常用 Die-Die / GPU-GPU 数量堆叠与互联弥补，但无法消除工艺差距。
2. 逐项列上游限制：
   - EDA：华大九天国内份额约 15.7%、全球仅 2-3%，尚无数字 IC 全流程套件；美国对 7nm 及以下高端 EDA 严格管制；
   - 光刻：依赖 ASML DUV 进口，2025 年加速采购对冲管制；EUV 出口管制是最关键卡点；
   - 代工：先进制程（N+2 7nm、N+3 5nm）稀缺，主要在中芯国际，多数设计厂排队等产能；华虹小规模量产，良率与产能待验证。
3. 每项都标明份额、来源、进展状态，最后指出最关键的卡点。

**关键指标与数据来源**：国产 EDA 份额、光刻设备来源、先进制程产能与良率。

**判断标准**

- 越上游、越受管制的环节，越是真正的瓶颈；堆叠与互联可以弥补性能，但不能消除工艺差距。
- 推理链条：设计工具受管制 → 设备（尤其 EUV）受管制 → 先进制程产能稀缺且集中 → 国产 GPU 即便用堆叠与互联弥补，也只能在工艺差距下运行。

**海豚案例**

- 壁仞科技《壁仞：国产 “英伟达”，到底 “几斤几两”？》（2026-06-18）第 2 节：给出国产 GPU 落后一至两代的共识，逐项评估 EDA（华大九天）、光刻（ASML DUV / EUV）、代工（中芯国际、华虹）的卡点。

**适用场景与注意事项**：适用于国产替代产业链的约束分析。数据需注明时点，管制与产能进展变化较快；EUV 依赖的绕行路径见 8.8.4，管制与地缘风险见 10.3。

### 8.8.3 识别中国市场因先进封装产能受限而选择的“妥协路线”，评估其对海外龙头在华渗透的影响

**方法要点**：分析技术路线时，单独考虑区域供应链约束；当本土大厂缺先进封装产能、又面临生态壁垒时，会选择折中方案作为当前重点，进而改变海外龙头在中国市场的渗透。

**操作步骤 / 拆分口径**

1. 识别被卡住的环节：先进封装、单芯性能。
2. 找本土可行的替代路径：NPO 近封装光学、超节点互联（华为自定义的 UB 协议、自有交换机、超强互联能力）。
3. 评估本土路线能持续多久，以及对外资份额的影响。
4. 判断路线定位：海豚君判断 NPO 不是终极方案，但可能在较长时间内成为中国数据中心的主流，从而一定程度上影响英伟达等美系方案在中国的渗透。
5. 以 DC 互联思路延伸假设：单芯差距大，但互联可以弥补；Scale-up 域在常见组网方案中只纳入 xPU，华为是例外。

**关键指标与数据来源**：先进封装产能可得性、本土厂商的路线选择、外资方案在华份额、本土协议与交换机能力。

**判断标准**

- 若区域约束使本土主流方案偏离全球终局方案，则需单独预测本土路线的持续时间，并相应修正海外龙头在华份额。
- 推理链条：阿里、华为等缺先进封装产能 + 生态壁垒 → 选择 NPO 作为当前重点 → NPO 可能在较长时间内成为中国数据中心主流 → 一定程度影响英伟达等美系方案在中国的渗透。
- 本土方案性能差距要用后续方案对比来验证。

**海豚案例**

- 光互连《AI 超连接时代：AI 向 “光” 飞奔？》（2026-06-03）：NPO 是阿里、华为在缺先进封装产能下的妥协方案。
- 光互连《“‘铜’ 牛夫人” 不走！CPO》（2026-06-24）：把中国大厂列为第三阵营。
- 数据中心互连《AI 时代 DC 互联》（2026-09-08）：以“真有中国机会吗”作为系列核心问题，并指出常见组网方案中 Scale-up 域只纳入 xPU，华为是例外；切入点是华为自定义的 UB 协议、自有交换机和超强互联能力。

**适用场景与注意事项**：适用于受出口管制或产能封锁影响的科技赛道。需警惕政策变动导致路线快速切换；本土方案的性能差距要用后续方案对比来验证。技术路线谱系见 6.1.1。

### 8.8.4 架构创新对 EUV 依赖的换算：设计规则放宽 ≈ 节省几代制程，评估受管制厂商的追赶路径

**方法要点**：把“架构换密度”换算成“省了多少代制程、少依赖多少光刻”，用来判断无法获得 EUV 的厂商能否靠架构创新缩小技术代差。

**操作步骤 / 拆分口径**

1. 取外部估计的设计规则放宽幅度：引用 UBS 估计，首代 4F² 带来的制程精度放宽约 30%，相当于省出约两代制程进步；首代 4F² 节点电容壁尺寸大致与 1c 节点相当。
2. 与现有路线对比：6F² 继续微缩越来越依赖 EUV 或更复杂的多重曝光（DUV 多重曝光成本与良率压力逐代上升），而 4F² 可以不缩线宽就拿到密度提升。
3. 识别附带收益：电容不必做得过于“细高”，高深宽比刻蚀与薄膜沉积压力减轻。
4. 对无法获得 EUV 的厂商（长鑫）判断追赶路径，并提示一次性红利属性。

**关键指标与数据来源**：设计规则放宽幅度（约 30%）、等效制程代数（约两代）、电容深宽比、光刻需求；来源：UBS 产业调研。

**判断标准**

- 换算口径：设计规则放宽约 30% ≈ 省出约两代制程进步；节点对标（首代 4F² 电容壁尺寸 ≈ 1c 节点）。
- 推理链条：6F² 微缩越来越依赖 EUV 或多重曝光，成本与良率压力逐代上升 → 4F² 不缩线宽就拿到密度提升 → 对无法获得 EUV 的厂商是关键的缩小代差路径。
- 必须提示该红利是一次性的，并不改变后续节点继续对光刻的依赖。

**海豚案例**

- 长鑫科技《长鑫把晶体管「竖起来」：绕开 EUV 的追赶路，会撼动存储三巨头吗？》（2026-10-16）：4F² 是绕开 EUV 的追赶路径；引用 UBS 估计首代 4F² 放宽约 30% 精度，相当于省出约两代制程，并识别电容深宽比、刻蚀与沉积压力减轻的附带收益。

**适用场景与注意事项**：适用于受设备管制的中国半导体厂商追赶可行性评估（DRAM、逻辑、先进封装）；需警惕一次性红利属性。技术路线的对比见 6.1，其他厂商时间表的“是否独有”检验见 8.7.9。

### 8.8.5 连接器格局：CR10 集中度趋势 + 龙头并购补短板 + 国产厂商排名追踪

**方法要点**：对细分行业的国产替代，按“门槛 → 龙头梯队 → 集中度趋势 → 龙头的战略应对 → 国产追赶者的排名与阶段”的顺序做格局分析。

**操作步骤 / 拆分口径**

1. 门槛：高速连接器对导电性和机械强度要求严苛。
2. 龙头梯队：安费诺、泰科电子长期占据第一梯队，凭技术积累并与芯片厂商（如 Credo）协作，形成从芯片到组装的完整方案。
3. 集中度趋势：连接器市场 CR10 从 2013 年的 60% 降到 2023 年的 50%，竞争更充分、更分散。
4. 龙头的战略应对：面对光进铜退，龙头正通过收购补充光连接能力。
5. 国产追赶者的排名与阶段：立讯精密进展较快，2023 年市占率升到全球第六；沃尔核材、兆龙互连正在上量。

**关键指标与数据来源**：CR10、全球排名、市占率、上量阶段。

**判断标准**

- CR10 下降说明格局更分散，为追赶者留出空间；但龙头通过并购补短板，会削弱这一窗口。
- 国产厂商以“全球排名 + 上量阶段”衡量，而不是只看“是否进入名单”。

**海豚案例**

- AWS《AWS 图省事…》（2026-10-12）、《AWS 组网靠「买」…》（2026-10-13）：连接器格局分析——安费诺、泰科第一梯队；CR10 从 2013 年 60% 降到 2023 年 50%；龙头通过收购补光连接能力；立讯精密 2023 年升至全球第六，沃尔核材、兆龙互连正在上量。

**适用场景与注意事项**：适用于国产替代型细分行业的格局分析。集中度趋势是“长期结构”而非短期景气，需与国产厂商的实际上量进度一起判断。

### 8.8.6 拆交换环节：Scale-up 走向自研、Scale-out 仍以采购为主；看价值占比与份额集中度，按毛利分层选有定价权的公司

**方法要点**：对 CSP 自研冲击下的供应商护城河，先分层判断“自研还是外采”，再看价值占比与份额集中度，最后按毛利分层筛选享有定价权的公司。

**操作步骤 / 拆分口径**

1. 分层判断自研与外采：
   - Scale-up 层：行业趋势是自研交换芯片，以配合自研协议（通用芯片的劣势已在 Helios 对比中体现）；
   - Scale-out 层：仍以采购为主；CSP 虽然在各环节推进自研，但高端交换芯片仍以博通、Marvell、英伟达为主，说明 SerDes IP、协议协同设计和软件栈形成的壁垒较为稳固。
2. 看价值与格局：据 Bernstein 测算，交换芯片约占交换机模组价值量的 30%，是交换机产业链中技术壁垒和价值量最高的环节；份额上博通约 70%，Marvell 约 15%，英伟达约 10%。
3. 看毛利分层：交换芯片毛利率约 50-70%；品牌交换机（Arista、思科、英伟达）毛利率超过 60%；白牌 ODM 交换机只有 10%-20%。
4. 结论：选高端芯片和品牌交换机这类享有定价权的厂商，即博通、Marvell、思科、英伟达、Arista。

**关键指标与数据来源**：交换芯片价值占比（30%）、份额（70% / 15% / 10%）、毛利率（芯片 50-70%、品牌交换机 >60%、白牌 10-20%）；来源：Bernstein。

**判断标准**

- 自研 / 外采分层：Scale-up 自研趋势强，Scale-out 以外采为主，各自的护城河来源不同。
- 价值占比高 + 份额集中 + 毛利高 = 享有定价权；白牌 ODM 毛利低，说明无定价权。
- 推理链条：高端交换芯片在 CSP 自研下仍以博通、Marvell、英伟达为主 → SerDes IP、协议协同设计和软件栈壁垒稳固 → 价值占比与毛利最高的环节与品牌交换机享有定价权。

**海豚案例**

- AI 组网《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：交换环节的自研趋势、份额与毛利分层，选出博通、Marvell、思科、英伟达、Arista 为有定价权的公司。

**适用场景与注意事项**：适用于判断 CSP 自研冲击下供应商的护城河。数字依赖 Bernstein 测算，需标注来源口径；价值链利润分配的一般方法见 2.4。

### 8.8.7 从客户在其他部件上的多供应商行为，推断关键芯片供应商的可替代性

**方法要点**：用客户在其他核心部件上的多供应商策略，推断本环节的份额风险；同时指出这块增量只存在于什么场景，避免高估。

**操作步骤 / 拆分口径**

1. 确认当前供应格局：谷歌 Scale-Out 交换机里的交换 ASIC 目前主要由博通供应。
2. 查客户在其他核心部件上的行为：谷歌对待 TPU 供应“三心二意”，引入了联发科。
3. 推断：不能排除谷歌之后与 Marvell、Astera Labs 合作；这块增量只存在于超出 ICI 域的场景。
4. 同理推 AWS：AWS 买标品意味着供应链高度多元；Trn3 交换芯片的核心供应商是 Astera Labs，但下一代交换托盘芯片可能转向高通，Trn4 可能用 NVSwitch 或 AMD 体系的 UALink 芯片。

**关键指标与数据来源**：供应商数量、客户历史上的多元化行为、下一代设计导入情况。

**判断标准**

- 客户在其他部件上的多供应商行为越明显，本环节供应商的份额风险越大。
- 推理链条：谷歌对 TPU 三心二意（引入联发科）→ 交换 ASIC 也可能引入 Marvell、Astera Labs；AWS 买标品、供应链高度多元 → Trn3 用 Astera Labs，下一代交换托盘芯片可能转向高通，Trn4 可能用 NVSwitch 或 UALink。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：谷歌 Scale-Out 交换 ASIC 主要由博通供应，但客户在 TPU 上引入联发科，不能排除之后与 Marvell、Astera Labs 合作，且增量只存在于超出 ICI 域的场景。
- AWS《AWS 组网靠「买」…》（2026-10-13）：AWS 买标品意味着供应链高度多元，Trn3 交换芯片核心供应商是 Astera Labs，下一代交换托盘芯片可能转向高通，Trn4 可能用 NVSwitch 或 AMD 体系的 UALink 芯片。

**适用场景与注意事项**：适用于大客户集中度高的硬件供应商风险评估。多供应商推断属于“行为类比”，需配合下一代设计导入的实际进展验证。

### 8.8.8 用供应商芯片路线图推演客户方案的性能改善节奏，并评估客户的自主权

**方法要点**：当系统厂商的关键芯片外采时，供应商的路线图直接决定客户方案的端口数、跳数和升级节奏，因此可以用供应商路线图推演客户方案，并据此判断客户的自主权；反过来，也能得出供应商的代际出货节奏。

**操作步骤 / 拆分口径**

1. 明确问题根源：交换侧的多跳、多平面，都是因为交换芯片端口数太少。
2. 按代际推演（以 AWS Trn3 生命周期内迭代三代、只换交换托盘里的 Scorpio-X 为例）：
   - 第一代 160 通道 PCIe 6.0：每柜 4 个平面，柜内最长 3 跳、跨柜 4 跳；
   - 第二代 320 通道：端口翻倍，平面从 4 个减到 2 个，托盘内相邻芯片仍经 Scorpio-P 互连；
   - 第三代 72+ 端口 UALink 交换机：每颗交换机能接到柜内每一颗 Trn3，柜内全互连、1 跳，跨柜仍需 2 跳；计算托盘内的交换芯片不再是必经中转，但仍在成本里。
3. 评估自主权：AWS 的端口数、跳数、升级节奏都取决于供应商。
4. 推演差距：缺乏自主权意味着 Trn4 与其他厂商的差距可能进一步拉大。
5. 反推供应商：给出供应商（ALAB）的代际出货节奏。

**关键指标与数据来源**：各代交换芯片的通道 / 端口数、平面数、跳数。

**判断标准**

- 客户方案的性能改善节奏由供应商路线图决定 → 客户缺乏自主权。
- 通道与端口数翻倍 → 平面数减少 → 跳数下降，是评估性能改善的核心链条。
- 同一份路线图既评估客户方案，也可反推供应商各代产品的放量时点。

**海豚案例**

- AWS《AWS 图省事…》（2026-10-12）、《AWS 组网靠「买」…》（2026-10-13）：用 Scorpio-X 三代路线图推演 Trn3 生命周期内的跳数与平面变化，指出 AWS 缺乏自主权，Trn4 与其他厂商差距可能进一步拉大，并反推 ALAB 的代际出货节奏。

**适用场景与注意事项**：适用于评估依赖外采关键芯片的系统厂商，也能反推上游供应商各代产品的放量时点。需要获取供应商公开的产品路线图，路线图兑现情况仍需跟踪。

### 8.8.9 跟踪大客户整机自产 / 外采计划与供应商份额，识别交付不及预期带来的替补机会

**方法要点**：由大客户主导的定制硬件链，要把总需求拆成“自产 / 外采”，再把外采份额分配给各供应商，核对交付偏差，从而识别替补供应商的机会。

**操作步骤 / 拆分口径**

1. 总需求台数。
2. 自产 / 外采拆分：谷歌 2026 年 OCS 规划自产 12,000-14,000 台、外采 6,000 台。
3. 外采份额分配：外采由 Lumentum 和另一家（大概率是 Coherent）平分。
4. 供应商交付偏差：因实际出货未达预期，谷歌已向采用压电陶瓷技术（DLBS）的 Polatis 下单。
5. 替补供应商与国内链：
   - 光迅科技：国内整机自供进展较快，MEMS 微镜阵列芯片、光纤阵列单元、精密耦合封装工艺都是全栈自研；
   - 光库科技：谷歌的代工厂主要是国内的光库科技，市场普遍认为其占谷歌 MEMS-OCS 采购份额七成以上。

**关键指标与数据来源**：自产 / 外采台数、供应商份额、出货达成率；数据多来自产业链调研。

**判断标准**

- 大客户的外采计划与实际交付偏差越大，替补供应商机会越明显。
- 推理链条：总需求 → 自产 / 外采拆分 → 外采份额分配 → 出货未达预期 → 大客户引入新供应商（Polatis）。

**海豚案例**

- 谷歌《叫板英伟达霸权…》（2026-09-21）：2026 年 OCS 规划自产 12,000-14,000 台、外采 6,000 台，外采由 Lumentum 与另一家（大概率 Coherent）平分；因实际出货未达预期，向采用压电陶瓷技术（DLBS）的 Polatis 下单；国内光迅科技全栈自研 MEMS-OCS 整机，光库科技为谷歌代工厂、份额七成以上。

**适用场景与注意事项**：适用于由大客户主导的定制硬件链。数据多来自产业链调研，需与公司披露交叉验证；供给端的产能与份额追踪见 4.2、4.3。

**本节速查清单**

- [ ] 国产与海外芯片是否按“同等算力总成本”（含功耗、机柜、网络配套）比较，推理与训练是否分开
- [ ] 是否逐项评估了上游卡点（EDA、光刻、代工），标明份额、来源与进展，并找出最关键的卡点
- [ ] 区域供应链约束下，本土主流路线是否属于“妥协方案”，持续时间与对海外份额的影响是否评估
- [ ] 架构创新对光刻依赖的换算（设计规则放宽 → 等效制程代数）是否有外部估计支撑，并提示一次性红利属性
- [ ] 细分行业是否按“门槛 - 龙头梯队 - 集中度趋势 - 龙头应对 - 国产排名与阶段”完成格局分析
