## 17.1 财报点评标准模板（完整版与行业变体）

> 本节导读：本节是海豚君完整财报点评的成文模板库。先给出适用于所有公司的“六段式主干”及各部分的写法（开篇、要点、一览表、观点、关注点、详细分析、回溯），再按行业给出变体（互联网与消费、半导体与IP、综合集团、车企、零部件、“传统主业加AI叙事”）和固定的“投资逻辑框架/认识公司”章节，最后用一张行业对照表速查各行业的要点顺序。写点评时先套主干，再按行业换要点顺序与详细分析章节；观点内部的推理链条见 13.1，估值段怎么算见第12章，火线速读与跟进文见 17.2，系列化追踪、纪要与固定组件见 17.3。

### 17.1.1 六段式主干骨架：开篇定性 → 编号要点 → 指标一览 → 海豚君观点 → 详细分析 → 历史回溯

**方法要点**：海豚君几乎所有季度财报点评都落在同一条主干上，把“30秒读完结论”（前半）与“逐项核对数据”（后半）分开：前半让读者立刻抓住 beat/miss 与核心矛盾，后半留给需要查证的人。主干固定，行业变体只替换要点顺序和详细分析章节。

**操作步骤 / 结构**：
1. 开篇：交代发布时间（北京时间、盘前或盘后）、财报期（标明财年与自然季的对应，如“2027财年第一季度（即26Q1）”）和一句话定性（相对预期的 beat/miss、指引、股价反应）。写法见 17.1.2。
2. 编号要点速览（通常4-9条）：每条写成“结论 + 核心指标实际值 + 同比/环比 + 与预期/指引的对比 + 一句归因”。顺序和句式见 17.1.3。
3. 核心数据与一致预期的对比表（“财报详细数据一览”“重要财务指标一览”“业绩指标一览”），多数放在要点末条或要点之后。见 17.1.4。
4. “海豚君观点”（或“海豚研究观点”）：先评价当季，再写市场关注的核心矛盾，给出后续展望（下季或全年、指引解读），最后落到估值（假设、倍数、情景、上行空间）和操作建议。版式见 17.1.5；半导体等硬科技在观点与估值之间单列“市场关注点 a/b/c”，见 17.1.6。
5. “以下是详细分析”：按“收入（分业务）→前瞻指标→毛利率→费用→利润→现金流/Capex→股东回报”展开，每节“结论式小标题 + 数据 + 图”。取舍规则见 17.1.7。
6. 文末：电话会纪要链接、历史财报点评、深度与热评索引，加风险披露，形成追踪链。见 17.3.1。

**关键指标与数据来源**：结构性方法，无固定指标。所用材料是财报与电话会、彭博一致预期（及大行/买方预期，预期基准的选择见 1.1）、公司指引、历史文章库。

**判断标准**：
- 读者能否在前半部分30秒内抓住 beat/miss；要点先行是盘后快速出稿的关键。
- 要点、观点、估值三段不能省；详细分析可以压缩为图表集合（快评场景）。
- 每个要点都完整写出“实际值 → 对比基准 → 原因”三件套（17.1.3）。
- 前后文可回溯：文末链接加引用前期深度结论，保证跨季判断一致。

**海豚案例**：
- 变体 A（经典完整版：速览 → 整体观点 → 市场关注点 → 估值 → 详细分析 → 回溯）：海康（2026-04-18）、AMD（2026-02-04）、Marvell（2026-03-06 / 05-28）、博通（2026-03-05 / 06-04）、戴尔（2026-02-27 / 05-29）。详细分析固定为“一、整体业绩（收入、毛利、费用、利润、EBITDA）；二、分业务；三、其他专题（软硬件拆分、资产负债表等）”，文末附相关文章回溯和风险披露。
- 变体 A′：英伟达（2026-02-26）：核心指标5条 → 整体观点（a 大厂 capex + b 芯片竞争 + c Rubin 进展）→ 估值 → 业务情况、核心指标、业务进展、财务指标四章。SEA（2026-05-12）：要点6条 → 海豚观点分“当季表现、后续展望、估值” → 五章详细解读。（该批14篇均遵循此结构；硬科技公司还会单列“财报之外市场关注的方面 1)2)3)”。）
- 变体 B（三段式：要点速览 → 海豚研究观点 → 详细图表和点评）：唯品会《唯品会：不增收也能增利，只是怕2Q坎难过》（2026-05-21）、拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）、携程《携程：监管“重锤”之后，还能“小而美”吗？》（2026-02-26）、滴滴《外卖大战卷到巴西，滴滴也惨了！》（2026-03-13）。快手系列在要点后加“财报详细数据一览”表，并写“电话会可关注”的提示。

- 变体 K（设问标题的电话会前点评）：全部15篇（网易 2026-02-11、MercadoLibre 2026-02-25、Roblox 2026-05-01 等）：标题设问 → 5-8个编号要点 → 一览表 → 观点 → 详细解读 → 历史文章；电话会前先发点评并预判电话会关注点，随后发纪要；对非紧密跟踪的子业务明确说不展开。网易（2026-02-11）：子业务并非紧密跟踪标的，不做展开，点评中预判电话会需关注《遗忘之海》《无限大》进展；MercadoLibre（2026-02-25）：盘后先涨后跌，大概率是电话会有负面发言，请期待后续纪要；Roblox（2026-05-01）：承诺在社区号定期跟踪高频数据。

**适用场景与注意事项**：适用于任何公司的季度财报点评，尤其是盘后快速出稿；非标准业务（如大模型半年报）要改变要点结构（见 17.1.15）。主干是写作模板，不替代分析：要点与观点里的数字必须来自第2-12章的拆解工作，模板只负责组织。多篇连续跟踪同一家公司时可沿用上季文字并局部更新数字（见 17.1.11），但要检查过时表述。

### 17.1.2 开篇定性与标题写法：一句话讲清“好坏、相对谁、为什么”

**方法要点**：标题用观点或比喻点出核心矛盾，开篇第一段给出发布时点和一句话定性，使读者在前10秒知道“这份财报相对预期怎么样”。定性的分级用语和双维度（当期 × 指引）组合见 17.2.2，业绩定性本身怎么判断见 2.1。

**操作步骤 / 写法**：
1. 标题：用“观点 + 比喻/设问”而不是公司名加“财报点评”。常见三类：比喻定性（“小而美”“老登化”“最后一跌”）；设问点矛盾（“业绩又塌方？”“真成 Dead Duo 了？”“还能‘小而美’吗？”）；口语化定性（车企常用“残了”“空想”“翻身”）。
2. 首句交代时间与口径：北京时间何时、盘前还是盘后、发布哪一季财报（截止某月）；财年与自然季不一致时标明对应关系（如“2027财年第一季度（即26Q1）”）。
3. 一句话定性：整体超/不及预期，预期差主要来自哪里，必要时加“美中不足”式的限定，并交代股价反应（盘后涨跌幅）。典型句式：“在足够低的预期下大体达标”“无惊无喜”“广告一拖三”“表观不错但真实压力大”“低预期下的超预期”。
4. 决定定性的1-2个原因直接点出，不要等到观点段。
5. 需要提醒读者更底层视角时在开篇说明阅读顺序（如酒店“照例先看底层经营数据，再看财务数据”）。

**关键指标与数据来源**：一致预期（彭博、大行、买方）、公司指引、盘后股价；预期基准要和一览表中的版本一致（见 17.1.4）。

**判断标准**：定性必须有基准——“相对谁超/不及”（彭博、买方预期、公司指引）；标题的比喻要与观点段结论一致；定性随时间更新（如上季说“低预期下不错”，本季若预期已抬高要明说）。

**海豚案例**：
- 唯品会（2026-05-21）、拼多多（2026-03-25）、携程（2026-02-26）、滴滴（2026-03-13）：标题用观点加比喻；开头一句话总评交代发布时间和相对预期的总体判断，如《唯品会：不增收也能增利，只是怕2Q坎难过》。
- 华住（2026-05-15）、泡泡玛特（2026-03-25）、Monster（2026-08-07）、沃尔玛2篇、可口可乐3篇：标题用比喻/设问点出核心矛盾；首段为“发布时间 + 财报期 + 一句话定性（超/不及预期 +「美中不足」）”；华住（2026-05-15）开篇点出“照例，在拆财务之前，还是先看最底层的经营数据”；泡泡玛特（2026-03-25）要点8条含指引。
- 理想三篇（2026-03-12、2026-05-29、2026-08-26）：标题用设问加口语化定性（“残了”“空想”“翻身”），导语3-4个要点，每点先给结论再给数字。
- 网易（2026-02-11）、MercadoLibre（2026-02-25）、Roblox（2026-05-01）等15篇：标题用一句话概括矛盾并设问（如“业绩又塌方？”“真成 Dead Duo 了？”，后者即多邻国《指引再暴雷，绿鸟真成Dead Duo了？》），开头交代发布时间与对市场预期的总体判断。
- 台积电《台积电：只吃饼不画饼，当得了带头大哥吗？》（2026-10-15）：开篇先写“核心关注点 a)毛利率拆解 b)业绩指引 c)资本开支”，收入端放后面（月度营收已公布，见 17.3.5）。
- 开篇定性示例：Meta（2026-01-29）“有好有坏，从预期差看惊喜远大于惊吓”；腾讯（2026-03-18）“无惊无喜”；京东《京东：老登“又深蹲”？别急，真快“出坑”了！》“足够低预期下大体达标”；唯品会《唯品会：再现负增长？别怕，有 10% 股东回报救场》“指引已下调，实际更差，控费保利润”。

**适用场景与注意事项**：所有点评。标题的比喻是风格元素，不能替代定性本身；定性句需要可被后文数字证实，避免“好/坏”空泛评价。

### 17.1.3 编号要点速览：每条“实际值→对比基准→原因”，顺序跟随行业

**方法要点**：要点速览是点评的主体信息区，每条把“结论小标题 + 实际数字 + 同比/环比 + 与预期或指引的对比 + 一句归因”写全，使读者不翻正文也能复原当季的核心数据与预期差。

**操作步骤 / 句式**：
1. 条数：4-9条（半导体常用1-5条，互联网/消费5-9条，车企5-6条，导语三要点的车企短版为3-4条）。
2. 单条固定句式：加粗结论句（可含关键数字）→ 实际值 → 同比/环比 → 与彭博/买方预期（或公司指引）对比 → 原因推断（可结合调研、电话会、第三方数据）。结论式小标题如“广告一拖三”“毛利率守住40%”。
3. 通用顺序（互联网/消费平台）：核心经营指标（GMV、用户、订单）→ 收入（分业务）→ 毛利率 → 费用 → 经营利润 → 指引 → 股东回报或现金。
4. 半导体/硬件顺序：整体业绩（收入、毛利率 vs 预期和指引，驱动）→ 分业务 → 核心或前瞻指标（ACV、订单、出货量、量价）→ 费用与资本开支 → 下季或全年指引 vs 预期。
5. 车企顺序：收入（卖车与非核心）→ ASP → 卖车毛利率 → 三费 → 经营利润/净利 → 指引；销量已公布时重心放在单车经济（见 17.1.11、17.3.5）。
6. 酒店/连锁顺序：先经营指标（RevPAR 量价、开店）→ 营收 → 毛利与费用 → EBITDA 或利润 → 指引。
7. 要点位置的灵活用法：最大问题或最大看点放第一条（如把“AI 指引低于预期”放首条、把“全年展望”放首条、把“指引”放首条用于重组公司）；要点末条放“财务核心数据一览”图或电话会纪要链接。
8. 行业特殊要点：硬科技的“核心增量信息”（如英伟达披露的 Commitments、担保敞口）、软件的“口径简介”“股东回报”可单列。

**关键指标与数据来源**：因行业而异，见第15、16章；预期来自彭博/买方预期，指引来自公司。

**判断标准**：每条能回答“比预期好还是差、差多少、为什么”；有多个口径时优先用不受口径影响的指标做结论；对非核心业务只写一笔带过的结论，把篇幅留给预期差最大的几条。

**海豚案例**：
- 标准顺序：唯品会、拼多多、携程、滴滴（2026）：核心经营指标（GMV、用户、订单）→ 收入（分业务）→ 毛利率 → 费用 → 经营利润 → 股东回报或现金，每点给出数值、同比或环比、和彭博预期对比。
- 百度、腾讯、美团、贝壳、网易：「具体来看」1-7条，每条结论式小标题 + 数据 + 预期对比，顺序为分业务收入 → 利润率 → 费用 → Capex/现金流 → 股东回报。
- 华住《华住：甩掉包袱、轻装上阵，还是酒店界的优等生！》：开头一句话定性（增长质量高、销售费用侵蚀利润）→ 要点1-5（RevPAR 量价、欧洲 DH、开店、营收加盟/直营、毛利与费用、EBITDA vs 一致预期）→ 财务一览图。
- 亚朵、华住、古茗、蜜雪、瑞幸、星巴克、嘉信、Circle、Coinbase：4-6条，每条为“结论性小标题 + 关键数字 + 同比/环比 + 与预期或指引对比 + 原因推测（结合调研或电话会）”。
- 英伟达（2026-02-26）核心指标5条：总收入 vs 上调后买方预期、数据中心计算/网络、游戏 vs AMD、核心经营利润、下季指引；《英伟达：下年再飙 70%，算力央行印钞机开到冒烟！》把“核心增量信息 Commitments、Additional Commitments、Guarantees”放在第2条。
- 戴尔《英伟达放量？戴尔：好日子还能更好！》：1.AI 收入 → 2.公司指引（全年指引倒算 Q4）→ 3.经营指标 → 4.ISG → 5.CSG → 6.纪要链接 → 7.数据概要。
- 博通《谷歌“三心二意”，博通独自画饼“难充饥”》：AI 收入与下季 AI 指引放首条，总收入指引、FY26-28 AI 展望及 GW 换算随后；博通《博通 AVGO：大佬 vs 大佬，ASIC 阵营要分家了？》第一条放“最大问题”——AI 指引低于预期，之后才是整体业绩、半导体、软件、费用、存货、VMware 指标和指引。
- Marvell《迈威尔 Marvell：比不了英伟达、撑不起期待，高估值先“挤水分”？》：全年展望放在首位（对比财报前机构预期和英伟达），再写数据中心、经营指标、下季指引及倒推的四季度收入、纪要链接。
- 迪士尼《迪士尼：新官首秀不俗，来自百年老牌的韧性》（2026-05-06）：要点把指引放在第一条（Q3 分部经营利润 +16%，全年 EPS +12% vs 预期 11%，53 周口径）。
- Salesforce 三篇（2026-02-26 / 05-28 / 08-27）：要点1-8，含股东回报、口径简介。

**适用场景与注意事项**：所有点评。切忌把数字堆成流水账：每条必须有“对比基准 + 原因”；财年/自然季、53 周/52 周、汇率、并表等口径要在条内注明（口径清洗见第4章）。

### 17.1.4 指标一览表与图表序列：实际 vs 预期同表，并标明预期来源与调整口径

**方法要点**：要点之外再给一张“实际值 vs 一致预期/指引”的核心指标一览表（图），并在详细部分配上标准化图表序列，使读者在同一口径下看清预期差，同时为跨季对比留下一致的数据结构。

**操作步骤 / 做法**：
1. 表的位置：多数放在要点末条（“关键财务信息一览图”）或要点之后、海豚君观点之前。
2. 列设计：实际值、同比、环比、预期（彭博/买方/大行）、指引。部分篇目加“业绩指标一览 & 订单新增情况”汇总表。
3. 预期来源要写明：彭博预期滞后或失真时改用大行/买方预期并说明（如阿里“彭博预期未更新，改用大行预期”；分众“BBG 失真，另列 CICC 预期”；Coinbase 披露前一日预期、引用 Barclays；Spotify 摘录 Jefferies 预期；蜜雪简评对照 JPM；美图“注明 BBG 偏差，对比机构预期”；Unity“修正彭博一致预期”）。预期基准的选择见 1.1。
4. 调整后口径用脚注说明（如 Marvell“调整后的经营数据中包含 SBC，但主要调整折旧摊销等影响”，见 17.3.4）。
5. 详细部分的图表序列统一为：收入 → 毛利率 → 费用 → 利润 → 分业务；每个结论后紧跟图。
6. 简版或快评可只保留“核心图表一览”或“数据图表附录”。

**关键指标与数据来源**：核心财务指标、分业务收入、费用与利润率；预期列来源标注。

**判断标准**：表内的预期版本与要点一致；预期差不在表里算两遍；非标指标（如 Covenant EBITDA、核心经营利润）在表注中给出口径与调整项。

**海豚案例**：
- 快手系列：要点后加入“财报详细数据一览”表及“电话会可关注”提示。
- 百度、腾讯、美团、贝壳、网易：「财报详细数据一览」表置于“具体来看”之后（17.1.1 变体 C）。
- Airbnb、Costco、Lululemon、Monster、东鹏、农夫、亚朵：“财务核心信息概览图（实际 vs 预期表）”。
- Meta 三篇：6条要点加“业绩指标一览”图；亚马逊、Reddit、Uber 等16篇均在要点后放“重要财务指标一览”图（实际 vs 预期）。
- Palantir 三篇：业绩指标一览（有的篇目附“业绩指标一览 & 订单新增情况”汇总表）；Unity 三篇：业绩指标一览 + 业务介绍附录。
- CoreWeave（2026-08-12）：第5节为“财报核心信息一览”表格；Marvell（2026-08-28）：附6张数据图，并注明“调整后”口径。
- 高通《高通：AI狂热消退，手机何时走出阴霾？》（2026-07-30）：观点后直接附8张数据图；Marvell 2026-08-28 简版：“速览 + 观点 + 数据图表附录”。
- 新东方、多邻国：1-7条要点加“重要财务指标一览表”，再接详细点评。

**适用场景与注意事项**：所有点评。表只做对照，不代替归因；预期口径变化（如买方预期被“预告”拉高）要在表注或要点中解释（预期还原见 1.2）。

### 17.1.5 “海豚君观点”段的版式：从当季到展望到估值再到操作

**方法要点**：观点段是点评的“结论区”，其内部有稳定的排版顺序，把当季评价、指引解读、核心矛盾、估值与操作建议依次写出。观点内部的推理链条与综合结论（如何形成判断）见 13.1、13.2；本方法只讲成文版式。

**操作步骤 / 版式**：
1. 先用一句定性小标题概括（如“好业绩没兜住一个保守指引”“不缺订单，只缺光刻机”“指引爆雷掩不住 AI 雄心，估值逻辑已然生变”）。
2. 当季评价：预期差来源、质量（表观与真实）。
3. 指引展望：管理层指引逐项解读（销量、收入、毛利率、EBITDA、Capex、现金、AI 进度），有全年指引时倒算下季/下半年隐含值（见 9.2）。
4. 核心矛盾/市场关注点：分板块或编号列出（见 17.1.6）；分歧点用数据量化（见 17.2.8）。
5. 近期动态与投资逻辑：事件、竞争、政策、叙事变化（见第11章、第14章）。
6. 估值：假设、倍数、情景、上下行空间（见第12章）。
7. 操作建议：安全垫价格、等待回调到 x 倍、有 x% 空间、观望/击球区，必要时分短期与中长期。
8. 跟踪重点/催化剂，列出下一个验证点。

**关键指标与数据来源**：一览表中的预期差、指引与预期的差距、历史估值区间、同业估值（见 12.2）。

**判断标准**：观点段要回答“市场最关心的矛盾是什么”“当季是否改变了投资逻辑”（见 17.3.7）；估值必须写假设，操作建议必须有价格或倍数条件；利多与利空要同时出现。

**海豚案例**：
- 标准通用版：当季表现 → 后续展望 → 估值（SEA 2026-05-12）；“当季关键信号、后续展望（利好和利空因素）、估值（分部或整体，情景倍数，上下行空间）”（唯品会、拼多多、携程、滴滴）。
- 百度、腾讯、美团、贝壳、网易：预期差总结 → 趋势信号 → 争议点展望 → 估值测算 → 交易策略。
- 互联网/消费（贝壳、阿里、Uber）：当季业绩判断 → 后续展望（分业务）→ 估值与操作建议；阿里（2026-03-19 / 05-14 / 08-21）观点含当季、展望、SOTP。
- 零跑、小米、苹果、歌尔等（2026）：先给整体判断，再写市场关注的核心问题（编号），然后是下季或全年展望、指引解读、估值（情景、倍数、区间、上行空间）和投资建议（安全垫价格）。
- 酒店/茶饮/金融：回答市场最关心的核心矛盾、展望下一阶段、给出估值与操作建议（等待回调至 x 倍、有 x% 空间）。
- 谷歌、亚马逊、奈飞等：当季表现 → 指引 → 核心矛盾 → 估值 → 跟踪重点/催化剂。
- Palantir、Salesforce、阳光电源：当季表现、指引展望、叙事或行业变化、估值与投资判断；Shopify（2026-08-06）、Unity 等：当季表现、下季指引、投资逻辑与近期动态、估值。
- Rivian 两篇：观点 + 指引逐项（销量指引倒算 R2 隐含销量 vs 大行、EBITDA 指引 vs 预期、Capex、智驾进度、现金和外部注资）→ 估值（P/S）。

**适用场景与注意事项**：所有点评。观点段越长越要保持“结论先行”；不要把详细分析的数字搬进观点段重复一遍，只引用决定结论的数字。

### 17.1.6 “市场关注点 a/b/c”与“财报之外”议题板块（硬科技点评的固定中段）

**方法要点**：半导体与硬件公司的点评在“整体观点”之后固定列“市场关注点 a/b/c”（或“财报之外市场关注的方面 1)2)3)”），把真正驱动股价的行业变量（下游资本开支、产能、技术进展、竞争、融资、政策）单独拉出，使一份点评同时回答“公司当季如何”和“行业变量怎么走”。

**操作步骤**：
1. 先用一句定性小标题评价当期、再评价指引（先当期后指引）。
2. 列 a/b/c 三项关注点，常见内容：下游大厂资本开支（汇总各家 capex，判断前低后高）、竞争与份额、产品迭代/制程/技术进展、产能与供给、融资与回购、政策管制。
3. 每项用数据支撑（如合计资本开支、份额推算、代际对比），并明确该变量如何传导到公司业绩。
4. 最后综合 a+b+c 给出判断，再转入估值（当前市值对应某年税后核心经营利润的 PE，对照历史区间和同行）。
5. 软件/互联网公司对应的是“核心矛盾”（传统基本盘 vs 新业务），写法类似。

**关键指标与数据来源**：大厂 capex 合计、份额、代际参数、产能（如 CoWoS 月产能）、历史 PE 区间。

**判断标准**：关注点必须是“能改变估值的变量”而非业务介绍；每一项都要有“已知/未知”判断（见 1.3）。

**海豚案例**：
- AMD《又是雷声大雨点小！AMD 何时才能硬气？》：关注 a. 大厂 Capex（四大合计超 6000 亿，前低后高）；b. CPU 份额（对比 PC 出货和英特尔）；c. AI GPU 代际（MI355 → MI455，Helios 机架）→ 估值 38 倍，对比英伟达和台积电。
- 博通《博通 AVGO：AI 火力全开，英伟达对头更飒？》：a. 大厂 Capex（6600 亿）；b. AI 芯片份额（1 成到 2 成）；c. 产品迭代（TPUv7 对比 B200）。《博通 AVGO：大佬 vs 大佬，ASIC 阵营要分家了？》：a. 客户和 Capex（Anthropic 从整机柜改为芯片销售）；b. AI 芯片进展；c. 网络护城河（Tomahawk 6、Jericho、UEC 对 InfiniBand）。
- 英伟达（2026-02-26）：财报之外三个议题 a) 大厂 capex，b) AI 芯片竞争（份额、自研、AMD-Meta 协议），c) Rubin 进展；综合 a+b+c 判断。《英伟达：下年再飙 70%…》：财报之外 1) 5000 亿融资平台结构，2) Rubin 爬坡与规格，3) 竞争格局。
- ASML《阿斯麦 ASML：AI 慌成一团，“铲子”热火朝天？》：关注点 a. 下游资本开支（逻辑 +20%、存储 +40%，美光上调），b. High-NA 时间表与单价。
- 台积电：CoWoS 产能和出货测算、2nm 与制程迁移、竞争（密度、良率）。
- 中芯国际《中芯国际：逆势加码，国产 AI 芯的“全村希望”？》：a. 资本开支与产能；b. 毛利率与自由现金流；c. 制程进展（N+2、N+3）。
- 美光《美光 MU：AI 带动存储“疯涨”，能破周期“紧箍咒”吗？》：a. 传统存储周期与推理需求；b. AI 存力与内存墙；c. capex 上调及 FY27 后可能回落。
- 应用材料：a. 晶圆厂资本开支；b. 存储占比，以及 AMAT（DRAM）与拉姆研究（NAND）的暴露对比。
- 英特尔《英特尔：AI CPU 火热造势，“冰冷”指引浇灭了期待？》：a. CPU 份额、b. capex（美国政府注资）、c. 代工及制程（18A 良率、备选方案逻辑）。
- 高通：a. 传统基本盘（手机出货、苹果 vs 安卓、存储短缺传导链）；b. AI 领域（OpenAI 合作、AI PC、AI 数据中心 AI200/250）。
- Marvell《迈威尔科技 Marvell：ASIC 单卡扑空，靠互联杀回 AI！》：a. 大客户 Capex 对比数据中心增速（推断份额）；b. AI 芯片份额约 1%；c. 收购 Celestial AI 和 XConn。
- 苹果《iPhone炸场、Gemini助攻，苹果AI时代真来了？》：财报之外关注（Gemini 合作、新品加量不加价、Siri 升级）。

**适用场景与注意事项**：适用于量价、产能、资本开支数据明确的硬科技；用于互联网/消费时把 a/b/c 换成用户、GMV、竞争口径。关注点不宜超过三项，否则稀释重点。

### 17.1.7 详细分析章节的组织：按业务分节、结论小标题加图，以及什么时候压缩

**方法要点**：“以下是详细分析”是要点与观点的数据后盾，按“整体业绩 → 分业务/地区 → 专题”分节，每节先给结论式小标题，再给数据与图。不同场景（完整版、快评、非紧密跟踪业务）有明确的取舍规则。

**操作步骤**：
1. 主干分节：一、整体业绩（收入、毛利、费用、利润、EBITDA）；二、分业务；三、其他专题（软硬件拆分、资产负债表、存货与应收等）。
2. 按行业调整第一节：车企第一节固定为“卖车毛利率”（销量已公布，见 17.3.5）；酒店/连锁先“经营数据”；半导体先“核心数据（收入量价、毛利率拆解、利润）”，再“细分结构（制程、应用、尺寸、地区）”，再“经营数据（费用、存货与应收、EBITDA）”。
3. 每一节先写结论式小标题，再列数据与图；调整后口径加注释。
4. 压缩规则：非紧密跟踪的子业务只给图不展开并明说；快评把详细部分简化为“核心图表一览”或“数据图表附录”；要点、观点、估值三段保留。
5. 在详细分析前如有口径/架构变化，单列“财报新口径”一节（阿里）或“认识公司”（见 17.1.10）。
6. 公司逻辑没有大变化（距上次深度/年报很近）时只做简要点评（见 17.2.6）。

**关键指标与数据来源**：按业务拆分的收入、毛利率、费用、利润；第15、16章各行业指标。

**判断标准**：详细部分的每个结论必须能被图表直接验证；章节顺序遵循“信息增量大的在前”（见 17.3.5）。

**海豚案例**：
- 中芯国际（2026-02-10）：一、三大核心指标（收入/毛利率/产能利用率）；二、业务层面（下游/尺寸/地区）；三、经营数据（经营开支/存货应收/EBITDA）。
- 网易有道、云音乐、严选：非紧密跟踪，只给图不展开；网易 Q2 用“重点图表”替代详细分析；网易（2026-02-11）明确子业务不做展开。
- Monster（2026-08-07）：详细部分仅放“核心图表一览”。
- 应用材料 Q3、ASML Q3、美光 Q4 快评：详细部分简化为图表集合；高通 2026-07-30：观点后直接附8张数据图。
- Shopify（2026-08-06）：重点图表分 GMV&GPV / MRR / 营收 / 毛利率 / 费用&利润。
- 阿里（三篇）：在详细解读前单列“财报新口径”一节；Uber《Uber：业绩都在线》（2026-05-07）：核心图表三节。
- 微软三篇：口径变化概览 → 分板块 → 合同 → Capex → 利润；甲骨文三篇：业务分类介绍 → OCI → RPO → Capex 与负债 → 其他板块 → 整体。

**适用场景与注意事项**：所有点评。图表过多会稀释重点，可把低信息量的图放在附录；使用图表时标明数据来源与口径。

### 17.1.8 互联网与消费平台点评模板

**方法要点**：互联网与消费类财报点评采用“开篇定性 → 编号要点 5-9 条（末附关键财务信息一览图）→ 海豚研究观点（当季、展望、估值与操作建议）→ 本季度财报详细解读（按业务板块逐一展开，每段配图）→ 相关研究”的结构，侧重业务板块与分部估值。

**操作步骤**：
1. 开篇一句定性（整体好坏，相对预期）。
2. 5-9 条要点：每条“核心指标数字 + 同比或环比 + 相对预期 + 原因”，最后附关键财务信息一览图。
3. “海豚研究观点”分三块：当季业绩判断、后续展望（分业务）、估值与操作建议（常用分部估值 SOTP，见 12.3）。
4. “本季度财报详细解读”按业务板块逐一展开（收入、利润率、成本费用），每段配图。
5. 文末附相关研究列表（点评、纪要、深度）。
6. 口径重组的公司（阿里）在详细解读前单列“财报新口径”一节。

**关键指标与数据来源**：GMV、用户、订单、变现率（见 15.6、15.8）；分部利润；彭博/大行预期。

**判断标准**：每个板块说清“核心矛盾 + 预期差”；估值按业务属性分部估值，并给出“落袋价位”等操作条件。

**海豚案例**：
- 贝壳《“跪太久”贝壳》（2026-05-20）、《一线再松绑》（2026-08-21）：要点6-7条 → 观点（含估值）→ 一至五节（存量房、新房、二航道、利润、成本费用）。
- 阿里三篇（2026-03-19、2026-05-14、2026-08-21）：要点 → 观点（当季、展望、SOTP）→ 新口径 → 各板块。
- Uber《Uber：业绩都在线》（2026-05-07）：要点 → 观点（当季加指引、近期动态、无人车逻辑、估值）→ 核心图表三节。
- 骨架补充：京东三篇（要点6条 → 观点分“当期业绩 / 业务逻辑 / 估值”→ 详细解读，以图表为主）；滴滴三篇（要点7-8条 → 观点 → 估值方法切换：国内加海外分部 / 集团打包）；B 站三篇（要点6-7条 → 观点 → 五章：用户、广告、游戏与 pipeline、增值服务、盈利）；拼多多三篇（总评 → 要点 → 观点 → SOTP 估值 → 四节）。

**适用场景与注意事项**：适合平台类、消费类公司的复盘或撰写。口径变更、业务重组的公司要先交代新旧口径映射（见 4.4）。

### 17.1.9 半导体、IP 与硬件点评模板（五段式）

**方法要点**：半导体点评是五段式：要点速览 → 整体观点 → 市场关注点 → 估值 → 分项详析（文末回溯），要点与观点用“收入、毛利率对比预期和指引”开场，估值统一用税后核心经营利润的 PE。

**操作步骤**：
1. 开篇固定句式：公司于北京时间何时、盘前还是盘后发布哪一季财报（截止某月）。
2. 要点 1-5 编号：① 收入、毛利率对比市场预期和公司指引，说明驱动；② 分业务；③ 核心或前瞻指标（ACV、订单、出货量、量价）；④ 费用与资本开支；⑤ 下季度或全年指引对比市场预期。ARM、IP 类公司换为“主要数据 → 业务情况 → 核心指标（ACV/RPO/比值）→ 费用 → 指引”。
3. “海豚君整体观点”：先一句定性小标题（如“好业绩没兜住一个保守指引”），再按“先当期，后指引”评价；半导体常加“当季来源”。
4. “市场关注点 a/b/c”（见 17.1.6）。
5. 估值：当前市值对应某年税后核心经营利润的 PE，对照历史区间与同行（见 12.1、12.2）；然后给综合结论。
6. 详细分析：一、核心数据（收入量价、毛利率拆解、利润，核心经营利润公式）；二、细分结构（制程、应用、尺寸、地区；数据中心/客户端/游戏/嵌入式）；三、经营数据（费用、存货与应收、EBITDA）。部分篇目直接附图表。
7. 文末列历史财报点评与同日电话会纪要。

**关键指标与数据来源**：核心经营利润（公式见 8.1）、量价、产能利用率、ACV/RPO、资本开支、历史 PE 区间。

**判断标准**：要点必须包含“收入 + 毛利率 vs 预期/指引”；观点必须给“当期 + 指引”两层；估值必须写假设并对照历史与同行；快评可压缩详析，但“要点、观点、估值”三段不省。

**海豚案例**：
- 中芯国际《中芯国际：逆势加码，国产 AI 芯的“全村希望”？》（2026-02-10）：完整三节结构（三大核心指标、业务层面、经营数据）。
- 台积电《台积电：只吃饼不画饼，当得了带头大哥吗？》（2026-10-15）：要点第一项直接写“核心关注点 a)毛利率拆解 b)业绩指引 c)资本开支”，收入端放后面，因为月度营收已经公布。
- 海力士《海力士：存储告别“暴涨叙事”，LTA 成了“避风港”？》（2026-07-29）：完整财报尚未公布，先基于 presentation 和 call 点评，并注明后续更新。
- ARM、ASML、AMAT、京东方、博通各篇：“要点 → 整体观点 → 关注点 → 估值 → 图表”。
- AMD《CPU“狂飙”》（2026-05-06）、《AMD：狂抢“AI大单”》（2026-08-05）：编号要点（整体业绩、经营费用、各业务细分、业绩指引）→ 整体观点（当季来源、指引、大厂 capex、CPU、AI GPU 进展，估值市值对应远期 PE 及假设）→ 具体分析 1.1 收入、1.2 毛利、1.3 经营费用、1.4 利润（核心经营利润公式），2.x 分业务（数据中心、客户端、游戏、嵌入式）。
- ARM《ARM：AI红利未消》（2026-02-05）、《ARM：“短期波动”难掩锋芒》（2026-05-07）：主要数据 → 业务情况 → 核心指标（ACV/RPO/比值）→ 费用 → 指引 → 观点（指引、ACV、RPO 三项）→ 估值 → 图表。
- 应用材料（2026-05-15）、英特尔（2026-01-23）、阿斯麦（2026-01-28）、高通（2026-02-05）：完整模板；美光《美光：牛气冲天！…》（2026-06-25）：叙事式开头（存力接棒算力）加6个要点再加观点的变体；美光 Q4、AMAT Q3、ASML Q3 的快评详细部分简化为图表集合。
- 高通《这一剂“AI强心针”，够抵消手机的“软肋”吗？》（2026-04-30）：核心数据 → 具体业务 → 经营费用 → 下季指引四要点，观点后分“一、整体业绩 二、各业务细分”，文末列 2025-02 至 2026-02 五组点评 + 纪要；高通《AI狂热消退，手机何时走出阴霾？》（2026-07-30）：观点后直接附8张数据图。
- 宁德《无可撼动的能源时代“台积电”！》（2026-04-16）：①-⑤ 核心数据 + 五大核心指标 + 盈利预测估值 + 详细内容。

**适用场景与注意事项**：适用于所有量价、产能、资本开支数据明确的硬件和半导体公司；用于互联网、消费公司时，核心指标要换成用户、GMV 等口径。个别篇目可在要点第一条放“核心关注点”（月度数据已公布的公司，见 17.3.5）。

### 17.1.10 综合集团与重组期公司：在观点之后加“认识公司”

**方法要点**：对业务架构复杂、刚经历重组的公司，在观点之后单列“认识公司”一节：新旧架构的区别、每个板块的定位和投资逻辑，再放详细业绩图表，使读者在看数据前先建立“这家公司靠什么赚钱、每块业务的角色是什么”的框架。要点部分把指引放在第一条。

**操作步骤**：
1. 要点：指引放第一条，再写分部（流媒体、公园、体育等）、股东回报，末条放指标一览。
2. 海豚君观点：先写宏观与行业背景、管理层信任度（情绪基线，见 1.4）、担忧缓解、催化剂（电影周期、游轮等），再给估值（当前倍数 vs 历史中枢，修复空间）。
3. “认识公司”：新旧架构对照、每板块定位和投资逻辑（稳定现金流、内容周期、成长曲线）。
4. 详细业绩图表。

**关键指标与数据来源**：分部经营利润、指引、板块增速、股东回报率。

**判断标准**：每个板块要有“角色（现金牛/成长/周期）+ 驱动 + 风险”三要素；估值落点要说明“修复到中枢倍数对应的市值”。

**海豚案例**：
- 迪士尼《迪士尼：新官首秀不俗，来自百年老牌的韧性》（2026-05-06）：要点（指引超预期、流媒体、公园、体育、回购、指标一览）→ 海豚君观点（宏观行业不利、管理层信任度低的情绪基线、担忧缓解、催化剂、估值 15 倍和 14 倍，修复到中枢 18 倍即 2100 亿）→ 一、认识迪士尼（新旧架构、投资逻辑框架）→ 二、详细业绩图表。
- 迪士尼《迪士尼：整合期波动难免，等待新成长被激活》：要点 → 观点 → 认识迪士尼（新旧架构对照）→ 投资逻辑框架（体验/娱乐/流媒体/体育）→ 详细业绩图表。
- 谷歌每篇附“谷歌基本介绍 + 基本面长逻辑 a/b”；奈飞附“业绩指标一览”；百度新架构还原旧口径（先说明新架构并还原旧口径，再展开）。

**适用场景与注意事项**：适合多元化集团和重组期公司。“认识公司”只写一次完整版，后续季度可只更新变化部分。

### 17.1.11 车企点评模板：卖车单车经济前置，要点（vs 预期）→ 观点 → 指引倒算 → 估值 → 详析

**方法要点**：车企月度销量先于财报公布，点评把“卖车毛利率/单车经济”作为第一节深挖，其次拆解管理层指引（销量、收入、毛利率），再写收入、费用、利润与现金；估值以“销量 × ASP + 其他收入，乘 P/S”或“销量 × 单车净利 × PE”为主。

**操作步骤**：
1. 导语 3-4 要点（短版）或要点 5-7 条（长版）：收入（卖车与非核心）、ASP、卖车毛利率、费用、经营/净利润（含核心经营利润），每条都有“vs 预期”和原因；服务收入/碳积分/授权收入拉高的整体毛利率要单独指出。
2. 整体判断：定性业绩（不及预期、低预期下不错），说明“当季已打入预期，关键看全年”。
3. 市场最关心的预期：销量指引倒算月销、收入指引倒算 ASP、毛利率指引（见 9.2）。
4. 全年视角：新车 pipeline、战略（AI、机器人）、行业 beta；产品打法主线（如比亚迪的纯电快充、智驾平权、DM6.0 插混防守）；国内销量情景、海外利润贡献。
5. 估值：销量 × ASP + 其他收入，乘 P/S；或中性/乐观两种情景（PE 或 SOTP），对比当前市值（见 12.5）。
6. 详细分析：一、卖车毛利率（单车价格、单车成本、单车毛利）；二、指引；三、整体毛利率；四、三费；五、净利含金量/核心经营利润；之后收入、现金流和在手现金。比亚迪式写法还含单车净利、市占率、海外、高端化、库存。
7. 文末附电话会纪要、历史深度与点评列表。

**关键指标与数据来源**：单车价格/成本/毛利（单车经济见 16.1）、销量指引、ASP、研发/销管用途、核心经营利润、库存天数。

**判断标准**：卖车毛利率要剔除碳积分、服务与授权、一次性项后对比；指引倒算的隐含月销/ASP要与行业订单数据对照；估值要给“安全点（P/S）/中性/乐观”三档。

**海豚案例**：
- 小鹏三篇（2026-03-20、05-28、08-24）：核心数据 6-7 条 → 海豚研究观点 → 一、卖车毛利率（单车经济）→ 二、指引 → 三、整体毛利率 → 四、三费 → 五、净利与核心经营利润。
- Rivian 两篇（2026-02-13、05-01）：关键信息 → 观点和指引 → 估值 → 一、毛利率 → 二、单车经济 → 收入 → 三费 → EBITDA；地平线两篇：核心数据 → 观点 → 指引反推 → 毛利率论据 → 估值。
- 比亚迪三篇（《王座失守…》2026-03-28、《宇宙车厂海外狂飙…》2026-04-28、《国内卷单价…》2026-08-29）：①要点 5-6 条：收入（卖车与非核心）、ASP、卖车毛利率、海外与国内、单车净利（含核心经营利润），每条“vs 市场预期”和原因；②海豚君观点：定性（不及预期或低预期下不错）、“当季已打入预期，关键看全年”、产品打法三条主线（纯电快充、智驾平权、DM6.0 插混防守）、国内销量情景、海外利润贡献；③估值：中性和乐观两种情景（PE 或 SOTP）；④PS 引导回看深度；⑤详细分析：一、毛利率（单车价格、成本、毛利）；二、单车净利（剔除子公司或汇兑、三费、核心经营利润）；三、市占率（插混、纯电、竞品）；四、海外（产能、渠道）；五、高端化；六、库存；⑥历史文章索引。大段文字（产品打法、海外扩张）逐季沿用并局部更新数字，便于做季度对比，需注意更新过时表述。
- 理想三篇（2026-03-12、05-29、08-26）：导语三要点 → 整体判断 → 市场最关心的预期（销量指引倒算月销、收入指引倒算 ASP、毛利率指引）→ 全年视角（新车 pipeline、战略、行业 beta）→ 估值（销量 × ASP + 其他收入，乘 P/S）→ 一、卖车毛利率；二、指引；三、研发和销管费用；四、收入和整体毛利率（含其他业务）；五、现金流和在手现金 → 历史文章索引；蔚来（2026-03-10、05-21）同构；蔚来（2026-09-01）简化为导语要点、指引、全年、估值，详细分析主要放在图表里，并引用电话会纪要《蔚来（纪要）：毛利率守 18.5%，Q4 月销破 4 万》。
- 骨架补充：吉利三篇（5-6 条核心数据 → 观点 → 2026 展望 → 估值：销量 × 单车净利 × PE）；零跑三篇（要点四条 → 海豚君观点：销量与毛利率承压、年度百万指引 → 保守情景 PS 估值 → 详细：毛利率三段拆解、费用）；小米三篇（要点1-6：整体、汽车、手机、IoT、互联网、利润 → 观点 → SOTP）。

**适用场景与注意事项**：可直接复用于整车及类似“量 × 价 × 单位成本”的硬件公司。模板化提高效率，但每季需更新过时的表述与数字。销量已提前公布，不要在“销量”上花篇幅（见 17.3.5）。

### 17.1.12 “传统主业 + AI 叙事”双线模板（特斯拉式）

**方法要点**：对传统主业是现金牛、估值由新业务叙事驱动的公司，点评分两层：第一层是主业预期差定性（卖车毛利率），第二层是新业务（Optimus、Robotaxi、FSD）的里程碑核对、Capex 与现金跑道、估值叙事和股价判断。标题直接点出“主业 vs AI”的矛盾。

**操作步骤**：
1. 要点5条：总收入 → 汽车收入 → 核心卖车毛利率（去碳积分）→ 研发加 Capex → 经营利润，每条对比预期。
2. 海豚君观点第一层：主业预期差定性（如“表观强劲、实际也有韧性”“超低预期下没那么差，没陷入恶性循环”）。
3. 第二层：AI 里程碑台账逐条核对（FSD 用户数与 V14 接管里程、Robotaxi 去安全员与扩张、Optimus V3 与量产节点），并核对 Capex 投向、现金跑道（如不到两年）、估值叙事（汽车不到市值 1/3；乐观 2 万亿）。
4. 详细分析：一、收入（汽车/能源/服务）和分业务毛利率；二、卖车（单车 ASP：分区域促销，车型结构，FSD；单车成本：折旧加可变；毛利率）；三、交付分地区、产销差和库存；四、支出端（研发、SG&A、SBC、经营利润、净利润、FCF、Capex、算力）。
5. 历史文章索引（热点、深度、财报点评、电话会）。

**关键指标与数据来源**：剔碳积分的卖车毛利率（“每个季度最重要的观测指标”）、AI 里程碑时间表、Capex 与现金。

**判断标准**：主业层面看真实卖车毛利率与预期；叙事层面看里程碑是否确认、是否推迟；股价与卖车脱钩时估值锚切换。

**海豚案例**：
- 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：要点5条（总收入超预期 → 汽车收入超预期，靠碳积分和 ASP 降幅小 → 剔碳积分卖车毛利率回升到 17.9% → 研发和 Capex 为 AI 投入，2026 年 Capex 超过 200 亿 → 经营利润超预期）→ 整体观点 → 详细分析一至四 → 历史文章。
- 特斯拉《造车罕见回血，AI宏图又跳票》（2026-04-23）：表观强劲、实际也有韧性；Optimus V3 推迟到年中，Robotaxi 贡献推到 2027 年并要等 V15，Capex 上调到超过 250 亿，现金跑道不到两年。
- 特斯拉《造车硬抗，AI大饼只摊不兑？》（2026-07-23）：真实卖车毛利率 16.3% 大幅低于预期，下半年隐含 Capex 167 亿；汽车不到市值 1/3；AI 里程碑台账逐条核对。三篇结构一致，标题点出“主业 vs AI”的矛盾。

**适用场景与注意事项**：适用于传统主业是现金牛、估值由新业务驱动的公司（如特斯拉，以及带 AI 叙事的硬件公司）。注意“里程碑台账”需沿用上季清单逐条更新（见 17.3.7、13.3）。

### 17.1.13 量增价减型零部件模板（禾赛式）：核心数据 → 核心观点 → 全年拆解 → 估值 → 中长期逻辑

**方法要点**：对“量增、价格下行”的科技零部件，点评以“量 × 价 × 毛利率”为主线：先逐项列出核心数据与预期/指引对比，再给核心观点（点出核心矛盾，如 ASP 下行幅度过大），然后做全年拆解、估值，最后写中长期逻辑和 TAM 对比。

**操作步骤**：
1. 导语逐项列出：收入（vs 指引和预期，是否剔除新业务）、出货量（分 ADAS 和机器人，vs 指引和预期）、ASP（同比、环比、vs 预期，三因子归因）、毛利率（关口和驱动）、核心经营利润（剔除非经常项）。
2. “海豚君核心观点”：定性本季（符合、超预期、低于预期），点出核心矛盾。
3. 全年拆解：出货（ADAS 按客户拆、机器人按产品拆）、ASP（指引倒算加自有预测）、新业务、毛利率、费用。
4. 估值：PE、PEG、P/S。
5. 中长期逻辑：市占率、L3 价值量、海外、机器人、ASP 拐点。
6. TAM 对比市值，并链接深度报告的估值测算；附往期深度与财报文章列表。

**关键指标与数据来源**：出货量、ASP、毛利率、核心经营利润、客户拆分、TAM。

**判断标准**：量价拆分要给“量 vs 预期、价 vs 预期”的双向结论；ASP 拐点用“快速下行到稳态年降”的路径判断；估值用 PE/PEG/P/S 多口径互证。

**海豚案例**：
- 禾赛三篇（2026-03-24、05-19、08-19）结构一致：核心数据 → 核心观点 → 全年拆解 → 估值 → 中长期逻辑；2026-08-19 增加了“ASP 从快速下行到稳态年降的拐点”一节。
- 骨架补充：《禾赛：单价继续狂泻，阵痛期还要熬多久？》导语四要点（收入符合指引偏下限，剔除 SGI 后核心增速 16.5%；量价均低于预期；毛利率守住 40%；经营利润低于预期因新业务研发）→ 核心观点“以价换量之年”→ 全年拆解（ASP 指引倒算并下修到 1268 元）→ 估值（PE 35 倍、PEG 1.8）→ 中长期逻辑 → TAM 对比市值 → 往期文章。

**适用场景与注意事项**：可复用于其他量增价减型科技零部件公司（光模块、功率器件、汽车电子）的财报点评。

### 17.1.14 “投资逻辑框架”固定章节：先讲披露口径、分部属性与占比，再进入数据

**方法要点**：在详细解读之前复述公司披露的分部结构、各分部商业模式属性、占比与增长拆法，写成固定的“投资逻辑框架梳理/认识公司/基本介绍”一节，保证跨季口径可比，后续分部分析都沿这个框架展开。

**操作步骤**：
1. 按公司披露口径列出各部门：收入占比、定位（基石、第二增长曲线、高利润补充、培育期）、核心产品矩阵。
2. 写明关键的利润来源环节（如掌握独家配方的浓缩液子公司）与增长拆法（内生/结构/外汇；同店 = 客流 × 客单 + 新店 + 电商）。
3. 放在观点之后、数据之前；每季沿用并更新占比。
4. 复杂集团配合“认识公司”（17.1.10）；软件/金融在详细分析中先放业务介绍与披露口径。

**关键指标与数据来源**：分部收入占比、分部增长驱动（披露口径）。

**判断标准**：框架能解释“每个分部在利润与估值中的角色”；占比数字与财报披露一致。

**海豚案例**：
- Monster（2026-05-08）：怪兽能量饮料部门约 92%（Original、Ultra、Rehab、Juiced、Java、Muscle），战略品牌约 5%（Predator、Relentless、Mother、NOS，来自 2015 年与可口可乐的资产交换），酒精约 2%，其他为 AFF 对外 B2B；AFF 生产全部浓缩液，是高毛利的关键。Monster（2026-02-27 / 08-07）同。
- Lululemon 三篇（2026-03-18、06-05、09-04）：女装（占比超 60%，业绩支柱）、男装（第二曲线，2026 年翻倍目标）、其他（鞋类、配件，高利润补充）。
- 可口可乐（2026-02-11 / 04-28 / 07-28）：五大部门 × 内生/结构/外汇。
- 沃尔玛（2026-05-22 / 08-21）：三大板块（美国约 68%、国际约 18%、山姆约 13%），同店 = 客流 × 客单 + 新店 + 电商，电商拆 1P/3P/广告/会员。
- 谷歌每篇附“谷歌基本介绍 + 基本面长逻辑 a/b”；迪士尼“认识迪士尼 + 投资逻辑框架”；瑞幸、星巴克用投资逻辑框架开篇；Coinbase、Circle 每篇详细分析先重复主业介绍和业务框架；Unity、Salesforce 等附业务介绍与披露口径附录。

**适用场景与注意事项**：适用于多品牌、多部门公司的财报点评开篇，也可迁移到个股深度。框架只写“稳定的结构”，不写当季数据；变化（如口径调整）要显式标注。

## 17.2 火线速读、短评与跟进文

> 本节导读：本节解决“时间只有几小时、篇幅只有几百字，或者财报之后出现分歧时，文章怎么写”的问题，涵盖火线速读三段式、一句话定性加编号分项、分行业的速读顺序库、事件前后的短文（预告、preview、机构沟通、小会补充、callback）、问题导向短评、快报先行时的双角度写法、大跌热评与专题追问、以及“分歧—优势—保守估值”的论证型写法。完整点评的主干见 17.1，业绩定性怎么判断见 2.1，预期差归因见 2.3，电话会待验证问题见 2.5，把“最大问题”放在开头见 1.3。

### 17.2.1 火线速读三段式：一句话定性 → 编号要点 → 观点与电话会悬念

**方法要点**：财报当天用几百字完成的快评结构。第一句给整体定性并点出决定性的1-2个原因；中段用①②③列3-6个要点；末段给海豚君判断并留出电话会要验证的问题。笔墨集中在预期差最大的1-2点，其他指标一笔带过。

**操作步骤**：
1. 第一句定性：使用分级用语（见 17.2.2）并交代原因，如“达到上调后的买方预期”“有好有坏，从预期差看惊喜远大于惊吓”。
2. “具体来看”用①②③或 1、2、3 列 3-6 个要点，顺序通常是：收入/核心业务指标 → 毛利率 → 费用与利润 → 指引 → 资本开支与股东回报。
3. 每个要点固定写成“实际值 → 对比基准（预期/指引/上季）→ 原因推断”。
4. 末段：海豚君判断（基本盘稳不稳、市场关注点转到哪里），并列出电话会要验证的问题（清单写法见 2.5）；预告后续财报点评与纪要。
5. 开头的“预热动作”：必要时先提示一致预期已过时（改用买方预期）、先交代预告背景、先说明确定性部分（如利息收入）已在预期之内，再分析预期差；对已有高频数据的公司，先写“月度数据已下调预期”。
6. 把本次“最大问题/最大看点”放在开头的做法详见 1.3；点评中预留电话会待验证问题清单详见 2.5。

**关键指标与数据来源**：定性分级用语；每个要点的实际值、预期值与差额；预期来源见 17.1.4。

**判断标准**：篇幅只有几百字，只对预期差最大的1-2点展开；其余指标一笔带过；判断必须能被后续电话会验证或证伪。

**海豚案例**：
- 台积电《(短评)台积电4Q25火线速读》（2026-01-15）：先定性“达到上调后的买方预期”，收入按美元和新台币两个口径，再按①毛利率 ②资本开支 ③经营面指引展开，结论“相当不错”。
- Meta（2026-01-29）：“有好有坏，从预期差看惊喜远大于惊吓”，分当期、收入指引、Opex/Capex 三段（当期不是重点；收入指引是大惊喜；Opex 和 Capex 是小惊吓，与买方预期对比；最后落到叙事反转的看点）。
- 腾讯（2026-03-18）：“无惊无喜”，分创收、盈利能力、资金配置三段（游戏、广告调研、倒算金科 → 推广费用与元宝、毛利率 → Capex 与现金流、分红、股东收益率）。
- 宁德时代（2026-03-09）：用①-⑤分别写收入与出货（动力出货对比新能源车销量）、毛利率与成本传导、产能利用率、Capex、净利（研发、减值、单 Wh 净利）。
- 阿里《(短评)阿里巴巴3QFY26火线速读》：先提示彭博预期已过时；1.中国电商 CMR 与利润，倒算闪购亏损；2.云（外部收入）；3.国际电商（真正的 miss）；4.其他板块 AI 投入（真正的 miss）。
- Unity《(短评)Unity 4Q25火线速读》：当期 beat 但 Grow 指引引发崩盘 → 指引与买方推演对比 → 指引风格修正 → Vector 趋势确定 → Create 超预期。
- Circle《(短评)Circle 1Q26火线速读》：先说明利息收入在预期之内，再分析预期差。亚马逊 1Q26：先看绝对表现，再看预期差；滴滴 1Q26：先看绝对表现，再看相对预期；沃尔玛 1Q27：先看绝对表现，再对照估值。

**适用场景与注意事项**：适用于所有财报当天的快评。时间紧时，宁可少写要点，也要确保每个要点有“对比基准”；不确定的归因要用“推测”标注，留待纪要验证。

### 17.2.2 一句话定性加编号分项：分级用语与“当期 × 指引”双维度定性

**方法要点**：速读开头一句话要同时看两个维度——当期相对预期，以及下季度指引相对预期，把二者组合起来下结论（例如“当期好、指引弱”）；然后用1-5个编号分项逐层展开，结尾落到“市场更关心什么”或下一步观察点。

**操作步骤**：
1. 选定性档位：大超 / 小超 / 符合 / in-line / 小幅 miss / 大幅不及；或描述式：全面超预期、符合预期但平淡、不及预期、冰火两重天、有好有坏、好坏参半、无惊无喜、低预期下的不错。
2. 组合两个维度：当期（收入、利润 vs 预期）× 指引（下季/全年 vs 预期），写出“好+好”“好+弱”“弱+好”“弱+弱”之一，并点明哪一维度决定股价。
3. 编号分项依次写：量价或核心经营指标 → 分业务收入 → 毛利率 → 费用率 → 经营利润 → 指引 → 股东回报。
4. 结尾：市场更关心什么（下一步观察点），并预告后续点评和纪要。
5. 在“预期”上做限定：对股价而言真正的基准常是“上调后的买方预期”而非彭博（见 1.2）。

**关键指标与数据来源**：收入/利润 vs 一致预期、指引 vs 预期、趋势（环比加速/放缓）。

**判断标准**：当期与指引的组合决定文章主轴；当期不错而指引弱的，主轴写“指引”，反之写“当期”；若有全年指引，季度指引不重要（见 9.3）。

**海豚案例**：
- 可口可乐《2Q26火线速读》（2026-07-28）：先说收入、利润全面超预期且全年指引二次上调，再按 1 量价、2 品类、3 毛利与费用、4 指引展开。
- Bloom Energy（2026-07-29）：用①-④分别写 Q2 业绩、毛利率、经营利润、全年指引。
- Airbnb（2026-08-07）：结论是当季和下季预期都不错。
- Rocket Lab（2026-08-11）：当季不错，但下季毛利率和 EBITDA 大幅 miss（当期 × 指引的“好 + 弱”）。
- 其他定性示例（骨架）：Netflix 4Q25“喜忧定性”（喜：Q4 超预期、订阅数；忧：指引平淡、利润率指引偏低）；谷歌 4Q25“好坏参差”；亚马逊 4Q25“业绩不差却大跌”；英特尔 4Q25“当期达标，指引不及预期”；Roblox 1Q26“业绩爆雷”；CoreWeave 1Q26“表现割裂”；Lululemon 4Q25“低预期内的符合预期”；唯品会 4Q25“比下调后的指引更差”；多邻国 4Q25“指引暴雷，对比下调后的预期，当期惯例 beat”；瑞幸、名创、Mercado“增收不增利”；美光《(短评)美光火线速读》“明显好于预期（价格驱动）”；小米 4Q25“与 Preview 一致”。

**适用场景与注意事项**：所有财报速读通用。第一时间写作时先定性，再给证据；定性词要与后文数字一致，避免“好”“差”无基准。

### 17.2.3 速读的行业要点顺序库

**方法要点**：不同行业的速读有稳定的“先看什么、后看什么”。本表给出各行业速读的主线顺序和代表性的“特色动作”，可在写速读时直接选用，再按当季预期差最大的点前置。完整点评的行业顺序见 17.1.15。

**主线顺序表**：

| 行业 | 速读主线（先给定性 → …） | 代表篇目 |
|---|---|---|
| 晶圆厂/设备/存储 | 毛利率对比预期 → capex（全年与来年，倒推剩余季度/隐含 Q4）→ 业绩指引（全年指引时下季不重要，倒推下半年）→ 订单/价格 → 结论或估值 | 台积电 4Q25 / 1Q26 / 3Q26，ASML 4Q25 / 1Q26，中芯 4Q25 / 1Q26 / 2Q26，美光，海力士，应用材料 |
| 芯片/服务器 | 披露口径 → 毛利率 → 指引 → AI 业务估算（剔除某产品）→ 竞争或叙事 | 博通，Marvell，AMD，英伟达，戴尔，高通，ARM，英特尔 |
| 云与大厂 | 绝对表现 → 云（收入、RPO/合约余额）→ Capex（对比预期、同行）→ 利润率与 FCF → 指引 → 股东回报/公司 ROI 账 | 微软 F2Q26 / F3Q26 / FY4Q26，谷歌 4Q25 / 1Q26，亚马逊 4Q25 / 1Q26 / 2Q26，Oracle，Meta，CoreWeave |

**特色动作（可借用的速读技巧）**：
- 双口径收入：台积电同时给美元和新台币两个口径，并与指引对比。
- 订单与季节性均值比较：ASML 4Q25“订单（逻辑与存储，与季节性均值比较）”；1Q26“订单未披露”时转看全年指引倒推下半年。
- 剔除口径再比：AMD 4Q25 估算 AI GPU（剔除 MI308）；Unity Q1 预告“广告（剔除剥离业务、Vector）”；Salesforce“剔除并表影响”；特斯拉 1Q26“先看表观业绩，再剔除一次性因素”。
- 倒算：小鹏 4Q25 / 1Q26 / 2Q26、蔚来、理想的“指引中隐含的月均交付与单价”；阿里“倒算闪购亏损”；台积电 1Q26“capex 倒推剩余季度”；ASML“下半年倒推”；智谱 callback“ARR 指引→隐含月增速”。
- 门槛推算：Unity 2Q26“核心指标门槛推算 → 实际与指引 → 质量拆分”。
- 解释股价：Uber 4Q25“解释跳水（非经营亏损 → 利润率缺陷 → 自动驾驶）”；应用材料《应用材料火线速读》“数据达标 → 盘后跳水归因 → 财年错位推演”；海力士 2Q26“盘后股价归因（LTA）”；高通 Q2FY26“解释为何已被定价（priced-in）”；零跑 1Q26“已被定价的因素”。
- 预期基准提醒：阿里“先提示 BBG 预期已过时”；Unity 1Q26“修正彭博一致预期”；Robinhood 4Q25“月度数据已下调预期，收入 miss，归因融券被线性外推”。
- 收尾：电话会关注点（携程 1Q26、零跑 1Q26）、后续思考框架（Robinhood）、关注 token 消耗（智谱）、估值（戴尔“估值 10 倍与存储担忧”、中芯 1Q26）、催化剂（Spotify 1Q26）。

**判断标准**：速读顺序要服务“预期差最大的点前置”；同一家公司的速读顺序跨季保持稳定，便于读者对比。

**适用场景与注意事项**：表是常用顺序，不是硬规则；遇到口径变化（Marvell“披露口径”、美团“披露口径”、英伟达“披露口径”）或特殊事件（裁员、并购、监管）时先写口径或事件。

### 17.2.4 事件前后的短文：预告、preview、机构沟通、小会补充与 callback

**方法要点**：财报之外还有一类“围绕事件”的短文：业绩预告点评、preview（财报前催化剂与预期）、机构沟通、分析师小会补充、管理层指引回访（callback）、月度/季度数据点评、简评。它们都用“先交代背景/预期，再给逐项判断”的短结构，是系列化追踪（17.3.2）里“财报—电话会—小会”之外的补充环节。

**操作步骤**：
1. 先交代事件背景与口吻：催化剂是什么（预告、剥离、股价回调、沟通口吻），一致预期是否过时。
2. 预告类：对照预告区间定位实际业绩，说明预告已经 price in 的部分，只写剩余的预期差；做不到预期差时改“双角度”（17.2.6）。
3. preview 类：按“催化剂 → 电商/核心业务 → 云/新业务 → 外卖/投入 → 结论或融资”列出本次要验证的看点。
4. 机构沟通/小会补充类：列“关键增量 N 条 → 与预期相符 N 条 → 小会基调 → 看多/看空逻辑是否确认”。
5. callback 类：就管理层指引做隐含值检验（隐含月增速、三种解释）并提示研发与毛利目标。
6. 数据点评/简评：先算账（数据）→ 分区域/分业务 → 估值 → 结论；保守估值后观望。

**关键指标与数据来源**：预告区间、一致预期、管理层指引、月度高频数据、小会增量信息。

**判断标准**：短文只回答“预期差在哪里/相对上次判断什么变了”；有结论、有观察点，而不是复述财报。

**海豚案例**：
- 阿里《(短评)阿里业绩前机构沟通》：开头说明股价回调和沟通口吻 → 1.淘天 CMR 放缓（预期内的坏消息，两个原因）→ 2.闪购亏损与单均亏损收窄，订单结构改善，管理层继续投入 → 对美团的判断 → 3.云增速与外部收入加速。
- 阿里《(短评)阿里2Q业绩preview点评》：先说明催化剂 → 电商 → 云业务 → 外卖 → 结论；《阿里preview》：云 → 电商 CMR → 外卖 → AI Lab → 融资。
- 阿里《阿里业绩后小会补充》：关键增量7条 → 与预期相符3条 → 小会基调 → 看多逻辑确认。
- Unity《(短评)Unity Q1预告及剥离》：盘后大涨，说明预告与剥离 → 1.广告（剔除剥离业务、Vector）→ 2.引擎（核心增速）→ 3.利润（摊销）→ 4.SOTP 估值更新。
- 心动公司《(短评)心动公司2025业绩预告》：1.收入 miss（倒算下半年，归因新游）→ 2.净利 beat（三个原因）→ 3.估值 PE 与看点。
- 壁仞科技《壁仞科技1H26简评》：预告已 price in → 收入 → 毛利对比 → 存货/合约负债 → TAM 估值。
- 唯品会《唯品会2Q26简评》：GMV miss → 用户/单量 → 费用 → 预期差 → 回购能力 → 保守 PE 估值 → 观望；蜜雪集团《蜜雪集团1H26简评》：收入 vs JPM → 开店 vs 单店倒算 → 费用 → 股息 → 保守 PE → 观望。
- 智谱《智谱callback》：ARR 指引 → 隐含月增速 → 三种解释 → 研发与毛利目标；《太空新云》：股价复盘 → 四类催化 → 判断 ARR 性质 → SOTP 估值 → 解禁节奏 → 融资与回本测算。
- 泡泡玛特《泡泡玛特一季度数据点评》：先算账 → 分区域 → PE → 结论；IBKR《IBKR 3Q26火线速读》：对比嘉信 → 账户 → AUC → 息差 → 费用 → 分红。
- 海力士《海力士：存储告别“暴涨叙事”，LTA 成了“避风港”？》（2026-07-29）：完整财报未公布时，先基于 presentation 和 call 点评，并注明后续更新。

**适用场景与注意事项**：适合有事件窗口或已有预告的公司；预告类要避免把已披露信息再当“新消息”写一遍；简评中给出“保守估值后观望”要说明条件。

### 17.2.5 问题导向短评：围绕 2-4 个核心问题展开，而非完整模板

**方法要点**：对关注度较低或业绩没有太多新意的公司，不套完整模板，而是先说明市场近期为什么关注，再抛出几个核心问题，每个问题用 2-3 张图和关键数据回答，最后给一句话估值。重点放在每季业绩演变背后的长期趋势，而不是当季 beat 或 miss。

**操作步骤**：
1. 开篇说明市场近期为什么关注（政策、行情、月度数据、股价事件）。
2. 抛出 2-4 个核心问题（如：是否跑出 Alpha？Alpha 能否保持？是否开启现金牛模式？利好体现了吗？）。
3. 每个问题用 2-3 张图和关键数据回答，必要时用检验指标（用户净增、净资产流入、换手率、变现率、融资余额与收入背离等）。
4. 对利好机制做推演，并说明数据尚未验证的部分。
5. 最后一句话估值（如季度利润年化 × 倍数），并给出短期与长期结论。

**关键指标与数据来源**：问题相关的趋势指标、政策时间线、估值假设。

**判断标准**：问题必须是“能被数据回答”的；结论不依赖当季 beat/miss；估值只给一句话和假设。

**海豚案例**：
- 微牛《微牛：终于熊转牛了》（2026-08-20）：三个问题（难得跑出 Alpha、Alpha 能保持吗、启动现金牛模式吗）。一、难得跑出 Alpha（股票与期权 DARTs、期权市占率）；二、Alpha 能保持吗（PDT 规则：旧规、改革时间线、新规；结构性提升的两个来源；是否开启市占率爬升，用用户净增、净资产流入、换手率检验）；三、是否启动现金牛模式（变现率与单笔 DART 收入、融资余额与收入背离、收入环比、营销费用摊销、核心经营利润与调整后利润）；估值：季度利润年化 × 25x PE 约 63 亿。
- Robinhood《Robinhood：美股散户罗宾汉真是特朗普扶不起的阿斗吗？》（2026-08-11）：先列出股价上涨的三个事件（PDT 解除、特朗普账户、6 月数据超预期）与利多兑现，再看长期趋势四点（用户与净资产流入；产品创新——Rothera 事件合约单张抽成、AI Agent、加密借贷、Social、Strategies、Cortex；PDT 利好机制推演与数据未明；特朗普账户的长期获客价值）、财务纪律（裁员 10%、内生员工、重组费剔除、调整后 EBITDA 57%、增量收入转利润）；估值 2027 年 60 亿 × 60% × 30x = 1000 亿，空间约 15%，带行情风险，等待更好价格；结论“短期 Beta、长期 Alpha”。

**适用场景与注意事项**：适用于跟踪型短评、非核心覆盖公司。问题不宜超过4个，否则变成泛泛而谈。

### 17.2.6 快报/年报已发时的“双角度”写法与简要点评（核心图表）模式

**方法要点**：业绩已通过快报/预告披露、没有预期差时，不再重复，而是改为两个角度：季度业绩的最新动向，以及只在半年报/年报才公布的细项；公司逻辑没有大变化（距上次年报很近）时，只做简要点评：要点、观点，加上“以下为核心图表”，不再逐段展开。

**操作步骤**：
1. 开头说明“快报已出，无预期差”。
2. 选两个角度：（a）季度动向（月度/季度的量价、行业对比、政策节点）；（b）年报/半年报独有细项（分类型、分地区、税金、商誉减值等）。
3. 简要点评版：3 条要点（营收、毛利与营销费、利润桥）→ 海豚君观点（含政策逻辑复述、待验证假设、估值）→ 核心图表三组（营收表现、毛利与营销费、利润）。
4. 利用季度占比倒推全年（如 Q1 利润占全年比例倒推全年利润区间），给出 PE 区间。
5. 说明 Beta 定位（政策驱动、行业景气）。

**关键指标与数据来源**：快报数据、行业量价（如离岛免税行业数据）、占比倒推。

**判断标准**：双角度各自要有独立增量，避免重复快报；简要点评不低于“要点 + 观点 + 核心图表”三件套。

**海豚案例**：
- 中国中免《海南封关顺风起，中国中免能成为“风口上的猪”吗？》（2026-03-31）：开头说明快报已出无预期差，分两个角度（季度动向、年报细项）；7条要点（营收与离岛行业量价、有税/免税与海南/上海拆分、毛利率结构、销售费用与毛销差、其他费用（税金、商誉减值）、经营利润与扣非、分红）；观点含封关政策逐条拆解（短期/中长期）、用数据归因于 10 月政策、上海机场丢标与合资分成、Wind vs 买方预期、利润率回归下的 PE（港股）、Beta 定位。
- 中国中免《封关后首次春节“大考”，中免成绩合格吗？》（2026-04-29）：简要点评，3 条要点（营收增长平平 vs 离岛行业 +26%，提出渠道转移/有税拖累两种假设；毛利率与营销费用对毛销差的贡献；利润桥——税金占比、所得税率、少数股东，至归母 +21%）→ 观点（弱修复撞瓶颈、待验证的两种假设及其对价值的影响、Q1 利润占全年比例倒推全年 59–70 亿、PE 18–20x）→ 核心图表三组（营收表现、毛利与营销费、利润）。
- 亚朵（2026-08-21）：观点后直接给“以下为详细图表”。
- 骨架补充：三花智控《“天灾人祸”一起来？三花智控，没有那么差》：开篇定位年报在预告区间的位置；小米 4Q25“与 Preview 一致”；蔚来 4Q25“高于预告”；三花 4Q25“接近预告下限”。

**适用场景与注意事项**：适用于快报先行的 A 股/港股，以及两次财报间隔短的情形。倒推全年利润要说明季节性假设。

### 17.2.7 财报大跌热评与专题追问文：定性跌因 → 分项拆解 → 估值测算 → 回到最终标准

**方法要点**：财报后股价大幅波动或出现争议时再写跟进文。分两种：大跌热评（解释暴跌、测算底部、判断定价是否到位）和专题追问（对一个争议点逐项举证并回到不受口径影响的最终判断标准）。

**操作步骤**：
大跌热评：
1. 先定性跌因（如指引几乎全面低于预期）。
2. 逐项拆解指引的预期差（收入、Capex、利润率），找出“最大元凶”和“叠加压力”，并检验传导链。
3. 用两种以上估值法（基本面 PE 与股东回报法等）测算底部区间。
4. 与收盘市值比较，判断定价是否到位；给出结论。

专题追问：
1. 先列出市场的几种解释（如会计口径 vs 业务走弱）。
2. 逐项举证（年报政策文本比对、产品机制、与相关费用的联动检验）。
3. 评估影响多大（若只是口径则不影响盈利），并设计联动检验（如收入减项与营销费用）。
4. 回到不受口径影响的最终判断标准（GMV 与利润），给出“不黑也不吹”的结论，并讨论估值安全垫。
5. 对依据不足的粗估明确声明，拒绝噪音。

**关键指标与数据来源**：指引分项、估值区间、收盘市值、会计政策文本、联动费用科目。

**判断标准**：热评必须有“估值区间 vs 收盘市值”的对照；追问必须落到“最终标准”，不停留在“口径争议”。

**海豚案例**：
- 快手《失望指引致暴跌，250亿美金的快手能“捞”吗？》（2026-03-26）：在财报次日解释暴跌：小会指引几乎全面低于资金预期 → 1.最大元凶：电商增长担忧（广告和 GMV 指引对比市场 13%，电商税传导链）→ 2.叠加压力：Capex 260 亿对预期 180 亿，按折旧测算毛利率削弱，利润 170~180 亿，剔除 AI 后利润率持平 → 3.可灵：Q1 流水好，但从全年翻倍指引倒推环比放缓，竞争（Seedance）、技术壁垒与生态壁垒、3.0 定位 → 4.底部估值：可灵 20x PS 加传统业务两种方法（6~8x PE、10% 股东回报收益率），得出 210~285 亿美元，与收盘 254 亿对比 → 结论。
- 拼多多《不黑也不吹，只剩2.5%增长的拼多多还好吗？》（2026-05-29）：提出问题（广告 +2.5% 异常，市场两种解释：智能优惠券、征税）→ 1.智能优惠券是否导致收入被冲减：证据1（2022 年与 2025 年年报激励处理定义的比对），证据2（全站推工具机制）→ 2.影响多大：若只是口径则不影响盈利；收入减项与营销费用联动检验（营销 338 亿不降反增），主站或 Temu 至少一个不好 → 3.怎么看：最终衡量依据是 GMV 和利润；参考淘天剪刀差粗估（声明依据不足），拒绝噪音 → 估值安全垫（6x PE，5000 亿现金对比 8000 亿市值），“别人恐惧”但修复不会很快；结论“不好就是不好”。
- Unity《一夜暴跌近30%，Unity被谁“杀”穿了？》：背景（财报前被连番狙击，又遇非农）→ 三个问题：①指引问题在哪（Grow 环比零增长 vs 买方环比预期）；②为什么资金预期这么乐观（季节性还原内生增速、渠道调研、估值倒推所需环比）；③市场还在怕什么（鬼故事、短线资金踩踏）→ ④怎么看崩盘（Vector 两点预期差、Create 超预期、7x/4x PS 分部估值得 110 亿 vs 不足 90 亿）→ 业绩指标一览 → 业务介绍与详细图表 → 管理层指引。
- 谷歌《“审判”谷歌：市场善变，还是猛投有罪？》（2026-07-27）：问题驱动的深度复盘：问题引入（同剧本不同反应）→ 一、投入是补作业（Capex/收入同业时序、在建工程、份额、供需缺口与算力价格、转化率下降）→ 二、订单驱动（方法1：订单 → GW → Capex；方法2：历史 Capex/新增订单比；结论 3000-4000 亿）→ 三、风险不等对（Backlog vs 美光长协、循环融资 Anthropic、8110 亿采购承诺与 SPV 担保）→ 四、被掩盖的盈利疲软（CIP 推折旧拐点、训练成本重分摊后云真实利润率）→ 五、小结与 SOTP 安全线 3.6 万亿、等待 Gemini 4。
- Reddit《Reddit：超预期却暴跌，“雷”藏哪里了？》：股价反应归因（上次 40x P/E 对应 350 亿 vs 财报前 342 亿，估值到位，需完美业绩）→ 后续观察与 Google 续约，回调可适度做多。哔哩哔哩《哔哩哔哩：广告硬挺，“瘸腿期”的小破站太难了》：开篇解释财报后大跌源于游戏延期和 AI 投入表态（会后量化 5-10 亿，对比 35 亿一致利润）。Spotify《Spotify：预期差瑕疵致“暴跌”，流媒体已成旧爱》：问题在指引（订阅净增 600 万 vs 资金按往年估的 700 万）。

**适用场景与注意事项**：适用于财报后出现分歧或剧烈价格反应的时点。热评要抢时效，追问要抢证据；估值测算务必写明假设，且避免把“已知利空”当成新信息（已定价判断见 11.2）。

### 17.2.8 论证型写法：“市场分歧 → 结构性优势 → 保守情景估值”

**方法要点**：对市场分歧较大、管理层指引激进的成长股，观点部分先把市场的主要分歧逐条列出并量化，再列出可能带来超预期弹性的结构性优势，最后在“不按公司激进指引”的保守情景下估值，说明即使指引落空也有安全边际。既承认风险，又给出可操作的估值锚。

**操作步骤**：
1. 列市场主要分歧（如政策环境、竞争格局、增长基数），每条量化（如目标销量需同比增长 68%-84%，而行业仅 5%-15%）。
2. 列海豚君识别的结构性优势（如出海确定性、垂直一体化降本、碳积分、技术授权），每条给出量化指标（如自研覆盖 65% 成本）。
3. 在“不按公司激进指引”的保守情景下估值（如把销量打折到 80 万辆、用 P/S 区间），给出上行空间。
4. 说明即使指引落空也有安全边际。

**关键指标与数据来源**：目标销量隐含增速 vs 行业增速、各结构性优势的量化指标、保守情景估值参数。

**判断标准**：分歧要有数字，优势要有量化，估值必须在保守情景下仍有支撑。

**海豚案例**：
- 零跑《零跑：出海神车，真能百万“领跑”新势力？》（2026-03-16）：市场担忧政策趋紧、10-20 万价格带竞争恶化、从 60 万到 100-110 万的高增长基数（需 +68%-84%，行业约 5%-15%）；海豚君列出出海确定性强、自研覆盖 65% 成本、碳积分纯利润、技术授权四点，再在 80 万辆的保守情景下给出估值（PS 估值 700-880 亿，上行 25-57%）。
- 同类应用：零跑《零跑：剑指百万，毛利先“失守”？》（下修单价后 PS 估值 632-790 亿）与《零跑：利润指引大幅缩水，全靠出海破局？》（中性 PS 0.6x）延续同一“指引缩水下做保守情景”的做法；蔚来《和“死神”拜拜，蔚来彻底翻身做主人了？》：行业 5%-15% 对比指引 40%-50%，取 20%-30%，1 倍 P/S，上行 30%-40%。

**适用场景与注意事项**：适用于市场分歧较大、管理层指引激进的成长股点评。保守情景要给出可检验的触发条件，避免沦为“事后合理化”。

- [ ] 是否同时看“当期 vs 预期”和“指引 vs 预期”，并明确哪个维度决定股价？
- [ ] 每个要点是否是“实际值 → 对比基准 → 原因”，且预期基准（彭博/买方/大行）已核对是否过时？
- [ ] 笔墨是否集中在预期差最大的1-2点，其余一笔带过？

## 17.3 系列化追踪、纪要与固定组件

> 本节导读：本节解决“研究如何跨季连成一条线、一次财报事件如何分阶段产出、固定组件怎么复用”的问题：文末回溯链、财报—电话会—分析师小会三段式跟踪、电话会纪要模板、“核心信息一览”表与口径注释、关注点排序（已知后置、未知前置）、复杂业务公司只抓主要矛盾、先梳理叙事与关注清单再逐条对照“答卷”，最后归并为可复用的组件库。适合长期覆盖的标的；和 17.1（完整点评）、17.2（速读与跟进）配合成一套成文流程，预测与验证的闭环复盘见 13.3，电话会待验证问题清单见 2.5。

### 17.3.1 系列化追踪：财报点评、电话会纪要、热点、深度组成回溯链

**方法要点**：每篇文章文末列出该公司过往的财报点评、电话会纪要、热点和深度文章及日期，形成纵向追踪链；新文章引用前期深度的结论，并用纪要标题点出上次电话会的关键信息，保证前后判断一致、可回溯。这是研究管理方法：为每家公司建档。

**操作步骤**：
1. 为每家覆盖公司建立文章库：财报点评、电话会纪要、分析师小会纪要、热点/突发点评、深度报告，按时间排序，成对列出“财报点评 + 电话会纪要”（时间倒序）。
2. 每篇文末附“历史文章回溯/过往研究/相关文章”，并附风险披露。
3. 新文章正文引用前期深度的结论（如估值假设、TAM），并用纪要标题带出上次电话会的关键信息。
4. 开篇或观点中回顾上季判断，用本季数据验证或修正，形成连续追踪链（方法详见 13.3）。
5. 多篇连续跟踪时，可沿用上季的长段落（产品打法、业务介绍），只更新数字与过时表述。
6. 篇首或 PS 提示读者回看深度报告，补齐业务全貌（见 17.3.6）。

**关键指标与数据来源**：无（研究管理）。数据源是自有文章库与纪要库。

**判断标准**：回溯链完整（按公司、按季度、按文体），前后判断可对照；本季结论如与前期不同，要明确说明修正原因。

**海豚案例**：
- Marvell（2026-08-28）：回溯了 2025 年 1 月以来的深度、财报点评、电话会纪要和热点（如 2026-08-20 热点《迈威尔 Marvell：“贴钱”结盟谷歌，能“撬动”博通墙角吗？》）。
- CoreWeave 各篇：引用 2025-12 深度《CoreWeave：云中新贵 or 苦命“打工人”？》。
- AMD（2026-02-04）：列出了 2025 年四个季度的财报点评和纪要。
- 高通《这一剂“AI强心针”，够抵消手机的“软肋”吗？》（2026-04-30）：文末列 2025-02 至 2026-02 五组点评 + 纪要，按时间倒序成对排列，形成可回溯的跟踪链。
- 零跑、小米：历史回溯含新品发布、财报季；比亚迪：财报季、热点、深度；特斯拉：热点、深度、财报点评、电话会索引；甲骨文、微软、谷歌、亚马逊等各篇均有“历史研究清单”。
- 骨架补充（验证上季判断）：亚马逊《亚马逊：AWS 发飙，亚马逊终于追上大部队了！》开篇验证上季判断；瑞幸《瑞幸咖啡：走出外卖后遗症，小蓝杯开启顺风局？》兑现上季设定的两个观察点；Coinbase《Coinbase：旱地已久，静待政策及时雨》对照上季底价区间，判断已跑超安全区间；美图《美图：AI SaaS“小而美”是条死胡同？》回顾上期核心观点。
- 回顾上季观点并用本季数据验证或修正的方法论，详见 13.3。

**适用场景与注意事项**：长期覆盖的标的。需要建立文章库与纪要库，便于跨季调用；回溯清单中应保留“同日电话会纪要”的链接，避免漏发。

### 17.3.2 财报、电话会、分析师小会三段式跟踪，并把未解决的问题明确留给电话会

**方法要点**：海豚君的财报覆盖分为财报点评、电话会纪要、分析师小会纪要三类。财报点评中把未解决的问题明确留给电话会（如 ASML 订单是否更新、2027 年指引），并引用分析师小会的增量信息（如美光小会提到 FY27 之后 capex 可能回落）；文末附“历史文章回溯”，保证论点可以跨季对照。点评中预留电话会待验证问题清单的写法详见 2.5。

**操作步骤**：
1. 财报点评阶段：在观点或末段列出“待电话会解决的问题”（订单是否更新、下一年指引、产品时间表、融资安排、管理层口吻等）；对已有信息的口径限制要说明（如订单已停止披露）。
2. 电话会阶段：纪要另发，链接回财报解读（模板见 17.3.3）；财报点评里预判的问题在纪要中逐条验证。
3. 分析师小会阶段：另出纪要或补充文，只写“关键增量 N 条 + 与预期相符 N 条 + 小会基调 + 逻辑是否确认”；点评中引用小会的增量信息时标注来源。
4. 每篇文末回溯：按时间列出该公司历次财报点评、纪要、深度和突发点评。
5. 盘后股价先涨后跌等异常反应，提示“可能来自电话会，请期待后续纪要”。

**关键指标与数据来源**：财报待解决问题清单；电话会/小会增量信息；历史文章时间线。

**判断标准**：问题要具体可验证（“订单是否更新”“2027 指引是否给出”）；增量信息要标明来源（电话会/小会/presentation）；跨季对照时能追溯同一问题的前后答案。

**海豚案例**：
- 阿斯麦（2026-04-15、2026-10-14）：订单与 2027 指引留待电话会。ASML 1Q26 速读：订单未披露，下季指引不重要，全年上调，倒推下半年，订单持续性等待交流。
- 美光《美光 MU：AI 带动存储“疯涨”，能破周期“紧箍咒”吗？》（2026-03-19）：引用分析师小会关于 capex 可能回落的内容；各篇文末均有“海豚君关于 XX 历史文章回溯”。
- 网易（2026-02-11）：点评中预判电话会需关注《遗忘之海》《无限大》进展；MercadoLibre（2026-02-25）：盘后先涨后跌，大概率是电话会有负面发言，请期待后续纪要；Roblox（2026-05-01）：承诺在社区号定期跟踪高频数据。
- 快手系列：要点后加“电话会可关注”的提示；携程 1Q26、零跑 1Q26 速读：以电话会关注点收尾；阳光电源 4Q25 速读：“关注电话会”。
- 小会补充：《阿里业绩后小会补充》：关键增量 7 条 → 与预期相符 3 条 → 小会基调 → 看多逻辑确认。
- 戴尔、蔚来、特斯拉等：要点末条放电话会纪要链接；蔚来（2026-09-01）引用电话会纪要《蔚来（纪要）：毛利率守 18.5%，Q4 月销破 4 万》。

**适用场景与注意事项**：适用于长期覆盖的标的；半年报公司把焦点放在全年指引的调整上。财报点评中的“待验证问题”不应超过3-5个，以便纪要环节逐条回应。

### 17.3.3 电话会纪要整理模板：核心信息回顾 → 高管陈述（CEO 按业务线、CFO 按科目）→ Q&A

**方法要点**：电话会纪要单独成文并链接到财报解读，不重复财报点评，而是把管理层陈述与问答里的增量信息、数字、时间表、投向、融资计划和竞争判断整理出来，便于核对点评中预判的问题。

**操作步骤**：
1. 一、财报核心信息回顾：用图表放财报核心数据。
2. 二、高管陈述：
   - CEO 按公司战略、各业务线（汽车、自动驾驶 FSD/Robotaxi、Optimus、能源、AI 基础设施与芯片、对外投资）、全年指引（Capex、现金和融资）分块；
   - CFO 按销量、汽车毛利率、储能、服务、整体毛利率、净利润、自由现金流等财务科目分块。
3. 三、Q&A 逐条整理（问题 + 回答要点），重点保留指引数字、产能和量产时间、投向比例、融资计划、竞争判断。
4. 在标题中直接点出最关键的数字或表态（如“200 亿资本开支，全力押注 AI 宏图”）。
5. 文末或首段链接对应的财报点评，保证从数字到管理层表述的闭环。

**关键指标与数据来源**：指引数字、产能和时间表、Capex 投向、融资方式、订单积压；电话会逐字稿或会议音频。

**判断标准**：纪要保留“可验证、可追踪”的信息（数字、时间、条件），而非泛泛的战略表述；陈述与问答中与点评预判不一致之处要显式标注。

**海豚案例**：
- 特斯拉《特斯拉2026：200亿资本开支，全力押注“AI宏图”》（2026-01-29）：CEO 部分记录了使命更新、S/X 停产改造为 Optimus 产线、电池组供应是核心瓶颈、CyberCab 4 月生产、AI5 优先、TerraFab、xAI 投资 20 亿、Capex 超过 200 亿；CFO 部分记录了交付 -16% 但汽车毛利润基本持平（区域结构优化，亚太和 EMEA 占比提升）、订单积压增加、服务毛利率 10.5% → 8.8%、整体毛利率超过 20.1%、关税超过 5 亿；Q&A 约 14 问覆盖 CyberCab 定位与 TAM、毛利率框架改为 Cost per mile 和 Duty cycle、Robotaxi 瓶颈、Cybertruck、Optimus 部署、无监督 FSD、芯片外销、Capex 和融资、xAI 协同、存储短缺、中国机器人竞争、垂直整合。
- 同一结构还体现在 CEO 块的细分：战略（使命更新）、汽车（S/X 停产改 Optimus 线、需求区域结构、Roadster、电池组瓶颈）、自动驾驶（Robotaxi 现状和扩张、CyberCab、FSD 用户和转订阅制）、Optimus（Gen3、产能、阶段）、能源（订单积压、毛利率压力、光伏 100GW）、AI 芯片（AI5/AI6、TerraFab）、xAI 投资、2026 指引（Capex 超过 200 亿、现金和融资）；CFO 块：销量、汽车毛利率（区域结构让毛利润持平）、储能、服务毛利率、整体毛利率和关税、净利润（比特币和汇兑）、FCF。
- 蔚来《蔚来（纪要）：毛利率守18.5%，Q4月销破4万》：被后续点评引用，作为电话会关键信息的索引。

**适用场景与注意事项**：适用于所有重要公司财报季的电话会跟踪。纪要里的数字务必与财报核对；管理层表述中的“目标”与“指引”要区分（见 9.5、9.6）。

### 17.3.4 “财报核心信息一览”表与调整后口径注释

**方法要点**：在文中插入标准化的“财报核心信息一览”表（实际值、同环比、预期、指引），配上收入、毛利率、费用、利润、分业务等序列化图表，并对调整后口径单独加注释，保证读者理解数据的口径，也让跨季文章保持同一数据结构。

**操作步骤**：
1. 表的字段：实际值、同比、环比、一致预期、公司指引（如适用）；预期来源写明（见 17.1.4）。
2. 图表序列：收入 → 毛利率 → 费用 → 利润 → 分业务，每季保持同一顺序，必要时在文末批量附“数据图表附录”（如 6-8 张图）。
3. 口径注释：对调整后（Adjusted/Non-GAAP）口径列出包含与剔除项（SBC、折旧摊销、重组、一次性、汇率、并表），并说明为何采用该口径。
4. 口径调整的公司（新旧架构、披露变化）在文首或详细分析前写“口径调整说明”与新旧映射。
5. 不适用口径时标明（如“该公司已停止披露某指标，以推算替代”）。

**关键指标与数据来源**：核心财务指标一览表；各调整项的披露来源（财报附注、非 GAAP 调节表）。

**判断标准**：同一指标跨季口径不变；调整项逐项可追溯；读者能据注释还原 GAAP 数据。

**海豚案例**：
- CoreWeave（2026-08-12）：第5节为“财报核心信息一览”表格。
- Marvell（2026-08-28）：注明“调整后的经营数据（Adjusted）中包含 SBC，但主要调整折旧摊销等影响，更直观地反映经营状况”，正文后附 6 张数据图。
- 骨架补充：阿里《阿里狂投，只为“中国版谷歌”？》要点1“披露结构大改（新旧板块映射）”，《阿里：电商再沦陷，AI才是大救星》详细分析首节“新口径”；百度《百度：老业务继续磨底，AI 全靠算力红利》“新旧融合表”；微软三篇“口径变化概览”；Salesforce《Salesforce：既没增长也没利润，AI故事还讲得动吗？》附“口径调整说明与核心图表”；迪士尼 1Q26 速读“口径说明”；Roblox 详细部分“Covenant EBITDA 原理”。
- 口径变更与停止披露的处理方法详见 4.4。

**适用场景与注意事项**：写作呈现模板；任何有 Non-GAAP/调整口径的公司。注释要精炼，不要把整篇文章写成口径说明。

### 17.3.5 关注点排序：先确定哪些信息已知，把重心放在未知项

**方法要点**：开篇先说明“当季哪些信息投资者已经知道”（如月度销量、月度营收、月度行业数据），已知项一笔带过，把正文篇幅和观点重心放在未知项上（单车经济、毛利率、指引、资本开支等），按“信息增量”排序。对半年报公司，焦点放在全年指引的调整上。已知/未知排序的分析逻辑见 1.3。

**操作步骤**：
1. 列出本季已披露的高频数据（月度销量、月度营收、行业数据、预告）。
2. 把它们归类为“已知项”，在正文第一节用一句话交代（如“由于销量已经公布，投资者更关心汽车业务收入和毛利率”）。
3. 把尚未披露、且对估值影响大的变量列为“未知项”：ASP、单车成本、毛利率、服务收入、下季指引、资本开支。
4. 要点与观点按“未知项在前”重排；必要时把“核心关注点 a/b/c”前置为要点第一项。
5. 半年报公司：把全年指引的调整作为核心焦点。

**关键指标与数据来源**：高频数据已披露清单；未知项清单；信息增量判断。

**判断标准**：每个章节标题都能回答“这节给读者带来什么新信息”；已知数据只做背景。

**海豚案例**：
- 小鹏（2026-03-20、05-28、08-24）：正文第一节都以“由于小鹏本季度销量已经公布，投资者更关心汽车业务收入和毛利率”开头。
- 地平线（2026-09-01）：“市场当下的核心焦点已全面转移至 2026 年前瞻指引”。
- 台积电《台积电：只吃饼不画饼，当得了带头大哥吗？》（2026-10-15）：要点前置为“核心关注点”（a 毛利率 66.4% 对比预期及单片三段拆解，2nm 稀释 2-3pct；b 指引，Q4 对比预期、全年 44%，隐含 Q4 同比 +55% 以上，市场要的是 2027 指引；c 资本开支，维持 600-640 亿，隐含 Q4 同比 +67-103%），收入量价后置，因为月度营收已经公布。
- Robinhood《Robinhood：爆炒之后，美股散户王还剩什么？》：详细分析写明“月度数据已知，看变现率、生息率、费用率”。
- 车企（理想、蔚来、小鹏）：销量指引倒算月销、收入指引倒算 ASP，是未知项的核心（见 9.2）。

**适用场景与注意事项**：适合有高频经营数据的行业（车企、晶圆厂、券商、连锁）。已知项不是不写，而是“降权”；若已知项与未知项相互矛盾（如销量超预期但毛利率差），应在开篇直接指出。

### 17.3.6 复杂业务公司“抓主要矛盾”：只深挖核心业务，其余按市值或简化处理

**方法要点**：业务多元的公司（如比亚迪涵盖汽车、手机部件及组装、二次电池、光伏），财报点评明确只把核心业务（汽车）当深挖对象（单车经济、毛利率、份额），非核心业务（比亚迪电子）只看对总收入和利润的扰动，估值时按市值计入。同时把“每个季度最重要的观测指标”定为固定的核心观测指标（如特斯拉“剔碳积分的汽车销售毛利率”）。文章开头或 PS 提示读者回看深度报告，补齐业务全貌。

**操作步骤**：
1. 判定核心业务：贡献大部分利润和估值的业务。
2. 核心业务深挖：单车经济、毛利率、份额、海外与高端化等。
3. 非核心业务：只写对总收入/利润的扰动（如“收入超预期来自比亚迪电子，卖车收入持平”），估值时按市值或简单倍数计入。
4. 固定“核心观测指标”（每季必看），并在文中强调其唯一性。
5. 文首或文末 PS 引导读者回看深度报告。

**关键指标与数据来源**：核心业务收入/利润占比、核心观测指标。

**判断标准**：核心业务应贡献大部分利润与估值；非核心业务不能“喧宾夺主”，否则会误导对核心趋势的判断（如总收入超预期但全来自非核心）。

**海豚案例**：
- 比亚迪《王座失守…》（2026-03-28）等三篇都有 PS：业务太多太杂，核心还是汽车，引导回看深度《比亚迪：最会做电池的整车厂》《比亚迪：暴涨过后，富贵稳中求》；《比亚迪：王座失守，未来是出海版“丰田”？》指出总收入超预期但来自比亚迪电子，卖车收入持平。
- 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：汽车毛利率“重要到不能再重要”，财报的真正增量信息一直是汽车毛利率。
- 相关做法：网易有道、云音乐、严选等非紧密跟踪业务只给图不展开（见 17.1.7）；京东把核心商城与新业务分拆预期差；美团“剔除非经营项目，计算核心经营利润”；百度把 AI 含量与传统业务分开看。

**适用场景与注意事项**：适用于多元化集团和复杂业务公司的季度跟踪。前提是核心业务贡献了大部分利润和估值；一旦非核心业务成为利润主要来源（如并购后），要重新判定核心。

### 17.3.7 先梳理叙事与核心关注清单，再逐条对照本季“答卷”

**方法要点**：观点部分先写清当前投资逻辑——哪块业务是唯一值得关注的、利多与利空逻辑各是什么；再列出市场核心关注点（如核心业务加速与 RPO、毛利率下滑程度、融资能力及对报表影响），逐条对照本季实际给出结论，最后判断本次是否是改变投资逻辑的关键拐点；还要跟踪关注点本身的演变。

**操作步骤**：
1. 写当前叙事：唯一值得关注的业务、利多与利空逻辑（叙事与多空逻辑见 1.4）。
2. 列核心关注清单（通常 2-4 项），每项写明“好/坏的判断标准”。
3. 逐条对照本季“答卷”，给出“通过/部分通过/未通过”式结论。
4. 判断是否改变投资逻辑（拐点或非拐点），指出“此前没有预料到的有价值增量信息”。
5. 跟踪关注点的演变（如 RPO 关注度下降，转向算力上线执行与融资；对高 Capex 态度由厌恶转为正面）。
6. 把本次清单沿用到下一季文章，作为“里程碑台账”（见 17.1.12、13.3）。

**关键指标与数据来源**：关注点清单及逐项结论。

**判断标准**：每条关注点都要有可检验的标准；“拐点”结论要有“逻辑被改变”的证据，而非单季数据好坏。

**海豚案例**：
- 甲骨文（2026-03-11）：两面逻辑都被验证，不是关键拐点，最重要的变化是 27 财年营收指引从 850 亿上调到 900 亿（隐含增速约 34%），提高了 2030 长期指引的可见度。
- 甲骨文（2026-06-11、2026-09-11）：关注点转为执行与融资。
- 微软（2026-05-01）：列出本次业绩“此前没有预料到的有价值增量信息”两条。
- 骨架补充：甲骨文《拿命博生存，甲骨文“AI注”真赢了？》：先梳理叙事与关注清单 → 逐条答卷 → 判断非拐点；估值：剔除 AI 的传统业务估值底 + 市值倒推 OCI AI 隐含定价 17x；《甲骨文暴跌？AI基建补不了的硬伤——高息、高债+歇菜软件》：关注点清单与答卷（AI 云利润率假设检验）；《甲骨文：AI撑起了面子，但谁来兜底里子？》：中短期两大关注点（执行、融资）的答卷与现金宽裕度；CoreWeave《Coreweave: 算力好卖赚钱难…》：好坏两面相互对应，并提炼行业启示；特斯拉：AI 里程碑台账逐条核对（见 17.1.12）；微软《微软：风水轮流转，老腊肉变香饽饽？》：复盘与 OAI 关系的周期，“投入克制 + 增长有力 + 利润率不塌 + 现金流不崩 + 估值折价”。

**适用场景与注意事项**：所有财报点评的观点段写法。尤其适用于“叙事主导股价”的公司（AI 基础设施、新能源车、SaaS）。关注点清单要在下一季回头核对，防止“选择性遗忘”。

### 17.3.8 固定组件库与组装顺序：把一篇点评当作可复用的模块拼装

**方法要点**：海豚君的点评由一组固定组件拼装而成。把这些组件列成清单，并给出组装顺序，既提高写作效率，也保证每篇文章在跨季、跨公司之间保持一致的信息结构。

**操作步骤（组件与组装顺序）**：
1. 标题（观点 + 比喻/设问）→ 17.1.2。
2. 开篇定性句（发布时间、财报期、相对预期的定性、股价反应）→ 17.1.2、17.2.2。
3. 编号要点（含对比基准与归因）→ 17.1.3。
4. 指标一览表/财务概览图（含预期来源）→ 17.1.4、17.3.4。
5. 海豚君观点（当季评价、指引倒算、核心矛盾、近期动态、估值、操作建议、跟踪重点）→ 17.1.5、13.1、第12章。
6. 市场关注点 a/b/c（硬科技）→ 17.1.6。
7. 投资逻辑框架/认识公司/业务介绍（多部门、重组、软件、金融）→ 17.1.10、17.1.14。
8. 详细分析（按业务分节，结论小标题 + 图）→ 17.1.7。
9. 附录：业务介绍、披露口径说明、数据图表附录 → 17.3.4。
10. PS：引导回看深度或提示非核心业务不展开 → 17.3.6。
11. 电话会待验证问题/纪要链接 → 17.3.2、2.5。
12. 历史文章回溯 + 风险披露 → 17.3.1。

**关键指标与数据来源**：无（组件清单）。

**判断标准**：快评可裁剪，但“要点、观点、估值”三件套保留；非紧密跟踪业务可裁剪；每个组件的口径跨季一致。

**海豚案例**：
- 比亚迪三篇：PS 组件引导回看深度；大段产品打法组件逐季沿用并局部更新。
- 迪士尼：“认识迪士尼”组件；谷歌：“基本介绍 + 基本面长逻辑 a/b”组件；Monster、Lululemon、沃尔玛、可口可乐：“投资逻辑框架”组件。
- Salesforce《Salesforce：AI替代论摧枯拉朽，SaaS龙头已成“弃子”？》：附“业务介绍（五大云）与核心图表”；甲骨文《甲骨文：AI撑起了面子，但谁来兜底里子？》附录业务介绍；三花智控《三花智控：汽零回正，机器人的“盛夏”还要等多久？》附业务介绍和图表。
- 唯品会《唯品会：再现负增长？别怕，有 10% 股东回报救场》：核心图表三节（经营指标、收入与毛利率、控费）+ 过往研究列表；贝壳（2026-05-20）：相关研究。
- Marvell（2026-08-28）简版：速览 + 观点 + 数据图表附录，保留回溯。

**适用场景与注意事项**：研究管理与写作效率工具。组件不是目的，当某个组件没有新增信息（如框架没变）时可省略或只更新差异。

**本节速查清单**

## 17.4 其他/未归类方法

> 本节导读：本节是整个框架的兜底。目前所有方法都已归入第1到17章的相应小节，没有无法归类的独立方法，也没有难以拆分的零散做法；因此本节不新增方法，只提供一张把全书串联起来的“使用路线图”，供研究一家公司、一个行业或一次财报季时，按先后顺序挑选各章的方法。若今后发现跨多个环节、难以拆分的新做法，应先尝试归入相近小节，实在无法归类时再追加到本节。

### 17.4.1 全框架使用路线图：一次财报事件从准备到复盘的章节串联

**方法要点**：把第1-17章按一次财报事件的先后顺序排成工作流，并说明与 17.1-17.3 中各类文体的对应关系。它不是新方法，而是兜底的“跨环节索引”。

**操作步骤**：
1. 财报前（准备）：建立预期基准与买方真实预期（第1章：1.1、1.2），确定核心问题、核心指标与已知/未知排序（1.3），梳理叙事与多空逻辑、情绪基线（1.4），做财报前推演、利用预告等前置披露（1.5）；用第三方高频数据、产业链、调研、竞争格局提前验证（第14章）。对应文体：preview、机构沟通、预告点评（17.2.4）。
2. 财报当天（速读）：业绩定性与综合评价、逐项对标与区间定位、预期差来源归因、超预期质量检验、电话会增量与待验证清单（第2章）。对应文体：火线速读（17.2.1-17.2.3）。
3. 数据清洗与边际变化：增量、二阶导、基数与日历效应（第3章）；汇率、并购、会计政策、披露口径、一次性、未披露数据推算（第4章）。
4. 逐项拆解：收入（第5章）、前瞻指标与订单（第6章）、毛利率（第7章）、费用与经营利润（第8章）、指引解读与隐含推算（第9章）、资本开支、现金流与资产负债表（第10章）；对照所属行业指标体系（第15、16章）。
5. 股价反应与估值：股价反应解释（第11章）；估值更新、盈利预测与交易结论（第12章）；观点判断链、核心矛盾与研究心态（13.1、13.2）。
6. 成文：完整点评（17.1）、跟进文（17.2.7、17.2.8）、纪要与系列化追踪（17.3）。
7. 复盘：用下季数据验证本季判断，修正观点（13.3），并更新文章库与关注清单（17.3.1、17.3.7）。

**关键指标与数据来源**：见各章；本节不新增指标。

**判断标准**：每一次财报事件至少走完“准备 → 速读 → 拆解 → 估值 → 成文 → 复盘”六步；若时间不足，保留速读（17.2.1）与“要点、观点、估值”三件套（17.1.1）。

**海豚案例**：
- 同一家公司在不同节点有不同的文体分工：阿里业绩前有《(短评)阿里业绩前机构沟通》和 preview 类文章（17.2.4），财报日有《(短评)阿里巴巴3QFY26火线速读》与完整点评（如《阿里：电商再沦陷，AI才是大救星》，两者都围绕倒算闪购亏损、云与国际电商展开），业绩后还有《阿里业绩后小会补充》。
- 特斯拉：点评《手撕“烂业绩”剧本，特斯拉要逆风翻盘了？》与电话会纪要《特斯拉2026：200亿资本开支，全力押注“AI宏图”》（2026-01-29）配对出现，并在后续季度沿用里程碑台账（17.1.12、17.3.3）。
- 台积电：4Q25 既有火线速读（2026-01-15），也有完整点评《台积电： AI 界“真大佬”，谁会拒绝？》；3Q26 的完整点评（2026-10-15）把“月度营收已公布”的信息降权，要点前置毛利率、指引与资本开支（17.3.5）。

**适用场景与注意事项**：适用于任何公司、行业或财报季；路线图只提供顺序，具体判断标准在各章。
