# 第11章 股价反应解释

> **本章目的**：解释财报后股价为什么这样走：剥离业绩、预期、估值、叙事、资金与宏观各自的作用，判断哪些已经定价，并为后续操作提供依据。

**本章小节**：11.1 多因素归因与分段归因框架｜11.2 已定价判断与利空出清｜11.3 估值水位、情绪与业绩门槛｜11.4 叙事、远期分歧与双线定价｜11.5 行业β、宏观与个股α分离

## 11.1 多因素归因与分段归因框架

> 本节导读：本节回答“财报后股价为什么这样走”的第一层问题——把业绩、预期差、指引、叙事、估值水位、风险偏好、资金结构等因素逐一拆开，再按信息释放的先后（盘后数据→PPT→电话会→盘中）分段归因。财报一出、需要写“海豚君观点/市场解读”或复盘“业绩好股价跌、业绩差股价不跌”时，先用本节找出主因；随后转入 11.2（是否已定价）、11.3（估值水位与业绩门槛）、11.4（叙事与远期分歧）、11.5（行业β与宏观）做针对性判断。预期基准的搭建见第1章，预期差来源归因见 2.3，指引本身的解读见第9章。

### 11.1.1 股价反应的五因素解释框架

**方法要点**：解释财报后的涨跌时，不只用“超预期/不及预期”一个维度，而是拆成预期差、趋势叙事、估值隐含预期、市场风险偏好、已涨跌程度五个因素，并叠加标的弹性，逐项打分后得出主因。

**操作步骤 / 拆分口径**：
1. 数据与预期的差距：当期数据相对预期的偏差（预期基准选择见 1.1）。
2. 趋势或叙事是否改善：即使预期差不大，趋势拐点（如利润率触底、产能上线加速）本身可以构成利好。
3. 估值隐含的预期高低：当前估值倍数对应的市场预期位置。
4. 市场整体风险偏好：参考同期其他公司财报后的涨跌，判断是公司特有反应还是情绪整体回升/回落。
5. 股价此前已经涨跌了多少（定价程度）：自高点回撤、自底部反弹的幅度。
6. 叠加标的弹性：高beta公司的涨跌会被放大。

**关键指标与数据来源**：盘后涨跌幅；同期可比公司财报后涨幅（需要同时跟踪多家公司财报后的股价反应）；股价自高点回撤幅度、自底部反弹幅度。

**判断标准**：
- 预期差并不出彩、但趋势或叙事改善：仍可大涨，趋势比单季数字更重要。
- 同期多家同类公司超预期后都涨 10%~20%：说明是风险偏好回升，而不是个股特有逻辑；反过来，此前被配对交易看空的板块，在风险偏好修复时弹性更大。
- 股价自高点大幅回撤、又自底部大幅反弹：逻辑改善已有反映，当季好坏两面相互对应时，股价变化不大。
- 叙事发生变化（如光学超级周期）：可直接带来大涨。
- 业绩处于上升期但股价平淡：去找市场正在担心的可持续性变量（如大厂Capex可否持续）。
- 增速低于同赛道龙头、核心产品展望未上调：属于相对失望，见 11.3.5 与 11.3.4。

**海豚案例**：
- CoreWeave（2026-08-12）：盘后涨约 15%。从预期差角度并不出彩，但算力上线加速、利润率触底是趋势利好；同期 Shopify、Airbnb、Sea、Unity、Palantir 超预期后都涨了 10%~20%，说明风险偏好回升；此前云厂商在配对交易中是被看空的一方。
- 另一例（2026-05-08）：股价自高点跌近 65%、自底部反弹 1 倍，逻辑改善已有反映；当季好坏两面相互对应，股价变化不大。
- Marvell（2026-08-28）：盘后大跌，两个原因——没有上调 ASIC 展望，以及数据中心增速 60% 以上低于英伟达的 70% 以上。
- Marvell（2026-05-28）：股价大涨源于叙事变化（光学超级周期）。
- 博通（2026-03-05）：业绩在上升期但股价平淡，原因是市场担心大厂 Capex 的可持续性。

**适用场景与注意事项**：通用框架。判断风险偏好必须同时跟踪多家公司财报后的股价反应，单看一家容易把市场情绪误当成个股逻辑。

### 11.1.2 驱动来源辨别（业绩/指引/叙事/不确定性）与估值隐含预期

**方法要点**：先分清股价是被当期业绩、指引、叙事还是外部不确定性驱动，再用当前估值倍数反推市场隐含的预期，最后判断财报能否改变资金情绪。

**操作步骤 / 拆分口径**：
1. 分清驱动来源：①当期业绩与预期的偏差；②指引（往往权重更大）；③叙事（新业务增长故事、拆分上市传闻等）；④不确定性（如监管）。
2. 用当前估值倍数反推隐含预期：例如约 9x PE 说明预期已下调甚至偏保守；自高点回撤约 40% 说明已较充分定价。
3. 梳理催化事件（传闻与公告）与股价的对应关系。
4. 判断财报能否改变资金情绪，作为观点部分的结论。

**关键指标与数据来源**：财报日涨跌幅；自高点回撤；当前 PE；指引与预期差；催化事件（传闻和公告）。

**判断标准**：
- 指引破趋势 → 当天大跌（指引权重高于当季）。
- 传闻催化（如拆分上市估值传闻）→ 股价反弹，但港股整体承压时会回落，说明叙事催化抵不过大环境。
- 业绩后下跌若主要源于监管不确定性，而非业绩，则不能用业绩偏差去解释，需单独评估监管风险。
- 估值倍数处于低位（约 9x P/E）：说明悲观预期已被计入，下跌空间受限。

**海豚案例**：
- 快手《快手：老铁翻身，就靠“可灵”了》（2026-05-27）：上季指引破趋势，当天大跌 15%；5 月中旬传出可灵以 200 亿美元估值寻求拆分上市，股价反弹，后又在港股承压下回落。
- 快手《快手：一场向死而生的暴跌，能换来 AI 重生吗？》（2026-03-25）：约 9x P/E 说明市场预期已下调甚至偏保守。
- 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：业绩后下跌主要源于监管不确定性，而不是业绩。
- 拼多多《不黑也不吹，只剩 2.5% 增长的拼多多还好吗？》（2026-05-29）：业绩后股价下跌近 15%。

**适用场景与注意事项**：通用方法，用于财报点评的观点部分。估值倍数反推隐含预期依赖估值假设，需写明口径；是否“已定价”的深入判断见 11.2。

### 11.1.3 股价驱动拆解：叙事估值情绪、业绩背离、资金风格与流动性/竞对虹吸

**方法要点**：解释股价不只看业绩，而是拆成叙事驱动的估值情绪、业绩与股价背离、资金风格、流动性与竞对虹吸四类驱动，据此判断财报后是持续性惩罚还是短期波动。

**操作步骤 / 拆分口径**：
1. 叙事驱动的估值情绪：把股价上涨/回落对应到叙事事件时间线（如算力国产替代、分拆上市、股东回报、入通，后期被 AI 颠覆论叙事反转）。
2. 业绩与股价背离：若回调与当期业绩关联不大，来自对 AI 削弱增长的担忧，则“无惊无喜”的财报不足以提振股价。
3. 资金风格：识别公司是否被资金当作某类风格资产（如主业稳定、AI 投入有限，被视为 AI 科技成长对立面的避险资产）。
4. 流动性与竞对虹吸：流动性收紧叠加字节等竞对虹吸，压制情绪。
5. 综合判断财报后是持续性惩罚还是短期波动。

**关键指标与数据来源**：估值倍数变化；事件时间线；风格资金流向。

**判断标准**：
- 调整已久 + 回购分红托底 + 有新叙事（上市入通等）→ 预计市场不会给太多持续性惩罚。
- 估值处于历史底部（13-14x）而回调来自 AI 担忧而非业绩 → 无惊无喜的业绩不足以提振，需要打消担忧的增量信息。
- 避险资产属性 → 全球调整时逆势上涨，利好兑现后市值底部不断抬高。

**海豚案例**：
- 百度《百度：广告根基已废，昆仑芯成“救命草”？》（2026-02-26）：预计市场不会给太多持续性惩罚——调整已久、回购分红托底、昆仑芯上市入通叙事。
- 腾讯《“老登” 腾讯》（2026-03-18）：13-14x 历史底部，回调来自对 AI 削弱增长的担忧，与当期业绩关联不大。
- 网易《不烧钱依旧吃老本》（2026-08-20）：主业稳定 + AI 投入有限，被视为避险资产，7 月全球调整时逆势上涨；以避险资产属性解释入通利好后市值逆势向上、底部不断抬高。

**适用场景与注意事项**：用于“海豚君观点”部分。需事先整理叙事时间线与资金风格，否则容易把风格行情误读为基本面。

### 11.1.4 三层归因：表观冲击 → 真实缺陷 → 外部叙事

**方法要点**：盘后大涨大跌时，把反应拆成三层——表观数字的冲击、真实的小缺陷、外部叙事或风险，剥掉前两层后，再评价最终跌幅是否“合理”。

**操作步骤 / 拆分口径**：
1. 第一层，表观数字冲击：如 GAAP 净利暴跌，多由非经营性项目造成，市场反应过来后会修正。
2. 第二层，真实的小缺陷：如利润率环比变化、指引不及预期。
3. 第三层，外部叙事或风险：如自动驾驶替代、AI 替代软件、Capex 的 ROI。
4. 对剔除一层后的剩余跌幅，逐层评价其合理性，写出“跌幅是否合理”的结论。

**关键指标与数据来源**：盘后涨跌幅；GAAP 与调整后利润；利润率环比变化。

**判断标准**：第一层属于数字冲击，修正后应当回补；第二层决定合理跌幅区间；第三层是估值压制的来源，需另行判断是否过度。若修正后的剩余跌幅超出第二层缺陷所能解释的程度，则认为跌幅偏过。

**海豚案例**：
- Uber（2026-02-04）：盘后先跌近 9%，源于约 16 亿非经营性亏损（第一层）；修正后仍跌约 5%，原因是网约车 adj.EBITDA 利润率（基于订单额）环比 -0.1pct，下季集团利润率指引环比持平、低于预期（第二层），再加上自动驾驶威胁（第三层）；海豚君认为 5% 的跌幅“不太合理”。
- 亚马逊（2026-02-06）：AWS 提速 3.4pct，但 Capex 2000 亿加利润指引 miss 导致大跌。
- AppLovin（2026-02-12）：业绩达到谨慎的买方预期，股价仍负反馈，原因是跟跌 Unity，以及担心 Meta 重返 iOS in-app 广告和 Cloudx（该日多因素归因见 11.1.12）。
- 美图（2026-03-27）：财报提前泄露，预计反应激烈。

**适用场景与注意事项**：普遍适用。关键是把 GAAP 的非经营扰动先剥掉，再讨论经营缺陷；GAAP 与调整后口径的清洗方法见第4章与 8.8。

### 11.1.5 按信息释放时点的分段归因（盘后/PPT/电话会）

**方法要点**：把财报后的股价走势按信息释放的时间点切成几段，每段对应一条信息（财报数据、PPT 增量信息、电话会细节），从中识别市场真正在定价的变量。

**操作步骤 / 拆分口径**：
1. 取分钟级行情，标出财报数据发布、PPT 发布、电话会各环节的时间戳。
2. 逐段对应：先跌 → 对业绩不及预期的直接回应；再拉升 → 往往来自 PPT 或电话会里的增量信息；再回落 → 电话会细节不及预期。
3. 若某条信息出来后股价反转，说明它比当期业绩更重要。
4. 盘后跳水也可能不是因为财报，而是管理层讲话没有上调展望。
5. 大涨要判断属于哪一类：业绩支撑、情绪股属性，还是叙事反转。

**关键指标与数据来源**：盘后涨跌幅；日内拐点；对应的信息披露时点；电话会/PPT 关键表述；前期股价回调幅度。

**判断标准**：结论通常是——市场更在意前瞻可见性（比如长协金额、指引），而不是当季数字。业绩数据不错但盘后大跌，多半是管理层没有上调全年展望；盘后大涨但业绩支撑有限，多半是叙事反转或情绪股属性。

**海豚案例**：
- 海力士《海力士：存储告别“暴涨叙事”，LTA 成了“避风港”？》（2026-07-29）：盘后下跌 10%，对应收入和毛利率不及预期；随后翻红，对应 PPT 首次官方确认 LTA（长协）含预付款或保证金机制；电话会没有披露具体金额，股价再度翻绿。
- 博通（2026-09-03，回顾上季）：财报后单日跌 12%，原因是 10GW 出货量没有转化为收入指引上调。
- 应用材料：财报数据不错，但盘后大跌，原因是管理层没有上调全年设备增速。
- Shopify：盘前 +30%，有情绪股属性，此前因 AI 叙事回调。
- Salesforce（2026-08-27）：盘后大涨，业绩支撑有限，主要是 AI 冲击 SaaS 的叙事反转。
- Marvell：盘后大跌，因为没有上调定制 ASIC 展望、增速低于英伟达。
- AppLovin（2026-08-06）：资金先跑为敬。

**适用场景与注意事项**：适用于有盘后交易的美股和 ADR，需要分钟级行情和信息时间戳；也适用于财报季盘后快速点评。港股无盘后交易时只能用次日盘中走势近似分段。

### 11.1.6 “业绩好、指引好、股价跌”的逐层检查链

**方法要点**：本季与下季指引都不差、股价却跌时，沿“本季业绩 → 下季指引 → 全年或长期口径 → 管理层定性表态 → 估值位置”逐层检查，找出真正改变预期的那一层——通常是管理层的全年口径或定性表态主导了股价。

**操作步骤 / 拆分口径**：
1. 本季业绩 vs 预期。
2. 下季指引 vs 预期。
3. 全年或长期口径：把全年增速与下季增速对比，推断隐含的后续节奏（下季已接近全年增速，则隐含后续不提速）。
4. 管理层定性表态：是否定量上调全年展望、措辞是否保守。
5. 估值位置：高估值公司对全年口径更敏感。
6. 找出第一个与预期“拐弯”的层级，作为股价主因。

**关键指标与数据来源**：盘后股价涨跌；本季、下季、全年各层与预期的差；管理层的定量与定性表述（电话会）。

**判断标准**：
- 全年口径与下季增速接近 → 隐含后续不提速 → 涨幅被消磨。
- 好业绩 + 好指引，但管理层不定量上调全年增速 → 盘后跳水。
- 业绩达标但毛利率指引远低于预期 → 给相关叙事（如“18A + AI CPU”）降温。
- 下季收入与 EPS 指引双低于预期 → 股价压力来自指引，而非当季。

**海豚案例**：
- 应用材料《Capex 狂飙在路上…》（2026-05-15）：Q2 本季和下季都超预期，盘后一度 +7%，但管理层随后给出“2026 自然年设备增速 30% 以上”的全年口径，而下季度设备增速已接近 30%，隐含后续不提速，涨幅被抹平。
- 应用材料《泼天富贵在前，应用材料 AMAT 竟然怂了？》（2026-08-14）：Q3 同样业绩和指引超预期，管理层却不定量上调全年增速，盘后跳水，好业绩没兜住保守指引。
- 英特尔《英特尔：AI CPU 火热造势，“冰冷”指引浇灭了期待？》（2026-01-23）：Q4'25 业绩达标，但毛利率指引 32.3% 远低于预期的 38%，给“18A + AI CPU”的热情浇了冷水。
- 高通（2026-02-05）：下季营收指引 102-110 亿美元 vs 一致预期 112 亿，EPS 指引 2.45-2.65 vs 预期 2.9，双双低于预期。

**适用场景与注意事项**：适用于财报后股价与数据背离的情况。前提是能拿到电话会信息；高估值公司对全年口径更敏感。指引如何对比预期、如何倒推隐含值见第9章。

### 11.1.7 指引主导的下跌归因：指引下修与“多层预期＋措辞”定位致命问题

**方法要点**：当季业绩略超预期而股价大跌时，把主因归到指引（下修或低于买方预期）与电话会措辞，并分层比较预期（一致预期/乐观买方/海豚君自身），定位导致下跌的“致命性问题”。

**变体 A：指引大幅下修**
1. 确认业绩与预期的关系（略超）。
2. 把主因归到指引大幅下修，并解释下修否定了什么市场逻辑（如“前低后高”）。
3. 从电话会里找下修原因（舆情冲击、新品不及预期），区分短期因素与结构性因素。

**变体 B：多层预期 + 指引 + 电话会措辞**
1. 把预期分层：彭博一致预期、部分乐观买方机构预估、海豚君自身预期，分别比较当期业绩。
2. 看指引是否低于市场预期。
3. 看电话会措辞（如高油价压制消费者预算、退税红利消退、下半年通胀可能上行）是否被市场解读为宏观更差。
4. 定位“致命性问题”（通常是指引或措辞，而非当期业绩），并与估值矛盾挂钩。

**关键指标与数据来源**：盘后/盘中涨跌幅；指引修订前后的收入与利润区间；彭博一致预期、买方预期、指引、电话会表述。

**判断标准**：
- 变体 A：指引权重往往高于当季结果；指引被管理层自己下修，等于否定了前期的市场逻辑；若原因是社媒负面舆情、新品反馈不及预期，需区分是短期还是结构性。
- 变体 B：业绩只低于乐观买方而与彭博一致预期无大差异时，主因多在指引与措辞；指引偏离市场约 30% 这类大幅缺口，足以引发暴跌。

**海豚案例**：
- Lululemon《创始人炮轰、业绩稀烂…》（2026-06-05）：营收略超预期，但全年收入指引从 +2%~4% 砍到 -1%~0，利润从个位数下滑扩大到 -15%~-17%，盘后跌 11%；“前低后高”的逻辑被管理层自己否认了一半，主因是社媒负面舆情（创始人公开批评、PFAS 风波）和新品反馈不及预期。
- 泡泡玛特《收入狂翻、股价狂泄，到底谁错了？》（2026-03-25）：盘中暴跌 22%；2H25 营收 232 亿、+174%，与 bbg 一致预期相差不大，仅低于乐观买方，主因是 2026 年收入 ≥20% 的指引低于市场约 30%。
- 沃尔玛（2026-05-22）：收入超预期，但指引低于乐观买方预期且管理层表述悲观，盘中下跌。

**适用场景与注意事项**：变体 A 适用于美股指引驱动型公司；变体 B 适用于所有财报后股价反应分析，尤其高预期股票。买方真实预期的还原见 1.2。

### 11.1.8 业绩强但股价平淡 / 高预期下业绩平淡的解释框架

**方法要点**：业绩强但股价平淡、或高预期下业绩显得平淡时，把反应分解为业绩对比预期、市场担忧的前瞻变量、估值位置、指引是否动摇买入逻辑，并区分海豚君认为更重要的变量与市场短期关注的变量。

**操作步骤 / 拆分口径**：
1. 业绩与预期的对比。
2. 找出市场担忧的前瞻变量（如内存涨价侵蚀毛利率）。
3. 看估值位置（如 PE 已从 29x 升至 35x）。
4. 看指引是否动摇市场的核心买入逻辑（资金因确定性买入，而管理层给出增长放缓信号）。
5. 区分变量重要性：海豚君自己认为更重要的变量（如 AI 化）vs 市场短期关注的变量（存储成本）。

**关键指标与数据来源**：业绩 vs 预期；下季指引增速；估值倍数变化；市场担忧点。

**判断标准**：估值抬升到“不便宜”的位置、增速却放缓，会动摇“为确定性而来”的资金；市场担心的变量若对高毛利公司影响有限（相对更重要的 AI 化趋势），则属于短期扰动。

**海豚案例**：
- 苹果《iPhone 炸场…》（2026-01-30）：业绩强，盘后平平，核心是担心内存涨价侵蚀毛利率；海豚君认为对高毛利的苹果，这远不如 AI 化重要。
- 苹果《硬刚涨价…》（2026-07-31）：高预期下业绩显得平淡；下季指引放缓到 +9-11%；估值已升到 35x（此前 29x）而增速放缓，明显“不便宜”，会动摇“为确定性而来”的资金。

**适用场景与注意事项**：适用于所有财报后的股价复盘。避免把市场的短期焦点等同于公司的核心价值变量，两者要分开写。

### 11.1.9 “超预期但股价跌”与“暴雷但跌幅有限”的对称归因清单

**方法要点**：对业绩与股价方向相反的两种情形分别给出检查清单，并用盘后跌幅与跌后估值倍数判断溢价是否已被挤出。

**操作步骤 / 拆分口径**：
1. 业绩超预期但股价跌：检查指引趋势（是否放缓）、利润与增长的取舍（市场偏好利润）、电话会负面表述、估值是否过高。
2. 业绩暴雷但跌幅有限：检查财报前资金是否已根据第三方数据提前下调预期。
3. 好业绩带来情绪释放：此前被压抑的情绪借业绩释放。
4. 看盘后跌幅与跌后的估值倍数，判断溢价是否被挤出。

**关键指标与数据来源**：盘后涨跌幅；跌后估值倍数；财报前股价走势；一致预期修正；第三方数据（见第14章）。

**判断标准**：
- 增长超预期但利润全面不及，在偏好利润的环境下会暴跌。
- 资金已据第三方数据下调预期、但管理层指引比下调后预期更悲观，仍会大跌。
- 业绩不差但估值高、又有行业性担忧，若缺乏亮点就会导致资金出走。
- 先涨后跌，往往归因于电话会内容。

**海豚案例**：
- Roblox（2026-02-06）：业绩偏积极，压抑许久的情绪借机释放。
- Roblox（2026-05-01）：盘后跌 20%，市值剩 316 亿；资金已据第三方数据下调预期，但管理层指引更悲观。
- 多邻国（2026-02-27）：盘后跌 20% 至 42 亿市值；部分机构已调预期，实际指引更保守。
- Sea（2026-03-03）：增长超预期、利润全面不及，在偏好利润的环境下暴跌。
- MercadoLibre（2026-02-25）：先涨后跌，归因于电话会。
- Shopify（2026-05-06）：业绩不差，但高估值加 SaaS 担忧，缺乏亮点就导致资金出走。

**适用场景与注意事项**：通用。第三方数据已提前下调预期的情形，要在财报前预期基准中就体现（见 1.2）。

### 11.1.10 “业绩好但股价跌”的多层归因：当季/指引/叙事阶段/估值位置与前期涨幅

**方法要点**：用五层结构回答“市场善变还是公司有问题”——当季是否超预期、指引、市场叙事阶段、估值位置与前期涨幅（止盈）、同一剧本不同反应所反映的情绪变化。

**操作步骤 / 拆分口径**：
1. 当季是否超预期（含买方预期）。
2. 指引。
3. 市场叙事阶段：如 Capex 从“喜爱”到“厌恶”、AI 回报担忧、内生增长信仰。
4. 估值位置与前期涨幅：判断是否出现止盈。
5. 同一剧本不同反应：把本次与历史上几乎相同剧本的反应对比，说明市场情绪变了还是公司变了。

**关键指标与数据来源**：绩后涨跌幅；财报前涨幅；估值倍数；叙事关键词。

**判断标准**：
- 叙事阶段切换：市场已过“Capex 越高越好”的奖励阶段，转而担心轻资产模式做重、摊薄 ROI。
- 财报前已大幅反弹、情绪过高，指引一旦暴雷就会下跌。
- 估值从低位被抬升、接近 30x 时，享受估值抬升的资金会止盈。
- 无大雷却下跌：属于风格与情绪因素。

**海豚案例**：
- 亚马逊（2026-02-06）：当季小幅跑赢仍暴跌，核心是 2000 亿 Capex 指引——市场已过“Capex 越高越好”的奖励阶段，担心将轻资产模式做重、摊薄 ROI。
- 谷歌（2026-07-27）：与 Q1 几乎相同剧本却绩后跌 7%，根源是 AI 投入回报不确定与 8000 亿支出承诺。
- 奈飞（2026-04-17）：财报前反弹 25% 情绪过高，指引暴雷后盘后跌 9%。
- 谷歌（2026-02-05）：从 19x 享受估值抬升的资金在近 30x 止盈。
- 迪士尼（2026-02-03）：无大雷但跌 6%。

**适用场景与注意事项**：通用；用于财报点评中的“解释市场”环节。同一公司跨季度比较时，要控制住估值与前期涨幅的差异。

### 11.1.11 财报后大跌时区分“当季业绩”与“增量信息”并量化影响

**方法要点**：大跌后先把当季业绩和增量信息（新游延期、AI 投入表态、大股东减持等）分开，再用管理层会后交流量化的利润影响，对比市场原有利润预期，评估冲击大小，并在后续季度检验是否“按剧本走”。

**操作步骤 / 拆分口径**：
1. 拆分：当季业绩（相对预期）与增量信息（延期、投入表态、大股东动作）。
2. 量化：用会后交流给出的利润影响（如 5-10 亿）对比市场原有利润预期（约 35 亿，利润率 10.5%）——影响相当于原预期的约 14%~29%（5÷35、10÷35）。
3. 评估管理层“边看边投”的措辞能缓冲多少风险。
4. 后续季度从费用趋势还原实际影响，检验是否“按剧本走”。

**关键指标与数据来源**：当季业绩 vs 预期；管理层量化的利润影响；市场利润预期；股价跌幅。

**判断标准**：大跌若不是因当季业绩，而是新游延期（如从 Q1 末延期到 Q2 末）加投入表态，就应把后续费用趋势作为验证；实际投入影响与指引一致（“基本是按照指引的剧本走”），说明冲击可控。

**海豚案例**：
- B站《哔哩哔哩：广告硬挺，“瘸腿期”的小破站太难了》（2026-03-05）：大跌不是因为 Q4 业绩，而是《三国：百将牌》从 Q1 末延期到 Q2 末，加上 AI 投入的表态；AI 投入影响利润 5-10 亿，而市场原预期今年利润约 35 亿。
- B站（2026-05-19）：腾讯表示会出售高估值投资资产支撑回购，B站周四、周五合计跌 15%；本季 AI 投入影响约 0.5-1 亿，“基本是按照指引的剧本走”。

**适用场景与注意事项**：通用。量化影响要用管理层口径（会后交流、电话会）而非自行拍数；后续季度的费用还原是闭环验证的一部分。

### 11.1.12 股价暴跌的多因素归因：指引、宏观、情绪、鬼故事、资金结构

**方法要点**：对财报日的暴跌逐层拆出指引、同日宏观事件、板块情绪、此前累积的“鬼故事”、资金结构五类原因，再判断杀估值是否过头、当前价格隐含了什么极端假设。

**操作步骤 / 拆分口径**：
1. 指引趋势是否不达资金预期。
2. 同日宏观事件叠加：如非农超预期，打压降息预期。
3. 板块情绪：成长股、软件股信心不足。
4. 此前累积的“鬼故事”：如 Genie 发布、Meta 回归 iOS 应用内广告、Cloudx。
5. 资金结构：财报前抄底博反弹、博超预期的短线资金，在业绩一般后踩踏止损。
6. 据此判断杀估值是否过头，写出当前价格隐含的极端假设。

**关键指标与数据来源**：股价跌幅；宏观事件；财报前资金结构。

**判断标准**：若财报前已大幅下跌、财报日再度暴跌，而基本面没有逆转，则主因是情绪和信心，而非基本面。

**海豚案例**：
- Unity（2026-02-12）：财报前已从高点跌 30%，财报日再跌近 30%，市值不足 90 亿；海豚君认为主因是情绪和信心，而非基本面逆转。

**适用场景与注意事项**：适用于财报后股价大幅波动的事件点评。多重利空共振后的“黄金坑”判断见 11.2.10；估值倒推的门槛法见 11.3.7。

### 11.1.13 事前预判股价反应：业绩 vs 被拔高的预期、AI 节点、Capex 压力、新故事

**方法要点**：财报前综合四个变量判断股价方向，并把结论写成“预计股价承压，除非有超预期 AI 进展或新故事”这类带条件的预判。

**操作步骤 / 拆分口径**：
1. 业绩对“真实市场预期”的偏差：交付超预期后预期被拔高，利润 miss 就是负面。
2. 估值主导业务（如 AI）的关键节点有没有确认。
3. Capex 和现金流压力。
4. 有没有新故事能撑住高估值（例如特斯拉与 SpaceX 合并，讲一个从 AI infra 到模型再到软硬应用层的故事）。
5. 把结论写成带条件的预判。

**关键指标与数据来源**：利润 vs 预期；里程碑确认情况；Capex 指引；FCF。

**判断标准**：交付超预期 → 期待被拔高；利润不及预期 + AI 节点未确认 + FCF 转负 + Capex 超过 250 亿不变 → 预计股价继续承压；AI 延后加 Capex 压力 → 短期可能让股价震荡，但长周期看 AI 正从“概念 PPT”进入“利润兑现前夜”。

**海豚案例**：
- 特斯拉《造车硬抗…》（2026-07-23）：交付大超预期拔高期待，利润不及预期，AI 节点没确认，FCF 转负，Capex 超过 250 亿不变，预计股价继续承压。
- 特斯拉《造车罕见回血…》（2026-04-23）：AI 延后加 Capex 压力，短期可能让股价震荡，但长周期看 AI 正从“概念 PPT”进入“利润兑现前夜”。

**适用场景与注意事项**：适用于高估值成长股的财报事件判断。要明确写出“除非”的条件，便于事后验证（见 13.3 预测—验证闭环）。

**相关方法交叉引用**：
- “是否已计价”判断：业绩/预期/叙事/估值四要素解释财报后股价，详见 11.2。
- 多重利空共振、叙事主导下的股价反应解释与“黄金坑”判断，详见 11.2。

**本节速查清单**
- [ ] 是否把涨跌拆成预期差、趋势叙事、估值隐含预期、风险偏好、已涨跌程度五项，并看了同期可比公司的财报后反应？
- [ ] 是否分清主驱动是当期业绩、指引、叙事还是外部不确定性（指引权重通常更大）？
- [ ] 是否把表观数字冲击（如 GAAP 非经营亏损）与真实缺陷、外部叙事三层分开？
- [ ] 是否用分钟级行情把盘后走势按财报数据、PPT、电话会分段，找出反转点对应的信息？
- [ ] “业绩好指引好股价跌”时，是否逐层检查本季→下季→全年/长期口径→定性表态→估值？

## 11.2 已定价判断与利空出清

> 本节导读：本节解决“这个好消息/坏消息市场是不是早就知道了”——区分已定价部分与真正的新增量，区分预期内的坏消息与超预期的坏消息，判断大跌之后风险是否出清、关注点该转向“会不会更差”。在股价与基本面背离（利空不跌、利好不涨）或股价已大幅调整的财报点评中使用；与 11.1（归因）、11.3（估值水位与门槛）、1.3（明牌指标与已知/未知排序）配合。

### 11.2.1 “已定价 vs 新增量”：先分清哪些信息市场已提前判断

**方法要点**：解释财报后股价反应时，先区分财报里哪些信息是市场已提前判断并定价的，哪些才是真正新的边际增量；对新增量的应激反应属正常，再判断其本质好坏，给出“下跌是否提供机会”的观点。

**操作步骤 / 拆分口径**：
1. 事先梳理财报前市场已知的信息：指引、调研、小范围交流。
2. 把财报信息逐项标注：已定价（如云加速、利润率提升已在指引或小范围沟通里）vs 新增量（如资本开支暴增、自由现金流深度为负）。
3. 承认市场对新增量的应激反应是正常的。
4. 判断新增量的本质：好还是坏（例如 capex 高投入在高 ROI 前提下反而是利好）。
5. 给出“下跌是否提供机会”的结论。

**关键指标与数据来源**：已披露指引和沟通内容；超预期或不及预期的新指标（capex、FCF）；股价反应。

**判断标准**：新增量若代表资源全面转向高 ROI 方向，则短期 capex 担忧反而会给出向上弹性；新增量若是不被预期的恶化（如 FCF 深度转负），则应激下跌无可厚非。

**海豚案例**：
- 阿里《阿里狂投，只为“中国版谷歌”？》（2026-08-21）：阿里云增长加速、利润释放市场已经定价；真正的新增量是 670 亿资本开支（预期约 360 亿）和约 -450 亿自由现金流，市场应激下跌无可厚非；但海豚君认为资本开支代表资源全面转向 AI，而且云业务 ROI 可期，所以“反而不慌”，短期的 capex 担忧反而会给出向上弹性。

**适用场景与注意事项**：适用于财报后股价与基本面表现背离的情况。需要先梳理财报前市场已知的信息（指引、调研、小范围交流），否则无法划分已定价与新增量。资本开支强度与 ROI 的评估见 10.1、10.2。

### 11.2.2 “是否已计价”判断：业绩/预期/叙事/估值四要素

**方法要点**：先问好消息或坏消息是否已被股价消化，再用事件与股价的对照复盘，落到“当前股价主要在定价哪个变量、下一个催化是什么”。

**操作步骤 / 拆分口径**：
1. 判断坏消息是否已消化：股价持续下跌、市场普遍接受短期承压 → 业绩不佳不会再带来大冲击，边际定价因素转为叙事（新合作、新订单）。
2. 判断好消息是否已消化：强劲业绩已打进预期时，强财报反而成了锁盈契机。
3. 事件与股价对照复盘：合作传闻 → 股价两位数上涨；进军新赛道 → 股价冲高；宏观主题（AI Capex 担忧）→ 涨幅被抹去。
4. 落到结论：当前股价主要在定价哪个变量，下一个催化是什么。

**关键指标与数据来源**：股价区间与事件时间线；市场关注点变化；估值区间位置。

**判断标准**：
- 传统业务低迷“已被市场充分消化”→ 近期业绩不佳不会再带来大影响。
- 剔汇后增长未加速、市场反应平淡 → “合乎情理”。
- 全年出货量已打进股价 → 强财报被视为锁盈契机。
- 股价已计价某次产品发布成功 → 后续基座模型发布前存在回调压力。

**海豚案例**：
- 高通（2026-04-30）：传统业务低迷“已被市场充分消化”，近期业绩不佳不会再带来大影响，与 OpenAI 合作传闻直接拉动股价两位数上涨。
- 高通（2026-07-30）：数据中心布局一度推高股价至 250 美元以上，AI Capex 担忧下回落至 160 美元左右，抹去数据中心涨幅。
- Airbnb《短期业绩没问题，但遇上“中年危机”？》（2026-05-08）：剔汇后增长未加速，市场反应平淡“合乎情理”。
- 宁德（2026-07-25）：2026 年出货已打进股价，投资者把强财报视为锁盈契机。
- MiniMax《大模型血亏 360%，MiniMax 照样“香饽饽”？》（2026-03-02）：刚发完 M2.5，股价已计价成功，DeepSeek 新基座在即有回调压力。

**适用场景与注意事项**：适用于叙事驱动、主题驱动明显的股票（AI、周期高位）；需要结合股价走势和事件时间线。

### 11.2.3 区分“预期内的坏消息”与“超预期的坏消息”

**方法要点**：坏消息如果早有预期（盈利预警、沟通过的趋势、公开流水已在下滑），就不算超预期利空；反之业绩爆表若已被价格数据充分反映，也算已经定价。

**操作步骤 / 拆分口径**：
1. 判断坏（好）消息的来源：盈利预警、管理层沟通、公开高频数据、市场价格数据是否已提前披露趋势。
2. 结合估值位置（历史低位、低 PE）与股价已有调整，判断是否已 priced-in。
3. 对称地，业绩爆表若已被价格数据（如存储市场价格）充分反映，也视为已定价。

**关键指标与数据来源**：估值分位；预警或沟通内容；公开高频数据（流水、价格）。

**判断标准**：事先已有预警/沟通/公开数据 + 估值处于低位 → 利空已 priced-in，不构成“超预期利空”；业绩爆表但价格数据早已体现 → 利好已定价。

**海豚案例**：
- 阿里（2026-01-08）：CMR 放缓到 3-5% 是“预期内的坏消息”（国补消退加变现率高基数），并非突发。
- 美团（2026-03-26）：发过盈利预警，亏损已是明牌。
- 快手（2026-03-25）：可灵小幅 miss，但估值不足 9x PE，利空已 priced-in。
- 心动（2026-03-06）：游戏流水有公开数据，下滑的大部分影响已逐步定价。
- 美光（2026-03-19）：结合存储市场价格，短期“业绩爆表”基本已被市场定价。
- 网易（2026-02-11）：估值已处于历史低位区间。

**适用场景与注意事项**：普遍适用。需要持续跟踪预警、流水和价格类公开数据，才能判断“预期内”。

### 11.2.4 利空已 priced-in 的清单写法

**方法要点**：解释差业绩为何不跌或跌得少：逐项列出市场已知的不利因素（管理层前期指引、行业共识、股价已有跌幅），业绩若只是兑现这些因素，影响就会弱化，市场转向新增变量。

**操作步骤 / 拆分口径**：
1. 列出“已 priced-in 清单”：管理层前期表态、行业共识、股价已有跌幅、已反映的外部冲击。
2. 判断本次业绩是否只是兑现这些因素。
3. 若是，则把关注点转向新增变量（AI 合作、新品等）。

**关键指标与数据来源**：近期股价跌幅；管理层前期表态；行业共识。

**判断标准**：业绩“是不好的，市场也都知道它是不好的”，则不会成为新的下跌理由；股价在短期内已大幅超跌，也属于已计价（超跌）情形。

**海豚案例**：
- 高通（2026-04-30）：下季指引 92-100 亿美元，低于预期的 102 亿，但“业绩是不好的，市场也都知道它是不好的”；OpenAI 端侧合作传闻带动股价两位数上涨。
- 小米（2026-05-26）：股价从 60 港元跌到 30 港元，已反映存储短缺、手机低迷、汽车降温。
- 零跑（2026-05-15）：priced-in 项为 Q4 会上已给淡季环比下滑指引、T03 占比从 11% 升到 22%、A10 下沉。
- 唯品会（2026-05-21）：Q2 负增长是行业共识。
- 阿里 preview（2026-07-08）：股价一个多月从 130 跌破 90，属于超跌。

**适用场景与注意事项**：适用于已大幅下跌、利空众所周知的标的。清单越具体越有说服力，同时要注明哪些因素是“新增量”而没有被计入。

### 11.2.5 机构预期已下调时，“明确下调指引”视为利空落地

**方法要点**：当公司全年目标已明显难以完成、主流机构已普遍下调预期时，如果管理层明确下调指引，市场可能把它解读为利空出尽，而不是新的利空。

**操作步骤 / 拆分口径**：
1. 比较三者：公司目标、机构一致预期、海豚君自己的测算。
2. 判断公司目标与实际进度、机构预期的差距有多大。
3. 若机构预期已显著低于公司目标，则管理层下调只是向市场预期靠拢，视为“利空落地”。

**关键指标与数据来源**：公司目标；机构一致预期；海豚君测算值。

**判断标准**：目标与进度明显脱节、主流机构已下调 → 管理层明确下调即为利空落地信号。

**海豚案例**：
- 小米《又双叒原地久跪…》（2026-08-18）：55 万目标在前 7 个月仅交付 21.6 万，主流机构已普遍下调到 46-50 万；若管理层明确下调，倒是“利空落地”信号。

**适用场景与注意事项**：适用于指引偏离市场预期较大的公司。指引保守度与管理层风格见 9.4，指引修订轨迹见 9.6。

### 11.2.6 股价大幅下跌后：列已计入的利空，把关注点转向“会不会更差”

**方法要点**：股价已大幅下跌时，先列出已被市场充分认知的利空，再界定市场接下来真正关注的边际问题，让财报解读围绕边际问题而不是重复已知利空。

**操作步骤 / 拆分口径**：
1. 记录股价回撤幅度（如从 60 港元跌到 30 港元）。
2. 列出已被市场充分认知的利空清单（如存储紧张、国补退坡、汽车积压订单消化）。
3. 界定边际问题：传统业务会不会更差（手机毛利率是否跌破 8%、IoT 何时重回增长）、目标是否下调、有没有超预期的新看点（出海、AI、机器人）。
4. 给每个边际问题设阈值，围绕阈值解读财报。

**关键指标与数据来源**：股价回撤幅度；已知利空清单；边际关注指标阈值。

**判断标准**：若硬件毛利率已稳住、经营面很难继续恶化，则存储影响已在股价中体现；若边际指标跌破阈值（如手机毛利率跌破 8%），则风险并未出清。

**海豚案例**：
- 小米《又双叒原地久跪…》（2026-08-18）：股价从 61 港元跌到 30 以下，逆风已被充分认知，市场关注手机毛利率是否跌破 8%、IoT 何时回到增长、55 万目标是否下调。
- 小米《跌到怀疑人生？…》（2026-05-26）：存储影响已在股价中体现，硬件毛利率已稳住，经营面很难继续恶化。

**适用场景与注意事项**：适用于股价已大幅调整的公司财报点评。阈值设定要有数据依据（历史区间、同业基准）。

### 11.2.7 用市值回撤幅度判断风险计价程度，即“风险是否出清”

**方法要点**：比较市值从高点的回撤幅度与基本面恶化程度，判断跌幅是在消化已发生的爆雷，还是已计价未来最悲观情景。

**操作步骤 / 拆分口径**：
1. 取市值高点与当前值，计算区间回撤。
2. 列出已发生的爆雷（当季）与未来可能的恶化情景（如下一年量价双杀、利润同比下滑）。
3. 比较跌幅所对应的恶化程度：若跌幅只消化了当季爆雷、未计价未来情景，则判定风险未出清。
4. 需要至少一个季度的业绩验证再下结论。

**关键指标与数据来源**：市值高点与当前值；区间回撤 %；未来利润情景。

**判断标准**：跌幅只覆盖已发生的爆雷 → 风险未出清；跌幅已覆盖未来最悲观情景 → 才可视为出清。

**海豚案例**：
- 阳光电源《平地起惊雷》（2026-04-01）：市值从三季报后超 4000 亿回撤至约 2792 亿（-36%），海豚君认为主要在消化四季报爆雷，尚未计价 2026 年量价双杀，结论是断言风险出清为时尚早。

**适用场景与注意事项**：适用于财报暴雷后判断是否抄底的场景。未来情景要有具体的量、价、利润假设。

### 11.2.8 业绩预告后：用盘面反应判断 price-in 与关注焦点转移

**方法要点**：业绩预告已发布时，正式财报的关注点要转向指引和未知信息；用预告次日的盘面反应及之后的估值修复动能，判断资金对后续增长的置信度。

**操作步骤 / 拆分口径**：
1. 标出预告发布日与次日盘面反应，判断市场对预告结果是否满意。
2. 观察预告后的估值修复动能。
3. 在正式财报点评中，把焦点转到指引与预告未覆盖的信息（如剥离业务后的指引）。

**关键指标与数据来源**：预告后股价反应；修复动能。

**判断标准**：预告日盘面显示满意但后续修复动能不强 → 说明资金对后续增长的置信度有限，焦点在指引。

**海豚案例**：
- 美图（2026-08-26）：7 月 30 日发布预告，7 月 31 日盘面显示市场相对满意，但后续估值修复动能不强。
- Unity（2026-05-08）：3 月底已发预告，本次焦点是剥离 IronSource 后的指引。

**适用场景与注意事项**：有业绩预告制度的港股/美股公司。

### 11.2.9 估值倍数历史轨迹 + 叙事拆解，判断已 priced-in 的部分

**方法要点**：追踪估值倍数轨迹，拆出驱动叙事并逐条判断兑现状态，推断“多少已经计价、多少仍有预期差”，并写出估值能否继续拉升所需条件。

**操作步骤 / 拆分口径**：
1. 追踪估值倍数轨迹（如百度 FY26 EV/GAAP EBIT 从 10x → 最高 25x → 回落 20x）。
2. 拆出驱动叙事：算力国产替代、创新业务分拆上市、股东回报提高、双重主板上市后入通。
3. 逐条判断兑现状态：已官宣（50 亿回购）、进行中（昆仑芯上市流程）、未兑现（萝卜快跑拆分、入通）。
4. 汇总：一半已 priced in，另一半有预期差但市场多少知晓。
5. 写条件：只有“估值回调 + 临近兑现”才能重复拉升；向上需基本面正面预期差（云显著超预期或传统广告触底）。

**关键指标与数据来源**：EV/EBIT；事件兑现状态。

**判断标准**：已官宣 → 已计价；进行中 → 部分计价；未兑现 → 有预期差但需临近兑现再度催化；无基本面预期差时，估值不能单靠叙事再度抬升。

**海豚案例**：
- 百度《百度：广告根基已废，昆仑芯成“救命草”？》（2026-02-26）：FY26 EV/GAAP EBIT 倍数从 10x 升至最高 25x、回落到 20x；拆出算力国产替代、创新业务分拆上市、股东回报提高、双重主板上市后入通四条叙事；50 亿回购已官宣，昆仑芯上市流程进行中，萝卜快跑拆分与入通尚未兑现；结论是“一半已 priced in，另一半有预期差但市场多少知晓”，只有“估值回调 + 临近兑现”才能重复拉升，向上需云显著超预期或传统广告触底这类基本面正面预期差。

**适用场景与注意事项**：叙事驱动型股票。需维护叙事清单与兑现状态表。

### 11.2.10 多重利空共振、叙事主导下的股价反应与“黄金坑”判断

**方法要点**：业绩不错却下跌时，区分业绩预期差、估值位置、叙事与情绪三类原因；若多种利空同时爆发造成情绪低谷、中长期担忧又被一次性打进股价，则视为情绪修复后的“黄金坑”。

**操作步骤 / 拆分口径**：
1. 区分三类原因：①业绩预期差；②估值位置；③叙事和情绪（行业整体如软件股“AI 侵蚀”、宏观事件如非农超预期打击降息预期、同行指引保守）。
2. 判断是否多种利空同时爆发造成情绪低谷。
3. 判断中长期担忧是否已被一次性打进股价，若是则视为情绪修复后的“黄金坑”。
4. 在长期威胁笼罩下，记住“没有好消息就等于坏消息”，需要超预期业绩才能给资金信心。

**关键指标与数据来源**：股价表现；宏观数据；同行财报；市场叙事。

**判断标准**：中长期的假设演绎在当下一次性打入股价、情绪处于冰点 → 一份不出错的财报就足以释放部分担忧；长期威胁下业绩只是“持平” → 仍会下跌。

**海豚案例**：
- AppLovin（2026-02-12）：非农超预期打击降息预期、同行 Unity 预期保守等利空同时爆发；“中长期的假设演绎，在当下就打入股价到位绝非理性”。
- Spotify（2026-02-10）：北美涨价慢、连续涨价后的流失、AI 冲击等多重负面叙事叠加，一份不出错的财报就足以释放部分担忧。
- Uber（2026-08-06）：业绩与预期大体持平，股价仍跌超 5%，“目前没有好消息就等同于坏消息”。
- Meta（2026-07-30）：Meta 成为“算力过剩、产业链见顶”叙事的导火索。

**适用场景与注意事项**：情绪主导期的成长股。“黄金坑”判断需要配合 11.3 的估值水位与 11.2.7 的风险是否出清检验，防止把仍在下行的基本面误判为情绪坑。

### 11.2.11 已 Price in 后跳出当期、转做年度展望

**方法要点**：当管理层此前已多次下调当季指引、外资行门店高频数据也已提前反映疲软时，判定当季业绩已被计入，点评重点就从当季数字转到下一年的核心变量。

**操作步骤 / 拆分口径**：
1. 统计指引下调次数，核对外资行门店高频数据。
2. 判定当季业绩已 Price in。
3. 点评重点转向下一年的核心变量（新管理层、新品周期、研发周期缩短、小单快反等），围绕“能否激活消费者”来写。

**关键指标与数据来源**：指引下调次数；外资行门店高频数据；管理层电话会中的战略口径。

**判断标准**：当季已被计入后，股价弹性取决于下一年能否激活消费者，而非当季数字。

**海豚案例**：
- Lululemon《放弃慢工细活…》（2026-03-18）：Q4 疲软已被指引下调和北美门店高频数据提前 Price in，海豚君转而展望 2026：新创意总监的产品 2–3 月集中上市，新品开发周期从 18–24 个月缩短到 12–14 个月，爆款 6–8 周补货，即转向 ZARA 式小单快反。

**适用场景与注意事项**：适用于基本面已长时间下行、市场预期很低的困境反转股。

**相关方法交叉引用**：
- 管理层事先沟通/刚更新指引，借此判断 miss 的成色，详见 1.5。
- 识别“明牌”指标和已打入预期的利空，把焦点放到真正的增量信息和全年展望上，详见 1.3。
- “预防针”情境下的业绩质量判断，详见 2.1。

**本节速查清单**
- [ ] 财报前市场已知的信息（指引、调研、小范围交流、预警、公开高频数据）是否已逐项梳理？
- [ ] 财报里的信息是否标注为“已定价”或“新增量”，对新增量是否判断了本质好坏？
- [ ] 坏消息是“预期内”还是“超预期”？估值是否已处于历史低位？
- [ ] 是否列出了“已 priced-in 清单”，并指出哪些变量尚未计入？
- [ ] 股价大跌后，是否把关注点转向“会不会更差”并设定了边际阈值？
- [ ] 风险是否出清：跌幅只覆盖了当季爆雷，还是已覆盖未来最悲观情景？
- [ ] 若管理层已有预告或此前多次下调指引，是否跳出当期、转做年度展望？
- [ ] 多重利空共振时，中长期担忧是否已被一次性打进股价（黄金坑），是否仍需要业绩验证？

## 11.3 估值水位、情绪与业绩门槛

> 本节导读：同样一份业绩，在不同估值水位、不同市场情绪、不同预期位置下，意义完全不同。本节教你先确定“这份财报要好到什么程度才够”——即业绩门槛：从估值水位、同行龙头指引、当前市值倒推的隐含预期，到管理层预告抬高的预期、财报前股价位置与宏观环境，再到价格驱动型周期股、低波动稳健股各自的股价决定逻辑。财报前（预判门槛）与财报后（解释“符合预期却下跌”）都要用；与 11.1（归因）、11.2（已定价）、1.2（买方真实预期还原）、第12章（估值更新）配合。

### 11.3.1 估值水位决定预期门槛：低估值低预期 vs 高估值高期待

**方法要点**：同样的业绩，在不同估值水位下股价反应不同，解读财报前先确认估值水位，据此判断“边际改善就能修复信心”还是“符合预期也会失落”。

**操作步骤 / 拆分口径**：
1. 取当前 PE，对比历史区间和同行。
2. 判断市场对利空的认知程度（是否已充分了解、是否没有给过多期待）。
3. 估值处于历史低位、利空已被充分认知 → 边际改善（毛利率回升、AI 亮眼）就能带来信心修复。
4. 估值高企 → 即使符合预期，市场也会有点失落。

**关键指标与数据来源**：当前 PE vs 历史区间/同行；市场对利空的认知程度；需维护历史估值区间数据。

**判断标准**：低估值 + 利空已充分认知 → 门槛低，改善即可；高估值 → 门槛高，需要超预期或上调展望，但高成长逻辑未变时仅是“短期失落”。

**海豚案例**：
- 海康（2026-04-18）：18 倍 PE 处于历史区间中间偏下，行业压力市场已充分了解、没有给过多期待，毛利率持续提升有望重新带来信心。
- 戴尔（2026-02-27）：9 倍 PE 接近历史下限，已经包含了存储紧张的担忧；AI 表现亮眼有望推动业绩和估值回升，存储周期缓解后还有修复空间。
- Marvell（2026-05-28）：37 倍 PE 已包含过高期待，年度指引没有惊喜，短期会让市场有点失落，但高成长逻辑仍在。

**适用场景与注意事项**：通用，需要维护历史估值区间数据。估值的更新与区间对比方法见 12.2。

### 11.3.2 高估值股“符合预期”的含义：要靠超强业绩支撑，并看风格在成长与确定性之间如何切换

**方法要点**：同样是“符合预期”，对估值高低不同的股票意义不同；PE 上百倍的股票需要持续的超强业绩来消化估值，市场风格从“成长性”转向“确定性”时，高估值标的被杀估值更明显。

**操作步骤 / 拆分口径**：
1. 算当前 PE。
2. 对比增速（可计算 PE/增速）。
3. 判断当期市场风格：成长性 vs 确定性（AI 链脆弱、大厂开始谨慎投入时，风格转向确定性）。
4. 看财报是否给出了足以支撑估值的增量。
5. 反向同理：增速 40% 以上而 PE 不到 20x，就进入了有吸引力的区域。

**关键指标与数据来源**：PE；营收增速；PE/增速；宏观与风格变量（大厂 capex 态度、美债利率、AI 融资成本）。

**判断标准**：只符合预期再加上部分下修，就足以构成失望；增速高、估值低，则回落后有吸引力；需要更强的指引来应对宏观与风格压力。

**海豚案例**：
- ARM《ARM：大厂“收手”，天价估值先“降温”？》（2026-07-30）：FY27 PE 约 100 倍，增速只有 20% 以上，本季符合预期，但 Royalty 全年增速从 20% 下调到 18%，CPU 需求也没有上调，判断为市场会失望；同篇提到微软不再上调资本开支反而获得市场奖励，可能引发多米诺骨牌效应。
- 台积电（2026-10-15）：美债利率破 5%、Anthropic 数据偏弱，市场需要更强的指引；增速 40% 以上、PE 不到 20x，回落后的台积电有吸引力。

**适用场景与注意事项**：成长股和高估值股。需要同时判断宏观和行业风格，不能只看公司自身。

### 11.3.3 叙事背景决定业绩门槛：“没有好消息就是坏消息”

**方法要点**：结合市场当前的担忧（自动驾驶威胁、AI capex 持续性、AI 替代 SaaS、高预期避风港）设定“足以改变情绪”所需的业绩门槛。

**操作步骤 / 拆分口径**：
1. 列出市场主流担忧。
2. 判断股价前期位置与估值水位。
3. 设定门槛：担忧氛围下，符合预期等于利空；预期已经很低时，比悲观预期好一点就能托底；高估值避风港股需要亮眼信息。

**关键指标与数据来源**：市场主流担忧；股价前期位置；估值水位。

**判断标准**：无惊无喜 = 坏消息（担忧氛围下）；低预期下的逆势改善（如广告收入逆势加速）= 支撑；避风港估值被抬高后，平淡财报 + 指引放缓 = 信心受影响。

**海豚案例**：
- Uber（2026-08-05）：自动驾驶威胁下，无惊无喜就等于坏消息。
- 苹果（2026-07-31）：成了 AI 回调中的避风港，估值被抬高，财报平淡加上指引放缓影响信心。
- 拼多多（2026-08-24）：在低预期下，广告收入逆势加速，就能给股价支撑。
- 英特尔（2026-07-24）：在 Meta 算力出租、K3 模型等冲击下，涨价链在脆弱市场中阶段性提供信心。

**适用场景与注意事项**：情绪驱动明显的时段。

### 11.3.4 高估值/故事驱动型公司：展望与电话会重于当期业绩

**方法要点**：对估值大部分来自未来期待的公司，财报后的电话会展望比当期业绩“更为重要”；用三条标准检验展望能否撑住高估值。

**操作步骤 / 拆分口径**：
1. 有没有宣布新大客户或新订单。
2. 全年关键产品指引（如 AI GPU 全年收入）有没有上调。
3. 新品出货当季的环比增量是否足够亮眼。
4. 三者都没有超出市场期待 → 即使业绩符合预期，高估值也会被“打折”。
5. 反之，长期逻辑没变时，短期平淡的业绩会被市场“原谅”。

**关键指标与数据来源**：新客户或新订单数量；全年分产品指引（是否上调）；下季环比增量；估值倍数相对同行的溢价。

**判断标准**：估值越依赖远期，当期业绩的权重越低；长期逻辑延续（数据中心、CSS、自研 AI CPU 等）→ 短期平淡可被原谅。

**海豚案例**：
- AMD《AMD：狂抢“AI 大单”，市场为何不领情？》（2026-08-05）：业绩基本符合预期，但没有宣布新大客户，全年 AI GPU 指引（140-150 亿美元）没有上调，MI455X 开始出货的下季环比增量也只是小幅提速，所以高估值“打个折”。
- ARM《ARM：“短期波动”难掩锋芒》（2026-05-07）：短期业绩平淡，“最后还是会被选择原谅”，因为数据中心、CSS 和自研 AI CPU 这些长期逻辑在延续。

**适用场景与注意事项**：适合高估值成长股（AI 芯片、IP 授权）。估值越依赖远期，当期业绩的权重越低。

### 11.3.5 用同行龙头的指引作为门槛，判断“够不够格”

**方法要点**：同一赛道里被期待更高成长性的挑战者，用龙头同期的增速、环比增量或指引作为门槛；挑战者增速跟不上龙头，即使符合自身预期，也撑不起溢价估值。

**操作步骤 / 拆分口径**：
1. 选定可对标的龙头（如英伟达）。
2. 取龙头最新季度的环比增量、下季指引环比增量、同期增长展望。
3. 与挑战者的相应指标对比，考虑体量差异。
4. 若挑战者作为更具成长性的赛道仍低于龙头，则判定“不够优秀”。

**关键指标与数据来源**：龙头最新季度环比增量与指引；同期增长展望。

**判断标准**：挑战者的环比增量/增速展望低于龙头 → 溢价估值缺乏支撑。

**海豚案例**：
- 博通（2026-06-04）：英伟达最新季度环比增 130 亿、下季指引环比增 80~90 亿，博通下季 AI 收入只环比增 52 亿，作为更具成长性的 ASIC 赛道，“显然不够优秀”。
- Marvell（2026-08-28）：FY28 数据中心增速展望 60% 以上，而英伟达这样的体量给出的明年增长指引都是 70% 以上，说明连接业务的爆发力也不够。

**适用场景与注意事项**：适合有明确龙头可对标的赛道，比较时要考虑体量差异。同业对标的一般方法见 14.5。

### 11.3.6 从当前股价/市值反推市场隐含的经营预期

**方法要点**：用当前市值和合理估值倍数，反推市场实际计入的销量或收入，以此判断财报和指引相对“市场真实预期”的方向，而不只是相对卖方预测。

**操作步骤 / 拆分口径**：
1. 取当前市值。
2. 假设合理估值倍数（如 P/S）。
3. 反推隐含的收入，再折算为隐含销量。
4. 把财报与指引对比这个隐含预期，判断超预期或不及预期。

**关键指标与数据来源**：市值；P/S 倍数；隐含销量和收入。

**判断标准**：财报与指引高于隐含预期 → 正向预期差；低于 → 负向预期差；同时评估托底因素（如净现金和新车周期）。

**海豚案例**：
- 理想（2026-03-12）：“从目前理想股价来看，市场对理想 2026 年的销量预期为 50 万辆”，同比 +23%，对应 2026 年 P/S 约 1 倍；又指出收入指引低于预期，但净现金和新车周期可以托底。

**适用场景与注意事项**：适用于判断买方真实预期。反推依赖估值倍数假设，需要说明。买方预期还原见 1.2。

### 11.3.7 估值倒推：从估值倍数反推所需增长，并换算成季度环比门槛

**方法要点**：把估值倍数翻译成单季可验证的指标门槛——正向由倍数推所需 CAGR 与季度环比，反向由季度环比路径推市值区间，判断当前市值需要怎样的单季表现来支撑。

**操作步骤 / 拆分口径**（公式：所需 EBITDA CAGR ≈ EV/EBITDA 倍数 ÷ 类 PEG 比率）：
- 正向：
  1. 取当前估值倍数（如 40x EV/EBITDA）。
  2. 用类 PEG 比率（EV/EBITDA-to-growth 0.85x）倒推所需的 EBITDA 3 年 CAGR（40 ÷ 0.85 ≈ 47% 以上）。
  3. 换算成总收入 CAGR（15%-20%）和核心业务 CAGR（25%）。
  4. 折算为平均季度环比增速（5%-6%）。
- 反向：
  1. 设定核心子业务的季度环比路径（15% 逐步放缓到 10%）。
  2. 推出年化同比，再推分部增速。
  3. 乘以利润率得调整后 EBITDA。
  4. 给行业中性偏高倍数，得市值区间。
  5. 对比财报前市值，判断下一个季度需要满足的条件。

**关键指标与数据来源**：EV/EBITDA；EBITDA CAGR；收入 CAGR；季度环比；调整后 EBITDA 利润率。

**判断标准**：当前市值需要的季度环比若显著高于业务现实路径，则估值有压力；财报前市值落在反向推出的区间内，则下个季度的核心业务环比必须达到路径起点。

**海豚案例**：
- Unity（2026-02-12）：要匹配 40x EV/EBITDA，需 EBITDA 3 年 CAGR 47% 以上，Grow CAGR 25%，即平均环比 5%-6%。
- Unity（2026-08-07）：Q1 Vector 环比 +15%，剩余三季从 15% 放缓到 10%，隐含 Vector 年化同比 60%-70%、Grow 40%-50%；按 30% 调整后 EBITDA 利润率得 6-6.5 亿，给 25-30x，对应 150-200 亿；财报前市值 155 亿，即 Q2 须满足 Vector 环比 +15%。

**适用场景与注意事项**：高估值、预期驱动的成长股；关键在于把估值翻译成单季可验证的指标门槛。类 PEG 比率与目标倍数属于假设，须明示。估值框架的完整更新见第12章。

### 11.3.8 推算资金的关键指标门槛（环比 → 年化）

**方法要点**：在业务拐点期，只盯一个核心指标的环比增速，把资金预期换算成隐含年化同比，扣除剥离业务影响，推出战略业务需要达到的环比门槛，再用实际值和指引对照。

**操作步骤 / 拆分口径**（换算：年化同比 ≈ (1 + 季度环比)^4 − 1，如 15% 环比 ≈ 75% 年化，12% 环比 ≈ 57% 年化）：
1. 确定核心指标（如核心业务的环比增速）。
2. 把资金预期（如 15%+ 环比）换算成隐含年化同比。
3. 扣除剥离业务和被并出业务的影响，推出战略业务所需的环比门槛。
4. 用实际值和下季指引对照门槛。
5. 超预期之后，拆分“份额让出”与“内生增长”，判断质量。

**关键指标与数据来源**：核心业务环比增速；隐含年化增速；剥离业务影响。

**判断标准**：实际环比与指引均高于门槛 → 达标；超预期后需要拆分被剥离业务让出的份额与新业务自身的内生增长，才能确认含金量。

**海豚案例**：
- Unity（2026-08-06）：资金对 Vector 环比预期 15%+（年化 75%），扣除 IronSource 剥离和 Supersonic 后，战略 Grow 门槛 12%（年化 57%）；实际环比 +18%，Q3 指引 16%，高于 10% 门槛；需拆分 IronSource 4 月关闭让出的份额和 Vector 内生增长。

**适用场景与注意事项**：转型期公司、单一核心变量驱动的个股。内生增长还原的口径方法见 4.2。

### 11.3.9 用上次给出的合理估值对比财报前股价，解释“超预期却下跌”

**方法要点**：回看上季财报给出的合理估值：如果财报前股价已涨到目标附近、相对同行还有溢价，资金就需要“更完美的业绩”，任何瑕疵都会被放大——把股价反应归因到估值位置，而不是业绩本身。

**操作步骤 / 拆分口径**：
1. 取上次财报给出的合理估值（如按未来 2-3 年利润增速给 40x P/E，对应 350 亿）。
2. 对比财报前的市值（342 亿）。
3. 对比同行估值，判断是否仍有溢价。
4. 估值空间不大且有溢价时，次要指标的瑕疵会被放大镜挑刺。

**关键指标与数据来源**：历史目标估值；财报前市值；同行估值。

**判断标准**：财报前市值已逼近自己上次给出的合理估值 + 相对同行溢价 → 需要更完美的业绩；股价自低点反弹超 30% 后估值约 25-26x → 属于中性。

**海豚案例**：
- Reddit《超预期却暴跌，“雷”藏哪里了？》（2026-07-31）：上次按未来 2-3 年利润增速给出今年 40x P/E、对应 350 亿，财报前已涨到 342 亿，估值空间不大且相对同行有溢价，于是美国 DAU 首次环比下滑被放大镜挑刺。
- 亚马逊（2026-04-30）：股价自低点反弹超 30% 后，估值约 25-26x，属于中性。

**适用场景与注意事项**：财报前股价大涨的公司。要保留自己历史给出的合理估值记录（见 13.3 复盘）。

### 11.3.10 情绪对照法：按历史市场情绪推算应有涨幅，与实际涨幅比较并归因差异

**方法要点**：把同样质量的财报放到过去的市场情绪中估算应有涨幅，与实际涨幅比较，差异即为当前情绪折价，再逐项归因。

**操作步骤 / 拆分口径**：
1. 选取参照期（如 24 年至 25 年上半年）的同类财报后涨幅，估算应有涨幅（如 10%+）。
2. 与实际涨幅（不到 7-8%）比较。
3. 归因差异：行业叙事（AI 原生应用颠覆软件的“鬼故事”）、买方预期惯性（习惯 10-20% 的 beat）、指数纳入利好消化后增量买盘减少、对次要指标（TCV、客户净增环比放缓）挑刺。
4. 分析财报后的资金结构：赌财报的资金离场；已杀估值导致空头回补动力弱。

**关键指标与数据来源**：盘后涨跌幅；历史财报后涨幅；市值变化；行业叙事；指数纳入事件。

**判断标准**：实际涨幅低于历史情绪下的应有涨幅，差异来自叙事与预期惯性；若美国商业 miss、指引隐含放缓、TCV 收敛，则赌财报资金离场；但此前杀估值已消化一部分时，空头大幅惩罚的意愿也有限。

**海豚案例**：
- Palantir《再交硬核成绩单》（2026-02-03）：盘后涨幅不到 7%，按以往情绪至少涨 10% 以上；市值从近 5000 亿高点缩至 3800 亿。
- Palantir《软件末日论汹涌》（2026-05-05）：美国商业 miss、指引隐含放缓、TCV 收敛，赌财报资金离场；但此前软件股杀估值已消化一部分，空头大幅惩罚的意愿也有限。

**适用场景与注意事项**：适用于高估值、高关注度的成长股。需有足够的历史财报后涨幅记录作对照。

### 11.3.11 事前判断资金对业绩要求的高低：股价位置 + 宏观

**方法要点**：财报前，如果股价已从低点大幅反弹、投资逻辑已部分反转、宏观波动又在抬头，则判断资金对本次业绩要求高；恐慌后的低位则相反。

**操作步骤 / 拆分口径**：
1. 计算财报前股价自低点的反弹幅度。
2. 判断投资逻辑是否已部分反转。
3. 判断宏观波动（利率、风险偏好）是否抬头。
4. 参考投行预期。
5. 结论：反弹大、宏观波动抬头 → 要求高，喜忧参半的业绩会导致下跌；恐慌后的低位 → 小的改善就可能带来上涨，脆弱情绪下的杀估值也容易过头。

**关键指标与数据来源**：财报前股价反弹幅度；宏观波动；投行预期。

**判断标准**：资金要求高 → 喜忧参半 = 失望；资金要求低（恐慌低位）→ 小改善即可上涨。

**海豚案例**：
- 甲骨文（2026-06-11）：股价自四月初低点反弹 40% 以上，投行普遍认为资金对业绩要求较高，喜忧参半的业绩令人失望。
- Unity（2026-02-12）：脆弱情绪下杀估值过头。

**适用场景与注意事项**：财报前预判与财报后股价解释均可使用。

### 11.3.12 管理层前瞻表态/提前预告/小范围沟通抬高预期，导致“符合”也会下跌

**方法要点**：解释“业绩不错但股价跌”时先问市场真实预期在哪——管理层在上季电话会、月度数据、小会上的提前表态，已把预期抬高（甚至被激进买方抬到高于一致预期），实际结果只要与行业大盘持平或略低于激进买方预期，就会出现利好兑现、获利了结。

**操作步骤 / 拆分口径**：
1. 回看上季电话会措辞：是否已明确表示数据向好。
2. 查月度经营数据与管理层预告增速，对比当时一致预期。
3. 查是否有小会上与部分机构的提前沟通。
4. 还原买方真实预期（可能高于一致预期），观察财报前股价走势与盘前/盘中涨跌。
5. 实际结果与行业大盘持平或略低于激进买方预期 → 利好兑现。
6. 反向：前一季业绩不错但股价已回调 → 形成易于触底反弹的基础。

**关键指标与数据来源**：上季电话会措辞；月度经营数据；管理层预告增速 vs 当时一致预期；财报前股价走势；盘前/盘中涨跌。

**判断标准**：提前预告把预期抬高 → 符合甚至小幅 miss 都会被放大；管理层在小会沟通 → 资金已提前博弈，财报后高开低走。

**海豚案例**：
- 亚朵《亚朵：酒店回血…》（2026-05-13）：Q4 电话会已表示春节 ADR 与 OCC 均超去年、Q1 RevPAR 继续改善，市场预期不低；实际与大盘持平，略低于部分激进买方预期，盘前下跌。
- 嘉信《嘉信理财：内生增长稳健…》（2026-04-16）：2 月亮眼经营数据后管理层预告 Q1 收入 +16%（当时预期 14.5%），提前拉高预期，收入略 miss 被放大。
- 古茗《古茗：补贴退坡，茶饮界 Costco 依然稳健！》（2026-03-26）：公司此前在小会上与部分机构沟通，资金获利了结，财报后高开低走。
- Block《Block：美版支付宝暴力裁员 40%!…》（2026-02-27）：上季业绩不错但股价回调 15%，形成触底反弹基础。
- Robinhood《Robinhood：美股散户罗宾汉…》（2026-08-11）：6 月经营数据已大超卖方预期，财报预期内不错，短期资金利多兑现撤出。

**适用场景与注意事项**：适用于所有财报后股价解读。关键是还原买方真实预期，而不只看彭博一致预期（见 1.2）。管理层事先沟通对 miss 成色的影响见 1.5。

### 11.3.13 结合财报前的预期位置和情绪评估“好坏”：冰点、低预期、资金抢跑

**方法要点**：同样的结果在不同预期位置下含义不同，评估好坏前先确定当前处于情绪冰点、低预期还是资金抢跑状态。

**操作步骤 / 拆分口径**：
1. 情绪冰点（多个负面叙事叠加）：“不出错”就能释放压抑。
2. 低预期：达标只是“低预期内的符合预期”。
3. 资金抢跑（参照激进机构的预估）：即便符合彭博一致预期，也会暴跌。
4. 被惩罚很久之后的超预期：值得“甜枣”。
5. 若调整已久、有回购托底：不会引发持续惩罚。

**关键指标与数据来源**：财报前股价回撤；预期修正方向；机构预期分化。

**判断标准**：把“结果”放在“预期位置”上读，而不是绝对数字；资金抢跑 + 指引偏弱 → 暴跌。

**海豚案例**：
- Spotify（2026-02-10）：多个负面叙事下情绪处于冰点，一份“不出错”的财报就能释放情绪。
- Rivian（2026-02-13）：基于“低预期”的不错业绩。
- Lululemon（2026-03-18）：连续下调指引后的“低预期内的符合预期”。
- 泡泡玛特（2026-03-25）：下半年业绩没有 miss BBG，只是低于部分激进机构的预估（资金抢跑），再加上 2026 年指引仅 20%，下午暴跌 22%。
- Meta（2026-01-29）：被惩罚许久，“值得一个甜枣”。
- 百度（2026-02-26）：股价调整已久、有回购托底，不会引发持续惩罚。

**适用场景与注意事项**：普遍适用。

### 11.3.14 预期被提前拉高 / 高估值下“不够好”的六类原因

**方法要点**：用六类原因解释“好业绩为何不涨甚至下跌”，逐项核对哪几条适用。

**操作步骤 / 拆分口径**：
1. 管理层预告或月度数据拉高了预期。
2. 财报前股价已大涨。
3. 高估值下“不上修即低于预期”。
4. 连续多季大 beat 形成惯例（平淡显得不够）。
5. 长期指引已给出，短期小超没有增量。
6. 盘后先涨，电话会给出谨慎全年指引后降温。

**关键指标与数据来源**：财报前股价涨幅；估值倍数；管理层预告；长期目标。

**判断标准**：命中的原因越多，下跌概率越高；高估值叠加叙事分歧，资金更挑剔。

**海豚案例**：
- 嘉信（2026-04-16）：管理层提前预告 Q1 增速 16%（当时预期 14.5%），“提前一个月拉高预期”。
- 沃尔玛（2026-05-21）：估值 45x+，全年指引不上修，盘前 -2~3%，属于“业绩不差但不够好”。
- 英伟达（2026-05-21）：GTC 已把累计收入上调到 1 万亿美元，短期小超难有提振。
- 台积电《26Q2》：市场需要“强心剂”。
- Shopify：相比连续多季大 beat 显得平淡。
- AMAT（2026-05-15）：盘后一度 +7%，全年谨慎指引出来后降温。
- Palantir：高估值加叙事分歧，资金更挑剔。

**适用场景与注意事项**：适用于高估值、高关注的强势股。

### 11.3.15 边际价格决定股价方向：区分“上涨条件”和“下跌条件”，判断区间震荡

**方法要点**：对价格驱动的周期股，明确写出股价向上和向下各自需要什么条件，据此推导股价状态；并把回调拆成行业 β 与产品结构两部分评估抗跌性。

**操作步骤 / 拆分口径**：
1. 写出上涨条件：如大幅拉估值需要 ASP 环比涨幅再次提速。
2. 写出下跌条件：如大跌需要边际价格向下。
3. 判断当前条件是否满足；两者都不满足 → “不上不下”的区间震荡。
4. 看产业链位置：AI capex 担忧下的回调，涨价链条上的股票跌得最多。
5. 拆产品结构评估抗跌性：如英特尔拆成客户端（纯涨价）与服务器 CPU（量价齐升）两部分。
6. 与行业回调对比，把行业 β 拖累与公司自身问题分开（见 11.5.1）。

**关键指标与数据来源**：ASP 环比变化方向；股价回调幅度 vs 行业；业绩驱动的量价结构。

**判断标准**：上涨条件与下跌条件都不满足 → 区间震荡；回调幅度小于行业 → 被视为行业 β 拖累，而非公司自身问题。

**海豚案例**：
- 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：股价“不上不下”区间震荡的判断（拉估值需 ASP 环比提速，大跌需边际价格向下，两者皆不满足）。
- 英特尔《英特尔：CPU 涨价救场，翻身还得看代工？》（2026-07-24）：涨价链跌幅最大；拆客户端（纯涨价）与服务器 CPU（量价齐升）判断抗跌性。
- 阿斯麦《阿斯麦：光刻机产能也紧俏了…》（2026-10-14）：AI 大回调中跌幅不到 10%，相对抗跌，被视为行业 β 拖累。

**适用场景与注意事项**：适用于周期股与产业链主题股。需要配合行业 β（板块回调）把个股因素分离出来。存储等周期行业的价格追踪指标见第15章 15.1。

### 11.3.16 低波动稳健股：股价由估值与风格偏好主导，而非单季业绩

**方法要点**：对营收、利润增速常年只在中低个位数区间内波动的稳健公司，单次业绩对股价影响有限，真正驱动是估值波动和市场风格（风险偏好、防御偏好），点评重点转向资金偏好、估值分位及借公司业绩观察宏观。

**操作步骤 / 拆分口径**：
1. 确认公司增速长期只在中低个位数区间内波动。
2. 看 PE 倍数与历史估值分位。
3. 判断市场风格（AI vs 传统防御）。
4. 点评时写：资金是否偏好防御、估值在历史什么分位，并借公司业绩观察宏观。

**关键指标与数据来源**：PE 倍数；历史估值分位；市场风格。

**判断标准**：风格转向防御 → 估值上移（如 FY26 PE 回升到 45x 以上）；业绩无论好坏，影响小于估值与风格；风险偏好回落时仍是防御性配置的第一选择。

**海豚案例**：
- Costco（2026-03-06）：市场对 AI 相关行业不再偏爱、转向传统防御公司，FY26 PE 回升到 45x 以上；股价更多取决于资金偏好。
- Costco（2026-05-29）：业绩无论好坏，增速波动只有中低个位数，估值和风格才是更主要的决定因素。
- Costco（2026-09-25）：若美股风险偏好回落，Costco 仍是防御性配置的第一选择。

**适用场景与注意事项**：适用于必选消费、会员制零售、公用事业类低波动龙头。

**相关方法交叉引用**：
- 股价反应归因（业绩、指引、叙事或不确定性），以及估值隐含预期，详见 11.1。

**本节速查清单**
- [ ] 解读财报前是否确认了当前估值水位（PE 对历史区间和同行的位置）与市场对利空的认知程度？
- [ ] 高估值股是否计算了 PE、PE/增速，并判断了当前风格是成长还是确定性？
- [ ] 是否设定了“足以改变情绪”的业绩门槛（担忧氛围下，符合预期 = 利空）？
- [ ] 高估值/故事型公司是否检验了新大客户/新订单、全年关键产品指引上调、新品环比增量三条标准？
- [ ] 是否用同行龙头同期指引做了“够不够格”的对标，并校正了体量差异？
- [ ] 是否用市值、估值倍数反推了隐含销量/收入或所需 CAGR 与季度环比，并写明了假设？
- [ ] 是否还原了管理层预告、月度数据、小会沟通后的买方真实预期，而非只看一致预期？
- [ ] 财报前股价位置、宏观环境、上次给出的合理估值与现价的关系是否已检查？
- [ ] 周期股是否写出了“上涨条件/下跌条件”，低波动股是否把重点放在估值与风格上？

## 11.4 叙事、远期分歧与双线定价

> 本节导读：当业绩与股价背离、且 11.2/11.3 的“已定价”“估值门槛”仍解释不通时，往往是叙事与远期分歧在起作用。本节提供几种拆法：把已被锁定的近期业绩与仍有分歧的远期分开；把股价拆成“主业基本盘”与“想象力业务”两条线；用回撤幅度衡量叙事强弱；识别叙事溢价与情绪惩罚；检验估值溢价依托的叙事与本季增长来源是否错位；用新品发布后的股价分化映射市场核心焦虑。成长与确定性的风格切换见 11.3.2，外部宏观对叙事的压制见 11.5.3。

### 11.4.1 业绩超预期但股价不涨：用“远期分歧”解释

**方法要点**：把股价反应分成两部分——已被长期展望锁定的近期业绩，与仍有分歧的远期（FY+2 以后）；分歧在远期时，即使当季 beat、大厂上调 capex，股价也只会区间震荡，只有能化解远期担忧的信息才驱动股价。

**操作步骤 / 拆分口径**：
1. 区分近期与远期：近期业绩（已被长期展望锁定）vs 远期（FY+2 以后）。
2. 列出远期担忧清单：下游 capex 会不会回落、份额和毛利率能否守住、业绩是否见顶。
3. 判断当季 beat、大厂上调 capex 等信息是否触及远期担忧；若没有，股价区间震荡。
4. 找出能化解远期担忧的信息（如下一财年增长指引），预判其对股价的驱动。
5. 给出判断，如“只有 EPS 单条腿支撑、难有戴维斯双击”。

**关键指标与数据来源**：当季 beat 幅度；股价反应；远期担忧清单。

**判断标准**：分歧集中在远期 → 近期 beat 不能带来股价上行；下一财年增长展望超预期 → 才能触发修复（如盘后由 -3% 转为 +5%）；业绩和估值的戴维斯双击“已有些困难”。

**海豚案例**：
- 英伟达《英伟达：业绩狂热 vs 股价冰冷，宇宙第一股就此失宠？》（2026-02-26）：大厂上调 capex 后股价未涨，分歧主要在 FY27 之后。
- 英伟达（2026-05-21）：业绩和估值的戴维斯双击“已有些困难”。
- 英伟达（2026-08-27）：FY28 营收 +70% 以上的展望是最大利好，盘后由 -3% 转为 +5%。

**适用场景与注意事项**：适用于预期充分、关注度高的龙头。股价反应取决于预期差和远期分歧，而不是业绩的绝对水平。

### 11.4.2 股价驱动拆成“主业基本盘”和“想象力业务”两条线，分别评估

**方法要点**：判断股价主要由哪条线定价——传统主业的业绩（收入、利润、指引），还是想象力业务（机器人、液冷、AI）的进展；财报点评分两条线评估。

**操作步骤 / 拆分口径**：
1. 判断股价主要由哪条线定价。
2. 主业平淡时，先用主业估值锚定下行空间（例如造车主业用 1-1.2 倍 P/S 覆盖）。
3. 再看想象力业务（或 AI 期权）的进度和催化剂，作为估值重估的来源。
4. 股价大幅回撤时，归因于想象力业务的延迟，而不是主业。

**关键指标与数据来源**：股价回撤幅度；主业估值 vs 市值；新业务进度。

**判断标准**：主业估值已大致覆盖市值 → 股价大部分来自想象力业务进展；想象力业务（如产品发布）延迟 → 股价大幅回撤。

**海豚案例**：
- 三花（2026-08-27）：“股价大部分来自想象力业务进展”；机器人收入未单独列示，符合预期；H 股自高点回撤约 42%，因 Optimus V3 再度延迟；主业估值 890-900 亿 vs 市值 941 亿。
- 小鹏（三篇财报点评）：造车主业用 1-1.2 倍 P/S 覆盖，AI 期权（Robotaxi、Iron）作为估值重估的来源。

**适用场景与注意事项**：适合主业加新叙事的公司。分部估值的具体方法见 12.3。

### 11.4.3 业绩与叙事分离：用股价离高点的回撤衡量叙事强弱

**方法要点**：把“业绩”和“逻辑叙事”分成两条线：业绩可以无可挑剔，叙事却在走弱；用股价距前高的回撤、自低点的反弹幅度作为叙事强弱的证据，并把中短期（业绩支撑）与中长期（叙事与可见性）结论分开写。

**操作步骤 / 拆分口径**：
1. 评估业绩一条线：当季业绩与近期趋势。
2. 评估叙事一条线：叙事事件（如 AI 变现方向从 2C 转向 2B，资金对电商 Agent 的热情消退）。
3. 用股价距前高的回撤、自低点的反弹幅度作为叙事强弱证据。
4. 判断规则：业绩处于高光时，小瑕疵会被资金暂时忽略；叙事转弱时，好业绩也只能带来有限修复。
5. 结论分开写：中短期业绩支撑，中长期叙事与可见性。

**关键指标与数据来源**：股价距前高回撤；自低点反弹幅度；叙事事件。

**判断标准**：自低点反弹 20% 以上但距前高仍跌超 30% → 叙事偏弱；基本面向好但长期可见性存疑 → 估值能否拉升存疑；模型和芯片自研没有改善、但订单回血 → 叙事转好。

**海豚案例**：
- Shopify（2026-08-06）：自低点反弹 20% 以上，但距去年底高点仍跌超 30%。
- 甲骨文（2026-09-11）：中短期基本面大概率向好，但中长期逻辑可见性未必向好，估值能否拉升存疑。
- 微软《微软：风水轮流转，老腊肉变香饽饽？》（2026-07-30）：模型和芯片自研没有改善，但 Azure 加速、订单回血，叙事转好。

**适用场景与注意事项**：叙事驱动明显的科技股。

### 11.4.4 叙事溢价 / 情绪惩罚识别

**方法要点**：区分基本面与叙事：同样的数据，AI 顺逻辑标的获得溢价，AI 颠覆论标的被惩罚；叙事切换可以让弱项被忽略；估值主要由新业务支撑时，旧业务财报对股价影响弱化，市场以新业务里程碑为准；同时列出催化日程。

**操作步骤 / 拆分口径**：
1. 判断公司处于“AI 顺逻辑”还是“AI 颠覆论”一侧。
2. 判断估值构成：新业务占比、旧业务影响是否已弱化。
3. 识别叙事切换（如从担忧份额流失，转向超级周期叙事）。
4. 判断股价下跌是基本面还是“阴影下的情绪惩罚”。
5. 列出催化日程（投资者日、法案等）。

**关键指标与数据来源**：估值构成；叙事事件；催化剂日程。

**判断标准**：估值主要由新业务支撑时，新业务里程碑未确认 → 预计股价承压；长期替代担忧未消除 → 难以消除长期担忧；公司事件（回购股权、合作）→ 推动股价。

**海豚案例**：
- Spotify（2026-04-28）：盘前下跌更像“AI 颠覆论阴影”下的情绪惩罚；5 月投资者日是潜在催化。
- 奈飞《2Q26》（2026-07-17）：难消除短视频和 AI 替代的长期担忧。
- Marvell（2026-05-28）：叙事从担忧 Trainium 份额流失，转向光学超级周期。
- 特斯拉《2Q26》：汽车估值不到市值 1/3，AI 节点未确认，预计股价承压。
- 英特尔：回购爱尔兰工厂股权及合作消息推动股价。

**适用场景与注意事项**：适用于叙事转换期的科技股。

### 11.4.5 估值溢价依托的核心叙事 vs 本季增长来源的错位检验

**方法要点**：先明确市场给高估值押注的逻辑（如北美出海，而非国内成熟基本盘），再看本季增长来源是否来自这条叙事；若增长来自非叙事部分、叙事部分却降速，就出现叙事与增长的错位。

**操作步骤 / 拆分口径**：
1. 明确市场押注的核心叙事（如北美出海）。
2. 拆本季增长来源：分地区增速、直营占比、区域同店。
3. 比较：叙事部分与非叙事部分增速是否背离。
4. 评估新问题：叙事部分降速、直营占比提升带来的组织复杂度；区域修复需警惕消费恢复不及、代理转直营后组织效率跟不上。

**关键指标与数据来源**：分地区增速；直营占比；区域同店。

**判断标准**：国内增速反超海外 → 短期说明国内仍有运营挖潜空间；但海外（定价叙事）降速 → 构成新问题。

**海豚案例**：
- 名创优品（2026-05-26）：主品牌 +30%（国内超预期），海外 +22% 至 19.4 亿明显降速，北美 Q1 同店低个位数，东南亚处渠道货盘调整期。

**适用场景与注意事项**：估值依赖某一增长叙事的公司。分地区的结构拆分见 5.3。

### 11.4.6 用产品发布事件后的股价分化映射市场的核心焦虑

**方法要点**：观察季度内各新品发布后的股价表现，发布后股价提振的产品，说明市场认可它对核心目标的支撑；发布后股价持续走跌的产品，说明市场担忧它无法解决核心问题；由此提炼市场最在意的变量，再在财报中重点验证。

**操作步骤 / 拆分口径**：
1. 列出季度内各新品及其发布日、定位（走量/高端）。
2. 对比发布日前后股价表现，剔除同期大盘或行业影响。
3. 提振 → 市场认可其对核心目标（如销量）的支撑；持续走跌 → 市场担忧它未能解决的核心问题（如品牌上攻、单价提升）。
4. 提炼市场当前最在意的变量，并在财报中重点验证。

**关键指标与数据来源**：新品发布日前后股价表现；新品定位（走量/高端）。

**判断标准**：走量型新品获认可、品牌上攻型新品差异化不明显而走弱 → 反映市场核心焦虑是车型结构进一步下沉对卖车单价的侵蚀。

**海豚案例**：
- 零跑《剑指百万…》（2026-05-15）：A10 作为百万销量的支柱，发布后股价明显提振；D19 作为品牌上攻产品，差异化不明显，发售后股价持续走跌，反映市场核心焦虑是车型结构进一步下沉对卖车单价的侵蚀。

**适用场景与注意事项**：适用于产品驱动型公司。需要剔除同期大盘或行业的影响。新品与产品周期的管线追踪见 6.5。

**相关方法交叉引用**：
- 成长与确定性之间的风格切换如何改变高估值股的业绩门槛，详见 11.3.2。
- 外部宏观环境对估值和叙事的压制识别，详见 11.5.3。

## 11.5 行业β、宏观与个股α分离

> 本节导读：财报后的股价波动里，有一部分来自行业整体回调、利率、流动性等系统性因素，并不反映公司财报本身。本节教你把行业β、宏观与个股α分开：用相对回调幅度衡量确定性溢价，识别资产价格或宏观流动性主导股价时降低财报权重，并列出外部环境对估值和叙事的压制。基本面上的行业增速与公司增速对比不在本节，见 14.5；与 11.1（多因素归因）、11.3.15（周期股边际价格）配合。

### 11.5.1 分离行业β与个股α：用相对回调幅度衡量确定性溢价

**方法要点**：行业整体回调时，先找共同因子，再比较个股相对跌幅；跌得少的归因于业绩确定性，跌得多的找个股特有逻辑，据此判断行业β企稳后估值能修复到哪里。

**操作步骤 / 拆分口径**：
1. 找共同因子：如 AI 链杀估值。
2. 比较个股与行业（及同业）的回调幅度。
3. 跌得少的，归因于业绩确定性：如下游资本开支明确增长、先进制程垄断。
4. 跌得多的，找个股特有逻辑：竞争威胁、业务敞口、政策风险。
5. 判断：行业β企稳后，估值有望修复到哪里（给出倍数区间或目标价）。

**关键指标与数据来源**：个股与行业回调幅度；同业相对表现。

**判断标准**：相对跌幅小 → 确定性溢价；相对跌幅大 → 行业β之外叠加了个股风险。

**海豚案例**：
- ASML（2026-07-15）：AI 大范围回调中只跌了 15%，归因于下游晶圆厂资本开支明确增长（美光上调 capex），判断行业β消化后估值可回到 30-35x。
- 台积电（2026-10-15）：近两周跌约 10%，跌幅较小，归因于先进制程垄断和业绩确定性，判断β企稳后可重回 20x 以上、冲击 500 美元。
- 博通（2026-09-03）：回调较深，因为行业β之外还叠加了 MTK 和 Marvell 的竞争担忧。
- 中芯 Q1'26（2026-05-14）：股价弱于联电、格芯，归因于手机等终端敞口占 3-4 成，以及 MATCH 法案风险。

**适用场景与注意事项**：通用，尤其是行业大幅波动期间。选取的同业必须可比，否则相对跌幅会误导。

### 11.5.2 资产价格或宏观流动性主导股价时，降低财报的权重

**方法要点**：收入与市场挂钩的公司，股价主要跟随外部价格（币价、USDC 规模、利率、流动性预期），财报只提供“非公开部分”的增量信息；还要识别宏观冲击对高估值、依赖流动性的公司的首当其冲影响。

**操作步骤 / 拆分口径**：
1. 拆收入敏感度：哪些收入与外部价格挂钩（如交易收入占比、区块链奖励与币价挂钩、利息收入占比）。
2. 观察股价是否已与前期预期脱节，主要跟随外部价格。
3. 识别宏观冲击：如“Warsh 冲击”（降息但收紧货币供应），对高估值、依赖流动性的公司影响最大。
4. 点评中降低财报权重，把财报当作“非公开部分”的增量。

**关键指标与数据来源**：币价；USDC 市值；利率预期；流动性。

**判断标准**：收入结构显示高度外部价格敏感 → 财报权重下调；估值高 + 依赖散户/虚拟资产 → 流动性收紧时首当其冲；特殊战略属性的资产，估值不完全受业绩影响。

**海豚案例**：
- Coinbase（2026-02-13）：交易收入占 55%，区块链奖励（约 10%）与 ETH、SOL 价格挂钩，股价已与 1 月给出的预期脱节。
- Robinhood（2026-02-11）：“Warsh 冲击”下的流动性紧缩预期，对依赖散户和虚拟资产、估值又高的公司首当其冲。
- Circle（2026-02-25）：利息收入占 95%，股价主要跟随 USDC 走势、降息预期和加密政策。
- 中芯（2026-02-10）：公司有特殊性，估值不完全受业绩影响。

**适用场景与注意事项**：券商、加密、稳定币，以及具有特殊战略属性的资产。金融科技/加密行业指标见 16.9。

### 11.5.3 列出外部环境风险，判断其对估值和叙事的压制

**方法要点**：业绩向好的同时，列出可能压制估值的外部因素，判断基本面向好与估值能否拉升之间的差距。

**操作步骤 / 拆分口径**：
1. 利率与融资成本：美债利率上行、政府和科技企业融资需求都高，推高融资成本。
2. 竞争格局对长期可见性的影响：大模型竞争加剧、开源与闭源差距缩窄、价格战，降低高度绑定单一模型商的长期可见性。
3. 需求侧信号：调研显示大模型 ARR 增速“盛极而衰”、算力过剩的讨论增多。
4. 结论：基本面向好，但估值能否拉升需要商榷。

**关键指标与数据来源**：美债利率；模型价格；大模型 ARR 增速。

**判断标准**：中短期业绩支撑股价，但外部环境使中长期可见性未必改善 → 估值拉升受限。

**海豚案例**：
- 甲骨文（2026-09-11）：结论是中短期业绩支撑股价，中长期可见性未必改善。

**适用场景与注意事项**：处于景气周期但估值依赖叙事的公司。政策、监管与突发事件的冲击测算见 14.6。

- [ ] 是否给出了行业β企稳后的估值修复区间？
