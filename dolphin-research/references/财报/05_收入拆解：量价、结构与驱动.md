# 第5章 收入拆解：量价、结构与驱动

## 5.1 通用量价拆分

> 本节导读：本节收纳不绑定行业KPI的量价拆解工具——收入＝量×价、同比量价分解、用增速差倒推单价或客单价、公司不披露出货量时“假设ASP反推量”或“借第三方出货反推量价”、平台收入＝成交额×变现率，以及付费客户数×客单价倒算客单价。它回答财报收入的第一问：增长（或下滑）究竟来自量还是价。拿到任何收入数字后都应先做一遍。行业专属公式（RevPAR、GMV三因子、单车、Wh等）见第15、16章；价格因素的深入分析见5.2，客户与用户维度见5.5、5.6，增速二阶导与基数处理见第3章。

### 5.1.1 收入同比的量价分解：(1+量同比)×(1+价同比)−1

- **方法要点**：把收入的同比变化拆成“销量同比”和“单价同比”两个因子，看清下滑或增长的主要来源，再从量价组合推出经营含义（例如量价双降，意味着以价换量的策略失效）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取收入同比、销量同比、单价（ASP）同比；单价可直接用披露值，也可用收入÷销量求得。
  2. 公式：收入同比 ＝ (1＋销量同比) × (1＋单价同比) − 1。变动幅度不大时，近似为“量同比＋价同比”，两者乘积为交叉项。
  3. 判断量价组合：量价齐升、量升价降、量降价升、量价双降，分别对应不同的经营含义。
  4. 变体 B（增速差倒推单价）：若只披露收入（或GMV）与“量”（订单量、销量），则单价同比 ＝ (1＋收入同比) ÷ (1＋量同比) − 1，即用收入与量的增速差倒推单价或客单价。行业专属的GMV三因子、订单量×客单价（含汇率处理）见15.6。
  5. 叠加结构分析：平均价会被产品结构（如车型结构）扭曲，需要再拆结构，见5.3。
- **关键指标与数据来源**：汽车收入同比、销量同比、ASP同比（公司财报与月度/季度交付数据）。
- **判断标准**：
  - 量价齐升：增长质量最高；量升价降：看是否为“以价换量”及毛利代价；量降价升：看价格增长能否持续（见5.2）。
  - 量价双降：说明降价走量的策略失效——即使推出低价走量车型并加大老款促销，在政策退坡与竞争加剧下也救不起整体销量。
  - 价格几乎不变、销量高增：增长几乎全部来自销量，说明增长靠规模扩张而非提价。
- **海豚案例**：
  - 理想《2Q26》（2026-08-26）：汽车销售收入241亿，同比-17%，约等于销量同比-11% × 单价同比-6%。海豚君推出：即使推出了低价走量的L6、i6并加大老款促销，在购置税退坡和激烈竞争下仍救不起整体销量。
  - 蔚来《2Q26》（2026-09-01）：卖车收入291亿，同比+80%，单价同比仅-0.3万，增长几乎全部来自销量。
- **适用场景与注意事项**：通用于任何能拆出“量”和“价”的业务。注意结构变化会让平均价失真，最好再叠加车型（或产品）结构分析；变体 B 倒推出的单价包含结构、汇率等所有杂项，仅作方向判断。

### 5.1.2 假设ASP反推出货量/销量（收入倒算量）

- **方法要点**：公司不披露量时，对单价做一个合理假设，用收入倒算出货量；或结合价格倒算销量增速；对存储类公司，则把业务收入环比拆成出货量与ASP，再与市场价格涨幅对比，判断价格敞口。
- **操作步骤 / 拆分口径 / 公式**：
  1. 变体 A（假设ASP倒算量）：先对单价同比做假设（如ASP同比-5%），出货量同比 ＝ (1＋产品收入同比) ÷ (1＋假设ASP同比) − 1，再折算为绝对出货量（如MW）。
  2. 把倒算出的出货量与公司全年收入指引对应的出货量（如GW）对照，检验指引是否可达。
  3. 变体 B（存储类，环比拆量价）：把业务收入环比拆成“出货量环比”和“ASP环比”，例如DRAM环比+42% ＝ 出货+8% × ASP+30%。
  4. 把公司ASP涨幅与市场现货/合约价涨幅对比：差距大说明公司对该品类的价格敞口小（如产能转向HBM，传统DRAM敞口变小）。
- **关键指标与数据来源**：产品收入、ASP假设、出货量、市场价涨幅（现货/合约价）。
- **判断标准**：
  - 倒算出的出货增速如果接近零甚至转负，即使收入增速尚可，也说明增长主要靠价格，而非需求放量。
  - 公司ASP涨幅明显低于市场价涨幅，原因是产能结构变化（转向高端产品）使传统品类敞口变小，而非公司没有提价能力。
- **海豚案例**：
  - Bloom Energy（2026-07-29）：假设ASP同比-5%，测算出货约308MW（+232%）；全年收入指引对应1.14-1.25GW。
  - 东鹏（2026-07-30）：结合价格倒算销量，Q2能量饮料销量增长接近零甚至转负。
  - SK海力士（2026-07-29）：DRAM环比+42%，其中出货+8%、ASP+30%；而传统DRAM市价+50%，原因是产能转向HBM，传统DRAM敞口小。
  - 美光（2026-10-01）：DRAM、NAND均价环比分别+21%、+30%。
- **适用场景与注意事项**：适用于能源设备、存储、快消等不披露量的行业。假设ASP是估算，结论对假设敏感；有新披露时及时校准。MW口径的收入÷假设ASP倒算出货量见16.3，硬件“总收入减软件收入再拆量×价”见15.10。

### 5.1.3 借第三方行业出货量反推量价，并拆客户结构

- **方法要点**：终端业务（如PC）只披露收入、不披露量时，用第三方的行业出货量代替“量”，反推公司增长来自ASP还是出货，并进一步拆商用/消费者收入，识别客户结构。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取公司分部收入及同比，再取第三方行业季度出货量及同比（如全球PC出货）。
  2. 对比：行业出货下滑而公司收入显著增长（如+20%），则推断增长主要来自ASP（如通过提价转嫁存储成本），出货同样承压。
  3. 再拆分商用与消费者的收入及增速，识别结构：商用为主、消费疲弱。
  4. 推断ASP的驱动：提价（转嫁成本）与产品结构，必要时结合5.2的提价时间线。
- **关键指标与数据来源**：CSG收入及同比、商用/消费者收入与增速、全球PC季度出货量及同比（第三方）、推断ASP。
- **判断标准**：行业量降、公司收入增 ⇒ 价格是主要驱动；商用增速显著高于消费者 ⇒ 增长质量取决于企业需求，消费端仍弱；同时需意识到出货同样承压。
- **海豚案例**：
  - 戴尔（2026-09-02）：CSG收入150亿、同比+20%，符合预期；商用132亿、+22%，消费18.4亿、+7%；全球PC出货6820万台、同比下滑，因此“增长主要来自ASP的带动（部分通过提价转嫁存储涨价影响）”。
- **适用场景与注意事项**：适用于有第三方出货/销量数据的行业（PC、手机、汽车、家电）。公司份额变化会干扰推断，需要份额数据配合（见14.5）；第三方数据的获取与校验见第14章。

### 5.1.4 平台变现率：收入＝成交额×变现率，解释收入与GMV的增速差

- **方法要点**：平台收入 ＝ 成交额（GMV/GTV/GBV/GPV）× 变现率（take rate）。收入增速与成交额增速的差异，几乎全部来自变现率的变化，因此用变现率把“量”（成交额）与“价”（货币化）分开。
- **操作步骤 / 拆分口径 / 公式**：
  1. 变现率 ＝ 收入 ÷ GMV（或GTV、GBV、GPV）；以bps或pct跟踪同比、环比变化。
  2. 变体 A（通用）：收入增速低于或高于GMV增速时，逐项归因变现率变化——高基数、佣金返点、预订与入住的时间差、佣金率下行、支付渗透率提升等。
  3. 变体 B（用增速差推算）：用分部收入增速与GMV（或订单额）增速之差，推算变现率变动；平台可分3P变现率、支付综合变现率、商家服务综合变现率等层次。
  4. 当GMV与收入增速差缩窄（或扩大）时，要进一步归因：退货率变化、业务结构变化。
  5. 与利润率挂钩：电商毛利率、按GMV口径的利润率，看变现率提升是否转化为利润。
- **关键指标与数据来源**：GMV；GPV；变现率（bps）；分部收入；3P变现率；支付综合变现率；退货率。
- **判断标准**：
  - 变现率上行（收入增速＞GMV增速）：属于“价”的改善；若由支付渗透率提升、3P占比提升等结构性因素驱动，质量更高。
  - 变现率进入高基数后，收入增速会向GMV增速靠拢，应提前预判而不是视为恶化。
  - 收入跌幅大于GMV（佣金率走低）、净变现率下降：属于价格端的负面因素，需判断是临时（时间差、返点）还是趋势（佣金率下行）。
- **海豚案例**：
  - 阿里（2026-01-08）：变现率进入高基数，CMR增速向GMV增速靠拢。
  - 快手（2026-03-25）：GMV+13%，佣金变现率同比+8bps，电商收入+22%，高于头部机构预期的18%。
  - Shopify（2026-02-11）：变现率+6.6bps，支付渗透率+2pct至67%，GPV+37%，高于预期31%；商家服务综合变现率+10bps。
  - Airbnb（2026-02-13）：净变现率-0.5pct，营收+12%，低于GBV的+16%。
  - 滴滴（2026-03-13）：国内名义变现率23.9%，上季为23%。
  - 贝壳（2026-03-16）：佣金率同比走低，营收跌幅大于GTV。
  - Sea（2026-08-11）：GMV+28.5%（预期26%），电商营收+48%，推算3P变现率环比+0.8%（近4年最高）；电商毛利率+1.2pct；利润率按GMV口径+0.7pct。
  - 唯品会：GMV-1.6%（彭博一致预期+1.5%），收入与GMV增速差缩窄，是因为退货率下降。
- **适用场景与注意事项**：适用于平台、电商、OTA、中介与支付类公司。GMV的口径（是否含退货、是否含时间差）要和收入口径对齐；各行业的GMV三因子、间夜等专属拆分见15.6、15.7。

### 5.1.5 付费客户数×客单价：倒算客单价，判断增长来自哪类客户

- **方法要点**：用收入（或Billings）除以付费客户数，得到隐含客单价；再结合客户数的净增，判断增长是来自“客户数扩张”还是“单客价值提升（提价、加购）”，并推断客户结构。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含客单价 ＝ 收入（或Billings）÷ 付费客户数；计算客单价同比。
  2. 取付费客户数的环比净增，对比历史是否创新高。
  3. 判断：客户数净增创新高、客单价同比持平 ⇒ 增长来自中小企业客户扩张，而非大客户提价或加购。
  4. 用移动端流水（iOS流水增速）交叉印证——中小企业更多在移动端随买随用。
  5. 窗口期（假期、春招等）会扰动净增，需剔除后看真实环比净增。
- **关键指标与数据来源**：付费企业客户数、环比净增、隐含客单价同比、iOS流水增速（第三方）。
- **判断标准**：客户数增而客单价平 ⇒ 中小企业需求拉动，增长依赖获客；客单价抬升而客户数停滞 ⇒ 依赖提价/加购，要看对价格的接受度。
- **海豚案例**：
  - Boss直聘（2026-05-20）：付费企业710万，环比净增30万、创新高；倒算客单价同比基本持平，“主要是中小企业的需求拉动”。
  - Boss直聘（2026-08-25）：剔除窗口期影响后，付费企业环比净增10万。
- **适用场景与注意事项**：适用于SaaS、招聘、广告等B端付费平台。客户数口径（付费企业数 vs 账号数）要保持一致；客户分层（大客户/长尾）的进一步拆分见5.5。

- [ ] 公司不披露量时，是否用假设ASP或第三方出货反推，并标注为估算、说明假设敏感性？

## 5.2 价格驱动与定价策略

> 本节导读：本节专注“价”这一半——提价事件的时间线与对量价的影响、产品代际升级带来的ASP提升、价格驱动与需求驱动的拆分、用结构占比变化反推同品提价、被动通胀提价与主动结构性溢价的质量区分、提价周期与基数退坡、提价与打包定价下的综合ASP测算，以及“表观收入”与主动降价/补贴后“真实业绩”的区分。当5.1的量价拆分显示“价”是主要驱动，或公司处于提价周期时使用；与第3章的基数效应、第7章的成本传导与毛利率配合。

### 5.2.1 提价事件时间线及其对量价的影响

- **方法要点**：把季内的提价公告按时间、范围、幅度逐条列出，用来解释收入与毛利率的变化；再检验提价后出货量是否维持（品牌力与需求弹性），以及提价能否对冲成本上升。
- **操作步骤 / 拆分口径 / 公式**：
  1. 梳理提价公告：日期、产品范围（全系/单品类）、幅度（%）。
  2. 把提价与收入增速、毛利率变化在时间上对齐，解释增速拐点。
  3. 看提价后的出货同比，判断需求弹性：提价后出货仍增长，说明品牌和管理能力强。
  4. 判断提价是否足以对冲成本（如存储涨价、硬件涨价）。
  5. 反向判断：提价幅度大、时点密集，是供不应求的信号。
- **关键指标与数据来源**：提价时间、产品范围、幅度；提价后出货同比；毛利率。
- **判断标准**：提价带动收入重回增长且毛利率同步提升 ⇒ 提价生效；提价后出货仍增 ⇒ 具备定价权；提价幅度普遍且连续 ⇒ 供不应求。
- **海豚案例**：
  - 海康（2026-04-18）：一季度三次涨价——2月27日全系产品上调8%~15%，3月12日硬盘单独涨价，3月24日全系再上调约5%；带动收入重回双位数增长（+11.8%），毛利率也提升。
  - 戴尔（2026-05-29）：1月6日对PC统一调价以转嫁存储成本，一季度出货仍+7%，体现品牌和管理能力。
  - CoreWeave（2026-08-12）：7月后产品线定价普遍上调25%（部分用于对冲硬件涨价），反映算力仍供不应求。
- **适用场景与注意事项**：适合有定价权的硬件/服务公司。提价可能透支未来需求，提价周期何时结束见5.2.6；成本传导机制见7.3。

### 5.2.2 产品代际升级带来的ASP提升（量价齐升）与收入节奏

- **方法要点**：跟踪产品代际迁移，判断ASP提升对收入的贡献，并把代际节奏映射到公司收入的季度/半年节奏（如下半年新品量产导致全年“前低后高”）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出代际路径：GB200→GB300→Rubin；MI355→MI455（MI450系列）；TPUv7→TPU8。
  2. 判断当前处于哪个代际的过渡阶段，该阶段ASP提升带来量价齐升。
  3. 找出下一代的量产时间，把它映射到收入的季度/半年节奏。
  4. 据此判断全年节奏（如“前低后高”）和下半年收入不会低于上半年等结论。
- **关键指标与数据来源**：代际产品结构、ASP、量产时间（公司指引与电话会）。
- **判断标准**：新代际量产晚于预期或占比爬坡慢，则上半年承压、下半年压力转移；新代际量产时点确定、客户订单下半年交付 ⇒ 收入呈“前低后高”。
- **海豚案例**：
  - 戴尔（2026-05-29）：AI服务器处于GB200向GB300过渡阶段，ASP提升，量价齐升；下半年Rubin升级，因此下半年收入不会低于上半年。
  - AMD（2026-02-04）：MI450系列下半年量产，AI收入前低后高。
  - 博通（2026-03-05）：Anthropic和第五客户的订单下半年交付，全年AI收入前低后高。
- **适用场景与注意事项**：适合产品迭代周期清晰的硬件/半导体公司。节奏判断依赖量产时点的确认，延迟会让“前低后高”变成“后移”，需持续跟踪（见6.5产品周期与管线）。

### 5.2.3 用结构占比的变化反推同品提价

- **方法要点**：公司不披露价格、只披露产品结构时，用“结构效应应拉低ASP，但ASP反而上升”这一矛盾，反推同品提价的存在及其发生的品类。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取ASP环比变化；取高价值产品（如12寸）收入占比的变化。
  2. 若高价值产品占比下降（结构效应本应拉低ASP），而ASP上升，则说明存在同品提价。
  3. 推断提价发生在哪个品类（如12寸占比下降，则推测8寸成熟制程已提价）。
  4. 用行业信息（功率需求回升、涨价传闻）交叉验证。
  5. 后续季度继续追踪是否兑现，并用市场信息校准提价幅度。
- **关键指标与数据来源**：ASP环比、12寸收入占比变化、行业涨价信息。
- **判断标准**：ASP↑且高价值产品占比↓ ⇒ 同品提价成立；后续ASP环比跳升并有市场信息证实，则推断兑现。
- **海豚案例**：
  - 中芯《一手涨价潮、一手新故事，中芯国际快 “发飙” 了？》（2026-05-14）：Q1'26出货-0.2%、ASP+0.9%，同时12寸收入占比从77.2%降到76%，海豚君推测8寸成熟制程已开始提价。
  - 中芯（2026-08-13）：市场信息证实成熟制程部分产品提价10%以上，ASP环比+5%。
- **适用场景与注意事项**：适用于披露产品结构、但不披露价格的公司。推断需配合行业涨价信息，避免把汇率、产品组合的其他变化误认为提价。

### 5.2.4 价格驱动 vs 需求驱动的拆分（结构升级＋直接提价；量价贡献估算）

- **方法要点**：行业总量下滑、公司收入却增长时，把增长归因到价格，再拆为“产品结构调整”和“直接涨价”，并给出产能逻辑；对高增的分部再做量价分拆，估算价格与数量各自的贡献，用于判断业绩可持续性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对比行业出货量与公司收入增速：行业量降而收入增，增长归因到价格。
  2. 把价格因素再拆成产品结构调整与直接涨价，并给出产能逻辑（例：数据中心CPU挤占传统CPU产能，导致PC类CPU涨价）。
  3. 对高增分部做量价分拆，估算价格贡献与量的贡献（价格贡献约20%、量贡献约40%）。
  4. 全年持续追踪提价幅度，随新信息修正（服务器CPU计划涨10-15%，后来判断为10-20%）。
  5. 推到结论：判断业绩可持续性——市场担心的是ASP的上行空间与客户的接受度。
- **关键指标与数据来源**：分部收入同比；行业出货量；提价幅度；量价贡献拆分。
- **判断标准**：增长“全部来自价格”（量无贡献）⇒ 增速依赖提价周期，可持续性要打折；量价均有贡献（价格约20%、量约40%）⇒ 增长更扎实；提价幅度被持续上修，说明供给紧张在加剧。
- **海豚案例**：
  - 英特尔《英特尔：CPU 涨价救场，翻身还得看代工？》（2026-07-24）：客户端+12.8%全部来自价格；数据中心及AI（DCAI）同比+59%，其中价格贡献约20%、量贡献约40%。
  - 英特尔（2026-01-23与2026-04-24）：服务器CPU计划提价10-15%；后续（2026-07-24）判断提价幅度为10-20%。
  - 产能逻辑：数据中心CPU挤占传统CPU产能，带动PC类CPU涨价，消费级CPU涨价约10%。
- **适用场景与注意事项**：适用于供给紧张、提价周期中的硬件公司。量价拆分依赖第三方出货数据或管理层口径，属于估算，文中应明确标注。

### 5.2.5 区分被动通胀提价与主动结构性溢价

- **方法要点**：对价格端增长的质量定性：被动跟随通胀的全线提价在高基数下会回落，被视为“挤出非理性价格泡沫”；主动结构性溢价来自产品版本升级、高端/健康品类占比提升、价格带精细化（小规格、迷你罐、可回收包装），具有可持续性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把价格增长拆成 price（list price）与 mix（结构）两部分。
  2. 检验三点：价格增长是否伴随销量健康；通胀回落后是否仍能保持；来自mix还是list price。
  3. 零售看客单价与交易次数：客单价放缓、交易次数提速，说明由被动涨价转向主动降价换客流（性价比引流）。
  4. 酒店看ADR的增长来源（新版本产品占比），消费品看高溢价品类占比与价格带管理。
- **关键指标与数据来源**：价格/组合（price/mix）、ADR、客单价、高端品类占比、新版本产品占比、交易次数。
- **判断标准**：
  - 被动提价红利消退、价格增速回落 ⇒ 挤泡沫，属正常出清；
  - 价格增长来自高溢价品类占比提升、价格带管理、新版本占比提升 ⇒ 结构性溢价，可持续；
  - 客单价增速下降、交易次数增速上升 ⇒ 主动让利引流。
- **海豚案例**：
  - 可口可乐《押注AI，肥宅快乐水在下一盘大棋？》（2026-02-11）：Q4价格仅+1%，因去年通胀被动提价红利消退，视为挤泡沫。
  - 可口可乐《无糖狂飙、AI节流…》（2026-04-28）：价格+2%来自Fairlife、Coke Zero、BODYARMOR等高溢价占比提升，及小包装价格带管理。
  - 华住（2026-05-15）：ADR+4.8%归因于汉庭3.5/4.0、全季5.0新版本占比提升。
  - 沃尔玛《高油价来袭！》（2026-05-22）：客单价+2.8%→+1.1%、交易次数+1.6%→+3.0%，判定由被动涨价转向主动性价比引流。
- **适用场景与注意事项**：适用于消费品、酒店、零售。结构性溢价也可能被地区结构稀释（如Monster的单箱均价，详见16.7食品饮料）；酒店分地区ADR见15.7。

### 5.2.6 根据提价周期与基数，判断提价利好何时结束

- **方法要点**：记录提价起始季度，按同比口径推算提价利好在满四个季度后退出；提示若无新的提价，下季增速将回落，并同步跟踪新的提价计划和新套餐，判断下一轮提价周期。
- **操作步骤 / 拆分口径 / 公式**：
  1. 标出提价的起始季度和幅度。
  2. 同比口径下，提价效应在满四个季度后基数抹平：到此为止“提价利好”结束。
  3. 提示：若没有新的提价，下季增速将回落。
  4. 同时跟踪新的提价与新套餐，判断下一轮提价周期是否启动。
- **关键指标与数据来源**：提价时间与幅度、同比基数。
- **判断标准**：满四个季度而无新提价 ⇒ 增速回落；有新一轮普遍提价或新套餐 ⇒ 新周期启动，利好延续。
- **海豚案例**：
  - 微软（2026-05-01）：消费者M365提价从上财年4Q开始，到下季度利好周期就结束；另外7月1日起对原有产品普遍提价，并推出E7套餐。
- **适用场景与注意事项**：靠提价驱动增长的订阅、消费品、运营商。基数逻辑与第3章的基数效应同源，见3.3。

### 5.2.7 跟踪提价与打包定价，测算综合ASP

- **方法要点**：把新套餐定价与原套餐对比，计算提价幅度；再计算“打包价”与“各功能单独售卖价之和”的差距，判断公司是否在用高附加值产品渗透来做高综合ASP（名降实升）；同时评估用户为AI附加值付费的推进速度，以及计费模式变化（月费改按用量计费）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 提价幅度 ＝ 新套餐价 ÷ 原套餐价 − 1。
  2. 打包折扣 ＝ 打包价 − Σ各功能单独购买价。打包价低于单独购买之和，名义上是“降”，但相对原套餐（如E5）是明显提价，即“名降实升”。
  3. 评估AI附加功能（Copilot、Agent、安全）的渗透与付费推进速度。
  4. 关注计费模式变化（月费 → 按用量计费），判断收入的波动性与变现上限。
- **关键指标与数据来源**：套餐价格、单独售卖价格、附加功能渗透率。
- **判断标准**：打包套餐把更多高价值模块纳入，综合ASP显著抬升（相对原套餐超过1/2）⇒ AI货币化推进较快；若附加功能渗透缓慢，则打包价只是账面提价。
- **海豚案例**：
  - 微软（2026-05-01）：M365 E7基础定价99美元（E5为60美元），提价超1/2。
  - 微软（2026-07-30）：Copilot（单价30美元）＋Agent＋安全功能单独购买约120美元，打包成E7为99美元；GitHub Copilot在6月从月费改为按用量计费。
- **适用场景与注意事项**：SaaS/订阅软件的AI货币化分析。AI ARR与占比等量化跟踪见5.4，软件行业专属指标见15.4。

### 5.2.8 区分“表观收入”与“真实业绩”（主动降价/补贴）

- **方法要点**：收入增速低，可能是主动降价、补贴冲减收入的结果。此时用订单额、毛利润或调整后利润衡量真实业绩，并判断主动降价是否属于应对竞争的预防性措施。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先确认收入是否被让利（降价、补贴、退税、返点）冲减。
  2. 改用订单额、毛利润、调整后利润等不被让利冲减的口径衡量。
  3. 把让利的资金流向弄清楚（如节省的保费再投入、退税让利给会员）。
  4. 剔除油价、汇率等干扰项后，看同店、客流频次、续费率等核心运营指标。
  5. 判断主动降价是预防性竞争措施，还是被迫让利。
- **关键指标与数据来源**：订单额、营收、毛利润增速；剔除油价与汇率后的同店增速；客流频次；续费率。
- **判断标准**：营收低增、但订单额与毛利润增速高于预期 ⇒ 表观收入低估了真实业绩；剔除一次性让利后核心毛利率改善、客流频次回升、续费率触底回升 ⇒ 基本面向好。
- **海豚案例**：
  - Uber（2026-08-05）：网约车营收仅+1%，因主动降价（把节省的保费再投入）；毛利润+27%，高于订单额增速和预期的22%，更能反映真实业绩。
  - Costco（2026-09-25）：退税大部分让利给会员，剔除后核心商品毛利率在改善；剔除油价和汇率后同店为6-7%；客流频次首次回升；续费率触底回升。
- **适用场景与注意事项**：平台、零售。要区分“主动让利”与“被动失速”；一次性让利的剔除口径见4.5，利润口径选择见8.1。

## 5.3 多维结构拆分

> 本节导读：本节讲“把收入按维度切开”的方法——事业群×地区×主业/创新业务矩阵、按下游应用拆分并挂钩终端市场、分地区收入（含地区作为客户代理、ship-to口径陷阱、对照管理层此前口径）、海外硬件与互联网拆分、地区×渠道矩阵、地区接力、核心子产品追踪、收入结构占比判断转型方向、品牌/品类/区域/渠道多维拆分，以及分部收入减内部抵消推算对外收入。用于识别增长引擎与拖累项、判断基本盘与成长点的转换。与5.1的量价、5.4的核心/新业务、5.5的客户结构互相配合；行业专属结构（如汽车分地区交付、iPhone分地区出货）见第15、16章。

### 5.3.1 事业群×地区×主业/创新业务矩阵拆分（用半年报补齐季报）

- **方法要点**：一季报不披露分部时，用最近的半年报（下半年）数据补齐分部结构，把“基本盘（主业）”与“成长点（创新业务）”分开看。
- **操作步骤 / 拆分口径 / 公式**：
  1. 整体用最新单季数据；分部用最近半年报/年报推出的半年数据（下半年 ＝ 全年 − 上半年），两者组合使用，文中必须注明时间口径不同。
  2. 按境内三大事业群（PBG/EBG/SMBG）、境外主业、创新业务（境内/境外）分别计算半年收入、同比、占比。
  3. 创新业务再拆子业务（智能家居、汽车、存储、机器人），逐一看增速。
  4. 对比各块增速与占比变化（pct），判断基本盘是否承压、成长点是否撑起总量。
- **关键指标与数据来源**：各事业群半年收入及同比、境外主业收入及同比、创新业务收入/占比/子业务增速（年报、半年报）。
- **判断标准**：主业整体下滑、承压最大的事业群（受宏观冲击）识别清楚；创新业务占比持续提升（pct）且多数子业务增速在25%以上，说明成长点逐步扛起；个别子业务出现两位数下滑（如机器人）则为拖累项。
- **海豚案例**：
  - 海康（2026-04-18）：2025年下半年主业370亿，同比-5.4%；PBG、EBG约-5%，SMBG -23%（受宏观冲击最大）；境外主业150亿，+3%；创新业务136.8亿，+12.5%，占比27%（+3pct），其中境内98亿+9%、境外39亿+22%；智能家居、汽车、存储增速都在25%以上（智能家居35%），机器人两位数下滑。
- **适用场景与注意事项**：适合季报信息少、分部数据要等半年报/年报的A股公司。半年数据与单季数据的口径不一致，不可直接相除；分部利润的倒算见8.7。

### 5.3.2 按下游应用拆分收入，并挂钩终端市场预期

- **方法要点**：按下游应用（HPC、手机、IoT、汽车、消费电子、工业、电脑平板等）拆分收入，计算金额、占比和环比，再挂钩第三方或产业链对终端市场的预测，判断哪些是拖累项、哪些是增长项。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取各应用收入金额；计算占比与环比（或同比）。
  2. 连续多个季度并列追踪，看占比的趋势性迁移（如HPC占比从55%升到68%）。
  3. 与终端市场预测对照（如全年手机出货-15%），判断公司该应用的收入是顺势还是逆势。
  4. 明确拖累项与增长项，并解释原因（如存储短缺压制手机出货）。
- **关键指标与数据来源**：各应用收入金额、占比、环比；终端市场预测（第三方/产业链）。
- **判断标准**：某一应用占比持续上升并贡献大部分增量 ⇒ 公司被该应用主导；某应用收入下滑且与终端预测方向一致 ⇒ 属于行业性压力，而非公司个体问题；工业及汽车、PC及平板等边际改善时，注意是否构成新的增长项。
- **海豚案例**：
  - 台积电（Q4'25至Q3'26连续追踪）：HPC：Q4'25 185.5亿，占55%；Q1'26 219亿（+18%），占61%；Q2'26 265亿（+21%），占66%；Q3'26 318亿，占68%。手机：Q4'25 108亿（+15%），Q1'26 93.3亿（-13%），Q2'26 88亿（-5%）。
  - 中芯（Q2'26）：消费电子占47%；智能手机从4.9亿降到4.5亿，占比不足两成；受存储短缺影响，市场预期2026年手机出货-15%；Q2'26工业及汽车、PC及平板拉动增长。
- **适用场景与注意事项**：服务多个下游的平台型制造商。终端市场预测是第三方口径，需标明来源；应用分类口径若调整，占比会出现断点。

### 5.3.3 地区收入拆分：对照管理层口径、地区作为客户代理、ship-to口径陷阱

- **方法要点**：记录地区收入的金额和占比，对照管理层此前给出的地区口径，判断出口管制和地缘政治的影响；同时把地区映射为具体客户（地区＝客户代理变量），并警惕“ship to location”披露口径带来的误判。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A（对照管理层此前口径）：
    1. 记录各地区收入金额与占比，连续多季度并列。
    2. 与管理层此前给出的地区占比对照（例：管理层此前说中国大陆“20%左右”，或先前口径25%），判断出口管制、地缘政治的实际影响是好于还是差于口径。
  - 变体 B（地区＝客户代理）：
    1. 把地区映射到客户：韩国→三星和海力士的存储扩产；中国台湾→台积电；北美→英伟达和苹果；中国大陆→国产化扩产与出口管制敞口。
    2. 地区占比回升被视为对应客户的采购/扩产增加（如AMAT韩国回升至20%左右被视为存储采购增加；ASML韩国从22%升到45%）。
    3. 中国大陆占比与公司先前口径对比（ASML：36%好于25%，19%低于25%，23%回到20%附近）。
  - 变体 C（ship-to口径陷阱）：先核对披露口径（发货地 vs 客户总部）。ASML按“ship to location”披露，台积电上调的capex有一部分会落在美国工厂，可能同时推高中国台湾和美国两个地区的占比，不能只看台湾。
- **关键指标与数据来源**：各地区收入及占比；公司对地区占比的指引；披露口径（发货地/客户总部）。
- **判断标准**：
  - 中国大陆占比低于管理层口径，说明出口管制影响比公司预告的更大；高于口径则说明国产化需求或存量设备出货好于预期。
  - 韩国占比大幅抬升 ⇒ 存储扩产周期启动；台湾占比下降而北美上升 ⇒ 客户结构向海外产能迁移。
- **海豚案例**：
  - ASML（2026-07-15）：韩国占43%，约40亿欧元；中国大陆约13亿，占14%，低于管理层此前说的“20%左右”。
  - 台积电：中国大陆Q4'25 30.4亿（9%）→Q1'26 25亿（7%）→Q2'26 24亿→Q3'26 23亿（约5%）；北美占比从74%升到79%。
  - AMAT（2026-02-13）：中国大陆30%、中国台湾25%、韩国21%。
  - 中芯：中国区占比88%→89%→90%以上。
  - 应用材料（2026-05-15）：中国大陆26%、台湾27%、韩国约20%。
  - 阿斯麦（2026-01-28）：中国大陆36%（约35亿），台湾13%，韩国22%。
  - 阿斯麦（2026-04-15）：韩国45%（39.5亿），中国大陆19%（16.7亿）。
  - 阿斯麦（2026-10-14）：台湾37亿、韩国36亿，中国大陆27亿（23%）。
- **适用场景与注意事项**：适用于受地缘政治和出口管制影响、客户集中且地区与客户高度对应的上游公司（设备、晶圆代工）。必须核对地区披露口径，避免误判客户；客户集中度的直接追踪见5.5。

### 5.3.4 海外收入拆成海外硬件与海外互联网，并追踪海外占比

- **方法要点**：把海外收入拆为海外互联网收入与海外硬件收入（海外总收入减海外互联网），分别看同比，并跟踪海外收入在总收入中的占比变化（受国内汽车业务增长稀释），据此判断海外需求的冷暖。
- **操作步骤 / 拆分口径 / 公式**：
  1. 海外硬件收入 ＝ 海外总收入 − 海外互联网收入。
  2. 分别计算海外总收入、海外互联网、海外硬件的同比。
  3. 计算海外占总收入的比重，并解释占比变动（国内汽车业务增长会稀释海外占比）。
  4. 判断：海外硬件连续多季下滑，反映海外需求偏弱；转正则提示回暖。
- **关键指标与数据来源**：海外收入及同比、海外收入占比、海外互联网收入及同比、海外硬件收入及同比。
- **判断标准**：海外硬件同比由负转正 ⇒ 需求回暖；占比回升（如从约31%回到约40%）⇒ 海外业务重新贡献增量；海外互联网持续增长但硬件连续下滑 ⇒ 海外需求偏弱、互联网增长不足以对冲。
- **海豚案例**：
  - 小米《天堂急跌地狱…》（2026-03-24）：4Q25海外收入361亿（-3.1%），占比降至约31%；海外互联网+18%至36.6亿，海外硬件-5%，连续三季下滑。
  - 小米《跌到怀疑人生？…》（2026-05-26）：1Q26海外396亿（+3.5%），占比回升至约40%；海外互联网+10%至30亿，海外硬件+3%，重回增长。
- **适用场景与注意事项**：适用于国内外业务结构差异大的消费电子公司。海外占比变化既受海外业务本身影响，也受国内业务（如汽车）增速稀释，需分开解读；分地区iPhone出货等见15.10。

### 5.3.5 地区×渠道矩阵：识别一次性流量、主动收缩与能力来源

- **方法要点**：对每个海外区域，再拆线上、线下及细分渠道（零售店、机器人商店、自研APP、第三方平台、小程序抽盒机），用不同渠道的增速组合识别一次性流量、主动渠道收缩和线上能力的真实来源。
- **操作步骤 / 拆分口径 / 公式**：
  1. 建立“地区 × 渠道”矩阵：各区域的线上、线下、细分渠道收入及增速。
  2. 解读组合信号：
     - 线上暴跌、线下增长 ⇒ 一次性抢购流量退潮；
     - 线下占比高且增长 ⇒ 健康、无泡沫回撤；
     - 自研APP增长而第三方平台崩塌 ⇒ 主动渠道收缩；
     - 国内线上（抽盒机自有玩法＋会员）与海外线上（外部流量）反差 ⇒ 判断线上能力的真实来源。
  3. 同时看单渠道的收入体量与占比变化，及海外整体占比。
- **关键指标与数据来源**：分地区分渠道收入及增速、线下占比、单渠道收入。
- **判断标准**：线下增长、线上被动回落 ⇒ 流量退潮但基本盘稳；线上依赖外部流量并同步崩塌 ⇒ 能力来自外部而非自身；自研渠道增长而第三方平台下滑 ⇒ 渠道主动收缩，不应误读为需求崩塌。
- **海豚案例**：
  - 泡泡玛特（2026-08-20）：海外49.7亿，-11.1%（占比40.3%→29.0%，上市以来首次负增长）；美洲18.9亿，-16.5%（线下+20%、线上-46%）；欧洲5.1亿，+5.9%（线下+50%、占比82%）；亚太25.8亿，-9.7%（线上-39.8%，Shopee崩塌而自研APP增长）；国内线上47.8亿，+63%，海外线上-44%；抽盒机20.6亿，+83.3%。
  - 泡泡玛特（2026-03-25）：北美45.4亿，+733%，11月后线下走弱、黑五增速降至500%以下。
- **适用场景与注意事项**：多渠道、多区域的消费品牌。需要公司披露渠道明细；对极高基数（如+733%）要结合基数看增速的下行是否属于正常。

### 5.3.6 地区接力与客户结构归因拆解GMV增长

- **方法要点**：把总GMV增长拆成北美与海外（以欧洲为主）两块，识别增长动力的“接力”；再用电话会定性信息拆解驱动来源（存量商户的平均销售额增长、年销售额超过2500万美元的大企业客户），判断增长的结构、可持续性与下一阶段风险。
- **操作步骤 / 拆分口径 / 公式**：
  1. 拆分地区GMV增速：北美、海外（欧洲为主）。
  2. 对比各季度，识别接力：前几个季度靠海外拉动，近两季海外明显回落，由北美再提速接力维持整体高增。
  3. 用电话会的定性信息拆解来源：存量商户平均销售额增长（同店）与大企业客户（年销售额超2500万美元）。
  4. 评估风险：单一地区一旦回落，还有没有接力者。
- **关键指标与数据来源**：分地区GMV增速、存量商户同店销售增长、大企业客户贡献（电话会定性）。
- **判断标准**：整体增速稳定但增长来源在地区间切换 ⇒ 当前动力脆弱度取决于接力者是否还有后手；若存量商户与大客户同时贡献，增长结构更健康。
- **海豚案例**：
  - Shopify（2026-08-06）：海外增长回落，北美再提速接力；存量商户和大企业用户是主要动力。
- **适用场景与注意事项**：跨地区的电商/平台/消费品公司。电话会信息为定性，需标注，不能当作精确拆分。

### 5.3.7 核心子产品的占比、环比、单月同比与年化run-rate追踪

- **方法要点**：在分部里继续拆出核心子产品，从四个维度追踪（占分部比重、季度环比、管理层披露的单月同比、年化收入规模），并识别分部内的拖累项，判断分部增速的真实成色。
- **操作步骤 / 拆分口径 / 公式**：
  1. 子产品占分部收入比重：看占比变化，判断分部增长是否由明星子产品驱动。
  2. 季度环比：看加速或放缓。
  3. 管理层披露的单月同比（如1月同比）：作为季度内的最新边际信号。
  4. 年化收入（run-rate）：单季或单月 × 对应倍数。
  5. 识别拖累项：规模不大但持续拖累的子业务，评估其对分部增速的拉低。
- **关键指标与数据来源**：子产品占分部比重、季度环比、单月同比、年化收入（财报与电话会）。
- **判断标准**：核心子产品占比持续提升、环比与单月同比创新高 ⇒ 分部增速由其带动；拖累项占比较小但持续拖累，意味着分部整体增速被低估或高估的程度要看拖累项何时出清。
- **海豚案例**：
  - Unity（2026-02-12）：Vector占Grow 56%，Q4环比+15%，Q1环比+10%，1月同比+70%创新高，年化收入超10亿；IronSource仅占Grow 10%，但近一年持续拖累。
  - Unity（2026-08-07）：Q2 Vector预计占战略Grow 80%以上，Q2/Q3环比+23%/+20%。
- **适用场景与注意事项**：有明星子产品的平台型公司。管理层披露的单月同比、年化收入口径常为口头披露，需核对；核心与非核心的定位见5.4。

### 5.3.8 跟踪收入结构占比变化，判断转型方向

- **方法要点**：跟踪各业务收入占比的变化（如核心业务在降价策略下份额下降）和新业务的增速，判断公司从连接服务向价值服务转型的进展，以及潜在成长点。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出各业务收入及占比，连续多期。
  2. 跟踪核心业务的份额（如流量份额）及趋势，判断降价策略等对核心的影响。
  3. 单独追踪新业务（应用及信息服务、数据中心与云）的增速与占比。
  4. 比较传统业务（语音、短彩信）的下滑速度，判断转型的“替代能力”。
- **关键指标与数据来源**：各业务收入占比、新业务增速、核心业务份额。
- **判断标准**：传统业务占比长期稳在高位（如通信服务80%以上）而份额下降 ⇒ 核心承压；新业务增速高于整体、占比稳步提升 ⇒ 转型有进展；传统细分业务（语音、短彩信）持续负增长 ⇒ 增长需由新业务补位。
- **海豚案例**：
  - 中国移动（2026-03-26）：通信服务长期占比80%以上，流量份额40.5%且呈下降趋势；应用及信息服务下半年1221亿，+6%；语音-4%，短彩信-7.6%；后续关注数据中心与云。
- **适用场景与注意事项**：处于转型期的传统行业龙头。占比变化既可能来自分子，也可能来自分母，需看绝对值；运营商专属指标见16.10。

### 5.3.9 品牌/品类/区域/渠道多维拆分

- **方法要点**：把收入按品牌、品类、区域、渠道拆开，识别增长引擎与拖累项，并结合基数和渗透阶段判断增速是否合理。
- **操作步骤 / 拆分口径 / 公式**：
  1. 选择公司披露的维度：品牌、品类、区域、渠道，分别计算增速与占比。
  2. 找出增长引擎（高增、占比提升）与拖累项（负增长或增速显著低于整体）。
  3. 结合基数与渗透阶段：高基数下的增速回落、低渗透阶段的高增要区别对待。
  4. 多维交叉时，转入5.3.5的矩阵方法。
- **关键指标与数据来源**：分维度收入增速与占比。
- **判断标准**：增速需放在基数和渗透阶段里评价——新品牌、新区域的高增不等于可持续；成熟区域的低增或负增要判断是份额流失还是行业性放缓。
- **海豚案例**：
  - Monster：国际业务占比45%。
  - 名创：TOP TOY +51%，海外+22%。
  - Lululemon：北美-3%，中国+29%。
  - 泡泡玛特：中国100-105%，欧美增速偏弱。
  - 新东方：K12新业务+23%。
  - 可口可乐：零糖+13%。
- **适用场景与注意事项**：适用于消费、零售、教育。各维度的占比加总要与总收入核对，避免口径重叠；品牌/IP的依赖度见5.5。

### 5.3.10 分部收入减内部抵消，推算对外收入（判断“自产自销”程度）

- **方法要点**：垂直一体化公司的某个分部收入包含为自有产品服务的内部收入；用分部收入减去合并报表中的业务间抵消总额，得到对外收入，并计算其占分部收入的比例，判断外部客户的实际突破程度。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对外收入 ＝ 分部收入 − 合并报表中的业务间抵消总额。
  2. 对外占比 ＝ 对外收入 ÷ 分部收入。
  3. 逐季追踪对外收入的绝对额与占比，判断外部客户有无实质性进展。
  4. 结论落点：只有外部大客户在先进制程（14A/18A）上的实质订单与收入贡献，才能支撑估值。
- **关键指标与数据来源**：代工部门收入；合并抵消总额；对外代工收入及占比。
- **判断标准**：对外占比极低（约3%-5%）⇒ 业务“仍几乎是自产自销”，估值逻辑尚未建立；对外收入持续提升并出现外部大客户订单 ⇒ 兑现。
- **海豚案例**：
  - 英特尔（2026-01-23）：Q4'25代工45亿，内部抵消43.4亿，对外极少。
  - 英特尔《英特尔：告别“至暗”时刻…》（2026-04-24）：Q1'26代工54.2亿，抵消52.5亿，对外约1.7亿（约3%）。
  - 英特尔《英特尔：CPU 涨价救场，翻身还得看代工？》（2026-07-24）：Q2'26代工57.7亿，抵消54.8亿，对外约3亿（约5%）；结论：代工“仍几乎是自产自销”。
- **适用场景与注意事项**：适用于有内部交易的垂直一体化公司（IDM、整车＋电池、云＋自用）。抵消额可能包含其他分部之间的交易，属于近似估算；合并报表内部抵消与物理吞吐指标的使用见4.3。

## 5.4 核心/非核心、新业务与AI收入

> 本节导读：本节讲“给业务定位并分别追踪”的方法——收入三分（核心、第二曲线、衰退业务）、剔除非核心收入或新业务后看核心业务的真实预期差与增速、非核心业务的简要追踪、次要业务增速变化推断主动收缩、新业务对总增长的百分点贡献（含隐藏在大板块中的新业务）、伴生业务验证主业景气，以及AI收入的估算、AI含量分层、年化run-rate、季度与指引展望追踪、量化代理指标、横向比较和“AI贡献 vs 行业β”的区分。当财报总数“符合预期”却藏着结构变化，或市场用AI叙事给公司定价时使用。与5.3（多维结构拆分）、第6章（前瞻指标）、第15章（AI算力、云、大模型、软件）配合。

### 5.4.1 收入三分定位（核心/第二曲线/衰退业务）＋事件型增量类比估算

- **方法要点**：把多业务线平台按定位分成三块——核心业务、第二曲线、衰退业务——分别用不同指标评价；对事件型增量（如大牌歌手新专辑）用历史类比估算贡献，并跟踪实际反响校准。
- **操作步骤 / 拆分口径 / 公式**：
  1. 业务三分与评价口径：
     - 订阅（占一半以上，估值关键）：看增速阈值；
     - 其他音乐服务（广告、数字专辑、演唱会、周边、版权转授权；第二曲线，占约30%）：看高增延续与占比；
     - 社交娱乐（直播/K歌；衰退业务）：看是否筑底。
  2. 每个季度分别记录各块增速与占比，并写出评价维度，避免用同一把尺子衡量。
  3. 事件型增量：用历史类比估算（如周杰伦上一张专辑独家数字版创收超2亿），推断新专辑增量；同时跟踪实际用户反响（弱于四年前）修正。
  4. 衰退业务下滑的原因要追问：用户活跃下滑、新场景（AI翻唱）与旧场景重合等（可用QuestMobile等第三方活跃数据验证）。
- **关键指标与数据来源**：三块收入增速与占比、演唱会场次、专辑销量；QuestMobile活跃数据。
- **判断标准**：第二曲线高增延续且占比提升、衰退业务降幅收窄或企稳 ⇒ 整体结构改善；第二曲线进入高基数后增速回落（如+41%→+28%→+16%），则要判断是正常的基数效应还是增长动能衰减；衰退业务降幅持续扩大（-5%→-11%→-16%）⇒ 尚未筑底。
- **海豚案例**：
  - 腾讯音乐《汽水猛攻》（2026-03-17）：其他音乐+41%、社交娱乐-5%。
  - 腾讯音乐《收编喜马拉雅》（2026-05-12）：其他音乐+28%、社交娱乐-11%（QM显示全民K歌活跃下滑，且AI翻唱场景重合）。
  - 腾讯音乐《慷慨回购》（2026-08-11）：其他音乐+16%（高基数）、社交娱乐-16%。
  - 腾讯音乐（周杰伦新专辑事件）：以上一张专辑独家数字版创收超2亿作类比估算新专辑增量，并跟踪到实际用户反响弱于四年前。
- **适用场景与注意事项**：多业务线平台。类比估算只是量级参考，需随实际数据修正；三分业务的占比口径要与公司披露分部一致。

### 5.4.2 剔除干扰项后看核心业务的真实预期差与真实增速

- **方法要点**：总收入符合预期或增长亮眼时，从中剔除“非核心收入”或“新业务收入”，单独看核心业务的收入与增速，避免总数掩盖核心业务的真实表现。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A（剔除非核心收入，看核心的预期差）：
    1. 把总收入拆成核心业务（如ToB网络招聘服务）与非核心收入（如C端增值服务）。
    2. 若非核心收入大幅下滑是公司的主动策略（提供更多免费服务以保持生态粘性），则核心业务收入的预期差应单独评价。
    3. 核心业务收入对照市场预期，得出“核心业务略超预期”这类结论。
  - 变体 B（剔除新业务，看核心的真实增速）：
    1. 核心业务收入 ＝ 总收入 − 新业务收入。
    2. 计算核心业务同比，对比总增速：新业务开始贡献收入时，核心业务增速可能已在放缓。
    3. 对照指引区间与市场预期，判断是否在指引偏下限。
- **关键指标与数据来源**：总收入、核心业务收入、其他收入及增速、新业务收入、核心业务同比。
- **判断标准**：
  - 非核心收入下滑属主动优化 ⇒ 不应拖累对核心业务的判断，核心业务可能略超预期；
  - 新业务贡献让总增速好看、核心增速明显低于总增速 ⇒ 总数会掩盖主业降速，核心业务增速低于市场预期时要下调对核心的判断。
- **海豚案例**：
  - Boss直聘（2026-05-20）：Q1总收入20.7亿、+7.6%；ToB网络招聘服务20.6亿、+8.2%；其他收入1101万、-50%，因为对求职者增值服务做了优化，“企业端的招聘收入实际上略超市场预期”。
  - 禾赛《2Q26》（2026-08-19）：总收入8.6亿，同比+22%，在8.5-9亿指引的偏下限；新业务SGI（Kosmo和执行器模组）贡献0.4亿，剔除后核心激光雷达收入约8.1亿，同比增速已放缓至约16.5%，低于市场预期。
- **适用场景与注意事项**：适用于有多条收入线、非核心收入扰动总数，或第二增长曲线开始贡献收入的公司。新业务口径要和公司分部披露保持一致；被市场忽视的次要业务预期差见2.3。

### 5.4.3 非核心业务的简要追踪：所处周期＋季节性＋管理层年度展望

- **方法要点**：占比较小的传统/非核心业务不做深度拆解，用一段话交代——收入与同比、所处的产品或主机周期年份、季节性因素、管理层的年度增长展望；目的是不遗漏潜在拖累项，同时把篇幅留给核心业务。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录非核心业务收入及同比。
  2. 标注所处的产品/主机周期年份（如主机周期进入第7年）及下一代产品时间点。
  3. 标注季节性因素（如无线业务的季节性下滑）。
  4. 引用管理层的年度增长展望（如FY27增长约10%、FY28低个位数）。
  5. 一段话收尾，点明该业务是拖累项、对冲项还是中性。
- **关键指标与数据来源**：非核心业务收入同比、周期年份、季节性、年度展望。
- **判断标准**：用来判断该业务是否会成为新的拖累或对冲项；管理层展望明显低于核心业务时，在整体增速判断中单列一笔风险。
- **海豚案例**：
  - AMD（2026-02-04）：游戏8.4亿，+49%，其中半定制同比增、环比降；主机周期进入第7年，下一代Xbox预计2027年推出；Radeon RX9000在假期期间需求旺盛。嵌入式9.5亿，+3%。
  - 博通：非AI半导体41亿持平 / 42亿+6%，企业网络、宽带、服务器存储的增长抵消了无线业务的季节性下滑。
  - Marvell：通信及其他业务5.7亿+25% / 5.85亿+28%，管理层预计FY27增长约10%、FY28低个位数增长。
- **适用场景与注意事项**：通用。避免在非核心业务上过度展开；一旦其占比或增速扰动总数，应升级为5.4.2的剔除分析。

### 5.4.4 次要业务线增速变化：推断主动收缩或红利期终结

- **方法要点**：对集团内的次要业务线，用增速变化来推断背后的战略动作或驱动因素的变化：行业改善而该业务下滑 → 主动清退低质业务；长期高增长的业务突然放缓 → 驱动红利期走完、进入瓶颈。
- **操作步骤 / 拆分口径 / 公式**：
  1. 找出与整体趋势反向的次要业务：行业改善、口径无调整，但该业务仍负增长。
  2. 若是，推断公司在主动收缩低质量业务（如自营零售）。
  3. 对长期高增长业务出现突然放缓，追问驱动因素是否已经走完（如会员附加服务费的红利）。
  4. 与核心指标（如CMR）对照，看次要业务是否同步减速。
- **关键指标与数据来源**：自营零售收入同比、1688批发收入同比、会员附加服务收入驱动。
- **判断标准**：行业改善而业务下滑且无口径调整 ⇒ 主动收缩；持续两年多10%-20%的高增后降至低个位数 ⇒ 红利期终结、进入瓶颈期。
- **海豚案例**：
  - 阿里《阿里：电商再沦陷》（2026-03-19）：自营零售同比+0.3%，与CMR一样大幅减速；1688批发同比+5.3%，靠会员附加服务拉动。
  - 阿里《阿里：电商退位，AI上位》（2026-05-14）：电商整体在改善，自营零售没有口径调整却同比约-6%，推断公司在主动收缩低质量自营；1688批发增速放缓到2.6%，在持续两年多10%-20%的高增后进入瓶颈期，会员附加服务费的红利可能已经走完。
- **适用场景与注意事项**：适用于多业务线集团的边缘业务诊断。推断需先确认没有口径调整、并表变化（见4.2）。

### 5.4.5 新业务收入对总收入增长的贡献（百分点）测算

- **方法要点**：新业务增长亮眼但体量小时，测算它对总收入增速的贡献，判断“战略意义大于当期贡献”，避免被叙事过度定价。有两种来源：公司披露了新业务体量和目标（变体 A），或新业务隐藏在传统板块中、需要从业绩会/年报文字里提取体量（变体 B）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取新业务去年收入与今年收入（或目标）。
  2. 贡献（pct）＝（新业务今年收入 − 去年收入）÷ 去年总收入；或用“新业务体量 × 指引增速 ÷ 总收入”换算。
  3. 同时计算新业务占营收比重。
  4. 变体 B：新业务（如数据中心液冷、储能热管理）并入传统板块、未单独列示时，从业绩会或年报文字中提取其体量（如10亿→14亿，与储能合计约20亿），再用指引增速（如50-100%）乘以体量、除以总收入，换算对总增速的贡献。
  5. 判断新业务对整体的拉动是否已经足够大，是“战略意义”还是“当期贡献”。
- **关键指标与数据来源**：新业务收入及目标、占营收比重、增速指引、对总增速贡献（pct）；业绩会口头披露、年报文字。
- **判断标准**：新业务贡献仅约3-5个百分点、体量占比不大 ⇒ 战略意义大于当期贡献，不应让它主导整体估值；若贡献足够大，才可视为总增速的实质性驱动。
- **海豚案例**：
  - 三花（2026-08-27）：液冷加储能2025年约20亿（液冷约14亿），2026年目标30亿（+50%-100%），2025年占营收约6.5%；海豚君测算对2026年总收入增长贡献约3-5个百分点。
  - 三花《“天灾人祸”…》（2026-03-31）：数据中心客户收入2024年10亿，2025年14亿（约+40%）；指引2026年数据中心与储能增速50-100%，相当于贡献总收入约3-5pct的增速，体量对增长的贡献有限。
  - 三花《汽零回正…》（2026-05-06）：维持50%-100%目标，客户覆盖北美特灵，以及国内维谛、英维克。
- **适用场景与注意事项**：适合有第二曲线的成熟公司，以及在传统业务中孵化新业务的公司。变体 B 需要管理层口头披露，体量属于估算；基数、指引的使用见第9章。

### 5.4.6 用伴生业务作为主业景气的验证

- **方法要点**：观察与主业增长相伴的小业务（如云部署带来的咨询需求），用其增速变化交叉验证主业景气度，同时说明其体量小、对整体影响有限。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别伴生业务：因主业放量而产生的配套服务（咨询、实施、部署）。
  2. 跟踪其增速变化，与主业增速对照。
  3. 声明体量，避免高估对整体的影响。
- **关键指标与数据来源**：咨询/服务收入增速。
- **判断标准**：伴生业务增速加快并突破某一阈值（如超过10%）⇒ 印证主业的部署需求旺盛；伴生业务减速则提示主业景气有边际变化。
- **海豚案例**：
  - 甲骨文（2026-03-11）：咨询业务因云业务快速增长带来部署需求，增速持续加快并突破10%，但体量不大。
- **适用场景与注意事项**：有服务/咨询伴生收入的软件、云公司。只能作为辅助验证，不能替代对主业订单（第6章）的直接追踪。

### 5.4.7 公司不披露时，自行估算AI收入/细分产品收入

- **方法要点**：市场最关心的细分收入（AI GPU、AI业务、互连、被并购业务）未披露时，结合公司口径、管理层表述和市场预期拆分估算，并逐季跟踪估算值的环比增量。
- **操作步骤 / 拆分口径 / 公式**：
  1. 办法一：用总额减已知项倒推（如博通软件总额减去原CA/Symantec/Brocade约20亿，得到VMware；AMD数据中心收入减AI GPU估算得出CPU）。
  2. 办法二：按管理层给的占比估算（如Marvell AI占比40%以上，则估算AI收入）。
  3. 逐季跟踪估算值及环比增量，以及占总收入的比重。
  4. 文中明确标注“海豚君预估”，公司一旦有新披露，立即校准。
- **关键指标与数据来源**：估算AI收入、AI占比、环比增量；被并购业务估算收入。
- **判断标准**：估算值的环比增量与管理层目标（如AI占比50%以上）对照，判断是否接近或偏离目标；两种办法互相印证时，估算可信度更高。
- **海豚案例**：
  - AMD（2026-02-04）：数据中心53.8亿 ＝ AI GPU约24亿 ＋ 数据中心CPU约29.8亿。
  - Marvell（2026-03-06）：AI收入约9.6亿，环比+1.1亿，占总收入40%以上（管理层目标50%以上）；2026-05-28：互连产品约9亿，约占数据中心一半。
  - 博通（2026-03-05）：VMware约46亿；2026-06-04：约50亿。
- **适用场景与注意事项**：适合信息披露较粗的半导体/软件公司。用总额倒推未披露业务的更一般方法见4.6。

### 5.4.8 “AI含量”：AI相关收入占比＋三层AI收入分项追踪

- **方法要点**：对AI转型中的传统互联网公司，构建 AI含量 ＝ AI相关收入 ÷ 核心总营收，逐季追踪；再把AI收入分三层分别看，识别真正扛大梁的一层，并通过AI收入同比增速变化判断加减速。
- **操作步骤 / 拆分口径 / 公式**：
  1. 计算AI含量：Q3 39% → Q4 43% → Q1 52% → Q2约50%（持平）。
  2. 分三层：
     - AI云基础（云、大模型API、算力租赁）；
     - AI应用（文库、网盘、数字员工、通用智能体）；
     - AI原生营销（Agent和数字人）。
  3. 分别看三层的环比/同比，以及在AI收入中的占比；同时看GPU云增速。
  4. 看AI收入同比增速的变化（Q1 49% → Q2 27%）判断加减速。
  5. 推导逻辑：若AI占比提升主要靠算力租赁，体现的是行业算力紧缺，而非公司产品竞争力；AI应用与AI原生营销连续2-3季走平，是对公司AI不乐观的核心依据。
- **关键指标与数据来源**：AI相关收入、AI含量、三分项收入及环比/同比、GPU云增速。
- **判断标准**：AI占比提升由云基础（算力租赁）贡献 ⇒ 反映行业景气而非产品力；应用与原生营销走平 ⇒ 公司自身AI变现不乐观；AI收入增速下降（49%→27%）⇒ 减速；AI云收入增速低于一致预期 ⇒ 不及预期。
- **海豚案例**：
  - 百度《百度：广告根基已废》（2026-02-26）：AI收入113亿，占43%；AI云环比+35%，AI应用环比持平，AI原生营销环比走低。
  - 百度《百度：其他没指望》（2026-05-18）：AI收入136亿，占52%；AI云88亿，占AI的2/3，同比+79%。
  - 百度《百度：老业务继续磨底》（2026-08-18）：AI收入124亿，增速49%→27%；AI云73亿，占60%，+53%，低于BBG一致预期。
- **适用场景与注意事项**：单独披露AI收入的转型公司。AI收入由公司自定义，可能含旧业务重分类，需留意口径；算力租赁、大模型、广告三块并归因到具体合同的做法见15.2。

### 5.4.9 AI相关收入占比与年化run-rate推算

- **方法要点**：把公司披露的单季AI相关收入乘以4得到年化规模，再计算其占云总收入的比重，并结合增速（三位数）推断：只要供给约束改善，云业务大概率持续加速；连续追踪AI收入占比的提升，也作为云利润率是否被拖累的观察基础。
- **操作步骤 / 拆分口径 / 公式**：
  1. 年化AI收入 ＝ 单季AI相关收入 × 4。
  2. AI占云收入比重 ＝ 单季AI相关收入 ÷ 云单季总收入（等价于年化AI ÷ 年化云收入）。
  3. 叠加AI收入同比增速，判断云业务的加速潜力与供给约束的关系。
  4. 连续多季追踪占比提升，并观察云利润率是否被拖累。
- **关键指标与数据来源**：单季AI相关收入、年化AI收入、AI收入占云收入比重、AI收入同比。
- **判断标准**：AI收入仍在三位数增长、占比快速提升 ⇒ 云业务有加速基础，约束在供给端而非需求端；占比上升而云利润率下降 ⇒ 需警惕AI收入拖累利润率。
- **海豚案例**：
  - 阿里《阿里：电商退位，AI上位》（2026-05-14）：AI相关收入约90亿，年化360亿，相当于云收入的1/5，仍在三位数增长。
  - 阿里《阿里狂投》（2026-08-21）：AI相关收入124亿，同比超150%，占板块总收入近26%。
- **适用场景与注意事项**：适合有AI业务披露的云厂商、软件公司。要注意公司对AI收入的定义是否一致；单季×4只是粗略run-rate，不代表全年。

### 5.4.10 单列AI业务：季度AI收入、环比增量、下季指引与年度展望

- **方法要点**：把AI业务从半导体收入里单独拿出来，跟踪季度收入相对预期、环比增量、下季AI收入指引相对预期，以及多年度的AI收入展望（旧值→新值），同时单看非AI业务增速，判断传统业务是否企稳。
- **操作步骤 / 拆分口径 / 公式**：
  1. AI收入实际值对比预期，计算环比增量。
  2. 下季AI收入指引对比预期。
  3. 年度AI收入展望：记录旧值与新值，计算上修幅度。
  4. 同时单列非AI业务（非AI半导体、基础设施软件）的收入与增速。
- **关键指标与数据来源**：AI收入、环比增量、下季AI指引、年度AI收入展望、非AI收入增速。
- **判断标准**：AI收入高于预期、环比增量大、下季指引高于预期 ⇒ 强；多年展望被上修 ⇒ 订单能见度提升；非AI业务企稳则说明传统业务不再拖累。
- **海豚案例**：
  - 博通（2026-09-03）：AI收入167亿，高于预期160亿，环比+59亿；下季指引217亿，略高于预期215亿；FY26-28 AI收入展望为580亿（原560亿）、1150亿（原1000亿）、2300亿；非AI半导体42亿（+5%）；基础设施软件87.5亿（+29%）。
- **适用场景与注意事项**：AI芯片、ASIC、网络类公司。展望的客户拆分与付款能力分级见5.5.4。

### 5.4.11 AI直接变现的量化代理指标

- **方法要点**：用可量化的指标衡量AI对业务的直接贡献——AI广告工具的年化收入运行率、新产品用户（MAU/DAU与粘性）、模型能力排名与API价格（性价比）、云业务订单意向；并提示意向订单到确认收入之间存在时间差。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取AI工具的年化收入运行率（如Advantage+）。
  2. 取新产品用户：MAU、DAU与粘性（DAU÷MAU）。
  3. 取模型能力排名与API定价，判断性价比（价格相对头部的比例）。
  4. 取云业务的订单意向，并折算成收入时注意确认时间差。
- **关键指标与数据来源**：AI工具年化收入；新产品MAU/DAU；模型排名与API定价；订单意向。
- **判断标准**：AI工具的年化收入达到可观规模、新产品用户与粘性持续提升、模型性价比具备竞争力 ⇒ 直接变现能力在增强；订单意向尚未转化为确认收入 ⇒ 对收入的拉动要后移。
- **海豚案例**：
  - Meta（2026-01-29）：Threads月活4亿以上、日活1.4亿，粘性35%。
  - Meta（2026-07-30）：Advantage+年化收入运行率超750亿美元；Threads月活5亿；Muse Spark智能水平进入TOP10、价格只有头部的30%，搭载算力的模型API具备竞争力；云业务主要以模型API形式出售算力，意向订单到确认收入有时间差。
- **适用场景与注意事项**：有AI新业务的平台公司。代理指标不等于收入，需持续追踪其向收入转化的进度；订单类指标见第6章。

### 5.4.12 AI收入/ARR横向比较

- **方法要点**：收集各家AI收入口径（年化营收、ARR、AI收入占比、付费用户、token量）做横向比较，并检查AI是否带动总收入提速；若AI增长被传统业务萎缩对冲，意义有限。
- **操作步骤 / 拆分口径 / 公式**：
  1. 统一各家披露口径：年化营收、ARR、占比、付费用户、token量。
  2. 同口径横向比较（如微软AI年化 vs 亚马逊AI年化）。
  3. 检查AI增长是否带动总收入提速，还是被传统业务萎缩对冲。
- **关键指标与数据来源**：AI年化收入、ARR、收入占比、付费用户、token量。
- **判断标准**：AI规模大但占总收入比重低、且传统业务萎缩对冲 ⇒ 对总收入提速的意义有限；AI规模对比时要核对口径一致（年化 vs ARR）。
- **海豚案例**：
  - 微软（2026-04-30）：AI年化370亿，比亚马逊的150亿高近150%。
  - 阿里（2026-05-13）：AI年化360亿，占云收入超1/5。
  - 快手：可灵ARR 5亿美元。
  - Salesforce：AI收入占比8%，但被传统业务萎缩对冲。
  - 谷歌：Gemini Enterprise付费用户+40%，token量从100亿增至160亿。
  - 百度：GPU收入+184%，AI应用环比-7%。
- **适用场景与注意事项**：适用于AI商业化早期的科技公司。各家AI口径不可直接比较，横向比较时需同时标注口径；软件类AI ARR跟踪见15.4。

### 5.4.13 增长归因：区分“AI贡献”与行业自身的β

- **方法要点**：面对“AI驱动增长”的叙事，把增长动能逐一列出——宏观、行业趋势、产品红利、新产品、AI——识别出“没有AI也会受益”的部分，以此评估纯AI的回报率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出广告（或其他主业）增长的所有驱动：
     - 宏观（北美宏观、冬奥会）；
     - 行业趋势（消费品营销线上化）；
     - 产品红利（Reels短视频、CPM上升）；
     - 新产品（Threads商业化）；
     - AI（推荐算法、Advantage+）。
  2. 把“没有AI也会受益”的部分（宏观、行业、产品红利）剔除，估算纯AI的贡献。
  3. 与有“几乎纯靠AI驱动、已进入兑现期”的第二曲线的公司对照（如谷歌云），评估AI回报是否可被清晰度量。
- **关键指标与数据来源**：广告增速；各驱动因素。
- **判断标准**：增长中大量动能属于行业β ⇒ AI的边际贡献被高估；缺少可清晰度量的AI第二曲线 ⇒ “纯AI回报率”算不明白，应谨慎给AI溢价。
- **海豚案例**：
  - Meta（2026-04-30）：Q1广告+33%，超过指引，但其中包括北美宏观不差、冬奥会、营销线上化、Reels红利和Threads增量，都属于广告业自身的动能；Meta缺少像谷歌云那样几乎纯靠AI驱动、已进入兑现期的第二曲线，“纯AI回报率”算不明白。
- **适用场景与注意事项**：处在AI叙事下的传统主业公司。各因素的贡献比例难以精确拆分，以定性排序为主；行业β与个股α的股价层面分离见11.5。

**相关方法交叉引用**

- 智能硬件按“旧产品线萎缩 vs 新产品线未放量”的新旧交替框架判断增长断档，详见15.10。
- 用总收入或指引减去成熟业务的假设增速，倒算未披露的新业务（电商广告）收入，详见4.6。
- AI业务拆为算力租赁/大模型/广告三块，并把增量归因到具体合同，详见15.2。
- AI业务ARR跟踪（规模、剔除并表后的环比增速、占总收入比重、应用层与中间层结构），详见15.4。
- 核心子产品的占比、环比、单月同比与年化run-rate追踪，详见5.3.7。
- 寻找被市场忽视的次要业务预期差，详见2.3。

## 5.5 客户结构与集中度

> 本节导读：本节讲“从客户维度看收入”——客户集中度与多元化追踪（含单一IP/单一客户依赖）、大客户与长尾客户拆分（增量是否依赖正在自研替代的大客户）、按付款能力分级（CSP vs AI实验室）、不同客户类型的价格弹性（长协锁价 vs 随行就市）、大客户销量增速对比公司对应业务增速、大客户项目级收入测算。适用于客户集中的半导体、云、零部件、IP消费公司，是判断需求确定性与单一客户风险的核心工具。与5.3.3（地区作为客户代理）、第6章（RPO与订单）、第9章（指引可信度）配合。

### 5.5.1 客户集中度与客户多元化追踪（含单一IP/客户依赖度）

- **方法要点**：持续跟踪最大客户（或客户体系）占RPO/收入的比重、已合作头部客户数量与新客户落地情况，判断单一客户风险是否在缓解；对IP类公司则追踪头部IP占比与第二梯队的增长，判断依赖风险。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A（B端大客户/客户体系）：
    1. 跟踪最大客户（体系）占RPO或收入的比重（如OpenAI＋微软体系占总RPO比重）。
    2. 列出已合作头部客户的数量与名单，新客户落地情况；ASIC类公司列出各客户的量产时间与需求量（GW）；终端硬件公司拆分客户类型（商用 vs 消费者）。
    3. 判断客户名单有无新增（“仍是6家，没有新增”）、核心客户份额是否下滑。
  - 变体 B（单一IP或单一客户）：
    1. 追踪头部IP（或头部客户）的收入占比，及第二梯队IP的占比与增速。
    2. 结合品类结构、区域增速，判断依赖风险。
    3. 零部件公司跟踪第一大客户占比的下降。
- **关键指标与数据来源**：大客户占RPO比重、客户数量与名单、各客户需求（GW）、商用/消费客户收入；IP收入占比；客户收入占比。
- **判断标准**：大客户占比持续下降、已签约头部客户数增多 ⇒ 单一客户风险缓解；客户名单长期无新增、核心客户份额下滑 ⇒ 集中度风险未解除；头部IP占比上升而新IP口碑一般 ⇒ 对单一IP依赖加重；第二梯队IP占比提升 ⇒ 依赖缓解的开端。
- **海豚案例**：
  - CoreWeave（2026-05-08）：OpenAI＋微软体系占总RPO的比重跌破40%，已与前四大AI模型商全部签约，Meta成为最大客户之一。
  - 博通（2026-03-05）：6大XPU客户（谷歌、Meta、字节、Anthropic、第五客户10亿、OpenAI），当前收入来自其中三家；2026-06-04：仍是6家，没有新增。
  - Marvell（2026-03-06）：核心客户只有亚马逊，且在Trainium中的份额在下滑。
  - 戴尔：CSG以商用客户为主（两个季度分别为商用116亿+16% / 消费19亿持平；商用130亿+18% / 消费16亿+9%）。
  - 泡泡玛特（2026-03-25）：The Monsters占比从34.7%升到40%，新IP口碑一般，引发对单一IP依赖的担忧；星星人占比从不到3%升到7.2%；毛绒品类从44%升到54%；国内+183%，海外+281%。
  - 三花（2026-03-23）：第一大客户占比从12.62%降到10.90%。
  - CoreWeave（2026-02-27）：新增RPO没有大单传闻，对头部大客户的依赖可能有所缓解。
- **适用场景与注意事项**：通用；对大客户驱动的半导体和云公司，这是核心风险指标；IP类消费公司、零部件公司同样适用。RPO与订单的指标详见6.1。

### 5.5.2 按客户类型（大客户 vs 长尾客户）拆收入，定位增量是否依赖正在自研替代的大客户

- **方法要点**：把数据中心收入按客户类型（超大规模CSP vs 其他云/ACIE：工业、企业、主权）拆分，计算各自的环比增量，判断增长是否依赖正在自研芯片的大客户；若主要增量来自长尾客户，说明公司在大客户“去依赖”的同时仍有第二增长曲线。
- **操作步骤 / 拆分口径 / 公式**：
  1. 拆分客户类型：超大规模（CSP）与其他云、ACIE（工业、企业、主权）。
  2. 计算各自收入及环比增量；比较增量来源。
  3. 若主要增量来自长尾客户，推导“只有大厂有能力定制ASIC”，长尾客户是护城河的延伸。
  4. 联系公司为长尾客户提供的附加承诺、担保、融资平台等，评估护城河的成本。
- **关键指标与数据来源**：超大规模客户收入及环增、ACIE/其他云收入及环增、占比变化。
- **判断标准**：长尾客户的环比增量大于或接近大客户增量 ⇒ 公司收入增长并非依赖正在自研替代的大客户；增量主要来自大客户而大客户有自研动力 ⇒ 增长存在被替代的风险。
- **海豚案例**：
  - 英伟达（2026-05-21）：超大规模379亿、环增40亿，其他云374亿、环增89亿，“是公司收入增长的最大增量”。
  - 英伟达（2026-08-27）：超大规模487亿、环增57亿，ACIE 403亿、环增81亿，“近两个季度的主要增量并非来自于大型CSP”。
- **适用场景与注意事项**：适用于客户集中、大客户有垂直整合风险的供应商（芯片、云、零部件）。长尾客户的付款能力与公司提供的担保、融资需单独评估，见5.5.4。

### 5.5.3 大客户销量增速 vs 公司对应业务增速，判断客户多元化进展

- **方法要点**：把第一大客户（如特斯拉）同期销量增速与公司对应业务（汽零）增速对比：大客户负增长而公司业务仍正增长，说明多元化取得进展；若指引偏乐观导致业绩不及预期，则判断是大客户预期过高，而非自身竞争力问题。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取第一大客户同期销量增速；取公司对应业务增速。
  2. 对比两者的差：公司业务增速显著高于大客户销量增速 ⇒ 来自份额提升或新客户。
  3. 追踪第一大客户收入占比（如12.6%→约11%）、前两大客户合计销量增速。
  4. 梳理新客户名单与贡献提升（比亚迪成为第二大客户，小米、零跑、吉利、理想贡献提升）。
  5. 业绩不及预期时判断归因：是大客户预期过高，还是公司自身竞争力问题。
- **关键指标与数据来源**：第一大客户收入占比、大客户销量增速、公司对应业务增速、新客户名单。
- **判断标准**：大客户销量负增长而公司业务仍增 ⇒ 多元化有进展；大客户占比持续下降且新客户占比提升 ⇒ 集中度风险缓解；指引失误源自大客户预期过高 ⇒ 属于需求预期问题，而非竞争力下滑。
- **海豚案例**：
  - 三花《“天灾人祸”…》（2026-03-31）：特斯拉25Q4销量-16%，三花汽零下半年仍+9%；第一大客户占比从12.6%降至接近11%；比亚迪成为第二大客户。
  - 三花《汽零回正…》（2026-05-06）：Q1新能源车行业-5%，比亚迪＋特斯拉销量合计-21%，三花汽零仍增长约15%（收入31.2亿），大客户占比降至20%-25%。
- **适用场景与注意事项**：适用于客户集中度高的零部件、代工企业（汽零、果链）。需要核对“对应业务”与“大客户销量”的口径匹配；汽车零部件行业专属指标见16.2。

### 5.5.4 按客户拆分需求，并按付款能力分级（CSP vs AI实验室）

- **方法要点**：把公司的远期需求拆到具体客户，再按付款能力分级：大型CSP（谷歌、Meta）的需求由资本开支指引背书，确定性强；AI实验室（Anthropic、OpenAI）的需求取决于ARR增长和外部融资，市场会打折。客户结构决定了指引的可信度。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把远期需求（如GW）拆到具体客户。
  2. 按付款能力分级：CSP（有自有资本开支支撑）与AI实验室（依赖ARR与融资）。
  3. 检验CSP的capex指引是否上调，检验AI实验室的ARR斜率是否放缓。
  4. 对不同层级的需求赋予不同的确定性折扣。
- **关键指标与数据来源**：各客户GW或收入占比、客户capex、客户ARR斜率。
- **判断标准**：CSP已上调capex ⇒ 需求确定性较强；AI实验室ARR斜率放缓、外部融资依赖高 ⇒ 对应部分的展望需要打折；某一客户占远期需求的比重过高（如占一半）⇒ 整体指引的可信度被该客户的兑现情况牵制。
- **海豚案例**：
  - 博通（2026-09-03）：2027财年10GW大致拆为谷歌3-4GW、Anthropic 5GW、OpenAI 1-2GW、Meta 1-2GW；公司共有6个XPU客户；谷歌和Meta已上调全年capex，确定性较强；2028财年20GW中有10GW来自Anthropic，因其ARR斜率放缓，市场对这部分展望打折。
- **适用场景与注意事项**：客户集中度高的B2B公司。客户capex与融资能力的数据需与外部验证（见第14章）；指引可信度的更多维度见第9章。

### 5.5.5 按客户类型/部门看价格弹性差异（长协锁价的大客户 vs 随行就市的中小客户）

- **方法要点**：利用公司按下游客户划分的部门（如美光的CMBU超大规模云客户内存含HBM、CDBU中小客户内存和数据中心闪存/SSD、MCBU移动与客户端、AEBU汽车与嵌入式），分析哪个部门环比最猛，并与合约结构关联，推断不同客户的价格弹性；同时用部门数据寻找超预期最多的地方，并推导下游厂商的成本压力。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取各部门收入及环比，计算数据中心占总收入比重（50%+→63%）。
  2. 比较各部门环比：哪个最猛、哪个明显放缓；与各部门的合约结构（长协 vs 市场价）对应。
  3. 推断弹性：超大客户的价格天花板被长协锁定，中小客户价格更受市场价影响，弹性更大。
  4. 找出超预期最多的部门（如核心数据中心环增103%）。
  5. 由上游涨价传导到下游：手机和PC存储收入环增接近50%，推导下游手机厂和PC厂的毛利率会承压。
- **关键指标与数据来源**：各BU收入及环比；数据中心收入占比（50%+→63%）；各BU的合约结构。
- **判断标准**：超大客户部门环增明显放缓、中小客户部门环增最猛 ⇒ 长协锁价限制了大客户的价格上行，价格弹性集中在中小客户；某部门环增接近50% ⇒ 上游涨价，下游厂商毛利率承压。
- **海豚案例**：
  - 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：数据中心占比63%，CMBU环增明显放缓、CDBU环增最猛，推断超大客户价格被长协锁定、中小客户弹性更大。
  - 美光《美光：牛气冲天！…》（2026-06-25）：核心数据中心115亿（环增103%），云存储138亿（+78%），手机/PC存储收入环增约50%，推导下游手机厂和PC厂毛利率会承压。
- **适用场景与注意事项**：适用于客户分层明显、合约定价方式不同的B2B公司（存储、晶圆代工、云）。需要公司披露按客户划分的部门，部门口径调整时先做口径还原；长协与价格机制对毛利率的影响见7.3。

### 5.5.6 大客户收入占比与项目级收入测算（项目GW→满产年化收入）

- **方法要点**：用外资行测算与项目体量估算大客户的贡献——项目GW规模换算为满产年化收入；大客户占收入比重的演变路径；结合大客户迁移时点解释为何此前拉动不显著、后续将更明显；以大客户ARR作为验证信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 项目GW规模 → 满产后年化收入（如2.2GW → 约140亿）。
  2. 外资行测算大客户占公司收入比重的演变（如从25年0.5%升至27年3%以上）。
  3. 结合大客户迁移时点（从GCP转向AWS，3Q25-4Q25才大量转用）解释此前拉动不显著、后续更明显。
  4. 以大客户ARR作为验证信号。
  5. 梳理与第二外援（OpenAI）的合同与潜在投资，评估新的集中度来源。
- **关键指标与数据来源**：项目GW、满产年化收入、大客户收入占比、客户ARR、合同额；外资行测算、Semi Analysis等第三方报道。
- **判断标准**：项目满产年化收入与公司整体体量对比，判断大客户对增长的重要程度；大客户占比逐年上升 ⇒ 集中度与增长贡献同步上行；客户ARR兑现是验证信号。
- **海豚案例**：
  - 亚马逊（2026-02-06）：Project Rainier总体量2.2GW，满产后年化约140亿收入；某外资行测算Anthropic占AWS收入比重从25年0.5%升至27年3%以上；Semi Analysis报道Anthropic在3Q25-4Q25才大量转用AWS；OAI与AWS签380亿7年合同，传亚马逊拟在1000亿融资中出500亿。
- **适用场景与注意事项**：客户集中度高的B端公司（云、半导体、零部件）。外资行测算与媒体报道属二手估算，应标注来源，并以客户ARR和公司披露做后续验证；云业务的容量与订单指标见6.1、15.2。

## 5.6 用户与流量指标

> 本节导读：本节收纳跨平台通用的用户指标方法——MAU/DAU环比净增与往年同期比较、DAU与MAU分拆判断用户质量、粘性（DAU/MAU、DAU/WAU、时长）、用年度平均MAU倒算净增、分地区用户与用户价值、补贴/门槛政策效果检验、用户活跃反常的季节性回落预警、订阅渗透率的分母效应，以及私域留存与月均交易客户。用于判断用户增长是真实流量还是活动冲量，是否真正转化为变现。游戏、社交、订阅内容的专属指标（如用户指标三件套）归15.8、15.9；季节性校正见3.4；用户价值的货币化环节见5.1、5.2。

### 5.6.1 MAU环比净增与往年同期比较，并用QuestMobile看垂类MAU排名与时长份额

- **方法要点**：看MAU时关注环比净增额，并和往年同期的季节性比较，区分短期因素（春节、赞助曝光）与中长期趋势（渗透阶段顶部、跨品类竞争）；再用QuestMobile数据看垂类内的MAU排名与用户总时长份额，判断竞争地位。
- **操作步骤 / 拆分口径 / 公式**：
  1. 计算MAU环比净增；取往年同期净增对比。
  2. 区分短期因素（春节、世界杯赞助曝光、春招）与中长期趋势（白领渗透接近阶段顶部；蓝领用户要与抖音、快手及线下招工渠道竞争）。
  3. 用QuestMobile看垂类内MAU排名和用户总时长份额，判断竞争地位。
- **关键指标与数据来源**：MAU、环比净增、往年同期净增、QuestMobile垂类MAU与时长份额。
- **判断标准**：净增弱于往年同期 ⇒ 增长动能弱于季节性；净增由春招、赞助曝光等短期事件拉动 ⇒ 不外推；用户总时长份额继续提升、MAU遥遥领先 ⇒ 竞争地位稳固。
- **海豚案例**：
  - Boss直聘（2026-05-20）：MAU 6090万，环比净增290万，弱于往年；QM显示MAU遥遥领先，用户总时长份额继续升至60%以上。
  - Boss直聘（2026-08-25）：MAU 7000万，净增930万，由春招和世界杯赞助曝光拉动。
- **适用场景与注意事项**：适用于消费互联网公司。季节性与日历效应校正方法见3.4；第三方数据与公司数据不一致时，见5.6.3。

### 5.6.2 粘性指标（DAU/MAU、日均时长）加QuestMobile总时长做同业横向对比

- **方法要点**：追踪MAU（注意季节性）、DAU/MAU与日均时长，并用QM总时长增速和同业横向比较，判断平台在存量竞争中的位置——这个位置是业绩低增长期的底部支撑论据。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取MAU，并剔除季节性后看趋势。
  2. 粘性 ＝ DAU ÷ MAU；日均时长同比变化（分钟）。
  3. 取QM总时长增速，并与同业（字节系、小红书、快手、微信、爱优腾）横向比较。
  4. 定位：“除字节、小红书外为数不多正增长的头部平台”，作为业绩低增长期的底部支撑论据。
- **关键指标与数据来源**：MAU、DAU/MAU、日均时长、QM总时长增速（公司及同业）。
- **判断标准**：DAU/MAU与日均时长同比提升、QM总时长正增长且领先同业 ⇒ 流量复苏、存量竞争地位稳固；DAU/MAU创新高 ⇒ 用户质量提升。
- **海豚案例**：
  - B站（2026-03-05）：MAU季节性环比减少1000万，DAU/MAU 30.9%，时长107分钟（+8分钟）；QM 1月总时长约+9%。
  - B站（2026-05-19）：MAU 3.76亿，DAU/MAU 30.6%，时长119分钟（+11分钟）。
  - B站（2026-08-27）：MAU 3.71亿、+2%，DAU/MAU 31.5%创新高，时长113分钟；QM 6月总时长+7%，流量复苏已持续一年多。
- **适用场景与注意事项**：适用于内容社区平台。MAU有明显季节性，需配合同比与往年同期；第三方总时长口径与公司口径不同，仅作方向与排名参考。

### 5.6.3 MAU与DAU分拆判断用户增长质量，并与第三方数据核对

- **方法要点**：MAU加速增长而DAU持平甚至流失时，判断MAU扩张来自春节活动或特定事件的短期冲量；与广告变现相关的是DAU、日均时长和粘性（DAU/MAU）。公司数据与第三方数据不一致时，在电话会上追问。
- **操作步骤 / 拆分口径 / 公式**：
  1. 分别比较MAU和DAU的净增与同比；比较DAU/MAU粘性与日均使用时长。
  2. 若MAU加速而DAU平甚至净流失，判断MAU扩张为活动冲量（春节活动等）。
  3. 与季节性及去年同期净增比较，并关注DAU与MAU的背离。
  4. 与第三方用户数据核对，不一致时列入电话会追问清单。
  5. 长期看：生态流量持续下滑是主业增长压力的根源。
- **关键指标与数据来源**：MAU净增和同比、DAU净增和同比、DAU/MAU粘性、日均使用时长、第三方用户数据。
- **判断标准**：MAU增而DAU减 ⇒ 增长质量低、与变现无关；DAU与时长同比持平且粘性稳定 ⇒ 用户生态已成熟；MAU与第三方数据背离 ⇒ 存疑，需追问。
- **海豚案例**：
  - 快手《快手：一场向死而生的暴跌，能换来AI重生吗？》（2026-03-25）：MAU 7.4亿，DAU 4.1亿，同比低个位数增长；粘性55%，时长同比持平，用户生态已成熟。
  - 快手《快手：老铁翻身，就靠“可灵”了》（2026-05-27）：DAU+1.2%至4.13亿，MAU加速增长5%（净增3100万）至7.7亿，可能是春节活动拉动，与第三方数据有差异。
  - 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：MAU净增2600万，但DAU净流失100万，MAU扩张更像短暂冲量；近两年生态流量持续下滑，为主业压力埋下隐患。
  - B站：MAU净增1000万，低于去年同期。
  - Roblox：用户指标低于预期，受监管影响。
  - Reddit：美国用户增长慢。
  - 唯品会：活跃用户零增长。
- **适用场景与注意事项**：适用于社交、内容及互联网平台。MAU口径受活动和外部投放影响大，判断时以DAU和时长为主。

### 5.6.4 DAU/MAU增速剪刀差判断“粘性 vs 破圈”，叠加分地区用户与付费力度

- **方法要点**：DAU高增而MAU低增，说明平台破圈吃力，只能专注忠诚用户的粘性与变现；将DAU增速与管理层全年用户增长目标对比；再分地区看用户增长，并比较各地区付费力度（ARPU水平），找出高增长又高付费的潜力市场。
- **操作步骤 / 拆分口径 / 公式**：
  1. 比较DAU与MAU的同比增速（剪刀差）。
  2. 将DAU增速与管理层全年用户增长目标对比。
  3. 拆分地区用户增速，并比较各地区的付费力度（ARPU）。
  4. 识别“高增长 × 高付费”的潜力市场。
- **关键指标与数据来源**：DAU、MAU同比，管理层用户目标，分地区用户增速，地区付费力度。
- **判断标准**：DAU增速（如+21%）高于管理层目标（20%）小幅超预期，但MAU仅+6% ⇒ 粘性强、破圈弱；高增长地区的付费力度接近成熟市场 ⇒ 变现潜力大。
- **海豚案例**：
  - 多邻国（2026-05-05）：DAU+21%，小幅超预期（管理层目标20%），MAU仅+6%；美国增长慢于其他地区，亚洲最快，中国用户付费力度接近法国等西欧水平。
- **适用场景与注意事项**：订阅、社区、工具类互联网产品。地区用户价值差异的进一步分析见5.6.9。

### 5.6.5 用年度平均MAU倒算下半年MAU净增

- **方法要点**：公司只披露年度平均MAU和上半年数据时，用“全年平均×2 − 上半年平均”倒算下半年平均MAU，判断下半年用户是否净增，并归因到新产品形态（小游戏）或新游拉动。
- **操作步骤 / 拆分口径 / 公式**：
  1. 下半年平均MAU ＝ 年度平均MAU × 2 − 上半年平均MAU。
  2. 与上半年平均比较，判断下半年是否净增。
  3. 归因到新产品形态（如小游戏上线）或新游。
  4. 前瞻：看今年新游能否带动用户扩张。
- **关键指标与数据来源**：年度平均MAU、上半年MAU、倒算下半年MAU。
- **判断标准**：倒算下半年MAU显著高于上半年 ⇒ 净增明显，需找到对应的产品触发点；若无明确触发点，应谨慎对待。
- **海豚案例**：
  - 心动公司（2026-03-27）：下半年TapTap国内月活略增；用年度MAU平均值倒算，下半年MAU预计净增明显，可能源于2025年7月TapTap小游戏推出；今年看《心动小镇国际服》和《仙境RO守爱2》能否带动用户扩张。
- **适用场景与注意事项**：适用于只披露年度或半年度平均值的公司。倒算得到的是“平均值”，不等于期末值；累计数倒算的一般方法见4.6。

### 5.6.6 验证补贴/门槛政策效果：DAU增速是否持续高于MAU增速

- **方法要点**：判断免邮门槛下调等补贴政策是否有效：看日活增速是否持续高于月活增速（粘性提升），以及人均购买件数是否高增，以验证“投入换增长”有没有换来回报。
- **操作步骤 / 拆分口径 / 公式**：
  1. 比较DAU与MAU增速，看DAU增速是否持续更高。
  2. 看人均购买件数的同比。
  3. 综合判断：投入（补贴、免邮门槛下调）是否换来需求与粘性。
- **关键指标与数据来源**：DAU增速；MAU增速；人均购买件数。
- **判断标准**：DAU增速持续高于MAU增速、人均购买件数高增 ⇒ 提升配送时效、降低免邮门槛在刺激需求与粘性上有效；反之则投入回报不佳。
- **海豚案例**：
  - MELI（2026-08-06）：巴西下调免邮门槛后，日活增速持续高于月活增速，人均购买件数+19%，说明提升配送时效、降低免邮门槛在刺激需求和用户粘性上效果不错。
- **适用场景与注意事项**：靠补贴换增长的平台。补贴期之后的用户留存见5.6.11；补贴与费用的利润影响见第8章。

### 5.6.7 用户活跃反常的季节性回落作为增长前瞻（加第三方下载量验证）

- **方法要点**：把用户活跃规模当作前瞻指标，关注是否首次出现与历史季节规律不同的回落；用SensorTower等第三方下载数据验证大盘拓圈是否见顶；同时考虑监管（如青少年用户限制）的影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 跟踪DAP/MAP的增速与环比，与历史同季对比，识别首次出现的反季节回落。
  2. 用SensorTower下载量验证：近几季下载的绝对值是否下降，拓圈增速是否趋平。
  3. 考虑监管影响（欧盟等地对青少年用户的限制）。
  4. 结合其他活跃指标（如Instagram时长仍保持10%以上增长）判断综合影响。
  5. 传导到利润：用户增长放缓意味着利润率压力更明显。
- **关键指标与数据来源**：DAP/MAP；历史同季对比；SensorTower下载量。
- **判断标准**：DAP增速放缓且首次出现Q1季节性回落 ⇒ 隐含利润率承压趋势更明显；第三方下载绝对值连续下降 ⇒ 拓圈见顶信号。
- **海豚案例**：
  - Meta（2026-04-30）：DAP增速放缓，且首次出现Q1季节间回落，隐含今年利润率承压的趋势更明显。
  - Meta（2026-07-30）：SensorTower显示近两季用户下载的绝对值下降，FB、Instagram拓圈增速趋平；欧盟等地对青少年用户的监管也可能有影响；公司称Instagram时长仍保持10%以上增长。
- **适用场景与注意事项**：由用户规模驱动的平台。需与时长、变现并读，用户规模下降未必意味着收入下降（取决于ARPU）。

### 5.6.8 DAU分地区环比净增、DAU/WAU粘性，核心地区首次环比下滑作为预警

- **方法要点**：跟踪DAU总量与环比净增、WAU同比与净增、DAU/WAU粘性；分地区重点看贡献主要商业价值的核心地区（如美国），核心地区DAU首次环比下滑视为重大的边际恶化，并与第三方用户流失数据交叉验证。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取DAU总量及环比净增；WAU同比及净增；DAU/WAU粘性。
  2. 分地区拆DAU净增，区分来自美国还是美国以外。
  3. 美国DAU首次环比下滑视为重大边际恶化。
  4. 与第三方用户流失数据交叉验证，并分析外部冲击（如搜索端AI概览对获客的影响）。
- **关键指标与数据来源**：DAU；WAU；DAU/WAU；分地区DAU；第三方用户数据。
- **判断标准**：总量增长主要来自美国以外 ⇒ 增量商业价值偏低；美国DAU首次环比下滑，且与第三方流失数据吻合 ⇒ 确认恶化、触发预警；DAU/WAU粘性下降 ⇒ 用户活跃质量走弱。
- **海豚案例**：
  - Reddit（2026-02-06）：Q4 DAU约1.2亿，环比净增540万，其中80%以上来自美国以外；美国仍是个位数增长。
  - Reddit（2026-05-01）：Q1 DAU 1.27亿，净增540万；WAU +23%、净增2150万；DAU/WAU 25.7%。
  - Reddit（2026-07-31）：Q2 DAU 1.3亿，净增350万；WAU +24%；粘性25.3%；美国DAU首次环比下滑，与第三方数据显示的2、3月用户流失吻合，市场开始担忧Google AI Overview对获客的影响。
- **适用场景与注意事项**：由用户驱动的社交平台。核心地区的界定以商业价值（ARPU）为准，而非用户数；与5.6.9的地区用户价值配合。

### 5.6.9 按地区区分用户价值：增量来自低价值地区时，用户增长不能完全转化为业绩

- **方法要点**：按地区拆MAU净增，区分高ARPU的核心地区（欧美）与低价值地区（亚太、拉美）。增量主要来自低价值地区时，判断为中长期健康、但短期业绩有压力；并用Sensor Tower验证个别国家用户流失的原因。
- **操作步骤 / 拆分口径 / 公式**：
  1. 分地区拆MAU净增。
  2. 按ARPU水平区分核心地区与低价值地区。
  3. 增量主要来自低价值地区 ⇒ 中长期健康但短期业绩压力。
  4. 用Sensor Tower下载与活跃数据验证用户流失原因（如加拿大流媒体税）。
- **关键指标与数据来源**：分地区MAU；Sensor Tower下载与活跃数据。
- **判断标准**：核心地区（北美、欧洲）环比负增长 ⇒ 对业绩的压力更大；增量集中在亚太、拉美 ⇒ 用户规模扩张未必转化为短期收入。
- **海豚案例**：
  - Spotify（2026-02-10）：Q4 MAU净增3800万至7.51亿，主要来自其他地区（以亚洲为主）；北美环比负增长，Sensor Tower显示主要是加拿大用户流失，或与加拿大流媒体税有关。
  - Spotify（2026-04-29）：Q1 MAU 7.61亿、净增1000万，增量来自亚太和拉美，欧洲环比下降。
- **适用场景与注意事项**：全球化的订阅和内容平台。地区ARPU需用披露数据或可比公司估算；订阅内容专属指标见15.9。

### 5.6.10 订阅渗透率的分母效应与环比净增付费用户

- **方法要点**：订阅渗透率上升若伴随MAU下滑，可能只是分母缩小带来的被动提升，转化质量要打折扣；应看订阅人数的半年环比净增来判断边际变现能力；渗透率下滑若伴随ARPPU上升（B端），说明用户扩张快于付费转化，但变现质量尚可。
- **操作步骤 / 拆分口径 / 公式**：
  1. 渗透率 ＝ 订阅人数 ÷ MAU；同时拆分子（订阅人数）与分母（MAU）的变化。
  2. MAU下滑时，渗透率“符合预期”可能只是分母变小的被动提升，要看订阅人数增量的绝对值。
  3. 看订阅人数的半年环比净增，判断边际变现能力。
  4. 渗透率下滑 ＋ ARPPU上升（B端）⇒ 用户扩张快于付费转化，但变现质量尚可。
  5. 联动收入与利润：订阅收入增速、核心经营利润是否由费用控制（三费）支撑。
- **关键指标与数据来源**：订阅人数环比净增、MAU变化、渗透率、ARPPU；订阅收入；销售费用占订阅收入比重。
- **判断标准**：订阅人数净增逐期回落、MAU下滑下渗透率“in-line” ⇒ 转化质量打折；两个场景付费用户增速同步放缓 ⇒ 边际变现减速。
- **海豚案例**：
  - 美图（2026-03-27/28）：MAU较上半年减少400万（生活场景减少500万）；出海MAU增速从15.7%降到6.9%，预期8.7%；订阅人数增量从上半年的280万降到下半年的150万，渗透率符合预期的质量要打折扣（MAU下滑下渗透率in-line是被动提升）；生产力渗透率增速从2%放缓到1.2%；订阅收入+38.8%，略超预期；核心经营利润4.66亿，基本符合预期，靠的是三费控制；销售费用约占订阅收入的16%。
  - 美图（2026-08-26）：环比净增逐期回落，两个场景付费用户增速同步放缓。
- **适用场景与注意事项**：订阅制App、工具型订阅产品。渗透率判断必须配合分母与绝对净增；订阅内容类公司的指标见15.9。

### 5.6.11 月活跃付费用户/月均交易客户数：判断补贴引入用户的私域沉淀率

- **方法要点**：外卖补贴期引入的大量价格敏感型用户能否沉淀到品牌私域，用月均交易客户数的同比与环比走势判断；补贴退潮后增速明显放缓，说明私域转化留存率不高，正在“挤水分”；之后若用户数超过补贴巅峰时期并创新高，说明流失用户已被新开门店和自然增长补回。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取月活跃付费用户（或月均交易客户）的同比与环比。
  2. 补贴期后观察增速是否明显放缓：放缓 ⇒ 私域留存率不高。
  3. 与补贴巅峰时期的用户数对比：超越并创新高 ⇒ 流失用户已被补回。
  4. 结合用户质量（客单更高、利润贡献更好）判断：质量提升可以抵消数量放缓。
- **关键指标与数据来源**：月活跃付费用户/月均交易客户数（同比、环比）、补贴峰值时期用户数。
- **判断标准**：补贴退潮后增速放缓 ⇒ 挤水分；用户数创新高并超过补贴巅峰 ⇒ 走出后遗症；留下的用户质量更高 ⇒ 数量放缓可以被质量抵消。
- **海豚案例**：
  - 瑞幸《瑞幸：外卖大战绑架了咖啡一哥？》（2026-02-26）：Q4月活付费用户9800万，+27%，较Q2、Q3明显放缓，判断外卖用户私域留存率不高。
  - 瑞幸《瑞幸咖啡：增收不增利…》（2026-04-29）：认为正在经历挤水分，价格敏感用户流失但留下的用户质量更高。
  - 瑞幸《瑞幸咖啡：走出外卖后遗症…》（2026-08-03）：月均交易客户1.13亿，+23%，创历史新高，超过3Q25补贴巅峰。
- **适用场景与注意事项**：适用于消费App、会员制零售、餐饮连锁。需要把补贴期的峰值作为参照系；用户质量的利润侧验证见第8章。
