# 第9章 指引解读与隐含推算

> **本章目的**：指引往往比当季业绩更决定股价：把指引与预期对比，倒算隐含值，校准管理层风格，解读措辞，并跟踪兑现度与长期目标。

## 9.1 指引对比预期

> 本节导读：指引（Guidance）往往比当季业绩本身更决定股价，而指引好不好不看绝对数字，只看它与市场预期（卖方一致预期、彭博 BBG、买方真实预期）的差距，以及与上一次指引相比的方向。本节给出把指引与预期逐项比较的全套方法：全口径逐项对比、区间上限/中值/下限的判定规则、中值换算为增速与金额、分业务与分项拆解、利润率指引及一次性因素还原、投入（Opex/Capex）指引、关键运营指标指引，以及本季指引与上季指引的纵向对比。使用顺序是：先在本节把指引定性为 beat / in-line / miss，再到 9.2 倒算隐含值检验节奏与可实现性，到 9.3 判断指引的权重，到 9.4 用管理层历史风格校准保守度；预期基准如何选择见 1.1、1.2，汇率剥离见 4.1。

### 9.1.1 全口径指引逐项对比一致预期，区分短期与中长期

- **方法要点**：不只比较收入指引，而是把公司给出的全部指引项（收入、Capex、调整后经营利润、EPS、EBITDA 利润率、AI 等细分业务）逐项与彭博/市场一致预期对比，并把短期（下季）和中长期（全年）分开定性，避免被单项数字误导。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出本次公司给出的全部指引项：收入、Capex、调整后经营利润、EPS、EBITDA%（或 EBITDA 利润率）、分业务（如 AI 业务）收入。
  2. 每项并排放上彭博/市场一致预期，逐项标记超预期、符合、低于预期，并量化差距（金额或百分点）。
  3. 把下季指引与全年指引分开比较：下季偏弱而全年与预期相当，判定为节奏问题，属于暂时性；全年也低于预期则是趋势问题。
  4. 利润、Capex 指引与收入指引放在一起读：收入、利润、Capex 同向偏低，多半是交付/建设节奏问题；收入高于预期、利润低于预期，则要追问投入加大或结构变化（利润率归因见 9.2）。
- **关键指标与数据来源**：各项指引区间及中值；彭博及卖方一致预期；公司财报新闻稿与电话会披露的指引表。
- **判断标准**：
  - 逐项都高于预期（收入、EPS、利润率、AI 业务同步超出）是全面超预期，典型如戴尔、博通的多个季度。
  - 只有短期项目偏弱、全年项目与预期相当，推理链条是：全年没有变，说明需求与全年总量未被破坏，下季偏慢只是确认节奏后移，因此属于暂时性。
  - 一个细分项（如 AI 业务）低于预期，即便总收入高于预期，也要单独标记，因为市场往往为该项支付溢价。
- **海豚案例**：
  - CoreWeave（2026-02-27）：下季收入指引 19~20 亿（预期 22.4 亿），Capex 60~70 亿（预期 71 亿），调整后经营利润 0~0.4 亿（预期 1.4 亿）；全年 120~130 亿与预期相当，因此下季偏慢判定为暂时性。
  - 戴尔（2026-02-27）：一季度收入指引 347~357 亿（预期 292 亿），EPS 2.55（预期 2）。
  - 戴尔（2026-05-29）：二季度收入指引 440~450 亿（预期 376 亿），EPS 4.5（预期 3）。
  - 博通（2026-03-05）：二季度收入 220 亿（预期 208 亿），EBITDA% 68%（预期 67%），AI 107 亿（预期 97 亿）。
  - 博通（2026-06-04）：三季度收入 294 亿（预期 287 亿），AI 160 亿（预期 170 亿）——收入高于预期但 AI 业务低于预期，属于分项缺口。
  - Marvell（连续三个季度）：下季收入指引 24 亿 vs 预期 22.7 亿；27 亿 vs 26.1 亿；31.5 亿 vs 31 亿。
- **适用场景与注意事项**：通用。指引项越多越要逐项对表，避免只看收入；全年与下季的“节奏 vs 趋势”判断需要配合 9.2 的隐含值倒算验证。

### 9.1.2 指引区间判定规则：上限、中值、下限分别与预期比较

- **方法要点**：公司给区间指引时，用上限、中值、下限分别与预期比较，形成统一的 miss / in-line / beat 判定规则，同时用区间宽窄判断确定性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对每个指引项（收入、利润、EPS 等）分别取上限、中值、下限，与卖方一致预期逐项比较。
  2. 按下面的判定规则定性（见判断标准）。
  3. 用中值算出隐含增速或隐含利润率（换算方法见 9.1.3、9.1.4，隐含利润率见 9.2.8）。
  4. 用区间宽窄（如 ±2%）判断公司对指引的把握：区间越窄确定性越高，区间越宽说明不确定性越大。
- **关键指标与数据来源**：指引上限、中值、下限；一致预期；隐含增速；隐含经营利润率。
- **判断标准**：
  - 连上限都低于预期：明确判为 miss。
  - 各项指标上限贴近或略高于卖方预期：判为 in-line。
  - 中值高于预期：判为 beat。
  - 一致预期贴着指引下限：说明市场预期本身不高，后续有望继续超预期（推理链条：公司保守给出下限附近的预期，而市场已经按下限定价，上行空间留在实际交付里）。
- **海豚案例**：
  - 亚马逊（2026-02-06）：Q1 经营利润指引 165-215 亿，上限仍低于预期约 220 亿，明确 miss；中值对应 OPM 10.8%，同比 -1pct。
  - Oracle（2026-03-11）：4Q 各指标上限基本贴近或略高于卖方，判为 in-line。
  - 戴尔（2026-02-27）：指引 347-357 亿，中值环增 20 亿，预期 318 亿，中值高于预期，判为 beat。
  - Circle（2026-02-25）：其他收入指引 1.5-1.7 亿，一致预期贴近下限，预期不高。
  - 唯品会（2026-02-26）：Q1 收入指引中值 +2.6%，再度转正，稍好于预期。
- **适用场景与注意事项**：普遍适用。注意“用哪个预期”：卖方一致预期与买方真实预期可能不同（见 1.1、1.2）；区间宽度本身有信息，宽区间要结合 9.4 的保守度校准。

### 9.1.3 指引区间中值换算为环比、同比与金额，并比较 EPS 与细分项

- **方法要点**：标准动作是把下季指引区间取中值，换算成同比/环比增速（或还原成金额），与一致预期和本季增速比较；EPS、毛利率指引同理，细分项指引往往比总数更关键。
- **操作步骤 / 拆分口径 / 公式**：
  1. 中值 =（上限 + 下限）/ 2；若公司给的是增速区间，则用上年同期或本季基数换算成金额区间再取中值。
  2. 中值环比 = 指引中值 / 本季实际 − 1；中值同比 = 指引中值 / 去年同期 − 1。
  3. 把中值金额（或增速）与一致预期比较，同时与本季增速比较，判断加速还是放缓。
  4. 同步比较 Non-GAAP EPS 或毛利率指引，与收入指引分开判断。
  5. 拆出细分项指引（如版税增速），检验总量背后的结构。
- **关键指标与数据来源**：指引区间、中值、中值环比和同比、一致预期、细分项指引；EPS 或毛利率指引及其预期。
- **判断标准**：
  - 中值与预期的差距决定指引的性质。
  - 强度细节一：“指引下限就高于预期”是更强的信号（Uber 的 adj.EBITDA 下限就高于预期）。
  - 强度细节二：下限等于预期时，看上限隐含的提速空间。
  - 强度细节三：收入指引和利润（EPS、EBITDA、毛利率）指引分别比较，收入、EPS 双低时可推断毛利率也会下降（高通）。
  - 强度细节四：指引细分项（如版税增速）可能比总数更关键——总指引符合预期而细分项增速仅 low-teens，则判断“并不太好”（ARM）。
  - 区间宽度本身有信息：宽区间说明不确定性大。
- **海豚案例**：
  - Uber《Uber：业绩都在线》（2026-05-07）：下季订单额指引 562.5 亿-578 亿美元，下限与预期一致；adj.EBITDA 指引 27 亿-28 亿，下限就高于预期的 26.5 亿，超预期幅度更大。
  - AMD《CPU“狂飙”》（2026-05-06）：收入指引 109 亿-115 亿，中值 112 亿，环比 +9%，市场预期约 105 亿。
  - ARM《ARM：AI红利未消》（2026-02-05）：营收指引 14.2 亿-15.2 亿，中值环比 +18%，符合预期，但细分来看版税只有 low-teens 增长，并不太好。
  - ARM《ARM：“短期波动”难掩锋芒》（2026-05-07）：中值 12.6 亿，同比 +19.7%，基本符合预期；EPS 指引 0.36-0.44 美元，略好于预期。
  - ARM（2026-07-30）：FY27Q2 收入指引 13.3-14.3 亿，中值 13.8 亿、同比 +21.6%，预期 13.5 亿；EPS 指引 0.43-0.51，预期 0.45。
  - 应用材料 AMAT（2026-02-13）：收入指引 71.5-81.5 亿，中值环比 +9%，预期 71 亿；EPS 指引 2.44-2.84，预期 2.25。
  - 应用材料（2026-05-15）：下季指引 84.5-94.5 亿，中值环比 +13%，对比市场 81.5 亿大幅超出；EPS 3.16-3.56 vs 2.68。
  - 应用材料（2026-08-14）：Q3 指引 97.5-107.5 亿，中值环比 +12.5%，EPS 3.82-4.22 vs 3.71。
  - 中芯国际（2026-05-14）：环比 +14-16%，对应 28.5-29 亿，预期 26.8 亿（环比 +7%）。
  - 中芯国际（2026-08-13）：环比 +2-4%，对应 30.6-31.3 亿，预期 30.7 亿。
  - 中芯国际（2026-02-10）：环比持平，对应 24.9 亿，预期 25 亿（环比 +3%）。
  - 英特尔（2026-04-24）：Q2 指引 138-148 亿，同比 +7%-15%，vs 预期 131 亿。
  - 英特尔（2026-07-24）：Q3 指引 158-168 亿，同比 +15%-23%，vs 预期 155 亿。
  - 高通（2026-02-05）：指引 102-110 亿 vs 预期 112 亿，EPS 2.45-2.65 vs 2.9，判断营收和毛利率可能双降。
  - 美光（2026-03-19）：327.5-342.5 亿，中值环比 +40.4%，vs 预期 268 亿。
- **适用场景与注意事项**：所有给单季指引的公司通用。EPS 指引与收入指引不一致时，用 9.2 的隐含利润率方法还原原因；中值只是展示口径，上限与下限的信号强度不能丢。

### 9.1.4 绝对值指引换算为隐含同比增速，并追踪全年指引与上调

- **方法要点**：把公司给的下季或全年收入绝对值区间换算成隐含同比增速，和当季增速、市场预期及原指引比较，判断是提速还是放缓，并解读驱动与资金是否已有预期；全年指引则与市场增长预期区间比较，并追踪后续上调作为基本面加速的信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含同比增速 = 指引区间 / 去年同期收入 − 1，上下限各算一遍，得到增速区间。
  2. 与当季实际增速比较：区间整体高于当季为提速，低于当季为放缓；与市场预期比较判断是否有预期差。
  3. 解读驱动：错位回补、基数回归正常、宏观压力等，并判断资金对这一变化是否已有预期。
  4. 全年指引：将全年金额换算为隐含全年增速，与原指引比较；若公司事先做过业绩前瞻（preview），判断指引上调是否已被提前打进预期。
  5. 全年指引区间与市场增长预期区间比较：中枢落在预期区间内为基本符合；之后某季上调则视为基本面加速。
  6. 把指引拆到分部和运营指标（如加盟业务增速、开店数），判断是阶段性放缓还是仍保持较快扩张。
  7. 从下季指引中剔除基数反弹和汇率，推断内生增长韧性（汇率剥离方法见 4.1）。
- **关键指标与数据来源**：收入指引区间（单季/全年）、去年同期收入、隐含同比增速；全年指引金额、分部收入指引、开店指引；市场一致预期增速。
- **判断标准**：
  - 变体 A（单季）：隐含增速环比提升且符合预期，为符合；环比放缓但原因是基数回归正常和宏观压力、且资金已有预期，则不构成新的利空。
  - 变体 B（全年上调）：全年指引上调幅度要看隐含增速区间的抬升（5-10% 上调到 8-12%）；若公司已做过 preview，上调已被提前定价，惊喜不足；剔除汇率和基数后仍隐含内生增长韧性，则不改变基本面判断。
  - 变体 C（全年区间 vs 市场区间）：指引中枢落在市场预期区间内为基本符合；后续上调到更高区间（如 20-24% 上调到 24-28%）是加速信号；拆分部和开店数，阶段性放缓但开店指引仍快，则扩张动能未变。
- **海豚案例**：
  - Boss直聘（2026-05-20）：Q2 指引 23.8-24.2 亿，隐含增速 13%-15%，环比提升，符合市场预期。
  - Boss直聘（2026-08-25）：Q3 指引隐含 11%-15%，环比小幅放缓，原因是基数回归正常和宏观压力，资金也已有预期。
  - 新东方（2026-01-28）：FY26 收入指引上调到 53-55 亿美元，隐含增速 8-12%（原 5-10%），下季指引符合预期。
  - 新东方（2026-04-22）：Q4 指引 14.3-14.7 亿美元（+15-18%），全年约 56 亿（+13-14%），惊喜不足，但剔除汇率和基数后仍隐含内生增长韧性。
  - 亚朵《亚朵：零售狂飙…》（2026-03-17）：2026 年收入指引 +20%-24%，市场预期 21%-22%，基本符合。
  - 亚朵《亚朵：酒店回血…》（2026-05-13）：全年收入指引从 +20%-24% 上调至 +24%-28%。
  - 华住《华住：深蹲起跳后…》（2026-03-18）：2026 年收入指引 +2%-6%，其中加盟 +12%-16%，较 2025 年阶段性放缓，但开店指引 2200-2300 家仍较快。
- **适用场景与注意事项**：通用，中概公司常只给收入绝对值区间，尤其适用；给出年度金额指引的公司适用变体 B/C。需注意管理层历史指引风格（保守还是激进，见 9.4），以及汇率与并表因素要先剔除（见 4.1、4.2）。

### 9.1.5 分业务与分项指引逐项对比一致预期

- **方法要点**：把总指引拆到分业务、分项，逐项与一致预期比较：既量化预期差，又识别结构变化（哪一块加速、哪一块放缓），并在全年口径下修时检验是否有其他分项抵消、找出下修的外部原因。
- **操作步骤 / 拆分口径 / 公式**：
  1. 变体 A（小会/分项指引）：收集财报后小范围会议或电话会给出的分业务全年和下季指引（广告增速、其他收入增速、Capex、新业务增速），逐项与市场一致预期对比，量化预期差，并与上年实际增速比较。
  2. 变体 B（分业务拆解与全年下修）：把总指引拆到分业务的增速，识别哪一块在加速、哪一块在放缓；全年某分项下修时，看是否有其他分项上行抵消、全年总增速是否维持，并找出下修的外部原因（如上游涨价）。
  3. 对差距大的项目，即便管理层“惯常保守”也要向下调整预期；指引高于市场的项目是潜在亮点。
- **关键指标与数据来源**：分业务指引（下季和全年，旧值 → 新值）、Capex 指引、一致预期分项、上年实际增速；小会纪要需核实来源与准确性。
- **判断标准**：
  - 指引几乎全面低于预期，会导致股价暴跌；传统业务预期过高、新业务指引高于市场，则可以解释“暴跌中仍有亮点”。
  - 分项下修但总量不变：被其他分项（如授权收入）抵消时，不构成全年增速放缓。
- **海豚案例**：
  - 快手《快手：一场向死而生的暴跌，能换来AI重生吗？》（2026-03-25）：市场对 2026 年的预期比小会指引乐观；传统业务预期增速仅 5%（上年 11.7%）；可灵指引至少翻倍（21 亿以上），高于市场 +85% 的预期。
  - 快手《失望指引致暴跌，250亿美金的快手能“捞”吗？》（2026-03-26）：广告 Q1 指引 8~9%、全年 6~7%，市场还停在 13%；Capex 260 亿，资金原本预期 180 亿，指引几乎全面低于预期，导致暴跌。
  - ARM（2026-07-30）：下季 License 约 +30%，Royalty 回落到 13% 左右；全年 Royalty 增速从 20% 下调到 18%，原因是手机端存储涨价，License 上行抵消，全年增速不放缓。
  - 海力士（2026-07-29）：全年 DRAM bit 出货约 +25%、NAND 约 +18%，资本开支 40-45 万亿韩元，约合 300 亿美元。
- **适用场景与注意事项**：适用于提供分项指引的多业务公司。小会信息的可得性和准确性需要核实；全年分项的倒算与隐含值检验见 9.2.2、9.2.13。

### 9.1.6 指引构成拆解：超预期的本质来源与“唯一缺陷”

- **方法要点**：利润指引超预期时，不停留在“高于预期”，而是拆成“收入（或毛利）× 利润率”，判断超预期来自增长还是利润率；再把收入、毛利润、费用率、现金流利润率逐项对照预期，找出整个指引里唯一的缺陷项，并用排除法归因。
- **操作步骤 / 拆分口径 / 公式**：
  1. 利润指引 = 收入（或毛利润）指引 × 隐含利润率；将隐含利润率与预期隐含利润率比较，若相当则超预期本质来自毛利/收入增长，而非利润率。
  2. 收入指引要先剔除汇率顺风和并表贡献，再比较（不变汇率增速，详见 4.1、4.2）。
  3. 变体 B（逐项对比）：把下季指引拆为收入增速、毛利润增速、费用占收入比重、FCF margin，逐项与卖方预期比较。
  4. 毛利润增速低于收入增速，推出毛利率同比承压；费用率区间低于去年同期，推出费用率同比收窄。
  5. FCF margin 偏弱时，用前两项排除经营原因，归因到营运资金（如资产负债表占款）。
  6. 找出整份指引中唯一低于预期的项目，作为该次指引的“缺陷”，并与股价反应对照。
- **关键指标与数据来源**：指引隐含利润率；汇率与并表贡献；毛利润、费用率、FCF 利润率指引；卖方预期。
- **判断标准**：
  - 隐含利润率与预期相当时，利润超预期来自毛利（收入）增长，质量取决于增长可持续性。
  - 收入指引中含汇率顺风或并表贡献的，要换算不变汇率或内生增速后再判断是否加速。
  - 其余各项均超预期、仅 FCF/现金流利润率一项低于预期时，归因路径是：毛利与费用率已排除经营恶化，缺口只能来自营运资金占款。
- **海豚案例**：
  - Block（2026-02-27）：毛利润指引 28 亿（+22%，比预期高约 3%），调整后经营利润 6 亿 vs 5.75 亿，但隐含经营利润率与预期相当，所以超预期本质来自毛利指引。
  - Shopify（2026-02-11）：Q1 收入增速 30%+ vs 卖方 25%，费用/收入 37-38% vs 38.5%，唯一缺陷是现金流利润率指引 10-15% vs 16.4%。
  - Shopify《业绩不俗却暴跌》（2026-02-12）：收入指引 30% 以上，卖方预期 25%；毛利润 +25-29%，预期 23.4%，隐含毛利率同比承压；费用率 37-38%，预期 38.5%；FCF margin 低于 1Q25 的 15.4%，预期 16.4%，推断是 BS 占款影响。
  - Airbnb（2026-02-13）：收入指引 14-16% 中含 3pct 汇率顺风，不变汇率中值 12%，比本季加速 1pct。
  - Salesforce：cc 指引 10-11% 中并表贡献 4pct，剔除并表后原有业务增速明显更低（并表推算见 9.2.13）。
- **适用场景与注意事项**：普遍适用；尤其适合给出多项指引的公司（如 Shopify 同时给毛利润和费用率指引）。与 9.2.11 的多项指引交叉倒推配合使用。

### 9.1.7 毛利率与 EBITDA 指引对比预期，用收入结构推演偏弱原因

- **方法要点**：当季 beat 但指引 miss 时，把毛利率、Adj.EBITDA 指引与市场预期逐项比较，再用收入结构（低毛利项目进入交付高峰、新项目爬坡、高毛利业务权重下降）推导指引偏弱的原因，判断这是阶段性的结构问题还是长期恶化。
- **操作步骤 / 拆分口径 / 公式**：
  1. 将 GAAP 毛利率指引、Adj.EBITDA 指引及 margin 与市场预期逐项对比，算出差距（百分点或金额）。
  2. 看 EBITDA margin 环比变化（如环比下滑 2-5ppt）。
  3. 用分业务收入结构解释：哪些低毛利项目进入交付高峰？哪些新项目在爬坡？高毛利业务（如发射）权重是否下降？
  4. 判断结构问题是否随项目交付完成而恢复（阶段性），还是产品组合长期恶化。
- **关键指标与数据来源**：GAAP 毛利率指引、Adj.EBITDA 指引及 margin、市场预期；分业务收入占比与项目交付节奏（电话会披露）。
- **判断标准**：毛利率指引远低于预期、且原因是低毛利项目交付高峰和新项目爬坡的时点性权重变化，倾向阶段性；若高毛利业务权重持续下降，则是长期恶化。毛利率指引还可作为新制程良率和提价效果的读数，详见 7.1。
- **海豚案例**：
  - Rocket Lab《中子号或延期》（2026-08-11）：3Q26 毛利率指引 29%-31%，远低于预期 36%；Adj.EBITDA 指引 -0.17 亿至 -0.23 亿美元，低于预期 -0.12 亿，margin 环比下滑 2-5ppt 至 -6% 至 -9%；原因是 SDA 整星项目交付高峰、新签 GEO 卫星和 Flatellite 项目爬坡、发射权重下降。
- **适用场景与注意事项**：通用，尤其适用于项目结构波动大的公司（航天、设备、定制交付）。结构解释依赖电话会披露的项目节奏，口径不足时需要标注为推断。

### 9.1.8 毛利率指引的一次性因素还原（调整后毛利率 vs 买方预期）

- **方法要点**：公司毛利率指引看起来环比下降时，先拆出其中的一次性成本，计算调整后的可比毛利率，再与买方预期比较，避免把一次性扰动误判为趋势反转。
- **操作步骤 / 拆分口径 / 公式**：
  1. 从电话会取得一次性成本金额（库存计提、激励薪酬、启动成本等）。
  2. 调整后毛利率 =（毛利指引 + 一次性成本）/ 收入指引。
  3. 将调整后毛利率与本季毛利率比较环比方向，与买方预期毛利率比较高低。
  4. 结论分两层：趋势有没有反转；边际变化（如涨价速度）有没有放缓。
- **关键指标与数据来源**：毛利率指引；一次性成本金额；调整后毛利率；买方预期毛利率。
- **判断标准**：调整后毛利率仍环比上升，则趋势没有反转；但若略低于买方预期，则意味着边际涨价放缓，要同步下调对盈利弹性的预期。
- **海豚案例**：
  - 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：下季度毛利率指引 86%（本季 86.8%），看上去下滑，但其中包括四季度计提激励薪酬形成的高成本库存、启动成本和其他费用，影响约 10 亿美元；剔除后约 87.6%，仍在环比上升，只是略低于买方预期 88%。结论：趋势没有反转，但边际涨价在放缓。
- **适用场景与注意事项**：适用于有大额一次性成本（库存计提、激励、新厂启动）的制造业公司；需要管理层在电话会披露金额，否则只能估算。

### 9.1.9 投入指引（Opex / Capex / 调整后费用）与买方预期、BBG 一致预期比较

- **方法要点**：Opex、Capex 以区间发布时，与买方预期区间和 BBG 一致预期逐一比较，定性为惊吓、中性还是惊喜；全年调整后成本费用指引则与市场预期的投入规模比较，判断经营效率；同时关注修订原因，以及是否只动了区间下限。
- **操作步骤 / 拆分口径 / 公式**：
  1. 变体 A（投入区间三方比较）：把 Opex、Capex 指引区间与买方预期区间、BBG 一致预期逐一比较，注意买方预期常稍高于 BBG。
  2. 识别修订方式：只上调下限、区间整体上调，还是下调；区分原因（零部件涨价、诉讼费等一次性/外生因素）。
  3. 若市场本来就有涨价增幅的预期，买方可能直接按区间上限定预期，此时下限上调属于预期内。
  4. 变体 B（费用指引判断效率）：本季经营效率没有明显提升时，转看全年费用指引（剔除 SBC 和折旧摊销的成本与经营费用区间及同比增速）与市场预期投入规模比较。
  5. 结合管理层惯性判断后续（如 Meta 往往在收入有压力时才控费）。
- **关键指标与数据来源**：Opex 指引、Capex 指引、买方/卖方预期区间；全年调整后成本与经营费用指引（剔除 SBC、D&A）及同比增速。
- **判断标准**：
  - 指引低于市场预期的投入规模，说明经营效率的提升会在全年体现；后续季度指引维持不变而市场原本预期更高投入，视为优于预期。
  - 费用指引环比持平，说明投入力度不因市场低迷而收缩。
  - 投入指引高于买方预期是“惊吓”；买方预期区间基本覆盖指引是中性；只上调下限而买方已按上限定价则偏中性。
- **海豚案例**：
  - Meta（2026-01-29）：2026 年 Opex 1620-1690 亿（+37%~44%），高于买方 1500-1600 亿（买方稍高于 BBG）；Capex 1150-1350 亿（+59%~87%），买方 1200-1300 亿基本落在区间内。
  - Meta（2026-04-30）：Capex 上调 100 亿至 1250-1450 亿，Opex 未下调。
  - Meta（2026-07-30）：Capex 只把下限上调 50 亿至 1300-1450 亿；市场本来就有约 100 亿的涨价增幅预期，买方直接按上限 1450 亿定预期；Opex 下限因 24 亿诉讼费上调。
  - Circle《Circle：用业绩回击唱衰…》（2026-02-25）：2026 年调整后成本与费用指引 5.7-5.85 亿，+10%，低于市场预期。
  - Circle《Circle：稀烂行情…》（2026-05-11）：指引维持 5.7-5.85 亿，优于市场更高的投入预期（7.25 亿）。
  - Coinbase《烂行情+烂业绩…》（2026-02-13）：Q1 经营费用指引 9.25-9.75 亿，环比持平，说明投入力度不因市场低迷而收缩。
- **适用场景与注意事项**：变体 A 适用于投入规模是关键变量的科技巨头；变体 B 适用于处在投入期、收入难以预测但费用可控的公司。Capex 的口径与 ROI 见第 10 章（10.1、10.2）。

### 9.1.10 关键运营指标指引 vs 按往年同季规律推算的预期

- **方法要点**：资金对下季运营指标（如订阅净增）的预期常按往年同季的增量推算；指引低于这一水平就是不及预期，并由此推出资金的担忧。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取往年同季的运营指标增量（如 Q2 订阅净增），推算资金的隐含预期。
  2. 将公司指引（订阅净增指引）与该隐含预期比较。
  3. 毛利率指引用同样标准：是否配得上“首个完整享受涨价红利的季度”这类事件的期待。
  4. 把指引缺口和费用投入（经营利润指引低于预期的原因）联系起来，解读管理层信心。
- **关键指标与数据来源**：订阅净增指引、毛利率指引、往年同季数据、经营利润指引与费用投入。
- **判断标准**：指引低于往年同季水平，推理链条是“涨价事件之后净增反而更少，可能反映流失担忧”；毛利率指引环比仅小幅提升，不足以体现涨价红利，则可能反映管理层对涨价后订阅稳定增长的信心不足。
- **海豚案例**：
  - Spotify《预期差瑕疵致“暴跌”》（2026-04-29）：Q2 指引订阅净增 600 万，低于资金按往年 Q2 推算的约 700 万；Q2 是首个完整享受北美涨价红利的季度，毛利率指引却只环比 +0.1%，可能反映管理层对涨价后订阅稳定增长的信心不足；经营利润指引低于预期，还因为费用投入更多（“Year of Raising Ambition”）。
- **适用场景与注意事项**：季节性规律明显的订阅公司。往年同季规律要核对是否受涨价、新品或基数影响（季节性校正见 3.4）。

### 9.1.11 本季指引 vs 上季指引：判断管理层所见景气方向

- **方法要点**：除了比较指引与一致预期，还要把本季对下季的指引与上季对本季的指引纵向对比，看收入、GBV、间夜量等是否全面加速，推断管理层看到的行业景气是否仍在走高；并对年度利润率指引的上调幅度做验证或证伪。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取本季对下季的指引（收入、GBV、间夜量等），与上季对本季的指引逐项比较。
  2. 检查是否“全面加速”：各项指引的同比增速都比上季指引更高。
  3. 把指引与卖方一致预期比较，注意预期中是否包含汇率贡献。
  4. 年度利润率指引的上调：验证是否转入改善周期，以及改善幅度。
- **关键指标与数据来源**：下季收入/GBV/间夜量指引、年度利润率指引、卖方一致预期、上季指引。
- **判断标准**：各项指引较上季指引全面加速，推断管理层看到的行业景气仍在走高；年度利润率指引上调是验证利润率转入改善周期，但改善幅度未必大。
- **海豚案例**：
  - Airbnb（2026-08-07）：Q3 营收指引 15-17% vs 市场 12%（含约 3pct 汇率）；GBV 增长约 15%、间夜量 10% 以上 vs 卖方 8%/10%；较上季指引全面加速；26 年利润率指引从 35% 提至 35.5% 或更高。
- **适用场景与注意事项**：适用于提供经营指标指引的平台公司（OTA、住宿、出行）。比较时要先统一汇率口径（见 4.1）。

**相关方法的交叉引用**：毛利率指引作为新制程良率和提价效果的读数，详见 7.1；指引拆解中剔除汇率后的不变汇率中值与本季比较加速/减速，详见 4.1；由利润指引区间推算隐含 OPM、比较指引上限与市场预期，详见 9.2.8。

## 9.2 指引隐含值倒算

> 本节导读：公司给的指引往往只是几个总量数字，真正的信息藏在“没直接说出来的隐含值”里：全年指引减去已实现得到下半年或 Q4，利润指引除以收入指引得到隐含利润率，收入指引除以销量指引得到隐含单价，季度销量指引减去已公布月度得到剩余月份月销。本节是指引解读的核心技巧，用来检验指引的节奏、激进程度与可实现性，并把“高于预期/低于预期”进一步落到“来自增长、利润率还是结构”。使用顺序是：先在 9.1 做指引对预期的定性，再在本节倒算隐含值，之后到 9.3 判断指引权重、到 9.4 校准管理层保守度；汇率剔除见 4.1，并表还原见 4.2，季节性校正见 3.4。

### 9.2.1 隐含增速、隐含利润率与隐含 EPS 增速：基础公式

- **方法要点**：把绝对值指引换算成隐含同比增速、隐含利润率和隐含 EPS 增速，再与本季、去年同期、市场预期比较，并剥离汇率顺风，据此判断“环比放缓 / 继续加速 / 利润率承压”。这是后面所有倒算的基础公式。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含增速 = 指引中值（或上限）÷ 去年同期 − 1；中值看常态，上限看最乐观情形。
  2. 隐含利润率 = 利润指引中值 ÷ 收入指引中值；隐含 EPS 增速 = EPS 指引中值 ÷ 去年同期 EPS − 1。
  3. 剥离汇率顺风，得到不变汇率（cc）增速，再与本季 cc 增速比较是否继续提速（汇率口径见 4.1）。
  4. 变体 A（订单额/指标指引 → 不变汇率增速）：订单额指引换算成不变汇率增速，看是否继续提速。
  5. 变体 B（细分项同比指引 → 环比方向）：用细分项同比指引结合去年同期基数，推出环比方向。
  6. 将隐含增速、利润率与本季、去年同期、市场预期并排，判断是环比放缓、继续加速还是利润率承压。
- **关键指标与数据来源**：收入、利润、EPS 指引上下限与中值，去年同期基数，汇率影响；细分项同比指引与去年同期基数。
- **判断标准**：
  - 隐含增速低于本季增速为放缓，要区分是基数、汇率还是真实降速。
  - 利润率中值低于去年同期，说明利润率承压；高于去年同期且高于预期，说明利润弹性。
  - EPS 中值隐含同比下滑，要结合收入指引判断是毛利率还是费用造成。
  - 细分项指引同比增速若低于上季环比后的基数，意味着环比将下滑（如版税）。
  - 按指引上限仍比本季提速，是“继续小幅提速”的信号（Uber 订单额，上限 22% vs 本季 21%）。
- **海豚案例**：
  - 奈飞《1Q26》（2026-04-17）：Q2 收入不足 126 亿，隐含增速从 16% 降到 13%，其中含 1pct 外汇顺风；全年 507-517 亿对应 12-14%。
  - 亚马逊（2026-04-30）：Q2 指引上限隐含 +19%；利润中值 220 亿对应利润率 11.2%，预期 12.1%。
  - 微软（2026-04-30）：下季利润率中值 44%，低于去年 44.9%。
  - Uber（2026-05-06）：adj.EBITDA 中值对应利润率 4.8%，去年 4.5%。
  - Uber《Uber：业绩都在线》（2026-05-07）：订单额指引隐含不变汇率增速 18%-22%，按上限比本季 21% 继续小幅提速；EBITDA 中值隐含利润率 4.8%，去年同期为 4.5%。
  - Reddit（2026-05-01）：隐含增速从 69% 降到 45%。
  - Salesforce（2026-05-28）：EPS 中值 1.75，隐含同比下滑超 10%。
  - Oracle（2026-06-11）：EPS 中值 1.74，隐含 +18%。
  - ARM《ARM：AI红利未消》（2026-02-05）：下季版税同比约 11%-13%，意味着环比将下滑。
- **适用场景与注意事项**：适用于所有给指引的公司。公式中的分母要与公司指引的口径一致（GAAP/Non-GAAP，收入/毛利/Bookings）；汇率与并表要先剥离（见 4.1、4.2）。

### 9.2.2 全年指引减已实现：倒算隐含下半年 / Q4 的收入、利润与增速

- **方法要点**：公司给出全年指引（或年末年化收入）时，用“全年指引 − 已实现 − 下季指引”倒推剩余季度隐含的收入、利润和 Capex，再算出同比、利润率和环比，判断指引兑现的难度或趋势加速/放缓的程度，并检验季度指引与全年指引是否自洽。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含下半年收入 = 全年指引 − 上半年实际。
  2. 隐含四季度收入 = 全年 − 前三季实际，或 = 全年 − 上半年实际 − 三季度指引。
  3. 算隐含同比增速并与当期增速比较，判断是加速、放缓、前低后高还是失速。
  4. 对利润与 Capex 同样倒推：隐含 Q4 调整后经营利润、隐含利润率；全年 Capex 指引下 Q4 可能回落的幅度。
  5. 变体 A（全年口径与下季口径对照）：把下季指引拆开，发现下季某业务增速已接近全年口径，意味着后续不会大幅提速（如 AMAT 设备业务下季近 30%，而全年指引是“30% 以上”）。
  6. 变体 B（用全年节奏推断行业结构）：下半年收入集中度反推行业资本开支的结构性后置（如 ASML）。
  7. 变体 C（只给全年指引或含并表）：全年指引减已披露季度得到后续增速，对含并表贡献的指引再减去并表增速，得到原有业务隐含增速。
- **关键指标与数据来源**：全年收入/利润/Capex 指引、上半年实际、下季指引、隐含 Q4 值及增速/利润率。
- **判断标准**：
  - 隐含剩余季度需要大幅爬坡，说明指引兑现压力大（CoreWeave 下半年单季近 40 亿）；隐含剩余季度环比与近期相当，则是平滑兑现。
  - 隐含下半年增速远高于当期增速，说明增长集中在下半年（ASML 隐含下半年同比 +45-55%，远高于二季度的 21%），指向后置节奏；季度指引与全年指引需自洽（台积电隐含 Q4 与 Q4 指引一致）。
  - 全年增速口径与下季已达水平几乎相同，后续无法大幅提速，给市场“浇凉水”。
  - 含并表的指引，隐含放缓要结合管理层风格判断是真实放缓还是保守。
  - 推理链条：先得到隐含值，再与本季实际、预期及历史指引惯性比较，判定是保守、失速还是产能/供给瓶颈。
- **海豚案例**：
  - CoreWeave（2026-05-08）：全年营收指引 120~130 亿，上半年不到 47 亿，意味着下半年单季要爬到近 40 亿，压力不小。
  - CoreWeave（2026-08-12）：上调全年指引后，隐含 Q4 营收 43~49 亿，中值同比 +194%；Q4 调整后经营利润 6.1~7.4 亿，隐含利润率 14.6%；Q3 Capex 指引 115~135 亿，按全年指引 Q4 可能回落到 100 亿以下。
  - Marvell（2026-08-28）：Q3 指引 31.5 亿 + 全年 120 亿，倒推 Q4 约 37 亿，两个季度环比都在 15~20%。
  - ASML（2026-07-15）：全年指引 430-450 亿欧（原 360-400 亿），同比 +31-37%，隐含下半年同比 +45-55%，远高于二季度的 21%；结合三季度指引 110-120 亿，隐含四季度约 140-150 亿欧。
  - 台积电（2026-10-15）：全年增速 44%，隐含四季度收入约 530-535 亿美元、同比 +55% 以上，与四季度指引 523-543 亿一致。
  - 应用材料《Capex 狂飙在路上…》（2026-05-15）：下季设备增速近 30%，与全年 30% 以上的口径对照，后续增长不会大幅提速，给市场浇了盆凉水（财年错位还要做日历调整，见 9.2.26）。
  - 阿斯麦《阿斯麦 ASML：有 AI 高烧在，光刻机只是假摔？》（2026-04-15）：全年 360-400 亿，上半年单季不到 90 亿，倒算下半年收入 180-220 亿，增长集中在下半年，并由此推断晶圆厂 Capex 在结构上也集中于下半年。
  - Palantir《软件末日论汹涌》（2026-05-05）：Q2 指引 +79%、全年超 76 亿（+71%），隐含增速放缓。
  - Palantir《瑕疵修复》（2026-08-04）：全年指引超 81 亿（+82%），下半年放缓；美国商业 120%+ 指引未上调，意味着下半年需放缓至 68%。
  - Salesforce《“AI替代论”证伪？》（2026-08-27）：按全年指引倒推，Q4 营收增速跌回 11% 以下。
  - 汇总性复盘：戴尔（2026-09-02）全年加下季度推出 Q4 约 500-540 亿（详见 9.2.3）；台积电全年 Capex 推出 Q4 193-234 亿（详见 9.2.5）；Palantir（2026-08-04）美国商业全年 120%+ 隐含下半年 68%。
- **适用场景与注意事项**：适合给年度指引的公司。注意区分口径：年化收入（run-rate）与全年累计不是一回事；全年指引若是自然年口径而财年不同，需先做日历调整（见 9.2.26）；含并表的指引要先还原内生（见 9.2.13）；管理层可能故意保守，需要结合 9.4 的历史 beat 惯性。

### 9.2.3 隐含 Q4 与新指引 / 旧指引 / 市场预期三方对比，判断指引保守度

- **方法要点**：公司同时给出下季指引和全年指引时，倒算隐含第四季收入及其相对 Q3 指引的环比增量，把该增量与已知产品周期强度对照，判断指引是否保守，并通过“新全年指引 / 上季全年指引 / 市场此前预期”三方对比量化指引高出市场多少。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含第四季收入 = 全年指引 − 已披露各季实际 − 下季指引。
  2. 隐含 Q4 环比增量 = 隐含 Q4 − 下季（Q3）指引。
  3. 将该增量与已知的产品周期强度对照（如新品 Rubin 在 Q4 真正放量）：隐含环增明显偏低，则判定指引保守，并给出上修预判。
  4. 三方对比：新全年指引、上季给的全年指引（算出上调金额）、市场此前已上调的预期区间，量化指引比市场高出多少。
  5. 下季收入与 EPS 指引逐项对比市场预期。
- **关键指标与数据来源**：下季收入/EPS 指引、全年收入指引区间及上调幅度、隐含 Q4 收入、隐含 Q4 环比增量、市场预期区间。
- **判断标准**：隐含 Q4 环增仅 10-50 亿，而新品周期正值放量，推理链条是“产品周期越强、隐含增量应越高；隐含增量反而很低，说明管理层把容错空间留在了指引里”，因此判定保守，预期后续上修。
- **海豚案例**：
  - 戴尔（2026-09-02）：下季收入指引 490 亿（预期 440 亿），GAAP EPS 6 美元（预期 4 美元）；全年 1900-1940 亿（上季 1650-1690 亿，上调约 250 亿；市场此前预期 1700-1800 亿），隐含 Q4 为 500-540 亿、环增仅 10-50 亿，判定“在 Rubin 开始放量的情况下明显保守”，后续很可能再上调至 1950 亿以上。
- **适用场景与注意事项**：适用于同时给季度和年度指引的公司（美股硬件、软件常见）。要结合季节性和供应约束；管理层风格（一贯保守还是激进）需参考历史 beat 幅度（9.4）。

### 9.2.4 全年指引减上半年实际：隐含下半年、基数效应与实现难度

- **方法要点**：公司给全年指引（利润增速、出货量、销量）时，用“全年指引 − H1 实际 = H2 隐含值”，对比去年 H2 算出隐含同比，与 H1 增速比较，判断指引是否后置（back-end loaded）、实现难度多大，以及下半年基数（如去年 H2 因关税偏低）是否降低了难度。
- **操作步骤 / 拆分口径 / 公式**：
  1. H2 隐含值 = 全年指引 − H1 实际。
  2. 隐含同比 = H2 隐含值 / 去年 H2 实际 − 1。
  3. 与 H1 同比增速比较：H2 隐含增速远高于 H1，说明放量压力后置。
  4. 检查去年 H2 的基数是否异常（关税、事件扰动），低基数会降低实现难度。
  5. 将缺口归因到具体新产品（如全靠 R2）。
- **关键指标与数据来源**：全年指引、H1 实际、去年 H2 实际、H2 隐含增速。
- **判断标准**：H2 需要的增速显著高于 H1，且基数并非特别低，则指引实现压力大；若基数低、新品放量节奏明确，则难度可控。
- **海豚案例**：
  - 三花（2026-08-27）：全年利润 +15% 指引，H1 归母只有 20.4 亿，H2 需要约 26.3 亿以上，同比 +35%（2025H2 制冷受美国关税影响，基数较低）。
  - 地平线（2026-09-01）：全年出货 500 万，H1 为 221.8 万，隐含 H2 约 278 万（+37%），H1 只有 +12%，说明放量压力后置。
  - Rivian（2026-05-01）：全年 6.2-6.7 万，Q2 指引 0.9-1.1 万，隐含 H2 需交付 4.2-4.7 万，比去年 H2 多 2-2.5 万，基本全靠 R2。
- **适用场景与注意事项**：通用。要注意季节性和基数（见 3.3、3.4）。

### 9.2.5 年度目标倒推剩余季度节奏：Capex、收入、开店与销量

- **方法要点**：用全年的 Capex、收入、开店、销量目标减去已实现值，得出后续季度平均水平，判断是否前低后高、对下半年爬坡要求是否过高，以及与供应链指引是否吻合。
- **操作步骤 / 拆分口径 / 公式**：
  1. 剩余季度均值 =（全年目标 − 已实现）÷ 剩余季度数。
  2. 把剩余季度均值与已实现季度均值比较，判断是否前低后高。
  3. 与上下游（如设备商指引）交叉验证：设备厂说下半年集中，晶圆厂 Capex 也应集中于下半年。
  4. 与实际对比：倒推值若低于最终实际，说明管理层或市场低估了本季投入。
- **关键指标与数据来源**：全年 Capex、收入、开店、销量目标，已实现值。
- **判断标准**：后三季需要的单季水平显著高于已实现水平，意味着爬坡要求高或前低后高；若与供应链指引吻合，则增强可信度。Capex 密集行业尤其重要。
- **海豚案例**：
  - 台积电《1Q26》（2026-04-16）：全年 Capex 520-560 亿减 Q1 的 111 亿，后三季为 409-449 亿，下半年单季 130-150 亿，与 ASML “前低后高”吻合。
  - 台积电《26Q2》：Capex 上调至 600-640 亿，下半年 332-372 亿，同比 +56~75%。
  - 台积电：全年 Capex 推出 Q4 193-234 亿（汇总性复盘）。
  - 中国移动（2026-04-20）：全年 1366 亿减 Q1 的 304 亿，后三季约 1064 亿。
  - 微软（2026-04-30）：全年 1900 亿，后三季单季 > 500 亿。
  - CoreWeave（2026-05-08）：全年 120-130 亿，上半年不到 47 亿。
  - Oracle（2026-06-11）：按全年 500 亿倒推本季约 110 亿，实际 165 亿。
  - ASML：倒推 Q4 约 140-150 亿欧元。
  - 名创：开店仅完成全年目标的 15%。
- **适用场景与注意事项**：适用于有年度指引的公司，Capex 密集行业尤其重要；Capex 口径见 10.1。

### 9.2.6 年度与多年指引：隐含节奏、长期目标换算与降权

- **方法要点**：公司给了全年指引后，单季指引的重要性下降，用全年指引减去已知季度倒推下半年的节奏；长期指引上调说明执行进度可能快于预期；把出货量的长期展望换算成收入规模；偏定性的多年 CAGR 目标在市场波动大时可以暂且忽略（权重判断见 9.3，长期目标本身见 9.7）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 有全年指引时，以全年指引减已知季度倒推下半年节奏，单季指引降权。
  2. 长期（多年）指引的上调幅度，作为执行进度的读数。
  3. 把出货量的长期展望 × 单价换算成收入规模，检验是否已被市场消化。
  4. 偏定性的多年 CAGR 目标降权，不作为当期定价依据。
- **关键指标与数据来源**：全年或多年收入指引；隐含下半年收入；隐含增速；长期出货量展望。
- **判断标准**：
  - 全年指引已上调、下半年集中兑现时，下季指引“并不重要”（ASML）。
  - 长期指引（财年收入）上调，说明执行进度快于预期。
  - 长期出货量展望换算成收入规模后，市场已按此定价，则不再担心下一财年（英伟达）。
  - 定性的多年 CAGR 目标没有可验证的路径，市场波动大时可忽略。
- **海豚案例**：
  - ASML（2026-04-15）：全年指引上调至 360-400 亿欧元（+10-22%），上半年单季不到 90 亿，倒推下半年 180-220 亿，意味着晶圆厂 Capex 集中在下半年，下季指引“并不重要”。
  - Oracle（2026-03-11）：FY27 收入指引从 850 亿上调到 900 亿，隐含增速约 34%。
  - 台积电（2026-01-15）：2026 年收入 +30%，即 2024-2026 连续三年 30% 以上。
  - 英伟达（2026-02-26）：Blackwell + Rubin 到 2026 年底累计 2000 万颗，约对应 5000 亿美元收入，市场不担心 FY27。
  - Marvell（2026-03-06）：FY27 110 亿（原 100 亿，+34%），FY28 150 亿（+40%）。
  - Circle：USDC 多年 CAGR 40% 的目标可以暂且忽略。
- **适用场景与注意事项**：给年度或多年指引的公司（半导体、软件，以及部分中概股）。多年目标要核对口径（增速是 CAGR 还是年度），避免与全年指引混用。

### 9.2.7 全年目标倒算剩余季度隐含环比：“至少翻倍”类目标的成长性检验

- **方法要点**：用公司的全年目标（如“至少翻倍”）减去已知或已指引的季度值，倒算剩余季度的平均水平和隐含环比增速；若隐含环比只是持平或个位数，说明管理层预期增长会放缓，不符合“高成长”特征，估值倍数应打折。
- **操作步骤 / 拆分口径 / 公式**：
  1. 全年目标金额 = 上年 × 倍数（如翻倍）；剩余季度合计 = 全年目标 − Q1 实际（或已指引季度）。
  2. 剩余季度平均值与隐含环比增速：与已实现环比比较。
  3. 隐含环比持平或个位数，则判断管理层预期放缓，思考原因（如竞争）。
  4. 后续跟踪实际季度值和单季指引是否超出这条隐含路径。
- **关键指标与数据来源**：全年收入指引、Q1 实际或指引、剩余季度隐含平均值和环比、单季指引。
- **判断标准**：隐含后续季度环比只是持平或个位数增长，达不到大模型“高成长”特征，估值溢价要打折；实际季度值高于隐含路径则是超预期。
- **海豚案例**：
  - 快手《失望指引致暴跌，250亿美金的快手能“捞”吗？》（2026-03-26）：可灵全年指引至少翻倍（约 21 亿以上），Q1 就有 5 亿，隐含后续季度环比只是持平或个位数增长，达不到大模型“高成长”特征，估值溢价要打折，推测是管理层考虑了 Seedance 的竞争。
  - 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：2Q 可灵收入超 8.5 亿，环比 +30%，略高于 Q1 财报后给的约 8.4 亿指引。
- **适用场景与注意事项**：适用于给出全年指引且季度可见度高的公司。管理层可能故意保守，需结合历史上的 beat 惯性判断（9.4）。

### 9.2.8 隐含利润率：利润指引 ÷ 收入指引，对比本季、去年同期与预期，识别拐点

- **方法要点**：把利润指引（调整后经营利润、EBITDA、经营利润等）除以收入指引，得到隐含利润率，再与本季实际、去年同期、市场预期比较，判断利润率趋势与拐点；同时测算指引上限情形，给出“还要看实际交付”的弹性判断。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含利润率 = 利润指引中值 ÷ 收入指引中值；隐含利润增速 = 利润指引中值 ÷ 去年同期 − 1。
  2. 与本季实际、去年同期、市场预期隐含利润率三者比较，得到同比、环比方向与预期差。
  3. 上限测试（变体 B）：按指引上限测算利润率是否与市场一致；“即便按上限交付也低于市场预期”是明确负面信号，暗示 Capex 拖累盈利。
  4. 拐点识别（变体 C）：判断是否为某年以来首次环比不增长；全年隐含利润率高于上半年时，推断下半年利润率显著改善。
  5. 隐含利润增速（变体 D）：比较利润隐含同比增速与收入/订单额增速，判断是否继续跑赢。
  6. 识别季节性/事件迁移（变体 E）：如大促日期提前到上一季，会同时改变收入与利润指引的同比口径。
  7. 收入中值隐含同比增速与本季比较，判断收入势头。
- **关键指标与数据来源**：收入指引区间、OP/EBITDA 指引区间、隐含利润率、隐含增速、市场预期、去年同期利润率。
- **判断标准**：
  - 隐含利润率高于本季和预期：利润率改善；低于市场：利润率承压；与去年同期相当：同比持平。
  - 利润额略低于预期、但利润率继续走高：属于规模效应下的“质量不差”（CoreWeave 2026-08-12）。
  - 利润率环比首次不增长：拐点信号（Uber 2026-02-05，21 年以来首次）。
  - 上限仍低于预期：明确负面（亚马逊 2026-02-06）。
- **海豚案例**：
  - CoreWeave（2026-02-27）：26 年调整后经营利润指引 9~11 亿，收入指引 120~130 亿，隐含利润率 7.5%~8.5%，意味着下半年利润率明显改善；下季利润指引 0~0.4 亿，低于预期 1.4 亿。
  - CoreWeave（2026-05-08）：下季 0.3~0.9 亿，隐含利润率 2.4%，比本季有提升但绝对值太低。
  - CoreWeave（2026-08-12）：下季 2.3 亿 / 35.3 亿，隐含 6.5%，利润额略低于预期 2.6 亿，但利润率继续走高。
  - 亚马逊（2026-04-30）：下季经营利润指引中值 220 亿，隐含利润率 11.2% vs 市场 12.1%，与去年同期相当；按上限 240 亿则与市场预期相当。
  - Uber（2026-02-05）：1Q adj.EBITDA 指引中值隐含利润率 4.59%，与本季持平、低于市场 4.77%，将是 21 年以来首次集团利润率环比不增长。
  - Uber（2026-08-06）：下季 adj.EBITDA 指引 28.6-29.6 亿，隐含同比 +29%，高于市场的不到 28%，继续跑赢订单额增速，利润率仍稳步走高。
  - Uber《Uber：业绩都在线》（2026-05-07）：EBITDA 中值隐含利润率 4.8%，去年同期为 4.5%。
  - 亚马逊（2026-02-06）：下季 OP 指引 165-215 亿，上限也低于市场约 220 亿；中值隐含 OPM 10.8%，同比降 1pct；收入中值隐含 13.1%，与本季相当。
  - 亚马逊（2026-07-31）：Q3 收入指引同比最多 12%（Prime Day 提前到 Q2），OP 指引 225-265 亿未超预期，按此云业务加速弹性不大。
- **适用场景与注意事项**：会给利润指引的公司；尤其适合利润率处在拐点的公司；给出季度区间指引的美股公司。分母口径要与利润口径一致（收入 / GBV / Bookings），避免把大促日期迁移误当成趋势。

### 9.2.9 全年指引倒推下半年的利润率、毛利率与出货量，及全年隐含利润率与费用收缩空间

- **方法要点**：用全年指引减上半年实际，得到下半年隐含的收入、出货量、毛利率与 OPM，判断指引是否保守、下半年是否继续环比改善；并用全年利润指引除以全年收入（或 Bookings）指引，得到隐含全年利润率，与当季实际比较，推断后续必须压缩的费用空间。
- **操作步骤 / 拆分口径 / 公式**：
  1. 变体 A（下半年隐含）：全年收入指引 − 上半年实际 → 下半年收入；结合 ASP 假设换算出货量 → 环比增速；全年毛利率指引 → 倒推下半年毛利率并与本季比较；全年 OP 指引 → 下半年 OP 及 OPM。
  2. 把本次指引对应的出货量与上季指引对应值比较，量化上调幅度。
  3. 变体 B（全年隐含利润率）：隐含全年利润率 = 全年利润指引 ÷ 全年 Bookings（或收入）指引，与当季实际（剔除一次性合规费用后）比较。
  4. 若隐含利润率显著高于当前水平，后续季度必须进一步压缩除核心分成外的经营费用（销售、管理、基建安全等），据此判断指引可实现性和费用纪律。
  5. 需确认分母口径一致。
- **关键指标与数据来源**：全年收入/GM/OP 指引、上半年实际、ASP 假设、H2 出货量、H2 GM、H2 OPM；全年利润指引、Bookings 指引、当季调整后利润率。
- **判断标准**：
  - 隐含下半年出货量环比继续增长，且较上季指引对应值上调，是继续上调的信号。
  - 隐含下半年毛利率与 OPM 与本季相比，判断是否继续改善：略高于本季是温和改善，不高于本季则是“不再改善”。
  - 隐含全年利润率远高于当季实际，说明公司必须继续大幅压缩费用，推断费用纪律较强但执行难度大。
- **海豚案例**：
  - Bloom Energy《Bloom Energy: 无惧延期疑虑，吃透 AI 缺电红利？》（2026-07-29）：全年收入指引上调至 39-42 亿（+93%-108%）→ SOFC 出货约 1.14-1.25GW，下半年 606-716MW，环比 +14%-34%，较上季指引对应 0.9-1GW 继续上调；全年 non-GAAP GM 34% → 隐含 H2 约 34.8%（本季 34.3%）；non-GAAP OP 上调至 8-9 亿 → H2 4.3-5.3 亿，OPM 20.7%-22.3%（本季 22.5%）。
  - Bloom（汇总性复盘）：下半年经营利润率 20.7%-22.3%。
  - Roblox（2026-05-01）：公司指引 2026 年 Covenant Adj. EBITDA 为 28.8-30.1 亿，相对 Bookings 的利润率为 40%，高于 Q1 剔除合规费用后的 22%，隐含公司将继续收缩开发者分成之外的经营费用。
  - CoreWeave（2026-02-27）：全年隐含利润率 7.5%~8.5%，下半年利润率明显改善（详见 9.2.8）。
- **适用场景与注意事项**：变体 A 适用于给出全年指引的公司，尤其成长期硬件/设备公司；变体 B 适用于给出利润和收入双指引的公司。成长期公司的全年指引常被上调，要与 9.4 的上调惯性并读。

### 9.2.10 毛利润与经营利润指引交叉：拆解超预期来源及上下半年利润率

- **方法要点**：由毛利润和经营利润指引倒算隐含利润率，并拆解超预期来自毛利增长还是费用节省；全年指引同样倒算全年利润率，并用全年减去上半年推算下半年利润率走势。
- **操作步骤 / 拆分口径 / 公式**：
  1. 下季毛利润指引与预期比较（高约 x%）。
  2. 下季调整后经营利润指引与预期比较。
  3. 两者相除得隐含利润率，与预期隐含利润率比较：相当则超预期来自毛利增长；高于预期则来自费用节省。
  4. 毛利率提升不大而利润释放明显时，推测主要来自费用减少（如裁员后）。
  5. 全年指引同样倒算全年利润率，并用全年减去上半年推算下半年利润率走势。
  6. 看全年指引相比此前指引及市场预期上调了哪一项。
- **关键指标与数据来源**：下季/全年毛利润指引、调整后经营利润指引、隐含利润率、市场预期、上下半年利润率。
- **判断标准**：隐含利润率与预期相当，超预期归因毛利增长；隐含利润率低于上季而毛利率提升有限，利润释放主要来自费用减少；全年隐含利润率高于上半年，说明下半年利润率更高，要看费用节省是否可持续。
- **海豚案例**：
  - Block《Block：美版支付宝暴力裁员40%!…》（2026-02-27）：下季毛利润指引 28 亿，+22%，比预期高约 3%；调整后经营利润指引 6 亿，高于预期 5.75 亿；隐含利润率与预期相当，超预期来自毛利增长。全年毛利润 122 亿（+18%），调整后经营利润 32 亿（原约 27 亿），利润率 26%，高于本季 20.5%。
  - Block《美版支付宝Block：增长靠信贷…》（2026-05-08）：下季毛利润 30.4 亿，预期 30 亿；调整后经营利润 7.4 亿，预期 7.2 亿；隐含利润率近 24%，低于本季 25%，毛利率提升不大，推测利润释放主要来自裁员后费用减少。全年毛利润增速从 18% 上调至 19%（123 亿），调整后经营利润从 32 亿上调至 33.4 亿，隐含 27%，意味着下半年利润率高于上半年约 25%。
- **适用场景与注意事项**：适用于同时给出收入/毛利与利润指引的公司；毛利润口径与收入口径不同，倒算时要使用相同分母。

### 9.2.11 毛利润增速与费用率、FCF 利润率指引交叉倒推毛利率与利润率方向

- **方法要点**：公司同时给出收入、毛利润增速、费用占收入比、FCF 利润率等多项指引时做交叉计算：用毛利润增速与收入增速之差推毛利率方向，用费用率推费用杠杆，合起来判断下季是否仍处于“营收高增 + 利润率上升”的双击。
- **操作步骤 / 拆分口径 / 公式**：
  1. 毛利润增速指引低于收入增速，说明下季毛利率继续承压；再判断原因是否与本季相同、只是更严重。
  2. 费用率指引低于去年同期，说明费用杠杆能抵消毛利率压力。
  3. 合起来判断下季是否仍处于“营收高增 + 利润率上升”的双击。
  4. 每项都与市场预期对比（营收增速、毛利润增速、费用率、FCF 利润率）。
  5. 结合管理层指引的惯常保守程度判断。
- **关键指标与数据来源**：营收增速指引、毛利润增速指引、费用/收入指引、FCF 利润率指引、对应市场预期。
- **判断标准**：毛利润增速由本季 30% 降到中高 20%，隐含毛利率压力更大；费用率同比大幅收窄，则利润率仍可能提升；FCF 利润率指引与卖方预期比较，判断现金转化。
- **海豚案例**：
  - Shopify（2026-08-06）：Q3 营收指引增速为低 30% 以上，市场预期不到 27%；毛利润指引增速为中高 20%，低于本季 30%，隐含毛利率压力更大；费用占收入 33%-34%，去年同期约 37%；FCF 利润率指引 16%-20% 以上，卖方预期 18%。
- **适用场景与注意事项**：指引项目较多的美股公司；需结合管理层指引的惯常保守程度（9.4）。与 9.1.6 的“唯一缺陷”拆解配合使用。

### 9.2.12 美股大盘公司多项指引逐项倒算：cc 增速、利润增速、利润率、费用与成本增速

- **方法要点**：对给出多项季度指引的大盘股，从指引上限/中值出发，逐步倒算 cc 增速、隐含利润增速、隐含利润率、费用与成本增速，并识别成本中的一次性项，综合判断指引强弱。
- **操作步骤 / 拆分口径 / 公式**：
  1. 营收指引上限 → 同比增速 → 减去汇率顺风 → cc 增速，与本季比较（汇率剥离见 4.1）。
  2. 核心业务的 cc 指引与头部卖方预期比较。
  3. 经营利润指引上限/中值 → 隐含同比增速与隐含经营利润率的同比变化。
  4. 经营费用与成本的指引增速，与过去 N 季比较：费用增速从个位数拉升到 10%-11%，说明控费挤利润的空间在收窄。
  5. 识别成本中的一次性项（裁员费用）。
  6. Capex 指引只给方向未给幅度时，自行估计绝对水平。
- **关键指标与数据来源**：指引上限/中值、汇率贡献、隐含增速、隐含利润率、费用/成本增速、历史 N 季费用增速。
- **判断标准**：cc 增速较本季再降速，说明收入动能减弱；利润指引上限低于市场预期（388 亿 vs 393 亿）则利润偏弱；费用增速由个位数抬升至 10%+，利润率被挤压；中值利润率同比下降。
- **海豚案例**：
  - 微软（2026-01-29）：营收上限 +17%，汇率顺风 3pct，cc 14%，再降速 1pct；Azure cc 37%-38%，头部行预期 38%；经营利润上限约 370 亿，隐含 +16%；经营费用 +10%-11%，此前 5 个季度均为个位数；Capex 环比下滑，估计仍在 300 亿以上。
  - 微软（2026-05-01）：营收 +13%-15%，汇率 1pct；Azure cc 39%-40%；经营利润上限 388 亿，市场预期 393 亿，隐含 +13%；中值隐含经营利润率 44%，同比 -0.9pct；成本 +22%-23%（含约 1.2pct 裁员费用）。
- **适用场景与注意事项**：给出多项季度指引的美股大盘公司。成本增速的一次性项要拆出，避免把裁员费用当成长期成本上升。

### 9.2.13 分部减法：由总指引倒推核心分部增速、内生增速与增量

- **方法要点**：公司只给总量指引时，用总指引减去其他分部的合理假设，倒推核心分部的隐含增速；或从总指引拆出某业务线，判断后续能否提速；或剔除并表贡献，得出原有业务增速；或把总收入环比增量归到核心分部，判断新品出货期的增量是否够亮眼。
- **操作步骤 / 拆分口径 / 公式**：
  1. 以指引上限（或中值）为基础，给成熟分部一个合理增速假设，并考虑大促挪期等日历效应。
  2. 核心分部隐含增速 =（总指引 − 成熟分部假设）÷ 核心分部基数 − 1，判断它是否继续提速。
  3. 并表还原：内生增速 = 总指引 cc 增速 − 并表贡献。
  4. 增量归因：假设其他业务平稳，把总收入环比增量归到核心分部，与本季增量比较。
  5. 拆分下季指引的口径，与全年口径对照，判断后续能否提速。
- **关键指标与数据来源**：总收入指引、分部收入占比、分部历史增速与假设、并表贡献、本季分部增量。
- **判断标准**：
  - 核心分部隐含增速高于本季，说明继续提速。
  - 并表贡献占指引增速大头，内生增速明显更低，指向后续减速。
  - 新品出货期的分部环比增量不高于本季，则“不太亮眼”。
- **海豚案例**：
  - 亚马逊（2026-04-30）：Q2 指引营收同比 +16%~19%；假设零售板块整体 +15-16%，按指引上限隐含 AWS 下季增速约 30-35%，继续提速，符合投行更新后的预期。
  - 应用材料（2026-05-15）：拆分下季指引，设备增速已接近 30%，全年“30% 以上”意味着后续难大幅提速，浇了盆凉水。
  - Salesforce《既没增长也没利润》（2026-05-28）：下季营收指引恒定汇率 +10%，其中并表贡献超 4pct，原有业务不足 6%；全年隐含 10-11%，后续减速。
  - AMD《AMD：狂抢“AI大单”》（2026-08-05）：Q3 收入指引 127 亿-133 亿，环比 +10%-15%；其他业务平稳的假设下，数据中心环比增量约 12 亿-18 亿（本季约 10 亿），在 MI455X 开始出货的背景下“不太亮眼”。
- **适用场景与注意事项**：只给总指引的多分部公司；需要对非核心分部有可靠假设；并表还原要以管理层披露的并表贡献为准（见 4.2）。

### 9.2.14 剔除季节性业务与一次性收入，推算细分业务下季收入

- **方法要点**：先用收入指引中值算环比，再对非核心业务的季节性变化做假设（客户端、游戏、嵌入式通常一季度季节性下滑），倒推核心业务（AI GPU）下季收入，并剔除指引中包含的一次性项，判断新产品的真实增量；再对照管理层解释（订单延后），判断是暂时性还是产品力问题。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取收入指引区间中值，算环比。
  2. 对季节性明显的分部假设下滑幅度（客户端、游戏、嵌入式在一季度通常季节性下滑）。
  3. 倒推核心业务下季收入 = 总指引中值 − 其他分部假设。
  4. 剔除指引中包含的一次性项（如约 1 亿 MI308）。
  5. 对照管理层解释，判断暂时性（客户准备不足、订单后移）还是产品力问题。
- **关键指标与数据来源**：指引区间及中值、环比、季节性假设、一次性收入、管理层订单交付说明。
- **判断标准**：剔除一次性项后核心业务环比增量很小，说明新品增量不足；若管理层给出明确的订单后移与交付时点（约 15 亿订单将在二季度交付），则偏向暂时性。
- **海豚案例**：
  - AMD（2026-02-04）：一季度收入指引 95~101 亿，中值 98 亿，环比 -4.5%（市场预期约 97 亿），其中含约 1 亿 MI308；考虑客户端、游戏、嵌入式的季节性下滑，推测 AI GPU 约 22 亿，剔除 MI308 后其余部分环比只增约 1 亿。管理层解释是客户准备不足，约 15 亿订单将在二季度交付。
- **适用场景与注意事项**：适合有多个季节性明显分部的公司。季节性假设是估计值，需标注为推断并留出误差。

### 9.2.15 总指引与管理层分部口径联立：倒算下季分部收入及隐含同比

- **方法要点**：在总收入和 EPS 指引之外，抓取管理层给的分部口径（如手机业务约 49 亿），自己算出隐含同比降幅，判断下滑是否扩大；结合季节性解释，并对增长分部给出管理层预期增速和收入占比，评估它对总量的对冲能力。
- **操作步骤 / 拆分口径 / 公式**：
  1. 在电话会中抓取管理层给的分部收入口径（金额或增速）。
  2. 隐含分部同比 = 分部指引金额 ÷ 去年同期分部收入 − 1，与上季同比比较，判断下滑是否扩大。
  3. 结合季节性解释（下半年旺季、苹果产品收入下滑抵消安卓环比增长等）。
  4. 增长分部（如汽车）：给出管理层预期增速和占总收入比重（1-2 成），评估对总量的对冲能力。
  5. 与 EPS 指引共同判断收入和毛利率方向。
- **关键指标与数据来源**：分部收入指引、隐含同比、分部占比、EPS 指引与预期。
- **判断标准**：主业分部同比降幅扩大，而增长分部体量太小无法对冲，则总量继续下滑；EPS 指引低于预期，意味着收入和毛利率继续下滑。
- **海豚案例**：
  - 高通（2026-04-30）：下季手机约 49 亿，同比约 -22%，下滑扩大；汽车预计约 +50%，但只占总收入 1-2 成；EPS 指引 2.1-2.3 vs 2.38，意味着收入和毛利率继续下滑。
  - 高通（2026-07-30）：下季手机约 52 亿，同比约 -25%，安卓环比增长被苹果收入下滑抵消。
- **适用场景与注意事项**：管理层会给分部口径的公司；倒算时注意财年和季节性（见 9.2.26、3.4）。

### 9.2.16 总指引扣除已知分项：倒算“其他”分项隐含收入与隐含硬件毛利率

- **方法要点**：营收指引只给总量和少量分项提示时，把增速指引换算成金额，扣除已知分项（iPhone、服务）的预测，得到其他硬件的隐含收入，并由整体毛利率指引倒推隐含硬件毛利率变化。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把同比增速指引换算成金额区间（如 13-16% 对应 1078-1106 亿）。
  2. 由整体毛利率指引，结合服务毛利率稳定的假设，倒推隐含硬件毛利率变化。
  3. 从营收指引中扣除 iPhone（指引约 +15%）和服务（平稳增长）的预测，得到其他硬件（Mac / iPad / 可穿戴）隐含收入，与去年同期比较。
  4. 结合事件（提价公告）解释需求前置。
- **关键指标与数据来源**：营收增速指引、毛利率指引、iPhone 增速指引、服务收入假设、去年同期分项收入。
- **判断标准**：隐含其他硬件收入低于去年同期，可能同比下滑；若同期提价公告引发需求前置，说明增量已提前释放；隐含硬件毛利率下降 1-1.5pct，说明存储涨价等成本压力。
- **海豚案例**：
  - 苹果《硬刚涨价…》（2026-07-31）：下季营收指引 +9-11%（1117-1138 亿美元），iPhone 约 +15%，毛利率 47-48%，隐含硬件实际毛利率下降 1-1.5pct；其他硬件仅 231-252 亿，可能同比下滑（去年 247 亿），因 Mac、iPad 在 6 月末宣布提价，需求已前置释放。
  - 苹果《iPhone炸场…》（2026-01-30）：指引 +13-16%（1078-1106 亿），毛利率 48-49%。
  - 苹果《AI缺位…》（2026-05-01）：指引 +14-17%（1071-1100 亿），毛利率 47.5-48.5%。
- **适用场景与注意事项**：适用于给出总量指引并有分项口径提示的公司；分项假设要写明，误差会向“其他”分项集中。

### 9.2.17 隐含同店：收入增速目标剔除开店贡献

- **方法要点**：用管理层收入增速目标减去新开门店贡献，倒算隐含同店增长，与市场预期比较判断指引保守程度，并引用管理层定性表述辅证。
- **操作步骤 / 拆分口径 / 公式**：
  1. 收入增速目标 − 新开门店贡献 = 隐含同店增长。
  2. 与市场预期的同店/增速比较，判断指引保守程度。
  3. 引用管理层定性表述辅证。
- **关键指标与数据来源**：收入指引、开店贡献、隐含同店、市场预期。
- **判断标准**：剔除开店后隐含同店仅低个位数，显著低于市场约 30% 预期，说明指引偏保守或管理层有意压低增长预期；要与管理层措辞一并读（9.5）。
- **海豚案例**：
  - 泡泡玛特（2026-03-25）：2026 年收入增长不低于 20%，剔除开店后隐含同店仅低个位数，管理层称“进维修站加油换轮胎”，显著低于市场约 30% 预期。
- **适用场景与注意事项**：门店驱动零售公司。开店贡献的拆分需要门店数与新店爬坡假设，同店与新店的量价拆分口径见 5.1。

### 9.2.18 总销量指引减老产品假设：倒算新品隐含销量

- **方法要点**：总销量指引里新车型贡献多少？假设老车型的同比变化，用“指引 − 老车型预测”得到新车型的隐含销量区间，再和卖方此前的普遍预测比较，判断管理层信心和市场预期差。
- **操作步骤 / 拆分口径 / 公式**：
  1. 假设老车型同比变化（如受补贴退坡影响 −7%）。
  2. 新车型隐含销量 = 全年销量指引 − 老车型预测。
  3. 与卖方此前对新车型的普遍预测比较。
  4. 随后季度沿用同一测算，判断增量是否几乎全部来自新车型。
- **关键指标与数据来源**：全年销量指引、老车型销量假设、新车型隐含销量、卖方预测。
- **判断标准**：新车型隐含销量显著高于卖方预测，说明管理层信心更强、市场担心被消除；增量几乎全靠新车型，则公司业绩与新品爬坡高度绑定。
- **海豚案例**：
  - Rivian（2026-02-13）：2026 销量指引 6.2-6.7 万（2025 年 4.2 万，+47%-60%），假设 R1 同比 -7%，隐含 R2 为 2.1-2.7 万辆，显著高于大行普遍预测的约 1 万辆（大行原本预计总销量 4.7-5 万），因此打消了市场担心。
  - Rivian（2026-05-01）：沿用同一测算，并指出增量几乎全部来自 R2。
- **适用场景与注意事项**：适合新品贡献增量的公司（车型、SKU、新门店）。老产品假设是关键，需要敏感性测算。

### 9.2.19 收入、出货、授权收入多指引联立：反推隐含 ASP 与产品结构并检验可行性

- **方法要点**：用“总收入或汽车收入增速指引、出货量指引、授权收入持平”等条件联立，反推隐含芯片 ASP，再用各型号单价与管理层给的结构反推达到该 ASP 所需的高端型号占比；如果推出“必须几乎全部是高端型号”，就判断指引激进、放量压力很大。
- **操作步骤 / 拆分口径 / 公式**：
  1. 产品收入 = 总收入（或汽车收入）− 授权收入。
  2. 隐含 ASP = 产品收入 ÷ 出货量。
  3. 用各型号单价（如 J6P 芯片 500 美元，约为平均 ASP 的近 10 倍）和管理层给的结构（中高端占比从 45% 升到 65% 以上）反推：要达到该 ASP，高端型号必须占多少份额。
  4. 若必须几乎全部为高端型号，判断指引激进。
  5. 指引下修后重算一遍，对比隐含 ASP 的下修幅度。
- **关键指标与数据来源**：收入增速指引、出货量指引、授权收入、隐含产品收入、隐含 ASP、各型号单价和方案结构。
- **判断标准**：隐含 ASP 同比大幅提升，且需要高端型号几乎占满份额，与管理层原口径（超半数）不一致，指引激进；下修后隐含 ASP 明显低于此前，说明结构预期被下调。
- **海豚案例**：
  - 地平线（2026-03-20）：汽车收入 +60%、出货 +35%（540 万）、授权持平，反推产品收入 +132% 至 37.6 亿，隐含 ASP +73.4% 至约 694 元；按 HSD 三种方案（J6P 700 美元、双 J6M 400 美元、单 J6M 协商中）测算，J6P 必须占 HSD 几乎全部，而管理层原口径是“超半数”。
  - 地平线（2026-09-01）：下修后总收入 50 亿、出货 500 万、授权持平，产品收入 +85% 至 30 亿，隐含 ASP 约 600 元，明显低于此前近 700 元。
- **适用场景与注意事项**：适合多产品线、有单价梯度的硬件公司。前提是各型号单价可得。

### 9.2.20 季度销量指引减已公布月度：倒算剩余月份隐含月销（含年度目标所需月均）

- **方法要点**：车企等公司在季度中后段发布财报时，季度首月甚至前两月的交付已经公布。用（季度指引 − 已知月交付）÷ 剩余月数得到隐含月均销量，并和最近月销对比，判断新车订单和指引激进程度；年度目标同理倒算剩余月份所需月均，并落到具体新车型上。
- **操作步骤 / 拆分口径 / 公式**：
  1. 变体 A（季度）：隐含剩余月均销量 =（季度销量指引上下限 − 已公布月份交付量）/ 剩余月数。
  2. 与已公布月份和历史峰值比较：隐含月销环比下滑，说明新车订单不足或在手订单在消耗；显著上行，说明新车订单储备充足；接近现有水平，说明增量有限或存在瓶颈（产能）。
  3. 变体 B（年度目标）：（年度目标 − 已累计交付）÷ 剩余月数，与历史峰值、当前月销水平对比，判断指引激进程度和达成难度。
  4. 变体 C（拆现有 + 新车）：拆成“现有车型维持当前月销 + 新车型需贡献多少”，把指引能否达成的压力落到具体新车上。
  5. 结合提车周期判断新车订单强弱，并把隐含月销作为下个月月度交付公告的验证点。
  6. 若主流机构已普遍下调预期，管理层明确下调指引反而可能是“利空落地”。
- **关键指标与数据来源**：季度/全年销量指引、已公布月度交付、剩余月均所需销量、历史月销峰值、提车周期、机构预期。
- **判断标准**：
  - 隐含月销明显上台阶 → 新车贡献，订单充足；接近当前水平 → 增量有限或产能瓶颈；低于已公布月份 → 新车订单平淡。
  - 年度目标所需月均远高于历史峰值，则目标压力大。
- **海豚案例**：
  - 小鹏（2026-03-20）：Q1 指引 6.1-6.6 万（预期 8.4 万），1 月约 2 万、2 月约 1.5 万，隐含 3 月 2.6-3.1 万。
  - 小鹏（2026-05-28）：Q2 指引 10-10.6 万，4 月 3.1 万，隐含 5、6 月月均 3.45-3.75 万，增量来自 M03 改款和 GX。
  - 小鹏（2026-08-24）：Q3 指引 11.5-12.1 万，7 月 3.8 万，隐含 8、9 月月均 3.85-4.15 万，环比增量有限，指向产能瓶颈（推断 L03 产能瓶颈）。
  - 理想 1Q26（2026-03-12）：8.5-9 万减去 1、2 月的 2.8 万和 2.6 万，3 月隐含 3.1-3.6 万。
  - 理想 2Q26（2026-05-29）：9.5-10 万减去 4 月 3.4 万，5、6 月隐含月均 3.05-3.3 万，比 4 月还低，判断新 L9 订单平淡。
  - 理想 3Q26（2026-08-26）：9.5-10 万减去 7 月 3 万，8、9 月隐含月均 3.2-3.5 万；全年 48 万目标预计下调至约 42 万。
  - 蔚来 1Q26（2026-03-10）：Q1 指引 8-8.3 万（预期 8.9 万）减去 1、2 月的 2.7 万和 2.1 万，3 月隐含 3.2-3.5 万。
  - 蔚来 2Q26（2026-05-21）：11-11.5 万，5、6 月需月均 4-4.3 万（3 月仅 2.94 万），判断 ES9 和 L80 订单充足；提车周期缩短，增量来自 ES9 和 L80。
  - 蔚来 3Q26（2026-09-01）：10.8-11 万减去 7、8 月月均 3.6 万，9 月隐含 3.6-3.8 万。
  - 零跑《剑指百万…》（2026-05-15）：Q2 指引 24-25 万辆，4 月 7.1 万，对应 5-6 月月均 8.7 万，判断指引不错；全年上调到 105 万，1-4 月累计仅 18 万，5-12 月月均需近 11 万，压力较大。
  - 小米《跌到怀疑人生？…》（2026-05-26）：55 万目标减 Q1 的 8.1 万，后三季需 47 万，单季 15.5 万以上。
  - 小米《又双叒原地久跪…》（2026-08-18）：前 7 月 21.6 万，SU7+YU7 维持月 3 万则全年约 37 万，澎程需在 4 个月交付 18 万（月均 4.5 万），机构普遍下调到 46-50 万；55 万目标对应后 5 个月月均需 6.68 万。
- **适用场景与注意事项**：适合公布月度交付的车企、手机、航空等；也适用于部分 SaaS 按月披露的指标。要注意月度数据的季节性和春节等假期因素；新品爬坡节奏会让月均并非线性。

### 9.2.21 季度收入指引 ÷ 销量指引：倒算隐含 ASP 并与预期对比

- **方法要点**：用收入指引（剔除服务等非核心收入）除以销量指引，得到隐含单价，上下限分别计算，与上季实际 ASP、市场预期 ASP 比较，判断价格端与结构变化：高价新车的订单强弱、促销加码、低价车占比，并预判下季卖车毛利率方向。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含 ASP =（收入指引 − 预估服务及其他收入）÷ 销量指引；公司只给总收入指引时，先扣除其他业务收入的估算值。
  2. 上下限分别计算，与上季实际 ASP、市场预期 ASP 比较。
  3. 隐含 ASP 下滑：推断促销加码、低价车占比上升；持平或上行：推断高价新车对冲。
  4. 结合车型占比解释 ASP 趋势（例如某车型占比从 26% 升到 60%）。
  5. 结合成本端（规模效应、原材料）预判下季卖车毛利率方向。
- **关键指标与数据来源**：汽车收入指引或总收入指引、销量指引、服务收入估计、隐含 ASP、市场预期 ASP、车型占比。
- **判断标准**：销量符合预期而收入大幅低于预期，问题出在价格端；销量低于预期而收入超预期，结构在向上；隐含 ASP 低于预期 ASP，说明高价车型受产能或订单限制、占比偏低。
- **海豚案例**：
  - 小鹏（2026-03-20）：Q1 收入指引 122-132.8 亿，隐含 ASP 15.5-16.5 万（剔除服务收入后），上限只与 Q4 持平，预期 17 万，推断促销加码、毛利率继续承压。
  - 小鹏（2026-05-28）：Q2 收入指引 196-208 亿（预期 193 亿），隐含 ASP 约 17.5 万，与 Q1 持平，原因是 GX（28.98-35.98 万）对冲了 M03（11.98-15.18 万）占比上升。
  - 小鹏（2026-08-24）：Q3 收入指引 217-234 亿（预期 282 亿），隐含 ASP 16.8 万（预期 17.3 万），反映 GX 受产能限制、占比偏低。
  - 理想 1Q26（2026-03-12）：收入指引 204-216 亿，市场预期 239 亿，隐含 ASP 22.2 万（4Q25 为 25 万）；归因于 i6 占比从 26% 升到 60%，以及清库存降价。
  - 理想 2Q26（2026-05-29）：汽车收入指引 241-254 亿，市场预期 263 亿，隐含 23.8 万，市场预期 24.5 万，推断改款 L9 订单一般。
  - 理想 3Q26（2026-08-26）：266-280 亿对比 327 亿，隐含 26.3 万，环比 + 近 2 万，说明 L9 和 L8 带来结构升级，但 L6 订单一般。
  - 蔚来 1Q26（2026-03-10）：收入 245-252 亿，高于预期 245 亿，隐含 ASP 26.5-27 万（从 25.3 万升到 26.5-27 万），ES8 占比预计升到 55%-60%；Q4 ES8 占比 +27pct 至 32%，ASP 从 22.1 万升到 25.3 万。
  - 蔚来 2Q26（2026-05-21）：329-344 亿，预期约 300 亿，ASP 约 27 万，需要 ES9 补位。
  - 蔚来 3Q26（2026-09-01）：333-340.5 亿，预期 344 亿，ASP 27.8-28 万，市场预期 25.2 万。
- **适用场景与注意事项**：适用于量价可分的行业：整车、硬件出货、航空（座公里 × 单位收益）。总收入指引中混有服务收入时需先剥离，服务收入估计会带来误差。

### 9.2.22 全年收入指引 ÷ 全年出货指引：隐含全年 ASP，对照季度实际 ASP 校验价格通缩

- **方法要点**：用公司全年收入指引除以全年出货量指引，倒算隐含的全年综合 ASP，与去年 ASP 比较算出同比降幅，再与最新季度的实际 ASP 比较，判断价格通缩是否超出公司指引和自己的预期。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含全年 ASP = 全年收入指引 ÷ 全年出货量指引（上下限分别算）。
  2. 与上年 ASP 比较，算出同比降幅。
  3. 与最新季度的实际 ASP 比较：季度 ASP 已低于全年隐含区间，说明价格通缩超出公司指引，需要下修全年 ASP 和收入。
  4. 考虑季度间结构差异会让单季 ASP 偏离全年均值，要结合季节性结构调整。
  5. 把自己对全年 ASP 的预测同步改为同比降幅。
- **关键指标与数据来源**：全年收入指引、全年出货指引、上年 ASP、季度实际 ASP。
- **判断标准**：隐含 ASP 同比降幅超出预期，是“通缩程度超预期”；季度实际 ASP 低于全年隐含下限，推理链条是“剩余季度只会更低或持平，全年 ASP 与收入都需下修”。
- **海豚案例**：
  - 禾赛（2026-05-19）：收入指引 42-46 亿除以出货 300-350 万台，对应 ASP 约 1300-1380 元，同比 2025 年的 1844 元下降 25%-29%，通缩程度超海豚君预期，全年 ASP 预测改为同比 -28% 至 1320 元。
  - 禾赛（2026-08-19）：二季度 ASP 已降到 1297 元，低于全年隐含下限，再下修全年 ASP 为同比 -31% 至 1268 元。
- **适用场景与注意事项**：适用于给出量和收入双年度指引的公司。单季结构差异要考虑（激光雷达等 ASP 受产品组合影响）。

### 9.2.23 商品型行业：由收入与毛利率指引倒算隐含 ASP 和隐含 EPS

- **方法要点**：对出货量基本确定、价格是主要弹性的公司（存储、面板、化工），用指引倒推价格假设：扣除出货增长后得到隐含 ASP 环比增速，用毛利率指引环比变化判断后续涨价，用“新增收入大多转为利润”的逻辑把收入指引换算成隐含 EPS。
- **操作步骤 / 拆分口径 / 公式**：
  1. 隐含 ASP 环比 =（1 + 收入环比增速）/（1 + 出货环比增速）− 1，需要对出货增速有独立判断。
  2. 毛利率指引环比变化：环比大幅提升说明下季继续涨价。
  3. 新增收入大多转为利润时，收入指引已隐含了 EPS 指引，与市场预期 EPS 比较。
  4. 把这类指引定性：“留容错空间以便超预期”还是“已经给足”。
- **关键指标与数据来源**：收入指引；出货量增速假设；隐含 ASP；毛利率指引环比变化；隐含 EPS。
- **判断标准**：隐含 ASP 环增放缓（10-15%）说明涨价速度下降；毛利率指引环比大幅提升，推断 DRAM 和 NAND 继续涨价；收入环比与市场一致、EPS 指引等于市场最乐观预期，则定性为留容错空间。
- **海豚案例**：
  - 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：收入指引 615 亿 ± 15 亿，环增 73 亿，扣除出货增长后，隐含存储 ASP 环增只有 10-15%，再次放缓。
  - 美光（2026-03-19）：毛利率指引 81%，环比 +6.6pct，说明下季 DRAM 和 NAND 会继续涨价。
  - 美光《美光：牛气冲天！…》（2026-06-25）：收入指引隐含环比 20%，与市场一致；因为新增收入大多转为利润，收入指引已经隐含了 EPS 指引（31 美元，等于市场最乐观预期），海豚君把这种指引定性为“留容错空间以便超预期”。
- **适用场景与注意事项**：适用于量相对刚性、价格弹性大的商品型行业（存储、面板、化工）。需要对出货增速有独立判断，否则隐含 ASP 失真。

### 9.2.24 利用财报发布时已公布的月度数据前瞻下季收入与毛利率

- **方法要点**：财报通常在下季度中段发布，此时已有 1-2 个月的月度交付数据。把它们与上季度月均、去年同期对比，再结合政策、经销商去库存、新车上市前观望等因素，预判下季收入和毛利率方向，并用低价车型占比、出海占比的月度变化判断单价和毛利率的对冲力量。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取当季前 1-2 个月销量，与上季月均（环比）、去年同期（同比）比较。
  2. 结合政策（购置税、以旧换新）、经销商去库存、新车上市前观望等因素判断量的方向。
  3. 销量环比大降意味着规模效应减弱、毛利率承压。
  4. 用月度车型占比、出海占比判断单价和毛利率的对冲力量。
  5. 与季度指引一起使用：先由月度数据判断趋势，再用 9.2.20 倒算剩余月份。
- **关键指标与数据来源**：当季前 1-2 个月销量、上季月均销量、同比增速、月度车型占比、月度出海占比。
- **判断标准**：月均销量同比增速低于上季，且低价车型占比大幅上升，则单价与毛利率承压；出海占比大幅上升可部分对冲。
- **海豚案例**：
  - 零跑《出海神车…》（2026-03-16）：2026 年 1-2 月销量仅 6 万辆（月均 3 万），对比 4Q25 月均 6.7 万，同比仅 +19%；T03 占比从 Q4 的 11% 升至 27%，出海占比从 14.6% 升至约 40%，据此预计 1Q26 毛利率继续承压，出海可部分对冲。
  - 小米《跌到怀疑人生？》（2026-05-26）：新 SU7 带动 4 月销量回到 3 万辆以上。
- **适用场景与注意事项**：适用于有月度数据披露的行业（汽车、手机、航空、互联网运营数据等），是做下季度预期最直接的工具。月度数据有季节性与春节等假期干扰（见 3.4）。

### 9.2.25 根据指引发布时点推断剩余月份趋势

- **方法要点**：公司在季度中后段（如 5 月底）给出的单季指引已经包含前两个月的实际数据；若季度结果仍低于这个指引，就能推出最后一个月（6 月）的趋势比指引时还差，据此修正对下半年的预期。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认指引发布日期，判断指引时已包含的实际月份数。
  2. 将实际结果与指引（或指引隐含增速）比较：低于指引，说明最后一个月比指引时的趋势更差；高于指引，则趋势好于预期。
  3. 结合上年同期基数（如下半年高基数）判断增长能否回暖。
- **关键指标与数据来源**：指引发布日期、单季指引、实际结果、上年同期基数。
- **判断标准**：实际低于指引，推理链条是“指引已含前两个月数据，结果更差只能由最后一个月拖累”，因此趋势恶化，叠加下半年高基数，难有增长支撑。
- **海豚案例**：
  - 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：2Q 广告 +4%，低于 5 月底指引隐含的约 6%，说明 6 月趋势更差；考虑下半年高基数，广告给不了多少增长支撑。
- **适用场景与注意事项**：适用于季度中段才发布指引的公司（港股和中概常见）。

### 9.2.26 财年与自然年错位换算、14 周季度调整与环比失速推演

- **方法要点**：公司财年与自然年错开时，管理层的全年展望常按自然年给，而市场按财季跟踪。把全年展望按财季重新映射，推演季度环比轨迹，判断要达到市场期待的增速需要什么样的季度形态，识别指引是否隐含失速；还要核对 14 周季度，把周数折回 13 周同口径。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认财年起止月（如 AMAT 财年比自然年错开 2 个月）与每个财季的周数（13/14 周）。
  2. 把自然年指引（如半导体设备 2026 自然年增速 30% 以上）按财季重新映射，假设达到更高的自然年增速（如 40%），倒算出各季环比路径。
  3. 对比各季环比：环比逐季下降（18% → 12% → 6%）即失速。
  4. 对 14 周季度折回 13 周同口径后再看环比，可能接近零增长。
  5. 用上述路径解释“指引超预期、股价却下跌”的矛盾。
- **关键指标与数据来源**：财年起止月；自然年指引；单季周数（13/14 周）；隐含环比增速序列；大厂 Capex 增速。
- **判断标准**：自然年增速指引没有上调，而大厂 Capex 增速在 40%+，即便把自然年增速抬到 40%，隐含环比仍逐季降低，意味着明显失速；14 周调整后的下一季环比接近零增长，进一步坐实失速。
- **海豚案例**：
  - 应用材料《泼天富贵在前，应用材料 AMAT 竟然怂了？》（2026-08-14）：自然年 40% 情形下，半导体设备环比路径为本季 18% → 下季 12% → 下下季 6%；Q1FY27（截至 2027 年 1 月）是 14 周，折回 13 周同口径后那个 +6% 环比接近零增长；由此解释为何下季指引超预期、股价却盘后跳水。
  - 应用材料（2026-08-14）：设备业务 2026 自然年增速 30%+ 的指引没有上调，大厂 Capex 增速 40%+；即便给到 40%，也意味着设备环比 18% 降到 12% 再降到 6%，明显失速，所以盘后跳水。
  - Marvell（2026-08-28）：由全年展望推出后两季收入约 31.5 亿、37 亿，环比 15-20%。
- **适用场景与注意事项**：适用于财年与自然年不一致的公司（AMAT、美光、高通、苹果等），以及有 53 周年或 14 周季度的公司。需要精确核对财季日历（见 3.4）；非自然年财年的半导体、软件公司尤其重要。

**相关方法的交叉引用**：全年收入指引上调后换算隐含全年增速并与上次指引、下季指引对比，详见 9.1.4；下季指引逐项（收入/毛利润/费用率/FCF margin）对比卖方预期并推出隐含毛利率与费用率，详见 9.1.6；指引的保守度判断与推导（按上限看、分业务指引、费用率指引推利润），详见 9.4。

**本节速查清单**

- [ ] 公式是否统一：隐含增速 = 指引中值（或上限）÷ 去年同期 − 1；隐含利润率 = 利润指引中值 ÷ 收入指引中值；剩余季度均值 =（全年目标 − 已实现）÷ 剩余季度数？
- [ ] 全年指引是否减去已实现和下季指引，倒算了隐含下半年 / Q4 的收入、利润、Capex，并与当期增速、季度指引做了自洽性检验？
- [ ] 倒算前是否先剔除汇率顺风、并表贡献、一次性项，并核对财年与自然年、13/14 周的日历差异？
- [ ] 隐含利润率是否同时与本季、去年同期、市场预期比较，并测试了指引上限情形与拐点（首次环比不增长）？
- [ ] 总指引是否做了分部减法（核心分部隐含增速、内生增速、新品隐含销量、隐含同店、其他分项隐含收入）？
- [ ] 车企等月度披露行业：是否用季度指引减已公布月度得到剩余月份隐含月销，并与历史峰值、提车周期、产能约束对照？
- [ ] 是否用收入指引 ÷ 销量指引得到隐含 ASP（先扣除服务收入），并用车型占比或价格弹性解释方向？
- [ ] 隐含值是否与管理层历史指引风格（保守或激进）、供应链指引（设备商 vs 晶圆厂 Capex）交叉验证，并给出“保守 / 失速 / 产能瓶颈 / 暂时性”的明确结论？
- [ ] 多年或偏定性长期目标是否已降权，不作为当期定价依据？

## 9.3 指引权重与时间维度

> 本节导读：同一份财报里同时存在当期业绩、下季指引、全年指引和多年展望，这些信息对股价的权重并不相同；海豚君的基本排序是“下一年指引 > 全年指引 > 季度指引 > 当期业绩”，并随公司是否已给出更长期限的指引而动态切换。写火线速读、确定“本次财报最大问题”和设定判断门槛时，先用本节回答“市场此刻在为哪个时间维度定价”。指引数值与预期的逐项对比见 9.1，隐含值倒算见 9.2，保守度与风格校准见 9.4，措辞与里程碑兑现见 9.5、9.6，多年目标见 9.7。

### 9.3.1 当期看是否达标，股价看指引与前瞻指标

- **方法要点**：先用一两句话确认当期收入、毛利率是否达标，再把主要篇幅放在下季/全年指引、订单、资本开支等前瞻信息上；当期与指引方向相反时，以指引定性。“相比于本季业绩，指引更重要”是海豚君速读的固定句式，原因是当季业绩往往已被月度数据或业绩预告部分锁定，股价反应主要由下季或全年指引决定。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先看当期收入、毛利率是否达标（对照一致预期、前期指引、月度数据），达标与否只做定调，不做重点展开。
  2. 把下季收入、毛利率、EPS、经营利润指引，以及全年指引、订单、资本开支，逐项与市场预期（指引中值或上下限 vs 一致预期）比较。
  3. 检查指引内部是否同向：收入指引与毛利率/利润指引是同升还是一升一降；收入是环比增长还是环比持平。
  4. 当期与指引方向相反时，以指引为准给整次财报定性（当季达标但指引 miss＝负面，当季平淡但指引大超＝正面）。
  5. 在速读首段写明“当季不是重点、指引才是重点”，并点出最大的那一个指引问题。
- **关键指标与数据来源**：下季收入、毛利率、EPS、经营利润指引；全年指引；订单；一致预期。来源为公司业绩公告、电话会及卖方/彭博一致预期。
- **判断标准**：
  - 指引隐含收入和毛利率双降，或者环比持平而市场预期环比增长，判为负面。
  - 指引中值（或上下限）明显高于预期，即便当季平淡也判为大惊喜；明显低于预期，即便当季超预期也判为“指引暴雷”。
  - 推理链条：当季业绩已被月度数据/预告锁定，信息增量小 → 股价定价的是未来几个季度的盈利路径 → 以指引与预期的差距作为主判断，同时要求收入与毛利率/利润同向。
- **海豚案例**：
  - Meta（2026-01-29）：Q4“不是重点”；Q1 收入指引 535-565 亿（+26%~34%），市场预期 21%，属大惊喜。
  - 英特尔（2026-01-23）：当期达标，但 Q1 GAAP 毛利率指引 32.3% vs 预期 38%，被评为“冷水”。
  - 高通（2026-02-05）：收入指引 102-110 亿 vs 112 亿，EPS 2.45-2.65 vs 2.9，手机营收仅约 60 亿。
  - 中芯（2026-02-10）：收入指引环比持平 vs 预期 +3%；毛利率 18-20% vs 21%。
  - AMAT（2026-02-13）：指引 71.5-81.5 亿，中值环增 9% vs 71 亿。
  - 泡泡玛特（2026-03-25）：2026 年指引仅 20%，当天下午跌 22%。
  - Spotify（2026-04-28）：Q1 全部达标，但 Q2 订阅净增 600 万（预期 700 万）、毛利率 33.1%（预期 33.7%）、经营利润 6.3 亿 miss。
  - 奈飞《1Q26》（2026-04-17）：当季超预期，但 Q2 收入不足 126 亿，低于一致预期，股价大跌。
  - Lululemon（2026-06-05）：“营收过关、指引暴雷”，全年收入从 +2%~4% 砍到 -1%~0，盘后 -11%。
  - 英特尔（2026-04-24）：下季 138-148 亿（预期 131 亿），毛利率 37.5%（预期 34.7%），收入与毛利率同时超预期。
  - 中芯（2026-05-14）：下季环增 14-16%（预期 7%）。
  - CoreWeave（2026-05-08）：下季收入指引 24.5-26 亿，低于预期 27-28 亿，被列为最大问题。
- **适用场景与注意事项**：普遍适用，周期股和高估值成长股对指引最敏感。前提是公司按季给出指引（美股/港股）；无指引的 A 股公司无法套用，需改用月度数据和前瞻指标代替。当期与指引的权重关系还要看公司是否另有更长期限的指引，见 9.3.2。

### 9.3.2 指引时间维度权重排序：下一年指引 > 全年指引 > 季度指引 > 当期业绩

- **方法要点**：给不同期限的指引明确排序，并按公司当前所处的指引阶段切换判断重心；财报前先弄清市场此刻在为哪个时间维度定价，再设定判断门槛。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认公司是否已给出全年增速或年度（AI）收入展望：给出后，季度指引的重要性“弱化”，看全年指引与预期的差距。
  2. 判断当年业绩是否已成“明牌”：多出现在下半年、全年指引已多次上调之后；此时市场焦点转到下一年的增速和资本开支，要列出市场想听到的下一年门槛（如增速下限、理想值、资本开支水平）。
  3. 检查公司是否拒绝给下一年指引：即便当期和季度指引都好，这也会被看作“没给定心丸”。
  4. 只给季度指引的公司，仍以下季度指引为核心。
  5. 按上述排序写速读：先写最高时间维度的结论，再写季度指引与当期业绩。
- **关键指标与数据来源**：当期收入/毛利率；下季指引；全年增速指引；下一年增速与资本开支指引；机构对下一年的预期（门槛）。
- **判断标准**：
  - 全年指引上调且达到或超过预期 → 季度指引略低不构成主要矛盾。
  - 当年已是明牌 → 当期业绩与季度指引都退居次要，下一年增速和资本开支是“考卷”；公司给出的表述弱于市场门槛（如只说“收入增长快于资本开支增长”，而市场要至少 40%、最好 50% 以上）就是失望。
  - 推理链条：先问“市场在为哪一年定价” → 把门槛设在该年 → 用公司给出的该年指引与门槛对比，而不是和当季 beat/miss 对比。
- **海豚案例**：
  - 台积电《台积电：AI 界 “真霸主”，谁能撼动？》（2026-04-16）：全年增速上调至“30%以上”，下季度收入的影响随之弱化。
  - 台积电（2026-07-16）：全年增速提至 40%，下季指引的重要性削弱。
  - 台积电（2026-10-15）：2026 年业绩已是“明牌”，市场要的是 2027 年增速至少 40%、最好 50% 以上，以及 2027 年 capex 高于 850 亿；公司只说“2027 收入增长快于资本开支增长”，市场因此失望。
  - 博通《谷歌 “三心二意”，博通独自画饼 “难充饥”》（2026-09-03）：公司给出 FY26-28 AI 收入 580/1150/2300 亿，下季总收入指引 348 亿低于预期 355 亿这件事因此被弱化。
- **适用场景与注意事项**：适用于给出全年或多年指引的成长型公司。只给季度指引的公司（中芯、AMAT）仍以下季度指引为核心。“明牌”的判断依赖全年指引已被多次上调，要避免在年初仍套用“看下一年”的逻辑。

### 9.3.3 已有全年指引时弱化单季指引：先看全年上调与预期吻合度，再用全年+单季组合判断节奏

- **方法要点**：公司已给出全年（或多年）指引时，下季度指引低于预期的信息量被明显削弱；优先看全年指引有没有上调、与机构预期是否吻合，再用“全年 + 单季”的组合判断交付/业绩节奏。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先看全年指引：相对上季是否上调、上调幅度多大。
  2. 把全年指引（含同比区间）与机构预期区间对比：是否落在或超出机构区间、是否 beat 所有机构预期。
  3. 再看单季指引：下季收入、毛利率与预期的差距；若全年已上调且吻合预期，则把单季差距解读为节奏扰动而非趋势恶化。
  4. 用全年指引倒推后续季度还能否提速（倒推方法见 9.2）。
  5. 若有多年指引，与机构远期预期做对比（见 9.3.5）。
- **关键指标与数据来源**：全年收入/增速目标及其修订；单季指引 vs 预期；机构全年预期区间；多年收入指引；分业务年度增速。
- **判断标准**：
  - 全年指引上修幅度够大、符合或超出机构区间 → “下季度指引并不重要”，短期业绩影响不大。
  - 全年指引仅符合预期（上修但机构已预期到）→ 判为“符合期待但无惊喜”。
  - 全年指引也低于预期时，本方法失效，单季不及预期要按负面处理。
  - 推理链条：全年指引已确定年度总量 → 单季低于预期多半是交付/季度节奏问题 → 只要全年上调且与预期吻合，节奏扰动不改变全年逻辑。
- **海豚案例**：
  - 阿斯麦《阿斯麦 ASML：有 AI 高烧在，光刻机只是假摔？》（2026-04-15）：Q2 指引 84-90 亿欧元，低于市场 91 亿；毛利率 51-52%，低于 52.5%。但全年已上调到 360-400 亿（同比 +10%-22%），符合机构 10%-25% 的区间，海豚君判定“下季度指引并不重要”，短期业绩影响不大。
  - 阿斯麦（2026-07-15）：全年 430-450 亿欧元，beat 机构的 395-400 亿。
  - Marvell（2026-05-28）：FY27 营收上调至 115 亿（原 110 亿），FY28 上调至 165 亿（原 150 亿），互连增速 >70%（原 50%+），判为“符合期待但无惊喜”。
  - 台积电《26Q2》（2026-07-16）：全年增速目标从至少 30% 提至 40%，略好于主流预期 35%+。
  - 博通（2026-06-04）：下财年 AI 指引 1000 亿+，机构预期 1300 亿+，判为平平无奇。
  - 戴尔（2026-05-29）：全年上调 170 亿，仍判为偏保守。
  - AMAT（2026-05-15）：全年设备 30% 以上被视为谨慎。
- **适用场景与注意事项**：适用于给全年指引、交付节奏不均的设备和大客户型公司，以及周期性/capex 驱动行业（半导体、设备）和给多年目标的公司。若全年指引也低于预期则不适用；全年指引的保守度仍需用 9.4 的方法校准，“上调了但仍偏保守”（戴尔、AMAT）是常见判断。

### 9.3.4 多年展望下的权重切换：以年度展望与预期的差距为核心，AI 链看 AI 业务指引而非总收入指引

- **方法要点**：公司给出全年乃至两年展望时，明确降低季度指引的权重，把年度展望与市场预期的差距作为核心判断；对 AI 链公司，最关键的是 AI 业务指引，而不是总收入指引。
- **操作步骤 / 拆分口径 / 公式**：
  1. 在速览第一条写年度/多年展望相对预期的位置，说明“相比于短期业绩，市场最关注的是后续成长性”。
  2. 下季度指引降级处理，仅作为全年展望的节奏验证。
  3. 对 AI 链公司，把总收入指引拆开，单独拿出 AI 业务（或 AI 细分业务）的季度与年度指引，与预期对比，并以 AI 指引的 miss/beat 为本次财报的主问题。
  4. 总收入略好但 AI 指引不及预期时，仍以 AI 指引定性。
- **关键指标与数据来源**：年度/多年收入展望、细分业务增速展望、季度指引（含 AI 业务指引）、机构预期。
- **判断标准**：年度展望高于预期 → 正面；年度展望与预期持平 → “没有惊喜”；AI 业务指引低于预期 → 即使总收入略超也列为最大问题。
- **海豚案例**：
  - Marvell（2026-05-28）：“由于公司管理层给出了全年指引，因而下季度指引的重要性就不高了”。
  - Marvell（2026-08-28）：把全年展望放在速览第一条，“相比于短期业绩，市场最关注的是后续成长性”。
  - 博通（2026-06-04）：总收入略好于预期，但把“下季 AI 指引 160 亿、低于预期 170 亿”列为本次财报的最大问题。
- **适用场景与注意事项**：适合提供长期展望的高成长公司，尤其是 AI 芯片链。如果公司只披露总收入、不披露 AI 细分，则需用 9.2 的方法倒推 AI 部分。

### 9.3.5 成长股以远期展望为核心：当季与下季指引弱化，看远期上修与预期对比

- **方法要点**：全年或多年展望已经给出（明牌）时，单季和下季指引的重要性下降，关键看远期展望能否上修，并与主流机构预期、同行增速、下游客户 capex 增速对比；上调幅度不足（只抬下限、不给下一年指引）同样视为失望。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出公司给出的多年收入/AI 收入展望（前值→新值）。
  2. 与主流机构预期对比：是否低于、持平还是高于机构区间。
  3. 与同行增速对比（如目标分部增速 vs 英伟达同类增速）。
  4. 与下游客户 capex 增速对比，检验增速目标是否与需求同步。
  5. 对展望中的集中度风险打折（如某一客户贡献半数 GW）。
  6. 检查公司是否只抬下限而未给下一年指引，或是否给出对上游供应的锁定承诺。
- **关键指标与数据来源**：多年收入/AI 收入展望；机构预期区间；同行增速；下游客户 capex 增速；供应锁定承诺。
- **判断标准**：展望低于机构预期（即便绝对值很高）→ 显得平淡甚至失望；展望上修幅度不足、只抬下限 → 失望；锁定未来年份上游供应的承诺 → 加分。
- **海豚案例**：
  - 博通（2026-09-03）：FY27 AI 指引 1150 亿+，机构预期 1300-1500 亿，显得平淡；FY28 2300 亿（20GW）中 10GW 来自 Anthropic，需打折。
  - Marvell：FY27/28 给 120/180 亿，机构已在 118/170-175 亿；数据中心 FY28 增速 60%+，低于英伟达 70%+。
  - 阿斯麦（2026-10-14）：全年指引只提下限，未给 2027 指引。
  - 台积电：2026 已是明牌，市场要 2027 年 40%+。
  - 英伟达（2026-08-27）：看锁定 FY28-29 上游供应的承诺。
- **适用场景与注意事项**：AI 半导体、设备商等长周期成长股。“明牌之后看下一年”的逻辑与 9.3.2 一致；展望中依赖单一客户的部分需单独折扣。

### 9.3.6 周期股：短期指引 vs 长期指引，看周期长度与措辞升级

- **方法要点**：当市场关注点从短期弹性转向周期长度时，“短期指引重要性不如长期指引”，要逐字对比管理层对供需的措辞变化，并寻找支撑信心的硬证据。
- **操作步骤 / 拆分口径 / 公式**：
  1. 保存每季电话会原话，把管理层对供需、周期年份的表述并排对比（如“很难判断”→“紧张得多”）。
  2. 判断措辞是升级、维持还是降级：升级说明对周期持续性更有信心。
  3. 寻找支撑措辞的硬证据：长协（SCA）签约份数、RPO；价格未锁定时留有容错空间。
  4. 记录分析师小会等场合关于未来 capex 回落的表述：若管理层仍在讲 capex 回落，则仍要用周期股视角看待。
- **关键指标与数据来源**：管理层对供需年份的表述；表述在各季间的变化；支撑证据（长协、RPO）；电话会原文。
- **判断标准**：措辞从“很难判断供给何时赶上需求”变为“供需将比上一年紧张得多”→ 对周期持续性更有信心；有长协/RPO 等硬证据 → 可以考虑拉估值；仍在提 capex 回落 → 仍属周期股估值。
- **海豚案例**：
  - 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：上季说即使 2028 年供需开始缓解，什么时候供给真能赶上需求也很难判断；本季改为“2027、2028 日历年内存与存储供需将比 2026 年紧张得多”，判定管理层对周期持续性更有信心，并找 SCA 签约份数和 RPO 作支撑证据。
  - 美光《美光：牛气冲天！…》（2026-06-25）：把供需紧张拉长到 2027 年之后，认为资金可以考虑拉估值。
  - 美光（2026-03-19）：分析师小会提到 FY27 之后 capex 可能回落，被视为仍要用周期股视角看待。
- **适用场景与注意事项**：适用于周期股和长周期业务。需要保存每季电话会原话做对照；措辞升级必须有硬证据（长协、RPO）配套才能提升估值假设。措辞对比的通用方法见 9.5.1。

### 9.3.7 下季指引好、全年指引平平时的“奖励”判断

- **方法要点**：下季指引小超预期，但全年指引维持或仅与市场一致时，市场无法对下季指引给出过多奖励；全年指引上调才是提高长期可见度、直接推动股价的关键信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对不变汇率指引只看上限（通常就是市场预期）。
  2. 比较下季营收/云业务/EPS 指引与预期：给出超出幅度。
  3. 比较全年营收与 EPS 指引相对上季与预期：上调、维持还是仅与预期一致。
  4. 若下季小超而全年不变/一致，推断公司自身对全年展望也不清晰，所以先按市场预期给；不对下季的小超给额外奖励。
  5. 若全年指引上调，视为长期指引可见度提高，可直接给出股价正面判断。
- **关键指标与数据来源**：下季营收/云业务/EPS 指引、全年营收与 EPS 指引、市场预期。
- **判断标准**：下季小超 + 全年维持 → 奖励有限；全年指引上调 → 直接推动股价；全年 EPS 与预期完全一致 → 公司在“先按市场预期给”。
- **海豚案例**：
  - 甲骨文（2026-03-11）：上调 27 财年营收指引到 900 亿，推动盘后上涨。
  - 甲骨文（2026-06-11）：下季云业务增速中值 60%，预期 57%；EPS 中值 1.74，小超预期约 3%；全年营收维持 900 亿，EPS $8.05 与预期一致，因此无法给下季指引过多奖励。
  - 甲骨文（2026-09-11）：下季总营收中值 +32%，大体符合预期；云业务 +68%，明显高于预期；EPS 同比 -15%，稍低于预期；全年 EPS 从 $8.05 上调到 $8.1。
- **适用场景与注意事项**：同时给季度与年度指引的公司。判断“给了奖励”与否要结合当时股价反应；汇率剔除口径见 4.1。

**相关方法（详见他节）**：高估值/故事驱动型公司的“展望与电话会重于当期业绩”，详见 11.3。

**本节速查清单**

- [ ] 先确认当期收入、毛利率是否达标，只做定调，不做重点；
- [ ] 明确市场此刻在为哪个时间维度定价（下一年 / 全年 / 季度），并设定对应的判断门槛；
- [ ] 公司是否已给全年或多年指引？若是，下季指引降级，改看全年上调幅度与机构预期吻合度；
- [ ] 当年是否已成“明牌”？公司是否拒绝给下一年指引或只抬下限？
- [ ] 指引内部收入与毛利率/利润是否同向，是否出现“环比持平 vs 预期环比增长”；
- [ ] AI 链公司单独拿出 AI 业务指引与预期对比，而不只看总收入；
- [ ] 周期股并排对比管理层各季供需措辞，并核查长协/RPO 是否支撑；
- [ ] 下季小超而全年平平时，不给额外奖励；全年上调才是关键信号。

## 9.4 指引保守度与管理层风格校准

> 本节导读：同一个指引数字，出自一贯保守的管理层和出自激进的管理层，含义完全不同；本节解决“这个指引是松是紧、该打几折、估值该取指引的哪一档”。前半部分讲单次指引的保守度判断（多证据交叉、按上限看、物理量换算、定性 vs 定量、动机解码、区间形态），后半部分讲管理层指引风格档案的建立与使用（分类、实际值定位、用历史 beat 幅度推算真实增速、对指引打折解读、估值取值修正）。指引与预期的逐项对比见 9.1，隐含值倒算见 9.2，风格档案的原始数据来自 9.6 的兑现度与修订轨迹台账。

### 9.4.1 指引保守度的多证据交叉判断：已实现额 + 产品周期 + 积压订单 + 超指引幅度 + 关键参数

- **方法要点**：用五条证据交叉验证指引是否保守，并据此预判后续是否还会再上调。
- **操作步骤 / 拆分口径 / 公式**：
  1. 已实现占比：上半年（或前几个季度）已实现额 ÷ 全年指引；并算出指引隐含的下半年（全年指引 − 已实现额），与上半年比较。
  2. 产品周期与 ASP：下半年是否有产品升级、ASP 提升，若有，则下半年不应低于上半年。
  3. 积压订单：收入大增的同时积压订单是否仍在增加。
  4. 超指引幅度：本季实际超出原季度指引多少。
  5. 关键驱动参数：驱动参数（如 GW 需求）上调而总额指引不动。
  6. 综合判断指引是否保守，并预判后续再上调的可能。
- **关键指标与数据来源**：上半年实际 / 全年指引、积压订单、实际超出原指引的幅度、驱动参数（GW）；来自公司指引、电话会披露的订单数据及一致预期。
- **判断标准**：五条证据中多数成立 → 判指引仍保守，后续有上调空间；其中“已实现额已占全年大头、积压订单仍增”最直接。即便判断保守，也要区分“公司保守”与“市场要的是超预期的展望”——保守但仍低于市场预期的数字，股价反应仍可能偏负面。
- **海豚案例**：
  - 戴尔（2026-05-29）：全年 AI 指引上调到 600 亿（原 500 亿），主流机构已到 650 亿。海豚君认为仍然保守：上半年 AI 收入就有 316 亿；下半年有 Rubin 升级，不会低于上半年；积压订单超过 500 亿且还在增加；本季已超原季度指引约 100 亿，所以全年收入指引后续还有机会再上调。
  - 博通（2026-06-04）：Anthropic 从 3GW 上调到 5GW，但 2027 年 AI 收入仍只说 1000 亿以上，管理层称会轻松超过，而主流机构已到 1300 亿以上，这个数明显保守，可市场要的是超预期的展望。
- **适用场景与注意事项**：适合需求旺盛、管理层惯于保守指引的公司。需有可量化的积压订单或关键参数；GW 类换算方法见 9.4.3。

### 9.4.2 指引解读五步法：按上限看、拆业务、费用率推利润、对照历史风格、看区间含义

- **方法要点**：把一份指引拆成五个动作，既判断保守度，又直接推出利润与趋势含义。
- **操作步骤 / 拆分口径 / 公式**：
  1. 默认按指引上限看，并考虑公司是否“故意压低预期”。
  2. 拆分业务指引，找出增速放缓的主因（如高基数下广告增速从 50% 降到 20%）。
  3. 结合费用率指引（如营销占收入提高约 2pct）反推利润增速。
  4. 参考管理层历史风格：自称“偏保守”时后续 beat 的可能性更大；过去分业务指引过保守的情况要纳入。
  5. 判断指引区间是否意味着止跌转正（如区间下限已回到 0%）。
- **关键指标与数据来源**：下季营收指引区间（上下限）、分业务指引、费用率指引、推算利润增速、历史指引与实际的偏差；数据来自公司指引、电话会及自建指引-实际偏差记录。
- **判断标准**：按上限看后仍显著低于预期 → 负面；利润指引靠费用率推算后增速低于收入增速 → 利润端比收入更弱；指引区间下限回到 0 以上 → 止跌转正信号；管理层自称“偏保守” → 后续 beat 概率大。
- **海豚案例**：
  - 携程《携程：监管“重锤”之后，还能“小而美”吗？》（2026-02-26）：下季营收指引按上限看约 17%；核心酒旅和票务大体持平，广告因高基数从 50%+ 降到约 20%；营销占收入可能提高约 2pct，推出调整后利润增长约 10% 出头。
  - 唯品会《唯品会：再现负增长？别怕，有 10% 股东回报救场》（2026-02-26）：下季营收指引 0%~5%，大概率止跌转正。
  - 快手《失望指引致暴跌，250 亿美金的快手能“捞”吗？》（2026-03-26）：公司评价自己的指引“偏保守”，言下之意后面 beat 的可能性更大。
  - 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：3%~8% 的指引是 2022 年后最低，利润可能更差。
- **适用场景与注意事项**：通用方法。需要积累管理层指引与实际的历史偏差记录；“按上限看”不适用于已知长期靠指引上限之外 beat 的公司，那类公司应改用 9.4.9 的 beat 幅度推算。

### 9.4.3 算力 GW 等物理量换算收入，检验指引保守度

- **方法要点**：管理层用客户算力需求（GW）等物理量描述远期订单时，用单位 GW 收入换算成隐含收入，与公司给出的收入口径比较，检验指引是否保守。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取管理层披露的客户 GW 数（分客户、分年度）。
  2. 隐含收入 = GW 数 × 单位 GW 收入。变体 A：按约 100 亿美元/GW 换算；变体 B：按单 GW 收入 150-200 亿美元换算，取区间；还可用公司自己给的“多年指引 ÷ GW 数”反推单 GW 价值（如 2300 亿 ÷ 20GW 约合 115 亿/GW）。
  3. 跟踪各客户 GW 数与总收入指引是否同步变化：单个客户 GW 上调而总额不动，说明指引偏保守。
  4. 隐含收入明显更高而公司不上调，会被解读为信心不足或藏业绩。
  5. 同时与机构对同一 GW 的收入预期比较，判断公司指引相对市场的位置。
- **关键指标与数据来源**：客户 GW 需求或出货口径、对应 AI 收入指引、单位 GW 收入、隐含收入、机构收入预期；来自电话会披露与机构预期。
- **判断标准**：GW 上调而收入总额不动 → 指引保守；隐含收入显著高于公司口径且迟迟不上调 → 信心不足/藏业绩，股价可能先跌；上调后仍低于机构对同一 GW 的收入预期 → 仍判为不及预期。
- **海豚案例**：
  - 博通（2026-03-05）：2027 年 6 大客户合计算力需求近 10GW，对应超 1000 亿美元 AI 收入（Anthropic 超 3GW，OpenAI 首款 XPU 超 1GW）。
  - 博通（2026-06-04）：Anthropic 上调到 5GW、OpenAI 到 1.3GW，总额仍只说 1000 亿以上，而主流机构已预期 1300 亿以上，判断这个数字明显保守。
  - 博通（2026-09-03）：上季给出 2027 财年出货 10GW，无论单 GW 按 150 亿还是 200 亿算，都明显超过 1000 亿，公司却维持“1000 亿以上”，财报后单日跌 12%；本季上调到 1150 亿，仍低于机构对 10GW 的 1300-1500 亿预期；2028 财年 20GW 对应 2300 亿，约合 115 亿/GW。
- **适用场景与注意事项**：适合用 GW 口径给订单或指引的 AI 芯片、服务器、数据中心公司，包括芯片、电力和数据中心。单位 GW 价值会因交付形式（芯片还是整机柜）、客户而不同，换算结果要给区间而非点值，并说明所用口径。

### 9.4.4 定性上调 vs 定量上调：管理层是否给出“定量”数字，作为信心强弱信号

- **方法要点**：需求明显强于前期时，看管理层是否把定性表述转成定量数字；只说“更强”而不给数字，或只抬下限不抬上限，被解读为对自身订单不够自信。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对比本季与上季全年指引数值及区间上下限的变化（上限/下限分别变了没有）。
  2. 记录管理层定性措辞（“需求继续走强”“增速会超过 30% 以上”“份额会提升”）与是否伴随定量数字。
  3. 拿客户 capex 增速等外部口径做对照，判断公司口径是否明显偏弱。
  4. 对照公司披露惯例（如按惯例三季度应给次年指引），本次是否缺席。
- **关键指标与数据来源**：全年指引数值及区间上下限变化；管理层定性措辞；惯例披露时点；客户 capex 增速。
- **判断标准**：定性强、定量缺席 → 对自身订单不够自信，判为偏弱（“哪怕是 40%”都没给）；只抬下限不抬上限 → 没有足够惊喜；惯例应给的次年指引缺席 → 市场不满。
- **海豚案例**：
  - 应用材料《泼天富贵在前，应用材料 AMAT 竟然怂了？》（2026-08-14）：管理层说需求继续走强、增速会超过“30% 以上”、年内份额会提升，但不给定量数字，“哪怕是 40%”；对比客户 capex 增速（全年 40% 以上），判断这个口径明显偏弱。
  - 阿斯麦《阿斯麦：光刻机产能也紧俏了…》（2026-10-14）：全年指引从 430-450 亿改为 440-450 亿，只抬下限、不抬上限；按惯例三季度应给次年指引，这次没给，被视为市场不满的地方。
- **适用场景与注意事项**：适用于有全年或长期口径的公司。要先了解公司的指引惯例（何时更新、给区间还是点值），否则容易把惯例性的“不给”误读为信号。

### 9.4.5 保守动机解码：全年指引不上调时，推断管理层为经营调整预留的空间

- **方法要点**：Q1 小幅超预期、全年指引却不上调时，不直接解读为基本面恶化，而是推断管理层是否在为后续经营调整（降价、免费功能）预留空间，并识别变现策略的反直觉影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录当季超预期幅度与全年指引（如订阅流水增速）是否上调。
  2. 列出管理层公开的后续策略（高端产品降价或下放到低付费层级、增加免费功能、延长免费试用期）。
  3. 判断策略对付费率、流水的短期与中期影响（如免费试用期从 7 天延长到 1 个月反而拉高付费）。
  4. 指出“财报季管理层惯常保守指引”会周期性压制股价，并判断本次不上调属于保守还是真实放缓。
- **关键指标与数据来源**：全年订阅流水指引增速、免费试用期、付费率；来自公司指引与产品策略披露。
- **判断标准**：超预期 + 不上调 + 存在明确的策略性让利计划 → 倾向解读为预留空间；若指引增速已降至成熟平台水平，则同时要看 9.4.6 的“真疲软”判断。
- **海豚案例**：
  - 多邻国（2026-05-05）：全年订阅流水增长 11% 未上调，引发市场对后续执行和增长放缓的担忧；海豚君认为是为 Max 降价、免费功能留出空间；新用户免费体验从 7 天延长到 1 个月，间接拉高付费。
- **适用场景与注意事项**：订阅模式公司的战略转型期。动机推断属于假设，需要后续季度用付费率、流水验证。

### 9.4.6 指引区间形态与清晰度：下季与全年同区间，以及“刻意保守”与“真疲软”的区分

- **方法要点**：从指引区间的“形状”读管理层对能见度的判断，并把刻意保守与真实疲软区分开。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看指引相对中长期目标（如长期 20% 流水增速）和一致预期的位置。
  2. 看形态：下一季度与全年放在同一区间（或数字相同），说明管理层对短期增长清晰度下降，干脆给偏谨慎的全年预期。
  3. 看区间宽窄与收窄方向：区间收窄到中部本身就是负面（对市场锚定在上沿的公司尤其如此，详见 9.4.10）。
  4. 区分刻意保守与真疲软：即便保守，若指引增速已降到成熟平台水平（约 10%），成长属性也被削弱，市场先杀估值是正常操作。
  5. 对利润率指引同样看趋势：利润率指引的措辞与形态见 9.5.4。
- **关键指标与数据来源**：季度/全年 Bookings 增速指引、利润率指引、一致预期、历史 beat 幅度。
- **判断标准**：同区间 → 能见度下降；指引增速相对上年断崖式下降（如 33% 到 10%-12%）→ 已非自然放缓；收入下调但盈利上调（减亏）→ 要拆开看。
- **海豚案例**：
  - Roblox（2026-05-01）：Q2 与全年 Bookings 指引都下调至 8%-12%，同区间反映清晰度下降；收入下调、盈利上调（减亏）。
  - 多邻国（2026-02-27）：Q1 Bookings 指引 +11%、全年 10%-12%（2025 年 33%），已非自然放缓；管理层一贯谨慎，但 10%-12% 已不属于高成长。
- **适用场景与注意事项**：适用于给出量化指引的美股公司。需要管理层多季度的指引与实际对比记录，才能判断“同区间”是新现象还是惯例。

### 9.4.7 管理层指引风格档案：分类、建立与更新

- **方法要点**：为每家公司建立一份“指引风格档案”，记录历次指引与实际结果的偏差，把管理层归入一贯保守、刻意压低、留容错空间、跟随市场一致预期、新管理层偏谨慎、个别板块过度保守或激进等类型；解读指引时先做风格修正，再与市场预期比较。
- **操作步骤 / 拆分口径 / 公式**：
  1. 每季记录：历次指引值及修订轨迹（含全年指引从初值到最新值的演变）、实际值与指引的偏离率、偏离发生在哪个板块。
  2. 归类（变体 A，风格类型）：一贯保守（实际总是超指引）、刻意压低、留容错空间（如价格未锁定时）、跟随市场一致预期（“先按市场预期来给”）、指引上限就是市场预期。
  3. 细分（变体 B，板块与管理层更替）：新管理层偏谨慎，实际表现应会更好；个别板块可能“过度保守”，要单独记录该板块的指引-实际偏差。
  4. 历次指引演变（变体 C）：把全年指引的修订序列当作档案，判断“谨慎型”公司后续的上调空间。
  5. 记录指引形态信号：例如下季指引与全年指引数字相同，代表能见度下降（见 9.4.6）。
  6. 应用规则：对保守型公司的指引 miss 降权、对指引 beat 打折；对指引一贯准确的公司，指引偏离要高度重视；指引低于预期时，对偏保守的公司打折解读。
- **关键指标与数据来源**：历史指引与实际的偏差、指引区间宽度与形态、指引区间上限/中值、历次指引值及修订轨迹、实际值与指引的偏离率；至少 4-8 个季度的“指引-实际”记录，来自历史业绩公告与电话会。
- **判断标准**：
  - 偏保守的公司：低于预期的指引打折解读，上调是大概率事件。
  - 指引一贯准确的公司：偏离即高度重视。
  - 指引上限才是市场预期的公司：按上限而不是中值与预期比较。
  - 推理链条：先用档案修正指引（还原“管理层真实预期”）→ 再与市场预期比较 → 再决定股价反应与估值取值。
- **海豚案例**：
  - 奈飞（2026-04-17）：当季超预期本身就隐含指引“一贯保守”。
  - Spotify（2026-04-28）：管理层倾向谨慎，不必过于担忧。
  - Reddit（2026-05-01）：一向保守，Reddit Max 上线后有望超指引。
  - Roblox（2026-05-01）：有压低指引的先例，但 Q2 与全年 Bookings 都调到 8-12%，说明下半年能见度下降。
  - 美光（2026-06-25）：价格未锁定时留“容错空间”。
  - 微软：个人计算一贯过于保守。
  - 甲骨文（2026-06-11）：FY27 EPS 与市场一致，推测公司“就先按市场预期来给了”。
  - 戴尔：全年仍保守，有望再上调。
  - Unity（2026-02-12、2026-05-08）：新管理层指引风格偏谨慎。
  - 微软（2026-01-29）：实际经营利润 383 亿，明显高于指引上限 367 亿。
  - 微软（2026-05-01）：个人计算板块指引过度保守，指引中值隐含 -10%，实际 -2.5%。
  - 甲骨文（2026-03-11）：指引上限才是市场预期。
  - 应用材料《Capex 狂飙在路上…》（2026-05-15）：AMAT 通常“相对谨慎”，设备全年增速指引从上季 20% 上调到本季 30%，判断后续可能再次上调。
  - 阿斯麦（2026-01-28）：全年指引 340-390 亿（同比 +4%-19%，相对机构 20%+ 偏保守）。
  - 阿斯麦（2026-04-15）：上调到 360-400 亿。
  - 阿斯麦（2026-10-14）：440-450 亿（上季 430-450 亿）；全年指引一路从 340-390 亿上调到 360-400 亿，再到 430-450 亿、440-450 亿。
- **适用场景与注意事项**：适用于所有给指引、且有可追溯指引历史的公司；需要多个季度的历史，新上市公司慎用；新管理层上任或宏观冲击期间，历史风格可能失效（先按“新管理层偏谨慎”重新起档）。

### 9.4.8 实际值在指引区间中的定位，再按指引风格修正

- **方法要点**：当期实际值先与公司前期指引比较，看落在区间的哪个位置、有没有超过上限，再结合管理层一贯的指引风格修正判断。这是风格档案的“逐季记账”动作，兑现度台账的方法见 9.6.2。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取上季给出的指引区间（收入、毛利率、经营利润、销量等），标记实际值落点：低于下限、下限附近、中部、上限、超出上限。
  2. 对一贯保守、每次都 beat 的公司，把“平淡指引”的真实含义下调负面程度；对指引贴上限的公司，落在上限也只是“达标”。
  3. 留意管理层在超预期季度之后是否仍不上调全年指引。
  4. 管理层更替（如换了新 CFO）时重新校准风格，不沿用旧档案。
- **关键指标与数据来源**：实际值在指引区间中的位置；历史 beat 率；业绩预告区间。
- **判断标准**：超出上限 → 经营明显好于指引；落在上限 → 达标；落在下限 → 偏弱（即便没 miss）；一贯保守的公司超预期之后仍不上调全年 → 要追问原因（见 9.4.5）。
- **海豚案例**：
  - 华住（2026-03-18）：收入 +8.3%，超出 2-6% 指引上限。
  - 蔚来（2026-03-10）：卖车毛利率 18.1% vs 指引 18%；经营利润 8 亿高于预告上限。
  - 理想（2026-03-12）：卖车毛利率 16.8%，落在 15.8-16.8% 指引上限。
  - 零跑（2026-03-16）：指引毛利率环比持平，实际 +0.5pct 至 15%。
  - 禾赛（2026-03-24）：收入 10 亿在 10-12 亿下限；毛利率 41% vs 指引 40%。
  - Roblox、AppLovin、Unity、多邻国：管理层“一贯偏保守”，实际可能更好。
  - 迪士尼（2026-02-02）：Q2 各业务 OI 目标略超一致预期，但全年指引不改。
- **适用场景与注意事项**：普遍适用。管理层更替时（如多邻国换了新 CFO）风格校准会失效；对季度指引区间很宽的公司，“落在区间中部”本身信息量有限。

### 9.4.9 用历史 beat 幅度推算真实增速与盈利假设

- **方法要点**：记录公司历史上实际超出指引上限的幅度，把“指引 + 惯例 beat 幅度”作为本季真实增速和估值盈利假设；若某季连惯例的 beat 都没有，就视为负面信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 为每家公司记录指引风格（保守、贴上限、惯例超预期）和历史 beat 幅度（如超上限 3-5%，或利润类 10-20%、5%）。
  2. 推算本季实际 ≈ 指引上限 × （1 + 历史 beat 幅度）；对利润类指引，估值盈利假设 ≈ 指引值 × （1 + beat 幅度）。
  3. 与一致预期比较：指引是否按惯例超过卖方预期；若没有，视为“观感不积极”。
  4. 对指引隐含的放缓，用 beat 惯例判断其可信度。
  5. 同时记录指引区间宽度、CEO 表述与指引的反差，辅助判断管理层风格。
  6. 提醒自己：保守指引会变相抬高买方预期，导致“beat 但不够”的股价反应。
- **关键指标与数据来源**：指引区间；历史实际值相对指引上限的超出幅度（3-5%、10-20% 或 5%）；指引区间宽度；CEO 表述与指引的反差。至少 3-4 个季度样本，最好 4-8 个季度。
- **判断标准**：本季指引按惯例会 beat 上限，则真实增速可往上推；指引符合卖方但未按惯例超预期 → 观感不积极；指引隐含明显放缓，但历史一贯 beat → 短期成长性仍可期待。
- **海豚案例**：
  - AppLovin（2026-05-07）：Q2 指引增长 55%，按惯例会 beat 指引上限 3-5%，增速有望与 Q1 持平。
  - Meta（2026-01-29）：Q1 指引高于卖方 515 亿，按一贯保守的风格，Q1 增速有望稳在 30% 以上。
  - Meta（2026-04-30）：Q2 指引符合卖方但未按惯例超预期，观感不积极。
  - Uber（2026-02-05）：近期实际表现普遍贴着指引上限。
  - Reddit（2026-02-06）：Q1 指引隐含增速 53%、明显放缓，但按一贯会 beat 的情况，短期成长性仍可期待。
  - Spotify（2026-04-29）：管理层一贯指引谨慎。
  - Palantir《再交硬核成绩单》（2026-02-03）：管理层常“口出狂言”，但指引偏保守，指引区间较窄；估值采用 26 年指引 EBIT 41 亿 × beat 10-20%。
  - Palantir《软件末日论汹涌》（2026-05-05）：按一贯 beat 习惯，Q2 仍有望加速。
  - Palantir《瑕疵修复》（2026-08-04）：“谨慎指引”已成惯用剧本，CEO 股东信的狂妄与财务指引的留有余地形成反差，估值用指引 +5%。
- **适用场景与注意事项**：有指引历史的公司，至少需要 3-4 个季度的样本，长期跟踪（4-8 个季度）更可靠。beat 幅度不是常数，高基数、宏观冲击期要降低外推；用于估值时，beat 幅度宜取偏保守的一档并注明。

### 9.4.10 对指引打折解读：保守型公司的指引 miss 降权与 beat 打折，以及市场锚定

- **方法要点**：统计公司过往实际与指引的偏离（是否总是 beat、beat 幅度），把指引视为下限或参考；管理层一贯保守时，指引“暴雷”的真实负面要打折，但要同时判断市场是否已把预期锚定在区间上沿。
- **操作步骤 / 拆分口径 / 公式**：
  1. 自建“指引-实际偏离数据库”：每季记录指引区间、中值、上沿与实际值。
  2. 判断指引在市场中的“锚定位置”：若市场按惯例把预期锚定在区间上沿以上，则指引区间收窄到中部本身就是负面。
  3. 判断市场是否“在意”指引：结合核心业务是否在加速；核心业务加速时，保守指引可以不在意。
  4. 判断公司是惯常保守还是已转为激进；从连续下调指引转回“指引谨慎、经营靠谱”的公司，估值情绪会修复。
  5. 保守型公司指引放缓不必悲观，但仍要判断放缓是否已不属于高成长（见 9.4.6）。
- **关键指标与数据来源**：历史实际 vs 指引偏离、指引中值/上沿、市场锚定值、指引上调次数。
- **判断标准**：一贯 beat 的公司只有 beat 幅度上的区别 → 指引仅作参考；指引收窄到中部、低于市场锚定上沿 → 未带来超预期；连续下修的公司 → 不适用“保守”逻辑，应转用 9.6.6 的业绩底判断。
- **海豚案例**：
  - 亚马逊（2026-07-31）：“亚马逊从来就是 Beat 指引，业绩只有 Beat 幅度上的区别”→ 指引仅做参考，市场也不在意。
  - 奈飞（2026-04-17）：Q1 超预期变相印证指引一贯保守 → 指引“暴雷”的负面要打折。
  - 奈飞（2026-07-17）：全年 507-517 亿收窄至 510-514 亿，资金按保守惯例预期定位 514 亿以上 → 未带来超预期。
  - 奈飞（2026-01-21）：管理层年度目标一般略偏保守。
  - Palantir（2026-08-04）：全年指引隐含下半年放缓，但谨慎指引是惯用剧本。
  - Uber（2026-08-05）：多数情况下实际好于指引，下季大概率与本季差异不大。
  - 新东方（2026-07-29）：回到“指引谨慎、经营靠谱、最终超预期”的状态。
  - 戴尔：全年指引仍偏保守，可能再上调。
  - Lululemon（2026-09-04）：全年指引连续第三次下修，属于“保守”逻辑不适用的反例。
- **适用场景与注意事项**：有长期指引记录、指引历史可追溯的公司；需自建指引-实际偏离数据库。要警惕“保守”标签被滥用：只要出现连续下修，就应转入 9.6 的轨迹分析。

### 9.4.11 估值取值修正：按指引上浮、取上限或中值、自建分层预测

- **方法要点**：估值时不机械采用公司指引，而按管理层风格与边际趋势决定取指引的哪一档（上限、中值、上浮一定比例，或干脆自建预测）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 变体 A（上浮）：对历史上倾向保守指引、且处在控费周期的公司，取略高于指引的值（利润率指引 8%，按 8.5% 算），并说明理由（控费提效的实际效果通常超出指引）；对一贯保守的公司，把指引上调一个比例（如 10%）作为海豚君预期。Palantir 的“指引 + beat 幅度”估值见 9.4.9。
  2. 变体 B（取上限 / 中值）：记录全年指引原值与调整值（集团收入、加盟收入分项），“指引全线上调”作为正面信号；据边际趋势决定取上限还是中值：行业渗透稳步修复、自身核心业务与 RevPAR 边际改善 → 取上限；同时按竞争加剧对费用假设上调修正。
  3. 变体 C（自建分层预测，用于指引激进或兑现记录差的公司）：不直接采用管理层指引，按产品层级自建预测——低、中、高端分别给出出货量，汇总成总量，再算 ASP 和收入，与管理层指引并列，给出差值与理由（下游需求、大客户自研挤压、高端放量进度），估值用这个更保守的预测，安全边际由此建立。
  4. 无论哪个变体，估值口径要在文中显式写明（用指引上限、指引 +10%、自建预测），便于后续滚动更新（见 12.6）。
- **关键指标与数据来源**：公司全年利润率指引、海豚君采用值、上年实际；集团收入增长指引、加盟收入增长指引；季度/全年 Bookings 增速指引、利润率指引、一致预期、历史 beat 幅度；分层出货量预测、总出货、ASP、收入，以及与指引的差。
- **判断标准**：指引风格保守 → 取值高于指引；边际趋势改善 → 取上限；指引激进或兑现差 → 取更保守的自建值，并披露与指引的差距。
- **海豚案例**：
  - 贝壳《“跪太久”贝壳》（2026-05-20）：公司全年调整后净利率指引 8%（25 年约 5%），“实际可能会更高”，按 8.5% 算，26 年调整后净利润约 75 亿。
  - Roblox（2026-02-06）：Q1 Bookings 指引 +50%-54%、全年 +22%-26%，均超一致预期，高于市场担心的低于长期 20%；管理层一贯保守，估值时按指引提高 10%。
  - 华住（2026-05-15）：按 2%-6% 指引取上限、小幅上调销售费用，得 2026 年经调净利润 56 亿（+14%）。
  - 华住（2026-08-17）：指引由收入 +2%-6%、加盟 +12%-16% 上调至 +4%-8%、+16%-20%。
  - 地平线（2026-09-01）：管理层指引出货 500 万、ASP 约 600 元、收入 50 亿；海豚君预测低端 190 万、中端 280 万（管理层说超过 300 万）、J6P 约 20 万（管理层说 HSD 30-40 万），合计约 490 万（+23.5%），ASP 524 元，收入 47 亿（+25%），并以此计算 P/S。
  - 地平线（2026-03-20）：管理层激进口径对应收入约 59 亿，海豚君保守口径约 53 亿。
- **适用场景与注意事项**：适用于给出年度指引的公司，需结合管理层历史指引风格；“上浮”只适合有历史兑现记录的公司，指引激进或兑现记录差的成长股（如地平线）应反向使用分层自建预测。

**相关方法（详见他节）**：用全年指引倒算隐含 Q4，并做新指引/旧指引/市场预期三方对比来判断保守度，详见 9.2。

**本节速查清单**

- [ ] 判断保守度时是否用了多证据交叉：已实现占比、产品周期/ASP、积压订单、超原指引幅度、关键驱动参数；
- [ ] 默认按指引上限看，并拆分业务指引、用费用率指引反推利润增速；
- [ ] 公司以 GW 等物理量给订单时，是否换算成隐含收入并给出区间，与公司收入口径和机构预期比较；
- [ ] 管理层是否把定性上调转成定量数字？只抬下限、不给惯例中的下一年指引要记为信号；
- [ ] 全年指引不上调时，是否识别出策略性预留空间，还是真实放缓；
- [ ] 下季与全年同区间、增速断崖、区间收窄到中部，是否记为能见度下降；
- [ ] 是否维护了“指引-实际偏离”档案（至少 4-8 个季度），并随管理层更替重新起档；
- [ ] 估值取值（上浮、上限、中值、自建预测）是否显式写明，并与指引风格一致。

## 9.5 措辞与管理层软信号

> 本节导读：指引的数字之外，管理层怎么说、没说什么、把定性说法换成什么数字，同样携带信息。本节讲文字层面的解读：措辞的跨季对比与同行强度对比、定性区间措辞到数值的换算、利润指引措辞的反向解读、把口头分项指引量化为可追踪数字、买方对定性表述的定量化、未提及事项与临场状态等软信号，以及把财务目标和资本开支计划当作信心信号。使用前提是保存每季电话会原话，建立“管理层历史表述库”；数值指引的保守度判断见 9.4，措辞对应的兑现检验见 9.6。

### 9.5.1 管理层措辞与口径的跨季度对比：把同一指标的表述排成序列

- **方法要点**：把管理层对同一指标（全年增速、新业务需求、涨价、capex）的表述按季度排成表，看是上调、维持、下修还是含糊其辞，并按固定规则解读。
- **操作步骤 / 拆分口径 / 公式**：
  1. 建立表述序列：每季记录管理层对同一指标的原话（如全年增速“30% 左右”→“30% 以上”→“40% 以上”→“44%”）。
  2. 标注每季变化：上调 / 维持 / 下修 / 含糊其辞。
  3. 按规则解读：
     - 连续小步上调，且管理层一贯谨慎 → 可信但不惊喜；
     - 隐含数据（如已披露的出货量）已明显超出，公司却不上调口径 → 解读为“信心不足”或“藏业绩”；
     - 新业务的需求“维持、未上调” → 偏负面；
     - “不更新、无法判断、不评论” → 等于没有提供可见性；
     - 首次官方确认某个机制 → 属于增量信息，但没有金额时，效果打折。
  4. 对照历史措辞风格（见 9.4.7），判断“小步上调”是惯例还是边际变化。
- **关键指标与数据来源**：全年增速措辞序列；新业务需求口径；首次披露事项；电话会逐字稿/PPT。
- **判断标准**：口径上调 + 数字高于预期 → 正面；隐含值明显高于口径而口径不变 → 信心不足/藏业绩，股价可能下跌；无金额的首次确认 → 增量信息有限。
- **海豚案例**：
  - 台积电全年增速措辞：“30% 左右”（2026-01-15）→“30% 以上”（2026-04-16）→“40% 以上”（2026-07-16）→“44%”（2026-10-15），海豚君评价为管理层一贯相对谨慎。
  - 博通（2026-09-03）：上季已给出 10GW 出货，收入口径仍维持“1000 亿以上”，被解读为信心不足，股价单日跌 12%；本季上调到 1150 亿，仍低于机构的 1300-1500 亿，被视为“藏业绩”。
  - ARM（2026-07-30）：AGI CPU 需求“超过 20 亿，维持未上调”。
  - 海力士（2026-07-29）：PPT 首次官方确认 LTA 含保证金，但电话会没有给出金额。
- **适用场景与注意事项**：通用。前提是建立管理层历史表述库（电话会纪要）；对同一指标的措辞要用原文对照，避免凭印象。周期股的供需措辞对比（美光）详见 9.3.6。

### 9.5.2 同行措辞强度对比：用“幅度 + 时间表”衡量议价能力与股价相对强弱

- **方法要点**：同一行业事项（如涨价），把几家同行的措辞强度并排对比，“明确幅度加时间表”强于“选择性”，由此判断各家的议价能力与股价相对强弱。
- **操作步骤 / 拆分口径 / 公式**：
  1. 选定同一事项（涨价、扩产、需求判断）。
  2. 列出各家公司的措辞要素：是否给出幅度、是否给出时间表、是否限定“选择性”。
  3. 将措辞强度排序：明确幅度 + 时间表 > 仅给方向 > “选择性”。
  4. 结合该排序判断议价能力强弱，并预判相关股价回调幅度的差异。
- **关键指标与数据来源**：同行涨价措辞（幅度、时间表）；各家业绩会表述。
- **判断标准**：措辞更强的一方议价能力更强，股价回调相对更少；措辞含糊的一方，涨价预期兑现度存疑。
- **海豚案例**：
  - 中芯 Q2'26（2026-08-13）：联电明确 8 寸涨价 25-40%、12 寸涨价 10-20%，格芯只说“下半年选择性涨价”，联电股价回调更少。
- **适用场景与注意事项**：适用于同赛道多家公司接连发布业绩的季度；需要同行表述来自同期电话会，避免跨季比较。同业财报的更多验证用法见 14.2。

### 9.5.3 全年指引措辞变化解码：低双位数 → 中低双位数，“约 35% 持平”→“至少 35%”

- **方法要点**：把本季与上季管理层对全年收入增速、利润率的定性措辞逐一对照，换算成数值区间，找到管理层给出的解释，并剥离下季指引中的汇率与事件影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 建立定性措辞→数值的换算：低双位数 ≈ 10% 出头；中低双位数 ≈ 15% 以下；“至少 35%”隐含上升空间，“大体持平约 35%”则无。
  2. 对比本季与上季措辞，判断是上调、维持还是下调，并换算出区间变化。
  3. 找管理层给出的解释（如变现率提升对冲投入）。
  4. 下季指引同时剥离汇率贡献和事件影响（地缘冲突等），还原内生增速。
- **关键指标与数据来源**：全年收入增速措辞、利润率措辞、下季指引中汇率贡献；业绩公告与电话会。
- **判断标准**：措辞从“低双位数”升到“中低双位数” → 全年增速上调；利润率措辞从“大体持平”改为“至少” → 利润率有上行空间；剔除汇率后增速退坡 → 内生放缓。
- **海豚案例**：
  - Airbnb（2026-05-08）：全年收入增速从低双位数上调到中低双位数；利润率从“大体持平约 35%”改为“至少 35%”；下季 GBV 名义增速退坡到 15% 以下，收入指引 14-16% 含 3pct 汇率。
- **适用场景与注意事项**：惯用定性区间措辞做指引的美股公司。换算区间是约定俗成的近似，需随公司惯例校准；汇率剔除口径详见 4.1。

### 9.5.4 利润指引措辞的反向解读：“不低于去年”即不增长，“与一致预期一致”不等于没问题

- **方法要点**：把利润类指引的措辞翻译成数值含义，并在指引数值与一致预期一致时，仍从趋势判断是否指向放缓。
- **操作步骤 / 拆分口径 / 公式**：
  1. 措辞翻译：承诺利润“不低于去年”，等于利润很可能同比不增长；若市场原本预期利润率继续提升，这就是大雷。
  2. 数值与预期一致时看趋势：收入和毛利润指引若指向高增长近一年后的不可避免放缓，对高增长高估值公司普遍意味着估值下调。
  3. 利润率指引维持在 mid-teens，意味着利润率不会恢复上行周期。
  4. 指引增速相对上年断崖式下降（33% 到 10%-12%），说明已非自然放缓；同时看管理层中期目标的增长路径是否清晰。
- **关键指标与数据来源**：GMV/收入/毛利润/FCF 利润率指引、利润底线承诺、一致预期、管理层中期目标。
- **判断标准**：利润底线承诺（不低于去年）+ 市场预期利润率上行 → 大雷；指引与预期一致但趋势放缓 → 高估值公司估值下调；利润率指引停在 mid-teens → 无上行周期；中期目标路径不清晰 → 难以提振信心。
- **海豚案例**：
  - Sea（2026-03-03）：管理层指引 26 年 GMV 增长约 25%，但只承诺 adj.EBITDA 不低于 25 年，而市场原预期利润率继续增长，因此算大雷。
  - Shopify（2026-05-06）：Q2 收入指引高 20s%、毛利润中 20s%、FCF 利润率约 15%，与彭博一致，但趋势指向增长放缓，FCF 利润率维持 mid-teens 意味着利润率不回到上行周期。
  - 多邻国（2026-02-27）：Q1 Bookings +11%，全年 10%-12%（2025 年 33%），EBITDA 利润率较 2025 年降 4pct；管理层中期目标是 2028 年前 DAU 达 1 亿（翻倍），但增长路径不清晰，未提振信仰。
- **适用场景与注意事项**：通用。需要掌握市场对利润率的原有预期，否则无法判断“不低于去年”是否构成负面；区间形态的补充判断见 9.4.6。

### 9.5.5 把管理层的分项口头指引量化成可追踪数字，并结合惯例判断保守程度

- **方法要点**：管理层在电话会上用口头形式给出分项指引（同比下滑超过某幅度、利润率“至少持平”、亏损“接近某水平”）时，把它们换算成具体数字，作为下个季度的检验基准，并结合管理层惯例判断保守程度。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录每一条口头分项指引（品类增速、分业务收入增速、利润率、新业务亏损）。
  2. 换算成可追踪的数字：如通电产品同比下滑超过 15%，据此推算商城收入约 -5%；新业务亏损仍接近 100 亿，据此推算全年至少 350 亿。
  3. 结合管理层惯例判断保守程度（如商城利润率“至少持平”，按惯例实际可能更好）。
  4. 下个季度把这些数字作为检验基准：若商城利润没有再大超预期，说明提利润的趋势遇到瓶颈。
- **关键指标与数据来源**：分项指引（通电增速、商城收入增速、利润率、新业务亏损）、历史 beat 惯例；业绩电话会。
- **判断标准**：实际利润显著高于“至少持平”的口径 → 惯例延续；表现平淡 → 趋势遇瓶颈；外卖等新业务减亏路径是否按环比持续，是否仍有全年亏损的“下限”。
- **海豚案例**：
  - 京东（2026-05-14）：二季度去年国补基数更高，加上内存涨价压制 3C 需求，通电产品下滑可能超过 15%，商城收入约 -5%；“下季度公司预期商城板块的利润率仍至少能持平（按京东的惯例实际表现很可能会更好些）”；外卖继续环比减亏，但新业务亏损仍接近 100 亿，据此推算全年至少 350 亿。
  - 京东（2026-08-13）：“过往商城板块的利润普遍远超预期和指引，本次相当平淡”。
- **适用场景与注意事项**：适用于管理层习惯给口头分项指引的中概公司。口头指引没有书面区间，需要在文中写明所用换算口径，避免事后争议。

### 9.5.6 管理层定性措辞追踪与买方定量化：远期 capex 的“预期分布”

- **方法要点**：公司对远期 capex 等不给定量指引时，追踪其定性措辞是否延续（如“increase significantly”），结合买方定量化后的预期分布（区间宽度、隐含增速）判断不确定性；同时记录全年指引的逐季上调路径，作为管理层态度的边际信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 逐季记录远期 capex 的定性措辞，看是否延续。
  2. 收集买方（机构）定量化的预期分布：区间宽度（下限到上限）、隐含增速。
  3. 以区间宽度衡量不确定性；区间越宽、越分散，说明定性措辞留给市场的想象空间越大。
  4. 把当年全年指引的逐季上调路径列出，作为管理层态度的边际信号。
  5. 财报后观察买方预期是否上调（如重心上移）。
- **关键指标与数据来源**：管理层措辞、指引上调路径、买方预期区间。
- **判断标准**：定性措辞延续且全年指引连续上调 → 态度偏积极；买方预期分布在财报后上移 → 措辞被市场理解为加码。
- **海豚案例**：
  - 谷歌：26 年 Capex 指引 1750-1850 亿（2026-02-05）→ 1800-1900 亿（2026-04-30）→ 1950-2050 亿（2026-07-23）；对 2027 年持续表述“increase significantly”，买方预期分布从不足 3000 亿到 4000 亿、增速 50%-100%，绩后上调到 3500 亿+（2026-07-27）。
- **适用场景与注意事项**：给定性远期指引的大型公司。买方预期分布随时间变化，引用时要注明时点；capex 本身的追踪与口径见 10.1。

### 9.5.7 软信号：管理层没说什么、如何解释、是否正面回应，以及临场状态

- **方法要点**：留意管理层“没说什么”（没上调某项指引、没提本财年目标、推迟到分析师日再讲）、对问题的解释（客户准备不足、订单延后）、是否正面回应竞争对手，甚至 CEO 的临场状态，把它们作为判断业务真实进展的辅助信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对比本季电话会与上季：哪些此前给过的指引项目这次消失了（未上调、未提）。
  2. 记录管理层把关键问题推迟的方式（推迟到分析师日、不评论）。
  3. 记录对问题的解释方式（客户准备不足、订单延后）及是否有具体数字或时点（如约 15 亿订单在二季度交付）。
  4. 记录是否正面回应竞争与供应商多元化问题。
  5. 记录发言质量与临场状态（如读错年份的发言稿），作为辅助而非决定性信号。
- **关键指标与数据来源**：电话会表述、指引项目的增删、管理层回应。
- **判断标准**：此前给过的项目这次未再提、未上调、未更新 → 视为不确定性上升；对订单延后的解释有明确交付时点 → 可信度较高；回避竞争问题或承认客户多元化 → 竞争压力信号。
- **海豚案例**：
  - Marvell（2026-08-28）：没有上调 ASIC 指引，也没提本财年的 ASIC 增长目标（上季给过 20% 以上），只维持 FY28 翻倍的展望，并表示会在 10 月 6 日分析师日给出情景区间，市场因此对谷歌能否带来增量打上问号。
  - 博通（2026-06-04）：一贯表现优秀的 CEO 陈福阳“不在状态”，开场把发言稿读成了 25 年二季度的内容，并承认客户在推进供应商多元化。
  - AMD（2026-02-04）：管理层解释是客户准备不足，约 15 亿订单将在二季度交付。
- **适用场景与注意事项**：通用，需要结合电话会纪要。软信号只能作为辅助：任何一条都不足以单独改变结论，需与订单、指引等硬指标交叉验证。

### 9.5.8 管理层财务目标与资本开支计划作为经营信心信号

- **方法要点**：管理层主动提出的财务目标（利润率底线、资本回报比例）和资本开支计划上调，可视为对经营面的信心表态。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录管理层主动提出的财务目标（如“每季度毛利率站稳 40% 以上”）及其作为“首要目标”的排序。
  2. 记录 capex 计划的修订（前值→新值）。
  3. 记录资本回报政策（长期目标、起始日期）。
  4. 判断目标的可达性：空泛的目标不能算信号；与当前利润率、订单是否匹配。
- **关键指标与数据来源**：毛利率目标；capex 计划修订；资本回报目标。
- **判断标准**：目标明确且可达（有时间表、有数字）→ 信心信号；capex 上调同时配套毛利率目标 → 对经营面的信心；仅有笼统表述 → 不算信号。
- **海豚案例**：
  - 英特尔《英特尔：CPU 涨价救场，翻身还得看代工？》（2026-07-24）：管理层把“每季度毛利率站稳 40% 以上”作为今年首要财务目标，并把 2026 年资本开支提到 200 亿美元以上（较此前提高约 30 亿），两点都被解读为对经营面的信心。
  - 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：宣布从 2026 年 12 月 9 日起增加资本回报，长期目标是向股东返还 100% 超额现金。
- **适用场景与注意事项**：适用于转型期或周期高点的公司。目标要结合可达性判断；资本回报的定量分析见 10.7，capex 追踪口径见 10.1。

**相关方法（详见他节）**：短期指引 vs 长期指引的权重分配，以及管理层措辞的跨季对比（美光），详见 9.3.6。

**本节速查清单**

- [ ] 是否保存了每季电话会原话，并把同一指标的措辞按季度排成序列；
- [ ] 隐含数据已明显超出而公司口径不动时，是否记为“信心不足/藏业绩”；
- [ ] 定性区间措辞（低双位数、中低双位数、至少 X%）是否换算成数值区间，并剥离汇率与事件影响；
- [ ] 利润指引的措辞（不低于去年、维持 mid-teens）是否翻译成“不增长/无上行周期”；
- [ ] 口头分项指引是否量化成数字，并作为下季检验基准；
- [ ] 同行对同一事项的措辞强度（幅度、时间表、选择性）是否并排对比；
- [ ] 本次电话会“没说什么”（缺席的指引项、推迟的回答）是否列出；
- [ ] 管理层的财务目标与 capex 计划是否可达，是否记为信心信号。

## 9.6 兑现度、修订轨迹与管理层可信度

> 本节导读：指引的价值取决于管理层说话算不算数。本节从历史维度评估指引：上季指引/口风与本季实际的对照、年度目标完成率与 run-rate 检验、多年展望与全年指引的逐季修订轨迹、指引下修“前科”、AI 与新业务里程碑台账、目标与产能口径的前后一致性，以及用管理层历史行为评估重大投入的可信度。它既是 9.4 风格档案的原始数据来源，也是估值折价与“业绩底”判断的依据。使用时务必维护历史指引台账：轨迹比单次数值更有信息量。

### 9.6.1 以上季管理层指引/口风为基准检验当季兑现度

- **方法要点**：把上季业绩会给出的指引或口风（毛利率、利润增速、大客户销量预期、全年 capex 走势、分业务指引）作为本季基准，对照实际，判断经营能力与指引可信度，并判断市场是否已提前计入（priced-in）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取上季电话会的指引/口风作为基准：毛利率区间、利润增速、大客户销量预期、全年 capex 口风、分业务 GTV 指引等。
  2. 对照本季实际并分档：贴合指引 → 符合预期；实际好于指引（如指引毛利率持平、实际上行）→ 降本等内生能力超预期；实际落在指引区间内 → 指引可信、经营可控；实际显著差于指引 → 追问是否因为公司对大客户等外部变量“过于乐观”。
  3. 剔除并表等因素后再与指引比较：剔除并表后与指引相比略差，则判质量偏弱。
  4. 对比公司指引与外资大行等机构预期的差距，判断指引偏乐观还是偏保守。
  5. 把公司给出的目标（如 UE 恢复至 1 元）直接作为估值情景参数；把管理层上季放出的口风（如全年 capex 大幅增长且逐季增加）作为本季 capex 判断的起点。
  6. 判断环比下滑等负面是否在上季财报会上已被指引（priced-in），避免对已知的环比下滑过度反应。
- **关键指标与数据来源**：上季指引值（毛利率区间、利润增速、销量目标）、本季实际值、偏离幅度、外资预期；上季电话会纪要。
- **判断标准**：贴合或好于指引 → 经营可控；显著差于指引 → 追问外部变量；已指引的环比下滑 → 视为 priced-in，不做额外负面。
- **海豚案例**：
  - 腾讯音乐《收编喜马拉雅，腾讯音乐能否打赢这场防守战？》（2026-05-12）：Q1 基本符合预期，即贴合上季指引，仅费用略少。
  - 腾讯音乐（2026-08-11）：剔除喜马拉雅后与 Q1 末指引整体差不多，核心订阅略差。
  - 美团《AI 分走战火》（2026-06-01）：公司指引到店 GTV<15%，头部外资已下调至高个位数，判断指引偏乐观；估值中 UE 按公司指引 1 元。
  - 腾讯《AI 撒钱火力全开？》（2026-08-12）：以管理层上季放出的口风（全年 Capex 大幅增长且逐季增加）作为本季 Capex 判断起点。
  - 零跑《出海神车…》（2026-03-16）：管理层指引 4Q25 毛利率环比持平，实际 +0.5pct 至 15%，略高于指引。
  - 零跑《利润指引大幅缩水…》（2026-08-25）：上季度指引 2Q26 毛利率 12-13%，实际 12.6%，符合指引。
  - 零跑《剑指百万…》（2026-05-15）：Q1 环比下滑已在 Q4 财报会上指引，因此判断已 priced-in。
  - 三花《“天灾人祸”一起来？》（2026-03-31）：公司此前对大客户特斯拉销量过于乐观，指引偏高，导致 Q4 不及预期。
- **适用场景与注意事项**：适用于有定期指引、管理层指引可信度较高的公司；应追踪管理层历史指引准确度，建立“指引-兑现”的历史记录以评估管理层是否保守。口风类基准需有电话会原文支撑。

### 9.6.2 指引台账：落点标注、年度目标完成率与管理层信誉

- **方法要点**：每季把公司此前给的销量、收入、毛利率、ASP 指引与本季实际值对照，标注落在区间的哪个位置，并对年度目标计算完成率；指引能兑现就增强对新指引的信任，连续 miss 或下调就在估值里打折。
- **操作步骤 / 拆分口径 / 公式**：
  1. 建立指引台账：季度销量、收入、毛利率、ASP 指引区间；年度销量和利润目标；预告区间。
  2. 标注落点：偏下、偏上、超出区间。
  3. 年度目标完成率 = 累计完成量 ÷ 年度目标（如 113%）；与指引隐含的 ASP、毛利率等关联指标同步核对。
  4. 能兑现 → 增强对新指引的信任；连续 miss 或下调 → 在估值里打折。
- **关键指标与数据来源**：季度销量、收入、毛利率指引区间；年度销量和利润目标；预告区间；公司公告与月度销量数据。
- **判断标准**：落在区间偏下 → 偏弱；实际打破指引隐含的 ASP → 价格端好于指引；半年度进展与全年目标差距过大 → 对全年目标降权。
- **海豚案例**：
  - 小鹏（2026-03-20）：4Q25 交付 11.6 万，低于指引 12.5-13.2 万；ASP 16.4 万，打破指引隐含的 15.5 万。
  - 小鹏（2026-05-28）：Q1 交付 6.3 万，处于指引 6.1-6.6 万偏下；毛利率 20.6%，指引 20%。
  - 吉利（2026-08-17）：Q2 毛利率 18.4%，环比 +0.9pct，符合“稳定或微增”的指引。
  - 吉利（2026-03-18）：2025 销量 302 万，超过上调后的 300 万；极氪新能源 168.8 万，对 150 万目标完成率 113%。
  - 地平线（2026-09-01）：1H26 产品收入 +15%，远低于全年 85% 的增长指引。
- **适用场景与注意事项**：通用。要保留历史指引台账；区间落点的风格解读见 9.4.8。

### 9.6.3 管理层承诺与前期表态逐一核对（含海豚君自身研究结论的检验）

- **方法要点**：把本季结果与管理层上季的承诺或解释（利润率低点在哪、延误的原因、是否有收入缺口）逐一对照，评估管理层可信度；同时检验海豚君自己前期深度研究的结论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出上季管理层的明确表态：利润率低点、延误原因、供应商供货时点、是否存在收入缺口。
  2. 逐条与本季实际对照：兑现、部分兑现或落空。
  3. 同时对照海豚君自己的深度研究判断，记录对错并复盘（见 13.3）。
  4. 以兑现情况调整对管理层表态的信任度。
- **关键指标与数据来源**：上季管理层表态、本季实际；电话会纪要。
- **判断标准**：延误问题在下季基本解决（营收达标甚至略好）→ 管理层说法兑现；利润率按“低点”预告回升 → 说法兑现；承诺的“无收入缺口”与持续供货吻合 → 可信。
- **海豚案例**：
  - CoreWeave（2026-02-27）：上季因供应商供货延后下调了四季度收入指引，本季营收 15.7 亿达标甚至略好，延误问题基本解决。
  - CoreWeave（2026-08-12）：管理层此前说一季度是利润率低点，二季度调整后经营利润率 5%（上季 1%），说法兑现；也符合海豚君深度研究中“AI 云利润率可能被普遍低估”的判断。
  - Marvell（2026-03-06）：仍为亚马逊供应 Trainium2.5，符合此前“无收入缺口”的表态。
- **适用场景与注意事项**：通用，需要结合电话会纪要建立管理层表态记录；对自身研究的检验要如实记录“被证伪”的情形，闭环方法见 13.3。

### 9.6.4 年度目标完成率 + 已知月度数据年化（run-rate），检验目标能否达成

- **方法要点**：把累计销量除以全年目标得到完成率，并结合季节性判断进度是否正常；把最近 1-2 个月或单季数据年化，与全年目标比较，判断能否超额完成。
- **操作步骤 / 拆分口径 / 公式**：
  1. 完成率 = 累计销量 ÷ 全年目标，并结合季节性判断进度（如 Q1 淡季 16.6% 属正常）。
  2. 年化：月销 × 12，季度 × 4（用最近 1-2 个月或单季）。
  3. 年化值 vs 全年目标：年化值已超过目标 → 大概率超额完成；远低于目标 → 完成度有待观察。
  4. 管理层上调或下调目标后，重新计算年化值与完成率。
  5. 调整季节性与新车型爬坡，必要时给出中性假设值。
- **关键指标与数据来源**：累计销量、全年目标、月度和季度销量、年化值；月度销量公告。
- **判断标准**：年化 > 目标 → 大概率超额完成；完成率偏低但处于淡季 → 正常；年化远低于目标 → 对目标存疑，改用中性假设。
- **海豚案例**：
  - 吉利（2026-03-18）：1-2 月出口 12.1 万（+129%），年化 73 万，对全年 64 万目标完成度高。
  - 吉利（2026-04-29）：Q1 出海 20.3 万，年化超过 80 万，对上调后的 75 万目标大概率超额完成；新能源完成率 16.6%。
  - 吉利（2026-08-17）：已出口 47.4 万，相当于上调后 92 万目标的一半；月销稳定在 10 万（年化近 120 万），海豚君预计 110 万。
  - 小鹏（2026-03-20）：1-2 月出海约 7000 辆，年化 4.2 万，对 9 万目标存疑。
  - 小鹏（2026-05-28）：1-4 月 1.75 万，中性假设 8 万。
  - Rivian（2026-05-01）：Q1 交付 1.03 万，只占全年目标 15.3%-16.6%。
- **适用场景与注意事项**：适合有月度数据、季节性可估的行业（汽车、出口等）。年化法需要调整季节性和新车型爬坡，月度数据的季节性校正见 3.4。

### 9.6.5 多年展望逐季修订轨迹的跟踪

- **方法要点**：把每季管理层对未来财年收入及分项增速的展望列成修订轨迹（前值→新值），对照财报前主流机构预期，判断上调幅度是否超出市场已有预期；哪一项上调、哪一项维持，反映增长来源的变化。
- **操作步骤 / 拆分口径 / 公式**：
  1. 建立多年展望台账：各财年收入展望、分业务增速展望，逐季记录前值→新值。
  2. 与财报前主流机构预期对比：上调后是否高于预期。
  3. 拆分上调来源：哪个业务上调、哪个维持，增长来源是否变化。
  4. 同步记录 capex、年底年化收入等配套指引的修订。
- **关键指标与数据来源**：各财年收入展望、分业务增速展望、主流机构预期；历次业绩会指引记录。
- **判断标准**：上调幅度超出机构预期 → 有惊喜；上调后仍与机构预期接近 → 只是略好；上调集中在单一业务 → 增长来源集中。
- **海豚案例**：
  - Marvell：FY27 收入展望从 100 亿上调到 110 亿（2026-03-06），再到 115 亿（2026-05-28）、120 亿（2026-08-28）；FY28 从 130 亿到 150 亿、165 亿、180 亿；光互连增速从 50% 以上提到 70% 以上，ASIC 维持 20% 以上，FY28 ASIC 翻倍、FY29 超 100 亿。2026-08-28 财报前，主流机构对 FY27/FY28 的预期是 118 亿/170~175 亿，所以这次上调只是略好。
  - CoreWeave（2026-05-08）：26 年底年化收入从 170~190 亿调到 180~190 亿，Capex 从 300~350 亿调到 310~350 亿。
  - 戴尔：FY27 收入从 1380~1420 亿上调到 1650~1690 亿，AI 收入从 500 亿上调到 600 亿。
- **适用场景与注意事项**：适合提供多年展望的公司，需要保存历次指引的记录；与机构预期的对比要用财报前一致预期而非财报后。

### 9.6.6 全年指引修订轨迹：上调/下修的次数、幅度与“业绩底”判断

- **方法要点**：把同一年度指引在每次财报中的变化列成轨迹，同时跟踪利润指引、分地区目标和下季利润率指引；连续多次下修意味着包括管理层在内没人能给出业绩底，操作上以观望为主；收入指引上调但利润释放不及预期，则警惕增长是“买来的”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出全年收入指引的修订序列（如 +2%~4% → -1%~0 → -5%~-7%）。
  2. 同步列出利润指引、下季营收与利润率指引，以及分地区增速目标（如中国增速目标）。
  3. 统计下修次数与累计幅度；下修是否仍在继续。
  4. 判断“业绩底”：连续下修 → 业绩底不明；上调收入的同时利润释放不及预期 → 增长质量存疑。
- **关键指标与数据来源**：全年收入指引、利润指引、下季营收与利润率指引、分地区目标；历次指引记录。
- **判断标准**：连续多次下修 → 观望为主，等待指引稳定；收入上调 + 利润不及预期 → 增长是买来的；分地区目标逐次降级 → 区域需求恶化。
- **海豚案例**：
  - Lululemon（2026-06-05）：全年收入从 +2%~4% 砍到 -1%~0，利润从个位数下滑扩大到 -15%~-17%。
  - Lululemon（2026-09-04）：全年收入砍到 -5%~-7%（第三次下修），3Q 营收 -10%~-11%、经营利润率约 6.5%，中国目标从两成降到高个位数，结论是业绩底不明、观望为主。
  - 亚朵（2026-08-21）：全年收入指引从 +24%~28% 上调到 +30%，但零售拖累利润释放不及预期。
- **适用场景与注意事项**：适用于给全年指引的公司。轨迹比单次数值更有信息量；与 9.4.10 配合，连续下修的公司不适用“保守”逻辑。

### 9.6.7 全年营收、利润率、FCF 多线指引的逐季上调或下调幅度跟踪

- **方法要点**：每季记录全年指引多条线（营收、GAAP 经营利润率、FCF 增长）的变化幅度，用“营收微调上、利润率下调”识别 AI 投入持续压制利润率；下季指引则与市场预期逐项比较。
- **操作步骤 / 拆分口径 / 公式**：
  1. 为全年指引建立多线台账：营收指引上调幅度（如不到 0.5%）、GAAP 经营利润率指引下调幅度、FCF 增长指引变化。
  2. 判断线与线之间的关系：营收微调上 + 利润率下调 → AI 投入持续压制利润率。
  3. 下季指引逐项对比市场预期：营收、cRPO、EPS。
  4. 判断连续两季指引方向是否一致。
- **关键指标与数据来源**：全年营收指引、GAAP 经营利润率指引、FCF 增长指引、下季营收、cRPO、EPS 指引。
- **判断标准**：营收小幅上调 + 利润率/FCF 下调 → 利润端承压；下季营收略高于预期、cRPO 增速回升 → 需求端边际改善，但不抵消利润率下调。
- **海豚案例**：
  - Salesforce《既没增长也没利润》（2026-05-28）：27 财年 GAAP 经营利润率指引从 20.9% 下调至 20.6%，FCF 增长指引从 9-10% 大幅下调至 4-5%；下季营收 +10%（降 2pct，不及预期），cRPO +13%，GAAP EPS 中值 1.75 美元（同比下滑超 10%，预期持平）。
  - Salesforce《“AI 替代论”证伪？》（2026-08-27）：全年营收指引上调不到 0.5%，GAAP 经营利润率再下调 0.8pct，FCF 维持 4-5%；下季营收 +11.7%（略高于预期），cRPO +14%。
- **适用场景与注意事项**：通用。cRPO 等前瞻指标的拆解见 6.1、6.2。

### 9.6.8 指引调整轨迹与管理层“前科”：用作估值折价依据

- **方法要点**：把管理层历次指引的口径变化（软性指引下调、全年收入或出货下修、贷款额度下调、FCF 转正门槛提高）按时间串起来；有多次下调“前科”的公司，即使给出超预期指引，也提示“谨慎乐观、不为远期大饼给高溢价”；维持指引的公司则评估达成路径。
- **操作步骤 / 拆分口径 / 公式**：
  1. 按时间串联历次指引的口径变化（软性指引、全年收入/出货、融资额度、FCF 转正门槛）。
  2. 计算每次调整的幅度（如增速 57% 降到 33%，出货 540-550 万降到 500 万）。
  3. 统计“前科”次数，作为估值折价依据：多次下调 → 不给远期大饼高溢价。
  4. 对维持指引的公司，评估达成路径（如利润增速高于收入增速靠开源节流：精简销管、集采、套保、材料替代）。
- **关键指标与数据来源**：历次指引值、调整幅度、管理层措辞；公司历次业绩会。
- **判断标准**：多次下调 → 谨慎乐观，不为远期给高溢价；维持指引且有明确降本路径 → 可信度较高；门槛被提高（如 FCF 转正所需产能上调）→ 盈利拐点后移。
- **海豚案例**：
  - 三花（2026-08-27）：年初 20% 软性利润指引下调到 15% 后维持；管理层表示汽零往两位数、制冷往约 10% 增长，利润增速高于收入，靠精简销管、集采、套保、材料替代。
  - 地平线（2026-09-01）：收入指引从 59 亿下修到 50 亿（增速 57% 降到 33%），出货从 540-550 万下修到 500 万。
  - Rivian（2026-02-13）：过去多次下调指引，所以保持谨慎乐观。
  - Rivian（2026-05-01）：DOE 贷款从 66 亿下调到 45 亿，FCF 转正门槛提高到 51.5 万辆产能。
- **适用场景与注意事项**：通用。需要维护指引历史台账；FCF 转正的产能门槛与政策性贷款额度变化的跟踪详见 10.5。

### 9.6.9 AI 与新业务里程碑台账：逐条核对上季承诺，判定是否“跳票”

- **方法要点**：为靠远期新业务估值的公司建一张里程碑台账，逐条核对上季度电话会给出的时间点，本季是否再次确认、推迟，还是只画了更大的饼；没确认就视为不确定性上升，作为股价承压依据。
- **操作步骤 / 拆分口径 / 公式**：
  1. 台账建立：对每个核心项目（如 Optimus、Robotaxi、FSD、Cybercab）记录上季给出的时间点（V3 展示年中、7 月下旬到 8 月开始生产、二厂 2027 年夏投产、年底十余州无监督、Q4 向消费者推无监督 FSD）。
  2. 本季逐条核对：再次确认 / 推迟 / 未再提及 / 只给更大的远期目标。
  3. 记录管理层自己说的“报表贡献时点”（如 Robotaxi 在 2026 年不会产生重大贡献，锚定 2027 年）。
  4. 观察扩张方式的措辞变化（如 Robotaxi 从“逐城市”改为“整州覆盖”并要求 99% 可靠性）是否暗示延后。
  5. 没确认即视为不确定性上升，作为股价承压的依据；里程碑未推迟则判断“进展在预期内”。
- **关键指标与数据来源**：里程碑时间节点、量产时间、产能目标、城市或州覆盖数、报表贡献时点；电话会纪要。
- **判断标准**：全部再次确认 → AI 进展在预期内；时间点推迟 → “AI 宏图又跳票”；时间点未再确认，只给更大的远期目标 → 不确定性上升。
- **海豚案例**：
  - 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：判断 AI 进展在预期内、没有推迟（Cybercab 4 月量产，Optimus V3 数月内发布，2026 年底量产）。
  - 特斯拉《造车罕见回血…》（2026-04-23）：Optimus V3 展示推到年中，Robotaxi 报表贡献推到 2027 年，要等 V15，被定为“AI 宏图又跳票”。
  - 特斯拉《造车硬抗…》（2026-07-23）：上季给出的 Optimus 关键节点都没有再确认，只给了 Optimus 4 的 1000 万台/年目标；Robotaxi 从“逐城市”改为“整州覆盖”，要求 99% 可靠性，暗示扩张延后；Cybercab 只试生产，无量产指引；无监督 FSD 的时间点也没确认。
- **适用场景与注意事项**：适用于估值主要来自远期新业务、靠里程碑驱动的公司。里程碑台账必须逐季更新；新业务里程碑的通用追踪见 6.5。

### 9.6.10 管理层前后表述与产能口径的一致性核对：识别目标上调、推迟或口径变化

- **方法要点**：逐季记录管理层的目标和产能口径，新一季出现变化时明确标注是上调、推迟还是口径变化；目标上调是正面信号，推迟或下修要提示风险。
- **操作步骤 / 拆分口径 / 公式**：
  1. 逐季记录：出口目标、工厂投产时间、储能产能、机器人产能、海外本土产能等。
  2. 标注变化类型：上调（出口目标 150→170-180 万）；推迟（匈牙利工厂从 Q2 推到下半年，Optimus V3 推到年中）；口径变化（储能产能 80GWh→60GWh，巴西产能 30 万→一期 15 万）。
  3. 对口径变化要问清是真实下修还是统计口径调整（目标值同时变化，如 100→66）。
  4. 上调视为正面，推迟或下修提示风险。
- **关键指标与数据来源**：各类目标、产能、时间节点的前后对比；历次业绩会与公告。
- **判断标准**：目标上调 → 正面；时间推迟 → 风险；口径缩小 → 隐含下修，需单独估算对业绩的影响。
- **海豚案例**：
  - 比亚迪《王座失守…》（2026-03-28）vs《国内卷单价…》（2026-08-29）：匈牙利工厂从 2026Q2 投产推到 2026 年下半年；巴西从规划扩到 30 万辆改为一期 15 万；海外本土产能从 51 万到 70 万；出口目标从 150-160 万上调到 170-180 万。
  - 特斯拉（2026-01-29 vs 2026-04-23）：储能产能口径从 80GWh（目标 100）变成 60GWh（目标 66）；Optimus V3 从“数月内”推到“年中”。
- **适用场景与注意事项**：通用，特别适用于管理层经常给出远期目标的公司。需维护逐季目标记录表，避免凭记忆比较。

### 9.6.11 以管理层历史行为记录评估重大投入与指引的可信度

- **方法要点**：判断激进投入是否盲投时，引用管理层历史：是否有已被印证过的盲目投入“黑历史”；一贯靠谱的管理层喊出的数字视为深思熟虑，从而提升对需求的信心；新任管理层信任未建立时，资金需反复验证；CEO 继任人选也纳入关注。
- **操作步骤 / 拆分口径 / 公式**：
  1. 回溯管理层的历史资本配置记录：有无盲目投入后被证伪的先例（横向对照同行，如 Meta vs 谷歌）。
  2. 回溯指引兑现率：是否一贯靠谱。
  3. 一贯靠谱 → 把其喊出的重大投入数字视为深思熟虑，由此提升对终端需求的信心。
  4. 新任管理层 → 信任未建立，要求资金反复验证。
  5. 跟踪管理层变动与继任人选，评估胜任概率。
- **关键指标与数据来源**：历史资本配置记录、指引兑现率、管理层变动。
- **判断标准**：无黑历史 + 指引一贯靠谱 → 提升对重大投入的容忍度；新管理层 → 信任度需要时间；继任人选胜任概率高 → 降低治理风险。
- **海豚案例**：
  - 谷歌（2026-02-05）：“不是有黑历史的 Meta”，管理层较少盲投 → 对谷歌 AI 实际需求提高信心。
  - 奈飞（2026-07-17）：基于对管理层一贯靠谱的信任，长期资金可逐步关注。
  - 迪士尼（2026-02-03）：Iger 继任是重要关注点，Josh D'Amaro 胜任概率较高。
  - 迪士尼（2026-08-05）：对新领导班子的信任度还没完全建立。
- **适用场景与注意事项**：重大资本配置或管理层变动期。属于定性判断，需与 9.6.1、9.6.2 的兑现率数据配合使用；capex 的回报评估见 10.2。

**相关方法（详见他节）**：年内指引多次上修并拆出汇率对 EPS 指引的贡献，详见 4.1；年度出货指引兑现率检验并拆解下一年出货指引的区域结构，详见 16.3；跟踪指引上修及首次给出的量化目标，详见 9.7.9；对照前期指引看兑现度再按管理层风格修正，详见 9.4.8；分项指引上调追踪与估值时取指引上限/中值的判断条件，详见 9.4.11。

**本节速查清单**

- [ ] 是否维护了历史指引台账（指引区间、实际值、落点位置、年度目标完成率）；
- [ ] 本季实际是否逐项对照了上季指引/口风，并分档（贴合 / 好于 / 显著差于）；
- [ ] 已被上季指引的环比下滑是否已判为 priced-in；
- [ ] 年度目标是否做了完成率与 run-rate 年化检验，并校正季节性与新车型爬坡；
- [ ] 多年展望与全年指引是否列成“前值→新值”轨迹，并与财报前机构预期对比；
- [ ] 下修次数与累计幅度是否统计，连续下修的公司是否已转入“业绩底不明、观望”模式；
- [ ] 营收、利润率、FCF 等多线指引是否同时跟踪，是否识别“营收微调上、利润率下调”；
- [ ] 里程碑台账是否逐条核对上季承诺（确认 / 推迟 / 未再提及）；
- [ ] 目标与产能口径的前后变化（上调 / 推迟 / 口径变化）是否标注；
- [ ] 重大投入的可信度是否参考了管理层历史行为与继任情况。

## 9.7 长期目标与多年展望

> 本节导读：多年展望和长期目标是成长股、转型股和投入期业务的估值锚。本节讲如何把多年累计展望当作预期锚并同口径换算、如何用行业需求反推长期指引的含义、如何把 TAM 与关键配比上调转化为空间重估、如何把多年目标逐年展开、何时把中长期定性目标降权而对短期量化指引做年化检验，以及利润率目标进度、盈利转正时点、长期趋势锚点和首次量化目标的跟踪。与 9.3（期限权重）、9.6（修订轨迹）配合，目标值本身进入估值时见第 12 章。

### 9.7.1 把管理层多年累计展望当作预期锚，并做同口径换算

- **方法要点**：管理层给出多年累计收入展望后，它就成为市场预期的“锚”：锚已给出时，短期季度小超预期对股价几乎没有提振，市场转而关注锚之后的年份；新展望出来时要与旧展望同口径换算后比较。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录管理层多年累计收入/出货展望（累计值、期限、口径）。
  2. 新展望与旧展望做同口径换算：例如把“FY28 营收 +70%”换算回“2025-2027 自然年 Blackwell + Rubin 累计收入”，相当于从 1 万亿上调到 1.2-1.3 万亿。
  3. 出货量展望换算成收入：如 2000 万颗约等于 5000 亿美元。
  4. 与下一财年增速指引、市场原预期对比（如 FY28 +70% 以上 vs 市场约 40%）。
  5. 锚已给出时，把关注点转向“锚之后的年份”；短期财报的小超预期不作为股价催化的主要依据。
- **关键指标与数据来源**：管理层多年累计收入/出货展望、下一财年增速指引、市场原预期；公司大会（如 GTC）与业绩会披露。
- **判断标准**：新展望同口径上调且高于市场预期 → 直接带动股价；展望已被锚定、当季只是小幅超预期 → 对股价几乎无提振；首次给出下一年指引且显著高于预期 → 盘后反转（从 -3% 拉到 +5% 附近）。
- **海豚案例**：
  - 英伟达（2026-02-26）：Blackwell + Rubin 到 2026 年底累计 2000 万颗，约对应 5000 亿美元收入，所以市场不担心 FY27。
  - 英伟达（2026-05-21）：GTC 上调为 2025-2027 累计 1 万亿（原 5000 亿），“短期财报的小超预期，不会对公司股价带来明显的提振”。
  - 英伟达（2026-08-27）：首次给出 FY28 营收 +70% 以上（市场约 40%），同口径对应 1.2-1.3 万亿，盘后股价从 -3% 拉到 +5% 附近。
- **适用场景与注意事项**：适用于给出多年目标的公司（芯片、电动车、平台）。注意自然年/财年、是否含特定地区（如不含中国）等口径差异，换算前先对齐口径。

### 9.7.2 长期指引反推：“若不上调，则意味着……”

- **方法要点**：把公司长期复合增速指引与行业需求增速（如 CSP Capex）比较，推演矛盾背后的两种可能——行业需求会回落，或公司份额在下滑；也可把长期收入目标换算成隐含市场份额。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取公司长期 CAGR 指引（如 2026~2030 年 AI 收入复合增速 20~25%）。
  2. 取行业需求增速（如四大 CSP Capex 增速）。
  3. 若公司指引低于行业增速，推演：长期指引不上调意味着 ① 行业 capex 增速之后会明显回落，或 ② 公司在行业支出中的份额会下滑。
  4. 隐含市场份额 = 公司长期收入目标 ÷ 行业对应市场规模（如 ASIC 100 亿约对应 20% 份额）。
  5. 同时看分业务长期复合增速，推演业务占比变化（如 ISG 占比会继续走高）。
- **关键指标与数据来源**：公司长期 CAGR 指引、行业需求增速、隐含市场份额；分业务长期增速。
- **判断标准**：长期指引明显低于行业需求增速 → 要么行业回落，要么份额下滑，两者都是风险提示；隐含份额与公司此前的份额目标吻合 → 长期指引自洽。
- **海豚案例**：
  - 戴尔（2026-02-27）：此前指引 2026~2030 年 AI 收入复合增速 20~25%，而四大 CSP Capex +62%；如果后续不上调，意味着 ① Capex 增速之后会明显回落，或 ② 戴尔在 AI Capex 中的份额会下滑；同时长期 ISG 复合增速 11~14%、CSG 2~3%，ISG 占比会继续走高。
  - Marvell（2026-05-28）：FY29 定制 ASIC 收入超 100 亿，大致对应此前 20% 市场份额的长期指引。
- **适用场景与注意事项**：适合给出长期框架性指引的公司。行业需求增速要用同口径、同期限的数据；反推只给出两种可能，需用后续季度数据判断哪一种在发生。

### 9.7.3 长期指引、TAM 与关键比例上调的解读（空间重估）

- **方法要点**：管理层上调长期可服务市场（TAM）、关键配比（如 CPU:GPU）、长期利润率目标、多年 capex 预算时，把这类信息视为对行业或业务空间的重估，用来解释估值溢价，并传导到相关公司。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录管理层 TAM、配比、长期利润率目标、多年 capex 预算的前后对比。
  2. 判断是空间重估（TAM、配比上调）还是短期改善（利润率突破某一水平）。
  3. 区分中短期指引（利润率突破 10%）和长期目标（20%）：长期目标不变但中短期预期上移，要分别记录。
  4. 把 TAM 上调传导到相关公司：如 AMD 上调服务器 CPU TAM，会抬高市场对整个 CPU 行业和 ARM 的预期。
  5. 对多年 capex 预算的修订与此前指引比较（如超过此前 3 年约 3800 亿指引，约 1300 亿/年）。
- **关键指标与数据来源**：TAM（前后对比）、CPU:GPU 配比、长期利润率目标、多年 capex 预算。
- **判断标准**：TAM、配比上调 → 行业/业务空间重估，可解释估值溢价；长期目标不变而中短期预期上调 → 阶段性改善；TAM 属管理层口径，要审慎看待。
- **海豚案例**：
  - AMD《CPU“狂飙”》（2026-05-06）：管理层把 CPU 可服务市场从 600 亿上调到 1200 亿美元，CPU/GPU 配比提升到 1:1，意味着 CPU 在 AI 中的地位不低于 GPU。
  - ARM《ARM：“短期波动”难掩锋芒》（2026-05-07）：引用 AMD 的 TAM 上调，认为这会提升市场对 CPU 行业的整体期待。
  - 阿里《阿里：电商退位，AI 上位》（2026-05-14）：云利润率预期从 9% 突破到 10% 以上，长期目标 20% 不变；capex 将超过此前 3 年约 3800 亿的指引（约 1300 亿/年）。
- **适用场景与注意事项**：适合成长行业龙头。TAM 属于管理层口径，需要审慎对待；传导到同业时要说明逻辑，避免把单一公司的口径直接套用。

### 9.7.4 管理层多年目标的逐年推算（如亏损每年减半）

- **方法要点**：把管理层的多年目标（亏损每年减半、某年盈利）按上年实际基数逐年展开，得到各年隐含值，作为估值输入和后续跟踪的基准；同时提示目标成立的前提，以及每季财报后公司是否“基本维持”了该指引。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取上年实际基数（如 26 财年闪购实际亏损近 900 亿）。
  2. 按目标逐年展开：亏损每年减半 → 27 财年约 400 多亿 → 28 财年约 200 多亿 → 29 财年实现盈利。
  3. 写明成立前提（竞争格局保持稳定）。
  4. 每季检查公司是否“基本维持”该指引。
  5. 把该年隐含值直接用于估值（如即时零售亏损取 430 亿）。
- **关键指标与数据来源**：上年实际亏损、减亏比例、各年隐含亏损、盈利年份；公司指引与财报。
- **判断标准**：实际减亏进度快于（或持平于）隐含值 → 目标可信；竞争格局恶化（前提被破坏）→ 目标下修风险；公司明确“基本维持” → 估值输入可沿用。
- **海豚案例**：
  - 阿里《阿里：电商退位，AI 上位》（2026-05-14）：公司指引 27-28 财年闪购亏损每年减半；按 26 财年实际亏损近 900 亿推算，27 财年约 400 多亿，28 财年约 200 多亿，29 财年实现盈利，本季后公司基本维持该指引；估值中即时零售亏损取 430 亿。
- **适用场景与注意事项**：适合有明确多年目标的投入期业务。“逐年减半”的目标成立依赖竞争格局稳定，需要在文中明确前提。

### 9.7.5 中长期定性指引暂不定价，短期量化指引用最新季度年化检验

- **方法要点**：两条规则——管理层的多年 CAGR 类定性指引在市场变化大时暂时忽略、不立即定价；全年量化指引用最新季度年化检验，并看一致预期在区间中的位置，判断继续 beat 的概率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 规则一：对多年 CAGR 类定性指引（如多年 CAGR 40%），在市场环境变化大时暂时忽略、不立即定价，因为按去年经验这类指引不代表短期一定达标。
  2. 规则二：全年量化指引（如其他收入 1.5-1.7 亿，同比 +46%）用最新季度 × 4 年化，检验是否落入区间。
  3. 对比一致预期在区间中的位置（贴下限还是上限），位置越靠下限，继续 beat 的概率越大。
  4. 看环比增速的变化：环比放缓（如 +29% 放缓到 +13%）则对年化外推要降权。
- **关键指标与数据来源**：多年 CAGR 指引、全年收入指引区间、最新季度年化值、一致预期在区间中的位置、环比增速。
- **判断标准**：年化值落入区间且一致预期贴下限 → 有继续 beat 的可能；环比放缓 → 仍需结合外部催化（如立法进展）判断；多年定性 CAGR → 暂不定价。
- **海豚案例**：
  - Circle《Circle：用业绩回击唱衰…》（2026-02-25）：管理层维持 USDC 多年 CAGR 40%，略超市场预期，海豚君建议暂且忽略；其他收入全年指引 1.5-1.7 亿，一致预期贴合下限；Q4 其他收入 3700 万，环比 +29%，认为有继续 beat 的可能。
  - Circle《Circle：稀烂行情…》（2026-05-11）：Q1 其他收入 4200 万，环比 +13%（放缓），年化 1.67 亿正好落入区间；CLARITY 法案推进下仍有望 beat。
- **适用场景与注意事项**：适用于所有给出多层次指引的公司。年化检验同样要做季节性调整（见 3.4），并与 9.6.4 的 run-rate 方法互通。

### 9.7.6 中期利润率目标的完成进度追踪（做季节性校正）

- **方法要点**：记录管理层的中期利润率目标，每季对照实际进度，并用季节性校正判断趋势是否仍在提升，结合指引估计全年靠近目标的速度。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录中期目标（如经调整 EBITDA 利润率 50%）。
  2. 每季记录实际 Adj.EBITDA 利润率，并与同季历史比较（Q1 淡季利润率通常低于 Q4），不与相邻季直接比。
  3. 判断趋势：同季同比与环比（环比扣除季节性）是否仍在提升。
  4. 结合下季利润率指引（淡季指引通常更低）与全年节奏，估计靠近目标的速度。
- **关键指标与数据来源**：Adj.EBITDA 利润率、中期目标、季节性；公司公告与指引。
- **判断标准**：淡季利润率回落属季节性波动，整体仍在提升 → 趋势未破；环比提升（如 +2pct）→ 向目标靠近。
- **海豚案例**：
  - Reddit（2026-02-06）：中期目标 50%，Q4 已达 45%；Q1 指引约 36%（淡季）。
  - Reddit（2026-05-01）：Q1 为 40%，属于季节性波动，整体仍在提升。
  - Reddit（2026-07-31）：Q2 环比 +2pct 至 42.6%。
- **适用场景与注意事项**：设定了中期利润率目标的公司。季节性校正需要至少一年历史；中期目标的达成时点不宜盲目外推。

### 9.7.7 EBITDA 与 FCF 转正时点的指引：与关键里程碑挂钩

- **方法要点**：把盈利拐点（Adj.EBITDA 转正、FCF 转正）的管理层表述与核心项目里程碑挂钩，判断里程碑延期对盈利时间线的连锁影响，以及 FCF 滞后的原因（提前生产后续箭体、扩张库存）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录管理层对 Adj.EBITDA 转正、FCF 转正的表述（如“首次成功试飞后的下一季度”、“还需 18-24 个月”）。
  2. 把每一个转正时点与前置里程碑挂钩（如首飞）。
  3. 里程碑延期 → 盈利时点顺延，推算新的转正时间窗口。
  4. 分析 FCF 滞后于 EBITDA 的原因：预生产投入、库存扩张。
- **关键指标与数据来源**：Adj.EBITDA 转正时点、FCF 转正时点、库存或预生产投入；电话会。
- **判断标准**：里程碑（如首飞）直接决定盈利拐点；里程碑延期 → EBITDA 与 FCF 转正均顺延；FCF 滞后属于主动投入而非经营恶化，要与库存、预生产数据交叉验证。
- **海豚案例**：
  - Rocket Lab《中子号或延期》（2026-08-11）：CFO 称 Neutron 首次成功试飞后的下一季度 Adj.EBITDA 有望转正，FCF 转正还需 18-24 个月，原因是需提前生产后续箭体并扩张发射库存，因此首飞直接决定盈利拐点。
- **适用场景与注意事项**：适用于亏损期的成长公司。FCF 转正的产能门槛与融资额度变化的类似跟踪详见 10.5。

### 9.7.8 把管理层长期趋势锚点当作市场最低心理门槛

- **方法要点**：管理层连续多个季度给出某指标的趋势锚点（如环比增长 mid-teens / 15%），资金会把它当作最低心理门槛：没达到就是明确 miss，超出才算超预期；还要据此推算分部整体的门槛。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录管理层连续多个季度给出的趋势锚点（指标、数值、期限）。
  2. 把它设为最低门槛：低于锚点 → miss；超出 → 超预期。
  3. 推算分部整体门槛：扣除剥离业务和低增速业务的影响后，战略业务需要达到多少增速才能使整体达标（如战略 Grow 需环比 12% 以上）。
  4. 对比实际：是否超出锚点（如“mid-teens”）。
- **关键指标与数据来源**：管理层趋势指引、子产品/分部环比；历次业绩会。
- **判断标准**：实际 ≥ 锚点 → 达标；实际显著高于锚点 → 超预期；低于锚点 → 明确 miss。
- **海豚案例**：
  - Unity（2026-08-07）：过去连续四个季度管理层给出 Vector 环比约 15%，推算战略 Grow 需环比 12% 以上；实际 Vector Q2/Q3 环比 +23%/+20%，超出“mid-teens”指引。
- **适用场景与注意事项**：管理层习惯给长期趋势指引的公司。锚点如果多次被调整，则不再适用，应转入 9.6.5 的修订轨迹分析。

### 9.7.9 跟踪指引上修与首次给出的量化目标

- **方法要点**：公司在业绩改善时上修指引，并首次给出明确的利润率目标，被视为管理层信心提升；记录各类指引与首次给出的量化目标，作为后续季度的验证基准。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录下季同店指引、全年同店指引、首次给出的利润率目标及长期门店目标。
  2. 标注“首次给出”和“上修”事项，视为信心信号。
  3. 把每一项数字写入台账，作为后续季度的验证基准。
  4. 对长期门店目标等远期数字，拆分地区贡献（如国际 4 万家中中国 1.5 万-2 万家）并评估现实性。
- **关键指标与数据来源**：下季同店指引、全年同店指引、Non-GAAP 经营利润率目标、长期门店数目标；公司业绩公告与电话会。
- **判断标准**：业绩改善 + 指引上修 + 首次给出利润率目标 → 管理层信心提升；目标可验证（有数字、有时间）→ 可作为后续检验基准。
- **海豚案例**：
  - 星巴克《星巴克：走出至暗时刻…》（2026-07-30）：Q4 美国同店指引 6.5% 以上；全年美国同店略高于 6.0%；首次给出 Non-GAAP 经营利润率目标高于 11.0%；国际长期目标 4 万家门店（约当前两倍），其中中国 1.5 万-2 万家。
- **适用场景与注意事项**：适用于所有提供指引的公司。首次给出的目标需要后续季度验证；长期门店数这类远期目标可达性要单独评估。

**相关方法（详见他节）**：FCF 转正的产能门槛，以及政策性贷款额度变化的跟踪，详见 10.5；由年度或中长期指引倒推隐含节奏和增速、偏定性的长期目标降权，详见 9.2。

**本节速查清单**

- [ ] 是否把多年累计展望设为预期锚，并把新旧展望换算到同一口径（自然年/财年、是否含特定地区）；
- [ ] 长期 CAGR 指引与行业需求增速对比后，是否写出“若不上调则意味着……”的两种可能；
- [ ] TAM、关键配比、长期利润率目标的上调是否区分为空间重估，并注明属管理层口径；
- [ ] 多年目标（如亏损减半）是否按上年实际基数逐年展开，并标注成立前提；
- [ ] 中长期定性指引是否暂不定价，短期量化指引是否用最新季度年化检验并看一致预期位置；
- [ ] 中期利润率目标进度是否做了季节性校正（淡旺季不直接比）；
- [ ] 盈利转正时点是否与关键里程碑挂钩，里程碑延期的连锁影响是否估算；
- [ ] 管理层连续给出的趋势锚点是否被设为最低门槛，并推算了分部整体门槛；
- [ ] 首次给出的量化目标是否写入台账，供后续季度验证。

## 9.8 指引归因与论据检验

> 本节导读：指引一旦偏弱、被下修或节奏后置，管理层都会给出一套解释；本节解决的是“这套解释站不站得住、真正的原因是什么、是暂时的还是结构的”。海豚君的做法是不直接采信归因，而是用业务敞口、可量化的结构数据、量价拆分、固定原因清单和历史走势去逐条检验，再给出自己的独立判断。使用时机是指引或电话会解释与预期差同时出现之后：先用 9.1 把指引对比预期，用 9.2 倒算隐含量价，再回到本节做归因；指引的保守度与管理层风格见 9.4，措辞信号见 9.5，兑现度与修订轨迹见 9.6，量价拆分的通用口径见 5.1，毛利率的驱动归因见 7.1，投入产出与 ROI 的通用框架见 10.2。

**选用速览**

| 遇到的情形 | 优先使用的方法 |
|---|---|
| 管理层把疲弱指引归咎于宏观、地缘、天气等外部因素 | 9.8.1 业务敞口检验；9.8.2 结构数据反证 |
| 管理层为回应质疑，推出新口径指标或新披露 | 9.8.3 新披露指标检验 |
| 收入指引低于预期，要分清是量的问题还是价的问题 | 9.8.4 量价归因 |
| 销量指引低于预期，要给出分类归因并判断暂时/结构 | 9.8.5 原因清单；9.8.6 新车周期反推 |
| 新车上市季，指引环比无增量或超预期，要判断新车订单强弱 | 9.8.6 新车周期反推 |
| 毛利率或利润指引低于预期、被下修、上修幅度不够 | 9.8.7 保守指引反推；9.8.8 下修分解；9.8.9 上修不及预期拆解 |
| 管理层承诺毛利率维持、转正，或把兑现押在后半年 | 9.8.10 毛利率论据评估；9.8.11 后置节奏风险；9.8.12 前低后高基数；9.8.13 全年不变的季度节奏 |
| 外部事件改变了经营前提，但指引没跟着调整 | 9.8.14 指引未随事件调整的预期差 |
| 管理层系统性解释投入回报（资本开支、AI 投入） | 9.8.15 投产比框架压力测试 |

### 9.8.1 用业务敞口检验管理层对指引疲弱的归因

- **方法要点**：管理层把疲弱指引归因于宏观或地缘事件时，不直接采信，而是逐条核对公司在这些因素上的实际敞口，把“短期外因”和“内部结构性因素”分开，并把分析重心放到后者。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出管理层给出的全部归因清单（指引说明与电话会里点名的每一个外部或内部原因）。
  2. 对每个外部因素找对应的敞口数据：分区域业务占比、受该因素影响的业务占收入的比重。例如“中东局势”要看公司在中东的业务占比，“油价”要看成本或需求对油价的传导程度。
  3. 判断每个冲击的持续时间：短期冲击（事件性、价格波动性）与持续性变量（监管、竞争格局）分开处理。
  4. 把敞口小、持续时间短的外因归入“短期外因”，把监管、变现方式变化、合规调整等归入“内部结构性因素”，并估算这类因素影响的业务在收入中的占比。
  5. 把分析的主要篇幅和估值判断的权重分配给内部结构性因素，外因只作为扰动项处理。
- **关键指标与数据来源**：管理层归因清单（电话会、指引说明）；分区域业务占比（财报分地区收入或业务披露）；冲击持续时间（事件类型与历史经验）；监管影响业务的收入占比（分业务收入及披露）。
- **判断标准**：
  - 公司在外因上的敞口有限、冲击是短期性的，则这条归因不足以解释指引的疲弱，不应据此给出“很快恢复”的判断。
  - 受监管影响的业务占比高、且影响尚未落完，则这是需要定价的核心变量，指引偏弱的真实含义要从这里读。
  - 海豚君的推理链：管理层归因 → 逐条查敞口 → 外因敞口有限且短期 → 真正决定指引的是内部结构性因素 → 分析重心放在后者。
- **海豚案例**：
  - 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：公司把 3%~8% 的指引归因于美伊冲突推高油价和机票价格、中东旅游需求下降、火车票加速包监管、合规调整。海豚君认为地缘是短期冲击，而且携程海外业务集中在东亚和东南亚，中东影响有限；关键问题仍是监管对国内酒旅和火车票变现的影响，把分析重心放在这一点上。
- **适用场景与注意事项**：适用于管理层归因可能偏向外因的场景。前提是了解公司的地区分布和业务敞口，否则无法判断一条归因是否站得住；敞口小只说明该外因不是主因，并不排除它有边际影响，结论上以“短期、有限”定性即可。与 9.8.2 配合：9.8.1 用敞口检验外部归因，9.8.2 用结构数据检验内部归因。

### 9.8.2 用可量化的结构数据反证管理层归因

- **方法要点**：对管理层的每一条解释，海豚君都找一个可量化的对应指标，检验方向是否一致；不一致就判定解释不充分，并给出自己的归因。它适用于管理层倾向把坏消息说成“一次性或结构性”的场景。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出管理层给出的原因（例如高基数、低价区占比提升、年底返利结算）。
  2. 为每条原因找到对应的结构数据（例如国内出货占比、低价区占比、海外收入占比）。
  3. 对比该数据在本季与前几季均值的变化，看方向是否符合管理层的说法。
  4. 如果结构没有恶化，价格或毛利仍然恶化，就推断管理层的解释不能成立，问题出在实质性的竞争环境上，而不是结构扰动。
  5. 给出自己的归因，并说明依据的是哪一组结构数据。
- **关键指标与数据来源**：国内出货占比（单季 vs 前三季度均值）、海外营收占比、单价与毛利率方向。数据来自财报的分区域、分产品披露与电话会说明。
- **判断标准**：
  - 管理层所说的结构变化真实存在，且幅度足以解释价格或毛利变化，则解释成立。
  - 结构数据没有朝管理层所述方向变动，价格与毛利却急剧恶化，则解释不充分，推断为实质性的竞争问题。
  - 海豚君的推理链：管理层原因 → 对应结构数据 → 与前几季均值对比 → 结构未恶化而价格、毛利恶化 → 判定为竞争传导，而非一次性因素。
- **海豚案例**：
  - 阳光电源《平地起惊雷》（2026-04-01）：管理层把单价下滑归因于 Q3 英国大项目带来的高基数、Q4 国内及美洲低价区占比提升、年底售后与返利结算。海豚君指出 Q4 国内出货占比 <14%，并不高于前三季度均值 17%，海外收入占比还不降反升，单价和毛利却急剧恶化，因此判断是国内内卷向海外传导，而不是管理层所说的结构性因素。
- **适用场景与注意事项**：通用，尤其适用于管理层倾向把坏消息解释为“一次性或结构性”的场景。前提是公司披露足够的结构数据（区域、产品、客户）；若披露不足，需要借助第 14 章的外部数据交叉验证。

### 9.8.3 检验管理层为回应质疑而新披露的指标

- **方法要点**：管理层面对质疑（做空报告、市场担忧）时常推出新的口径或新披露的指标来自证；海豚君不直接接受，而是回看这个指标的历史走势，检验它能否真正打消疑虑。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录管理层在电话会上的回应逻辑（例如强调业务多元化、存量贷款池成熟后新签发的公允价值溢价对总池影响变小）。
  2. 找出新披露的指标及其当季数值，对照它所对应的传统口径（例如现金收入对应去掉服务权公允价值变动后的经调整净收入），看两者是否一致。
  3. 回看历史：构造“新指标 / 传统口径”的比值序列（如现金收入 / 经调整收入），观察它在业务不同阶段的方向。
  4. 把比值的历史变化与业务节奏对照（新业务快速起量时、增速放缓时），判断该指标是否只是在业务增长好的时候看起来健康。
  5. 给出结论：指标能否解决核心疑虑；若不能，指出唯一的出路是什么（例如用更高的收入增速、更高比例的费用型收入去稀释存疑部分）。
- **关键指标与数据来源**：现金收入、经调整净收入、现金收入 / 确认收入比、费用型收入占比；数据来自财报、电话会和历史披露。
- **判断标准**：
  - 新指标与传统口径长期一致、不随业务节奏波动，才可以作为打消疑虑的证据。
  - 新指标在增长好时高于确认收入、增长放缓时又低于经调整收入，说明它受业务增速节奏影响，不能完全打消对利润虚高部分的顾虑。
  - 海豚君的推理链：质疑 → 管理层新披露指标 → 回看历史比值 → 比值随增速起伏 → 不能打消顾虑 → 只有靠更高的收入增速（尤其是导流、支付、投资等费用型业务）稀释公允价值调节在总收入中的比重。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：针对浑水的指控，管理层在 Q1 电话会强调业务多元化，并称存量贷款池成熟后，新签发的公允价值溢价对总池影响变小，同时首次披露现金收入（cash revenue），Q1 为 11 亿，与经调整净收入（去掉服务权公允价值变动）一致。海豚君回看历史“现金收入 / 经调整收入”：LPB（贷款平台业务）推出并快速起量时，现金收入高于确认收入；Q1 LPB 增速明显放缓时，又低于经调整收入。结论是该指标不能完全打消资金对利润虚高部分的顾虑，唯一出路是用更高的收入增速，尤其是 LPB 导流、支付、投资等费用型业务，来稀释公允价值调节在总收入中的比重。
- **适用场景与注意事项**：适合管理层被质疑后推出新口径的场景；必须回溯历史数据检验其一致性，仅凭单季数值一致不足以下结论；新指标往往没有长历史，要说明样本局限。

### 9.8.4 指引 miss 的量价归因：区分“需求问题”与“结构/定价问题”

- **方法要点**：收入指引低于预期时，不把缺口笼统地归为“需求弱”，而是分别拿隐含销量和隐含 ASP 与市场预期比较，判断缺口来自量还是来自价。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取收入指引（中值）与市场预期，计算收入缺口。
  2. 取销量指引与市场预期，判断销量缺口。
  3. 隐含 ASP = 收入指引 ÷ 销量指引；与市场预期 ASP 比较，得到价格缺口。若收入指引口径包含服务及其他收入，应先剥离非整车部分，再折算整车 ASP。
  4. 定性：
     - 缺口主要来自量 → 指向需求或订单问题；
     - 缺口主要来自价 → 指向结构下沉或降价问题；
     - 反向情形：销量 miss 但收入 beat → 结构在向上（ASP 高于预期）。
  5. 若公司只给收入指引，需借助月度数据或行业数据推算量，再作上述拆分（口径细节见 9.2、5.1）。
- **关键指标与数据来源**：收入指引与市场预期、销量指引与市场预期、隐含 ASP 与市场预期 ASP；数据来自公司指引、彭博或卖方一致预期、月度交付数据。
- **判断标准**：
  - 销量指引与预期基本持平、收入指引却大幅低于预期，缺口全部来自价格，定性为“结构下沉或降价”。
  - 销量指引大幅低于预期、隐含 ASP 反而高于上季，缺口的根本原因是量。
  - 销量 miss 同时隐含 ASP 高于预期，收入未跟随恶化，说明产品结构上移。
- **海豚案例**：
  - 理想 1Q26（2026-03-12）：销量指引 8.5-9 万，与预期 8.8 万基本持平，收入指引却大幅低于预期，完全是价格问题（ASP 降到 22.2 万）。
  - 理想 3Q26（2026-08-26）：收入指引 266-280 亿，对比预期 327 亿，“根本原因仍是销量指引大幅 miss 预期”，隐含 ASP 反而环比 +2 万。
  - 蔚来 1Q26（2026-03-10）：销量指引 8-8.3 万对比预期 8.9 万为 miss，收入却 beat，判断结构向上。
  - 蔚来 3Q26（2026-09-01）：收入指引 333-340.5 亿，略低于预期 344 亿，主因销量；隐含 ASP 27.8-28 万，高于市场预期 25.2 万。
- **适用场景与注意事项**：适用于同时给出量与收入双指引的公司（如整车）。如果只给收入指引，必须先通过月度或行业数据推算量。拆出缺口后，销量缺口的具体原因继续用 9.8.5 的原因清单展开。

### 9.8.5 销量指引不及预期的原因归纳清单（暂时性 vs 结构性）

- **方法要点**：海豚君用一套固定清单来归因销量指引不及预期，再把原因分成暂时性与结构性，从而决定是“下季有望反转”还是“压力仍大”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 按固定清单逐项排查：
     - a. 供应链扰动（零部件短缺、断供）；
     - b. 产品空窗期，或用户等老车型换代而持币观望；
     - c. 竞品分流，以及自家新车分流老车；
     - d. 宏观政策（购置税退坡、地方补贴尚未落地）；
     - e. 季节性（春节淡季）。
  2. 每一项都要给出可验证的证据，例如交付周期、断供公告、竞品发布与价格、政策时间表、新车上市时间，不做泛泛而谈。
  3. 归类：供给、空窗、政策窗口属于暂时性；竞争（竞品围剿、自家分流）、车型老化属于结构性。
  4. 据此给出结论：以暂时性为主，则判断下季有望反转；以结构性为主，则判断压力仍大。
- **关键指标与数据来源**：销量指引、市场预期、供应链事件（公告、减产量）、新车上市时间、竞品发布、政策时间表、同比月销数据。
- **判断标准**：
  - 暂时性：供给扰动可以消除、空窗期随新车上市结束、政策窗口随补贴落地而恢复，则下季有望反转。
  - 结构性：新品订单一般且分流自家车型、同价格带被竞品围剿、车型老化，则压力持续，不能指望下季自动修复。
  - 多项因素叠加时，要说明哪一项是主因，哪几项是催化；暂时性与结构性并存时，按占比定性。
- **海豚案例**：
  - 蔚来 1Q26（2026-03-10）：指引 8-8.3 万低于预期 8.9 万，归因于 ES8 音响芯片短缺、L90 用户观望 L80、一季度新车空窗期、购置税退坡；判断为暂时性，“二季度销量有望迎来反转”。
  - 理想 3Q26（2026-08-26）：7 月 i6 大灯零部件临时断供，减产约 4000 台；L9 拉动尚未释放；L6 订单一般并分流 i6；25-35 万价格带受竞品围剿，叠加购置税退坡；判断为结构性。
  - 理想（2026-03-12）：老款 L 系列 1-2 月同比 -67%，归因于车型过老等换代、竞品推出更大更便宜的车、自家纯电 i6 和 i8 的挤压、行业层面购置税退坡。
- **适用场景与注意事项**：适用于所有销量驱动型公司的指引点评。归因必须有可验证的证据，避免泛泛而谈；暂时性与结构性的判断要写进后续的跟踪点（如下季交付周期、断供是否解除），以便 9.6 做兑现度回看。

### 9.8.6 新车周期下“指引无环比增量”反推新车订单强弱

- **方法要点**：新车上市季度，销量指引相对上季的增量（或无增量）本身就是订单强弱的信号：用指引的环比变化，加上老车型交付周期的变化，反推新车订单储备是充足还是平淡。
- **操作步骤 / 拆分口径 / 公式**：
  1. 梳理新车上市和交付时间表（本季上市了哪些车型、何时开始交付），以及已公布的月销数据，列出指引隐含的月均销量（如 5、6 月隐含月销）。
  2. 比较销量指引的环比变化，并与市场预期对比。
  3. 反推推理链：
     - 新车上市季，销量指引环比持平或下滑、并低于市场预期 → 新车订单平淡，或新车分流了自家老车型（增量被自家分流或在手订单消耗抵消）；
     - 指引超预期，同时老爆款的交付周期在缩短（存量订单正在消化）→ 老车不可能提供增量，增量只能来自新车 → 新车订单储备充足、交付节奏跟得上。
  4. 在下结论前，先排除供给扰动（如零部件断供、产能受限），否则会把供给问题误读成需求问题。
  5. 与 9.8.5 的原因清单并用，判断环比无增量究竟是订单问题、分流问题还是供给问题。
- **关键指标与数据来源**：季度销量指引的环比变化、新车上市和交付时间表、老车型交付周期（提车周期）、已公布月销、市场预期；数据来自指引、月度交付公告与电话会。
- **判断标准**：
  - 指引环比无增量（或环比下滑）且低于预期，叠加新车上市，判断新车订单平淡、或新车分流自家老车。
  - 指引超预期，且老爆款交付周期缩短，判断新车订单储备充足。
  - 供给扰动未排除前，不得把无增量直接解读为需求弱。
- **海豚案例**：
  - 理想 2Q26（2026-05-29）：L9 在 5 月 15 日上市，5、6 月隐含月销反而环比下滑，判断换代 L9 订单平淡、i6 在手订单在消耗。
  - 理想 3Q26（2026-08-26）：L9、L8、L6 改款加 i8 改款同期上市，指引 9.5-10 万，对比二季度 9.8 万没有增量，远低于市场预期 12.2 万，判断 L6 和 L8 订单平淡、L6 分流 i6。
  - 蔚来 2Q26（2026-05-21）：ES8 提车周期从 3 月的 4-5 周缩短到 4 月的 2-4 周，指引 11-11.5 万超预期 10.6 万，判断 ES9 和 L80 订单储备充足、交付节奏跟得上。
  - 蔚来 3Q26（2026-09-01）：ES9、L80、ES8 五座三款新车同期，指引 10.8-11 万与二季度持平，低于预期 12.3 万，判断三款新车订单一般。
- **适用场景与注意事项**：适用于产品周期驱动的公司，如整车、手机、游戏新品。必须排除产能和供应链约束；区分“需求不足”与“产能瓶颈”的方法，可参考大定、在手订单与历史爆款的对比，详见 16.1。

### 9.8.7 从保守（偏低）指引反推经营含义

- **方法要点**：指引低于市场预期时，不停留在“指引弱”，而是找出背后的经营原因，并判断是暂时性还是趋势性，决定能否容忍。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对比毛利率指引与收入指引相对预期的偏差，分别列出：毛利率指引低于预期多少个百分点、收入指引持平或低于预期多少。
  2. 针对毛利率偏低，在以下原因里定位：良率偏低、新制程爬坡稀释、终端需求弱、一贯保守的指引风格。
  3. 针对收入偏平，在以下原因里定位：下游备货谨慎（如手机）、传统业务需求偏弱。
  4. 判断属性：暂时性因素（良率爬坡、新制程初期稀释）→ 可以“阶段性容忍”；趋势性因素（需求持续偏弱）→ 需要下调预期。
  5. 若是管理层一贯保守，需要结合历史兑现情况校准（见 9.4、9.6）。
  6. 下季毛利率或 Adj. EBITDA 指引对比预期并用收入结构推演原因的做法，详见 9.1。
- **关键指标与数据来源**：毛利率指引相对预期、收入指引相对预期、良率、新制程占比；数据来自指引、电话会与买方预期。
- **判断标准**：
  - 毛利率指引低于预期，且原因是先进制程良率低或新制程爬坡，属于暂时性稀释；只要战略性产品（如 AI 芯片）能量产，这部分毛利率损失可以容忍。
  - 收入指引持平反映下游备货谨慎或传统需求偏弱，要与终端需求数据交叉验证。
  - 趋势性原因不能用“一贯保守”来搪塞，需要在后续季度验证。
- **海豚案例**：
  - 中芯（2026-02-10）：Q1 毛利率指引 18-20%，低于预期 21%，说明先进制程良率仍低；收入指引持平，说明手机备货谨慎、传统半导体需求偏弱；海豚君认为只要 AI 芯片能量产，这部分毛利率损失可以“阶段性容忍”。
  - 台积电（2026-07-16）：Q3 毛利率指引 65-67%，低于买方 67.5%，原因是 2nm 量产爬坡。
  - 台积电（2026-10-15）：Q4 毛利率指引 65-67%，原因是 2nm 初期侵蚀。
- **适用场景与注意事项**：通用，尤其是制造类公司在新制程、新产品爬坡期。注意把“偏低指引”按原因拆成可跟踪的项目（良率、占比、需求），并在下一季检验是否恢复。

### 9.8.8 利润指引下修的分解：下修项、对冲项与短期/中长期分层

- **方法要点**：管理层下修全年利润或毛利率指引时，把下修拆成“原因 + 对冲项 + 自己的独立预期 + 分层结论”，帮助区分“一次性冲击”和“趋势恶化”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 量化下修幅度：净利润指引（如 50 → 30 亿）、全年毛利率（如 14-15% → 13-14%）、整车毛利率（如 10-11%）。
  2. 拆解原因：原材料涨价（如电池、存储）；出口占比提升而出口车型单价低带来的结构影响。
  3. 同时列出上调项：如出口销量指引上调，说明增量业务仍在，下修只是毛利与利润的质量问题。
  4. 给出自己的独立预期：如海豚君对销量的预期（95-100 万）低于公司指引（105-110 万），说明对公司销量也有折扣。
  5. 结论分层：短期，市场需要消化盈利下修、股价承压；中长期，看降本与出海是否抵消；
  6. 列出催化剂，作为后续验证节点（新平台技术、旺季、放量车型的毛利率目标等）。
  7. 分业务指引下修的全年口径解读，详见 9.1。
- **关键指标与数据来源**：净利润指引、毛利率指引（整体 / 整车）、出口指引、海豚君独立销量预期；数据来自公司指引、电话会、行业月度销量与出口数据。
- **判断标准**：
  - 下修原因是成本端的一次性上涨（原材料）或结构变动（出口占比提升）、且有明确的上调对冲项，倾向判断为“盈利承压的暂时性冲击”。
  - 下修原因指向竞争恶化、定价能力下降，且没有对冲项，判断为趋势恶化。
  - 海豚君的推理链：量化下修 → 拆原因（成本 + 结构）→ 看对冲项（出口上调）→ 给独立预期（低于公司指引）→ 短期承压、中长期看降本与出海 → 列催化剂。
- **海豚案例**：
  - 零跑《利润指引大幅缩水…》（2026-08-25）：净利润指引从 50 亿下调至约 30 亿，全年毛利率从 14-15% 下调到 13-14%，整车毛利率 10-11%；同时出口指引从 15 万上调至 20 万，2027 年 35-40 万；海豚君保守预计 2026 年销量 95-100 万辆（+59%-68%），低于公司 105-110 万；催化剂为 9 月新平台技术、Q4 旺季、D99 放量（D 系列目标毛利率 20%+）。
- **适用场景与注意事项**：适用于指引下修的财报，核心价值是区分“一次性冲击”和“趋势恶化”。独立预期必须自己给出，不能只复述公司口径；催化剂要带时间节点，方便后续验证。

### 9.8.9 指引上修幅度不及预期的拆解：一次性投入的成本时点、促销错期与单季指引

- **方法要点**：全年指引小幅上调却低于预期时，不简单归为“保守”，而是拆出成本时点、促销错期等原因，并记录下季单季利润指引作为短期压力，设定后续检验指标。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对比全年指引的上调幅度与预期（固定汇率净销售、经调整经营利润等）。
  2. 拆原因：
     - 一次性资金投入（如一次性退税）多在季末才投入降价，完整成本落在下季；
     - 子公司大促错期，带来超过 100bps 的销售逆风；
     - 记录下季单季经营利润指引，视作短期压力。
  3. 设定检验战略的后续指标（客流改善、食杂份额提升），看投入是否有产出。
  4. 季度与年度指引需要放在一起看：年度上修但单季指引偏低，说明利润在后续季度被压低，节奏上需要重新校准。
- **关键指标与数据来源**：全年固定汇率净销售指引、经调整经营利润指引、单季经营利润指引；数据来自指引、电话会。
- **判断标准**：
  - 年度上修幅度低于预期，但拆解后原因是成本时点与促销错期（时间性因素），则判断为“短期压力、非趋势”。
  - 单季经营利润指引显著低于全年增速，则说明利润后置，估值要考虑短期压力。
  - 检验指标（客流、份额）能否持续改善，是判断降价投入是否值得的关键。
- **海豚案例**：
  - 沃尔玛（2026-08-21）：全年固定汇率净销售由 3.5%-4.5% 上调至 4.0%-5.0%，经调整经营利润由 6.0%-8.0% 上调至 7.0%-8.5%；Q3 经营利润指引仅 2.0%-4.0%；Flipkart 大促错期带来 >100bps 逆风。
- **适用场景与注意事项**：适用于同时给季度与年度指引的公司。上修“幅度不及预期”与“指引下调”性质不同，要和 9.8.8 区分；一次性投入的成本时点要核对管理层何时投入、何时全面体现。

### 9.8.10 拆解管理层“维持毛利率”或“毛利率转正”的论据，逐条评估可信度

- **方法要点**：管理层承诺毛利率维持在某个水平，或在某个季度转正时，把论据拆成几条，逐条判断是可验证的硬约束还是过渡性假设，并标出需要跟踪的时间点。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把管理层的论据拆成条目，常见类型：
     - 商业模式回归（如硬件交还 Tier1，回到 SoC 加软件授权）；
     - 供应链对冲（如锁价）；
     - 架构创新降本（如舱驾一体，每车省数千元）；
     - BOM 降本（如新平台 BOM 约为旧平台的 50%）；
     - 规模释放（产能爬坡、产量集中释放）。
  2. 逐条打标签：属于“可验证的硬约束”（已锁价、已有量产时点、有合同安排），还是“过渡性假设”（依赖产量、依赖新方案落地）。
  3. 标出每条论据需要跟踪的时间点，如 Q4 量产。
  4. 综合判断承诺的可信度，并写入后续检验计划。
  5. 下季毛利率或 Adj. EBITDA 指引的对比与收入结构推演，详见 9.1。
- **关键指标与数据来源**：毛利率指引、BOM 占比、锁价状态（如锁定内存价格的时点）、新方案量产时点；数据来自电话会、指引、产业链信息。
- **判断标准**：
  - 论据中含有已锁定的成本（锁价）、已落地的商业模式调整，可信度较高。
  - 论据依赖于产量集中释放、新方案量产，则取决于时间节点是否兑现，应作为过渡性假设对待。
  - 时间节点一旦错过，原承诺即需要下调；要明确列出“哪一个时间点的哪一个数据”是检验口。
- **海豚案例**：
  - 地平线（2026-03-20、2026-09-01）：60% 以上毛利率的依据有三条：系统级交付只是过渡，2026 下半年把硬件交还 Tier1；2025 年底前锁定 DRAM 价格；基于星耀芯片的舱驾一体方案 Q4 量产，每车省数千元。
  - Rivian（2026-05-01）：Q4 毛利率转正，依据是规模释放，以及大压铸、结构化电池包、新电子电气架构降本。
  - 吉利（2026-04-29）：Q2 毛利率稳定或微增，依据是极氪 8X 交付对冲约 2000 元的大宗成本。
- **适用场景与注意事项**：通用。重点跟踪论据中的时间节点是否兑现；与 9.8.11 配合，后者讨论的是毛利率转正押在后半年时的节奏风险。

### 9.8.11 指引节奏后置（back-end loaded）的风险识别：销量和毛利率拐点都押在 Q4

- **方法要点**：管理层把销量释放和毛利率转正都集中到年末某一季时，识别中间季度的承压原因和转正驱动，并指出关键季度一旦不达预期，全年指引会有下调风险，因此估值上要等待安全边际。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出分季度毛利率指引（如 Q2-Q3 承压、Q4 转正）和全年销量指引。
  2. 列出中间季度承压的原因：新产线开始计提折旧但单班制产量小、新团队薪酬、爬坡复杂度。
  3. 列出后续转正的驱动：产量集中释放、BOM 降本（如新品 BOM 约为老品的 50%，非量产相关 COGS 下降 50% 以上）。
  4. 追踪产能爬坡节点：单班转双班、周产目标（如年底每周 4000 辆）。
  5. 给出风险推断：若关键季度量产再不及预期，全年销量指引有下调风险；估值上要等待安全边际。
- **关键指标与数据来源**：分季度毛利率指引、产能爬坡节点（单班转双班、周产目标）、全年销量指引；数据来自指引、电话会及工厂排产披露。
- **判断标准**：
  - 全年指引的完成度严重依赖单一季度（Q4）的量产节奏，则风险偏高。
  - 中间季度的承压有明确原因与时间表，Q4 转正的驱动有硬数据（BOM 比例、周产目标），则风险相对可控。
  - 海豚君的推理链：中间季度承压原因 → 转正驱动 → 节点集中在 Q4 → 一旦未达则全年下调 → 等待安全边际。
- **海豚案例**：
  - Rivian（2026-05-01）：Q2-Q3 汽车毛利率受 R2 拖累，Q4 转正（R2 的 BOM 约为 R1 的 50%，非量产相关 COGS 下降 50% 以上）；单班启动，年末转双班，诺默尔工厂年底目标每周 4000 辆。海豚君判断 Q4 若不及预期，全年销量指引有下调风险，建议等待安全边际。
  - 地平线（2026-09-01）：出货和 HSD 放量都后置到 H2。
  - 三花（2026-08-27）：利润释放安排在 H2。
- **适用场景与注意事项**：适合新品、新产能爬坡期的公司。后置本身不是问题，问题是后置的驱动是否有硬证据；要把关键季度写进跟踪表，作为“进场/等待”的判断依据（交易节奏见 12.7）。

### 9.8.12 “前低后高”的全年口径压低了市场的预期基数

- **方法要点**：公司事先给出全年“前低后高”的节奏时，市场会相应压低上半年预期，后续季度指引就更容易大超；识别“低基数之上的超预期”，再据此推断下半年的拉货强度。
- **操作步骤 / 拆分口径 / 公式**：
  1. 找到公司此前给出的全年节奏口径（前低后高、上半年小幅增长等）。
  2. 把全年节奏口径与单季预期一起看：市场对上半年预期被压低到什么水平（如只预期小幅增长）。
  3. 比较单季指引与这个低基数的差距（如指引中值环比 +9%），识别“低基数之上的超预期”。
  4. 横向印证下半年拉货强度：看设备商的季度指引、晶圆厂资本开支节奏是否同样集中在下半年。
  5. 推断结论：下游拉货集中在下半年，周期正在拐头向上。
- **关键指标与数据来源**：全年节奏口径、季度预期、季度指引（环比中值）、上下游的资本开支与指引；数据来自电话会、一致预期。
- **判断标准**：
  - 单季指引中值环比大幅高于被压低的预期，并且全年节奏口径未变，说明需求在加速。
  - 上下游节奏口径互相印证（设备商出货集中下半年、晶圆厂资本开支集中下半年），推断下半年拉货强度的可信度提升。
  - 超预期来自低基数，不等于对全年上调；需要用 9.8.11 的框架评估后置风险。
- **海豚案例**：
  - AMAT（2026-02-13）：此前给出 2026 年全年前低后高，市场对上半年只预期小幅增长；Q2 指引中值环比 +9%，大超预期。
  - ASML（2026-07-15）：三、四季度分别约 110-120 亿、140-150 亿，下游拉货集中在下半年。
  - 台积电（2026-04-16）：资本开支集中在下半年，与 ASML 节奏吻合。
- **适用场景与注意事项**：周期拐点期的设备和资本品公司。要把“节奏口径”与“单季预期”放在一起看，避免把低基数上的超预期误当成全年大幅上修。

### 9.8.13 全年指引不变下的季度利润释放节奏解读（结合基数与滚动规划）

- **方法要点**：管理层重申全年目标、但当季增速偏低时，结合管理层的季度口径、去年同期基数、滚动式规划与分业务拐点，判断后续季度是否会加速，并找出“下半年加速”的确定性条件。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录全年利润增速指引（如 +15%）、当季增速以及管理层对下一季的口径（如“平稳增长而非大幅反弹”）。
  2. 对照去年同期基数：下半年的基数（如制冷业务）是否更低，基数效应是否在下半年消失。
  3. 理解滚动式规划的含义：全年目标不改，实际在逐季验证、逐季调整。
  4. 拆分业务拐点：区域回暖节点（如北美 5 月回暖）、政策（以旧换新）。
  5. 推出“下半年加速”的确定性条件：低基数 + 业务回暖；并与催化剂（新品量产）的时间匹配。
  6. 用当季增速、Q2 平稳口径和下半年基数，反推全年目标是否可达、下半年需要多大的增速（基数口径见 3.3）。
- **关键指标与数据来源**：全年利润增速指引、季度增速、去年同期基数、管理层季度口径；数据来自指引、电话会和上年分季度数据。
- **判断标准**：
  - 当季增速偏低但全年目标重申，且下半年基数更低、有明确回暖节点，则全年目标可达，判断为“下半年加速”。
  - 若管理层对 Q2 的口径是平稳而非反弹，则不要提前把加速计入 Q2。
  - 业务拐点与新品量产时点能叠加，确定性更强。
- **海豚案例**：
  - 三花《汽零回正…》（2026-05-06）：重申全年利润 +15%，采用滚动式规划，Q2 平稳、下半年加速；制冷北美自 5 月有望回暖；25 年下半年制冷基数更低，与 Optimus V3 量产期叠加。
  - 三花《“天灾人祸”…》（2026-03-31）：行业需求不振下公司仍指引 Q1 正增长，国内制冷高基数下半年消失，判断全年 15% 目标很有希望实现。
- **适用场景与注意事项**：适用于给出全年指引但季度波动大的公司。要把基数与季节性（见 3.3、3.4）一起看，避免把基数效应当成需求回暖。

### 9.8.14 指引未随事件变化调整的预期差，以及预期重置后的 beat

- **方法要点**：外部事件改变了经营前提后，机构会先行调整预期；若公司指引不同步调整，就形成“失望”。反过来，上季利润低于预期、管理层解释后市场下调盈利预期，下一季即使正常经营也会形成 beat。判断 beat 或 miss，必须看预期在季度间如何被重置。
- **操作步骤 / 拆分口径 / 公式**：
  1. 回看上季财报与电话会：管理层提到哪些影响指引的因素（如收购带来的利润率拖累），量化为多少（如 0.5pct）。
  2. 本季若发生事件，使得该因素消失（如放弃收购），推断机构会如何调整预期（如把年度 OPM 预期上调）。
  3. 对比公司本季指引是否同步调整：不调整，则相对上调后的预期构成失望。
  4. 反向情形：上季业绩低于预期，管理层解释后机构下调盈利预期；本季正常经营，对重置后的低预期形成小幅 beat。
  5. 分解季度指引：列出下季指引同比下滑的原因（成本投入类项目），避免只看全年口径。
- **关键指标与数据来源**：年度 OPM 指引、机构预期调整、上季预期修正、季度 OPM 指引；数据来自财报、电话会与卖方预期变动。
- **判断标准**：
  - 指引未调整、预期已被抬高，则指引本身变成了“利空”，即使数值未变。
  - 预期已下调、业绩恢复正常，则小幅 beat 并不代表经营改善，而是预期重置的结果。
  - 评估 beat / miss 的含金量时，把预期的变动路径纳入基准（见 1.2 预期动态、2.4 超预期质量）。
- **海豚案例**：
  - 奈飞（2026-04-17）：全年 OPM 指引仍为 31.5%，但上季称收购 WBD 影响 0.5pct，放弃收购后机构已提高到约 32%，指引不变即失望；Q2 利润率指引同比下滑 1-2pct（儿童游戏、体育直播成本、收购 InterPositive）。
  - 奈飞（2026-07-17）：上季下调盈利预期后，本季经营利润 42 亿、OPM 33%，小幅 beat。
- **适用场景与注意事项**：经常调整指引或有重大事件的公司。订阅类公司因指引未上调而引发的动机解码（如订阅流水指引不变背后的变现策略），详见 9.4。

### 9.8.15 结构化复述管理层投产比框架并做压力测试

- **方法要点**：当公司系统性解释投入产出逻辑（如大规模资本开支、AI 投入）时，先结构化复述管理层的框架，再指出框架没有覆盖的风险，对其压力测试，并给出“解释有理有据，但未扫清质疑”这类分层结论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 结构化复述管理层的投产比逻辑：
     - a. 以在手订单计算投产比（确定订单为分母）；
     - b. 长 / 短周期资产的区别（厂房等长周期资产拉高前置投入但长期可用；服务器等短周期资产按需提前采买）；
     - c. 回本周期与使用年限（如服务器回本约 3 年、使用 5-6 年，3 年后出 FCF）。
  2. 与此前对同类公司的分析比对，验证是否一致。
  3. 指出框架未覆盖的风险（压力测试项）：
     - 订单毁约惩罚机制；
     - 上游采购合同的违约机制；
     - 上游采购订单与下游合同余额之间的期限错配；
     - “客户的客户”支付能力，即 AI 是否真正创造增量收入，而非仅降本或挪用预算。
  4. 给出结论：解释是否有理有据、是否安慰了市场、是否为整个行业代言，以及质疑是否真正扫清。
- **关键指标与数据来源**：在手订单、长 / 短周期资产占比、回本周期、使用年限；数据来自电话会、财报附注、资本开支披露。
- **判断标准**：
  - 投产比以确定订单计算、回本周期与使用年限清晰，则逻辑自洽。
  - 但订单惩罚机制、采购违约机制、期限错配、客户的客户支付能力任一项缺失，则质疑未被扫清。
  - 海豚君的结论：解释有理有据、安慰了市场、为整个 CSP 代言，但并未扫清质疑。
- **海豚案例**：
  - 亚马逊（2026-07-31）：公司以确定在手订单计算投产比；厂房等长周期资产拉高前置投入但长期可用，服务器等短周期资产按需提前采买；服务器回本约 3 年、使用 5-6 年，3 年后出 FCF；与海豚君分析谷歌时的判断一致。
- **适用场景与注意事项**：任何管理层给出投资回报论证的场合。资本开支强度与 ROI 的通用方法见 10.2，折旧传导见 10.3；压力测试的重点是找出框架里“没说的部分”，而不是复述管理层。
