# 第13章 观点形成与研究闭环

> **本章目的**：把各环节的判断汇成“海豚君观点”，抓住主要矛盾，并通过逐季回测形成“预测→验证”闭环。

**本章小节**：13.1 观点判断链与综合结论｜13.2 核心矛盾、分歧论证与研究心态｜13.3 预测—验证闭环与观点复盘

---

## 13.1 观点判断链与综合结论

> 本节导读：本节回答“怎么把前面各环节的判断汇成一段站得住的‘海豚君观点’”：按什么顺序组织推理链、当季好坏两面并存时怎么下结论、短期业绩驱动与中长期看点如何分层、最终结论综合哪几个因素。写观点段、形成投资判断、给财报点评收尾时使用。上游依赖第2章（业绩定性与预期差）、第9章（指引）、第11章（股价反应）、第12章（估值与交易结论）的输出；核心矛盾与分歧论证见13.2，结论的回测与复盘见13.3，整篇点评的版式模板见17.1。

**四种观点骨架对照**（海豚君实际使用的推理顺序，可按公司情形选用或混用）：

| 骨架 | 推理顺序 | 更适合的情形 | 代表案例 |
|---|---|---|---|
| A 好坏两面链 | 好坏两面 → 指引 → 行业与动态 → 估值 → 结论 | 默认骨架，当季好坏并存、需要把指引与近期动态一并纳入 | CoreWeave、海康、戴尔 |
| B 三段式 | 当季定性 → 分业务展望 → 估值与操作 | 多业务公司：压舱石业务、投入期业务、成长业务各有各的节奏 | 阿里、贝壳 |
| C 预期差三层 | 预期差 → 抛开预期差的趋势信号 → 决定股价的核心变量 → 估值与操作 | 需要从一堆信号里抓出少数决定股价的变量，或存在竞争、投入产出争议 | 美团、腾讯、百度 |
| D 矛盾链 | 当季 → 指引 → 核心矛盾 → 估值与操作 → 点名跟踪信号 | 当季不差、真正的问题在指引、Capex、竞争或内生增长 | 亚马逊、奈飞、分众、谷歌 |

无论选哪种骨架，最后一步都要落到13.1.8的四因素综合判断，并落到13.3的可验证观察点，这样观点才能被下一季回测。

### 13.1.1 观点骨架A：好坏两面 → 指引 → 行业与动态 → 估值 → 结论

**方法要点**：观点段最常用的五步推理顺序，把“当季业绩的好与坏”依次推进到“估值与操作结论”，并用一句带态度的口语化小标题给全篇定性。

**操作步骤 / 拆分口径**：
1. 当季好坏两面各列出来：好的、坏的分别列条目，不回避瑕疵（业绩定性的具体维度见2.1，逐项对标见2.2）。
2. 短期与中长期指引分别对比预期（对比口径见9.1）：指引偏低、符合还是保守，直接决定后面估值是否有上修空间。
3. 行业和公司近期动态：订单、融资、合作、行业叙事。这一步补充“财报之外已经发生、但会影响估值定位”的信息。
4. 估值定位：把当前股价放进估值框架（PE、历史区间、情景分析，见第12章），给出“两个情景”或“相对历史上限/中枢的位置”。
5. 落到结论，常见四类落点：可期待、观望、回调后更舒适、估值有望突破；对高波动标的则用“高弹性、高风险”这类定位。
6. 小标题：每个观点段或全文标题常用一句带态度的口语化定性（如“涨价托增长，主业仍承压”“全面超预期，AI与传统服务器双双起飞”），让读者在标题层就能读到结论倾向。

**关键指标与数据来源**：本方法本身没有专属指标，沿用上游各章的输出：当季核心指标对预期的位置、指引对预期、订单与融资与合作等公司动态、估值水位。数据来自财报、电话会、公司公告与第12章的估值快算。

**判断标准**：
- 结论必须能从前四步“推”出来，而不是先有结论再找依据：好坏两面决定业绩定性；指引决定上修还是下修空间；近期动态决定风险与催化；估值位置决定风险回报。
- 案例中的推理对应关系：指引偏低 + 新签大单与融资落地 + 估值两个情景 → 高弹性高风险（CoreWeave）；主业承压但涨价托底增长 + 估值中间偏下 → 毛利率回升有望重拾信心（海康）；全面超预期 + 指引保守 → 估值有望突破历史上限（戴尔）。
- 注意：好坏两面要写“两面”，只有好或只有坏的观点段，说明第1步没有做完。

**海豚案例**：
- CoreWeave（2026-05-08）：好坏两面 → 指引偏低 → 近期动态（新签大单、锁定约150亿资金）→ 估值两个情景 → 落到“高弹性、高风险”的定位。
- 海康（2026-04-18）：小标题“涨价托增长，主业仍承压” → 估值中间偏下 → 结论是毛利率回升有望重拾信心。
- 戴尔（2026-05-29）：小标题“全面超预期，AI与传统服务器双双起飞” → 指引保守 → 结论是估值有望突破历史上限。

**适用场景与注意事项**：可直接作为写作与判断的模板，适用于绝大多数财报点评。若业务线很多、各线节奏不同，可改用13.1.2的三段式；若争议集中在少数变量，可改用13.1.3。小标题的“态度”应与最终结论一致，避免标题偏乐观而正文落点是观望。

### 13.1.2 观点骨架B：当季定性 → 分业务展望 → 估值与操作（三段式）

**方法要点**：先用一句话把当季业绩定性，再按业务逐一给出后续展望并排出核心驱动因素的主次，最后落到估值与操作结论。适合多业务、各业务处于不同生命周期的公司。

**操作步骤 / 拆分口径**：
1. 当季定性：给出绝对表现、预期差、边际变化三个层面的判断，常用“过去已是过去，更重要的是展望”作为过渡，把读者带向后续。
2. 分业务展望：对每条业务线逐一判断。
   - 压舱石业务：维持现状还是修复；
   - 投入期业务：减亏节奏；
   - 成长业务：关键观察点是什么。
   然后给出核心驱动因素的主次排序（谁是核心决定因素、谁是次要因素）。
3. 估值：PE、SOTP（分部估值），并给出中性与保守情景。
4. 操作结论：是否利空出尽、区间博弈、风险回报比如何。

**关键指标与数据来源**：本方法为推理框架，无专属指标。各业务线展望所需指标来自分部披露与第5至8章的拆解；估值来自第12章的PE快算与分部估值（12.3）。

**判断标准**：
- 驱动因素要分主次：主因决定股价方向，次因只影响幅度，不能把所有因素并列处理。
- 结论用风险回报比表述：不是只说“看多看空”，而是说明向上、向下的概率与空间（贝壳案例的表述是“风险回报比相对偏上，但向上向下的概率都不小”）。
- “利空出尽”必须有前提：当季偏负面、但负面已被估值反映，且后续因素（远场电商、即时零售、AI、资金压力等）已逐一梳理并给出SOTP保守情景（利空出清的更多判据见11.2）。

**海豚案例**：
- 阿里《阿里：电商退位，AI上位》（2026-05-14）：当季偏负面 → 后续按业务展望：远场电商、即时零售、AI（模型、芯片、2C/2B）、资金压力 → 估值用SOTP得到$151 → 结论“利空出尽”。
- 贝壳《一线再松绑》（2026-08-21）：业绩不错 → 核心决定因素是楼市景气，次要因素是控费和二航道 → 年化PE 18-19倍 → 结论“风险回报比相对偏上，但向上向下的概率都不小”。

**适用场景与注意事项**：所有财报点评都适用，尤其是多业务集团（电商、本地生活、云、新业务并存）。易错点：分业务展望只罗列、不排序，会让观点失去重心；强周期公司的“业绩不错”不等于后续持续，需配合13.2.6。

### 13.1.3 观点骨架C：预期差 → 抛开预期差的趋势信号 → 决定股价的核心变量

**方法要点**：先相对预期定性，再把预期差放一边、只看好与不好的“趋势信号”，随后从中提炼决定业绩与股价的少数核心变量，最后落到估值与操作。核心是区分“乍看”和“实际含金量”。

**操作步骤 / 拆分口径**：
1. 相对预期定性：给出一句带分寸的评价，例如“有瑕疵的中性稍偏弱”“预期之内的好”“好坏参半”。
2. 抛开预期差：把好的趋势信号（a、b、c）和不好的趋势信号（a、b、c）分别列出，不再与一致预期比，只看趋势方向本身。
3. 提炼核心变量：从信号中收敛出决定业绩和股价的少数几个变量。
   - 美团：与阿里的即时零售竞争、与抖音的到店竞争、自身新业务投入，三件事；
   - 腾讯：AI投入-产出。
4. 落到估值与操作。
5. 全程区分“乍看”与“实际含金量”（数据看起来好或坏，扣除一次性、会计与口径后真实含金量如何，检验方法见2.4与第4章），并描述资金态度（例如腾讯“又爱又怨”）。

**关键指标与数据来源**：判断框架，无专属指标。趋势信号来自第3章的增量与二阶导、第5至8章的拆解；资金态度来自股价与成交反应及市场讨论（股价反应归因见第11章）。

**判断标准**：
- 预期差定性回答“市场会不会惊讶”，趋势信号回答“公司在往哪走”，两者可以背离（预期之内的好 ≠ 趋势转好）。
- 核心变量要少而硬：一般收敛到“三件事”或一个投入产出关系，之后的估值与操作都围绕它们展开。
- 当含金量与表面数字相反时，以含金量为准写结论。

**海豚案例**：
- 美团《三山压顶》（2026-03-26）：核心变量收敛为与阿里的即时零售竞争、与抖音的到店竞争、自身新业务投入三件事。
- 美团《阿里、抖音熄火？》（2026-08-28）：同一框架在后续财报的应用，决定业绩与股价的核心变量仍落在与阿里的即时零售竞争、与抖音的到店竞争、自身新业务投入三件事上。
- 腾讯《AI撒钱火力全开？》（2026-08-12）：核心变量是AI投入-产出，并描述资金“又爱又怨”的态度。
- 百度《其他没指望》（2026-05-18）：同样按“预期差 → 趋势信号 → 核心变量 → 估值与操作”的三层结构撰写观点。

**适用场景与注意事项**：财报观点撰写与投资判断。适合竞争格局、投入产出争议突出的互联网平台。易错点：趋势信号一旦与预期差混写，读者无法分辨“超预期”与“趋势好”；核心变量过多（超过三四个）说明还没有抓到主要矛盾，应回到13.2.1重新提炼。

### 13.1.4 观点骨架D：当季 vs 指引 vs 核心矛盾 vs 估值，并点名跟踪信号

**方法要点**：先承认当季好坏，再指出真正的问题，回到市场最关心的根本问题，给出估值位置与操作倾向，最后点名后续要盯的具体信号，使观点可以被下一季验证。

**操作步骤 / 拆分口径**：
1. 承认当季：“单看本季挑不出毛病”，或“当季业绩表现并不差”。先给出对方（市场、读者）能接受的客观评价。
2. 指出真正的问题：指引、Capex、竞争或内生增长，是当季之外决定股价的东西。
3. 回到市场最关心的根本问题：AI竞争力、ROI（投入回报）、信仰。
4. 给出估值位置与操作倾向：等待分歧期、博弈反弹、在调整中找更舒服的机会。
5. 点名后续跟踪信号：写成具体可观察的变量，如Anthropic ARR、Gemini 4、涨价后的用户反噬、新潮收购、世界杯后的接力。

**关键指标与数据来源**：无专属指标。跟踪信号的数据来自后续财报、公司披露与行业数据（如ARR、新模型发布、用户流失）。

**判断标准**：
- 当季好与长期问题要分开评价：当季好不能抵消指引、Capex或竞争的问题（亚马逊：“当季业绩表现并不差，天量Capex和指引是问题所在”）。
- 操作倾向要与根本问题挂钩：如果根本问题是“AI投入的回报”，操作就应写成“等待分歧期/在调整中找更舒服机会”，而不是追涨。
- 结尾必须有“可跟踪信号”：没有信号的观点无法回测（回测见13.3）。

**海豚案例**：
- 亚马逊（2026-02-06）：“当季业绩表现并不差，天量Capex和指引是问题所在”，先承认当季，再把真正的问题落在Capex与指引上。
- 亚马逊（2026-07-31）：点名跟踪信号Anthropic ARR。
- 奈飞（2026-04-17）：点名关注3月底涨价的效果（涨价后的用户反噬）。
- 分众（2026-08-21）：alpha = 新潮收购（向上）+ 分红（托底）。
- 谷歌（2026-04-30）：从行业情绪分歧中寻找“更舒服的机会”。
- 其他被点名的跟踪信号还有Gemini 4、世界杯后接力，均写成可观察的具体变量或事件。

**适用场景与注意事项**：财报观点输出，适用于“当季不差但股价承压”的龙头与大Capex公司。注意：点名的跟踪信号要具体到变量或事件，且尽量带阈值（见13.3.2）；否则退化为泛泛的“后续观察”。

### 13.1.5 辩证判断：增长与利润、融资压力“相互对应”

**方法要点**：对处于投入期的公司，好消息和坏消息往往是同一件事的两面——业务增长越快，Capex越大，利润率和融资压力也越大，短期内不可能两头都好。因此不能凭当季数据简单定性好坏，要看两者的“相对速度”何时扭转。

**操作步骤 / 拆分口径**：
1. 把当季的“好”（收入、订单、新签大单）和“坏”（毛利率下滑、负债走高、亏损）并排列出。
2. 判断两者是否“相互对应”：坏的是不是为了好的而付出的代价（增长越快→Capex越大→利润率与融资压力越大）。
3. 比较相对速度：收入和提价 vs 成本和投入（收入增速 vs Capex增速、利润率与负债增量的变化）。
4. 找扭转点：规模效应出现、折旧/费用/利息被摊薄、投入产出比改善，即视为相对速度开始扭转。
5. 据此定性：处于“业务越多、亏损也越多”阶段 → 不简单判差；规模效应出现 → 投入产出比改善。

**关键指标与数据来源**：收入增速、Capex增速、利润率、负债增量；另可结合折旧与利息摊薄情况。数据来自财报、Capex指引与融资披露（资本开支与ROI方法见10.1、10.2，融资与现金跑道见10.5）。

**判断标准**：
- “收入和提价”的增速持续快于“成本和投入”，才算扭转；否则只是用更高的负债换增长。
- 营收超预期、新签大单与毛利率下滑、负债走高同时出现，是“相互对应”，当季业绩不能说差。
- 规模效应的证据：折旧、费用、利息三项同时被摊薄。

**海豚案例**：
- CoreWeave（2026-05-08）：营收超预期、新签大单，与毛利率下滑、负债走高“相互对应”，当季业绩不能说差。
- CoreWeave（2026-02-27）：处在“业务越多、亏损也越多”的尴尬阶段。
- CoreWeave（2026-08-12）：规模效应出现，折旧、费用、利息都被摊薄，投入产出比在改善。

**适用场景与注意事项**：适合处于扩张期的重资产公司（算力云、产能扩张期制造等）。易错点：只看单季毛利率下滑就判“坏”，或只看收入超预期就判“好”；需持续比较相对速度，并关注融资环境是否支撑投入（融资压力的现金跑道测算见10.5）。

### 13.1.6 区分短期业绩驱动与中长期看点

**方法要点**：观点部分明确分开“短期业绩和股价由什么决定”与“中长期看什么”，分别给出不同时间维度的判断，避免用短期数据否定长期逻辑，或用长期叙事掩盖短期压力。

**操作步骤 / 拆分口径**：
1. 列出短期驱动：当季产品出货、季节性、指引（短期指标）。
2. 列出中长期看点：下一代产品、新客户、新订单、交付形态（长期指标：新品量产、客户订单）。
3. 对两个时间维度分别下判断：短期怎么走（是否有回调压力）、长期看什么（哪些变量兑现才算验证）。
4. 常配合“前低后高”的节奏判断：当新客户或新品要到下半年才交付时，全年收入呈现前低后高，低点由现有客户与产品的短期节奏决定，高点则挂在新客户、新订单的兑现上（如博通案例）。

**关键指标与数据来源**：短期指标（当季出货、指引）；长期指标（新品量产进度、客户订单、机架级交付）。来源为财报、指引、电话会增量信息（见2.5）与产品周期追踪（见6.5）。

**判断标准**：
- 短期压力不因长期逻辑而取消：如某产品环比不及预期，会带来回调压力，即使长期逻辑完好。
- 长期逻辑要有“可兑现的节点”：新客户何时交付、新订单何时转收入（如“下半年才交付”）。
- 当“当季不好、长期不变”或“当季好、长期未验证”时，要把两个判断都写清楚，而不是混成一个结论。

**海豚案例**：
- AMD（2026-02-04）：短期受CPU业务和MI355出货影响，MI355环比不及预期会带来回调压力；中长期看MI450系列的新增客户、新增订单和机架级集群交付。
- 博通（2026-03-05）：短期看现有三家客户（尤其谷歌TPUv6/v7的量产），Anthropic和第五客户下半年才交付，因此全年AI收入前低后高。
- Marvell（2026-05-28）：当前最大的增量来自互连产品；ASIC、CXL内存扩展、机架级方案是长期看点。

**适用场景与注意事项**：通用，尤其适合产品迭代快、客户导入与交付存在时间差的科技硬件与芯片公司。注意：“前低后高”需有客户交付时点作支撑，不能仅是对增速的乐观假设。

### 13.1.7 单列“市场更关心的中长期议题”并综合结论

**方法要点**：除当季业绩和指引外，单独列出市场更关心的中长期议题，逐项分析后综合（a+b+c）给出结论。决定估值的往往是这些议题，而不是当季数字。

**操作步骤 / 拆分口径**：
1. 识别议题：回答“市场现在最担心什么、最想知道什么”，列成a、b、c（通常2至3项，常见表述形式为“1）…2）…3）…”）。核心问题的提炼方法见1.3，叙事与分歧见11.4。
2. 逐项分析：每项议题配置自己的跟踪指标。
3. 综合：把a、b、c的结论合成一个判断（如“领先优势仍在，但要看下游经济性”）。
4. 随时间更新议题：议题会演变，每次点评都要重新审视议题清单，而不是沿用上季。例：英伟达从“capex + 竞争 + 新品”，演变为“承诺、担保、融资平台 + Rubin节奏 + 竞争格局”。

**关键指标与数据来源**：议题清单及每项的跟踪指标（如大厂资本开支、竞争进展、新品爬坡节奏、融资平台规模等），来自财报、电话会、同业与产业链信息（外部验证见第14章）。

**判断标准**：
- 当议题成为估值的主导因素时，议题的结论权重高于当季业绩。
- 议题清单应随市场焦点变化：当“市场关心的是什么”变了，指标权重和重点也应变（核心矛盾切换的识别见13.2.2）。
- 综合时要说明各议题是并列相加还是有主次。

**海豚案例**：
- 英伟达（2026-02-26）：议题a大厂资本开支、b AI芯片竞争、c Rubin进展；综合后认为领先优势仍在，但要看下游经济性。
- 英伟达（2026-08-27）：议题演变为1）5000亿融资平台，2）Rubin爬坡节奏，3）竞争格局。
- 戴尔（2026-09-02）：1）AI服务器，2）CSG（PC）与存储价格。
- SEA（2026-08-11）：电商（利润率与竞争）、金融（增长、信用风险、利润率之间的平衡）、游戏（新游）。

**适用场景与注意事项**：适用于所有财报点评，尤其是远期叙事主导估值的公司。易错点：议题清单只复制上一篇，会漏掉新的主要矛盾；议题与跟踪指标脱节，则无法在13.3中验证。

### 13.1.8 四因素综合判断：业绩边际变化、相对预期、估值消化程度、叙事环境

**方法要点**：海豚君的结论通常综合四层信息，再叠加研究风格的约束，形成最终的投资判断。

**操作步骤 / 拆分口径**：
1. 基本面边际变化：加速还是放缓，利润率方向（见第3章）。
2. 相对预期：卖方、买方与指引三条线（见第1、2章与9.1）。
3. 估值处于什么位置、消化了多少：与年初、同行、合理估值比（见11.3与第12章）。
4. 行业叙事：AI颠覆、Capex ROI、政策等宏观与行业叙事（见11.4）。
5. 叠加研究风格约束：
   - 不为“梦想”定价；
   - 回避存在归零风险的标的；
   - 偏好估值低且有回购支撑的标的；
   - 或在悲观价位分批布局。

**关键指标与数据来源**：判断框架，沿用前述各章指标与估值倍数、回购规模等。

**判断标准**：
- 四个因素要同时过：基本面好但估值太贵 → 不是喜欢的类型；业绩稳定但有归零风险 → 观望；估值低且回购高 → 下行空间有限；财报好但Capex ROI与解禁压力在 → 等悲观估值再分批布局；估值仍有下行空间 → 等待回落。
- 估值“消化”要用数字表达（如“仍有19-24%下行空间”“有望逐步迈入低溢价的正常区间”），而非形容词。
- 叙事环境既可以是风险（AI替代论、鬼故事调整），也可以是切入机会（在鬼故事调整中切入）。

**海豚案例**：
- Shopify《业绩不俗却暴跌》（2026-02-12）：基本面优秀，但估值太贵，不是喜欢的类型。
- Salesforce《AI替代论摧枯拉朽》（2026-02-26）：业绩稳定但有归零风险，选择观望；估值低、回购高，下行空间有限。
- Palantir《瑕疵修复》（2026-08-04）：估值有望逐步迈入低溢价的正常区间，在“鬼故事”调整中切入。
- SpaceX《豪赌AI》（2026-08-05）：财报好，但Capex ROI加解禁压力，等到悲观估值再分批布局。
- 阳光电源《收入倒春寒》（2026-04-28）：估值仍有19-24%下行空间，等待回落。

**适用场景与注意事项**：适用于形成最终投资判断。风格约束属于海豚君的偏好，使用者可按自己的风险偏好调整，但“四个因素缺一不可”的检查框架通用。易错点：只凭基本面或只凭估值下结论；把叙事环境当成理由而不核对数据。

**本节速查清单**

## 13.2 核心矛盾、分歧论证与研究心态

> 本节导读：本节解决“抓什么、怎么证、以什么心态看”：提炼主要矛盾、识别当前阶段的胜负手变量、在市场分歧中逐条证伪或反驳，并对周期股的“成长叙事”和新技术的非线性保持警惕与敬畏。适合在写观点段之前先做一遍，也适合在股价大跌或情绪极端时使用。输出会被13.1的判断链调用；市场叙事与远期分歧如何被定价见11.4，估值保守情景见12.5，论证链在写作中的版式见17.2。

### 13.2.1 先提炼“主要矛盾”：眼前的优秀业绩 vs 长期的不确定威胁

**方法要点**：观点部分先提炼投资判断的主要矛盾（如当期业绩 vs 长期颠覆），分别论证两端，再给出操作建议。

**操作步骤 / 拆分口径**：
1. 写出主要矛盾：一端是眼前正在发生的事实（业绩、订单、增长），另一端是未来大概率发生但还看不清的威胁或缺口（颠覆、竞争、第二曲线）。
2. 分别论证两端：一端用数据证明“确实在发生”，另一端用逻辑和可见信号说明“为什么会发生、到哪一步会发生”。
3. 给操作建议，通常三选一：做中短期趋势、要求高折价、或等待更多迹象。

**关键指标与数据来源**：无统一指标，按矛盾两端选取：眼前端用收入、利润、订单；威胁端用竞争指标（如ROAS相对优势、eCPM、转化率）或新业务进度。

**判断标准**：
- 主要矛盾应是“一件事”，而不是列一串风险；围绕它的其他因素应归并为它的组成部分（如Applovin案例中，电商竞价推高eCPM、伤及游戏客户转化率、同行带来新竞争，三者都归入“ROAS相对优势变化”这一件事）。
- 若威胁端“大概率发生但看不清”，操作上需要高折价或等待迹象，而不是按当期业绩满估值；若威胁端被信号证伪，则回到趋势交易。
- 竞争类矛盾的本质往往是相对优势的变化（如ROAS相对优势），而非绝对数据好坏。

**海豚案例**：
- Uber（2026-02-05）：主要矛盾是眼前正在发生的优秀业绩，与未来大概率发生但还看不清的无人网约车冲击。
- Applovin（2026-08-06）：今年投资逻辑的核心是竞争变化，本质是ROAS相对优势的变化，包括电商竞价推高eCPM、伤及游戏客户转化率，以及同行带来的新竞争。
- Meta（2026-04-30）：核心问题是缺少兑现AI故事的第二曲线。

**适用场景与注意事项**：通用。尤其适用于“业绩很好、股价却跌”的公司。易错点：矛盾提炼得太宽（“竞争加剧”），无法形成验证清单；应具体到变量（如ROAS、eCPM）。

### 13.2.2 识别市场核心矛盾切换，并重新分配指标权重

**方法要点**：海豚君在每篇观点中都明确“当前市场最关心的核心问题”，并判断它与上季相比是否发生了切换，再据此重新分配指标权重。核心矛盾错判会导致指标选择错误。

**操作步骤 / 拆分口径**：
1. 写出当前市场核心问题（一句话）。
2. 对比上季核心问题：是否切换？切换的方向是什么（如从“还能涨多高”转向“好日子能持续多久”）。
3. 把核心问题映射到关键指标：切换后，哪些指标权重上升，哪些降低。
4. 必要时分两层：短期（业绩超预期、突发事件）与中长期（赚钱的持续性：长协、需求保障度、远期展望）。
5. 用权重变化重排财报阅读顺序（核心问题、核心指标与已知/未知排序的前置方法见1.3）。

**关键指标与数据来源**：市场核心问题；对应的关键指标；权重变化。例如长期指引、SCA、长协与需求保障度、RPO、合同负债、产能计划。

**判断标准**：
- 美光：从“还能涨多高”转向“好日子能持续多久”，所以长期指引、SCA、RPO比单季beat更重要。
- ASML：从“需求有多强”转向“供给能扩多快、客户愿意为确定性付多少溢价”，所以合同负债和产能计划成为核心。
- 美光Q2时期：关注点分为短期（业绩超预期、罢工）和中长期（赚钱的持续性：长协、需求保障度、FY27展望）两层。

**海豚案例**：
- 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：核心矛盾切换为“好日子能持续多久”，指标权重向长期指引、SCA、RPO倾斜。
- 阿斯麦《阿斯麦：光刻机产能也紧俏了…》（2026-10-14）：核心矛盾从需求强度转向供给扩张与确定性溢价，合同负债与产能计划成为核心。
- 美光（2026-03-19）：短期/中长期两个维度并列。

**适用场景与注意事项**：适用于所有长期跟踪的公司，对周期上行阶段尤其重要，因为此时“单季beat”边际价值递减。订单类指标的口径见6.1、6.2与6.4。

### 13.2.3 识别决定“消化估值还是杀估值”的单一胜负手变量

**方法要点**：在观点段明确指出市场当下唯一的核心焦点变量（如旗舰芯片的放量节奏、新车型的量产爬坡），后续所有指引解读和估值判断都围绕它展开，并说明在这个变量于财报中实质兑现之前，向上博弈超额收益的空间有限。

**操作步骤 / 拆分口径**：
1. 找出单一变量：问“如果只能盯一个变量，哪个变量决定股价走向？”常见为核心产品出货量、量产节点、份额。
2. 阐明它与估值的关系：兑现则消化估值，不兑现则杀估值。
3. 把指引解读和估值判断都挂到该变量上：指引中与它直接相关的部分权重最高。
4. 设置兑现前后的操作含义：兑现前向上博弈的超额收益有限。

**关键指标与数据来源**：核心产品出货量、量产节点、份额。来源为财报、指引、产品周期与管线追踪（6.5）。

**判断标准**：
- 变量“实质兑现”才算数：只有预期与管理层表态，不算兑现。
- 在变量兑现前，向上博弈的超额收益空间有限，意味着操作上以等待或区间思路为主。

**海豚案例**：
- 地平线（2026-03-20、2026-09-01）：J6P（560 TOPS）的放量节奏是决定“消化估值”还是“杀估值”的胜负手。
- Rivian（2026-02-13、2026-05-01）：R2能否放量是支撑股价的核心逻辑。
- 小鹏（2026-03-20）：“一车双能”新车周期的爆发力。

**适用场景与注意事项**：适合单一产品驱动的成长股（智驾芯片、新车型、旗舰芯片等）。易错点：把变量设得过多，实际成了“因素清单”，与13.1.3提炼核心变量的思路冲突；同时要定期确认胜负手是否已切换（见13.2.2）。

### 13.2.4 识别投资逻辑阶段切换：技术验证 → 产能爬坡验证

**方法要点**：为成长股明确当前所处验证阶段及核心命题，并据此决定每季最该看的指标。

**操作步骤 / 拆分口径**：
1. 判断阶段：
   - 技术验证期：问“技术是否可靠、客户是否会用”；
   - 产能爬坡验证期：获得大客户背书、在手订单充足后，焦点从“需求是否真实”转向“供给能否跟上”。
2. 为当前阶段选指标：出货量、产能、交付节奏、项目延期、供应链。
3. 每季检查阶段是否已切换，切换后更新关注清单。

**关键指标与数据来源**：出货量、产能、在手订单、交付节奏。来源为财报、订单与交付披露（订单类指标见第6章）。

**判断标准**：
- 阶段切换的信号：已获得大规模客户背书、在手订单充足。
- 产能爬坡阶段，强劲交付可打消执行力与延期担忧。
- 若仍在技术验证阶段，不应用产能指标评价，反之亦然。

**海豚案例**：
- Bloom Energy（2026-07-29）：投资逻辑重心从“技术验证”迈入“产能爬坡验证”，已获CSP（云服务商）大规模背书；本季强劲交付打消执行力与延期担忧。

**适用场景与注意事项**：早中期成长股、新技术商业化公司。注意：阶段切换并非单季完成，需有客户背书、订单、交付三项证据同时支持。

### 13.2.5 市场担忧逐一证伪：先列分歧，再用数据与产业链信息逐条拆解

**方法要点**：股价回撤、市场分歧时，先明确列出市场最担心的几个深层矛盾，再逐条用数据和产业链信息证伪，最终落到出货和盈利预测。

**操作步骤 / 拆分口径**：
1. 列出市场担忧（三大分歧）：需求放缓、成本侵蚀单位盈利、涨价导致需求下降的负反馈。
2. 逐条证伪：
   - 需求端：用结构性变量对冲，如单车带电量、商用车、海外、市占率；
   - 成本端：用成本传导机制、上游一体化（参股洛阳钼业约25%、自有锂矿重启）、囤货和历史周期复盘；
   - 负反馈逻辑：用链主地位的逻辑悖论（高成本与弱需求无法长期共存：需求真弱，上游必然跌价）和刚性需求（AIDC断电的机会成本远超电池涨价）反驳。
3. 给出保守情景，并落到出货和盈利预测（盈利预测构建见12.6）。
4. 该论证链在文章层面的完整写法（“市场主要分歧 → 海豚君结构性优势 → 保守情景估值”）详见17.2。

**关键指标与数据来源**：各担忧对应的验证指标：带电量、成本传导周期、单Wh净利历史值。来源为财报、产业链价格、历史周期数据（成本传导与产业链验证见7.3与14.2）。

**判断标准**：
- 每一条担忧要对应一个可验证指标，而不是用态度反驳。
- 证伪需有结构性依据（一体化、历史单Wh净利稳定），而非只用“估值已低”。
- 对负反馈逻辑，用“若需求真弱则上游必然跌价”的逻辑悖论检验其自洽性。

**海豚案例**：
- 宁德时代（2026-03-10）：H股自去年10月2.5万亿高点回撤约18%，徘徊在2万亿；三大担忧（新能源车增速放缓、原材料上涨侵蚀单Wh盈利、涨价导致需求下降）逐一证伪；2021-22年锂价周期单Wh净利稳在0.11元；参股洛阳钼业约25%，江西锂矿有望2026年重启。

**适用场景与注意事项**：通用的观点写作框架，适用于存在明显市场分歧的财报。注意：证伪要给出保守情景，证明“即使担忧部分成立”结论也不至于崩坏。

### 13.2.6 强周期公司：业绩好 ≠ 持续，要看行业周期

**方法要点**：对强周期公司，靠降本提效挤出的利润只说明执行力；后续是上探新高还是利多落地后盘整，取决于行业走势。

**操作步骤 / 拆分口径**：
1. 拆分利润来源：调整后利润的变化中，来自降本提效/费用控制的部分与来自行业景气（中介、家装收入）的部分分别评估。
2. 判断行业走势：对地产链看楼市走势，对其他强周期看对应景气指标。
3. 区分“执行力”与“景气度”：前者说明管理层，后者决定持续性。
4. 给出结论：利多落地后是盘整还是再上一层，取决于行业。

**关键指标与数据来源**：调整后利润、中介/家装收入、楼市走势。来源为财报与行业景气数据（宏观与行业基准数据见14.3）。

**判断标准**：
- 利润增长而收入下跌，说明利润是挤出来的，不是行业推动的。
- 家装收入跌幅扩大等业务端信号，提示行业景气仍弱。

**海豚案例**：
- 贝壳（2026-08-21）：调整后利润32亿 vs 预期24亿，利润+75%而收入下跌；家装收入跌幅扩大。与13.1.2同篇点评相呼应：核心决定因素是楼市景气，次要因素是控费和二航道。

**适用场景与注意事项**：地产链、周期股。易错点：把降本带来的利润超预期外推为持续增长。

### 13.2.7 警惕周期品“成长叙事”过热，同时对非线性技术保持敬畏

**方法要点**：评估“周期股变成长股”时给出一对对冲原则：一方面警惕大宗商品资产的成长逻辑过热；另一方面，在AI基建超级周期中清空自己的历史“内存”，对新技术的非线性迭代保持敬畏。

**操作步骤 / 拆分口径**：
1. 警惕端：当大宗商品资产（如锂矿在吨价六七十万时）被喊出成长逻辑，往往是行业进入癫狂的时候，需高度警惕。
2. 敬畏端：在AI基建超级周期中，避免“太阳底下没有新鲜事”的经验主义，承认技术迭代可能是非线性的。
3. 佐证：2025年上半年美光自己还预期NAND去库存需要一段时间，结果NAND随后暴涨，说明管理层与历史经验都可能被非线性变化打破。
4. 落地方式：用硬证据（长协条款、担保金、capex构成）而不是情绪来判断“这次是否不同”。

**关键指标与数据来源**：商品价格所处历史分位；长协与担保等结构性证据；管理层过往预测的准确度。

**判断标准**：
- 商品价格处于历史极高分位时，成长叙事越流行，越需要警惕。
- 判断“这次不同”的证据应是结构性的（长协、担保金、capex构成），而不是需求的故事。
- 管理层过往预测的准确度越低，越不能依赖其“去库存”“复苏”等周期判断。

**海豚案例**：
- 美光《美光：牛气冲天！“凄凉周期”要变“超级成长”？》（2026-06-25）：以锂矿案例作为过热的警示，同时用美光2025年上半年对NAND去库存的判断被推翻，说明对新技术的非线性要有“敬畏感”。

**适用场景与注意事项**：适用于所有处于极端景气的周期行业研究（存储、锂、大宗商品等）。易错点：把“警惕”与“敬畏”当成互相矛盾——前者防过热，后者防低估，两者共同要求以硬证据判断。

### 13.2.8 同业横向比较“危机—组织变革”路径，评估管理层战略聚焦度

**方法要点**：横向比较同业在困境中的应对：现金压力迫使企业做组织反思、供应链改革和战略收缩；现金充裕的公司反而可能缺乏危机感、战线拉长。海豚君据此对战略聚焦度做定性评价，并作为估值倍数取舍的考量之一。

**操作步骤 / 拆分口径**：
1. 并排同业：比较各家的现金储备、费用结构、战略方向（新业务数量）、组织调整动作。
2. 判断路径：现金压力 → 组织反思、供应链改革、战略收缩；现金充裕 → 缺乏危机感、战线拉长。
3. 给出战略聚焦度的定性评价。
4. 把评价作为估值倍数取舍的考量（聚焦度低 → 给予更保守倍数）。
5. 用费用和利润数据验证（费用分项与组织效率见8.4与8.5）。

**关键指标与数据来源**：现金储备、费用结构、战略方向（新业务数量）、组织调整动作。

**判断标准**：
- 现金压力下的组织变革被视为“生死劫”后的结果；现金充裕下进入新业务（机器人、AI）而基本盘偏弱，视为聚焦度不足。
- 变革是否见效，要看降本增效在利润表中的体现。

**海豚案例**：
- 理想（2026-05-29）：蔚小理都经历了自己的“生死劫”；小鹏和蔚来因为现金短缺，经历了痛苦的组织反思、供应链改革和战略调整；理想靠L系列积累了现金，但这削弱了内部“度存亡”的危机感，在造车基本盘弱的情况下又进入机器人和AI，海豚君“还是希望看到造车上的组织反思和变革”。
- 蔚来（2026-03-10）：自2025年二季度开始大刀阔斧改革，被视为降本增效见效。

**适用场景与注意事项**：适用于行业洗牌期。定性判断要配合费用和利润数据验证，不能只凭“动作多”就判定变革有效。

**本节速查清单**
- [ ] 是否把主要矛盾提炼成“一件事”（眼前业绩 vs 长期威胁），并分别论证两端、给出操作建议？
- [ ] 是否写明当前市场核心问题，并与上季比较是否发生切换，据此重分配指标权重？
- [ ] 是否指出了决定“消化估值还是杀估值”的单一胜负手变量，且明确它在财报中兑现前的操作含义？
- [ ] 成长股当前处于“技术验证”还是“产能爬坡验证”阶段，每季看的指标是否随阶段更新？
- [ ] 有市场分歧时，是否先列出担忧、再用数据和产业链信息逐条证伪，并给出保守情景？
- [ ] 对强周期公司，是否区分了“降本带来的执行力”与“行业景气带来的持续性”？
- [ ] 对周期品成长叙事与新技术非线性，是否都用硬证据（长协、担保金、capex构成）而非情绪判断？

## 13.3 预测—验证闭环与观点复盘

> 本节导读：本节讲怎样把一次次点评连成可检验的研究闭环：先给出自己的预期与可证伪的观察点，下一季回测，再据此强化或修正观点，必要时坦然承认误判。适合持续覆盖的公司，每篇点评的开头（回顾）和结尾（验证清单）都要用到。数据与口径上承13.1的观点判断链，管理层承诺的兑现见9.6，目标价与估值区间的逐季回测见12.7，新收入线进度与催化剂跟踪见12.8，系列化追踪的版式见17.3。

**闭环流程**：设定（自有预期 + 验证清单）→ 记录（目标价、关键阈值、前期判断）→ 回测（下季用实际数据核对）→ 修正（强化或调整观点、盈利预测与估值）→ 写进下一篇的开篇回顾，再设定新的预期与验证清单。

### 13.3.1 明确给出“海豚君自有预期”，并与市场预期对比

**方法要点**：财报点评里不只复述市场预期，还对下季关键指标给出自己的方向性判断（往往与市场相反），写明理由，留作下季验证点。

**操作步骤 / 拆分口径**：
1. 选择下季的关键指标（如毛利率、ASP、出货量）。
2. 给出自己的预测（数值或方向），同时列出市场预期。
3. 写明理由：结构、规模、原材料等（可对应毛利率拆解的各项驱动，见第7章）。
4. 在下季发布后，用实际数据核对：判断得到验证则强化；低于或偏离预测则下修，并在后续文章中更新全年预测。
5. 新收入线等关键进度类指标，可同时比较“实际 vs 海豚君自身预期 vs 机构预期”并识别下一个催化，详见12.8。

**关键指标与数据来源**：下季毛利率、ASP、出货量的自有预测与市场预期；预测理由所需的结构数据（产品占比、销量环比、原材料价格）。

**判断标准**：
- 自有预期与市场预期方向相反时才具备信息量；一致时，需说明“为什么不是更高或更低”。
- 预测必须落在可验证数字上，实际值与预测值的偏差决定下一轮预测的调整幅度。

**海豚案例**：
- 理想（2026-03-12）：海豚君预计1Q26卖车毛利率继续环比走低、达到经营底部，而市场预期与4Q25持平（16.8%）；理由是i6占比升到60%、清库存降价、销量环比-17%至-22%、锂电和存储涨价。实际为6.1%，判断得到验证。
- 禾赛（2026-03-24）：海豚君预计1Q26综合ASP 1548元，与上季持平；实际1441元，低于预测，于是在后续文章中下修全年ASP。

**适用场景与注意事项**：通用。要求研究员持续记录预测，下季复盘偏差，避免只做事后解释。预测错误（如禾赛ASP）同样要留痕并用于修正后续预测，而不是删除。

### 13.3.2 设定下季度可证伪的关键观察点（验证清单）

**方法要点**：每篇观点结尾都给出后续需要验证的具体变量和阈值，把当期判断变成可跟踪的假设，供下季点评回溯。

**操作步骤 / 拆分口径**：
1. 回到观点的核心矛盾（见13.2），列出若干个关键变量。
2. 给每个变量设置阈值或条件，写成“可证伪”的形式：例如“客流回升能否延续到没有油价引流的季度”“旺季增速是否达到某水平”“某区域高增能否持续全年”“弱修复的原因是A还是B”“新帅上任后新品数据”。
3. 在观点结尾点名这些变量，形成下季复盘的目录。
4. 下一季按清单逐项回测（见13.3.3）。

**关键指标与数据来源**：指定的经营指标及阈值，数据来自下季财报、电话会与行业数据。

**判断标准**：
- 清单项要有明确的“是/否”判据，能被下季数据回答。
- “原因归属类”清单项（A还是B）也要给出区分指标，如区分“有税拖累”与“渠道转移”的数据。

**海豚案例**：
- Costco（2026-09-25）：观察客流回升能否延续到没有油价引流的季度，以及FY27上半年退税让利对核心毛利率的压制。
- 东鹏饮料（2026-04-30）：二季度能量饮料约15%，补水啦旺季能否回到30%以上；华北高增是否持续；单商产出。
- 中国中免（2026-04-29）：弱修复是有税拖累，还是渠道转移。
- Lululemon（2026-06-05）：等9月新帅到位、新品周期数据进一步验证。

**适用场景与注意事项**：所有财报点评都适用，用于构建跨季度的跟踪闭环。注意：阈值不应事后修改，否则失去回溯意义。

### 13.3.3 每季回测前期判断与估值，形成“预测→验证”闭环

**方法要点**：每季复盘上一季给出的判断和估值：目标价区间是否被触及；管理层指引的投入影响是否按剧本兑现；海豚君对某板块的逻辑是否被验证。被验证的强化，没被验证的修正。

**操作步骤 / 拆分口径**：
1. 提取上一季的前期判断、前期目标价、板块逻辑。
2. 对照实际结果：
   - 目标价区间：股价是否触及，位置在哪（如逼近上限）；
   - 管理层指引的投入影响：是否按剧本兑现；
   - 板块逻辑：是否被验证（如“电商利润率只要想要总能挤出来”“新业务亏损如预期没有缩窄多少”）。
3. 被验证的强化，没被验证的修正，持续校准判断。
4. 目标价与PE区间的逐季回测，见12.7。

**关键指标与数据来源**：前期判断、前期目标价、实际结果。

**判断标准**：
- 目标价区间被触及或接近上限，说明估值判断基本有效，后续是否继续上修需要重新评估（目标兑现后的操作调整见13.3.4）。
- 指引的投入影响与实际基本吻合，可信度上升。
- 板块逻辑被验证后，可作为后续预测的默认假设；未被验证则需重新检视核心假设。

**海豚案例**：
- 英伟达（2026-05-21）：上次给175-240美元目标区间，近期股价高点236美元接近上限。
- B站（2026-05-19）：AI投入影响约0.5-1亿，“基本是按照指引的剧本走”。
- SEA（2026-05-12）：游戏表现“逻辑上也符合海豚君此前的判断”。
- SEA（2026-08-11）：“如同海豚君预期的‘只要想要，电商板块总归能挤出利润’”。
- 京东（2026-08-13）：创新业务亏损“如同海豚君预期的较上季并没有缩窄多少”。

**适用场景与注意事项**：适用于持续覆盖的研究体系。注意：回测要既看“对了”也看“错了”，只记对的会造成幸存者偏差。

### 13.3.4 前期判断的回溯验证：目标兑现、压力测试、此前预判

**方法要点**：在新一季点评中引用上一季或深度中的判断并核对，三类结果对应三种后续动作，形成可检验的研究闭环。

**操作步骤 / 拆分口径**：
1. 估值目标已兑现 → 调整操作建议（持有不追高）。
2. 风险预言兑现 → 判定公司“未通过压力测试”，强化商业模式定性。
3. 利润问题此前已预判 → 延续判断逻辑，并更新后续预测。
4. 在点评中明确引用上期判断的位置，以便读者核对。

**关键指标与数据来源**：前期目标价/估值、前期风险判断。

**判断标准**：
- 目标兑现的判据：股价或市值达到前期设定的倍数或市值目标，如40倍、920亿美元市值。
- 压力测试的判据：前期假设的“压力情景”（如金价下行周期周转率下滑）真实发生并冲击业绩。
- 费用刚性等利润问题，若此前已作出判断，延续判断而不重复推演。

**海豚案例**：
- Monster（2026-08-07）：一季度点评的40倍、920亿美元市值目标7月中旬兑现（目标兑现对应的处理原则是持有不追高）。
- 老铺黄金（2026-08-25）：引用此前“金价下行周期周转率下滑会严重冲击业绩”，认为老铺未通过压力测试。
- 名创优品（2026-05-26）：费用刚性问题“海豚君此前就做出了判断”。

**适用场景与注意事项**：持续覆盖的公司。管理层承诺与前期表态是否兑现，属于对管理层可信度的验证，详见9.6。

### 13.3.5 回顾上季观点并用本季数据验证或修正，形成连续追踪链

**方法要点**：每篇点评引用上季判断，用本季数据验证，并同时检查管理层上季口径（长期毛利率目标、出货目标）在本季是否维持，形成跨季度追踪链。

**操作步骤 / 拆分口径**：
1. 提取上季观点（采购改革是否利好、国际回暖是否持续、AI模型威胁是否需要悲观等）。
2. 提取上季管理层口径（长期毛利率目标、出货目标等）。
3. 对照本季数据：
   - 观点是否被证实或证伪；
   - 管理层口径是否维持、是否被修正。
4. 同时跟踪上季担忧是否兑现（如“价的崩塌”）。
5. 若验证，则延续判断；若证伪，则修正结论，并写出修正原因。

**关键指标与数据来源**：上季观点、上季管理层口径、本季对应数据。

**判断标准**：
- “淡季不淡”之类的验证，意味着上季的利好逻辑得到数据支持。
- “意外回暖”但未延续，印证上季“持续性存疑”的谨慎。
- 上季提出的威胁（如大模型威胁）被订单证伪，则在本季观点中降低相应风险权重。
- 管理层口径（如“30%毛利率是储能合理长期目标”）要检查本季表现是否与之一致。

**海豚案例**：
- Palantir《再交硬核成绩单》（2026-02-03）：政府淡季不淡，印证上季“采购体系改革反而利好”的判断。
- Palantir《瑕疵修复》（2026-08-04）：Q1国际商业“意外回暖”未延续，印证上季的谨慎；上季讨论的大模型威胁被订单证伪。
- 阳光电源《收入倒春寒》（2026-04-28）：引用上季管理层“30%毛利率是储能合理长期目标”，并跟踪上季担忧的“价的崩塌”是否兑现。

**适用场景与注意事项**：适用于长期覆盖的标的。管理层承诺兑现的专门方法见9.6；本方法重点在“观点”与“口径”的连续追踪。

### 13.3.6 前后季度观点一致性复盘与自我纠错

**方法要点**：每季回顾上季判断，验证或承认误判，并据此调整盈利预测与估值观点，形成连续跟踪的可信度与修正机制。

**操作步骤 / 拆分口径**：
1. 回顾上季判断：验证（“应了海豚君上季度说的”“验证了上季财报已看到的迹象”“不幸演绎了预期的悲观剧本”）或承认误判（“对消费政策、世界杯期待值过高，有所误判”）。
2. 量化调整：上季预测vs实际，调整幅度是多少。
3. 调整盈利预测与估值观点：如从“不必悲观”转为“修复已走完大半”。
4. 明确写出前后观点的变化，使读者能追踪。

**关键指标与数据来源**：上季预测 vs 实际、预测调整幅度。

**判断标准**：
- 判断被验证 → 观点延续；被证伪 → 必须承认并调整，而不是改口径后默默更新。
- 观点方向的变化（“不必进一步悲观” → “修复已走完大半”）需有数据依据。

**海豚案例**：
- 亚马逊（2026-07-31）、Airbnb（2026-08-07）、奈飞（2026-07-17）：均在点评中回顾上季判断，并据此调整盈利预测与估值观点。
- 奈飞（2026-04-17）：“不同于上季度我们强调不必进一步悲观”，观点随数据切换。
- 分众（2026-08-21）：下调后预计今年收入123亿（-3.8%）、扣非归母50亿。

**适用场景与注意事项**：持续跟踪覆盖。承认误判是可信度机制的一部分；但调整必须量化，避免用含糊措辞掩盖修正。

### 13.3.7 开篇回顾上期核心观点，在本期验证

**方法要点**：开篇先回顾上期点评的核心观点（或首篇深度的判断），再给出本期“是否改善”的结论；或引用此前已经指出的问题和测算区间，证明判断的连续性，并据此更新观点。

**操作步骤 / 拆分口径**：
1. 找出上期点评或深度的核心观点（或测算区间）。
2. 在开篇引用，并给出本期是否改善的结论。
3. 若此前有测算区间或安全区间，用本期数据核对。
4. 据此更新本期观点。

**关键指标与数据来源**：上期观点、本期验证结果。

**判断标准**：
- 本期数据验证了上期判断 → 观点延续；
- 若上期问题已price-in（如生活场景收缩已基本price-in），则本期观点相应更新。

**海豚案例**：
- 美图（2026-08-26）：回顾25财年点评“生活场景基本盘受挫、生产力能见度差”，结论是生活场景收缩已基本price-in。
- Shopify（2026-08-06）：上季已指出AI主方向转向2B。
- 微软（2026-01-29）：上次已提到OpenAI约2500亿合同。
- Unity（2026-05-08）：回溯3月27日预告点评中测算的安全区间。

**适用场景与注意事项**：持续覆盖的公司。开篇回顾要简洁，重点放在“本期是否验证”，而不是复述上期全文。
