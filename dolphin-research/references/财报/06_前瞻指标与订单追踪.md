# 第6章 前瞻指标与订单追踪

> **本章目的**：用订单、合同、预收、年化收入、产品管线等领先指标，判断未来几个季度的收入可见度和供需状态。

**本章小节**：6.1 RPO、Backlog与新签订单｜6.2 合同负债、预收与递延收入｜6.3 ARR/ACV/MRR等年化收入指标｜6.4 订单质量、可见度与供需约束｜6.5 产品周期、管线与新业务里程碑

---

## 6.1 RPO、Backlog与新签订单

> 本节导读：本节解决“收入还没确认，怎么提前看到未来几个季度的可见度”的问题：用 RPO、Backlog、新签订单这类已锁定的合同余额，判断收入加速或放缓的确定性，并识别增量背后的客户、合同与期限结构。适用于云、AI 基础设施、企业软件、设备、航天军工等订单驱动或订阅制公司的财报点评，尤其是 RPO 暴增或停滞的季度。与 6.2（资产负债表预收项）、6.3（ACV / ARR / MRR）、6.4（订单真实性与供需约束）配合使用；客户集中度的一般方法见 5.5，把订单折算成收入预期见 9.2。

### 6.1.1 按商业模式选择前瞻指标，搭建订单指标组

**方法要点**：不同商业模式的“订单”口径不同，先选对前瞻指标，再把它们组合成一组指标，用来验证收入增长的可持续性；重点看环比净增量和来源结构，而不是只看余额。

**操作步骤 / 拆分口径 / 公式**：
1. 按商业模式选指标：
   - SaaS：cRPO（12 个月内确认的剩余履约义务）与新增订单（新签）。
   - IP 授权：ACV、RPO，以及 ACV/RPO 比值（判断订单期限结构，详见 6.3）。
   - 数据平台 / 政企混合软件：TCV、RPO、客户数。
   - 服务器：AI 新增订单与积压订单。
   - 设备商：订单。
2. 搭建订单指标组：TCV（当期新签总价值）、RPO 与 RDV（RDV 含可取消合同，RPO 只含不可取消的已锁定部分）、cRPO、积压订单、客户数净增。
3. 对每个指标先算环比净增量，再拆来源结构（企业还是政府、哪家大客户）。
4. 把前瞻指标与当季收入增速并列，检验“收入增长有没有订单支撑”。

**关键指标与数据来源**：cRPO、新增订单、ACV、RPO、TCV、RDV、客户数、积压订单；来源为公司财报、电话会披露及一致预期。

**判断标准**：
- 前瞻指标要看净增量与来源，而不是静态余额；同一指标的不同拆分（企业 / 政府、短期 / 长期）往往给出相反信号。
- 新增订单增速骤降而 cRPO 增速持平，说明需求边际转弱，cRPO 的“稳”只是期限结构在撑；cRPO 仅提速 0.5pct 属于弱信号。
- 订单与积压大幅超预期而收入略低时，以订单为准做判断，并据此估计下季收入（详见 6.4.1）。
- 前瞻指标同向改善且收入高增，才说明增长可持续。

**海豚案例**：
- Salesforce（2026-05-28）：cRPO +13%，与上季持平；新增订单仅 +4%（上季 +19%），前瞻指标背离。
- ARM（2026-05-07）：ACV 16.6 亿；RPO 20.7 亿，低于预期的 26.7 亿；从 ACV/RPO 看在手订单偏短期。
- Palantir（2026-05-05）：TCV、RPO、客户数环比均增长。
- 戴尔（2026-05-29）：AI 订单 244 亿（预期 100-150 亿），积压订单 513 亿，据此估计下季 AI 收入 155 亿+。
- Palantir（2026-08-04）：TCV 34 亿，其中美国企业 21 亿；美国商业 TCV 环比净增 9.5 亿；RPO / RDV 环比净增；收入 +93%。
- Salesforce：cRPO 只提速 0.5pct；Agentforce + 数据云 ARR 39 亿，上期 34 亿。
- CoreWeave：未履约合同 1040 亿，环比 +46 亿，符合预期。
- 戴尔（2026-09-02）：AI 新增订单 609 亿，积压订单 950 亿。
- Unity：RPO 显示 Create 业务短期承压。

**适用场景与注意事项**：适用于软件、IP 授权、数据平台、服务器、设备等披露订单类指标的公司。不同公司对 RPO、TCV、ACV、Backlog 的定义不同，跨公司比较前先对齐口径；需识别框架性协议与非真实订单（见 6.4.2）。

### 6.1.2 RPO / Backlog 环比净增：对账大单、对比预期与历史峰值

**方法要点**：RPO 是领先指标，把环比净增额与历史峰值、媒体报道的大单、市场预期逐一对账，推断增量来自谁、是否超预期，并评估其对业绩与情绪的双重意义。

**操作步骤 / 拆分口径 / 公式**：
1. 计算 RPO（或 Backlog）环比净增额 = 期末余额 − 上季末余额，并与历史单季净增峰值比较。
2. 逐一对账季内媒体报道的大单（金额、客户），看净增额能被哪些合同解释。
3. 如果没有大单新闻但 RPO 仍大增，推断增量来自长尾 / 新客户，再用电话会披露的新增客户数验证。
4. 把实际值与市场预期（彭博一致预期、投行预期）比较；财报前没有大单传闻时，市场预期会偏低，超预期更显著。
5. 结合新闻推测订单来源（例如政府订单），评估其双重意义：业绩贡献（可推测达百亿级）与政府支持态度带来的情绪利好。
6. 关注季后至今的新签订单，作为对期末数据的补充。
7. 判断当前阶段市场对 RPO 的关注度：当关注点已转向执行与融资时，要看新订单会不会改变既定融资计划。

**关键指标与数据来源**：RPO 余额、环比净增、媒体报道的合同金额、新增客户数、期后新签金额、彭博一致预期（或投行预期）。

**判断标准**：
- 净增额创历史单季新高、且能与大单对上，说明需求强且增量可解释，但要同步评估客户集中度（见 6.1.4）。
- 对不上大单却大增，推断来自长尾或新客户，对头部客户的依赖在缓解。
- 低于投行预期（如预期 100 亿、实际净增 46 亿）说明增量放缓，需用期后新签订单判断是时点问题还是趋势。
- 超预期部分若可对应政府 / 战略客户订单，除业绩外还有情绪溢价；若公司明确新订单不影响既定融资计划，则资金面中性。

**海豚案例**：
- CoreWeave（2026-02-27）：RPO 668 亿，高于彭博一致预期 620 亿；环比增近 170 亿（上季 200 亿），季内没有大单新闻，推断来自非头部客户，电话会证实新增客户数是此前高点的 2 倍（Cognition、Cursor、Mercado Libre、Midjourney、Runway）。
- CoreWeave（2026-05-08）：RPO 994 亿，环比增约 330 亿创纪录，与 Meta 210 亿、Jane Street 60 亿、Anthropic 数十亿的订单大体对得上。
- CoreWeave（2026-08-12）：RPO 1040 亿，只环比增 46 亿，略低于部分投行 100 亿的预期；三季度至今新签约约 250 亿。
- 谷歌《1Q26》（2026-04-30）：Backlog 4620 亿，去年末 2400 亿；净增 2200 亿主要来自 Anthropic、Meta。
- 甲骨文（2026-06-11）：RPO 环比增 850 亿至 6380 亿，市场预期约 5900 亿；推测超预期部分来自美国联邦政府和战争部合作；另有客户预付或自供硬件合同达 750 亿。
- 甲骨文（2026-09-11）：RPO 6640 亿，环比 +260 亿，公司表示新订单不影响既定融资计划。

**适用场景与注意事项**：适合披露 RPO / Backlog 的云、软件、设备公司；需要结合期限结构（6.1.6）和客户集中度（6.1.4）一起看。媒体报道的合同金额通常是上限或框架金额，对账时要区分是否已进入 RPO（见 6.1.5、6.4.2）。

### 6.1.3 新签订单倒算：新签合同额 ≈ ΔRPO / Backlog + 当季确认收入

**方法要点**：多数公司不披露新签合同额，可用“期末余额净增 + 当季确认收入”粗算新签，再与确认收入、上季和同业比较，判断收入将加速还是放缓。

**操作步骤 / 拆分口径 / 公式**：
1. 记录期末 Backlog / RPO，算环比净增额 = 期末 − 上季末。
2. 公式：**新签合同额 ≈ 环比净增额 + 当季确认收入**（确认收入取与 Backlog 对应的业务口径，如云收入）。
3. 与上季新签、同业新签比较，看新签是在加速还是放缓。
4. 新签 vs 当季确认的同类收入（如 to B 云收入）：新签大于确认收入，RPO 必然越积越多，预示未来收入。
5. 订单厚度：用 RPO 环比净增额相当于当季核心业务收入的倍数，衡量新增订单的厚度（例如一个季度新增了约 1.5 年的收入）。
6. RPO 环比下滑时，新签合同额环比下降，据此判断订阅业务后续短期增长压力，并检验涨价对新签规模的拉动效果。
7. 合同期限结构（短 / 长期占比）待年报校正，用来判断对下一年收入的支撑。

**关键指标与数据来源**：Backlog / RPO、环比净增、当季确认收入、新签合同额、to B 云收入、RPO 净增 / 当季收入、短 / 长期合同占比；来源为财报与电话会。

**判断标准**：
- Backlog 是云 / 订阅公司最关键的前瞻指标（海豚君称为“情绪指标”）。
- 新签远超确认收入，意味着随产能释放收入必然加速；新签低于确认收入或持续下滑，说明增长后劲不足。
- RPO 净增相当于数倍季度核心业务收入，说明订单储备很厚。
- 涨价（如产品提价 5%）对新签规模没有拉动，说明价格动作没有转化为需求。

**海豚案例**：
- 谷歌《谷歌：大哥也疯狂，翻倍赌 AI》（2026-02-05）：Q4 Backlog 2400 亿，环比净增 850 亿，计算新增合同 1027 亿；Q3 为净增 470 亿 / 新签 620 亿。
- 谷歌（2026-04-30）：Backlog 4620 亿，净增 2200 亿，新签 2400 亿（大头为云合同，小部分为 TPU 直销）。
- 谷歌（2026-07-23）：Backlog 5140 亿，净增约 500 亿，新签 1000 亿。
- 亚马逊（2026-07-31）：合同余额 4690 亿，环比新增千亿，毛估新签约 1500 亿，显著超过微软。
- 微软（2026-07-30）：新签 774 亿，对比 to B 云收入 593 亿；RPO 环比增 500 亿至 6780 亿。
- 甲骨文（2026-03-11）：RPO 5530 亿，环比净增约 300 亿，相当于本季 OCI 收入的 6 倍（约 1.5 年收入）。
- Unity（Create 业务，2026-08-07）：RPO 环比 -4%，粗算新签合同额环比下降；年初 Unity 6 涨价 5%，对新签规模拉动不大。

**适用场景与注意事项**：云、SaaS、军工、设备等订单驱动行业，订阅 / 合同制软件同样适用。该公式是粗算，余额变动还会受汇率、合同修订等影响；要识别框架性 / 非真实订单；期限结构需待年报校正。

### 6.1.4 剔除单一大客户，看“常态”增速并推断客户集中度

**方法要点**：领先指标暴增时，先找出来自少数大客户的部分，再算剔除后的增速是否正常，同时从新增额的趋势和是否有大单传闻，推断客户集中度的变化。

**操作步骤 / 拆分口径 / 公式**：
1. 找出领先指标暴增中来自少数大客户的部分及其占 RPO 的比重。
2. 计算剔除后的 RPO / 新签合同同比（同时给出“不剔除”口径对比）。
3. 对集中于少数、自身造血能力有限的客户的“异常”大单，不能太当回事。
4. 反过来：大客户订单消失后新签合同可能负增长，这时也要剔除该客户看剩余部分的真实增速，并据此解释核心业务增速乏力的原因。
5. 看环比新增额的趋势（是否“沉寂”）：大单落袋后连续多季新增走低，要有预期。
6. 新增额较大而又没有大单传闻时，可推断客户集中度有所改善。
7. 反推大客户订单余额的环比变化（用剔除前后同比差异倒算）。

**关键指标与数据来源**：新签企业合同额同比、RPO 及环比增量、大客户占 RPO 比重、剔除大客户后 RPO 同比、环比新增额；来源为财报、电话会及大客户公开承诺。

**判断标准**：
- 剔除大客户后的增速才是“常态”增速（如不剔除 +99%，剔除后仅 +26% ~ +29%）。
- 大客户占比越高，指标含金量越低；大客户余额环比下降意味着订单被消耗而未补充。
- 新增额大且无大单传闻 → 来自长尾客户 → 集中度改善；新增额连续走低 → 订单动能“沉寂”。

**海豚案例**：
- 微软（2026-01-29）：新签合同 +230%，RPO 环比增约 2330 亿至 6250 亿，主要来自 OpenAI 约 2500 亿承诺和 Anthropic 约 300 亿；OpenAI 占 RPO 约 45%（2810 亿），剔除后 RPO 同比仅 +28%。
- 微软（2026-05-01）：新签合同 -4%，剔除 OAI 后 +7%；RPO 6270 亿，环比仅增 20 亿，剔除 OAI 同比 +29%，不剔除 +99%。
- 微软（2026-04-30）：RPO +99%，剔除 OpenAI 仅 +26%，测算 OAI 余额环比减少约 50 亿（不同文章对剔除后同比取值略有差异，+26% / +29%）。
- 谷歌（2026-02-05）：云 RPO 2400 亿，环比净增 850 亿。
- 甲骨文（2026-03-11）：RPO 环比 +约 290 亿，1Q 签下大单后连续两季新增走低，有些“沉寂”。
- CoreWeave（2026-02-27）：RPO 668 亿 vs 彭博预期 620 亿，环比 +近 170 亿（上季 200 亿），没有大单传闻，可能来自非巨头客户，对头部客户的依赖有所缓解。

**适用场景与注意事项**：客户集中度高的云、AI 基础设施、软件公司。前提是能拿到大客户的公开承诺金额；剔除口径是估算，应同时报告剔除前后两个数字；客户集中度的一般框架见 5.5。

### 6.1.5 把增量追溯到具体大合同，并折算年化收入、核对是否已计入

**方法要点**：前瞻指标或收入出现大幅环比增量时，把增量拆到具体公开合同（金额、客户、项目），判断是一次性脉冲还是可持续需求；再把大单折算成年化收入，核对是否已计入 RPO，以判断未来收入加速的确定性。

**操作步骤 / 拆分口径 / 公式**：
1. 把环比净增额拆到具体公开合同（金额、客户、项目、期限）。
2. 判断是一次性脉冲还是可持续需求；脉冲过后下季净增放缓，视为“自然放缓”，不等于需求转弱。
3. 公式：**年化收入贡献 ≈ 合同金额 ÷ 合同年限**。
4. 核对哪些大单已计入 RPO、哪些还没计入，据此判断未来收入加速的确定性。
5. 同时记录芯片使用承诺（GW 算力承诺）以及公司对大客户的追加投资等关联安排。

**关键指标与数据来源**：RPO 环比净增额、具体合同金额与期限、年化收入贡献、GW 算力承诺；来源为财报、电话会及公开合同公告。

**判断标准**：
- 已计入 RPO 的大单，对应收入将按合同节奏兑现；尚未计入的大单是 RPO 的潜在增量。
- 增量完全由少数脉冲合同贡献时，下季净增放缓属常态，不应据此下“需求转弱”的结论。

**海豚案例**：
- Palantir《再交硬核成绩单》（2026-02-03）：RPO 环比净增近 16 亿，包括海军 ShipOS 4.5 亿、英国国防部追加 3.1 亿，以及 61 家 1000 万美元以上的企业订单。
- Palantir《软件末日论汹涌》（2026-05-05）：Q1 RPO 净增 3.7 亿，视为上季脉冲后的自然放缓。
- SpaceX《豪赌AI》（2026-08-05）：Anthropic 协议贡献约 16 亿增量收入。
- Rocket Lab《中子号或延期》（2026-08-11）：SB-AMTI 3.97 亿美元。
- 亚马逊（2026-04-30）：RPO 从上季 2440 亿增至 3640 亿，已含 OpenAI 订单，Anthropic 的千亿合同还没计入；OpenAI 把对 AWS 的承诺扩大到 1380 亿 / 7 年，相当于每年约 200 亿 AWS 收入，其中约 2GW 基于 Trainium；Anthropic 扩大到 10 年 1000 亿、合计使用 5GW Trainium；亚马逊承诺再投资 Anthropic 50 亿，最多可追加 200 亿。

**适用场景与注意事项**：大合同驱动的企业软件、军工、云服务、算力服务商。合同金额折算年化收入是平均口径，实际确认节奏受产能和交付进度影响（6.1.7）；公开合同信息可能存在上限金额与框架金额，需结合 6.4.2 打折。

### 6.1.6 RPO / Backlog 期限结构：24 个月内 vs 以上、12 个月内确认比例与分部拆分

**方法要点**：把 RPO / Backlog 按确认期限（以及分部）拆开，判断新增订单对近期收入有没有帮助、未来 1-2 年增长的能见度有多高。

**操作步骤 / 拆分口径 / 公式**：
- 变体 A：24 个月内 vs 24 个月以上
  1. 把 RPO 拆成 24 个月内确认和 24 个月以上两部分，分别看余额及环比变化。
  2. 若新增全部落在远期、24 个月内余额不增反降，则新合同对近期收入没有帮助，应下调近期增速预期、上调远期。
- 变体 B：用披露的未来 24 个月确认比例换算两年可确认收入
  1. 用公司披露的 Backlog 中未来 24 个月确认比例（如“约一半两年内确认”）换算未来两年可确认收入，估算收入可见度。
  2. 结合合同期限结构（短 / 长期占比，待年报校正）判断对下一年收入的支撑。
- 变体 C：按分部 + 按确认期限双维拆分，再加季后新签
  1. 把在手订单拆成分部（如发射 / 太空系统）和确认期限（未来 12 个月 vs 12 个月以后）两个维度，得到下一年可见收入。
  2. 加上季度内和季后新签订单，按分部拆分并列出重大合同，评估订单动能。
  3. 发射业务另追踪在手发射次数。

**关键指标与数据来源**：24 个月内 RPO 余额、24 个月以上 RPO 余额、环比变化；24 个月内确认占比；在手订单总额、分部占比、12 个月内确认比例、新签合同额（分部）、在手发射次数、重大合同金额。

**判断标准**：
- 24 个月内余额下降、新增全在远期 → 近期收入没有新合同支撑，要等到更远年份才落地。
- 超过一半的积压订单两年内确认 → 1-2 年收入高增无忧。
- 12 个月内确认比例（如 45.5%）直接给出下一年可见收入；再叠加新签订单与重大合同，评估订单动能是否在加强。
- 在手发射订单创历史新高，说明发射业务需求储备充足。

**海豚案例**：
- CoreWeave（2026-05-08）：24 个月内的 RPO 余额实际在下降，新增部分全部在 24 个月以上，说明近期新签合同大多要到 27 年以后才开始落地。
- 谷歌（2026-04-30）：积压订单超一半两年内确认 → 1-2 年收入高增无忧；同时依据“约一半两年内确认”估算收入可见度。
- Rocket Lab《中子号或延期》（2026-08-11）：在手订单 24 亿美元（发射约 40% 即 9.4 亿，太空系统 60% 即 14.2 亿），45.5%（10.9 亿）将在未来 12 个月确认；Q2 + 季后新签超 10 亿（发射 4.37 亿，太空系统 5.81 亿，含 SB-AMTI 3.97 亿、3 颗 GEO 卫星超 1.6 亿）；Q2 新增 26 次发射，在手发射订单超 90 次、创历史新高。

**适用场景与注意事项**：适合披露 cRPO / RPO 期限的 SaaS、云、长约供应商，以及订单驱动型的航天、军工、设备、工程公司。期限信息往往只在年报或特定季度披露；期限越长，取消或重谈条款的风险越大（见 6.4.3）。

### 6.1.7 当期收入 ÷ 上季 Backlog 转化率：判断供给约束

**方法要点**：用“当期收入 / 上季末 Backlog”的转化率判断收入没起来是需求问题还是供给问题；转化率持续下降，说明订单在积压而产能跟不上。

**操作步骤 / 拆分口径 / 公式**：
1. 公式：**转化率 = 当期确认收入 ÷ 上季末 Backlog**，逐季记录，形成趋势。
2. 若转化率持续下降，说明问题不在需求，而在产能供给跟不上。
3. 结合管理层是否反复表达“供不应求”，进一步推导管理层可能把订单外包给第三方平台承接。
4. 外包承接会压低云业务后续利润率，要把这一影响计入利润率预期。

**关键指标与数据来源**：当期收入、上季末 Backlog、转化率趋势、外包比例（若披露）；来源为财报与电话会。

**判断标准**：转化率连续多期下降 + 管理层反复强调供不应求 + Backlog 仍在增加 → 供给约束；此时收入由产能释放节奏决定，并且利润率可能因外包而受压。

**海豚案例**：
- 谷歌（2026-07-27）：当期收入与上季 Backlog 转化率持续下降，管理层反复表达供不应求，考虑将订单外包第三方 → 影响云利润率。

**适用场景与注意事项**：产能受限的订单型公司；需多期数据形成趋势，单期转化率受季节性和合同结构影响。供需判断的更多证据（三线对照、需求满足率等）见 6.4。

### 6.1.8 拆分短期（cRPO）与长期 RPO，检验订单含金量和 cRPO 提速的质量

**方法要点**：把 RPO 拆成 12 个月内确认的短期部分（cRPO）和长期部分，区分“真提速”与“期限结构搬家”。

**操作步骤 / 拆分口径 / 公式**：
1. 把 RPO 拆为短期（cRPO，12 个月内确认）与长期两部分，分别算同比增速。
2. 短期 RPO 增速更快：说明锁单中能快速确认收入的比例上升，订单含金量改善。
3. 若 cRPO 提速，但总 RPO 与一年以上 RPO 放缓，说明只是长期转短期的期限结构变化，并非新需求。
4. 用新签订单增速复核：新签订单增速低于 cRPO 增速，则提速主要来自期限结构（详见 6.1.10）。

**关键指标与数据来源**：短期 RPO（cRPO）、长期 RPO、总 RPO 增速、新签订单增速；cRPO 增速用恒定汇率口径。

**判断标准**：
- 短期 RPO 增速 > 长期 / 总 RPO 增速，且新签订单同步走强 → 含金量改善。
- cRPO 提速 + 总 RPO / 一年以上 RPO 放缓 + 新签订单增速低于 cRPO → 提速质量低。

**海豚案例**：
- Palantir《瑕疵修复》（2026-08-04）：RPO 49 亿，其中短期 20.9 亿（+105%），长期 28.1 亿，短期增速更快，订单含金量改善。
- Salesforce《“AI替代论”证伪？》（2026-08-27）：cRPO 335 亿，恒定汇率 +14%（提速 1pct），但总 RPO 与一年以上 RPO 放缓，新签订单约 99 亿（+10%）低于 cRPO 增速，判断提速主要来自期限结构变化。

**适用场景与注意事项**：适用于披露 RPO 期限结构的软件和合同制公司；cRPO 要用恒定汇率口径，避免汇率噪音（汇率剔除见 4.1）。

### 6.1.9 TCV 与 RPO 增速偏离，推断新增订单的客户结构

**方法要点**：RPO 只含不可取消的已锁定部分，TCV 含全部合同价值；两者增速是否同步，可以反推短期增量来自政府端还是企业端。

**操作步骤 / 拆分口径 / 公式**：
1. 对比 TCV 增速与 RPO 增速：同步，说明新增合同基本都锁定；
2. RPO 增速持续高于 TCV（偏离），说明短期增量主要来自政府端的扎堆签约（政府合同金额大、不可取消比例高），企业端新签放缓；
3. 拆分客户口径（如美国商业 TCV）看企业端是否放缓；
4. 结合公开签单信息，推测增量来源（如英国政府、农业部、国防部等）。

**关键指标与数据来源**：TCV 增速、RPO 增速、分客户 TCV（美国商业 TCV）、公开合同信息。

**判断标准**：TCV 与 RPO 同步 → 新增合同基本锁定；RPO 连续两季高于 TCV 且美国商业 TCV 增速下滑 → 增量集中于政府，企业端动能减弱。

**海豚案例**：
- Palantir《再交硬核成绩单》（2026-02-03）：TCV 环比增 15 亿，与 RPO 基本同步，说明新增合同多为锁定需求；美国商业 TCV 增速放缓至 67.4%，新签主要在政府端，推测 RPO 增量来自英国政府。
- Palantir《软件末日论汹涌》（2026-05-05）：TCV +61%、环比减少 18 亿，RPO +134%，连续两季偏离，判断农业部、国防部、能源部、财政部等政府合同扎堆，企业端或有放缓。

**适用场景与注意事项**：适用于政企混合、同时披露 TCV 与 RPO 的软件公司；“推测增量来自某政府”属于逻辑推断，需有公开签单信息佐证。

### 6.1.10 新签订单金额及同比增速，与 cRPO 增速比较

**方法要点**：把新签订单金额与同比增速作为需求强弱的独立证据，与 cRPO 增速交叉对照，识别 cRPO 提速的真实来源。

**操作步骤 / 拆分口径 / 公式**：
1. 单独追踪新签订单金额及同比增速（披露或可推算，推算方法见 6.1.3）。
2. 新签订单断崖下跌、同比增速创新低时，即使 cRPO 增速持平，也说明需求不强。
3. 新签订单增速低于 cRPO 增速时，cRPO 提速更多来自期限结构变化。
4. 与上季及历史低点对比，判断是反弹还是继续走弱。

**关键指标与数据来源**：新签订单金额、同比增速、cRPO 增速；来源为财报及电话会。

**判断标准**：新签同比增速创两年新低 → 需求弱；新签反弹但增速仍低于 cRPO → 提速质量不足。

**海豚案例**：
- Salesforce《既没增长也没利润》（2026-05-28）：新签订单约 72 亿，上季 205 亿，同比仅 +4%，为 1Q25 以来两年内最低。
- Salesforce《“AI替代论”证伪？》（2026-08-27）：新签订单约 99 亿（+近 10%），反弹但低于 cRPO 增速。

**适用场景与注意事项**：适用于披露或可推算新签订单的订阅制软件公司；新签订单季度波动大，需看同比与连续多季趋势。

**相关方法交叉引用**：RPO 与市场预期对比、ACV/RPO 比值判断订单期限结构，详见 6.3；积压订单与非流动合同负债（客户预付款）作为产能锁定证据，详见 6.2。

**本节速查清单**

## 6.2 合同负债、预收与递延收入

> 本节导读：当公司不披露订单、或订单披露已经停止时，资产负债表里的预收类科目（合同负债、非流动合同负债、递延收入）就成了替代的前瞻指标：客户已付钱而公司尚未确认的部分，直接对应未来的交付或收入。适用于 To B 制造、设备、软件、游戏、教育、会员制等业务。与 6.1（RPO / Backlog）互为补充；订单真实性与三维财务验证见 6.4；白酒经销商打款的“蓄水池”等行业专属用法见 16.7。

### 6.2.1 合同负债（预收款）作为 To B 在手订单的代理指标

**方法要点**：To B 生意里，客户已预付、尚未交付的部分记为合同负债，可以近似看作在手订单的变化；关键是读懂合同负债环比下降到底是订单流失还是交付加速。

**操作步骤 / 拆分口径 / 公式**：
1. 取合同负债余额及环比变化，把它当作在手订单（预收部分）的代理指标，可类比 RPO。
2. 合同负债环比下降时，区分两种情形：①订单流失；②产能释放、加速交付后结转为收入。结合出货增速判断：出货高增时，合同负债下降通常是交付结转。
3. 看绝对水平：如果合同负债仍处历史高位，说明新增订单仍在补位。
4. 逐季跟踪余额变化，形成连续轨迹。

**关键指标与数据来源**：合同负债金额及环比、出货增速；来源为资产负债表（合同负债科目）及出货数据。

**判断标准**：合同负债环比下降 + 出货高增 + 余额仍处历史高位 → 积压订单被高效交付，需求未转弱；合同负债下降且出货不增、余额也回落到常态水平 → 订单流失风险。

**海豚案例**：
- 宁德（2026-04-16）：合同负债 455 亿，环比 -37 亿（从 492 亿），解释为积压订单高效交付。
- 宁德（2026-07-25）：合同负债再降 91 亿至 365 亿，仍处历史相对高位。

**适用场景与注意事项**：To B 制造、设备、软件（可类比 RPO）。合同负债只反映已预付的部分，没有预付的订单不会体现；需要和出货口径一起读，避免把“交付结转”误读成“订单下滑”。

### 6.2.2 非流动合同负债与客户预付款：未来产能被锁定的证据

**方法要点**：订单不再披露后，转向资产负债表中的前瞻指标——积压订单为后续增长打底，非流动合同负债（客户预付款）的猛增则说明客户在用真金白银预付，锁定未来的产能交付。

**操作步骤 / 拆分口径 / 公式**：
1. 订单披露停止后，改看资产负债表：记录仍可得的积压订单余额，作为后续增长的底盘。
2. 看合同负债（流动 / 非流动）余额及单季环比增量，尤其是非流动合同负债：增加说明客户为远期交付预付。
3. 看客户下单年限：部分客户有兴趣下 2029 甚至 2030 年的订单，说明需求已排到远期。
4. 据此重构投资主线：从“需求有多强”转到“供给能扩多快、客户愿意为确定性付多少溢价”。
5. 与管理层口径交叉核对，区分是多数客户的广泛预付，还是单个大客户贡献。

**关键指标与数据来源**：积压订单；合同负债（流动 / 非流动）及环比增量；客户下单年限；来源为资产负债表及电话会。

**判断标准**：非流动合同负债单季大幅环增、客户愿意提前 3-4 年下单，说明需求不是约束，稀缺的是产能；海豚君认为“最亮眼的数据藏在资产负债表中”，投资主线随之转向供给扩张速度与溢价。

**海豚案例**：
- 阿斯麦《阿斯麦 ASML：有 AI 高烧在…》（2026-04-15）：上季度末积压订单 388 亿欧元，为后续增长打底。
- 阿斯麦《阿斯麦：光刻机产能也紧俏了，ASML 离涨价还有多远？》（2026-10-14）：非流动合同负债猛增到 93 亿欧元，单季环增 57 亿，客户用预付锁定未来产能交付，部分客户有兴趣下 2029 甚至 2030 年的订单。

**适用场景与注意事项**：适用于预收款模式的设备、软件、长协制造业。合同负债增加也可能来自单个大客户，要结合管理层口径；产能约束如何推导收入下限与涨价，见 6.4.9。

### 6.2.3 递延收入作为下季收入领先指标，并解释“确认时点”

**方法要点**：递延收入代表已付费未确认的收入，上季末递延高增为本季收入提供支撑，本季末递延则预示下季；还能解释表观收入低于预期只是确认时点问题。

**操作步骤 / 拆分口径 / 公式**：
1. 取期末递延收入的同比和环比变化。
2. 上季末递延高增 → 本季收入有支撑；本季末递延 → 预示下季收入。
3. 三种用途：
   - ① 解释本季收入超预期的可预见性（上季递延高增，早已为本季收入打底）；
   - ② 提前识别下季风险（递延环比转负，提示产品空窗期）；
   - ③ 解释表观收入低于预期只是确认时点问题（新产品季末才上线，收入还没确认但递延加速）。
4. 与产品上线节奏、产品空窗期判断结合。

**关键指标与数据来源**：期末递延收入同比 / 环比；来源为资产负债表及电话会。

**判断标准**：递延收入高增或加速 → 后续收入有支撑，收入低于预期可能只是时点问题；递延环比下滑 → 产品空窗期问题体现在数据里，提前预警下季。

**海豚案例**：
- 网易《空窗期照赚》（2026-05-21）：上季递延 +22%，已说明对 Q1 收入的支撑（收入超预期可预见）。
- 网易《不烧钱依旧吃老本》（2026-08-20）：Q2 递延环比 -12%，递延收入印证产品空窗期问题，提前提示下季风险。
- 腾讯《不再躺尸功劳簿》（2026-05-13）：Q1 洛克王国季末上线 → 表观收入低于预期，但递延收入相较 Q4 明显加速，属于确认时点问题。

**适用场景与注意事项**：游戏、SaaS、教育、会员制业务。游戏递延等行业专属用法见 15.8；递延收入受会计确认政策影响，口径变化时指标会失真（见 4.3）。

**三类预收指标读法对照**

| 指标 | 代表什么 | 重点看 | 常见误读 |
|---|---|---|---|
| 合同负债（流动） | To B 客户已预付、尚未交付的订单 | 余额、环比，结合出货增速 | 环比下降 ≠ 订单流失，可能是高效交付后结转收入 |
| 非流动合同负债 | 客户为远期交付预付的真金白银 | 余额、单季环增、客户下单年限 | 可能来自单个大客户，要结合管理层口径 |
| 递延收入 | 已付费未确认的收入 | 同比 / 环比；上季末预示本季，本季末预示下季 | 产品上线时点造成表观收入与递延背离 |

**相关方法交叉引用**：合同负债“蓄水池”——环比降幅收窄判断经销商打款意愿，以及模式变化后该指标失效的识别，详见 16.7；订单 - 预付款 - 备产三维财务验证（在手订单、合同负债、存货结构），详见 6.4。

**本节速查清单**
- [ ] 公司是否仍披露订单？若不披露，改看合同负债 / 非流动合同负债 / 递延收入？
- [ ] 合同负债环比下降：是订单流失，还是交付加速后结转（对照出货增速）？
- [ ] 合同负债余额是否仍处历史高位（新增订单是否在补位）？
- [ ] 非流动合同负债单季环增多少？客户已愿意下几年后的订单？是否来自单一大客户？
- [ ] 上季末递延对本季收入的支撑，本季末递延对下季的预警？
- [ ] 表观收入与预期的偏差，是否只是确认时点（新品季末上线）造成？
- [ ] 业务模式或会计政策是否发生变化，导致预收类指标失效？

## 6.3 ARR/ACV/MRR等年化收入指标

> 本节导读：年化收入类指标（ACV、ARR、MRR）把“当前的收入速率”换算成年度口径，适合高增长、早期或合同制的公司：授权类看 ACV，AI 大模型与应用看 ARR，订阅 SaaS 看 MRR。本节讲怎么识别口径、拆结构、算斜率、外推年底、倒算指引隐含的增速，以及如何对管理层的激进目标做自下而上的缺口检验。与 6.1（合同余额）、5.4（AI 收入与 ARR 横向比较）、9.2（指引隐含值倒算）、12.5（情景分析）配合使用。

### 6.3.1 ACV 作为下季收入前瞻，并拆分新老合同收入

**方法要点**：把年化合同价值（ACV）当作下季收入的前瞻指标，跟踪环比变化，并估算本季收入中“老合同折算”与“新增合同 + 版税”各自的构成，倒推新合同带来的收入增量，观察签约动能。

**操作步骤 / 拆分口径 / 公式**：
1. 跟踪 ACV 绝对值及环比变化，作为下季收入的前瞻指标。
2. 用 ACV 环比变化估算本季新增合同带来的收入增量。
3. 拆分本季收入：**本季收入 ≈ 老合同折算入本季的收入 + （新增合同计入本季收入 + 本季版税 Royalty）**；老合同折算部分约 4 亿美元量级，两项合计对应本季收入。
4. 倒推本季新合同带来的收入增量，观察签约动能。
5. RPO 停止披露后，ACV 成为主要替代指标。

**关键指标与数据来源**：ACV 金额及环比、新增合同收入增量、老合同折算收入；来源为公司披露的 ACV 与海豚君的估算分解。

**判断标准**：ACV 仅环比微增，说明前瞻动能有限；新合同带来的收入增量规模用来衡量签约动能的强弱；这一分解属于估算，宜按趋势而非单点解读。

**海豚案例**：
- ARM《ARM：AI红利未消》（2026-02-05）：ACV 16.2 亿美元，环比 +1.3%；估算新合同带来的收入增量约 2.3 亿，老合同折算约 4 亿，“新增合同计入加版税”合计约 8.4 亿。
- ARM《ARM：“短期波动”难掩锋芒》（2026-05-07）：ACV 16.6 亿，环比 +2.5%；新合同增量约 5.4 亿，“新增合同计入加版税”约 10.9 亿。
- ARM（2026-07-30）：ACV 17.3 亿，环比 +4.3%；预估新合同带来的收入增量约 2.8 亿；老合同折算入本季约 4.15 亿，新增合同计入本季加本季 Royalty 合计约 8.7 亿。

**适用场景与注意事项**：适合披露 ACV 或 ARR 的订阅、授权、合同制公司。分解结果是估算，依赖对老合同折算金额的假设；需要连续多个季度比较才有意义。

### 6.3.2 RPO 对比预期，并用 ACV/RPO 比值判断订单期限结构

**方法要点**：把 RPO 与市场预期、环比对比，同时计算 ACV/RPO 比值判断在手订单是偏短期还是偏长期，再把“指引、ACV、RPO”作为核心三指标，综合判断经营面是否有隐患。

**操作步骤 / 拆分口径 / 公式**：
1. 把 RPO 与市场预期对比，同时跟踪环比。
2. 公式：**ACV/RPO = 年化合同价值 ÷ 剩余履约义务**。比值上升，说明在手订单越来越偏短期（短合同多、长合同少）。
3. 解读两面性：偏短期可以理解为符合 AI 市场需求迫切的特征；也可能意味着长期能见度下降。
4. 把指引、ACV、RPO 三项放在一起，作为“核心三指标”，综合判断经营面是否有隐患。

**关键指标与数据来源**：RPO（环比）、RPO 一致预期、ACV/RPO 比值、指引。

**判断标准**：RPO 环比下滑且低于预期、ACV/RPO 同时上升，叠加版税增速回落，就被列为隐患；比值上升同时意味着订单期限变短、长期能见度下降。

**海豚案例**：
- ARM《ARM：AI红利未消》（2026-02-05）：RPO 为 21.5 亿美元，环比 -4.4%，低于预期的 25.3 亿；ACV/RPO 为 0.75 且在上升；与版税增速回落一起被列为隐患。
- ARM《ARM：“短期波动”难掩锋芒》（2026-05-07）：RPO 为 20.7 亿，环比 -3.6%，低于预期的 26.7 亿；ACV/RPO 为 0.8，订单结构更偏短期。

**适用场景与注意事项**：适合有 RPO 披露的软件、IP、SaaS 公司；RPO 停止披露后，此方法转化为只看 ACV（见 6.3.1）。

### 6.3.3 ARR 跟踪：年化口径识别、结构与斜率

**方法要点**：ARR（年化经常性收入）被海豚君视为量化模型智能程度和受欢迎程度的核心指标；跟踪时要先识别年化口径，再看结构（企业占比）和斜率，并与目标、卖方、同业比较。

**操作步骤 / 拆分口径 / 公式**：
1. 识别年化口径：
   - 变体 A：按周年化 vs 按月年化（按月更保守）；
   - 变体 B：ARR 是否含非 API 的持续性收入；
   - 变体 C：用季度收入 ×4 推算 ARR（例如“AI 相关 ARR = 季度收入 ×4”）。
2. 跟踪 ARR 结构（如企业占比），看收入质量是否在改善。
3. 把多个披露点（3 月 / 5 月 / 7 月 / 8 月）连起来算月环比增速，看斜率。
4. 与公司年度目标、卖方估算、同业（可灵、MiniMax）比较绝对值和斜率。
5. 注意 ARR 转化为实际收入存在时间差。
6. 外推年底的方法见 6.3.4。

**关键指标与数据来源**：ARR 绝对值、月环比增速、企业占比、年化口径、年度目标、卖方估算、同业 ARR。

**判断标准**：ARR 绝对值超过海豚君预期或一致预期、斜率仍高、企业占比上升，则视为强信号；口径不同的 ARR 不能直接横比（按月年化比按周年化保守）；公司给的年度目标若只等于最新月份年化值，说明目标偏保守。

**海豚案例**：
- MiniMax（2026-08-26）：5 月 4 亿 → 8 月 8 亿以上，月环比超 25%；ARR 中企业占 80%（去年 30%）；卖方估 8 月约 6 亿。
- 智谱（2026-03-31）：3 月 API ARR 2.5 亿美元（17.5 亿人民币），超海豚君预期；可灵 1 月 ARR 过 3 亿，但全年指引只等于 1 月年化；MiniMax 2 月 1.5 亿。
- 智谱（2026-08-31）：3 月 2.5 亿 → 7 月初 10 亿 → 8 月底 16 亿（按月年化，不同于 MiniMax 按周）；ARR 从 7 月 10 亿升至 8 月 16 亿，“抹掉财报瑕疵”。
- 阿里：AI 相关 ARR = 季度收入 ×4 = 495 亿人民币。

**适用场景与注意事项**：AI、SaaS 等以年化收入衡量的高增长公司；最大的坑是口径差异（按周 / 按月 / 季度 ×4），跨公司比较前必须对齐；ARR 不等于已确认收入。AI 收入的横向比较详见 5.4。

### 6.3.4 月复合增速外推 ARR 至年底

**方法要点**：对高速增长、披露了 ARR 时点值的业务，计算历史月复合增速（月 CAGR），按乐观或保守的月增速外推年底 ARR 和月化收入，作为情景测算的输入。

**操作步骤 / 拆分口径 / 公式**：
1. 取两个 ARR 披露点，计算月复合增速：**月 CAGR = （期末 ARR ÷ 期初 ARR）^（1/间隔月数）− 1**。
2. 外推：**年底 ARR ≈ 最新 ARR ×（1 + 月增速）^（剩余月数）**；月化收入 = 年底 ARR ÷ 12。
3. 给出乐观与保守两档月增速（可线性或保守外推），形成区间，而不是单点。
4. 对无披露点的业务（如 Grok），直接假设月增速（如 10%）。
5. 把外推结果与年度目标、一致预期比较（缺口检验见 6.3.7）。

**关键指标与数据来源**：ARR 时点值、月 CAGR、外推 ARR、月化收入。

**判断标准**：外推值显著高于公司目标或一致预期，则目标偏保守、预期有上修空间；外推结果对月增速假设高度敏感，宜给区间。

**海豚案例**：
- SpaceX《豪赌AI》（2026-08-05）：Cursor 的 ARR 从 2025 年 6 月的 5 亿、2025 年底约 10 亿，到 2026 年 2 月 20 亿、6 月 40 亿，月 CAGR 约 19%，按 19% 外推年底约 114 亿（月化 9.5 亿）；Grok 假设 10% 月增速，年底 ARR 约 50-64 亿；Cursor 收购选择权 600 亿美元，6 月以换股行权。
- MiniMax（2026-08-26）：5 月 4 亿 → 8 月 8 亿以上，月环比超 25%，外推年底超 10 亿“几乎确定”。
- 智谱（2026-08-31）：保守月环比外推年底约 35 亿，远超一致预期 20 亿以上。

**适用场景与注意事项**：适用于早期高增长的 AI 或 SaaS 业务。增长率会随体量放大而衰减，复合外推在长期会高估；月增速假设要与竞争格局、产能约束一起检验。

### 6.3.5 用年底 ARR 指引倒算隐含月增长率

**方法要点**：跟踪 ARR 时间序列，用年底 ARR 指引倒算剩余月份所需的隐含月增长率，与此前月增速对比，识别指引是保守还是增速出现断崖。

**操作步骤 / 拆分口径 / 公式**：
1. 跟踪 ARR 的时间序列。
2. 公式：**隐含月增速 =（年底指引 ARR ÷ 当前 ARR）^（1/剩余月数）− 1**，并与此前的月增速对比。
3. 增速断崖时，给出三种解释：时点拉高（短期冲高）、竞争或价格战、指引保守。
4. 同时关注 to B 收入、毛利率目标等配套指标。

**关键指标与数据来源**：ARR、隐含月增长率、to B 收入、毛利率目标。

**判断标准**：隐含月增速远低于此前月增速，则指引要么保守、要么增速拐点已现，需用三种解释逐一排除；毛利率目标给出盈利质量的改善路径。

**海豚案例**：
- 智谱（2026-09-01 callback）：8 月 ARR 16 亿美元，年底指引 24 亿，隐含月增速从此前的 40-50% 降到不足 15%（按剩余 4 个月粗算约 11%）；毛利率目标 1-1.5 年内超过 50%。
- 智谱（2026-08-31）：ARR 从 7 月 10 亿升至 8 月 16 亿，“抹掉财报瑕疵”。

**适用场景与注意事项**：大模型、AI 应用公司；指引口径（按周 / 按月年化）需先与实际披露口径对齐；倒算结果属于粗算。一般性的指引隐含值倒算方法见 9.2。

### 6.3.6 收入体量匹配市值：对照一级估值与同业

**方法要点**：对 AI 公司，把已披露的收入 / ARR 体量与当前市值对照，并与可比公司的一级市场估值比较，判断估值是否已经透支。

**操作步骤 / 拆分口径 / 公式**：
1. 取最新收入口径（如上半年 to B 收入）与 ARR 目标。
2. 对应当前市值，计算估值与收入体量的匹配关系。
3. 与可比公司的一级估值对照，判断相对高低。

**关键指标与数据来源**：to B 收入、ARR、市值、可比一级估值。

**判断标准**：收入体量与市值匹配，说明估值有基本面支撑；与可比一级估值差距大，则需解释差异（增速、业务结构、盈利预期）。

**海豚案例**：
- MiniMax（2026-08-26）：上半年 to B 收入 0.74 亿美元（+700%），对应市值 135 亿，对比可灵一级估值 180 亿；ARR 目标 10 亿。

**适用场景与注意事项**：适用于大模型、AI 应用等估值难以用传统 PE 衡量的公司；一级估值是参照而非定价依据。估值方法与情景分析见第 12 章。

### 6.3.7 管理层激进 ARR 目标：自下而上拆解找缺口

**方法要点**：面对管理层提出的宏大 ARR 目标，按业务自下而上测算各块的年底 ARR，加总后与目标比较，缺口即需要新订单填补的部分，据此判断目标可达性与所需催化。

**操作步骤 / 拆分口径 / 公式**：
1. 记录管理层目标并折算月化（如年底 1000 亿美元 = 月化约 83 亿）。
2. 按业务逐块测算年底 ARR：
   - 算力租赁：由在手订单折算；
   - Cursor 等高增长业务：按月复合增速外推（见 6.3.4）；
   - Grok 等新产品：假设月增速；
   - 广告；
   - 星链 + 发射等成熟业务。
3. 加总各块，在乐观且无新增大订单的假设下与目标比较。
4. 缺口 = 目标 − 加总，需要新增订单（如算力租赁新订单）来填补；据此判断目标可达性和所需催化。

**关键指标与数据来源**：管理层 ARR 目标、分业务 ARR、在手订单、月化收入。

**判断标准**：自下而上的加总显著低于目标，说明目标依赖未来新订单，达成难度大；缺口大小就是所需催化的量级。

**海豚案例**：
- SpaceX《豪赌AI》（2026-08-05）：在乐观且无新增大订单的假设下，AI 约贡献 500 亿 ARR（算力租赁约 300 亿，Cursor 约 114 亿，Grok 50-64 亿，广告约 20 亿），星链 + 发射年底 ARR 约 260-300 亿，合计约 760-800 亿，不足 1000 亿，说明需要算力租赁新订单才能达到目标。

**适用场景与注意事项**：适用于管理层给出宏大量化目标的公司。各块假设不确定性高，宜给区间；算力租赁类订单还要叠加可终止条款、纸面订单打折（见 6.4.2、6.4.3）。

### 6.3.8 MRR 作订阅业务领先指标，并剔除试用 / 折扣期的扰动

**方法要点**：订阅业务以 MRR（月重复性收入）为核心领先指标；先与市场预期比较，再剔除免费 / 折扣试用造成的低基数扰动，判断增速是向常态恢复还是真实加速，并映射到订阅收入增速及预期差。

**操作步骤 / 拆分口径 / 公式**：
1. 取 MRR 绝对值及同比、环比增速变化，并与彭博一致预期比较。
2. 识别去年免费 / 折扣试用期促销造成的低基数（例如去年 Q2 是增长最低点）：试用会压低 MRR 增速和客单价。
3. 判断增长是向常态恢复，还是真有加速：试用影响消退后 MRR 增速修复，会领先带动订阅收入增速和订阅毛利率回升。
4. 映射到订阅收入增速及其预期差。

**关键指标与数据来源**：MRR 绝对值与同比、环比增速变化、订阅收入增速、订阅毛利率、试用期政策变化；彭博一致预期。

**判断标准**：MRR 同比增速修复且略超预期，同时订阅收入增速、订阅毛利率随之回升（如订阅毛利率由跌转涨），则趋势确认；低基数下的增速反弹，要与“真实加速”区分。

**海豚案例**：
- Shopify《业绩不俗却暴跌》（2026-02-12）：MRR 2.05 亿美元，同比修复至 15%（环比加速近 5pct），略超预期；订阅收入 +16.7%（彭博预期 15%），订阅毛利率扭跌转涨。
- Shopify（2026-08-06）：MRR 2.21 亿美元，+19.5%，超市场预期近 1pct；订阅收入 +22%，小超预期约 1.5pct。

**适用场景与注意事项**：订阅制 SaaS，尤其是曾通过试用 / 折扣拉新的公司；MRR 分层（Plus 大客户与普通商户）、商家服务变现率等电商平台专属拆法见 15.6。

**相关方法交叉引用**：MRR 分层、试用期政策与商家服务变现率（商家服务收入 / GMV），详见 15.6；cRPO / 新增订单 / ACV / TCV / 积压订单的指标选择，详见 6.1；AI 收入 / ARR 横向比较，详见 5.4。

**本节速查清单**
- [ ] ARR 的年化口径是什么（按周 / 按月 / 季度收入 ×4）？横比前是否已对齐？
- [ ] ARR 结构（企业占比）和斜率（月环比）如何？与目标、卖方、同业比怎样？
- [ ] 用月 CAGR 外推年底 ARR 时，是否给了乐观 / 保守两档区间？
- [ ] 年底 ARR 指引倒算的隐含月增速，相对此前月增速是否断崖？是时点拉高、竞争还是指引保守？
- [ ] 管理层宏大 ARR 目标，自下而上加总后缺口多大，需要什么新订单？
- [ ] ACV 环比变化与新老合同拆分（新合同带来的收入增量）如何？
- [ ] ACV/RPO 比值上升了吗？订单偏短期的含义是需求迫切还是长期能见度下降？
- [ ] MRR 增速的修复是否只是去年试用期低基数？订阅收入与毛利率是否同步改善？

## 6.4 订单质量、可见度与供需约束

> 本节导读：订单数字大不等于收入确定。本节解决三个问题：订单是不是真订单、能确认成多少收入（纸面订单、上限金额、可提前终止条款、可见度分层）；合同条款怎么读（长期协议、SCA 份数、履约担保、定金比例）；收入没起来，究竟是需求问题还是供给约束（三线对照、需求满足率、产能计划推导收入下限）。适用于 AI 硬件与算力、设备、存储等供给受限或订单驱动的行业，与 6.1（订单余额）、6.2（预收验证）、第 9 章（指引）、10.1（资本开支）配合；行业专属的交付周期、定点、GW 换算见 16.1 ~ 16.3。

### 6.4.1 新增订单 × 积压订单 × 收入三线对照：判断需求问题还是供给约束

**方法要点**：核心业务收入环比增量偏小时，不直接下“需求放缓”的结论，而是并列收入、新增订单、积压订单三组数据；订单远高于确认收入且积压持续攀升，则判定需求旺盛、收入受上游供给约束，并据此推算下季收入。

**操作步骤 / 拆分口径 / 公式**：
1. 并列三组数据：①当季收入及环比增量；②当季新增订单（bookings）；③期末积压订单（backlog）及其连续多季轨迹。
2. 计算订单出货比：**book-to-bill = 新增订单 ÷ 当季收入**。
3. 判定：book-to-bill 远大于 1、积压订单又连续攀升 → 需求旺盛，收入受上游供给（GPU / 存储产能）约束，新品量产爬坡后收入会集中释放。
4. 当季收入大增、积压订单还在增加（新增订单大于出货）→ 判定“供不应求”。
5. 当季收入不及预期但订单大幅超预期时，以订单为准做判断。
6. 用积压订单和收入指引推算下季收入，给出海豚君自己的下季预估（如本季 164 亿 → 下季冲击 200 亿，环增 30 亿以上）。
7. 衡量储备厚度：**积压订单增量 ÷ 季度收入**（如 +440 亿 ≈ 2.7 个季度的 AI 收入）。
8. 用厚积压订单解释股价韧性：AI 链整体回调时，这类公司跌幅更小，因为 backlog 让增长看得见。

**关键指标与数据来源**：AI 服务器收入及环比增量、AI 新增订单、期末 AI 积压订单（逐季序列）、book-to-bill、市场预期 AI 收入；来源为公司财报与电话会。

**判断标准**：
- 收入环增小但订单与积压大增 → 供给约束而非需求疲软，收入将在供给放开后释放（如 Rubin 发货可能继续超预期）。
- 收入高增时积压仍在增加 → 供不应求。
- 当季收入不及预期、订单大幅超预期 → 以订单为准，上调下季收入预期。
- 厚 backlog 对应更强的股价防御性，但 backlog 高不等于利润率高。

**海豚案例**：
- 戴尔《英伟达放量？戴尔：好日子还能更好！》（2026-09-02）：AI 收入 164 亿，仅环增 3 亿，但好于预期 158 亿；新增订单 609 亿；积压订单 430 → 513 → 950 亿，本季增加 440 亿（约 2.7 个季度的 AI 收入）；结论是“AI 需求依然很旺，只是供应不足，Rubin 发货可能继续超预期”，预估下季 AI 收入冲击 200 亿；backlog 厚，所以相比其他 AI 链公司股价回调更少。
- 戴尔（2026-02-27）：AI 收入 89.5 亿，不及预期 94 亿；但 AI 新增订单 341 亿，远超预期 110 亿，积压 430 亿；海豚君预估下季 AI 收入在 130 亿以上（原市场预期 75 亿）。
- 戴尔（2026-05-29）：AI 收入 161 亿，好于上调后的买方预期 156 亿；新增订单 244 亿（预期 100~150 亿），积压 513 亿；预估下季 AI 收入在 155 亿以上；收入大增时积压仍在增加，说明供不应求。

**适用场景与注意事项**：适用于订单 / 交付制的服务器、半导体设备、工业设备、工程类公司，前提是公司披露订单与 backlog。局限：订单可能取消或递延，需关注客户集中度（如新云客户）和订单转化周期；backlog 高不等于利润率高。

### 6.4.2 区分纸面订单 / 上限金额与可确认收入

**方法要点**：对宣布的大订单、协议上限、意向订单打折看：上限不等于在手订单，订单是否转成收入取决于指引、条款与出货时点。

**操作步骤 / 拆分口径 / 公式**：
1. 判断订单性质：已签的约束性订单、协议上限、意向 / 框架订单，三者含金量依次递减。
2. 检查是否已反映在全年指引里（指引没上调，说明市场不应提前计入）。
3. 检查是否有终止条款（见 6.4.3）。
4. 对照产品出货时点：产品放量前，市场对订单转化成收入会保持谨慎。
5. 把订单金额与下季收入环比增量对照，检验订单是否真的在近期兑现。

**关键指标与数据来源**：订单金额、指引是否上调、合同条款、出货时点。

**判断标准**：新增客户很多、但全年指引不变、产品尚未出货 → 订单仍是纸面承诺；上限金额须打折；溢价应拆成稀缺性与订单可撤销性两部分。

**海豚案例**：
- AMD（2026-08-05）：新增 OpenAI、Meta、Anthropic、微软等客户，但 AI GPU 全年指引维持 140-150 亿，MI455X 下季才出货，订单还只是纸面承诺；下季数据中心环比增量约 12-18 亿，相对偏弱。
- SpaceX：845 亿是上限，不是在手订单；溢价一半来自稀缺、一半来自订单可撤销。

**适用场景与注意事项**：AI 硬件、算力租赁等订单叙事强的行业；需对照指引与出货节奏，避免把媒体报道的总金额直接计入收入预期。

### 6.4.3 识别可提前终止条款，下调收入可见度

**方法要点**：细读重大合同条款：算力租赁协议若含任一方可提前通知终止的条款，即使当期收入强劲，收入可见度也天然不确定，高溢价背后是订单可撤销的另一面。

**操作步骤 / 拆分口径 / 公式**：
1. 梳理重大合同的终止条款、通知期、合同期限。
2. 对含提前终止条款的订单，在计算在手订单与 RPO 时单独标注并下调可见度。
3. 把可撤销性与 Capex 回报判断联动：投入已发生、订单可撤销，则回报的不确定性上升。
4. 以此解释市场为何要求更多新订单来匹配 Capex。

**关键指标与数据来源**：合同终止条款、通知期、合同期限、在手订单。

**判断标准**：含“任一方可提前 90 天通知终止”的协议，收入可见度不能按合同总期限计算；终止条款越宽松，在手订单折价越大。

**海豚案例**：
- SpaceX《豪赌AI》（2026-08-05）：AI 租赁协议均含任意一方可提前 90 天通知终止的条款，海豚君据此提示收入可见度存在不确定性，也用它解释为何市场要求更多新订单来匹配 Capex。

**适用场景与注意事项**：适用于大客户合同集中的云和算力、外包服务公司。条款细节通常只在招股书 / 重大合同公告中披露，需主动查阅。

### 6.4.4 本季新增订单与历史大单比较，判断边际增量能否支撑 Capex

**方法要点**：新增订单不是零，但要与已公布的大单和 Capex 体量比较，判断边际增量是否“有限”；投入节奏若跑在可验证回报之前，再叠加订单可撤销，市场就会打折。

**操作步骤 / 拆分口径 / 公式**：
1. 记录本季新增云服务 / 算力协议金额。
2. 与历史大单的金额与期限（如 450 亿 / 3 年、303.6 亿 / 33 个月）比较，判断边际增量大小。
3. 与资本开支体量对照，看新增订单能否覆盖投入。
4. 核对在手订单合计及对应 ARR。

**关键指标与数据来源**：新增云服务协议金额、历史大单金额与期限、Capex、在手订单与对应 ARR。

**判断标准**：新增订单远小于历史大单 → 边际增量有限；订单增长慢于投入 → 市场对回报打折。

**海豚案例**：
- SpaceX《豪赌AI》（2026-08-05）：本次仅宣布约 67 亿美元新增云协议，而此前 Anthropic 为 450 亿 / 3 年、Google 约 303.6 亿 / 33 个月，边际增量有限；算力租赁在手订单约 884 亿（含三季度新增），对应 ARR 约 300 亿。

**适用场景与注意事项**：订单驱动的 AI 基础设施、云服务公司；资本开支强度与回报的一般方法见 10.1、10.2。

### 6.4.5 订单可见度分层：滚动预测期 vs 对话期

**方法要点**：对管理层披露的可见度信息，区分“确定性”（滚动预测、正式订单）与“对话阶段”（意向沟通）两层，不把对话阶段计入确定性。

**操作步骤 / 拆分口径 / 公式**：
1. 记录管理层披露的客户滚动预测期（如 8 个季度）。
2. 记录增量信息中的长期对话年限（如延伸至 2030 年）。
3. 按承诺强度分级：滚动预测 = 相对确定；对话阶段 = 仅作线索。
4. 估算可见度覆盖的收入比例，并跨季跟踪变化。

**关键指标与数据来源**：客户滚动预测期、长期对话年限、可见度覆盖的收入比例。

**判断标准**：相对确定的仍是滚动预测期的时间维度；“部分客户对话延伸至 2030 年”仍属对话阶段，不计入确定性。

**海豚案例**：
- 应用材料《泼天富贵在前，应用材料 AMAT 竟然怂了？》（2026-08-14）：管理层维持“最大客户提供 8 个季度滚动预测”，增量信息是“部分客户对话延伸至 2030 年”；海豚君判定后者仍处对话阶段，相对确定的仍是 8 个季度的时间维度。

**适用场景与注意事项**：适用于没有正式订单披露的设备和零部件公司；管理层的可见度表述需要按承诺强度分级，避免把“愿景”当“订单”。

### 6.4.6 拆解长期协议（LTA）条款并与同行对比

**方法要点**：把长协拆成数量、期限、结构、锁定比例、价格上下限、预付款 / 保证金、RPO 披露等维度，与同行比较锁价能力和财务担保的透明度，用来解释估值差距，并列出管理层还能释放的增量信息。

**操作步骤 / 拆分口径 / 公式**：
1. 逐项拆解：签约数量（笔数）、期限、结构（固定期 + 浮动期）、锁定量价的比例、价格上下限、预付款或保证金及其金额、是否披露 RPO。
2. 与同行逐项对比锁价能力和财务担保的透明度。
3. 用对比结果解释估值差距（如 PE 倍数差异）。
4. 列出管理层还能释放的增量信息（重签增强型 LTA、更大的产能覆盖度、财务担保金额）。

**关键指标与数据来源**：LTA 笔数、期限、结构、锁定比例、价格上下限、保证金或预付款金额、RPO；来源为财报、电话会。

**判断标准**：有保证金、有价格上下限、披露 RPO 和财务担保的长协，透明度和确定性更高，估值也更高；固定期越长、锁定比例越高，周期波动越小。

**海豚案例**：
- 海力士（2026-07-29）：LTA 落地 10 笔，首次官方确认含保证金；期限通常 5 年，结构为 2+3 或 3+2，前 2-3 年固定、后 2-3 年部分浮动；市场预期锁定未来 5 年 60-70% 的量价。
- 美光（作为同行对比）：设有价格上下限，披露 220 亿美元财务担保和客户 RPO，美光 PE 6x 对海力士 4x；海豚君列出可期待的增量信息：重签增强型 LTA、更大的产能覆盖度、财务担保金额。

**适用场景与注意事项**：存储等周期品，也适用于有长协或照付不议合同的行业。披露透明度差异本身会被定价，不同公司条款不可直接类比。

### 6.4.7 长协前瞻指标：SCA 份数、RPO、履约担保、定金比例

**方法要点**：美光的长期战略协议（SCA）是评估周期持续性的核心，逐季追踪四个量：SCA 份数、RPO、履约担保、定金比例，既看确定性，也看对价格弹性的封顶。

**操作步骤 / 拆分口径 / 公式**：
1. SCA 份数：逐季追踪（首份 → 16 份 → 26 份）。
2. RPO：约 1500 亿美元，要强调 RPO 只计入已确定定价框架（固定价或带上下限价格带）的部分。
3. 履约担保：逐季追踪金额及季度新增（220 亿 → 320 亿，季增 100 亿）。
4. 定金比例：客户需付 20-30% 定金，take-or-pay（不提货也得付钱）。
5. 跟踪 SCA 框架下的收入占比。

**关键指标与数据来源**：SCA 份数；RPO；履约担保金额及季度新增；定金比例；SCA 框架下收入占比。

**判断标准**：
- 担保体现议价权，并增强抗风险能力。
- 长协锁住量的确定性，但也封住了部分现货涨价弹性：ASP 可预测性增强、涨幅趋缓、难以大幅 beat。
- 份数与担保金额逐季增加，说明周期持续性在增强。

**海豚案例**：
- 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：26 份 SCA，RPO 约 1500 亿，担保 320 亿。
- 美光《美光：牛气冲天！…》（2026-06-25）：16 份 SCA，担保 220 亿。
- 美光（2026-03-19）：首份 5 年期 SCA（由 1 年期 LTA 升级）。

**适用场景与注意事项**：适用于开始签长约的周期品公司（存储、锂、硅料、晶圆代工）；注意 RPO 的计入口径和价格条款，定价框架外的合同不计入。

### 6.4.8 客户需求满足率（供给保障度）：供需缺口的直接度量

**方法要点**：把管理层披露的“对核心客户中期需求的满足比例”当作供需缺口的直接度量，并跨季对比，判断缺口是在收窄还是持续。

**操作步骤 / 拆分口径 / 公式**：
1. 记录管理层披露的需求满足比例（如满足 50% 至 2/3）。
2. 与前几个季度对比（如与三个月前对比）。
3. 比例无明显变化，说明缺口没有收窄；比例上升，说明供给在追上需求。
4. 结合管理层对远期（如 2027 年后）的措辞，判断增长持续性。

**关键指标与数据来源**：客户需求满足比例；跨季变化。

**判断标准**：满足率长期低于 100% 且无改善 → 供不应求延续，相应年份的增长相对确定；管理层对更远年份措辞谨慎，则远期增长不应外推。

**海豚案例**：
- 美光《美光 MU：AI 带动存储“疯涨”，能破周期“紧箍咒”吗？》（2026-03-19）：对核心客户中期需求只能满足 50% 至 2/3，与三个月前相比无明显变化，缺口没有收窄，2026-2027 年的增长相对确定；公司对 2027 年后的表现相对谨慎。

**适用场景与注意事项**：适用于供给受限的上游行业；依赖管理层主动披露，口径可能不稳定。

### 6.4.9 产能扩张计划推导收入增速下限，并据此判断是否涨价

**方法要点**：对供给受限的龙头，用公司公布的产能计划推算收入增速下限，再与市场预期和可能给出的指引比较，判断是否隐含涨价。

**操作步骤 / 拆分口径 / 公式**：
1. 取公司公布的产能年增速（如 Low-NA EUV 和浸没式 DUV 产能各增长 30%）。
2. 推算收入增速下限：若产能满载、价格不变，收入增速 ≈ 产能增速。
3. 与市场预期的收入增速对比。
4. 公式：**价格或结构贡献 ≈ 指引增速 − 产能增速**。指引远超产能增速，即隐含涨价或结构升级。
5. 将管理层可能给出的指引与上述公式对照，判断是否超预期。

**关键指标与数据来源**：产能年增速；市场收入增速预期；指引增速 − 产能增速 ≈ 价格或结构贡献。

**判断标准**：即便光刻机不涨价，2026-2028 年也能维持 30% 以上的增长；若管理层给出 45% 甚至 50% 的 2027 年增长指引，就超出市场预期（约 35%-40%），并意味着光刻机明年可能出现涨价迹象。

**海豚案例**：
- 阿斯麦《阿斯麦：光刻机产能也紧俏了，ASML 离涨价还有多远？》（2026-10-14）：给出 2027、2028 年 Low-NA EUV 和浸没式 DUV 产能各增长 30%，市场对 2027 年增长的预期约 35%-40%；产能年增 30%，指引若到 45-50% 即意味涨价。

**适用场景与注意事项**：适用于供给瓶颈型、订单远大于产能的龙头（光刻机、先进封装、HBM）。需要产能利用率接近满载的前提；产能增速与收入增速之间还有良率、产品结构等因素，差额不全是价格。

### 6.4.10 订单 - 预付款 - 备产三维财务验证

**方法要点**：在产品力不突出时，用财报三项侧面印证下游需求确定性：在手订单、合同负债、存货结构，核心是区分“备货”与“积压”。

**操作步骤 / 拆分口径 / 公式**：
1. 在手订单：核对招股书披露的框架销售协议及销售合同中未完成、具约束力订单总价值。
2. 合同负债：客户是否以预付方式锁定订单。
3. 存货：取净额及同比增速，拆结构（原材料 / 在制品 / 产成品）。
4. 判断存货扩张的性质：原材料 + 在制品占比高 → 源于确定订单的备产，而非成品滞销。
5. 三项互相印证，得出下游需求确定性结论。

**关键指标与数据来源**：在手订单、合同负债、存货净额及结构（原材料 / 在制品 / 产成品）、同比增速；来源为招股书与年报。

**判断标准**：存货暴增但结构以原材料和在制品为主，并有在手订单和预收款支撑 → 备产；若以产成品为主 → 积压风险。

**海豚案例**：
- 壁仞科技《壁仞：国产 “英伟达”，到底 “几斤几两”？》（2026-06-18，第 4 节）：在手订单——招股书披露框架销售协议及销售合同中未完成、具约束力订单总价值 8.22 亿元；合同负债——2025 年末 0.77 亿元，客户已以预付方式锁定订单；存货——2025 年末净额 9.49 亿元、同比 +500% 以上，结构上原材料（3.86 亿）与在制品（4.31 亿）合计约 85%，存货扩张源于确定订单的备产，而非成品滞销。

**适用场景与注意事项**：早期商业化 / 硬件公司的需求验证；存货结构是区分备货与积压的关键。存货与应收等资产负债表项目的一般分析见 10.6。

### 6.4.11 逐项目、逐合同条款排查订单延期 / 违约与供应链风险（含做空报告回应）

**方法要点**：针对市场担忧（项目退单、做空报告）逐条拆解：点名具体项目、说明担忧、给出反驳证据、下结论；供应链风险则核对原材料供给能力与产能扩张模式。

**操作步骤 / 拆分口径 / 公式**：
1. 点名具体项目，列出市场担忧（如管道审查、合作方退出）。
2. 给出反驳证据：替代方案（早期槽车供气可替代）、交付节奏（集中在 27-28 年）、合同条款（MSA 框架不绑定单一站点，可调配）、融资方有接收义务、直接合同方是谁、第三方澄清。
3. 给出结论（如退单概率微乎其微）。
4. 供应链：针对做空机构对关键原材料的质疑，核对供给能力；产能扩张看管理层预测算法与扩产模式。

**关键指标与数据来源**：合同条款、项目时间表、原材料供给能力、产能规划。

**判断标准**：每项担忧都要有条款、时间表或第三方信息的证据支撑，再得出风险概率判断；做空报告若不能被条款与供给数据证伪，则需下调订单可见度。

**海豚案例**：
- Bloom（2026-07-29）：甲骨文新墨西哥 Project Jupiter 2.45GW；Project Jade AEP 1GW 框架首期 100MW 已交付。市场担忧 FERC Section 7 管道审查、合作方 Crusoe 退出，海豚君逐条反驳——早期槽车供气可替代、交付集中在 27-28 年、MSA 框架不绑定单一站点可调配、融资方有接收义务、直接合同方是 AEP、第三方 Black Hills 澄清——结论是退单概率微乎其微。Hunterbrook 做空报告质疑氧化钪，公司称工业尾流回收可支撑每年最高 25GW 产能且不依赖中国单一来源。

**适用场景与注意事项**：订单集中、单项目风险大的公司；应对做空报告。结论取决于公开条款与公司口径，需持续跟踪项目进度。

**相关方法交叉引用**：交付周期 / 提车周期作为订单积压与供给瓶颈的高频指标，详见 16.1；在手订单 / 定点 / 客户覆盖 / 产能规划作为出货指引的可信度验证，详见 16.2；周订单 + 官网交付周期判断积压订单是否消化、供需由“供不应求”转为“需求驱动”，详见 16.1；Backlog 期限结构与“当期收入 / 上季 Backlog”转化率判断供给约束，详见 6.1；在手订单金额 ↔ GW 容量换算、覆盖年限与订单结构（试点 → 标配、复购倍数），详见 16.3。

**本节速查清单**
- [ ] 收入环增小时，是否并列收入、新增订单、积压订单三条线并算 book-to-bill？
- [ ] 订单是约束性订单、协议上限还是意向订单？是否已反映在指引里？
- [ ] 合同是否含可提前终止条款（通知期多久）？可见度是否已下调？
- [ ] 新增订单与历史大单、Capex 体量相比，边际增量有多大？
- [ ] 管理层的可见度表述，哪些是滚动预测（确定），哪些只是对话阶段？
- [ ] 长协条款：份数、期限、结构、锁定比例、价格上下限、定金、履约担保、RPO 计入口径？
- [ ] 客户需求满足率是否跨季收窄？管理层对更远年份的措辞如何？
- [ ] 产能增速能推出的收入增速下限是多少？指引超出部分是否隐含涨价？
- [ ] 存货、合同负债、在手订单能否三维互相印证？订单延期 / 违约风险是否逐项目排查过？

## 6.5 产品周期、管线与新业务里程碑

> 本节导读：订单之外，产品节奏本身就是前瞻指标：什么时候送样、量产、放量，决定收入节奏、毛利率波动和估值溢价能否维持。本节讲怎么维护产品路线图并核实延迟传闻、给新产品建里程碑表、追踪第二曲线新业务从“期权”变成“收入”的速度、用产品周期年数定位次要业务，以及用内容 / 功能产能前瞻用户粘性。适用于半导体、硬件、成长型科技与内容型产品；与 6.1 ~ 6.4（订单类指标）、8.6（新业务亏损）、9.6（里程碑兑现与跳票）配合；游戏新品 pipeline、新车大定等行业专属内容见行业章节。

### 6.5.1 跟踪产品路线图、量产节点与关键规格，并用 IR 信息核实延迟传闻

**方法要点**：为产品周期驱动的公司维护一张路线图和关键节点表（工艺、性能、整机规格、量产时点），对市场的延迟传闻用公司 IR 信息核实；产品周期同时用来解释收入节奏和毛利率波动。

**操作步骤 / 拆分口径 / 公式**：
1. 维护产品路线图（Blackwell → Rubin / CPX → Rubin Ultra → Feynman）。
2. 记录关键节点：
   - 工艺（台积电 3nm）；
   - 性能倍数（Rubin 在 NVFP4 推理下算力为 Blackwell 的 5 倍）；
   - 整机规格（VR200 NVL72：72 颗 Rubin GPU + 36 颗 Vera CPU、NVLink 260TB/s、3.6 EFLOPS 推理）；
   - 量产时点（Q3 开始出货、Q4 真正放量）。
3. 对市场的延迟传闻，用公司 IR 信息核实。
4. 用产品周期解释收入节奏和毛利率波动（新品爬坡期毛利率回落）。
5. 同步跟踪供应链公司的产品对接（能提供哪几代方案、是否参与下一代平台合作）。

**关键指标与数据来源**：量产时点、性能指标、平台规格、延迟传闻核实；来源为公司财报、电话会和 IR 沟通。

**判断标准**：“全面量产”与“真正放量”要区分（量产在先、放量在后）；IR 明确否认延迟，则传闻不构成估计调整依据；新品爬坡期的收入与毛利率节奏要提前纳入预期。

**海豚案例**：
- 英伟达（2026-02-26）：Rubin 和 CPX 在 2026H2 推出，采用 3nm，Rubin Ultra 2027 年推出。
- 英伟达（2026-08-27）：Rubin 已全面量产，Q4 才是真正放量点；IR 透露 Rubin Ultra 未延迟。
- 戴尔（2026-09-02）：能提供 Blackwell、Vera Rubin 方案，并参与 Feynman 平台合作。

**适用场景与注意事项**：适用于产品周期驱动的半导体和硬件公司，以及它们的供应链；延迟传闻的核实依赖公司 IR 口径，应与供应链数据交叉验证（见第 14 章）。

### 6.5.2 新产品里程碑表：送样、量产、需求规模、产能锁定、收入贡献

**方法要点**：给每家公司的新产品或新技术建一张里程碑表，每季更新，把“是否按时推进、需求展望是否上调”作为估值溢价能否维持的依据。

**操作步骤 / 拆分口径 / 公式**：
1. 建表字段：送样、首批出货、量产爬坡、收入占比、客户名单、需求规模、产能锁定。
2. 每季更新各节点状态，对比上季的计划。
3. 检查是否按时推进、需求展望是否上调。
4. 把进展映射到估值溢价：节点按时 / 提前且需求上调，溢价可维持；延后则溢价承压。

**关键指标与数据来源**：送样或量产时点、收入占比、客户、需求规模、产能锁定；来源为财报与电话会。

**判断标准**：里程碑兑现（送样 → 量产 → 收入占比提升）与需求规模、产能锁定同步推进，才算新产品从期权变成收入；收入占比的跳升（如 2nm 占比由 3% 升至 8%）是验证节点。

**海豚案例**：
- ARM（2026-07-30）：AGI CPU 需求超过 20 亿、锁定 10 亿产能、2027 财年三季度贡献收入、第二代 2027 年推出。
- 海力士（2026-07-29）：HBM4 在 Q2 出货、下半年爬坡，HBM4E 上半年已送样。
- 台积电：2nm 收入占比从 3%（Q2'26）升到 8%（Q3'26）。
- 中芯（2026-05-14、2026-08-13）：升腾 950DT、麒麟 9030 下半年出货，客户包括寒武纪、海光、H 公司。
- ASML：High-NA EUV 放量在 2028 年及以后。

**适用场景与注意事项**：处在产品周期驱动阶段的科技公司。里程碑多来自管理层口径，需与上季指引对照，核对是否“跳票”（兑现度与可信度见 9.6）。

### 6.5.3 第二曲线新业务：收入指引上调、出货爬坡与客户拓展

**方法要点**：对新业务建立单独的追踪台账，用收入指引及其上调、单季贡献、出货爬坡、客户与合作方数量、订单获取速度、量产时间，判断新业务从期权变成收入的速度。

**操作步骤 / 拆分口径 / 公式**：
1. 收入指引及其上调（当年与次年）。
2. 单季收入贡献。
3. 出货爬坡：累计出货、月产能（月出货能力）。
4. 客户和合作方数量、订单获取速度。
5. 量产时间（SOP）。
6. 结合管理层指引与海豚君自己的预测，对比指引与预期差。

**关键指标与数据来源**：新业务收入指引、单季收入、累计出货、月出货能力、合作方数量、SOP。

**判断标准**：指引连续上调、单季贡献逼近指引、出货和客户同步放量 → 新业务由期权转为收入；早期数据多来自管理层口径，波动大，需持续验证。

**海豚案例**：
- 禾赛（2026-08-19）：SGI 分为 Kosmo 空间智能平台和执行器模组（从灵巧手切入）。Kosmo 原型机 7 月发出，7 天内获银河通用等人形机器人公司订单，自 4 月预览以来有超过 200 家潜在合作方接洽。模组截至二季度末累计出货超过 1 万台，近期爬坡到每月约 1 万台，2027 年目标六位数出货。2026 年 SGI 收入指引从 1 亿上调到 2-3 亿（三季度单季接近 1 亿），2027 年维持 7 亿；海豚君预计 2026 年 2.5 亿，2027 年同比 +180%。

**适用场景与注意事项**：适用于有孵化业务的成长公司。新业务的利润率稀释和收入起始时点判断，详见 8.6。

### 6.5.4 按产品周期年数定位次要业务

**方法要点**：对游戏主机半定制芯片这类周期性业务，用“周期进入第几年”判断所处阶段，叠加零部件涨价影响，预判下半年的变化幅度；嵌入式业务按下游领域列驱动因素。

**操作步骤 / 拆分口径 / 公式**：
1. 判断主机周期进入第几年；换代过渡期业务就会下滑。
2. 叠加零部件（存储）涨价对成本和需求的影响，预判下半年下滑幅度。
3. 嵌入式业务按下游领域（测试测量、航空国防、通信、x86 嵌入式）列出驱动。
4. 关注可服务市场（TAM）是否扩大。
5. 下一季财报回头验证上述预判。

**关键指标与数据来源**：游戏业务收入同比、主机周期年数、嵌入式收入同比、下游领域。

**判断标准**：主机周期进入第 7 年、处于换代过渡期、叠加存储涨价 → 下半年明显下滑；实际数据（同比 -30.6%）验证预判，则周期定位有效。嵌入式则看下游领域的复苏与 TAM 扩大。

**海豚案例**：
- AMD《CPU“狂飙”》（2026-05-06）：游戏收入 7.2 亿美元，同比 +11%；主机周期在 2026 年进入第 7 年，处于换代过渡期，叠加存储涨价，预计下半年明显下滑；嵌入式 8.7 亿，同比 +6%。
- AMD《AMD：狂抢“AI大单”》（2026-08-05）：游戏 7.8 亿，同比 -30.6%，验证了此前判断；嵌入式 9.8 亿，同比 +18.6%。

**适用场景与注意事项**：适合有明确产品周期的硬件业务；主业之外的次要业务也要定位周期阶段，避免用线性外推。

### 6.5.5 内容与功能产能：用户粘性的前瞻指标

**方法要点**：用户粘性的源头在供给端：统计当季推出的新功能数量与类型、新上线的课程单元数，并与历史产出对比，判断“产能扩张”能否支撑 DAU 增长。

**操作步骤 / 拆分口径 / 公式**：
1. 统计当季推出的新功能数量和类型。
2. 统计新上线的课程 / 内容单元数。
3. 与历史产出对比（如一季度产出等于去年全年）。
4. 判断“内容 / 功能产能”的扩张能否支撑后续 DAU 增长。

**关键指标与数据来源**：新功能数量、新增课程单元数、对比历史产出。

**判断标准**：内容与功能产出相对历史大幅放量（单季接近或超过去年全年产出），则对 DAU 与粘性形成前瞻支撑；产出放缓则需警惕后续用户增长乏力。

**海豚案例**：
- 多邻国（2026-05-05）：Q1 推出 Spoken tokens、Flashcards、Speaking adventures 三项功能，上线 2 万多个单元课程，相当于去年一年的产出。

**适用场景与注意事项**：内容型产品（教育、游戏、视频）；供给端指标只是先行线索，最终要用 DAU、留存等需求端指标验证（用户与流量指标见 5.6）。

**相关方法交叉引用**：判断新业务的利润率稀释和收入起始时点，详见 8.6；AI 业务里程碑台账——逐条核对上季度电话会指引，本季是否再次确认，以此判定“跳票”，详见 9.6；新品占比 / 新品数量 / 规格结构追踪，详见 16.7。

**本节速查清单**
- [ ] 产品路线图与关键节点（工艺、性能、规格、量产时点）是否最新？“量产”与“放量”区分了吗？
- [ ] 对延迟传闻，是否用公司 IR 信息核实？
- [ ] 每个新产品是否有里程碑表（送样、首批出货、量产爬坡、收入占比、客户、产能锁定），并按季更新？
- [ ] 新业务的收入指引是否上调？单季贡献、累计出货、月产能、客户 / 合作方数量、SOP 到哪一步了？
- [ ] 次要业务处于产品周期的第几年？是否叠加了零部件涨价等扰动？
- [ ] 内容 / 功能产出相对历史如何？能否支撑 DAU 增长？
- [ ] 里程碑是否按时兑现，上季指引是否被再次确认（防止“跳票”）？
