## 14.1 第三方高频与另类数据

> 本节导读：财报一个季度才披露一次，而第三方数据（App流水与活跃、网页流量、门店客流、搜索热度、电商GMV与ASP、渠道扫描、信用卡、广告像素安装数等）按月、按周甚至按日更新，可以在财报前提前判断当季，在财报后与披露互验，并补全公司不披露的维度。海豚君使用这类数据的纪律有两条：一是第三方数据适合看趋势和相对强弱，绝对值必须用公司披露校准；二是高频数据已经透支的预期，要从财报当天的预期差里扣除。本节讲通用数据源的用法，行业专属的高频指标见第15、16章；高频数据与预期层级的关系见1.3，用户与流量指标本身的拆解见5.6，产业链与同业数据验证见14.2，份额与竞争格局判断见14.5。

### 14.1.1 高频数据使用总纲：提前判断当季、与财报互验、识别预期透支

**方法要点**：把第三方或高频数据当作财报前的“先行指标”和财报后的“对账单”：财报前用它估计当季并理解市场预期为何已经变化，财报后用披露值核对，同时留意第三方口径与公司口径的偏差。

**操作步骤 / 拆分口径**：
1. 财报前，为公司选定与收入最相关的高频代理变量：尼尔森月度零售数据（购买率、购买频次、家庭渗透率）、第三方平台活跃度监测、游戏流水、周订单、单月流水、公司按月披露的经营数据、便利店扫描数据、渠道GMV、App流水、用户活跃、产业调研、券商引述的供应链信息。
2. 把高频数据换算成对当季的方向性判断，与市场一致预期对照，回答“预期是不是已经被高频数据调整过了”。
3. 财报后，用披露值验证，并明确本次使用第三方数据的三种用途：①解释市场预期为何已调整；②验证份额变化；③发现公司披露与第三方数据的差异。
4. 逐一核对第三方口径与公司口径是否一致（覆盖平台、地区、统计对象）。第三方显示暴跌而公司披露温和，优先怀疑口径，而不是直接判定公司撒谎。
5. 高频数据如果已把预期推到位，财报当天的预期差要扣掉这一部分，转看未披露的项目（详见1.3）。

**关键指标与数据来源**：尼尔森数据、第三方APP监测（Sensor Tower）、久谦、QuestMobile、便利店扫描数据、周订单、月度经营数据、券商调研及供应链引述。

**判断标准**：
- 高频数据方向与财报披露一致，是趋势确认；方向不一致，先排查口径（只统计iOS、只统计某渠道、样本偏差），再判断是否为公司披露的问题。
- 高频数据已明显偏好，而财报仍显著超出，才是真正的超预期（Monster的案例：预期本就不低，实际仍更超）。
- 高频数据显示的“坏消息”早已被股价消化时，财报里的同类坏消息不构成新的利空。
- 第三方数据只提供方向和相对强弱，不用来精确推算收入。

**海豚案例**：
- Monster（2026-02-27）：外资行用尼尔森月度数据追踪购买率和购买频次，北美家庭渗透率创新高（33%），所以财报前预期已经较高。
- Roblox（2026-02-06）：第三方监测显示平台活跃度环比暴跌，但财报中总时长的降幅要温和得多，体现第三方数据与公司口径的偏差。
- AppLovin：假日季电商高频数据放缓，财报前预期已受影响。
- 小米（2026-03-24）：汽车周订单到3月初回落到4k左右。
- 快手：12月可灵单月流水2000万美元，用作AI业务的单月高频参照。
- Robinhood（2026-02-11）：公司按月披露经营数据，11月正股和期权交易已经明显下滑，财报前已可提前判断。
- Monster（2026-05-08）：外资行便利店高频数据显示能量饮料双位数增长，预期本就不低，实际仍更超。
- 可口可乐：扫描数据显示几乎全品类份额提升（用于验证份额变化）。
- Reddit（2026-05-01）：Cleveland调研显示商家削减品牌广告预算，股价承压（调研数据解释股价压力）。
- 亚朵（2026-05-13）：久谦数据显示线上GMV +41%，家纺大盘-10%（验证份额）。
- 腾讯音乐：QuestMobile数据显示全民K歌活跃下滑（解释社交娱乐恶化）。
- BOSS直聘：Sensor Tower流水（详见14.1.2）。
- 特斯拉《2Q26》：摩根士丹利引述供应商产能指引，作为量产节奏的第三方参照（详见14.2.4）。

**适用场景与注意事项**：适用于消费品、游戏、汽车、券商、互联网、广告平台等有公开高频数据的公司。第三方数据多以iOS或样本为主，覆盖有限；高频数据存在“已被市场提前定价”的问题，使用时先问“这个信息市场已经知道了吗”。

### 14.1.2 Sensor Tower iOS流水前瞻与“iOS增速 vs 总流水增速”解读

**方法要点**：用Sensor Tower跟踪移动端付费产品的iOS流水季度、月度同比，作为财报前后的前瞻验证；并把iOS流水增速与公司总流水（Billings）增速的差值，解读为客户付费行为结构的变化。

**操作步骤 / 拆分口径**：
1. 拉取iOS流水的季度同比与当季至今、单月同比（如Q1、Q2至今、7月）。
2. 与公司披露的Billings增速对比：
   - iOS增速 > 总流水增速：说明需求更多变成随招随买的灵活付费（偏中小企业），而不是单纯的需求景气，反映企业预算有压力或不确定性上升。
   - iOS增速加速：视为财报前后的正面前瞻信号，也可用来解释股价反弹。
3. 财报后用披露的Billings、收入验证前瞻是否兑现。

**关键指标与数据来源**：Sensor Tower iOS流水（季度和月度同比）、公司Billings增速。

**判断标准**：iOS流水连续加速（如从+14%到+29%）说明短期付费活跃；但若同时高于总流水增速，要提示需求质量偏弱、客户结构偏中小、预算压力上升，而不是简单作为景气证据。

**海豚案例**：
- Boss直聘（2026-05-20）：iOS端Q1 +14%，高于总流水增速；Q2至今+29%，进一步加速。
- Boss直聘（2026-08-25）：Q2 iOS流水+27%，7月+41%；海豚君解读为“企业对招聘预算整体还是有压力或者不确定性提升，更多的变成随招随买的灵活性需求”；7月高频数据加速带动股价反弹。

**适用场景与注意事项**：适用于移动端付费为主的互联网公司（招聘、游戏、订阅）。iOS只覆盖部分渠道，结构上可能存在偏差，需要结合公司披露的Billings做校正（口径偏差详见14.1.15）。

### 14.1.3 App用户端数据（下载量、MAU、DAU、人均时长）作前瞻用户与商户指标

**方法要点**：用Sensor Tower等第三方App数据，提前感知用户和商户增长的变化，作为收入、订阅商户数、MRR、MAU等财报指标的前瞻或互验。

**操作步骤 / 拆分口径**：
- 变体A：商家端App下载量与MAU，作为订阅商户增长的前瞻。观察商家端App下载量、MAU同比，出现首次同比下滑，暗示订阅商户增长不佳，可以解释MRR偏弱。
- 变体B：消费端App月度DAU增速序列，提前反映季度用户趋势。取相邻月份的DAU增速序列（如12月、1月），再按地区拆分，找出问题来源；观察加大营销、投放之后下滑是否被稳住；活动（如联名活动）结束后是否仍延续放缓趋势。
- 变体C：核心地区下载量、人均使用时长、分地区下载。核心地区下载量是用户的前瞻指标；人均时长同比用来判断用户健康度，进而判断广告疲软是不是变现问题；分地区下载用来验证国际扩张。
- 变体D（扣除已定价部分）：第三方数据往往被市场提前使用，已经体现在股价里，所以财报时的预期差要扣除这一部分。

**关键指标与数据来源**：App下载量、MAU、DAU同比（月度）、分地区数据、人均时长、用户数；Sensor Tower。

**判断标准**：
- 商家端App下载量和MAU双双同比下滑，且为多年来首次，是订阅商户增长偏弱的信号。
- DAU增速序列连续回落（如26%→22%）且集中在个别地区，要找出区域原因；加大营销后“基本稳住”说明下滑可被投放对冲，但活动结束后仍放缓则说明基础趋势没有改变。
- 时长仍在增长而广告表现疲软，说明问题出在变现而不是用户参与度。
- 第三方显示各地日活持续下降、核心市场下载量下滑，且已被股价提前反映，则财报当天不构成新的预期差。

**海豚案例**：
- Shopify（2026-05-06）：Sensor Tower显示Shopify Store App下载量和MAU双双同比下滑（2021年以来首次），暗示订阅商户增长不好。
- 多邻国（2026-02-27）：Sensor Tower显示12月DAU增速降至26%，1月22%，问题主要在北美和拉美；1月加大营销和广告投放后基本稳住；Dead Duo活动结束后Q1仍是放缓趋势。
- 奈飞（2026-07-17）：Sensor Tower显示各地App日活继续下降，前瞻指标上核心美国下载量下滑，市场已提前反映。
- 谷歌（2026-02-05）：YouTube用户时长仍增长，人均时长提升不亚于Instagram。
- 谷歌（2026-04-30）：YouTube用户数小幅增长、日均时长稳步提高。
- 迪士尼（2026-08-05）：日本Disney+下载量增长较高（验证国际扩张）。

**适用场景与注意事项**：适用于App驱动的消费互联网、订阅公司和SaaS。注意App数据对Web端和PC端覆盖不足，只能看方向；用户指标自身的拆解口径（MAU环比净增、DAU/MAU粘性、时长）见5.6。

### 14.1.4 海外业务：分地区MAU、访客排名与监管新闻互验

**方法要点**：跟踪出海平台的海外业务时，用第三方数据看分地区月活和全球独立访客排名，再结合海外监管处罚和调查新闻，与财报中的代理科目（如交易服务收入）互相验证，提前判断海外业务好坏。

**操作步骤 / 拆分口径**：
1. 用Sensor Tower等看分地区月活（例如美国月活是否恢复到关税前水平）、App MAU同比。
2. 用第三方报道看全球独立访客数及全球排名，据此校准自己对海外增速的预期（访问量已经很高时，增长不应太惊喜）。
3. 收集海外监管处罚、调查新闻，作为风险和费用的解释变量。
4. 与财报里的代理科目（交易服务收入）验证。

**关键指标与数据来源**：Temu美国月活（Sensor Tower）、全球独立访客数及排名、Temu App MAU同比、海外监管事件。

**判断标准**：月活恢复到政策冲击前水平，说明冲击已基本消化；访问量已排全球第二时，实际增长“不算惊喜”；App MAU同比下滑加上监管频繁调查和处罚，与交易服务收入明显不及预期相互印证。

**海豚案例**：
- 拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）：根据Sensor Tower数据，到12月Temu美国月活已接近关税前水平。
- 拼多多《拼多多：又老又“傲慢”，彻底人人嫌》（2026-05-27）：报道显示Temu全球独立访客3.66亿，访问量全球第二（仅次于亚马逊），所以海豚君原本预期更高，实际增长不算惊喜。
- 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：Temu App MAU同比下滑，加上欧盟频繁调查和处罚，与2Q佣金收入（交易服务收入）明显不及预期一致。

**适用场景与注意事项**：适用于跨境和出海平台。App数据对Web端覆盖不足，只能看方向；监管事件的量化测算见14.6.1。

### 14.1.5 第三方游戏流水、下载榜与token消耗：与财报互验

**方法要点**：财报前市场常依据第三方数据形成担忧或期待；海豚君用财报（含递延）来检验这些数据，并用下载榜、模型调用量判断AI产品的实际热度和性价比。

**操作步骤 / 拆分口径**：
1. 游戏：财报前取Sensor Tower流水同比，形成市场担忧的基线；财报后用披露的本土游戏收入（含递延收入口径）核对，判断担忧是否缓解。
2. AI模型：用OpenRouter的tokens消耗，判断模型被开发者实际调用的受欢迎度与性价比。
3. AI应用：用App下载排名，判断产品推广效果。

**关键指标与数据来源**：Sensor Tower流水、App下载排名、OpenRouter tokens消耗。

**判断标准**：财报披露显著好于第三方趋势，说明第三方数据覆盖有限（多为iOS或样本口径），应以财报为准，并视为担忧缓解；tokens消耗上升且性价比好，才支持“模型确实受欢迎”的叙事；下载榜位次反映推广效果，但不等于收入。

**海豚案例**：
- 腾讯《AI撒钱火力全开？》（2026-08-12）：市场依据Sensor Tower游戏流水担心腾讯流水同比下滑，财报本土游戏+17%后担忧缓解。
- 腾讯《不再躺尸功劳簿》（2026-05-13）：用OpenRouter tokens消耗判断模型实际受欢迎度与性价比。
- 百度《老业务继续磨底》（2026-08-18）：用App下载排名判断AI产品的推广效果。

**适用场景与注意事项**：游戏、AI应用。第三方数据多以iOS或样本为主，绝对值不能直接代入收入。

### 14.1.6 QuestMobile数据：时长份额、用户重合度、DAU/MAU与商家端月活

**方法要点**：用QuestMobile（QM）验证财报并判断竞争，尤其适合对已停止披露某些数据的中国互联网公司。

**操作步骤 / 拆分口径**：具体用法包括：
1. 时长与份额：微信总时长与行业份额；整体互联网时长（剔除短视频后）是否下滑。
2. 活跃度：长视频活跃度的变化（“惨不忍睹”），解释腾讯视频会员流失；全民K歌活跃下滑，解释TME社交娱乐业务恶化。
3. 用户重合度与粘性：汽水音乐的DAU/MAU，以及与QQ音乐、喜马拉雅的用户重合度，判断新进入者对在位者的冲击。
4. 商家端月活：抖音到店商家月活已超美团且差距拉大，用来判断本地生活的竞争格局。

**关键指标与数据来源**：QM时长、MAU/DAU、用户重合度、商家月活。

**判断标准**：第三方活跃度的下滑方向与公司业务恶化一致，才可作为解释；商家端月活的反超和差距扩大，是竞争格局变化的领先信号；重合度高说明新进入者在抢同一批用户。

**海豚案例**：腾讯（2026-03-18、2026-05-13、2026-08-12）、腾讯音乐（2026-03-17、2026-05-12、2026-08-11）、美团《AI分走战火》（2026-06-01）：分别使用QM的上述数据，即微信时长份额、长视频活跃度、全民K歌活跃度、汽水音乐DAU/MAU与重合度、抖音到店商家月活和整体互联网时长。

**适用场景与注意事项**：中国互联网公司；对停止披露数据的公司尤为关键。QM的垂类MAU排名、时长份额与用户粘性的同业横向对比，见5.6。

### 14.1.7 流量来源结构：App端vs Web端、搜索导流vs直接访问

**方法要点**：用第三方流量数据拆分App端和Web端的DAU走势，再拆Web端访问来源（搜索导流、直接访问），量化公司对外部流量入口的依赖度，识别合作关系的风险。

**操作步骤 / 拆分口径**：
1. 拆App端DAU与Web端DAU的走势，找出放缓来自哪个端。
2. 拆Web端访问来源：搜索（Google）导流与直接访问。
3. 把公司DAU增速与搜索导流增速对比，走势一致则得出“吃搜索导流红利”的结论。
4. 量化依赖度：搜索贡献约30-40%的新流量；再观察直接访问是否恢复（通过优化访问便利性和个性化推荐）。
5. 评估合作关系的风险：搜索入口算法或政策变化会直接冲击流量。

**关键指标与数据来源**：App/Web DAU；流量来源占比；Google导流增速；第三方流量数据。

**判断标准**：DAU增速与搜索导流增速同步，说明增长主要来自外部流量红利，而不是内生；直接访问明显下滑说明品牌心智弱化，恢复则说明产品改善有效；外部流量占比越高，对合作关系的风险敞口越大。

**海豚案例**：
- Reddit（2026-02-06）：App端DAU放缓明显，Web端保持稳定；Google搜索是Web端主要来源，流量次数还在稳步提高；Reddit直接访问在Q2明显下滑，Q3-Q4通过优化访问便利性和个性化推荐有所恢复；机构把Reddit披露的DAU增速与Google导流增速对比，发现趋势基本一致（该思路也见14.2.5“核心大客户或流量来源作为领先指标”）。
- Reddit（2026-07-31）：Google大约贡献30-40%的新流量。

**适用场景与注意事项**：依赖外部流量入口的平台（社区、内容、电商）。

### 14.1.8 用SimilarWeb流量数据量化检验AI叙事

**方法要点**：用第三方网页流量数据，量化AI叙事的实际进展，从而证实或证伪叙事带来的业绩想象空间。

**操作步骤 / 拆分口径**：
1. 取SimilarWeb网页端LLM（大模型）直接带来的电商流量占比。
2. 看近几个月（近三个月）趋势，判断是否在提升。
3. 与竞争对手同口径比较。
4. 结合调研，从“绝对比重”和“提升速度”两个角度下结论。

**关键指标与数据来源**：SimilarWeb网页端LLM导流占比及近三月趋势、竞对对比。

**判断标准**：绝对比重极低且近期没有提升，则叙事缺乏数据支持，想象空间应被打折；比重低但提升快，则要重点跟踪。

**海豚案例**：Shopify（2026-08-06）：网页端LLM直接带来的流量占比最高仅0.7%，Shopify不到0.3%，且近三个月基本没有提升，海豚君判定Agentic Commerce的想象空间已基本破灭。

**适用场景与注意事项**：AI叙事驱动的互联网、电商、广告公司。网页端数据不含App内和Agent内部交易，结论只能说明“当前”进展。

### 14.1.9 月度MAU份额追踪赛道格局

**方法要点**：用卖方（如UBS）的月度追踪数据，观察产品在赛道中的MAU份额与赛道总量的变化，判断竞争格局，并与财报MAU互相验证。

**操作步骤 / 拆分口径**：
1. 取公司各产品线的月度MAU份额与赛道总MAU。
2. 判断：龙头份额是否稳定；海外新产品是否爆发；大模型是否侵蚀轻度用户。
3. 把赛道总量（扩张或收缩）与公司MAU对比，区分是赛道问题还是份额问题。
4. 与财报披露的MAU互验。

**关键指标与数据来源**：UBS月度MAU、赛道份额。

**判断标准**：份额稳定而赛道总量收缩，说明问题在赛道，不在公司；份额持续收缩说明竞争力下降；新产品在海外爆发但与既有产品差异化，说明增量空间存在。

**海豚案例**：
- 美图（2026-03-28）：美图系在国内图片编辑仍是龙头，份额稳定；Wink海外全面爆发，与剪映差异化竞争，但视频编辑赛道份额持续收缩。
- 美图（2026-08-26）：据UBS，生活场景整体市场收缩。

**适用场景与注意事项**：移动互联网App类公司。

### 14.1.10 Pixel安装数与商家域名数：追踪广告新业务的客户渗透

**方法要点**：把第三方渠道跟踪的广告像素（如AXON Pixel）安装商家数、域名数，当作电商广告客户渗透的高频指标，在财报前预判收入增速，财报后印证需求是否真的爆发。

**操作步骤 / 拆分口径**：
1. 追踪Pixel安装的商家数、商家域名净增。
2. 财报前：净增放缓预示收入增速放缓，买方会据此调整预期。
3. 财报后：产品放开（如自助平台全面开放）后，看安装数是否显著增长，据此印证需求是否爆发。

**关键指标与数据来源**：Pixel安装商家数；商家域名净增。

**判断标准**：净增放缓＝增速前瞻转弱；产品放开后安装数无明显增长，说明需求没有爆发，股价回调有基本面依据。

**海豚案例**：
- Applovin（2026-02-12）：开年以来AXON Pixel商家域名数净增放缓，买方已调整预期。
- Applovin（2026-08-06）：广告自助平台全面开放后，Pixel安装人数维持在7000左右、没有显著增长，电商需求未爆发，6月后股价开启回调。

**适用场景与注意事项**：广告技术、SaaS等可追踪安装量的公司。

### 14.1.11 电商平台第三方GMV/ASP数据（久谦、天猫淘宝、抖音口径）

**方法要点**：用第三方电商数据追踪线上GMV、ASP和分平台增速，验证财报、判断增量来源和份额，并量化舆情冲击的深度与持续时间。

**操作步骤 / 拆分口径**：
- 变体A（价格、结构、渠道拆分）：
  1. 分品类单品ASP同比：判断是否在降价换量。
  2. 整体ASP变化是否只来自品类结构（高单价品类占比提升而非单品提价）。
  3. 分平台增速（货架电商vs内容电商）：判断增量来源，以及销售费用率的长期下行空间（内容电商流量靠买、复购弱，会压缩销售费用率下行空间）。
  4. 月度GMV同比：量化舆情冲击的深度和持续时间。
- 变体B（对比大盘与竞品，判断是否逆周期拿份额）：
  1. 追踪公司月度、季度线上GMV（久谦）及抖音官方月销售额。
  2. 与同期品类大盘、主要竞品对比：公司增速远高于大盘而竞品大幅下滑，说明逆周期拿份额；月度增速环比提速，说明仍处在渗透率快速提升阶段。
  3. 用这些数据反驳市场担忧（爆品渗透率见顶、传统龙头抢份额），并提前预判下季零售收入。

**关键指标与数据来源**：月度/季度线上GMV同比（久谦）、抖音官方月销售额、品类ASP、分平台增速、品类大盘同比、竞品同比。

**判断标准**：
- 单品降价而整体ASP靠结构抬升，打破“不靠降价换增速”的逻辑；增量转向内容电商且复购弱，销售费用率难以继续下降。
- 公司增速大幅高于品类大盘、竞品下滑，是份额获取；同行能跟卖相似单品，但难以复制品牌故事、直播转化和场景导流。

**海豚案例**：
- 亚朵（2026-08-21）：久谦数据显示6月枕头ASP -7%至442元、被芯 -11%至506元，整体ASP仅+2%且完全靠向高单价被芯倾斜，打破了不靠降价换增速的逻辑；6月天猫淘宝+8%、抖音+51%，增量转向内容电商，流量靠买、复购弱，压缩销售费用率的下行空间。
- Lululemon（2026-09-04）：天猫淘宝口径GMV 5月-54%、6月-45%、7月-39%，二季度滚动三个月接近腰斩（量化舆情冲击的深度与持续时间）。
- 亚朵《亚朵：零售狂飙…》（2026-03-17）：1月抖音官方销售额1.6亿，+67%，较12月的37%明显提速。
- 亚朵《亚朵：酒店回血…》（2026-05-13）：久谦数据显示Q1线上GMV +41%，家纺大盘-10%；3月全部线上渠道零售额+43.4%，同期家纺大盘-26%，水星/罗莱分别-36.1%/-36.7%；结论是同行可以跟卖相似单品，但难以复制品牌故事、直播转化和酒店场景导流。

**适用场景与注意事项**：适用于中国线上占比高的消费品牌、电商渠道占比高的公司。第三方数据有覆盖偏差，适合看趋势和相对强弱，不适合精确推算收入。

### 14.1.12 渠道扫描数据：便利店扫描与尼尔森品类大盘

**方法要点**：用外资行或零售商反馈的渠道扫描数据（如北美便利店扫描、尼尔森月度零售），看品类大盘增速与主要玩家增速，判断业绩爆发的前提、竞品动作的性质，以及放缓信号。

**操作步骤 / 拆分口径**：
1. 判断品类景气：品类大盘是否处于高增长，作为业绩爆发的前提。
2. 判断竞品新品性质：竞品增速没有显著超过公司，即为“做大蛋糕”，而不是抢份额。
3. 捕捉放缓：把竞品近10周增速与此前12周增速对比。
4. 用尼尔森月度数据看购买率、购买频次、家庭渗透率，判断用户基础与预期高度。

**关键指标与数据来源**：便利店渠道品类销售增速、品牌增速、近N周滚动增速；尼尔森购买率、购买频次、家庭渗透率。

**判断标准**：大盘与两大龙头同时回到双位数，景气是前提；竞品增速骤降（如从+8.7%到+0.5%）并伴随SKU精简、对标产品低价竞争，则留下竞争窗口期；扫描数据已显示双位数增长而财报仍更超，才算真正超预期。

**海豚案例**：
- Monster（2026-05-08）：一季度能量饮料大盘约+13%，Monster约+12%，红牛约+11%，两大玩家都回到双位数；红牛无糖新品没有显著跑赢Monster，说明是做大蛋糕；Celsius近10周仅+0.5%，此前12周为+8.7%，大幅减速（SKU精简加Costco Kirkland对标产品24罐16.99美元），2026年是Monster的竞争窗口期。
- Monster（2026-02-27）：尼尔森月度数据显示北美家庭渗透率创新高（33%），财报前预期较高（见14.1.1）。

**适用场景与注意事项**：适用于饮料、零食等便利店渠道占比高的美国快消品。该类数据在食品饮料行业的专属用法，详见16.7。

### 14.1.13 门店客流（Placer.ai）与搜索热度（Google Trends）追踪品牌势能

**方法要点**：用月度门店客流同比验证线下同店下滑的来源，用搜索热度同比及品牌排名衡量品牌势能的相对变化，并与竞品对照。

**操作步骤 / 拆分口径**：
1. Placer.ai月度门店客流同比：拆月度，看趋势与幅度，并结合公司策略（主动收缩折扣、转向正价销售）判断客流下降是否部分为主动取舍的代价。
2. Google搜索热度同比：与同类品牌横向排名（如35个运动品牌），再与竞品（Nike、Hoka）同期对照。

**关键指标与数据来源**：Placer.ai门店客流月度同比、Google搜索热度同比及排名。

**判断标准**：客流下滑若部分来自主动收缩折扣，则不能简单等同于品牌力下降；搜索热度同比下滑且排名靠后、竞品同期大幅增长，说明品牌势能被竞品挤压。

**海豚案例**：
- Lululemon（2026-06-05）：Placer.ai显示Q1门店客流约-4.1%（2月-1.9%，3月-7.1%），一部分是主动收缩折扣、转向正价销售的代价。
- Lululemon（2026-09-04）：6月美国Google搜索热度-6%，在35个运动品牌中排倒数第三，同期Nike +29%、Hoka +14%。

**适用场景与注意事项**：适用于美国线下零售和消费品牌。搜索热度反映关注度，不等于销售，需要与同店、GMV数据交叉验证。

### 14.1.14 公司不披露同店时：调研区间＋信用卡数据＋客流数据补全并追踪

**方法要点**：公司不披露同店具体值时，用调研区间、业绩会披露的季后同店、外资行信用卡高频数据和Placer.ai客流数据，补全同店趋势并按月追踪。

**操作步骤 / 拆分口径**：
1. 国内：结合调研给出同店区间（如中个位数→高个位数→双位数），再用业绩会披露的季后1-2月同店验证趋势。
2. 海外：用外资行信用卡高频数据追踪美国月度同店变化，判断降速。
3. 流量引流型业务：用Placer.ai周客流数据解释交易次数加速（如会员店加油站周客流），并用管理层给的加油量 vs 行业、燃油会员其他品类消费倍数验证引流效应。

**关键指标与数据来源**：调研同店区间、信用卡数据月度增速、Placer.ai周客流同比、加油量同比 vs 行业。

**判断标准**：区间逐季上移说明趋势改善；信用卡数据月度回落说明海外降速；引流业务的客流提速与管理层给出的倍数相互印证，才能确认交易次数加速。

**海豚案例**：
- 名创优品（2026-04-01）：Q4国内同店由Q3中个位数升至近双位数，北美同店突破20%，海外约15%。
- 名创优品（2026-05-26）：美国1-2月>20%，3月信用卡数据回落至19.7%，Q1海外同店低个位数。
- 沃尔玛（2026-05-22）：Placer.ai显示山姆加油站3月周客流+10~13%、4月中旬+16%以上。
- 沃尔玛（2026-08-21）：5月山姆加油量+12% vs 行业-5%，燃油会员其他品类消费为1.6倍。

**适用场景与注意事项**：零售、餐饮。另类数据样本覆盖需要注意；调研区间属于估计，应在后续披露中验证。

### 14.1.15 识别第三方数据口径缺陷，并用公司披露校正

**方法要点**：使用第三方数据前先检查其覆盖范围：只统计iOS、只覆盖某渠道的数据，会系统性偏离公司真实表现；判断以公司披露（如ARR及环比）为准，并把口径偏差本身当作预期差的来源。

**操作步骤 / 拆分口径**：
1. 确认第三方数据的统计范围（iOS/Android、App/PC/Web、C端/B端）。
2. 判断业务结构：生产力类工具的B端（专业用户）收入主要在PC端或Web端，第三方往往统计不到；B端占比逐季提升时，第三方趋势会系统性低估。
3. 用公司披露指标（ARR及环比、B端收入占比、季度收入）校准，以披露为准。
4. 将口径偏差转化为预期差判断：市场按第三方数据形成的悲观预期，会在财报披露后产生“小超预期”。

**关键指标与数据来源**：第三方iOS月流水、公司披露的ARR及环比、B端收入占比、季度收入。

**判断标准**：第三方显示流水快速滑落，而公司披露ARR环比增长，则以ARR为准；B端占比越高，第三方低估越严重。

**海豚案例**：
- 快手《快手：一场向死而生的暴跌，能换来AI重生吗？》（2026-03-25）：外部数据显示可灵1月流水（iOS）快速滑落，但电话会披露1月ARR超过3亿美元，环比+25%；B端占比在3Q已达40%，主要在PC端，正好是第三方数据缺失的口径。
- 快手《失望指引致暴跌，250亿美金的快手能“捞”吗？》（2026-03-26）：小超预期的主要原因是市场只跟踪iOS App流水，可灵实际在B端（专业用户）卖得更开。

**适用场景与注意事项**：适用于AI应用、SaaS、游戏等多端分发的产品。第三方数据适合看趋势，绝对值必须用公司披露校准。

**本节交叉引用**：MAU环比净增与往年同期比较、QuestMobile看垂类MAU排名和时长份额，详见5.6；粘性指标（DAU/MAU、日均时长）加QuestMobile总时长的同业横向对比，详见5.6；用户活跃出现反常的季节性回落作为增长前瞻（加第三方下载量验证），详见5.6；用户活跃度与第三方核对，详见5.6；用第三方追踪数据（FSD Tracker接管里程）和硬件参数验证自动驾驶技术进展，详见16.1；尼尔森月度扫描数据追踪购买率、购买频次、家庭渗透率以预判并验证财报，详见16.7；同业电话会表述加机场客流高频数据交叉验证需求，详见14.2；月度或第三方高频数据提前透支预期后转看未披露项，详见1.3。

**本节速查清单**
- [ ] 选定与收入最相关的高频代理变量，并在财报前形成对当季的方向性判断
- [ ] 核对第三方数据的覆盖范围（iOS/PC/Web、C端/B端、样本），必要时用公司披露的ARR、Billings、时长校准
- [ ] 比较iOS流水增速与总流水增速，解读付费结构（灵活随买 vs 景气）
- [ ] 看用户指标的序列（月度DAU、下载量、MAU）与区域拆分，判断营销投放是否稳住下滑
- [ ] 用公司、品类大盘、竞品三条线对照电商GMV、渠道扫描，判断是否逆周期拿份额
- [ ] 区分客流/搜索热度下降是主动取舍还是品牌势能下降
- [ ] 判断高频数据是否已被股价和预期提前消化，扣除后再评估财报当天的预期差
- [ ] 对AI叙事、新业务渗透用可量化的第三方数据（SimilarWeb、Pixel安装数）验证“绝对比重”和“提升速度”

## 14.2 产业链上下游与同业财报验证

> 本节导读：当公司自身指标难以拆分、管理层又回避关键节点时，海豚君会借用供应商、客户、同业、上游分部和龙头公司的财报与表述做交叉验证，用来确认趋势、识别与产业链不一致的地方，并外推政策冲击。本节讲怎么选取“对照公司”、怎么对照口径、怎么把对方的数据转化为对本公司的领先或互验信号。同业横向对比与份额判断见14.5，宏观统计和行业基准数据见14.3，行业专属的同业同店与RevPAR交叉验证见16.6。

### 14.2.1 用供应商与同业财报交叉验证平台变现率和政策冲击

**方法要点**：平台自身指标难以拆分时，借用上游供应商或同业的公开数据做验证，推断平台对上游的变现率变化，并把同业对某项政策影响的明确表态外推到商家结构相近的平台。

**操作步骤 / 拆分口径**：
1. 变现率推断：取供应商端（如酒店集团）的收入、客单价、RevPAR环比变化，与平台（OTA）对应业务的收入增速、环比变化对照。供应商端环比改善而平台端环比降速，推断平台变现率下滑，并结合监管背景解释。
2. 政策冲击外推：同业管理层对某项政策影响的明确表态（如在指引中归因于电商征税），外推到商家结构相近的平台，按商家构成估计受冲击程度。
3. 会计口径参照：同业的会计口径调整，也可作为本公司口径变化的参照。

**关键指标与数据来源**：酒店集团RevPAR、客单价、收入环比；OTA酒店收入增速；同业指引中的归因表述。

**判断标准**：上游供应商经营环比改善而平台降速，是变现率（take rate）被压缩的信号；同业将指引欠佳归因于政策时，政策冲击在商家结构相近的公司同样成立，受冲击程度取决于商家构成（如直播电商受冲击最大）。

**海豚案例**：
- 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：1Q26亚朵和华住的酒店收入、客单价环比改善，携程酒店收入（+17.5%）却环比降速，海豚君怀疑监管下酒店预订变现率下滑。
- 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：快手对3Q电商指引欠佳，明确提到电商征税变严的影响；直播电商受冲击最大，拼多多从商家构成看仅次于直播电商，因此外推到拼多多。

**适用场景与注意事项**：适用于平台型公司（OTA、电商）的变现率推断。上下游数据的统计口径和区域覆盖可能不一致，只能作为辅助证据。监管影响的归因与同业股价交叉验证，见14.6.12。

### 14.2.2 用上下游、同业和客户的财报与指引互相验证（产业链交叉验证）

**方法要点**：点评一家公司时，同步引用产业链上下游刚发布的数据与指引，确认趋势，或识别与产业链不一致之处。

**操作步骤 / 拆分口径**：
1. 客户capex对照设备商节奏：客户（代工厂、存储厂、云厂商）的资本开支节奏，对照设备商的订单与指引；上下游节奏一致则趋势确认。
2. 终端厂判断对照代工厂、芯片厂需求：终端厂或上游芯片厂对市场周期位置的判断，对照下游代工或品牌需求。
3. 龙头指引力度对照同行指引：龙头给出明确程度、增速，用作同行指引的参照，判断市场对同行的期待。
4. 同业价格与毛利率信号：同业毛利率变化、涨价（如成熟制程毛利率上行、8寸普遍涨价）用来判断供需紧张是否外溢到更多领域，对设备需求是增量。
5. 客户重大披露：客户披露的新产能、前期投入和技术节点选择（如特斯拉财报会透露的Terafab，近期30亿美元前期投入、预计采用英特尔14A），为被选中的供应商增加确定性。
6. 产品路线规格：客户产品路线与规格（英伟达的Vera、Rubin CPX、ICMS、Rubin Ultra HBM规格）用于验证存储等上游需求。
7. 核对时效与口径：对方信息的发布时间、统计口径要与本公司一致。

**关键指标与数据来源**：客户capex、供应商指引、终端厂判断、竞争对手指引、同业毛利率与价格、客户财报会披露、产品路线规格。

**判断标准**：
- 客户capex节奏与设备商指引的“前低后高/集中在下半年”相吻合，则本公司指引可信；
- 龙头明确给出多年增速目标，而同行没有给，市场会期待同行给出同等程度的明确指引；
- 同业价格或毛利率上行，说明供需紧张在向其他细分外溢；
- 产业链各环节说法不一致的地方，就是需要在点评里重点说明的风险或预期差。

**海豚案例**：
- 台积电（2026-04-16）：资本开支集中在下半年，与前一日ASML全年“前低后高”的指引吻合。
- 台积电（2026-07-16）：下半年资本开支同比+56-75%，符合ASML节奏。
- ASML（2026-07-15）：引用美光上调资本开支和签订EUV协议。
- 中芯（2026-05-14）：引用高通管理层“手机市场有望在二季度触底”。
- 博通（2026-09-03）：以英伟达明确给出2028财年70%以上增速作为对照，市场期待博通给出同等明确的指引。
- 海力士（2026-07-29）：引用谷歌资本开支和美光的LTA（长期协议）披露。
- ARM（2026-07-30）：引用微软资本开支的态度。
- 应用材料《泼天富贵在前…》（2026-08-14）：用中芯国际毛利率判断成熟制程开始上行、8寸普遍涨价，得出“供需紧张外溢到更多半导体领域”，对设备需求是增量；并用台积电和美光的capex指引验证AMAT与ASML。
- 英特尔《英特尔：告别“至暗”时刻…》（2026-04-24）：特斯拉财报会透露Terafab近期30亿美元前期投入、预计采用英特尔14A，增加英特尔合作确定性，英特尔盘后+3%。
- 美光（2026-03-19与2026-10-01）：用英伟达产品路线（Vera、Rubin CPX、ICMS、Rubin Ultra HBM规格）验证存储需求。

**适用场景与注意事项**：产业链研究和财报季连续点评；半导体链条用得最多。要确认信息的时效与口径一致，避免把不同时点、不同口径的数据直接并列。

### 14.2.3 引用上游/同业管理层交流观点验证行业周期判断

**方法要点**：引用上游芯片厂等管理层的观点，判断问题的性质与市场所处的周期位置，作为下游品牌商业绩拐点的外部验证。

**操作步骤 / 拆分口径**：
1. 判断问题性质：上游管理层对存储问题的表述从“涨价”升级为“短缺”，则会直接影响下游出货，而不只是成本上升。
2. 判断周期位置：渠道库存去化是否缓解、市场哪个季度触底、下半年是否环比回升。
3. 把上游的判断映射为下游品牌商的业绩拐点预期，并与公司自己的指引对照。

**关键指标与数据来源**：产业链管理层口径、渠道库存、市场触底时点。

**判断标准**：上游称“短缺”而不是“涨价”，意味着出货受限；上游称渠道库存去化缓解、下季触底、下半年环比回升，则为下游拐点的外部验证。

**海豚案例**：
- 小米《天堂急跌地狱…》（2026-03-24）：结合高通管理层交流，存储涨价已升级为存储短缺，将直接影响手机出货。
- 小米《跌到怀疑人生？…》（2026-05-26）：高通称渠道库存去化将缓解，中国安卓市场下季触底，下半年重回环增。

**适用场景与注意事项**：适用于产业链上下游联动紧密的行业（半导体-消费电子）。管理层交流观点属于定性信息，需要与出货、库存数据互验。

### 14.2.4 引用卖方或行业报道的供应链下单指引，补充管理层未确认的量产进度

**方法要点**：管理层在电话会上回避具体节点时，用卖方引述的行业报道、供应商产能指引（每周台数），侧面判断量产节奏和市场预期的变化，作为预期差的参照。

**操作步骤 / 拆分口径**：
1. 记录电话会上管理层没有确认的关键节点（量产时间、产能）。
2. 引用卖方（如MS）转述的行业报道：供应商被要求的产能指引（台/周）和时间节点。
3. 对比“供应链口径”与“公司口径”：供应链下单量重新点燃市场期待，但公司没有确认，则形成预期差。
4. 对第三方信息保持交叉验证，等待公司确认。

**关键指标与数据来源**：供应商产能指引（台/周）、时间节点。

**判断标准**：供应链节奏（如9月前每周1000台、年底前每周2000-2500台）与公司口径不一致时，以公司确认为准，但可用作市场预期变化的解释。

**海豚案例**：特斯拉《造车硬抗…》（2026-07-23）：MS引述行业报道，特斯拉已向供应商下达9月前每周1000台、年底前每周2000-2500台的Optimus产能指引，市场因此重新期待量产，但电话会没有确认关键节点。

**适用场景与注意事项**：适用于新品量产期的硬件公司。第三方信息需要交叉验证，不能当作公司指引。

### 14.2.5 把核心大客户（或流量来源）的经营数据当作公司收入的领先指标

**方法要点**：公司收入高度依赖某个外部大客户或流量入口时，追踪对方的年化收入、用量和产品发布，把它们作为公司云用量与收入的领先指标。

**操作步骤 / 拆分口径**：
1. 识别客户集中度：哪个客户或入口贡献了关键增量。
2. 追踪对方的ARR（年化收入）、Token消耗量、模型发布节奏、外部导流量。
3. 映射：客户ARR翻倍，供应商相关收入大概率同幅增长；客户新品若成功、Token消耗再攀升，供应商增速可能超预期。
4. 结合公司自身的合同余额（RPO）规模和产品提价，判断公司何时走出低迷期。
5. 流量依赖型平台：把公司披露的用户增速与外部导流增速对比，趋势一致则说明依赖度高（详见14.1.7）。

**关键指标与数据来源**：客户ARR；Token消耗量；模型发布节奏；外部导流量；RPO。

**判断标准**：客户新产品能否复制成功、推高Token消耗，是供应商增速超预期的触发条件，可直接作为入手信号；大客户的月度ARR已经高出整个上一季度，则当季云收入大概率超预期。

**海豚案例**：
- 亚马逊（2026-04-30）：Anthropic年化收入从25年底约90亿涨到26年3月的190亿；AWS作为主要算力供应商，一季度AI收入大概率有类似幅度的增长；后续跟踪Claude Mythos等新模型能否复制Claude Code的成功、推高Token消耗，把它作为入手亚马逊的信号。
- Reddit（2026-02-06）：机构把Reddit披露的DAU增速与Google导流增速对比，发现趋势基本一致。
- 微软（2026-07-30）：Codex近期猛追，OAI 7月ARR收入已高出整个二季度；7月GPT 5.6发布带动云用量；RPO接近6800亿，结合合同余额和产品提价判断何时走出低迷。

**适用场景与注意事项**：客户集中度高的供应商（云、算力），或流量依赖型平台。大客户自身的ARR口径与公司确认收入存在时滞，也不一定与供应商收入同幅增长，应保留转化折扣。

### 14.2.6 同业电话会表述加区域高频客流，交叉验证短期需求

**方法要点**：用竞争对手的电话会对需求的定性表述，加上区域性与全国性的客流高频数据，判断短期需求的边际变化，再与公司实际经营数据对比，得出“没想象中那么差”或“压力不如同行”的判断。

**操作步骤 / 拆分口径**：
1. 收集同业管理层对需求的描述（如6月之后需求下滑、下季持续承压）。
2. 用区域机场客流与全国航空客流数据验证需求是否确实疲软。
3. 对比公司实际经营数据（本土客流、人均消费）。

**关键指标与数据来源**：同业管理层表述、机场旅客吞吐量、全美航空客流。

**判断标准**：同业与客流数据都显示疲软，而公司的客流、人均仍在增长，则评价为“没想象中那么差”、相对同行韧性更好。

**海豚案例**：迪士尼（2026-08-05）：6月底Comcast称6月之后奥兰多主题公园需求下滑、下季持续承压；奥兰多机场与全美客流显示需求确有疲软；但迪士尼本土客流+3%、人均+4%。

**适用场景与注意事项**：旅游、线下消费、交通相关公司。行业专属的同业同店与出行成本交叉验证，见16.6。

### 14.2.7 以龙头公司财报为宏观消费晴雨表

**方法要点**：把Costco等消费龙头的客流、客单、续费率、新增会员，与官方统计数据对照，判断宏观消费的走势及原因，并识别底层风险。

**操作步骤 / 拆分口径**：
1. 取龙头公司的客流、客单、续费率、新增会员数据。
2. 与官方零售统计（美国统计局零售数据）对照，判断名义消费为何不降反升：通胀初期抬名义额、美股财富效应、3–4月退税。
3. 识别底层风险：客流持续走低（如不足2%）、线上对线下的替代。
4. 把AI裁员叙事（亚马逊裁员、Block削减40%员工）对中产客群的潜在冲击纳入风险。

**关键指标与数据来源**：美国统计局零售数据、公司客流/客单/续费率、宏观事件。

**判断标准**：官方统计和公司业绩同时显示零售不降反升，说明通胀未导致零售下滑；但客流持续走低、商品价格高位，可能对消费造成反噬；高薪岗位裁员从逻辑上冲击中产客群。

**海豚案例**：
- Costco（2026-05-29）：统计局数据和公司业绩都显示，美伊冲突后通胀走高并未导致零售下滑，反而提速；但美国门店客流持续走低到不足2%，商品价格高位之后可能对消费造成反噬。
- Costco（2026-03-06）：亚马逊裁员万人、Block靠AI削减40%员工，高薪岗位裁员从逻辑上冲击中产客群。

**适用场景与注意事项**：适用于用零售、支付、消费龙头的数据研判宏观消费。同业同店差距推断消费分层的方法见14.5.10。

### 14.2.8 拆分上游分部收入增量来源（下游结构＋量价），验证供给受限

**方法要点**：用上游公司的分部财报验证“某类产能扩张受限”的判断：下游需求暴增而上游以价为主、量不动，说明产能被锁死、上游掌握定价权。

**操作步骤 / 拆分口径**：
分部收入 → 同比增量 → 按下游拆各自贡献占比 → 再拆量和价。
1. 取分部收入与同比增量（如发动机业务板块收入43.20亿美元，同比+15.6%，增量5.85亿美元）。
2. 增量按下游拆分（商业与国防航发贡献45%，燃机贡献32%）。
3. 再对下游需求最强的一类拆量与价：燃机增长主要来自产品涨价，而非销量放大。
4. 再看其他上游环节增速（PCC 2025年收入同比仅增4.6%，增速放缓）作为佐证。

**关键指标与数据来源**：分部收入、同比、增量贡献占比（航发45%、燃机32%）、量价拆分。

**判断标准**：下游需求暴增而上游增量主要来自价格、销量没有放大，就是产能被锁死、上游掌握定价权的证据。

**海豚案例**：《AI电荒突围》（2026-04-14）：HWM 2025年发动机业务板块收入43.20亿美元，同比增长15.6%（增量5.85亿美元），增量里商业与国防航发贡献45%，燃机贡献32%，但燃机增长主要来自产品涨价而非销量放大；PCC 2025年收入同比仅增4.6%，增速放缓；据此验证燃机产能扩张受限。

**适用场景与注意事项**：适用于用财报交叉验证产业链供需判断。需要公司披露足够细的分部数据或电话会说明。

**本节交叉引用**：逐个分部比较收入和利润与彭博预期、并用上市子公司公告交叉验证，详见2.3；酒店行业STR月度RevPAR＋出行成本（燃油附加费）＋同业同店交叉验证，详见16.6；同业同店差距对照推断消费分层（Costco vs Walmart），详见14.5；监管影响归因与同业交叉验证，详见14.6。

**本节速查清单**
- [ ] 找出能互相印证的“对照公司”：上游供应商、下游客户、同业龙头、终端厂，并确认其披露时间与统计口径一致
- [ ] 把客户capex与设备商、代工厂指引放在同一时间轴上对比，检查节奏是否吻合
- [ ] 平台变现率难以拆分时，对比上游商户的收入、客单价与平台对应业务的环比
- [ ] 引用同业管理层对政策或周期的表态时，先核对对方商家结构、客群与本公司的相似度
- [ ] 对依赖大客户或流量入口的公司，追踪对方的ARR、Token消耗、模型发布与导流量
- [ ] 管理层不确认关键节点时，用供应链下单指引侧面验证，并标明是第三方信息
- [ ] 判断“供给受限”时拆分上游增量：下游结构，量还是价
- [ ] 用龙头公司数据与官方统计对照，识别宏观消费背后的结构性风险（客流、替代、裁员）

## 14.3 宏观统计与行业基准数据

> 本节导读：公司业绩好坏离不开所处行业的大环境，海豚君习惯先拿官方统计和行业数据给公司表现“定锚”，再区分哪一部分是行业β、哪一部分是公司α。本节涵盖统计局社零分品类与线上实物零售、海关出口与行业销量、美国统计局无店铺零售、牌照与签证等供给数据，以及宏观冲击在不同公司传导位置的识别。公司与行业、竞对三方对照的份额判断见14.5，政策冲击的量化测算见14.6，龙头财报充当宏观晴雨表见14.2。

### 14.3.1 行业数据给公司表现定锚：跑赢还是跑输，竞争地位与需求解释

**方法要点**：用行业增速、第三方份额与活跃度数据、政策或供给数据，为公司表现定一个“锚”，判断公司是跑赢还是跑输行业、竞争地位如何、需求变化由什么解释。

**操作步骤 / 拆分口径**：
1. 行业增速对比公司增速：同口径、同周期并列，判断跑输、跑赢以及落后或领先幅度。
2. 第三方份额与活跃度数据验证竞争地位（如活跃用户占比、收视份额、下载量）。
3. 用政策或供给数据（牌照、签证、销量）解释需求，判断下滑或回升的原因及强度。
4. 把行业数据放到历史坐标上：行业数据已创数年新低，说明公司收入下滑已被充分预期。

**关键指标与数据来源**：社零、新能源乘用车销量、Questmobile、Nielsen、签证/牌照数据、乘用车零售。

**判断标准**：行业增速高而公司增速明显低（如行业+14%、公司+5.4%），就是明显跑输；行业数据本身极弱而公司尚可，则属于相对韧性；行业数据处于数年低点时，公司的下滑可能已被充分预期。

**海豚案例**：
- 京东：Q2社零为22年后最低，收入下滑已被充分预期。
- 三花（2026-08-26）：新能源乘用车Q2 +14%，而汽零只有+5.4%，明显跑输。
- 地平线：乘用车零售-20.2%。
- BOSS直聘：Questmobile显示活跃用户占比过半。
- 迪士尼：Nielsen收视份额、第三方下载量。
- 新东方：素培牌照每月-0.2%，签证发放下滑放缓。
- Monster：尼尔森口径Ultra +19%。
- 唯品会：GMV对比线上社零。

**适用场景与注意事项**：消费、汽车零部件、平台。行业统计口径与公司收入确认存在差别，对比时要尽量选同口径和同周期。公司、行业、竞对三方增速对比判断份额，见14.5.2。

### 14.3.2 统计局社零分品类与线上实物零售：验证收入并判断行业拐点

**方法要点**：用国家统计局的社零总额、线上实物零售以及分品类（家用电器、通讯器材、家具）零售额，验证并解释公司表现，判断公司跑赢还是跑输行业，并据月度数据的跌幅收窄判断行业拐点。

**操作步骤 / 拆分口径**：
1. 品类解释：限上家电类零售额同比与通讯器材同比，解释公司对应品类（如通电产品）的增速。
2. 跑赢/跑输：线上实物零售增速与公司自营增速对比，判断是否跑赢行业。
3. 行业拐点：用最新月度社零（整体及线上实物）、家电、家具、通讯类跌幅收窄，判断行业拐点。
4. 政策走向：结合海外投行调研（如国补投向从线下转回线上），推演下半年。

**关键指标与数据来源**：社零总额同比、线上实物零售同比、家用电器/通讯器材/家具类零售额同比。

**判断标准**：公司自营增速低于同期线上实物零售增速为跑输；品类拖累减轻（通讯产品高增长抵消家电下滑）说明公司表现部分由结构性因素解释；月度社零由负转正、线上实物提速、分品类跌幅收窄，为行业拐点信号。

**海豚案例**：
- 京东（2026-03-05）：自营零售2261亿、同比−2.5%，“跑输10~11月间线上实物零售约+3%的增长”；限上家电10-11月同比−14%~−19%，通讯产品+20%以上，减轻了家电拖累。
- 京东（2026-08-13）：6月社零从−0.6%修复到+1%，线上实物从2.6%升到3.9%，家电、家具、通讯类跌幅收窄；某海外行调研显示下半年国补投向会边际转回线上。

**适用场景与注意事项**：适用于国内消费类公司（电商、家电、餐饮、品牌消费）。统计局数据按月披露，口径为社会零售而非公司口径。

### 14.3.3 海关出口、零售统计与行业销量：验证下游需求并预判公司拐点

**方法要点**：把公司业务增速放到下游行业数据中验证；用行业数据转正的时间点预判公司业务拐点；公司表现好于行业时，给出“已算不错”的评价。

**操作步骤 / 拆分口径**：
1. 家电板块：海关家电出口增速（关税影响）、统计局家电零售额（国补高基数）。
2. 汽零板块：新能源车行业销量增速、新能源乘用车出口量、欧洲补贴政策。
3. 用行业数据的转正时间点预判公司业务拐点（如家电出口26年已转正，国补高基数持续到26Q2）。
4. 公司表现好于行业时，给出“已算不错”的评价。

**关键指标与数据来源**：海关家电出口增速、统计局家电零售额增速、新能源车行业增速、新能源乘用车出口量、欧洲补贴政策。

**判断标准**：行业数据转正是公司业务拐点的前置信号；公司增速高于行业，在行业下行阶段即可评价为“已算不错”；注意行业数据与公司收入确认之间的时滞。

**海豚案例**：
- 三花《“天灾人祸”…》（2026-03-31）：25H2家电出口同比下滑近8%，26年以来转正；统计局家电零售额Q4前两个月下滑约20%，12月下滑约15%；美国25年6月对“钢铁衍生产品”加征特殊关税。
- 三花《汽零回正…》（2026-05-06）：中国新能源乘用车Q1出口64万辆（+14.8%），欧洲重启电动车补贴（单车3000-6000欧元）。

**适用场景与注意事项**：适用于上游零部件公司。行业数据与公司收入确认存在时滞。进一步将分业务增速、行业增速、核心客户销量三层拉开的“剪刀差”定位，见14.5.4。

### 14.3.4 用官方行业月度统计区分行业β与公司α

**方法要点**：把公司分地区零售增速与官方行业月度数据对比：行业同期也在提速，说明加速有行业性；再用公司自身运营指标论证公司自己的贡献。

**操作步骤 / 拆分口径**：
1. 取公司分地区零售增速及上季变化（提速或降速的pct）。
2. 取官方行业月度同比（如美国统计局无门店零售），观察是否同步提速。
3. 行业也提速，则部分增速是行业β；再用公司自身运营指标（订单量增速、物流效率、近场生鲜日杂投入）论证公司自身贡献。

**关键指标与数据来源**：美国统计局无门店零售月度同比；订单量增速。

**判断标准**：公司提速幅度大于行业提速幅度、并有运营指标支持，才可归因于公司α；行业提速而公司只是跟随，则以β为主。

**海豚案例**：亚马逊（2026-04-30）：北美零售+12%，较上季提速超2pct；美国统计局无门店零售10-12月同比5-7%，1-2月7.7-8.6%，说明行业整体提速；另外订单量+15%是疫情后新高，物流效率和近场生鲜日杂的投入也有贡献。

**适用场景与注意事项**：美国零售/电商公司；其他市场可用国家统计局的网上零售额。电商零售的分业务线拆分与行业无店铺零售对比，见15.6；公司业务增速与行业基准（百强房企销售额）对标，见16.11。

### 14.3.5 宏观冲击传导点识别

**方法要点**：识别同一宏观冲击在不同公司传导到财报的哪个位置（收入减项、客单价、成本、需求或费率），并判断影响是短期还是长期、市场是否误判。

**操作步骤 / 拆分口径**：
1. 列出冲击变量：油补、燃油成本、关税、通胀、客流。
2. 逐公司定位传导点：收入减项、客单价、成本、需求、费率。
3. 判断时间属性：影响是否短期；市场担忧与实际是否一致。
4. 量化：用bps、pct等度量对利润增速、毛利率的影响。

**关键指标与数据来源**：油补、燃油成本、关税、客流。

**判断标准**：同一冲击，传导位置不同则处理不同：记为收入减项的要还原口径；推高客单价则不一定是坏事；拖累利润增速的要量化bps；市场担心的方向与财报不符（如零售利润率不降反升）即为市场误判。

**海豚案例**：
- Uber：油补记为收入减项。
- Costco：通胀推高客单价。
- 沃尔玛：燃油拖累利润增速250bps。
- 迪士尼：园区客流-1%。
- 亚马逊：零售利润率不降反升，与市场担心相反。
- Lululemon：关税压低毛利率。

**适用场景与注意事项**：适用于宏观冲击期。关税对成本的季度影响量化，以及政策抵免对冲，详见7.3；政策参数向需求和成本的映射，见14.6。

**本节交叉引用**：公司业务增速对比行业基准（百强房企销售额）判断超额表现，详见16.11；平台佣金收入（CMR）、GMV与行业大盘三层比较并与同行交叉验证，详见15.6；龙头公司财报作宏观消费晴雨表，详见14.2；电商零售分业务线拆分与行业无店铺零售数据对比，详见15.6；“低预期下的超预期”并用第三方出货数据交叉验证，详见2.1；行业供给增速、行业ADR跌幅、促销力度等衬托公司表现，详见16.6。

**本节速查清单**
- [ ] 选择与公司同口径、同周期的行业统计（社零分品类、线上实物、海关出口、行业销量、无店铺零售）
- [ ] 比较公司与行业的增速与落后（领先）幅度，判断跑赢、跑输与幅度变化
- [ ] 用行业数据转正或跌幅收窄时点预判公司拐点，并提示行业数据与收入确认的时滞
- [ ] 把增长拆成行业β与公司α：行业同步提速的部分归β，其余用运营指标论证
- [ ] 识别宏观冲击在各公司传导的位置（收入减项、客单价、成本、费率）并量化bps
- [ ] 判断市场对宏观冲击的担忧是否与财报相符（误判或已充分预期）
- [ ] 注意同口径：统计局口径与公司口径存在差异，区间对比只作方向性参考

## 14.4 产业调研、专家与渠道草根

> 本节导读：公司披露不足时，海豚君会用产业调研、专家访谈、渠道草根和市场流传数据来补全信息，但始终守住两条纪律：取保守端并标注“仅供参考”，以及把“事实”和“推测”分开。本节讲调研数据如何取值、如何与财报交叉验证、如何用“海豚君推测”标注未披露驱动，以及如何用客户案例与行业大会验证产品落地深度。行业专属的调研指标（经销商可退订单、门店排队、RevPAR中段调研等）归行业节；第三方高频数据见14.1。

### 14.4.1 专家调研与市场流传数据的使用与保守取值

**方法要点**：大量使用调研和专家数据（GMV目标、利润率目标、佣金率变化、新业务模式），但用“保守取值＋标注＋事后验证”三条纪律控制样本偏差。

**操作步骤 / 拆分口径**：
1. 取区间中偏保守的一端，或用可比公司的实际值打折（调研说利润率3~5%，实际取2%）。
2. 明确标注“仅供参考”或“只是传言”，使读者知道证据强度。
3. 在后续财报里验证或修正。
4. 反向使用：调研数据也用于提示风险（如新业务计划会影响盈利目标）。

**关键指标与数据来源**：调研给出的GMV目标、利润率目标、佣金率变化、新业务计划。

**判断标准**：调研给出区间时取偏低端；调研与可比公司实际值差距较大时按可比值折扣；传闻性质的信息不进入基础预测，只作为风险提示。

**海豚案例**：
- 拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）：调研显示2026年主站GMV目标10~15%，保守取10%；Temu 2026年计划增长30~40%，取35%；长期利润率目标3~5%，保守取2%；有消息称多多买菜有望在2026年下半年盈利，但也有传言要上线即时零售模式，会影响盈利目标。
- 携程《监管铁拳落定，携程能“轻装上阵”了吗？》（2026-09-16）：调研显示调整后综合佣金率可能下降约2pct（仅供参考）。
- 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：根据近期调研，Temu明显减少了投放。

**适用场景与注意事项**：适用于信息披露不足的公司。调研样本偏差需要靠财报持续校验。

### 14.4.2 产业调研数据与财报交叉验证

**方法要点**：用调研获取公司不披露的数据，并校验财报推论。

**操作步骤 / 拆分口径**：调研可获取的数据类型包括：
1. 业务规模与增速目标：抖音到店GTV增速（Q3 50%→Q4 60%，26年目标30%，侧重规模和商家变现）。
2. 单位经济：美团单均履约成本同比-15%以上；8月外卖重新加补、UE（单位经济）环比下滑。
3. 产品与广告结构：腾讯广告位结构。
4. 行业景气：7月游戏流水反弹；上海新政后成交量爆发但价格稳中略降。
5. 新业务预期：昆仑芯收入机构预期60-70亿。
6. 订单与客户：在手订单客户名单。
7. 写作时统一标注“据悉/根据调研”，以区分事实与调研信息。

**关键指标与数据来源**：调研GTV、履约成本、流水、成交量、订单。

**判断标准**：调研结论与财报披露方向一致，则强化判断；调研显示的拐点（如补贴重启使UE下滑）在后续财报被验证，才进入正式的盈利预测。

**海豚案例**：上述用法分布于以下文章：美团《三山压顶》（2026-03-26）、美团《阿里、抖音熄火？》（2026-08-28）、腾讯（2026-03-18、2026-08-12）、贝壳（2026-03-16）、百度《其他没指望》（2026-05-18）。

**适用场景与注意事项**：通用；注意样本偏差，文中标注“据悉/根据调研”。

### 14.4.3 用渠道和产业调研解释财报未披露的驱动因素

**方法要点**：财报披露不足时，用调研信息解释超预期或不及预期的原因，并标注“结合调研信息，海豚君推测”。

**操作步骤 / 拆分口径**：
1. 对超预期或不及预期的数据，先列出财报没有说明的驱动。
2. 用调研补足：电商直播转化率、门店物料定价、北美线下黑五表现、加盟签约、广告细分渠道等。
3. 在行文中标注“结合调研信息，海豚君推测”，并在后续财报验证。

**关键指标与数据来源**：转化率；签约数；渠道销售；细分渠道广告表现。

**判断标准**：调研结论要与财报表观数据方向一致；渠道调研显示的趋势（如黑五没有爆发、感恩节后明显放缓）用来解释增速下降而非直接推算数值。

**海豚案例**：
- 亚朵（2026-03-17）：亚朵星球在抖音直播间和小红书的种草转化率Q4创新高，控温被的GMV占比提升；加盟商在年底加快4.0版本的签约。
- 蜜雪（2026-03-24）：推测下半年同店为低个位数增长，靠杯量驱动。
- 泡泡玛特（2026-03-25）：北美11月后线下明显走弱，黑五没有爆发，增速降到500%以下。
- Lululemon（2026-03-18）：感恩节购物季强劲，之后明显放缓。
- 腾讯（2026-03-18）：视频号、小游戏、搜索广告都还可以，公众号下滑较多，QQ、搜狗、腾讯新闻继续拖累。
- 阿里（2026-01-08）：调研显示云的外部收入增速将明显加速。

**适用场景与注意事项**：消费和互联网公司。调研样本可能偏向某一渠道，需要用后续披露校准。

### 14.4.4 未披露驱动的“海豚君推测”：事实与推断分开标注

**方法要点**：公司未披露驱动因素时，结合电话会信息、行业数据与调研给出可能原因，明确标注“海豚君推测”，把事实与推断分开，便于后续季度验证。

**操作步骤 / 拆分口径**：
1. 识别未披露项：费用投放方向、直营细分、品类增速、渠道库存。
2. 汇集证据：电话会表述、行业数据、调研。
3. 给出最可能的归因，并标注“海豚君推测”。
4. 在后续季度验证并修正。

**关键指标与数据来源**：电话会表述、调研、行业数据。

**判断标准**：推测要有至少两类证据支持（电话会+行业逻辑/调研）；与事实性陈述严格分行区分。

**海豚案例**：
- 华住（2026-05-15）：推测销售费用率+0.3pct至4.8%源于商旅弱、内卷而加大社交媒体与短视频投放，直营降幅收窄源于禧玥、花间堂等高端直营。
- 可口可乐（2026-02-11）：推测浓缩液快于单位箱为备货、即饮咖啡持平受现饮咖啡冲击。
- Monster（2026-02-27）：推测战略品牌放缓因资源聚焦主品牌、NOS等高糖品被零糖挤压。

**适用场景与注意事项**：信息披露有限的公司。推测不是结论，应在下季度跟踪验证。

### 14.4.5 用客户案例清单、产业调研和行业大会验证产品落地深度与预期差修正时点

**方法要点**：列举当季代表性客户案例以证明落地深度与行业广度，引用产业调研结论，并指出预期差往往在大会发布加上真实订单披露后才开始修正，以此解释股价时点。

**操作步骤 / 拆分口径**：
1. 客户案例清单：覆盖营销、ERP迁移、法律、能源、政府等行业，并给出可量化收益（成本节约）。
2. 引用产业调研结论，支持落地深度判断。
3. 把行业大会（如AIPCon）发布与订单增量（TCV）出现的时点对照，判断预期差修正的起点。
4. 用此解释股价为何在某个时点才开始反应。

**关键指标与数据来源**：客户案例、可量化收益（成本节约）、大会发布与订单增量时间。

**判断标准**：案例覆盖行业越广、量化收益越明确，落地越深；订单增量与大会时点吻合，说明大会是需求催化。

**海豚案例**：Palantir《瑕疵修复》（2026-08-04）：Zeta Global、SAP（CEO站台）、Kirkland & Ellis、Centrus Energy（识别近3亿美元成本节约）、USDA（上线62分钟打破注册纪录）；美国商业TCV 21.3亿（+153%，创历史新高），增量与6月AIPCon 10有关。

**适用场景与注意事项**：适用于企业软件公司。客户案例是公司挑选的样本，只能证明可行性，不能推算渗透率。

**本节交叉引用**：用调研得到的补贴预算推算全年和季度亏损节奏，详见8.6；经销商调研的可退订单量与稳态月销预测，详见16.1；调研获取重点区域经营利润率改善以验证海外投入产出，详见16.8；铺货率、试销复购率、场景渗透率、子系列占比、新兴市场份额增速验证产品力，详见16.7；门店景气调研（排队时长、跨店调货、月均销量相对峰值），详见16.8；广告收入看不变汇率增速并用广告预算调研对比行业大盘，详见15.5；渠道调研追踪广告平台份额、ROAS、eCPM和预算分配，详见15.5。

**本节速查清单**
- [ ] 调研数据取保守一端，或用可比公司实际值打折，并标注“仅供参考/传言”
- [ ] 把事实与推断分开，推测一律写明“海豚君推测”并在后续季度验证
- [ ] 用调研补全公司未披露的GTV、履约成本、转化率、签约数、渠道表现
- [ ] 调研样本是否有偏差，是否有至少两类证据（电话会+行业逻辑）
- [ ] 调研结论是否被后续财报验证或修正，并记录
- [ ] 软件类公司要列出客户案例及可量化收益，并对照大会与订单时点

## 14.5 竞争格局、份额与同业对标

> 本节导读：判断一家公司是“行业红利”还是“自身竞争力”，要把公司放进行业、竞对、客户三条参照线里：公司增速对照行业增速和竞品增速（份额），分部增速对照大客户资本开支（供应链份额），分业务增速、行业增速、核心客户销量三层剪刀差（定位问题出在哪）；还要用同业对比定位绝对增速、环比降速、利润体量、费用率和估值溢价。本节解决“好或坏是相对的”这一问题。行业专属的市占率口径（如剔除自供对手的电池份额、整车多口径市占率）归行业节，第三方份额数据见14.1，宏观与行业统计见14.3。

### 14.5.1 公司增速 vs 行业统计增速：份额、渠道转移与竞争力判断

**方法要点**：把公司收入或分项增速与可得的行业统计（离岛免税总额、美国运动服饰品类、包装水行业销售额、百强房企销售额、行业游戏流水、支付行业增速）对照，判断公司是跑赢还是跑输、是行业问题还是公司问题，并对不同解释提出可验证的假设。

**操作步骤 / 拆分口径**：
1. 并列公司增速和行业增速，计算相对差值及其变化（落后幅度从约4pt扩大到10pt以上说明份额流失在加速）。
2. 按相对位置归类：
   - 公司跑输行业：提出两种假设并说明对价值判断的不同含义（如“有税渠道继续萎缩”与“行业复苏以其他渠道走弱为代价，即渠道转移”）。
   - 公司跑赢行业但仍受拖累：说明是行业需求问题。
   - 行业景气而公司分项走平或下滑：推断竞争加剧或产品力不足。
   - 公司增速不再好于行业：下结论“已不再跑赢行业”。
   - 公司优于行业：确认alpha。
3. 对行业内部结构做对比（如Q2手游低基数修复、端游走弱），防止把结构性因素当成公司能力。

**关键指标与数据来源**：公司收入增速、行业销售增速（离岛免税总额、百强房企销售额、行业游戏流水、支付行业增速、品类销售额）、相对差值及其变化。

**判断标准**：
- 行业景气而公司AI应用、AI原生营销环比下滑，是“和行业景气度不匹配”，推断竞争加剧或产品力不足；
- 公司增速低于行业且差距扩大，份额流失在加速；
- 公司优于行业整体，确认alpha；
- 两种假设对价值判断含义不同时，要明确列出并等待后续数据验证。

**海豚案例**：
- 中国中免《封关后首次春节“大考”…》（2026-04-29）：中免营收+近1%，离岛行业+26%；假设一是机场等其他渠道不佳或有税继续萎缩，假设二是离岛复苏以其他渠道走弱为代价（渠道转移），两者对价值判断差异很大。
- Lululemon（2026-09-04）：美国运动服饰品类Q2大致持平，Lululemon下滑低双位数，落后幅度从去年约4pt扩大到10pt以上。
- 农夫山泉（2026-08-26）：包装水行业销售额-7%~-9%，农夫+2.1%，跑赢大盘但仍受拖累。
- 百度《其他没指望》（2026-05-18）：AI应用环比下滑“和行业景气度不匹配”。
- 贝壳《下跌“深不见底”》（2026-03-16）：新房GTV-42%，跌幅高于彭博一致预期-39%，而百强房企10-12月销售额-30%~-40%，结论是“已不再跑赢行业”。
- 腾讯《不再躺尸功劳簿》（2026-05-13）：本土游戏流水十几%，优于行业整体，确认alpha。
- 腾讯（2026-08-12）：支付行业估算增长不到3%，作为公司支付业务的行业基准。

**适用场景与注意事项**：所有有行业数据可对照的公司都适用，是份额判断的基础工具。行业数据口径（渠道范围、品类定义）要尽量与公司一致；无法确认原因时，把两种假设同时列出，而不是强行给出唯一结论。

### 14.5.2 公司、行业、竞争对手三方增速对比（出货口径）推断份额

**方法要点**：用第三方行业出货（IDC类数据）作基准，对比公司分部收入或出货增速与主要竞争对手同类业务增速，差值即份额得失的粗略信号。

**操作步骤 / 拆分口径**：
1. 取第三方行业出货量与同比（全球PC出货、全球手机出货、中国手机市场）。
2. 并列公司分部收入（或出货）同比与竞争对手同口径同比。
3. 判断：公司 > 行业 > 对手，说明公司在抢份额；公司 < 行业，说明份额在丢失。
4. 再引用第三方份额数据佐证（桌面级份额、服务器CPU出货份额、中国市场份额）。
5. 当行业出货下滑而公司收入增长，则增长来自价格或结构，而非份额。
6. 对终端有结构性分层的行业，进一步拆分（如手机拆分苹果与非苹果），找出拖累来源。
7. 竞品在同一市场中的增速也要并列（行业、竞品、公司三方），区分“行业下行”与“份额被抢”。

**关键指标与数据来源**：行业出货量同比（IDC类数据）、公司收入/出货同比、竞争对手同业务同比、市场份额。

**判断标准**：
- 公司增速 > 行业 > 对手：抢份额；
- 公司增速 < 行业：丢份额；行业走弱而公司增长：增长完全来自价格；
- 同一市场竞品大增、公司大幅下滑、行业温和：说明份额被抢走，而不是只有行业下行。

**海豚案例**：
- AMD（2026-02-04）：四季度全球PC出货7640万台，+11%；AMD客户端+34%，英特尔客户端-6.6%，此消彼长；AMD在桌面级的份额已反超英特尔；第三方数据显示AMD服务器CPU出货份额升到两成以上。
- 戴尔（2026-02-27）：戴尔PC出货1170万台，+17%，高于行业的+11%，份额回升到15%。
- 戴尔（2026-05-29）：1030万台，+7%，高于行业6560万台的+4%，份额15.7%。
- 英特尔（2026-01-23）：客户端收入同比-6.6%，同期全球PC出货同比+11%（7640万台），继续丢份额。
- 英特尔（2026-04-24）：下季客户端+1.3% vs PC出货+3.8%（6560万台），份额仍在丢失。
- 英特尔（2026-07-24）：再下季PC出货重回下滑（6820万台），客户端却+12.8%，结论变成增长完全来自价格。
- 高通《高通：“存储荒”加码…》（2026-02-05）：全球手机出货3.63亿台，同比+1.4%，苹果+5.7%，除苹果外2.55亿台同比持平，推断安卓阵营低迷拖累高通手机业务。
- 小米《天堂急跌地狱…》（2026-03-24）：4Q25苹果中国出货+20%，市场-0.8%，小米中国-18%。
- 小米《跌到怀疑人生？…》（2026-05-26）：1Q26苹果中国+34%，市场-3.6%，小米-34%。
- 小米《又双叒原地久跪…》（2026-08-18）：2Q26苹果中国+24%，市场-4.3%，小米-21%。
- 苹果《AI缺位、存储涨价…》（2026-05-01）：iPhone中国份额19%（+5.3pct）。
- 小米的分析逻辑：苹果“加量不加价”、iPhone 17 256G享受国补，在中国出货大增，而小米大幅下滑，说明份额被抢走，而不是只有行业下行。

**适用场景与注意事项**：适合终端市场有第三方出货统计的芯片、硬件、消费电子、汽车等行业。收入增速包含价格与结构变化，份额推断只是方向性的，最好用出货口径，并结合ASP变化。

### 14.5.3 公司分部增速 vs 大客户Capex增速：推断供应链份额变化

**方法要点**：把公司与某大客户相关业务的增速（或指引增速）和该客户的Capex增速对比：明显低于客户Capex增速，说明公司在客户采购中的份额在下降。

**操作步骤 / 拆分口径**：
1. 取公司数据中心、ASIC等相关业务的增速或指引增速。
2. 取大客户Capex增速（如云厂商资本开支指引）。
3. 对比：公司增速 < 客户Capex增速，说明份额下降。
4. 用供应链信息（新一代产品由谁供货）验证。
5. 排除产品周期错位：新一代产品未量产时，增速本来就偏低。

**关键指标与数据来源**：公司数据中心/ASIC增速指引、大客户Capex增速、供应链份额信息。

**判断标准**：数据中心业务增速、ASIC增速均低于客户Capex增速，说明产品没有让客户满意，份额在流失。

**海豚案例**：
- Marvell（2026-03-06）：亚马逊2026年Capex +50%，而Marvell上调后的数据中心增速是40%以上、定制ASIC只有20%以上，都低于客户Capex增速，说明ASIC产品没有让亚马逊满意；Trainium3基本交给台厂Alchip，Marvell只做Trainium2.5。
- Marvell（2026-05-28）：ASIC全年增速20%，“远低于CSP资本开支增速”，反映在大客户处丢了份额。

**适用场景与注意事项**：适合大客户集中的供应商。注意产品周期错位：新一代产品未量产时，增速本来就偏低。

### 14.5.4 分业务增速、行业增速、核心客户销量增速三层剪刀差定位问题

**方法要点**：某业务收入增速放缓或超预期时，并排拉三条线（行业、核心客户、公司），用“行业β→客户β→公司α”的推理链，通过三者剪刀差定位alpha或问题所在。

**操作步骤 / 拆分口径**：
1. 下游行业整体增速，含内销和出口。
2. 核心客户销量合计增速（如前两大客户）。
3. 公司该业务收入增速。
4. 判断规则：
   - 行业和客户都回暖、公司增速明显落后：问题在公司自身，可能是份额、年降或产品结构，这就是“核心低于预期的原因”；
   - 行业下滑而公司逆势增长：继续拆跑赢行业的来源，如结构升级、海外、新业务、材料替代。

**关键指标与数据来源**：分业务收入同比；新能源乘用车销量和出口同比（行业协会口径）；核心客户季度销量；国内家电零售额同比、家电出口额（海关）。

**判断标准**：三者剪刀差就是alpha或问题所在；公司增速明显低于行业和客户，据此判定核心miss；公司“远超行业”则继续拆驱动。

**海豚案例**：三花智控《三花智控：主业平淡，静待机器人起飞？》（2026-08-27）：汽零Q2收入+5.4%，Q1为+15%，市场预期+15%。同期新能源乘用车同比由Q1的-5%回升到+14%，出口+126%至133万辆，比亚迪加特斯拉合计销量由Q1的-21%改善到+5%。公司增速明显低于行业和客户，据此定为核心miss。制冷+6.5%，同期国内家电零售额-14%至3000亿、中国家电出口+7.5%至275亿美元，属于“远超行业”，于是继续拆四个驱动。

**适用场景与注意事项**：适合下游集中、客户销量查得到的To B零部件和供应链公司。局限：单车配套价值量变化、年降、客户结构迁移都会让公司增速天然偏离客户销量，需要配合单车价值量一起看。

### 14.5.5 用竞争对手同类业务的季度收入做绝对规模比较

**方法要点**：对有竞争意义的非核心业务，用竞争对手同类业务的季度收入做绝对规模对比，快速判断市场地位和领先幅度；业务被合并披露后，先估算占比再比较。

**操作步骤 / 拆分口径**：
1. 取公司同类业务季度收入与竞争对手同类业务收入。
2. 业务被合并披露时先估算占比（如游戏约占边缘计算6-7成）。
3. 对比绝对规模和同比，判断领先幅度。
4. 核对口径差异（如对手游戏业务包含主机芯片）。

**关键指标与数据来源**：公司同类业务收入、竞争对手同类业务收入。

**判断标准**：绝对规模显著大于对手且同比更高，即“明显领先”。

**海豚案例**：
- 英伟达（2026-02-26）：游戏收入37亿、同比+46%，AMD游戏业务约8.4亿。
- 英伟达（2026-05-21）：边缘计算64亿，游戏约占6-7成，AMD游戏7.2亿，“英伟达在游戏显卡市场仍具有明显的领先优势”。

**适用场景与注意事项**：适用于寡头市场。注意口径差异（如对手游戏业务包含主机芯片）。

### 14.5.6 同业二维对比：绝对增速加环比降速幅度，以及“不进即退”

**方法要点**：判断“不及预期”有多严重，必须放到行业里同时看两个维度：绝对增速水平与环比变化幅度；竞争性行业的核心业务还要看相对同行的增速，即使绝对表现达标，相对同行跑输也等效于不好。

**操作步骤 / 拆分口径**：
1. 并列同行的绝对增速与环比变化（降速或加速多少pct）。
2. 行业普遍走弱时，降速幅度更小的公司属于“相对跑赢”，问题不大。
3. 同行普遍改善而公司逆势走弱，是“从优等生变差生”的信号。
4. 竞争性行业核心业务（云、广告、芯片）：即使公司绝对表现略好于预期，只要相对同行跑输，在“逆水行舟”背景下等效于不好。
5. 同行科目口径尽量对齐（如CMR与广告）。

**关键指标与数据来源**：拼多多广告收入、京东商城、阿里CMR的同比增速及环比变化（pct）；Azure/AWS/GCP同期增速变化。

**判断标准**：行业普遍降速而公司降幅更小，为相对跑赢；行业改善而公司走弱，为相对最差；寡头竞争行业里相对跑输即“表现平平实际大体等效于不好”。

**海豚案例**：
- 拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）：4Q25广告+5%，低于彭博8%；京东商城和阿里CMR在0%上下，环比降速约10pct，拼多多只降3pct，判断为国补退坡下的边际受益方，问题不大。
- 拼多多《拼多多：又老又“傲慢”，彻底人人嫌》（2026-05-27）：1Q26行业和同行普遍比4Q改善，拼多多广告却从5%降到2.5%，营收+11%低于预期13.5%，成为板块“最差生”。
- 微软（2026-05-01）：Azure提速1pct，但AWS和GCP显著拉升，判定Azure相对跑输，“表现平平实际大体等效于不好”。

**适用场景与注意事项**：适用于同质化竞争行业的季度对比和寡头竞争行业（云、广告、芯片）。同行科目口径（CMR与广告）要尽量对齐。

### 14.5.7 同业利润体量与核心业务稳定性横向比较

**方法要点**：把公司放到板块里，和同行比较利润的绝对体量、利润是否正增长、核心主业是否稳定，在行业逆风时判断个股的相对质量。

**操作步骤 / 拆分口径**：
1. 取同行单季经营利润绝对值、利润同比。
2. 看核心业务利润占比、同行同期投入强度（外卖、AI等）。
3. 同行因大额投入把利润打光时，能维持单季稳定利润的公司就是“相对佼佼者”。
4. 对同样因投入而整体亏损的公司，区分核心主业是否稳定：核心稳定则不存在“归零”风险，核心不稳则不同。

**关键指标与数据来源**：单季经营利润绝对值、利润同比、核心业务利润占比、同行同期投入强度。

**判断标准**：核心主业稳定（如业绩和竞争格局稳定），即使新业务做得差也只是退回国内业务估值；核心不稳的同行风险更大。

**海豚案例**：
- 唯品会《唯品会：再现负增长？别怕，有10%股东回报救场》（2026-02-26）：美团、阿里因外卖和AI投入利润几乎打光，唯品会业务体量小得多，单季仍有20~30亿利润并保持正增长，在泛电商板块算佼佼者。
- 滴滴《国内熟透、海外猛投，滴滴未来看“国际滴”？》（2026-06-02）：和美团、阿里一样因外卖投入导致整体利润暴跌，但核心差异是滴滴国内主业的业绩和竞争格局稳定，海外做得再差也只是退回国内业务估值。

**适用场景与注意事项**：适用于判断行业逆风时个股的相对质量。同行业务结构不同，比较时要聚焦可比的利润口径。

### 14.5.8 费用率同行对标：定位改善程度与后续压降空间

**方法要点**：把公司的销管费用率等指标放到同业中比较，判断改善是否已到行业正常水平，进而判断后续压降的空间。

**操作步骤 / 拆分口径**：
1. 取销管费用率（销管费用/总收入）。
2. 与同业同口径费用率对比（理想、小鹏等）。
3. 判断是否“已到同业水平”，若已接近，则后续压降空间有限；对照公司给出的指引。

**关键指标与数据来源**：销管费用率（销管费用/总收入）、同业费用率。

**判断标准**：费用率降到同业水平，说明被诟病的问题已明显改善，后续空间看是否继续有规模杠杆。

**海豚案例**：蔚来4Q25（2026-03-10）：销量杠杆释放后，销管费用率降到约10%，“基本和理想和小鹏同一水平”，长期被诟病的销管费用明显改善；公司指引2026年销管费用率约10%（2026-05-21、2026-09-01）。

**适用场景与注意事项**：适用于同质化行业的横向比较。商业模式不同（直营与经销）会使费用率不可直接比较，需要说明口径。

### 14.5.9 同业横向对比：定位业绩成色与估值溢价

**方法要点**：与同行在同一指标上（签单量、账户净增、毛利率、增速、估值）对比，判断竞争力和估值溢价是否合理。

**操作步骤 / 拆分口径**：
1. 选定同口径指标：新签、账户、毛利率、增速、PE、FCF。
2. 多家同业密集发布财报时并列比较。
3. 若估值溢价建立在份额预期上，而增速不及龙头，就难以接受；若估值包含对新业务的期待，要单独评估。

**关键指标与数据来源**：同口径指标（新签、账户、毛利率、增速、PE）。

**判断标准**：估值高于同业而增速、毛利率、份额不占优，则溢价难以合理化；同业对比中FCF仍为正，是相对优势。

**海豚案例**：
- 亚马逊 vs 微软：单季新签约1500亿 vs 700-800亿。
- IBKR vs 嘉信：账户净增折损10% vs 35%。
- Marvell估值高于英伟达，增速却更低。
- 壁仞毛利率低于摩尔线程、沐曦的约60%。
- 英特尔估值明显偏高，包含了对代工的期待。
- 微软与谷歌、Meta比，FCF仍能为正。

**适用场景与注意事项**：多家同业密集发布财报时。同行口径要对齐，估值比较需考虑增速与业务结构差异。

### 14.5.10 同业同店差距对照：推断消费分层（Costco vs Walmart）

**方法要点**：把两家定位不同的零售商的同店增速（剔油气汇率）放在同一时间轴，看差距的变化，再结合管理层的客群表述，推断各收入层的消费强弱，从而判断消费分层是否加剧。

**操作步骤 / 拆分口径**：
1. 取两家公司同店增速（剔除油气和汇率），放在同一时间轴。
2. 看差距的变化（如从2–3pt扩大到近5pt）。
3. 结合管理层对客群的表述（如“份额增长由高收入家庭引领”）。
4. 推断：中上收入正常消费，越往下越谨慎，说明消费分层在加剧。
5. 补充对照客流、客单、可选品类等指标。

**关键指标与数据来源**：两家公司同店增速及差值变化、管理层客群表述。

**判断标准**：定位高端的一方同店保持稳定，定位大众的一方降速，差距扩大，且大众零售商称增长由高收入家庭引领，则其中低收入基本盘走弱，消费分层加剧。

**海豚案例**：Costco《消费分层加剧…》（2026-09-25）：Costco剔油气汇率同店在6%–7%区间稳了一年，Walmart美国同店从去年同期4.6%降到2.6%，差距从2–3pt扩大到近5pt；Walmart称份额增长由高收入家庭引领，意味着其中低收入基本盘走弱；Costco客流、客单、可选品类同步增长，非食品最强。

**适用场景与注意事项**：适用于同一行业不同客群定位公司的横向对比（零售、餐饮、酒店），属于行业研究方法。龙头公司财报作为宏观消费晴雨表见14.2.7。

**本节交叉引用**：车企总销量/新能源销量增速对比大盘，判断逆势alpha或掉队，详见16.1；多口径市占率追踪（整体/国内新能源/插混/纯电，加竞品份额和历史峰值对比），详见16.1；市占率追踪（剔除垂直一体化对手的口径），并识别份额流失的原因是产能还是竞争力，详见16.3；用第三方月度MAU份额追踪赛道格局，详见14.1；公司日均交易笔数对比市场，识别是否跑出相对市场的超额（Alpha），详见16.9；第三方/行业数据交叉验证公司表现，详见14.3。

**本节速查清单**
- [ ] 为每项核心业务找到同口径的行业数据，计算公司与行业的相对差值及其变化
- [ ] 并列公司、行业、竞对三条增速线，用出货口径推断份额，并区分价格和份额
- [ ] 公司跑输行业时，列出两种以上假设（渠道转移、有税萎缩、竞争力）并说明价值含义
- [ ] 分业务增速、行业增速、核心客户销量三层拉剪刀差，判断问题在行业、客户还是公司
- [ ] 供应链份额：公司分部增速对照大客户Capex增速，排除产品周期错位
- [ ] 同业二维对比：绝对增速加环比降速幅度；寡头行业中相对同行跑输即等效于不好
- [ ] 利润体量、核心主业稳定性、费用率、估值溢价要用同口径对标，并说明商业模式差异
- [ ] 消费分层、客群变化用定位不同的同业同店差距加管理层客群表述验证

## 14.6 政策、监管与突发事件冲击测算

> 本节导读：政策、监管和突发事件对财报的影响，海豚君的做法是“拆成参数、映射到科目、给出区间”：罚款相当于多少利润，补贴退坡对应多少销量，税率变化对应多少收入和利润，从量税需要提价多少才能对冲，停产几周拖累多少利润；并判断冲击是一次性还是持续性、是行业面还是公司面。本节与11.1的股价归因、9.8的指引归因互相配合；关税对成本的季度影响量化见7.3。

### 14.6.1 监管罚款评估与整改措施的影响映射

**方法要点**：罚款落地后，按“量化→定性→映射”三步评估：罚款占利润比例、罚款构成与比例横比，再判断一次性影响与整改后的商业模式变化，并把整改条款逐条映射到竞争力、费用和佣金率。

**操作步骤 / 拆分口径**：
1. 量化：
   - 罚款金额占年经营利润的比例；
   - 罚款构成：罚款＝没收违法所得＋境内销售额×罚款比例；
   - 罚款比例与历史案例对比（阿里约4%、美团约3%）。
2. 定性：罚款是一次性影响，真正重要的是整改后商业模式和盈利能力怎么变。
3. 映射：把整改公告逐条对应到竞争力（优质房源独占下降）、费用（价格战需要平台自担营销）、佣金率（新佣金档位，调研显示综合佣金率下降约2pct）。
4. 看监管有没有触及更严重的核心问题（如强制全网最低价），没触及则风险大幅减轻。

**关键指标与数据来源**：罚款金额、没收违法所得、境内销售额、罚款比例、年经营利润、整改条款、调研佣金率变化。

**判断标准**：罚款占年经营利润比例有限（如1/3或相对千亿年利润影响有限）、整改未触及核心壁垒，则格局和壁垒没有根本变化；罚款比例是近年平台最高，要评估整改对竞争力、营销费用和佣金率的持续影响。

**海豚案例**：
- 携程《监管铁拳落定，携程能“轻装上阵”了吗？》（2026-09-16）：罚款约52亿，相当于全年经营利润的约1/3，包括没收违法所得16.58亿，以及2025年境内销售额约467亿×7.5%，是近年平台最高罚款比例（阿里约4%，美团约3%）。整改包括取消特牌和金牌、下线调价助手、退还储备金约1.2亿、推出10%~15%三档佣金、不强迫促销；判断优质房源类独占能力下降、营销费用可能上升、综合佣金率可能下降约2pct，但格局和壁垒没有根本变化。
- 拼多多《拼多多：又老又“傲慢”，彻底人人嫌》（2026-05-27）：多平台合计罚款近36亿，拼多多独罚15亿，相对千亿年利润影响有限，而且没有涉及强制全网最低价问题，监管风险大幅减轻。

**适用场景与注意事项**：适用于反垄断、合规处罚事件。整改影响的量化依赖调研，需标注“仅供参考”（见14.4.1）。

### 14.6.2 监管整改与算法调整：短期冲击与长期验证指标

**方法要点**：公司主动整改（年龄分级、聊天限制、推荐算法从短期变现转向长期留存）时，分析短期对用户和收入的冲击，并找出长期验证指标；取消全年指引意味着可见度下降，底部业绩难以测算。

**操作步骤 / 拆分口径**：
1. 识别整改措施及受影响用户比例。
2. 分析短期冲击：DAU、使用时长、Bookings。
3. 找出长期验证指标：如D28留存（推荐目标从7天变现优化改为28天留存优化）。
4. 评估可见度：公司取消全年指引，则底部业绩难测；回购规模是否足以吸引资金。
5. 监管落地、最大不确定性解除，意味着“杀估值阶段”可能已过去。

**关键指标与数据来源**：DAU、使用时长、Bookings、D28留存。

**判断标准**：整改带来的短期Bookings转负是代价，若长期留存指标改善才说明整改有效；取消指引使底部不可测，需要更大的安全边际。

**海豚案例**：
- Roblox（2026-07-31）：约1/3用户受聊天限制；推荐从7天变现优化改为28天留存优化；Q3 Bookings转负，取消全年指引；回购隐含3%，不足以吸引资金。
- 携程：监管落地，最大不确定性解除，杀估值阶段过去。

**适用场景与注意事项**：受监管影响的平台。

### 14.6.3 出口管制与法案立法进程追踪：量化受限范围

**方法要点**：跟踪美国出口管制法案和BIS规则的内容、阶段和暂停状态，量化受限范围，再映射到中国区收入占比、拉货节奏和国内代工厂的先进制程产能。

**操作步骤 / 拆分口径**：
1. 条款：覆盖哪些设备和服务、针对哪些节点。
2. 阶段：提出、审议还是生效；是否暂停；暂停多久。
3. 受限比例：暂停后仍受限的收入比例。
4. 映射：中国区收入占比、客户拉货节奏、国内代工厂先进制程产能。
5. 关注缓和因素（如和解费）。

**关键指标与数据来源**：法案或规则条款、立法阶段、受限收入比例、中国区收入占比。

**判断标准**：法案仍在立法流程中，则冲击是潜在风险而非确定事实；规则暂停后仍有一部分受限（约20%）时，要把剩余受限范围计入基准。

**海豚案例**：
- ASML（2026-07-15）、中芯（2026-05-14）：MATCH法案于2026年4月2日提出，将浸润式DUV及相关维保服务纳入出口管制，针对中国7nm以下先进逻辑和存储的扩产；目前仍在立法流程中，影响中国客户的DUV拉货和中芯的先进制程产能。
- AMAT（2026-02-13）：BIS的50%关联实体规则于2025年9月29日发布，2025年11月10日起暂停一年；暂停后对中国大陆的限制范围仍约20%（先进制程、NAND、DRAM、部分ICAPS）；2.5亿和解费缓和了摩擦。

**适用场景与注意事项**：半导体设备和代工等受地缘政治影响的公司。

### 14.6.4 政策参数量化：补贴、购置税、IRA、关税条款映射到需求和成本

**方法要点**：把相关政策的关键参数逐项写清，映射到行业销量增速、公司季度销量和单车成本，用来解释表观数据，并判断冲击是一次性还是持续性。

**操作步骤 / 拆分口径**：
1. 写清政策参数：补贴退坡时点、比例、上限、总额；购置税恢复；IRA退坡；232条款抵消比例和期限。
2. 映射到行业销量增速、公司销量环比与同比、单车成本。
3. 判断冲击是一次性还是持续性：需求被提前透支则后续承压。

**关键指标与数据来源**：政策参数、行业销量同比、公司销量环比和同比、单车成本。

**判断标准**：补贴参数收紧（品类、比例、上限、总额）与行业销量下滑同步，则表观数据主要由政策解释；以旧换新退坡使中低端需求被提前透支，冲击具有延续性。

**海豚案例**：
- 三花（2026-08-27）：2026国补收紧的参数（品类12减到6、比例20%降到15%、上限2000降到1500、总额3000亿降到2500亿）；新能源乘用车Q1因补贴退坡和购置税恢复为-5%。
- Rivian（2026-02-13）：IRA补贴退坡，4Q25销量环比-26%至0.97万；232条款3.75% MSRP抵消延长到2030年。
- 小鹏（2026-03-20）：2025Q4末以旧换新退坡，中低端需求在Q3被提前透支，冲击了M03。

**适用场景与注意事项**：适合政策敏感行业（汽车、家电、新能源）。

### 14.6.5 政策→产品策略→价格/成本传导链

**方法要点**：把政策变化逐层推到财报：政策条款→公司产品策略→价格或成本，每条政策都落到ASP、成本、销量、份额四个变量之一。

**操作步骤 / 拆分口径**：
1. 购置税技术门槛提高（PHEV纯电续航从43km提到100km）：公司对淘汰车型大幅折扣并兜底购置税（ASP下降），同时对主力车型“加配不加价”（BOM上升）。
2. 新一轮国补向16.7万元以上车型倾斜：对10-15万的主力车型不利（销量和份额）。
3. 反内卷监管：龙头不能再靠大幅降价抢份额（份额下滑、价格战受限）。
4. 海外：欧盟境内组装且售价低于4.7万欧元的补贴门槛、美国IRA补贴退坡、3.75% MSRP关税抵免。
5. 把条款映射到具体车型或SKU。

**关键指标与数据来源**：政策门槛参数（续航、价格带）、ASP、单车BOM、份额、销量。

**判断标准**：政策使ASP与成本两头受压，则利润率承压；公司若转向“保利润、稳基盘”，说明基本盘面临挑战；减配版车型对应补贴门槛，是产品策略对政策的适配。

**海豚案例**：
- 比亚迪《王座失守…》（2026-03-28）：购置税门槛导致4Q25清库折扣和被动加配，ASP和成本两头受压；国补倾斜16.7万以上、反内卷限制价格战，海豚君据此判断国内基本盘挑战大，公司20万以下主力车型转向“保利润、稳基盘”。
- 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：美国7500美元IRA补贴退坡，特斯拉推出减配版Model 3/Y（36990/39990美元），欧洲减配版迎合4.7万欧元补贴门槛，美国本土组装车型享受3.75%零售价关税抵免（延到2030年）。

**适用场景与注意事项**：适用于受政策强影响的行业（汽车、新能源、医药）。要求熟悉具体政策条款，并能把条款映射到具体车型或SKU。

### 14.6.6 政策税负敏感性：单位税额×国内出货占比×转嫁比例→利润拖累区间

**方法要点**：新政策（恢复征收消费税）先换算成单位税额，再考虑豁免部分和转嫁比例情景，得出对利润拖累的百分比区间，并注明下一代技术享受豁免。

**操作步骤 / 拆分口径**：
1. 税率换算成单位税额（元/kWh）。
2. 扣除豁免部分：海外出货免征，只对需缴税的国内出货计税。
3. 设定转嫁比例情景：完全不转嫁、一半转嫁。
4. 利润拖累＝单位税额×需缴税出货占比×（1−转嫁比例），再相对公司利润基数，换算成百分比区间，按税率阶段（2026年与2027年）分别给出区间。
5. 注明下一代技术（钠离子、固态等）的暂免期，对长期影响的缓冲。

**关键指标与数据来源**：税率、单位税额、海外出货占比、转嫁比例、利润拖累%。

**判断标准**：转嫁比例越高，利润拖累越小；海外出货占比越高，需缴税比例越低；影响是否可控看区间上限。

**海豚案例**：宁德（2026-07-25）：2026年9月1日起锂电池消费税2%，2027年9月1日起升至4%，对应单位税额10/20元/kWh；海外出货超30%免征；不转嫁时利润拖累7-14%，一半转嫁时3.5-7%；钠离子、固态等在2026.9-2028.12暂免。

**适用场景与注意事项**：受政策税费影响的行业。转嫁能力取决于议价权与竞争格局。

### 14.6.7 从量税调整：完全对冲所需提价幅度与后续价格压制

**方法要点**：对新增或上调的从量税，计算每升税额变化幅度，按产品单价估算完全对冲税负所需的提价幅度；再观察渠道执行与销量，判断价格传导能力，并在后续季度追踪政策对消费者价格敏感度与高端化的压制。

**操作步骤 / 拆分口径**：
1. 计算税额变化（比索/升，含新增零糖等品类的税率）。
2. 按产品单价估算完全对冲所需提价幅度。
3. 观察装瓶商是否已在现代渠道提价、销量是否受影响。
4. 后续季度追踪地区价格/组合增速。

**关键指标与数据来源**：税额（比索/升）、所需提价幅度、地区价格/组合增速。

**判断标准**：完全对冲所需提价幅度越大，对销量与价格的压制越大；价格/组合增速明显低于前年，说明政策对价格敏感度形成压制。

**海豚案例**：可口可乐（2026-04-28）：墨西哥IEPS税从1.65升至3.08比索/升（+87%），零糖新增1.5比索/升，测算需约10%提价，Arca Continental与Coca-Cola FEMSA已完成现代渠道提价；（2026-07-28）：拉美价格/组合仅+3%（2Q25为+15%）。

**适用场景与注意事项**：受税收监管影响的饮料、烟草、酒类。

### 14.6.8 税改（增值税）影响分层测算：收入→利润→股息，并剔除后还原真实增速与ARPU

**方法要点**：税制变更压低价税分离后的收入，海豚君分层测算对收入、利润、股息的影响，区分行业面与公司面、一次性与持续性，并剔除后还原真实收入增速，把增值税影响与ARPU（资费）下滑分开。

**操作步骤 / 拆分口径**：
1. 按受影响业务收入占比，估算税率调整（如增值税从6%升至9%）对总收入的影响（1-2%）。
2. 判断能否向下游转嫁：降价引流策略下难转嫁，对利润的影响为5-7%，股息影响约5%。
3. 剔除后计算真实收入增速。
4. 把通讯业务降幅拆为增值税影响（约2%）与ARPU下滑（约3%），避免用增值税掩盖资费下滑。
5. 区分行业面冲击（三家运营商都受影响）还是公司面冲击，是一次性还是持续性。

**关键指标与数据来源**：增值税率、相关业务收入占比、通讯服务收入同比、ARPU同比（含税/剔税）、利润弹性。

**判断标准**：剔除税改后的真实增速高于表观增速；ARPU剔除增值税后仍下滑，说明资费下滑在提速，不能用政策影响解释。

**海豚案例**：
- 中国移动（2026-03-26）：流量、短信、彩信从“增值电信”改为“基础电信”，增值税6%→9%；对总收入影响约1-2%，利润影响约5-7%，股息影响约5%。
- 中国移动（2026-04-20）：增值税对总收入影响1-2%、利润5-7%；1Q26总营收2664.8亿（+1%），剔除后增速约2-3%；通讯服务收入2198亿（-1.1%），产品销售466亿（+12%）。
- 中国移动（2026-08-14）：2Q26营收2716亿（-3%），通讯业务下滑近5%，其中增值税约2%、ARPU约3%；上半年ARPU 45.1元（-9%），剔除增值税仍-6%，资费下滑在提速。

**适用场景与注意事项**：适用于税制、会计准则、监管收费调整的情形，需要业务收入占比数据。

### 14.6.9 监管规则变化对用户行为与收入结构的机制推演

**方法要点**：面对监管规则变化，先讲清旧规则、改革时间线与新规则，再推演对平台的传导，判断受益程度与公司客群的关系，并区分结构性提升还是一次性提升；政策生效时间短、公司没有量化数据时，不急于下结论。

**操作步骤 / 拆分口径**：
1. 讲清旧规则（5个交易日内4笔日内交易被标记为PDT，须维持2.5万美元权益）、改革时间线与新规则（取消计数与门槛，改为券商实时风险监控）。
2. 推演对平台的传导：提高交易活跃度；用户借款拖到T+1以上时，免息融资变为生息融资；解禁过去被限制的用户；多账户合并带来转户。
3. 判断受益程度与单客AUM的关系（小账户、0DTE期权用户受益最大）。
4. 区分结构性提升还是一次性提升。
5. 政策生效时间短、公司未给量化数据时，不急于下结论。

**关键指标与数据来源**：政策生效日期、日内交易量、期权合约数、融资余额 vs 融资收入、单客AUM、公司给出的结构性提升指引。

**判断标准**：单客AUM越小，受益越大；公司给出结构性提升指引且表示保守，说明有上修空间；生效不足一个月、公司无量化数据，则没有清晰结论。

**海豚案例**：
- Robinhood《Robinhood：美股散户罗宾汉…》（2026-08-11）：PDT于6月4日生效，不足一个月，公司未提供量化数据，没有清晰结论；融资余额216亿（+128%）。
- 微牛《微牛：终于熊转牛了》（2026-08-20）：详细梳理PDT旧规、时间线（2025年9月FINRA通过→2026年4月14日SEC加速批准→6月4日生效→券商18个月内落地）；对单客AUM不到5000的Webull几乎是定向利好；公司指引PDT可结构性提升20%交易量，且表示保守；过去6年关闭超100万活跃入金账户可召回。

**适用场景与注意事项**：适用于受监管规则直接影响的金融、医药、平台公司。

### 14.6.10 突发事件冲击倒推：渠道占比→覆盖率→收入→EBIT margin×停产周数→利润拖累

**方法要点**：对停产、召回、网络安全、自然灾害等短期冲击，用卖方调研的渠道数据倒推受影响业务的年化收入，再按停产周数估算利润拖累，并区分基本面影响与情绪/战略影响。

**操作步骤 / 拆分口径**：
1. 用卖方调研获取品牌在追踪渠道零售额占比与增速。
2. 假设追踪渠道覆盖率，倒推年化收入与占公司营收比。
3. 按业务模式（成品 vs 浓缩液）给出单品EBIT margin。
4. 按停产周数估算对季度利润拖累pct。
5. 区分基本面影响（小）与情绪/战略影响（核心产品在产能刚释放时停产）。

**关键指标与数据来源**：追踪渠道零售额占比、近13周增速、覆盖率假设、EBIT margin、停产周数。

**判断标准**：测算出的利润拖累很小则基本面影响有限，但仍要评估对产品增长叙事和战略的冲击。

**海豚案例**：可口可乐（2026-07-28）：大摩数据fairlife占美国追踪渠道零售额10.6%，近13周+13%（公司+5.6%），按覆盖率75%倒推年化收入约35亿美元（约7%），EBIT margin约15%，按停产3周估算对Q3利润拖累仅0.9pct。

**适用场景与注意事项**：停产、召回、网络安全、自然灾害等短期冲击。覆盖率和EBIT margin属于假设，需给出敏感性。

### 14.6.11 税收政策造成的区域价差：推导跨境消费与境外收入

**方法要点**：从税收政策造成的区域终端价差，推测消费者购买地转移，并结合公司在目标地区的渗透率与新开店，判断境外收入的延续。

**操作步骤 / 拆分口径**：
1. 识别价差来源：如内地金饰加征7%增值税，拉开港澳与内地价差。
2. 推测游客转向港澳购金。
3. 结合公司在港澳的渗透率低、新开店（香港IFC、澳门巴黎人），判断境外收入下半年继续加速。
4. 用境外收入及占比验证。

**关键指标与数据来源**：增值税率、区域价差、境外收入及占比。

**判断标准**：价差扩大且公司在价差受益区渗透率低、有新店增量，则境外收入具备延续加速条件。

**海豚案例**：
- 老铺黄金（2026-08-25）：境外收入33.2亿+108%，占比12.9%→16.7%。
- 老铺黄金（2026-03-23）：海外23.5亿+314%，占比15.7%，香港+400%，新加坡金沙店单店超10亿。

**适用场景与注意事项**：存在跨境价差的消费品（黄金、奢侈品、免税）。

### 14.6.12 监管影响归因：多种解释并列，用同业表现交叉验证主因

**方法要点**：指引异常时，列出几种可能的解释，用同业表现交叉验证哪一个是主因；同时跟踪尚未明确的罚款与整改，以及相关法案和税制变化。

**操作步骤 / 拆分口径**：
1. 列出指引偏低的几种可能解释（监管、竞争、需求、自身节奏）。
2. 用同业的指引和股价表现交叉验证：同业没有同步走弱，则公司指引偏低的原因更可能在监管。
3. 持续跟踪尚未明确的罚款与整改、法案进度、税制变化。

**关键指标与数据来源**：指引、同业股价。

**判断标准**：同业表现良好而公司指引偏低，且存在明确监管事件，则监管是主因。

**海豚案例**：
- 携程（2026-06-25）：Q2指引仅3-8%；同业OTA股价表现不错，推断监管是主因。
- 拼多多：电商征税。
- 中芯：MATCH法案。
- 中国移动：增值税。
- Coinbase/Circle：CLARITY法案。

**适用场景与注意事项**：适用于受监管的行业。

**本节交叉引用**：关税对成本的季度影响量化，以及政策抵免对冲，详见7.3。

**本节速查清单**
- [ ] 把政策或监管事件拆成参数：时点、比例、上限、总额、豁免、暂停期、立法阶段
- [ ] 逐项映射到财报科目：收入减项、ASP、单车BOM、销量、份额、费用、佣金率、股息
- [ ] 罚款事件：占年经营利润比例、罚款构成、比例横比，并逐条映射整改条款
- [ ] 税改与从量税：先算单位税额和所需提价幅度，再给出转嫁比例情景下的利润拖累区间
- [ ] 剔除政策影响后还原真实增速，区分税改与ARPU、行业面与公司面
- [ ] 突发事件：渠道占比→覆盖率→年化收入→EBIT margin×停产周数，并区分基本面与情绪影响
- [ ] 政策生效时间短、公司无量化数据时，不急于下结论；整改类事件设定长期验证指标（如D28留存）
- [ ] 指引异常时，用同业表现交叉验证监管是否为主因
