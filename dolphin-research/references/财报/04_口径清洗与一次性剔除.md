# 第4章 口径清洗与一次性剔除

> **本章目的**：把汇率、并表、会计确认、披露口径、一次性事项等噪音剔掉，并用推算补齐未披露数据，得到可比的“真实”数字。

**本章小节**：4.1 汇率剔除与不变汇率口径｜4.2 并购、剥离与出表：内生增长还原｜4.3 收入确认与会计政策变化｜4.4 披露口径变更与停止披露｜4.5 一次性与非经常事项剔除｜4.6 未披露数据推算与累计数倒算

## 4.1 汇率剔除与不变汇率口径

> 本节导读：跨国公司、出海企业和非本币报表的公司，报表增速里总夹着一块“汇率噪音”——名义加速可能全是汇率顺风，名义放缓可能恰恰是真实加速。本节给出海豚君处理汇率的整套动作：收入、分部、订单额、单价、变现率、指引与 EPS 指引的不变汇率（cc）口径，报表货币与收入货币错配的还原，利润端的汇兑与不对称影响，以及汇率作为业绩与估值的顺逆风因子。做任何环比趋势判断（见 3.2）、预期差归因（见 2.3）、指引倒算（见 9.2）之前都应先过这一关；并购并表的剔除见 4.2，与汇率一起构成“三层剔除”。

### 4.1.1 名义增速与不变汇率（cc）增速并列：伪加速、伪放缓的判定

- **方法要点**：每个收入、分业务、订单额（GBV/GTV/GMV/TPV）和利润指标，同时给出名义（表观）增速与不变汇率增速，环比趋势只用不变汇率口径比较，用来识别“汇率造成的伪加速”和“被汇率掩盖的真实加速”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取公司披露的不变汇率（constant currency / 恒定汇率 / FX-neutral）增速，对总收入、各分业务或分部、订单额类指标、利润逐项并列“名义 | cc | 差值”，差值即汇率贡献 pct（汇率贡献 pct = 名义增速 − cc 增速）。
  2. 用本季 cc 增速减去上季 cc 增速，得到真实加速或放缓幅度（pct）；名义口径的环比变化只做参照，不作结论依据。
  3. 多分部公司逐个分部剔除（国际零售、广告、GBV、TPV、总收入等），再判断加速来自哪里，避免用集团总数一概而论。
  4. 海外分部、海外游戏等子业务，在报告增速旁标注“汇率顺风/逆风约 X pct”，用不变汇率增速判断真实需求。
  5. 把它作为财报速读的必做一步：先剔汇率，再下“提速/放缓”结论；同时检查利润增速（见 4.1.8）、指引（见 4.1.5）、客单价与变现率（见 4.1.4）是否也被汇率带偏。
  6. 汇率大幅波动期（美元贬值期、新兴市场货币剧烈波动期）尤其关键；汇率顺风期的高增长需要打折看待。
  7. 公司没有披露 cc 数据时，按币种结构和汇率变动自行估算（做法见 4.1.2）。
- **关键指标与数据来源**：名义同比、cc 同比、汇率影响 pct、cc 口径环比变化（pct）、分业务名义 vs cc 的订单额与营收；数据来自公司财报、业绩稿与电话会披露的 constant currency / FX impact。
- **判断标准**：
  - 名义提速而 cc 持平 → 只是汇率利好，“没有真正意义上的加速”。
  - 名义放缓而 cc 持平 → 不算放缓。
  - 名义降速而 cc 提速 → 真实是加速，结论反转（“没有乍看那么弱”）；反之名义加速而 cc 放缓，则“没有乍看那么强”。
  - 名义与 cc 同向时，真实加速幅度只取 cc（例如微软商用 M365 名义加速 2pct、cc 只加速 1pct，真实加速只有 1pct）。
  - 名义小幅超预期、但 cc 只等于指引上限，则“超预期”主要来自汇率，含金量要打折。
  - 推理链条：先问“这几个点从哪来”→ 名义减 cc 得汇率贡献 → 只拿 cc 做环比 → 再检验管理层“加速”“触底回升”的叙事是否成立。

### 4.1.2 汇率影响的取数与估算：披露金额换算为 pct，未披露时自行估算，并检验超预期质量

- **方法要点**：把公司披露的“汇率贡献金额”换算成点数，或在未披露时按币种结构和汇率变动估算，从而得到可与一致预期、历史趋势对比的内生增速，判断 beat 的质量。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先找公司披露的固定汇率增速或汇率影响金额（财报“FX impact”、电话会口头说明）。
  2. 金额换算成 pct：汇率影响金额 ÷ 去年同期收入基数（例如 5200 万美元约 2pct）。
  3. 报告收入 − 汇率贡献金额 = 剔汇收入，再算剔汇增速（例如 Monster）。
  4. 公司未披露内生增速时，按季末汇率与币种结构估算顺风/逆风点数（例如新东方按季末汇率估 6-7pct 顺风），结论按“估算”标注。
  5. 剔汇增速与一致预期比较，判断 beat 质量：表观超预期要看有多少来自汇率；表观不及预期也先检查是否汇率逆风；剔除汇率正面影响后仍超预期，才是实质超预期。
  6. 对海外子市场（如中国区），要剔除本币（人民币）升值影响后，才能判断是否真的负增长或首次负增长。
  7. 汇率逆风时方向相反：cc 增速高于报表增速，说明内生比表观更强。
- **关键指标与数据来源**：报表增速、固定汇率增速、汇率影响金额/pct、一致预期；公司披露（财报、业绩稿、电话会）；未披露时用季末汇率、币种结构估算。
- **判断标准**：
  - 汇率顺风占增速的比重越大，内生越弱；用 cc 增速与上季 cc 比较才是真实加速或放缓。
  - 剔汇后仍超预期 → 实质超预期；剔汇后转为不及预期 → 靠汇率撑起的 beat，打折。
  - 表观不及预期但主因是汇率逆风 → 不应直接判负面。
  - 推理链条：汇率金额/点数 → 内生增速 → 对比一致预期与上季内生增速 → 判断真实边际变化。
- **海豚案例**：
  - Lululemon《创始人炮轰、业绩稀烂，换帅救得起小黑裤？》（2026-06-05）：1Q26 营收 +4%，其中约 5200 万美元（约 2pct）来自汇率，内生只有低个位数。
  - Lululemon《Alo围剿、经典老去…》（2026-09-04）：2Q26 报表 -4.3%，固定汇率 -5%；中国剔除人民币升值后 -2%，进入中国以来首次固定汇率负增长。
  - Airbnb（2026-02-13）：营收 +12%，含汇率约 1pct。
  - Costco《消费分层加剧…》（2026-09-25）：会费 +7.3%（剔汇率 7.7%），电商 +19.5%（剔汇率 19.8%）。
  - Monster（2026-08-07）：销售额 25.4 亿美元，+20.2%，汇率贡献 4850 万美元，剔除后 +17.9%。
  - 沃尔玛（2026-05-22）：国际净销售 351 亿美元，+18.0%，固定汇率 +10.1%。
  - 可口可乐（2026-02-11）：表观不及预期，主因汇率逆风。
  - 新东方（2026-04-22）：未披露内生增速，按季末汇率估 6-7pct 顺风；成人英语 14.5% vs 上季 13%，剔汇后内生持平；整体营收 +20% 中汇率贡献 6-7pct，内生 13%。
  - 新东方（2026-07-29）：营收 +23%，汇率顺风估 6-7pct，内生约 16%，环比提升近 3pct。
  - 特斯拉（2026-04-23）：收入含约 9 亿外汇正面影响，剔除后 215 亿仍超预期。
- **适用场景与注意事项**：适用于海外收入占比高的公司，以及人民币收入、美元报表的中概股；美元贬值期尤其重要。估算值误差较大，须标注“仅供参考”；汇率顺风期的高增长须打折，指引里的汇率假设同样要拆开（见 4.1.5）。

### 4.1.3 量指标交叉验证：用订单数、支付笔数等不受汇率影响的指标检验内生增长，并把汇率计入买方预期

- **方法要点**：跨境或新兴市场公司的美元口径增速受汇率影响很大，除了并列名义与不变汇率增速，再用订单量、支付笔数这类不受汇率影响的“量指标”交叉验证内生增长，并把汇率顺风计入对买方真实预期的推断。
- **操作步骤 / 拆分口径 / 公式**：
  1. 同时给出名义增速与不变汇率增速，判断加速是否主要来自汇率顺风。
  2. 环比看不变汇率增速的边际变化：是真实加速，还是放缓。
  3. 用订单量、支付笔数等不受汇率影响的指标交叉验证：量指标的增速与 cc 增速是否一致。
  4. 推断买方真实预期时，把汇率顺风计入（彭博一致预期可能没有充分反映汇率，导致“乍看超预期”）。
  5. 指引中注明汇率顺风贡献（如 0.5pp），再看内生指引（见 4.1.5）。
- **关键指标与数据来源**：名义增速、不变汇率增速、订单量增速、支付笔数增速、汇率影响 pct；公司披露的 FX-neutral 数据与运营数据。
- **判断标准**：
  - 名义提速、cc 略放缓、量指标也放缓 → 提速主要来自汇率。
  - 名义提速、cc 仍小幅加速、量指标提速 → 真实加速，幅度只取 cc 与量指标。
  - 推理链条：名义 → cc → 量指标三层验证，三者方向一致才确认为内生趋势。
- **海豚案例**：
  - MercadoLibre《拉美阿里的撕裂人格》（2026-02-25）：总营收 +45%（不变汇率 47%，较上季略放缓）；名义收入 +45% 看似提速，cc +47% 实际比上季放缓 2pct。GMV +37%（上季 28%），提速主要来自汇率，但不变汇率下仍加速 2pct；订单量 +43%，提速约 4pct；电商营收 +40%，剔汇率 37%，降速 1pct；TPV +42% 主要受汇率推动，支付笔数 +35.5% 略放缓。
  - Shopify（2026-05-06）：GMV +35%，剔汇率 30%，与前三季 29%-30% 持平；营收 +34%，汇率利好约 2pct，真实增速仅提升 1pct；Q2 收入指引高 20s% 含约 0.5pp 汇率顺风。
- **适用场景与注意事项**：适用于跨国公司、新兴市场龙头（拉美、东南亚）。量指标本身要确认口径（订单数、笔数是否含新并入业务）；当量指标和 cc 营收背离时，要回头查单价、变现率（见 4.1.4）。

### 4.1.4 价格类指标的汇率剔除：客单价、ARPPU、ADR、同店与变现率

- **方法要点**：客单价、ARPPU、ADR、同店增速这类“价格/单价”指标，汇率同样会让涨价效应虚高；要把汇率（以及油价等其他价格因素）单独拆出来，才能看到真实的涨价或结构效应；再用剔汇后的收入增速与订单额增速比较，反推变现率方向。
- **操作步骤 / 拆分口径 / 公式**：
  1. 客单价（或 ARPPU、ADR）同比增速 = 汇率贡献 + 其他价格因素（油价、产品结构、真实提价）；先扣掉公司披露或可估算的汇率贡献 pct，再讨论真实价格。
  2. 对成本类、油价敏感的行业，同时剔除油价与汇率（如 Costco 剔除油价与汇率后的客单价、同店）。
  3. 变现率方向：剔汇后的收入增速 vs 剔汇后的订单额/预订额增速。收入 cc 增速低于订单额 cc 增速 → 变现率下行；高于 → 变现率上行。
  4. 对 ARPPU 等单价指标，先剔汇率，再看涨价效应与订阅人数效应各占多少。
- **关键指标与数据来源**：客单价/ARPPU/ADR 名义增速、汇率贡献 pct、油价贡献、剔汇后同店；GBV/订单额 cc 增速与收入 cc 增速的差。
- **判断标准**：
  - 价格指标的“涨价”若大部分是汇率贡献，真实价格效应其实很弱。
  - 订单额 cc 加速而收入 cc 降速 → 隐含变现率真实下行，要追问是否补贴、让利或结构变化。
  - 推理链条：先剔汇率 → 再拆油价等其他价格因素 → 得出真实涨价 → 再对照量的变化判断量价结构。
- **海豚案例**：
  - Uber《Uber：业绩都在线，只是Robotaxi威胁难散》（2026-05-07）：客单价同比 +5%（上季 0.7%），归因于汇率和油价上涨。
  - Airbnb（2026-05-08）：客单价 +9% 中汇率贡献 5pct。Airbnb（2026-02-13）：间夜仍维持高个位数，ADR 在汇率推动下继续上涨。
  - Airbnb（2026-08-07）：预订 +16%，剔汇后 15%，环比加速 2pct；营收剔汇后仅 13%，隐含真实变现率下行；Q3 营收指引含约 3pct 汇率顺风。
  - Spotify（2026-02-10）：ARPPU 剔汇率后 +4%（披露的 7% 收入增长剔汇率后为 13%）。
  - Costco（2026-03-06）：剔除油价和汇率后，客单价 +3.5%；Costco：剔除油价与汇率后同店 6.6%。
- **适用场景与注意事项**：适用于海外收入占比高的平台、OTA、零售与订阅类公司。汇率贡献若只披露在总收入层面，对客单价的归因只能估算；变现率结论要与补贴、结构变化一起验证（见 5.1、5.2）。

### 4.1.5 收入指引的汇率剥离：不变汇率中值与趋势比较

- **方法要点**：公司指引里往往包含汇率顺风或逆风；先把指引区间换算为同比增速，再扣掉指引里的汇率贡献，得到内生（cc）指引增速，与本季 cc 增速比较，判断是继续加速还是放缓，并据此校准指引的乐观或保守程度。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取下季收入指引区间，取中值（或上限、下限）；除以去年同期收入换算为同比增速。
  2. 扣掉公司在指引中说明的汇率顺风（pct），得到不变汇率中值：cc 指引增速 = 指引同比增速 − 汇率顺风 pct（上限则为“指引上限增速 − 汇率顺风”）。
  3. 与本季 cc 增速比较，判断继续加速还是放缓，并记录幅度。
  4. 汇率由顺风转逆风 → 提示下季名义增速有压力；逆风缓解 → 名义增速有改善。
  5. 再看经营指标指引（间夜、ADR 等）和全年指引（收入增速下限、利润率持平）：综合判断指引整体是乐观还是保守。
  6. 指引超预期的幅度也要扣除汇率顺风后重算，才是真实的超预期幅度。
  7. 指引的隐含利润与费用倒算见 9.2。
- **关键指标与数据来源**：下季收入指引区间、汇率影响 pct、不变汇率中值、经营指标指引、全年收入与利润率指引、卖方/彭博一致预期；来自公司指引与电话会说明。
- **判断标准**：
  - cc 指引中值高于本季 cc 增速 → 指引隐含继续加速；低于 → 隐含放缓。
  - 名义指引看似很强、扣汇率后只与本季持平或更弱 → “强”主要来自汇率。
  - 全年收入下限、利润率持平等硬指标，可用来判断管理层给的是保守下限还是乐观目标。
  - 推理链条：指引区间 → 同比增速 → 扣汇率 → cc 中值 → 与本季 cc 比 → 结合经营指标与全年指引 → 判定乐观/保守。
- **海豚案例**：
  - Airbnb（2026-02-13）：下季收入指引 +14%~16%，含汇率顺风 3pct，不变汇率中值 12%，较本季再加速 1pct，好于预期；间夜仍维持高个位数，ADR 在汇率推动下继续上涨；2026 年全年收入至少 +10%，利润率因投入只预期持平。
  - Airbnb（2026-05-08）：下季收入指引 14-16% 含约 3pct 汇率，不变汇率中值较本季放缓约 3pct；GBV 名义增速将退坡到 15% 以下。
  - Airbnb《Airbnb：“火热” 世界杯，引爆酒旅业》（2026-08-07）：Q3 营收指引 15-17%，含约 3pct 汇率。
  - Meta（2026-01-29）：1Q26 指引 535-565 亿，同比 +27%~34%，其中 4pct 为汇率顺风，明显高于卖方 515 亿。Meta（2026-04-30）：2Q 指引 580-610 亿，同比 +22%~28%，含 2pct 顺风；中位数 25% vs Q1 实际 33%。Meta（2026-07-30）：Q2 汇率顺风 1 个点，Q3 预计逆风 1pct，指引同比 +19%~25%。
  - Spotify（2026-02-10）：Q1 指引 45 亿，+9.2%，剔汇率 16%。Spotify（2026-04-29）：Q2 指引 48 亿，+14.5%，剔汇率 15.3%。
  - 奈飞《不收华纳照样 “暴雷”，奈飞真已 “江郎才尽”？》（2026-04-17）：Q2 指引不足 126 亿，隐含增速 16%→13%，且含 1pt 汇率顺风；全年 507-517 亿，隐含 12-14%，含 1pt 顺风。
  - Shopify（2026-05-06）：Q2 收入指引高 20s%，含约 0.5pp 汇率顺风。
  - 甲骨文《拿命博生存，甲骨文“AI注”真赢了？》（2026-03-11）：营收 cc +18% 只与指引上限相当（用指引上限对比 cc 的做法）。
- **适用场景与注意事项**：适用于给出季度区间指引的美股公司，尤其是 Meta、Airbnb、Spotify 这类跨国平台。指引里的汇率假设通常基于指引发布时的即期汇率，后续汇率变化会让实际名义增速偏离指引；指引上限还是中值，要与市场比较口径一致。指引倒算（隐含利润、费用）见 9.2，指引保守度见 9.4。

### 4.1.6 EPS 指引与年内多次上修：拆出汇率贡献

- **方法要点**：记录内生营收指引与可比 EPS 指引的历次变化（维持、上调、二次上修），把每次上调拆成“内生改善”与“汇率贡献”，只有内生收入指引上调才代表需求改善。
- **操作步骤 / 拆分口径 / 公式**：
  1. 建立年内指引时间线：每个季度记录内生（有机）营收指引、可比 EPS 指引区间。
  2. 对比每次修订的变化：上调、维持、下调；找出管理层给的原因。
  3. 拆原因：EPS 上调来自汇率从逆风转顺风（约 3pct）还是内生改善；内生营收指引的上调才代表需求改善。
  4. 首次指引略低于市场预期，也记为负面要点。
  5. 速读阶段同样要识别利润增速、EPS 指引变化是否来自汇率。
- **关键指标与数据来源**：内生营收指引、可比 EPS 指引、汇率影响（pct）；公司指引与电话会。
- **判断标准**：
  - 内生营收指引不变而 EPS 指引上调 → 来自汇率或费用，不代表需求改善。
  - 内生营收指引上调 → 才是需求改善；叠加 EPS 同步上调则质量更高。
  - 推理链条：指引修订轨迹 → 拆内生/汇率 → 判断管理层信心与指引保守度（修订轨迹的可信度见 9.6）。
- **海豚案例**：
  - 可口可乐（2026-02-11）：2026 内生 4%-5%，略低于市场预期。
  - 可口可乐（2026-04-28）：维持 4%-5%，可比 EPS 从 +7%-8% 上调至 +8%-9%（汇率约 3pct 顺风）。
  - 可口可乐（2026-07-28）：内生上调至约 5%，EPS 至 +9%-10%，年内二次上修。
- **适用场景与注意事项**：适用于跨国公司，尤其是内生与汇率贡献差异明显的消费品公司。EPS 指引还受回购、税率、费用影响，不能只归因汇率。

### 4.1.7 报表货币与收入/成本货币错配：本币口径还原与逆风测算

- **方法要点**：当报表货币与主要收入、成本货币不一致时，分别用报表货币和本币算增速与环比，对照公司用哪种货币给指引；成本端也要用本币口径，避免把汇率带来的“降本”当作经营改善；估值假设里写明汇率。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A：美元报表、收入和成本以本币为主（台积电）
    1. 分别计算美元口径与本币（新台币）口径的收入环比，并对照公司给指引所用的货币（新台币指引）。
    2. 成本端同样分币种：本币口径折旧总额持平或增加，而美元口径下降 → 单位成本下降部分来自汇率（美元升值），不能当作经营改善。
    3. 单位固定成本、可变成本的变化，拆出“汇率”与“经营”两部分。
    4. 本币口径环比更高，说明实际比美元口径所示更好。
  - 变体 B：欧元报表、北美收入占比大（Spotify）
    1. 确定北美收入占比（约 35%）和美元兑欧元的变动，算出汇率损益占当期收入的比例。
    2. 还原内生增速，判断“个位数增速”是否只是被汇率压低。
    3. 订阅、广告分部分别给出不变汇率增速。
    4. 前瞻下季汇率逆风是否缓解（如美元回升），预判名义增速的修复。
  - 变体 C：估值汇率假设
    - 估值模型里显式写明汇率假设（欧元/美元、美元/韩元等），以便后续复盘时区分“预测误差”与“汇率变化”。
- **关键指标与数据来源**：美元/本币收入环比、本币口径指引、本币与美元口径的折旧总额、分地区收入占比、汇率逆风 ppt、不变汇率订阅/广告增速、估值汇率假设；来自公司披露的分币种数据与财报附注。
- **判断标准**：
  - 美元口径与本币口径出现背离时，以公司实际计价和给指引的货币为准判断真实环比（如台积电新台币口径高于美元口径，说明实际比美元口径所示更好）。
  - 单位成本改善若主要来自汇率 → 不计入经营改善。
  - 汇率逆风 ppt 占收入比重大 → 个位数增速不代表经营疲弱，内生可能是低双位数；逆风将缓解 → 名义增速有望修复。
  - 推理链条：确定指引与成本的计价货币 → 分币种还原 → 剥离汇率 → 再下经营结论。
- **海豚案例**：
  - 台积电（2026-01-15）：Q4'25 美元口径收入环比 +1.9%，新台币口径 +5.7%，指引是新台币 +1%；单位固定成本 -13 美元/片、可变成本 -64 美元/片，主要来自美元升值。
  - 台积电（2026-04-16）：Q1'26 美元口径 +6.4%，新台币口径 +8.4%，指引 +6%；新台币口径折旧总额增加，美元口径基本持平。同一季度，359 亿美元好于指引上限，新台币口径环比 +8.4%，实际更好。
  - Spotify（2026-02-10）：Q4 收入 +7%（连续两季个位数），汇率影响约占收入 5%（逆风 6ppt），剔除后约 13%；订阅 +8%，不变汇率 +14%；广告 -5%，不变汇率 +4%；以欧元计价，北美约占收入 35%；ARPPU 剔汇率后 +4%。
  - Spotify（2026-04-29）：Q1 收入 +8%，汇率逆风 8ppt，剔除后 14%；Q2 逆风只剩 0.8pct。
  - ASML：估值假设 EUR/USD = 1.14；SK 海力士：估值假设 USD/KRW = 1400。
- **适用场景与注意事项**：适用于跨国公司或非美元记账公司（台积电、ASML、海力士、Spotify 等）。折旧、人工等成本的汇率影响与收入端不同步，务必分别还原；套保安排会让汇率影响滞后，需看公司披露。

### 4.1.8 利润端剔汇：分部利润、收入与成本的不对称、汇兑损益单列与剔除后残余

- **方法要点**：利润端同样要剔汇率——汇率对收入和成本的影响并不对称，会虚增或虚减利润增速；汇兑损益这类不可控的宏观因素要单列；剔除后仍然存在的下滑，才是经营恶化。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A：分部利润扣掉汇率贡献，重算利润率
    1. 找出公司披露的汇率对经营利润的影响额；
    2. 从分部利润中扣掉，重算分部利润率，并与去年同期比较；
    3. 同时给出汇率中性下的利润增速。常见结论是“名义超预期，实际利润率同比下滑”。
  - 变体 B：收入与成本的不对称影响，计算剔汇后的利润增速
    1. 汇率顺风对收入增速的贡献（如 +2pct）往往大于对成本费用增速的贡献（+1pct），会虚增利润增速；
    2. 用公司披露的剔汇影响（如经营利润增速 -2pct）还原 cc 利润增速；
    3. 比较 cc 利润增速与 cc 营收增速，判断利润率是否真的扩张；
    4. 利润增速的环比比较同样用 cc 口径。
  - 变体 C：汇兑损益单列，用核心主业经营利润评价主业
    1. 经调整净利润含汇兑损益（如海外收入产生汇兑损失），因此用剔除利息、投资收益、汇兑的“核心主业经营利润”评价主业；
    2. 避免汇率噪音掩盖经营改善，同时把投资收益变化与汇兑损失分别列出。
  - 变体 D：剔除汇兑损失后看残余降幅
    1. 把汇兑损失这类不可控宏观因素单独剔除，算出调整后净利及同比；
    2. 强调剔除后仍有的下滑才是经营恶化——不会因为可剔除项就放过问题。
- **关键指标与数据来源**：汇率对收入/成本/经营利润增速的影响 pct 或金额、调整后分部利润率、汇率中性利润增速、汇兑损失同比增量、调整后归母净利及同比；数据来自公司披露的 FX impact 与财务费用附注。
- **判断标准**：
  - 剔汇后分部利润率同比下降 → 名义超预期不可靠。
  - cc 利润增速明显低于名义利润增速、且接近 cc 营收增速 → 利润率实际大体持平，没有真正扩张。
  - 经调整净利润持平，但剔除投资收益减少与汇兑损失后核心经营在改善 → 主业向好。
  - 剔除汇兑后仍显著下滑 → 竞争或价格压力是真问题，而非宏观噪音。
  - 推理链条：名义利润 → 扣汇率（含收入/成本不对称）→ 扣汇兑损益 → 残余变化 = 真实经营。
- **海豚案例**：
  - 变体 A：亚马逊（2026-04-30）：国际零售经营利润 14.2 亿，高于预期，但约 3.5 亿来自汇率顺风，剔除后国际板块利润率同比略降。Spotify（2026-02-10）：Q4 经营利润 +47%，汇率中性下 +53%。
  - 变体 B：微软（2026-01-29）：剔除汇率利好后，经营利润增速下降 2pct。微软《分手后的阵痛期，微软何时能重振雄风？》（2026-05-01）：经营利润 +20%，cc +16%，cc 营收 +15%，利润率实际大体持平。微软（2026-04-30）：剔汇率后利润增速 16%，上季 19%，实为变差。
  - 变体 C：网易《空窗期照赚》（2026-05-21）：经调整净利润同比持平，因投资收益减少与海外汇兑损失抵消了经营增量，改用核心主业经营利润衡量主业。
  - 变体 D：阳光电源《收入倒春寒》（2026-04-28）：欧元、美元贬值使汇兑损失同比增加 4 亿以上，剔除后 Q1 归母净利约 27 亿，同比降幅从 40% 收窄至 30%，仍反映储能单价与毛利率同比双降的竞争压力。
- **适用场景与注意事项**：适用于海外业务占比高、汇率波动大的季度，以及海外收入占比高、外币资产多的出海企业；成本以本币计、收入多币种的公司，不对称效应尤其明显。汇兑损益在估值中的处理（剔除汇兑看核心经营利润率，但估值时下调汇兑拖累的净利润）详见 8.8。

### 4.1.9 海外收入占比 × 汇率变动幅度：粗估汇兑冲击并区分高基数

- **方法要点**：本币升值时，用“海外收入占比 × 期间汇率变动幅度 × 敞口”粗估汇兑损失量级，再与去年同期的汇兑收益或损失比较，得到对同比增速的拖累；对去年同期有大额汇兑收益的公司，特别指出“高基数”造成的表观下滑。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取海外收入占比（如三花约 42%）与期初、期末汇率（人民币兑美元，如年初约 7.19 → 6 月末约 6.91）。
  2. 粗估汇兑冲击量级 ≈ 海外收入占比 × 期间汇率变动幅度 × 敞口；精确测算还需要套保比例与外币资产负债的净敞口。
  3. 与去年同期的汇兑收益/损失比较，得出同比多出（或少掉）的汇兑拖累金额。
  4. 用财务费用同比变化验证汇兑测算（汇兑损益主要体现在财务费用里）。
  5. 去年同期有大额汇兑收益时，明确提示“高基数”，剔除汇兑后再看主业利润同比。
- **关键指标与数据来源**：海外收入占比、人民币兑美元期初与期末汇率、汇兑损益、财务费用同比、套保比例；数据来自财报与财务费用附注。
- **判断标准**：
  - 汇兑拖累占利润比重大，而剔除后主业仍增长 → 利润下滑属表观，主业健康。
  - 汇兑拖累之外主业仍下滑 → 才是经营问题（与 4.1.8 变体 D 合用）。
  - 推理链条：占比 × 汇率变动 → 汇兑量级 → 与去年同期比 → 财务费用验证 → 还原主业增速。
- **海豚案例**：
  - 三花（2026-08-27）：海外收入占比约 42%，人民币从年初约 7.19 升到 6 月末约 6.91，汇兑损失比去年同期多影响约 2.9 亿。
  - 吉利《吉利：单车净利追平迪王，吉利迎大反击？》（2026-04-29）：Q1 归母 41.7 亿，同比 -26.6%，因为去年同期有大额汇兑收益，财务费用同比多约 31 亿。
  - 吉利（2026-08-17）：1H26 汇兑亏损 5.5 亿，1H25 为汇兑收益 26.4 亿，归母仍 +37.5% 至 49.2 亿。
  - 小鹏（2026-05-28）：Q1 汇兑损失加大，拖累净亏损。
- **适用场景与注意事项**：适合出口型制造业、出海车企。只是粗估，套保比例和净敞口不清时只能给量级，结论要标注不确定性。

### 4.1.10 汇率作为业绩与估值的顺风/逆风因子

- **方法要点**：按公司海外收入占比和报表货币，判断本币升值或美元贬值对收入、利润、ASP、毛利率的影响方向；分析收入与 ASP 增长时，单独标注汇率贡献。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看海外收入占比（歌尔近 9 成）与报表货币。
  2. 判断方向：出口型、本币报表公司，本币升值（美元贬值）是逆风——收入换算减少、汇兑损失、毛利率承压；以美元报表、海外收入多的公司（苹果），美元贬值使海外收入换算增加，推升收入、ASP 与毛利率。
  3. 区分换算效应（报表折算）与交易效应（实际结算）。
  4. 分析收入与 ASP 增长时单列汇率贡献；估值假设里写明汇率（见 4.1.7）。
- **关键指标与数据来源**：海外收入占比、汇率变化、汇率对收入/ASP/毛利率的贡献；来自财报与电话会对汇率影响的说明。
- **判断标准**：
  - 汇率逆风下业绩仍达标 → 经营实质更好；汇率顺风下的毛利率或 ASP 提升 → 部分不可持续，需打折。
  - 汇率变动方向可能反转，因此对依赖汇率的毛利率改善，要提示“非经营性”。
  - 推理链条：占比 → 方向 → 通道（收入/成本/毛利率/汇兑）→ 在估值与预测中显式假设。
- **海豚案例**：
  - 歌尔《跨过越南“招工坑”…》（2026-04-23）：近 9 成收入来自海外，美元贬值是逆风。
  - 苹果《iPhone炸场…》（2026-01-30）：iPhone 增长受美元贬值带动，美国以外地区收入和价格享受汇率优势；毛利率提升部分来自美元贬值。
  - 苹果《AI缺位…》（2026-05-01）：美元兑人民币贬值带动中国地区收入、价格和硬件毛利率。
  - 三花《汽零回正…》（2026-05-06）：美元贬值拖累毛利率，汇率波动影响净利润。
- **适用场景与注意事项**：适用于跨境经营企业。需区分换算效应与交易效应；对不同通道（收入、成本、汇兑）分别判断，不要只看单一方向。

**本节速查清单**

- [ ] 每个收入、分业务、订单额、利润指标是否都并列了名义与不变汇率增速，环比趋势是否只用 cc 口径？
- [ ] 名义与 cc 的差（汇率贡献 pct）是否算清；“名义提速、cc 持平”是否已判为伪加速？
- [ ] 公司未披露 cc 时，是否按币种结构与季末汇率估算并标注“仅供参考”？
- [ ] 超预期或不及预期，是否先检查汇率贡献，再与一致预期比较？
- [ ] 订单量、支付笔数等不受汇率影响的量指标是否与 cc 营收方向一致？
- [ ] 客单价、ARPPU、ADR、变现率是否已剔除汇率（及油价）？
- [ ] 指引是否扣掉汇率顺风/逆风，得到 cc 中值并与本季 cc 比较？EPS 指引的上调是否拆出汇率？
- [ ] 报表货币与收入、成本货币是否错配，是否用本币口径看了环比、折旧与指引？
- [ ] 利润端是否扣掉了汇率对收入/成本的不对称影响与汇兑损益，剔除后残余是否仍下滑？
- [ ] 估值模型是否写明汇率假设，海外占比高的公司是否把汇率列为顺/逆风因子？

**本节交叉引用**：剔除汇兑损益看核心经营利润率、但估值中下调汇兑拖累的净利润，详见 8.8；“名义增速 → 恒定汇率增速 → 剔除并表后的原有业务真实增速”三层剔除，详见 4.2；指引倒算（上限/中值 → cc 增速、隐含利润增速、利润率、费用与成本增速），详见 9.2。

## 4.2 并购、剥离与出表：内生增长还原

> 本节导读：收购、剥离、关停与出表都会让报表增速失去可比性——并购把外延增长混进来，剥离与出表让名义收入下滑却不代表经营恶化，并表业务还会稀释整体变现率。本节讲如何把这些口径变化剔掉，还原“同口径、内生”的真实增速，并识别并购的战略目的。适合并购、剥离、重组频繁的大型集团，以及软件、平台和高增长公司；与 4.1（汇率）一起构成“名义 → 不变汇率 → 内生”的三层剔除，与 3.2、3.3 的趋势判断配合；并购整合的财务监控（协同、商誉、融资）见 10.8。

### 4.2.1 并购并表贡献的量化：把外延增长单列，还原内生（有机）增速

- **方法要点**：对含收购标的的收入或分部，把被收购资产的增量贡献单独量化（金额或 pct），扣除后得到内生增速，避免把并表增量误读为内生加速，并判断剩余增长是否由有机驱动。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A：以 pct 单列并表贡献
    1. 内生增速 = 报表增速 − 并表贡献 pct；
    2. 收入加速时先问“有没有并表贡献”；
    3. 判断核心业务（如订阅收入）是量价齐增还是单靠价格；
    4. 并表后口径发生变化、部分同比已无法比较时，直接提示不可比。
  - 变体 B：以金额单列并表增量，并评估战略意义
    1. 并购当季，单独量化被收购标的的增量收入（金额）；
    2. 评估其对供应链、产品线的战略意义；
    3. 再判断剩余增长是否来自有机驱动（如大合同进入交付高峰）。
  - 变体 C：大并购年，把并表拉动整体剥开
    1. 对有重大并购的年份，把并表带来的收入拉动占总营收的比例单列；
    2. 剔除后再看内生增速，并用剔除并表后的子业务增速判断该业务是否逐年放缓。
- **关键指标与数据来源**：被并购标的当季收入、并表贡献 pct、分部收入增速、内生（有机）增速、订阅收入增速；数据来自公司对 acquisition contribution 的披露或电话会说明，未披露时自行估算。
- **判断标准**：
  - 剔除并表后增速明显低于报表增速 → 加速主要是外延；内生仅低个位数则增长质量差。
  - 剔除并表后仍提速、且量价齐增 → 内生改善。
  - 推理链条：报表增速 → 扣并表 → 内生增速 → 对照上季与指引 → 判断增长质量；同时说明并购是否补齐了供应链或产品线缺口。
- **海豚案例**：
  - 迪士尼《迪士尼：新官首秀不俗》（2026-05-06）：流媒体增长中，收购 Fubo 并表拉动收入增长约 4%。
  - 迪士尼（2026-08-05）：流媒体（占娱乐收入 48%）+11%，其中 Fubo TV 增量贡献 4%；订阅收入 +15%，量价齐增（One Disney+ 策略）。迪士尼：并表 Fubo 后口径变化，部分同比无法比较。
  - Uber（2026-02-04）：外卖 GB +26% 中，收购 Trendyol 贡献约 2-3pct。
  - Rocket Lab《中子号或延期，RKLB凭何撼动SpaceX？》（2026-08-11）：Space Systems 收入 1.895 亿美元（+94%），驱动一是 SDA Tranche II/III 等大合同按履约进度法进入交付高峰，二是 Mynaric、Motiv 并表，其中 Mynaric 当季贡献 0.13 亿美元增量，并补齐激光通信供应链缺口。
  - 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：FY23 初收购医疗软件头部公司 Cerner，并表对当年总营收约有 14% 的拉动，让 FY23 增速明显加速，剔除后内生收入增速仍然只有低个位数；并用剔除并表后的 OCA 增速判断 SaaS 业务在逐年放缓。
- **适用场景与注意事项**：适合所有并购活跃的公司，避免把外延增长误判为内生改善。与三层剔除（见 4.2.3）配合使用；并表的量化往往要靠公司披露或电话会，缺失时只能粗估，需标注“仅供参考”。

### 4.2.2 并表当季：核对一致预期是否已反映并表，按结构占比剔除并用 ARPPU 倒推净增

- **方法要点**：并购当季，先判断“超预期”有多少只是并表；再按被并购方收入 × 业务结构占比剔除，还原原业务增速，并用假设的 ARPPU 倒推核心用户净增，与上季管理层指引对照。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别一致预期是否已反映并表：多数机构原预期下半年并表，7 月中旬才部分上调，彭博一致预期未完全反映，造成“乍看超预期”。
  2. 按被并购方收入 × 其业务结构占比剔除并表贡献（被并购方收入 4 亿 × 订阅占比 65%），得到原业务订阅增速。
  3. 用假设 ARPPU（同比 -2% 至 11.5 元）倒推订阅净增人数。
  4. 与上季管理层指引比较，下结论（“整体差不多、核心订阅可能还略差”）。
  5. 同时识别并表带来的无形资产摊销增量，以及内容成本的协同（优化内容成本）。
- **关键指标与数据来源**：被并购方收入、订阅占比、ARPPU 假设、订阅净增人数；公司披露的并表时间、被并购方收入。
- **判断标准**：
  - 剔除并表后原业务增速远低于报表增速 → “超预期”来自并表。
  - 倒推出的订阅净增处于历史最低 → 核心订阅偏弱，即便整体收入看起来达标。
  - 推理链条：一致预期是否含并表 → 剔并表 → ARPPU 假设倒推净增 → 与指引比 → 判断核心是否变差。
- **海豚案例**：
  - 腾讯音乐《腾讯音乐：慷慨回购，能买回 “小而美” 信仰吗？》（2026-08-11）：并表 1 个多月喜马拉雅，4 亿收入 × 65% 订阅占比剔除后，原音乐订阅 +2%；假设 ARPPU 同比 -2% 至 11.5 元，倒推订阅净增约 60 万（历史最低）；毛利率受演唱会拖累，但并购优化内容成本；新增无形资产摊销。结论：整体差不多、核心订阅可能还略差。
- **适用场景与注意事项**：任何有并购并表的季度；被并购方数据不披露时需用结构假设，结论标注“仅供参考”。

### 4.2.3 三层剔除：名义增速 → 恒定汇率增速 → 剔除并表后的原有业务真实增速

- **方法要点**：对收入和 cRPO 等前瞻指标做三层剔除——名义、恒定汇率、剔除并表——得到原有业务真实增速；剔除后仍放缓，就判断为“看似提速、实际放缓”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 第一层：名义增速。
  2. 第二层：剔除汇率（恒定汇率，做法见 4.1.1）。
  3. 第三层：剔除并购并表（如 Informatica 约 4pct），得到原有业务真实增速。
  4. 对收入与 cRPO（前瞻指标）同样三层剔除，并分板块（订阅收入、数据和平台等）逐项做。
  5. 也用来推算指引中原有业务的隐含增速。
  6. 并表对高增长业务影响大时（如数据和平台），要单独算剔除后的增速。
- **关键指标与数据来源**：名义增速、恒定汇率增速、并表贡献 pct、原有业务增速（订阅收入、cRPO、分板块）；公司披露的汇率与并购影响。
- **判断标准**：
  - 剔除后仍放缓 → 看似提速、实际放缓，管理层“触底回升”的指引未兑现。
  - 剔除后持平或提速 → 内生稳定或改善。
  - 推理链条：名义 → cc → 内生，每一层差额都要能说清来自哪。
- **海豚案例**：
  - Salesforce《AI替代论摧枯拉朽，SaaS龙头已成“弃子”？》（2026-02-26）：订阅收入名义 +13%，恒定汇率 +11%（提速 2pct），其中 4pct 来自 Informatica，原有业务放缓；cRPO 名义 +16%，恒定汇率 +13%，含并表 4pct，原有业务放缓。速读版本：收入 cc +11%、订阅 +10%，环比各提速 2pct，但 Informatica 并表贡献约 4pct；cRPO 13% 里也有 4pct 并表，说明原有业务疲软。
  - Salesforce《既没增长也没利润》（2026-05-28）：订阅收入恒定汇率 +12%（加速 1pct），剔除并表后持平；数据和平台 +23%，剔除后约 10%；总营收真实增速近 9%（上季约 8%）。
  - Salesforce《“AI替代论”证伪？》（2026-08-27）：名义约 10.8%，恒定汇率 11%（降 1pct），并表影响相近，确实在放缓。
  - Shopify《业绩不俗却暴跌》（2026-02-12）：GMV 名义 +31%，剔除汇率 +29%（环比仅降 1pct）；总营收 +30.6%，汇率贡献约 2pct。
- **适用场景与注意事项**：适用于并购频繁或海外收入占比高的公司。并表贡献若按“约 N pct”披露，只能近似；前瞻指标（cRPO）的并表影响与收入不一定同步，要分别确认（前瞻指标见 6.1、6.3）。

### 4.2.4 剥离、关停业务的可比口径：存续业务增速、指引隐含内生增速与战略分部环比

- **方法要点**：公司处置子公司、出售或关停业务时，剔除被剥离部分的基数，用“可比/存续/核心战略业务”口径重算增速与分部环比，以可比增速做环比趋势判断；指引也同样剔除剥离影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 分别算名义增速与剔除后的可比增速，趋势判断只用可比增速。
  2. 公司出售业务后，剔除被剥离部分的基数，单独计算存续业务（如广告）同比，作为核心指标。
  3. 对指引同样剔除剥离影响，得到隐含内生增速（指引中值 ÷ 存续业务去年同期基数）。
  4. 以“核心战略业务”口径重算收入增速和分部环比，并按指引上沿计算战略分部的隐含环比。
  5. cRPO 等前瞻指标也要同样剔除，对剥离业务调整同比基数。
  6. 提示：剥离会让指引更能看出核心业务的真实趋势。
- **关键指标与数据来源**：总收入名义增速、被剥离业务基数、可比增速、存续业务/核心战略业务增速、指引隐含内生增速；数据来自公司披露的剥离业务收入。
- **判断标准**：
  - 名义增速很低甚至为负，但可比增速保持高位或提速 → 趋势好于表观；
  - 可比增速环比放缓 → 即便基数走高，也需追问核心业务动力；
  - 推理链条：剥离基数 → 可比增速 → 对比上季可比与指引隐含内生 → 判断提速/放缓。
- **海豚案例**：
  - 阿里《阿里：电商再沦陷》（2026-03-19）：总收入同比 +1.7%，剔除银泰、高鑫后可比增速 9%（上季 15%）。
  - 阿里《阿里：电商退位，AI上位》（2026-05-14）：名义 +2.9%，可比 +11%（上季 9%），判定提速。
  - AppLovin（2026-02-12）：4Q 总营收 16.6 亿，+21%；剔除 1P 游戏应用剥离后，广告同比 +66%（同口径内生 +66%），上季为 68%；Q1 指引 17.5-17.8 亿，隐含内生增速近 53%。
  - AppLovin（2026-05-07）：Q1 营收 18.4 亿，+24%，内生 +59%（上季 66%）；Q2 指引隐含内生近 55%。
  - AppLovin（2026-08-06）：Q2 收入 +53%，按原软件收入趋势看，基数走高下继续放缓。
  - Unity（2026-05-08）：Q2 收入指引 +15%-17%，剔除 IronSource 与 Supersonic 后核心战略业务 +29%-32%；战略 Grow 按指引上沿环比 +10%，Vector 应有 10% 以上增长。
  - Unity（2026-03-27）：Grow +24%，剔除 Ironsource 和 Supersonic 后 +48%；Create +3%，剔除 Weta 和专业咨询后核心引擎 +14%。
- **适用场景与注意事项**：适合频繁重组、剥离、并购的大型集团，以及处于业务剥离、重组期的公司。需要公司披露剥离或并表的收入影响，否则只能粗估；剥离基数的年份边界要对齐，避免把已经出表的季度重复扣除。

### 4.2.5 口径扩容：新板块纳入后用体量倍数换算，判断增速下滑是否合理

- **方法要点**：口径扩容时（新板块纳入增速较慢的业务，或把多个业务合并成新分部），要换算体量变化倍数，据此解读增速下滑是否合理，并推断扩容业务的真实表现。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对比新旧口径，量化新口径下体量相对旧口径扩大的倍数。
  2. 扩容后收入增速若只比旧口径略降，而新纳入业务体量不小，则说明新纳入业务同样在高增长。
  3. 高基数期尤其要关注“增速只降了多少”，而非“降了没有”。
  4. 反推驱动：增速保持的原因（如更快配送）。
- **关键指标与数据来源**：新口径收入与同比、新口径体量倍数、高基数期增速降幅；来自公司分部口径调整说明。
- **判断标准**：
  - 体量显著放大而增速仅小幅下降 → 新纳入业务的增长强于预期；
  - 推理链条：体量倍数 → 增速降幅 → 对被纳入业务增长的反推 → 与运营动作（如配送提速）互证。
- **海豚案例**：
  - 阿里《阿里狂投》（2026-08-21）：新即时零售板块纳入盒马、猫超小时达后体量扩大约 1.5 倍，营收 533 亿、同比 +45%，在高基数期增速只降了约 10pct，据此推断更快配送拉动了盒马和猫超的销售。
- **适用场景与注意事项**：适用于分部口径调整、新板块并入的重组季；新旧口径都要能找到，否则趋势无法衔接。

### 4.2.6 并购整合与商业模式切换效应：区分外延、模式切换与内生增长

- **方法要点**：软件等行业的高增长要拆开看，有多少来自并购并表、整合，以及收费模式切换（永久许可转订阅）；这些效应结束后，后续增长只能看订阅的内生增长，预期增速要相应下调，并找新的增量来源。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把软件收入同比拆成：并购并表 + 整合 + 收费模式切换（永久许可 → 订阅）+ 订阅内生增长。
  2. 标定并购影响与模式切换的影响期——影响期结束后，同比增速的“红利”会消失。
  3. 并购影响结束后，预期只看订阅的内生增长，并相应下调增速预期。
  4. 找新的增量来源（新产品、新场景、存量客户的工作负载回迁等）。
- **关键指标与数据来源**：软件收入同比、并购和模式切换的影响期、订阅内生增长、新增量来源；公司披露与电话会说明。
- **判断标准**：
  - 并购与模式切换红利结束后，同比增速回落是正常衰减，关键看内生订阅增速与新增量来源是否能接上；
  - 推理链条：红利期拆分 → 红利结束 → 内生增速 → 新增量来源 → 估值预期下调幅度。
- **海豚案例**：
  - 博通（2026-09-03）：基础设施软件 87.5 亿，同比 +29%；此前的增长主要来自 VMware 并购整合，以及从永久许可全面转向订阅；并购影响已结束，未来看 VMware 订阅的内生增长，新增量来自 VMware Private AI Cloud 和 VCF 工作负载回迁。
- **适用场景与注意事项**：有大型并购或正在转订阅的软件公司。被并购软件业务从“定价红利期”到“内生增长期”的阶段判断，详见 10.8。

### 4.2.7 内生增速 + 环比增速双重检验（高增长公司）

- **方法要点**：剔除并购和拆分的影响得到内生增速；对高增长公司，再用环比增速与公司中长期指引、去年同期的环比增速比较，检验内生增长是否仍在“正常轨道”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 剔除并购并表与业务拆分，计算同口径内生增速。
  2. 计算环比增速，与公司的中长期指引（如每季环比增长目标）比较。
  3. 再与去年同期的环比增速比较，判断动能是否衰减。
  4. 资产类指标（如净新增资产）要确认是否含收购带来的存量，剔除后才是内生。
- **关键指标与数据来源**：内生增速、环比增速、中长期指引、去年同期环比、利润率；公司披露。
- **判断标准**：
  - 环比高于中长期指引 → 动能仍强；低于去年同期环比 → 边际在降速；
  - 推理链条：内生增速（同比）→ 环比 → 对照指引与去年同期 → 判断是否仍在加速轨道。
- **海豚案例**：
  - AppLovin（2026-05-07）：内生增速 59%；环比 +11%，高于 5% 的中长期指引，但低于去年同期的 16%；利润率 78%。
  - 嘉信：NNA（净新增资产）不含收购带来的客户资产。
  - Unity：剔除拆分业务。
- **适用场景与注意事项**：适用于有并购的公司和高增长公司。

### 4.2.8 并表业务对整体变现率的稀释：本体与并表业务分开算，并判断收购的战略目的

- **方法要点**：并表收购业务的客户结构（如 90% 为机构流水）不同于本体时，会显著拉低整体变现率。把 APP 本体与并表业务分开计算变现率，避免误判核心业务恶化，再从战略角度判断收购目的，而不是拉高变现率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 分别列出本体与并表业务的交易流水、收入，并各自计算变现率（收入 ÷ 流水，bps）。
  2. 对比整体变现率与本体变现率，差额即并表稀释。
  3. 看并表业务的客户结构（机构 vs 零售），解释变现率差异。
  4. 判断收购目的：国际化牌照、向上游清结算做垂直一体化，而不是拉高变现率。
- **关键指标与数据来源**：并表业务交易流水、并表业务变现率、整体变现率 vs 本体变现率、本体流水；来自公司披露的分业务数据。
- **判断标准**：
  - 整体变现率下滑若主要来自并表稀释，本体变现率稳定 → 不代表核心业务恶化；
  - 推理链条：整体变现率下降 → 拆本体与并表 → 本体稳定 → 稀释属结构性 → 回到收购战略价值。
- **海豚案例**：
  - Robinhood《Robinhood：爆炒之后…》（2026-02-11）：Bitstamp Q4 交易流水 485 亿（90% 机构），变现率仅 3.52bps，收入 1700 万，把公司整体加密变现率拉低至 27bps；APP 本体流水 340 亿；收购目的在国际牌照与清结算一体化。
- **适用场景与注意事项**：适用于有重大并表收购的公司，分析时需本体与并表分开。

### 4.2.9 业务出表（直营转授权）：收入、门店结构与同店口径的拆解

- **方法要点**：大型业务出表（如中国直营门店转授权合资）时，报表收入下滑不代表经营恶化；要先剔除口径变化，再把直营与授权收入、门店结构、同店口径和权益法收益分别拆开，把真实经营改善和口径优化区分开。
- **操作步骤 / 拆分口径 / 公式**：
  1. 收入口径：从“直营全额确认”变成“只确认授权费与商品供货”，先剔除这一口径变化，不按表面下滑下结论。
  2. 分部内的直营收入与授权收入分别列出同比。
  3. 门店结构：直营转授权带来的门店数变化（直营 → 授权）。
  4. 同店口径变化：低客单价市场被剔出同店，带来口径优化，需把真实经营改善和口径优化区分开。
  5. 剩余市场构成（如日本 78%、英国 19%）：说明分部波动性下降，但天花板依赖单一市场。
  6. 保留权益按权益法确认收益。
  7. 收入驱动从“门店数 × 单店销售”变为“授权费与供货”。
  8. 利润率与绝对利润要同时看：利润率可能因口径变窄而被机械抬高，绝对经营利润才是真实变化。
- **关键指标与数据来源**：报表收入同比、直营/授权门店收入同比、直营/授权门店数、同店口径、剩余市场构成、权益法收益、OPM 与绝对经营利润；来自公司分部披露与电话会。
- **判断标准**：
  - 报表收入下滑但主因是出表 → 先还原；
  - 同店增速优于预期但包含剔除低客单价市场的口径优化 → 打折；
  - 利润率大幅提升但绝对利润下降 → 口径抬升，不是真改善；
  - 推理链条：出表 → 还原收入 → 拆直营/授权 → 同店口径优化 → 利润率 vs 绝对利润 → 剩余市场结构与新驱动。
- **海豚案例**：
  - 星巴克《星巴克：走出至暗时刻，星巴克涅槃重生？》（2026-07-30）：3QFY26 营收 93.2 亿，-1.4%（一致预期 91.2 亿），主因 7991 家中国直营门店转为授权；国际营收 13.2 亿，-34%，直营收入从 15.3 亿降至 7.5 亿（-51%），授权从 4.7 亿增至 5.6 亿（+21%）；国际直营门店从 10277 家降至 2464 家，授权从 12086 家增至 20469 家；国际同店 5.7%（预期 4.1%）中包含剔除中国的口径优化；保留 40% 权益按权益法入表；国际 OPM +4pct 至 17.6%，但绝对经营利润 -7.3%。
- **适用场景与注意事项**：适用于发生出表、合资、重分类的公司。出表后的新增长驱动与旧驱动不同，旧的同店、门店数预测框架要同步更换。

**本节速查清单**

- [ ] 收入加速或放缓时，先问有没有并购并表、剥离、关停或出表？一致预期是否已反映并表？
- [ ] 并表贡献是否量化（pct 或金额），并扣除得到内生增速？被并购方数据未披露时是否标注了估算性质？
- [ ] 是否做了“名义 → 恒定汇率 → 剔除并表”三层剔除，cRPO 等前瞻指标是否同样处理？
- [ ] 剥离/关停业务是否剔除基数，指引是否也还原为内生口径？
- [ ] 口径扩容（新板块并入）时，是否换算了体量倍数并据此解读增速降幅？
- [ ] 并购红利期与收费模式切换效应是否结束，后续是否只能看内生订阅增长？
- [ ] 并表业务是否稀释了变现率等整体指标，本体与并表是否分开算，收购的战略目的是什么？
- [ ] 业务出表时，同店口径优化与真实经营改善是否区分，绝对利润是否与利润率一起看？
- [ ] 高增长公司的内生增速是否与环比增速、中长期指引、去年同期环比交叉检验？

**本节交叉引用**：被并购软件业务从“定价红利期”到“内生增长期”的阶段判断，详见 10.8；表观营收 = 内生增长 + 结构影响（并购/剥离）+ 外汇影响、按五大部门拆分的做法，详见 16.7；毛利率三层拆解（分部收入占比 / 分部内产品结构 / 并购整合期），详见 7.2；口径变化、出表与披露结构调整的还原，详见 4.4。

## 4.3 收入确认与会计政策变化

> 本节导读：同一门生意，不同的会计确认方式会给出截然不同的收入、毛利率和费用。毛额与净额、补贴记作营销费用还是收入减项、履约进度法与时点法、资本化与折旧、公允价值与摊余成本、合并内部抵消，都会扭曲增速、单价和利润率。本节讲如何识别这些会计层面的口径变化、还原可比数字，并在口径干扰时用利润、量指标和物理指标做“锚”。适合平台、项目制、垂直一体化和金融科技类公司；与 4.4（披露口径变更）、5.1（量价拆分）、8.1（利润口径选择）配合使用。

### 4.3.1 营收由毛额改净额：用经营量指标和利润额还原真实增长

- **方法要点**：业务营收确认从毛口径改成净口径时，名义收入增速会失真（甚至转负）；不按表面增速下结论，改用不受口径影响的经营量指标和利润额还原真实增长。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先点明口径变化，不按表面负增长下结论。
  2. 找不受口径影响的经营量指标当代理，例如在管房源数同比。
  3. 用贡献利润额衡量真实增长——毛/净口径只改变收入和成本的列示，利润额不变。
  4. 口径变窄时，利润率会被“机械性”抬高；解读利润率改善要扣掉这部分。
  5. 估算：用量指标增速与名义收入增速的差距，粗估真实业务量增速并标注不确定性。
- **关键指标与数据来源**：分业务营收（新口径）、在管房源数同比、分部贡献利润额同比、贡献利润率环比；来自公司分部披露。
- **判断标准**：
  - 名义收入下滑，但量指标与利润额大幅增长 → 口径影响，真实增长强劲；
  - 利润率环比大幅提升，要拆出“口径抬升”与“真实改善”两部分；
  - 推理链条：点明口径变化 → 量指标代理 → 利润额验证 → 扣除利润率的机械抬升。
- **海豚案例**：
  - 贝壳《“跪太久”贝壳》（2026-05-20）：租赁收入同比 -1%，原因是省心租改按净营收确认；在管房源同比约 +47%，可见实际增长强劲，贡献利润率环比 +4.4pct 至 14.8%（创新高），利润额比预期高约 34%。
  - 贝壳（2026-05-19）：省心租改按净收入确认，租赁营收 -1%，实际业务量可能增长 20-30%。
  - 贝壳《一线再松绑》（2026-08-21）：租赁营收同比 -15%，但贡献利润额同比 +56%，占公司总利润约 9%，文中写明“利润额不受口径调整影响，更准确反映实际增长”。
- **适用场景与注意事项**：适合有代理/自营切换、毛净额确认变更的平台型公司（中介、电商、租赁、旅游）。需要公司披露量指标或分部利润，否则只能估算。

### 4.3.2 补贴改记收入减项：还原可比增速，名义与可比两套口径并列追踪

- **方法要点**：公司把给商户或用户的补贴从营销费用改为收入减项时，收入、毛利率、营销费用三项同时失真；还原可比增速，并坚持两套口径并列追踪，避免被名义负增长误导。
- **操作步骤 / 拆分口径 / 公式**：
  1. 用公司披露或测算的影响额，算出剔除后的可比增速，以可比增速为准判断趋势：可比增速 ≈ 名义增速 + 补贴调整额占去年同期收入的比例，或直接取公司披露的可比增速。
  2. 提醒这类调整不影响利润，所以利润端可直接比较。
  3. 后续季度坚持名义与可比两套口径并列。
  4. 与大行预期（同样按新口径）对比，确认预期口径一致。
  5. 同步检查毛利率和营销费用是否一起发生了“腾挪”（联动检验见 4.3.5）。
  6. 利润主口径同时更换时（如 adj. EBITDA 改为调整后经营利润），要说明并重新建立可比序列。
  7. 反推隐含补贴金额：营收增速的缺口可倒推出补贴的量级（如油费补助）。
- **关键指标与数据来源**：名义增速（如 CMR）、可比增速、补贴调整额、头部大行预期；影响额往往要靠电话会或测算获得。
- **判断标准**：
  - 名义增速与可比增速差越大，口径影响越大；趋势判断只用可比增速；
  - 可比增速环比改善 → 真实好转；
  - 推理链条：口径变更 → 可比增速 → 对比上季与预期 → 利润端交叉验证。
- **海豚案例**：
  - 阿里《阿里：电商退位，AI上位》（2026-05-14）：CMR 名义同比 +1.2%，剔除补贴改收入减项影响后可比增速约 8%，比上季显著改善。阿里（2026-05-13）：商户补贴改记收入减项，CMR 表观 +1.2%，可比约 +8%。
  - 阿里 preview（2026-07-08）：CMR 预计降高个位数，剔除口径影响后持平到微增。
  - 阿里《阿里狂投，只为“中国版谷歌”？》（2026-08-21）：CMR 同比 -7.5%（头部大行预期约 -8%），剔除口径影响后真实可比增速约 +1%。
  - Uber（2026-05-06）：油费补助记收入减项，网约车营收仅 +5%，隐含补助可能超 10 亿；主利润指标改为调整后经营利润。
- **适用场景与注意事项**：适合电商、外卖、出行等补贴密集平台。口径调整的金额往往要靠电话会或测算获得，误差较大；必须同步检查毛利率和营销费用是否一起发生了“腾挪”，并提示后续数据的可比性。

### 4.3.3 净额法与补贴科目归属：先弄清会计处理，再用对的指标判断补贴力度

- **方法要点**：判断扩张或补贴对毛利率的影响前，先弄清收入确认方式（总额或净额）与补贴计入科目；业务按净额法确认、补贴计入营销费用时，毛利率会对补贴“失明”，应改看营销费用和平台销售额。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认业务的收入确认方式：总额还是净额（已剔除司机分成等）。
  2. 确认补贴计入科目：营销费用还是收入减项。
  3. 补贴计入营销费用 → 毛利率不会被补贴拖累，补贴扩张体现在营销费用和经营利润上；补贴计入收入减项 → 毛利率与收入同时承压。
  4. 据此选择观察指标：营销费用、四项经营费用、平台销售额。
  5. 横向对比时，统一不同公司的补贴入账口径。
- **关键指标与数据来源**：收入确认方式、补贴计入科目、毛利率、营销费用、四项经营费用；来自财报附注与会计政策说明。
- **判断标准**：
  - 净额法 + 补贴入营销费用下，毛利率稳定不代表没有补贴，反而要看营销费用同比；
  - 推理链条：会计口径 → 指标选择 → 毛利率失效 → 改看费用与利润。
- **海豚案例**：
  - 滴滴《外卖大战卷到巴西，滴滴也惨了！》（2026-03-13）：毛利率 19.2%，环比反升 0.1pct，没有受巴西外卖影响，因为国际业务按净额计入，海外补贴计在营销费用里，四项经营费用 144 亿，同比 +45%。
- **适用场景与注意事项**：适用于补贴驱动的平台。不同公司补贴入账方式不同（拼多多部分改为收入减项），横向对比要注意。

### 4.3.4 年报会计政策逐年文本比对 + 产品机制拆解：识别收入口径变更

- **方法要点**：收入增速异常时，逐年比对年报中同一会计政策的定义文字，找出新增条款；再结合产品机制，确认口径变化确实存在并符合条款。
- **操作步骤 / 拆分口径 / 公式**：
  1. 对同一会计政策（如对消费者激励和补贴的处理），逐年比对年报定义文字（如 2022 年 vs 2025 年）。
  2. 找出新增条款（如在“明确合同义务”下代商家发放的红包记为收入减项，而不是营销费用）。
  3. 结合产品机制（广告工具把一部分广告预算自动转为消费券）确认口径变化真实存在、并符合“明确合约义务”。
  4. 明确口径变化的影响方向与范围，再进入联动检验（见 4.3.5）。
- **关键指标与数据来源**：年报会计政策原文（不同年份）、广告工具的功能机制、广告收入增速；来自年报附注与产品说明。
- **判断标准**：
  - 新增条款 + 产品机制一一对应 → 口径变更成立，收入确实被冲减；
  - 推理链条：增速异常 → 文本比对 → 产品机制验证 → 确认变更 → 量化影响。
- **海豚案例**：
  - 拼多多《不黑也不吹，只剩2.5%增长的拼多多还好吗？》（2026-05-29）：2022 年定义只有“隐含”代商家发放红包可以冲减收入；2025 年新增“明确合同义务”下代商家发放红包记为收入减项。海豚君认为这个合同义务就是“全站推”工具里的“智能优惠券”：商家设定 ROI 或预算后，工具自动把部分预算转为消费券，所以记为广告收入的减项，证明收入确实被冲减。
- **适用场景与注意事项**：适用于收入增速异常、怀疑口径变化的公司。需要细读年报附注。

### 4.3.5 收入减项与营销费用联动检验：区分纯口径变化和实质让利

- **方法要点**：补贴从营销费用改记为收入减项后，用“收入减少额与营销费用减少额是否同步”检验：同步 → 纯口径变化，不影响盈利；不同步 → 平台实质让利，竞争变差。
- **操作步骤 / 拆分口径 / 公式**：
  1. 假设某平台把 20 亿广告收入转为补贴：若自掏营销费用同时从 100 亿降到 80 亿，属于纯口径变化，对盈利没有实质影响。
  2. 若营销费用仍是 100 亿，本质是平台让渡更多利润维持吸引力，是竞争变差。
  3. 检验营销费用的季节性：淡季是否异常（与旺季持平），与去年补贴高峰时对比。
  4. 同步看广告收入增速与营销费用绝对额、同比。
- **关键指标与数据来源**：广告收入增速、营销费用绝对额及同比、季节性对比（淡季 vs 旺季）；来自财报。
- **判断标准**：
  - 收入减项额与营销费用减少额同步 → 纯口径变化；
  - 营销费用不降甚至不降反增 → 实质让利，业绩确实差；
  - 推理链条：口径变化 → 费用科目对冲 → 营销费用绝对额 → 季节性 → 判断是口径还是竞争。
- **海豚案例**：
  - 拼多多《不黑也不吹，只剩2.5%增长的拼多多还好吗？》（2026-05-29）：广告收入增速降到 2.5%，营销费用仍高达 338 亿，比去年国补高峰时不降反增；投放淡季的 1Q 和旺季 4Q 基本一致，说明即便部分广告收入转成了补贴，平台自己的营销支出也没减少，业绩确实差。
- **适用场景与注意事项**：适用于补贴科目可能变化的平台（电商、外卖、OTA）。

### 4.3.6 借用同行口径调整的“剪刀差”类比，并遵守证据纪律

- **方法要点**：同行做过类似口径调整并披露了实际与名义增速的差，可以把这个剪刀差套用到目标公司估算实际增速，但必须声明缺乏依据、仅为粗略参考；在没有可信第三方数据前，不可证实也不可证伪的市场猜测都视为噪音。
- **操作步骤 / 拆分口径 / 公式**：
  1. 找同行口径调整后的实际 vs 名义增速差（如淘天 CMR 实际与名义相差约 7pct，名义被口径调整压低；阿里 CMR 名义 +1.2% 对可比约 +8% 即是同类现象）。
  2. 套用到目标公司：实际增速 ≈ 名义增速 + 剪刀差，估算实际广告增速与 GMV 增速。
  3. 明确声明“缺乏依据，只是粗略参考”，标注不确定性。
  4. 证据纪律：市场上从高个位数到 18% 的各种猜测，在没有可信第三方数据之前都是噪音；不如依赖明确披露的利润。
- **关键指标与数据来源**：同行名义与实际增速差、目标公司名义增速、可信第三方 GMV 数据。
- **判断标准**：
  - 剪刀差类比只用于“量级感知”，不作为结论依据；
  - 推理链条：同行剪刀差 → 粗估 → 声明依据不足 → 回到可证实的披露（利润）。
- **海豚案例**：
  - 拼多多《不黑也不吹，只剩2.5%增长的拼多多还好吗？》（2026-05-29）：参考淘天把营销费用改为收入减项后，CMR 实际与名义相差约 7pct（名义被压低），套用后拼多多实际广告增速可能约 10%（名义 2.5%），GMV 可能在 10% 以上；同时声明剪刀差相同的判断“并没什么依据”，市场的 18% 和高个位数说法都视为噪音。
- **适用场景与注意事项**：适用于无法拆分口径影响时的粗略估算。必须明确标注不确定性。

### 4.3.7 口径干扰收入时，用利润“一锤定音”

- **方法要点**：收入端同时受多种口径变化影响（补贴改记收入减项、全托管改半托管导致营收变小、罚后部分支出冲减收入）时，收入增速的可比性下降；以不受口径影响的利润（调整后经营利润）作为最终判断依据，并回到两个终极标准：GMV 增速和利润增长。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出收入端的所有口径变化因素，评估其对收入增速的影响方向。
  2. 判断收入的可比性是否严重下降；是则降低收入增速的权重。
  3. 以调整后经营利润作为最终判断依据；评价公司好坏回到 GMV 增速和利润增长。
  4. 利润本身也要剔除一次性项目（见 4.5）。
  5. 对异常偏低的收入增速（如罚后），先怀疑口径问题而非业务恶化。
- **关键指标与数据来源**：调整后经营利润、GMV 增速、收入口径变化说明。
- **判断标准**：
  - 费用记成收入减项还是营销费用没有根本影响，真正关键是 GMV 与利润；
  - 推理链条：收入口径混乱 → 弃用收入做定论 → 以利润和 GMV 为锚。
- **海豚案例**：
  - 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：增长端喜忧参半，且受营收结构和口径变化影响（Temu 改半托管），所以用不受口径影响的利润来一锤定音，调整后经营利润 291 亿，小超彭博预期。
  - 拼多多《不黑也不吹，只剩2.5%增长的拼多多还好吗？》（2026-05-29）：最终衡量依据是 GMV 增速和利润增长，费用记成收入减项还是营销费用没有根本影响。
  - 携程《监管铁拳落定，携程能“轻装上阵”了吗？》（2026-09-16）：酒店收入 +5.6% 偏低，可能是受罚后把部分支出确认为收入冲减项的口径问题。
- **适用场景与注意事项**：适用于收入口径频繁变化的平台。利润本身也需要剔除一次性项目。

### 4.3.8 收入确认口径变更识别（毛转净、佣金改总运费），并用利润交叉验证

- **方法要点**：某业务收入增速突然骤降或骤升时，先查是否口径变更（毛改净、中介佣金改承运总运费），再用调整后经营利润验证真实经营是否变化。
- **操作步骤 / 拆分口径 / 公式**：
  1. 异常增速出现时，首先排查口径变更：如业务从毛收入改为净收入，会让变现率下降（如英国业务约 400bps）；货运中纯中介按佣金记收入、实际承运按总运费记收入，承运占比上升会放大名义收入。
  2. 拆分变现率的下降：口径变更部分 vs 实质下降部分。
  3. 用调整后经营利润验证真实经营是否变化。
  4. 对照量指标（订单额增速），判断收入与利润的背离方向。
- **关键指标与数据来源**：收入；变现率；调整后经营利润；订单额；来自财报与电话会对口径变更的说明。
- **判断标准**：
  - 收入大幅变化而利润变化有限 → 口径影响为主；
  - 推理链条：增速异常 → 查口径 → 拆变现率 → 利润验证。
- **海豚案例**：
  - Uber《Robotaxi 伤脑筋，转头猛干外卖？》（2026-08-06）：网约车营收增速放缓到 1%，变现率同比下降超 500bps，其中约 400bps 来自英国业务口径变更（毛改净）；网约车利润 +28%，高于订单额增速；货运营收 +26%，显著高于个位数的市场预期，原因是中介与承运业务交叉销售，但调整后经营利润仍亏损约 2400 万、变化有限，判断主要是口径影响。
- **适用场景与注意事项**：平台公司毛额/净额确认变化、业务模式转换时。

### 4.3.9 交付形式变化（整机柜改纯芯片、总额法与净额法切换）：测算收入口径缩水与毛利率变化

- **方法要点**：客户交付形式发生变化（整机柜改为纯芯片）时，收入口径会缩水而毛利率变高；测算缩水比例与毛利率差异，判断市场下调预期是否合理，以及对公司利润的净影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别交付形式变化：由采购整机柜改为芯片销售。
  2. 测算新旧形式下单位价值比：芯片销售占整机柜收入的比例（约 20~30%）。
  3. 比较两种形式的毛利率差异（芯片毛利率更高）。
  4. 判断对收入的影响（早期爬坡阶段的收入贡献变化）和对利润的净影响：收入缩水幅度 × 毛利率提升幅度。
  5. 对照市场预期调整的时点：预期是否已提前下调、下调幅度是否合理。
- **关键指标与数据来源**：芯片销售占整机柜收入的比例、毛利率差异；来自公司电话会、客户合作公告。
- **判断标准**：
  - 收入大幅缩水但毛利率更高 → 利润的净影响要计算而非直接看收入；
  - 市场已提前下调预期 → 财报公布时负面可能已被消化（见 11.2）；
  - 推理链条：交付形式 → 收入口径缩水比例 → 毛利率变化 → 净利润影响 → 预期下调是否合理。
- **海豚案例**：
  - 博通（2026-06-04）：与 Anthropic 的合作由采购整机柜改为芯片销售，芯片收入约只占整机柜的 20~30%，但毛利率更高；这会影响 Anthropic 在早期爬坡阶段的收入贡献，市场已提前下调相关预期。
- **适用场景与注意事项**：适合同时提供系统/整机和芯片两种交付形式的公司，也适用于总额法与净额法切换的情形。

### 4.3.10 履约进度法 vs 时点法：还原表观单价与收入增速的失真

- **方法要点**：同一业务中，不同合同的确认方式（履约进度法 over-time、发射成功时点一次性全额确认、里程碑或完工进度法）会让表观单次价格和收入增速失真；先识别各合同的确认口径，再解释“次数增加而收入下降”这类背离，避免误判为价格下跌或价格战。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别各类合同的收入确认方式：时点法（发射成功时一次性全额确认）、履约进度法（按进度分期确认，前期已确认大部分收入）。
  2. 对当期次数/单位数的变化与收入的变化做背离检查（次数增加但收入下降）。
  3. 按确认方式还原单次均价：把前期已确认的收入加回，或把当期已确认的收入按次数分摊。
  4. 对比同期的确认方式差异（如去年采用时点法、本季部分采用履约进度法），避免把表观单价下降误读成价格战。
- **关键指标与数据来源**：发射次数、单次发射均价、发射收入、收入确认方法；来自财报附注与电话会。
- **判断标准**：
  - 表观均价下降若由确认方式差异造成 → 不是价格战；
  - 推理链条：次数↑ 收入↓ 的背离 → 查确认方式 → 还原均价 → 排除价格下跌。
- **海豚案例**：
  - Rocket Lab《中子号或延期，RKLB凭何撼动SpaceX？》（2026-08-11）：发射次数从 5 次增至 6 次，但发射收入 0.45 亿（-4%）；本季 2 次 HASTE 任务按履约进度法、前期已确认大部分收入，去年的 Electron 采用时点法，导致单次均价从 930 万美元摊薄至 740 万美元，表观上看似降价。
- **适用场景与注意事项**：适用于航天军工、工程、软件实施等合同期长、确认方式多样的行业，以及项目制、工程类公司。

### 4.3.11 按收入确认方式（里程碑 / 完工进度法）判断收入波动性，并预判大额确认时点

- **方法要点**：把同一分部的收入按合同性质拆开——标准化按次/按重量收费的商业订单，与按里程碑或完工进度确认的定制研发项目；后者取决于政府预算拨付节奏和技术节点的通关速度，收入非线性，预测时不能简单线性外推。
- **操作步骤 / 拆分口径 / 公式**：
  1. 将分部收入拆成：按次收费的标准化订单 vs 里程碑/完工进度法确认的定制研发项目（如 NASA HLS 登月舱、军方研发）。
  2. 对里程碑项目列出关键技术节点日程（设计审查、发动机试车、轨道测试）和政府预算节奏。
  3. 根据项目时间表预判大额确认时点，不做线性外推。
  4. 对该类项目占比较高的公司，收入预测给区间并标注节点依赖。
- **关键指标与数据来源**：按次收费收入与里程碑收入的占比、关键技术节点日程、政府预算节奏；来自公司披露与项目公告。
- **判断标准**：
  - 里程碑项目收入随预算拨付与节点通关呈台阶式变化，单季同比、环比波动不代表需求变化；
  - 推理链条：合同性质 → 确认方式 → 节点日程 → 大额确认时点 → 收入波动性。
- **海豚案例**：
  - SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：Space 板块由发射服务与定制研发两部分构成，定制研发以“里程碑/完工进度法”确认，收入呈非线性。
  - SpaceX《豪赌AI》（2026-08-05）：发射与研发服务（NASA HLS、军方）按里程碑/完工进度法确认，取决于预算拨付和技术节点，预计 2027 年 Artemis III、2028 年登月时有大额确认。
- **适用场景与注意事项**：适用于国防军工、航天、工程总包、CRO 等项目制公司。与履约进度法对单价的扭曲（见 4.3.10）配合使用。

### 4.3.12 合并报表内部交易抵消：改用物理吞吐指标衡量真实规模

- **方法要点**：当公司把自己的产能主要供给内部业务时，合并报表里内部收入被冲销，分部账面收入会低估该业务的真实经济价值；改用物理指标衡量真实地位，并解释“运力暴增而收入增长缓慢”的悖论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 算出内部使用占总产能的比例。
  2. 改用物理指标（发射次数、入轨质量份额、占本国发射次数比例）衡量真实地位。
  3. 解释“运力暴增而收入增长缓慢”的悖论——内部交易被合并冲销。
  4. 分析分部价值时，可参考市场价重估内部交易的价值。
- **关键指标与数据来源**：内部发射占比、年发射次数、主力机型占比、全球入轨质量份额、占全美发射次数比例；来自公司披露与行业统计。
- **判断标准**：
  - 内部使用占比高 → 账面收入严重低估真实规模，需用物理指标与市场价重估；
  - 推理链条：账面收入与物理规模背离 → 算内部占比 → 物理指标 → 市场价重估。
- **海豚案例**：
  - SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：2025 年发射 165 次猎鹰火箭（猎鹰 9 号占 97%），控制全球 80% 的入轨质量，占全美发射次数的 86%；其中 74% 运的是自家货，被合并冲销，Space 板块 25 年收入仅 41 亿美元。
- **适用场景与注意事项**：适用于垂直一体化公司（自供芯片、自供电力、自有物流）；重估内部交易价值时，市场价口径要明确标注。

### 4.3.13 资本化与折旧政策：识别成本被资本化对分部利润的影响

- **方法要点**：注意分部成本的会计处理——发射成本被资本化为卫星部署成本并按年限折旧，意味着成本不一次性进入当期损益；折旧年限、折旧占比决定利润率弹性，需要同时看 EBITDA 与经营利润两个口径。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别哪些成本被资本化（如 Starlink 组网发射成本资本化为卫星部署成本）与折旧年限（5 年）。
  2. 理解其含义：发射成本不一次性进入当期损益，且以低成本占用自家运力。
  3. 判断折旧在成本结构中的占比（卫星折旧是 Starlink 成本结构中占比最高的项目之一）。
  4. 分析降本对利润的传导：卫星和发射降本会直接改善折旧和利润率。
  5. 利润率同时看 EBITDA 率与经营利润率，二者之差反映折旧负担。
- **关键指标与数据来源**：折旧年限（5 年）、折旧占成本比例、EBITDA 利润率与经营利润率的差；来自财报与会计政策。
- **判断标准**：
  - 折旧年限假设越长，当期利润越好看，需提示对折旧政策敏感；
  - 推理链条：资本化 → 折旧年限 → 折旧占比 → 降本如何传导至利润率（折旧传导详见 10.3）。
- **海豚案例**：
  - SpaceX《Space X：天空之网…》（2026-06-15）：发射成本资本化、按 5 年折旧；卫星折旧是成本结构中占比最高的项目之一。
- **适用场景与注意事项**：适用于重资产基础设施（卫星、数据中心、电信）；折旧年限假设对利润影响很大。

### 4.3.14 研发费用化率变动还原：推断实际研发总投入与可比利润

- **方法要点**：研发费用的表观数字受“费用化率/资本化率”影响；同时追踪费用化率的季度与年度序列，推断实际研发总投入的变化，并用旧费用化率重算利润，还原会计口径对利润的压制。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取研发费用、费用化率（单季和全年）、资本化研发支出，计算研发总投入 = 费用化研发 + 资本化研发。
  2. 费用化率上调而研发费用仍下降 → 实际研发总投入在收缩（新品研发告一段落或整合降本见效）。
  3. 用旧的费用化率重算利润：“若维持去年 Q1 费用化率，净利润将突破 X 亿”，把会计口径对利润的压制还原出来。
  4. 解读研发费用环比大增时，区分费用化率提高与一次性费用（团队整合）。
- **关键指标与数据来源**：研发费用、研发费用化率（单季和全年）、资本化研发支出、净利润；需要公司披露资本化金额。
- **判断标准**：
  - 费用化率上调但费用下降 → 总投入收缩，研发周期可能进入收获期；
  - 利润在旧费用化率口径下更高 → 表观利润被口径压制；
  - 推理链条：费用化率 → 总投入 → 旧口径利润 → 判断研发周期与利润质量（研发投入方向见 8.4）。
- **海豚案例**：
  - 吉利（2026-04-29）：Q1 研发费用 45.6 亿，环比 -13.5 亿，低于预期 50.8 亿；费用化率上调到 44%（25Q1 为 28.5%，2025 全年 36%），推断研发总投入开始收缩。若维持去年 Q1 费用化率，净利润会超过 50 亿，实际 41.7 亿。
  - 吉利《吉利猛追，能否撼动比亚迪王者地位？》（2026-03-18）：Q4 研发 59 亿，环比 +15 亿，部分因为费用化率提高，以及智驾团队整合等一次性费用。
- **适用场景与注意事项**：适合研发资本化比例高的车企、科技硬件公司。需要公司披露资本化金额，否则只能看趋势。

### 4.3.15 营销激励摊销入账：识别当期费用与实际投放的错位

- **方法要点**：营销费用大幅变化时，先看会计处理——转仓返现等用户激励若分期摊销入账，过去的投放会影响当期费用，当期费用下降并不代表投放收缩；随着摊销影响占比降低，营销费用更多反映当期实际投放。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别用户激励、获客补贴的入账方式：一次性计入还是分期摊销。
  2. 把当期营销费用拆成“历史激励摊销”与“当期实际投放”，判断费用变化的真实原因。
  3. 随摊销影响占比降低，营销费用更可控、更能反映当期投放。
  4. 同时观察三费结构异常（如行政费用偏高，推测在做国际市场开拓前期工作）。
  5. 利润用剔除 SBC 的调整后经营利润交叉看。
- **关键指标与数据来源**：营销费用环比、激励摊销金额、行政费用占比、调整后经营利润（剔除 SBC）。
- **判断标准**：
  - 营销费用环比大降但主要由摊销回落造成 → 不代表投放收缩；
  - 推理链条：费用变化 → 摊销 vs 当期投放 → 费用结构异常项 → 利润口径交叉验证。
- **海豚案例**：
  - 微牛《微牛：终于熊转牛了》（2026-08-20）：费用环比 -5.5%，营销费用环比 -29%，原因是去年转仓返现摊销对上季影响大；核心经营利润 4500 万，利润率 22%；剔除 SBC 后调整后经营利润 6300 万，利润率 31.5%。
- **适用场景与注意事项**：适用于存在用户激励、获客补贴摊销的互联网金融公司。

### 4.3.16 公允价值法 vs 摊余成本法：账面价值路径对比与公允价值变动占收入比重

- **方法要点**：同类信贷资产，用公允价值计量与用摊余成本计量，利润表的波动与账面价值路径截然不同；测算公允价值变动占收入的比重，可解释看似“EBITDA 缩水”的指控，并在跨公司比较前统一口径。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别计量方法：公允价值法（输入参数 WAC、CDR、CPR、折现率，第三方模型测算、审计复核；变动计入非利息收入中的“贷款发放、出售、证券化与服务”项目）vs 多数持牌信贷机构的摊余成本法。
  2. 对比账面价值路径：发放初期公允价值高于未偿本金（UPB）约 5%（未来应计利息的现值）；存续期内账面价值向 UPB 收敛，产生公允价值变动损益，利润表波动频繁；摊余成本法方向相反，到期时账面价值向上回归（可用假设值拟合两种方法的账面价值路径图）。
  3. 利率上升或坏账风险上升时，公允价值下降立即冲击当期利润；公司用套期保值对冲，过去三年基本覆盖价差和公允价值变动。
  4. 测算：对冲后公允价值净变动占当期收入的比重——早期 30-40%，目前约 15%；对照调整后 EBITDA 率约 30%，评估指控“EBITDA 缩水近 90%”的合理性。
  5. 战略含义：全部贷款按公允价值计量，也意味着公司倾向平台生意（卖流量变现加风控模型），与 Fintech 同行一致。
- **关键指标与数据来源**：公允价值溢价（约 5%）、公允价值净变动/收入（30-40% → 15%）、调整后 EBITDA 率、套保损益；来自财报附注与公司披露。
- **判断标准**：
  - 公允价值净变动占收入比重高 → 利润对利率与信用假设敏感，调整后 EBITDA 的可比性要打折；
  - 套保覆盖程度高 → 实际经济风险被对冲，需看净额；
  - 推理链条：计量方法 → 账面价值路径 → 公允价值变动占收入比 → 套保覆盖 → 判断指控与真实利润质量。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：公允价值变动约占收入 15%；早期（对冲后）占 30-40%；调整后 EBITDA 率仅约 30%，这解释了浑水“EBITDA 缩水近 90%”的说法；海豚君用假设值拟合了两种方法的账面价值路径图。
- **适用场景与注意事项**：适合用公允价值计量贷款或金融资产的 Fintech、保险、资管公司，做横向比较前要统一口径。

**本节速查清单**

- [ ] 收入增速或毛利率异常时，是否先查毛额/净额、补贴记账科目（营销费用 vs 收入减项）、中介佣金 vs 总运费是否变更？
- [ ] 是否对年报会计政策做了逐年文本比对，并用产品机制确认新增条款？
- [ ] 补贴改记收入减项后，是否并列名义与可比两套口径，并检验收入减少额与营销费用是否同步（淡季营销费用是否异常）？
- [ ] 口径干扰时，是否改用调整后经营利润、GMV、量指标和利润额作为锚，而不是纠缠收入？
- [ ] 借用同行口径剪刀差估算时，是否声明“缺乏依据，仅供参考”，并把无法证实的市场猜测视为噪音？
- [ ] 项目制、航天、工程类收入，是否区分时点法、履约进度法、里程碑法对单价与波动性的影响，并预判确认时点？
- [ ] 垂直一体化公司是否识别了合并内部抵消，并用物理指标和市场价重估分部价值？
- [ ] 资本化与折旧、研发费用化率、用户激励摊销、公允价值与摊余成本等会计处理，是否已还原再比较利润？
- [ ] 交付形式变化（整机柜→芯片）对收入口径、毛利率与利润的净影响是否测算？

**本节交叉引用**：新业务按收入确认方式（佣金制 vs 自营毛额制）拆分归因，详见 15.6；识别会计/披露口径变化、避免误读指引和分部数据，详见 4.4；剔除比特币收入后的核心收入、以毛利润为核心规模口径，详见 16.9。

## 4.4 披露口径变更与停止披露

> 本节导读：公司改分部、改地区或收入分类、合并或取消披露指标时，口径本身既是噪音，也是信号。本节解决三件事：口径变了，怎样把新旧数据接起来（口径地图、追溯重述、还原到卖方建模口径）；口径变化意味着什么（管理层想强调或淡化的叙事、停止披露的负面含义、对商业模式的重新定性）；口径变了以后怎样继续追踪（可追踪性评估、替代指标与自建估算）。本节与 4.1～4.3（汇率、并购出表、会计政策）互补，与 4.6（未披露数据推算）配合使用；还原后的数据再进入第 2 章的预期差对标和第 9 章的指引解读。

### 4.4.1 口径地图：识别口径变化并写明新旧映射

- **方法要点**：公司重组分部或组织架构、调整地区或收入分类、变更会计口径时，先画一张“口径地图”，在点评中独立交代新旧口径的对应关系，使后续每个数字都放在正确的口径下解读，避免把口径变化误当成真实增长，或把会计口径变化误读为经营或指引变化。
- **操作步骤 / 拆分口径**：
  1. 识别变化：逐项对比本期与上期的分部、地区、收入类型清单，找出合并、拆出、更名、迁移；集团内部的业务划转也要识别为口径变化（见 4.4.10）。
  2. 画口径地图，逐项标注：哪些科目不变（可直接与历史比较）；哪些合并；哪些拆出单列（便于看清投入和亏损）；哪些指标口径有小幅变化；哪些业务从 A 分部迁到了 B 分部。
  3. 在正文开头设一个独立章节（固定命名如“披露口径变化概览”“业务介绍”“业绩口径调整”），写明新板块由哪些旧业务组成、哪些指标口径未变、哪些有小幅变化、哪些被拆出单独披露。
  4. 在历史数据图表下加注，写明口径调整的内容和起始期，让读者看图时知道序列是否可比；地区口径调整要标注“数据上略有差异”。
  5. 评估旧的市场预期能否沿用：若并入的业务盈亏体量不大，原有预期仍有参考价值（新旧口径的预期差对标见 4.4.3）。
  6. 数据比较一律以公司重述的历史数据为准；公司没有提供重述时，只能用新口径自行重建序列，或明确标注“不可比”（重建做法见 4.4.2）。
  7. 数字变动先判断是不是会计口径变化：例如 Capex 指引数字下调，可能只是会计处理变化而实际指引不变。
- **关键指标与数据来源**：新旧分部对应关系；口径未变的核心指标（如 CMR）；拆分后新增披露的指标（如 AI 应用板块营收和亏损）；调整影响的历史期间；新口径下各分部占比；数据来自财报分部附注、公司重述的历史数据、业绩小会。
- **判断标准**：
  - 口径未变的核心指标是跨期比较的锚；口径变化的指标只能与公司重述后的历史比较。
  - 分部重分类后，要先确认同比是否还可比，重分类可能改变同比方向（见 4.4.10）。
  - 并入或拆出业务体量不大，原预期可沿用；体量大，则预期需要重做。
  - 拆出来单列的新披露（如 ESPN、AI 应用板块）是投入与亏损透明度的提升，值得单独追踪。
  - 指引数字的变动，先排除会计口径影响，再谈上调或下调。
  - 推理链条：先问“口径变了什么”→ 再问“哪些数还能和历史比”→ 最后才问“增长或预期差是多少”。
- **海豚案例**：
  - 变体 A：分部、组织架构重组的新旧映射
    - 阿里《阿里：电商再沦陷》（2026-03-19）与《阿里：电商退位，AI 上位》（2026-05-14）：中国电子商业集团等于原淘天加飞猪加闪购/饿了么，其他板块归并菜鸟、本地服务、大文娱；正文开头用独立章节交代新旧对应。
    - 阿里《阿里狂投》（2026-08-21）：原中国电商、国际电商和盒马合并为“阿里电商”；阿里云加平头哥组成“AI 云和算力”；AI 实验室和应用（千问 C 端、千问办公）单列；国际电商本身在盈亏边缘，因此并入后原有预期仍可参考。
    - 迪士尼《迪士尼：新官首秀不俗》（2026-05-06）：新架构分为娱乐、体育、体验三块，ESPN 被单独拎出，便于看清其体量。
    - 应用材料（AMAT，2026-02-13）：200mm 设备业务从应用全球服务转入半导体系统，显示器业务归入“其他”；点评中写明调整内容，并提示同比是否还可比。应用材料《Capex 狂飙在路上，应用材料 AMAT 能接住“泼天富贵”吗？》（2026-05-15）：同一调整，在图表下加注，保证历史序列可比。
    - 英特尔《英特尔：AI CPU 火热造势，“冰冷”指引浇灭了期待？》（2026-01-23）：网络及边缘不再单独披露，部分并入客户端，Altera、Mobileye、IMS 归入“所有其他”；图注写明“公司在 2025 年第一季度调整了业务口径，将一部分原来的网络及边缘收入计入客户端”。
    - 美光《美光 MU：AI 带动存储“疯涨”…》（2026-03-19）：把 CNBU/SBU/MBU/EBU 重组为 CMBU/CDBU/MCBU/AEBU，按下游市场划分；数据中心及云占比已超 50%（动机解读见 4.4.4）。
    - 微软（2026-07-30）：25 财年把企业 Office 365、Windows 365、Security 365 并入生产力与流程板块。甲骨文：26 财年改为云、软件、硬件、服务四大板块（历史重分见 4.4.2）。Unity：2023Q1 并入 IronSource 后改为 Create/Grow 两分部。这几例用于固定设置“披露口径变化概览”或“业务介绍”章节，交代新旧口径对应关系。
  - 变体 B：地区口径调整
    - 中芯（2026-02-10）：地区口径从“北美洲/中国内地及香港/欧洲及亚洲”改为“中国区/美国区/欧亚区”，标注“数据上略有差异”；同期 2022Q1 起不再披露制程节点占比（替代做法见 4.4.8）。
  - 变体 C：会计口径变化，而非业务变化
    - 微软（2026-07-30）：26 自然年 Capex 从 1900 亿下调到 1750 亿，更多是会计“小心思”，实际指引不变，不能解读为资本开支收缩。
- **适用场景与注意事项**：所有公司在口径调整季都应做；尤其适合频繁调整架构的集团型公司。公司没有提供重述历史数据时，只能用新口径重建序列或标注不可比。前后季度的数据需按公司重述的历史数据比较。

### 4.4.2 追溯重述、历史序列重建与旧口径估算延续

- **方法要点**：口径变更后，要让时间序列继续可比：公司有重述就用重述；没有重述就按新分类把历史重新归类；对不再披露的旧口径，继续用自己的方法估算。这样才能看长期趋势，也才能和卖方仍在使用的旧口径衔接。
- **操作步骤 / 拆分口径**：
  1. 先查公司是否提供重述的历史数据，有则直接采用。
  2. 没有重述时，依据公司补充披露或合理假设，把更长的历史（如 FY18 至 FY26E）按新分类重新归类，画出各板块的长期增长曲线；注明估算成分。
  3. 对关键旧口径继续估算：例如用已披露的新口径加外部信息拆出旧口径的计算、网络；对不再单独披露的业务（如 VMware）自行估算，继续跟踪（做法见 4.4.8）。
  4. 在图表下注明历史口径，必要时图表仍按历史口径绘制，保证读者看到的是同一把尺子。
  5. 维护一份历史口径数据库，口径变化之后每个季度都按旧口径与新口径双轨更新（过渡期做法见 4.4.3）。
- **关键指标与数据来源**：新旧口径分部收入、占比、增速；重分类依据（公司补充披露、10-K/年报附注、管理层表述）；估算值及假设。
- **判断标准**：
  - 重分类后能做的新判断，才是这套工作的价值：例如把长期历史按新分类重排后，可以看出“非云传统业务 9 年在 300-350 亿美元之间振荡”，从而判断云业务才是真正的增量来源。
  - 估算出的旧口径数据只能用来看趋势和边际变化，必须标注“估算”；与公司后续披露或管理层口径对不上时，要校准。
  - 集团内部重组（业务划转）造成的数据跳变，不是真实增长（见 4.4.10）。
- **海豚案例**：
  - 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：甲骨文从 FY26（自然年 2025 年 8 月起）调整收入分类，原先云和软件在同一大板块里交叉披露，现在拆成云（OCI+OCA）、软件（License+Support）、硬件、服务四大板块；海豚君按新分类把 FY18 到 FY26E 的历史收入重新归类，画出各板块 9 年的增长曲线，从而对比非云传统业务（软件、硬件、服务）与云业务内部（OCA vs OCI）的长期表现；重分类后发现非云业务 9 年在 300-350 亿美元之间振荡。
  - 英伟达《英伟达：群雄逼宫、AI“堵点”生变，宇宙股也会“小失意”？》（2026-05-21）：新口径只披露超大规模客户和其他云，海豚君继续估算旧口径：计算约 600 亿（环比 +87 亿）、网络约 151 亿（环比 +42 亿）；新口径下游戏等并入“边缘计算”后，游戏约占边缘计算的 6-7 成。
  - 博通（2026-03-05）：不再单独披露 VMware，海豚君自行估算后继续跟踪（见 4.4.8）。
  - 英特尔（2026-01-23）：图注写明业务口径调整，保证历史图表可比（见 4.4.1）。
  - Block（2026-02-27）：收入类型口径改变后，本季速读仍按历史口径展示（见 4.4.3）。美团（2026-06-01）：口径调整后图表仍沿用历史口径（见 4.4.6）。
- **适用场景与注意事项**：适合披露口径变更的公司。重分类需要依据公司补充披露或合理假设，要注明估算成分；估算误差在公司不提供桥接数据时会加大。

### 4.4.3 新旧口径融合：还原到卖方建模口径比预期差

- **方法要点**：公司切换分部披露，而多数机构仍按旧架构给预期时，不直接用新口径评价 beat/miss，而是把新口径映射回旧口径，在与一致预期同口径下判定预期差，同时保留新口径追踪新的增长引擎。原则：预期差必须在市场建模的同一口径下比较，新口径用来看趋势和叙事。
- **操作步骤 / 拆分口径**：
  1. 确认卖方一致预期（如彭博）仍按哪套口径建模，通常是旧架构；分部口径切换的过渡期（通常前 2-4 个季度），卖方模型尚未切换。
  2. 新口径映射回旧口径，例如：传统广告 + AI 原生营销 ≈ 旧口径广告；AI 云 + 自动驾驶硬件等 ≈ 旧口径云和其他。
  3. 在与一致预期同口径下判定 beat/miss。
  4. 同时保留新口径，单独追踪新增长引擎（如 AI Infra、AI 应用、AI 原生营销各线）的规模、环比和占比。
  5. 两套框架合并在同一张表里呈现，读者可同时看到“旧口径预期差”和“新口径趋势”。
  6. 处理抵销项等小差异：如百度核心与爱奇艺之间约 1%（2-4 亿）的抵销项，海豚君自拆的百度核心细分数据与公司报数略有差距，但声明“无碍趋势判断”，并只聚焦百度核心（不含爱奇艺）。
  7. 还原含估算误差，必须在文中声明；公司不提供桥接数据时误差加大；部分细分项同比分析有难度，也要写明。
- **关键指标与数据来源**：新/旧口径分部收入；彭博一致预期（旧口径）；抵销项规模；百度核心 vs 爱奇艺；还原后的同比增速。
- **判断标准**：
  - 对标预期用旧口径：还原后若优于一致预期则为超预期，反之为不及预期；不能因为新口径下某个新板块漂亮就直接判定超预期。
  - 新口径下看新引擎的规模、环比和占比，判断“增长引擎是否已接棒”。
  - 推理链条：卖方在旧口径下建模 → 在旧口径下比预期差 → 再回到新口径解读叙事；两个口径给出的结论冲突时，写清楚谁服务于哪个问题。
- **海豚案例**：
  - 百度《百度：广告根基已废，昆仑芯成“救命草”？》（2026-02-26）：2025Q4 起首次按新架构披露（AI 业务 + 传统业务，AI 再分 AI Infra、AI 应用、AI 原生营销），而机构仍按旧架构（广告、云和其他）给预期；还原旧口径后，广告整体 -16.5%、传统广告 -26%，云和其他 +13%（高基数，符合预期，云基础服务好于资金预期）。
  - 百度《百度：其他没指望，全靠昆仑芯》（2026-05-18）：旧口径广告 -21.5%、传统广告 -28%，云和其他 +42%，超预期。
  - 百度《百度：老业务继续磨底，AI 全靠算力红利》（2026-08-18）：继续使用新旧融合表。
  - 同类速读做法：Block（2026-02-27），细分从交易/服务/硬件/加密改为商务/金融/比特币，本季仍按历史口径；应用材料（2026-02-13），200mm 设备转入半导体系统、显示器归入其他，以突出核心业务；迈威尔 Marvell（2026-03-06），业务从 5 项改为 2 项（数据中心、通信及其他）；美光（2026-03-19），重新划分为 CMBU、CDBU、MCBU（管理层意图解读见 4.4.4）。
- **适用场景与注意事项**：分部口径切换的过渡期适用；还原含估算误差，需在文中声明；公司不提供桥接数据时误差加大；若卖方已切换到新口径，则直接用新口径对标。

### 4.4.4 解读口径调整背后的管理层动机与叙事

- **方法要点**：口径变化往往是管理层“想让市场看什么”的表达：合并增长慢的业务、单独凸显增长快的业务，或淡化某项恶化的指标。海豚君在说明新旧映射之后，会解读动机，并用后续数据检验“被突出的板块”是否真的更强。
- **操作步骤 / 拆分口径**：
  1. 先写清映射（见 4.4.1），再回答：哪些业务被合并掉了、哪些被单独拎出来、哪些口径被淡化。
  2. 推断动机：突出核心业务或 AI；在大厂自研芯片的背景下凸显工业云、政企云、主权客户的成长性；把增长慢的传统业务与增长较快的数据和平台业务区分开；把占比已不足一成的业务并入“边缘/其他”。
  3. 用占比数据验证动机，例如被突出的业务是否已占比过半。
  4. 之后用新口径继续跟踪，检验“被突出”的板块是否真的更强，而不是接受叙事。
  5. 把“口径变化本身”记成一个管理层信号（他们希望市场关注什么、淡化什么），与指引、措辞等软信号一并纳入第 9 章的判断。
- **关键指标与数据来源**：新旧分部映射；各板块占比；各板块恒定汇率增速；被合并业务的历史占比。
- **判断标准**：
  - 业务合并、占比不足一成的业务被并入“其他/边缘”，通常意味着该业务已不是叙事重点。
  - 新口径下被突出的板块，增速若不能持续领先，则“叙事”不被业绩支持。
  - 口径变化后若分部提速或放缓趋势发生反转，要回到旧口径核实。
  - 推理链条：口径变化 → 管理层想强调的业务 → 该业务占比和增速是否支撑 → 下季验证。
- **海豚案例**：
  - 变体 A：突出核心业务与增长引擎
    - 迈威尔 Marvell（2026-03-06）：业务从 5 项改为 2 项（数据中心、通信及其他），企业网络、运营商、消费、汽车工业合并，凸显数据中心的重要性。
    - 海康（2026-04-18）：2021 年起不再披露前端、后端、中心控制产品，改为主业 + 创新业务，并重点披露创新业务，说明发展重心在迁移。
    - 英伟达《英伟达：群雄逼宫、AI“堵点”生变，宇宙股也会“小失意”？》（2026-05-21）：把数据中心从“计算/网络”改为“超大规模客户/其他云（ACIE）”，是为了在大厂自研芯片背景下，凸显工业云、政企云、主权客户的成长性；把游戏、汽车等并入“边缘计算”，是因为这些业务占比已不足一成。新口径下超大规模 379 亿（环增 40 亿）、其他云 374 亿（环增 89 亿）；边缘计算 64 亿，同比 +29%。
    - 美光（2026-03-19）：四大 BU 按下游市场重新划分，数据中心及云占比已超 50%，海豚君解读为“凸显了公司对相关业务的重视”。
    - 应用材料（2026-02-13）：200mm 设备转入半导体系统、显示器归入其他，意图是突出核心业务。
    - 百度（2026-02-26）：新架构意图是突出核心业务和 AI（还原做法见 4.4.3）。
  - 变体 B：区分增长快慢业务，并验证被突出板块
    - Salesforce《既没增长也没利润》（2026-05-28）：从 Sales、Service、Marketing & Commerce、Platform、Analytics 五条线，合并为 Agentforce Apps（SaaS，含 Sales、Service、Slack）与 Data 360 & Platform & Others（PaaS，含 Data 360、Headless Platform、Informatica、MuleSoft）两块；Apps +7%，Data & Platform +23%（剔除并表约 10%）；海豚君解读意图是把增长慢的传统 SaaS 与 AI 时代增长较快的数据和平台业务区分开，引导市场关注后者。
    - Salesforce《“AI 替代论”证伪？》（2026-08-27）：Apps +8%（提速 1pct），Data & Platform 放缓 3pct，即被突出的板块并不出彩。
  - 变体 C：借口径调整重新定性商业模式，见 4.4.5。
- **适用场景与注意事项**：通用。口径变更往往暗示管理层想要的叙事，是读财报的重点；动机属于推断，需要用后续数据验证，不能当作事实陈述。

### 4.4.5 借新收入分类发现真实驱动，并重新定性商业模式

- **方法要点**：公司修改收入分类口径（按业务类型/融资属性重新分类）时，不止做映射，还要判断变更目的、利用新口径发现真正驱动业绩的科目，并据此重新定性商业模式，提示后续跟踪重点。
- **操作步骤 / 拆分口径**：
  1. 列出新旧口径对照（如 交易型/服务型/硬件/加密货币 → 商务相关/金融相关/比特币相关），附新口径业务分类图。
  2. 判断变更目的：例如把金融借贷收入从笼统的服务型收入中剥离、独立披露，引导市场跟踪主增长方向。
  3. 利用新口径发现真实驱动（金融贷款是业绩改善的核心）。
  4. 据此重新定性商业模式：从轻资产佣金变现，转为需要考虑资产负债与坏账率的中资产模式；提示后续跟踪重点（如信贷规模、坏账率）。
  5. 把历史数据按新口径回溯，保证可比。
- **关键指标与数据来源**：新旧口径收入分类对照；新口径下各类收入及毛利；信贷业务相关指标。
- **判断标准**：新口径下，若改善主要来自金融/借贷类业务，则业绩质量与资产负债、坏账率挂钩，估值框架要从轻资产向中资产调整；板块不变而收入类型改变，说明公司想让市场换一种视角看增长。
- **海豚案例**：
  - Block《Block：美版支付宝暴力裁员 40%!…》（2026-02-27）与《美版支付宝 Block：增长靠信贷…》（2026-05-08）：板块仍为 Square/Cash App/其他三类，收入类型改为商务/金融/比特币三类；新口径下清晰可见 Cash App Lending 是改善的核心驱动，商业模式向中资产转变。
- **适用场景与注意事项**：适用于任何口径调整、分部重组的财报；需把历史数据按新口径回溯保证可比。

### 4.4.6 新口径可追踪性评估与替代拆分路径

- **方法要点**：口径调整后，评估公司还让我们“看得见什么、看不见什么”，对丢失的拆分能力找替代路径，而不是让分析能力无声退化。
- **操作步骤 / 拆分口径**：
  1. 画口径地图：哪些科目不变（如配送收入）、哪些合并（佣金 + 广告 → 商家服务收入）、哪些拆出（自营零售从“其他收入”拆出单独披露），历史数据同步追溯调整。
  2. 评估对分析能力的影响：①无法再用佣金与广告的增速差，去拆到家和到店；②拆出自营零售，可以更好地跟踪小象超市与将并表的叮咚买菜。
  3. 为丢失的拆分能力找替代：业绩小会信息（另发短评）、调研，以及推理法——“到家改善而合并收入持平 → 隐含到店放缓”。
  4. 图表沿用历史口径绘制，保持与旧序列衔接。
- **关键指标与数据来源**：配送收入、商家服务收入、自营零售收入、其他收入；历史重述数据；业绩小会信息。
- **判断标准**：推理法依赖对其他子业务趋势的假设，结论需注明；新口径下的合并收入与上季“旧口径加总”增速基本持平，则说明被合并的子业务之间此消彼长，可结合另一子业务的方向推断剩余一项的方向。
- **海豚案例**：
  - 美团《美团：AI 分走战火，终能回口老血了？》（2026-06-01）：26 财年起佣金 + 广告合并为“商家服务收入”，自营零售从“其他收入”拆出；新口径商家服务收入 356 亿、+0.2%，与上季“广告 + 佣金”增速基本持平，结合到家改善，推断到店环比放缓；到家与到店更难拆分，更依赖小会，可追踪小象超市；图表沿用历史口径。
  - 美团《阿里、抖音熄火？治不住美团的焦虑症》（2026-08-28）：专设“业绩口径调整”小节，重申两点影响。
- **适用场景与注意事项**：任何口径调整季都应先做口径地图；推理法依赖对其他子业务趋势的假设，结论需注明。

### 4.4.7 停止披露即信号：定性、追问与独立判断理由

- **方法要点**：公司停止或拒绝披露某个关键指标，本身就是信息，通常按负面信号处理；同时对管理层给出的理由做独立判断，评估它对估值（增长能见度）的影响，并追问替代信息。
- **操作步骤 / 拆分口径**：
  1. 把“停止披露”记为独立事项：写清楚停了什么、从哪一期开始，对后续分析有什么影响。
  2. 评估管理层的理由，给出自己的独立判断：理由是否成立（如论证该指标对商业化是否仍然重要）。
  3. 判断对估值与情绪的影响：增长能见度下降是估值压制，对资金预期是负面信号；尤其在行业逆风时不披露，情绪影响更大。
  4. 追问管理层：看电话会或后续交流是否给出明确信息；若也不给，视为“不太好”的信号。
  5. 把替代追踪方式纳入跟踪（高频 App 数据、第三方份额、收入与单价推算等，见 4.4.8）。
  6. 当管理层改为以经营利润等为指引核心时，追问利润率提升的来源：涨价/降本，还是用户扩张驱动——后者才有估值弹性；市场不希望过早进入牺牲增长保利润的阶段。
  7. 提示口径变化可能带来方向性误判（见 4.4.10）。
- **关键指标与数据来源**：被停止披露的指标；电话会纪要；第三方数据；财报后股价反应。
- **判断标准**：
  - 停止披露重要的前瞻或用户指标 → 负面信号，影响短期情绪与估值。
  - 管理层理由与商业逻辑冲突（如认为登录/未登录用户商业化差别不大，而效果广告依赖登录用户的个性化数据和画像），则不接受其理由，并自建替代追踪。
  - 推理链条：停止披露 → 为什么（往往指标在恶化或增长能见度下降）→ 对估值的压制 → 找替代指标验证。
- **海豚案例**：
  - 阿斯麦《阿斯麦 ASML：有 AI 高烧在，光刻机只是假摔？》（2026-04-15）：2026 年 Q1 首次没有在财报中披露季度订单，海豚君明确表示，如果后续交流也不给明确信息，就是“不太好”的信号，会影响短期情绪。阿斯麦（2026-07-15）：上季起不再披露订单，需要关注电话会是否披露，待电话会追问。
  - Reddit（2026-05-01）：Q3 起不再分别公布登录和未登录用户，管理层认为两者商业化差别不大；海豚君认为效果广告依赖登录用户留存的个性化数据和画像，两者区别明显，改为跟踪高频 App 数据观察美国用户增长。Reddit（2026-07-31）：重申登录用户的站内行为数据对后续 Feed 分发帮助很大。
  - 迪士尼《迪士尼：整合期波动难免，等待新成长被激活》（2026-02-03）：不再披露 Disney+ 订阅数后，增长不确定性成为估值压制，财报后股价跌 6%；同时追问管理层以经营利润为指引核心时，利润率提升靠涨价/降本还是用户扩张驱动。迪士尼（2026-08-05）：不披露用户数在行业逆风下对情绪更不利，财报前谨慎，实际流媒体表现还可以；（速读）不再披露用户数，偏负面。
  - 腾讯音乐：不再公布量价；快手：电商停报 GMV；二者均被视为对资金预期偏负面的信号（替代推算见 4.4.8）。
- **适用场景与注意事项**：适用于任何减少披露的公司；停止披露既可能因指标恶化，也可能是调整考核口径，需要两面看；独立判断理由要有商业逻辑支撑，不能只复述管理层。

### 4.4.8 停止披露后的替代指标与自建估算

- **方法要点**：指标停披后不放弃跟踪：用同一业务链上的其他披露、第三方数据、合同负债/积压订单、上下游资本开支、电话会表述等做替代，或用“总额减已知项”自建估算，并把假设说明白。
- **操作步骤 / 拆分口径**：
  1. 先指出停披对后续分析的影响，再选择替代路径。
  2. 前瞻类指标（订单、RPO、制程占比）：找同一链条上的前瞻信号作替代：RPO → ACV；订单 → 合同负债、积压订单，或下游晶圆厂资本开支加电话会表述；制程占比 → 8 寸/12 寸占比。
  3. 业务线停披（如 HBM、VMware）：结合行业与公司情况自建估算；子项用“合计 − 已知项”倒算（如 DRAM 总额减 HBM 得传统 DDR）。
  4. 用户与量价类停披：用收入与用户净增反推人均指标方向（通信收入同比 + 用户环比净增 → ARPU 方向），或用“收入 ÷ 假设 ARPPU”倒推付费用户，用“电商收入 ÷ 佣金率”推 GMV，用涨价幅度 vs 收入增速、第三方份额（Nielsen）、第三方下载量等推断。
  5. 获取渠道：电话会、业绩小会、调研；对话中追问管理层。
  6. 图表仍按历史口径绘制；估算要说明假设来源，并在后续季度根据管理层口径校准；结论标注“估算/仅供参考”。
- **关键指标与数据来源**：被停止披露的指标；替代指标（合同负债、积压订单、ACV、8 寸/12 寸占比、下游资本开支）；自建估算值；第三方数据（QuestMobile、Nielsen、下载量）；电话会、小会。
- **判断标准**：
  - 前瞻指标的替代口径只能近似：合同负债、积压订单代表已确认部分，不能完全等同新签订单。
  - 通信类 ARPU 的反推：用户仍在净增而通信收入同比为负 → 单用户资费仍在下滑；增值税等口径因素要估算并剔除后再看趋势。
  - 估算值须与后续披露或管理层口径交叉验证，偏离时及时校准。
- **海豚案例**：
  - 变体 A：前瞻指标（订单、RPO、制程占比）停披后的替代
    - 阿斯麦（2026-04-15）：首次未披露订单，上季度末剩余订单 388 亿欧元作为替代。阿斯麦《阿斯麦：光刻机产能也紧俏了…》（2026-10-14）：不再披露订单，转看非流动合同负债 93 亿；同时用合同负债和积压订单作为替代前瞻指标，并可用下游晶圆厂资本开支加电话会表述来替代订单信号。
    - ARM（2026-07-30）：本季起不再披露 RPO，用 ACV 替代 RPO。
    - 中芯（2026-02-10）：2022Q1 起不再披露制程节点占比，用 8 寸/12 寸占比替代。
  - 变体 B：业务线停披后的自建估算
    - 美光《美光 MU：AI 带动存储“疯涨”…》（2026-03-19）：宣布不再单独披露 HBM 季度收入，海豚君结合行业与公司情况自建估算（HBM 约 27 亿，环增约 5 亿），用 DRAM 总额减去 HBM 得到传统 DDR（约 160 亿，环比 80%+）。
    - 博通（2026-03-05）：不再单独披露 VMware，海豚君自行估算后继续跟踪。
  - 变体 C：用户、量价、ARPU 停披后的推算
    - 中国移动（2026-04-20）：Q1 起不再披露单用户资费；移动用户 10.09 亿，环增 376 万，而通讯业务同比 -1.1%，推断 ARPU 仍在下滑，延续降价引流。中国移动（2026-08-14）：移动用户 10.11 亿，环增 212 万；海豚君估算增值税对资费影响约 3%，剔除后资费下滑仍在提速。
    - 腾讯音乐（2026-05-12）：不再披露付费用户，海豚君估算净增 100 万、ARPPU 11.7 元（推算方法见 4.6.11）。
    - 快手（2026-05-27）：不再披露 GMV，用电商收入和佣金率推算增速接近 10%。
    - 迪士尼（2026-02-03、2026-08-05）：不再披露 Disney+ 订阅数，用涨价幅度 vs 收入增速、Nielsen 份额、第三方下载量推断，同时追问利润率驱动。
    - 美团（2026-06-01）：到家与到店更难拆分，转向业绩小会（见 4.4.6）。
  - 英伟达：只披露数据中心和边缘计算两项；Marvell：业务从 5 项并为 2 项，对应的旧口径子项同样需要估算（口径动机见 4.4.4）。
- **适用场景与注意事项**：适用于披露变化的季度；需要维护历史口径数据库；估算要说明假设来源并在后续季度校准；通过倒算补齐子项的通用做法见 4.6.6。

### 4.4.9 用户口径扩大与管理层 KPI/考核口径切换

- **方法要点**：两类“口径漂移”：一是用户或规模指标的统计范围扩大，数字变好看但不可比；二是管理层改变自己的考核指标，指标切换往往意味着商业模式和估值方法的切换，也可能是在回避旧指标的恶化。
- **操作步骤 / 拆分口径**：
  - 变体 A：用户口径扩大
    1. 明确写出新旧口径的统计范围差异（如有线宽带数 → 宽带联网数，含家庭宽带、企业宽带、互联网专线、数据专线）。
    2. 明确提示口径扩大带来的不可比，以及可能的“美化效应”。
    3. 在饱和市场中，用户数仍环比净增，可作为竞争力的证据。
  - 变体 B：管理层 KPI 切换
    1. 留意管理层是否放弃传统指标、改用新的 KPI，并把新 KPI 记成后续要跟踪的指标。
    2. 追问切换原因，两面看：商业模式变了，还是旧指标在恶化。
    3. 为新 KPI 建立拆分：如每英里成本、资产利用率（每周使用小时）、单车 COGS。
- **关键指标与数据来源**：移动用户数及环比净增、宽带联网数、通讯服务收入、隐含 ARPU；每英里成本（Cost per mile）、资产利用率（周使用小时）、单车 COGS；电话会纪要。
- **判断标准**：
  - 口径扩大后增长的部分不能算内生增长；与历史比较时必须注明。
  - KPI 切换：传统指标（单车毛利）不再适用，意味着估值方法也要换（如按运营里程成本、利用率）；若只是回避旧指标的恶化，则偏负面。
- **海豚案例**：
  - 中国移动（2026-04-20）：宽带联网数 3.33 亿，环增 390 万；口径从有线宽带改为宽带联网数；移动用户 10.09 亿，环增 376 万（ARPU 推算见 4.4.8）。中国移动（2026-08-14）：宽带联网 3.37 亿，环增 390 万；移动用户 10.11 亿，环增 212 万。
  - 特斯拉（电话会纪要，2026-01-29）：管理层表示传统“单车销售毛利”框架不再适用，核心考核改为全口径自动驾驶每英里成本，资产利用率（每周使用小时）成为盈利关键；对“现有车型是否仍有独立毛利率目标”，管理层回答重心在单车 COGS 的极致管控，自动驾驶车型核心看每英里成本；私家车每周使用约 10-11 小时，自动驾驶车辆预计 50-60 小时，利用率高约 5 倍，车辆设计向商用卡车级耐用性靠拢；全球 90% 以上的里程只载 1-2 人，所以 CyberCab 采用双座设计。
- **适用场景与注意事项**：变体 A 通用，尤其适用于公司在指标恶化时调整披露的情形；变体 B 适用于商业模式转型期的公司。

### 4.4.10 分部重分类、出表、并表与内部划转对可比增速及方向判断的影响

- **方法要点**：口径变化会让增速“凭空”改变，尤其当业务处于零增长附近时，重分类可能直接改变“增长还是下滑”的方向判断；出表、并表、收入确认改为净额、补贴冲减收入、集团内部划转等，也要还原成可比口径再判断趋势。
- **操作步骤 / 拆分口径**：
  1. 识别口径事件：出表、并表、业务重分类、收入确认改为净额、补贴冲减收入、指标停止披露、集团内部业务划转。
  2. 判断受影响业务是否处于增长与下滑的临界线（如 +1% 左右），若是，提示方向性误判风险。
  3. 分部重分类时，写明调整内容，并确认同比是否还可比。
  4. 还原成可比口径：对出表业务做可比口径下的同比；对内部划转，把转入转出规模还原。
  5. 按可比口径重新看趋势；仍无法还原时，明确提示“不可比/可能造成方向性偏差”。
  6. 同时提示停止披露（用户数、量价、GMV）对资金预期的负面信号（见 4.4.7）。
- **关键指标与数据来源**：可比增速；出表前后收入确认方式；分部重组明细；内部划转规模；全球同店、国际同店等被出表影响的指标。
- **判断标准**：
  - 口径变化若改变增速的符号或使其落在临界线上下，趋势判断必须按可比口径重做。
  - 出表使低价区域退出口径时，剩余业务的同店、均价等指标会被动改善，不能全部当作经营改善。
  - 补贴被确认为收入减项时，表观增速会被压低；换算为可比口径后才反映真实趋势。
  - 集团内部划转不是真实增长，“本质属于集团内部的利益再分配”。
- **海豚案例**：
  - Spotify（2026-08-04）：今年起广告收入剔除与广告非直接相关的部分（如与播客订阅捆绑的收入），挪到订阅；Q2 广告 4.5 亿、仅 +1%，正处于增长与下滑的临界线，口径变化可能改变方向判断；广告技术栈历时一年半基本建成，预计下半年可逐步达到双位数增长。
  - 星巴克（2026-07-30）：中国业务出表，营收 -1.4%，但全球同店 +7.9%；国际同店变好部分源于低价中国市场被剔出口径。
  - 阿里（2026-08-20）：分部大改，CMR 因补贴确认为收入减项为 -7.5%，可比约 +1%（会计确认口径见 4.3）。

- **适用场景与注意事项**：适用于重组、出表、改披露的公司；还原需要核对公司重述数据，无法还原时要明确提示不可比。

## 4.5 一次性与非经常事项剔除

> 本节导读：利润、毛利率、费用率或增速一旦大幅偏离预期、历史或基数，第一反应不是下趋势结论，而是先问“有没有一次性项目”。本节把库存减值或释放、资产减值及冲回、罚款与和解、裁员重组、收购整合与交易费用、一次性税项、额外周、一次性大单、保修准备金冲回、关税退税、一次性补贴、战略合作毛利增厚等扰动逐类拆开，给出海豚君的剔除口径，并用“极端假设法”做边界测试、用“三层分析”看资产处置。它与 4.4（口径变化）、4.3（会计政策）一起构成“可比口径”的清洗；经常性的非经营损益（投资收益、利息、汇兑等的利润质量）见 8.8，剔除后的指标再进入第 7、8 章的毛利率与经营利润归因。

### 4.5.1 一次性事项排查与剔除总流程（含“真一次性 vs 经常性一次性”判别）

- **方法要点**：利润大超、大 miss，或毛利率、费用率、增速出现异常变动时，先排查一次性或非经营因素，量化并剔除，再用“核心/调整后口径”评价经营面并与预期比较；同时判别“真一次性”和“经常性一次性”，后者不应剔除。
- **操作步骤 / 拆分口径**：
  1. 触发：利润大幅偏离预期；毛利率或费用率异常环比；同比增速出现“虚高/虚低”。
  2. 逐项排查：①持仓的公允价值变动与投资损益；②非经营性亏损；③商誉或资产减值（含冲回）；④裁员补偿与坏账计提；⑤负债计提变动等一次性费用；⑥并购整合费用与交易费；⑦补缴税款与税项变化；以及罚款、诉讼费、关店收益、关税退税等。
  3. 处理四步：识别事项 → 标注金额与来源（原始公告、财报附注、10-Q、电话会）→ 从费用或利润中剔除 → 用剔除后的核心口径判断趋势或与预期比较。
  4. 口径选择：公司更看重的调整后口径（adj. EBITDA、Non-GAAP）是主要依据，且剔除口径要与管理层或市场惯例一致。
  5. 判断市场是否会“容忍”：例如上行周期中加大的资产减值，市场通常会容忍；事件若已提前公告，市场已有预期，则不构成“爆雷”。
  6. 判别真假一次性：年年重组、长期频繁出现的同类项目、公司把经常性费用包装成一次性的，应视为经营性成本，不应剔除。
  7. 把一次性事件解读为前瞻信号并跨期验证（见 4.5.18）。
- **关键指标与数据来源**：GAAP vs 调整后经营利润；其他收益；投资损益；一次性计提；剔除后的毛利率、费用率、经营利润；原始公告、附注、10-Q、电话会。
- **判断标准**：
  - 先看剔除后的结果，再判断 beat/miss：一次性项目导致的 miss 不改变判断，一次性项目带来的 beat 不算质量。
  - 剔除后若仍符合预期或小超预期，说明没有“爆雷”；若剔除后落在盈亏平衡边界，头条数字的含金量就要打折。
  - 推理链条：数字异常 → 逐项排查一次性 → 量化剔除 → 回到核心口径比预期 → 判断市场是否容忍 → 看是否会重复出现。
- **海豚案例**：
  - 变体 A：利润大幅偏离预期时的快速排查（速读）
    - 网易（2026-02-11）：经调整利润 -27%，主要来自拼多多持仓损益，投资亏损 17 亿（比上年多亏 12 亿）。
    - Uber（2026-02-04）：约 16 亿非经营性亏损使 GAAP 净利不足 3 亿。
    - 可口可乐（2026-02-10）：BODYARMOR 计提 9.6 亿美元减值，剔除后费用率小幅下降。
    - 百度（2026-02-26）：近 7 亿裁员补偿加坏账计提，GAAP 经营利润低于预期，剔除后小超预期。
    - Costco（2026-03-06）：费用率 +13bps 中，一次性负债计提占 6bps、总部成本占 4bps。
    - 中国移动（2026-03-26）：净利下滑来自其他收益，经营性利润 +8%。
    - 迪士尼（2026-02-02）：FCF 为负，原因是补缴税款加资本投入。
    - 宁德时代：加大资产减值导致单 Wh 净利下滑，但“上行周期中市场会容忍”。
  - 变体 B：剔除一次性损益，还原核心/调整后利润（速读）
    - Uber（2026-08-05）：GAAP 经营利润少于预期 1.4 亿，实际有 1.1 亿一次性计提，调整后略好于预期。
    - 美团（2026-08-28）：关闭优选等确认 30 多亿其他收益，剔除后在盈亏边缘。
    - 携程（2026-09-16）：52 亿罚款导致经营利润转负，调整后 44 亿，同比 -6.5%。
    - 网易（2026-08-20）：持仓阿里、拼多多带来近 30 亿投资亏损，核心经营利润 +33%。
    - Salesforce（2026-08-27）：26 亿投资收益。BOSS 直聘（2026-08-25）：智谱上市投资收益。
    - Meta（2026-07-30）：24 亿诉讼费，剔除后预期差缩小。
    - 苹果（2026-07-31）：关税退税约 2-2.5pct，剔除后毛利率约 48%。
  - 变体 C：费用端与非经营端事项的处理步骤，见 4.5.8 与 4.5.12（应用材料、英特尔）。
- **适用场景与注意事项**：所有公司、所有财报点评都适用；中概互联网普遍有投资损益。要找原始公告或附注确认事项性质；警惕公司每年都有“一次性”项目（实为常态成本）；各类具体事项的剔除细节见 4.5.2～4.5.17。

### 4.5.2 剔除一次性/特殊区域收入与大额许可证，还原核心产品真实增量

- **方法要点**：当季收入里若含不可持续的特殊项（如受出口管制产品对华的一次性销售、一次性大额许可证收入），先估出细分产品收入，再减掉特殊项，得到核心产品的真实环比增量；下季指引里的同类项也同样剔除，用来推算下季核心产品增量。
- **操作步骤 / 拆分口径**：
  1. 估算细分产品（如 AI GPU）总收入。
  2. 减去一次性项（上季为 0、本季出现；公司通常披露金额）。
  3. 与上季同口径比较，得到核心产品的真实环比增量。
  4. 下季指引里若含同类项，同样剔除，推算下季核心产品增量。
  5. 判断新产品放量是否达到预期。
  6. 一次性大额许可证收入：单季峰值不代表趋势，剔除后再看许可证收入是否仍在上升。
- **关键指标与数据来源**：特殊收入金额（公司披露）；估算的细分产品收入；同口径环比增量；指引中的同类项。
- **判断标准**：
  - 剔除特殊项后，核心产品增量若连续两季放缓，说明产品力存疑，市场会打问号。
  - 一次性大额收入只代表单季峰值；剔除后仍在上升，趋势才成立。
  - 推理链条：总增量 → 减去一次性项 → 真实增量 → 与预期放量节奏比较 → 下季指引同口径推算。
- **海豚案例**：
  - AMD《又是雷声大雨点小！AMD 何时才能硬气？》（2026-02-04）：数据中心环比增约 10 亿，其中 MI308 对华销售 3.9 亿（上季为 0）；海豚君估 AI GPU 约 24 亿，剔除后其余部分（含 MI355）约 20 亿，环比仅增 1.5 亿；下季指引含约 1 亿 MI308，推测 AI GPU 约 22 亿，剔除后 MI355 增量只有约 1 亿；连续两季环比增长放缓，因此判断市场会给 AI GPU 产品力打问号。
  - ARM《ARM：AI 红利未消，手机却成了当下羁绊？》（2026-02-05）：此前单季许可证收入 6 亿美元，其中含马来西亚政府约 2.5 亿美元的一次性确认，剔除后许可证收入仍在上升。
- **适用场景与注意事项**：适合有政策性/一次性订单、库存释放或大客户一次性采购的公司；公司不披露特殊项金额时只能估算。去年同期大项目造成的高基数还原见 3.3，剥离一次性收入后的中性收入假设估值见 12.1。

### 4.5.3 库存减值/释放与资产减值冲回：还原实际毛利率

- **方法要点**：毛利率被前期减值、已减值库存的释放或资产减值冲回扭曲时，分别算“含影响”和“剔除影响”两个毛利率，对历史序列中的减值季、释放季都做调整，再判断经营面毛利率有没有真正变化。
- **操作步骤 / 公式**：
  1. 取减值或释放金额（来自电话会、10-Q 或财报附注）。
  2. 释放季：实际毛利率 =（毛利 − 释放增厚）/ 收入。
  3. 减值季：实际毛利率 =（毛利 + 减值）/ 收入。
  4. 资产减值冲回：把冲回金额加回营业成本，得到“按原会计口径”的真实毛利率，再做环比；本季如有资产减值计提，则同样按原会计口径还原（剔除本季资产减值后得调整毛利率）。
  5. 对历史序列中的减值季、释放季同样调整，让时间序列可比。
  6. 同一处理也要用于核心经营利润，检验利润增长是否真实。
  7. 同比基数含去年同期的减值时（如出口管制库存减值），毛利率和利润的同比要剔除后再算。
  8. 与价格变化对应：面板等周期行业，调整毛利率的环比应与面板价格变化吻合。
- **关键指标与数据来源**：GAAP 毛利率；库存减值/释放金额；资产减值冲回/计提金额；调整后毛利率及同比/环比（pct）；数据来自电话会、10-Q。
- **判断标准**：
  - 剔除后毛利率同比基本持平，说明表观提升主要靠释放，不是经营改善。
  - 剔除减值后核心经营利润仍有提升，增量来自哪个业务（如服务器 CPU 回暖）要说清。
  - 周期行业的调整毛利率与价格走势一致，才能确认真实环比变化。
- **海豚案例**：
  - 变体 A：库存减值/释放
    - AMD《又是雷声大雨点小！AMD 何时才能硬气？》（2026-02-04）：GAAP 毛利率 54.3%（同比 +3.6pct），其中 MI308 库存释放增厚约 3.6 亿；剔除后实际毛利率 50.8%，同比基本持平；此前减值季毛利率一度低至 39.8%（剔除减值约 50.2%）；剔除该 3.6 亿后，核心经营利润仍有提升，增量来自服务器 CPU 回暖。
  - 变体 B：去年同期减值形成低基数
    - AMD《AMD：狂抢“AI 大单”，市场为何不领情？》（2026-08-05）：去年同期因中国管制有约 8 亿美元减值，剔除后毛利率同比约 +3.5pct，核心经营利润同比 +133%。
  - 变体 C：资产减值冲回（面板、重资产周期行业）
    - 京东方《京东方：周期太“熬人”，龙头也只赚辛苦钱？》（2026-03-31）：4Q25 报告毛利率 19.4%，剔除约 21 亿资产减值冲回后，调整后毛利率 15.1%，环比 +2pct。
    - 京东方《京东方：主动控产撞上世界杯…》（2026-04-30）：Q1 报表毛利率 15.6%，环比大幅回落，因上季资产减值冲回约 21 亿；剔除本季资产减值约 1.35 亿后，调整毛利率 15.3%，环比 +0.2pct，对应面板价格环比略升。
- **适用场景与注意事项**：适合半导体、硬件、面板、化工等存货敏感或重资产周期行业。前提是公司在电话会、10-Q 或附注中披露了减值/释放/冲回金额。

### 4.5.4 调整后毛利率：剔除收购无形资产摊销与重组费用

- **方法要点**：靠外延并购扩张的公司，GAAP 毛利率里夹着大量收购资产摊销，反映不了经营面。海豚君固定用“调整后毛利率/实际经营面毛利率”做跟踪口径，逐季比较环比变动并解释原因。
- **操作步骤 / 拆分口径**：
  1. 并列给出 GAAP 毛利率与调整后（Non-GAAP/实际经营面）毛利率。
  2. 调整项：收购无形资产摊销、重组费用等；注明各家调整项差异（如 Marvell 的调整后口径包含 SBC，主要调整折旧摊销）。
  3. 逐季比较调整后毛利率的环比变动（单位 pct）并解释原因。
  4. 跨公司比较前统一口径（是否含 SBC）。
- **关键指标与数据来源**：GAAP 毛利率；调整后毛利率；环比 pct 变动；公司 Non-GAAP 调节表。
- **判断标准**：用调整后口径判断经营面毛利率是否变化：环比只变动零点几个 pct 时基本视为持平；GAAP 口径变化若主要来自摊销变化，不代表经营面变化。
- **海豚案例**：
  - 迈威尔 Marvell《迈威尔科技 Marvell：ASIC 单卡扑空，靠互联杀回 AI！》（2026-03-06）：GAAP 51.7%，调整后 58.5%（环比 -0.5pct）；《迈威尔 Marvell：AI 推理时代，连接比算力更吃香？》（2026-05-28）：52.1%/58.3%（-0.2pct）；（2026-08-28）：53.1%/58.3%（持平）。
  - 博通（2026-03-05）：GAAP 68.1%，实际经营面 75.8%（-0.8pct）；（2026-06-04）：69.5%/76.1%（基本持平）；（2026-09-03）：GAAP 毛利率 69%，剔除收购摊销和重组费用后，实际经营面毛利率 74%，环比 -2pct。
- **适用场景与注意事项**：适合并购型半导体/软件公司（博通、Marvell、AMD-Xilinx）；各家调整项不同（是否含 SBC），横向比较前要统一口径。

### 4.5.5 剔除保修冲回、关税、补贴、战略合作、召回等一次性毛利扰动，得到核心毛利率

- **方法要点**：表观毛利率大超预期（或大幅下滑）时，海豚君逐项找出一次性因素，量化后从毛利率里剔除，得到“实际核心毛利率”，再与上季和市场预期比；结论分两层：表观超预期幅度，和剔除后是否仍超预期。
- **操作步骤 / 拆分口径**：
  1. 逐层拆：报表毛利率 → 剔除一次性项（保修准备金冲回、关税补贴/退税、汇兑收益、战略合作收入、购置税补贴、电芯计提、召回、供应商合约损失、质保金计提）得到实际毛利率 → 再看核心卖车毛利率（去碳积分、租赁）。
  2. 步骤：①识别增厚或扣减项金额；②从毛利与收入中剥离；③重算毛利率；④比较剔除前后的同比或环比变化。
  3. 分部层面同样处理（如储能剔除关税补贴；汽车销售剔除保修冲回与汇兑）。
  4. 建立“真实”系列指标：真实卖车毛利率、真实整体毛利率、真实经营利润、真实单车毛利，并用剔除后的数字作为环比基准；在历史毛利率图表下注明剔除口径，保证长期时间序列可比。
  5. 下一季做环比时，要考虑上季一次性收益的回吐（见 4.5.18）。
  6. 归属分部不明时，用极端假设法做稳健性检验（见 4.5.6）。
- **关键指标与数据来源**：报表毛利率；保修准备金冲回金额；关税相关汇兑收益、关税补贴/退税；战略合作毛利；购置税补贴；碳积分；一次性项目金额来自公司公告、附注、电话会、10-Q。
- **判断标准**：
  - 剔除后的“核心毛利率”才是与上季及预期比较的基准；结论分两层写：表观强劲，且剔除后“实际也具备一定韧性”；或表观超预期主要来自一次性。
  - 剔除一次性增厚后，同比降幅反而更小/更大，才能判断是高估还是低估了经营改善/恶化。
  - 环比的对比基准也要用剔除后的数字，避免“基数被一次性项目扭曲”。
  - 防止把重复发生的“一次性”项目当作一次性剔除，长期频繁出现的同类项目应视为经营性成本。
- **海豚案例**：
  - 变体 A：车企逐层还原
    - 特斯拉《造车罕见回血…》（2026-04-23）：汽车销售毛利率表观 19.2%，剔除保修冲回 2.3 亿和关税汇兑收益 2 亿后，核心约 17.5%（上季 17.9%），仍高于预期 14.7%-15.3%；储能毛利率表观 40%（预期 28%），剔除 2.5 亿关税补贴后约 29.2%，与上季持平；整体毛利率表观 21.1%，剔除后约 18.7%（环比 -1.4pct）。
    - 特斯拉《1Q26》（2026-04-23，速读）：报表毛利率 21.1%（预期 16.9%），剔除保修冲回 2.3 亿、关税补贴 2.5 亿、汇兑 2 亿后实际为 18.7%；卖车毛利率 19.2%，还原后约 17.5%（预期 15.3%）。
    - 特斯拉《2Q26》（2026-07-23）：卖车毛利率 16.3%，环比 -2.9pct，主因上季约 2pct 一次性收益不复存在；储能毛利率从 39.5% 降到 20.4%，含 2.4 亿计提。

  - 变体 B：战略合作毛利增厚、关税退税

### 4.5.6 极端假设法：用边界测试检验结论稳健性

- **方法要点**：一次性收益（如汇兑收益）的分部归属没有披露时，用最保守的极端假设做边界测试：假设它全部归到要检验的分部，重算关键指标；极端假设下结论仍成立，结论就稳健，真实情况只会更好。
- **操作步骤 / 拆分口径**：
  1. 取一次性收益总额与披露不完整的归属。
  2. 假设全部归入要检验的分部（如汽车销售），从该分部收入或毛利中剔除。
  3. 重算关键指标（如单车 ASP = 汽车销售收入 / 交付量，或分部毛利率）。
  4. 看极端假设下指标是否仍持平或改善；若是，则结论稳健，且真实情况（收益在各业务间分摊）只会更好。
- **关键指标与数据来源**：一次性收益金额；分部收入；交付量；调整后 ASP；核心毛利率。
- **判断标准**：极端假设下结论仍成立 → 稳健；若极端假设下结论反转，则必须说明结论不稳健，需要管理层给出归属。
- **海豚案例**：
  - 特斯拉《造车罕见回血…》（2026-04-23）：把全部 9 亿美元汇兑收益都归到汽车销售，调整后单车收入仍与上季度约 4.11 万美元持平，所以剔除汇兑后的真实单车收入环比增幅更高，ASP 止跌回升的结论成立；同篇把 2 亿关税汇兑收益“极端假设下全部确认在汽车业务”，用来算核心毛利率。
- **适用场景与注意事项**：适用于信息披露不完整时做稳健性检验，通用；要明确写明这是“极端假设”，避免被误读为实际归属。

### 4.5.7 GAAP 与调整后口径的差额归因（摊销、罚款等）

- **方法要点**：GAAP 利润与预期差距很大，而调整后口径却符合预期时，要找出差额对应的一次性项目并归因，既解释异常的费用科目，也以调整后口径与市场预期比较，判断有没有“爆雷”。
- **操作步骤 / 拆分口径**：
  1. 比较 GAAP 经营利润与一致预期，再比较调整后经营利润与一致预期。
  2. 把两者差额逐项归因到一次性项目（无形资产摊销、监管罚款等）。
  3. 用该项目解释异常走高的费用科目（如研发费用）；罚款计在管理费用里，费用分项也要剔除罚款。
  4. 确认该事件是否已提前公告、市场是否已有预期。
  5. 用剔除一次性项目并加回 SBC 的调整后经营利润与市场预期对比。
  6. 看调整后利润的同比，识别排除一次性影响后的真实压力。
- **关键指标与数据来源**：GAAP 经营利润；调整后经营利润；一次性摊销金额；罚款金额；SBC；研发/管理费用；市场预期。
- **判断标准**：
  - 差额基本等于一次性项目 → 异常来自一次性，调整后与预期大差不差则无“爆雷”。
  - 调整后利润与预期一致，但同比下滑，说明剔除一次性之后仍有真实压力（如变现手段调整导致利润负增长）。
- **海豚案例**：
  - 京东（2026-03-05）：GAAP 经营亏损 58.5 亿，比预期多近 17 亿；调整后亏损约 31 亿，与预期大差不差；差额“基本就是上述一次性资产摊销的影响”，研发费用异常走高也和约 16 亿无形资产摊销有关。
  - 携程《监管铁拳落定，携程能“轻装上阵”了吗？》（2026-09-16）：2Q26 GAAP 经营亏损近 15 亿，原因是 7 月底已宣布的 52 亿罚款；剔除罚款并加回 SBC 后，调整后经营利润近 44 亿，与市场预期一致；但同比下滑约 6.5%，说明国内变现调整的压力不小；剔除罚款后管理费用 +5%。
- **适用场景与注意事项**：通用方法；要区分真正的一次性项目和反复出现的“一次性”项目。

### 4.5.8 费用侧一次性项目剔除：罚款、和解、诉讼、交易/IPO 费用、集中结算与补贴

- **方法要点**：费用或费用率异常环比或同比时，先找一次性或集中性项目（监管罚款与和解费、诉讼费、出售业务的交易费、IPO 专业费用、集中结算的补贴、政府补贴冲减开支），指出来源和金额，剔除后再看核心费用率，避免把一次性波动误读为趋势或“费用失控”。
- **操作步骤 / 拆分口径**：
  1. 识别事项，标注金额与来源（原始公告或附注确认事项性质）。
  2. 从费用或利润中剔除，用剔除后的核心口径判断趋势；一次性费用在图表中单独标出。
  3. 若上季一次性费用造成基数偏高，本季回落属于正常化，不是改善。
  4. 剔除后，判断利润率是否仍创新高：创新高才算真正的经营杠杆，否则只是会计噪音。
  5. 给出调整后口径（如核心经营利润率调回 IPO 费用后的数值）。
- **关键指标与数据来源**：销售/管理费用率；核心经营利润率（调整前/后）；一次性费用金额；经营费用同比。
- **判断标准**：剔除一次性后费用率恢复常态 → 费用没有失控；剔除后增速仍高 → 才是真实的费用压力。
- **海豚案例**：
  - 变体 A：监管罚款、和解、诉讼
    - 应用材料（2026-02-13）：经营费用 16 亿，同比 +21%，其中 2.5 亿是与 BIS 的和解费用；剔除后核心经营费用率 19.1%。应用材料《Capex 狂飙在路上，应用材料 AMAT 能接住“泼天富贵”吗？》（2026-05-15）：上季 2.5 亿美元 BIS 和解费用导致费用大增，本季回落属于正常化，经营费用 14.2 亿，同比 +8%。
    - 阿里《阿里狂投》（2026-08-21）：管理费用确认了约 5.5 亿欧元罚款，剔除后增长约 17%。
    - Meta（2026-07-30）：Q2 总运营支出 +65%，含 24 亿诉讼费和 12 亿裁员补偿，剔除后利润率仍环比走低。
    - 美团《美团：AI 分走战火，终能回口老血了？》（2026-06-01）：未分配亏损 23 亿含市场监管总局罚款约 7.5 亿。
    - Roblox《产品小周期尾声遭遇监管连环杀》（2026-05-01）：Q1 多笔合规和解费用 5700 万美元，剔除合规费用后利润率 22%。
  - 变体 B：交易费用、IPO 专业费用
    - Applovin（2026-02-12）：管理费用含出售 1P 游戏应用的交易费用，剔除后同比下滑。
    - 鸣鸣很忙《小心拓品类，零食小而美可以有？》（2026-04-01）：管理费用因 IPO 专业费用阶段性走高，核心经营利润率 5.2%，调回后 5.3%。
  - 变体 C：集中结算的补贴与采购
    - 贵州茅台（2026-04-17）：4Q25 集中结算第三代文化体验馆装修补贴和设备采购费，加上地推/品鉴会频率提高，销售费用率 +3.9pct 至 6.7%。
  - 变体 D：政府补贴冲减经营开支
    - 中芯（2026-02-10）：经营开支 1.8 亿受政府补贴增加影响，费用率处于 7.2% 的低位。
  - 分项里的专业服务费、绩效奖励等特定费用剔除，见 4.5.14（Monster）；裁员补偿与整合费，见 4.5.9。
- **适用场景与注意事项**：通用。需警惕公司每年都有一次性项目（实为常态成本）；剔除口径要与管理层或市场惯例一致；费用同比高增也可能来自上年异常低基数（见 4.5.10），投入方向的分项拆解见 8.4。

### 4.5.9 裁员重组与并购整合费用剔除：还原常规费用、验证裁员真实性

- **方法要点**：GAAP 利润被裁员补偿、重组、收购整合等一次性费用扭曲时，量化并剔除，只看“销售、研发、管理”三项常规经营性支出，用调整后口径与指引、预期对比，判断真实利润释放；同时验证裁员是否真实，并把一次性事件当作后续费用下降的前瞻信号。
- **操作步骤 / 拆分口径**：
  1. 量化一次性重组/遣散费用、收购整合费用；从总费用中剔除。
  2. 只看三项常规支出（销售、研发、管理）并逐项看增速；非经营性费用（无形资产摊销、重组）单独看。
  3. 去年同期的重组费用会压低本期同比，要一并剔除后比较。
  4. 用调整后经营利润/EBITDA 与公司指引、市场预期对比。
  5. 提示调整项的方向：重组费压低当期，退税抬高当期，下季会回落。
  6. 验证裁员真实性：把员工数拆成内生与并购带来的部分，判断净裁员幅度。
  7. 下一季验证费用率是否按预期下降（见 4.5.18）。
- **关键指标与数据来源**：一次性重组/遣散费用；收购整合费用；GAAP vs 调整后经营利润/EBITDA；员工数（内生/并购）；三项常规费用增速；营销费用增速。
- **判断标准**：
  - 剔除后调整后经营利润超预期/高于指引，才算真实超预期。
  - 剔除裁员补偿后核心经营利润仅刚刚持平，则裁员的利润释放尚未体现。
  - 三项常规支出增速显著低于预期，才是真实的降本增效。
- **海豚案例**：
  - 百度《百度：广告根基已废，昆仑芯成“救命草”？》（2026-02-26）：GAAP 经营利润低于预期，因近 7 亿裁员补偿 + 坏账，剔除后 Non-GAAP 经营利润 28.4 亿，超一致预期 25.4 亿；百度《百度：其他没指望，全靠昆仑芯》（2026-05-18）：Q1 经营费用 -10%，占收入比 45% → 31%，验证裁员效果。
  - 甲骨文（2026-06-11）：整体费用 +5.4%，高于预期 1.7%，但含约 8 亿重组费用；三项常规支出同比 -5.6%，比预期低 7pct，营销费用下滑超 10%；调整后经营利润 86 亿，+22%。甲骨文（2026-03-11）：非经营性费用走低，经营 + 非经营费用合计仅 +1%。甲骨文（2026-09-11）：经营性 Opex -7%，叠加去年同期重组费用，整体 Opex 同比降超 15%。
  - Block《美版支付宝 Block：增长靠信贷…》（2026-05-08）：确认约 8.5 亿一次性组织架构调整费用（裁员 40%），合计费用 +57% 至 30.8 亿，GAAP 经营利润转负；剔除后调整后经营利润 7.3 亿，高于指引 6 亿。
  - Coinbase《Coinbase：旱地已久…》（2026-05-08）：裁员 14%（700 人），遣散约 0.5 亿；Coinbase《Coinbase：币价退潮再探底…》（2026-07-31）：0.5 亿补偿加回后核心经营利润才刚刚持平。
  - Robinhood《Robinhood：美股散户罗宾汉…》（2026-08-11）：裁员 10%，期末 2998 人，剔除并购约 450 人后内生约 2500 人，重组支出约 2300 万；剔除后调整后 EBITDA 7.41 亿，利润率 57%。
  - 星巴克《星巴克：走出至暗时刻…》（2026-07-30）：剔除重组等一次性费用后，北美经营利润率 13.3% → 16.0%；渠道发展利润率受关税退税抬高，预计 Q4 回落至 45%-48%。
  - 蜜雪《蜜雪集团：幸运咖逆袭…》（2026-03-24）：收购福鹿家的一次性整合费用拉高管理费用。
  - Meta（2026-07-30）：12 亿裁员补偿的处理见 4.5.8。
- **适用场景与注意事项**：适用于处于重组期的公司和所有存在重大非经常性项目的财报；防止公司把经常性费用包装成一次性；并购带来的员工数要拆出，否则裁员幅度会被误判。并购一次性交易成本与项目阶段性刚性投入的费用拆分见 8.4。

### 4.5.10 去年同期一次性与异常低基数对同比的扭曲

- **方法要点**：同比增速不只受本期一次性项影响，还会被基数里的一次性项或异常低基数扭曲：去年同期的一次性费用会压低本期同比，去年异常低的费用（反腐期、无新品期）会让本期同比“虚高”。先还原基数，再下“费用失控”或“费用节约”的结论。
- **操作步骤 / 拆分口径**：
  1. 同比增速异常（异常低或异常高）时，先查去年同期是否有一次性法律费用、减值、重组，或营销等费用处于异常低位。
  2. 还原基数：剔除去年同期一次性项后，重算本期费用同比增速（可比增速 = 本期费用 /（去年同期费用 − 去年同期一次性）− 1）。
  3. 对分项也要分别看：被一次性压低的科目与其余科目增速分开呈现，避免平均掉真实信号。
  4. 对异常低基数引起的高增，指出基数原因，不将其解读为费用失控。
  5. 剔除后重算利润率，再判断利润率趋势。
- **关键指标与数据来源**：一次性费用金额；调整后费用增速；调整后利润率；上年同期基数及其成因。
- **判断标准**：
  - 剔除去年同期一次性项后增速反而明显更高，说明真实费用增速被掩盖。
  - 同比高增源于异常低基数，则不代表费用失控；剔除异常基数后增速回归常态才是判断依据。
- **海豚案例**：
  - Uber（2026-02-05）：总费用乍看同比 -1%，但去年同期管理费用含 4.6 亿一次性法律费用（使管理费看似 -34%），剔除后费用增速仍有 12%；运营支持、营销、研发三费增 11-13%，明显高于此前中低个位数的增速。
  - 网易《猪厂还得熬》（2026-02-11）：销售费用同比高增，原因是前一年反腐叠加无新品，基数异常低。
  - Mercado（2026-02-25）：费用 +50%，部分因去年基数低。
  - AMD 与甲骨文同类用法：AMD 去年同期减值形成的低基数，见 4.5.3；甲骨文去年同期重组费用压低同比，见 4.5.9。
- **适用场景与注意事项**：通用；需区分一次性基数和公司惯用的“经常性一次性”。去年同期大项目形成的高基数的收入还原，见 3.3。

### 4.5.11 额外周（第 53 周）：剔除与不剔除两种口径并列

- **方法要点**：财年多出的第 53 周会抬高当期收入、利润和 EPS；点评中同时给出“剔除额外周”和“不剔除”两种口径的增长，避免读者被表观增速误导。
- **操作步骤 / 拆分口径**：
  1. 确认财年是否有第 53 周。
  2. 分别计算剔除与不剔除额外周的指引增速（EPS、收入）。
  3. 以剔除口径判断可比趋势，同时保留不剔除口径对应公司披露的数字。
- **关键指标与数据来源**：全年调整后 EPS 增长指引（剔除/不剔除第 53 周）；收入。
- **判断标准**：剔除后的增速更接近真实经营趋势；两者差异即额外周的贡献。
- **海豚案例**：
  - 迪士尼《迪士尼：新官首秀不俗》（2026-05-06）：全年调整后 EPS 增长指引约 12%（剔除第 53 周），不剔除则为 16%。
- **适用场景与注意事项**：适用于 52/53 周财年的公司；日历效应的更一般校正见 3.4。

### 4.5.12 非经营收益与利润 beat 含金量检验：金融资产重估、业务关停收益、公允价值变动、一次性 SBC

- **方法要点**：利润超预期时，先看“其他收益”等非经营项目是否异常，识别来源并剔除，得到真实经营利润；若剔除后落在盈亏平衡边界，头条超预期要定性为“含金量没有乍看那么高”。同时检查一次性收益如何摊入分部，避免误读为分部减亏；净利润异常波动若来自公允价值变动，同样与经营无关。
- **操作步骤 / 拆分口径**：
  1. 取“其他收益（净额）”“金融资产公允价值变动”“投资收益”，与该公司历史常规水平对比（如美团该项历史仅几亿到十几亿，本季约 35 亿）。
  2. 识别来源：关停业务收益、投资收益、金融资产公允价值、公允价值计量的托管股、被投资产估值提升引发的员工股权激励等。
  3. 剔除后得到真实经营利润，与一致预期比较。
  4. 检查一次性收益如何摊入分部（新业务/未分配项），避免把“被扰动”的分部收窄误读为真实减亏。
  5. 公允价值变动造成的净利润大幅波动，直接标注“与经营无关”；一次性 SBC 加回后重新判断 beat/miss。
- **关键指标与数据来源**：其他收益净额；金融资产公允价值变动；历史常规水平；分部（新业务/未分配）亏损；一次性 SBC。
- **判断标准**：
  - 剔除后若在盈亏平衡边界，则头条超预期含金量打折。
  - 分部亏损的“收窄”若主要来自一次性确认，则不代表经营改善。
  - 加回一次性 SBC 后若反超预期，说明表观 miss 来自一次性。
- **海豚案例**：
  - 美团《阿里、抖音熄火？治不住美团的焦虑症》（2026-08-28）：集团经营利润约 27 亿 vs 彭博预期亏 8 亿，但含约 35 亿关停优选等收益，剔除后仍在盈亏平衡边界；新业务亏 17 亿、未分配亏 12.4 亿的收窄也受其扰动。
  - 美团《三山压顶》（2026-03-26）：未分配亏损看似收窄，实为确认约 22 亿金融资产重估。
  - 英特尔《英特尔：CPU 涨价救场，翻身还得看代工？》（2026-07-24）：Q2 净亏 110 亿，主要受公允价值变动影响（2025 年 8 月美国商务部提前拨款约 57 亿美元，部分股票托管、按公允价值计量，来自 CHIPS 法案 Secure Enclave 协议下托管股的公允价值变动），与经营无关。
  - 谷歌（2026-02-05）：Q4 经营利润 359 亿，含 21 亿 Waymo 估值提升后的员工激励（Waymo 获 160 亿融资、估值约 1260 亿），加回后 380 亿，反超预期。
  - 同类速读的投资损益案例见 4.5.1（网易、Salesforce、BOSS 直聘等）。
- **适用场景与注意事项**：持有大量投资或金融资产的平台型公司尤其适用；经常性非经营损益的利润质量判断见 8.8。

### 4.5.13 一次性税项、税费跨期、违约金与补缴税款：区分时间迁移与永久性影响

- **方法要点**：净利润增速远高于经营利润，或利润/现金流受税务因素影响时，识别税收政策变化导致的计提拨回、税费补缴的时间迁移、收购违约金、补缴税款等一次性项，剔除或加回后重新判断 beat/miss、净利润同比以及年度指引含义。
- **操作步骤 / 拆分口径**：
  1. 净利润增速 ≫ 经营利润增速时，查找一次性税项（税法变化带来的计提拨回、递延税调整）。
  2. 剔除后再算净利润同比（调整后净利润 = 净利润 − 一次性税项）。
  3. 税费补缴时间迁移（前移/后移）会影响跨期利润：区分“只是时间迁移”还是“永久性影响”，据此调整本季与全年预期。
  4. 收购违约金：计入其他收益，不影响经营利润（OP），但会抬高 FCF 指引且需交税。
  5. 补缴税款会冲击经营现金流（OCF）和 FCF，要单独标注。
- **关键指标与数据来源**：一次性税项；调整后净利润；税费补缴金额与时点；违约金；调整后 OP/FCF。
- **判断标准**：
  - 时间迁移 → 本季超预期而下季/全年低于预期，要同时调整两期；永久性影响才改变全年中枢。
  - 违约金抬高 FCF 目标属于一次性，不代表经营现金流中枢上移。
- **海豚案例**：
  - Meta（2026-04-30）：Q1 经营利润 229 亿、利润率 41%；净利润增长较多，是因为 2 月税收政策变化带来 80 亿税收计提拨回，剔除后为 188 亿，同比 +13%。
  - 奈飞（2026-01-21）：剩余不到 2 亿巴西税费延至 26 年补缴 → Q4 超预期、26 年低于预期。
  - 奈飞（2026-04-17）：28 亿 WBD 违约金计入其他收益，FCF 目标从 110 亿上调至 125 亿。
  - 迪士尼（2026-02-03）：支付 2025 及部分 2024 财年补缴税款，拖累现金流（同类速读见 4.5.1：迪士尼 2026-02-02 FCF 为负，原因是补缴税款加资本投入）。
- **适用场景与注意事项**：通用；遇到税法变化、递延税调整、跨期补缴的公司尤其适用；关键是区分时间迁移与永久性影响。

### 4.5.14 退税、减值与计提的综合剔除：还原经营利润增速、利润率与真实经营杠杆

- **方法要点**：先识别报表利润里的一次性项目（关税退税净收益、商誉减值、商标减值、负债计提变化、专业服务费与绩效奖励等特定费用），估算金额，再算剔除后的经营利润增速和利润率，回答“利润率到底是改善还是持平”“经营杠杆是否仍在释放”。
- **操作步骤 / 拆分口径**：
  1. 识别一次性项目并估算金额；披露不完整时，从费用的异常跳升倒推减值金额（管理费用 5.9 亿 → 9.1 亿，推算约 3 亿减值）。
  2. 非现金商标/商誉减值：剔除后看可比经营利润率。
  3. 专业服务费、绩效奖励等特定费用：剔除后看经营杠杆是否仍在释放。
  4. 一次性关税退税：剔除后看经营利润增速是否重新快于收入，并换算为占年销售额的比例（如 29 亿美元，约美国年销售额 0.5%）。
  5. 费用率里的一次性 bps：把一次性负债计提等占比单独列出（如费用率 +13bps 中，一次性占 6bps）。
  6. 结论：一次性项目导致的 miss 不改判断；一次性带来的 beat 不算质量。
- **关键指标与数据来源**：一次性项目金额；剔除后经营利润增速；剔除后经营利润率；可比经营利润率；费用率中的一次性 bps；退税占年销售额比例。
- **判断标准**：
  - 剔除后增速和利润率才是趋势判断依据，海豚君倾向用剔除后的口径判断趋势。
  - 剔除后经营利润仍快于收入，经营杠杆才算真实；若超预期部分基本来自退税，则判定为一次性带来的 beat，不算质量。
- **海豚案例**：
  - Costco《消费分层加剧…》（2026-09-25）：经营利润 38 亿、+13.8%，含 0.9 亿关税退税一次性净收益，剔除后约 +11%，利润率基本持平。
  - Costco（2026-03-06）：费用率 +13bps 中，负债计提的一次性影响占 6bps。
  - 中国中免《海南封关顺风起…》（2026-03-31）：管理费用 5.9 亿 → 9.1 亿，推算子公司商誉减值约 3 亿；报表经营利润率 5.9%，剔除后约 8%。
  - Lululemon（2026-09-04）：剔除一次性退税后毛利率 54.9%、经营利润率 13.2%。
  - 可口可乐（2026-02-11）：剔除 BodyArmor 商标 9.6 亿美元非现金减值，可比经营利润率 +0.4pct 至 24.4%。
  - Monster《新一轮产品周期将至…》（2026-02-27）：剔除一次性费用后，经营杠杆仍在释放。
  - 沃尔玛（2026-08-21）：剔除 29 亿美元退税（约美国年销售额 0.5%）后，经营利润 +9.9%，快于营收，且判断超预期部分基本来自退税。
- **适用场景与注意事项**：所有公司都适用；尤其注意关税退税、减值、诉讼和会计估计变化；警惕公司把经常性费用也放进调整项。

### 4.5.15 资产减值拆分：存货跌价、长期资产减值与信用减值，及其竞争信号含义

- **方法要点**：减值上升或年末集中计提拖累表观净利时，不只当作一次性噪音，而是拆成存货跌价准备、长期资产减值、信用减值，判断它是一次性还是持续性、市场是否已预期，并把“因竞争加剧计提存货跌价”视为价格下行的佐证。
- **操作步骤 / 拆分口径**：
  1. 计算减值占收入比重（减值/收入）。
  2. 拆分：存货跌价准备（与原材料价格波动、备货有关）；长期资产减值（如矿山停产导致的矿产资源减值、电站资产减值）；信用减值。
  3. 判断一次性还是持续性，市场是否已有充分预期；在上行周期中通常影响不大。
  4. 存货跌价若因竞争加剧而计提，当作价格下行的佐证，用于判断行业价格周期。
  5. 与利润桥衔接：核心运营利润率 = 毛利率 − 三费率 − 资产/信用减值损失率（见 8.1）。
- **关键指标与数据来源**：资产减值总额及环比；减值/收入；存货跌价准备；长期资产减值；信用减值损失；环比增量。
- **判断标准**：
  - 减值与事件对应（如矿山停产）且市场已有预期、处于上行周期 → 影响不大。
  - 存货跌价集中计提且伴随竞争加剧 → 价格周期偏弱的信号，不能只作噪音剔除。
- **海豚案例**：
  - 宁德时代（2026-03-10）：Q4 资产减值 46 亿（环比 +30 亿），占收入约 3.3%；2025H2 存货跌价准备环比 +15 亿至 33 亿；长期资产减值环比 +18 亿至 22 亿，与 2025 年 8 月枧下窝锂矿因采矿证续期停产有关，市场已有预期，影响不大。
  - 阳光电源《平地起惊雷》（2026-04-01）：Q4 资产及信用减值约 9 亿（环比增近 6 亿），含越南电站和国内长期未开工电站减值，以及约 2 亿存货跌价准备；海豚君特别把“因竞争加剧计提存货跌价”视为价格下行的佐证。
- **适用场景与注意事项**：适用于资源、制造业、年末减值集中的 A 股公司；存货跌价对判断行业价格周期很有价值。

### 4.5.16 剔除少数股东权益，还原真实归母利润

- **方法要点**：归母净利润可能被少数股东权益扭曲；剔除少数股东权益的影响，算出调整后净利润和同比，才能看清上市公司层面的真实盈利变化。
- **操作步骤 / 拆分口径**：
  1. 取归母净利润与少数股东权益相关项目。
  2. 剔除少数股东权益的影响，得到调整后净利润，并计算同比。
  3. 与资产减值冲回的剔除（见 4.5.3）结合，得到真实毛利率和真实利润的双重还原。
- **关键指标与数据来源**：归母净利润；剔除少数股东权益影响后的净利润；报告毛利率；剔除减值冲回后的毛利率。
- **判断标准**：调整后净利润同比大幅偏离表观，说明少数股东权益/一次性项扭曲了表观。
- **海豚案例**：
  - 京东方《京东方：周期太“熬人”，龙头也只赚辛苦钱？》（2026-03-31）：4Q25 归母净利润 12.6 亿，剔除少数股东权益影响后为 6.2 亿，同比约 -72%；同时报告毛利率 19.4%，剔除约 21 亿资产减值冲回后，调整后毛利率 15.1%，环比 +2pct。
- **适用场景与注意事项**：适用于子公司少数股东占比高、频繁计提或冲回减值的重资产公司。

### 4.5.17 一次性资产处置：账面利润、现金流、长期利润影响三层分析

- **方法要点**：公司处置资产（退出参股公司）时，不只看账面数字，而是分三层看：账面利润、现金流、对未来利润的影响，再计算历史投资回报倍数。
- **操作步骤 / 拆分口径**：
  1. 账面利润层：资产减值、投资收益确认导致当季利润转负或转正；记录投资收益确认额。
  2. 现金流层：实际回款增厚现金，支撑分红或回购；记录现金到账额与账面现金变化。
  3. 未来利润层：处置后少了投资收益，同时也避开了监管下可能的亏损；判断对主业聚焦的影响。
  4. 投资回报倍数 = 处置金额 / 当初投资额。
- **关键指标与数据来源**：投资收益确认额；现金到账额；账面现金变化；投资回报倍数。
- **判断标准**：账面利润的转负/转正不代表经营变化；现金到账和风险回避才是实质影响；长期看少了一块投资收益来源，但风险敞口下降。
- **海豚案例**：
  - 分众（2026-04-29）：退出数禾，资本公积确认投资收益 5.65 亿，Q1 到账 4 亿，账面现金环比 +6 亿；当初投资 1 亿，以 7.9 亿卖出（约 7.9 倍）；退出可回避助贷新规的监管风险，更聚焦主业。
- **适用场景与注意事项**：适用于有参股或处置资产的公司。

### 4.5.18 一次性事件的前瞻含义与跨期回吐

- **方法要点**：一次性事项不是剔除完就结束，它会改变后续季度的基数：重组费压低当期、退税抬高当期，下季会回落；上季一次性收益在本季形成高基数；裁员补偿预示后续费用率下降；上季设备减值预示本季折旧下降。海豚君会把它们当作前瞻信号并在下季验证。
- **操作步骤 / 拆分口径**：
  1. 为每个被剔除的一次性事项标注方向（压低/抬高）和所在期间。
  2. 预判下季的回吐或回落：上季一次性收益不复存在 → 环比下滑，并量化其贡献（pct）。
  3. 事件的因果前瞻：裁员补偿 → 后续费用率下降；设备减值 → 折旧下降；税费补缴时间迁移 → 本年两期的节奏重分配。
  4. 下季验证：用实际数据检验费用率、折旧、毛利率是否按预期变化。
- **关键指标与数据来源**：上季一次性收益占毛利率的 pct；裁员后的费用率；折旧；税费补缴时点。
- **判断标准**：环比下滑若主要由上季一次性收益的消失解释，则不代表经营恶化；预判与验证一致，才能提高对一次性项的信任度。
- **海豚案例**：
  - 特斯拉《2Q26》（2026-07-23）：卖车毛利率 16.3%，环比 -2.9pct，主因上季约 2pct 一次性收益不复存在。
  - 百度（2026-05-18）：裁员补偿（近 7 亿）→ Q1 经营费用 -10%、占收入比 45% → 31%，验证裁员效果。
  - 奈飞（2026-01-21）：剩余不到 2 亿巴西税费延至 26 年补缴，本季超预期、26 年低于预期。
  - 星巴克（2026-07-30）：渠道发展利润率受关税退税抬高，预计 Q4 回落至 45%-48%。
  - 上季设备减值 → 本季折旧下降，是海豚君在利润拆解中使用的前瞻性逻辑（折旧传导见 10.3）。
- **适用场景与注意事项**：通用；上季一次性收益对环比的贡献，要量化到 pct，才能说清环比下滑的主因。

**相关交叉引用**：毛利率指引的一次性因素还原（调整后毛利率 vs 买方预期）见 9.1；资产减值/收入比及“核心运营利润率 = 毛利率 − 三费率 − 资产/信用减值损失率”见 8.1；剔除“系统级交付/捆绑硬件”后的核心产品毛利率见 16.2；上季度一次性收益形成的高基数、量化剔除去年同期大项目高基数以还原同比真实降幅，见 3.3；剥离一次性收入后的中性收入假设 × 净利率 → PE，对标传统同业，见 12.1；把费用增长拆为项目阶段性刚性投入和并购一次性交易成本，见 8.4；分部经营利润率剔除重组、关税退税后看内生扩张，并预判一次性因素消失后的回落区间，见 8.7；经常性非经营损益见 8.8。

**本节速查清单**

- [ ] 利润、毛利率、费用率、增速出现异常时，是否先排查了投资损益、减值、裁员/坏账、整合费用、补缴税款、罚款、诉讼、退税等一次性项目？
- [ ] 一次性项目是否标注了金额与来源（公告、附注、电话会、10-Q），并剔除后用核心口径与预期比较？

- [ ] 毛利率是否分别给出含影响与剔除影响两个数字（库存释放、减值冲回、保修冲回、关税、补贴、战略合作、召回），环比基准是否也用剔除后的数字？

## 4.6 未披露数据推算与累计数倒算

> 本节导读：公司不给的数据，往往能用公司给的数据算出来。本节集中收纳“已披露 → 未披露”的推算方法：累计数倒算单期（全年减前三季、全年减上半年、半年报或预告减一季度）、合计减已知项的残差法、用关联收入线或收入科目做代理、借助子公司与对手方披露、用总量与平均值反推、假设驱动的估算，以及一季报与年报联读。所有推算结论都要写出假设并标注“推算/估算/仅供参考”。停披后的信号含义与替代追踪见 4.4；行业专属公式（如游戏流水残差）归第 15、16 章对应行业节；推算出的数据再进入第 3 章（增量、基数、季节性）和第 5 章（收入拆解）使用。

### 4.6.1 累计数倒算单期：全年减前三季、全年减上半年

- **方法要点**：公司只披露年报、半年报，或招股书已披露前期数据时，用全年数减去已知期间，单独算出最新单季或下半年的收入、分业务收入、毛利、费用及同比增速，再与前期累计增速比较，判断是否放缓，避免累计增速掩盖边际变化。
- **操作步骤 / 公式**：
  1. 取全年数与已知的前三季或上半年累计数（招股书、半年报、季报）。
  2. Q4 = 全年 − 前三季；下半年 = 全年 − 上半年；对总收入、分业务收入、毛利、费用都做同样处理。
  3. 用同样方式倒算去年同期，得到单季或下半年的同比增速。
  4. 与前期累计增速比较，判断放缓或加速；分业务看结构变化（如占比、各业务增速的分化）。
  5. 单期毛利 / 单期收入，得到单期毛利率，与前期累计毛利率比较，看修复或恶化。
- **关键指标与数据来源**：单季/半年收入、分业务收入、毛利率、同比增速；数据来自年报、半年报、招股书、季报。
- **判断标准**：单季同比明显低于前期累计增速 → 边际放缓；某业务单季增速反而高于累计 → 加速；单期毛利率与累计毛利率的差异反映修复或恶化。推理链条：累计增速可能掩盖边际 → 倒算单期 → 比较累计与单期 → 判断拐点方向。
- **海豚案例**：
  - MiniMax《大模型血亏 360%...》（2026-03-02）：2025 全年 7900 万美元（+160%）减前三季，得 Q4 约 2600 万，同比从前 9 月 175% 降至 130%；AI 产品从约 150% 降至 82%，API 从 160% 加速到 278%（单季超 1055 万）；毛利率从前 9 月 23% 修复到 Q4 30%。
  - 智谱《赚 7 亿、亏 32 亿？》（2026-03-31）：全年 7.2 亿人民币（+132%），拆出 2H25 收入 5.3 亿，仅 +99%；本地部署 +57% 至 3.7 亿、占比滑至 70%，API +430% 至 1.6 亿；2H 毛利 2 亿，+30%。
  - 宁德时代（2026-07-25）：26H1 减值 19 亿 vs 25H2 64 亿，倒算半年度减值对比。
- **适用场景与注意事项**：半年报披露公司、新上市公司（尤其新股和只出半年报的港股）、季报口径不全的公司；招股书可作为前期累计数的来源。

### 4.6.2 全年减上半年：识别年内趋势拐点

- **方法要点**：A 股公司年报只披露全年分业务、分地区数据时，用全年减中报得到下半年数据，再与去年下半年比较，识别业务从上半年高增长到下半年转负的拐点。半年度趋势比全年数据更能反映边际变化。
- **操作步骤 / 公式**：
  1. 下半年 = 全年 − 上半年（分业务、分地区逐项算）。
  2. 与去年下半年比较，得到下半年同比。
  3. 与上半年同比、Q3 同比等已知数据并列，识别拐点；进一步用“下半年 − Q3”推单季（如 Q3 为正增长而下半年为负，则 Q4 必为负）。
  4. 分业务与分地区并看，定位拐点来自哪里。
- **关键指标与数据来源**：分业务/分地区下半年收入及同比；上半年同比；Q3 同比。
- **判断标准**：上半年高增长而下半年转负，即年内拐点；下半年与上半年增速基本持平，则无拐点；半年度增速的下行节奏用来判断业务景气度方向。
- **海豚案例**：
  - 三花《“天灾人祸”…》（2026-03-31）：制冷业务上半年 +25%，Q3 约 +10%，Q4 转负，下半年整体 -1%；汽零下半年 +9%，与上半年近乎持平；海外下半年 61 亿（-8%）。
  - 三花（2026-03-23，速读）：下半年制冷 -1%，而 Q3 为正增长，推出 Q4 为负。
  - 歌尔《跨过越南“招工坑”…》（2026-04-23）：智能硬件 25H2 收入 334 亿（-10%），声学整机 146 亿（+8.5%），精密零组件 104 亿（+18.7%）。
- **适用场景与注意事项**：适用于只在半年报/年报披露分部数据的 A 股、港股公司。

### 4.6.3 半年报/业绩预告倒算单季与季度贡献占比

- **方法要点**：只披露半年报的公司，用 H1 减去 Q1（此前的季度预估或盈利预告）得到 Q2，计算同比与环比；或用预告区间中值算 Q1 占 H1 收入与利润的比重，揭示业绩集中于某个时点（如提价前抢购），判断后续动能。
- **操作步骤 / 公式**：
  1. Q2 = H1 − Q1（Q1 取实际值、此前预估或预告区间）；预告为区间时，取区间并给出 Q2 的区间。
  2. 计算 Q2 同比、环比（Q2/Q1 − 1）。
  3. 季度贡献占比 = Q1（预告中值）/ H1，收入与利润分别算。
  4. 业绩过度集中于一个季度（提价前抢购等）时，判断后续动能是否衰竭。
  5. 同时用预告落点看正式财报在预告区间中的位置（见 2.2）。
- **关键指标与数据来源**：H1 收入；Q1 预告/预估；Q2 倒算值及同比、环比；Q1 占 H1 收入与利润比重。
- **判断标准**：Q2 环比大幅回落、同比转负，说明动能已退潮；Q1 占 H1 的比重过高，说明业绩前置。
- **海豚案例**：
  - 泡泡玛特《海外熄火，Labubu 退潮…》（2026-08-20）：26H1 营收 172 亿，+24%，估算 Q2 约 73 亿，环比 Q1 约 -25%。
  - 老铺黄金《金价颓了…》（2026-08-25）：Q1 预告收入 165-175 亿、净利润 36-38 亿，倒算 Q2 收入 23-33 亿（同比 -16% 至 -42%），Q1 约占 H1 收入 86%、利润 87%。
- **适用场景与注意事项**：港股/中概半年报公司；预告为区间时结论也是区间，要说明。

### 4.6.4 一季报与年报联读：用年报下半年数据补全业务判断

- **方法要点**：一季报只披露总量数据时，结合同时发布的年报，用年报分业务数据算出下半年（全年减中报）的分业务收入和毛利率，判断各业务趋势；再用一季报的整体毛利率检验下半年的异常是否持续。
- **操作步骤 / 公式**：
  1. 一季报取总营收、毛利率与预期的对比。
  2. 年报取分业务数据，算出下半年（全年 − 中报）各业务收入、毛利率与同比（见 4.6.2）。
  3. 用一季报整体毛利率与下半年比较，验证下半年的异常（如毛利闪崩）是短期还是持续。
- **关键指标与数据来源**：一季度总营收、毛利率；年报分业务下半年收入与毛利率。
- **判断标准**：一季报毛利率回升 → 下半年毛利率下滑是短期影响；一季报毛利率继续下行 → 异常可能延续。
- **海豚案例**：
  - 歌尔《跨过越南“招工坑”，毛利回血、增长仍“断档”？》（2026-04-23）：1Q26 营收 187 亿（+14%，低于预期 217 亿），毛利率 13.8%（+1.4pct）；联读年报，25H2 智能硬件 334 亿（-10%），声学整机 146 亿（+8.5%），精密零组件 104 亿（+18.7%）；Q1 毛利率回升，验证下半年毛利闪崩是短期影响。
- **适用场景与注意事项**：适用于一季报、三季报披露简略的 A 股公司。

### 4.6.5 A 股半年度分业务毛利率：H2 对 H1 比较，推断 Q4 单季压力

- **方法要点**：A 股公司通常只在半年报、年报披露分业务毛利率，披露频率低。海豚君用下半年对上半年的变化比较各业务毛利率，再结合 Q4 单季综合毛利率，推断 Q4 单季的实际压力比半年口径更大；下一年一季度再借电话会口径补齐单季数据。
- **操作步骤 / 公式**：
  1. 取 H1、H2 分业务毛利率，计算 H2 − H1（单位 ppt）。
  2. 结合 Q4 单季综合毛利率，推断 Q4 单季压力：若 H2 已明显低于 H1，且 Q4 单季综合毛利率更低，则 Q4 单季压力比半年口径体现的更大。
  3. 下一年 Q1 借电话会披露的单季分业务毛利率补齐，并与 Q4 比较（如 Q1 对 Q4 的回升幅度）。
- **关键指标与数据来源**：H1/H2 分业务毛利率；单季综合毛利率；电话会补充的单季分业务毛利率。
- **判断标准**：H2 对 H1 下降幅度大的业务，即压力来源；Q1 对 Q4 回升，则 Q4 为阶段性低点。
- **海豚案例**：
  - 阳光电源《平地起惊雷》（2026-04-01）：储能毛利率从 2025H1 约 40% 降 6.6ppt 至 H2 的 33.4%，逆变器 H2 33.6%（-2.1ppt），电站开发 H2 10.8%（-7.2ppt），下半年整体毛利率 29.4%（-5ppt），并指出 Q4 单季压力更大。
  - 阳光电源《收入倒春寒》（2026-04-28）：Q1 储能毛利率 30%，较 Q4 约 24% 回升 6ppt。
- **适用场景与注意事项**：适用于 A 股/港股等分部披露频率低的公司；需要结合电话会口径补单季数据。

### 4.6.6 “合计 − 已知项”残差法：倒推未披露的分部或子业务

- **方法要点**：公司只披露合并分部、部分分部增速或总量时，用“总收入增速 = Σ 各分部占比 × 分部增速”反推剩余分部；用“合计 − 已知项”“全年 − 已知季度”“板块利润 − 假设的基本盘利润”倒算子项，必要时结合调研；结论标注为“推测/估算”。
- **操作步骤 / 公式**：
  1. 取已披露的总量增速、已知分部占比与增速（占比要有可靠来源，如年度披露）。
  2. 反推：未知分部增速 g_x =（总增速 − Σ 已知分部占比 × 已知增速）/ 未知分部占比。
  3. 合并分部（如金科企服合计）：用合计增速、已知子项增速及权重，倒推另一子项；子项内部再拆（如企业服务含云外部收入 + 小店技术佣金）。
  4. 利润残差：板块利润 −（假设的基本盘利润）= 隐含的新业务亏损。
  5. 用行业数据交叉验证（如支付行业增长不到 3%），并估算占比（如云收入占总营收 7-8%）用于判断估值支撑。
  6. 把总收入放缓的原因定位到具体分部，结论标注“推测/估算”。
- **关键指标与数据来源**：总收入同比；已知分部占比与增速；合并分部增速；行业增速；调研信息。
- **判断标准**：推导结果要能解释总量变化（如定位到受监管影响的国内业务）；与行业数据、调研一致才更可信；假设基本盘不变带来的误差要说明。
- **海豚案例**：
  - 变体 A：由已知分部增速倒推未披露分部（携程）
    - 携程《监管铁拳落定，携程能“轻装上阵”了吗？》（2026-09-16）：2Q26 总收入 157 亿，+5.5%；纯海外营收 +50% 以上，隐含国内业务可能同比下滑 10% 以上，剔除入境游会更差，监管和国内酒旅景气影响明显。
    - 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：海外订单 +65%、入境 +90% 依然强劲，所以收入环比放缓大概率来自国内，监管影响可能已初步显现。
  - 变体 B：合并分部倒推子业务（腾讯金科企服）
    - 腾讯《“老登”腾讯：到了去登味、AI 上火候的时候了！》（2026-03-18）：金科企服合计 +8%，企业服务 +22% → 金科中低个位数（倒算金科中个位数增长，估 +5% yoy）；腾讯云 10-20%，未跟随算力景气（优先内供）。
    - 腾讯《不再躺尸功劳簿》（2026-05-13）：企业服务 +20% → 金科约 +5%。
    - 腾讯《AI 撒钱火力全开？》（2026-08-12）：企业服务约 30%（Q1 20% 出头），预计 Q3 继续加速，云收入占 7-8%。
  - 变体 C：板块利润减假设基本盘，倒推隐含亏损
    - 阿里（3QFY26）：中国电商 adj. EBITA 346 亿，同比少约 265 亿，假设原淘天利润微跌，隐含闪购亏损约 250 亿。
  - 变体 D：“全年 − 已知季度”倒推单季符号
    - 三花（2026-03-23）：下半年制冷 -1%，而 Q3 为正增长，推出 Q4 为负。
  - 变体 E：停披或合并披露后，结合调研倒推
    - 迪士尼（2026-02-02）：不再披露流媒体订阅数，倒算出“量”的推动不大。
    - 新东方（2026-01-28）：咨询业务未披露，推断留学整体同比持平。
    - 老铺（2026-03-23）：取消品类占比披露，结合调研推断镶嵌类占比提升。
    - 东鹏（2026-03-30）：地区口径变更，结合调研推测两广只有低个位数增长。
- **适用场景与注意事项**：适用于部分披露分部数据、合并披露分部的集团公司；各分部占比要有可靠来源；代理或基本盘假设会引入误差，必须标注。停披后的信号含义见 4.4.7，替代追踪见 4.4.8。

### 4.6.7 关联收入线与收入科目代理：推断未披露业务

- **方法要点**：公司不披露某项业务时，找包含或反映该业务的关联收入线或收入科目作为代理：用物流性收入增速推外卖业务量变化；用在线营销服务（广告）反映国内主站、交易服务（佣金）反映 Temu，推断海外业务强弱，并用自有模型测算（标注“仅供参考”）。
- **操作步骤 / 拆分口径**：
  1. 建立科目到业务的映射：如拼多多的在线营销服务（广告）主要反映国内主站，交易服务（佣金）主要反映 Temu（加上多多买菜）；京东的物流及其他收入包含外卖配送收入，创新业务收入反映海外。
  2. 主业务基本盘稳定或偏弱时，用代理科目的超预期/低于预期推断未披露业务的强弱（主站佣金不会好的情况下，交易服务收入超预期 → Temu 更强）。
  3. 观察代理科目增速的变化（外卖高峰期约 35%，之后 24%、22%、5.9%），并用另一科目的变化印证（新业务板块收入下滑）。
  4. 自建模型测算未披露业务的营收与 GMV 增速，标注“仅供参考”。
  5. 考虑分部口径变化（全托管改半托管）对科目的影响，并定期复核代理关系。
- **关键指标与数据来源**：物流及其他收入增速、新业务板块收入、创新业务收入、环比变化；在线营销服务收入同比、交易服务收入同比、彭博一致预期、Temu 营收和 GMV 测算增速。
- **判断标准**：
  - 代理科目增速显著放缓 → 隐含被代理业务量环比下滑。
  - 交易服务收入高于/低于一致预期的幅度，反映 Temu 强弱；低于预期且部分来自半托管导致营收口径变小，则要区分口径与需求。
  - 代理关系可能因业务演变失真，需要定期复核。
- **海豚案例**：
  - 变体 A：关联收入线（京东）
    - 京东（2026-03-05）：物流性收入增速环比放缓近 12pct，从约 35% 降到 24%，“隐含京东外卖&闪购的业务量确实是环比有所下滑的”；用新业务板块收入下滑（156 亿到 141 亿）印证。
    - 京东（2026-08-13）：物流及其他增速放缓到 5.9%，回到 25 年之前的常态；创新业务营收环比约 +15%，推测海外收入增加。
  - 变体 B：收入科目代理（拼多多）
    - 拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）：4Q25 交易服务收入约 639 亿，同比 +19%，高于彭博 14%，推断 Temu 超预期，测算 Temu GMV 增速约 50%。
    - 拼多多《拼多多：又老又“傲慢”，彻底人人嫌》（2026-05-27）：1Q26 交易服务 +20%，高于彭博 18%，测算 Temu 营收增速从约 20% 提到约 25%。
    - 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：2Q26 交易服务仅 +13%，低于彭博 21%，推断 Temu 增长相当不好，部分来自半托管导致营收口径变小。
- **适用场景与注意事项**：适用于新业务信息披露不足、分部披露不足的多业务公司；代理关系可能因业务演变失真，需要定期复核。

### 4.6.8 子公司披露：年报重要子公司拆分与独立上市子公司提前披露

- **方法要点**：上市公司不披露细分业务时，借重要子公司的财务数据做拆分；母公司财报前，若独立上市子公司已提前披露，可提前掌握分部关键数据。
- **操作步骤 / 拆分口径**：
  - 变体 A：年报中的重要子公司
    1. 用负责某区域销售的子公司收入，量化区域冲击（如美国关税冲击），同比、环比都看。
    2. 用细分业务子公司（如商用制冷）的营收和净利，计算该板块增速与净利率，并测算它比板块整体净利率高多少，估计结构变化对毛利率的拉升。
  - 变体 B：独立上市子公司提前披露
    1. 母公司财报前，子公司已提前约一个月披露，先拿到国际分部的关键数据。
    2. 同店拆为客单价与客流，并与当地行业客流对比。
    3. 细拆 1P/3P 电商 GMV，定位 3P 异常下滑的原因，并关注子公司指引下调。
- **关键指标与数据来源**：子公司营收、净利润、净利率、同比/环比变化；子公司同店、客单价、客流、1P/3P GMV、广告增速、子公司指引。
- **判断标准**：子公司的区域收入同比、环比双降，说明该区域冲击已兑现；板块净利率显著高于整体，说明结构提升毛利；同店变化拆为客单与客流后，与行业客流对比判断是否跑赢；3P 断崖要定位到卖家结构原因（头部 3C 卖家合规下架、依赖少数超级大卖家、长尾不足）。
- **海豚案例**：
  - 三花《“天灾人祸”…》（2026-03-31）：负责北美销售的三花国际（美国）25H2 收入 17 亿，同比 24H2、环比 25H1 都下滑超过 10 亿；浙江三花商用制冷 2025 年营收 30.6 亿（+26%），净利 5.88 亿（+38%），净利率约 19%，测算比制冷整体净利率高约 7pct。
  - 沃尔玛（2026-05-22）：Walmex 同店 +3.1% = 客单 +4%、客流 -0.9%，优于行业客流 -2%~-3%；1P GMV +20%，3P GMV 从 +15% 降至 -14%，广告 +33%（上季 +5%）；3P 断崖原因是头部 3C 卖家合规下架、依赖少数超级大卖家、长尾不足。
  - 沃尔玛（2026-08-21）：Walmex 收入 +1.9%（固定汇率 3.2%），墨西哥同店 +1.8%（客单 +2.9%、客流 -1.1%），全年指引下调至 3.5%-4.5%。
- **适用场景与注意事项**：变体 A 适用于子公司业务划分清晰、年报披露主要子公司财务数据的 A 股公司；变体 B 适用于拥有上市子公司的集团。

### 4.6.9 总量、平均值与对手方披露交叉倒推

- **方法要点**：公司停止详细披露某项数据，或根本不披露时，用其他披露倒推：行业总量乘以公司平台占比再减已知项、收入与储备利息倒推分成比例、年度平均值反推单季、对手方财报交叉验证，并将倒推结果用于判断战略动作。
- **操作步骤 / 公式**：
  1. 自持余额 = 总量 × 平台占比 − 用户持有量（如 USDC 总量 × Coinbase 平台占比，减去用户持有量，倒推 Coinbase 自持 USDC）。
  2. 激励分成比例 = 给用户的激励 / 稳定币收入（用稳定币收入与储备利息倒推）。
  3. 单季用户数 = 4 ×（全年平均值）−（前三季之和）（用全年交易用户平均值和前三季数据反推 Q4）。
  4. 用对手方（如 Circle）财报与自身财报交叉验证渠道分布。
  5. 倒推结果用于判断战略动作（如为保持生态地位加速囤币）；说明为粗略估算。
- **关键指标与数据来源**：自持 USDC 余额；激励分成比例；季度 MTU；渠道分布；Circle 与 Coinbase 财报。
- **判断标准**：自持余额大幅上升 + 分成比例上升，说明公司在用利润换生态地位；分成比例下降，说明让利收敛。倒推有误差，需说明。
- **海豚案例**：
  - Coinbase《烂行情+烂业绩…》（2026-02-13；Circle《Circle：用业绩回击唱衰…》2026-02-25 同引）：倒推 Coinbase 自持 USDC 环比 +60%，从 37 亿增至 60 亿；用户激励分成较 Q3 提高 8pct 至 52%；由全年交易用户平均 920 万反推 Q4 MTU 为 910 万。
  - Coinbase《Coinbase：旱地已久…》（2026-05-08）：粗算激励分成达 60%（去年 40%）。
  - Coinbase《Coinbase：币价退潮再探底…》（2026-07-31）：激励分成从 61% 降至 51%。
- **适用场景与注意事项**：适用于披露口径变化、关键数据缺失的公司；倒推有误差，需说明是粗略估算。年度 MAU 平均值倒算下半年 MAU 净增的同类做法见 5.6。

### 4.6.10 用总收入或指引减成熟业务的假设增速，倒算未披露的新业务

- **方法要点**：新业务没有单独披露时，假设成熟业务按某个内生增速增长，用总收入（或指引）减去成熟业务，得到新业务收入的估计，再算同比、环比，与自己上季的预估比较，判断节奏是“正常”“惊艳”还是“不足”。
- **操作步骤 / 公式**：
  1. 设定成熟业务的内生增速假设（如 20% 或 40%），并给出依据（公司指引、渠道调研）。
  2. 新业务收入 = 总收入（或指引）− 去年同期成熟业务收入 ×（1 + 假设增速）。
  3. 计算新业务的同比、环比增速。
  4. 与上季自己的预估比较，判断节奏是“正常”“惊艳”还是“不足”。
  5. 对假设敏感，需给出多种口径（如 20% 与 40% 两种假设）并在结论中说明。
- **关键指标与数据来源**：总收入/指引；成熟业务增速假设；推算出的新业务收入。
- **判断标准**：淡季实现难度大、而推算值仍较高，说明成熟业务在对冲季节；新业务的推算值高于上季预估，说明节奏超预期。
- **海豚案例**：
  - Applovin（2026-02-12）：游戏广告按公司指引的 20% 内生增速算，Q1 电商收入约 3.8 亿，淡季实现难度不小，判断 Q1 仍是靠强势的游戏收入对冲季节影响（与渠道调研中游戏开发商提高预算份额相符）。
  - Applovin（2026-05-07）：假设游戏等其他广告保持 40% 内生增速，Q1 电商广告约 4 亿，同比 +230%、环比 +30% 以上；另一口径测算为 4.5 亿，比海豚君上季预估多。
- **适用场景与注意事项**：新业务尚未披露的公司；结论对假设很敏感。

### 4.6.11 停披用户数据后：第三方趋势 + 收入倒推量价

- **方法要点**：公司不再披露 MAU 与付费用户时，用第三方 App 趋势描摹整体用户变化，用“收入 ÷ 假设 ARPPU”倒推付费用户净增，并明确标注“仅供参考”。停披本身被视作竞争压力的侧面信号（见 4.4.7）。
- **操作步骤 / 公式**：
  1. 用 QuestMobile 中各 App（QQ 音乐、酷狗、酷我、全民 K 歌等）的 MAU/DAU 趋势描摹整体 MAU 变化。
  2. 付费用户 = 订阅收入 ÷（假设 ARPPU × 期间）；用两期差额得到净增。
  3. 剔除并表业务（如喜马拉雅）对订阅收入与付费用户的影响后，再算原业务的净增。
  4. 明确标注“仅供参考”，并用多源交叉验证。
- **关键指标与数据来源**：QM MAU/DAU；订阅收入；ARPPU 假设。
- **判断标准**：订阅收入增速与 ARPPU 假设共同决定付费用户净增的方向；第三方 App 趋势中下滑最大的 App 反映内部竞争压力；误差较大，需多源交叉。
- **海豚案例**：
  - 腾讯音乐《收编喜马拉雅，腾讯音乐能否打赢这场防守战？》（2026-05-12）：自 2026 年起不再披露 MAU 与付费用户；估算 Q1 付费用户净增约 100 万、ARPPU 11.7 元。
  - 腾讯音乐《腾讯音乐：慷慨回购，能买回“小而美”信仰吗？》（2026-08-11）：Q2 剔除喜马拉雅后净增约 60 万；酷狗下滑最大。
- **适用场景与注意事项**：停止披露关键运营指标的公司；误差较大，需多源交叉。

### 4.6.12 假设驱动的未披露业务估算与“仅供参考”标注规范

- **方法要点**：对完全未披露或披露粒度很粗的业务，设定可辩护的假设并倒推规模，同时标注“仅供参考”；常见路径包括：非控制权益变动推算子公司收入、按订阅占比剔除并表业务、半年报减 Q1 倒算 Q2、拆分合并科目、估算 AI GPU 收入、从净增口径推算净新增付费用户。
- **操作步骤 / 拆分口径**：
  1. 选路径：①非控制权益变动推算子公司收入；②按订阅占比剔除并表业务；③半年报减 Q1 倒算 Q2（见 4.6.3）；④拆分合并科目（如金科企服中的企业服务，见 4.6.6）；⑤估算细分产品收入（如 AI GPU）；⑥从净增口径推算净新增付费用户（见 4.6.11）；⑦直接设定假设参数（如 ARPPU、老合同贡献）。
  2. 写出假设来源（公司指引、调研、行业数据），给出估算值与边界。
  3. 标注“仅供参考”，必要时给出多口径（高/低假设）。
  4. 后续季度用公司披露或管理层口径校准。
- **关键指标与数据来源**：非控制权益、并表业务占比、季度差额、ARPPU 假设、假设参数；公司披露、调研、行业数据。
- **判断标准**：估算值用于判断方向与节奏，不用于精确判断；假设越少、越可验证，结论越可靠。
- **海豚案例**：
  - 变体 A：假设参数驱动（速读汇总）
    - AppLovin：电商广告约 4 亿以上（+250%）。腾讯音乐：ARPPU 约 11.7 元。ARM：老合同贡献约 4 亿。AMD：服务器 CPU 约 38 亿。拼多多：Temu 约 +25%。微软：OpenAI 订单减少约 50 亿。
  - 变体 B：间接披露推算分部（速读汇总）
    - 新东方：通过非控制权益估算东方甄选 +40%，高中学科约 18%。
    - 腾讯音乐：喜马拉雅按 65% 订阅占比剔除，原音乐会员约 45 亿，ARPPU 同比 -2% 时净增付费约 60 万。
    - 腾讯：企业服务（云外部收入 + 视频号佣金）约 30%（Q1 20% 出头）。
    - AMD：AI GPU 约 27 亿，服务器 CPU 约 40 亿（+80%）。
    - 泡泡玛特：Q2 约 73 亿，环比 -25%。
    - Spotify：估算 Q3 ARPPU +7% 以上。
- **适用场景与注意事项**：披露不足或披露粒度粗的公司；估算要说明假设来源，并在后续季度校准；不要把估算值写成公司披露值。

**相关交叉引用**：披露口径收缩后的替代追踪见 4.4；用增值税退税倒算软件收入见 15.10；事业群 × 地区 × 主业/创新业务矩阵拆分（用半年报补齐季报）见 5.3；用年度 MAU 平均值倒算下半年 MAU 净增见 5.6；未单独披露业务的归类假设，以及按占比乘增速测算其对母业务的增量拉动见 3.1；用业绩预告或盈利预警倒算下半年、单季，并看正式财报落在预告区间的位置见 2.2。
