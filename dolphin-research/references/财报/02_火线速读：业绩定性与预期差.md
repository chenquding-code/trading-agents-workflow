# 第2章 火线速读：业绩定性与预期差

> **本章目的**：财报发布后第一时间判断“好还是坏、超还是不及预期、超预期含金量多少、差异来自哪里”，形成一句话定性，并为电话会留出问题。

**本章小节**：2.1 业绩定性与综合评价维度｜2.2 逐项对标与区间定位｜2.3 预期差来源归因｜2.4 超预期质量与含金量检验｜2.5 电话会增量信息与待验证清单

## 2.1 业绩定性与综合评价维度

> 本节导读：财报一出，第一件事是回答“好还是坏”，并给出一个带分级的定性词。本节提供定性的几套工具：绝对表现/预期差/边际趋势三维评价、当期与指引的双轴分级、速读开头句的复合判断，以及“低预期”“预防针”“表观 vs 实际”等语境修饰。每份财报点评或火线速读的第一段都要用到；逐项对标的数据见2.2，预期差来源见2.3，含金量检验见2.4，指引本身的深度解读见第9章，股价反应与已定价判断见第11章。

### 2.1.1 三维评价：绝对表现、预期差、边际趋势

**方法要点**：给财报定性时，把“绝对表现”“预期差”“动态边际变化”三个维度分开下结论，再综合成观点。三者的方向经常相反，拆开写才不会被单一维度带偏，也才能说清股价到底由哪一维决定。

**操作步骤**：
1. 绝对表现：不谈预期，只看增长和利润本身的水平好不好。例如一家单季营收2500亿的轻资产公司，调整后利润只剩50亿，“利润差”是确定的。
2. 预期差：相对彭博一致预期、头部大行预期、公司指引，是 beat 还是 miss。
3. 动态边际变化：环比加速还是放缓，跌幅是否收窄，利润率是否改善，是否出现拐点信号。
4. 三个维度分别写一句结论；若方向背离，要明确写出背离（见下方常见结论形态）。
5. 最后综合成观点，并说明股价逻辑主要由哪一维决定。

**关键指标与数据来源**：核心指标（营收、利润）的绝对值与同比/环比增速；彭博一致预期、头部大行预期、公司指引；营收和利润相对一致预期的偏离（%）；同比和环比的变化方向。

**判断标准**：
- 三维可以同时成立但方向相反，常见的结论形态有：
  - “绝对表现不好，但预期差有亮点”（国内利润大超、海外亏损少于预期，但整体利润绝对值很低）；
  - “预期差无惊无喜，但趋势承压”（预期差中性，营收降速、利润负增长）；
  - “绝对表现差，但相对预期还可以”（绝对降幅很大，但预期更差）；
  - “增长趋势向好，但投入太高导致利润太差”；
  - “功过相当”（同一业务中营收不及预期、利润改善却超预期，互相抵消）；
  - “相比极低预期表现不错，但绝对增速不高，更多是修复故事，没有很大的向上空间”。
- 推理链：绝对表现回答“公司好不好”，预期差回答“相对市场定价的惊喜或失望”，边际趋势回答“方向能否延续”；最终观点要选出对股价影响最大的那一维，并明确说出来。

**海豚案例**：
- 滴滴《国内熟透、海外猛投，滴滴未来看“国际滴”？》（2026-06-02）：整体 adj.EBITA 不足2亿，绝对表现不好；但国内利润大超预期、海外亏损少于预期，预期差亮点不少。
- 携程《监管铁拳落定，携程能“轻装上阵”了吗？》（2026-09-16）：预期差无惊无喜；趋势上营收明显降速、利润负增长。
- 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：相比极低预期表现不错，但整体营收只增8%、利润增长不到5%，更多是修复故事，没有很大的向上空间。
- 唯品会《唯品会：不增收也能增利，只是怕2Q坎难过》（2026-05-21）：绝对意义上算不上好，但相对不高的预期可圈可点。
- 贝壳《“跪太久”贝壳》（2026-05-20）：新房营收-37%是绝对差，但彭博预期是-42%，所以相对好；家装营收不及预期，但利润改善超预期，“大体功过相当”。
- 贝壳《一线再松绑》（2026-08-21）：一航道改善幅度大体在预期之内，二航道仍在调整。
- 阿里《阿里：电商退位，AI上位》（2026-05-14）：增长趋势向好，但投入过高导致利润太差（调后 EBITA 仅51亿）。
- 阿里《阿里：电商再沦陷》（2026-03-19）：从预期差看，接近已下调的指引；但绝对表现比较弱。

**适用场景与注意事项**：所有财报点评的观点形成通用，一季财报同样适用。三个维度可能方向相反，务必写明哪个维度对股价更关键，不要把三条结论平均处理。

### 2.1.2 速读开头句：绝对表现与预期差双轴定性

**方法要点**：火线速读的第一句话先给定性，并明确区分“绝对角度”和“预期差角度”两条轴，再给出复合判断和分级定性词，用一句“唯一瑕疵/最大亮点/美中不足”点题。

**操作步骤**：
1. 绝对角度：增速、利润、趋势是否健康或改善。
2. 预期差角度：相对彭博一致预期、头部卖方预测、买方预期的偏差。
3. 两条轴经常背离，据此给复合判断：
   - 绝对不错但预期已被拉高 → 算不上大惊喜；
   - 绝对不佳但比预期好不少 → 大超预期；
   - 业绩差但落在卖方区间偏低位置 → 预期差角度也不算很差。
4. 使用分级定性词：全面超预期、大超、小超、基本 inline、略 miss、爆雷。
5. 后面紧跟一句“唯一瑕疵/最大亮点/美中不足”，把最关键的一个点点出来。

**关键指标与数据来源**：收入、利润的同比与环比；彭博一致预期；卖方预测区间；财报前股价涨跌幅（用来判断预期是否已被拉高）。

**判断标准**：
- 绝对好 ≠ 利好：股价已从低点大幅反弹、预期已被抬高时，绝对不错也只是“算不上很大惊喜”。
- 绝对差 ≠ 利空：市场预期的亏损更大时，绝对不佳反而是“大超”。
- 落在卖方预测区间的偏低位置，意味着预期差并不突出。
- 触底回暖若早已被预期，也不算惊喜。

**海豚案例**：
- 亚马逊《亚马逊1Q26火线速读》（2026-04-30）：营收+17%（剔汇率15%），经营利润近240亿，超指引上限215亿；但股价自低点反弹超30%，AWS +28% 落在预期区间偏低位置，结论“算不上很大惊喜”。
- 滴滴《滴滴1Q26火线速读》（2026-06-02）：adj.EBITA 不足2亿，绝对不佳；市场预期亏损5亿，所以算大超。
- 阿里《阿里巴巴4QFY26火线速读》（2026-05-13）：adj.EBITA 仅51亿，但落在头部卖方区间偏低位置。
- 美团（2026-06-01）：经营亏损65亿，彭博预期约90亿。
- 京东（2026-05-13）：触底回暖早有预期，不算惊喜。
- 唯品会（2026-05-21）：“在不高的要求下小超”。

**适用场景与注意事项**：适用于所有财报速读的开头。前提是先掌握近期股价走势和预期修正轨迹，否则容易把“绝对好”误判为利好。

### 2.1.3 当期对比预期 × 指引对比预期：双维度定性分级

**方法要点**：每份财报先得到一个定性词（平淡、一般、不错、相当不错、亮眼、炸裂、不如意、难以让市场满意）。判断分两步：当期业绩相对预期和指引的偏离，加上下季度或全年指引相对预期的偏离，其中指引权重更高。

**操作步骤**：
1. 当期：收入、毛利率或核心利润偏离市场预期和公司指引多少。
2. 指引：下季度或全年指引偏离市场预期多少，同时看指引是上调还是下修。
3. 两者叠加，对照下表定性：

| 当期 | 指引 | 定性 |
|---|---|---|
| 符合 | 大超 | 炸裂 / 春天 |
| 达标，但毛利率走弱 | 低于预期 | 一般 |
| 略低 | 大超 | 不错 / 走出底部 |
| 超预期 | 超预期 | 相当亮眼 |
| 低于预期 | — | 不如意 |
| 符合 | 下修部分全年指引 | 平淡 / 失望 |

4. 当季数据权重的调整：若当季收入已由月报披露（如台积电），或公司已给出全年指引（如博通），当期数据的权重还要再往下调。

**关键指标与数据来源**：收入、毛利率、核心经营利润相对预期的偏离；下季度及全年指引相对预期的偏离；指引上调或下修的方向。

**判断标准**：
- 核心原则：“相比于本季度业绩，下季度指引更为重要。”
- 当期符合 + 指引大超 → 炸裂/春天；当期双超 → 相当亮眼；当期略低但指引大超 → 不错/走出底部。
- 当期达标但毛利率走弱 + 指引低于预期 → 一般。
- 当期低于预期 → 不如意；当期符合但下修部分全年指引 → 平淡/失望。

**海豚案例**：
- ASML《阿斯麦 ASML：AI 慌成一团，“铲子” 热火朝天？》（2026-07-15）：收入93亿欧元高于预期89亿；毛利率54%高于指引51-52%；Q3收入指引110-120亿高于预期103亿；全年指引上调至430-450亿。定性为“指引炸裂”。
- AMAT《应用材料 AMAT：Capex 大周期驾到，设备股春天来了！》（2026-02-13）：收入70亿符合预期，指引71.5-81.5亿大超预期71亿，对应“当期符合且指引大超”的组合（炸裂/春天）。
- 中芯 Q4'25（2026-02-10）：收入达标，毛利率19.2%走低；指引收入环比持平，低于预期的+3%。定性为“业绩一般”。
- 中芯 Q1'26（2026-05-14）：收入略低于预期；收入指引环比+14-16%，远超预期+7%，对应“当期略低但指引大超”的组合（不错/走出底部）。
- 中芯 Q2'26（2026-08-13）：收入30.1亿高于预期28.7亿，毛利率25.3%超指引上限。定性为“相当亮眼”。
- 海力士 Q2'26：收入79万亿韩元低于预期85万亿，定性为“不如意”。
- ARM（2026-07-30）：业绩符合预期，但下修 Royalty 全年增速，定性为“平淡/失望”。

**适用场景与注意事项**：通用，对给季度或年度指引的公司最有效。指引的深度解读（隐含值倒算、权重、保守度）见9.1至9.3。

### 2.1.4 “低预期下的超预期”：焦点转向指引，并用第三方数据验证

**方法要点**：当前期的差已被高频数据或月报提前暴露、股价已经消化，或公司指引过度保守时，当季“超预期”并不稀奇，要把判断重心转到下季或全年指引，并用第三方数据校验表现是否合理。

**变体 A：当季差已提前暴露，看指引证明拐点**
1. 先点明“低预期”的背景（补贴退坡、销量低谷、股价持续下跌）。
2. 判断当季财报本身影响有限（差已在销量月报或行业数据中暴露、股价已消化）。
3. 把指引是否超预期作为股价方向的主要判断：指引超预期就判定拐点初现；指引 miss 就预计财报后短期承压。
- 关键指标：当季业绩 vs 预期；下季销量和收入指引 vs 市场预期；股价前期走势。
- 案例：
  - Rivian（2026-02-13）：IRA 退坡后 4Q25 处于销量低谷，财报“在低预期背景下相当不错”，市场最关心2026指引（销量6.2-6.7万，大超预期，预计推高股价）。
  - 小鹏（2026-05-28）：Q1颓势“已基本被股价消化”，Q2销量指引10-10.6万，预期9.7万，判定“新车周期拐点初现”。
  - 小鹏（2026-08-24）：Q3指引严重 miss，预计财报后短期股价承压。
- 适用：有月度高频数据的公司（车企、互联网），财报信息增量集中在指引上。

**变体 B：公司指引过度保守，用第三方出货数据交叉验证**
1. 公司指引过度保守时，实际降幅只要小于指引，就是“低预期下的超预期”。
2. 用第三方市场调研数据（如季度 PC 出货同比增速）验证实际表现是否合理。
3. 同时对照市场自身的预期，而不只对照公司指引。
- 关键指标：板块指引、市场预期、第三方 PC 出货量。
- 案例：
  - 微软（2026-05-01）：个人板块-1%，市场预期-5%；Windows 和硬件-2.5%，指引-10%，与调研显示一季度 PC 出货同比+2%-4%一致。
  - 微软（2026-07-30）：个人板块-5%，预期-10%；市场预期 Windows 跌15%以上，实际-7%。
- 适用：消费电子、PC 链相关业务。

**判断标准**：“低预期”要说明相对谁低（公司指引、市场预期、第三方出货）；财报当季超预期不等于股价会涨，真正决定方向的是指引能否证明拐点。

**适用场景与注意事项**：变体 A 要结合股价在财报前的走势，判断利空是否已计价（见11.2）；变体 B 要先确认第三方数据与公司口径大体可比。

### 2.1.5 定性措辞分级：表观 vs 实际、低预期下还不错、超低预期下没那么差

**方法要点**：给业绩下定性词时，同时说明“相对谁的预期”和“剔除一次性之后”如何，避免一句“不错”或“不好”产生歧义；定性词还决定后文的写作重心。

**操作步骤**：
1. 判断预期水平是高还是低，写成“超低预期”“低预期”“高预期”。
2. 判断表观数据和剔除一次性后的偏差。
3. 选择措辞：
   - “在市场超低预期的前提下显得没那么差”（关键是没有进入恶性循环）；
   - “低预期下还不错”；
   - “表观强劲、实际也具备一定韧性”（剔除一次性后仍超预期）；
   - “在交付超预期拔高期待后，利润端不及预期”。
4. 依据定性决定后文重心：主业继续深挖，还是转向全年展望和 AI 叙事。

**关键指标与数据来源**：预期水平（高或低）、表观数据与剔除一次性后的偏差。

**判断标准**：“不错”若建立在超低预期上，要点明其关键是没有陷入“销量差到业绩烂”的恶性循环；若交付端已把预期拔高，则利润端的不及预期要被单独强调。

**海豚案例**：
- 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：所谓“不错”是建立在超低预期上，关键是没陷入“销量差到业绩烂”。
- 比亚迪《宇宙车厂…》（2026-04-28）：“低预期下还不错”。
- 特斯拉《造车罕见回血…》（2026-04-23）：“表观强劲、实际也具备一定韧性”。
- 特斯拉《造车硬抗…》（2026-07-23）：利润端不及预期。

**适用场景与注意事项**：通用于财报点评写作。“表观 vs 实际”的数字拆法（汇率、一次性）见2.4。

### 2.1.6 “预防针”情境下的业绩质量判断

**方法要点**：管理层上季已提前沟通坏消息（如给出很低的毛利率指引、发布业绩预告），市场预期已被下修时，“达到低预期”本身没有信息量，要看“没有提前沟通的项目”有没有继续恶化。

**操作步骤**（三条判断标准）：
1. 实际值是否只是刚好达到低预期。
2. 没有提前沟通的项目（单价、下季指引、经营利润、现金流）有没有继续恶化。
3. 净利润是否靠非经营性收益托底。
4. 结论写成“即使在悲观预期下，业绩本身也比较一般”。反过来，若公司已发布业绩预告，实际仍超预告上限，则判定为全面超预期。

**关键指标与数据来源**：上季指引、一致预期、业绩预告区间；未沟通项目（ASP、下季指引、经营利润、FCF）。

**判断标准**：已打预防针的指标只是“及格线”；真正区分好坏的是 ASP、下季指引、经营利润、FCF 等未沟通项目。预告被突破、净利润实质转正（而非靠非经营收益）才算全面超预期。

**海豚案例**：
- 理想 4Q25（2026-03-12）：毛利率符合指引，但 ASP 低于预期，收入指引大幅低于预期，判断为“真实的卖车单价和卖车毛利率都呈现环比下滑”。
- 理想 1Q26（2026-05-29）：毛利率6.1%只比低预期高约1pp，但经营利润-30亿、FCF -74亿，结论为“卖车单价与卖车毛利率的再次暴跌，直接导致经营利润与自由现金流的显著失血”。
- 蔚来 4Q25（2026-03-10）：已有预告，但经营利润8亿高于预告上限，净利润1.2亿对比市场预期-6亿，结论为全面超预期。

**适用场景与注意事项**：适用于管理层习惯提前沟通（预告、指引、业绩前喊话）的公司。要结合股价在财报前的反应，判断“利空出尽”是否已经计价。

**本节速查清单**
- [ ] 绝对表现、预期差、边际趋势三个维度是否分别写了结论？是否点明哪一维对股价最关键？
- [ ] 开头句是否同时交代“相对谁的预期”和“剔除一次性后”的口径？
- [ ] 当期与指引是否分别对标？指引的权重是否高于当期？当季已被月报或全年指引锁定时，是否下调了当期权重？
- [ ] 是否说明预期水平高低（超低/低/高）及其背景（补贴退坡、销量低谷、股价走势）？
- [ ] 低预期下的超预期：是否核对了第三方数据（如 PC 出货）和市场预期，而不只看公司指引？
- [ ] 有预告或预防针时：是否检查了未提前沟通的项目（ASP、下季指引、经营利润、FCF）和净利润的非经营托底？
- [ ] 是否核对了财报前股价走势和预期修正轨迹，避免把“绝对好”误判为利好？

## 2.2 逐项对标与区间定位

> 本节导读：定性之后，要把每个能量化的指标逐项放到“实际 vs 预期/指引”下比对，并判断实际值落在指引区间、预告区间或卖方预期区间的哪个位置。本节是财报开头“核心数据摘要”的标准做法，回答“哪些 beat、哪些 miss、落在区间的什么位置”。对未来指引的对比见9.1；预期基准的分层与选择见1.1；对 beat/miss 的来源归因见2.3，质量检验见2.4。

### 2.2.1 逐项对标一致预期的 beat/miss 清单

**方法要点**：不只比总收入，把每一个能量化的指标（收入、毛利率、分业务收入、指引、EPS、出货量、单位利润、分部利润率）都放进“实际 vs 市场预期”，列出 beat/miss 清单，先定位最大的偏差项，再追溯驱动。

**操作步骤**：
1. 列出总量：总收入、毛利额、毛利率、经营利润、EPS。
2. 列出分部：各分业务收入、分部毛利率、分部经营利润率；有关键经营量的（出货量、GMV、同店）一并列出。
3. 列出指引：下季收入和 EPS 指引区间，同时看中值和上沿能否覆盖预期。
4. 标注“超/符合/低于”，先定位哪一项 miss/beat 最大，再追溯驱动因素。
5. 区分“当季 beat/miss”和“指引 miss/beat”：指引往往对股价影响更大。

**关键指标与数据来源**：彭博一致预期或卖方一致预期；分部一致预期；经营量预期（出货量 GWh、单 Wh 净利等）。

**判断标准**：
- 收入符合、毛利率低于预期 → 盈利质量变差。
- 指引区间的上沿都低于预期 → “指引爆雷”，意味着下季收入和毛利率继续下滑。
- 分部有的符合、有的略低 → 要找到具体拖累来源。
- 周期制造业把出货量预期和单位利润预期分开看，判断超预期来自量还是来自价和利润，再把“全线超预期”“量超利不及”这类组合写进标题。
- 业务多元的公司要逐分部比较，避免总量 beat 掩盖结构问题。

**海豚案例**：

变体 A：总量 + 分部 + 指引 + EPS + 经营量
- 高通（2026-04-30）：收入106亿 vs 105.6亿符合；GM 53.8% vs 54.6%低于；手机60 vs 60.6；汽车13 vs 13；IoT 17 vs 17.8略低；FQ3 收入指引92-100亿 vs 102亿、EPS 2.1-2.3 vs 2.38，定性“指引爆雷”。
- 高通（2026-07-30）：收入99.5 vs 96好于；GM 53.1 vs 54.6低于；指引97-105 vs 99.5符合；EPS 2.05-2.25 vs 2.36低于。
- 宁德《无可撼动...》（2026-04-16）：收入1291 vs 1142、出货200+ vs 168GWh、净利207 vs 176，定性“全线超预期”。
- 宁德《风光宁王，暗藏“虚火”？》（2026-07-25）：收入1478 vs 1486持平，出货232 vs 222超，GM 23.2% vs 25%、净利225 vs 234、单 Wh 净利0.097 vs 0.106不及，标题定性“虚火”。

变体 B：总量 + 分部 + 经营量 + 毛利额 + 分部经营利润率，定位最大偏差
- 阳光电源《平地起惊雷》（2026-04-01）：Q4 收入228亿 vs 预期306亿；储能84.9亿 vs 132.5亿；逆变器77.4亿 vs 94亿；出货33GW vs 54GW。
- 阳光电源《收入倒春寒》（2026-04-28）：Q1 收入156亿 vs 212亿。
- SpaceX《SpaceX豪赌AI，千亿大饼香吗？》（2026-08-05）：收入78亿 vs 69亿，毛利43亿 vs 37亿，经营利润-1.4亿 vs -16.8亿；发射9.6亿 vs 8.7亿，星链42.9亿 vs 38.8亿，AI 25.6亿 vs 20.8亿；发射经营利润率-56% vs -86.4%，AI 经营利润率-49% vs -115%。
- Rocket Lab《中子号或延期》（2026-08-11）：毛利率36% vs 34%，经营利润-0.58亿 vs -0.63亿。
- Shopify《业绩不俗却暴跌》（2026-02-12）：GMV 增速31% vs 28%，毛利率46.1% vs 46.4%。

变体 C：分业务逐项对标，把整体预期差归因到具体分部
- 做法：对每一个披露的分部（汽车、手机、IoT、互联网、iPhone、Mac、iPad、可穿戴、服务）和整体收入、毛利率、费用，写出实际值与市场预期值，标注“好于/符合/低于”，再把整体预期差归因到具体分部；若财报与此前 Preview 沟通一致，也要注明，说明信息已被市场消化。
- 小米《又双叒原地久跪…》（2026-08-18）：汽车249亿（预期255亿），汽车毛利率19.2%（预期20.5%），手机421亿（预期413亿），IoT 313亿（预期309亿），互联网90亿（预期92亿），核心利润不及预期主要因汽车均价和毛利率下滑。
- 苹果《硬刚涨价…》（2026-07-31）：Mac 104亿（预期89亿），是唯一超预期的项目；iPad 62亿（预期66亿）。
- 小米《天堂急跌地狱…》（2026-03-24）：与此前 Preview 沟通的基本一致。

**适用场景与注意事项**：适用于卖方覆盖成熟的大市值公司；缺少单季预期的 A 股、港股或新股要换基准（预期基准校正见1.1）。区间指引要同时看中值和上沿。分部预期需要有足够的卖方覆盖。

### 2.2.2 “实际值—环比变化—一致预期”三元组逐项打分

**方法要点**：财报点评开头的核心数据摘要，对每个关键科目都给出三个数：实际值、环比（或同比）变化、市场预期，并标注超/符合/低于，再按固定顺序推导最终利润为什么 beat 或 miss。

**操作步骤**：
1. 选定关键科目：总收入、分业务收入、毛利率、分业务毛利率、研发、销售、Adjusted EBITDA、核心经营利润、净利润、单车 ASP、单车毛利。
2. 每个科目写三元组：实际值 / 环比或同比变化 / 市场预期，标注超、符合或低于。
3. 按“收入 → 毛利率 → 费用 → 利润”的顺序推导最终利润为什么 beat 或 miss，例如“收入超预期 + 毛利率环比上行 + 三费控制合理，所以 EBITDA 高于预期”。

**关键指标与数据来源**：彭博或卖方一致预期中各科目的预期值；实际值；环比和同比。

**判断标准**：利润的 beat/miss 必须能沿着“收入→毛利率→费用→利润”这条链条逐层解释，链条上哪一环偏差最大，哪一环就是主因。

**海豚案例**：
- Rivian（2026-02-13）：4Q25 收入12.9亿，预期12.6亿；毛利率9.3%，预期3.4%；Adj. EBITDA -4.7亿，预期-5.7亿；调整后净利-6.6亿，预期-8.3亿。
- 小鹏（2026-03-20）：收入223亿，预期208亿；汽车收入191亿，预期184亿；卖车毛利率13%，预期13.9%；服务收入32亿，预期23.5亿；研发28.7亿，预期24.8亿；销管27.9亿，预期23亿。
- 三花（2026-08-27）：收入增速6%，预期8%；毛利率28.3%，预期29.2%。
- 吉利（2026-03-18）：收入1057亿，预期1043亿。

**适用场景与注意事项**：通用的财报点评开头格式，需要一致预期数据库。

### 2.2.3 “实际 vs 公司指引 vs 市场一致预期”三方比对

**方法要点**：对毛利率、收入、出货量、费用、利润等关键指标，同时列出公司上季给的指引、市场一致预期和实际值，判断落在哪种组合。指引和市场预期往往不同，市场可能已在指引基础上上调或下调，所以两者都要比。

**操作步骤**：
1. 从上季电话会和财报中取公司指引。
2. 取市场一致预期（通常为彭博/卖方一致预期）。
3. 列出实际值，判断落在哪种组合：符合指引但略低于预期、处于指引上限、超指引上限、不及指引、位于指引下限，等等。
4. 若公司不给指引，退化为实际与一致预期的两方比较。

**关键指标与数据来源**：公司上季指引（电话会、财报）、市场一致预期、实际值。

**判断标准**：实际值相对指引的位置体现管理层的掌控力；相对一致预期的位置体现预期差；两者背离时要分别说明（例如：处于指引上限，但仍略低于市场预期）。

**海豚案例**：
- 理想（2026-03-12）：4Q25 卖车毛利率16.8%，指引15.8%-16.8%处于上限，市场预期16.6%。
- 理想（2026-05-29）：1Q26 6.1%，指引约5%，一致预期约5%。
- 理想（2026-08-26）：2Q26 9.4%，略低于10%指引。
- 蔚来（2026-03-10）：4Q25 18.1%，指引18%，市场18.1%。
- 蔚来（2026-05-21）：1Q26 18.8%，指引为与上季持平，市场18.2%。
- 蔚来（2026-09-01）：2Q26 18.5%，指引17%-18%，市场17.6%。
- 禾赛（2026-03-24）：4Q25 毛利率41%，指引40%，市场39.7%；收入10亿位于10-12亿指引下限，市场10.8亿；出货63.1万，指引60万，市场61.9万。

**适用场景与注意事项**：适用于所有提供季度指引的公司。市场预期的来源文中通常未注明，一般为彭博或卖方一致预期，使用时应自行确认口径。

### 2.2.4 实际值在公司指引区间中的位置（下限/中枢/上限/超上限）

**方法要点**：对收入、出货、净利润等给区间指引的指标，标明实际值落在区间的什么位置，以及海豚君自己的全年预测落在全年指引区间的什么位置，作为质量评价的一部分。

**操作步骤**：
1. 取公司区间指引（或“不低于X%”这类下限式指引）。
2. 用“偏下限、中上、中枢、上限、超出”等措辞，标明实际值的位置。
3. 对全年指引，标明海豚君自己的全年预测落在区间的位置。
4. 优先以公司自身给出的季度/年度指引为基准判断是否超上限；再与市场预期并列看（见2.2.3）。
5. 区间宽度本身也是信息：区间宽，说明管理层的不确定性高。

**关键指标与数据来源**：公司区间指引、实际值、海豚预测值。

**判断标准**：超上限是明确的超预期；落在下限或偏下限是偏弱信号；落在中值则大体符合管理层自己的预期。

**海豚案例**：
- 禾赛 4Q25（2026-03-24）：收入约10亿，在10-12亿下限；GAAP 净利润1.5亿，在0.7-1.7亿上限；出货63.1万，超过60万指引。
- 禾赛 1Q26（2026-05-19）：收入6.8亿，在6.5-7亿的中上位置；出货47.7万，超过40-45万。
- 禾赛 2Q26（2026-08-19）：收入8.6亿，在8.5-9亿偏下限；全年收入预测44.8亿，在42-46亿中轴；净利润5.2亿，在5-7亿偏下限。
- 蔚来 1Q26（2026-05-21）：交付8.35万辆，略超指引上限。
- 理想 4Q25（2026-03-12）：销量10.9万，在10-11万指引偏上限。
- 名创优品《大店增收，海外增利…》（2026-04-01）：4Q25 营收62.5亿，+32.6%，超20%-25%指引。
- 名创优品《AI投资开挂…》（2026-05-26）：1Q26 营收56.9亿，+28.5%，超“不低于25%”。
- 老铺黄金《高位增发…》（2026-03-23）：2H25 营收149亿落在指引中值，小超市场预期147亿。

**适用场景与注意事项**：通用。有指引或盈利预告的公司（港股常见）；区间宽度本身要读；位置判断要和市场预期的位置并列。

### 2.2.5 跌破公司指引下限：比低于卖方预期更严重的信号

**方法要点**：实际收入不仅与一致预期比，还要与公司自己三个月前给出的指引区间对照，算出低于下限的绝对金额。跌破下限，说明管理层对经营的掌控力弱。

**操作步骤**：
1. 取公司上季给出的指引区间上下限。
2. 计算实际值与下限的差额（绝对金额）。
3. 结合同店/可比销售等核心经营指标，以及下季指引是否继续下修，解释股价反应。

**关键指标与数据来源**：指引区间上下限、实际值与下限的差额、可比销售、下季指引。

**判断标准**：跌破指引下限是比低于卖方预期更严重的信号，管理层自己都没有算准；再叠加下季指引继续下修，就足以解释股价暴跌。

**海豚案例**：
- Lululemon《Alo围剿、经典老去…》（2026-09-04）：2Q26 营收24.2亿美元，低于6月初指引24.5–24.8亿美元的下限约3500万美元；可比销售-9%，为疫情以来最差；叠加三季度营收指引-10%至-11%，盘后跌18%，跌破52周新低。

**适用场景与注意事项**：适用于给出季度指引的美股公司，尤其是困境中的公司。

### 2.2.6 业绩预告区间定位（A股/港股/主动预告的美股）

**方法要点**：公司已发布业绩预告或盈利预警时，把实际值放到预告区间里定位（下限、中枢、上限、超上限），区分 GAAP 与调整口径；预告还可用来倒算下半年或单季。

**操作步骤**：
1. 比较实际值落在预告区间的位置，并区分 GAAP 口径与剔除 SBC 的调整口径；确认预告与实际口径一致。
2. 若超预告上限，即使已有预告，也定性为超预期。
3. 年报或半年报出来后，先看落点（上限、中值、下限）及与机构预期的差距，再定位本季真正的变量（单季收入比机构预期低多少），把它作为影响利润的最大因素做深入归因。
4. 用全年预告减去上半年，得到下半年隐含值；结合“收入 miss、利润 beat”推断利润率超预期的原因（结构、广告、费用）。
5. 港股盈利预告落在区间下沿时，推断季末月份比公司自己预期的更弱。

**关键指标与数据来源**：业绩预告上下限和中值（GAAP、Non-GAAP）、实际值、机构预期、隐含下半年值、利润率。

**判断标准**：超预告上限 = 超预期；落在中值偏下或下限 = 弱于机构预期；落在预告下沿 = 季末月份比公司预期更弱；预告倒算出的下半年收入明显低于市场预期而利润却高于预期，说明利润率远高于预想。

**海豚案例**：
- 蔚来 4Q25（2026-03-10）：预告 GAAP 经营利润2-7亿，剔除 SBC 后7-12亿；实际经营利润8亿，超过 GAAP 口径上限；净利润1.2亿，市场预期-6亿；上市以来首次扭亏，“终于甩掉了万年巨亏的标签”。
- 三花《“天灾人祸”一起来？三花智控，没有那么差》（2026-03-31）：25年年报落在预告中值偏下、接近下限，弱于机构预期；Q4收入70亿，同比-5%，比机构预期低10亿以上，是影响利润的最大因素。
- 心动（2026-03-06）：全年收入不低于57亿（+14%），倒算下半年约26亿（-5%），市场预期34亿；净利不低于15.8亿，机构预期14-15亿，说明利润率明显高于预想，原因是自研游戏占比提升、TapTap 广告超预期、买量控制。
- 三花（2026-03-23）：业绩落在预告中值偏下、接近下限。
- Unity（2026-03-27）：Q1业绩预告收入和利润都超出指引，盘后大涨。
- 老铺黄金《金价颓了…》（2026-08-25）：1H26 198亿落在预告198-204.5亿下限，说明六月更弱。

**适用场景与注意事项**：适用于有预告制度的 A 股、港股，以及主动发预告的美股。要确认预告与实际的口径一致（GAAP 与调整口径、是否剔除 SBC）。

### 2.2.7 卖方预期区间定位法（落在区间上沿还是下沿）

**方法要点**：对于市场只给出区间、没有一致点值的指标（隐藏业务的亏损、分部利润），看实际值或倒推值落在卖方区间的哪个位置，并结合环比改善方向，区分“趋势向好但速度不及预期”和“趋势本身有问题”。

**操作步骤**：
1. 收集卖方预期区间（上限/下限）。
2. 取实际值；若公司不披露，则倒推（如闪购亏损）。
3. 定位：落在亏损区间上限 → 改善速度不及期待；落在利润区间下端 → 不够给力。
4. 结合环比改善方向一起看。

**关键指标与数据来源**：卖方预期区间、实际值或倒推值、环比改善幅度。

**判断标准**：区间位置只说明预期差的相对强弱；与环比方向结合才能判断是“速度问题”还是“趋势问题”。

**海豚案例**：
- 阿里《阿里：电商再沦陷》（2026-03-19）：倒推闪购亏损约250亿，落在市场预期200-250亿区间的上限，说明 UE 在改善但速度不及期待。
- 阿里《阿里：电商退位，AI上位》（2026-05-14）：中国电商集团 adj.EBITA 为240亿，处于卖方预期区间的靠下端；倒推闪购亏损约160-170亿，处于卖方区间的相对偏上位置。

**适用场景与注意事项**：适用于隐藏亏损、新业务利润等难以直接预测的指标。

**相关方法（交叉引用）**：分业务线对照公司指引识别“小业务”超预期、Beat 幅度跨季比较、分项一致预期对比，详见2.3；以上季管理层口风检验兑现度，详见9.6；卖方一致预期与买方真实预期的区分（“beat 但 miss”）、卖方一致/买方真实/公司指引三层比较、预期基准分层与区间定位，详见1.1。

**本节速查清单**
- [ ] 是否把总收入、毛利率、分业务收入、分部利润率、经营量、下季指引、EPS 逐项放进“实际 vs 预期”，并标注超/符合/低于？
- [ ] 每个关键科目是否写出“实际值—环比变化—一致预期”三个数？
- [ ] 指引类指标是否同时比较了“公司指引”和“市场预期”，并确认两者口径？
- [ ] 区间指引：是否同时看了中值和上沿能否覆盖预期，并说明实际值位于下限/中枢/上限/超上限？
- [ ] 是否算出了跌破指引下限的绝对金额？是否结合下季指引下修解释股价反应？
- [ ] 有业绩预告时：实际值落在预告区间的哪个位置？GAAP 与剔 SBC 口径是否一致？是否倒算了下半年或单季？
- [ ] 对没有点值预期的隐藏业务（亏损、分部利润），是否用卖方区间上沿/下沿定位，并结合环比方向？
- [ ] 是否先定位最大偏差项，再追溯驱动；是否区分“当季 beat”和“指引 miss”？

## 2.3 预期差来源归因

> 本节导读：知道“超了/不及了”之后，必须回答“差异来自哪里”：哪个分部、哪个科目、哪个价量因子贡献了预期差，以及这个来源能否持续。本节从收入端、分部利润、利润表科目、利润率、单位利润、跨季序列和“可算/不可算收入”七个角度给出归因方法，是2.4含金量检验的前置步骤。逐项对标的底表见2.2；对剔汇率、一次性等的单项剔除见第4章与8.8；指引与股价反应分别见第9章、第11章。

### 2.3.1 总收入预期差拆到分部/子业务：谁贡献了超预期

**方法要点**：把总收入的预期差（或环比增量）一路拆到分部、子业务，找出真正贡献超预期或不及预期的那一块。它常常不在市场焦点业务，而在被忽视的业务或体量小的业务。

**操作步骤**：
- 变体 A：全面超预期时找主要来源。市场已提前上调热门业务（如 AI）预期时，真正的惊喜往往来自被忽视的业务（如传统服务器）。反过来，当季核心指标不及预期、但前瞻指标大幅超预期时，以前瞻指标定性。
- 变体 B：环比增量逐层拆分。先把总收入环比增量分到各业务线（ISG/CSG），再把 ISG 增量拆到传统服务器、AI 服务器、存储，找出本季预期差的主要来源。对该子项给出同比增速和市场预期对比，再定性拆需求来源：①存量客户更新换代；②agentic 工作流带来的 CPU 算力需求。逻辑是：预期差来自哪里，决定后续叙事能否持续。
- 变体 C：分业务线逐项对照公司指引。对比各业务线实际增速和公司指引区间（看是否超过上端），找出超预期的真正来源，常常是体量小的业务（商旅、打包游、广告）；对指引过于保守的业务（隐含增速很低）要点明；超预期的业务还要追问驱动（渗透率提升、出境游、海外广告），判断能否持续。
- 变体 D：总收入超指引上限后再问“超在哪个分部”。对比市场对各分部的隐含预期：市场对高增长分部预期本来就高，实际高增也只算符合预期；被市场忽视的分部才是超预期的关键；再对超预期分部做归因。

**关键指标与数据来源**：分业务实际值 vs 分业务预期值；分业务收入、环比增量、同比增速、子项 vs 市场预期；各业务线收入及同比、公司分业务指引区间、隐含增速；总收入同比 vs 公司指引区间、分部收入同比与占比变化、市场对各分部的预期（可从卖方模型推断）。

**判断标准**：
- 超预期的“含金量”看来源：来自被市场忽视的、预期低的业务，才是真正的预期差；来自预期高的业务，只是符合。
- 子项增量来源决定叙事能否持续（存量更新换代 vs 新增需求）。
- 指引保守的业务，其超预期要先扣除“指引本身太低”的成分。

**海豚案例**：
- 戴尔（2026-05-29）：AI 服务器的预期在财报前已上调，最大的预期差在传统服务器：收入85亿，同比+92%，远超预期50亿，而市场原本只预期“稳中有升”；ISG 收入290亿，预期249亿。
- 戴尔（2026-02-27）：AI 收入89.5亿，不及预期94亿；但订单341亿远超110亿，指引也大超预期，整体定性为订单“炸裂”（以前瞻指标定性）。
- 戴尔（2026-09-02）：总收入470亿、同比+58%、环增31亿，主要来自 ISG；ISG 318亿、环增28亿（预期297亿）；传统服务器约105亿、同比+122%（预期94亿），被认为“是本季度预期差的主要来源”，AI 业务环增不明显。
- 携程《携程：监管“重锤”之后，还能“小而美”吗？》（2026-02-26）：4Q25 总收入154亿，+21%；酒店+21%，超过指引18%~19%的上端；票务+12.3%；商旅8.1亿，+15%，远好于指引（原指引隐含4%，过于保守，超预期原因是企业商旅渗透率提升）；打包游10.6亿，+21%；广告等其他收入+54%，主要来自出境和海外广告。
- 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：商旅6.9亿，+20%，是唯一加速的业务；广告+33%，跑赢预期10pct以上。
- 华住《华住：深蹲起跳后…》（2026-03-18）：Q4 营收65.3亿，+8.3%，超出2%-6%指引上限；加盟业务+21%（环比略降速），占比+4.8pct 至46.3%，但市场预期高，只算符合预期；直营32.7亿，-3.2%，降幅收窄，小幅超预期，是营收超预期的关键，推测禧玥、花间堂等高端直营表现优异（归因：一线城市商务恢复带动自营 ADR，高端直营品牌充当稳定器）。

**适用场景与注意事项**：适用于多业务线公司，尤其是市场焦点业务和真实增量来源不一致时；需要分业务的一致预期数据；子项常为估算，需注明；分业务指引的公司（携程）可用变体 C。

### 2.3.2 分项一致预期对比与“惊艳度”：预期高低决定预期差大小

**方法要点**：不只比较总量，还对比关键分项（销量、价格/组合、内生增速、EBITDA、同店、收入增速、利润率改善幅度、会费收入、电商增速）的市场预期，找出“超预期的关键”来自哪个分项、哪个分项小幅不及；同一份财报里，预期原本高的业务即使表现很好，预期差也小。

**操作步骤**：
1. 列出行业特有的关键分项（量、价/组合、内生增速、同店等）。
2. 逐项比较实际与一致预期。
3. 找出超预期的关键分项，以及小幅不及的分项。
4. 判断每个分项的“预期基础”：市场预期高的业务，表现好也只算符合；市场原本担忧的业务表现好，才最惊艳。
5. 据此判断 beat 的结构、质量和可持续性。

**关键指标与数据来源**：彭博/市场一致预期分项值；营收、利润率改善幅度、分业务收入与市场预期。

**判断标准**：“惊艳度” = 实际表现 − 市场预期，而不是实际表现本身。量增、内生增长这类更本质的分项超预期，质量高于价格/组合的小幅波动。

**海豚案例**：
- 可口可乐（2026-07-28）：浓缩液销量+4%（市场预期1%）为超预期关键，价格/组合+2%小幅不及，内生+6% vs 一致预期3.6%。
- 华住（2026-05-15）：调整后 EBITDA 18.6亿，+24%，vs 一致预期17.7亿。
- 沃尔玛（2026-08-21）：美国同店+2.6% vs 一致预期3.8%。
- Monster（2026-08-07）：收入+20.2% vs 一致预期+15.1%。
- Costco（2026-03-06）：经营利润率+0.1pct，低于预期的+0.2pct；商品销售+9.2%，好于预期8.5%。
- Costco（2026-09-25）：营收957亿，略好于预期949亿；会费+7.3%，好于预期6.3%。
- 农夫山泉《防御转进攻，“水茅”强势狂飙！》（2026-03-25）：茶饮表现亮眼，但市场对无糖茶预期一直较高，预期差不如包装水（价格战担忧下表现好）惊艳。

**适用场景与注意事项**：所有财报点评都适用。分项一致预期需要彭博或大行模型。

### 2.3.3 寻找被市场忽视的次要业务预期差

**方法要点**：市场聚焦某一业务（尤其是股价被单一业务主导）时，检查其他业务的指引或表现是否超预期，以及其盈利状态和背后驱动，作为反驳过度悲观的证据；同时用来跟踪次要业务的风险（AI 替代、销售周期结束）。

**操作步骤**：
1. 先确认市场焦点业务是什么。
2. 逐一检查其他业务的指引和实际表现，是否超预期。
3. 查其盈利状态（如已实现 non-GAAP 盈利）与驱动（新产品采用、区域需求）。
4. 把结论放进“反驳过度悲观”或“新增风险”的论证。

**关键指标与数据来源**：次要业务指引与实际、盈利状态。

**判断标准**：次要业务指引超预期 + 已盈利 + 驱动清晰 → 可作为反驳悲观叙事的证据；次要业务表现平庸 → 短期有压力，需纳入风险清单。

**海豚案例**：
- Unity（2026-02-12）：Create 业务 Q1 指引实际超预期，反映 Unity 6 的快速采用和中国市场强劲需求，且已实现 non-GAAP 盈利。
- Unity（2026-08-07）：Create 表现平庸，短期有压力。

**适用场景与注意事项**：多分部公司，股价由单一业务主导时。

### 2.3.4 分部利润预期差逐分部比较：找“元凶”，区分表面 miss 与真正 miss

**方法要点**：把集团利润的预期差拆到各分部：核心业务利润与预期比、新业务亏损与预期比，找出真正的来源；必要时用上市子公司公告交叉验证。

**操作步骤**：
1. 按分部分别比较收入和经营利润与彭博一致预期，找出不及预期的“元凶”。
2. 区分表面 miss 与真正 miss：核心业务利润虽同比下降，但仍好于预期，则不是真 miss；新业务亏损收窄幅度低于预期，才是真问题。
3. 有上市子公司时，用其公告拆内部和外部客户收入，识别增长是否来自集团内部（外部客户收入基本没增长），并解释子公司利润为什么受拖累（如闪购和外卖配送利润率低甚至亏损）。

**关键指标与数据来源**：分部收入、分部经营利润、彭博分部预期、子公司内部/外部客户收入、新业务亏损。

**判断标准**：同比下降 ≠ 不及预期（要对比的是预期而不是去年同期）；真正的 miss 看“预期差”而不看“同比方向”；子公司增长靠集团内部时，增长含金量打折扣。

**海豚案例**：
- 京东（2026-03-05）：商城利润98亿，同比-2.5%（前三季每季约130-150亿，国补红利期），但好于彭博78亿；新业务亏损148亿 vs 预期138亿，收窄幅度低于预期，是不及预期的元凶；调整后经营亏损31亿（上次亏损要追溯到2017年）；JDL 收入+21%主要靠集团内部即配业务，外部客户收入基本没增长，利润仅+3%。
- 京东（2026-05-14）：商城利润近150亿，+16.5%，远好于预期126亿。
- 京东（2026-08-13）：商城利润近135亿，略高于彭博约130亿，同比约-3%；创新业务亏损近99亿，略高于彭博。
- 阿里（3QFY26）：国际电商营收增长不到4%，是真正的 miss；其他板块亏损近98亿 vs 已上调到85亿的指引，也是真正的 miss。
- 美团（2026-03-26）：新业务亏损比预期多约12亿。
- 滴滴（2026-03-13）：国内 adj.EBITA 26亿（+20%），海外亏损34亿 vs 上季17亿、预期21亿。

**适用场景与注意事项**：适用于有分部披露或有上市子公司的集团，以及多业务的互联网集团。

### 2.3.5 分部经营利润率三值对比：预期 / 实际 / 去年同期

**方法要点**：把整体利润超或不及预期拆到每个分部：列出实际利润率、市场预期利润率、去年同期利润率，以及利润额 vs 预期，得出“利润超预期主要靠谁”；对受 AI 投入影响利润率下滑的业务，看下滑幅度是否小于卖方担忧，并判断这一趋势能否避免。

**操作步骤**：
1. 取每个分部：分部经营利润、分部利润率（预期/实际/去年同期）。
2. 比较利润额 vs 预期、利润率 vs 预期、利润率同比变化。
3. 找出超预期的功臣分部。
4. 对利润率下滑的分部，判断下滑幅度是否小于卖方担忧，以及长期趋势是否可避免。

**关键指标与数据来源**：分部经营利润；分部利润率（预期、实际、去年同期）。

**判断标准**：功臣分部 = 利润额超预期最多的分部；利润率下滑幅度小于卖方担忧是“好于预期”，但大趋势（如因投入加大而下行）不会因此改变。

**海豚案例**：
- 亚马逊（2026-04-30）：北美零售经营利润率7.9% vs 预期6.7% vs 去年同期6.3%；AWS 利润率37.3% vs 预期33.7%，经营利润约142亿 vs 预期124亿，同比+23%，利润率同比仅降1.8pct；结论是利润超预期主要靠北美和 AWS，但 AWS 利润率继续下行的大趋势无法避免。
- Uber（2026-02-05）：Mobility adj.EBITDA 利润率8%（环比-0.1pct）vs 预期8.1%；外卖4%（环比+0.1pct）vs 预期4.1%。
- Meta（2026-07-30）：FoA 分部利润率环比走低10pct。

**适用场景与注意事项**：有多分部披露的公司。分部利润率的一次性费用识别见8.7。

### 2.3.6 多分部公司逐分部给“预期差 + 趋势”判断

**方法要点**：对多分部公司逐个分部给结论：收入相对预期、利润率同比、驱动因素（客流×人均、量价）、风险点；引用竞品电话会信息作为预期锚，最后汇总为“有喜有忧”等结论。

**操作步骤**：
1. 每个分部写：收入 vs 预期、利润率同比、驱动（客流 × 人均、量 × 价）、风险点。
2. 引用竞品或同业电话会信息，作为预期锚。
3. 汇总成总判断（如“有喜有忧”）。
4. 对尚未披露的单价、ARPU 等，推算后写出（并标注为推算）。

**关键指标与数据来源**：分部收入、分部经营利润率、客流、人均消费。

**判断标准**：不同分部的预期差与趋势可能方向不同，最后的汇总判断要说明哪个分部决定整体观感。

**海豚案例**：
- 迪士尼（2026-08-05）：Experience 经营利润率30%+（+3ppt），本土客流+3%、人均+4%，Comcast 电话会的悲观信息构成预期锚；Entertainment 利润率15%，电影不及预期；Sports 利润率-5ppt。
- SpaceX（2026-08-05）：推算发射单价从5400万升到6500万，毛利率约66%；星链 ARPU 66美元/月，用户1200万；AI 业务毛利率约57%。

**适用场景与注意事项**：综合性集团。

### 2.3.7 利润预期差“对账”归因：金额能对上才算归因完成

**方法要点**：整体利润超或不及预期时，逐层寻找金额能“完全匹配”差额的来源，找不到金额对得上的科目就不算归因完成。

**操作步骤**：
1. 分部层：找到差额近似等于整体预期差的分部。例如核心本地商业实际亏20亿 vs 预期40亿+，差额≈整体超预期的约20亿。
2. 科目层：进一步找金额对上的科目。例如毛利率低于彭博预期，可排除“收入减项下降”这一来源；营销费用约230亿 vs 预期250亿+，差值约20亿正好对上，结论：超预期的根本原因是消费者红包补贴减少。
3. 分部超预期但整体只符合预期时，找抵消项（新业务多亏、非经营收益）。
4. 剔除非经营性项目后，再核对一次。

**关键指标与数据来源**：分部经营利润 vs 预期、毛利率 vs 预期、各费用 vs 预期。

**判断标准**：归因的标准是“金额对得上”，而不是“方向对得上”；整体与预期一致不代表分项都与预期一致，要找抵消项。

**海豚案例**：
- 美团《美团：AI 分走战火，终能回口老血了？》（2026-06-01）：整体经营亏损65亿 vs 预期90亿；剔除非经营性后实际多赚约20亿，与本地商业及营销费用差额完全匹配。
- 美团《美团：三山压顶，外卖“老登”要长跪不起？》（2026-03-26）：新业务亏46亿 vs 预期35亿，被22亿非经营收益抵消后，整体与预期一致。

**适用场景与注意事项**：有分部利润披露和细项一致预期的公司。

### 2.3.8 利润超预期来源的量化分解：毛利端 vs 费用端，分板块贡献

**方法要点**：利润超预期时，拆出超预期的金额分别来自毛利端、费用端、哪个板块，并判断哪个来源更可持续（毛利率结构性改善比一次性控费更可持续）。

**操作步骤**：
1. 利润表维度：毛利比预期高多少、费用比预期少多少，量化每一部分。
2. 分部维度：哪个板块贡献了利润超预期，是靠营收规模还是靠利润率。
3. 判断可持续性：毛利率结构性改善 > 一次性控费。
4. 必要时再给每个来源写原因（如对供应商压价、红包补贴减少）。

**关键指标与数据来源**：毛利额相对预期的偏差、费用相对预期的偏差、分部贡献利润相对预期的偏差、毛利率和费用率变化（pct）。

**判断标准**：毛利端贡献大于费用端 → 质量更高；超预期主要靠营收规模还是靠利润率，决定增长质量。

**海豚案例**：
- 贝壳《“跪太久”贝壳》（2026-05-20）：调整后净利润约16亿，同比+16%（市场预期约11.5%）；其中毛利比预期高约2.4亿，费用比预期少约1.6亿，毛利改善的贡献更大；租赁利润额比预期高34%，是最超预期的板块。贝壳速读（2026-05-19）同样量化：超预期近5亿，其中毛利率贡献约2.4亿，费用节省约1.6亿。
- 贝壳《一线再松绑》（2026-08-21）：调整后净利润31.8亿（市场预期约24亿），超预期主要来自一航道（营收增长加利润率改善）；毛利率环比+4.5pct 是主要功臣，费用率环比-1.2pct 为次要因素。
- Sea：游戏板块多贡献约1.3亿。
- 美团：营销费用少约23亿。
- 京东：商城毛利率+1.8pct，推测来自对供应商压价。
- 唯品会：毛利率是最大亮点。

**适用场景与注意事项**：适用面广；需要拆到分部或利润表科目层面的一致预期。

### 2.3.9 利润超预期归因：毛利率扩张还是费用率摊薄

**方法要点**：把经营利润率的变化拆成“毛利率变化 + 经营费用率变化”，回答“利润超预期主要靠 X 而非 Y”。

**操作步骤**：
1. 看毛利率同比变动，并与上季的变动幅度比较（判断是否延续既有趋势）。
2. 看总经营费用增速与营收增速：两者持平，说明费用率没有摊薄、费用端贡献有限。
3. 找出增速异常的费用科目（如研发+29%）。
4. 结论写成“利润超预期主要靠X而非Y”。

**关键指标与数据来源**：毛利率；经营费用总额与增速；各费用科目增速；费用率。

**判断标准**：毛利率提升且幅度与上季相当 → 趋势延续；费用增速≈营收增速 → 没有摊薄；费用绝对值下降（如 Applovin）→ 利润率优化来自费用端。

**海豚案例**：
- 亚马逊（2026-04-30）：毛利率51.8%，同比+1.2pct（与上季幅度相当）；经营费用698亿略高于预期，同比+16.3%与营收大体持平，所以利润超预期主要靠毛利率提升而非控费；研发+29%。
- Spotify（2026-02-10）：利润超预期来自毛利率提升、研发同比-20%、Social charge 下降。
- Applovin（2026-02-12）：EBITDA 利润率84%，优化主要来自经营费用绝对值下降。

**适用场景与注意事项**：通用。分项费用与预期的对账见2.3.11。

### 2.3.10 利润率偏差分解：费用率偏差与毛利率偏差（bps）的相对大小

**方法要点**：利润率相对预期的偏差 = 毛利率偏差 − 费用率偏差。比较两者的 bps 大小，就能解释利润率是 beat 还是 miss；再落到公司和市场最关注的指标（如 FCF margin）的偏差。

**操作步骤**：
1. 计算毛利率偏差（实际 − 预期，bps）。
2. 计算费用率偏差（实际 − 预期，bps）。
3. 利润率偏差 = 毛利率偏差 − 费用率偏差，比较两项大小。
4. 再落到最受关注的指标，对比 FCF margin 与预期的差。

**关键指标与数据来源**：毛利率 vs 预期（bps）、费用率 vs 预期（bps）、FCF margin vs 预期。

**判断标准**：费用率比预期低170bps，大于毛利率比预期低的31bps，所以利润率好于预期；谁的偏差更大，谁就是利润率偏差的主因。

**海豚案例**：
- Shopify《业绩不俗却暴跌》（2026-02-12）：费用率低于预期170bps，毛利率低于预期31bps，利润率整体好于预期；FCF margin 约19.5%，高于预期0.5pct，FCF 同比+17%。

**适用场景与注意事项**：通用。

### 2.3.11 费用分项预期差的相互抵消分析

**方法要点**：把各费用分项分别和市场预期比较，找出哪些高于预期、哪些低于预期，判断它们是否相互抵消，从而解释为什么最终利润“与预期一致”；同时给每个分项的偏差找业务原因。

**操作步骤**：
1. 逐项比较研发、管理、营销等费用的实际值与预期值之差。
2. 判断是否相互抵消（有的高、有的低）。
3. 给每个偏差找业务原因，例如研发高于预期来自 AI 功能投入，管理费用低于预期体现高人效。
4. 汇总为总的利润预期差解释。

**关键指标与数据来源**：研发、管理、营销费用实际值与预期值之差；彭博或大行模型的分项一致预期。

**判断标准**：分项预期差相基本相抵 → 总利润符合预期，但内部结构有变化；费用整体比预期低（如低约2%）→ 利润好于预期。

**海豚案例**：
- 拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）：4Q25 管理费用同比-19%，低于预期；研发同比+32%，高于预期（AI 功能研发）；两者的预期差基本相抵，所以经营利润277亿和预期一致。
- 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：费用实际支出比市场预期低约2%，利润因此好于预期。

**适用场景与注意事项**：通用，需要分项一致预期数据。三费逐项与预期对账的更细做法见8.4。

### 2.3.12 毛利预期差拆到“收入端 vs 成本端”：判断不及预期的性质

**方法要点**：毛利或卖车毛利大幅不及预期时，不只看结果，要拆清是收入端（单价、结构）还是成本端（单位成本）没达到预期，由此判断是短期噪音还是长期逻辑受损。

**操作步骤**：
1. 收入端：单价、车型结构是否低于一致预期。
2. 成本端：单位成本是否符合一致预期。
3. 成本端符合预期（In-line）且存在季节性因素（淡季产量低、产能利用率下降）→ 成本走出淡季后回弹会很快。
4. 收入端因车型结构下沉、降价而不及预期 → 属于结构性问题，更值得担忧。

**关键指标与数据来源**：收入 vs 一致预期、单车成本 vs 一致预期、卖车毛利 Miss 幅度、产能利用率。

**判断标准**：成本端的季节性/原材料问题是短期噪音，收入端的结构下沉是长期逻辑受损。这是判断 beat/miss 质量的核心工具。

**海豚案例**：
- 零跑《剑指百万，毛利先“失守”？》（2026-05-15）：1Q26 收入108.2亿、同比+8%，不及预期；卖车毛利大幅 Miss 40pct，核心原因是低价车型（B+T+A 系列）占比上升拖累单车收入；卖车成本结合一致预期基本 In-line，成本端增量信息是淡季产量下降导致单台制造成本上升，以及原材料上涨。海豚君判断收入端的下沉更值得担忧。

**适用场景与注意事项**：适用于任何毛利不及预期的财报，需要分项的一致预期（收入、成本或毛利）。毛利率驱动归因框架见第7章。

### 2.3.13 单位利润（单车净利）偏差归因清单

**方法要点**：单车净利对比市场预期后，按固定清单归因偏差，并判断哪些是经营性可持续的、哪些是一次性的，以此决定是否改看“核心经营利润”口径。

**操作步骤**（固定清单）：
1. 毛利率修复力度；
2. 销售费用（清库、年末价格战、渠道投入）；
3. 其他收入（政府补贴）增减；
4. 负向杠杆（固定费用摊到单车）；
5. 汇兑损益等非经营项。
6. 逐条列出后，区分经营性/可持续与一次性，决定是否看核心经营利润口径。

**关键指标与数据来源**：单车净利、市场预期单车净利、毛利率、销售费用、其他收益/政府补贴、财务费用（汇兑）。

**判断标准**：偏差若来自毛利率修复不足和销售费用，是经营性问题；若来自政府补贴减少或汇兑损失，是非经营项，需剔除后看核心。

**海豚案例**：
- 比亚迪《王座失守…》（2026-03-28）：单车净利0.67万（环比约+500元），预期0.71万；原因是毛利修复偏弱、销售费用环比多出15.8亿、其他收入（估计是政府补贴）减少。
- 比亚迪《宇宙车厂…》（2026-04-28）：单车净利0.58万（环比从0.67回落），但预期只有0.34万；回落原因是清库折扣、销量-30%的负向杠杆、汇兑损失（财务费用同比约40亿负向变动）。

**适用场景与注意事项**：适用于单位利润追踪的制造企业。政府补贴、汇兑等项目需要从利润表附注识别。

### 2.3.14 利润率与利润额分开判断：收入超预期会让利润率的预期差变差

**方法要点**：收入或 GBV 显著超预期、利润额只是符合预期时，利润率其实低于预期；反过来，利润率略低于预期但规模超预期，利润额仍可能超预期。同时写出“利润额 vs 预期”和“利润率 vs 预期”两个结论。

**操作步骤**：
1. 先看利润额 vs 预期。
2. 再看利润率 vs 预期。
3. 对照收入/GBV 的预期差，解释两者为何背离（分母变大）。
4. 两个结论并列写出。

**关键指标与数据来源**：利润额；利润率；收入/GBV 预期差。

**判断标准**：收入大超 + 利润额符合 → 利润率低于预期，不是经营恶化；利润率略低 + 规模大超 → 利润额仍可能高于预期。

**海豚案例**：
- MELI（2026-08-06）：经营利润6.8亿、同比-17%，与市场预期大体一致；但收入超预期，经营利润率6.7%比预期低约0.2pct。
- Uber（2026-02-05）：外卖利润率4%低于预期4.1%，但订单额显著超预期，利润额仍高于预期；集团 adj.EBITDA 24.9亿、+35%，利润率4.59%低于预期4.77%。

**适用场景与注意事项**：增长型平台公司、收入波动大的公司。

### 2.3.15 超预期溯源：找出唯一的真实预期差并检验传导

**方法要点**：逐项比较 GMV、收入、毛利率、费用、经营利润相对预期的差异，找出最源头的那个超预期项，判断其他项的超预期是否由它机械传导出来；把“真实预期差”写成一句话：市场原以为 X 会放缓，实际没有。

**操作步骤**：
1. 逐项比较 GMV、MRR、商家服务收入、变现率、毛利率、费用、经营利润 vs 预期。
2. 找出最源头的超预期项（如 GMV 增速）。
3. 检验其他项是否由它传导：若毛利率和费用都与预期一致，则利润超预期完全来自收入，含金量有限。
4. 据此评估股价涨幅是否合理。
5. 用一句话写出真实预期差。

**关键指标与数据来源**：GMV、MRR、商家服务收入、变现率、毛利率、费用 vs 预期。

**判断标准**：超预期若只来自收入一个源头，且毛利率、费用均与预期一致，含金量有限；毛利率跑输而仅调整后经营利润超预期的组合，市场一般不喜欢。

**海豚案例**：
- Shopify（2026-08-05）：超预期的核心只有 GMV 增速（外加变现率+10bps），收入、毛利、经营利润的超预期都由此传导，含金量不值盘前30%的涨幅；真实预期差在于市场认为增速不可避免会明显放缓，实际却高位持平。
- CoreWeave（2026-08-12）：营收符合、毛利率跑输，只有调整后经营利润超预期，这种组合市场一般不喜欢。

**适用场景与注意事项**：高增长平台、SaaS；股价反应剧烈时用来验证涨跌幅是否合理。

### 2.3.16 Beat 幅度的跨季比较与超预期来源（价格 vs 出货）

**方法要点**：把每季度相对指引或预期的超出金额排成序列，判断超预期在扩大还是收窄；再归因超预期来自量还是价。

**操作步骤**：
1. 计算每季度：实际值 − 指引中值或上限；实际值 − 一致预期。
2. 排成序列，看 beat 幅度扩大还是收窄。
3. 归因：给指引时出货量基本确定，弹性几乎全部来自价格，所以 beat 收窄等价于涨价超预期在收窄。
4. 叠加其他约束（如长协设了天花板价，后续很难再大幅 beat）。
5. 单季 beat 幅度要结合指引给法（是否故意保守）一起看。

**关键指标与数据来源**：实际值 − 指引中值或上限；实际值 − 一致预期；超预期来源（量、价）。

**判断标准**：beat 从80亿收窄到40亿，减半，被判定为“好，但没那么惊艳了”；连行业垄断龙头都摸不清需求有多疯（实际远超指引上限和市场预期），说明需求/价格的不确定性很高。

**海豚案例**：
- 美光《美光：没了疯涨，长协真能撑起存储涅槃吗？》（2026-10-01）：上季收入超指引约80亿，本季只超约40亿，减半，beat 收窄；出货量基本确定，弹性几乎全部来自价格，等价于涨价超预期在收窄；加上长协（SCA）设了天花板价，后续很难再大幅 beat。
- 美光《美光：牛气冲天！…》（2026-06-25）：Q3 实际415亿，远超指引上限342亿和市场354亿，推断连行业垄断龙头都摸不清需求有多疯。

**适用场景与注意事项**：适用于给出单季指引的公司，尤其是价格弹性大的周期品。

### 2.3.17 区分公开可算的收入与不可见收入：预期差聚焦在不可见部分

**方法要点**：如果某类收入能用公开数据精确推算（稳定币储备利息 = USDC 流通规模 × 国债利率；券商交易量、融资余额按月公布），财报前就已定价，股价更多随公开变量波动；财报真正能产生预期差的是不可提前推算的项目。把分析重心放在这些项目上，同时警惕卖方对波动性收入的线性外推。

**操作步骤**：
1. 财报前先把可算部分算好（公开变量 × 费率）。
2. 识别真正可能产生预期差的项目：非利息的其他收入、经营效率（费用）、变现率/生息率、指引所体现的中长期战略。
3. 检查卖方是否对波动性收入（如融券收入）做线性外推。
4. 预期差分析集中在上述不可见项目上。

**关键指标与数据来源**：公开变量（USDC 市值、联邦利率、月度经营数据：获客、客资、交易流水、融资余额、融券收入）、其他收入、费用、变现率、指引。

**判断标准**：大部分收入可由公开数据算出 → 预期差只能来自非公开部分；股价大部分时间随公开变量（如 USDC 市值）变化，财报当天的看点只有其他收入、经营效率和指引。

**海豚案例**：
- Circle《Circle：用业绩回击唱衰…》（2026-02-25）：利息收入（占95%）基本透明，通过其他收入及分成占比、经营费用、指引判断管理层能力；USDC 规模和储备利率都公开，预期差在“其他收入”（环比加速）和毛利率（40%，环比+50bps）。
- Circle《Circle：稀烂行情…》（2026-05-11）：股价大部分时间随 USDC 市值变化，预期差只在其他收入、经营效率和指引。
- Coinbase《烂行情+烂业绩…》（2026-02-13）：稳定币利息分成（约20%）几乎公开可算，与预期一致；其他细项基本 miss。
- Robinhood《Robinhood：爆炒之后…》（2026-02-11）：公司按月公布获客、客资、交易流水、融资余额、融券收入，看点在资产变现率、生息率和费用率；收入12.8亿 vs 预期13.5亿，差5%，主要是市场线性多估了融券收入近5000万（上季0.9亿，本季不足0.3亿），交易收入2.2亿 vs 2.5亿。

**适用场景与注意事项**：适用于收入高度依赖公开变量的公司（稳定币、券商、交易所、航运、大宗商品生产商）。财报前先把可算部分算好。可预测收入与真实预期差在金融科技中的应用详见16.9。

**相关方法（交叉引用）**：剔除非核心收入后看核心业务收入的真实预期差，详见5.4；超预期来源归因（主业驱动 vs 高毛利授权、碳积分、一次性）与总收入超预期的核心 vs 非核心拆分，详见2.4；拆开提价带来的表观增量与模式转换对吨价的拖累来解释业绩不及预期的根因，详见16.7；分部经营利润率对比一致预期并识别一次性费用，详见8.7；三费逐项与预期对账，详见8.4；可预测收入与真实预期差（金融科技），详见16.9。

**本节速查清单**
- [ ] 总收入预期差是否拆到了分部/子业务？超预期来自被忽视的业务还是预期已很高的业务？
- [ ] 是否对照了分业务指引，找到体量小但超指引的业务？是否扣除了指引本身过于保守的成分？
- [ ] 分部利润是否逐一对比了预期？是否区分了“表面 miss”和“真正 miss”？
- [ ] 利润差额是否在分部或科目层面“金额对得上”？分部超预期但整体符合时，是否找到抵消项？
- [ ] 利润超预期是否量化为毛利端与费用端的贡献（金额或 bps）？哪个更可持续？
- [ ] 毛利 miss 是否拆到了收入端（单价、结构）和成本端（单位成本、季节性）？
- [ ] 利润额与利润率是否分开判断？收入大超是否稀释了利润率的预期差？
- [ ] 单位利润偏差是否按固定清单（毛利率、销售费用、其他收益、负向杠杆、汇兑）逐项归因？
- [ ] 公开可算的收入是否已在财报前算好？预期差是否聚焦在不可见项目（其他收入、变现率、费用、指引）？
- [ ] beat 幅度是否做了跨季序列比较？弹性来自量还是价？

## 2.4 超预期质量与含金量检验

> 本节导读：名义上的 beat 不等于好业绩。本节是“beat 是否掺水”的综合检验：超预期来自哪个板块、是否由汇率顺风/低基数/一次性项推动、是核心主业还是高毛利的非核心业务（授权、碳积分、子公司）带来、表观 miss 穿透后是否并不差、增长是内生还是承接竞品份额。使用时机是2.3完成来源归因之后，用来决定“该给多少权重”。本节只收综合判断，具体的汇率剔除、并购口径、一次性剔除方法归第4章与8.8；核心经营利润口径见8.1。

### 2.4.1 按板块重要性评估“超预期的含金量”，并结合预期基础

**方法要点**：beat 之后要问超预期来自哪个板块。来自重要性已下降的板块，含金量打折；来自最重要板块，整体观感才偏正面。同时看市场预期的基础，判断是否属于“低预期下的好业绩”。

**操作步骤**：
1. 列出各板块的超预期幅度。
2. 对板块按重要性排序（如电商第一、游戏降到第三）。
3. 判断超预期来自重要板块还是次要板块。
4. 看市场预期的基础：上季不及预期、指引高投入，导致本季预期很低 → “低预期下的好业绩”。

**关键指标与数据来源**：各板块超预期幅度、板块重要性排序、预期基础。

**判断标准**：
- 超预期主要来自次要板块（游戏），而不是最重要的板块（电商）→ “含金量稍显欠缺”，但低预期下仍无疑不错。
- 最重要板块增长和利润都超预期，三大板块营收全面好于预期，只有一个指标较差 → 整体观感偏正面。

**海豚案例**：
- SEA（2026-05-12）：营收和利润超预期主要靠游戏而不是电商，“超预期的含金量稍显欠缺”，但在较低预期下表现无疑不错。
- SEA（2026-08-11）：三大板块营收全面好于预期，只有金融利润一个指标较差，业绩整体观感偏正面。

**适用场景与注意事项**：适用于多业务公司的财报快评。

### 2.4.2 beat 质量判定：剔除汇率顺风、低基数、一次性项后是否“不掺水分”

**方法要点**：名义 beat 不等于质量好，要估算汇率贡献、低基数和一次性项，看剔除后是否仍超预期；对已经失去市场信任的公司，需要连续两个季度“不掺水分”的 beat 才能重建长期信心。

**操作步骤**：
1. 估算汇率贡献（不披露内生增速时，按季末汇率粗算）。
2. 看去年同期基数是否偏低。
3. 剔除一次性收益和会计项目。
4. 看驱动是量还是价。
5. 剔除后仍超预期，才算坚实 beat。

**关键指标与数据来源**：汇率贡献（pct）、去年同期基数、一次性项、量价贡献。

**判断标准**：剔除汇率顺风后增速“相对平淡”，且去年基数不高，则 beat 含金量低；各项略好于预期但主要来自汇率顺风 → “不能说有很大惊喜”；信任修复期的公司要连续两季“不掺水分”的 beat。

**海豚案例**：
- 新东方（2026-04-22）：营收+20%中约6-7pct 为汇率顺风，剔除后“相对平淡”，且去年基数不高。
- 多邻国《匍匐前进，Duo的翻身路没那么好走》（2026-05-05）：需连续两季“不掺水分”的坚实 beat 才能重拾长期信心。
- Airbnb（2026-05-08）：各项略好于预期，但主要来自汇率顺风，“不能说有很大惊喜”。

**适用场景与注意事项**：跨国收入占比高、汇率波动大的公司；信任修复期的公司。汇率剔除的具体口径见4.1。

### 2.4.3 超预期含金量/来源核查：非核心板块、非经常性收益、汇率、股本变化

**方法要点**：出现超预期后追问“超在哪里”。来自市场最关注的核心业务或核心指标，含金量高；来自非核心板块、非经常性收益、汇率、回购减股本或投资公允价值变动，则判为“含金量不足/失真/不具持续性”。

**操作步骤**：
1. 把利润 beat 拆到分部和损益表下半部分（其他收益、投资收益、汇兑）。
2. 把 EPS beat 拆到股本变化（回购）。
3. 把指引上调拆到汇率。
4. 对 EPS beat 与经营利润 beat 分开看。
5. 给出判语：含金量不足 / 失真 / 不具持续性。

**关键指标与数据来源**：分部利润、其他收益、投资收益、公允价值变动、汇兑、股本变化、EPS vs 经营利润。

**判断标准**：来自与主业无关的其他收益 → 不可持续；来自被投资资产估值增值 → “失真”；来自回购使股数减少 → EPS 指引上调是股本变动而非经营改善；来自汇率顺风 → 剔汇率后再看。

**海豚案例**：
- Sea《Sea 1Q26火线速读》（2026-05-12）：adj.EBITDA 10.3亿，超预期约15%，但主要来自游戏（板块超约1.3亿、33%），不是最受关注的电商，判为含金量不足。
- 快手（2026-05-27）：经营利润 beat 来自与主业无关的其他收益，不可持续。
- 名创（2026-05-26）：经营利润+114%靠 MiniMax 公允价值收益约8.8亿，剔除后经调整经营利润+14.3%。
- 谷歌《谷歌2Q26火线速读》（2026-07-23）：EPS+294%来自 SpaceX、Anthropic 估值增值，判为“失真”。
- Salesforce（2026-05-28）：EPS 指引上调是因回购使股数减少约10%。
- 可口可乐（2026-04-28）：可比 EPS 指引上调至8-9%，主因汇率转为约3pct 顺风。

**适用场景与注意事项**：通用。尤其适用于持有大量投资资产的公司（腾讯系、名创、谷歌）和大额回购公司。核心经营利润口径（毛利−三项费用，剔除其他收益）见8.1；金融资产重估、业务关停收益等非经营收益的剔除，见4.5。

### 2.4.4 超预期来源归因：主业驱动 vs 高毛利的非核心业务（授权、碳积分、子公司、一次性）

**方法要点**：整体收入、毛利率或利润超预期时，先拆开“核心主业”与“非核心/高毛利附属业务/一次性”，看超预期到底来自哪一块。若小体量高毛利业务贡献了大部分超预期，质量偏弱；若来自主业，质量高。

**操作步骤**：
- 变体 A：毛利贡献占比法。按业务拆解超预期金额的来源，计算“非主业收入占比 vs 非主业毛利贡献占比”。若占比很小的高毛利业务贡献了大部分超预期，判定质量偏弱、表观数据被“粉饰”；若超预期来自主业卖车或卖芯片，判定质量高，如“与此前高度依赖软件授权不同，本次由主业驱动”。还要指出综合毛利率是被结构“被动抬高”的，而不是降本增效的结果。
  - 关键指标：分业务收入及预期、分业务毛利率及预期、分业务毛利额占比。
- 变体 B：总收入拆“核心主业收入”与“非核心或一次性收入”。拿到财报先把总收入与市场一致预期比，不停在总数，马上把总收入拆成“核心主业收入”（比亚迪卖车收入、特斯拉核心汽车销售收入）和“非核心或一次性收入”（比亚迪电子、正面汇兑影响等），再看超预期来自哪一块。写法上在要点第一条就交代“超预期由谁带来”，后面的利润分析也以核心主业为主线。
  - 判断标准：①核心主业只持平、超出部分来自非核心子公司，算“收入虽超预期但质量一般”；②剔除一次性收入后仍超预期，算“真超预期”；③表面持平、剔除一次性后略低于预期，算“表观持平、实际略不及预期”。
  - 关键指标：总收入、分部收入（卖车/电子/储能/服务）、汇兑影响（FX impact）、市场一致预期。
- 变体 C：剥离高毛利的非核心收入（服务、碳积分、补贴、子公司），还原主业真实表现。车企等公司的表观收入、毛利或利润超预期时，先看增量来自哪里：服务及其他收入（技术合作里程碑）、碳积分、政府补贴，还是非核心子公司业务。如果超预期主要来自这些，主业的“真实表现”要打折。
  - 关键指标：服务及其他收入；碳积分收入；政府补贴；分部收入。

**判断标准（汇总）**：看非主业收入占比 vs 非主业毛利贡献占比的倍数差；主业只持平而超出来自非核心 → 质量一般；剔除一次性后仍超 → 真超；整体毛利率被结构抬高而主业毛利率不及预期 → 主业真实表现打折。

**海豚案例**：
- 变体 A：
  - 小鹏（2026-03-20）：服务及其他只占收入14%，却以70.8%的毛利率贡献22.5亿毛利（预期17亿），接近公司毛利的一半，把整体毛利率拔到21.3%（预期20.5%）。
  - 小鹏（2026-05-28）：Q1 整体毛利率20.6%，超预期20.2%和指引20%，主因卖车毛利率超预期，质量较高。
  - 小鹏（2026-08-24）：整体毛利率20.7%，预期19.3%，全靠服务业务75.1%的毛利率。
  - 地平线（2026-03-20）：2H25 收入21.9亿，预期19.4亿，靠授权11.7亿（预期7.5亿），产品8.4亿低于预期10.5亿。
  - 地平线（2026-09-01）：综合毛利率66%，预期63.2%，是90.4%毛利率的授权占比上升带来的。
- 变体 B：
  - 比亚迪《比亚迪：王座失守，未来是出海版“丰田”？》（2026-03-28）：4Q25 总收入2377亿，略高于预期2367亿，但卖车收入1815亿与预期持平，超出部分来自比亚迪电子环比高增，因此定为“收入超预期但由非核心带来”。
  - 特斯拉《特斯拉：造车罕见回血，AI宏图又跳票》（2026-04-23）：总收入224亿美元，预期207-209亿，含约9亿美元正面汇兑，剔除后调整收入215亿仍高于预期，算真超预期。
  - 特斯拉《特斯拉：造车硬抗，AI大饼只摊不兑？》（2026-07-23）：总收入282亿 vs 预期281亿，剔除5亿汇兑后277亿，略低于预期（表观持平、实际略不及预期）。
- 变体 C：
  - 小鹏（2026-03-20）：总收入223亿 vs 208亿，服务及其他收入环比+8.5亿至32亿（预期23.5亿），来自大众合作里程碑和碳积分；整体毛利率21.3%被拉高，汽车毛利率只有13% vs 预期13.9%。
  - 比亚迪（2026-03-27）：收入超预期主要来自比亚迪电子，核心卖车收入1815亿与预期持平。
  - Rivian（2026-02-13）：收入略超，主要靠与大众合作的服务收入。

**适用场景与注意事项**：适合有高毛利附属业务（授权、软件、积分）的硬件公司，以及车企、有技术授权或合作收入的硬件公司；多业务、跨国经营、汇兑敞口大的公司。汇兑影响通常摊在各分部，公司没有拆开披露时需要做假设；非核心子公司若单独上市，可用它自己的财报交叉验证。

### 2.4.5 表观 miss 的穿透：区分非主业收入下滑与主业真实表现

**方法要点**：总收入或归母净利 miss 时，先找出拖累项是否属于非主业，剔除后看主业核心指标，得出“初看不及预期，穿透后主业仍在改善”的判断；反过来，也对“表面达标”做穿透。

**操作步骤**：
1. 找出拖累项是否属于非主业：零部件销售、对外技术授权（电池卖给其他车企）、汇兑高基数、会计费用化率。
2. 剔除后看主业核心指标：卖车 ASP、毛利率、三费、单车核心经营利润是否改善。
3. 得出结论：“初看不及预期，穿透后主业仍在改善”。
4. 对“表面达标”做反向穿透：例如收入落在预告上限，但结构依赖授权。

**关键指标与数据来源**：总收入、零部件和技术授权收入、卖车 ASP、毛利率、核心经营利润。

**判断标准**：非主业下滑拖累总收入，而主业 ASP 持平、毛利率好于预期、单车核心利润稳定 → 主业仍在改善；增量几乎全部来自授权、产品业务增速低 → 表面达标，核心质量偏弱。

**海豚案例**：
- 吉利（2026-04-29）：Q1 收入838亿，预期923亿，miss 主要来自零部件和对外技术授权（电池卖给沃尔沃等）下滑；卖车 ASP 11.2万，与 Q4 持平；毛利率17.5%，预期17%；单车核心运营利润近0.6万。
- 地平线（2026-09-01）：1H26 收入20.6亿，同比+33%，毛利率落在预告偏上限，但增量几乎全部来自授权，产品业务只增15%，结论是“表面达标，核心质量偏弱”。

**适用场景与注意事项**：通用，适合业务多元或会计扰动大的公司。

### 2.4.6 “均值回归”型预期差：识别高基数下增速的持续维持

**方法要点**：画出核心指标多个季度的同比增速（cc 口径），找到加速起点。若某指标从某季起加速到高位并维持了约一年，市场通常默认它将“均值回归”回落；如果新季度在高基数下仍然维持高增，预期差就来自这个被证伪的回落假设。

**操作步骤**：
1. 画出核心指标多个季度的同比增速序列（cc 口径）。
2. 标出加速起点和基数抬升幅度。
3. 说明本季是在高基数上“继续狂奔”，对照市场默认的回落假设。
4. 用两年复合增速验证增长是否真实。

**关键指标与数据来源**：多季度同比增速序列（cc）、去年同期基数增速、两年复合增速。

**判断标准**：高基数下增速不回落，证伪了市场的“均值回归”假设，是超预期和股价大涨的来源；可配合两年复合增速验证增长是否真实。

**海豚案例**：
- Shopify（2026-08-06）：GMV 自去年 Q2 加速到30%以上，市场预期回落，本季 cc 仍为30%，预期差来源于此。

**适用场景与注意事项**：高增长平台/消费类公司；可配合两年复合增速验证增长是否真实。

### 2.4.7 拆分增长来源：承接竞品退出份额 vs 内生增长

**方法要点**：当行业内有竞品或自有业务退出时，拆分本季高增中有多少来自承接的份额（一次性），有多少来自产品内生改进（ROAS 改善、新算法、数据整合）。内生占比越高，超预期质量越高。

**操作步骤**：
1. 识别竞品退出事件及其时点。
2. 借助第三方跟踪调研估计份额流向。
3. 列出产品内生改进（ROAS、新算法、数据整合）。
4. 判断主要增长来自承接份额还是内生。

**关键指标与数据来源**：份额流向调研、产品效果指标（ROAS）。

**判断标准**：内生占比越高，超预期质量越高；承接份额带来的增长是一次性的。

**海豚案例**：
- Unity（2026-08-07）：IronSource 4月底关闭，Jefferies 调研认为 Unity 可能是主要承接方；D28 全面推出、ROAS 改善、Q2 末接入30亿玩家的 Runtime 数据；海豚君倾向认为主要增长来自 Vector。

**适用场景与注意事项**：行业格局变化期的广告、平台公司。

**相关方法（交叉引用）**：用核心经营利润口径（毛利−三项费用，剔除其他收益）判断 beat 质量，详见8.1；剔除金融资产重估、业务关停收益等非经营收益来检验利润 beat 含金量，详见4.5。

**本节速查清单**
- [ ] 超预期来自哪个板块？该板块在公司中的重要性排序如何？是否属于“低预期下的好业绩”？
- [ ] 是否估算了汇率贡献、低基数、一次性项？剔除后是否仍超预期？是量驱动还是价驱动？
- [ ] 利润 beat 是否拆到了损益表下半部分（其他收益、投资收益、公允价值变动、汇兑），EPS beat 是否拆到了股本变化？
- [ ] 总收入是否拆成核心主业和非核心/一次性收入？非主业收入占比 vs 非主业毛利贡献占比如何？
- [ ] 整体毛利率的改善是主业降本增效，还是高毛利业务占比抬升的结构效应？
- [ ] 表观 miss 是否穿透到主业核心指标（ASP、毛利率、三费、单车核心经营利润）？表观达标是否也做了反向穿透？
- [ ] 高基数下的高增是否构成对“均值回归”假设的证伪？是否用两年复合增速验证？
- [ ] 高增长中有多少来自承接竞品份额、多少来自内生改进？
- [ ] 失去信任的公司：是否已连续两季“不掺水分”？

## 2.5 电话会增量信息与待验证清单

> 本节导读：速读和点评往往抢在电话会之前发布，数字能回答的问题有限，决定中长期判断的问题要留给电话会、小范围交流和 callback。本节解决三件事：怎样在文末列出高质量的待验证清单，怎样把小范围交流和电话会的信息纳入判断并标注来源可信度，怎样把小会信息分级为“关键增量”和“与此前预期相符”。与2.1至2.4的数字判断、第9章的指引解读（小会指引与一致预期对比，见9.1）、17.3 的纪要写作相互衔接。

### 2.5.1 点评与速读结尾的电话会/纪要待验证问题清单

**方法要点**：速读或点评只回答“数字”，把财报数据无法回答、需要管理层补充的问题列成清单，形成下一步跟踪重点，并在纪要文中验证。

**操作步骤**：
1. 在文末列出2-5个留待电话会或小会验证的问题。
2. 问题类型通常包括：
   - 财报未解释的异常（如单车毛利下滑原因）；
   - 指引细节（Q2 指引、增长指引、长协订单、客户需求满足度、2027年需求展望）；
   - 战略或资本事件（上市、并购、法案、监管；Capex 与股东回报规划、回购和分红表态）；
   - 投入与产出节奏（AI 进展、新产品周期、token 消耗、新业务 ARR 和续约率、下一代产品发布时间）；
   - 与第三方数据的差异（用户数据）、新业务业绩增量的来源、监管进展（罚款、时间表）。
3. 这一清单是速读、正式点评与纪要之间的衔接点；随后在纪要文中逐一验证（纪要写作见17.3）。
4. 电话会未给出关键信息本身也会被当作负面。

**关键指标与数据来源**：待验证问题清单；管理层口径；小会信息。

**判断标准**：清单应聚焦“财报数字无法回答、但决定中长期判断”的问题；若电话会回避关键问题（如监管没有任何表示、未给 Optimus V3 信息），本身就是负面信号，需纳入股价判断。

**海豚案例**：
- 快手《快手：一场向死而生的暴跌，能换来AI重生吗？》（2026-03-25）：建议关注管理层对投流税影响是否在2026年扩大、静默期后的回购表态。
- 快手《快手：老铁翻身，就靠“可灵”了》（2026-05-27）：关注可灵拆分上市进展、用户增长与第三方数据的差异。
- 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：关注用户付费续约、ARR 预期、Kling 4.0 发布时间和核心功能；其他收入超指引是否来自 CBA 带货和线上演唱会。
- 携程《携程：监管“重锤”之后，还能“小而美”吗？》（2026-02-26）：业绩会上公司对监管没有任何表示；速读中待验证项为近期监管问题的影响。
- 特斯拉（2026-01-29）：AI 业务的进展和规划。
- 网易（2026-02-11）：《遗忘之海》《无限大》的上线规划。
- 腾讯（2026-03-18）：游戏大年和 AI 拉动下的增长指引、Capex 与股东回报规划。
- 美光（2026-03-19）：长协订单、客户需求满足度、2027年需求展望。
- ASML（2026-04-15）：订单未披露，等管理层交流。
- 智谱（2026-03-31）：新模型发布并涨价后的 token 消耗量。
- 快手：可灵的增长指引。
- 腾讯音乐：继续聚焦还是寻求扩张。
- Spotify：盈利趋势（继续涨价还是降本）和 AI 的影响。
- 零跑（2026-05-15）：a）单车毛利下滑原因；b）Q2 指引；c）战略合作可持续性。
- Circle（2026-05-11）：CLARITY 法案进展、投入与产出节奏。
- 百度（2026-05-18）：昆仑芯上市计划（预计 Q3 底前）、回购规划。
- 携程（2026-06-25）：监管整改方向与处罚金额。
- 美团：与抖音到店竞争。
- ASML：订单。
- 快手：用户数与第三方的差异、可灵拆分。
- 特斯拉《2Q26》：电话会未给 Optimus V3 信息，判断股价承压。

**适用场景与注意事项**：适用于所有速读收尾，以及电话会之前发布的快评。

### 2.5.2 小范围交流与电话会补充信息纳入判断

**方法要点**：除了公开财报和电话会，补充“小范围交流”中获取的更细指引（如下季云收入增速），验证或修正自己的判断，并在文中标注为补充信息；电话会纪要作为配套文章同步发布，点评正文引用电话会里的关键数字。

**操作步骤**：
1. 获取小范围交流中的更细指引（下季某业务增速等）。
2. 与自己的判断对比，验证或修正。
3. 在文中明确标注信息来源为“小范围交流”。
4. 引用电话会里的关键定量表述（如 capex 回本年限）。
5. 电话会纪要作为配套文章同步发布。

**关键指标与数据来源**：小范围指引的增速、电话会定量表述。

**判断标准**：小范围信息与自己判断一致 → 强化；不一致 → 修正；其可信度低于公开指引，使用时要标注。

**海豚案例**：
- 阿里《阿里狂投》（2026-08-21）：小范围交流中，阿里把9月季度云收入增速指引到超过50%，并说明12月和3月季度还要更高，与海豚君的判断一致；电话会表示 capex 约3年回本，后续可能改善到2.5年。

**适用场景与注意事项**：信息来源需要标注，可信度低于公开指引。

### 2.5.3 业绩会后小会/callback 增量信息分级

**方法要点**：把小会或 callback 里的信息分成“关键增量”（新指引、新数字、口径澄清）和“与此前预期相符”两类，比较小会与大会的基调差异，再据此确认或修正看多逻辑；callback 中的年底指引也可能反转财报当晚的乐观情绪。

**操作步骤**：
1. 逐条记录小会信息。
2. 分类：关键增量（新指引、新数字、口径澄清）vs 与此前预期相符。
3. 比较小会与大会的基调差异。
4. 据此确认或修正看多逻辑。
5. 关注 callback 中的年底指引是否反转财报当晚的情绪。

**关键指标与数据来源**：下季增速指引、亏损区间、ARR、利润率路径、FCF 转正时点。

**判断标准**：增量信息越多、基调比大会越乐观，越能确认原有逻辑；年底指引不及乐观预期时，要修正。

**海豚案例**：
- 阿里（2026-08-21）：增量信息包括云下季增速约50%并继续加速、AI Lab 单季亏损约百亿、AI ARR 495亿、剔除平头哥后云利润率更高、29财年 FCF 转正、国际电商盈利；与预期相符的有 MaaS 年底300亿、闪购29财年盈利；小会基调比大会更乐观，确认了“电商企稳 + AI 进攻”。
- 智谱 callback：年底24亿 ARR 指引不乐观。

**适用场景与注意事项**：中概公司业绩后的机构交流。

**相关方法（交叉引用）**：小会指引与市场一致预期逐项对比，判断预期下修的幅度和方向，详见9.1。
