# 第7章 毛利率拆解

> **本章目的**：回答毛利率为什么变：价格、结构、成本、产能爬坡、跨期会计因素各占多少，以及毛利率水平是否健康、是否反映议价权。

**本章小节**：7.1 毛利率驱动归因框架｜7.2 结构效应与分业务毛利率｜7.3 成本传导：原材料、关税与定价机制｜7.4 产能爬坡、库存与跨期因素｜7.5 毛利率基准、议价权与真实毛利

---

## 7.1 毛利率驱动归因框架

> 本节导读：毛利率是价格、结构、成本、产能和会计因素合力的结果，海豚君的第一步从来不是只报一个“同比 ±x pct”，而是把变动编号、逐项配证据、再和市场预期比。本节给出通用归因框架：十项排查清单、多因素编号归因、提价与结构的主次、环比归因桥、毛利率持续 miss 与单季回落的归因、异常闪崩的经营还原，以及毛利率指引的归因与解读。拆出主因之后，分别进入 7.2（结构效应）、7.3（成本传导）、7.4（跨期因素）、7.5（水位与议价权）深挖；行业专属驱动（晶圆、游戏、车企等）见第 15、16 章。

### 7.1.1 毛利率驱动因素十项排查清单

- **方法要点**：毛利率变动时不凭印象下结论，把十个候选驱动逐项过一遍，找出当季真正起作用的几项，并顺手判断毛利率是否已经逼近天花板。
- **操作步骤 / 拆分口径 / 公式**：
  1. 产品结构：高毛利服务或设备占比、低毛利 ASIC 等产品占比。
  2. 价格：提价、急单溢价。
  3. 规模效应：出货增加摊薄固定成本。
  4. 产能利用率：满载，甚至超过 100%。
  5. 新制程或新产品爬坡带来的稀释，包括低良率。
  6. 资本开支推高折旧。
  7. 汇率。
  8. 原材料成本。
  9. 会计调整（如减值冲回）。
  10. 毛利率是否已到天花板（80% 以上，上行空间有限）。
  - 逐项排查后，只保留有证据的项目，标出方向和量级，并给出“主因/次因”排序；没有证据的项目不硬凑。拆出主因后，再转入 7.2（结构）、7.3（成本传导）、7.4（跨期因素）做深度验证。
- **关键指标与数据来源**：产品结构、ASP、单位成本、产能利用率、良率、折旧、汇率；来源为公司分部披露、电话会、行业价格数据。
- **判断标准**：
  - 结构类因素看占比方向和被稀释/对冲的幅度；价格类因素看提价事件与溢价幅度；产能利用率超过 100% 是供给偏紧、规模效应与价格强势的信号。
  - 新制程、新产品的稀释通常以“几个 pct”为量级，要与良率进展一起看。
  - 毛利率已在 80% 以上时，上行空间有限，后续更多是维持而非继续抬升。
- **海豚案例**：
  - ASML（2026-07-15）：毛利率 54%，指引为 51-52%，归因为服务占比提升。
  - 应用材料 AMAT（2026-02-13）：毛利率 49%，归因为高毛利设备占比回升。
  - 博通（2026-09-03）：Adjusted 毛利率 74%，环比 -2pct，原因是低毛利 ASIC 占比提升，中长期仍有下行压力。
  - 台积电（2026-07-16）：N5 及以下制程利用率超过 100%，部分急单溢价超过 50%。
  - 台积电（2026-10-15）：2nm 稀释毛利率 2-3pct。
  - 中芯国际（2026-02-10）：等效 7nm 的低良率压制毛利率。
  - SK 海力士（2026-07-29）：毛利率 83%，已在 80% 以上，进一步上行空间有限。
- **适用场景与注意事项**：通用，尤其是半导体及设备链条；十项清单是“排查框架”，每一项都要落到具体数字或电话会表述上。会计调整类因素（减值冲回等）要与 7.4 的跨期因素、4.5 的一次性剔除配合。

### 7.1.2 毛利率变动的多因素编号归因（价格 / 成本 / 结构 / 良率 / 原材料）

- **方法要点**：毛利率显著变动时，海豚君把驱动因素按编号列出，每一项尽量配证据，并区分方向；同时比较毛利额增速与收入增速，再与市场预期对比，得出“变动是否健康、成本管理能力如何”的结论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先列事实：毛利率同比、环比 pct 变化；毛利额增速 vs 收入增速（毛利额增速快于收入增速，说明毛利率抬升是实打实的）。
  2. 把驱动因素编号列出并配证据：
     - ①价格：列出提价事件时间线；传统存储等品类的涨价幅度。
     - ②成本：硬件 BOM 精简、原材料涨价、成本投入增加（设备和服务领域加大投入会使毛利率提升变慢）。
     - ③结构：高/低毛利业务占比变化。
     - ④新品与良率：新设备推出、提价、良率改善。
     - ⑤原材料：存储等上游涨价侵蚀分部毛利率。
  3. 每个驱动标注方向（正/负）。
  4. 与市场预期对比：毛利率虽然下降但好于预期，可以推断成本管理能力较强；低于预期则要回答“市场担忧哪一项兑现了”。
  5. 标注驱动来源是“公司解释”还是“海豚君自己的判断”，因为驱动归因往往需要电话会佐证。
  - 变体 A（编号归因 + 毛利额 vs 收入增速 + 预期对比）：适用于需要同时回答“毛利率为何变”与“盈利质量如何”的场景。
  - 变体 B（逐公司标注驱动类型与方向）：同一篇或同一系列中，对每家公司都明确归到“价格 / 产品结构 / 新品与良率 / 成本投入 / 原材料成本”中的某一类，便于横向比较。
- **关键指标与数据来源**：毛利率同比/环比 pct、毛利额增速 vs 收入增速、提价事件、原材料价格、产品 mix、ASP、良率；来源为公司公告、电话会、第三方原材料价格。
- **判断标准**：
  - 毛利额增速 > 收入增速 → 毛利率扩张是真实的盈利改善。
  - 毛利率同比下降但好于预期 → 成本管理能力相对不错（戴尔）。
  - 价格驱动的大幅提升（美光环比 +18.4pct）源自传统存储涨价；结构驱动（ASML）源自高价 EUV、服务、ArFi 占比；良率与提价驱动（英特尔）要用下一季验证；成本投入驱动（AMAT）说明毛利率爬升慢是主动投入的结果；原材料驱动（高通）说明存储涨价正在侵蚀分部毛利率。
- **海豚案例**：
  - 海康威视《涨价“续命”、裁员“增效”，海康威视能起死为生吗？》（2026-04-18）：毛利率 49.1%（+4.2pct），毛利 102 亿、同比 +22%，快于收入 +12%；归因于①全系涨价、②硬件成本精简、③软件占比回升。
  - 戴尔《戴尔：AI 狂飙，传统升温，老登已“满血沸腾”！》（2026-05-29）：毛利率 17.8%（-2.4pct），归因于①存储涨价、②低毛利 ISG 占比提升；但好于市场预期的 16%，说明“成本管理能力相对不错”。
  - 美光（2026-03-19）：毛利率 74.4%，环比 +18.4pct，来自传统存储涨价（价格驱动）。
  - ASML（2026-01-28 / 04-15 / 10-14）：毛利率分别为 52.2% / 53% / 57.4%。Q4'25 的 52.2% 来自高价 EUV 占比提升；Q1'26 来自服务占比；Q3'26 的 57.4% 超指引上限，来自 ArFi 和服务（产品结构驱动）。
  - 应用材料（2026-08-14）：毛利率 50.3%，环比 +0.4pct，提升较慢是因为在设备和服务领域增加了成本投入；新设备推出带动设备毛利率上升（新品驱动、成本投入）。
  - 高通（2026-02-05）：毛利率 54.6%，同比 -1.2pct，低于预期 55.2%，存储涨价侵蚀 QCT 毛利率（原材料驱动）。
  - 英特尔（2026-04-24）：毛利率 39.4%，环比 +3.3pct，来自提价和 Intel 3/18A 良率改善（新品与良率驱动，详见 7.1.8）。
- **适用场景与注意事项**：适用于所有硬件和制造业公司；对 BOM 占比高、涨价事件多的公司尤其有用。要配合第三方原材料价格和公司调价公告。各分项的贡献多是定性或粗略估算，要诚实标注“公司解释”与“自己判断”的区别。

### 7.1.3 毛利率变动的“提价 vs 结构”主次归因，检验成本转嫁与议价权

- **方法要点**：毛利率大幅变化时，拆成价格因素（产品提价、上游涨价转嫁）与结构因素（高/低毛利业务占比变化）并分清主次；如果上游在涨价、低毛利业务又在放量，毛利率却不降反升，就解读为公司对产业链有议价权。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取毛利率实际值，与市场预期比（差多少 pct），再看环比变化。
  2. 拆价格因素：公司对产品线是否提价、提价是否针对上游涨价（如存储 DRAM/NAND 涨价）。
  3. 拆结构因素：低毛利业务（如 AI 服务器）占比是否上升。
  4. 判断主次：谁是主因，谁是次因。
  5. 检验成本转嫁：上游成本在涨 + 低毛利业务放量 + 毛利率不降反升 → 成本转嫁成功，公司有议价权。
  6. 把结论写进投资叙事：直接回应市场“增收不增利”的核心担忧，形成“收入与利润率双升”的叙事。
- **关键指标与数据来源**：毛利率实际值与市场预期、环比 pct、提价信息、上游 DRAM/NAND 价格、AI 服务器收入占比。
- **判断标准**：
  - 毛利率明显好于预期，且主因是提价 → 议价权成立，“增收不增利”的担忧被化解。
  - 若毛利率提升主要来自一次性提价红利，则要继续观察成本回落后价格是否有粘性。
  - 推理链条：上游涨价（压力）→ 提价（转嫁）→ 低毛利业务放量（稀释）→ 毛利率仍提升 → 议价权。
- **海豚案例**：
  - 戴尔（2026-09-02）：毛利率 21%，环比 +3pct，明显好于预期 17.4%；海豚君的结论是“提价是主因，结构性因素是次因”，公司为应对存储涨价对产品线提价，有力回应了增收不增利的担忧，体现产业链议价权。
- **适用场景与注意事项**：适用于成本传导型企业（硬件组装、制造、品牌消费品）。要区分一次性提价红利与持续性，并观察成本回落后价格是否有粘性。议价权的其他检验方法见 7.5（增收不增利交叉验证）和 15.5（广告媒体的议价权测算）。

### 7.1.4 毛利率环比变动归因桥：结构红利 vs 负向规模 vs BOM 上涨 vs 价格下滑

- **方法要点**：把毛利率的环比变化做成一座“桥”，把正向项与负向项逐项列出，判断哪一项压过了哪一项，并解释“市场担忧是否兑现”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 桥的起点：上季毛利率；终点：本季毛利率。
  2. 正向项：海外/高端结构红利、规模效应、技术降本。
  3. 负向项：清库折扣、被动加配、原材料涨价、负向规模效应（销量下滑）。
  4. 判断哪一项压过哪一项，写成类似“结构红利吞掉了国内加配带来的 BOM 上涨，也消化了销量下滑的负向规模效应”的结论。
  5. 同时把实际值和市场预期比（差多少 pct），再解释为什么市场的担忧没有兑现或兑现了。
  6. 若披露了 ASP 与单车成本，可直接对比 ΔASP 与 Δ单车成本，看谁更大（参考 2Q26 比亚迪：单车成本降 1.8 万基本对冲 ASP 降 2.4 万）。
- **关键指标与数据来源**：卖车毛利率（环比 pct 变化）、出口占比、单车成本分项、市场预期毛利率；来源为公司业绩与电话会，以及卖方预期。
- **判断标准**：
  - 正向项合计 > 负向项合计 → 毛利率环比上行；反之下行。
  - 毛利率低于预期，说明某个负向项（如供应链涨价、被动加配）吃掉了规模效应；高于预期，说明结构红利或降本好于市场担忧。
  - 桥上每一项多为定性或粗略估算；精确量化需要更细的成本披露。
- **海豚案例**：
  - 比亚迪《王座失守…》（2026-03-28）：4Q25 卖车毛利率 21.6%，环比 +1pct，低于预期 22.5%；规模效应被供应链涨价和被动加配吃掉。
  - 比亚迪《宇宙车厂…》（2026-04-28）：1Q26 毛利率 23.4%（环比 +1.8pct，比预期高 1.7pct）；海外占比爆发，对冲了国内被动加配、原材料涨价和销量下滑的负向规模效应。
  - 比亚迪《国内卷单价…》（2026-08-29）：2Q26 毛利率 23%（环比 -0.4pct），高于预期 22.2%；单车成本降 1.8 万，基本对冲了 ASP 降 2.4 万。
- **适用场景与注意事项**：通用于制造业毛利率分析，尤其是车企。桥的每项贡献多为定性或粗略估算，注意不要把估算写成精确值；汽车行业专属驱动（高价车型占比、新工厂折旧等）见 16.1。

### 7.1.5 毛利率持续 miss 与单季回落的多因素归因

- **方法要点**：毛利率连续不及预期，或单季出现明显回落时，不能只说“结构不好”，而是把原因拆成若干条可检验的线索，并区分结构性/趋势性因素与一次性因素，判断回落能否持续。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A：毛利率持续 miss（AI 应用公司）。
    1. 拆成三个原因：①高毛利广告业务占比下降（结构）；②新产品处于早期，API 成本占收入比例高，规模效应尚未发挥；③“以订阅计划分摊算力成本”的策略（低价订阅、可多次调用模型）推高第三方 API 成本。
    2. 同时标记“连续两个财报期大幅 miss”，提示这是趋势而非偶发。
    3. 关键监控：毛利率 vs 预期、广告收入占比、API 成本占收入比。
  - 变体 B：单季毛利率回落（航天/制造）。
    1. (a) 收入结构：低毛利客户（政府国防）占比上升了多少个百分点。
    2. (b) 新品研发拖累：新火箭良率低、供应链磨合，单次固定成本上升。
    3. (c) 试飞失败的硬件损失直接计入当期成本。
    4. (d) 新项目巨额资本开支的折旧摊销部分计入成本。
    5. 区分结构性与一次性：(a)(b)(d) 偏结构性/趋势性，(c) 偏一次性，据此判断回落能否持续。
- **关键指标与数据来源**：变体 A——毛利率 vs 预期、广告收入占比、API 成本占收入；变体 B——季度毛利率同比、政府类收入占比、试飞结果、折旧摊销。
- **判断标准**：
  - 连续两个财报期大幅 miss → 属趋势性问题，市场应重新定价；
  - 回落若主要来自一次性项目（试飞失败损失），则下季有望修复；若来自结构变化（客户结构、折旧）则会延续；
  - 毛利润增速放缓、毛利率与上半年持平或回落 → 说明规模效应尚未体现。
- **海豚案例**：
  - 美图（2026-03-28）：毛利润增速放缓到 20.8%，毛利率与上半年持平，大幅 miss。
  - 美图（2026-08-26）：毛利 miss 7pct，已连续两期大幅 miss（另见 2026-03-27 的业务结构解释，详见 7.2.6）。
  - SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：2026 年一季度发射毛利率从约 66% 降至约 55%；NSSL 第二阶段和阿尔忒弥斯任务使政府国防收入占比从约 35% 升至约 47%；星舰 V3 制造成本高；2026 年 5 月第 12 次试飞一级坠海，损失计入当期；星舰折旧摊薄利润。
- **适用场景与注意事项**：变体 A 适用于调用第三方大模型的 AI 应用公司；变体 B 适用于新老产品切换期、客户结构变化中的制造或服务公司。折旧部分的测算详见 10.3，库存与一次性因素的跨期影响见 7.4。

### 7.1.6 毛利率异常闪崩的经营原因还原与下季验证

- **方法要点**：某业务毛利率异常闪崩（如声学整机降到 0.4%）时，不止报数字，而是还原背后的经营机制，判断是“短期错配”还是“长期恶化”，并用下一季、下半年的数据验证。
- **操作步骤 / 拆分口径 / 公式**：
  1. 找到异常点：分业务毛利率相对历史水平异常下跌。
  2. 还原机制：关税政策 → 产能转移到越南 → 大量同行同时赴越南建厂招工 → 劳动力阶段性短缺 → 公司高价抢人；业务本身是劳动密集型组装，且高度集中在越南；出货高峰在下半年，因此成本压力集中体现在下半年。
  3. 判断：这是短期错配，而非长期竞争力受损。
  4. 验证：在下一季、下半年的毛利率数据中检验——回升到 10% 附近，即为暂时性；整体毛利率回升也是佐证。
- **关键指标与数据来源**：分业务毛利率、生产地集中度、出货季节性、人力成本；来源为公司业绩与管理层说明。
- **判断标准**：
  - 异常毛利率若在下一季/下半年恢复，并且整体毛利率回升、扰动“出清”，则判定为暂时性。
  - 若业务本身劳动密集且产能高度集中、出货季节性强，则异常更可能是错配而非趋势。
- **海豚案例**：
  - 歌尔《跨过越南“招工坑”…》（2026-04-23）：25H2 声学整机毛利率降至约 0.4%，归因于越南劳动力短缺和高价抢人；Q1 整体毛利率回升，说明并非长期影响。
  - 歌尔《果链“有量无价”…》（2026-08-20）：2Q26 毛利率 15.2%，同比环比均提升，越南用工扰动出清；声学整机 1H26 毛利率 9.7%。
- **适用场景与注意事项**：适用于代工、组装类劳动密集型企业，以及产能迁移期的公司。必须有“下季验证”的闭环，否则“短期错配”只是一个未经检验的解释。

### 7.1.7 毛利率指引变化的归因：以管理层目标和机构远期预期作锚

- **方法要点**：毛利率指引下滑时，先归因（产品切换、原材料），再引入管理层年度目标作为“市场信心的锚”，并对照主流机构对远期毛利率的预期，判断市场实际在为什么定价。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取下季毛利率指引，与当季和市场预期比（环比变化、与预期差）。
  2. 归因：产品切换（新品爬坡期的成本和良率）、原材料（内存等涨价）。
  3. 引入管理层的年度目标毛利率，作为市场信心的锚。
  4. 对照主流机构对更远年份毛利率逐步下滑的预期。
  5. 判断：市场目前交易的是“当季指引的小幅下修”，还是“年度目标之后的滑坡”。
- **关键指标与数据来源**：当季毛利率、下季毛利率指引、管理层年度目标、机构远期预期；来源为电话会与卖方预期。
- **判断标准**：
  - 指引低于预期、但管理层年度目标不变 → 短期扰动，信心锚仍在；
  - 机构对更远年份的下滑预期若被市场重视，则估值压力来自远期而非当季。
- **海豚案例**：
  - 英伟达（2026-08-27）：下季毛利率指引 74%（环比 -1pct，低于市场 75%），海豚君归因于 Rubin 爬坡和内存等上游原材料。
  - 英伟达（2026-02-26、2026-05-21）：管理层 FY27 目标毛利率 75%，“在一定程度上给予了市场信心”，但市场仍担心 FY27 之后毛利率滑坡（主流机构预期 FY28 及以后逐步下滑）。
- **适用场景与注意事项**：适用于毛利率是核心估值变量的公司（高毛利龙头）。指引保守度、措辞类信号等方法见 9.4、9.5。

### 7.1.8 毛利率指引作为新制程良率与提价效果的读数

- **方法要点**：对处在制程爬坡期的公司，海豚君把“毛利率指引与预期的差距”直接翻译为技术进展信号：指引远低于预期，意味着良率与稀释比预想差；下季实际与指引大幅好于预期，则意味着提价和良率改善好于市场想象。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取 GAAP 毛利率指引，与市场预期比（差多少 pct）。
  2. 把差距翻译成技术信号：低于预期 → 新制程对毛利率的拖累和良率提升不如意；
  3. 下一季检验：实际毛利率与新一季指引相对预期的差距，判断是提价（如服务器 CPU 提价）还是良率（Intel 3、18A 良率改善）驱动。
  4. 跟踪新制程良率（18A 约 60%，每月改善约 7%）与提价幅度。
  5. 关注管理层是否把“毛利率站稳 40% 以上”之类设为年度首要财务目标——这被视为信心信号。
  6. 剔除库存收益等一次性因素（详见 7.4.2）。
- **关键指标与数据来源**：GAAP 毛利率指引 vs 预期；新制程良率（18A 约 60%，每月改善约 7%）；提价幅度。
- **判断标准**：
  - 指引大幅低于预期 → 解读为新制程拖累和良率未达预期；
  - 实际与指引双双超预期 → 解读为提价和良率改善好于预期；
  - 管理层给出明确的毛利率年度目标 → 信心信号。
- **海豚案例**：
  - 英特尔《英特尔：AI CPU 火热造势，“冰冷”指引浇灭了期待？》（2026-01-23）：Q1'26 毛利率指引 32.3%，远低于市场预期 38%，被解读为 18A 对毛利率的拖累和良率提升都不如意。
  - 英特尔《英特尔：告别“至暗”时刻，老霸主打响“反击战”》（2026-04-24）：实际 39.4% vs 预期 32.5%；Q2 指引 37.5% vs 预期 34.7%，被解读为服务器 CPU 提价和 Intel 3/18A 良率改善好于预期。
  - 英特尔《英特尔：CPU 涨价救场，翻身还得看代工？》（2026-07-24）：实际 40.4% vs 37.6%，指引 41% vs 39.3%；随后管理层把“毛利率站稳 40% 以上”作为年度首要财务目标，被视为信心信号。
- **适用场景与注意事项**：适用于 IDM 和代工厂，以及新产品爬坡期的硬件公司。需要剔除库存收益等一次性因素（其时序拆解见 7.4.2），否则会把一次性项目误读为技术进展。

## 7.2 结构效应与分业务毛利率

> 本节导读：综合毛利率最常见的“假变化”来自 mix：低毛利业务放量会在各业务自身毛利率不变的情况下拉低整体，高毛利业务占比提升则反之。本节解决的核心问题是——毛利率变动究竟是结构效应（占比变化）还是同口径恶化（价格/成本），前者往往伴随高增长、可以接受，后者才是警讯。涵盖产品、地区、渠道、业务结构的稀释与对冲，双因素分析，多层拆分，用合并毛利率倒推未披露分部，以及“降幅收窄、环比回升”的触底判定。与 7.1（总框架）、7.3（成本传导）配合；利润率层面的 mix 效应见 8.2，行业专属结构见第 15、16 章。

### 7.2.1 产品结构对毛利率的稀释 / 对冲：区分结构性下滑与价格性下滑

- **方法要点**：毛利率下滑时，先分清是“结构性”（低毛利业务占比上升）还是“价格/成本性”（同一产品自身毛利率下降）。结构性下滑往往伴随高增长，可以接受；价格性下滑才是警讯。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别高毛利业务与低毛利业务（至少要定性知道各产品毛利率的高低）。
  2. 看各业务占比的变化。
  3. 验证整体毛利率方向是否与结构变化一致（占比向低毛利业务倾斜，整体毛利率就应当下行）。
  4. 找对冲项：同板块内是否有高毛利产品（如网络交换芯片）在对冲低毛利产品的稀释。
  5. 按占比趋势预判中长期毛利率压力（结构性趋势会延续）。
  6. 与对手的毛利率趋势对比（如博通 vs 英伟达），判断是行业共性还是个体差异。
  7. 判别口诀：整体毛利率下降，先检查各分部自身毛利率——占比因素导致的下降不必过度担忧，各分部自身毛利率下降才是真问题。
- **关键指标与数据来源**：分业务毛利率（至少定性高低）、业务占比、整体毛利率环比/同比；来源为公司分部披露与电话会。
- **判断标准**：
  - 整体毛利率下行、且与低毛利业务占比上升方向一致 → 结构性稀释；
  - 同一业务自身毛利率下降 → 价格/成本性恶化，是真问题；
  - 同板块高毛利产品能对冲 → 当季持平，但仍要看中长期占比趋势（如博通“中长期仍有下滑压力”）；
  - 高毛利业务占比回升 → 结构上带动毛利率抬升（如海康的软件占比）。
- **海豚案例**：
  - 博通（2026-03-05）：毛利率 -0.8pct，原因是定制 ASIC 占比提升。
  - 博通（2026-06-04）：毛利率持平，网络交换芯片的高毛利对冲了 ASIC，但中长期仍有下滑压力；市场担心“英伟达毛利率越来越高，博通结构性走低”。
  - Marvell（三篇）：定制 ASIC 占比提升拉低调整后毛利率，判断“后续 ASIC 加速增长时毛利率仍有下滑压力”。
  - 戴尔《戴尔 DELL：翻倍成长的 AI，能打消“存储紧张”的担忧吗？》（2026-02-27）：毛利率 20.2%（-0.5pct），低毛利的 AI 服务器/ISG 占比提升造成稀释。
  - 海康威视（2026-04-18）：软件占比回升到约 22%，从结构上带动毛利率。
  - Shopify（2026-05-05）：整体毛利率 -1.2pct，但各分部自身毛利率都在走高（纯结构效应）。
  - 华住：加盟占比提升带动毛利率上升（轻资产转型的结构性变化，详见 16.6）。
  - 腾讯音乐：毛利率 +30bps。
  - 名创：海外占比下降拉低毛利率（地区结构，另见 7.2.10）。
  - Sea 金融：销售费用翻倍（分部自身层面的压力，与 mix 效应对照）。
- **适用场景与注意事项**：适合多产品线、各产品毛利率差异大的公司。要警惕把“结构性”当成万能借口——必须验证各分部自身毛利率的方向。与对手毛利率趋势的横向对比能帮助判断行业共性。

### 7.2.2 分业务毛利率 × 收入结构的双因素分析（结构效应 vs 实质受损）

- **方法要点**：整体毛利率变动 = 各业务自身毛利率变化 + 高/低毛利业务占比变化。把二者分开，才能说清“表观的结构拖累”还是“核心业务实质受损”。
- **操作步骤 / 拆分口径 / 公式**：
  - 定量形式（有分部毛利率和收入时可直接计算）：
    - 结构效应 = Σ（本期占比 − 上期占比）× 上期分部毛利率；
    - 同口径效应（各业务自身毛利率变化）= Σ 本期占比 × （本期分部毛利率 − 上期分部毛利率）；
    - 两项之和 = 整体毛利率变动。海豚君实际写作中多为定性或粗略估算，没有分部毛利率时按本节其他方法做倒推或定性判断。
  - 变体 A（双因素共振四步法）：
    1. 整体毛利率与卖方预期比较（达标/跑输），并看同比；
    2. 拆各分部毛利率的同比变化与预期差，找具体原因（如免费 AI 服务带来算力成本、提价、低毛利硬件萎缩）；
    3. 看结构效应（低毛利业务占比上升）；
    4. 结论落到毛利润增速与营收增速的对比上。
  - 变体 B（按分部方向判断是否为真问题）：先看各分部毛利率同比方向——若各分部毛利率都在提升，而低毛利分部收入占比上升，就是纯结构效应，算不上真正的问题；若某分部自身毛利率下滑（如电商履约成本增速快于变现率提升），则是实质问题。再对照彭博预期看跌幅大小，并做分部级的预期差（如“订阅弱、商家服务强”）。
  - 变体 C（结构性拖累 vs 核心业务实质受损，并识别“被动优化”）：
    1. 结构效应：低毛利业务收入占比的变化（如 EPC 年底集中确收、低毛利商家服务占比提升）——属于“表观”影响；
    2. 分业务自身毛利率变化——自身毛利率恶化才是实质受损；
    3. 反过来，低毛利业务收缩带来的毛利率改善要识别为“被动优化”，不能当成竞争力提升。
  - 变体 D（多业务公司 mix 与自身毛利率逐项拆）：先拆“结构效应”与“各业务自身毛利率”，再把二者叠加说明整体毛利率为什么变（百度、贝壳、TME、腾讯的做法）。
- **关键指标与数据来源**：整体毛利率、分部毛利率同比/预期差、分部收入占比（ppt 变化）、毛利润增速 vs 营收增速、彭博预期毛利率；来源为公司分部披露与卖方一致预期。
- **判断标准**：
  - 各分部自身毛利率同比均提升 + 低毛利分部占比上升 → 纯结构效应，不是真问题；
  - 某分部自身毛利率下滑，且占比同步上升 → 实质受损，叠加结构拖累；
  - 低毛利业务收缩带来的毛利率改善 → 被动优化，不等于竞争力提升；
  - 毛利润增速低于营收增速 → 低毛利业务占比抬升的直接表现。
- **海豚案例**：
  - 变体 A：
    - Shopify（2026-08-06）：整体毛利率 47.7%，同比 -0.9pct，刚好符合卖方预期；订阅毛利率 -1.9pct，明显低于预期（Sidekick 免费提供产生算力成本）；商户服务毛利率 +0.5pct，高于卖方约 75bps；低毛利商户服务占比上升，毛利润 +31% 低于营收增速。
    - 微软（2026-01-29）：智慧云毛利率 -4.4pct，生产力 +1pct，个人计算 +2.4pct（提价、低毛利硬件萎缩）。
    - 中国移动《中国移动：直面税改冲击，分红底色依然不变？》（2026-03-26）：低毛利产品销售占比提升，Q4 毛利率同比 -3.8pct。
  - 变体 B：
    - Sea（2026-03-03）：整体毛利率 43.8%，同比 -0.8pct，低于预期；游戏和金融毛利率同环比提升，电商（平台 + 自营）毛利率 -0.9pct 且收入占比上升，主因履约成本增长更快（实质问题在电商）。
    - Shopify（2026-05-06）：毛利率 48.8%，-0.7pct，跌幅小于彭博预期；订阅和商家服务毛利率同比均上升，整体下滑完全是收入结构变化；从预期差看，订阅弱、商家服务强。
    - MercadoLibre（2026-02-25）：毛利率 43.2%，同比收窄超 2pct，原因是免邮门槛下调，支付和信贷变现率同比走低（自身变现率问题）。
  - 变体 C：
    - 阳光电源《平地起惊雷》（2026-04-01）：Q4 综合毛利率从约 36% 骤降至约 23%；电站开发（EPC）占比环比 +10ppt 至 23%，核心主业合计占比 -12ppt 至 71%，同时储能、逆变器毛利率自身下滑（结构 + 实质叠加）。
    - 阳光电源《收入倒春寒》（2026-04-28）：Q1 毛利率回升至 33.3%（+10.3ppt），来自低毛利开发业务占比下降、储能毛利率修复、逆变器放弃户用（其中部分是被动优化）。
    - Shopify《业绩不俗却暴跌》（2026-02-12）：整体毛利率 46.1%（同比 -2pct），一是低毛利商家服务占比提升，二是商家服务自身毛利率 -1.6pct（比彭博预期低 60bps）；订阅业务因试用影响消退，毛利率扭跌转涨（比预期高 80bps）。
  - 变体 D：
    - 百度《其他没指望》（2026-05-18）：低毛利 AI 云上拉、高毛利广告下滑 → 核心毛利率降至 44%。
    - 贝壳《下跌 “深不见底”》（2026-03-16）：一航道贡献利润率持平/提升，但低毛利家装/租赁占比上升，叠加门店成本刚性（-10% vs 收入 -30%）→ 整体毛利率 -1.6pct。
    - TME《收编喜马拉雅》（2026-05-12）、《慷慨回购》（2026-08-11）：高毛利非订阅（广告）占比提升 → +30bps；Q2 演唱会高成本 → 小降。
    - 腾讯（2026-03-18、2026-08-12）：视频号广告与自研游戏占比提升 → 毛利率改善。
- **适用场景与注意事项**：多业务、毛利率差异大的公司通用；要求披露分业务收入和毛利（或可推算）。注意：分部级预期差（彭博分项预期）能让判断更扎实；被动优化与真实改善必须分开写，否则会高估竞争力。

### 7.2.3 结构性拖累识别与“降幅收窄、环比回升”的触底判定

- **方法要点**：毛利率下滑时先区分是结构性拖累（低毛利业务如 Temu、海外、短剧占比上升）还是同口径恶化；对结构性拖累，跟踪重点是同比降幅是否收窄、是否环比触底回升，由此判断“对毛利率的拖累越来越小”。若有两股方向相反的力量，要说明哪一边占优。
- **操作步骤 / 拆分口径 / 公式**：
  1. 区分结构性拖累（低毛利业务占比上升）与同口径恶化。
  2. 跟踪整体毛利率同比的降幅变化：降幅是否收窄（如 -1.3pct 之后继续收窄）。
  3. 跟踪环比：是否触底回升（上季 55.5% → 本季 55.9%）。
  4. 对照市场预期（高于/低于预期）。
  5. 有两股力量时（国内毛利率升、海外毛利率降），明确哪一边占优，以及净效应方向。
  6. 反向情形：降幅扩大、同比拖累加深，说明结构拖累与外部因素（如监管）在叠加。
- **关键指标与数据来源**：整体毛利率（同比、环比）、低毛利业务收入占比、同比降幅变化、市场预期毛利率。
- **判断标准**：
  - 同比降幅持续收窄 → 结构拖累边际减弱；环比回升 + 高于预期 → 触底；同环比都走高 → 驱动要进一步拆（主站变现回暖、全托管改半托管、减亏提效）；
  - 降幅扩大 → 拖累在加重；
  - 两股相反力量大体抵消时，以净效应方向（谁略占优）为准。
- **海豚案例**：
  - 拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）：4Q25 毛利率 55.5%，略低于预期，因 Temu 占比提升带来结构性拖累；同比降约 1.3pct，降幅持续收窄。
  - 拼多多《拼多多：又老又“傲慢”，彻底人人嫌》（2026-05-27）：1Q26 毛利率 55.9%，上季 55.5%，环比触底回升，高于预期 55.6%。
  - 拼多多《拼多多：电商“邪修”，终成“本分老登”》（2026-08-24）：2Q26 毛利率 57.3%，同环比都走高，驱动是主站变现回暖、全托管改半托管和减亏提效。
  - 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：毛利率 79.5%，同比降幅扩大到 0.9pct，因海外占比上升叠加监管。
  - 滴滴《国内熟透、海外猛投，滴滴未来看“国际滴”？》（2026-06-02）：毛利率 19.5%，国内上升和海外承压大体抵消，国内略占优。
- **适用场景与注意事项**：适用于多业务、多地区公司；需要知道各业务的毛利率差异（可以定性）。触底判定至少需要两个以上季度的趋势，单季回升可能是季节性或基数效应（参见第 3 章）。

### 7.2.4 低毛利业务 / 品类放量对综合毛利率的结构稀释

- **方法要点**：综合毛利率的小幅变动，先判断是否由低毛利新品、低毛利收入占比变化造成（各业务自身毛利率不变也会被拉动），并预判第二曲线放量后盈利上行斜率受压。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先区分结构效应与同口径效应。
  2. 找出低毛利新品/收入：电解质水、其他饮料、供应链收入、有税销售、国际平价品牌、低毛利汽油等。
  3. 看各业务收入占比与各业务毛利率，计算在毛利率不变的假设下占比变化对综合毛利率的拉动。
  4. 预判：第二曲线放量后，盈利上行斜率会被压制。
  5. 反向（占比下降）：低毛利业务占比下降会抬升综合毛利率。
- **关键指标与数据来源**：各业务收入占比、各业务毛利率、综合毛利率。
- **判断标准**：
  - 低毛利业务放量 + 综合毛利率小幅下行 → 结构稀释；
  - 主力品类放缓后，产品结构被低毛利新品稀释 → 盈利上行斜率受压；
  - 多因素同向（有税销售占比下降、有税毛利率提升、免税毛利率持平）→ 毛利率抬升。
- **海豚案例**：
  - 东鹏饮料（2026-03-31）：低毛利的电解质水和其他饮料放量，毛利率 -0.2pct 至 43.9%。
  - 东鹏饮料（2026-04-30）：特饮放缓后，产品结构更多被补水啦和低毛利新品稀释，压制盈利上行斜率（同篇毛利率 +2.4pct 至 46.9%，主要来自原材料价格下降，见 7.3.6）。
  - 亚朵（2026-08-21）：零售毛利率 -1.9pct 至 51.4%，叠加低毛利供应链收入占比提升，总毛利率 -1.7pct 至 43.6%。
  - 中国中免（2026-03-31）：低毛利有税销售占比下降、有税毛利率提升、免税毛利率大体持平，三因素共同推高毛利率。
- **适用场景与注意事项**：适用于多业务、多品类公司的毛利率归因。低毛利新品放量往往是增长的代价，应与增速、市占率一起评估，而不是单看毛利率下降。

### 7.2.5 高毛利业务占比提升对毛利率与分部利润率逆势扩张的支撑

- **方法要点**：高资本开支背景下毛利率仍扩张时，归因于高利润业务（广告、订阅、AWS）占比上升与经营效率优化；毛利率改善时，还要拆费用端，确认改善来自业务结构而非单纯费用缩减。
- **操作步骤 / 拆分口径 / 公式**：
  1. 判断利润率改善来自高毛利业务占比提升，还是费用端。
  2. 比较同比扩张幅度较上季是收窄还是扩大，判断动能。
  3. 零售类业务：看零售利润率能否抵御成本上行，取决于广告占比提升。
  4. 研发费用增长拆分：自身投入增长（推荐模型优化、新引擎开发等）vs 业务整合期的裁员补偿（一次性），得出利润率改善的主要来源。
  5. 同时看销售、管理费用的变化方向。
- **关键指标与数据来源**：整体毛利率及同比、业务收入结构、分部 OPM；毛利率同比、研发费用增速（内生/一次性）、销售管理费用增速。
- **判断标准**：
  - 高毛利业务占比提升，且毛利率与分部 OPM 同时扩张 → 结构性改善；
  - 扩张幅度收窄（如 +1.8pct → +1.2pct）→ 动能边际放缓，但方向未变；
  - 研发费用增长中一次性占比高 → 对利润率的拖累不可持续、不必外推。
- **海豚案例**：
  - 亚马逊（2026-02-06）：毛利率 48.5%，同比 +1.2pct（上季 +1.8pct，略收窄）；总经营利润 250 亿，+近 18%，OPM 11.7%，同比 +0.4pct。
  - 亚马逊（2026-07-31）：毛利丰厚的广告占比越来越高，对零售毛利率持续正向，成本上行侵蚀不明显。
  - Unity（2026-08-07）：广告业务拉起后整体毛利率同比 +5.5ppt；研发费用同比 +30%，其中自身投入 +17%，其余与裁员补偿有关；销售、管理费用小幅下滑。
- **适用场景与注意事项**：混合业务结构的平台公司、处于业务结构切换期的公司。研发费用拆分的更多方法见 8.4、8.5；高毛利细分业务（如机器人雷达）占比提升的支撑详见 16.2。

### 7.2.6 平台与软件公司：用业务结构变化解释毛利率

- **方法要点**：平台型公司的毛利率变动主要来自业务结构：低毛利的支付、租赁业务占比，广告占比，自研游戏占比，以及算力成本。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出平台各业务线，标注高/低毛利：支付、租赁（低毛利）；广告、自研游戏（高毛利）。
  2. 跟踪各业务占比变化，对应到整体毛利率方向。
  3. 单独标出非结构因素：大促期带宽成本、算力成本、版税结构（捆绑套餐版税较低）、涨价。
  4. 对分部毛利率降幅偏大的，追问是否有客户结构变化（如中大型客户占比提升）。
- **关键指标与数据来源**：各业务占比；分部毛利率。
- **判断标准**：
  - 低毛利业务占比上升 → 毛利率结构性下行（贝壳租赁毛利率只有 9%）；
  - 高毛利广告/自研游戏占比提升 → 毛利率改善；
  - 订阅类公司环比提升靠涨价，同比提升靠捆绑套餐版税较低等成本因素，要把二者分开解释。
- **海豚案例**：
  - Shopify（2026-02-11）：低毛利的支付收入占比上升，加上大促期带宽成本，毛利率 46.1%，同比 -2pct；商家服务毛利率降幅偏大，怀疑中大型企业客户占比提升。
  - 贝壳（2026-03-16）：租赁毛利率只有 9%，占比上升带来结构性拖累，整体毛利率 -1.6pct。
  - 美图（2026-03-27）：高毛利的广告占比下降，加上用订阅分摊算力成本，毛利大幅 miss（详见 7.1.5）。
  - 腾讯（2026-03-18）：自研游戏占比提升、视频号广告占比提升，推动毛利率改善。
  - Spotify（2026-02-10）：毛利率环比提升靠涨价，同比提升与捆绑套餐的版税较低有关。
- **适用场景与注意事项**：平台和软件公司。算力成本类因素（AI 推理成本、API 成本）的拆解可结合 7.4.3（先降后升路径）和 15.2/15.3。

### 7.2.7 毛利率变动的多维结构归因：产品 / 渠道 / 区域 / 成本

- **方法要点**：把毛利率变动拆成产品 mix（高低毛利产品占比）、渠道 mix（直销与批发）、区域 mix（海外与国内）、原材料成本（铝、存储、锁价、套保时滞）、规模效应、库存成本线等几类，再判断是结构性还是暂时的。
- **操作步骤 / 拆分口径 / 公式**：
  1. 产品 mix：高/低毛利产品占比变化（如整星平台约 30% 低毛利占比上升）。
  2. 渠道 mix：直销 vs 批发（渠道升级是否带来毛利率改善）。
  3. 区域 mix：海外 vs 国内。
  4. 成本：原材料（铝、存储）、锁价、套保时滞。
  5. 规模效应、库存成本线（存货的混合成本）。
  6. 逐类判断：结构性还是暂时性。
- **关键指标与数据来源**：分产品/渠道/区域毛利率与占比、原材料价格、存货成本。
- **判断标准**：
  - 渠道升级但毛利率下降 → 说明吨价与结构恶化盖过了渠道升级；
  - 低成本囤金/锁价 + 提价使毛利回到前高，但存货抬高混合成本线 → 后续承压；
  - 提前锁价使毛利率提升，是成本端的暂时红利；
  - 国产化降本可守住毛利率关口。
- **海豚案例**：
  - 茅台（2026-08-14）：直销占比升高，毛利率却下降，说明吨价与结构恶化盖过了渠道升级；i茅台占直销 83%。
  - 泡泡玛特：高毛利的海外占比下降，存货周转天数从 123 天升到 201 天。
  - Rocket Lab：整星平台约 30% 低毛利占比上升，Q3 毛利率指引 29-31% vs 预期 36%。
  - 地平线：低端芯片为主、存储涨价、域控系统级交付三重挤压。
  - 博通：ASIC 占比提升。
  - 三花：铝价加套保时间差。
  - 老铺黄金（2026-08-25）：低成本囤金叠加提价使毛利回到前高，但 190 亿存货抬高了混合成本线，下半年承压。
  - 东鹏：提前锁价 PET 使毛利率 +4pct。
  - 禾赛：SPAD 与芯片国产化降本，守住 40%。
- **适用场景与注意事项**：制造、消费、半导体。多维归因的目的是避免单一解释；每一维都要尽量配数据，无法量化的维度要诚实标注为定性判断。

### 7.2.8 毛利率三层拆解：分部占比 / 分部内产品结构 / 并购整合期

- **方法要点**：对产品组合差异大、并购活跃的公司，毛利率不只看分部层，还要拆到分部内部的产品结构和新并表标的的整合期，三层叠加解释当季毛利率，并据此推断下季指引。
- **操作步骤 / 拆分口径 / 公式**：
  1. 第一层：高毛利与低毛利分部的收入占比变化。
  2. 第二层：分部内部的产品结构（如低毛利的整星平台约 30%，高毛利零部件 70%+）。
  3. 第三层：新并表标的整合初期的低毛利，参照历史并购的修复周期（需几个季度）。
  4. 三层叠加解释当季毛利率；据此推断下季毛利率指引。
- **关键指标与数据来源**：分部收入占比、分部毛利率、产品线毛利率、并购标的毛利率修复周期。
- **判断标准**：
  - 第一层看占比，第二层看内部 mix，第三层看修复周期；三层同向叠加则压力更大；
  - 新并表标的的低毛利是暂时性的，修复时间可参照既往整合案例。
- **海豚案例**：
  - Rocket Lab《中子号或延期》（2026-08-11）：整体毛利率 36%（环比 -2ppt）；Space Systems 占比 +13ppt 至 81%；Space Systems 毛利率 34.6%（-0.7ppt），因卫星平台约 30% 毛利占比上升，而零部件（反作用轮、星敏感器等）部分达 70%+；Mynaric 并表初期毛利低，参照 SolAero 整合经验需几个季度修复；发射毛利率 42.9%（-1.5ppt），受 HASTE 影响。
- **适用场景与注意事项**：适用于产品组合差异大、并购活跃的硬件或航天公司。分层越细对披露要求越高，无法获得分层数据时用定性判断并说明局限。

### 7.2.9 分业务毛利率异动的驱动归因（储能 / 服务等分部）

- **方法要点**：整体毛利率之外，对各分部的毛利率异动分别归因，并判断分部毛利率是否趋势性下移，把它与公司第二增长曲线的逻辑联系起来。
- **操作步骤 / 拆分口径 / 公式**：
  1. 储能分部：单价下滑（竞争加剧、工商储 ASP 下降）、关税（电芯从中国采购）、一次性关税补贴（需剔除）。
  2. 服务分部：服务中心人员储备（为车队扩张提前招人）、超充利用率、二手车和保险改善、Robotaxi 早期成本。
  3. 判断分部毛利率是否趋势性下移，并与第二增长曲线的叙事对接。
  4. 对管理层长期指引（如储能长期 20% 出头）做对照。
- **关键指标与数据来源**：储能毛利率、服务毛利率、单价、关税影响、人员成本。
- **判断标准**：
  - 剔除一次性补贴后毛利率持平 → 趋势未变；
  - 毛利率向管理层长期指引靠拢（如储能 20.4% 对长期 20% 出头）→ 前期高点不可持续；
  - 服务毛利率创新高，需拆清是二手车、超充、服务中心、保险中的哪些驱动。
- **海豚案例**：
  - 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：储能毛利率 29%（-3pct，竞争导致降价，关税从 4 亿增到 5 亿），服务 8.8%（-2pct，人员储备）。
  - 特斯拉《造车罕见回血…》（2026-04-23）：储能剔除一次性后 29.2% 持平，服务 9.2%（超充利用率加 Robotaxi 早期扩展）。
  - 特斯拉《造车硬抗…》（2026-07-23）：储能 20.4%，管理层指引长期 20% 出头；服务 14.1% 创新高（二手车、超充、服务中心、保险）。
- **适用场景与注意事项**：适用于多分部的硬件公司。关税对成本的量化见 7.3.11，新能源行业专属成本拆分见 16.3。

### 7.2.10 地区结构：收入占比 vs 毛利占比，及地区占比变化的毛利率影响

- **方法要点**：地区之间毛利率差异大时，识别高/低毛利地区的占比变化会给综合毛利率带来的结构性上行或下行压力。
- **操作步骤 / 拆分口径 / 公式**：
  - 变体 A（收入占比 vs 毛利占比）：
    1. 计算海外与国内的收入占比和毛利润占比（如海外用 40% 出头的收入创造近 50% 的毛利）；
    2. 判断高毛利地区占比下降会不会给整体毛利率带来结构性下行压力；
    3. 按半年拆分海外收入增速，找出拖累来源（如美国子公司），以及剔除问题市场后其他海外市场的增速。
  - 变体 B（地区占比变化 pct 与毛利率挂钩）：
    1. 计算高增地区的收入占比提升幅度（pct）；
    2. 把它与毛利率变化挂钩：低毛利的国际或新兴市场占比提升，会对综合毛利率形成结构性拖累；
    3. 对国际高增，还要用营销投入、试销复购率和新兴市场平价策略做归因。
- **关键指标与数据来源**：分地区收入/毛利/毛利率、分地区收入占比与毛利占比、半年度增速；分地区收入及同比、地区占比变化 pct、毛利率。
- **判断标准**：
  - 毛利占比 > 收入占比的地区 → 高毛利地区，其占比下降是结构性风险；
  - 低毛利地区占比提升 + 综合毛利率下行 → 结构性拖累，叠加原材料涨价则压力更大；
  - 剔除问题市场后增速仍高 → 拖累是局部问题而非全球性问题。
- **海豚案例**：
  - 三花《“天灾人祸”…》（2026-03-31）：海外用 40% 出头的收入创造集团近 50% 的毛利；25H2 海外收入 61 亿，同比 -8%（绝对值约 -6 亿）；剔除美国业务，海外全年增长超 20%，下半年同比超 14%。
  - 苹果：软件服务以 21%/28% 的收入占比贡献 33%/43% 的毛利润。
  - Monster（2026-05-08）：国际收入 9.4 亿、+45%，占比提升 4.5pct 至 45%；归因于世界杯预选赛和电竞营销、Storm 在英德法试销（复购率 32%），以及 Predator、Fury 在印度、非洲、墨西哥以价换量；低毛利国际市场占比提升叠加铝罐涨价，毛利率 -1.5pct 至 55%。
- **适用场景与注意事项**：适用于不同地区或业务毛利率差异大的公司，以及国际化扩张中的消费品公司。地区毛利率往往不披露，常用“毛利占比 / 收入占比”倒推相对高低。

### 7.2.11 用合并毛利率倒推未披露的子业务毛利率

- **方法要点**：公司不披露分部毛利率时，利用“整体毛利 = Σ 分部收入 × 分部毛利率”，假设较稳定的一端，倒推另一端，判断被推算分部是否因降价让利或价格战而回落。
- **操作步骤 / 拆分口径 / 公式**：
  1. 公式：整体毛利 = Σ（分部收入 × 分部毛利率）；未知分部毛利率 =（整体毛利 − 已知分部收入 × 假设毛利率）÷ 未知分部收入。
  2. 选定较稳定的一端（成熟业务或 to C 端），给出其合理假设（如 to C 毛利率从 4.7% 升至 5%；软件毛利率不变）。
  3. 倒推另一端的毛利率（企业服务、云业务）。
  4. 如需进一步，把推算结果与卖方预期结合，估算核心子业务（如 OCI）的毛利率并判断趋势。
  5. 解释整体毛利率为什么没有随高毛利业务占比提升而大幅上升（被推算分部在让利）。
- **关键指标与数据来源**：整体毛利率、分部收入、假设分部毛利率；云 + 软件合计毛利率及同比跌幅、假设的软件毛利率。
- **判断标准**：
  - 倒推结果显著下行 → 商业化让利或价格战；
  - 整体毛利率持续修复但被推算分部回落 → 整体修复来自其他分部；
  - 倒推属于估算，需要敏感性（假设略变，结论是否稳健）。
- **海豚案例**：
  - MiniMax（2026-03-02）：整体毛利率从前 9 月 23% 修复到 Q4 30%（全年约 2000 万毛利，毛利率 25%），假设 to C 从 4.7% 升至 5%，倒推企业服务毛利率从近 70% 回落到约 65%，判断为商业化让利。
  - MiniMax（2026-08-26）：26H1 整体毛利率 18%（Q4 为 30%），估算 to B 约 25%，API 价格战下毛利率明显下滑。
  - 甲骨文（2026-03-11）：云 + 软件毛利率约 68%，同比 -8pct（上季 -5.9pct），差于预期；假设软件毛利率不变，推算云整体毛利率可能已跌破 50%，OCI 或仅 30% 上下；集团毛利率 64.6%（-5.7pct），市场预期 67%。
- **适用场景与注意事项**：分部信息披露不全的公司。假设端必须稳定且有依据；倒推结果是区间性判断，不是精确值，必须写明假设。

### 7.2.12 合并口径毛利率的“表观”与“实质”：多业务混合下不急于归因

- **方法要点**：合并口径毛利率里有多个业务（传统软件、OCA、AI 云租赁、传统 OCI）时，表观下滑可能只是高增长、低毛利业务占比上升的结构变化，并不说明该业务自身毛利率在恶化；表观回升也无法直接归因到核心业务止跌。需要多季度观察，区分暂时性还是趋势性拐点。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出合并口径内的业务构成，标注各自毛利率的相对高低。
  2. 观察合并毛利率环比/同比、业务收入占比变化。
  3. 判断下滑/回升是占比变化还是自身变化；若无法拆分，诚实写“无法准确归因”。
  4. 观察多个季度，识别暂时性与趋势性拐点，不急于下结论。
- **关键指标与数据来源**：合并毛利率环比/同比、业务收入占比变化。
- **判断标准**：
  - 同比跌幅收窄 + 环比回升 → 有触底迹象，但需要后续验证；
  - 毛利率环比大幅下降而 AI 云租赁占比大幅上升 → 可能主要是结构性变化，而非核心业务恶化；
  - 整体仍低于预期但无法拆分 → 保持不确定性，不强行归因。
- **海豚案例**：
  - 甲骨文（2026-06-11）：云 + 软件毛利率 68.8%，上季 68.2%，有触底迹象，同比跌幅收窄到 -6.8pct；但整体 65.2% 低于预期 66% 以上，无法准确归因。
  - 甲骨文（2026-09-11）：云 + 软件毛利率不到 63%，环比下降超 6pct，可能主要是 AI 云租赁占比大幅上升导致的结构性变化。
- **适用场景与注意事项**：业务结构快速变化的公司。与 7.2.11 配合使用：能倒推则倒推，不能倒推则承认不确定。

**与他节的衔接**

- 结构效应（mix）解释综合利润率变化，详见 8.2。

## 7.3 成本传导：原材料、关税与定价机制

> 本节导读：毛利率能不能守住，取决于“成本涨多少、什么时候进报表、有多少能转嫁给下游”。本节给出成本端的完整工具链：先画出传导链并找到价格领先指标，再用 Δ成本/ASP 折算毛利率影响、用转嫁比例敏感性矩阵给区间、用对冲因素加减判断净效应；然后判断时滞（长协、库存、锁价、联动定价、套保），最后处理关税、通胀、利率贴息、退税等政策与金融成本，并核对公司的应对措施。推荐的使用顺序是：定价机制（联动/固定/闭口）→ 时滞 → 量化折算 → 对冲加减 → 用下季指引验证。与 7.1（总框架）、7.4（跨期因素）、第 14 章（外部价格验证）配合。

### 7.3.1 上游成本周期的双重传导链与价格斜率领先指标

- **方法要点**：画出“上游成本周期 → 中游出货与毛利”的传导链，并把上游涨价斜率与下游接受度当作周期拐点的领先信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 画传导链：
     - 存储短缺 → OEM 备货和出货受阻 → 芯片营收下滑（量的传导）；
     - 存储涨价 → BOM 成本上升 → QCT 毛利率下滑（价的传导）；
     - 国补收紧 → 终端需求转弱（需求侧叠加）。
  2. 跟踪上游涨价斜率（涨幅是否开始放缓）与下游接受度（大厂是否拒绝加价）。
  3. 把毛利率下滑拆到具体成本项：晶圆制造、封装、测试、先进封装、存储及材料。
  4. 判断拐点：存储周期一旦下行，传统基本盘的压力就会释放。
  5. 观察管理层表述的升级：从“侵蚀毛利率”升级为“缺货”，意味着约束从价格变为数量。
- **关键指标与数据来源**：存储价格涨幅斜率、OEM 对涨价的接受度、毛利率成本项；来源为电话会、第三方存储价格数据、供应链调研。
- **判断标准**：
  - 涨价斜率放缓 + 下游拒绝加价 → 周期拐点的领先信号；
  - 管理层表述从“侵蚀毛利率”升级为“缺货” → 约束升级，出货和营收风险上升；
  - 成本项全面上升（晶圆制造、封装、测试、先进封装、存储等）→ 毛利率压力来自全链条，而非单点。
- **海豚案例**：
  - 高通（2026-04-30）：管理层上季已提到存储问题，这次从“侵蚀毛利率”升级为“缺货”，链条为存储短缺 → 备货/出货受阻 → 营收下滑。
  - 高通（2026-07-30）：毛利率 53.1%，同比 -2.5pct，晶圆制造、封装、测试、先进封装、存储等成本全面上升；存储涨价斜率开始放缓，OPPO、vivo 拒绝存储厂加价，若存储周期下行有望释放压力。
- **适用场景与注意事项**：产业链中游、受上游原材料周期影响的公司（芯片设计、整机、电池）。上游价格数据与调研验证见 14.2、14.4。

### 7.3.2 原材料涨价对毛利率的量化折算：Δ毛利率 ≈ Δ单车成本 ÷ ASP

- **方法要点**：把管理层给出的“单车成本增加 X 元”折算成毛利率影响，再据此判断全年毛利率目标是否需要下调，并对下季毛利率做方向性预测。
- **操作步骤 / 拆分口径 / 公式**：
  1. 公式：Δ毛利率 ≈ Δ单车成本 ÷ ASP（成本增量除以单价）。
  2. 取管理层口径的单车成本增量；注意区分影响范围：有时管理层只说单一车型（如 i6），有时说整车。
  3. 折算为毛利率影响（pp）。
  4. 与全年毛利率目标比较：是否需要下调。
  5. 对下季毛利率给出方向性预测。
  6. 检查有无提价或产品结构对冲，以及合约滞后。
- **关键指标与数据来源**：管理层口径的单车成本增量、ASP、毛利率指引；上游存储、碳酸锂、NCM、铜铝价格。
- **判断标准**：
  - 折算后的毛利率影响如果大于目标下调余地 → 需下调全年毛利率目标（蔚来从 20% 下调至 17%-18%）；
  - 单车型的影响不能直接外推到整车，需要看该车型占比；
  - 管理层坦言“核心零部件对单车成本影响不小”，通常意味着对冲手段有限。
  - 校验口径：蔚来的 4000-5000 元对应 1.6%-2.0% 毛利率，两端数字隐含的 ASP 约 25 万元，可作为口径自洽性的检查。
- **海豚案例**：
  - 蔚来（2026-03-10）：管理层预计电池、存储、铝材涨价使单车年均成本增加 4000-5000 元，对应侵蚀毛利率约 1.6%-2.0%。
  - 蔚来（2026-05-21、2026-09-01）：二季度起行业平均每台车成本影响超过 1 万元，全年整车毛利率目标从 20% 下调至 17%-18%。
  - 理想（2026-05-29）：i6 原毛利率目标 15%，存储涨价影响约 3pp。
  - 理想（2026-08-26）：存储对 i6 毛利率冲击 3-4pp，管理层坦言核心零部件对单车成本影响不小。
  - 理想（2026-03-12）：海豚君据此预判 1Q26 车辆毛利率继续走低。
- **适用场景与注意事项**：适用于原材料占成本比重高、且产品定价难以顺价的行业。涨价影响往往有合约滞后（见 7.3.5），也要看有没有提价或产品结构对冲（见 7.3.4）。

### 7.3.3 原材料价格区间 × 成本转嫁比例的毛利率敏感性矩阵

- **方法要点**：上游原材料涨价时，设定价格中枢区间，并分三种转嫁比例（完全转嫁、共担、不转嫁）测算对毛利率的拖累区间，转嫁能力取决于合同类型与市场格局。
- **操作步骤 / 拆分口径 / 公式**：
  1. 设定原材料价格中枢区间（如碳酸锂 14-23 万元/吨）。
  2. 设三种转嫁比例：100%（完全转嫁）、50%（共担）、0%（不转嫁）。
  3. 测算毛利率拖累区间：拖累 ≈（1 − 转嫁比例）× 全额未转嫁时的拖累，因此 50% 转嫁的拖累约为 0% 转嫁的一半。
  4. 判断转嫁能力：合同类型（闭口固定价 vs 价格联动）与买方/卖方市场格局。
  5. 得出“要保住盈利需要多少转嫁比例”的结论。
- **关键指标与数据来源**：碳酸锂价格中枢（万元/吨）、转嫁比例、毛利率拖累 ppt。
- **判断标准**：
  - 只有 100% 转嫁才能保住现有盈利；
  - 转嫁比例越低，拖累区间越宽；合同是闭口价、市场是买方市场时，转嫁比例应偏向下限。
- **海豚案例**：
  - 阳光电源《平地起惊雷》（2026-04-01）：碳酸锂中枢上行至 14-23 万元/吨时，50% 转嫁对应储能毛利率拖累 3-7ppt，0% 转嫁拖累 6-14ppt，只有 100% 转嫁才能保住现有盈利。
- **适用场景与注意事项**：适用于原材料占成本比例高、处于产业链中游的集成商或加工商（储能集成、电池、家电等）。矩阵给的是区间而非点估计，配合 7.3.9 的合同机制演变一起跟踪转嫁比例。

### 7.3.4 上游涨价对毛利率的对冲因素加减分析

- **方法要点**：原材料（铝、铁、存储、电池、铜）上涨时，不直接下结论说毛利率下滑，而是把正负因素逐项列出做对冲，看净效应，并判断提前备货能否延后成本冲击。
- **操作步骤 / 拆分口径 / 公式**：
  1. 负向项：原材料成本、季节性产量下降。
  2. 正向项：规模效应（销量环比大增）、高毛利收入上行（碳积分）、高价高毛利车型占比上升、提价/联动机制。
  3. 逐项估计方向与量级，得出净效应。
  4. 判断提前备货（库存缓冲）能否延后成本冲击；对无法避免的部分（如电池原材料）给出判断。
- **关键指标与数据来源**：原材料价格走势、销量环比、高毛利收入、车型结构、备货情况。
- **判断标准**：
  - 正向项合计 > 负向项 → 毛利率仍环比提升（零跑 2Q26 环比 +3.2pct）；
  - 提前备货只能延后而不能消除成本冲击，后续季度需要跟踪。
- **海豚案例**：
  - 零跑《利润指引大幅缩水…》（2026-08-25）：2Q26 面对铝、铁、存储、电池上涨，被规模效应（销量环比 +124%）、碳积分、D 系列占比上升对冲，毛利率仍环比 +3.2pct。
  - 零跑《剑指百万…》（2026-05-15）：1Q26 原材料上涨，因 4Q25 已提前备货影响有限，但海豚君推测电池原材料涨价的影响难以避免。
- **适用场景与注意事项**：适用于原材料占成本比重高的制造业。需要跟踪大宗商品价格和公司库存周期；与 7.1.4（毛利率环比桥）配合使用，桥上每项即可对应这里的正负因素。

### 7.3.5 成本传导时滞：长协采购与库存缓冲决定涨价何时进入报表

- **方法要点**：判断原材料涨价什么时候反映到财报成本。采购基于长期合约的，重大成本变动会滞后约一个季度；持有低价库存的（如换电模式下的电池库存），可阶段性缓冲涨价。据此解释“本季冲击有限”，同时提示“下季毛利率压力会显现”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认采购合约结构：长协周期、定价方式。
  2. 确认库存水平与成本：低价库存能撑几个季度。
  3. 对照上游现货价走势，推算成本进入报表的时点。
  4. 解释当季：成本冲击有限；提示下季：压力显现，并把它设为下季的跟踪点。
  5. 下季验证：用下季毛利率指引与实际值检验（含结构和规模的对冲）。
- **关键指标与数据来源**：采购合约周期、库存水平（电池库存）、上游现货价格走势、下季毛利率指引；通过电话会或调研确认合约结构。
- **判断标准**：
  - 长协 + 低价库存 → 当季成本滞后，下季压力显现；
  - 库存缓冲只能撑一两个季度；
  - 成本冲击到位后，如果毛利率仍有韧性，要拆清是结构和规模在对冲。
- **海豚案例**：
  - 蔚来 1Q26《走过ICU，蔚来难得靠谱了！》（2026-05-21）：采购成本基于长期合约，重大成本变动可能二季度才显现；换电模式有低价电池库存可缓冲；海豚君据此提示“二季度短期可能面临的毛利率压力仍然不小”。
  - 蔚来《指引拖后腿，蔚来还能打赢翻身仗？》（2026-09-01）：二季度起单车成本影响超 1 万元，但 2Q26 卖车毛利率仍有 18.5%，靠结构和规模对冲。
- **适用场景与注意事项**：适用于原材料周期波动期的制造业财报。库存缓冲只能撑一两个季度，不能用来支撑全年判断。

### 7.3.6 消费品原材料的现货价追踪与锁价库存时滞（PET、白砂糖、铝罐、瓦楞纸）

- **方法要点**：追踪关键原材料现货价，计算区间涨跌幅，判断毛利率方向；若公司采用备库 + 锁价合约 + 现货的采购组合，要识别成本冲击的时滞——上半年靠低价库存扛住，压力落在下半年。
- **操作步骤 / 拆分口径 / 公式**：
  1. 选定关键原材料：PET 瓶片、白砂糖、铝罐、瓦楞纸等，记录期初与期末现货价，计算区间涨跌幅。
  2. 对照毛利率方向：原材料下行 → 毛利率抬升；上行 → 压力。
  3. 识别采购组合：备库、锁价合约、现货的比例决定时滞，涨价冲击往往下半年才完全体现。
  4. 判断最敏感的品类：单瓶售价最低、PET 占比最高的包装水。
  5. 同行提价而公司不跟进时，评估对利润率的影响。
- **关键指标与数据来源**：PET 瓶片价格（元/吨）、白砂糖价格、铝罐价格、毛利率；来源为大宗价格数据与公司电话会。
- **判断标准**：
  - 瓶片三个月涨超 40%，当期毛利率仍创历史新高 → 靠锁价库存扛住，下半年压力更大；
  - 同行调价而公司不跟进 → 利润率承压；
  - 原材料下行期（PET、瓦楞纸处于低位）→ 毛利率大幅提升。
- **海豚案例**：
  - 农夫山泉（2026-08-26）：PET 瓶片从 1 月约 6300 元/吨涨到 4 月中约 9000 元/吨，三个月涨超 40%；上半年靠锁价库存，毛利率 +0.6pct 至 60.9%（历史最高），下半年压力更大；包装水 PET 占比最高，同行调价而农夫没有跟进，利润率 -1.7pct。
  - 农夫山泉（2026-03-25）：下半年 PET、瓦楞纸处于低位，毛利率 +3.4pct 至 60.7%。
  - 东鹏饮料（2026-04-30）：PET 和白砂糖价格下降，毛利率 +2.4pct 至 46.9%。
  - Monster（2026-05-08）：铝罐涨价拖累毛利率。
- **适用场景与注意事项**：适用于饮料、食品、包装消费品等原材料占成本比重高的公司。要特别关注采购组合的时滞。更多食品饮料专属的原材料前瞻（铝价 + 区域溢价）见 16.7。

### 7.3.7 铜价联动定价 + 加权平均存货计价造成的毛利率阶段性错配

- **方法要点**：对采用原材料联动定价的产品（三花制冷，铜价联动覆盖率约 90%），铜价上涨时售价同步上调，而会计成本按加权平均法计价，确认的成本涨幅低于售价涨幅，毛利率阶段性抬升；铜价见顶或回落后会出现反向错配。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认联动覆盖率与存货计价方法（加权平均）。
  2. 对照季度铜价均价、季末价格与毛利率变化。
  3. 把铜价驱动的部分剥离，再判断真实的毛利韧性（例如用不受铜价影响的汽零业务净利率变化验证）。
  4. 下一季毛利率环比下滑时，提示“上季基数异常高”。
- **关键指标与数据来源**：季度铜价均价/期末价、联动覆盖率、分业务毛利率、存货计价方法。
- **判断标准**：
  - 铜价上升周期 → 联动业务毛利率阶段性抬升，需要剥离；
  - 剥离铜价后的业务（汽零）净利率仍然环比提升 → 毛利韧性真实；
  - 次季环比下滑可能是上季基数异常高，而非恶化。
- **海豚案例**：
  - 三花《“天灾人祸”…》（2026-03-31）：Q4 毛利率 31.2% 创新高（同比 +4pct、环比 +3pct），主因是铜价上涨周期；剔除铜价影响后，汽零业务 Q4 净利率仍高于 Q3，体现毛利韧性。
  - 三花《汽零回正…》（2026-05-06）：Q1 毛利率 27.8%，环比 -3.4pct，低于预期 28.5%；部分原因是 Q4 铜价飙升（年底 10 万/吨，季度均价 8.7 万），而成本端存在时滞，导致 Q4 基数异常高。
- **适用场景与注意事项**：适用于原材料联动定价的制造业（铜铝加工、零部件）。需要了解公司的存货计价方法和联动周期。

### 7.3.8 固定价格产品 + 套期保值的时滞对毛利率的短期压制

- **方法要点**：汽零等固定价格产品（铝为主要原材料，行业较少采用铝价联动）主要靠套期保值对冲，但套保有时间差，铝价快速上涨的季度里成本压力难以当季完全消化，毛利率会被短期压制。
- **操作步骤 / 拆分口径 / 公式**：
  1. 分业务：联动业务看结构变化；固定价格业务看原材料涨速与套保时滞。
  2. 叠加汇率因素（如美元贬值拖累）。
  3. 叠加基数因素（上季基数是否异常高）。
  4. 叠加结构因素（高毛利海外业务占比下降、低毛利国内业务占比被动提升）。
  5. 得出整体毛利率变化的完整归因。
- **关键指标与数据来源**：铝价季度变化、套保比例、分板块毛利率、汇率变化。
- **判断标准**：
  - 铝价快速上涨的季度，固定价格业务毛利率受短期压制；
  - 产品价格年降幅度低于行业、产品结构优化与规模效应能支撑毛利率缓慢走高，是真实的竞争力。
- **海豚案例**：
  - 三花《汽零回正…》（2026-05-06）：Q1 毛利率下滑的四个原因：①汽零铝价上涨，套保有时滞；②制冷铜价联动有效，但高毛利的海外业务占比下降，低毛利的国内业务占比被动提升；③Q4 基数高；④美元贬值拖累。
  - 三花《“天灾人祸”…》（2026-03-31）：汽零产品价格年降幅度远低于一般汽零企业，靠产品结构优化和规模效应，毛利率缓慢走高。
- **适用场景与注意事项**：适用于汽车零部件等成本加成定价不充分的行业。年降机制与联动机制的对比见 16.2。

### 7.3.9 合同定价机制演变：从闭口固定价到顺价机制，判断毛利拐点

- **方法要点**：识别存量合同多为固定单价、缺乏原材料联动，是毛利下滑的原因之一；追踪公司下一季是否建立顺价机制及传导比例，以此判断毛利率是否见底回升。
- **操作步骤 / 拆分口径 / 公式**：
  1. 本季：识别合同类型（闭口固定价 vs 价格联动）与存量占比，说明传导困难。
  2. 下一季：追踪新订单的传导比例与存量订单的传导比例（如“新单全额、存量一半”）。
  3. 对照原材料价格变化（如碳酸锂反弹）与毛利率环比变化。
  4. 把“传导困难 → 新单全额、存量一半”视为扭转最悲观预期的关键边际变化，并据此推断后续毛利率继续回升的节奏。
- **关键指标与数据来源**：合同类型、传导比例（新单/存量）、原材料价格变化、毛利率环比。
- **判断标准**：
  - 存量闭口合同无法传导 → 毛利率承压、议价“会比较痛苦”；
  - 新建顺价机制 + 毛利率环比回升 → 见底信号；
  - 存量订单交付完毕后，传导比例整体提升，毛利率有望继续回升。
- **海豚案例**：
  - 阳光电源《平地起惊雷》（2026-04-01）：存量闭口合同无法传导碳酸锂涨价，管理层称议价“会比较痛苦”。
  - 阳光电源《收入倒春寒》（2026-04-28）：碳酸锂从去年底 10 万元/吨反弹至 18 万元/吨，公司落实“新订单全额传导、存量订单传导一半”，储能毛利率环比回升 6ppt 至 30%，预计下半年继续回升。
- **适用场景与注意事项**：适用于长单、项目制、原材料价格波动大的行业。与 7.3.3 的转嫁比例敏感性矩阵配合：矩阵给区间，合同机制决定落在区间的哪一端。

### 7.3.10 大宗原材料与利率（贴息成本）对单车可变成本和 ASP 的传导

- **方法要点**：把单车可变成本的上行归因到具体大宗品（锂、钢、铝、铜、DRAM 内存、金银等贵金属，比亚迪是碳酸锂）；同时注意“利率上升导致贴息成本上行”这条经常被忽略的链条：0% APR 促销的成本会随基准利率上升，侵蚀净 ASP 和毛利率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取公司披露的单车可变成本增量，逐项对应到大宗品。
  2. 跟踪金融促销：0% APR 覆盖率、基准利率变化，估算贴息成本。
  3. 计算净 ASP：名义 ASP（含提价）− 贴息成本，判断提价是否被侵蚀。
  4. 对照毛利率变化，得出成本侧与定价侧的净效应。
- **关键指标与数据来源**：碳酸锂、钢、铝、铜、DRAM、贵金属价格，基准利率，贴息促销覆盖率，单车可变成本。
- **判断标准**：
  - 单车可变成本逐季上行（+1000 → +1180 美元）→ 大宗品全面涨价向毛利率传导；
  - 提价被贴息成本抵消 → 净 ASP 没有改善，需要在毛利率预判中扣除。
- **海豚案例**：
  - 特斯拉《造车罕见回血…》（2026-04-23）：单车可变成本 +1000 美元，来自钢、铝、铜和存储价格全面上涨。
  - 特斯拉《造车硬抗…》（2026-07-23）：可变成本 +1180 美元，来自锂、钢、铝、铜、DRAM、金银；利率上升带动贴息成本上行，抵消了 Model Y 提价 1000 美元的效果。
  - 比亚迪《宇宙车厂…》（2026-04-28）：1Q26 碳酸锂和大宗涨价侵蚀成本。
- **适用场景与注意事项**：适用于原材料成本占比高、金融促销普遍的耐用消费品。需要大宗商品价格数据和促销覆盖率估算。

### 7.3.11 关税对成本的季度影响量化，以及政策抵免对冲

- **方法要点**：把关税单独当作成本项量化，引用公司披露的季度关税影响金额，关注征税范围扩大与低价库存耗尽导致的滞后释放；同时识别对冲政策（抵免、补贴），并剔除一次性关税收益。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取公司披露的季度关税影响金额（逐季对比）。
  2. 关注征税范围扩大（如钢铝关税覆盖电工钢）与低价原材料库存耗尽带来的滞后释放；公司指引显示因销售核算滞后，关税成本会在后续季度全额释放。
  3. 识别对冲政策：美国本土组装车型按零售价 3.75% 抵免进口零部件关税，有效期延到 2030 年；2025 年 11 月起扩大 3.75% MSRP 抵减。
  4. 对跨境采购的分部（储能电芯从中国采购）单独评估持续影响。
  5. 剔除一次性关税补贴收益（储能毛利率含约 2.5 亿关税补贴，剔除后 29.2%）。
- **关键指标与数据来源**：季度关税影响金额、关税抵免比例、有效期、一次性关税收益。
- **判断标准**：
  - 关税逐季上行且有滞后释放 → 后续季度毛利率仍承压；
  - 抵免政策使单车可变成本反而下降 → 对冲有效；
  - 含一次性补贴的毛利率不具有可持续性，需剔除后再比较。
- **海豚案例**：
  - 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：4Q25 关税影响 5 亿美元（3Q25 为 4 亿），公司指引因销售核算滞后，关税成本会在后续季度全额释放；美国 2025 年 8 月 18 日扩大钢铝关税范围；3.75% 抵免让单车可变成本反而下降。
  - 特斯拉《造车罕见回血…》（2026-04-23）：2025 年 11 月起扩大 3.75% MSRP 抵减，一季度持续受益；储能毛利率含约 2.5 亿关税补贴，剔除后 29.2%。
- **适用场景与注意事项**：适用于跨境供应链、受贸易政策影响的制造企业。关税税率变化对硬件毛利率的量化归因见 15.10，每辆车的关税/大宗/芯片冲击折算见 16.1；政策冲击的整体测算见 14.6。

### 7.3.12 通胀 / 关税成本的“承担 vs 转嫁”策略与退税让利测算

- **方法要点**：判断公司面对成本上涨时是先自主消化（压毛利、保价格竞争力），还是向消费者转嫁；用毛利率与客单价的同步变化验证管理层说法；关税退税到账时，测算退税金额中有多少在当季以降价形式让出，并预判剩余退税对未来毛利率的压制。
- **操作步骤 / 拆分口径 / 公式**：
  1. 观察毛利率与客单价的同步变化：成本上升而毛利率下降、客单价没有同步上行 → 公司在自主承担。
  2. 验证管理层说法（如“先自主承担、晚一点传导”）。
  3. 退税测算：本季退税金额（含利息），当季已让出的比例，具体商品降价幅度佐证。
  4. 预判剩余退税的到账时间与让利节奏，估算对未来季度毛利率的压制。
- **关键指标与数据来源**：毛利率、客单价、退税金额、降价幅度、剩余退税比例。
- **判断标准**：
  - 毛利率下降而价格纪律不变 → 自主承担型；
  - 退税被用来降价让利（Kirkland 商品降价 10%-30%）→ 退税不会全部转为利润，剩余部分在到账季度继续压制毛利率。
- **海豚案例**：
  - Costco（2026-05-29）：通胀下零售毛利率 -21bps，公司一贯先自主承担、晚一点传导，验证了这一说法。
  - Costco（2026-09-25）：本季收到退税 1.84 亿美元（退税 1.74 亿加利息 0.10 亿），约一半当季已让出，Kirkland 核桃、咖啡豆、黑胡椒降价 10%–30%；剩余约三分之二的退税 FY27 上半年到账，会继续让利，海豚君据此预判 FY27 上半年报表毛利率大概率继续小幅下滑。
- **适用场景与注意事项**：适用于零售商和品牌商在通胀、关税周期中的利润率预测。会员制零售的专属指标见 16.4。

### 7.3.13 关税 + 折扣清库存 + 免税额取消对毛利率的分解归因

- **方法要点**：品牌服饰毛利率大幅下滑时，把它分解到关税、最低免税额取消、清库存折扣和一次性退税等项目，并判断去库存的代价是否换来了健康的库存结构。
- **操作步骤 / 拆分口径 / 公式**：
  1. ①关税全面生效后供应链成本上升；
  2. ②最低免税额取消（de minimis，8 月生效）；
  3. ③向正价销售转型、清理老旧库存付出的折扣代价（We Made Too Much 折扣渠道）；
  4. ④剔除一次性关税退税，得到可比毛利率；
  5. 判断去库存的代价是否换来健康的库存结构（库存同比、折扣力度调研）。
- **关键指标与数据来源**：毛利率 bps、折扣力度（调研）、库存同比。
- **判断标准**：
  - 毛利率降幅中有主动清库存的成分 → 属于换取库存健康的代价，可能一次性；
  - 剔除一次性退税后的毛利率降幅，才是可持续的压力。
- **海豚案例**：
  - Lululemon（2026-03-18）：关税加最低免税额取消，以及 Q4 加大 We Made Too Much 折扣，毛利率 -4.6pct。
  - Lululemon（2026-06-05）：毛利率 -410bps 至 54.2%，部分是向正价转型、主动清库存的代价。
  - Lululemon（2026-09-04）：剔除一次性退税后毛利率 54.9%、-3.6pct。
- **适用场景与注意事项**：适用于进口依赖度高的服饰、鞋类、消费品品牌。折扣力度需要调研数据佐证，库存健康度的跟踪方法见 10.6。

### 7.3.14 “ASP 大涨而毛利率仍低”反推成本端压力强度

- **方法要点**：ASP 大幅上升而毛利率没有相应改善、甚至下滑时，可以推断成本端（存储涨价）的冲击比提价幅度更大；结合供应链信息与公司的资源配置，判断毛利率会继续恶化还是已企稳。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取 ASP 同比与毛利率同比：ASP 涨 + 毛利率降 → 成本冲击 > 提价效果。
  2. 结合供应链信息：存储从“涨价”升级为“短缺”。
  3. 看公司资源配置：存储优先分配给高价机型，提升 ASP、稳住毛利率。
  4. 判断市场关注点的转移：从“会不会回升”转到“是否进一步恶化”（如“会不会跌破 8%”）。
- **关键指标与数据来源**：ASP 同比、手机毛利率、存储价格走势、存储供给状态。
- **判断标准**：
  - ASP +25% 而毛利率仍只有 8.5%（同比 -3pct）→ 存储压力“非常大”；
  - 存储优先配给高价机型、ASP +8%、毛利率环比回升 → 传统硬件毛利率企稳。
- **海豚案例**：
  - 小米《又双叒原地久跪…》（2026-08-18）：手机 ASP 同比 +25%，毛利率仍只有 8.5%（同比 -3pct），说明存储压力“非常大”，市场关注点是毛利率会不会跌破 8%。
  - 小米《跌到怀疑人生？…》（2026-05-26）：存储优先配给高价机型，ASP +8%，毛利率环比回升到 10.1%，判断传统硬件毛利率已经企稳。
- **适用场景与注意事项**：适用于上游关键零部件涨价时的下游品牌商分析。

### 7.3.15 公司应对核心零部件涨价的措施清单，并用毛利率指引验证

- **方法要点**：上游存储等关键零部件涨价时，系统列出公司的应对措施，再用下季毛利率指引是否稳住来验证措施是否有效，并与竞争对手（中低端安卓厂商受冲击更大）比较。
- **操作步骤 / 拆分口径 / 公式**：
  1. 措施①：签订长期采购协议锁价，利用规模优势加提前备货；
  2. 措施②：自研关键芯片（基带），压降其他非内存零部件成本；
  3. 措施③：产品结构优化或适当提价；
  4. 验证：下季毛利率指引是否稳住，硬件毛利率（剔除退税）是否体现供应链管理能力；
  5. 比较竞争对手的差异：安卓厂商普遍涨价、iPhone 维持价格而赢得份额。
- **关键指标与数据来源**：毛利率指引、长协情况、自研零部件、提价动作。
- **判断标准**：
  - 面对存储大幅涨价仍给出稳定的毛利率指引 → 措施有效；
  - 剔除退税后硬件毛利率维持高位 → 供应链管理能力的体现。
- **海豚案例**：
  - 苹果《AI缺位…》（2026-05-01）：长期内存协议锁定成本、自研基带、结构优化或提价；面临存储大幅涨价仍给出 47.5-48.5% 的毛利率指引。
  - 苹果《硬刚涨价…》（2026-07-31）：剔除退税后硬件毛利率约 37.5%，体现供应链管理能力；安卓厂商普遍涨价，iPhone 维持价格，赢得份额。
- **适用场景与注意事项**：适用于上游成本冲击下的品牌商比较。

### 7.3.16 上游涨价对下游硬件毛利率的传导评估（手机、PC、汽车、云 Capex）

- **方法要点**：评估上游涨价对下游手机、PC、汽车和云 Capex 的影响：毛利率能否守住（高端定位、规模效应），厂商如何调配产能（优先保高均价产品），出货是否受短缺拖累。
- **操作步骤 / 拆分口径 / 公式**：
  1. 毛利率维度：高端定位、规模效应能否守住毛利率。
  2. 产能分配：是否优先保高均价产品。
  3. 出货维度：是否受短缺拖累（如手机业务下季约 -20%）。
  4. 资本开支维度：云厂商 Capex 因涨价增加。
- **关键指标与数据来源**：硬件毛利率、手机出货、BOM 成本。
- **判断标准**：
  - 高端品牌（苹果）毛利率同比提升且指引稳定 → 守住；
  - 中低端 + 无规模优势 → 毛利率或出货承压。
- **海豚案例**：
  - 苹果（2026-05-01）：存储涨价下毛利率仍同比提升，下季指引 47.5-48.5%。
  - 小米（2026-05-26）：存储优先分配给高均价产品，毛利率环比回升。
  - 高通：手机业务下季约 -20%。
  - 特斯拉《2Q26》：存储原材料涨价。
  - 谷歌：预计 Capex 因此增加 50-100 亿。
- **适用场景与注意事项**：适用于消费电子、手机芯片、汽车。属于 7.3.1 传导链在下游的落地版本。

**与他节的衔接**

- 原材料价格传导机制对比：价格联动条款 vs 固定价加套保时间差，再叠加年降，详见 16.2。
- 关税、大宗、芯片涨价对单位成本的冲击量化（每辆多少元或美元），详见 16.1。
- 关税税率变化对硬件毛利率的量化归因，详见 15.10。
- 毛利率 = 组合改善 vs 原材料/包材成本 + 促销，两股力量对冲判断，详见 16.7。
- 原材料成本前瞻（铝价 + 区域溢价）与提价对冲，判断后续利润率改善来源，详见 16.7。

**本节速查清单**

- [ ] 先判断定价机制：联动、固定价还是闭口价？存货计价（加权平均）与长协、库存、套保的时滞各是多少？
- [ ] 是否画出传导链，并找到领先指标（上游涨价斜率、下游接受度）？
- [ ] 是否把管理层的“成本增加 X”折算为 Δ毛利率 ≈ Δ成本 ÷ ASP，并判断是否要下调全年目标？
- [ ] 是否做了转嫁比例敏感性（100% / 50% / 0%）并说明合同类型决定落点？
- [ ] 对冲因素加减是否完整（规模、高毛利收入、车型结构、提价、备货）？

- [ ] 公司应对措施（长协、自研、结构、提价）是否被毛利率指引验证？

## 7.4 产能爬坡、库存与跨期因素

> 本节导读：同样一个毛利率数字，可能夹带着上季的减值冲回、库存收益、新产线折旧或新制程良率稀释，这些都是“会计或跨期因素”，不等于经营的持续改善或恶化。本节教你把这些因素剥离出来，并判断它们会在未来几个季度怎样释放：折旧摊销与一次性减值的跨期影响、库存收益与新制程爬坡的时序拆解、毛利率“先降后升”的四点路径比较、新产能爬坡期的三因素框架。与 7.1（总框架）、4.5（一次性剔除）、10.3（Capex 引起的折旧测算）配合。

### 7.4.1 折旧摊销 / 一次性减值对毛利率的跨期影响

- **方法要点**：上季一次性减值会让本季折旧摊销下降，毛利率环比反弹，要识别为会计因素而非经营改善；反向，AI 投入带来的服务器折旧开始计入分部成本后，毛利率压力会随高投入折旧的叠加而累积。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取折旧摊销金额的环比变化（如 22 亿 → 17 亿）。
  2. 回溯上季是否有一次性减值（传统设备减值）。
  3. 把毛利率环比反弹中由折旧摊销下降贡献的部分剥离，认定为会计因素。
  4. 反向：识别新增 AI 资本开支折旧开始进入分部成本的节点（如广告分部确认部分 AI 折旧）。
  5. 前瞻判断：高投入折旧叠加，毛利率压力随之累积。
- **关键指标与数据来源**：折旧摊销金额、分部毛利率。
- **判断标准**：
  - 毛利率环比反弹 + 折旧摊销环比大降 + 上季有减值 → 会计因素，不代表经营改善；
  - 分部毛利率同比小幅下滑（-50bps）且折旧开始计入 → 压力会累积，而非一次性。
- **海豚案例**：
  - 百度《广告根基已废》（2026-02-26）：Q4 折旧摊销 17 亿 vs Q3 22 亿（上季对传统设备一次性减值，本季折旧摊销下降，毛利率环比反弹）。
  - 腾讯《不再躺尸功劳簿》（2026-05-13）：广告确认部分 AI 折旧，分部毛利率 -50bps。
- **适用场景与注意事项**：重资产或进入 AI 资本开支周期的公司。Capex 引起的折旧测算、折旧传导与利润率窗口见 10.3；剔除库存减值/释放、还原实际毛利率见 4.5。

### 7.4.2 库存收益与新制程爬坡对毛利率的时序拆解

- **方法要点**：把毛利率的季度波动拆成三类力量：提价（正向）、新制程量产初期良率低造成的稀释（负向）、上季度库存收益等不可持续项（一次性），再用下一季的实际数据检验。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取 GAAP 毛利率实际值与指引、与市场预期的差距。
  2. 拆三类力量：提价（正向）、新制程良率稀释（负向）、库存收益等一次性项。
  3. 对环比回落的指引，解释为“下一季没有上一季的库存收益 + 新制程初期稀释”。
  4. 下一季验证：实际是否超过指引、超出的部分是提价还是良率。
  5. 对指引远低于预期的情形，解读为新制程毛利率和良率不如意（详见 7.1.8）。
- **关键指标与数据来源**：GAAP 毛利率实际值与指引；库存收益；新制程产量占比及良率；提价幅度。
- **判断标准**：
  - 毛利率大超预期且部分来自库存收益 → 不可持续，下季指引应回落；
  - 实际毛利率高于回落指引 → 提价超预期，覆盖了新制程稀释；
  - 毛利率环比下滑且归因于良率低 → 技术进展偏慢。
- **海豚案例**：
  - 英特尔《英特尔：告别“至暗”时刻，老霸主打响“反击战”》（2026-04-24）：Q1 毛利率 39.4% vs 预期 32.5%（部分来自库存收益）；Q2 指引 37.5% 环比下滑，归因于库存收益消失和 18A 初期稀释。
  - 英特尔《英特尔：CPU 涨价救场，翻身还得看代工？》（2026-07-24）：Q2 实际 40.4%，涨价覆盖 18A 稀释。
  - 英特尔（2026-01-23）：Q4 毛利率 36.1%，环比下滑因 18A 良率低；Q1 指引 32.3% 远低于预期 38%，被解读为 18A 毛利率和良率不如意。
- **适用场景与注意事项**：适用于制程爬坡期的 IDM 或代工厂，以及有库存跌价/回转的制造业。库存收益通常要靠电话会才能确认。

### 7.4.3 毛利率 / 利润率的“先降后升”路径：当季 vs 下季指引 vs 全年指引 vs 上季指引

- **方法要点**：把利润率放到四个时点比较，识别成本结构变化对毛利率的阶段性拖累，以及随付费率提升的恢复路径。
- **操作步骤 / 拆分口径 / 公式**：
  1. 当季实际（同比变化）。
  2. 下季指引。
  3. 全年指引。
  4. 上季给的全年指引（与本季全年指引比较，判断指引是上调还是下调）。
  5. 识别成本结构变化（AI 功能渗透到低付费/免费用户，推理成本上升）对毛利率的阶段性拖累，以及随付费率提升的恢复路径。
  6. 管理层是否重申“先降后升”的路径。
- **关键指标与数据来源**：毛利率、Adj. EBITDA 利润率（当季/下季指引/全年指引/上季指引）。
- **判断标准**：
  - 当季毛利率超预期 + 管理层重申“先降后升” → 路径未变；
  - 全年指引略高于上季指引 → 隐含对全年更有信心；
  - 下季指引环比回落（如 24%）属于路径中的“降”，要看全年隐含的“升”。
- **海豚案例**：
  - 多邻国（2026-05-05）：Q1 毛利率超预期，环比微升至 73%；管理层重申 AI 功能下放导致毛利率先降后升；Adj. EBITDA 利润率 Q1 28.6%（同比 +1.5pct），Q2 指引 24%，全年 25.7%，略高于上季指引。
  - MiniMax（2026-08-26）：公司指引毛利率下半年及 26 年之后持续向上。
- **适用场景与注意事项**：嵌入 AI 功能、成本结构正在变化的软件/订阅公司。指引的解读与保守度校准见第 9 章。

### 7.4.4 新产能爬坡期毛利率承压的三因素框架：新增折旧、新团队成本、爬坡复杂度

- **方法要点**：新车型或新产线投产初期，毛利率下滑归因于三类因素，并用“转正条件”预判各季毛利率的路径与拐点时间。
- **操作步骤 / 拆分口径 / 公式**：
  1. 因素一：投产即开始计提折旧，而单班制产量有限，单位折旧被推高。
  2. 因素二：新组建的制造团队带来额外薪酬。
  3. 因素三：量产初期工艺复杂、损耗高（爬坡复杂度）。
  4. 转正条件：产量集中释放、BOM 成本优势、采购议价。
  5. 预判各季毛利率的路径与拐点时间（哪一季产量集中释放，哪一季转正）。
- **关键指标与数据来源**：新产线折旧、班制（单班或双班）、周产量、BOM 成本对比。
- **判断标准**：
  - 三因素叠加期 → 毛利率承压，不宜用稳态毛利率外推；
  - 产量集中释放 + BOM 优势出现 → 拐点；
  - 新车型 BOM 显著低于上一代（R2 约为 R1 的 50%）→ 长期毛利率改善的潜力。
- **海豚案例**：
  - Rivian（2026-05-01）：R2 在 Q2 量产并计提折旧，单班产量有限；新制造团队薪酬；爬坡复杂度。三者导致 Q2-Q3 毛利率承压；转正驱动是 Q4 产量集中释放，以及 R2 的 BOM 约为 R1 的 50%。
  - 小鹏（2026-03-20、2026-05-28）：超级增程版首次引入，早期爬坡损耗推高单车成本。
- **适用场景与注意事项**：适合制造业新产品导入期。折旧的量化测算见 10.3，新品周期与里程碑的追踪见 6.5。

**与他节的衔接**

- 剔除库存减值/释放影响，还原实际毛利率，详见 4.5。
- Capex 引起的折旧测算与利润率窗口，详见 10.3。

**本节速查清单**

- [ ] 毛利率环比的变化里，有多少来自上季减值冲回、折旧摊销下降等会计因素？
- [ ] 是否识别了库存收益等不可持续项，并解释下季指引为何回落？
- [ ] 新制程或新产品的良率稀释是否单列，并有下季验证？
- [ ] 是否比较了当季、下季指引、全年指引、上季全年指引四个点？
- [ ] 新产线：折旧、新团队薪酬、爬坡损耗三项是否分别估算，并给出转正条件与拐点时间？

## 7.5 毛利率基准、议价权与真实毛利

> 本节导读：毛利率“是好还是坏”不只看环比和预期差，还要有绝对水位：健康线、关键关口、历史分位，以及它能否反映公司的议价权和真实增长质量。本节给出四个工具：健康毛利率基准线与历史分位定位；用毛利额增速代替收入增速衡量真实增长（收入口径迁移时）；增量毛利转化率（判断纯价格驱动程度）；“增收不增利”的交叉验证（识别被大客户压价）。与 7.1.3（提价 vs 结构与议价权）、7.3（成本传导）配合；毛利率作为议价权指标的广告媒体用法、“真实毛利率”自定义等行业专属做法见第 15 章。

### 7.5.1 健康毛利率基准线 / 关键关口与历史分位定位

- **方法要点**：除了环比和预期差，海豚君还为公司设一个绝对的“健康水位”或心理关口，作为好坏的定性标准；并用历史极值（“2021 年以来最低”“历史新高”）强化结论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 设基准：采用管理层长期坚守的目标毛利率（如理想的 20%）、行业公认水平、或稳态区间（如禾赛 40%、特斯拉储能长期 20% 出头）。
  2. 定性：跌破基准线 → 经营压力显著；即使反弹，只要仍远低于基准 → “修复有限”；守住关口 → 稳健；创出新高 → 强化。
  3. 用历史序列描述：“2021 年以来最低”“历史新高”“首次跌破 40%”，为判断提供位置感。
  4. 动态更新基准线：随行业竞争格局调整，管理层可能下调目标（蔚来从 20% 下调到 17%-18%）。
  5. 突破或跌破关口时，据此推断竞争或技术进展。
- **关键指标与数据来源**：卖车毛利率、整体毛利率、单车毛利的历史序列；管理层长期目标毛利率；毛利率阈值（关口、稳态区间）。
- **判断标准**：
  - 低于健康线（理想 20%）→ 压力显著；回升后仍大幅低于 → 修复有限；
  - 在关口附近（禾赛 40%）→ 首次跌破、守住、站稳三种状态对应不同定性；
  - 已到极高水位（如 80%+）→ 进一步上行空间有限（见 7.1.1）。
- **海豚案例**：
  - 理想 4Q25（2026-03-12）：卖车毛利率 16.8%，“真实卖车毛利率脱离 20% 健康线”，单车毛利来到 2021 年以来最低点。
  - 理想 1Q26（2026-05-29）：二季度毛利率指引约 10%，“仍然大幅低于 20% 健康毛利率水准，修复程度有限”。
  - 理想 2Q26（2026-08-26）：9.4%，同比下滑约 10pp。
  - 禾赛 1Q26（2026-05-19）：39.1%，“首次跌破 40% 稳健线”。
  - 禾赛 2Q26（2026-08-19）：40.1%，“守住 40% 关口”。
  - 禾赛 4Q25（2026-03-24）：41%，“守住 40% 以上”。
  - 蔚来 1Q26（2026-05-21）：整体毛利率 19%，达到历史新高。
  - 其他关口与水位：特斯拉储能长期 20% 出头（低于此前 30%）；英特尔毛利率是关键指标；台积电 66%；美光 86%。
- **适用场景与注意事项**：适用于有长期目标利润率或行业公认合理利润率的公司，尤其是制造业。基准线需要随行业竞争格局变化而调整，管理层自己可能下调目标，所以要同时记录“基准线的来源与日期”。

### 7.5.2 用毛利额增速代替收入增速衡量真实增长（跨收入口径）

- **方法要点**：收入结构在总额法和净额法之间迁移时（1P 转 3P、半托管等），收入增速会失真，这时改看毛利润额增速，把它和 GMV 增速对照，判断底层业务是否真的不差。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认收入口径迁移（1P → 3P、半托管等）使收入增速失真。
  2. 取毛利额及同比、毛利率同比变动（pct）。
  3. 把毛利额增速与 GMV 增速对照：毛利额增速更接近 GMV，说明底层业务其实不差（“反转之后的再反转”）。
  4. 毛利额绝对值与市场预期比，算出超预期多少亿元。
  5. 检查经营利润增速是否与底层 GMV 增速一致甚至更高，判断利润释放是否健康。
- **关键指标与数据来源**：毛利额及同比、毛利率同比变动（pct）、毛利额与市场预期差额（亿元）、GMV 同比、经营利润同比。
- **判断标准**：
  - 毛利额增速 ≈ GMV 增速 → 底层业务健康；
  - 毛利额超预期（如高 3.3 亿）+ 经营利润增速 ≥ GMV 增速 → 利润释放健康，属“不太增营收但增利润”。
- **海豚案例**：
  - 唯品会《唯品会：不增收也能增利，只是怕2Q坎难过》（2026-05-21）：1Q26 收入只增长 1.2%，但毛利额 65 亿、同比近 +7%，比市场预期高 3.3 亿，毛利率 24.4%（同比 +1.2pct）；海豚君据此认为毛利增长更贴近 GMV；经营利润 25 亿、同比 +10%，与 GMV 增速基本一致甚至更高，属于“不太增营收但增利润”。
- **适用场景与注意事项**：适用于收入确认口径会因业务模式变化而迁移的平台和零售公司。毛利额本身也会受退货、补贴等因素影响，需要结合起来看；收入确认与会计政策变化的清洗见 4.3。

### 7.5.3 增量毛利转化率：新增毛利 ÷ 新增收入

- **方法要点**：在纯涨价驱动的季度，边际交付成本几乎为零，新增收入几乎全部转为新增毛利；增量毛利转化率就是判断“增长有多少是纯价格驱动”的指标。
- **操作步骤 / 拆分口径 / 公式**：
  1. 公式：增量毛利转化率 = Δ毛利 ÷ Δ收入（Δ 为本季相对上季的绝对增量）。
  2. 与毛利率对照：转化率高于上季毛利率时，毛利率会上升（这是由算术关系决定的）；转化率接近 100% 时，毛利率只是“顺带值”。
  3. 转化率极高 → 收入基本全部由涨价驱动。
  4. 推论：收入指引已经隐含 EPS 指引。
- **关键指标与数据来源**：Δ毛利 / Δ收入；毛利率。
- **判断标准**：
  - 转化率近 100%（美光 98%）→ 纯价格驱动，毛利率只是顺带值；
  - 转化率明显低于当期毛利率 → 增量被成本或结构稀释。
- **海豚案例**：
  - 美光《美光：牛气冲天！“凄凉周期”要变“超级成长”？》（2026-06-25）：Q3 新增收入向新增毛利的转化率高达 98%，毛利率 84.6%；说明“毛利率只是顺带值”，收入基本全部由涨价驱动。
- **适用场景与注意事项**：适用于价格驱动的商品型行业，也可用于判断软件、平台类公司的增量利润率。价格驱动的收入拆解方法见 5.2。

### 7.5.4 “增收不增利”交叉验证：收入高增而毛利率下滑，推断被大客户压价

- **方法要点**：某业务收入大幅增长，毛利率却同比下滑，说明公司缺乏议价能力、被大客户压价；再结合相关业务增速回落，判断增长主要由客户产品周期驱动，而不是份额抢占。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取分业务收入增速与毛利率同比（如收入 +36%、毛利率 -0.2pct）。
  2. 判断：量增价不增 → 议价能力不足、被压价。
  3. 交叉验证关联业务增速（精密零组件增速从 20% 回落到 2%），判断是否只是“回到牌桌”而非抢到大量份额。
  4. 结论：增长主要由客户产品周期驱动。
- **关键指标与数据来源**：分业务收入增速、分业务毛利率同比、关联业务增速。
- **判断标准**：
  - 收入高增 + 毛利率同比下降 → 缺乏议价权；
  - 关联业务增速大幅回落 → 增长偏周期性，份额并未显著提升。
- **海豚案例**：
  - 歌尔《果链“有量无价”…》（2026-08-20）：声学整机收入 +36%，毛利率 9.7%（同比 -0.2pct），判断仍受苹果压价；精密零组件增速从 20% 降到 2%（77.6 亿），综合判断只是“回到牌桌”。
- **适用场景与注意事项**：适用于对大客户依赖度高的供应商。与 7.1.3（成本转嫁成功 = 议价权）形成正反对照：前者是毛利率不降反升，后者是收入高增而毛利率下滑。

**与他节的衔接**

- “真实毛利率” = (收入 − 营收成本 − 技术与基建费用) ÷ 收入，详见 15.2。
- 分业务毛利率 vs 历史峰值 + 成本绝对值 + 单点位租赁成本测算议价权，详见 15.5。
- 毛利率作为议价权指标：拆为点位 UE 提升 + 行业集中度带来的刊例价/租金变化，详见 15.5。
