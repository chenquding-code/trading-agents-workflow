# 第4章 单位经济与成本结构

> **本章目的**：在最小经营单元上算清收入、成本、利润和回报，判断降本空间和规模效应。

**本章小节**：4.1 单位经济模型构建｜4.2 投资回报、回本周期与客户经济性｜4.3 成本结构、降本路径与经营杠杆

---

## 4.1 单位经济模型构建

> 本节导读：本节解决“在最小经营单元上，每一单位投入能换回多少收入、成本和利润”的问题，最小单元可以是 1GW 算力、1 个 token、1 家门店、1 辆车、1 个终端用户或 1 个订单。公司没有披露分部利润、需要判断扩张是否划算、或某个定价是否“反常”时使用。本节只负责把“单位收入—单位成本—单位利润”立起来；把单位经济折算成回本期与 ROI 见 4.2，把成本拆到部件与环节见 4.3，收入端的量价拆分见 3.2，用单位经济锚定营收与利润预测见第 8 章。

**通用搭建顺序**（下列各方法共享）：①选定最小经营单元并统一口径（每 GW、每百万 token、每店、每车、每用户、每单、每英里）；②分别写出单位收入、单位变动成本、单位前置投入或固定成本；③区分“公司口径 / 行业口径 / 自己的测算口径”，关键假设给区间而不是单点；④与同业或自身历史对比，算出溢价或折价倍数；⑤向后连接回本期（4.2）、降本空间（4.3）与利润预测（第 8 章）。

**本节方法一览**：4.1.1 单 GW 算力单位经济模型；4.1.2 每 GW 年化收入推演（IT 负载 → 设施功率 → 交叉验证）；4.1.3 Token 工厂经济学；4.1.4 单位 Token 经济模型；4.1.5 国内与海外单车利润分拆；4.1.6 目标利润定价法；4.1.7 分履约方式单位经济拆解；4.1.8 ToC 单用户经济；4.1.9 加盟商视角的单店模型横向对比；4.1.10 新店型单店模型。

### 4.1.1 单 GW 算力单位经济模型（单 GW 年收入 / Capex / 租金 / 回本期）

**方法要点**：把算力产业链的各项经济量统一折算到“每 GW”口径，使不同公司、不同合同、不同芯片代际之间可以直接比较，是海豚君分析算力租赁类公司和算力事件的通用尺子。

**操作步骤 / 拆分口径 / 公式**：
1. 定义四个“每 GW”量：
   - 单 GW 年收入：必须区分三类价格——即时需求溢价价、长约价、行业正常价，三者不能混用；
   - 单 GW Capex：区分“自建全口径”（含数据中心基础设施）与“只买 IT 设备”两种口径；
   - 单 GW 年租金：按租赁口径计的每 GW 年租金（Oracle 案例中为 20 亿美元/GW），与单 GW 年收入、Capex 并列，用于核对租金收入与投入之比；
   - 单 GW 系统部署成本：按芯片代际（如 B300 系统）计的整套系统部署成本。
2. 把各家公司披露、指引或第三方测算的数字统一折算成上述口径，并标注来源（公司指引 / 海豚君模型取值 / 供应商口径）。
3. 推算派生量：回本期 ≈ 单 GW 部署成本 ÷ 单 GW 年收入（粗算口径，详细回报测算见 4.2）；溢价倍数 = 当前成交价 ÷ 行业正常价；所需 GW 与营收峰值 = 目标营收 ÷ 单 GW 年收入（营收锚定与峰值推算详见 8.5）。
4. 与同业价格带对比（如 Neocloud 的 5 年期平均合同价），判断当前公司或事件处于价格带的什么位置。

**关键指标与数据来源**：单 GW 年收入、单 GW Capex、单 GW 年租金、单 GW 系统部署成本、回本期；来源包括公司指引与合同披露、同业（Oracle、CoreWeave 等）对照、供应商（英伟达）口径与海豚君模型取值。

**判断标准**：①先判断价格属于哪一类：即时需求溢价价通常远高于长约价，只能说明短期稀缺，不能直接外推；②Capex 口径先对齐再比较——同样叫“每 GW Capex”，公司指引 250 亿、海豚君模型取 200 亿、英伟达口径 500~600 亿，差异主要来自口径（自建全口径还是只买 IT 设备）与芯片代际；③回本期远短于 GPU 寿命与合同期，才说明出租在经济上有吸引力；④海豚君的推理链条是：每 GW 收入 → 对比每 GW 成本 → 回本期与溢价倍数 → 解释公司或上游供应链的行为与需求规模。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：每 GW 年收入约 100 亿美元（Oracle）、约 88 亿美元（CoreWeave）；Capex 指引为 250 亿美元/GW，海豚君模型取 200 亿美元/GW，英伟达口径为 500~600 亿美元/GW；年租金 20 亿美元/GW。
- Meta《算力太贵，Meta 掀桌？》（2026-07-06）：xAI 即时大单每 GW 年化收入在 300 亿美元以上，是行业正常价格的 2~3 倍；B300 系统部署成本 400~500 亿美元/GW，约 1.5 年回本；Neocloud 的 5 年期平均合同价为 100~150 亿美元/GW。

**适用场景与注意事项**：适用于 AI 算力租赁、云、IDC、Neocloud，以及上游供应链（芯片、电力、设备）的需求测算。单 GW 数值随芯片代际、合同期限、供需紧张程度波动很大，使用时必须写明价格类别与 Capex 口径，并给出区间；不要把即时溢价价当作稳态价格使用。

### 4.1.2 每 GW 年化收入推演：IT 负载按 PUE 换算设施功率，双合同交叉验证，再对标行业价格

**方法要点**：公司没有披露算力定价时，用已知合同的年化金额反推“每 GW 设施功率对应的年化收入”，再用第二份合同交叉验证，最后与行业价格带对比，判断定价是否偏离行业。

**操作步骤 / 拆分口径 / 公式**：
1. 取合同年化金额（如年化 150 亿美元）与对应的纯 IT 负载（如约 330MW）。
2. IT 负载换算为设施总功率：设施功率 = IT 负载 × PUE。PUE 按冷却方式取区间——风冷 H100/H200 为主的集群取 1.3~1.5，液冷集群取 1.1~1.2。
3. 每 GW 年化收入 = 合同年化收入 ÷ 设施功率（换算到 GW）。
4. 用第二份合同交叉验证：先由 GPU 数量与单芯片功耗得到 IT 负载（单芯片功耗口径需换算到整体 IT 负载，如 11 万颗 GB300、单芯片 1400W、IT 负载约 220MW），再乘对应的液冷 PUE，同样折成每 GW 年化收入。
5. 对比行业：头部 Neocloud（裸金属）约 100 亿美元/GW，综合 CSP 约 150 亿美元/GW，计算偏离倍数。
6. 在结论里标注口径风险（合同可能涉及不同集群、不同代际硬件）。

**关键指标与数据来源**：年化合同收入、IT 负载（MW）、PUE、单芯片功耗、每 GW 年化收入、行业基准价格（来自行业调研）。

**判断标准**：两份合同、两套 PUE 假设下推出的每 GW 年化收入若都明显高于行业带，则结论稳健——海豚君的推理链条是“单合同推算 + 另一合同交叉验证 + 行业对标”，只要不同口径下都得到同方向结论，就可以认定定价存在系统性溢价而非测算误差。

**海豚案例**：
- SpaceX《SpaceX：AI 烧钱不止…》（2026-06-30）：①Anthropic 合同按年化 150 亿美元、约 330MW 纯 IT 负载计，Colossus 1 以风冷 H100/H200 为主，PUE 取 1.3~1.5，总设施功率约 430~495MW，每 GW 设施功率对应年化收入约 300~350 亿美元（提示合同还涉及部分 Colossus 2，口径可能偏高）；②用 Google 合同交叉验证：11 万颗 GPU 假设以 GB300 为主，单芯片 1400W，IT 负载约 220MW，液冷 PUE 取 1.1~1.2，设施功率约 242~264MW，每 GW 年化收入约 416~455 亿美元；③对比行业：头部 Neocloud（裸金属）约 100 亿美元/GW，综合 CSP 约 150 亿美元/GW。结论：无论按哪个口径，xAI 的定价都是行业均值的 3~4 倍，存在显著的“反常识溢价”。

**适用场景与注意事项**：适用于数据中心、算力租赁、电力类业务的单位定价推演。PUE 与芯片功耗假设对结果敏感，必须给区间；合同若覆盖多个集群或多代硬件，要提示口径偏差方向。该溢价是否可持续、对回本期与融资的含义，接 4.2.1、4.2.2；其成本端（累计资本开支 ÷ 已部署算力）见 4.3.9。

### 4.1.3 Token 工厂经济学：功率约束下按速度分层定价，测算单位功率收入

**方法要点**：把数据中心看成受功率约束（如 1GW）的“token 工厂”，产出用吞吐量（tokens/watt）和速度（智能度）两个维度衡量，token 像大宗商品一样按速度分层定价，从而评估新架构提升“单位功率收入”的能力，而不只是单芯片算力。

**操作步骤 / 拆分口径 / 公式**：
1. 设定功率约束（如 1GW）。
2. 用两个维度刻画产出：吞吐量（tokens/watt，高吞吐对应低速度）与 token 速度（智能度，高速度对应低延迟、高带宽）。
3. 按速度把 token 分层定价：从免费层（高吞吐、低速度）一直到顶级低延迟、高带宽层，每层给出每百万 token 价格。
4. 给每个层级分配一部分功率（如每 25% 功率分配一个层级）。
5. 单位功率收入 ≈ Σ（层级功率占比 × 该层级 tokens/watt × 该层级每百万 token 价格）；比较不同代系统的结果，得到代际收入倍数。

**关键指标与数据来源**：tokens/watt；token 速度；每百万 token 价格；单位功率收入；来源为厂商发布会（GTC）披露的分层价格与代际对比。

**判断标准**：新一代硬件的价值看“同样 1GW 功率能多赚多少收入”（代际收入倍数），而不是看单芯片算力提升；速度越快的层级单价越高，因此架构对高速层的支持能力决定收入天花板。使用时要注意这套分层价格出自供应商叙事，需要与客户实际支付意愿、实际成交价对照（见 4.1.4）。

**海豚案例**：
- 英伟达（2026-03-17，GTC 要点解读）：价格分层为免费、$3、$6、$45、$150/百万 token；1GW 数据中心每 25% 功率分配一个层级；Grace Blackwell 比 Hopper 多产生 5 倍收入，Vera Rubin 在此基础上再提升 5 倍。

**适用场景与注意事项**：适用于 AI 算力硬件的价值量评估，以及云厂商算力收入测算。分层价格与功率分配比例是假设而非实际成交，结论对分配比例敏感，应做情景。

### 4.1.4 单位 Token 经济模型：租赁价格、单卡吞吐、单位成本、单位毛利率

**方法要点**：评估 AI 云业务能否持续，不看“3 年回本”叙事本身，而是建单位 token 经济模型，检验其隐含假设——单位 token 毛利率至少保持稳定。

**操作步骤 / 拆分口径 / 公式**：
1. 收入端：取 GPU 租赁价格（如 H100 云租赁价）及其历史降幅；开源模型与价格战对单价形成压缩。
2. 成本端：单卡吞吐量（tokens/卡）提升，软件迭代（FlashAttention、投机解码、MoE、前缀缓存）提升芯片有效利用率，使单位 token 成本下降。单位 token 成本 ≈ 单卡成本 ÷ 单卡吞吐。
3. 单位 token 毛利率 = 1 − 单位 token 成本 ÷ 单位 token 价格，分时间序列观察。
4. 检验“3 年回本”叙事：回本成立的隐含条件是毛利率不下滑；看毛利率是否已见顶、价格降幅与成本降幅谁更快。

**关键指标与数据来源**：GPU 租赁价格；单卡吞吐；单位 token 成本；单位 token 毛利率；来源为实际租赁价格与单卡吞吐数据，以及海豚君的测算。

**判断标准**：成本降幅（硬件有效利用率提升）大于价格降幅，毛利率上行；反之下行。海豚君的结论是持续性存疑：硬件有效利用率有天花板，而价格端被开源模型和价格战压缩得可能更快，因此“3 年回本”的前提并不稳固。

**海豚案例**：
- 百度（2026-09-07）：以 H100 云租赁为例，三年租赁价格下降 78%，单卡吞吐量提高 8 倍，单位 token 成本下降 97%；单位 token 毛利率在 2024 年中升到 75% 左右后不再改善，2026 年上半年因终端价格下杀和老卡利用率瓶颈隐约走弱。

**适用场景与注意事项**：适用于 AI 云、推理服务和算力租赁公司。本方法验证的是“毛利率稳定”这一假设；回本周期与平衡点的具体测算接 4.2.4。

### 4.1.5 国内与海外单车利润分拆：测算销量结构变化对利润的拉动

**方法要点**：把单车利润按区域拆开，量化“销量结构向高利润地区倾斜”对总利润的拉动，解释为什么总销量几乎不增长、利润仍能显著增长。

**操作步骤 / 拆分口径 / 公式**：
1. 分区域取销量（国内、海外）。
2. 分区域估算单车利润（如国内 3000~4000 元，海外约 2 万元）。
3. 净利润 ≈ 国内销量 × 国内单车利润 + 海外销量 × 海外单车利润 + 其他业务。
4. 在中性假设下，比较“总销量增速”与“利润增速”的差异，判断利润增长中结构（海外占比提升）的贡献。

**关键指标与数据来源**：国内单车利润（3000~4000 元）、海外单车利润（约 2 万元）、分区域销量、归母净利润；分区域单车利润多为估算，需用海外子公司财务数据或调研校准。

**判断标准**：海外单车利润是国内的 5~7 倍时，销量结构每向海外倾斜一点，利润弹性就远大于总销量弹性；国内销量下滑的冲击可被海外放量对冲，即“单车利润结构性改善”。预测结论要注明是在中性假设下得出。

**海豚案例**：
- 比亚迪《比亚迪：“颠覆性”发布会，能“颠回”宇宙车厂吗？》（2026-03-06）：海外单车利润约 2 万元，远高于国内 3000~4000 元；总销量仅增长 2.3%，利润仍显著增长；中性假设下 2026 年归母净利润 450~470 亿元，较 2025 年约 350 亿元提升 29%~34%。

**适用场景与注意事项**：适用于国内外盈利差异大的出海企业（车企、家电、工程机械等）。分区域单车利润为估算值，对关税、汇率、渠道费用敏感，要用海外子公司财务或调研数据校准后再用于预测。

### 4.1.6 目标利润定价法：从每英里成本推定价与利润率，并考虑价格与 TAM 的弹性

**方法要点**：在垄断或定价权较强的情景下，从“每单位运营成本目标”倒推定价区间与利润率，同时权衡“定价越低 TAM 越大、定价越高利润率越高但受众越窄”的弹性。

**操作步骤 / 拆分口径 / 公式**：
1. 取公司披露的单位运营成本目标（如每英里 0.20 美元）。
2. 设定含税、收费后的定价区间（如每英里 0.30~0.40 美元）。
3. 毛利率 = 1 −（每英里成本 ÷ 每英里定价）；净利率 = 毛利率 − 运营费用率（如约 10%）。
4. 区间两端分别计算后取中位数作为估值使用的利润率。
5. 弹性分析：定价低于替代品（私家车、竞品打车）的价格阈值，才可能替代私家车、扩大 TAM；定价越高，利润率越高但受众变窄。TAM 本身的测算见 5.1。

**关键指标与数据来源**：每英里运营成本；每英里定价；毛利率；运营费用率；替代私家车的价格阈值；来源为公司发布会目标与海豚君测算。

**判断标准**：毛利率 33.3%~50%、扣除运营费用率后的净利率 23%~40%，取中位数约 30% 作为目标净利率。海豚君的推理链条是：成本目标 → 垄断情景下的定价空间 → 利润率区间 → 定价与 TAM 的权衡，目标是在“最大化 TAM”与“最大化单均利润”之间找平衡。

**海豚案例**：
- 特斯拉《从造车到造梦：1.5 万亿 AI 特斯拉真的贵了吗？》（2026-01-12，第一部分第 4 点③）：Cybercab 目标利润率约 30%（运营成本目标 0.20 美元/英里，定价约 0.30~0.40 美元/英里，毛利率 33.3%~50%，扣约 10% 运营费用率后净利率 23%~40%，取中位数约 30%）。
- 特斯拉《Cybercab 发布会…》（2026-09-04）：运营目标为每英里成本约 0.2 美元，打车价格将远低于 Uber。

**适用场景与注意事项**：适用于出行、物流等按里程（或按单位服务量）计价的运营业务。成本目标来自公司口径，需要用实际运营数据验证；“垄断情景”是前提假设，竞争加剧时定价空间会被压缩。

### 4.1.7 分履约方式单位经济拆解（费用率 × 订单占比 × 增速）

**方法要点**：把电商订单按履约方式分类，分别给出履约周期、费用率区间、订单占比、增速和适用品类，识别经济性最优与最差的履约方式，判断公司正在通过哪些手段优化结构。

**操作步骤 / 拆分口径 / 公式**：
1. 按履约方式分类（如到店自提、门店发货、仓配发货）。
2. 对每种方式列出：履约周期、费用率区间、订单占比、增速、适用品类。
3. 综合履约费用率 = Σ（各方式订单占比 × 各方式费用率）；结合增速判断结构变化方向。
4. 找出经济性最优（费用率最低）与最差的方式，观察公司通过引入 3P、提升近场履约来优化结构的手段。
5. 补充网络平台化：配送网络向外部零售商开放，摊薄固定成本，提升订单密度与骑手稳定性。

**关键指标与数据来源**：各履约方式费用率、占比、增速、履约时效；来源为公司交流与外资行模型（费用率多为估算，需注明来源）。

**判断标准**：占比和增速上升的方式如果是低费用率方式，说明综合履约费用率将下行；还要核对高费用率方式是否“仍在下降”。海豚君的推理链条是“方式 → 费用率 → 占比与增速 → 综合费用率趋势”。

**海豚案例**：
- 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：①到店自提：2~3 小时，最后一公里成本为零，费用率 3%~5%，占约 35%；②门店发货：由 Spark 众包完成，2025 年增长 50%，占近 40%，费用率 8%~12% 且仍在下降；③仓配发货：约 30 个 FC，适用长尾和大件，费用率 15%~18%，弱于亚马逊；④2021 年 Spark 开放给 Home Depot 等外部零售商，实现配送网络平台化。

**适用场景与注意事项**：适用于全渠道零售与即时配送。费用率多为外资行估算，要注明来源；各履约方式的品类适用性不同，不能只看费用率高低。履约链路的全程成本拆解（国内分拣到海外末端）见 4.3.7。

### 4.1.8 ToC 单用户经济：终端硬件售价、成本、寿命，加月套餐费

**方法要点**：把消费者业务拆成一次性的终端硬件收入和经常性的月套餐费，判断硬件是否还在拖累利润，利润主要来自哪里。

**操作步骤 / 拆分口径 / 公式**：
1. 硬件端：比较终端售价与终端成本，看是否已打平；记录设计寿命（如约 10 年）。
2. 追踪终端成本的下降路径（与消费电子供应链合作重塑供应链）。
3. 订阅端：月套餐费 × 使用周期，对比硬件寿命，形成单用户全生命周期收入。
4. 判断：硬件基本盈亏平衡后，利润主要来自订阅。

**关键指标与数据来源**：终端售价（约 500 美元）、终端成本（早期 3000 美元，现为数百美元）、设计寿命（约 10 年）、月费；来源为公司披露与供应链合作信息。

**判断标准**：终端成本降至接近售价（硬件盈亏平衡）是单用户经济成立的前提；此后单用户的价值由月费和使用寿命决定。

**海豚案例**：
- SpaceX《Space X：天空之网…》（2026-06-15）：与意法半导体、联发科、美光合作，把终端成本降到数百美元，硬件基本盈亏平衡。

**适用场景与注意事项**：适用于“硬件 + 订阅”模式（卫星宽带、智能硬件、汽车软件）。注意硬件补贴期的用户获取成本和流失率，以及终端寿命内的更换成本。

### 4.1.9 站在加盟商视角，横向对比主流品牌的单店模型

**方法要点**：对加盟驱动的连锁品牌，不只看品牌方财务，而是列出各品牌的单店模型对比表，从加盟商回报的角度判断品牌的扩张能力与竞争位置。

**操作步骤 / 拆分口径 / 公式**：
1. 选定对标品牌（如亚朵与华住全季等中高端酒店）。
2. 列单店模型对比表：前期投入、人房比、ADR、零售业务贡献、获客成本（会员收入占比）、EBITDA 利润率、投资回收期。
3. 逐项解释差异：前期投入与人房比（成本端）、品牌溢价带来的 ADR（收入端）、零售业务贡献（高利润率附加收入）、获客成本（酒店与零售会员体系深度打通，会员收入占比最高则获客成本更低）。
4. 汇总到 EBITDA 率与回收期，并从“抗风险能力”和“加盟商回报”两个维度综合判断梯队位置。

**关键指标与数据来源**：单店投资额、人房比、ADR、EBITDA 率、回本周期、会员收入占比；数据多来自调研与公司披露。

**判断标准**：亚朵前期投入和人房比更高，但品牌溢价带来高 ADR，加上利润率更高的零售业务、更低的获客成本，使 EBITDA 率处于行业极高水平、回收期更短；全季只有前期在核心地段开的优质门店回本周期能和亚朵相当。抗风险能力和加盟商回报两个维度合起来，确认亚朵在中高端第一梯队。

**海豚案例**：
- 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：亚朵 vs 全季单店模型对比图。

**适用场景与注意事项**：适合加盟驱动的连锁企业，加盟商回报决定扩张能力。数据多来自调研，要注意样本代表性（门店位置、开业年份）；比较时区分“平均门店”与“优质门店”。

### 4.1.10 新店型单店模型：面积、建造成本、投资回收期改善打开新点位

**方法要点**：当消费行为变化使标准大店变得“空间冗余”时，用新店型的单店模型量化建造成本与回收期的改善，判断是否打开此前跑不通的新点位、让同样资本开支开出更多店。

**操作步骤 / 拆分口径 / 公式**：
1. 识别行为变化对旧店型的冲击（如移动订单占比五年从 17% 升至 31%，使 200~300㎡ 标准大店在极速取单场景下空间冗余）。
2. 区分双线路线：存量门店优化做体验，增量门店做效率。
3. 用投资者日披露的原型店量化单店模型：面积、座位数、建造成本、投资回收期，与标准大店对比。
4. 判断新店型能否让此前跑不通的点位（如中部下沉小镇）重新可行。
5. 评估网络密度提升对数字业务与外送边际成本的带动。

**关键指标与数据来源**：移动订单占比、单店面积、建造成本、投资回收期、座位数；来源为投资者日披露的原型店数据。

**判断标准**：单店回收期是判断开店能否加速的核心指标——建造成本较标准大店降 20%~30%，投资回收期从 4 年缩至约 3 年，则同等资本开支可开更多店，原本不成立的点位重新可行。动机是压低单店 capex，并以网络密度提升摊薄数字业务与外送的边际成本。

**海豚案例**：
- 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：存量门店做体验（Coffeehouse Uplift，2026 年末完成 1500 家北美门店轻改造，增设沙发、电源插座）、增量门店做效率；增量店型为 Starbucks Pickup 纯取餐店（高密度都市）与 Double Drive-Thru 双车道得来速（郊区与公路枢纽）；原型店（32 座、得来速、约 125㎡）建造成本较标准大店降 20%~30%，投资回收期从 4 年缩至约 3 年，使中部下沉小镇点位重新可行。

**适用场景与注意事项**：适用于连锁业态转型。原型店数据是公司披露的目标值，需用新开门店的实际回收期验证；同时留意新店型对既有门店的分流。

**与其他小节的衔接**：用单 GW 年收入锚定营收，并以已上线/规划 GW 推算营收峰值，详见 8.5；单位经济折算为回本期与 ROI，详见 4.2。

**本节速查清单**

## 4.2 投资回报、回本周期与客户经济性

> 本节导读：本节解决“投进去的钱多久能回来、回报率是否足以覆盖融资与风险，以及客户为什么愿意为这套方案付溢价”的问题。适用于重资产投入（AI 云、算力租赁、IDC、产能扩张）的回报验证，以及 To-B 解决方案的定价权论证。单位经济的搭建见 4.1，成本侧的降本路径与 TCO 平价见 4.3；公司层面资本用途之间的回报比较（回购、分红、并购、资本开支如何取舍）不在本节，见 11.3。

**本节方法一览**：4.2.1 算力出租的 ROI 与回本期；4.2.2 回本期与融资期限错配；4.2.3 CSP 的 AI 变现模式分类与 IaaS/MaaS 的 ROIC；4.2.4 “3 年回本”平衡点反推（稳态利润率、现金回收、毛利率 × 增速矩阵）；4.2.5 “Time to Power”时间套利与电费溢价 vs 提前投产收益。

### 4.2.1 算力出租的 ROI 与回本期（溢价单价 vs 部署成本）

**方法要点**：用当前市场成交的单 GW 年化收入（即时需求溢价价）对比单 GW 系统部署成本，算出回本期，再与行业正常价格比较溢价倍数，说明出租的经济吸引力，从而解释公司的行为动机。

**操作步骤 / 拆分口径 / 公式**：
1. 取当前成交的单 GW 年化租赁收入（区分即时需求溢价价、长约价）。
2. 取单 GW 系统部署成本（按芯片代际，如 B300 系统）。
3. 回本期 ≈ 单 GW 系统部署成本 ÷ 单 GW 年化租赁收入。
4. 溢价倍数 = 成交价 ÷ 行业正常价格。
5. 用回本期与溢价倍数回答“公司为什么愿意这样做”（行为动机）。
6. 长期测算改用长约价（如 Neocloud 5 年期平均合同价 100~150 亿美元/GW）重算，检验溢价消失后经济性是否仍然成立。

**关键指标与数据来源**：单 GW 年化租赁收入、行业正常价格、单 GW 部署成本、回本期；单 GW 口径的搭建与取数见 4.1.1。

**判断标准**：回本期远短于 GPU 使用寿命与合同期，则出租在经济上有强吸引力；但溢价价格短期且不可持续，只能解释短期动机，不能外推到稳态回报。

**海豚案例**：
- Meta《算力太贵，Meta 掀桌？》（2026-07-06）：据海豚君测算，xAI 最新几笔百亿大单每 GW 年化收入在 300 亿美元以上，是行业正常价格的 2~3 倍；按 B300 系统 400~500 亿美元/GW 的部署成本，约一年半即可回本。

**适用场景与注意事项**：适用于算力租赁、IDC 资产的经济性判断。溢价价格短期且不可持续，长期测算要用长约价；回本期是未扣运营成本与融资成本的粗算，精细口径见 4.2.3、4.2.4。

### 4.2.2 回本期与融资期限错配测算

**方法要点**：不仅算算力租赁“多久回本”，还要把回本期与 GPU 寿命、债务期限和合同可撤销条款放在一起比较，识别“靠短期可撤销合同偿付多年期债务”的期限错配，以及融资额对规划的覆盖程度。

**操作步骤 / 拆分口径 / 公式**：
1. 回本期 = 每 GW 投入（capex） ÷ 每 GW 年租价。
2. 与 GPU 寿命比较：回本期占寿命的比例越高，风险越大。
3. 情景：租价回落到同行水平时重算回本期（回本拉长多少）。
4. 对照融资结构：债务期限、合同可撤销条款（如可提前 90 天终止）与回本期之间的错配。
5. 融资覆盖度 = 融资额 ÷（每 GW 投入 × 规划 GW），看融资额能覆盖规划的比例。

**关键指标与数据来源**：每 GW 租价、每 GW capex、回本年限、合同终止条款、融资额/规划。

**判断标准**：回本期显著短于 GPU 寿命、债务期限能覆盖回本期、合同不可轻易撤销，才算健康；如果偿债依赖可短期终止的合同，则回本测算再漂亮也存在期限错配。融资额远低于规划所需投入，则规划能否兑现取决于后续融资。

**海豚案例**：
- SpaceX（2026-10-07）：租价每 GW 300~450 亿美元，约一年回本；若回落到新云（Neocloud）的 100~150 亿美元，回本拉长到 3~4 年；400 亿美元融资按 350~400 亿美元/GW 的投入只够约 1GW，约为规划的十分之一；多年期债务靠可提前 90 天终止的合同偿付，存在期限错配。

**适用场景与注意事项**：适用于新云、算力租赁、杠杆扩张型公司。与 4.2.1 配合使用：先用 4.2.1 算溢价下的回本期，再用本方法检验价格回落与融资结构的压力。

### 4.2.3 CSP 的 AI 变现模式分类，并测算 IaaS/MaaS 的 ROIC 与回本周期

**方法要点**：把云厂商的 AI 变现模式分成五种，找出当前真正贡献增长、ROIC 为正的模式（集中在 IaaS 和 MaaS），引用机构模型测算 ROIC 与按经营现金流（OCF）计的回本周期，并指出模型的遗漏项。

**操作步骤 / 拆分口径 / 公式**：
1. 对云厂商的 AI 变现路径分类（共五种），逐类判断是否已贡献增长、ROIC 是否为正。
2. 对 IaaS：以具体芯片代际（如 GB300）为例，比较年租金收入与前置 Capex，按 OCF 算回本周期，并得出 ROIC。
3. 对 MaaS：不计入 1P 模型训练成本时，分别对自建算力与租赁算力算边际经营利润率，再得出 ROIC 与回本周期。
4. 补遗漏项：①第三方模型厂的分润；②云厂面对头部模型厂时议价能力弱，意味着利润被分走。

**关键指标与数据来源**：ROIC；OCF 回本周期；边际经营利润率；租金收入与 Capex 之比；数据引用机构（大摩）模型。

**判断标准**：自建算力的边际经营利润率远高于租赁算力（75% vs 30%），ROIC 与回本周期也明显更优；ROIC 为正（如 IaaS 自建约 30%、MaaS 自建约 46%）且回本周期约 2 年上下的模式，才是当前真正的增长来源。同时必须扣除模型的遗漏项——分润与议价弱势会让实际回报低于模型值。

**海豚案例**：
- 百度（2026-09-07，引用大摩模型）：①北美 IaaS 自建数据中心 ROIC 约 30%，以 GB300 为例，租金收入 230 亿美元/年对应前置 Capex 390 亿美元/年（约 0.59），按 OCF 算回本 2.2 年；②北美 MaaS 不算 1P 模型训练成本时，边际经营利润率自建算力 75%、租赁算力 30%，前者 ROIC 46%、回本不到 2 年；③指出模型遗漏项：北美 CSP 面对 Anthropic 和 OpenAI 天然缺乏议价优势，第三方模型厂的分润未计入。

**适用场景与注意事项**：适用于评估云厂商 AI 资本开支的回报。机构模型的假设与口径需核对，尤其是 1P 模型训练成本是否计入；结论更适合用来判断模式优劣，而非精确回报率。

### 4.2.4 反推“3 年回本”平衡点：稳态利润率、现金回收、毛利率 × 增速敏感性矩阵

**方法要点**：管理层给出“增速 30% 以上 + 毛利率 30%”是 3 年回本的平衡点，海豚君自己拆开测算其含义，从稳态利润率、现金流回收、毛利率 × 增速敏感性三个角度验证这条平衡线是否成立。

**操作步骤 / 拆分口径 / 公式**：
1. **稳态利润率视角**：订单毛利率至少 30%，扣掉 15%~20% 的稳定运营支出，经营利润率约 15% 才算可持续。
2. **现金流视角（自建算力）**：按 5 年折旧；假设收入 100 亿、毛利率 35%，则营业成本（简化视为折旧）65 亿，倒推初始投入 = 年折旧 65 亿 × 5 年 = 325 亿；零增长时扣 20 亿 Opex，OCF = 毛利 35 亿 + 折旧 65 亿 − Opex 20 亿 = 80 亿；回本期 = 325 ÷ 80，约 4 年多。
3. **引入收入增速做情景矩阵**：以毛利率为一个轴、收入增速为另一个轴，计算各组合下的回本周期，读出“毛利率越低，对增速要求越高”的边界。
4. 追问毛利率的决定因素：租赁价格（难以自控）与 Capex 节奏（可以自控）共同影响毛利率。

**关键指标与数据来源**：毛利率；Opex 率；折旧年限；Capex；OCF；收入增速；回本周期；来源为管理层指引与海豚君测算。

**判断标准**：零增长下回本需 4 年多，说明“3 年回本”必须依赖增长；毛利率 30% 时，收入增速需在 30% 以上才能 3 年内回本，毛利率越低对增速要求越高。结论：保持毛利率稳定更容易保证回本，应重点跟踪租赁价格走势与 Capex 节奏。

**海豚案例**：
- 百度（2026-09-07）：情景矩阵显示，毛利率 30% 时，收入增速需在 30% 以上才能 3 年内回本，毛利率越低对增速要求越高；本轮北美的亚马逊和中国的阿里、百度都首次对 AI 投入给出了 3 年回本的定量描述。

**适用场景与注意事项**：适用于重资产投入（AI 云、IDC、产能扩张）的回报验证。上述示例以“营业成本主要由折旧构成”作简化，实际使用时要把电费、运维等现金成本单独拆出；毛利率假设的稳定性需与 4.1.4 的单位 token 毛利率检验配合。

### 4.2.5 “Time to Power”时间套利：以客户提前投产的增量收入衡量产品价值（含电费溢价 vs 提前投产收益）

**方法要点**：对速度与可得性取胜、而非成本取胜的产品，不与传统方案比拼度电成本（LCOE），而是测算客户采用该方案提前投产带来的增量收益，论证溢价合理，说明产品摆脱 LCOE 竞争内卷。

**操作步骤 / 拆分口径 / 公式**：
- **变体 A：增量收入 vs 溢价的时间套利（财报视角）**
  1. 以 1GW 全栈 AI 数据中心为例，计算提前一年投产带来的额外算力（token）收入。
  2. 计算客户为此付出的电费与设备溢价总额。
  3. 套利倍数 = 额外收入 ÷ 溢价。
  4. 补充非价格优势：审批（避开邻避效应：低污染、低耗水、低噪音）、原生 800V 直流架构适配、融资模式（PPA 按月付电费，融资方授信）。
- **变体 B：先算 LCOE 差，再算电费溢价与提前投产收益（行业深度视角）**
  1. 对照 LCOE：北美并网或大型燃机约 0.05~0.08 美元/kWh；该方案的 SOFC 即使叠加 IRA 补贴（初始 capex 从约 5 美元/W 降至 2.5~3.5 美元/W），LCOE 仍约 0.10~0.14 美元/kWh，存在约 5~6 美分/度的劣势。
  2. 年多付电费 = 1GW × 8760 小时 × 电价差（0.05 美元/kWh）≈ 4.38 亿美元。
  3. 若因此提前一年投产，抢跑带来的额外算力租赁/服务收入达 100~150 亿美元，即用不到 5 亿美元撬动超百亿美元收益。

**关键指标与数据来源**：交付时长、设备/电费溢价、单 GW 数据中心收入（见 4.1.1）、LCOE、装机、年运行小时。

**判断标准**：额外收入对比溢价高出一个数量级以上（120~240 亿美元 vs 不到 5 亿美元），即认定为“纯粹时间套利”。海豚君的推理链条是：电价劣势（分歧点）→ 年度溢价绝对额 → 提前一年投产的收益 → 套利倍数 → 非价格优势（审批、架构、融资）加固 → 只要 CSP 需求持续，该方案就能摆脱 LCOE 竞争内卷。需求端的验证（客户是否真的放弃替代方案）是最终的证据。

**海豚案例**：
- Bloom Energy（2026-07-29，财报解读）：甲骨文首个项目 55 天通电；1GW 提前一年投产带来的额外 token 收入 120~240 亿美元，对比不到 5 亿美元的电费与设备溢价；部分客户取消燃气轮机/往复式发动机订单转向 Bloom（Nebius 类似）；Brookfield 授信扩至 250 亿美元。
- Bloom Energy（2026-07-20，“时间就是算力”）：LCOE 约有 5~6 美分/度劣势；1GW × 8760 小时 × 0.05 美元 ≈ 每年多付 4.38 亿美元；提前一年投产带来的额外算力租赁/服务收入达 100~150 亿美元，用不到 5 亿美元撬动超百亿美元，是“时间套利”。

**适用场景与注意事项**：适用于 To-B 解决方案的定价权分析（以客户 ROI 替代成本对比），也适用于任何以速度、可得性而非成本取胜的产品。前提是客户的瓶颈确实是“能否尽快投产”（电力、审批、设备交付）；一旦供给瓶颈缓解（如燃机、变压器产能恢复），时间价值收窄，溢价论证就会减弱。定价权与议价能力的更系统分析见 6.6。

## 4.3 成本结构、降本路径与经营杠杆

> 本节导读：本节解决“成本从哪里来、能降多少、规模能不能放大利润”的问题：先按部件和环节拆成本、找出降本杠杆最大的一环，再判断降本来自组织方式还是技术复用、是否带来量级变化，最后看规模扩张时经营杠杆能否释放、投入期亏损何时能扭转。适用于制造型、重资产、平台型和新技术替代型公司。与 4.1（单位经济）、4.2（回本与 ROI）配合；利润率的同业对标归 8.1，以成本差论证护城河归 6.4，航天专属的发射成本指标归 15.10。

**本节方法一览**：4.3.1 按部件拆解产品成本；4.3.2 降本来源拆分（组织/产业链 vs 技术复用）；4.3.3 单颗卫星制造降本与分代际成本路径；4.3.4 龙头单位成本学习曲线；4.3.5 晶圆面积利用率与存储成本归属；4.3.6 晶圆分级“副产物模式”成本摊薄；4.3.7 履约费用全链路拆解；4.3.8 仓配供应链成本拆解；4.3.9 累计资本开支 ÷ 已部署产能与“壳成本”；4.3.10 TCO 中的运维冗余与寿命折损；4.3.11 TCO/LCOC 平价时点；4.3.12 “成本剪刀差”双情景；4.3.13 经营杠杆倍数；4.3.14 “规模不经济”诊断；4.3.15 扭亏收入门槛反推；4.3.16 由商业模式成熟度推断盈利改善路径；4.3.17 数据业务的边际成本与订阅制现金流。

### 4.3.1 按部件拆解产品成本，定位降本杠杆最大的环节

**方法要点**：先讲清产品的物理结构和工作原理，再判断成本集中在哪个部件，由此推出“把成本最高的部件多次复用，降本意义最大”。

**操作步骤 / 拆分口径 / 公式**：
1. 讲清产品结构与工作原理（以二级推进火箭为例：整流罩、二级、一级；分级是为了逐级减重，并让发动机针对大气层和真空环境分别优化）。
2. 按部件拆成本占比，找出占比最高的部件（如一级推进器占比最高，燃料成本占比不高）。
3. 计算一次性使用模式下每次需全额承担的制造成本。
4. 推论：降本杠杆在“占比最高的部件”，复用或工艺改进应优先作用于这一环。

**关键指标与数据来源**：各部件成本占比（一级 + 整流罩约占硬件成本 70%）、燃料成本占比、单次制造成本；公开成本数据较少时，需注明为估算。

**判断标准**：成本越集中于少数部件，针对该部件的复用或降本越有杠杆；燃料占比低意味着“省燃料”不是主要降本方向，复用才是。

**海豚案例**：
- SpaceX《马斯克再甩“王炸”…》（2026-02-24）：主流液体火箭二级结构中，一级推进器成本占比最高，燃料成本占比不高，因此一级复用降本显著。
- SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：猎鹰 9 号一级助推器与整流罩合计占硬件成本 70%，一次性模式每次需全额承担约 5000 万美元制造成本。

**适用场景与注意事项**：适用于资产复用型、制造型商业模式（火箭、飞机、设备租赁）。公开成本数据少时，成本占比为估算；航天专属的发射成本指标见 15.10。

### 4.3.2 把降本拆成“组织/产业链方式”与“技术复用”两部分，并判断是否带来量级变化

**方法要点**：把领先者的成本优势拆成两块，分别判断对成本量级的影响，从而决定下一代产品的战略价值，避免把“管理/组织效率”误当成“技术突破”。

**操作步骤 / 拆分口径 / 公式**：
1. 第一块：市场化与全产业链自研自产带来的综合降本（组织/产业链方式）。
2. 第二块：技术本身（如一级复用）带来的降本。
3. 对每一块判断其对成本量级的影响：是百分比级的降低，还是量级变化（如从千美元/kg 到百美元/kg）。
4. 判断实现量级变化所需的条件（完全复用 + 高复用次数）。
5. 据此评估下一代产品的战略价值。

**关键指标与数据来源**：成本降幅、量级（如从千美元/kg 到百美元/kg）、复用次数。

**判断标准**：一级复用降本显著，但没有让成本发生量级变化；只有完全复用加高复用次数才能实现量级下降。这个判断决定了下一代产品（全部可复用）的战略价值。

**海豚案例**：
- SpaceX《马斯克再甩“王炸”…》（2026-02-24）：Falcon 的成本优势一部分来自市场化和全产业链自研，一部分来自一级复用，但一级复用没有带来量级变化；Starship 全部可复用才能实现量级降低。

**适用场景与注意事项**：适用于判断“技术突破”和“管理/组织效率”对成本的贡献，可迁移到制造业降本分析。拆分贡献时要避免把两者的效果重复计算。

### 4.3.3 单颗卫星制造降本拆解：材料替代、流水线批产，加分代际成本路径

**方法要点**：把单颗卫星的制造成本按代际追踪，再拆解每一次降本的具体手段，说明为什么成本能指数级压缩。

**操作步骤 / 拆分口径 / 公式**：
1. 按代际追踪单星制造成本：早期 100~150 万美元以上，目前 60~80 万美元，V3 预计 20 万美元。
2. 拆降本手段 (1)：材料替代——用意法半导体、德州仪器等的汽车级或工业级成熟芯片取代宇航级芯片（550 公里轨道辐射较小，才可以这样做）。
3. 拆降本手段 (2)：流水线生产——雷德蒙德工厂每周批产 70 颗，用汽车底盘式流水线和模块化；款式单一，所以能批量生产。
4. 汇总为代际成本路径，并判断每一代的降本是由哪一手段贡献。

**关键指标与数据来源**：单星制造成本（代际）、周产能（70 颗/周）、芯片等级。

**判断标准**：降本手段如果可持续（成熟芯片替代、批量生产）且有前提条件支撑（轨道辐射小、款式单一），则降本路径可信；V3 的 20 万美元是预期值，需要实际量产数据验证。

**海豚案例**：
- SpaceX《Space X：天空之网…》（2026-06-15）：文章将卫星制造降本归纳为三大逻辑，实现成本指数级压缩；核心手段包括用汽车级/工业级成熟芯片替代宇航级芯片，以及雷德蒙德工厂每周批产 70 颗的汽车底盘式流水线与模块化生产；单星成本从早期 100~150 万美元以上降至目前 60~80 万美元，V3 预计 20 万美元。

**适用场景与注意事项**：适用于制造型降本分析（汽车、卫星、消费电子）。材料替代要先确认使用环境是否允许降规格；批产降本依赖产品标准化，款式一旦增多，效果会打折。

### 4.3.4 龙头单位成本历史下降曲线（美元/W，年均降幅）验证规模降本

**方法要点**：用龙头公司的单位成本时间序列验证技术路线的降本能力，算出历史年均降幅，再把降本与可服务市场的扩大联系起来（经济性边界外移）。

**操作步骤 / 拆分口径 / 公式**：
1. 取龙头公司单位成本时间序列（如美元/W）。
2. 年均降幅 CAGR = （终值 ÷ 初值）^（1 ÷ 年数）− 1。
3. 外推未来的单位成本路径，注意降本放缓的可能。
4. 联系市场：降本使经济性边界外移，突破高电价地区局限，向低电价州规模化扩张，从而扩大可服务市场（TAM 测算见 5.1）。

**关键指标与数据来源**：单位成本（美元/W）、年均降幅（CAGR）。

**判断标准**：历史降幅是否稳定且持续，决定外推的可信度；降本是否足以把产品经济性推到新的市场（如低电价州），是判断规模化空间的关键。

**海豚案例**：
- Bloom Energy 行业篇《AI 电荒突围》（2026-04-14）：SOFC 系统单位成本从 2019 年约 4.67 美元/W 降至 2025 年约 3.14 美元/W，年均降幅约 6%；降本使其突破高电价地区局限，向全美低电价州规模化扩张。

**适用场景与注意事项**：适用于有学习曲线的制造业（电池、光伏、燃料电池）。外推需注意降本放缓，学习曲线通常随规模放大而趋缓。

### 4.3.5 晶圆面积利用率与存储成本归属分析

**方法要点**：从成本端看颠覆性方案的代价和结构差异，一看晶圆面积的浪费比例，二看存储成本归属于谁，据此理解公司毛利结构和对代工厂的依赖。

**操作步骤 / 拆分口径 / 公式**：
1. 面积利用率：晶圆面积浪费率 = 1 − 方片面积 ÷ 晶圆面积（方片切割浪费晶圆月牙形边角料）。
2. 存储成本归属：对比 SRAM 方案与 GPU 方案——SRAM 的 bit cell 设计和代工由代工厂完成，包含在晶圆报价中；GPU 方案需要外购 HBM。
3. 据此判断公司的毛利结构、对代工厂的依赖，并与后续经营分析衔接。

**关键指标与数据来源**：晶圆面积利用率/浪费率、存储成本归属（晶圆报价 vs 外购 HBM）。

**判断标准**：面积浪费率越高，每片晶圆能产出的有效芯片面积越小，成本负担越重；存储成本在晶圆报价内意味着成本结构更集中，对代工厂议价与产能依赖更强，而外购 HBM 则受存储供应链影响。

**海豚案例**：
- Cerebras《Cerebras：不切晶圆的芯片“怪兽”，有希望挑战英伟达？》（2026-10-09）：300mm 晶圆切成 215mm × 215mm 方片，约浪费 35% 面积（算式：1 − 215² ÷ (π × 150²) ≈ 35%）；SRAM 包含在台积电晶圆报价中，与 HBM 外采模式不同。

**适用场景与注意事项**：适用于新芯片架构的单位成本分析。后续经营分析需要与此衔接，把成本结构映射到毛利率与客户经济性。

### 4.3.6 晶圆分级“副产物模式”的成本摊薄分析

**方法要点**：分析高端玩家在中端产品上的结构性成本优势——能做最高规格的厂商，顺手就能做中规格，中规格成为高端产线的“副产物放量区”，晶圆分级摊薄了成本。

**操作步骤 / 拆分口径 / 公式**：
1. 列出产品分级（如按功率档划分：最高规格 400mW，中规格 150~200mW）。
2. 判断谁能做最高规格：能做高规格的厂商，中规格是同一条产线的副产物。
3. 对从低端向上突破的二梯队或中国厂商，判断其能否跨到最高档：跨不到，就享受不到晶圆分级的摊薄，中规格综合成本难以与头部抗衡。
4. 比较各档综合成本，评估中端市场的竞争格局。

**关键指标与数据来源**：晶圆分级比例、各档综合成本。

**判断标准**：头部厂商的中规格产品是“副产物”，边际成本低；二梯队若只做中规格，综合成本更高，价格竞争中处于劣势。

**海豚案例**：
- Lumentum《从光互联老炮到“全能卖水人”，Lumentum 凭什么？》（2026-09-24）：150~200mW 中功率档相当于高功率玩家的副产物放量区；对二梯队来说，这一档是冲击高端的必经之路，但难以对抗副产物模式的低成本。

**适用场景与注意事项**：适用于有产品分级（binning）的半导体、光器件、电池等行业。以成本差论证护城河的部分见 6.4。

### 4.3.7 履约费用全链路拆解：单均履约费 + 费用率 + 链路环节归因

**方法要点**：计算履约费用占收入比与单均履约费，与标杆对比后，按链路逐段解释高成本的原因，并点出高成本的“交换物”（周转效率与体验），避免单向结论。

**操作步骤 / 拆分口径 / 公式**：
1. 履约费用率 = 履约费用 ÷ 收入；单均履约费 = 履约费用 ÷ 订单数。
2. 与标杆（如亚马逊）对比，量化差距。
3. 按链路逐段解释高成本原因：国内分拣打包 → 跨境空运/海运 → 目的国清关 → 进口关税 → 海外末端配送。
4. 叠加品类退货率与免费退货政策的影响。
5. 点出高成本的“交换物”：换来的是周转效率和用户体验，因此需要区分模式性成本与规模可摊薄成本。

**关键指标与数据来源**：履约费用率、单均履约费用、海外仓/直邮比例、退货率。

**判断标准**：履约成本偏高若来自模式性成本（如中国仓小包直邮全链路、高退货率），则难以靠规模快速摊薄；若来自网络密度不足，则可随规模下降。看标杆常年水平是否出现趋势性下行，判断降本空间。

**海豚案例**：
- SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：履约费用占比达 48%，单均履约费 17.9 美元，显著高于亚马逊；主因是大量订单仍为中国仓小包直邮的全链路成本，叠加快时尚高退货率与免费退货政策。
- 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：亚马逊包裹经 3~4 个节点，最后一公里占物流成本 45%~55%，履约费用占营收常年 14%~16%，未见趋势性下行。

**适用场景与注意事项**：适用于电商、物流密集型零售。要区分模式性成本与规模可摊薄成本；分履约方式的单位经济对比见 4.1.7。

### 4.3.8 仓配供应链成本拆解：短链路 / 整箱拣选 / 配送半径 / 数字化仓管

**方法要点**：把供应链成本优势拆成三环（短链、整箱拣选、数字化），分别量化其对搬运损耗、人工、库存周转与资金占用的节省。

**操作步骤 / 拆分口径 / 公式**：
1. **短链**：工厂 → 总仓 → 门店，替代工厂 → 经销商仓 → 门店，减少搬运损耗与运输成本；所有门店都在仓库 300 公里内、24 小时送达，减少库存积压。
2. **整箱拣选**：服务加盟门店的标准化大批量订单，使 95% 为整箱拣选，省掉拆箱分拣人工，避免拆零后积压临期；仓库周转 5~7 天，间接节省资金占用。
3. **数字化**：按销量自动分配库位（热门品放易拣区）、规划最优拣货路径、规划配送路线提高车辆满载率、实时监控门店库存。
4. 汇总为：库存周转天数、配送时效、人工效率和车辆满载率等指标对比。

**关键指标与数据来源**：仓库周转天数（5~7 天）、整箱拣选比例（95%）、配送半径（300 公里）、送达时效（24 小时）、车辆满载率。

**判断标准**：短链路加整箱拣选加数字化，三者叠加才形成对库存周转、损耗和人工的综合优势；周转天数越短、整箱比例越高，说明资金占用与人工成本越低。

**海豚案例**：
- 鸣鸣很忙《（短评）鸣鸣很忙供应链有多能省》（2026-01-28）：短链路（工厂 → 总仓 → 门店）、95% 整箱拣选、300 公里配送半径与 24 小时送达、仓库周转 5~7 天、数字化库位与路径规划。

**适用场景与注意事项**：适用于零售与仓配物流成本分析；与电商拆零物流不可直接比较，因为整箱拣选依赖标准化大批量订单。

### 4.3.9 累计资本开支 ÷ 已部署算力，侧面验证成本优势并拆解“壳成本”$/MW

**方法要点**：公司没有披露单 GW 成本拆解时，用累计资本开支除以已部署算力，与行业新建同规模数据中心的总投资对比，再拆基础设施“壳成本”，侧面验证成本竞争力。

**操作步骤 / 拆分口径 / 公式**：
1. 取累计资本开支区间（2023 年到 2026Q1 约 265~300 亿美元）与已部署算力（约 1GW 混合算力：0.3GW H100/H200 + 0.7GW GB200/GB300）。
2. 单 GW 成本 ≈ 累计资本开支 ÷ 已部署 GW（本例约 265~300 亿美元/GW，混合架构）。
3. 与行业新建 1GW 最新架构数据中心的总投资（含 IT 设备 400~600 亿美元）对比，并考虑架构代差。
4. 拆基础设施壳成本（$/MW）：据 Oppenheimer，xAI 为 300 万美元/MW，行业平均在 1000 万美元/MW 以上，只有行业的三分之一。
5. 解释壳成本低的原因：棕地改造（避开审批和电网接入长周期）、Megapack 储能替代柴油发电机、供电冷却网络全链路垂直整合、模块化建设。
6. GPU 采购方面：大单加快速部署使其成为英伟达优先客户，可能拿到折扣。

**关键指标与数据来源**：累计资本开支、已部署 GW、行业单 GW 投资、壳成本 $/MW（Oppenheimer）。

**判断标准**：若总投入显著低于行业，并且低成本有清晰的结构性原因（棕地、储能、垂直整合、模块化），则成本优势可信；再叠加 4.1.2 中 3~4 倍于行业的定价，就形成“低成本 + 高定价”的暴利。比较时必须调整架构代差（老架构占比越高，单 GW 成本越低，不能与最新架构直接比）。

**海豚案例**：
- SpaceX《SpaceX：AI 烧钱不止…》（2026-06-30）：以低于行业的总投入完成部署，加上 3~4 倍定价，形成暴利。

**适用场景与注意事项**：适用于重资产业务的成本竞争力验证。架构代差要调整；累计资本开支可能包含未投产或在建资产，需核对口径。定价端的推演见 4.1.2。

### 4.3.10 运维冗余与寿命折损参数显式纳入 TCO

**方法要点**：对无法人工维修、高可靠性要求的资产，把可靠性所需的冗余与寿命折损单独参数化后放进 TCO，得到与传统方案的真实成本倍数，并标注让参数改善的技术拐点。

**操作步骤 / 拆分口径 / 公式**：
1. 列出可靠性相关参数：预留 GPU 冗余配置 20%；计算可用率 95%（扣除辐射造成的折损）；芯片寿命 5 年（地面 15 年）；定制抗辐射与散热硬件的额外成本。
2. 把这些参数代入 TCO：冗余越多、可用率越低、寿命越短，单位有效算力的总拥有成本越高。
3. 与地面方案对比，得出 TCO 倍数（2026 年太空数据中心 TCO 是地面的 4 倍以上），并拆解倍数的来源。
4. 标注技术拐点：2032 年后在轨机器人逐步成熟，可以维修、换部件、延寿，作为未来下调冗余参数的依据。

**关键指标与数据来源**：GPU 冗余比例 20%、算力可用率 95%、芯片寿命 5 年 vs 15 年、TCO 倍数；参数需要行业或工程报告支撑。

**判断标准**：冗余、可用率、寿命三类参数分别驱动 TCO 倍数，找出贡献最大的一项即为降本重点；技术拐点（如在轨维修能力）出现，参数才有下调依据，否则不能提前在模型里乐观处理。

**海豚案例**：
- SpaceX《SpaceX：太空算力，马斯克新饼，还是真未来？》（2026-07-08）：TCO 超 4 倍的来源拆解（20% 冗余、95% 可用率、5 年寿命 vs 地面 15 年、抗辐射与散热定制）；2032 年后在轨机器人成熟可作为参数改善的依据。

**适用场景与注意事项**：适合无法维修、高可靠性要求的资产（卫星、海底设施、偏远矿场）。参数需要行业或工程报告支撑，不可凭空设定。

### 4.3.11 TCO/LCOC（平准化算力成本）平价时点测算

**方法要点**：借鉴新能源的 LCOE 思路，构建平准化算力成本（LCOC），比较新旧方案（太空与地面）的成本曲线，找出平价年份，并把平价时点作为业务价值兑现时间的锚，接到估值折现期。

**操作步骤 / 拆分口径 / 公式**：
1. 构建 LCOC：把全生命周期成本（含 4.3.10 的冗余与寿命折损）摊到每单位有效算力。
2. 画新方案与旧方案的 LCOC 曲线（包含长期成本学习曲线假设）。
3. 找出基准情形下的平价年份，并标出沿途关键节点（如相对旧方案溢价收窄到可规模化的门槛）。
4. 将平价时点作为价值兑现时间，接到后续估值的折现期（远期价值折现见 9.7）。

**关键指标与数据来源**：TCO 倍数、LCOC、平价年份、太空相对地面的溢价比例。

**判断标准**：基准情形下，2026 年太空 TCO 是地面的 4 倍以上；到 2030 年代初只比地面高约 30%，接近规模化门槛；2040 年前后 LCOC 达到平价。平价年份越远，价值兑现越靠后，折现后的现值越低。

**海豚案例**：
- SpaceX《SpaceX：太空算力，马斯克新饼，还是真未来？》（2026-07-08）：2026 年 4 倍以上 → 2030 年代初 +30% → 2040 年平价。

**适用场景与注意事项**：适合新技术对旧技术的成本替代拐点分析。需要长期的成本学习曲线假设，对参数很敏感，应配合 4.3.12 的情景测算使用。

### 4.3.12 “成本剪刀差”双情景：地面成本上升 × 太空成本下降，看平价拐点提前多少

**方法要点**：设计一个与基准情形对照的压力情景——旧方案成本上升、新方案成本下降同时发生——量化平价拐点提前多少，作为估值情景的输入。

**操作步骤 / 拆分口径 / 公式**：
1. 设定基准情形（如 LCOC 平价在 2040 年前后）。
2. 设计压力情景，必须有现实触发条件支撑：
   - 旧方案成本上升：地面数据中心 Capex 因电网审批、燃气轮机和变压器产能短缺，从基准的 3460 万美元/MW 涨到 5340 万美元/MW；
   - 新方案成本下降：星舰把发射成本降到 80 美元/kg 并形成规模效应，太空数据中心 Capex 降到 1100 万美元/MW。
3. 在两情景下分别重算 LCOC 曲线，比较平价年份与到某年（如 2039）的成本差距。
4. 把两种情景的平价时点差异作为后续估值情景（见 10.2）的输入。

**关键指标与数据来源**：地面 Capex $/MW（34.6M → 53.4M）、太空 Capex $/MW（11M）、发射成本 $/kg（80）、平价年份、LCOC 差距。

**判断标准**：剪刀差让太空 LCOC 在 2034 年前后与地面持平，比基准提前约 6 年，到 2039 年比地面低近 20%。情景的触发条件（电荒、变压器短缺）越现实，该情景的概率权重越高。

**海豚案例**：
- SpaceX《SpaceX：太空算力，马斯克新饼，还是真未来？》（2026-07-08）：电荒情景下平价提前到 2034 年，2039 年太空 LCOC 比地面低近 20%。

**适用场景与注意事项**：适合核心变量双向联动的替代性赛道。情景假设要有现实触发条件（如变压器短缺）支撑，不可只靠“想象中的双向有利”。

### 4.3.13 经营杠杆倍数：利润增长倍数 ÷ 用户（收入）增长倍数

**方法要点**：对“高前置固定投入、低边际成本”的业务，用利润增长倍数与用户（或收入）增长倍数之比衡量经营杠杆，比值越大，说明规模越能放大利润。

**操作步骤 / 拆分口径 / 公式**：
1. 取区间起点和终点的用户数（或收入）与经营利润。
2. 经营杠杆倍数 = 利润增长倍数 ÷ 用户（收入）增长倍数。
3. 解释杠杆来源：组网完成后网络容量固定，新增用户只是分配已有带宽，几乎没有增量投入。
4. 判断比值是否大于 2：大于 2 说明经营杠杆释放到了极致。

**关键指标与数据来源**：用户数（230 万至 890 万，近 4 倍）、经营利润（4.69 亿至 44.23 亿美元，超过 9 倍）。

**判断标准**：利润增速是用户增长倍数的两倍以上，体现经营杠杆的极致释放；若比值接近 1，说明成本随规模同比例增长，没有杠杆。

**海豚案例**：
- SpaceX《Space X：天空之网…》（2026-06-15）：用户从 230 万增至 890 万（近 4 倍），经营利润从 4.69 亿增至 44.23 亿美元（超过 9 倍），利润增速是用户增长倍数的两倍以上，体现经营杠杆的极致释放。

**适用场景与注意事项**：适用于固定成本占比高的行业（电信、软件、平台、半导体）。要注意下一代网络资本开支会重新压低利润率，即杠杆释放之后会有新的固定投入周期。

### 4.3.14 前沿 AI 业务“规模不经济”诊断：研发/收入、亏损率、资本开支/收入、折旧/收入

**方法要点**：用几个比率刻画投入期业务的财务压力，指出资金来源，判断该业务在收入规模尚未覆盖投入时的“规模不经济”程度。

**操作步骤 / 拆分口径 / 公式**：
1. 研发 ÷ 收入：51 亿美元 ÷ 32 亿美元 = 1.6 倍。
2. 经营亏损率：经营亏损约 64 亿美元，约 −200%。
3. 资本开支 ÷ 收入：127.3 亿美元，约 4 倍，占 SpaceX 总资本开支的 61.4%。
4. 折旧摊销 ÷ 收入：36 亿美元 > 32 亿美元，收入连折旧都覆盖不了。
5. 指出资金来源：Starlink 44 亿美元利润与外部融资输血。
6. 行业层面概括：一代模型投入数亿美元，创收窗口可能只有一年，下一代成本往往翻倍。

**关键指标与数据来源**：分部收入、研发开支、经营亏损、资本开支及占比、折旧摊销。

**判断标准**：研发/收入、资本开支/收入、折旧/收入越高，规模不经济越严重；折旧 > 收入，意味着即便不考虑研发，业务也无法覆盖资产成本。投入期亏损要结合远期回报和资金来源（内部造血 vs 外部融资）判断。

**海豚案例**：
- SpaceX《SpaceX：AI 烧钱不止…》（2026-06-30）：AI 分部 2025 年的财务压力拆解——研发 51 亿美元对收入 32 亿美元（1.6 倍）；经营亏损约 64 亿美元（约 −200%）；资本开支 127.3 亿美元（约 4 倍，占 SpaceX 总资本开支 61.4%）；折旧摊销 36 亿美元大于收入 32 亿美元；资金来源为 Starlink 44 亿美元利润与外部融资。

**适用场景与注意事项**：适用于重投入期的 AI、半导体、新能源业务。投入期亏损要结合远期回报判断；需分清分部之间的资金输送关系，避免只看合并报表。

### 4.3.15 模型经济账：收入 × 毛利率 ≥ 训练 + 研发人员 + 运营支出，反推扭亏收入门槛

**方法要点**：借用 DeepSeek 梁文锋的模型经济账，把半年支出年化并换算成美元，用业务做大、推理降本后的目标毛利率，反推所需年收入，再对照当前 ARR，判断扭亏是“时间问题”还是“能不能的问题”。

**操作步骤 / 拆分口径 / 公式**：
1. 参照基准：模型收入达到 10 亿美元、毛利率 50%（推理成本吃掉一半），剩下 5 亿美元基本能覆盖训练、研发人员和运营支出。
2. 取公司半年总支出，简单年化（×2）并按汇率换算成美元。
3. 设定业务做大、推理降本后的目标毛利率（如 40%）。
4. 所需年收入 = 年化总支出 ÷ 目标毛利率（即满足：收入 × 毛利率 ≥ 年化总支出）。
5. 对照当前 ARR，判断缺口与达成时间，区分“时间问题”和“能力问题”。

**关键指标与数据来源**：年化总支出、目标毛利率、所需收入、当前 ARR。

**判断标准**：所需收入与当前 ARR 的距离，以及 ARR 的增速，决定扭亏的时间表；目标毛利率设得越低，所需收入越高，需要与推理降本的实际进度挂钩。

**海豚案例**：
- 智谱（2026-08-31）：上半年开支 24 亿人民币，年化 48 亿，约 6.8 亿美元；按 40% 毛利率估算，需要年收入 17~20 亿美元（120~140 亿人民币）才有望扭亏，明显高于 DeepSeek；8 月 ARR 已达 16 亿，扭亏只是时间问题。

**适用场景与注意事项**：适用于大模型及高固定投入的平台型公司。对照 ARR 时要统一币种和口径；半年支出年化会忽略季节性与增长，需要结合支出趋势修正。预测模型的搭建见 8.6。

### 4.3.16 以商业模式成熟度推断盈利改善路径（Fabless 规模效应）

**方法要点**：对尚处商业化起步、亏损的公司，如果其商业模式在海外已被充分验证，就不逐年建模，而是直接参考成熟同业给出远期稳态利润率，并以规模效应的方向判断盈利改善路径。

**操作步骤 / 拆分口径 / 公式**：
1. 判断商业模式是否已被市场充分验证（如芯片设计 Fabless：晶圆制造与封测外包）。
2. 判断盈利改善驱动：出货量释放带来规模效应，毛利率与费用率改善。
3. 参考成熟同业，直接给出远期稳态利润率（如 40%），用于估值，而非逐年建模。
4. 观察当前是否已出现改善趋势。

**关键指标与数据来源**：出货量、毛利率、费用率、远期稳态利润率假设。

**判断标准**：商业模式验证越充分，直接给稳态利润率越合理；稳态利润率需参考成熟同业，不能高于同业成熟水平。商业化起步期的亏损不否定模式本身，但需要出货量的验证。

**海豚案例**：
- 壁仞科技《壁仞：国产“英伟达”，到底“几斤几两”？》（2026-06-18，第 5 节）：壁仞尚处商业化起步阶段，亏损；但芯片设计（Fabless）商业模式已被市场充分验证，预期盈利能力将随出货量释放带来的规模效应稳步提升，目前已呈改善趋势，因此在估值中直接给远期稳态利润率 40%，而非逐年建模。

**适用场景与注意事项**：适用于商业模式已在海外验证的早期公司；稳态利润率需参考成熟同业。对商业模式在本土是否同样成立、客户集中度等差异要单独核对；估值方法见第 9 章。

### 4.3.17 数据变现业务的边际成本与订阅制现金流分析

**方法要点**：拆解数据业务的产品形态，论证固定成本一次性投入后新增客户的边际成本几乎为零，订阅制带来稳定现金流，规模越大利润率越高，并说明其与会员、广告的相互强化。

**操作步骤 / 拆分口径 / 公式**：
1. 拆产品形态：脱敏结构化消费数据打包成订阅产品，卖给供应商品牌商，提供单店实时库存与销售、全渠道行为趋势、广告闭环归因。
2. 拆成本：固定成本一次性投入，之后新增客户的边际成本几乎为零。
3. 拆收入：订阅制带来稳定现金流，收入随订阅客户数与数据产品类型增加而增长。
4. 判断规模越大利润率越高（固定成本被摊薄）。
5. 说明与会员、广告业务的相互强化：高频、全品类、线上线下完整轨迹的会员数据加工成产品，变现为高毛利广告收入并反哺供应链效率。

**关键指标与数据来源**：订阅客户数、数据产品类型。

**判断标准**：数据资产的独特性（高频、全品类、线下线上轨迹完整）决定其定价力；边际成本近零说明规模扩大会带来利润率上升。

**海豚案例**：
- 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：Luminate 数据业务把 Walmart+ 会员高频、全品类、线上线下完整轨迹的数据加工，变现为高毛利广告收入并反哺供应链效率。

**适用场景与注意事项**：适用于拥有海量交易数据的零售/平台；需关注隐私监管。
