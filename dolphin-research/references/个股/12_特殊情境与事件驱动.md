# 第12章 特殊情境与事件驱动

> **本章目的**：收纳 IPO、做空、分拆或上市地变更、合作协议、发布会、政策冲击等特殊情境下专用的分析方法。

## 12.1 IPO与招股书研究

> 本节导读：本节解决“一家公司要上市或刚上市时，研究从哪里切入”的问题：发行条款怎么数字化、热度与稀缺性光环怎么和基本面剥离、公司为什么偏偏此刻上市、发行估值如何在情绪退潮后落到可比公司之间、询价区间里藏着什么隐含预期，以及首日供需和首日点评怎么写。适用于新股、次新股的首次覆盖、询价传闻期和上市首日。用招股书数据做的常规业务拆解（收入结构、单位经济、财务拆解）不在本节，按方法归入第 3、4、8 章；一级市场融资估值轨迹的复盘详见 2.3，具体估值方法见 9.3（可比公司）、9.5（收入倍数与早期/亏损公司估值）和 10.1（反向估值）。

**方法选择速览**

| 要回答的问题 | 优先使用的方法 | 编号 |
| --- | --- | --- |
| 发行规模、保荐人、基石是谁，发行市值是多少 | 发行条款与基石阵容速览，发行市值作估值锚 | 12.1.1 |
| 首日热度到底是基本面还是光环 | 热度数据 + 稀缺性标签识别“估值光环” | 12.1.2 |
| 公司为什么不得不上市（财务硬约束） | “不上不行”财务压力测算 | 12.1.3 |
| 公司立场反转后，为什么现在上市（战略动机） | 立场对比 + 资本开支需求倒推 | 12.1.4 |
| 热门赛道新股值多少钱 | 剔除情绪，在可比公司倍数之间取中间价 | 12.1.5 |
| 手上有传闻的询价区间或卖方目标价 | 反推隐含收入与倍数，再做谨慎下调 | 12.1.6 |
| 首日会不会冲高 | 首日实际流通盘与供需测算 | 12.1.7 |
| 上市首日要出短评 | 首日表现 → 回到商业模式 | 12.1.8 |

**推荐串联顺序**：发行要素速览（12.1.1）→ 热度与光环识别（12.1.2）→ 上市动机（12.1.3 / 12.1.4）→ 估值（12.1.5 / 12.1.6）→ 首日供需（12.1.7）→ 首日点评（12.1.8）。其中估值和首日供需都以 12.1.1 的发行要素为起点。

### 12.1.1 IPO 发行条款与基石阵容速览，以发行市值作为估值锚

- **方法要点**：在 IPO 节点覆盖时，先把发行要素全部数字化列出，再用上市历程和监管节点说明上市确定性；发行市值随后成为估值结论的比较基准，也是筹码结构分析的起点。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列发行要素：发售股数、招股价区间、最高募资额（本币 + 美元）、对应发行市值、联席保荐人、基石家数与名单。
  2. 交代上市历程（被拒 / 搁浅 / 转战）与关键监管节点（证监会境外上市备案日期），用来说明上市确定性。
  3. 以发行市值作为后续估值结论的比较基准：算“合理市值较发行价的空间”。
  4. 把发售占比、基石锁定等信息带入筹码结构分析（见 12.1.7）。
- **关键指标与数据来源**：发售股数、招股价区间、募资额、发行市值、保荐人、基石名单、备案日期；来源为招股书、发售公告和监管备案信息。
- **判断标准**：
  - 基石阵容和保荐人阵容只是信号，不是定价依据，必须与独立估值结合。
  - 上市确定性看监管节点（是否已拿到备案）和上市历程（是否经历被拒、搁浅后转战）。
  - 推理链条：发行市值是“市场愿意付的价” → 独立估值得出“合理市值” → 二者之差就是新股的价值空间。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：发售 2.8 亿股，招股价 47.60–49.50 港元，最多募资约 138.6 亿港元（约 17.7 亿美元），对应市值约 270 亿美元；高盛、大摩、小摩联席保荐；博裕、Tiger Global、General Atlantic、腾讯、景林、泰康人寿六家基石；2026 年 7 月 10 日拿到证监会备案；此前纽约被拒、伦敦搁浅后回到港股。
- **适用场景与注意事项**：适用于新股、次新股首次覆盖。基石阵容是情绪与信誉信号，不能替代估值；上市历程要如实交代以说明确定性，而不是渲染。

### 12.1.2 IPO 热度数据 + 稀缺性标签识别“估值光环”，再追问“抛开光环是否优质”

- **方法要点**：新股开篇先把热度数据罗列出来、点明光环来源，然后把热度和基本面切开，把核心问题转为“抛开光环，这是不是一家优质公司”，防止用首日热度替代价值判断。
- **操作步骤 / 拆分口径 / 公式**：
  1. 罗列热度数据：发行定价在区间中的位置（是否顶格）、开盘涨幅、盘中与收盘市值、公开认购超额倍数。
  2. 点出光环来源：稀缺性（如首家上市的某类公司）和标签（如“国产英伟达”）。
  3. 提出核心问题：抛开稀缺性与标签，公司本身的产品、客户、盈利和竞争力如何。
  4. 正文转入基本面拆解，热度数据只用来衡量情绪，不进入价值判断。
- **关键指标与数据来源**：定价在区间中的位置、首日涨幅、超额认购倍数、市值（来自发售公告、交易所行情）。
- **判断标准**：热度越高、标签越响亮，越需要追问基本面；情绪指标与基本面指标必须分开表达，不能互相背书。
- **海豚案例**：
  - 壁仞科技《壁仞：国产 “英伟达”，到底 “几斤几两”？》（2026-06-18）：开篇罗列发行顶格定价 19.60 港元、开盘 +82.14%、盘中市值突破千亿港元、收盘约 825 亿港元、公开认购超额 2347 倍；光环来自“首家港股上市 GPU 公司”的稀缺性和“国产英伟达”标签；然后转入核心问题——抛开光环，壁仞是否是一家优质公司。
- **适用场景与注意事项**：适用于新股、次新股研究，尤其是热门赛道和带“国产替代”“中国版某龙头”标签的标的；标签只说明市场的类比，不构成对公司质量的证明。

### 12.1.3 “不上不行”财务压力测算：优先股负债列账与对赌补偿成本

- **方法要点**：从招股书里挖出逼迫公司上市的硬约束，测算“每拖延一个季度的现金流成本”，据此判断公司为何接受低估值发行，以及发行定价对买方是否有利。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看账面股东权益：优先股按负债列账会使账面股东权益为巨额负数，只有上市转股才能把报表转正。
  2. 看对赌条款：后期优先股对赌要求按年息支付现金补偿，计算已累积金额、利率跳升节点。
  3. 推导拖延成本：每拖延一个季度需额外支付的补偿现金与履约压力。
  4. 回到定价：公司有“不上不行”的约束，意味着愿意接受折价发行，对买方定价有利。
- **关键指标与数据来源**：账面股东权益（含优先股负债）、对赌年息率及跳升时点、累计补偿金额；来源为招股书财务报表附注。
- **判断标准**：区分会计负值与真实经营问题——优先股负债导致的负权益上市即消除，不代表经营恶化；真正的压力来自现金补偿的累积和利率跳升，它决定公司的时间成本和谈判地位。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：2025 年末账面股东权益为 -69 亿美元；需向 Pre-D 至 D+ 轮优先股股东支付年息 8% 的现金补偿，累计已达 11 亿美元，3 月起利率跳升至 12%，上市拖延带来的现金流与履约压力加重。
- **适用场景与注意事项**：适用于有优先股、对赌、赎回权的 IPO 公司；注意区分会计层面的负权益与现金层面的补偿成本，前者是报表问题，后者才是真实压力。

### 12.1.4 战略动机推理：对比创始人过去的立场，倒推资本开支需求

- **方法要点**：当公司的上市（或增发、并购）与创始人一贯表态相反时，先假设原有风险没变，再找“变化了的现实因素”，并用资本开支需求去量化解释动机。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先列公司（创始人）过去拒绝上市的理由，以本人公开表述为主线还原其逻辑（如资本市场追逐短期盈利，与长期慢热、烧钱的使命相悖）。
  2. 假设这些风险没有变，于是推断一定有别的现实因素变了。
  3. 内因：新战略需要极大规模的资本开支——列出项目规模、数量、电力规模和代际造价。
  4. 外因：现有业务的资本开支扩张、竞争、政府订单不稳定、监管审查。
  5. 补充非财务动机：上市后强化叙事、更加“大而不能倒”。
  6. 结论：上市是募资的起点，融资落地效果决定后续布局速度。
  - **变体 A：创始人立场对比（偏重“新战略 + 外部压力”）**——先还原创始人不愿上市的原因，再逐项论证新战略、现有项目资本开支、政府合同风险等内外因。
  - **变体 B：资本开支需求倒推（偏重“资金缺口量化”）**——沿“能源瓶颈 → 数据中心上天 → 卫星规模和电力规模 → 卫星代际造价飙升 → 轨道和频谱争夺”的链条，把资金缺口逐项量化。
- **关键指标与数据来源**：新战略的资本开支规模、现有项目的资本开支、卫星数量与电力规模（GW）、卫星代际造价、政府合同风险事件（FAA 审查等）。
- **判断标准**：能把“态度反转”归因到一个可量化的资金需求，且该需求在量级上足以解释上市，则动机成立；创始人的表态与真实动机可能不一致，需以资金需求而非表态为准。
- **海豚案例**：
  - SpaceX《马斯克再甩“王炸”…》（2026-02-24）：马斯克多次表示不想让 SpaceX 上市，因资本市场追逐短期盈利；海豚君认为上市最主要的原因是太空算力——FCC 申请 100 万颗卫星的轨道数据中心系统、规划 100GW 太阳能产能，需要极大规模的资本开支；外部还有 Starlink V2 资本开支、竞争、特朗普威胁终止合同、FAA 审查等压力；非财务动机是强化叙事、更加“大而不能倒”。
  - SpaceX《(短评)马斯克为何急着让SpaceX上市》（2026-03-12，id 39217223）：先列原拒绝理由（资本市场追求短期盈利，与火星移民等慢热烧钱的长期使命相悖），再找新变量——美国 AI 算力卡在能源瓶颈，于是把数据中心搬上太空（100 万颗卫星组成的轨道数据中心，配套 100GW 太阳能产业）；Starlink V2 升级造价从 V1.5 的 15 亿美元飙升到 600 亿美元以上；轨道与频谱争夺迫在眉睫；结论是上市只是为太空算力和星链升级募资的起点，融资落地效果决定后续布局速度。
- **适用场景与注意事项**：适用于 IPO、增发、并购等资本动作的动机分析；注意创始人表态与真实动机的差异；与 12.1.3 配合使用：12.1.3 解释“被迫”，本方法解释“主动”。

### 12.1.5 IPO 估值：先剔除情绪，再在可比公司倍数之间“取中间价”

- **方法要点**：给热门赛道新股定价时，先把可比 IPO 的情绪溢价识别出来并判断其可持续性，再以成熟可比公司估值为锚，取区间中间价作为短中期价值倍数。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看近期上市的同类公司（摩尔、沐曦、壁仞）的发行价和首日表现，识别情绪溢价（对成长性和稀缺性的押注），并判断该溢价会随竞争加剧、上市标的增多而削弱。
  2. 看已上市多年的成熟公司估值：寒武纪因需求爆满仍有 80 多倍 PS；英伟达和港股半导体都比较正常。
  3. 考虑上市地资金结构差异：港股由外资定价，对国产芯片的认可度不如 A 股内资的情绪。
  4. 情绪退潮后，取两家可比公司 PS 的中间价作为短中期价值倍数；用 倍数 × 预测收入 得出估值区间。
- **关键指标与数据来源**：可比 IPO 的首日涨幅、可比公司 PS、上市地；来源为招股书、行情数据与公司预测收入。
- **判断标准**：情绪溢价（来自稀缺性和成长性押注）会随同类标的增多而被稀释，不应永久计入估值；最终倍数落在成熟可比公司估值区间内，而不是可比 IPO 首日的极端值。
- **海豚案例**：
  - 昆仑芯（2026-01-02）：参照摩尔、沐曦、壁仞的发行与首日表现识别情绪溢价；对照寒武纪（80 多倍 PS）、英伟达和港股半导体的估值；考虑港股外资定价；取华虹和英伟达 PS 的中间价，给 26 年 10–15 倍 PS，对应 840–1260 亿元（120–180 亿美元）（按此反推，对应的 26 年收入口径约 84 亿元）。
- **适用场景与注意事项**：适用于热门赛道新股，需要警惕情绪周期；可比公司的选择决定结果，应同时检验上市地资金结构；倍数基础（PS）适合早期、利润尚未释放的公司，具体口径见 9.5。

### 12.1.6 从传闻的 IPO 询价区间反推隐含收入和倍数，再做谨慎下调

- **方法要点**：拿到传闻的询价区间或卖方目标价后，先反推市场是怎么算出来的（隐含收入 × 隐含倍数），再按风险因素调整，找到自己与市场的分歧点——分歧可以落在收入上，也可以落在倍数上。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取传闻的询价区间（市值）。
  2. 反推隐含口径：市值 ÷ 预期收入 = 隐含 PS（或反过来先假设倍数，推隐含收入）。
  3. 识别风险因素（产能切换、客户结构、竞争），判断应调整收入还是倍数。
  4. 做谨慎下调，并明确说明下调落在哪一项（收入保持、倍数下调，或相反）。
  5. 得出自己的估值，并与传闻区间对比，标出分歧。
- **关键指标与数据来源**：询价区间、隐含收入、隐含 PS、风险折扣。
- **判断标准**：分歧点必须清晰（收入还是倍数），且有对应风险因素支撑；只有说明市场隐含了什么，才能说明自己为什么不同意。
- **海豚案例**：
  - 百度（2026-09-07）：昆仑芯 IPO 询价传闻为 400–500 亿美元，海豚君反推对应 26 年 80 亿元收入 × 40 倍 PS；考虑三星换国产代工的产能切换不确定性，收入保持 80 亿元（同比去年 35 亿元 +120%），倍数下调到 30 倍 PS，得出约 350 亿美元。
- **适用场景与注意事项**：适用于有传闻估值或卖方目标价的标的；传闻本身未经证实，只用来拆解市场的计算逻辑；与 10.1（反向估值与隐含预期）同属“先还原市场、再提出分歧”的思路。

### 12.1.7 新股首日实际流通盘测算与供需判断

- **方法要点**：估算新股上市首日真正可流通的筹码占总股本的比例，再结合标的稀缺性和发行估值折价，判断首日供需偏向。
- **操作步骤 / 拆分口径 / 公式**：
  1. 计算发售股数占发行后总股本比例。
  2. 扣除基石投资者锁定（通常 6 个月）与老股东锁定份额。
  3. 得到首日真正可流通筹码：公开发售中签散户 + 未锁定的国际配售。
  4. 结合标的稀缺性（同类标的在该市场是否稀缺）和发行估值折价，判断首日供需偏向（流通比例低、稀缺、折价发行 → 冲高概率大）。
- **关键指标与数据来源**：发售占总股本比、基石锁定期、首日流通比例；来源为招股书股本结构、发售公告。
- **判断标准**：首日流通盘占比越低、稀缺性越强、发行折价越明显，首日供需越偏向多头；该判断只指示短期供需，与中长期价值无关。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：发售 2.8 亿股，占发行后总股本约 6.4%，首日流通约占总股本 4.8%–5.1%；港股缺乏纯正的全球化电商龙头，加上折价发行，判断首日冲高大概率。
- **适用场景与注意事项**：IPO 交易层面的判断；解禁期（基石 6 个月等）需另行跟踪（减持与解禁的跟踪见 11.2）。

### 12.1.8 IPO 首日点评：首日表现与认购热度 → 回到商业模式

- **方法要点**：首日点评先列热度指标，随后不纠缠短期交易，而是回到此前深度研究的商业模式，回答“公司为什么值得被资本追捧”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列热度指标：首日涨幅、超额认购倍数、基石投资者及巨头押注。
  2. 不讨论短期交易（涨多少、能不能追），转而回到前期已有的商业模式结论。
  3. 把商业模式拆成若干条，逐条回答“为何是行业第一”：以“二道贩子”模式为例，拆成价差来源（砍掉中间环节）、运营效率（周转）、市场卡位（下沉空白）、规模飞轮四条。
  4. 以商业模式的答案收束，解释资本追捧的原因。
- **关键指标与数据来源**：首日涨幅、超额认购倍数、基石投资者。
- **判断标准**：热度只说明市场情绪，价值要由商业模式的竞争优势来解释；若无法落回商业模式，说明热度缺乏基本面支撑。
- **海豚案例**：
  - 鸣鸣很忙《(短评)鸣鸣很忙登陆港股首日大涨》（2026-01-28，id 38159087）：首日涨幅超 88%，超额认购近 1900 倍，腾讯和淡马锡等巨头押注；随后回到商业模式，把“二道贩子”模式拆为价差来源、运营效率、市场卡位、规模飞轮四条，回答它为何能坐稳行业第一并获得资本追捧。
- **适用场景与注意事项**：适用于新股首日、上市点评；需要此前已有深度研究作为底稿，否则无法快速“回到商业模式”。

**本节速查清单**

- [ ] 发行要素是否列全：发售股数、价格区间、募资额（本币 + 美元）、发行市值、保荐人、基石名单、备案日期。
- [ ] 上市确定性是否交代清楚：被拒、搁浅、转战的历程和监管备案节点。
- [ ] 热度数据与基本面是否分开：是否追问了“抛开光环是否优质”。
- [ ] 上市动机是否量化：财务硬约束（负权益、对赌补偿、利率跳升）或资本开支需求（项目规模、造价）。
- [ ] 估值是否先剔除情绪：可比 IPO 的情绪溢价与成熟可比公司估值是否分开，上市地资金结构是否考虑。
- [ ] 询价区间或传闻是否反推过隐含收入与倍数，分歧点落在收入还是倍数是否明确。
- [ ] 首日流通盘是否测算（扣除基石与老股东锁定），解禁节点是否另行跟踪。
- [ ] 首日点评是否回到商业模式，而不只是复述热度。

## 12.2 做空报告核查

> 本节导读：本节解决“做空报告出来后，怎么判断它的火力、核查它的指控、评估它对股价和估值的真实影响”的问题。顺序上，先做“降维”（抽出能影响商业基本面的可量化指控）和“火力评估”（证据硬度、信息增量、传播度），再看市场反应与多头究竟买的是什么，然后逐条复现测算（资产质量、利润质量、风险转移、物理约束）。适用于做空报告发布后 1–2 天的快速点评，也适用于后续的深度核查。与 8.2（利润质量与会计口径调整）、13.1（风险识别与传导分析）配合；短期股价反应的窗口期判断见 12.6.10，预期差的一般方法见 1.3。

**方法选择速览**

| 要回答的问题 | 优先使用的方法 | 编号 |
| --- | --- | --- |
| 叙事型、故事型的做空报告怎么处理 | 商业视角降维，抽出可量化的收入虚增指控 | 12.2.1 |
| 这份报告火力大不大 | 证据硬度 / 信息增量 / 传播度三把尺 + 历次做空横向比 | 12.2.2 |
| 市场和做空者本人怎么反应 | 市场反应与做空者仓位行为评估 | 12.2.3 |
| 报告有没有新信息，多头究竟买的是什么 | 增量信息量判断 + 多头定价逻辑 | 12.2.4 |
| 怎么系统回应一份多条指控的报告 | 结论先行，逐条核查论据、假设、样本与趋势 | 12.2.5 |
| 坏账率是否被低估 | 表内外合并作分母，重构坏账率 | 12.2.6 |
| 利润被粉饰到什么程度 | 藏匿坏账折算当期 EBITDA 占比 | 12.2.7 |
| 宣称的“风险已转移”是否成立 | 风险自留、回购承诺与实际损失率核查 | 12.2.8 |
| 做空方用物理 / 资源约束讲故事 | 关键原材料供需模型逐项量化反驳 | 12.2.9 |

**推荐串联顺序**：降维抽指控（12.2.1）→ 火力三把尺（12.2.2）→ 市场与做空者反应（12.2.3）→ 增量信息与多头逻辑（12.2.4）→ 逐条核查（12.2.5），其中涉及金融资产质量用 12.2.6–12.2.8，涉及物理约束用 12.2.9。写作上永远回到一个落点：这份报告对基本面的直接攻击力有多大，对情绪的影响有多大，两者分开表达。

### 12.2.1 叙事型做空报告的“商业视角降维”：抽出可量化的收入虚增指控并拆子问题

- **方法要点**：面对以股东身份、洗钱、诈骗等为主线的叙事型做空报告，不纠缠故事细节，先问“哪些指控会影响商业基本面”，把它降维成一个可量化的问题（收入虚增），再拆成可以逐一判断的子问题。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别报告主线（股东背景、资金来源、洗钱链条等叙事），不陷入故事细节。
  2. 提问：哪些指控会影响商业基本面？把它们降维成一个可量化问题——收入虚增。
  3. 把收入虚增拆成两个子问题：①收入中有多少来自非法 / 灰色广告主（如博彩应用买量）；②股东关联方贡献占比。
  4. 逐一判断：
     - 子问题①：先看是否个例——横向对照 Meta、Google 等大平台同样存在博彩广告买量（Meta 曾被曝对非法赌博广告放水）；关键在于占比大小，以及监管认真整改时占比高的平台受冲击更大。
     - 子问题②：关联方占比外部无法查明；不能因股东身份有污点，就直接推演公司深度参与洗钱链条（避免有罪推定式的逻辑跳跃）。
  5. 落结论：对公司直接攻击力有限，但会影响情绪。
- **关键指标与数据来源**：违规品类广告收入占比、关联方收入占比、监管整改敞口；同业（Meta、Google）同类负面新闻作为基准。
- **判断标准**：
  - 行业共性问题（同业普遍存在）的攻击力低于公司特有问题，但要看占比和监管整改下的受冲击程度。
  - 外部无法证伪的指控，只能作定性评估，不能做有罪推定。
  - 推理链条：叙事 → 降维成收入虚增 → 拆成可判断的子问题 → 同业基准 + 可得数据 → 对基本面的直接影响 vs 对情绪的影响。
- **海豚案例**：
  - AppLovin《Applovin：空头开年又整活，这次火力如何？》（2026-01-20）：CapitalWatch 指控神秘华人股东 Tang Hao / Tang Ling 家族初始资金来自 P2P 诈骗，并联合柬埔寨犯罪集团通过在 APP 为博彩诈骗应用买量洗钱；海豚君拆成“博彩买量占比”“关联方占比”两问，前者是行业共性、后者外部无法证伪，结论为攻击力不如此前浑水。
- **适用场景与注意事项**：适用于以治理、关联方、灰色收入为主线的做空报告（广告平台、支付、平台型公司）；局限在于外部无法核实关联交易，结论只能是定性的攻击力评估，需等待公司回应或监管动作。

### 12.2.2 做空报告火力三把尺：证据硬度 / 信息增量 / 传播度，并与历次做空横向比较

- **方法要点**：用固定的三把尺评估一份做空报告的火力，再与同一标的历史上的做空报告对比，快速给出“攻击力强弱”的判断。
- **操作步骤 / 拆分口径 / 公式**：
  1. 证据硬度：是否披露银行流水、交易记录等可核验证据；故事细节多不等于证据强，没有流水往往是报告的 bug。
  2. 信息增量：相对此前同主题指控（如独立分析师的神秘股东说法）是否只是更细节化，而没有新证据。
  3. 发布方影响力与传播度：发布平台规模、欧美主流财经媒体是否跟进、X 等社交媒体的讨论热度。
  4. 横向对比：与同一标的历史做空报告（如浑水）比较攻击力。
  5. 提示：做空方可能留一手、连续放料维持热度，但硬证据通常会随报告一起放出。
- **关键指标与数据来源**：证据类型（流水 / 合同 / 访谈）、主流媒体跟进情况、社媒讨论量、与前次做空报告的对比。
- **判断标准**：证据不可核验、增量信息有限、传播度低、弱于历次做空 → 攻击力弱；反之则强。强弱判断后仍需持续追踪是否有后续放料或监管调查。
- **海豚案例**：
  - AppLovin（2026-01-20）：CapitalWatch 平台不大，欧美主流媒体未跟进、X 上讨论少，全篇无银行流水；相对独立分析师 Lauren Balik 此前的神秘股东说法，只是更细节化；对比前作《浑水也来锤了！Applovin真是“有缝的蛋”？》，判断本次攻击力弱于浑水。
- **适用场景与注意事项**：适合做空报告发布后 1–2 天内的快速点评；需持续追踪是否有后续放料或监管调查。

### 12.2.3 做空报告的市场反应与做空者仓位行为评估

- **方法要点**：评估做空报告的实际冲击，既看股价的实际反应和管理层应对，也看做空方自身的仓位行为，据此判断市场是否已经消化。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录报告次日的股价涨跌，并结合管理层的应对（如 CEO 快速增持力挺）。
  2. 与其他影响因子对比（如加密货币市场波动对股价的影响反而更大），判断报告是否是股价的主导因素。
  3. 看做空方自身行为：是否披露平掉空头仓位（“看空不做空”）。
  4. 解读做空方的行为：高成长预期让做空者也不愿长期持有空头。
- **关键指标与数据来源**：报告次日股价涨跌、管理层增持、做空方持仓披露、其他影响因子（加密货币行情）。
- **判断标准**：市场反应温和、管理层增持背书、做空方自己也平仓，说明冲击有限；若做空方持仓不变甚至加仓，则需提高警惕。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：3 月 23 日浑水报告把 SoFi 比作 GE 和安然，但市场反应一般，CEO 快速增持力挺后次日只跌 2.6%；对比来看加密货币市场波动对股价影响更大；浑水在发报告后披露会平掉 SoFi 空头仓位，即“看空不做空”，海豚君解读为高成长预期让做空者也不愿长期持有空头。
- **适用场景与注意事项**：适合所有被做空的公司，先判断市场是否已经消化；短期股价反应还要结合窗口期（见 12.6.10）。

### 12.2.4 判断做空报告的增量信息量，并识别多头买的到底是什么

- **方法要点**：对做空报告先做预期差判断——报告里有多少是新信息、多少是旧信息的情绪化重述——再回答“为什么这家公司还有估值溢价”，识别多头真正买的是什么、用什么方式定价。
- **操作步骤 / 拆分口径 / 公式**：
  1. 判断信息是否已披露：会计确认方式、客户权利义务关系是否在年报中一直公开；已披露则对成熟机构增量信息有限，做多就意味着接受这些缺点。
  2. 判断影响人群：报告可能影响资金体量不小的非专业投资者，削弱其看多情绪。
  3. 回答“为什么还有估值溢价”：多头买的是什么（用户生态；从单一业务转身为综合平台的成功可能；框架已搭好、渗透浅、变现浅）。
  4. 找出多头的底层信仰：管理层中期指引（收入 CAGR、EPS 增速）。
  5. 找出多头的定价方式：匹配增速的 PEG，或更乐观地直接对标“做成之后”的同行市值。
- **关键指标与数据来源**：信息是否已披露、管理层 3 年指引（收入 CAGR、EPS 增速）、PEG。
- **判断标准**：对有估值溢价的公司，摸清潜在风险比算明白成长前景更重要——高成长可以解决一切问题，但前提是风险没有击穿成长叙事；区分“新信息”与“旧信息的情绪化重述”。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：会计确认方式从一开始就公开披露，与客户的权利义务关系也在年报中定期披露，对成熟机构增量信息不多；多头买的是 1400 万用户生态，以及从单一信贷机构转身为综合金融平台的成功可能；管理层指引未来 3 年收入 CAGR 30%、EPS 增速 38–42%（约 40%）是多头的底层信仰；多头用匹配增速的 PEG 定价，或更乐观地对标“做成之后”的同行市值。
- **适用场景与注意事项**：适合做空事件和负面舆情事件；关键是把“增量信息”和“情绪重述”分开；预期差的一般方法见 1.3。

### 12.2.5 逐条核查做空指控：结论先行，检验论据、假设参数、样本选择和趋势方向

- **方法要点**：把一份做空报告拆成若干个问题，逐个“先给结论，再复现测算”，并用统一的维度检验每一条指控是否站得住，重在复现而不是站队。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把报告拆成若干问题，每个问题先给结论，再复现测算过程（SoFi 案例拆成四条：坏账率、公允价值财技、LPB 信用风险转移、管理层损害小股东）。
  2. 区分核心指控与“鸡蛋里挑骨头”：前两条（坏账率、公允价值）是核心指控，后两条（LPB 信用风险转移、管理层损害小股东）属于挑刺。
  3. 对每条逐一检验：
     - 论据：是否有公开数据支撑（浑水的问题基本都有充实论据，SoFi 确有逻辑瑕疵）。
     - 关键假设：参数是否合理（如 70% 转化率不算胡乱假设，但全程都用 70% 未必合理）。
     - 样本选择：是否挑了最极端的样本（如“90% 利润虚报”选的是问题最严重的 2024 年初季度）。
     - 趋势：是改善还是恶化（如逐季改善）。
  4. 定性分级：区分“数据造假 / 欺诈”“粉饰报表”“表述不严谨”三个等级。
- **关键指标与数据来源**：做空报告的各项测算参数、公司披露数据（财报、ABS 披露、监管文件）。
- **判断标准**：论据有数据支撑且假设合理、样本无明显挑选、趋势恶化 → 指控成立；假设过强、样本极端、趋势改善 → 指控被削弱；最终落到三级定性（欺诈 / 粉饰 / 表述不严谨）。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：四条指控逐一回应，结论是“不是欺诈，是粉饰”，风控能力不差。
- **适用场景与注意事项**：适合所有做空报告的研究，重在复现测算、而不是站队；分级定性要有数据支撑，避免情绪化。

### 12.2.6 资产质量核查：以表内外资产池合并作分母重构坏账率

- **方法要点**：当公司有大量证券化或出表操作时，不要分别看表内、表外的坏账率，而是把表内外贷款池合并作分母，并剔除出表过程中的折价损失（属于过程损失，已包含在表外池坏账里），重构一个口径统一的综合坏账率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 还原做空方逻辑：当季逾期 120 天须核销的坏账，应基本来自上季末逾期 30 天以上的贷款；若公司披露的表外核销金额高于上季末 30+ 逾期额（2023、2024 年尤其严重，最近一季才扭转），则推断表内坏账被转移到表外 ABS 和过桥公司（例如把公允价值 6250 万美元的违约贷款以 500 万美元卖给 Eltura Ventures）。
  2. 做空方计算：假设上季末 30+ 逾期中 70% 会转化为 120+ 核销，超出部分算作藏匿坏账；分子加总三类坏账（表内明报坏账、临期出表折价损失、表外坏账）再加公允价值调整；分母只用表内 1P 余额，由此把坏账率拉高约 1 个百分点。
  3. 海豚君重构：
     - 分母：合并表内和表外的贷款池（两者是同一风控逻辑下的资产，没必要纠结各自比例）。
     - 分子：剔除临期出表的折价损失（属于过程损失，已经包含在表外池坏账里）。
  4. 得出综合坏账率，与公司还原临期出表后的表内坏账率对比。
  5. 对照贷款利率判断可承受程度。
- **关键指标与数据来源**：表内 / 表外贷款余额、30+ 逾期、120+ 核销、出表折价损失、坏账率（FFIEC 规定个贷逾期 120 天以上认定为坏账）、贷款利率。
- **判断标准**：重构后的综合坏账率不高于公司自己的口径，说明风控能力和资产质量不差；再看与贷款利率（接近 10%）的差——4% 出头的坏账率可以承受。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：重构后综合坏账率 4.4%，低于公司还原临期出表后的表内坏账率 4.6%，说明风控能力和资产质量不差；贷款利率接近 10%，4% 出头的坏账率可以承受。
- **适用场景与注意事项**：适合有大量证券化或出表操作的贷款机构，关键是统一口径看整体风控；做空方与自己的口径差异（分子、分母）要明确列出，才能说明分歧来源。

### 12.2.7 利润质量核查：把“藏匿坏账”折算为当期 EBITDA 占比

- **方法要点**：把争议的会计问题换算成对当期利润的影响比例，用“注水比例”衡量利润粉饰程度，便于判断严重性并定性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别藏匿坏账：表外坏账中超出“上季末 30+ 逾期 × 70%”的部分，视为藏匿在表外的表内坏账，即 藏匿坏账 = 表外核销额 − 上季末 30+ 逾期额 × 70%（取正值）。
  2. 拉回表内计算利润影响：注水比例 = 藏匿坏账 ÷ 当期 EBITDA。
  3. 看趋势：近几个季度的注水比例是在上升还是下降。
  4. 检验做空方结论：对“最高虚报 90% 利润”的判断，核对其所用比例（70%）和样本（问题最严重的 2024 年初数据）。
  5. 定性：区分欺诈与粉饰；数据每季披露、投资人可自行还原，则欺诈不至于。
- **关键指标与数据来源**：藏匿坏账金额、EBITDA、注水比例、趋势。
- **判断标准**：欺诈——数据不披露、无法还原；粉饰——数据披露但口径使利润虚高；本案属于粉饰，利润虚高但不影响现金流，不适合与同行横向对比，只能靠自身同比高增长让资金忽略这个原生瑕疵，所以市场对其成长性问题的容忍度很低。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：按 1Q26，“藏匿”坏账约 6500 万美元，约为当期 EBITDA 的 20%，即利润注水约 20%（近两季都约 20%，2023–24 年更严重）；对浑水“最高虚报 90% 利润”的判断，核心是用了 70% 比例并挑了问题最严重的 2024 年初数据，噱头成分大，趋势逐季改善；定性为：欺诈不至于，粉饰报表确实明显。
- **适用场景与注意事项**：适合把会计争议换算成利润影响比例；注意区分利润口径问题和现金流问题，粉饰不等于现金流虚假。会计口径调整的一般方法见 8.2。

### 12.2.8 风险转移核查：监管风险自留、回购承诺与实际损失率

- **方法要点**：对宣称“信用风险已转移”的轻资产金融公司，核查是否真的转移：监管要求的风险自留、隐含的回购承诺、资金方的准入标准与实际损失率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 区分业务模式：LPB 有两种模式——①纯导流（用户清楚资金方不是 SoFi，基本不承担信用风险）；②外部不具备放贷和 ABS 资格的机构出资、SoFi 代签发。
  2. 查监管自留：证券化时 SoFi 作为发起人，须按 Dodd-Frank 风险自留规则保留 5% 的信用风险（表现为持有至到期债券投资，每档证券按面值 95% 对外发行）。
  3. 逐条回应做空方指控：宣传“全部信用风险已转移”属于虚假宣传；95 折加约 105% 的销售执行溢价可能是先提价再打折；资金方 OWLCX 给该 ABS 设定的坏账率 4.3%，低于浑水算的 6–7%，差价可能由 SoFi 暗中承担。
  4. 核查事实：资金方（Blue Owl、Fortress）设定了准入标准（最低 FICO、最高 DTI、贷款规模），并通过增加 SoFi 的履约义务对冲，不是买盲盒；SoFi 对代签发贷款预提了回购承诺负债（违约或不合约定须回购）；过去两年实际损失仅约占总贷款 0.1%；FICO 平均分 744 以上，总期望损失小。
  5. 风险提示：LPB 激进扩张或经济恶化时回购损失会上升，需要风控模型挖掘新的优质借款人。
- **关键指标与数据来源**：风险自留比例 5%、销售执行溢价 105%、资金方设定坏账率（4.3%）、回购损失率 0.1%、平均 FICO 744；来源为 ABS 披露、公司回购负债披露。
- **判断标准**：表述不严谨 ≠ 造假；若资金方有明确的准入标准、公司已为回购承诺预提负债、实际损失率很低，则不能用来证明造假；但回购承诺是隐性或有负债，激进扩张或经济恶化时会放大。
- **海豚案例**：
  - SoFi《竟是翻版「安然」！浑水博眼球 or SoFi 真烂？》（2026-06-17）：核查结论为表述确实不严谨，但不能用于证明造假；回购损失过去两年仅约 0.1%。
- **适用场景与注意事项**：适合助贷、ABS 发起人等宣称轻资产的金融公司，核查隐性担保和回购义务；重点是看合同上谁承担尾部风险。

### 12.2.9 做空方关键原材料供需模型的逐项量化反驳

- **方法要点**：当做空报告以物理或资源约束（某种关键原材料不够）为核心论点时，逐项核对供给端、单耗口径、远期矿端弹性，并承认残余风险，关键是“单耗口径”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 还原做空方模型：需求 = 目标装机量 × 单 GW 耗用；供应 = 全球供应量；供需缺口 → 物理上无法扩产；降低含量还会加速老化、威胁长期服务合同。
  2. 核对供给端：公司官网称仅工业尾流（钛、镍、钴、铀加工副产）回收每年即可产数百吨，足以支撑每年最高 25GW。
  3. 核对单耗口径：按公司专利电解质含 5–12 摩尔 % 氧化钪折算，单 GW 约 29 吨，5GW 仅 145 吨，远低于做空方的 220 吨。
  4. 核对远期矿端弹性：澳洲 Sunrise Energy Metals 的 Syerston 项目拥有 3.2 万吨氧化钪当量资源，理论支撑约 1103GW（≈ 32000 吨 ÷ 29 吨 / GW）。
  5. 承认残余风险：当前对中国渠道的依赖（经泰国、日本、韩国转运）与出口管制风险；西方钪矿投产后可提供替代路径。
- **关键指标与数据来源**：单 GW 原材料耗用、全球供需量、回收产能、远期资源量；来源为公司官网与专利、资源项目公告、做空报告。
- **判断标准**：做空方的结论对单耗口径极其敏感——单耗口径下降，需求量大幅缩小，“物理上无法扩产”不成立；同时诚实标出残余风险，不为反驳而反驳。
- **海豚案例**：
  - Bloom Energy（2026-07-20）：Hunterbrook 的模型是 5GW 需约 220 吨氧化钪，全球供应仅 240 吨、需求约 310 吨 → 物理上无法扩产；海豚君逐项核对：回收供给每年数百吨，足以支撑每年最高 25GW；按专利电解质含量折算单 GW 约 29 吨，5GW 仅 145 吨；远期 Syerston 项目 3.2 万吨氧化钪当量资源理论支撑约 1103GW；同时承认对中国渠道的依赖与出口管制风险。
- **适用场景与注意事项**：做空报告以物理或资源约束为论点时的核查方法；关键在单耗口径；结论要给出“剩余风险”而不是全盘否定。

**本节速查清单**

- [ ] 是否先降维：哪些指控会影响商业基本面，能否拆成可量化的子问题（如收入虚增 → 灰色收入占比 + 关联方占比）。
- [ ] 火力三把尺是否评估：证据硬度（流水 / 合同）、信息增量、传播度（主流媒体跟进、社媒热度），并与同一标的历次做空对比。
- [ ] 市场反应是否记录：次日涨跌、管理层增持、做空方是否平仓。
- [ ] 增量信息是否区分：相关信息是否早已披露，多头买的究竟是什么、用什么方式定价（PEG 等）。
- [ ] 逐条核查是否检验四件事：论据、假设参数、样本选择、趋势方向，并分出欺诈 / 粉饰 / 表述不严谨三级。
- [ ] 金融资产类：坏账率分母是否合并表内外、分子是否剔除出表过程损失；是否核查风险自留比例、回购承诺和实际损失率。
- [ ] 利润质量是否折算成当期 EBITDA 注水比例，并看趋势。
- [ ] 物理约束类：单耗口径、供给端、远期弹性是否逐项核对，残余风险是否写明。
- [ ] 结论是否把“基本面攻击力”与“短期情绪影响”分开表达。

## 12.3 分拆上市、股权处置与上市地变更

> 本节导读：本节解决“集团把子公司拆出去、卖掉控股权、或把股票搬到另一个市场”这类资本运作怎么研究的问题，分为三组：子公司分拆（快速三问、分拆动因与母公司持股处置、独立融资作为重估催化、自研业务的期权评估、出售控股权的三维解读）、ADR 与二次上市（发行条款五要素量化拆解）、上市地迁移对估值的影响（三条通道和 ADR 双向转换）。适用于分拆公告刚出而招股书未出的首篇快评、母公司持股减持的跟踪，以及二次上市 / ADR 发行事件。分拆后子公司的估值折算归 9.6（SOTP 分部估值与母子公司价值）；指数纳入归 13.3（催化剂识别与时间线）；IPO 动机与发行估值见 12.1。

### 12.3.1 子公司分拆上市的快速三问：前世今生、竞争优势、母公司受益几分

- **方法要点**：子公司刚公告分拆、招股书还没出时，用三个问题快速梳理，先给出数量级判断，详细经营数据和估值留待招股书再讨论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 前世今生：起源、产品代际、团队、技术分工、产能约束。
  2. 竞争优势：先论证赛道优势（比如国产替代），再谈公司在技术和生态层面的优势。
  3. 母公司受益几分：子公司估值区间 × 持股比例，更新母公司的分部估值（SOTP，见 9.6）。
  4. 明确说明详细经营数据和估值要等招股书再讨论，先给出数量级判断。
- **关键指标与数据来源**：母公司持股比例、历轮融资估值、收入、出货量；来源为分拆公告、融资公告、母公司披露。
- **判断标准**：母公司受益 = 子公司估值区间 × 持股比例（分拆后控股权保留比例），与母公司现有市值对比，判断对母公司估值的边际贡献。
- **海豚案例**：
  - 百度 / 昆仑芯《昆仑芯上市加速，百度的「谷歌时刻」来了？》（2026-01-02）：百度公告分拆昆仑芯赴港上市，保留 59.45% 控股权，已秘密递表；全文按“前世今生、竞争优势、母公司受益几分”三问展开。
- **适用场景与注意事项**：适用于任何子公司分拆或 IPO 事件的首篇快评；数量级判断后需在招股书出来后补充细化。

### 12.3.2 分拆动因（合并折价）+ 母公司持股处置路径拆解 + 抛压消化判断

- **方法要点**：把一次分拆讲成完整的因果链——为什么分（合并折价）、怎么分（持股处置路径）、分完以后供给面还有没有压力（抛压是否消化），并判断子公司分拆后是否真正独立。
- **操作步骤 / 拆分口径 / 公式**：
  1. 历史：创立、被母公司收购的价格与融资方式（并购贷款）、近年债务负担。
  2. 分拆动因：两块业务成长性和发展逻辑明显不同，合在一起导致“低估折价”；梳理宣布分拆和重新独立上市的时间点。
  3. 持股处置：母公司保留比例 → 逐步减持 → 公告处置全部剩余持股；拆解处置方式。
  4. 结论：双方股权是否彻底脱钩、子公司能否独立主导，股东是否转为长期机构，母公司抛压是否已消化。
  - **处置方式拆解**：分两步——一部分通过“债转股 + 二级市场公开发售”（借过桥资金 → 赎回高级票据 → 债转股 → 银行转手卖出）；另一部分通过“股换股”（把子公司股票换成母公司自身股票，换回的股票注销）。
- **关键指标与数据来源**：母公司持股比例变化、处置股数与方式、债务规模、主要股东构成；来源为公司公告与股东披露。
- **判断标准**：母公司减持节奏与完成度是股价供给面的重要变量；处置全部完成、股东转为机构长期持有，意味着抛压已消化、子公司独立主导；合并折价消除是分拆的价值逻辑。
- **海豚案例**：
  - 闪迪《AI 推理大爆发，“悲催” 闪迪真有凤凰涅槃？》（2026-09-14，第一节）：
    - 历史：闪迪 1988 年创立，2016 年被西部数据以约 160 亿美元收购，西数为此借约 180 亿美元并购贷款，近十年承受高额债务。
    - 分拆动因：HDD 与 NAND 成长性及发展逻辑明显不同，合在一起导致“低估折价”；2023 年 10 月宣布分拆，2025 年 2 月闪迪重新独立上市。
    - 持股处置：西数保留 19.9%，2025 年 6 月减至约 5%，2026 年 2 月公告处置全部 750 万股（减债 30 多亿美元）；其中 582 万股通过“债转股 + 二级市场公开发售”（借过桥资金 → 赎回高级票据 → 债转股 → 银行转手卖出），169 万股通过“股换股”（把闪迪股换成西数自身股票，换回的 480 万股注销）。
    - 结论：双方股权彻底脱钩，闪迪独立主导、无需兼顾 HDD；股东转为富达、先锋、贝莱德等机构，西数抛压已消化。
- **适用场景与注意事项**：适用于已分拆上市的公司；母公司减持节奏与完成度是股价供给面的重要变量，需持续跟踪；解禁与减持的跟踪见 11.2。

### 12.3.3 子业务分拆上市和独立融资作为价值重估催化，并用历史案例类比

- **方法要点**：把子业务的独立融资和拆分上市进展视为影响母公司估值最大的变量之一，跟踪每一轮融资的估值锚，并用历史案例验证重估路径。
- **操作步骤 / 拆分口径 / 公式**：
  1. 跟踪每一轮融资：投后估值、融资额、领投方、母公司持股比例变化。
  2. 跟踪拆分上市进展（递表、聆讯、上市时间）。
  3. 用融资估值锚折算母公司所持子业务的价值（投后估值 × 母公司持股比例）。
  4. 用历史案例类比验证重估路径：某公司推进子业务拆分上市，叠加 AI 增量收入兑现和股东回报提升后，估值上涨约 50%。
- **关键指标与数据来源**：融资额、投后估值、持股比例、上市进展、可比案例的估值变化。
- **判断标准**：子业务融资估值越高、母公司持股价值占市值比重越大，分拆催化越强；类比案例要说明本次与先例的共同条件（分拆推进、业务收入兑现、股东回报）是否具备。
- **海豚案例**：
  - 快手《快手：老铁翻身，就靠“可灵”了》（2026-05-27）：可灵拆分上市是快手价值重估的机会；类比百度宣布拆分昆仑芯、推进上市流程，叠加 AI 收入兑现和股东回报大幅提升后，估值涨了近 50%。
  - 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：7 月可灵完成 30 亿美元融资，投后估值 180 亿美元，快手持股降至 68%，领投方包括 CPE 源峰、国方创投，腾讯参与（据此可折算快手所持可灵价值约 122 亿美元，为推算值）。
- **适用场景与注意事项**：适用于有可分拆资产的集团公司；分拆时点和折价不确定；子公司估值折算进母公司的方法见 9.6。

### 12.3.4 自研业务的分拆融资与外部商业化期权评估

- **方法要点**：对内部孵化的自研业务（如自研芯片），追踪其独立融资、性能、降本效果和商业化路径，把它当作母公司市值的“期权部分”单独描述，但不计入核心估值。
- **操作步骤 / 拆分口径 / 公式**：
  1. 独立融资：融资金额、母公司持股比例。
  2. 性能：制程、算力、流片进展。
  3. 对主业的降本：替代外购芯片后的单车节省。
  4. 商业化路径：从内部自用 → 外部供应 → 产品矩阵 → 独立上市。
  5. 单独描述为期权部分，不计入核心估值。
- **关键指标与数据来源**：融资金额、持股比例、芯片制程和算力、单车降本额、流片进展。
- **判断标准**：外部订单落地前只能定性看作期权，不宜高估；内部自用带来的降本是可验证的实际价值，外部商业化与独立上市是上行期权。
- **海豚案例**：
  - 蔚来（2026-03-10、2026-05-21）：负责 NX9031 的蔚锐科技通过发行新股获得 22.57 亿元注资，蔚来持股 62.7%；5nm 工艺，单片算力超 1000TOPS；替代 Orin-X 每车降本约 1 万元；第二代 5nm 芯片已流片，规划中端产品线，长远目标是独立上市。
  - 蔚来（2026-09-01）：NX9031 号称全球首款车规 5nm 芯片。
  - 理想（2026-08-26）：M100 单颗 1280TOPS，成本仅为外购芯片的一半。
- **适用场景与注意事项**：适用于有内部孵化业务的公司；在外部订单落地前只能定性看作期权，不宜高估。期权估值方法见 9.7。

### 12.3.5 出售子公司控股权的三维解读：速度、定位、风险与期权

- **方法要点**：对“在最大增量市场出售控股权”这类反直觉的资本运作，从扩张速度、品牌定位、风险与期权三个维度解读，并识别它是否复用了公司的历史方法论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 速度——用轻资产换扩张速度：把门店目标与资本开支压力对照（中国目标从 8000 余家拓至 2–3 万家，全直营资本开支压力大，无法匹配本土加盟品牌下沉的速度），引入合作方承担下沉资金与本地资源；识别是否复用历史方法论（复用 2018 年雀巢 CPG 授权的方法论：把不擅长的重投入环节交给最合适的人，自己保留品牌资产收版税）。
  2. 定位——坚守高端定位、不被拖入价格战：用管理层表述佐证（CEO Brian Niccol：风味创新超越、数字化至少匹配、体验差异化）。
  3. 风险与期权——转移风险、保留上行期权：出售比例一次性兑现中国业务估值，保留剩余股权 + 长期品牌授权费分享未来成长，即“落袋为安 + 保留看涨”的资本纪律。
- **关键指标与数据来源**：交易估值、出售比例、保留股权、授权费率、门店目标。
- **判断标准**：从战略（速度）、竞争（定位）与资本配置（风险与期权）三方面都能解释，才算解读完整；识别是否为历史方法论的复用，则能增强可信度。
- **海豚案例**：
  - 星巴克《星巴克：“披着咖啡外衣的银行”，凭何称霸全球四十年？》（2026-07-21）：中国业务总估值超 130 亿美元，出售 60%（博裕作为合作方），保留 40% 股权 + 长期品牌授权费；门店目标从 8000 余家拓至 2–3 万家；复用 2018 年雀巢 CPG 授权方法论；一次性兑现估值、保留看涨。
- **适用场景与注意事项**：适用于业务出售、合资、分拆、授权等资本运作事件；要从战略、竞争与资本配置三方面解释，并识别是否为历史方法论的复用。

### 12.3.6 ADR 发行条款五要素量化拆解：股数 → ADS 比例 → 股本占比 → 定价锚 → 募资额

- **方法要点**：拿到 F-1 招股书后，先把发行条款全部数字化，再据此推断公司的意图，把新闻事件变成可比较的数字，作为后续判断融资动机、ADR 稀缺性溢价和指数纳入时间的基础。
- **操作步骤 / 拆分口径 / 公式**：
  1. 股数与 ADS 比例：发行普通股数与 ADS 份数 → 算出 ADS : 普通股比例，与市场常规（1:2 或 1:4）对比；1:10 属于高度拆细，目的是把单价做得接地气，吸引散户与中小机构。
  2. 股本占比：新股占总股本比例，结合法定约束解释额度上限（如韩国《公平交易法》要求大股东持股不低于 20%，现持股 20.5%，因此只能小额增发）。
  3. 定价锚：招股书以某日本地收盘价折算 ADS 参考价，与最终定价比较，得出折让率（折让 = 1 − 最终定价 ÷ 参考价）。
  4. 募资总额 = ADS 份数 × 定价。
  5. 列出关键时间表：簿记、定价、上市、交割、底层新股上市。
- **关键指标与数据来源**：发行普通股 1779 万股 / 1.779 亿份 ADS、ADS 比例 1:10、占总股本约 2.5%、大股东持股 20.5% 与 20% 法定红线、锚定价 W2,425,000 → 约 158 美元 / ADS、最终定价 149 美元 / ADS、募资约 265 亿美元、关键日期；来源为 F-1 招股书、交易所公告。
- **判断标准**：拆细比例只改变单价，不改变价值，只影响投资者结构；法定约束决定额度上限；定价较锚定价的折让（约 6%）反映发行的“让利”程度。
- **海豚案例**：
  - SK 海力士《海力士赴美，来讨一个 “公道估值”？》（2026-07-10）：1:10 拆细被解读为争取散户；2.5% 额度受大股东 SK Square 20.5% 持股与 20% 法定红线约束；定价 149 美元，较锚定价约 158 美元低约 6%；募资约 265 亿美元；7 月 6 日至 9 日簿记，7 月 10 日纳斯达克交易，7 月 14 日交割，7 月 29 日底层新股在韩上市。
- **适用场景与注意事项**：适用于二次上市、ADR / GDR、增发、配售等资本市场事件；注意各法域对大股东持股、外资额度的约束；拆细比例只改变单价，不改变价值。

### 12.3.7 ADR / 二次上市对估值影响的三通道：交易端、披露端、叙事端

- **方法要点**：把“股票搬到美国交易”对估值的影响拆成三条通道，逐一写清机制，并把股东结构变化视为“股东质量提升”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 交易端：
     - 边际买家扩容——大量美国养老金、共同基金受政策限制不能买海外存托凭证，ADR 后可直接配置。
     - 被动资金——有望纳入 Nasdaq Composite、美国指数基金、MSCI 美国相关指数。
     - 同一市场、同一货币下与同行（如美光）直接比较估值。
  2. 披露端：美式披露降低信息不对称。
  3. 叙事端：从“韩国局部市场的存储标的”转为与英伟达、美光同框的“全球化 AI 核心资产”。
  4. 股东结构：从韩国本土机构 + 交易型外资，转向长期机构与被动资金，视为“股东质量提升”（拓宽投资者范围）。
- **关键指标与数据来源**：可纳入指数清单、潜在被动资金规模、股东结构（本土机构 / 外资 / 被动资金占比）。
- **判断标准**：三通道均成立，才能支持“重估”的论述；被动资金纳入规则与时点要单独核实，避免把预期当成事实。
- **海豚案例**：
  - SK 海力士《海力士赴美，来讨一个 “公道估值”？》（2026-07-10）：三通道分析 + “拓宽投资者范围，提升股东质量”。
- **适用场景与注意事项**：适用于二次上市、转板、纳入指数、MSCI 扩容等事件；注意被动资金纳入规则与时点（指数纳入的催化剂跟踪见 13.3）。

### 12.3.8 ADR 双向转换通畅度与额度稀缺性推演 ADR 溢价

- **方法要点**：分析存托凭证与本地股之间两个方向的转换，单向受限会让 ADR 具备稀缺性，从而支撑相对本地股的溢价。
- **操作步骤 / 拆分口径 / 公式**：
  1. 本地股 → ADR（受限）：初始额度用尽后，只有其他 ADR 持有者注销后才能发行新 ADR；又受《垄断规制与公平交易法》约束（大股东需保持 ≥ 20%），短期增发扩额可能性极低。
  2. ADR → 本地股（畅通）：底层新股上市后可随时注销换股，无实质限制。
  3. 推演：单向受限意味着无法直接投资本地市场的投资者不愿轻易交出 ADR，从而支撑 ADR 相对本地股的溢价。
  4. 量化预期：市场普遍预期溢价 5–10%，若被纳入美股指数或 ETF 可能更高。
- **关键指标与数据来源**：ADR 额度占总股本比例（2.5%）、转换规则、ADR 与本地股价差（溢价率）、指数 / ETF 纳入事件。
- **判断标准**：额度越稀缺、转换越单向，溢价越有支撑；额度一旦放开，溢价会收敛。
- **海豚案例**：
  - SK 海力士《海力士赴美，来讨一个 “公道估值”？》（2026-07-10）：正文与补充信息“ADR 转换机制”——额度占总股本 2.5%，本地股 → ADR 受限而 ADR → 本地股畅通，市场普遍预期 ADR 溢价 5–10%，纳入美股指数或 ETF 可能更高。
- **适用场景与注意事项**：适用于有外资额度 / 转换限制的存托凭证（韩国、台湾、印度等）；额度一旦放开，溢价会收敛。

**本节速查清单**

- [ ] 分拆快评是否回答三问：前世今生、竞争优势、母公司受益几分（估值区间 × 持股比例）。
- [ ] 分拆动因是否讲清（合并折价）；母公司持股处置路径与完成度、抛压是否已消化。
- [ ] 子业务独立融资是否跟踪估值锚：投后估值、融资额、持股比例变化，历史类比案例的前提是否具备。
- [ ] 自研业务是否按“期权”单独描述：融资、性能、降本额、商业化路径，不计入核心估值。
- [ ] 出售控股权是否从速度、定位、风险与期权三维解读，是否识别历史方法论的复用。
- [ ] ADR 发行条款是否五要素数字化：股数、ADS 比例、股本占比、定价锚（折让）、募资额，以及法定约束。
- [ ] 上市地迁移是否分三条通道（交易端、披露端、叙事端）写明机制，被动资金规则与时点是否核实。
- [ ] ADR 转换是否分两个方向检验，溢价的稀缺性依据与收敛条件是否交代。

### 12.4.1 认股权证 / 客户激励协议的条款逐项拆解

- **方法要点**：遇到公司向客户发行认股权证或股权激励的事件，把每个条款逐项数字化，算出公司实际让渡的价值和能收到的现金，并推算隐含的合资格收入规模，再看同步指引是否上调，以判断这是实质订单还是框架性协议。
- **操作步骤 / 拆分口径 / 公式**：
  1. 时间节点：签署日和发行日。
  2. 行权价：相对发行日收盘价的折溢价（折价率 = 行权价 ÷ 发行日收盘价 − 1）。
  3. 授予总股数，并拆成直接赠予（无条件、分几期时间归属）和业绩归属两部分。
  4. 业绩归属条件：每实现多少合资格收入解锁多少股、份数、计算截止日；隐含合资格收入总额 = 份数 × 每份收入门槛。
  5. “合资格收入”的定义：含不含第三方代采、是定制品还是通用件。
  6. 行权方式：现金 / 无现金，谁有选择权，到期价内是否自动行权，净额行权时公司能否收到现金。
  7. 综合算出公司实际让渡的价值与能收到的现金；同时观察公司是否同步上调相关业务指引（判断实质订单还是框架协议）。
- **关键指标与数据来源**：行权价、折价率、总股数、时间归属股数、业绩归属股数、解锁单位（每 5 亿美元收入）、计算期、合资格收入定义、行权方式；来源为公司 8-K 公告、权证协议、财报指引。
- **判断标准**：
  - 要评估稀释比例和收入门槛的可达性（门槛对应的合资格收入总额是否合理）。
  - 若公司同步上调了相关业务指引 → 更像实质订单；若没有上调 → 更像“主动送钱”的框架性协议。
  - 若净额行权时公司拿不到现金，则这笔权证本质上是让渡股权价值换订单。
- **海豚案例**：
  - Marvell《迈威尔 Marvell：“贴钱”结盟谷歌，能“撬动”博通墙角吗？》（2026-08-20）：商业协议 2026-07-29 签署，权证 2026-08-18 发行；行权价 206.58 美元（8/18 收盘 216 美元，折价约 4%）；共 5897 万股，其中时间归属 136 万股（第 3 / 6 / 9 / 12 个月各约 34 万股），业绩归属 5761 万股，分 240 份，每实现 5 亿美元合资格销售解锁一份（24 万股），期限从 2026-08-01 至 2033-01-29（推算全部解锁对应约 1200 亿美元合资格收入）；只计入定制 ASIC（AI 推理加速器、存储控制器、NIC、内存接口控制器、近存计算），第三方代采计入，通用光 DSP、DCI 模块、通用 SSD 控制器不计入；谷歌可单方面选择现金或无现金行权，到期价内自动无现金行权，净额行权时 Marvell 拿不到现金。
  - Marvell（2026-08-28）：授予谷歌认股权证共 5897 万股，行权价 206.58 美元；其中直接赠予 136 万股，在 3、6、9、12 个月各归属 34 万股；业绩解锁 5761 万股，分 240 份，自 2026 年 8 月 1 日起每实现 5 亿美元合资格收入解锁一份（约 24 万股），全部解锁对应约 1200 亿美元合资格收入；合资格收入指谷歌的定制 ASIC 芯片（推理加速器、存储 / 网络 / 内存接口控制器、近存计算）；整体方式参照了此前与亚马逊的合作；同时没有上调 ASIC 指引，因此判断这更像“主动送钱”的框架协议，Marvell 处于弱势。
- **适用场景与注意事项**：适用于客户权证、战略入股、可转优先股等资本交易事件，尤其是供应商以股权换客户订单的案例；要评估稀释比例和收入门槛的可达性。

### 12.4.2 判断条款强弱方，并从“合资格收入”定义推断交易意图

- **方法要点**：通过条款的性质判断谈判地位，并从合资格收入圈定的产品范围推断公司真实的战略意图，以及对方为什么愿意接受。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看条款性质判断强弱：无条件赠股、对方不用出现金（净额行权），说明公司是弱势一方，在主动示好。
  2. 看“合资格收入”范围圈定了哪些产品，推断公司真实意图（想撬动哪块业务）。
  3. 分析对方为什么愿意接受：白送的好处、已有合作基础、提升对现有供应商的议价能力。
  4. 与同步的指引（是否上调）交叉验证强弱判断。
- **关键指标与数据来源**：赠股比例、现金对价、合资格收入范围。
- **判断标准**：对方无现金出资、公司先白送股权 → 公司弱势、主动示好；合资格收入范围越聚焦某一类产品 → 战略意图越明确（撬动对应业务）；对方的收益（白送 + 提升对现有供应商的议价）解释了其接受动机。
- **海豚案例**：
  - Marvell《迈威尔 Marvell：“贴钱”结盟谷歌，能“撬动”博通墙角吗？》（2026-08-20）：先白送 136 万股、谷歌无需出现金，说明 Marvell 明显弱势；合资格收入限定在定制 ASIC，说明意图是从博通手里撬动谷歌的定制 ASIC 业务；谷歌一方面收下白送的权证，另一方面已有 Axion CPU 合作、后续还有 MPU 计划，并能提升对博通的议价能力。
  - Marvell（2026-08-28）：没有上调 ASIC 指引，进一步佐证这是“主动送钱”的框架协议、Marvell 处于弱势。
- **适用场景与注意事项**：适用于供应商与大客户的各类绑定协议分析；意图推断需要后续的订单落地来验证。

### 12.4.3 与公司历史同类协议横向对比，对客户关系性质分类

- **方法要点**：把本次协议与公司过去和其他客户签的同类方案列表对比，识别量级变化，并把合作关系分成两类：对方出真金白银、互相协作的战略合作，和公司为获取大客户订单而主动示好的激励。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列表对比各协议：签署时间、覆盖产品、总股数、时间归属与业绩归属结构、行权价、对方是否实付现金、是否有投票权。
  2. 横向比较量级（股数倍数、行权价相对平价的位置）。
  3. 按“对方是否出真金白银”分类：战略协作（对方出资、有投票权、业务协作） vs 主动示好的激励（公司送权证换订单）。
- **关键指标与数据来源**：各协议股数、行权价、归属结构、是否现金出资、投票权；来源为公司历次公告和协议。
- **判断标准**：对方实付现金、有投票权、有业务依附（如共同生态）→ 战略协作；公司送股、对方不出现金、行权价接近平价 → 主动示好。
- **海豚案例**：
  - Marvell《迈威尔 Marvell：“贴钱”结盟谷歌，能“撬动”博通墙角吗？》（2026-08-20）：
    - 亚马逊第一份（2024-12-02）：418 万股，其中 28 万时间归属、270 万挂钩定制 AI 收入、120 万挂钩其他产品，收入计算至 2030-01-05，行权价 87 美元。
    - 亚马逊第二份（2025-12-02）：与收购 Celestial AI 同日签署，104.5 万股挂钩 Photonic Fabric 采购。
    - 英伟达 A 系列可转优先股（2026-03-31）：唯一真金白银出资 20 亿美元、有投票权的方案，依附 NVLink Fusion 合作。
    - 谷歌版：股数是亚马逊的 10 倍以上，行权价接近平价。
    - 结论：与英伟达是战略协作，与亚马逊和谷歌是主动示好。
- **适用场景与注意事项**：适用于客户关系与资本绑定交易的定性判断；需要公司历史上有可比的协议作为参照。

### 12.4.4 合作事件三层拆解：业务内容、股权绑定条款、对标先例

- **方法要点**：拿到合作公告后分三层拆——业务合作内容、股权绑定机制、对标市场先例，重点看归属条件是否和真实采购挂钩、以及采购上限，这两项决定合作的实质确定性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 业务合作内容：产品、技术、软件协同的具体范围。
  2. 股权绑定机制：认股权证数量、行权价、价值、期限、无现金行权、分批归属条件、采购上限。
  3. 对标市场先例：同类公司给大客户的同类方案，判断这是行业惯例还是特例。
  4. 重点检查归属条件与真实采购的挂钩程度，以及采购上限（决定实质确定性）。
- **关键指标与数据来源**：认股权证股数、行权价、价值、到期日、归属条件、采购上限。
- **判断标准**：归属条件与真实采购挂钩越紧、采购上限越高，合作的实质确定性越强；若同类先例已存在，则可视为行业惯例而非特例。认股权证可视为给客户的折让，要同时评估股东稀释。
- **海豚案例**：
  - 高通《抱上亚马逊大腿，高通 AI 第二曲线“稳了”？》（2026-09-09）：业务内容包括定制 AI 推理 ASIC、最高 1.6Tbps 及以上光互连（SerDes、光 DSP），高通还在自身工作负载上使用 Amazon Bedrock EDA 压缩设计周期；股权绑定：授予亚马逊 2500 万股认股权证，行权价 161.26 美元，价值 40 亿美元，2036 年 9 月 3 日到期，可无现金行权，分批归属与采购高通服务器芯片和技术挂钩，采购上限 600 亿美元；先例：参照 Marvell 给谷歌的方案。
- **适用场景与注意事项**：适用于半导体 / 云供应链中的战略合作事件；认股权证可视为给客户的折让，要同时评估股东稀释。

### 12.4.5 战略合作或新客户事件的价值判断：背书价值、业务性质、确定性增量

- **方法要点**：对合作新闻，从三方面判断价值：背书价值、业务性质、确定性增量；必要时用功率或规模换算新业务体量。
- **操作步骤 / 拆分口径 / 公式**：
  1. 背书价值：合作对象能否为公司带来急需的“重要客户”背书。
  2. 业务性质：是采购、联合开发还是代工——市场更看重联合开发的价值，而不是单纯采购；并对市场的相关观点给出反驳（如对“某技术弱化 CPU”的观点）。
  3. 确定性增量：客户是否披露了前期投入、是否明确采用公司的下一代产品。
  4. 新业务体量测算：用功率规模折算收入机会（部署功率 × 单位功率收入）。
- **关键指标与数据来源**：合作对象；合作形式（采购 / 联合开发 / 代工）；投入金额；功率规模 → 收入估算。
- **判断标准**：背书价值高、业务性质偏联合开发、客户有明确投入与产品采用，则增量确定性高；合作公告常缺少金额与时间，需要等客户侧披露验证。
- **海豚案例**：
  - 英特尔《英特尔：告别“至暗”时刻…》（2026-04-24）：英特尔与马斯克的 Terafab 能为代工带来急需的“重要客户”背书；谷歌合作中市场更看重联合开发 IPU（类似 DPU，负责网络、存储、安全，把 CPU 从“苦活”中解放出来做 Agent 编排），而不是单纯采购 Xeon，并对“TPU Direct Storage 弱化 CPU”的市场观点给出反驳；特斯拉披露 30 亿美元前期投入并预计用 14A，增加了确定性。
  - 高通《高通：“存储荒”加码…》（2026-02-05）：Humain 计划部署 200MW 算力，估算约 30 亿美元收入机会（新业务体量测算）。
- **适用场景与注意事项**：适用于新闻驱动的个股研究；合作公告常缺少金额与时间，需要等客户侧披露验证。

### 12.4.6 逐条追踪关键合作协议条款，判断对投资逻辑的影响

- **方法要点**：对影响投资逻辑的重大合作关系，列出每次重谈的条款变化，逐条判断它对收入、毛利率、竞争力的影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出协议的每一条重点条款及其变化。
  2. 逐条映射到三类影响：收入（是否丢失云合同、订单分流）、毛利率（是否不再分成）、竞争力（是否失去模型独占）。
  3. 追踪后续新增变化（新增的分销权、订单流向）。
- **关键指标与数据来源**：协议条款、大客户订单变化。
- **判断标准**：独占权失去（模型独占、分销独家、算力优先供应权）→ 竞争力下降；云合同或新增订单流向其他云厂商 → 收入流失；分成条款的变化（终止、设上限）→ 落在毛利率上，要判断对毛利率是增还是减；每条变化都要明确归入收入、毛利率、竞争力三类之一并判断方向，对高度依赖单一伙伴 / 大客户的公司，每次条款变化都要更新逻辑。
- **海豚案例**：
  - 微软（2026-01-29）：列出 25 年 10 月新协议的重点变化——模型使用权到 2032 年；双方都可独立研发 AGI；OpenAI API 仅在 Azure 独家提供；OAI 可向其他云采购算力；微软失去算力优先供应权；分销权不再独家；OpenAI 收入分成 2030 年终止并设上限。
  - 微软（2026-05-01）：新增变化——亚马逊也获得分销权，OAI 把更多新增订单给 Oracle、Amazon、CoreWeave。
- **适用场景与注意事项**：高度依赖单一伙伴 / 大客户的公司；需每次重谈后更新跟踪。

### 12.4.7 合资（JV）产能结构拆解：共同出资、研发共享边界、产能分配、协议期限与新投资

- **方法要点**：对依赖合资工厂的公司，拆出合资的结构要素——谁出资、研发共享到哪里为止、产能怎么分、协议能持续多久、新的投资和新产品是什么，据此理解公司份额稳定性和资本开支分担。
- **操作步骤 / 拆分口径 / 公式**：
  1. 共同出资：共同购买设备，分担重资产风险。
  2. 研发共享边界：共同研发的环节（如同一实验室研发 BiCS 架构、die 之前的环节共研共享）与各自自研的差异化环节（die 之后的控制器、固件）。
  3. 产能分配比例：前道晶圆产能分配（约 4:6），各自独立销售，因此市场份额长期接近。
  4. 协议期限：由原定到期日延长至何时，续约风险。
  5. 产能基地与新投资：现有基地、新 fab 的启动与投产目标、日本投资总额（前提是政府支持）、市场预期的单 fab 投资额。
  6. 同期产品进展：新一代产品的规格对比。
- **关键指标与数据来源**：JV 晶圆分配比例、协议期限、投资额、新 fab 投产时间、产品规格。
- **判断标准**：合资协议期限越长、产能分配越稳定，份额越稳；研发共享在 die 之前、差异化在 die 之后，决定了合资双方“同质产能 + 异质产品”的竞争格局；续约风险需关注协议期限。
- **海豚案例**：
  - 闪迪《AI 推理大爆发，“悲催” 闪迪真有凤凰涅槃？》（2026-09-14，第二节）：闪迪产能基本来自与铠侠在日本的合资工厂——
    - 共同出资购买设备，分担重资产风险。
    - 研发共享：同一实验室研发 BiCS 架构，die 之前的环节共研、成果共享，die 之后（控制器、固件）各自自研形成差异化。
    - 产能分配：前道晶圆产能约 4:6，各自独立销售，两家市场份额长期接近（合计约 15%）。
    - 期限：合资协议由原定 2029 年延长至 2034 年 12 月 31 日。
    - 产能基地：四日市（Fab3–Fab7，全球最大闪存基地）与北上（K1、K2，铠侠宣布启动北上 Fab3 场地准备，目标 2029 财年投产）；两家宣布 2032 年前在日投资超 310 亿美元（约 5 万亿日元，前提是政府支持），市场预计 K3 约 1.8 万亿日元（约 113 亿美元）。
    - 同日送样 BiCS10：332 层、1Tb TLC、密度 > 29Gb/mm²（较 BiCS8 +59%）、接口 4.8Gb/s（+33%）。
- **适用场景与注意事项**：适用于合资产能、代工绑定、产能共享模式的公司；需关注协议期限与续约风险；“前提是政府支持”的投资额只是计划，不等于已确定的资本开支。

**本节速查清单**

- [ ] 权证 / 激励条款是否逐项列出：签署日与发行日、行权价与折价率、总股数、时间归属与业绩归属、合资格收入定义、行权方式。
- [ ] 隐含合资格收入总额是否算出（份数 × 门槛），稀释比例与收入门槛的可达性是否评估。
- [ ] 谈判强弱是否判断：有无无条件赠股、对方是否实付现金、公司是否同步上调指引。
- [ ] 合资格收入的定义圈定了什么产品，是否据此推断真实意图和对方的接受理由。
- [ ] 是否与公司历史同类协议列表对比，并把客户关系分为“战略协作 / 主动示好”。
- [ ] 合作事件是否三层拆解：业务内容、股权绑定（归属条件是否挂钩真实采购、采购上限）、对标先例。
- [ ] 新闻价值是否按背书价值、业务性质、确定性增量判断，金额与时间缺失时是否等客户侧验证。
- [ ] 关键合作协议是否逐条追踪，并映射到收入、毛利率、竞争力三类影响。
- [ ] JV 结构是否拆清：出资、研发共享边界、产能分配、协议期限与新投资。

## 12.5 发布会与产品/模型发布点评

> 本节导读：本节解决“发布会、开发者大会、新品或新模型发布后，怎么快速分出信息的轻重、写出有增量的点评”的问题：先把信息分成“对产业链的影响”和“对公司自身的增量”，再把内容拆成同质化与差异化部分分配篇幅，用“市场期待清单”比对识别缺席项；针对产品发布（竞品对比表 + 五维度）、大模型发布（基准拆解、可用性折扣、定价、市场反应归因）和生态大会（要点映射到落地场景）分别给出模板。与 12.6（事件影响评估：发布会信息映射到供应链、事件定级）配合使用。发布会或投资者日上的财务指引解读归 8.5；点评的写作模板归 14.3。

| 要回答的问题 | 优先使用的方法 | 编号 |
| --- | --- | --- |
| 这场发布会对公司本身有没有增量，还是只影响产业链 | 产业链影响 vs 公司自身增量二分 | 12.5.1 |
| 发布内容那么多，篇幅怎么分 | 同质化简单带过，差异化重点分析 | 12.5.2 |
| 发布会为什么“扫兴” | 市场期待清单对比，识别缺席项 | 12.5.3 |
| AI 助手 / 消费产品发布快评 | 竞品汇总对比表 + 五维度评估 | 12.5.4 |
| 新大模型发布，怎么评、怎么解释股价反应 | 基准拆解 + 可用性折扣 + 定价对标 + 反应归因 | 12.5.5 |
| 开发者大会 / 公开课怎么提炼 | 要点分线 + 映射 AI 落地场景 | 12.5.6 |

### 12.5.1 把发布会信息分成“对产业链的影响”和“对公司自身的增量”

- **方法要点**：发布会信息分成两类——一类影响产业链公司（技术路线选择、新的芯片选项），另一类是公司自身的增量（新订单、新指引），据此判断这场发布会对股价是“增量”还是“扫兴”，并把产业链信息映射到相关环节。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把发布内容逐条归类：产业链影响（技术路线、新选项） vs 公司自身增量（订单、指引）。
  2. 若大部分篇幅是产品推销和路线规划，就是产业链影响多、公司自身增量少，股价可能“扫兴”。
  3. 产业链那一类信息再映射到相关环节（铜缆、光模块、存储等）。
- **关键指标与数据来源**：技术路线（铜 / CPO）、新增芯片选项、订单与指引。
- **判断标准**：看是否有新订单、新指引——有则是公司自身增量；只有路线图与产品推销，则对公司自身增量少，对产业链影响多。
- **海豚案例**：
  - 英伟达（2026-03-17）：Feynman 首次同时支持 Kyber 铜缆和 CPO scale-up，客户倾向于把铜缆用到极致再切 CPO（部署维护更简单）；LPU 与 HBM 分担不同工作；对产业链影响多，对英伟达自身增量少。
- **适用场景与注意事项**：适用于平台型公司大会解读，以及对产业链的二次映射；映射到供应商的受益 / 受损见 12.6.5。

### 12.5.2 把发布内容拆成同质化部分和真正差异化部分，按此分配篇幅

- **方法要点**：把发布内容拆成两部分——市场上已经很常见、难以产生本质差异的同质化功能（简单带过），和真正差异化的部分（重点分析），再检查差异化功能的闭环成熟度以及后续会接入哪些功能。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把发布内容拆成同质化功能和差异化功能。
  2. 同质化部分（海内外已有成熟产品、最多是 90 分和 70–80 分的区别）简单带过。
  3. 差异化部分重点分析。
  4. 检查差异化功能的闭环成熟度（能否在 App 内无跳转完成全流程）以及后续还会接入什么。
- **关键指标与数据来源**：功能闭环程度、跳转情况。
- **判断标准**：同质化功能已有成熟竞品、难做出本质差异，不值得占用篇幅；差异化功能要看是否闭环（全流程无跳转）、依托什么生态资源、后续接入计划。
- **海豚案例**：
  - 阿里（2026-01-16）：任务助理（办公向）海内外已有微软 Copilot、Manus 等，很难做出本质差异，最多是 90 分和 70–80 分的区别，所以不多讨论；生活助理是真正的重点，连接虚拟和现实世界，依托淘宝购物、闪购外卖、飞猪出行、支付宝政务，后续还会接入高德打车、大麦订票；目前只有闪购能在 App 内无跳转完成全流程，其他仍是卡片跳转。
- **适用场景与注意事项**：适用于产品发布会解读。

### 12.5.3 列出市场期待的增量清单，与发布会实际内容比对，识别缺席项

- **方法要点**：点评不只看发布了什么，更看市场期待但没发布什么：事前整理好期待清单，与实际发布比对，对缺席项用时间判断影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 事前整理市场期待清单（媒体报道、卖方预期）。
  2. 与实际发布内容逐项比对，列出缺席项和已发布项。
  3. 对缺席项预计发布时间和对销量的影响做判断（如预计下半年才发布，则短期无法支撑销量）。
  4. 判断本次更新是否足以带来质变的销量催化，尤其关注对主力价格带的覆盖。
- **关键指标与数据来源**：市场期待项清单；实际发布项；缺席项的预计发布时间；对主力价格带销量的影响。
- **判断标准**：缺席项越是市场高度关注，对点评结论影响越大；发布项不能覆盖主力价格带，则销量催化不足。
- **海豚案例**：
  - 比亚迪《比亚迪：“颠覆性”发布会，能“颠回”宇宙车厂吗？》（2026-03-06）：本次只更新了快充和二代刀片电池；市场高度关注的 DM-i 6.0 插混平台（媒体称热效率有望达 48%，馈电油耗降至 1.8–2.79L/100km，DM-i 5.0 为 3.8L/100km）和城市 NOA 向 10 万元级主力车型下放的进度都没有释放增量信息；DM-i 6.0 可能在 2026 年下半年发布，短期无法支撑插混销量；天神之眼 5.0 旨在让高阶智驾覆盖更多价位，但没看到继续下沉到 10–15 万元核心价格带的信号；结论：当前更新短期不足以带来质变的销量催化，海豚君保守预计国内销量承压。
- **适用场景与注意事项**：适用于所有发布会和投资者日；需要事前整理好市场期待清单。政策层面对价格带的影响见 12.6.14。

### 12.5.4 产品发布快评：竞品汇总对比表 + 五维度评估（形态 / 体验 / 入口 / 隐私 / 商业化位置）

- **方法要点**：产品发布时，制作与竞品、同类产品的汇总对比表，再按固定的五个维度逐项评价，最后给出总评。
- **操作步骤 / 拆分口径 / 公式**：
  1. 做竞品 / 同类产品的汇总对比表。
  2. 按五个维度评价：
     - 形态定位：产品对标什么（如类比“普通人的 Openclaw”），侧重什么场景。
     - 体验：实测是否快速流畅，算力与专属模型情况，门槛高低。
     - 入口覆盖：App、PC 客户端、Web、AI 眼镜等入口数量，与同类产品对比，是否借助庞大的社交生态裂变。
     - 隐私合规：是独立应用还是内嵌超级 App、与社交数据是否隔离、是否每用户专属云端虚拟机、是否触达账号密码和支付卡号。
     - 商业化位置：是否记住习惯、主动建议，为未来商业化留位置。
  3. 给总评。
- **关键指标与数据来源**：功能清单、入口数量、隐私设计、定价方式。
- **判断标准**：形态定位清晰、体验流畅、入口多、隐私合规、有商业化位置，则综合评价高；欧美市场需重点考察隐私。
- **海豚案例**：
  - Meta《(短评)Meta Muse发布》（2026-09-10，id 43844051）：形态定位——Muse 类比“普通人的 Openclaw”，侧重生活场景多任务；体验——实测快速流畅（算力多、有面向多任务的专属模型，门槛低）；入口——App、PC 客户端、Web、AI 眼镜，与豆包、千问有一拼，借 30 亿社交生态裂变；隐私合规——独立应用而非内嵌超级 App，形成与社交数据隔离的观感，每用户专属云端虚拟机，不触达也不存储账号密码、支付卡号，比 Instinct 更合规；商业化位置——记住习惯、主动建议，为未来商业化留位置。
- **适用场景与注意事项**：适用于 AI 应用 / 消费产品发布点评；实测样本有限，应结合后续留存数据；欧美市场需重点考察隐私。

### 12.5.5 大模型发布快评：细分基准拆解 + 可用性折扣 + 定价对标 + 市场反应归因

- **方法要点**：评估新模型时，不只看综合排名，而是按市场最关心的能力拆细分基准、对自报分数做可用性折扣、做价格对标，并解释股价反应的原因，列出扭转叙事所需的催化。
- **操作步骤 / 拆分口径 / 公式**：
  1. 综合智能：是否回到第一梯队。
  2. 按市场最关心的能力（如 AI Coding）拆细分基准，区分领先项与落后项，归纳落后项的共同特征（长时间硬核编码、无图形界面的终端原生操作）。
  3. 可用性折扣：模型未对公众开放 → 刷榜频出的情况下，KOL 实测已成为新的考核标准，自报分数可信度打折。
  4. 价格对标：标准价对标竞品，首发优惠。
  5. 市场反应归因：催化兑现后落袋为安、搜索侵蚀等空头叙事回归、明年利润削弱预期。
  6. 列出扭转叙事所需的催化（产品开放、新 Agent 上线等）。
- **关键指标与数据来源**：DeepSWE、Vibe Code Bench、FrontierSWE v2、Terminal-Bench 4.0、OSWorld-2.0；API 定价。
- **判断标准**：领先项 vs 落后项的结构决定“是否真回到第一梯队”；可用性（是否已开放）决定自报分数的可信度；市场反应用“催化兑现落袋为安 + 空头叙事回归 + 利润预期”解释，而不是只看基准分数。
- **海豚案例**：
  - 谷歌《(短评)Gemini 4发布市场反应平淡》（2026-10-02，id 44162543）：综合智能回到第一梯队；领先项为 DeepSWE（多文件实现）、Vibe Code Bench，落后项为 FrontierSWE v2、Terminal-Bench 4.0、OSWorld-2.0，归纳为长时间硬核编码与无图形界面的终端原生操作落后；未对公众开放，KOL 实测成为新的考核标准；标准价对标 Opus 5.5，首发半价；市场反应归因为催化兑现后落袋为安、搜索侵蚀空头叙事回归、明年利润削弱预期；列出扭转叙事所需的催化（Argon 开放、新 Agent 上线）。
- **适用场景与注意事项**：适用于大模型公司产品发布点评；基准易被刷榜，需辅以第三方实测与 token 份额。

### 12.5.6 公开课 / 开发者大会要点提炼，并映射到 AI 落地场景

- **方法要点**：把生态大会、公开课的内容按业务拆成若干条线，逐条提炼数据与政策要点，再映射到市场的核心逻辑（如“AI Agent 最大落地场”），并加上研究者自己的约束条件。
- **操作步骤 / 拆分口径 / 公式**：
  1. 按业务拆条线，每条线提炼关键数据与政策（如电商小店的 GMV 增长、小游戏的分成新规、小程序 AI 应用规模）。
  2. 映射到市场的核心多头逻辑（“微信是 AI Agent 最大落地场”）。
  3. 加上约束：涉及全网全量用户调用，产品打磨和充足的基础设施仍需准备充分。
- **关键指标与数据来源**：小店 GMV、小游戏分成政策、AI 应用小程序数量增速。
- **判断标准**：数据线（GMV、小程序数量增速）是否支持多头逻辑；约束条件（用户量级对产品打磨和基础设施的要求）决定落地节奏。
- **海豚案例**：
  - 腾讯《(短评)腾讯AI太安静》（2026-01-16，id 37878111）：把微信公开课内容按业务拆三条线——微信小店（服务商带动 GMV 高速增长）、小游戏（苹果与微信分成新规下，用新游激励缓解开发商分成影响）、小程序 AI 赋能（2025 年 AI 应用小程序规模增长两倍，推出 AI 应用成长计划）；再映射到“微信是 AI Agent 最大落地场”的多头逻辑，并加上约束（全网全量用户调用，产品打磨和基础设施仍需准备充分）。
- **适用场景与注意事项**：适用于生态大会、开发者大会点评。

**本节速查清单**

- [ ] 发布会信息是否二分：对产业链的影响 vs 对公司自身的增量（订单、指引），产业链信息是否映射到相关环节。
- [ ] 内容是否分出同质化与差异化部分，篇幅是否向差异化倾斜，差异化功能的闭环成熟度是否检查。
- [ ] 是否事前整理市场期待清单，并识别缺席项及其预计发布时间、对主力价格带的影响。
- [ ] 产品发布是否有竞品对比表，并按形态、体验、入口、隐私、商业化位置五维度评估。
- [ ] 模型发布是否拆细分基准、区分领先 / 落后项，并对未开放模型的自报分数做可用性折扣。
- [ ] 模型发布是否做价格对标，并把市场反应归因，列出扭转叙事所需的催化。
- [ ] 生态大会是否按业务拆条线、映射到核心落地逻辑，并写明约束条件。

## 12.6 事件影响评估与政策推演

> 本节导读：本节是事件分析的通用工具箱，解决“一条新闻、一次公告或一项政策出来后，怎么快速判断它的真实分量”的问题。路径分四步：先分层给结论并给事件定级（12.6.1–12.6.2），再沿客户、竞争对手、供应链和行业供需做一阶与二阶传导（12.6.3–12.6.6），然后校准判断——认定真正超预期的动作、纠偏市场叙事、考虑情绪窗口期、借助历史先例（12.6.7–12.6.11），最后专门处理政策与监管变化（12.6.12–12.6.15）。适用于突发新闻、行业性利空、大客户绑定、组织变动、补贴与监管调整等一切“股价被事件牵动”的时刻，与 12.4（单次合作条款拆解）、12.5（发布会点评）、12.2（做空事件）配合；风险传导见 13.1，催化剂时间线见 13.3，估值折溢价见 10.3。

**方法选择速览**

| 要回答的问题 | 优先使用的方法 | 编号 |
| --- | --- | --- |
| 突发的行业性利空 / 新闻，怎么先给出一版有层次的结论 | 先给结论，再按短期情绪 / 产业逻辑 / 公司基本面 / 定量测算分层评估 | 12.6.1 |
| 这场发布会或事件对估值逻辑到底有多重要 | 拆分市值中依赖新业务兑现的部分，给事件重要性定级 | 12.6.2 |
| 一个产业事件对客户、各家竞争对手和公司分别意味着什么 | 事件影响矩阵：客户、竞争对手（逐家）、公司本身 | 12.6.3 |
| 事件会不会改变供应商或同业的长期逻辑 | 推演事件对产业链其他玩家的竞争与估值影响 | 12.6.4 |
| 终端发布会 / 新品对哪些供应链公司是利好、哪些是利空 | 从发布会信息映射到供应链公司的受益和受损 | 12.6.5 |
| 巨头的一个动作会不会改变整个行业的供需周期 | 个股事件向行业供需的二阶推演 | 12.6.6 |
| 公司短期连续放出多个动作，哪一个才是真正超预期 | 连续多动作分层定性 | 12.6.7 |
| 市场对事件的第一反应是不是解读偏了 | 纠偏市场解读，用期权式表述结论 | 12.6.8 |
| 爆炸性事件背后，是叙事驱动还是底层动因 | 区分市场叙事与底层动因，用历史数据检验 | 12.6.9 |
| 利多不涨、利空猛跌，是不是窗口期问题 | 情绪窗口期下利多利空的非对称反应判断 | 12.6.10 |
| 以前有没有结构类似的事件，后来怎么走的 | 用结构相似的历史先例校准冲击的方向与概率 | 12.6.11 |
| 政策变化会不会带来需求溢出或增量 | 政策变化清单 → 借款人压力 → 需求溢出的推理链 | 12.6.12 |
| 已经发生和即将生效的政策，对业务量的影响有多大 | 政策变化对业务量的量化回溯与前瞻 | 12.6.13 |
| 行业政策对公司是利是弊 | 把行业政策变化映射到公司主力价格带 | 12.6.14 |
| 公司的商业模式能不能缓冲政策冲击 | 商业模式对政策冲击的缓冲分析 | 12.6.15 |

**推荐串联顺序**：先用 12.6.1 搭出分层结论的骨架，用 12.6.2 给事件定级；再用 12.6.3–12.6.6 把影响传导到客户、竞争对手、供应链与行业供需；然后用 12.6.7–12.6.11 校准判断（哪个动作真超预期、市场是否解读偏了、窗口期与先例）；政策与监管类事件改走 12.6.12–12.6.15。写作上始终把“对基本面的影响”和“对短期股价 / 叙事的影响”分开表达。

### 12.6.1 先给结论，再按短期情绪 / 产业逻辑 / 公司基本面 / 定量测算分层评估事件

- **方法要点**：对突发的行业性事件（尤其是利空），开篇先给出分层结论，再逐层展开论证，避免把“股价大跌”“产业逻辑受损”“公司基本面变差”混为一谈。
- **操作步骤 / 拆分口径 / 公式**：
  1. 开篇先给结论，分四层：
     - 短期情绪层：当日跌幅是否属于情绪宣泄过度。
     - 产业逻辑层：产业逻辑出现分歧后，能否马上修复，还是需要时间消化或新利好对冲。
     - 公司本身层：事件对公司利大于弊还是弊大于利；对估值（P/E）和对基本面拐点分别有什么影响。
     - 定量测算层：事件能带来多少基本面提振——给出带假设的测算，并标注“仅作参考”。
  2. 正文逐层展开论证，每一层对应开篇的一个结论。
  3. 把“对估值（P/E）的影响”和“对基本面拐点的影响”分开说：前者可能短期修复，后者要看其他变量（如内部大模型进展）验证。
- **关键指标与数据来源**：当日涨跌幅、估值（P/E）、事件带来的利润增量（带假设的测算）；来源为媒体报道、行情数据、公司披露。
- **判断标准**：
  - 情绪层：用事件对公司实际影响的大小去对照当日跌幅，跌幅明显大于实际影响即属于情绪宣泄过猛。
  - 产业层：产业逻辑的分歧需要时间消化，不会因为一篇点评就马上修正。
  - 公司层：利大于弊还是弊大于利，要同时回答对 P/E（短期估值修复）和对基本面拐点（中期验证）的影响。
  - 测算层：基本面提振要量化为利润增量比例；测算依赖假设，必须标注“仅作参考”。
  - 推理链条：事件 → 情绪是否过度 → 产业逻辑能否修复 → 对公司利弊 → 量化提振。
- **海豚案例**：
  - Meta《算力太贵，Meta 掀桌？》（2026-07-06）：彭博报道 Meta 计划对外出租算力，引发 AI 硬件和 Neocloud 下跌，存储也被恐慌下杀；海豚君的分层结论为：①情绪宣泄过猛；②不会马上修正；③对 Meta 利大于弊，短期修复 P/E，但反转拐点要看内部大模型和 Meta AI；④测算利润增量约 10%–15%（标注仅作参考）。
- **适用场景与注意事项**：适用于行业新闻引发的跨标的波动事件的快速点评；先出结论再论证，便于读者在开篇就拿到判断；测算只是带假设的量级参考，不能当作预测；对产业链其他玩家的传导见 12.6.4，行业供需推演见 12.6.6。

### 12.6.2 拆分市值中依赖新业务兑现的部分，据此给事件重要性定级

- **方法要点**：评估一场发布会或一个事件有多重要，先算“当前市值有多少依赖相关业务兑现”，再看这些业务各自的兑现阶段和基本盘压力，据此给事件定级。
- **操作步骤 / 拆分口径 / 公式**：
  1. 拆市值：算当前市值中依赖新业务（期权价值）兑现的部分。依赖占比 = 新业务隐含市值 ÷ 当前市值。
  2. 拆兑现度：在新业务内部区分各板块的兑现阶段——是已进入付费商用，还是仍处于早期试产。
  3. 看基本盘：叠加基本盘压力（毛利率环比变化、资本开支规模），判断新业务是否必须提供新的现金流支撑。
  4. 定级：依赖占比高、兑现阶段处于关键验证期、基本盘又承压，则事件对估值逻辑至关重要。
- **关键指标与数据来源**：当前市值；AI 业务隐含市值及占比；各 AI 业务的兑现阶段；基本盘毛利率；资本开支；来源为前期 SOTP、公司财报与指引。
- **判断标准**：
  - 依赖占比越高，事件越重要；占比近三分之二即属于“估值逻辑系于此”的级别。
  - 同一新业务内部兑现度差异大时，事件对兑现度高的板块影响更直接、更易验证。
  - 基本盘越承压，新业务越需要尽快提供现金流，事件的分量越重。
  - 推理链条：市值依赖度 → 各板块兑现度 → 基本盘压力 → 事件对估值逻辑的重要性。
- **海豚案例**：
  - 特斯拉《Cybercab 发布会：告别概念，开启 Robotaxi 大时代？》（2026-09-04，开篇）：特斯拉约 1.4 万亿美元市值中，近三分之二（约 1 万亿美元）依赖 AI 业务兑现；Robotaxi 是 AI 业务中兑现度远高于 Optimus 的板块（已进入付费载客阶段，Optimus 仍处早期试产）；叠加基本盘压力——26Q2 汽车毛利率 16.3%，环比下降 3 个百分点，2026 年资本开支预计超过 250 亿美元，Robotaxi 要提供新的现金流支撑；由此定性这场发布会对估值逻辑至关重要。
- **适用场景与注意事项**：适用于期权价值占比高的公司做事件前后的定级；需要有前期的 SOTP（见 9.6）作为拆分基础，否则无法算出“依赖占比”。

### 12.6.3 事件影响矩阵：客户、竞争对手（逐家）、公司本身三方

- **方法要点**：把一个产业事件拆到三类主体——客户、竞争对手（逐家）、公司本身——分别评估，避免只讲公司自己，并用产品线重叠度给竞争对手的受伤程度排序。
- **操作步骤 / 拆分口径 / 公式**：
  1. 客户：供应链结构怎么变；议价权如何体现；客户得到了什么（如认股权证福利）。
  2. 竞争对手：按产品线重叠度逐家评估；区分短期与中长期；区分真实影响与情绪影响。
  3. 公司本身：对业绩确定性和估值的影响。
  4. 排序：重叠度最高的竞争对手受伤最大。
  5. 用客户的分单历史和各对手相关收入所处阶段，校准对竞争对手的判断。
- **关键指标与数据来源**：产品线重叠度、客户分单历史、各对手相关收入所处阶段。
- **判断标准**：
  - 产品线重叠度越高，对手受损越大；重叠度低的对手，影响主要体现为情绪。
  - 短期看客户已有的订单与分单历史，中长期看客户是否把“让设计伙伴互相竞争”当作常态。
  - 要明确标注哪些影响是真实的（订单丢失），哪些只是情绪（股价反应）。
- **海豚案例**：
  - 高通《抱上亚马逊大腿…》（2026-09-09）：亚马逊由 Annapurna（2015 年收购，架构 owner）主导，Alchip（Trainium3/4）、Marvell（Trainium 存量、光 DSP、NIC / 存储控制器）、高通（新入）是三个外包方，形成“让设计伙伴互相竞争”的打法（去年已把 Trainium3 从 Marvell 切给 Alchip）；逐家评估：ALAB 受伤最大（Alphawave 产品线最接近）；Marvell 主要是情绪影响（第三方 DSP 竞争本来就激烈）；Alchip 短期不大、中长期风险不小。
- **适用场景与注意事项**：适用于产业链合作、丢单、新进入者等事件对多家上市公司的连带分析；协议条款本身的拆解见 12.4.4。

### 12.6.4 推演事件对产业链其他玩家的竞争与估值影响

- **方法要点**：事件分析要延伸到受影响的其他玩家，尤其是原来的大买家反过来加入供给侧竞争的情形；区分“对买方本身”和“对其供应商 / 同业”的不同影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先判断事件对买方（事件主体）本身的影响（见 12.6.1）。
  2. 再判断对依赖它作为客户的供应商和同业的影响：大买家反过来加入供给侧，会改变这些供应商的长期逻辑。
  3. 检查现有合同与签约规则：即便现有合同有履约保障，短期不受影响。
  4. 判断长期：供给侧新增竞争者带来的竞争加剧，会影响这些公司的逻辑和估值预期。
  5. 分开表述短期（履约）与长期（逻辑、估值）。
- **关键指标与数据来源**：客户集中度、合同条款、供给侧新增竞争者。
- **判断标准**：
  - 短期看合同：签约规则强势、履约有保障，则短期业绩风险有限。
  - 长期看格局：曾经的大买家变成竞争对手，不可避免地影响依赖其订单的公司的逻辑和估值预期。
  - 对买方是否因此调整投入（如是否暂停增加 Capex）若仍有争议，应如实说明分歧，而不是强行下结论。
- **海豚案例**：
  - Meta《算力太贵，Meta 掀桌？》（2026-07-06）：CoreWeave 有比较强势的签约规则，短期合同履约有保障，但长期下 Neocloud 不可避免会遇到曾经的大买家反过来加入算力租赁竞争；市场对 Meta 是否会因此暂停增加 Capex 仍有争议，但竞争加剧势必影响 Neocloud 的逻辑和估值预期。
- **适用场景与注意事项**：适用于产业链任何环节的事件传导分析；注意区分“合同层面的短期保障”和“竞争格局层面的长期影响”，二者结论可以相反。

### 12.6.5 从发布会信息映射到供应链公司的受益和受损

- **方法要点**：把对终端公司的判断传导到供应链，区分“出货量变化（影响全链）”和“新品新增部件（影响特定环节）”，分别映射到对应的供应商。
- **操作步骤 / 拆分口径 / 公式**：
  1. 判断终端出货预期的变化：例如存储涨价带来的整机涨价压力会抑制需求，影响总体出货预期。
  2. 把出货量变化映射到主力组装 / 主力供应商：出货量下降间接影响对该客户收入依赖度高的供应商。
  3. 识别新品新增的部件：新品明确增加某类部件的需求，利好对应环节的供应商。
  4. 逐家标注受益或受损，并参考供应商对该客户的收入依赖度。
- **关键指标与数据来源**：终端出货预期变化；新品新增部件；供应商对该客户的收入依赖度。
- **判断标准**：
  - 出货量变化是“全链”变量：影响所有供应商，对份额最大的主力组装商影响最直接。
  - 新增部件是“特定环节”变量：只利好提供该部件的供应商。
  - 两类变量可以方向相反，需分别判断后再合并为各家公司的净影响。
- **海豚案例**：
  - 苹果《苹果：存储暴涨逼提价，折叠屏能救场吗？》（2026-09-10）：存储带来的涨价压力会抑制需求，影响 iPhone 总体出货预期，间接影响立讯精密等主力组装供应商（受损）；iPhone Duo 如期发布，明确增加铰链等方面的需求，利好领益智造、安费诺等相关产业链（受益）。
- **适用场景与注意事项**：适用于苹果链、特斯拉链等大客户驱动的 A 股和港股供应链研究；发布会信息的二分（产业链影响 vs 公司自身增量）见 12.5.1；供应商对客户的依赖度需要查证，不能只凭“苹果链”标签。

### 12.6.6 个股事件向行业供需的二阶推演

- **方法要点**：跳出个体看行业——龙头公司的一个动作（角色转换、巨额融资）可能改变整个产业链的投资节奏和供需格局，据此更新全行业的供需缺口，并在个股点评结尾给出行业供需测算的预告。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别角色变化：例如从算力需求方变为供给方。
  2. 给出背景判断：如大模型边际效用提升递减；头部模型公司虽 ARR 持续增长，但可能出现“一超多强”的虹吸。
  3. 提出行业层面的问题：这是否会加速产业链投资见顶？
  4. 汇总各家的集中加码节奏：各家集中加码意味着 27、28 年是全球算力供给膨胀大年。
  5. 更新全行业算力供需缺口，判断硬件投产错配的窗口期红利还能持续多久、边际增量是否开始收敛。
  6. 个股点评结尾以行业供需测算作为下一篇预告。
- **关键指标与数据来源**：全行业算力供给（GW）、需求增速、供需缺口。
- **判断标准**：供给膨胀节奏快于需求增速时，错配红利期缩短、边际增量收敛，对上下游标的的判断随之下调；需要把个股事件与行业周期位置一起看。
- **海豚案例**：
  - Meta（2026-07-10，小结）：从算力需求方变为供给方，在大模型边际效用提升递减、Anthropic 虽 ARR 持续增长但可能一超多强虹吸的背景下，是否会加速产业链投资见顶？各家集中加码意味着 27、28 年是全球算力供给膨胀大年，因此需更新全行业算力供需缺口，判断硬件投产错配的窗口期红利还能持续多久、边际增量是否开始收敛；结尾以行业供需测算作为下一篇预告。
  - 谷歌《谷歌再借800亿，行情“续杯”还是泡沫“试金石”？》（2026-06-02）：从巨头融资推演到市场资金虹吸。
- **适用场景与注意事项**：适用于产业链龙头公司的事件分析，用于判断上下游标的；行业供需缺口的系统测算见 5.3。

### 12.6.7 连续多动作分层定性：常规准备 / 降本提 ROI / 真正超预期

- **方法要点**：公司在短期内连续释放多个动作时，逐个定性并排序，找出其中“真正超预期”的那一个；并把短期财务影响与叙事 / 估值影响分开表达。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出动作清单。
  2. 逐个定性并排序：
     - 扩建数据中心：最直接的准备工作（常规准备）。
     - 量产自研 ASIC：平衡成本以获得更高 ROI（降本提 ROI）。
     - 新模型发布：真正超预期——大模型能力是长期内生增长的直接体现，且能缓解组织问题担忧。
  3. 把短期财务影响（Capex 继续上提、EPS 承压）与叙事 / 估值影响分开表达。
  4. 指出资金会看淡前置投入的短期压力。
- **关键指标与数据来源**：动作清单、对 Capex / EPS 的方向性影响、对叙事的影响。
- **判断标准**：
  - 只推进既有计划的动作（扩建）算“常规准备”；通过降本提升回报的动作算“降本提 ROI”；直接体现长期内生增长能力、并能缓解市场担忧的动作才算“真正超预期”。
  - 财务端（Capex 上提、EPS 承压）与叙事端（模型能力）分开判断，两者方向可以相反。
- **海豚案例**：
  - Meta《过剩外租vs疯狂扩建，“精分”Meta背后是明晃晃的“阳谋”？》（2026-07-10）：三个动作（扩建、Iris 自研 ASIC 量产、Muse Spark 1.1 新模型）中，认定新模型为真正超预期；短期财务影响为 Capex 继续上提、EPS 承压，但资金会看淡前置投入的短期压力。
- **适用场景与注意事项**：适用于发布会、战略公告密集期的事件点评；定性排序要给出理由，否则容易沦为主观排名。

### 12.6.8 纠偏市场对事件的解读，用期权式表述结论

- **方法要点**：把市场对事件的直接解读（如“抢到了某核心大单”）和自己基于产业格局的判断对比；结论不全盘否定，而是把超预期的可能性表述为“期权”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 写出市场的直接解读及股价反应。
  2. 查客户现有的供应商结构：是否已有多年合作的主供和备胎供应商。
  3. 据此判断公司短期更可能拿到的产品范围——核心产品周边的配套，还是核心产品本身。
  4. 不全盘否定：把超预期的可能表述为期权——合作加深后“万一”拿到核心大单。
  5. 同时评价公司在竞争中的态度是否积极。
- **关键指标与数据来源**：客户现有供应商结构（主供 + 备胎）、公司可能获取的产品范围。
- **判断标准**：客户已有成熟的备胎供应商时，新进入者短期拿到核心大单的概率低，更可能是配套产品；后续的核心订单落地才能把“期权”转化为“确定性”。
- **海豚案例**：
  - Marvell《迈威尔 Marvell：“贴钱”结盟谷歌，能“撬动”博通墙角吗？》（2026-08-20）：市场把事件解读为 Marvell 抢夺谷歌 TPU 订单（Marvell 涨 10% 以上、博通下挫）；海豚君认为谷歌已在博通之外找了 MTK 做备胎（多年合作共研），Marvell 短期更可能拿到 TPU 配套而非 TPU 本身，后续可能有定制 MPU、TPU 配套芯片落地；超预期的部分只表述为期权。
- **适用场景与注意事项**：适用于股价因单一新闻大幅波动的事件；需要对客户的供应商格局有扎实了解；条款拆解与强弱判断见 12.4.1–12.4.3。

### 12.6.9 重大公司事件区分市场叙事与底层动因，用历史数据检验

- **方法要点**：面对裁员 40% 这类爆炸性事件，先列出管理层的动机，分别分析各动机对业绩和叙事的影响，再用历史数据检验哪个才是更底层的原因，提醒自己和读者冷静对待宏大叙事，并在下一季用业绩验证。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出管理层的动机：
     - a. 组织精简、回归创业氛围。
     - b. AI 工具让少人做更多事。
  2. 分别分析两种动机对业绩和叙事的影响：
     - a 带来费用下降和利润率提升。
     - b 切中 AI / 算力替代人力的宏大叙事，激发对经营杠杆的想象。
  3. 用历史数据检验：拉出员工总数与营收的时间序列，计算人均营收的变化。
  4. 判断哪一种才是更底层的原因，并提醒冷静对待 AI 叙事。
  5. 下一季再用业绩验证：裁员后业绩趋势是否依然向上、费用与利润率是否改善，减员提效的逻辑能否讲通。
- **关键指标与数据来源**：员工总数时间序列、营收时间序列、人均营收、裁员后的费用与利润率变化；来源为公司财报、员工人数披露。
- **判断标准**：
  - 若历史上人员扩张远快于营收增长（组织臃肿），则“精简组织”是更底层的原因，AI 叙事只是放大器。
  - 若裁员后业绩趋势依然向上、费用与利润率改善，则减员提效逻辑成立。
  - 推理链条：动机 a / b → 对业绩与叙事的不同影响 → 历史数据检验 → 判定底层动因 → 下季业绩验证。
- **海豚案例**：
  - Block《Block：美版支付宝暴力裁员 40%!…》（2026-02-27）：总员工从略超 1 万裁至约 6000 人；疫情期间员工从不到 4000 人扩到超 1.2 万人（增长 3 倍），而 2023–2025 年营收仅从约 220 亿增长到 240 亿，说明组织臃肿本来就需要精简；由此判断 a 才是更底层的原因，提醒冷静对待 AI 叙事。
  - Block《美版支付宝 Block：增长靠信贷…》（2026-05-08）：下一季验证——裁员后业绩仍维持向上，认为在 AI 帮助下减员提效逻辑能讲通。
- **适用场景与注意事项**：适用于裁员、并购、战略转型等引发叙事炒作的事件；叙事可以同时成立，但要分清主因和放大器；一次业绩验证不等于长期有效，需继续跟踪。

### 12.6.10 情绪窗口期下利多利空的非对称反应判断

- **方法要点**：判断事件对股价的影响时，不只看事件本身的强弱，还看事件所处的“窗口期”；并把“基本面影响有限”和“短期股价承压”两个结论分开表达。
- **操作步骤 / 拆分口径 / 公式**：
  1. 先评估事件对基本面的影响强弱。
  2. 再判断所处窗口期，逐项检查：
     - 板块逻辑是否脆弱（如软件股被大模型冲击）。
     - 是否处于财报前、资金谨慎的时点。
     - 估值是否偏高。
  3. 窗口期偏差时，利多不一定带动上涨，利空多半压制短期股价；估值较高时，市场更容易被风险叙事引导（如中大商家投放意愿疑虑）。
  4. 分开表达：“基本面影响有限”与“短期股价承压”是两个结论，不能互相替代。
- **关键指标与数据来源**：板块情绪、距财报时间、估值水平。
- **判断标准**：板块逻辑脆弱 + 财报前窗口期 + 估值偏高，三项叠加越多，利空越容易压制短期股价、利多越难兑现；三项均偏友好时，才可能出现事件的正常反应。
- **海豚案例**：
  - AppLovin（2026-01-20）：认为做空报告攻击力有限，但正值软件股逻辑脆弱、财报前窗口期，利空会压制短期股价；基本面结论与短期股价结论分开表达。
- **适用场景与注意事项**：事件驱动点评通用；需配合估值分位与资金面判断；做空报告本身的火力评估见 12.2.2。

### 12.6.11 用结构相似的历史先例校准事件冲击的方向与概率

- **方法要点**：多篇快评都用历史先例来判断事件后果：先找结构相似的先例，再说明本次与先例的异同，用先例的后续走势校准当前事件的冲击方向与概率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别当前事件的结构特征（如被列入清单、护城河迁移、景气扩产、合资融资）。
  2. 找结构相似的历史先例，记录先例的后续股价 / 行业结果。
  3. 说明本次与先例的异同，据此调整对方向与概率的判断。
  4. 警惕结构变化导致“这次不一样”。
  - 本组先例的四种用法：
    - 清单事件：CMC 清单——小米、腾讯曾被列入后又移出，恐慌下跌反而是买点。
    - 护城河迁移：社交护城河——微博、QQ → 微信的迁移，说明关系链并非不可迁移。
    - 周期纪律：NAND——景气时无序扩产导致价格暴跌的教训，解释当前的供给纪律。
    - 交易结构：Meta 数据中心 JV——类比此前的 Blue Owl 模式，判断结构与目的。
- **关键指标与数据来源**：先例事件及其后续股价 / 行业结果。
- **判断标准**：先例与本次的结构越相似（事件性质、参与方、市场环境），先例的后续走势越有参考价值；若本次存在先例中没有的新变量，需明确指出并下调先例的权重。
- **海豚案例**：
  - 《(短评)美国防部CMC清单乌龙》（2026-02-16，id 38746791）：以小米、腾讯曾被列入后又移出的先例，判断恐慌下跌反而是买点。
  - 《(短评)腾讯AI太安静》（2026-01-16，id 37878111）：以微博、QQ → 微信的迁移先例，说明社交关系链并非不可迁移。
  - 《(短评)NAND为何不放手扩产》（2026-01-23，id 38048048）：以景气时无序扩产导致价格暴跌的教训，解释当前的供给纪律。
  - 《(短评)Meta与BlackRock数据中心合资》（2026-07-28，id 42988695）：类比此前的 Blue Owl 模式，判断合资的结构与目的。
- **适用场景与注意事项**：通用；需警惕结构变化导致“这次不一样”；先例只能校准方向与概率，不能替代对本次事件的基本面分析。

### 12.6.12 政策变化清单 → 借款人压力 → 需求溢出的推理链

- **方法要点**：把影响市场结构的政策按时间线逐条列出，推导其对需求端的传导路径，用来推翻“规模停滞”的线性外推，并把结论量化为份额提升假设。
- **操作步骤 / 拆分口径 / 公式**：
  1. 按时间线列政策清单：用 a / b / c 逐条列出政策节点（含生效日期）。
  2. 推导传导路径：
     - 政策收紧公共供给 / 取消补贴 → 现有借款人还款压力上升 → 再融资需求提升。
     - 公共贷款额度压缩 → 新贷款需求溢出至私营机构。
  3. 推翻线性外推：原先“私营市场规模停滞在某水平”的判断，改为“有希望明显增长”。
  4. 写作上先列政策节点，再给因果结论，最后量化为份额提升假设。
  5. 区分一次性红利（“余温”）与长期结构性变化。
- **关键指标与数据来源**：政策生效时间、联邦贷款额度变化、再融资需求、私营机构新增贷款；来源为政策文本、公司与行业披露。
- **判断标准**：政策是否真的改变了供给结构（公共供给收紧、额度压缩）；传导路径是否完整（压力 → 需求 → 向私营机构转移）；一次性红利会随时间消退，长期结构性变化才能支撑份额的持续提升。
- **海豚案例**：
  - SoFi《槽点多多的 SoFi，“贵” 得有理？》（2026-06-29）：列出三项政策——2023 年联邦校园贷恢复还款还息、2025 年 8 月 SAVE 计划终结、2026 年 7 月 OBBBA 法案取消 Grad PLUS 并压缩联邦研究生贷款额度；推导私营学贷占比从 8% 升至 10%+，并作为 SoFi 短期看点（学贷政策红利）。
- **适用场景与注意事项**：适用于受政策驱动的金融、医疗、教育、新能源等行业；需区分一次性红利（“余温”）与长期结构性变化；政策影响业务量的量化回溯见 12.6.13。

### 12.6.13 政策变化对业务量的量化回溯与前瞻（恢复计息、借款上限）

- **方法要点**：对已发生的政策，用历史数据回溯它对业务量的影响幅度；对即将生效的政策，用历史数据估算受影响的范围；再叠加公司的市场份额，判断公司能承接多少。
- **操作步骤 / 拆分口径 / 公式**：
  1. 回溯已发生的政策：
     - 2023 年 9 月联邦贷款恢复计息（到 2024 年 9 月是一年缓冲期），还款压力推动再融资需求快速回暖。
     - SoFi 学生贷款单季签发从 2023 年上半年约 4 亿 / 季，增到 2025 年下半年 15 亿以上 / 季，约 3 倍。
  2. 前瞻即将生效的政策：《大美丽法案》7 月起执行校园贷借款上限；回溯历史数据，有 38% 的学生借款人超过上限，预计会有更多溢出需求。
  3. 看份额：公司校园贷再融资余额（包括表内和已转售但仍代为服务的部分）占私人再融资市场约 50%，是绝对龙头，因而是主要承接方。
  4. 看占比：截至 1Q26，学生贷款余额超过总贷款余额的 1/3。
- **关键指标与数据来源**：单季签发额、超上限借款人比例、市场份额、学生贷款余额占比；来源为公司财报、政策文本、历史借款数据。
- **判断标准**：回溯到的签发增幅（约 3 倍）说明政策对业务量的弹性；超上限比例（38%）说明前瞻性溢出需求的范围；份额（约 50%）说明龙头能承接多少；业务占比（超 1/3）说明政策对公司整体的重要性。
- **海豚案例**：
  - SoFi《被浑水盯上的 SoFi：真金科新贵 or「高科技噱头」？》（2026-06-16）：学生贷款单季签发约 3 倍（约 4 亿 / 季 → 15 亿以上 / 季）；回溯历史数据，38% 的学生借款人超过《大美丽法案》的借款上限；校园贷再融资余额占私人再融资市场约 50%；1Q26 学生贷款余额超过总贷款余额的 1/3。
- **适用场景与注意事项**：适合受政策驱动的金融和教育类公司，用历史数据回溯政策影响的范围；政策节点的梳理与传导链见 12.6.12。

### 12.6.14 把行业政策变化映射到公司主力价格带

- **方法要点**：把宏观和行业政策落到公司的销量结构上——政策影响哪个价格带，公司在这个价格带的销量占比多高，从而得出净影响方向。
- **操作步骤 / 拆分口径 / 公式**：
  1. 梳理政策要点：新能源汽车购置税退坡；新一轮国补更倾向 16.7 万元以上中高价车型，15 万元以下（尤其 10 万元以内）车型能拿到的补贴比 2025 年明显减少。
  2. 找出受政策影响的价格带，并与公司的主力价格带对照：这恰好是比亚迪的主力价格带。
  3. 取公司在该价格带的销量占比，得出政策对公司的净影响方向。
  4. 与发布会等其他信息合并，形成销量判断。
- **关键指标与数据来源**：补贴门槛价格（16.7 万元）；购置税政策；公司各价格带销量占比。
- **判断标准**：政策收紧的价格带与公司主力价格带重合度越高、该价格带销量占比越大，净影响越负面；推理链条：政策变化 → 影响的价格带 → 公司在该价格带的销量占比 → 净影响方向 → 与发布会信息合并形成销量判断。
- **海豚案例**：
  - 比亚迪《比亚迪：“颠覆性”发布会，能“颠回”宇宙车厂吗？》（2026-03-06）：国补倾斜中高价车型，对比亚迪的主力价格带不利；与发布会信息（缺席项）合并后，形成国内销量下滑约 10% 的判断。
- **适用场景与注意事项**：适用于受政策补贴影响大的消费品行业（汽车、家电）；需要公司分价格带的销量结构数据；发布会缺席项的识别见 12.5.3。

### 12.6.15 商业模式对政策冲击的缓冲分析（BaaS 降低购置税计税基数）

- **方法要点**：分析公司独特的商业模式如何改变宏观政策对它的冲击：同样的政策，因商业模式不同，对公司和对同业的实际影响可以不一样；并用渗透率衡量这种缓冲的覆盖面。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别政策变化的作用机制（如购置税退坡）。
  2. 检查公司商业模式是否改变了政策的计税或补贴基数（如电池租用模式下，电池不计入购车发票，计税价格基数大幅降低）。
  3. 对比用户承担的税负与同级竞品：用户税负低于同级竞品，则可以对冲部分行业逆风。
  4. 用渗透率衡量缓冲的覆盖面（采用该模式的用户占比）。
  5. 补充其他缓冲：换电模式持有低价电池库存，可以缓冲电池涨价。
- **关键指标与数据来源**：BaaS 渗透率、购置税率变化、计税价格差。
- **判断标准**：缓冲幅度 = 同级竞品税负与自身税负之差，覆盖面 = 渗透率；渗透率越高，缓冲越普遍；缓冲只是相对优势，不改变行业整体需求方向。
- **海豚案例**：
  - 蔚来（2026-03-10、2026-05-21、2026-09-01）：在 2026 年新能源大盘受购置税退坡拖累的背景下，BaaS 模式优势凸显——电池不计入购车发票，计税价格基数大幅降低，用户承担的税负低于同级竞品；2026-09-01 补充 BaaS 渗透率已超过 80%；另外换电模式持有低价电池库存，可以缓冲电池涨价（2026-05-21）。
- **适用场景与注意事项**：适用于政策影响大的行业；缓冲效应只是相对优势，不改变行业整体需求方向；评估时要同时看渗透率，否则容易高估缓冲效果。

**相关方法（详见他节）**：分地区收入占比跟踪与关税 / 免税政策冲击映射，详见 3.3。

**本节速查清单**

- [ ] 是否开篇先给分层结论：短期情绪是否过度、产业逻辑能否修复、对公司利弊与 P/E / 基本面拐点、定量测算（标注“仅作参考”）。
- [ ] 是否给事件定级：市值中依赖新业务兑现的部分、各业务兑现阶段、基本盘压力（毛利率、资本开支）。

- [ ] 二阶影响是否覆盖：供应商 / 同业的长期逻辑与估值（区分合同短期保障与竞争长期影响）、供应链映射（出货量变化 vs 新增部件）、行业供需缺口更新。
- [ ] 连续多个动作是否逐个定性并排序，短期财务影响与叙事 / 估值影响是否分开表达。
- [ ] 市场的直接解读是否对照了客户现有供应商结构（主供 + 备胎），超预期是否以期权式表述。
- [ ] 爆炸性事件是否区分叙事与底层动因，并用历史数据（人数、营收、人均营收）检验、下季业绩验证。
- [ ] 是否考虑窗口期（板块情绪、距财报时间、估值水平），并把“基本面影响有限”与“短期股价承压”分开表达。
- [ ] 是否找了结构相似的历史先例并说明异同，警惕“这次不一样”。
- [ ] 政策类事件是否检查：政策时间线与生效日、传导链、历史回溯量化、主力价格带映射、商业模式缓冲与渗透率，以及一次性红利 vs 长期结构变化。
