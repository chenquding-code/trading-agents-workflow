# 第10章 估值判断：隐含预期、情景与折溢价

> **本章目的**：在具体估值方法之上做判断：价格里隐含了什么预期，不同情景下的上下限和赔率是多少，估值为什么折价或溢价，定价锚是否正在切换。

**本章小节**：10.1 反向估值与隐含预期｜10.2 情景估值与上下限测算｜10.3 估值折溢价、定价锚与框架切换

---

## 10.1 反向估值与隐含预期

> 本节导读：本节回答“当前价格里已经装进了什么预期”。做法是先不预测，而是从市值、EPS指引中值、远期FCF与收入、可比倍数出发，倒推隐含的增速、ARR、利润率修复、变现率或剩余业务的定价，再与自己的判断、对标公司的成长路径比较，看预期是合理、过满还是已经被price in。财报后股价大涨大跌、需要判断“好公司是不是好击球区”、或高估值股需要识别“priced for perfection”时使用；DCF框架内的反推验证见9.8，分部估值的正向做法见9.6，反推结果再落到上下限与赔率见10.2。

### 10.1.1 SOTP反推：市值扣除已估值资产，得到剩余业务的隐含定价

**方法要点**：集团里有一块业务已经有外部估值锚，或能用成熟倍数可靠估值时，用总市值（或EV）减去这部分价值，剩余部分就是市场隐含给“真正要研究的那块业务”的定价；再把这个隐含定价与干净口径的利润、正常倍数或自己的中性假设对比，判断这块业务是被低估、被错杀，还是已被计入。这是SOTP（分部估值，正向做法见9.6）的反方向用法。

**操作步骤 / 拆分口径 / 公式**：

*变体 A：减去子业务权益价值，反推隐含主业估值与隐含PE（子业务有融资估值或传闻上市估值时）*

1. 取子业务的外部估值锚（融资估值、投后估值或传闻中的上市/拆分估值）。
2. 计算集团可归属的子业务权益价值：子业务权益价值 = 子业务估值 × 持股比例 ×（1 − 控股折价）。控股折价取值如50%，用来反映持股比例下降和内部交叉销售等因素（通常在30%~50%，需要说明取值理由）。
3. 隐含主业估值 = 集团市值 − 子业务权益价值。
4. 把主业利润还原为干净口径：剔除为子业务新增的折旧（如为支持子业务投入的算力折旧）、不含其他收益、按15%有效税率算税后，得到主业税后核心经营利润。
5. 隐含PE = 隐含主业估值 ÷ 主业税后核心经营利润，与同业和历史对照，判断主业是否被低估。

*变体 B：减去成熟业务估值，得到被叙事冲击业务的隐含PS（股价暴跌后判断是否被错杀）*

1. 取股价暴跌后的最新市值。
2. 对未受叙事冲击的成熟业务按合理倍数估值（如广告业务按20倍2026年调整后EBITDA）。
3. 市值减去上一步，得到被冲击业务的隐含估值；除以该业务2026年收入，得到隐含PS。
4. 与该业务“正常应有的PS”（如8倍）对比；同时列出分业务的一致预期增速作背景，判断增长是否真的配得上惩罚性估值。

*变体 C：EV减去各分部估值与战略资产，得到市场隐含的高弹性业务（平台业务）定价*

1. EV = 当前市值 + 净负债。
2. 减去已用倍数法估出的各重资产业务价值，再减去单独估值的战略资产（如海外数字资产）。
3. 剩余部分就是市场隐含给高弹性轻资产业务的定价。
4. 与自己的中性假设对比：若基本持平，则该业务对当前估值是“上行期权”而不是“当前支柱”，不宜过早计入乐观情形；反之若隐含定价明显低于自己的中性假设，说明该业务尚未被充分计价。

**关键指标与数据来源**：集团市值或EV（含净负债）、子业务外部估值（融资公告、市场传闻、一级市场估值）、持股比例、控股折价率、主业或成熟业务的核心经营利润/EBITDA、有效税率、分部倍数、被冲击业务的收入、一致预期增速与产业调研。

**判断标准**：
- 变体A：隐含PE明显低于同业和历史（案例中不足8倍、约9x+）→ 说明市场几乎只在给子业务定价、把主业近似“白送”→ 绝对估值偏低。推理链条是“外部锚 → 打控股折价 → 剩余即主业 → 干净利润 → 隐含PE”，每一环的取值都要写明理由。
- 变体B：隐含PS显著低于正常PS（4倍对8倍）→ 市场已把“传统软件被AI颠覆”的叙事打成惩罚性估值 → 存在错杀可能。
- 变体C：隐含定价与中性假设“基本持平”→ 平台业务只是上行期权。
- 三种变体的共同前提：被扣除部分的倍数/估值是关键假设，要明示并做敏感性（倍数偏高会压低隐含值）。

**海豚案例**：
- 快手《快手：老铁翻身，就靠“可灵”了》（2026-05-27）：250亿美元市值，可灵传闻以200亿美元估值拆分，打50%折价，隐含主业不到150亿美元；主业剔除110亿算力投入的折旧影响后，核心经营利润约155亿，按15%税率得税后132亿，对应PE不足8倍，判断绝对估值明显偏低。
- 快手《“熟透”的快手，全村希望都在可灵上了！》（2026-08-19）：市值209亿美元，可灵按180亿美元投后估值×63%股权×50%折扣=57亿美元，剩余主业约150亿美元，对应2026年税后经营利润约9x+ PE。
- Unity《血洗游戏股，谷歌打出“灭霸”响指？》（2026-02-02）：周五收盘市值约125亿美元；先给Grow（广告）业务按20倍2026年调整后EBITDA估值约100亿美元，剩余Create（引擎）业务只对应约25亿美元，相当于2026年收入的约4倍PS，而正常应为约8倍PS，结论是市场已打入“传统软件被AI颠覆”叙事下的惩罚性估值。一致预期背景：2026年Unity收入预计反弹10-15%，其中广告接近20%、引擎稳定在约13%；调研显示Vector带动Q4游戏份额略升，但IronSource仍拖累，整体增长体现较慢。
- 沃尔玛《沃尔玛：老兵不老，重估路还能走多长？》（2026-06-10）：市值约9500亿美元+净负债约350亿=EV约9850亿；扣除门店零售、山姆、国际线下合计约7235亿与印度数字资产383亿，市场隐含平台定价2232亿，与中性假设2355亿基本持平，说明平台业务目前是上行期权而非估值支柱（该文对应的三层价值框架见10.3.17）。

**适用场景与注意事项**：变体A适用于有可分拆子公司、外部融资或上市定价的集团；变体B适用于多业务公司在单一业务遭叙事冲击时判断是否错杀；变体C是SOTP的配套检验。三者的结论都强依赖被扣除部分的估值假设（分部倍数、控股折价），倍数偏高会压低隐含值，必须说明取值理由；外部估值锚若只是传闻，要在文中标明；主业利润要先做干净口径还原再算隐含PE，否则会被子业务投入和其他收益扭曲。

### 10.1.2 用P/FCF、P/S反推当前价格隐含的业务假设

**方法要点**：用当前市值除以远期FCF和远期收入，得到P/FCF与P/S，再倒推这个溢价里隐含了哪些乐观假设，并与自己对这些假设的判断比较，识别“priced for perfection”（需要为梦想买单）的高估值成长股。

**操作步骤 / 拆分口径 / 公式**：

1. 取远期年份（如27年）的FCF和收入预测，计算：P/FCF = 市值 ÷ 远期FCF；P/S = 市值 ÷ 远期收入。
2. 问“要撑起这个倍数，市场必须相信什么”，把乐观假设逐条写出（如电商Agent帮助份额提升、GMV维持高增长、变现方式从约3%的支付型变现切入高个位数到10%以上的佣金型变现）。
3. 逐条与海豚君自己的判断对照（如中短期贡献有限），得出“已计价 vs 可兑现”的差距。
4. 结论表达：估值太贵、需要为梦想买单，或“不是喜欢的类型”。

**关键指标与数据来源**：市值、远期（27年）FCF、远期收入、P/FCF、P/S、变现率假设（支付型约3% vs 佣金型高个位数至10%+）、GMV增速；数据来自财报、一致预期与管理层指引。

**判断标准**：倍数本身高不是结论，关键是溢价对应的假设是否是自己判断中“中短期难以兑现”的假设。若隐含假设依赖尚未验证的商业模式切换（如从支付型变现切到佣金型变现），则溢价属于期权定价，不应当作确定性计入。

**海豚案例**：
- Shopify《业绩不俗却暴跌》（2026-02-12）：市值1430亿，对应27年约35亿FCF约40x，对应27年约180亿收入约8x P/S；当前溢价隐含了切入佣金型变现的假设，海豚君判断中短期难以兑现，“不是喜欢的类型”。

**适用场景与注意事项**：适用于高估值成长股，识别“priced for perfection”。需要把乐观假设写具体、可验证，而不是只说“估值贵”；倍数是否贵还要与历史区间和同业比较（见9.2、9.3）。

### 10.1.3 EPS指引中值×PE：反推市场已计价的远期利润率修复

**方法要点**：对转型期、市场给予高估值的公司，用上调后的EPS指引中值直接算当前PE；PE显著偏高时，反推市场已经提前计价了哪一条远期利润率修复路径，据此判断当前该观望还是买入。

**操作步骤 / 拆分口径 / 公式**：

1. 取公司最新上调后的EPS指引中值，PE = 当前股价 ÷ EPS指引中值（如盘后价格对应当年财年）。
2. 判断PE偏高后，倒推：要让这个PE在未来几年回落到合理区间，经营利润率必须修复到什么水平、需要多久（如到2028年经营利润率从11%修复到13.5%-15%）。
3. 比较市场计价的修复路径与自己对管理层路径可达成性的判断（可达成性验证见8.5），决定观望或买入。

**关键指标与数据来源**：EPS指引中值、股价、PE、远期经营利润率目标（管理层给出的修复区间）。

**判断标准**：若当前PE已经高到只有“利润率完全修复”才能消化，则市场已“提前”给了修复溢价，此时进场只赚超预期的钱，建议观望；买点应等待估值回到与修复进度相匹配的位置（击球区的表达见14.2）。

**海豚案例**：
- 星巴克《星巴克：走出至暗时刻…》（2026-07-30）：按EPS指引中值2.6美元，盘后109美元对应FY26约42x，意味着市场已提前计价2028年经营利润率修复至13.5%-15%（当前约11%），建议观望。

**适用场景与注意事项**：适用于转型期、市场给予高估值的公司；EPS指引中值本身可能被管理层保守设定或受一次性因素影响，要结合指引可达成性（8.5）核对。与10.1.6“当前价=积极情景完全兑现”配合使用。

### 10.1.4 用可比倍数从市值倒推隐含ARR与隐含增速

**方法要点**：对估值远超当前基本面的热门股，用可比公司的P/ARR倍数把当前市值倒推成“隐含ARR”，再结合当前已知ARR和时间窗口，算出隐含的月环比增速（m/m），判断这个增速是否现实。也可以正向给出参照系，比较二者。

**操作步骤 / 拆分口径 / 公式**：

1. 选可比公司及其对应阶段的P/ARR倍数。
2. 隐含ARR = 当前市值 ÷ 可比P/ARR。
3. 隐含月环比增速：以当前已知ARR为起点、隐含ARR为终点，按预期兑现的时间窗口折算成月均复合增速（m/m）。
4. 正向参照系：假设复制对标公司的节奏，在给定时间内把ARR做到某个规模，在对标倍数下对应多少估值，再与当前市值比较（上一轮估值的参照系可作为锚）。
5. 对照现实：隐含增速是否超过了任何已知可比公司在任何阶段的增速。

**关键指标与数据来源**：市值、可比P/ARR、隐含ARR、隐含m/m增速、公司官方披露的ARR（年报或公告）、对标公司的ARR成长路径。

**判断标准**：隐含增速远超可比公司的实际增速（如m/m 150% vs 对标的12%~30%）→ 估值显然不现实、市场在定价远超基本面的预期。可比倍数与可比阶段的选择决定结论，需要写明。

**海豚案例**：
- 智谱《智谱：万亿市值，国产 Anthropic 真来了？》（2026-06-22）：上一篇的参照系是用约一年（m/m约12%）把ARR做到10亿美元，在Anthropic倍数下约600亿美元估值；当前市值已达1500亿美元，倒推隐含ARR约40亿美元，对应3—6月内的m/m高达150%，显然不现实。

**适用场景与注意事项**：适用于估值远超基本面的热门股，判断市场隐含了什么；P/ARR只适用于ARR口径清晰的订阅/API类业务；倍数取自对标公司时，对标所处阶段必须匹配。第一步倒推不现实后，进一步用10.1.5拆成多层预期，乐观情景的检验见10.2.8。

### 10.1.5 用对标公司成长期路径，把估值拆成多层隐含预期

**方法要点**：第一步反推出的隐含增速不现实时，退一步用对标公司在可比阶段的实际增速路径检验：先假设目标公司“当前已经达到某个ARR”（并算出这本身隐含的过去几个月增速），再按对标增速向后跑若干月，看能否对上当前市值。这样把估值拆成两层（或多层）隐含预期，与公司官方披露的数据对比，判断预期是否“过于饱满”。

**操作步骤 / 拆分口径 / 公式**：

1. 第一层：假设当前ARR已达到某一规模（高于官方披露），算出这一假设本身隐含的过去几个月m/m。
2. 第二层：按对标公司同阶段的m/m向后推若干个月，得到未来某时点的ARR。
3. 在对标倍数下，把第二层的ARR换算成市值，看是否大体对上当前市值。
4. 把第一层的假设ARR与公司官方披露的ARR对比，差距就是“预期过于饱满”的部分。

**关键指标与数据来源**：官方ARR（年报）、假设ARR、隐含过去m/m、对标未来m/m、对标倍数。

**判断标准**：若要对上当前市值，需要同时满足“当前ARR远高于官方数字”和“未来仍按对标最快阶段增长”两层假设，则估值是在为两层乐观预期同时买单，预期过满。

**海豚案例**：
- 智谱《智谱：万亿市值，国产 Anthropic 真来了？》（2026-06-22）：Anthropic从10亿到50亿美元ARR用了近半年，m/m约30%；若智谱当前ARR已达10亿美元（隐含过去三个月m/m近60%），再以30% m/m跑半年到约50亿，在Anthropic倍数下大体对上1500亿市值；而智谱最近年报披露的官方ARR只有2.5亿美元。

**适用场景与注意事项**：适用于成长股估值合理性检验；关键是对标阶段要匹配（规模、行业、商业模式相近），否则增速路径不可比。

### 10.1.6 “当前价=积极情景完全兑现”的隐含预期判断与赔率表达

**方法要点**：当自己的估值结果与现价重合、而所用假设又偏积极时，判断市场已提前计价乐观剧本，把结论表达为赔率不佳，并给出明确买点以留足安全边际。

**操作步骤 / 拆分口径 / 公式**：

1. 先坦承自己的预测是否偏积极（假设是否取了积极端）。
2. 比较积极情景下的公允价值与现价：若二者重合，说明现价=积极情景完全兑现。
3. 推演两侧结果：买入只能赚“超预期”的钱；下行则要承担修复被证伪的“双杀”（业绩+估值）风险→赔率不佳。
4. 给出击球区：在历史估值区间下沿（如25x）对应价位再考虑，以留足安全边际。
5. 结论表达固定为：“好公司，但不是好的击球区”。

**关键指标与数据来源**：现价、积极情景公允价值、历史区间下沿PE、对应价位。

**判断标准**：现价≈积极情景公允价值 + 市场共识已偏乐观 → 赔率不佳；估值回落到历史区间下沿才进入可考虑区间。

**海豚案例**：
- 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：现价与积极情景估值重合，判断市场已提前计价乐观剧本，建议25x/约89美元再入手。

**适用场景与注意事项**：适用于市场共识已较乐观的困境反转股；关键是先坦承自己的预测是否偏积极，再判断现价隐含了什么。与10.1.3（用EPS指引中值和PE反推计价的修复）、10.2（情景上下限）配合，最终表达见14.1、14.2。

### 10.1.7 增量经营利润×目标PE折现：股价弹性排序，并对照近期涨幅判断是否已price in

**方法要点**：事件驱动下，对拿到“纯增量”的几家公司，用增量经营利润乘目标PE再折现，得到市值增厚和股价弹性，排出弹性顺序；再把这个顺序与近期实际涨幅的顺序对照，若一致，说明事件基本已反映在股价里。

**操作步骤 / 拆分口径 / 公式**：

1. 设定增量业务收入与经营利润率（案例中Agent CPU业务取25%）：增量经营利润 = 增量收入 × 经营利润率。
2. 给目标PE（按公司属性：如ARM给25倍，高通给20倍）。
3. 折现：市值增厚 = 增量经营利润 × 目标PE ÷ (1+折现率)^n，折现率如11%；折现年数需自行设定（文中未显式写出年数；按案例数字反推，ARM的25亿×25倍≈625亿折回约410亿、高通的10亿×20倍=200亿折回约130亿，大致对应约4年的折现期）。
4. 股价弹性 = 市值增厚 ÷ 当前市值。
5. 对各家公司按弹性排序，并加入定性修正（如ARM除了卖芯片还能卖核心IP，弹性更大）。
6. 与近期（如上一周）各股涨幅排序对照：顺序一致 → 增量需求基本已在股价里；顺序不一致 → 存在预期差。
7. 把后续跟踪变量写清：增量能否继续把蛋糕做大，谁能抢到额外份额。

**关键指标与数据来源**：增量收入、经营利润率25%、目标PE（25x/20x）、折现率11%、市值增厚、股价弹性、近期涨幅。

**判断标准**：
- ARM：100亿美元收入 → 25亿经营利润；25倍PE、按11%折现 → 估值增厚约410亿美元以上，股价弹性约15%（ARM还能卖核心IP，弹性更大）。
- 高通：40亿 → 10亿经营利润；20倍PE、同样11%折现 → 估值增厚约130亿美元，股价弹性约6%。
- 综合弹性排序：ARM（15%）>英特尔/AMD（10%）>高通（6%）>英伟达（3%）。
- 这个排序和上周各股涨幅的排序一致，所以判断Muse带来的Agent CPU需求基本已反映在股价里；后面要看Agent能否继续把服务器CPU这块蛋糕做大，以及谁能抢到额外份额。

**海豚案例**：
- Muse/CPU《Muse“爆火”…》（2026-09-28）：以上述口径对ARM、高通、英特尔/AMD、英伟达做弹性排序，并与上周涨幅对照，判断已price in。

**适用场景与注意事项**：适用于事件驱动下的个股弹性比较。远期利润折现对目标PE和折现率非常敏感，需做敏感性；增量收入和利润率假设是主观输入，要说明来源；弹性排序与涨幅排序“一致”只是已price in的间接证据，还需结合后续份额争夺（竞争格局见第6章）。

**交叉引用**：情景估值与“反推当前估值隐含增速”（下调某业务假设、算净利润、再反推PE隐含的利润增速）的做法，详见10.2.6；在DCF框架内做的反推验证，详见9.8；反推出的隐含预期如何转为上下限与赔率，见10.2。

**本节速查清单**
- [ ] 先明确要倒推的是哪一个变量（隐含增速、隐含ARR、隐含利润率修复、隐含主业估值/PS、隐含变现率）。
- [ ] 分部扣除法：被扣除资产的外部估值锚或倍数是否有依据；控股折价是否说明理由（30%~50%）。
- [ ] 主业或剩余业务的利润是否已还原为干净口径（剔除为新业务新增的折旧、不含其他收益、税率写明）。
- [ ] 隐含倍数（PE、PS、P/ARR）是否与同业、历史、对标公司同阶段对比。
- [ ] 隐含增速或隐含ARR是否与公司官方披露数据、对标公司的实际成长路径对照，并拆成多层预期。
- [ ] 当现价≈积极情景估值时，是否先坦承自己的假设偏积极，并给出具体的击球区（价位与PE）。
- [ ] 事件驱动场景：是否算出增量经营利润×目标PE折现后的股价弹性，并与近期涨幅排序对照。
- [ ] 隐含预期的结论是否落到“与自己判断的差距”，而不只是“贵/便宜”。

## 10.2 情景估值与上下限测算

> 本节导读：本节回答“估值的下限、中枢、上限分别在哪，赔率和胜率如何”。海豚君的做法是围绕最敏感的变量搭建2~4档情景，逐一写明假设、估值、峰值倍数和相对现价的空间，并专门设计悲观（底价）和乐观（上限）情景，最后把向上与向下空间作为赔率判断的输入。适用于业绩难预测的强周期股、期权型新业务占比高的公司、早期成长股与核心/新业务并存的集团；各情景里用到的具体估值方法见第9章，反向倒推隐含预期见10.1，估值折溢价与定价锚切换见10.3，结论与击球区表达见第14章。

### 10.2.1 四情景估值：中性/悲观/极度悲观/乐观，逐一写明“假设→估值→峰值倍数→空间”

**方法要点**：不确定性高、结果分布宽的公司，用统一的四要素模板写出四个情景，使每个情景的假设、估值、倍数和空间可比，并汇总成向上/向下空间，作为赔率判断的输入。悲观情景刻意区分“盈利下修”和“估值去溢价”两种不同来源。

**操作步骤 / 拆分口径 / 公式**：

1. 每个情景统一写四要素：①基本假设（缺口、价格见顶年份、长协履约等关键变量）；②估值（跨周期净利润 × 倍数）；③对应的峰值净利润倍数（估值 ÷ 峰值年净利润）；④相对现价的空间。
2. 情景设计：
   - 中性：基准情景。
   - 悲观：盈利照常兑现，但估值“去溢价”，也就是市场把本轮行情当作一次性超级周期来定价，用存储股历史估值下沿倍数。
   - 极度悲观：重新设定ASP路径、bit增速和长协重谈，用来揭示存储股在周期反转时的真实下行空间（概率低）。
   - 乐观：管理层“熨平周期”模型兑现。
3. 估值 = 跨周期净利润（多年均值）× 倍数；再反算对应的峰值年净利润倍数，用来对照历史周期顶部的估值水位。
4. 汇总向上、向下空间，形成赔率判断（与10.2.12的上下行非对称判断配合）。

**关键指标与数据来源**：各情景的ASP、bit增速、净利润路径、跨周期净利润、PE倍数、市值/每股价值、相对现价空间；数据来自公司指引与长协、行业价格与供需模型、历史估值区间。

**判断标准**：
- 悲观情景：跨周期净利润给8—10x（存储股历史估值下沿）→ 区分出“盈利没问题但估值去溢价”的下行。
- 极度悲观：靠重设价格路径和长协重谈得到真实下行空间，因概率低只作为尾部风险边界。
- 乐观：只在管理层“熨平周期”模型被证实时成立。
- 看向上与向下空间的比例：向下幅度显著大于向上，则赔率不佳。

**海豚案例**：
- 闪迪《AI 改不了“DNA”…》（2026-10-06）：
  - 悲观：跨周期净利润给8—10x，市值约1275—1593亿（FY28峰值的3—3.8x），较现价-36%~-49%。
  - 极度悲观：设紧缺2027H1结束，ASP 0.31/0.22/0.13/0.10，bit增速12%~15%，净利265/187/88/55亿，FY30毛利率约49%；九年均值约75亿×8—12x=600—900亿（每股410—615美元），-64%~-76%（FY27峰值的2.3—3.4x）。
  - 乐观：FY30净利约508亿，跨周期约194亿×18—20x=3485—3870亿（FY30E的6.9—7.6x），+40%~55%。

**适用场景与注意事项**：适用于不确定性高、结果分布宽的公司（存储等强周期股）；悲观情景要把“盈利下修”与“估值去溢价”分开写，否则无法判断下行来自哪里；极度悲观情景概率低，不应当作基准；每个情景的关键假设要能被后续数据验证或证伪（跟踪见13.2）。

### 10.2.2 双情景：集团整体利润（含新业务亏损）vs 核心板块利润，并推演两种定价的收敛路径

**方法要点**：核心业务盈利、新业务亏损并存的公司，同时算两个口径的PE：按集团整体利润（含新业务亏损）和按核心板块利润；两种口径对应两类资金的定价方式，并推演二者如何随新业务减亏而收敛，每季更新两个核心预测数字。

**操作步骤 / 拆分口径 / 公式**：

1. 保守情景：集团整体利润 = 核心商城经营利润 − 新业务亏损（不加回SBC），PE = 市值 ÷ 集团利润；论点是“市场并未纳入新业务亏损”来定价，严格看可下行到10x。
2. 中性情景：以核心商城的经营利润为基准算PE，再加上股东回报（回购+分红）对市值的托底。
3. 修复路径：新业务减亏后，按集团利润定价的保守资金会逐步向按核心利润定价靠拢，估值有望从约6x修复到8-10x。
4. 每季只更新两个核心预测数字：商城全年利润和新业务亏损；据此重算集团利润和两个口径的PE。

**关键指标与数据来源**：商城经营利润预测、新业务亏损预测、集团经营利润、市值、PE（两种口径）、回购加分红占市值比例。

**判断标准**：
- 两种口径的PE差距越大，说明市场分歧越大；新业务减亏是两种定价收敛的核心催化。
- 若按集团利润的PE偏高（如16x），而按核心利润的PE偏低（如5.5x），说明价格取决于市场用哪一种口径定价，需看新业务亏损的趋势。
- 回购加分红占市值的比例可作为核心口径下估值的托底。

**海豚案例**：
- 京东（2026-03-05）：集团净利润约200亿以上，对应不到2500亿市值约12-13x，严格看可下行到10x；按商城利润约6x，回购加分红约占市值12%，可修复到8-10x。
- 京东（2026-05-14）：商城利润约560亿、新业务亏损370亿，集团利润约190亿，对应约3100亿市值为16x，按商城利润约5.5x。
- 京东（2026-08-13）：商城利润560亿、亏损365亿，集团利润约195亿，对应约2680亿市值为14x，按商城利润不到5x。

**适用场景与注意事项**：适用于核心业务盈利、新业务亏损并存的公司（京东、美团、阿里、Meta Reality Labs）。不加回SBC的口径更保守；新业务亏损预测的不确定性是该方法最大的误差来源；核心利润口径下的低PE不等于低估，要看新业务能否减亏（亏损业务的剔除与利润口径见9.1）。

### 10.2.3 悲观/保守底价：分项年化加总 × 历史偏差利润率 × 传统金融EV/EBITDA（以空间换时间）

**方法要点**：股价跟随行业行情、短期业绩难预测的强周期、强Beta公司，先把“最差情况”算清楚，得到一个保守估值区间，之后每季对照这个区间判断安全边际是否被跑超。核心思路是“以空间换时间”：不赌短期，等股价进入底价区间。

**操作步骤 / 拆分口径 / 公式**：

1. 交易收入：按最差季度年化。
2. 稳定币收入 = 假设稳定币市值 × 公司份额（回落）× 综合储备利率。
3. 质押收入：按最差季度年化。
4. 其他收入：按低环比增速年化。
5. 总收入 = 以上各项 + 公司利息收入。
6. 用历史偏差（偏低）水平的EBITDA利润率，得到EBITDA。
7. 按成熟传统金融机构10-15x EV/EBITDA，得到保守估值区间。
8. 与当前市值比较；之后每季对照区间，判断安全边际是否被跑超。

**关键指标与数据来源**：分项年化收入、稳定币市值与份额假设、储备利率、EBITDA利润率、EV/EBITDA（10-15x）；数据来自公司财报分项披露与行业数据。

**判断标准**：
- 当前市值落入或低于保守区间 → 安全边际充足，可以布局。
- 当前市值显著高于区间 → 已经跑超“绝对安全区间”，继续观察，不追。
- 区间外的空间，就是用来等待的“时间成本”。
- 最差季度年化、低份额、保守倍数叠加，得到的是接近“估值底”的价位，而不是中性估值。

**海豚案例**：
- Coinbase《烂行情+烂业绩…》（2026-02-13）：交易收入年化40亿；稳定币从760亿增至900亿，份额回落至20%，利率3.7%，收入17亿；质押6亿；其他6.5亿；净收入70亿+利息3亿=73亿；35%利润率；按10-15x，得出260-380亿；当前市值385亿，“一只脚迈入保守区间”。
- Coinbase《Coinbase：旱地已久…》（2026-05-08）：估值已涨至500亿，跑超绝对安全区间。
- Coinbase《Coinbase：币价退潮再探底…》（2026-07-31）：跌至450亿，仍未到底价区间，建议继续观察。

**适用场景与注意事项**：适用于强周期、强Beta、短期业绩难预测的公司；每项收入的“最差”口径要有依据（最差季度、历史偏差利润率），否则底价会失去意义；传统金融倍数10-15x是锚，不同类型公司需换成对应成熟同业倍数（倍数选择见9.3）。

**相关方法的交叉引用**：最新季度收入年化×利润率×PE给出中性估值，并另设零增长情景的安全边际价位，详见9.1；传统业务税后核心经营利润×PE + 汽车业务收入×PS测算悲观底部价与中长期价，详见9.6。

### 10.2.4 乐观与悲观（新业务归零）情景市值区间，与当前股价比较判断已反映的预期

**方法要点**：对期权业务占市值比重大的主题股，同时给出乐观情景的目标市值和“期权业务归零”的悲观情景目标市值，再与当前市值比较，判断股价已经反映了多少预期、悲观情景是否有安全边际。

**操作步骤 / 拆分口径 / 公式**：

1. 乐观情景：期权业务按较乐观的一套假设估值（如机器人取第一种假设），汇总得到目标市值（人民币和港币）。
2. 悲观情景：假设期权业务商业化失败、价值归零，只保留主业价值，得到目标市值。
3. 与当前市值比较：当前价靠近乐观端 → 股价已反映充分预期，向上空间不大；若当前价远高于悲观情景 → 若期权业务进展不及预期，向下缺乏安全边际。
4. 悲观情景用“业务归零”算，可以直观看出股价中期权部分的占比。

**关键指标与数据来源**：乐观和悲观目标市值；当前市值；股价隐含的机器人业务价值；安全边际。

**判断标准**：乐观与悲观两端的区间比较现价，距乐观近、距悲观远 → 预期已充分，赔率不佳。

**海豚案例**：
- 三花智控《三花：AI 机器人时代…》（2026-01-08，第五部分第4点）：乐观情景（机器人取第一种假设）目标市值2482亿元人民币，约合2748亿港元；悲观情景假设人形机器人商业化失败、价值归零，目标市值950亿元人民币，约合1052亿港元；结论是A股股价已反映对机器人业务的充分预期，向上空间不大，若Optimus进展不及预期则向下缺乏安全边际。

**适用场景与注意事项**：适用于期权业务占市值比重大的主题股。该方法没有给出中性情景和概率加权，表达更接近区间判断；如需更完整的赔率表达，可补上中性情景和概率（见10.2.1、10.2.9）。

### 10.2.5 中性情景：用对冲假设（单店杯量不变）让业绩完全由开店驱动，推导净利润与PE

**方法要点**：新旧驱动因子相互对冲、不确定性大（补贴退坡、高基数）时，用对冲假设构建中性情景：新驱动抵消旧驱动退坡，单店杯量不变，业绩完全由开店驱动，据此推净利润和PE，再与未来三年增速比较，得出下行风险和修复空间。

**操作步骤 / 拆分口径 / 公式**：

1. 写出对冲关系：新驱动（咖啡渗透率提升）对冲旧驱动退坡（外卖补贴放缓）。
2. 设单店杯量不变，业绩完全由新开店数驱动（如全年新增3000家）；或假设下半年利润与上半年持平。
3. 推出全年净利润，PE = 市值 ÷ 净利润。
4. 与未来三年增速比较，判断PE是否合理；把PE修复到某个历史/合理倍数（如18x）的幅度作为修复空间，PE偏离处作为下行风险。

**关键指标与数据来源**：开店数假设、杯量假设、净利润、PE、未来三年增速。

**判断标准**：中性情景下的PE若明显低于同类公司或历史区间，且未来三年增速可支撑更高倍数，则对应修复空间；中性情景之外的不确定性（补贴、基数）作为风险项单独列出。

**海豚案例**：
- 古茗《古茗：补贴退坡，茶饮界Costco依然稳健！》（2026-03-26）：假设咖啡对冲外卖放缓、杯量不变，2026年新增3000家门店，净利润35亿，对应15x；修复到18x有20%空间。
- 古茗《古茗：补贴退坡，咖啡接力…》（2026-08-27）：假设下半年与上半年持平，全年约31亿净利，17x，修复到18x有8%-10%空间。

**适用场景与注意事项**：适用于驱动因子相互对冲、需要中性假设的消费公司；对冲假设本身要有依据（如咖啡业务的渗透率走势），不能只是为了得到想要的结果；开店节奏假设要与实际开店进度对照（见7.2）。

### 10.2.6 基准+乐观情景估值，并反推当前估值隐含的利润增速（含等待时点）

**方法要点**：成熟消费龙头同时用两种思路：①情景法——基准情景下当前PE合理，乐观情景给出上涨空间；②反推法——下调某业务假设，得到全年营收和净利润，再算当前市值对应PE，反推隐含的利润增速，判断是否便宜，并据此给出等待时点。

**操作步骤 / 拆分口径 / 公式**：

1. 情景法：基准情景（利润增速自然放缓，如+15%）对应当前PE合理；乐观情景（市占率继续提升）估值提到更高倍数（如30x），对应上涨空间。
2. 反推法：
   - 下调某业务假设（如包装水下半年-3%、其他不变），汇总得到全年营收。
   - 净利润 = 全年营收 × 净利率（如29%）。
   - 当前市值 ÷ 净利润 = 当前PE，再反推该PE对应的隐含利润增速（约8%）。
3. 判断：隐含增速对比合理增速，决定是否便宜；若不便宜，给出等待时点（度过高基数期、看到需求修复）。

**关键指标与数据来源**：分业务收入假设、净利率、PE、隐含增速；数据来自财报分部数据与管理层指引。

**判断标准**：隐含增速低于合理增速→便宜；隐含增速已接近或高于合理增速→不算便宜，需要等待。基准情景和乐观情景的区别在于市占率、需求是否继续提升。

**海豚案例**：
- 农夫山泉（2026-03-25）：水和茶两大支柱均接近200亿体量，假设2026年利润+15%，对应25x合理；若市占率继续提升，可到30x，约20%上涨空间。
- 农夫山泉（2026-08-26）：包装水下半年按-3%、其他不变，全年营收586亿；按29%净利率得170亿净利润；当前约25倍只对应全年8%左右的增速，不算便宜，建议度过下半年高基数期、看到包装水需求修复再布局。

**适用场景与注意事项**：适用于成熟的消费龙头；下调的假设要选真正的边际变量（如某核心业务的下半年增速）；反推的“隐含增速”是个比较口径，需与历史增速和管理层指引对比（指引解读见8.5）。

### 10.2.7 乐观情景：只改最关键的一个价格假设 × 区间最高倍数，得出上行空间

**方法要点**：周期股的乐观情景不要同时改很多变量，只改最敏感的一个（如价格路径），再给估值区间的最高倍数，得到上行空间，并与基准、股东回报反推入场价一起构成“下—中—上”三点。

**操作步骤 / 拆分口径 / 公式**：

1. 确定最关键的变量（案例中为DDR价格），写出乐观假设：若DDR仍偏紧，27年继续上涨25%，28年才微调-3%。
2. 计算目标年盈利（案例为2028年盈利约410万亿韩元）。
3. 给估值区间最高的PE（案例为6x），换算成市值（约1.82万亿美元）。
4. 与现价比较，得出上行空间（较当前约+40%）。
5. 三点并列：基准（5x、中性）、乐观（6x）、以及股东回报反推的入场价（0.85万亿美元，下沿）。

**关键指标与数据来源**：情景价格假设、情景利润、峰值PE上限、基准倍数。

**判断标准**：乐观情景应围绕最敏感变量构建，而不是堆叠多重乐观假设；上行空间要与下沿入场价一起看，形成完整的“下—中—上”三点。

**海豚案例**：
- SK海力士《SK 海力士：长协能熨平周期？估值到哪一步》（2026-10-09）：乐观情景只改DDR价格，27年继续上涨25%、28年才微调-3%，2028年盈利约410万亿韩元，给最高6x PE，对应市值约1.82万亿美元，较当前约+40%；与基准（5x、中性）和股东回报反推入场价（0.85万亿美元，股东回报定价见9.9）共同构成“下—中—上”三点。

**适用场景与注意事项**：适用于周期股情景估值；区间最高倍数应取该股历史估值区间的上限，而不是随意拔高；周期股估值的整体方法见9.4。

### 10.2.8 乐观情景下的P/ARR合理性检验（与对标公司同期倍数比较）

**方法要点**：给出乐观假设（某月ARR达到一定规模，隐含的m/m增速），按对标公司在相应阶段的月均增速推到年底ARR，用当前市值除以年底ARR得到隐含P/ARR，与对标公司同期倍数比较。如果连乐观情景下倍数都接近对标的两倍，估值就已经过满。

**操作步骤 / 拆分口径 / 公式**：

1. 设定乐观假设：某月ARR达到某一规模，并算出这一假设隐含的m/m增速。
2. 按对标公司在对应阶段的月均增速，把ARR推到年底。
3. 隐含P/ARR = 当前市值 ÷ 年底ARR。
4. 与对标公司同期倍数比较，判断是否“最好的情况也不便宜”。

**关键指标与数据来源**：乐观ARR、对标月均增速、年底ARR、隐含P/ARR、对标公司同期倍数。

**判断标准**：隐含P/ARR远超对标同期倍数（接近两倍）→ 估值已过满；“乐观情景也不便宜”是最强的估值过高论证。

**海豚案例**：
- 智谱《智谱：万亿市值，国产 Anthropic 真来了？》（2026-06-22）：乐观假定9月ARR超10亿美元（隐含m/m约30%），参考Anthropic从10亿到90亿期间月均增速20%，算得2026年底ARR约17.3亿美元，隐含P/ARR仍高达80x，接近同期Anthropic的两倍。

**适用场景与注意事项**：适用于高估值成长股的“最好情况也不便宜”论证；与10.1.4、10.1.5的反向估值合用，形成“反推+正推”的完整论证；对标阶段必须匹配。

### 10.2.9 终局份额情景法：市值测算+赔率/胜率表达

**方法要点**：早期、利润尚未释放、行业高速扩容的成长股，从“终局份额”倒推市值：先给行业规模，再设几种份额情景，统一假设净利率和PE，折现得到目标市值，再与当前市值比较，用“赔率+胜率”表达结论。

**操作步骤 / 拆分口径 / 公式**：

1. 行业规模：取机构普遍预测的增长倍数（如商业航天市场2035年为2025年的2-4倍，含最大增量星座运营），取3倍。
2. 份额情景：
   - 情景A：10年后达到行业龙头SpaceX当前份额，收入≈SpaceX 2025年收入（150-160亿美元）×3≈465亿。
   - 情景B：位于第三/第四，份额约10%（一供约50%，约其1/5）→约93亿。
3. 统一假设20%净利率，基于成长性与竞争格局给30x PE，再折现，得到目标市值（A约1050亿、B约210亿美元）。
4. 与当前市值（近400亿）比较：更接近下限 → 赔率较高。
5. 胜率：基于业务确定性（如Neutron成功只是时间问题）判断情景能否达成；赔率高、胜率也高 → 整体看好。

**关键指标与数据来源**：行业规模倍数、份额、收入、净利率、PE、折现（折现年限与折现率需自行设定）；数据来自机构行业预测与龙头公司披露。

**判断标准**：
- 赔率：现价相对于上下两端的位置，更靠近下限（保守情景）→ 赔率较高。
- 胜率：业务确定性（关键产品商业化能否按时落地）。
- 两者同时较高才给出整体看好。

**海豚案例**：
- Rocket Lab（2026-04-10，“对于市值的判断”）：A/B两情景目标市值约1050亿/210亿美元，当前市值近400亿，更接近下限；Neutron成功只是时间问题，胜率也较高，整体看好。

**适用场景与注意事项**：适用于处于早期、利润尚未释放、行业高速扩容的成长股；对份额和时间假设敏感，务必给出上下两端并检查“现价更靠近哪一端”；折现年数、折现率应写明。

### 10.2.10 情绪估值区间（当前/中枢/乐观）：税后经营利润×PE，叠加“守城+进攻”拆分

**方法要点**：成熟大型科技股以税后经营利润为基数，给出三档PE（当前、中枢、历史乐观）对应的市值区间，并把新产品价值拆成“守城”和“进攻”两部分，分别对应不同的情绪定价逻辑，并设定时间约束，避免过早打入乐观预期。

**操作步骤 / 拆分口径 / 公式**：

1. 以税后经营利润为基数（2026年710亿美元，有效税率按20%）。
2. 三档PE：当前18x≈1.3万亿美元；中枢25x≈1.8万亿；过往乐观最高28x以上。
3. 新产品价值拆两部分：
   - 守城：夯实广告护城河，缓解AI高投入下高基数+TikTok/OpenAI竞争带来的收入放缓担忧，推动从18x向25x中枢的情绪修复。
   - 进攻：佣金向上期权，由投资者按风险偏好做短期情绪定价。
4. 设时间约束：当年利润压力在眼前，不宜过早打入乐观预期，最早明年（云算力租赁+Muse商业化）才能缓解。

**关键指标与数据来源**：税后经营利润、有效税率、PE中枢与历史区间、市值。

**判断标准**：守城拉动估值向中枢回归（18x→25x）；进攻只是期权，不计入基础估值；乐观区间（28x以上）依赖时间窗口的兑现。

**海豚案例**：
- Meta《(短评)Meta Muse发布》（2026-09-10）：税后经营利润710亿美元，18x≈1.3万亿 → 25x≈1.8万亿 → 28x以上；守城推动向25x修复，进攻为佣金期权，最早明年才能缓解利润压力。

**适用场景与注意事项**：适合成熟大型科技股；用经营利润可剔除投资收益扰动；情绪估值区间适用于短评或事件点评，要写清时间约束；与10.3.15（叙事切换）、10.3.18（估值驱动阶段）配合。

### 10.2.11 高倍数新业务对公司总市值的敏感性测算

**方法要点**：新业务被给予高PS倍数时，计算其收入或ARR的变动对公司总市值的影响，用来解释为什么短期流水波动会引起股价大幅波动，也提示资金乐观预期越高、估值波动越大。

**操作步骤 / 拆分口径 / 公式**：

1. 取新业务的ARR或收入在不同情景下的差异ΔARR（如1.5亿美元vs 3亿美元）。
2. 乘以资金给的PS倍数，并换算币种（汇率）。
3. 公式：对总市值的影响 = ΔARR × PS倍数 × 汇率 ÷ 公司总市值。
4. 与总市值比例比较，说明“高倍数×小基数”的杠杆。

**关键指标与数据来源**：ARR（不同情景）、PS倍数、汇率、公司总市值。

**判断标准**：ΔARR带来的市值变动占总市值比例越高，股价对新业务数据越敏感；资金乐观程度越高、倍数越高，波动越大。

**海豚案例**：
- 快手《快手：一场向死而生的暴跌，能换来AI重生吗？》（2026-03-25）：资金在可灵起量后按高成长给到约35x PS；ARR是1.5亿美元还是3亿美元，对快手估值的影响约为350亿港元，相当于当时市值的15%。

**适用场景与注意事项**：适用于“传统业务+高成长新业务”的组合型公司；PS倍数本身随竞争和增速变化，需要动态调整；该方法用于解释波动与风险敞口，不等同于估值结论（与10.1.1变体A的SOTP反推配合）。

### 10.2.12 “供给确定、需求不确定”的非对称性：判断上下行概率

**方法要点**：供给刚性、需求波动大的行业，在“估值中性”结论之外，补充一个基于上下行不对称的概率判断：供给端确定而有限，需求端则可能突然出现意外增量，因此上行风险偏大。

**操作步骤 / 拆分口径 / 公式**：

1. 判断供给的确定性：存储产能大体明确且有限，不会突然出现意料之外的新产能。
2. 判断需求的不确定性：需求高度不确定，突然冒出意料之外的增量并不鲜见。
3. 把最终判断转为一个问题：AI对内存的需求会突然超预期减少，还是突然出现预料之外的需求？
4. 给出直觉概率判断：需求低于当前预期的概率不高，后者更可能 → 上行风险偏大。
5. 作为在“估值中性”结论之外的补充判断。

**关键指标与数据来源**：产能确定性、需求情景概率。

**判断标准**：供给确定性强于需求确定性时，意外更可能来自需求上行；因此上行风险偏大。

**海豚案例**：
- SK海力士《SK 海力士：长协能熨平周期？估值到哪一步》（2026-10-09，第4.3节）：供给确定、需求不确定，需求低于预期的概率不高，上行风险偏大，作为“估值中性”之外的补充判断。

**适用场景与注意事项**：适用于供给刚性、需求波动大的行业估值判断；概率判断是直觉性的补充，不能替代情景估值；与10.2.1（四情景）、10.2.7（乐观情景）配合使用。

**本节速查清单**
- [ ] 情景是否围绕最敏感的变量构建，每个情景统一写明“假设→估值→峰值倍数→相对现价空间”。
- [ ] 悲观情景是否区分“盈利下修”与“估值去溢价”，并有可追溯的数据依据（最差季度、历史偏差利润率、历史估值下沿）。
- [ ] 是否给出保守底价/安全边际价位，并每季对照是否被跑超。
- [ ] 核心业务盈利、新业务亏损并存时，是否同时算集团利润和核心利润两个口径的PE，并跟踪两个关键数字。
- [ ] 中性情景的对冲假设是否有依据（单店杯量不变、下半年与上半年持平）。
- [ ] 乐观情景是否只改最关键假设并配区间最高倍数；成长股是否做了与对标的P/ARR合理性检验。
- [ ] 期权型业务是否做了“归零”情景，看出股价中期权部分的占比，以及高倍数新业务的市值敏感性。
- [ ] 是否把向上、向下空间并列，形成赔率（和胜率）结论，必要时补充上下行非对称的判断。

## 10.3 估值折溢价、定价锚与框架切换

> 本节导读：本节回答“同一家公司，市场为什么给折价或溢价，以及市场用来定价的那把尺子是不是正在换”。前半部分把折价、溢价拆到可检验的成因（国别与治理、会计质量、内外资分歧、不确定性、稀缺性、周期共振、高估值的两面性）；后半部分识别基本面与股价背离时的定价锚切换、估值框架迁移、角色转换、叙事切换，以及切换进入后半程的风险。估值驱动出现背离、股价对“好消息”反应异常、或事件声称“估值逻辑已变”时使用；大股东减持悬置（overhang）归11.2；具体估值方法见第9章，隐含预期倒推见10.1，情景上下限见10.2。

**（一）折价与溢价的归因**

### 10.3.1 国别/治理折价三分拆：可得性折价 + 信任折价 + 不透明折价，并区分“披露升级≠治理升级”

**方法要点**：把一整块“国别折价”（如韩国折价）拆成可被事件修复程度不同的三块，逐项判断某一事件（如赴美挂牌）能修复哪一块，避免一刀切地期待估值完全拉平。

**操作步骤 / 拆分口径 / 公式**：

1. 先量化折价：与可比公司的PE差（如FY27海力士4.2x vs 美光6.6x）。
2. 把折价拆成三块：
   - ①可得性：此前海外投资者难以直接买到该国股票，边际买家受限。
   - ②信任：本国家族财阀等历史上的恶意分拆上市、暗箱操作、利益输送等“黑历史”，使海外投资者印象分减分。
   - ③信息不透明。
3. 逐项判断事件能修复多少：
   - 交易端扩容（ADR挂牌、潜在指数纳入）→ 修复可得性部分。
   - 外国私人发行人（FPI）身份可豁免交易所大部分治理规则，治理仍按本国标准 → 信任折价修复有限。
   - 首次提交美式F-1（风险因素、MD&A、分部数据，英文、受美国证券法责任约束），后续按20-F披露 → 属“披露升级”，可压缩折价中的“不透明溢价”部分。
4. 关键判别：披露升级不等于治理升级，因此不能期待估值完全拉平。

**关键指标与数据来源**：可比公司PE差（FY27海力士4.2x vs 美光6.6x）、FPI治理豁免范围、披露文件类型（F-1/20-F/MD&A/分部数据）、潜在指数纳入。

**判断标准**：折价的三个来源，被事件修复的程度不同：可得性（交易端扩容）可被修复，不透明（披露升级）可被压缩，信任（治理不变）修复有限。如果事件只触及前两项，结论是“部分修复”，而不是“拉平”。

**海豚案例**：
- SK海力士《海力士赴美，来讨一个 “公道估值”？》（2026-07-10）：用三分拆论证ADR主要修复交易与披露层面，治理与“韩国公司印象分”仍会压制估值。

**适用场景与注意事项**：适用于中概股、韩股、日股、港股二次上市、A+H等存在国别/治理折价的标的；先拆折价来源，再判断事件能修复哪一块；治理结构是否真的改变（而不是只改披露）是最容易被忽略的一环。修复后的目标空间如何测算见10.3.2。

### 10.3.2 先列不可修复的基本面差异，再按“部分修复”给出目标空间

**方法要点**：判断折价能否拉平时，先列出“不可修复”的差异，再对残余可修复的折价按“部分修复”算空间，而不是直接把可比公司的估值当作目标价。

**操作步骤 / 拆分口径 / 公式**：

1. 列出基本面上无法被事件修复的差异（案例中两项）：
   - 订单保障度差异：美国大厂签LTA时更倾向美国本土产能（美光），以2027年HBM为例海力士LTA保障度约70%、美光已达80-90%，美光订单确定性更高，应享溢价。
   - 治理仍按本国标准。
2. 据此判定“完全拉平不太可能”。
3. 取当前在本地市场的低估值（如韩国约4x PE）作为起点，假设只重估一部分（如约5x），测算涨幅空间（案例约20%）。
4. 用“残余可修复折价”计算空间，而不是“完全对标可比公司”。

**关键指标与数据来源**：LTA保障度（海力士70% vs 美光80-90%）、PE重估倍数（4x→5x）。

**判断标准**：目标估值 = 本地当前估值 +（可比公司估值 − 本地当前估值）× 可修复比例（比例由不可修复差异的个数和大小决定）；结论落为“部分修复空间约X%”。

**海豚案例**：
- SK海力士《海力士赴美，来讨一个 “公道估值”？》（2026-07-10）：LTA保障度、治理两项差异不可修复，重估到约5x（相对约4x）即可带来约20%涨幅空间。

**适用场景与注意事项**：所有“估值修复/对标重估”类判断；避免把可比公司估值当成目标价；不可修复的差异要具体可验证（订单保障度、治理）。与10.3.1配合。

### 10.3.3 对会计粉饰（公允价值计法）打入折价后重算倍数

**方法要点**：若前序研究（如做空报告核查，见12.2）发现会计处理虚高了利润，在估值时显式打折，把“质量问题”量化进估值，观察倍数档位和结论的变化。

**操作步骤 / 拆分口径 / 公式**：

1. 参照最近季度的情况，估算粉饰幅度（案例为20%）。
2. 把利润/EBITDA打8折（×0.8），重算P/E、EV/EBITDA。
3. 对比调整前后的估值档位：从“不算高估”变成“处于金科明星档”，结论随之反转。
4. 长期估值中同样对远期EBITDA剔除折价（案例中2030年EBITDA 38亿，剔除20%折价后为30亿）。

**关键指标与数据来源**：公允价值计法对利润的贡献、调整前后P/E与EV/EBITDA；数据来自财报附注和季度拆分。

**判断标准**：调整后倍数档位显著上移（29x P/E→37x，EV/EBITDA 14x→18x）说明估值看似合理只是因为利润里有水分；折价幅度必须基于可追溯的季度数据，而不是拍脑袋。

**海豚案例**：
- SoFi《槽点多多的 SoFi，“贵” 得有理？》（2026-06-29）：参照1Q26打20%折价；29x P/E→37x，EV/EBITDA 14x→18x，从“不算高估”变为“处于金科明星档”；2030年EBITDA 38亿剔除折价后为30亿。

**适用场景与注意事项**：适用于存在公允价值重估、资本化费用、一次性收益、非经常性损益较大的公司；折价幅度应基于可追溯的季度数据；利润口径的会计调整方法详见8.2。

### 10.3.4 用内外资的看法分歧解释估值

**方法要点**：同一标的上，境内外资金的定价逻辑可能完全不同；把分歧当作估值差异和股价波动的解释变量，并找出能够弥合分歧的催化剂。

**操作步骤 / 拆分口径 / 公式**：

1. 对比内外资券商评级和A/H价差，观察分歧程度。
2. 分析分歧原因：
   - 内资带有战略和产业扶持属性，愿意长期陪伴。
   - 外资看能否自我造血，且有海外同业可替代，还要承担汇率和政治风险。
3. 找出能弥合分歧的催化剂（如先进制程量产、国内AI客户需求）。
4. 结论：当前业绩不重要，催化剂兑现与否决定能否维持超额估值。

**关键指标与数据来源**：内资和外资券商评级、A/H价差、可替代标的。

**判断标准**：内外资分歧的根源是定价逻辑（战略属性 vs 自我造血）；弥合分歧的催化剂兑现，才能维持高于同行的超额PB。

**海豚案例**：
- 中芯（2026-02-10）：国内券商一致看多，JP摩根等外资长期看空；原因有二，一是内资有“为国助力”的战略格局，二是公司未实现自我输血，外资不需要战略持有，并且有台积电、联电等替代选择；结论是当前业绩不重要，只要先进制程能量产出货、国内AI客户需求持续，就能维持高于同行的超额PB。

**适用场景与注意事项**：适用于A+H两地上市、受产业政策驱动的中国公司；需要找到能弥合分歧的催化剂，并持续检验（催化剂见13.3）。

### 10.3.5 不确定性折价与“利空出尽”框架（最后一跌→轻装上阵）

**方法要点**：市场不喜欢不确定性：监管调查、AI Agent冲击OTA、自动驾驶冲击网约车这类未必落地的风险，也会导致持续抛售（类比AI替代SaaS）。股价真正的拐点需要关键问题完全落地，哪怕结果负面也算利空出尽。

**操作步骤 / 拆分口径 / 公式**：

1. 梳理压制股价的不确定性清单（监管、竞争、技术颠覆），标出每一项的落地时点。
2. 监管落地前，判断是否还有一波“杀利润”的下跌；财报发布时点（是否延迟）是重要信号。
3. 监管落地后，即使业绩一般，估值杀也基本结束，转入磨底和修复。
4. 每一阶段对应的表达：好坏参半的业绩不足以扭转弱势 → 可能还有最后一跌 → 利空出尽、轻装上阵。

**关键指标与数据来源**：监管事件时间线、财报发布时点（是否延迟）、估值倍数变化、业绩与预期差。

**判断标准**：关键不确定性完全落地（哪怕负面）→ 估值杀基本结束；落地前即使业绩尚可，也不足以扭转；财报明显延迟发布且监管未落地，要警惕最后一波“杀利润”。

**海豚案例**：
- 携程《携程：监管“重锤”之后，还能“小而美”吗？》（2026-02-26）：好坏参半的业绩不足以扭转弱势；监管、竞争、AI冲击都是不确定性，类比AI替代SaaS、自动驾驶替代网约车。
- 携程《监管重锤没落完，携程还有最后一跌？》（2026-06-25）：一季报发布明显偏晚，市场期待监管落地却没有，“携程可能还有最后一波杀利润的下跌”。
- 携程《监管铁拳落定，携程能“轻装上阵”了吗？》（2026-09-16）：监管落地，业绩无惊无喜，判断“最后一跌”已完成，可以轻装上阵。

**适用场景与注意事项**：适用于受政策或技术颠覆不确定性压制的公司；需要判断不确定性何时落地（风险与证伪条件见13.1、13.2）；“利空出尽”是对不确定性折价结束的判断，不等于业绩立即好转。

### 10.3.6 估值溢价三因子归因：智能排名、地缘战略资产稀缺、流通盘稀缺

**方法要点**：基本面（ARR）解释不了的估值溢价，归因为几类因子并逐一评估其持续性，区分“可持续溢价”和“阶段性溢价”。

**操作步骤 / 拆分口径 / 公式**：

1. 模型实力：国产模型首次跻身智能榜前三，参数与开源许可，加上相对海外顶级模型的价格优势，提振国产替代信心。
2. 地缘叙事：美国收紧前沿模型对海外服务，同一周中国放出MIT许可、无地区限制的开放权重，形成对比叙事；前沿模型可以看作承载地缘博弈的战略性资产，美国有两家、中国只有一家，享受稀缺溢价；但要检验叙事能否转化为收入（限制并非永久、窗口短、体验略逊）。
3. 筹码结构：真实自由流通盘极低，叠加入通的被动需求，稀缺性被放大，但随锁定期到期不可持续。
4. 对每一因子评估持续性，并找出能转化为收入的证据。

**关键指标与数据来源**：模型榜单排名、定价相对比、流通盘占总股本比例、解禁时间表、入通。

**判断标准**：溢价因子若能转化为收入（地缘叙事→真实订单），才可持续；仅靠流通盘稀缺和被动资金的溢价属于阶段性，随锁定期到期而衰减。

**海豚案例**：
- 智谱《智谱：万亿市值，国产 Anthropic 真来了？》（2026-06-22）：GLM-5.2是7440亿参数的MoE模型，激活参数400亿，上下文100万token，MIT许可开放权重；API定价约为Opus的1/4、Fable 5的1/10；创始人唐杰称年内可能超越Anthropic；Anthropic二月指控中国厂商蒸馏的名单中没有智谱；上市首日流通盘不足总股本3%，下半年各档锁定期陆续到期。

**适用场景与注意事项**：适用于题材股/稀缺资产的估值分析；要区分可持续溢价和阶段性溢价；锁定期和解禁对股价的冲击属于筹码问题，详见11.2；与10.1.4、10.1.5的反向估值配合，说明溢价超出基本面的部分。

### 10.3.7 多周期共振框架：拆解暴涨的四大驱动周期，以及持续享受溢价的前提

**方法要点**：解释股价暴涨暴跌时，把上涨拆成多个周期共振，再列出持续享受估值溢价的前提，逐一检验哪个前提失效，判断下跌是估值水分挤压而不是基本面崩塌，最终定位资产属性。

**操作步骤 / 拆分口径 / 公式**：

1. 拆上涨的驱动周期：产品创新周期、并购扩张周期、变现率拉升周期、流动性泛滥下的市场牛。
2. 列出持续享受溢价的前提：生态变现率还有释放红利；美股牛市持续。
3. 逐一检验：变现率拉升期是否结束、流动性是否收紧。
4. 判断下跌的性质：估值水分挤压（而非基本面崩塌）。
5. 资产定位：短期Beta、长期Alpha；估值回归后，在情绪过度负面、跌入安全边际时，是长期持有机会。

**关键指标与数据来源**：变现率趋势、流动性指标（政府关门、美联储主席提名）、PE变化、产品线数量。

**判断标准**：四个周期共振时股价被放大；其中任何一个周期的前提失效，估值就会被挤压；基本面仍在则视为长期持有机会。

**海豚案例**：
- Robinhood《Robinhood：爆炒之后…》（2026-02-11）：9个月四倍是四周期共振，之后腰斩是流动性收缩与变现率红利结束下的估值挤压。
- Robinhood《Robinhood：美股散户罗宾汉…》（2026-08-11）：去年市场给了太多故事性和线性外推式估值，行业是超级Beta；多线业务开花（事件合约Rothera、AI Agent交易、加密借贷、Social、Strategies、Cortex），认为是值得持续陪伴的短期Beta、长期Alpha资产。

**适用场景与注意事项**：适用于经历暴涨暴跌、叙事驱动的成长股；需要判断各周期的前提何时失效，并区分估值挤压与基本面恶化（二者对应的决策完全不同）。

### 10.3.8 高估值的“两面性”分析

**方法要点**：对估值近百倍的公司，分析高估值的两面：一方面反映市场对稀缺性和高增长的认可，另一方面一旦核心市场逆风、高增长难以实现，高估值就成为“利剑”。

**操作步骤 / 拆分口径 / 公式**：

1. 列出支撑高估值的正面因素（数据中心需求、费率提升、AI PC）。
2. 列出可能令增长落空的核心终端市场风险（如手机遭遇逆风、存储危机）。
3. 说明高估值需要持续高增长和持续超预期来维持信心，否则业绩展望和估值都会被下调。
4. 判断主逻辑是否延续：只要正向逻辑（AI）在延续，市场仍会给相对较高的估值。

**关键指标与数据来源**：PE水平、增长预期、核心终端市场风险。

**判断标准**：估值倍数越高，对超预期的依赖越大；核心终端市场的逆风（如存储危机下手机大幅下滑）会使展望和估值被下调；正向逻辑延续时仍给较高估值。

**海豚案例**：
- ARM《ARM：AI红利未消》（2026-02-05）：约99倍PE；在存储危机解除之前，手机市场“大幅下滑”会持续给增长施压，展望和估值将被再次下调。
- ARM《ARM：“短期波动”难掩锋芒》（2026-05-07）：约100倍PE；只要AI正向逻辑在延续，市场仍会给相对较高的估值。

**适用场景与注意事项**：适合高估值成长股；要同时写出“靠什么维持高估值”和“什么会令它失效”，避免只讲其中一面。

### 10.3.9 “业绩向好、估值下杀”：识别中长期竞争或持续性担忧

**方法要点**：业绩超预期而估值不升时，不要只看业绩，找出市场在担心的中长期变量，并指出管理层需要给出的中长期信心。

**操作步骤 / 拆分口径 / 公式**：

1. 确认背离：业绩高增但估值难以提升。
2. 找出市场担心的中长期变量：ASIC的竞争、从训练转向推理后客户更看重性价比、客户Capex的持续性。
3. 关联指标：市占率、毛利率、客户Capex/收入。
4. 指出管理层需要在这些点上给出中长期信心。

**关键指标与数据来源**：市占率；毛利率；客户Capex/收入。

**判断标准**：业绩确定性强但估值被杀，说明市场的核心担忧在中长期（竞争格局、客户支出持续性），而不是当期业绩；缓解这些担忧才能修复估值。

**海豚案例**：
- 英伟达（2026-02-26）：收入环比+111亿，毛利率回到75%，下季指引780亿；但大模型重心从训练转向推理，客户兼顾算力与性价比，ASIC对其高市占率和高毛利率构成潜在威胁，于是业绩高增而估值难以提升。
- 博通（2026-03-05）：AI业务快速成长相当确定，但市场担心大厂Capex的持续性，陷入“业绩向好、估值下杀”。

**适用场景与注意事项**：AI芯片等业绩确定性强但中长期变量不确定的行业；需要列出具体的担忧变量并跟踪（跟踪见13.2）。

**（二）定价锚与估值框架切换**

### 10.3.10 基本面与股价背离时，识别“定价锚切换”（及背离的两种写法）

**方法要点**：核心经营指标走弱而股价上涨时，不直接判泡沫，而是识别市场在为哪块业务定价、定价锚是否已经切换，并找出推动切换的事件时间线，把研究重心转到新业务的空间和变现上。

**操作步骤 / 拆分口径 / 公式**：

1. 列出硬数据（交付量、销量及同比/环比）与股价/市值走势，确认“销量下滑、估值攀升”的背离。
2. 解释基本面走弱的原因（如补贴退坡、购置税退坡、以旧换新红利耗尽）。
3. 用分部估值证明定价主体已从“旧业务”切到“新叙事”。
4. 找出推动切换的事件时间线（催化剂）。
5. 把跟踪重点换成新业务的里程碑。

变体 A（长篇深度版）：除背离数据外，完整列出催化剂时间线，并把研究重心转向新业务拆解。

变体 B（短评速读版）：用硬数据与股价的背离 + 分部估值占比，直接得出“定价主体切换”的判断，并给出新的跟踪清单。

**关键指标与数据来源**：季度和年度交付量、环比/同比增速、股价/市值、分部估值占比、关键里程碑事件。

**判断标准**：
- 背离的存在不等于泡沫，要问“市场在为什么定价”。
- 判断锚切换的证据：交付持续下滑但股价创新高；分部估值中新业务占比超过旧业务。
- 切换后的跟踪重点：新业务里程碑（Cybercab量产、Optimus量产、监管审批）。
- 叙事兑现不及预期时，估值锚会反向切换。

**海豚案例**：
- 特斯拉《Robotaxi出行帝国，能再造特斯拉？》（2026-01-07）：Q4交付41.8万辆，环比下滑16%（美国IRA 7500美元补贴退坡、中国购置税退坡、以旧换新红利耗尽）；2025全年交付164万辆，同比下滑8.6%，连续第二年萎缩；股价却逼近500美元、创历史新高。结论是定价锚从“汽车制造”切换到“AI叙事”，市场在交易Robotaxi的落地与变现。催化剂时间线：Robotaxi Day与FSD V13推送；2025年6月奥斯汀上线，随后拓展到加州；12月奥斯汀测试车队移除安全员。由此把研究重心放到Robotaxi业务的拆解上。
- 特斯拉《(短评)特斯拉估值里AI占比超60%》（2026-01-15）：先列硬数据（2025年交付164万辆、同比-8.6%、连续两年萎缩）与股价（巅峰近500美元、市值约1.5万亿）的背离，再用分部估值证明定价主体已从“造车公司”切到“AI叙事”（估值里AI占比超60%），进而把跟踪重点从交付量换成AI业务里程碑（Cybercab量产、Optimus量产、监管审批）。

**适用场景与注意事项**：适用于叙事驱动的成长股；确定锚切换后，研究重心应转到新业务的空间和变现；叙事兑现不及预期时，估值锚会反向切换。分部权重的具体拆法见10.3.11。

### 10.3.11 市值归属拆分与估值锚切换：谁在为股价定价

**方法要点**：判断股价由哪部分业务定价：估算旧业务与新业务在市值中的占比，解释为什么股价与旧业务基本面脱钩，并把每季财报的重点转为检验新业务兑现节点。

**操作步骤 / 拆分口径 / 公式**：

1. 估算各业务在市值中的占比（汽车业务约占市值1/3以下，AI业务约占2/3）。
2. 解释脱钩：股价与卖车基本面脱钩，“销量越差股价反而上行”。
3. 给新业务定位：AI业务处在“天花板极高、短期逻辑无法证伪”的甜蜜期；汽车和储能被定位为“现金流奶牛”。
4. 每季财报的重点：检验AI兑现节点（Optimus V3、Cybercab量产、Robotaxi扩张、监管获批、量产订单）。
5. 若AI进度超预期，估值锚加速切到“AI成长”，给出乐观假设下的目标市值（2万亿美元）。

**关键指标与数据来源**：汽车业务估值占比、AI业务估值占比、乐观情景目标市值；目标市值的测算依赖深度报告里的假设。

**判断标准**：旧业务占比下降到1/3以下，说明股价对旧业务数据的敏感度下降；新业务甜蜜期的特征是天花板极高、短期无法证伪，此阶段重点看里程碑兑现而不是旧业务销量。

**海豚案例**：
- 特斯拉《手撕“烂业绩”剧本》（2026-01-29）：股价和销量脱钩，AI业务在甜蜜期，催化剂有Optimus V3、Cybercab量产、Robotaxi扩张，乐观假设2万亿美元市值。
- 特斯拉《造车罕见回血…》（2026-04-23）：卖车业务在估值中的权重下降，退为现金流奶牛，中期仍有向2万亿进发的势能。
- 特斯拉《造车硬抗…》（2026-07-23）：汽车不到市值1/3，约2/3取决于AI。

**适用场景与注意事项**：适用于叙事驱动、远期业务主导估值的公司；目标市值的测算依赖深度报告里的假设，不能当作确定结论；占比拆分用分部估值（见9.6）。

### 10.3.12 估值框架迁移：从传统行业可比，切换到新叙事可比

**方法要点**：判断市场给公司的定价锚是否正在切换：传统业务缺乏成长时，历史估值区间偏低；一旦签下新业务大订单，估值逻辑会从“传统公司”升级为“新赛道玩家”，有机会突破历史区间。文中必须写清“估值逻辑已然生变”的触发条件。

**操作步骤 / 拆分口径 / 公式**：

1. 确认旧框架下的估值区间（历史估值区间、可比公司估值）。
2. 找触发事件（新业务大订单：端侧或数据中心AI；ARR起量）。
3. 确定新的可比对象（如从“本地部署AI提供商”折价切换到“海外to B模型（Claude）估值模式”）。
4. 判断触发事件是否足以改变叙事，并写清触发条件。
5. 比较新旧框架下的估值差，作为空间的来源。

**关键指标与数据来源**：历史估值区间、可比公司估值、触发事件（大订单/ARR）。

**判断标准**：触发事件签下后，估值框架才升级；没有触发事件时，仍按历史估值区间。

**海豚案例**：
- 高通（2026-04-30）：观点标题“估值逻辑已然生变”，签下AI大订单就会带来叙事转变，从“传统手机芯片公司”升级为“AI芯片玩家”，打破历史估值限制。
- 智谱（2026-03-31）：一季度股价涨6倍，定价从本地部署AI的折价晋级为Claude式to B估值。
- MiniMax（2026-08-26）：市值135亿美元，甚至低于一级市场可灵180亿美元的估值。

**适用场景与注意事项**：转型或新赛道公司；需要明确可比对象和触发事件；框架切换后要继续核对收入兑现，否则面临10.3.19的“框架切换风险”。

### 10.3.13 竞争角色转换带来的估值中枢重估

**方法要点**：公司在行业叙事中的角色变了，估值中枢会随之移动：从“挑战龙头、抢份额的进攻者”变成“被二线对手围猎的被竞争者”，估值期待会从溢价回到折价。

**操作步骤 / 拆分口径 / 公式**：

1. 说明原来的角色（挑战龙头、抢份额）及对应的估值期待。
2. 找出角色转换的证据（如客户引入第二供应商）。
3. 看估值中枢的变化（PE变化、竞争事件、客户份额）。
4. 给出顾虑解除前估值的大致上限。

**关键指标与数据来源**：PE变化、竞争事件、客户份额。

**判断标准**：竞争事件证实角色转换后，估值中枢下移；在顾虑解除前，估值被压在某一倍数附近。

**海豚案例**：
- 博通（2026-09-03）：最初被视为向英伟达争夺份额的竞争者，估值期待较高；现在面临MTK和Marvell的竞争，成为“被竞争者”，估值回落到16x左右，顾虑解除前会被压在15x附近。

**适用场景与注意事项**：竞争格局正在变化的科技公司；要给出可检验的角色转换证据，竞争格局的细节见6.1。

### 10.3.14 定价逻辑切换：强周期品 → 供给约束型卖方市场的“三重红利”

**方法要点**：解释公司为何重估：先描述传统模式（强周期），再论证新需求如何改变供需结构，使行业进入卖方市场，头部产能企业同时享受产品溢价、锁价长单和毛利率上行。

**操作步骤 / 拆分口径 / 公式**：

1. 传统模式：强周期，需求跟随资本开支起伏、供需均衡、竞争充分、价格年年下降。
2. 需求端：AI横向互联让高速光连接需求指数级爆发，800G→1.6T抬高单机用量。
3. 供给端：高端芯片量产壁垒极高、全球仅寥寥几家能扩产、只能靠自建晶圆厂，扩产周期2~3年。
4. 供需极致错配：周期波动减弱，行业进入卖方市场。
5. 头部产能企业同时享受“三重红利”：产品溢价、锁价长单、毛利率上行。
6. 持续验证供给瓶颈何时缓解，否则会回到周期定价。

**关键指标与数据来源**：需求增速（光模块出货、单机用量）、有效供给厂商数、扩产周期、价格趋势、长单比例、毛利率。

**判断标准**：需求指数级、供给刚性且扩产周期长、价格趋势转为上行、长单比例上升、毛利率上行，同时成立，才算定价逻辑从周期品切换为卖方市场。

**海豚案例**：
- Lumentum《从光互联老炮到“全能卖水人”，Lumentum 凭什么？》（2026-09-24）：股价一年近10倍、市值700亿美元以上，英伟达2026年3月以20亿美元入股；高端高速激光芯片（200G以上）全球仅寥寥几家能扩产。中篇再次归纳EML和CW“殊途同归”：拥有自建产能的头部厂商同时享受涨价、长单与毛利率上行。

**适用场景与注意事项**：适用于周期性零部件/材料在新需求下的重估判断（光芯片、存储、电力设备）。要持续验证供给瓶颈何时缓解，否则会回到周期定价（周期股估值见9.4，行业供需见5.3）。

### 10.3.15 叙事逻辑切换：从“成本项To C AI”到“具备经济性的To B AI”

**方法要点**：判断事件是否值得重估，看它是否改变市场叙事：叙事由成本项变为有直接经济性，资金会淡化前置投入带来的基本面压力、提高对直接变现的预期；同时写出硬币的反面。

**操作步骤 / 拆分口径 / 公式**：

1. 旧叙事：Meta的AI是成本趋向的To C AI（AI对广告增长并非主力，属纯成本项）。
2. 事件：算力租赁确认，从“考虑将闲置算力出租”的模棱两可到明确战略。
3. 新叙事：具备经济性的To B AI（裸租算力吃行业beta，进一步可搭售大模型API、Agent乃至云服务）。
4. 估值影响：资金淡化前置投入带来的基本面压力，提高AI直接变现预期，估值情绪更明确修正。
5. 硬币反面：身份转变侧面说明To C AI商业模式仍有阻碍，会弱化C端变现预期，但对压抑已久的投资情绪整体有利。

**关键指标与数据来源**：AI是否有可直接计量的收入、Capex回报路径。

**判断标准**：判断事件价值的关键不是事件大小，而是是否有可计量的收入，是否把“成本项”变成“有回报路径的资产”。

**海豚案例**：
- Meta（2026-07-10）：确认长期战略性布局算力租赁，从“考虑将闲置算力出租”的模棱两可到明确战略；To C AI的“成本项”叙事切到To B AI的“具备经济性”叙事。

**适用场景与注意事项**：重资本开支公司的重估判断；需验证新叙事的收入落地；既写正面（经济性），也写反面（C端变现预期弱化）。

### 10.3.16 识别可转为经常性收入的新商业模式，作为估值倍数上修的“向上期权”

**方法要点**：在基础估值之外，单独列出可能改变估值倍数的“向上期权”：一次性卖车收入只配低PS，而授权、外供如果能变成经常性收入，估值倍数就有上修空间。只做定性列示，或作为乐观情景的支撑，不计入基础估值。

**操作步骤 / 拆分口径 / 公式**：

1. 列出向上期权清单：技术授权（电子架构授权给其他车企）、零部件外供、海外合作工厂等。
2. 区分已签约量产与意向合作。
3. 说明倍数上修逻辑：一次性收入→经常性收入，倍数由低PS向更高倍数迁移。
4. 不计入基础估值，只作为乐观情景支撑；并跟踪合作方、量产时间和合作产能。

**关键指标与数据来源**：技术授权合作方与项目、外供量产时间、合作产能。

**判断标准**：能否形成持续的经常性收入（授权费、外供量）；已签约量产的权重高于意向合作。

**海豚案例**：
- 零跑《出海神车…》（2026-03-16）：技术授权目前主要与一汽合作，若能持续输出电子架构授权、形成经常性收入，估值倍数有上修空间。
- 零跑《利润指引大幅缩水…》（2026-08-25）：一汽红旗G117项目Q4量产、STLA平台合作；与Stellantis西班牙本土化合作（马德里工厂、2027年本土化5万台）为估值提供向上期权。

**适用场景与注意事项**：适用于有平台化、技术外溢潜力的制造企业；需区分已签约量产和意向合作；期权不计入基础估值，避免过早乐观。

### 10.3.17 公司价值三层框架 + 重估逻辑拆分（资产再认知 vs 平台利润释放）

**方法要点**：估值前先把公司价值拆成几层、把重估逻辑拆成几条，再提出核心问题：重估走到哪、还剩多少空间。

**操作步骤 / 拆分口径 / 公式**：

1. 价值三层：
   - 底层：宽护城河的线下零售主业（增长温和、现金流极稳，是估值地基，也是上层平台的基础设施）。
   - 中层：被低估的增长极（山姆）。
   - 顶层：最具弹性的轻资产平台经济（3P+广告+会员）。
2. 重估逻辑拆成两条：a. 线下零售资产的再认知（疫情后二次线上化红利）；b. 线上3P轻资产平台带来的利润释放重估。
3. 提出核心问题：重估走到哪、还剩多少空间。
4. 以系列前三篇的结论为基础构建三层价值框架，各层收入、增速、利润率作为支撑。

**关键指标与数据来源**：各层收入、增速、利润率。

**判断标准**：分层后每一层用与自己属性相符的估值方法，各层的重估空间分开判断，再看哪一层已被计价（与10.1.1变体C的隐含定价对照）。

**海豚案例**：
- 沃尔玛《沃尔玛：老兵不老，重估路还能走多长？》（2026-06-10）：以系列前三篇结论为基础构建三层价值框架，并把重估逻辑拆为线下资产再认知与线上3P平台利润释放。

**适用场景与注意事项**：多业务、多属性的大型公司估值前的定性准备；分层是为后续估值服务，每层要有对应的数据支撑。

### 10.3.18 估值驱动阶段判断：股价靠什么涨

**方法要点**：在速读或点评中，用一句话定位“当前股价靠什么涨”的阶段，用来判断超预期能带来多大股价弹性。

**操作步骤 / 拆分口径 / 公式**：

1. 判断所处阶段，类型包括：拔估值阶段（叙事加估值扩张）、EPS驱动阶段、业绩估值双升（突破历史估值区间）、估值溢价被同行追平、PE低估平台价值。
2. 依据：PE、历史估值区间、同行估值对比。
3. 推导弹性：不同阶段下，超预期能带来的股价弹性不同（如拔估值阶段过去后，股价主要靠EPS，难再享双击）。

**关键指标与数据来源**：PE、历史估值区间、同行估值对比。

**判断标准**：
- 拔估值阶段过去 → 股价主要靠EPS，难再享受双击。
- 估值突破传统区间上限 → 业绩估值双升。
- 先进制程等原有估值溢价被同行大涨追平 → 溢价消失。
- PE偏低而市场当周期品定价 → 低估平台价值。

**海豚案例**：
- 英伟达（2026-05-21）：“大幅拔估值的阶段已经过去”，股价主要靠EPS，难再享双击。
- 戴尔（2026-05-29）：估值突破传统区间上限，业绩估值双升。
- 中芯（2026-05-14）：原有“先进制程突破期待”的估值溢价，被联电、格芯大涨基本追平。
- 泡泡玛特（2026-05-12）：按全年净利160亿约12x，市场当作周期消费品定价，低估平台价值。
- 沃尔玛：45x+对应全渠道履约加高毛利科技服务平台。

**适用场景与注意事项**：速读中做简要定位，详细估值放在正式点评；阶段判断是定性结论，要能对应到具体倍数和同行比较。

### 10.3.19 估值框架切换风险：故事进入后半程 / 业务属性被重估

**方法要点**：识别市场给高估值的叙事前提；当前提被证伪时，估值框架会切换到更低一档，资金会持续杀估值，直到估值与新的增长阶段匹配。

**操作步骤 / 拆分口径 / 公式**：

1. 写出当前高估值依赖的叙事前提（单一超级大单品加全国化扩张的高确定性故事；零售是消费品牌）。
2. 找出前提被证伪的信号：大单品进入中后期、零售靠降价换增长。
3. 判断新框架：增速下台阶、家纺制造。
4. 设定框架切换的阈值指标（如核心单品增速、零售毛利率若跌破50%）。
5. 判断杀估值何时结束：估值与新的增长阶段匹配。

**关键指标与数据来源**：核心单品增速、毛利率阈值、PE。

**判断标准**：叙事前提被证伪 → 估值框架下移一档；阈值指标（如零售毛利率跌破50%）是触发信号。

**海豚案例**：
- 东鹏饮料（2026-04-30）：一旦单一超级大单品加全国化扩张的故事进入后半程，估值框架就要切换。
- 东鹏饮料（2026-03-31）：资金将持续杀估值，直到与新的增长阶段匹配。
- 亚朵（2026-08-21）：零售毛利率若跌破50%，估值框架会从消费品牌退回家纺制造。

**适用场景与注意事项**：适用于成长股降速期的估值判断；阈值要可跟踪、可证伪（跟踪指标见13.2）；与10.3.12（框架迁移）对照，迁移是向上、切换风险是向下。
