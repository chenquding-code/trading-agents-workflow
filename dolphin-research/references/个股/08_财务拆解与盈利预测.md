## 8.1 利润率、费用与回报率拆解

> 本节导读：本节解决“公司赚的是什么钱、利润率为什么是这个水平、费用为什么下不来、回报率靠什么驱动”的问题，是拆解历史与当期利润表的起点。毛利率层面看分产品线、结构稀释与定价机制，营业利润率层面看分层解读、同业对标与可比对象，费用层面看刚性与投入强度，回报层面用杜邦拆 ROE。研究任何一家公司的利润表、或要判断“利润率能不能持续”时先用本节；未来利润率路径的假设归 8.6，会计口径调整与利润质量归 8.2，Capex 与现金流归 8.3，SOTP 估值中的分部利润使用见 9.6。

**方法选择速览**

| 要回答的问题 | 优先使用的方法 | 编号 |

### 8.1.1 分产品线毛利率分档，并与市场的毛利率预期对比

- **方法要点**：多业务公司的总毛利率由业务结构决定。先把各细分产品线的毛利率分成几档，找出决定总毛利率的主要矛盾，再对市场没有看清的业务给出与共识不同的毛利率假设，形成预期差。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：总毛利率 = Σ（业务 i 营收占比 × 业务 i 毛利率）。
  1. 结合市场研究，把各细分产品线毛利率分档：许可证 90% 以上；SaaS、硬件、数据库云约 70%；托管、咨询 20%~30%；AI 算力租赁更低。
  2. 列出营收结构占比及其演变，找出决定总毛利率的主要矛盾：一是低毛利业务占比快速上升带来的结构变化，二是新业务稳态毛利率是多少。
  3. 对“其他业务”（不在主叙事里、但占比不小的业务）的毛利率给出与市场不同的假设，并与市场一致预期毛利率逐项对比，把差异列为预期差来源之一。
  4. 对外部估算的细分毛利率注明不确定性，不当作公司披露值使用。
- **关键指标与数据来源**：分产品线毛利率（公司披露 + 市场研究估算）、营收结构占比、市场一致预期毛利率。
- **判断标准**：总毛利率变化的主因若是结构（低毛利业务占比抬升）而非单业务盈利恶化，应先测结构效应再谈经营；市场假设“传统业务毛利率稳步提升”而自己判断“平稳或略降”，这一差异就是预期差来源。新业务稳态毛利率是最大的不确定项，必须单列假设。
- **海豚案例**：
  - Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：传统软件毛利率 90% 以上；OCA SaaS、硬件、数据库云约 70%；Legacy Hosting 和咨询 20%~30%。市场预期传统业务毛利率稳步提升，海豚君假设平稳或略降，这是与市场的主要差别之一。
- **适用场景与注意事项**：适用于多业务、毛利率差异大的公司。细分毛利率多为外部估算，需注明不确定性；结构稀释的量化测算见 8.1.2。

### 8.1.2 结构性毛利率稀释测算与“增长不增利”判断（毛利额倍数 vs 营收倍数）

- **方法要点**：按各业务毛利率路径和营收结构，测算预测期总毛利率的变化，再对比营收增长倍数与毛利额增长倍数，判断扩张是“增长又增利”还是“增长不太增利”，进而决定估值是否能按营收增速给倍数。
- **操作步骤 / 拆分口径 / 公式**：
  - 恒等式：毛利额倍数 ÷ 营收倍数 = 期末毛利率 ÷ 期初毛利率。
  1. 给各业务设定毛利率路径（成熟业务、新业务分别设定，新业务可设“首度转正—逐步爬升”的路径）；
  2. 按各业务营收预测加权，得到各年总毛利率；
  3. 计算预测期营收倍数（期末营收 ÷ 期初营收）与毛利额倍数（期末毛利额 ÷ 期初毛利额）；
  4. 若毛利额倍数明显低于营收倍数，判定为“增长不太增利”，估值上不能按营收增速给倍数，要按毛利额或利润口径折算。
- **关键指标与数据来源**：分业务毛利率路径、总毛利率、营收倍数、毛利额倍数。
- **判断标准**：毛利额增速明显跑输营收，即是“增长不增利”的信号；扩张业务的毛利率越低、占比越高，稀释越严重。判断时要把“稳定部分”和“新业务部分”的毛利率路径分开列，避免用总毛利率一个数字掩盖结构。
- **海豚案例**：
  - Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：Core OCI 非 AI 部分毛利率稳定在 40% 出头；AI 部分 27 财年首度转正、30 财年接近 30%；Oracle 整体毛利率从 25 财年的 70% 出头降到 30 财年约 45%；30 财年毛利额是 26 财年的 2.3x，而营收是 3.3x（二者之比约 0.7，即毛利率相当于期初的七成左右），因此是“增长不太增利”。
- **适用场景与注意事项**：适用于低毛利新业务快速放量的公司（软件转 IaaS、品牌转代工、平台转自营）。关键假设是新业务毛利率路径，应做敏感性测算；与 8.6 的利润率路径假设配合使用。

### 8.1.3 新业务收入按业务类型拆分，用结构因子解释“收入高增而利润率不降”

- **方法要点**：把一块高增长的新收入（如 AI 收入）拆成利润率差异很大的几类业务，用结构占比解释整体利润率为什么没有下降（或下降多少），并用跨公司对比说明不同公司利润率差异的结构来源。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把 AI 收入拆为四类：
     - AI 算力租赁（IaaS）：基于 Trainium / Inferentia 或 NVIDIA GPU，客户集中于大型 AI Lab、议价权强，芯片与存储成本高涨，利润率低于传统云；
     - Bedrock MaaS / TaaS：部署好模型后直接卖 API / Token；
     - SageMaker：预部署的训练、微调与部署平台；
     - Amazon Q：面向开发者、企业员工、客服的 Agent 产品线。
  2. 判断各类业务的利润率层级：后三者是在硬件之上附加一层服务，利润率更高。
  3. 做跨云对比：看各云 AI 收入中 IaaS 纯硬件租赁与 MaaS 的占比；比较 MaaS 绝对规模；比较 MaaS 经营利润率与云整体经营利润率。
  4. 对软件能力弱的新云（甲骨文、CoreWeave 等）说明 MaaS 收入可忽略，因此其 AI 收入的利润率结构更接近纯租赁。
- **关键指标与数据来源**：AI 收入结构占比、MaaS 收入规模、分业务经营利润率；数据来自第三方调研（SemiAnalysis）。
- **判断标准**：AI 收入中租赁占比越高，利润率越低于传统云；MaaS / 平台层占比越高，对整体利润率的支撑越强。因此“收入高增而利润率不降”的解释是结构因子：高利润率的服务层被一并带动，对冲了低毛利租赁的稀释。
- **海豚案例**：
  - Amazon（2026-06-24，数据引自 SemiAnalysis 调研）：Bedrock 约占 AWS AI 收入 37%，而 Azure、GCP 的 AI 收入约 80% 仍来自 IaaS 纯硬件租赁；MaaS 绝对规模 AWS 约 55 亿美元、GCP 稍低于 50 亿、Azure 不到 20 亿；AWS MaaS 经营利润率约 55%，对比 1Q26 AWS 整体不到 38%；甲骨文、CoreWeave 等新云软件能力弱，MaaS 收入可忽略。
- **适用场景与注意事项**：适用于云厂商与新云对比、利润率变化的结构归因。MaaS 的高利润率还受收入确认口径影响（见 8.2.3），跨公司比较前先统一口径。

### 8.1.4 追赶者的毛利压力：低定价 + 高 BOM，并区分自研件收入与低毛利转售收入

- **方法要点**：对向系统化、整机化转型的追赶者，从成本差推导它的毛利压力，并把收入拆成“自研高毛利件”和“转售低毛利件”两部分，避免被整机架收入的增长掩盖毛利率的摊薄。
- **操作步骤 / 拆分口径 / 公式**：
  1. 比较追赶者与领先者的 BOM 成本与定价：追赶者面对客户显然会采取更低的定价（不考虑存储容量差异），BOM 成本上的差距会全部体现在组网方案的毛利上；
  2. 拆收入质量：整机架方案里，列出哪些是自家芯片和部件（真正留在体内的高毛利收入），哪些是第三方组件（低毛利转售业务）；
  3. 在预测中分别给自研件与转售件设定毛利率，加权得到整体毛利率；
  4. 得出结论：机架化会抬高收入，但摊薄毛利率。
- **关键指标与数据来源**：机架售价、BOM 成本、自研件收入占比、毛利率。
- **判断标准**：整机收入增长中，转售件占比越高，毛利率摊薄越明显；只有自研件（如 GPU、CPU、网卡）是留在体内的高毛利收入。
- **海豚案例**：
  - 《AMD 跟英伟达 “掰手腕”，Helios 够格吗？》（2026-09-15）：Helios 大量使用第三方组件，即便同样卖整机架，真正留在体内的高毛利收入只有 GPU（MI455X）、CPU（EPYC Venice）和网卡（Pensando Vulcano），其余多是低毛利的转售业务；作为追赶者，BOM 成本差距全部体现在组网方案的毛利上。
- **适用场景与注意事项**：适用于向系统化、整机化转型的公司（如 AMD、超微、整机 ODM）的收入与毛利拆分。自研件与转售件的毛利率多为推断，需区间化处理。

### 8.1.5 毛利率稳定性归因：品类结构（刚需占比）对比

- **方法要点**：毛利率不仅看水平，更看波动性。若某公司毛利率长期在窄区间内波动，就拆它的商品结构，看刚需高频、低促销依赖的品类是不是“毛利稳定器”，并与可选消费占比高的同业对比。
- **操作步骤 / 拆分口径 / 公式**：
  1. 拉长期毛利率时间序列，判断水平和波动幅度；
  2. 拆商品结构：食品杂货占比、非食占比；
  3. 与可选消费占比高的同业对比结构，说明后者毛利更易受经济周期和季节性影响；
  4. 结合定价机制一起看（定价机制可参见 6.6）。
- **关键指标与数据来源**：毛利率及波动、食品杂货占比、非食占比。
- **判断标准**：毛利率水平可以“中等偏低”，但只要几十年波动极小，就说明品类结构（刚需占比高）提供了稳定性；可选消费占比越高，毛利率越顺周期、波动越大。
- **海豚案例**：
  - 沃尔玛《沃尔玛：“万亿零售真神”…》（2026-04-21）：沃尔玛美国毛利率长期稳定在约 27%（行业中等偏低，但几十年波动极小）；食品杂货占 60%，而 Target 食品仅 23%、非食 77%。
- **适用场景与注意事项**：适用于综合零售。稳定性只说明经营波动小，不等于利润率高；需结合定价机制和费用刚性一起看。

### 8.1.6 毛利率同业对标 + 结构驱动归因（品类、3P）

- **方法要点**：先用业态相近的公司给毛利率定位，再解释“同水平背后的不同来源”，最后把毛利率抬升归因于结构变化，避免把结构性、机械性的抬升误读为盈利能力提高。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把毛利率与业态相近的公司对标，定位水平（落在哪个区间）；
  2. 解释同水平的不同来源：低价商品的高毛利来自供应链压价与产业带直采，而不是品牌溢价；
  3. 把毛利率抬升归因于结构变化：高毛利非标品类的扩张、3P 净额确认占比提升；
  4. 3P 净额确认会机械性抬升毛利率，必须拆开看 1P 与 3P。
- **关键指标与数据来源**：毛利率时间序列、可比公司毛利率、品类结构、3P 占比。
- **判断标准**：同样的毛利率，来源不同含义不同——来自供应链压价说明效率，来自品牌溢价说明定价权；毛利率抬升要先扣除确认口径（总额 / 净额）和品类结构因素，剩余部分才是真实能力的改善。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：过去毛利率约 60%，与 Zara、Lululemon 处同一水平，但对一家卖 6 美元 T 恤的公司而言，这反映的是极致的供应链压价；拓品类（美妆、饰品）与 3P 转型后，集团毛利率升至约 70%。
- **适用场景与注意事项**：适用于零售 / 电商。3P 净额确认带来的毛利率抬升是机械性的，需拆开看；收入口径的影响参见 8.2.3。

### 8.1.7 按客户 / 合同定价机制拆分利润率

- **方法要点**：同一业务里不同客户的定价机制不同，利润率差异是系统性的。分析时追踪各类客户的收入占比，用来解释毛利率的变动。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把业务按客户类型（政府与国防 / 商业）和合同类型（成本加成 / 固定价格 / 市场定价）拆分；
  2. 判断各类合同的利润率特征：政府与国防任务安全要求高、准备周期长、测控复杂，利润率通常低于纯商业发射；国防通信采用成本加成固定利润，合同 5-10 年，利润率不高但确定性很高；
  3. 追踪政府类收入占比、合同类型与合同期限，用占比变化解释毛利率变动。
- **关键指标与数据来源**：政府 / 国防收入占比、合同类型（成本加成 / 固定价格）、合同期限。
- **判断标准**：政府 / 国防发射利润率系统性低于商业发射，政府类占比上升会拉低整体毛利率；成本加成合同虽然利润率低，但提供收入确定性，要在“利润率”与“可见度”之间分别评价。
- **海豚案例**：
  - SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：政府国防发射利润率系统性低于商业发射。
  - SpaceX《Space X：天空之网…》（2026-06-15）：星盾（Starshield）采用“成本 + 固定利润”，合同周期 5-10 年，收入确定性极高。
- **适用场景与注意事项**：适用于有政府客户的军工、航天、IT 服务公司。收入占比之外还要看合同期限和续签条件，合同的可见度分析见 8.4。

### 8.1.8 毛利率与营业利润率分层解读：毛利率看定价权，营业利润率看成本与客流压力

- **方法要点**：把利润率分层读——毛利率反映产品层面的定价权，营业利润率反映运营端的成本与客流压力——再由二者的落差推导管理层动作的财务动因。
- **操作步骤 / 拆分口径 / 公式**：
  1. 毛利率层（仅扣产品与分销原料成本）：若常年稳定，直接印证品牌定价权（原料成本极低，溢价几乎原封不动体现在毛利）；
  2. 营业利润率层：使用 Non-GAAP 口径，剔除门店减值、组织精简等一次性重组费，观察变化及原因（人力与原材料成本抬升、客流走弱）；
  3. 由两层利润率的落差推导管理层的“减重”动作（授权、CPG 版税、合资）的财务动因：把重资产转为轻资产，抬高整体利润率天花板；
  4. 对标轻资产高利润的模式（如麦当劳）判断目标形态。
- **关键指标与数据来源**：毛利率、Non-GAAP 营业利润率、一次性重组费用。
- **判断标准**：毛利率稳而营业利润率下滑，说明问题不在定价权，而在运营端（人工、租金、客流）；落差越大，管理层越有动力把重资产业务转轻。
- **海豚案例**：
  - 星巴克《星巴克：“披着咖啡外衣的银行”，凭何称霸全球四十年？》（2026-07-21）：毛利率常年稳定约 68%；Non-GAAP 营业利润率从 15.0% 降至 9.9%（2025 年下滑约 5pct）；由此推导管理层的“减重”动作（授权、CPG 版税、中国合资），向麦当劳“轻资产高利润”模式靠拢。
- **适用场景与注意事项**：适用于品牌消费、餐饮。“高毛利 + 低营业利润率”的组合提示运营端（人工、租金）是关键矛盾；务必剔除一次性重组费，否则营业利润率会被低估。

### 8.1.9 让利换量背景下的利润率质量检验：靠效率还是靠提价

- **方法要点**：检验利润率的“含金量”——如果在主动压低客单价、需求最弱的阶段利润率反而上升，就说明利润来自内生降本提效而不是提价，这类能穿越周期的利润率比顺周期高盈利更值钱。
- **操作步骤 / 拆分口径 / 公式**：
  1. 确认大背景：需求最弱 + 公司主动让利换量（降价套餐、促销日）；
  2. 观察客单价变化与门店 / 餐厅层面利润率的走势：客单价下行而利润率上行，利润就不可能来自提价；
  3. 拆出利润率上行的两条内生路径：供应链压低食材成本、数字化驱动人效提升；
  4. 与国际一线同业的餐厅层面利润率区间对照，确认水平是否处于合理区间。
- **关键指标与数据来源**：餐厅层面利润率、客单价变化、同行餐厅利润率区间。
- **判断标准**：“价格下行 + 利润率上行”是效率护城河的强证据；能穿越周期、靠效率做出的利润率含金量远高于顺周期高盈利。
- **海豚案例**：
  - 百胜中国《百胜中国：一只“洋鸡”，凭何在东方称王三十年？》（2026-07-02）：过去几年恰为需求最弱、KFC 主动用 9.9 元套餐 + 疯狂星期四让利换量的阶段，主动压低客单价下，KFC 餐厅利润率非但没被侵蚀，反而从 2022 年低谷回升至约 17%（五年从 15% 升至 17%，国际一线 QSR 餐厅层面利润率普遍 15-20%）；利润来自供应链压低食材成本、数字化提升人效这两条内生路径，而非提价。
- **适用场景与注意事项**：适用于消费公司的利润率分析。须同时看客单价和利润率，避免只看利润率；效率型利润率的持续性可结合 8.1.10 的多业态验证。

### 8.1.10 分业态利润率：解释先天差异与修复路径，验证平台能力的可复用性

- **方法要点**：对多业态集团，按业态拆分利润率，先解释业态本身带来的先天差异，再看修复动作的效果，并用弱势业态的改善反推集团平台能力能否复用。
- **操作步骤 / 拆分口径 / 公式**：
  1. 解释业态差异导致的先天承压：休闲正餐门店面积大、堂食占比高、翻台效率低，租金人工等刚性成本摊薄能力弱，餐厅费用率天然高于快餐；
  2. 列修复动作：拓宽价格带、上线平价引流单品、WOW 小型店型压缩租金与人工；
  3. 观察分品牌门店利润率是否稳步修复；
  4. 反推：集团一体化供应链与数字化中台是“可复用的平台能力”，盈利基础偏弱的品牌也能依托集团体系改善。
- **关键指标与数据来源**：分品牌餐厅利润率、门店面积、堂食占比、翻台率。
- **判断标准**：弱势业态在不换底层模式的前提下利润率仍能修复，才说明平台能力可复用；仅靠降价引流却利润率不修复，则说明先天劣势难克服。
- **海豚案例**：
  - 百胜中国《百胜中国：一只“洋鸡”，凭何在东方称王三十年？》（2026-07-02）：第二品牌必胜客（休闲正餐 CDR）先天利润率承压，通过拓宽价格带、平价引流单品与 WOW 小型店型，门店利润率稳步修复，由此验证集团供应链与数字化中台的可复用性。
- **适用场景与注意事项**：适用于多业态餐饮集团。业态比较要同口径（餐厅层面利润率对餐厅层面利润率），避免混入总部费用。

### 8.1.11 1P 自营与 3P 平台的盈利结构拆解

- **方法要点**：公司没有单独披露分业务利润时，借外资行调研估算 1P 自营的 EBIT 利润率，与 3P 平台模式的轻资产高弹性对照，并跟踪 3P 与 1P 的增速差和 3P 占比，判断利润率跃升的路径。
- **操作步骤 / 拆分口径 / 公式**：
  1. 借外资行调研估算 1P 自营电商的 EBIT 利润率（低毛利品类为主，即便履约成本低也小幅亏损）；
  2. 说明 3P 模式：卖家承担库存与商品风险，平台赚佣金 + 履约费 + 广告费，是轻资产高弹性的模式；
  3. 跟踪 3P 与 1P 的 GMV 增速差、3P 占 GMV 比例；
  4. 核对佣金率区间，判断 3P 变现空间；
  5. 用“自己卖货是搬砖生意，帮别人卖货是收租生意”概括结构。
- **关键指标与数据来源**：1P EBIT 利润率、3P 与 1P GMV 增速、3P 占 GMV 比例、佣金率；外资行调研估算。
- **判断标准**：3P 增速持续快于 1P、占比提升，利润率就具备结构性跃升路径；1P 即使亏损，只要被 3P 与广告等高利润业务覆盖，整体盈利仍可改善。
- **海豚案例**：
  - 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：外资行调研 1P 电商 EBIT 约 -2%；3P GMV 增速连续多季度在 30% 以上，快于 1P 的约 25%，3P 已占电商 GMV 约 26%（450 亿美元）；亚马逊和沃尔玛大部分品类佣金率 8%-15%。
- **适用场景与注意事项**：适用于电商平台化分析。外资行估算有误差，需交叉验证；3P 的收入确认口径影响毛利率的可比性（见 8.1.6）。

### 8.1.12 高利润率业务的利润贡献测算（收入 × 利润率）以对冲主业亏损

- **方法要点**：对新兴的高毛利业务，用“收入 × 估算利润率”得出利润贡献，与亏损业务对比，说明其对整体利润的“填补”作用，并解释高利润率的来源。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：利润贡献 = 业务收入 × 估算利润率。
  1. 取高利润率业务（如零售媒体广告）的收入及增速；
  2. 估算该业务的利润率（与主业利润率对比）；
  3. 相乘得到利润贡献额，与亏损业务（如 1P 电商）的亏损额对比，说明填补程度；
  4. 解释高利润率来源：广告位、客户、数据都是现成的，只需搭投放系统、反复变现。
- **关键指标与数据来源**：广告收入及增速、广告利润率、利润贡献额。
- **判断标准**：高利润率业务的利润贡献大于或接近亏损业务的亏损额，即可认为其“填补亏损”，整体盈利改善有支撑；该业务利润率与主业的倍数差距越大，对整体利润的杠杆越强。
- **海豚案例**：
  - 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：Walmart Connect 从 2022 年起高速增长，2025 年增长 45% 达 64 亿美元，利润率超 40%（主业约 5%），2025 年贡献超 26 亿美元利润，填补 1P 自营的亏损。
- **适用场景与注意事项**：适用于零售媒体、平台广告。利润率多为估算，应给出区间；高利润率业务的成长依赖流量与客户基础。

### 8.1.13 同业利润率与有机增长横向对比，归因到商业模式（轻资产 vs 重资产）

- **方法要点**：把核心经营利润率与直接竞争对手对比（看差距是拉大还是收窄），把有机增长与必选消费板块对比，并把差距归因到商业模式、定价权与创新节奏。
- **操作步骤 / 拆分口径 / 公式**：
  1. 将核心经营利润率与直接竞争对手对比，观察差距变化；
  2. 将有机增长与必选消费板块（日化巨头、行业整体）对比；
  3. 把差距归因到商业模式：轻资产浓缩液模式把大宗成本与关税风险转移给装瓶商，重资产全产业链则要承担成本波动；
  4. 叠加定价权与创新节奏的差异。
- **关键指标与数据来源**：核心经营利润率、有机增长率（同业财报）。
- **判断标准**：利润率差距若能由商业模式（轻 / 重资产）解释，则具备结构性；差距拉大且伴随有机增长更优，说明定价权与创新在发挥作用。
- **海豚案例**：
  - 可口可乐《无糖狂飙…》（2026-04-28）：26Q1 核心经营利润率 34%，对比百事 15.7%；有机增长 10%，对比宝洁、高露洁接近持平、北美饮料约 -4%。
- **适用场景与注意事项**：适用于同行业商业模式差异大的公司。对标时先统一口径（核心经营利润率 vs 报告利润率），并说明差异来源，不要只比数字。

### 8.1.14 经营利润率对标，并寻找“真正可比对象”重新定性

- **方法要点**：先与表面同业对标经营利润率，解释差距来源；再指出真正可比的是哪类业务，给公司重新“定性”，并据此决定估值参照。
- **操作步骤 / 拆分口径 / 公式**：
  1. 与表面同业（如线下快时尚）对标经营利润率，列出差距；
  2. 解释差距来源：线下品牌靠租金人力换品牌溢价与定价权，标的把省下的门店钱让渡给消费者与履约；
  3. 看费用结构（履约、营销、技术、管理）和同款售价倍数；
  4. 指出真正可比的业务类型（如自营零售，长期低个位数利润率），据此重新定性，并调整估值倍数参照。
- **关键指标与数据来源**：经营利润率、费用结构（履约、营销、技术、管理）、同款售价倍数。
- **判断标准**：表面同业的利润率差距巨大而又能被业态差异解释时，说明对标对象选错了；真正可比对象的利润率区间才是合理参照。定性改变后，估值参照也要随之改变。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：SHEIN 经营利润率约 4%（技术内容 + 管理费用合计不到 3%），Zara 约 19%、优衣库 16%、H&M 约 8%，线下同款可卖到 SHEIN 的 2-5 倍；真正可比的是亚马逊自营零售，定性为“服装版亚马逊自营，赚运营效率的辛苦钱”。
- **适用场景与注意事项**：适用于跨渠道、跨业态的公司。重定位后估值倍数参照也应调整（可比公司选取见 9.3）。

### 8.1.15 经营利润率跨市场对标，界定“苦生意”中的顶尖水平

- **方法要点**：用经营利润率衡量零售商综合运营效率，与本土同业（含困难年份的亏损案例）对比，解释行业低利润率的结构原因，从而凸显标的长期稳定利润率的稀缺性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取标的长期经营利润率，并取本土同业的利润率区间及亏损年份；
  2. 解释行业低利润率的结构原因：商品同质化、租金 / 人工 / 物流刚性费用高、竞争激烈、无品牌溢价导致容错率极低；
  3. 对比得出标的在“苦生意”里的位置，强调稳定性。
- **关键指标与数据来源**：经营利润率、同业利润率区间与亏损年份。
- **判断标准**：在利润率普遍很低、同业甚至出现亏损的行业里，长期稳定的利润率本身就是稀缺的竞争力证据。
- **海豚案例**：
  - 沃尔玛《沃尔玛：“万亿零售真神”…》（2026-04-21）：沃尔玛经营利润率长期稳定在约 5%，中国本土综合零售普遍 1%-3%，2022 年永辉、大润发、家乐福一度亏损，即巴菲特所说“极难做的苦生意”。
- **适用场景与注意事项**：适用于低利润率行业的龙头论证。跨市场对比要注意会计与租赁口径差异。

### 8.1.16 与传统运营商做盈利能力对比（剔除 / 不剔除折旧摊销两个口径）

- **方法要点**：把新型运营商与传统运营商放在一起比较收入规模与利润率，分别看剔除和不剔除折旧摊销的口径，找出规模经济性差异，再拆原因。
- **操作步骤 / 拆分口径 / 公式**：
  1. 比较两者收入规模；
  2. 分别比较 EBITDA 利润率（剔除折旧摊销）和经营利润率（不剔除）；
  3. 若收入规模只有同行的十分之一而盈利能力远超同行，说明规模经济性更强；
  4. 拆原因：分层定价（同样维护成本，高价等于高利润）；零边际成本（没有最后一公里约束）；低维护成本（没有大规模客服和地面工程车队，地面几乎零维护）；垂直一体化供应链。
- **关键指标与数据来源**：收入规模、EBITDA 利润率、经营利润率、维护性资本开支、人力成本。
- **判断标准**：两个口径都占优才说明优势真实：EBITDA 口径优秀而经营利润率口径偏弱，说明折旧负担重；两口径同时占优，才是真正的结构优势。
- **海豚案例**：
  - SpaceX《Space X：天空之网…》（2026-06-15）：“三、同为通信运营商，Starlink 有何优于同行？”——以传统电信运营商为对标，收入只有同行的十分之一，盈利能力却远超同行，原因见上述四项。
- **适用场景与注意事项**：适用于跨业态对标（新模式对传统模式）。要注意两者所处的生命周期阶段不同，成长期公司的折旧结构尚未稳定。

### 8.1.17 由商业模式推断费用率刚性（开放 IP 生态 → 销售费用两变量）

- **方法要点**：由商业模式推断哪些费用具有刚性，把销售费用率的上升拆成两个具体变量，判断它能不能回落，并对战略定性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把销售费用率上升拆成两个变量：
     - IP 授权费：开放生态（“安卓系”）下靠海量联名撬流量，授权费是销售费用大头，短期难降；
     - 海外直营化前置投入：开店、人员、品牌投放；
  2. 判断只要两个变量未缓和，销售费用率难回落；
  3. 看管理费用率：下降说明后台效率改善，但抵不过前端投入；
  4. 定性为“砸钱换增长”。
- **关键指标与数据来源**：销售费用增速 vs 收入增速、销售费用率、管理费用率。
- **判断标准**：销售费用增速持续高于收入增速、费用率上升且无缓和变量，说明费用刚性；管理费用率下降只能说明后台效率，不能抵消前端投入。
- **海豚案例**：
  - 名创优品（2026-04-01）：销售费用率 +5.3pct 至 26.5%。
  - 名创优品（2026-05-26）：销售及分销费用 14.7 亿、同比 +44%，费用率 +2.8pct 至 25.9%；管理费用 3 亿、同比 +22.8%，费用率 5.5% 降至 5.2%。
- **适用场景与注意事项**：适用于授权 IP 零售、直营扩张期公司。要区分一次性前置投入与长期刚性费用，前者随扩张放缓会回落。

### 8.1.18 营销费用增速 vs 用户增速 vs 下单频次，推断获客成本上升

- **方法要点**：营销费用率明显提升、广告费用增速远超用户增速、而用户频次没有变化时，可推断单位获客成本在上升（钱花得更多，换来的用户和消费没有同步增加）。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取营销费用率及其变动（pct）、广告费用增速、活跃用户增速、下单频次；
  2. 对比：广告费增速 >> 用户增速，且频次几乎不变，则推断获客成本上升；
  3. 结合竞争对手行为解释外因（如对手抬高 Meta、Google 流量竞价）。
- **关键指标与数据来源**：营销费用率及变动 pct、广告费用增速、活跃用户增速、下单频次。
- **判断标准**：广告投入增速超过用户增速的幅度越大、频次没有改善，获客成本恶化越明显；若竞争对手同期抬高流量竞价，则属于外部成本传导。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：2025 年营销费用率提升 4.1pct 至 14.8%，广告费 +26% 至 50 亿美元，远超用户增速，频次几乎不变，得出“获客成本越来越贵”；外因是 Temu 抬高 Meta、Google 流量竞价。
- **适用场景与注意事项**：适用于依赖付费流量的 C 端平台；需排除品牌广告等长期投入的干扰。

### 8.1.19 用分部亏损指引的环比差额推算新业务投入，再叠加集团现金流约束

- **方法要点**：新业务没有单独披露时，用分部指引的环比差额推算投入规模，再叠加集团层面的现金流约束，判断新业务能否“不计代价”地烧钱。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：新业务季度增量投入 ≈ 本季分部亏损指引 - 上季分部亏损（并扣除该分部内其他业务的变动）。
  1. 取分部指引（含新业务在内的“All others”板块亏损）与上季对比，得到环比多亏金额；
  2. 粗算新业务多出的亏损量级，并结合上线时间判断全季投入上限；
  3. 叠加集团层面的约束：自由现金流（经营现金流减 Capex）是否已转负，其他战略投入（补贴、Capex）占用多少，主力造血业务能产出多少利润；
  4. 判断新业务能否不计代价烧钱。
- **关键指标与数据来源**：分部 adj.EBITA 与环比变动；自由现金流；Capex；其他业务亏损；主力业务利润。
- **判断标准**：新业务投入的上限不仅由管理层意愿决定，更由集团现金流约束决定；主力业务利润已被其他战略投入占用、自由现金流已转负时，新业务无法持续高强度烧钱。
- **海豚案例**：
  - 阿里（2026-01-16）：公司指引 12 月季度包含千问在内的“All others”板块亏损约 100 亿，环比多亏约 66 亿，粗算因千问多出的亏损约 50 亿量级；千问 11 月中旬上线，全季买量投入应不会明显超过 100 亿。约束条件：2025 年 6 月季度起经营现金流减 Capex 后的自由现金流已转负，闪购单季仍亏 200 亿以上，Capex 单季 300 亿以上，而淘天每季 adj.EBITA 约 500 亿，已是紧平衡。
- **适用场景与注意事项**：适用于判断新业务的烧钱规模与可持续性。该方法给出的是量级，不是精确值；集团层面现金流与 Capex 的详细分析见 8.3。

### 8.1.20 由竞争策略（错位 vs 正面硬碰）推断费用投入强度

- **方法要点**：用公司选择的竞争策略推断费用投入强度——错位竞争、产品长期定位又不明确时，公司不太可能不计代价投钱；只有正面硬碰硬时才会出现补贴大战。
- **操作步骤 / 拆分口径 / 公式**：
  1. 判断竞争定位：与主要对手是错位还是正面竞争；
  2. 推断费用投入：错位竞争不会出现补贴大战；正面硬碰才会；
  3. 与已发生的补贴战业务（如闪购）类比，推断新业务亏损规模会比它小还是大。
- **关键指标与数据来源**：竞争定位；费用投入。
- **判断标准**：定位错位 → 亏损规模有限；定位正面 → 补贴战风险高。需要与 8.1.19 的量级测算互相印证。
- **海豚案例**：
  - 阿里（2026-01-16）：千问与豆包错位竞争（豆包强在聊天娱乐，千问发力办公和生活助手），不像闪购那样正面硬碰，结论是千问的亏损不会像闪购那么大。
- **适用场景与注意事项**：适用于判断补贴战风险。竞争策略可能随行业格局变化而变，需持续跟踪。

### 8.1.21 分部费用率与利息的分摊方法（大客户集中 → 低 Opex；利息按增量分摊）

- **方法要点**：做分部利润时，把费用和利息合理分配到各分部，避免分部利润被高估或重复扣减。
- **操作步骤 / 拆分口径 / 公式**：
  1. 客户高度集中的业务（单个客户可贡献数百亿营收），销售与管理投入很少，给很低的 Opex 率；
  2. 成熟业务不再需要投入，费用假设基本持平或略降；
  3. 利息：先算全公司远期总利息，扣掉非 AI 业务原本已承担的部分，余下作为 AI 业务需额外承担的利息；
  4. 全程保持分摊口径前后一致。
- **关键指标与数据来源**：分部 Opex / 收入、总利息、非 AI 业务已承担利息、增量利息。
- **判断标准**：分部 Opex 率与客户集中度成反比；利息分摊以“增量”原则归属给引起举债的新业务，避免平均摊给成熟业务。
- **海豚案例**：
  - Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：AI 业务 Opex 按占收入不到 7% 计算；传统业务费用从 26 年起基本持平、略降；AI 部分利息 = 30 财年总利息费用 - 非 AI 业务已承担利息。
- **适用场景与注意事项**：适用于所有 SOTP 分部利润估值（见 9.6）。分摊口径要前后一致；利息的总量测算见 8.3.14。

### 8.1.22 ROE 杜邦三因子拆解：净利率修复 + 资产周转提升 + 权益乘数稳定

- **方法要点**：把 ROE 的变化拆成净利率、资产周转率、权益乘数三个因子，判断回报率的提升来自盈利、效率还是杠杆，并结合资本回报政策评估综合股东回报。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：ROE = 净利率 × 资产周转率 × 权益乘数。
  1. 取 ROE 的起点与终点，分别拆出三个因子：
     - 净利率：由低谷修复至常态中枢（盈利复苏）；
     - 资产周转率：看同店客流回暖、轻资产加盟占比提升带来的变化，通常比净利率更重要；
     - 权益乘数：看长期水平，并检查负债构成（以应付账款、租赁负债等经营性无息负债为主，还是有息负债）；
  2. 结合资本回报政策（回购、分红、FCF 返还比例）判断综合股东回报。
- **关键指标与数据来源**：ROE、净利率、资产周转率、权益乘数、有息负债、FCF 返还比例。
- **判断标准**：ROE 提升来自周转率、净利率，而不是权益乘数（杠杆）时，质量最高；有息负债几乎为零、权益乘数稳定说明回报不靠加杠杆；资本回报越慷慨，综合股东回报越优。
- **海豚案例**：
  - 百胜中国《百胜中国：一只“洋鸡”，凭何在东方称王三十年？》（2026-07-02）（标题为“周转率驱动 ROE 稳步提升”）：ROE 从 2022 年低谷 6.5% 修复至 2025 年 16.7%；净利率 4.6% 回升至约 8% 常态中枢；资产周转率 0.8 升至 1.1（同店客流回暖 + 轻资产加盟占比提升），被认为更重要；权益乘数长期约 2 倍，负债以应付账款、租赁负债等经营性无息负债为主，几乎无有息负债；资本回报方面，长期大额回购、持续分红，2027 年后计划把扣除少数股东分红后的全部自由现金流返还股东。
- **适用场景与注意事项**：适用于正权益的成熟消费公司；对负权益公司（如星巴克）应弃用 ROE，改看其他回报指标。

## 8.2 利润质量与会计口径调整

> 本节导读：本节解决“报表上的利润能不能直接拿来比、能不能持续”的问题，覆盖四类口径陷阱：折旧年限（延长 GPU 寿命是否只是权宜之计）、收入确认方式（总额还是净额、渠道分成）、分部成本分摊（模型训练成本放在集团还是云分部）、集团内部转移定价（隐性补贴）。做同业利润率对标（8.1）、做 SOTP 分部估值（9.6）、或怀疑利润“偏高”之前，都应先过一遍本节。做空报告里的坏账与公允价值核查归 12.2，会计粉饰带来的估值折价归 10.3。

### 8.2.1 分部利润可比调整：把集团层面的模型训练成本重新分摊到云业务

- **方法要点**：集团把模型研发等成本挂在集团层面（不计入云分部），使云业务披露利润率偏高。通过设定“非模型训练支出”的基准并外推，把超出的部分重新挪到云分部，得到可与同业对标的调整后利润率。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：模型训练相关成本 = 集团层面（Alphabet-level）实际经营亏损 - 基准支出；基准支出 = 2022 年集团层面经营亏损 × (1 + 5%)^n。
  1. 识别：DeepMind 等模型研发归入 Alphabet-level activities，导致云业务披露利润率偏高；
  2. 设定基准：以 AI 前的 2022 年集团层面经营亏损视为“训练模型之外的支出”，按 5% 低速增长外推；
  3. 超出基准的部分视为模型训练相关研发，挪到云分部确认；
  4. 重新计算云业务经营利润率，得到调整后水平，并观察趋势是否仍在改善；
  5. 声明估算不精确，看趋势而非绝对值。
- **关键指标与数据来源**：Alphabet-level 经营亏损、2022 基准、增长率假设 5%、调整后云 OPM。
- **判断标准**：调整后云利润率较披露值低约 20pct，说明披露值不能直接对标；但只要调整后的趋势仍在改善，云盈利改善的逻辑就成立。SOTP 给云估值时，不宜直接用披露利润率对标同业。
- **海豚案例**：
  - 谷歌（2026-07-27）：调整后云经营利润率比披露低约 20pct；披露云 OPM Q4'25 30% → Q1'26 33% → Q2'26 36%，趋势向好。
- **适用场景与注意事项**：适用于分部成本分摊口径不一的集团公司，做 SOTP（见 9.6）或同业对标前必需。基准与增长率假设是主观的，应做区间测算。

### 8.2.2 判断延长 GPU 折旧年限是否只是权宜之计

- **方法要点**：关注云厂商延长 GPU 使用年限（降低年折旧额）对利润的影响，并检验这种做法是否可持续：用单位 token 模型验证老卡的单位经济，若老卡在价格战中守不住单位经济，延长寿命就只是权宜之计，会让账面利润显得偏高。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录行业折旧年限变化（如把 GPU 使用年限延长）及管理层 / 行业权威对寿命的表述；
  2. 建立单位 token 模型：老卡在当前价格下的单位 token 成本与收入，判断单位经济是否成立；
  3. 若价格战下老卡单位经济不成立，则延长折旧年限带来的利润抬升是账面上的权宜之计；
  4. 把产业资源倾斜方向落到硬件供应瓶颈上。
- **关键指标与数据来源**：折旧年限；老卡的单位经济。
- **判断标准**：折旧年限越长、而老卡在价格战中单位经济越差，账面利润质量越低；结论是产业资源仍应倾斜到硬件供应瓶颈上，而不是依赖延寿的存量。
- **海豚案例**：
  - 百度（2026-09-07）：行业普遍延长老卡使用期限，黄仁勋亲自认证 A100 可以用到 2029 年，寿命拉长到 10 年；但老卡 H100 已无法在价格战中稳住单位经济模型。
- **适用场景与注意事项**：适用于判断重资产云、IDC、设备租赁公司的利润质量。折旧年限变化的影响要与 Capex 节奏（见 8.3）联动看。

### 8.2.3 收入按总额还是净额确认、渠道分成机制对利润率的影响

- **方法要点**：解释平台 / 分发型业务利润率为什么偏高：一是自家模型的研发费用没有完全计入该业务，二是对外分发第三方模型属于基于流量的渠道分发，按净佣金（净额）确认收入，自然推高利润率。所以跨公司比较利润率前，要先统一收入口径。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式（案例中的分成机制）：渠道方净收入 = 50% × （被分发方毛收入 - 推理成本）。
  1. 识别业务的收入确认方式：总额（毛收入）还是净额（净佣金）；
  2. 看分成机制和分成比例，计算渠道方实际入账；
  3. 看渠道收入占比，判断对利润率的拉动幅度；
  4. 跨公司比较利润率前统一口径（把净额还原成总额，或把毛收入还原成净额）。
- **关键指标与数据来源**：收入确认方式（总额 / 净额）；分成比例；渠道收入占比。
- **判断标准**：净额确认业务的利润率机械地高于总额确认业务；渠道方的分成收入是纯利润增量，所以高利润率不能直接等同于更强的盈利能力。
- **海豚案例**：
  - 百度（2026-09-07）：亚马逊 Bedrock 确认净收入，Anthropic 确认毛收入；分成方式是 Anthropic 的毛收入扣掉推理成本后，剩余部分的 50% 付给 Bedrock 作为渠道费，对 Bedrock 是纯利润增量；据调研，Bedrock 渠道占 Anthropic 总营收的一半。
- **适用场景与注意事项**：适用于平台、渠道、分发型业务的利润率分析。同一业务在不同公司被拆成毛收入或净收入，比较前必须统一（另见 8.1.3 的 MaaS 利润率比较、8.1.6 的 3P 净额确认）。

### 8.2.4 识别内部转移定价的“隐性补贴”：对内成本 vs 对外报价，及单星发射成本对比

- **方法要点**：当集团内部一个业务给另一个业务提供服务时，比较对内成本与对外报价，揭示受益业务实际获得的隐性补贴，再换算成单位成本与竞对对比，判断这是不是竞争对手无法复制的结构性壁垒。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：隐性补贴 = 对外报价 - 对内成本；单星发射成本 = 单次发射成本 ÷ 每次发射卫星数。
  1. 取内部发射成本（约 1500 万美元 / 次）与对外报价（6200 万美元 / 次），差额即为受益业务获得的隐性补贴；
  2. 折算单位成本：单次 1500 万美元除以每次约 24 颗 V2 Mini 卫星，单星发射成本约 60-70 万美元；
  3. 与竞对外购发射服务的单星成本（200-300 万美元以上）对比，约为对方的 1/4 到 1/5；
  4. 判断本质：垄断运力、优先供给内部，因此是对手无法复制的结构性壁垒。
- **关键指标与数据来源**：内部发射成本、对外报价、每次发射卫星数、竞对单星发射成本。
- **判断标准**：对内成本与对外报价差距越大，受益业务的利润率中含有的隐性补贴越多；这类优势来自垂直整合，难以被对手复制；但独立估值时需要把隐性补贴按市场价还原。
- **海豚案例**：
  - SpaceX《Space X：天空之网…》（2026-06-15）：本质是垄断运力、优先供给内部；仅发射一项，Starlink 的成本就是竞品的 1/4 到 1/5。
- **适用场景与注意事项**：适用于垂直整合集团的分部盈利质量评估；分拆或独立估值时要按市场价调整。

**本节速查清单**

- [ ] 披露的分部利润率是否包含了全部相关成本（模型训练、研发等是否挂在集团层面），做 SOTP / 同业对标前是否已重新分摊
- [ ] 资产折旧年限是否被延长；老卡在价格战下的单位经济是否仍成立
- [ ] 业务收入是按总额还是净额确认，分成比例与渠道占比是多少，跨公司比较前是否统一口径
- [ ] 集团内部的服务是否按对外市场价结算；对内成本与对外报价的差额（隐性补贴）有多大
- [ ] 调整后的利润率趋势是否仍在改善（估算不精确时看趋势而非绝对值）

## 8.3 资本开支、现金流与资产负债表

### 8.3.1 模拟管理层视角：用历史“Capex / 新增订单”比率（12 个月滚动）推算投入节奏

- **方法要点**：从电话会表述中提炼管理层判断投入节奏的隐含方法，即回溯同期“投入额”与“订单额”的比例。把历史比率当作基于需求能见度的 ROI 控制指标，发现“投资缺口”后，推算次年 Capex 区间。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：次年 Capex ≈ 按 70% 比率补齐的投资缺口 + 未来新增订单（按季累计到全年）× 65%-85%。
  1. 拉历史数据：12 个月滚动周期内的 Capex / 新增订单，发现其多落在 65%-85%；
  2. 订单失控上行而 Capex 未跟上时，比例跌至 30% 以下，形成“投资缺口”；
  3. 按 70% 的比率补齐缺口；
  4. 假设未来每季新增订单，乘以 65%-85%，得到次年 Capex 区间；
  5. 与另一条测算路径交叉验证。
- **关键指标与数据来源**：滚动 12 个月 Capex、新增订单额、Capex / 新增订单比。
- **判断标准**：比率回到 65%-85% 区间是“补齐缺口”的方向；比率长期低于 30% 说明投入落后于订单，需要补投；两条路径给出同一量级，则可信度提高。
- **海豚案例**：
  - 谷歌（2026-07-27）：比例历史 65%-85%，2025H2 后降至 30% 以下；缺口按 70% 补齐约 2060 亿；按每季 500 亿新增订单（参考 2025 年均 514 亿）全年 2000 亿 × 65%-85% = 1300-1700 亿；合计 2027 年 3300-3700 亿；两法结合，Capex 在 3000-4000 亿，与市场预期一致。
- **适用场景与注意事项**：适用于订单驱动投入的公司；“模拟管理层视角”的思路可迁移到其他资本开支预测。比率区间是历史统计，不是管理层承诺。

### 8.3.2 Capex 自下而上测算：算力投建（GW × 单 GW 成本 × 园区周期）+ 其他 Capex

- **方法要点**：把 Capex 拆成两块——算力投建支出与其他 Capex——自下而上逐园区测算，并在外部报道的算力目标高于自测值时，计算净差和增量 Capex，给出区间。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：算力投建 Capex = Σ（园区规划 GW × 单 GW 平均部署成本），按各园区建设周期分配；总 Capex = 算力投建 + 其他 Capex。
  1. 算力投建支出：各数据中心园区规划 GW × 单 GW 平均部署成本（约 350 亿美元 / GW），按各园区建设周期分配，剔除表外融资部分（如向 Blue Owl 的融资），再按 5 年平均；
  2. 其他 Capex：27 年后按 20% 常规增速；
  3. 得到原预期 26 / 27 年 Capex 1400 亿 / 2030 亿；
  4. 当外部报道的算力目标（14GW）高于自测（27 年底 9-10GW）时，计算净差约 4GW；
  5. 考虑部分采购 TPU 与自研 ASIC 降低综合成本，按 300 亿美元 / GW 计算额外需 1200 亿；
  6. 最终给出区间：今年 1400-1700 亿，明年 2000-2900 亿。
- **关键指标与数据来源**：规划 GW、单 GW 部署成本（350 亿 / 300 亿美元）、园区建设周期、表外融资额、其他 Capex 增速。
- **判断标准**：自测与外部目标有缺口时，用净差 × 单 GW 成本直接量化增量；单 GW 成本随芯片组合（GPU / TPU / ASIC）而异，应给区间而不是单点。
- **海豚案例**：
  - Meta（2026-07-10）：路透报道 Meta 明年算力部署目标 14GW（较今年底翻倍），海豚君原测算 26 年约 7GW、27 年底 9-10GW，少估约 4GW；按 300 亿美元 / GW 额外需 1200 亿，修正后今年 1400-1700 亿、明年 2000-2900 亿。
- **适用场景与注意事项**：适用于超大规模云 / AI 基建公司的 Capex 预测。单 GW 成本因 GPU / TPU / ASIC 组合差异大，需情景化；表外融资需剔除（见 8.3.18）。

### 8.3.3 顶格 Capex 预算推算：次年 OCF + 募资额 + 净现金

- **方法要点**：先测公司的资金实力（OCF、现金、债务、净现金），再推次年“顶格”Capex 预算，用以量化管理层“明年显著增长”的上限，也可反推产业链订单天花板。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：顶格 Capex = 次年 OCF + 募资额（+ 净现金，“油门踩到底”情形）。
  1. 测资金实力：单季 OCF、现金 + 短期投资、短期商业票据、长期有息债务，得到严格口径净现金；
  2. 判断一年内可承受的 Capex 量级（净现金约 250 亿，一年 2500 亿以内 Capex 勉强可承受，超过即融资迫切）；
  3. 推次年顶格预算：次年 OCF（按增长率外推）+ 募资；
  4. “油门踩到底”情形再加净现金；
  5. 与当年 Capex 指引对比（接近翻倍），说明管理层“显著增长”的上限。
- **关键指标与数据来源**：OCF、现金 + 短期投资、商业票据、有息债务、净现金、Capex 指引。
- **判断标准**：顶格预算与指引的比值给出管理层增长的“最大可能”；若预期 Capex 接近顶格，说明融资压力与不确定性都已处于极限。
- **海豚案例**：
  - Google（2026-06-02）：单季 OCF 400-500 亿，现金 + 短期投资 1268 亿，短期商业票据 250 亿，长期有息债务 775 亿，严格口径净现金约 250 亿，一年 2500 亿以内 Capex 勉强可承受；27 年 OCF 约 2400 亿（增长 20%）+ 800 亿募资 = 3200 亿，“油门踩到底”再加 250 亿净现金约 3500 亿，接近 26 年指引 1800-1900 亿的翻倍。
- **适用场景与注意事项**：适用于判断大厂 Capex 上限与融资必要性，也可反推产业链订单天花板。增长率与募资额都是假设，需做敏感性。

### 8.3.4 用资金配置表推算下一年 Capex 预算的上限

- **方法要点**：把公司现金的来源与去向列成资金配置表，在没有额外必需投资的假设下，参照前两年“其他及留存”的规模，倒推下一年 Capex 的最大可用空间。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：Capex 可用空间 ≈ 经营现金流 - 回购 - 分红 - 其他及留存（参照前两年规模）。
  1. 把现金来源与去向列成资金配置表：经营现金流 → Capex、回购、分红、投资、其他及留存；
  2. 观察历史上现金净变动是否一直维持在平衡线附近（基本在平衡线上方或紧贴下方）；
  3. 在没有额外必需投资或运营支出的假设下，参照前两年的“其他及留存”规模，倒推下一年 Capex 最大可用空间；
  4. 说明这只是从可用现金流角度算的上限，实际采购和到货取决于供给。
- **关键指标与数据来源**：经营现金流；Capex；回购；分红；其他及留存；现金净变动。
- **判断标准**：这一方法给出的是“钱的上限”，不是“实际花多少”；若实际 Capex 显著低于上限，要进一步检验是不是供给约束（见 8.3.5）。
- **海豚案例**：
  - 腾讯（2026-01-26）：参照 2024、2025 年“其他及留存”项，测算 2026 年 Capex 预算空间最高超过 1100 亿元，同比 +32%；同一框架下回购约 800 亿元、分红约 450 亿元。
- **适用场景与注意事项**：适用于现金流稳定、资本配置风格稳定的成熟公司。

### 8.3.5 对比 Capex 的现金流出与会计确认额，识别供给约束

- **方法要点**：当公司 Capex 低于预期、被市场诟病“不舍得花钱”时，对比资本开支的实际现金流出与会计确认额，判断是不愿投入还是钱预付了而货未到。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取现金流量表中的购建资产支出（现金流出）与利润表 / 资产负债表中的资本开支确认额；
  2. 比较二者差额（预付款）：现金流出持续大于确认额，说明钱已预付、货没到；
  3. 结合管理层关于算力需求、外部租借算力的表态交叉验证。
- **关键指标与数据来源**：现金流量表中的购建资产支出；资本开支确认额；预付款。
- **判断标准**：现金流出 > 确认额，且差额扩大 → 供给约束（而非投入意愿不足）；二者同步 → 才需检验投入意愿。
- **海豚案例**：
  - 腾讯（2026-01-26）：二季度 Capex 现金流出已大于确认额，三季度差额更大，说明不是腾讯吝啬花钱，而是钱预付了却拿不到货，背后是行业性算力紧缺。
- **适用场景与注意事项**：适用于供给约束期的资本开支分析；注意现金口径与权责发生制口径的差异。

### 8.3.6 单 GW Capex 拆解及商业模式差异解释（租毛坯 DC、客户预付 / 自购 GPU）

- **方法要点**：把公司的单 GW Capex 指引与产业链口径比较，找出差异来源，并根据管理层的新表态下调假设，得出模型使用值。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取公司指引的单 GW Capex，与产业链口径（如英伟达所说的单 GW 总投资）比较；
  2. 找差异来源：公司不自建数据中心，而是向外部供应商租已建好的“毛坯”数据中心，厂房、供电、冷却等投入不进 Capex，而是作为租金进成本；
  3. 根据管理层新表态（部分项目靠客户预付款买设备，或客户直接买好 GPU 交给公司）下调单 GW Capex 假设；
  4. 得到模型用的数值。
- **关键指标与数据来源**：单 GW Capex 指引、产业链单 GW 总投资、租金成本、客户预付款。
- **判断标准**：单 GW Capex 的口径（是否含土建、是否含 GPU）决定可比性；租赁模式会把 Capex 转成长期租赁负债和成本，所以单 GW Capex 低并不等于总投入低。
- **海豚案例**：
  - Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：公司指引每新建 1GW 对应 Capex 约 250 亿美元，明显低于英伟达所说的每 GW 约 500-600 亿；考虑客户预付和客户自购 GPU，模型假设为 200 亿 / GW。
- **适用场景与注意事项**：适用于算力租赁、云厂商、IDC。口径不一致时，只做定性比较。

### 8.3.7 数据中心项目拆解：规模 / 进度、建设速度对标、单 GW 投资额对标与口径提示

- **方法要点**：逐个营址整理计划投资、总算力 GW、开工与运营时间、各期上线规模与芯片数量，得出总产能、建设速度和单 GW 投资，并提示投资额口径的不确定性，只做定性结论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 逐个营址整理：计划投资、总算力 GW、开工与运营时间、各期上线规模与芯片颗数；
  2. 汇总：已宣布总产能与合作协议总量的对应关系，项目建设节奏可作为双方合作关系的风向标；
  3. 建设速度对标：从零到约 1GW+ 的月数，与同业项目（如 Oracle Abilene Phase 2，约 1GW，15 个月）对比；
  4. 单 GW 投资额对标：与 NVIDIA 宣称的每 GW 500 亿框架比较，但提示公司未说明投资额覆盖范围（按常识不太可能含全部芯片服务器），只做定性结论。
- **关键指标与数据来源**：项目投资额、GW、建设周期、芯片颗数。
- **判断标准**：已宣布产能与合作协议规模匹配，且建设节奏与同业相当，则合作进展可信；单 GW 计划投资仅 50-60 亿美元，远低于 NVIDIA 的每 GW 500 亿框架，但因口径不明，只能得出“Trn 单 GW 综合建设成本比 NVIDIA GPU 低不少”的定性结论，不能简单推断为 1/10。
- **海豚案例**：
  - Amazon（2026-06-24）Project Rainier：已宣布总产能约 4.6-4.7GW，对应合作协议的 5GW；从零到约 1GW+ 需 15-16 个月，与 Oracle Abilene Phase 2（约 1GW，15 个月）相当；New Carlisle 计划投入 110 亿、2.2-2.3GW，24 年 9 月开工、25 年 10 月底首次运营（约 50 万颗 Trn2），26 年初一期约 1.3GW（约 170 万颗 Trn2），Trn3 量产后再增 0.9-1GW；Northern Indiana 约 2.4GW、150 亿美元；单 GW 计划投资仅 50-60 亿美元。
- **适用场景与注意事项**：适用于 AI 数据中心项目跟踪；投资额口径不明时只下定性结论。

### 8.3.8 新建产能公告的历史定位：距上座 fab 年限 + 投资规模倍数 + 与管理层既往口径对照

- **方法要点**：解读扩产公告时，把它放到公司自己的历史中：这是第几座同类工厂、距上座工厂多少年、投资规模是上座的几倍，并对照管理层此前的口径，判断策略边际变化及对行业供给的含义。
- **操作步骤 / 拆分口径 / 公式**：
  1. 梳理公司同类工厂的历史序列与投产年份；
  2. 计算本次投资规模相对上一座工厂的倍数；
  3. 对照管理层此前的口径（如“优先靠制程迁移提升单片 bits，而非增加晶圆投入”）；
  4. 判断策略的边际变化，及对行业供给的含义。
- **关键指标与数据来源**：投资总额（清州约 100 万亿韩元，其中 80 万亿 NAND fab、20 万亿 P&T7）、历史 fab 投资额与投产年份、管理层口径。
- **判断标准**：距上座新 fab 年限越长、投资规模倍数越高，说明策略转向越强；若与此前口径冲突，就是强信号；同行扩产则削弱“供给无增量”的叙事。
- **海豚案例**：
  - SK 海力士《海力士赴美，来讨一个 “公道估值”？》（2026-07-10）：M17 是海力士自建的第四座闪存工厂（前为 M11、M12、M15），也是 NAND 领域九年来首座新 fab（上一座 M15 于 2018 年投产），投资规模（约 80 万亿韩元）为当年 M15 的四倍；对照管理层此前“NAND 优先靠迁移到 321 层提升单片 bits，而非增加晶圆投入”的口径，策略出现边际变化。
  - 闪迪《比 DRAM 还摇钱树，闪迪真有那么香？》（2026-08-17）：引用“海力士 NAND 业务已决定新建产线”，作为同行会扩产的反证。
- **适用场景与注意事项**：适用于周期性制造业的产能投资事件，需关注产能规划、投产时间与竞争者反应。

### 8.3.9 从监管申请文件和产能目标反推资本开支规模与融资需求

- **方法要点**：用公司向监管机构提交的申请文件和公开产能目标，推断未来资本开支的数量级，再与现有现金流来源对比，判断是否需要外部融资。监管文件是领先指标，往往比财报更早透露战略规模。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取监管申请文件中的规划规模（如 FCC 文件中的卫星数）与公开的产能目标（如 100GW 太阳能）；
  2. 推断资本开支的数量级；
  3. 与现有现金流来源对比，判断是否需要外部融资；
  4. 判断融资急迫性的主因。
- **关键指标与数据来源**：FCC 申请卫星数（100 万颗轨道数据中心）、太阳能产能目标（100GW）、发射 AI 卫星时间（2-3 年内）。
- **判断标准**：规划规模远超现有现金流承受力，则外部融资不可避免；这类文件揭示的是“战略规模”而非“已落地的开支”。
- **海豚案例**：
  - SpaceX《马斯克再甩“王炸”…》（2026-02-24）：FCC 文件显示规划 100 万颗卫星的“轨道数据中心系统”，同时布局 100GW 太阳能，据此认为急于融资的主因是极大规模资本开支。
- **适用场景与注意事项**：适用于电信、航天、能源等需要牌照或申报的重资产行业；申请规模不等于实际部署。

### 8.3.10 跟踪新业务研发和 Capex 指引，以及老业务承压时的资本开支背景

- **方法要点**：把公司公布的投入计划当作战略决心和未来费用压力的指标记录，并与当前现金流、基本盘毛利率结合看：投入越大、基本盘越弱，新业务兑现的紧迫性越高。
- **操作步骤 / 拆分口径 / 公式**：
  1. 记录年度研发 + Capex 指引、多年累计投入计划及投向；
  2. 结合基本盘毛利率与经营现金流，判断投入的资金来源与压力；
  3. 判断新业务兑现的紧迫性：基本盘越弱，新业务越需要提供新的现金流支撑；
  4. 持续跟踪实际支出与指引的偏差。
- **关键指标与数据来源**：年度研发加资本开支指引；多年累计投入计划；投入方向；基本盘毛利率；经营现金流。
- **判断标准**：投入指引越大、基本盘越承压，新业务能否兑现越成为估值关键。
- **海豚案例**：
  - 小米《小米（春季发布会）：SU7“低调”换代，MiMo 限免冲榜》（2026-03-20）：预计当年 AI 研发和资本开支超过 160 亿元，未来三年总投入 600 亿元，主要投向大模型、具身智能和 AI 应用。
  - 特斯拉《Cybercab 发布会：告别概念，开启 Robotaxi 大时代？》（2026-09-04）：2026 年资本开支预计超过 250 亿美元，同时卖车毛利率承压（26Q2 汽车毛利率 16.3%，环比下降 3 个百分点），因此 Robotaxi 能否提供新的现金流支撑成为估值关键。
- **适用场景与注意事项**：适用于大额投入新业务的科技和制造公司。要跟踪实际支出与指引的偏差。

### 8.3.11 Capex / 收入对照 OCF / 收入的现金流承受力测试

- **方法要点**：用两个比率对比判断投入的可持续性：Capex 占收入比对照经营现金流占收入比，前者大于或等于后者，意味着日常经营现金流全部投入算力，再叠加对外投资、债务利息，自由现金流将连续为负。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：自由现金流占收入比 ≈ OCF / 收入 - Capex / 收入。
  1. 计算 Capex / 收入（如 26 / 27 年 55% / 65%）与 OCF / 收入（50%-60%）；
  2. 比较二者：Capex 占比 ≥ OCF 占比，则经营现金流全部投入算力，连续负自由现金流不利于经营稳定；
  3. 结合公司现金管理习惯（Cash Neutral）与资产负债表（现金 + 短期投资、长期债务），判断是否需要动用存款与现金储备、后续是否需要债务融资；
  4. 列出可用工具：发公司债、私募信贷表外融资。
- **关键指标与数据来源**：Capex / 收入、OCF / 收入、FCF、现金 + 短期投资、长期债务。
- **判断标准**：Capex / 收入长期高于 OCF / 收入，则不可避免依赖外部融资；公司的现金管理习惯（如 Cash Neutral）决定融资节奏。
- **海豚案例**：
  - Meta（2026-07-10）：Capex 占收入比 26 / 27 年 55% / 65%，对照 OCF 占收入比 50%-60%；原 Capex 预期下两年经营现金流全拿去投算力；资产负债表上现金 + 短期投资 810 亿、长债 590 亿；短期需动用存款与现金储备，后续债务融资少不了（发公司债、私募信贷表外融资）。
- **适用场景与注意事项**：适用于重资本开支阶段的大型科技公司；OCF 利润率假设需随业务变化调整。

### 8.3.12 Capex ÷ 收入、Capex ÷ 经营现金流、净负债 ÷ 权益，结合 Capex 高峰时点做压力测试

- **方法要点**：用 Capex 相对收入、相对经营现金流的倍数和净负债 / 权益衡量当下的资产负债表压力，再用历史现金支出模式和 Capex 高峰时点判断“真正的压力测试还没到”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取最新指引：总 Capex 相对当年预期总收入的占比、相对预期经营现金流的倍数；
  2. 缺口只能靠消耗现金或发债填补；
  3. 看资产负债表现状：现金余额、净负债 / 股东权益；
  4. 看历史：现金支出是否几乎每年都高于经营现金流（早年用于大规模回购和收购，属于“举债经营”）；
  5. 看时点：数据中心投产高峰与 Capex 高峰所在财年，判断压力测试的时间窗口；
  6. 极端情形：若出现黑天鹅，是否存在资不抵债、股东权益归零的风险。
- **关键指标与数据来源**：Capex、Capex / 收入、Capex / 经营现金流、现金余额、净负债 / 股东权益、历史现金支出 vs 经营现金流。
- **判断标准**：Capex 占收入 75%、是经营现金流 2 倍多，说明现金缺口巨大；净负债已接近股东权益 3 倍，又处于举债经营的历史模式，高峰期还没到，说明风险未充分暴露。
- **海豚案例**：
  - 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：FY26 总 Capex 翻倍到 500 亿美元，相当于当年预期总收入的 75%、预期经营现金流的 2 倍多；截至 2Q26 现金不到 200 亿，净负债已接近股东权益的 3 倍；FY16 以来现金支出几乎每年都高于经营现金流；数据中心投产高峰从 FY28 开始，所以 Capex 高峰从 FY27 左右开始，真正的压力测试还没到。结论：若出现黑天鹅，存在资不抵债、股东权益归零的风险。
- **适用场景与注意事项**：适合重资产扩张期的公司（AI 云、半导体、新能源）。需要结合资本开支高峰期前瞻判断。

### 8.3.13 用季度净现金流出与有息负债 / 账面净资产衡量重资本扩张对股东权益的风险

- **方法要点**：对靠举债做前置 Capex 的公司，单独追踪两个指标：连续季度的净现金流出规模，以及有息负债相对股本账面价值的倍数。两者叠加说明资产负债表风险，据此把标的定性为“博弈性标的”，估值环节配套悲观情境。
- **操作步骤 / 拆分口径 / 公式**：
  1. 追踪连续季度的净现金流出（FCF 或净现金变动）；
  2. 计算有息负债 / 股东权益账面值；
  3. 两者叠加说明公司承担的资产负债表风险：需求证伪或执行失误时，可能出现大额坏账乃至股东权益归零；
  4. 定性：确定性不高、向上向下弹性都大的博弈性标的；
  5. 在估值环节配套悲观情境。
- **关键指标与数据来源**：季度净现金流、自由现金流、有息负债 / 股东权益账面值、Capex 占经营现金流比。
- **判断标准**：连续净现金流出且有息负债倍数高，则风险与机遇并存，不能按稳健成长股的方法估值。
- **海豚案例**：
  - Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：连续两个季度净现金流出约百亿，有息负债达股本账面价值的 2.4x，因此定性为风险与机遇并存的博弈性标的。
- **适用场景与注意事项**：适用于 AI 算力租赁、Neocloud、重资产扩张期的云厂商和制造业。账面净资产可能因回购被压低（Oracle 历史上大额回购），倍数偏高时要结合现金流和利息覆盖一起看。

### 8.3.14 按 Capex 的举债比例和平均利率测算利息峰值，并与对标公司的借贷成本对比

- **方法要点**：公司已处于净负债且 FCF 紧张时，保守假设 Capex 中较高比例靠新增负债承担，结合平均利率估算利息费用峰值及其占收入比，再与同类公司的借贷成本对比，论证融资成本的优势或劣势。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：新增负债 = Capex × 举债比例；利息费用 ≈ 累计负债 × 平均利率；利息 / 收入 = 利息费用 ÷ 当年收入。
  1. 保守假设 Capex 中较高比例靠新增负债，并随 Capex 峰值过去、经营现金流能覆盖 Capex 后下调该比例；
  2. 结合历史平均负债利率和市场预期设定利率区间；
  3. 算出利息费用峰值及其占收入比；
  4. 与同类业务公司的借贷成本、利息 / 收入比对比，论证融资成本优势或劣势。
- **关键指标与数据来源**：Capex、新增负债 / Capex 比例、平均负债利率、利息费用、利息 / 收入。
- **判断标准**：同样的 Capex 强度下，借贷成本越低、利息 / 收入越小，融资成本优势越明显；利息峰值占收入比越高，对利润率与 FCF 的挤压越大。
- **海豚案例**：
  - Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：假设 28~29 财年 Capex 的 70%~75% 靠新增负债，30 财年降为 20%；平均利率 4.6%~5%；30 财年利息支出峰值约 110 亿美元，占当年收入 5%；对标 CoreWeave，平均借贷成本 10% 以上，利息可占收入约 20%，所以融资成本是 Oracle 相对 CoreWeave 的重大优势。
- **适用场景与注意事项**：适用于重资产扩张、杠杆驱动的公司。利率环境和信用评级变化会显著改变结论；利息的分部分摊见 8.1.21。

### 8.3.15 负营运资本 + 低资本开支，判断“现金奶牛”

- **方法要点**：综合在手现金、有息负债、收付款节奏（消费者先付款、供应商后结算形成负营运资本）、Capex 占收入比，判断即使利润率低，公司现金创造能力是否强，为分红承诺与估值下限提供支撑。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取在手现金、有息负债；
  2. 看营运资本周期：消费者先付款、供应商后结算形成负营运资本；
  3. 看 Capex 及其占收入比；
  4. 综合判断现金创造能力，并衔接分红承诺与估值下限。
- **关键指标与数据来源**：在手现金、有息负债、营运资本周期、Capex 及其占收入比。
- **判断标准**：在手现金充沛、几乎无有息负债、Capex 占收入比极低，即使利润率低，也可判定为现金奶牛。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：截至 26Q1 在手现金 148 亿美元，几乎无有息负债，每年 Capex 仅 2-3 亿美元（占收入不足 1%），定性为标准现金奶牛。
- **适用场景与注意事项**：适用于零售、平台类轻资产公司；需警惕供应商账期被动拉长带来的“伪现金流”。

### 8.3.16 储值卡浮存金分析：“披着咖啡外衣的银行”

- **方法要点**：在现金流分析中挖掘容易被忽略的来源——预付储值：消费者先充值后消费，公司常年沉淀无息浮存金，降低营运资金占用与外部融资成本，并与高周转、轻库存的零售底子一起构成强现金流的一部分。
- **操作步骤 / 拆分口径 / 公式**：
  1. 从资产负债表识别预付储值余额（递延收入中的储值卡负债）；
  2. 判断沉淀规模：常年沉淀 15 亿美元以上的无息浮存金；
  3. 评估对营运资金占用与外部融资成本的降低作用；
  4. 叠加高周转、轻库存的零售底子，给出“像银行一样吸纳低成本预付款”的定性标签。
- **关键指标与数据来源**：储值卡负债余额（递延收入）、营运资金占用。
- **判断标准**：浮存金规模越大、越稳定，越能降低营运资金占用；其增速变化反映用户粘性。
- **海豚案例**：
  - 星巴克《星巴克：“披着咖啡外衣的银行”，凭何称霸全球四十年？》（2026-07-21）：星礼卡浮存金 15 亿美元以上。
- **适用场景与注意事项**：适用于有预付卡、会员预存、订阅预收的消费 / 服务公司；需关注浮存金增速变化反映的用户粘性。

### 8.3.17 采购承诺与 SPV 担保的“未来权利 vs 潜在义务”不对称分析

- **方法要点**：从 10-Q 附注读取已签约未履行的采购承诺，追踪环比增量与 1 年内到期部分，识别约束最硬的合同，并补充 SPV 租金 / 设备担保；对比订单（权利）与承诺（义务）的约束性，判断算力紧张与过剩两种情形下的盈亏不对称。
- **操作步骤 / 拆分口径 / 公式**：
  1. 从 10-Q 附注读取采购承诺总额，追踪环比增量与 1 年内到期部分；
  2. 拆分固定金额 / 有担保部分；
  3. 识别约束最硬的合同：能源照付不议、终止罚金；
  4. 补充 SPV 租金 / 设备担保（类比 Meta 与 Blue Owl）；
  5. 对比 Backlog（权利）与承诺（义务）的约束性：算力紧张时对公司有利，算力过剩时双压（Backlog 兑现不力 + 采购照付）；
  6. 总结：公司已变成拿现金流加杠杆博弈 AI 超额回报的重资产风险生意，定价在成长溢价与回本质疑间撕扯。
- **关键指标与数据来源**：采购承诺总额及环比、1 年内到期额、固定 / 担保部分、能源协议期限、SPV 担保额。
- **判断标准**：义务的约束性强于权利（固定金额、有担保、照付不议、期限长）时，下行情景更脆弱；权利端约束弱而义务端约束强，则为不对称风险。
- **海豚案例**：
  - 谷歌（2026-07-27）：Q2 10-Q 采购承诺 8110 亿，环比净增 3000 亿，1 年内 2000 亿，固定或有担保 7070 亿；能源服务协议期限 2-26 年、义务延至 2054 年、照付不议，预计 2030 年前履行；SPV 担保类似 Meta 与 Blue Owl 的 300 亿合作。
- **适用场景与注意事项**：适用于重资本投入期的大型科技公司；需阅读 10-Q / 10-K 承诺与或有事项附注。Backlog 约束力的对标见 8.4.11。

### 8.3.18 数据中心合资（JV）表外融资识别，风险评估时加回表外负担

- **方法要点**：处理巨头的数据中心合资公告时，判断是否为新增规划、拆总成本与出资比例、类比已有结构，识别其“表外融资”的实质，并在风险衡量时加回表外负担。
- **操作步骤 / 拆分口径 / 公式**：
  1. 判断是否新增规划：是不是公司早已确定的自有数据中心之一；
  2. 拆总成本与出资比例（总成本含土地、建筑、电网、冷却）；
  3. 类比已有结构（如 Meta 与 Blue Owl 模式），画运作关系图；
  4. 判断实质：本质是 1P 自用数据中心，目的是减少表内可见负担，实为用巨头担保与优质信用变现；
  5. 风险衡量时必须加回表外负担，并横向联系同业的表外扩张算力，视为 Big Tech 通用做法。
- **关键指标与数据来源**：项目算力（GW）、总建设成本、出资比例、上线时间、担保 / 租赁承诺。
- **判断标准**：JV 的使用方与担保方都是公司自身时，就应把这部分租赁承诺和担保视同债务加回，否则杠杆被低估。
- **海豚案例**：
  - Meta《(短评)Meta 与 BlackRock 数据中心合资》（2026-07-28）：El Paso 是 Meta 早定的五大自有数据中心之一，1GW，2028 年运营；总成本 140 亿美元（含土地、建筑、电网、冷却），BlackRock 80% / Meta 20%；类比 Meta 与 Blue Owl 模式；同文提及前一日谷歌资本开支点评中的表外扩张算力。
- **适用场景与注意事项**：适用于 AI 资本开支较重的云厂商与巨头的杠杆评估；需查 10-K 中的租赁承诺、VIE 与担保条款。只有主营良好的巨头能用这种方式融资。

**交叉引用**

- 用分部亏损指引的环比差额推算新业务投入、再叠加集团现金流约束的方法，详见 8.1.19。

**本节速查清单**

- [ ] 次年 Capex 是否用了至少两条独立路径交叉验证（历史 Capex / 订单比率、自下而上 GW 测算、顶格预算、资金配置表）
- [ ] 单 GW 投入的口径是否一致（是否含土建 / GPU、自建 vs 租赁、客户预付与自购），口径不明时是否只下定性结论
- [ ] Capex 低于预期时，现金流出与会计确认额的差额是否提示供给约束，而不是投入意愿不足
- [ ] 扩产公告是否放到公司历史中定位（距上座工厂年限、规模倍数、与既往口径是否冲突）
- [ ] Capex / 收入与 OCF / 收入的对比、净负债 / 权益、季度净现金流出：是否已识别出压力测试的时点（Capex 高峰）
- [ ] 举债比例与利率是否测算了利息峰值及其占收入比，并对比了同类公司的融资成本
- [ ] 低利润率公司是否检验了现金奶牛特征（负营运资本、浮存金）以及“伪现金流”（被动拉长的供应商账期）
- [ ] 表外项目（采购承诺、SPV 担保、JV 表外融资）是否已加回风险衡量，且权利与义务的约束性是否对称

## 8.4 订单、合同与收入可见度

> 本节导读：本节解决“订单到底有多真、能转化成多少收入、可见度能覆盖到哪一年”的问题。方法分两条线：一条是订单本身的量与质（大单相对化、RPO 与合同期的覆盖率、在手订单拆分、客户多元化与复购、订单结构迁移、签约到落地的转化、合同拆解成 ARR、隐含单价倒推）；另一条是长协与 Backlog 的约束力（四维拆解、实质保护力、押金与担保、同业长协策略对比、循环融资识别）。订单驱动的公司（云、算力租赁、设备、周期品长协）在验证管理层指引（见 8.5）、搭建盈利预测（见 8.6）前先用本节；大单客户的信息拼图推断见 1.5，Capex 与融资端的约束见 8.3。

**方法选择速览**

| 要回答的问题 | 优先使用的方法 | 编号 |
| --- | --- | --- |
| 天量订单到底有多大（相对公司体量） | 订单 ÷ 上年营收，订单 ÷ 上期末 RPO | 8.4.1 |
| 在手订单能不能支撑收入目标 | RPO ÷ 平均合同期；RPO 按期限分段覆盖率与缺口 | 8.4.2、8.4.3 |
| 订单由什么构成、能覆盖几年产能、与指引是否一致 | 产品 / 服务拆分 → 对应容量 → 覆盖年限 → 指引交叉验证 | 8.4.4 |
| 订单质量好不好 | 客户多元化、试点到标配、老客户复购倍数；区域与客户结构迁移 | 8.4.5、8.4.6 |
| 签约多，能不能真正转成业绩 | 以 GW 计的订单追踪 + 落地转化检验 | 8.4.7 |
| 大合同到底值多少收入 | 合同拆解汇总 ARR；长期合同隐含单价倒推 | 8.4.8、8.4.9 |
| 长协有多“硬” | 四维拆解；Backlog 约束力对标；实质保护力拆解；同业长协策略对比 | 8.4.10 至 8.4.13 |
| 订单是不是“用自己的钱买来的” | 循环融资识别 | 8.4.14 |

### 8.4.1 大单规模相对化：订单 ÷ 上年营收、订单 ÷ 上期末 RPO

- **方法要点**：面对“惊天一响”的天量订单，先把绝对值换成相对量级，再讨论其意义。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：订单 / 营收倍数 = 新签订单 ÷ 上年总营收；订单 / RPO 倍数 = 新签订单 ÷ 上期末未履约合同余额。
  1. 取新签合同额；
  2. 除以上一财年总营收，得到“订单相当于几倍年营收”；
  3. 除以上期末 RPO，得到“相当于存量积压的几倍”；
  4. 用这两个比值直观说明订单对公司体量的颠覆程度。
- **关键指标与数据来源**：新签合同额、上年营收、上期末 RPO。
- **判断标准**：订单是营收的数倍、是存量 RPO 的数倍，说明公司业务体量面临重估；但“相对化”只解决量级，订单的质量与兑现仍需后续方法检验（见 8.4.3 至 8.4.14）。
- **海豚案例**：
  - 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：F1Q26 新签约 3000 多亿美元需求合同，相当于 FY25 总营收的 5.8 倍，是 F4Q25 末未履约合同余额（1380 亿）的近 2.4 倍。
- **适用场景与注意事项**：适合大订单驱动的公司（云、军工、设备、建筑）。

### 8.4.2 订单覆盖度检验：RPO ÷ 平均合同期 vs 年化收入目标

- **方法要点**：用已有 RPO 总额除以平均合同期限，得到在手订单能支撑的年化收入，与管理层的年化收入目标比较，判断目标是否已有订单支撑、还需要新签多少。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：订单可支撑的年化收入 ≈ RPO ÷ 平均合同期；缺口 = 年化收入目标 - 订单可支撑的年化收入。
  1. 取最新 RPO 总额与平均合同期；
  2. 计算可支撑的年化收入；
  3. 与管理层年化收入目标比较，得到缺口；
  4. 同时检查利润率目标是否已有验证。
- **关键指标与数据来源**：RPO、平均合同期、年化收入目标。
- **判断标准**：可支撑的年化收入显著低于目标时，目标依赖大量新签订单，可信度要打折；稳态利润率目标是否可实现要单独验证。
- **海豚案例**：
  - CoreWeave（2026-05-08）：按已有订单金额（约 994 亿）和 5~6 年的平均合同期（折合每年约 165-200 亿），还不足以支撑 27 年末年化收入 300 亿的目标；25%~30% 的稳态经营利润率能否实现也还未知。
- **适用场景与注意事项**：适合长约型商业模式（云、IDC、长协供应）。平均合同期是粗算，实际收入是爬坡的，不是平均分布；更细的分期限口径见 8.4.3。

### 8.4.3 RPO 按履约期限分段，计算分年覆盖率与缺口，验证远期收入与指引

- **方法要点**：把公司披露的 RPO 按履约期限分段，分别对应自己（或管理层指引）的分年收入预测，计算覆盖率，进而推算在手订单能支持的单年营收峰值与目标缺口，检验指引的可信度。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：覆盖率 = 某期限段 RPO ÷ 对应年份的收入预测（或指引）之和；缺口 = 对应年份收入预测 - 该段 RPO。
  1. 把 RPO 按披露期限分段（如未来 12 个月、13-24 个月、13~36 个月、37~60 个月等），对应到各财年的收入预测 / 指引；
  2. RPO 没有按业务披露时，做归属假设：参考管理层表述或投行观点，把长期限 RPO 视为主要来自某一业务（如云基础设施 OCI）；
  3. 计算各段覆盖率，并推算在手订单能支持的单年营收峰值；
  4. 找出被覆盖年份（确定性高）和未被覆盖年份（依赖新签大单），并解读管理层对前景的态度。
- **关键指标与数据来源**：分期 RPO、RPO 中云业务占比、分年收入预测 / 指引、覆盖率、可支持的营收峰值、缺口。
- **判断标准**：近端年份被 RPO 完全覆盖，指引确定性高；远端年份覆盖率低、缺口大，则公司必须继续拿到大单才能完成指引，这既是风险，也暗示管理层对前景乐观。
- **海豚案例**：
  - 变体 A（逐期限覆盖 + 峰值推算）：Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：RPO 没有按业务披露，参考投行观点“至少 90% 来自 OCI，且越远期来自 OCI 的比重越高”，于是把 12 个月以上的 RPO 全部视为 Core OCI；13~36 个月的未履约余额（原文写作 171 亿，按量级推算应为约 1710 亿）覆盖 28~29 两财年 Core OCI 预测营收之和的 91% 以上；37~60 个月的余额（原文 193 亿，量级约 1930 亿）只能覆盖 30~31 两财年的 58%；结论：在手订单最多能支持 Core OCI 单年营收峰值约 1000 亿，与 30 财年 1500 亿目标有不小缺口。
  - 变体 B（四段 RPO 对应分年指引）：甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：把最新 RPO 按公司披露的确认期限分成四段（未来 12 个月、13-24 个月等），分别对应 FY26、FY27-28、FY29-30 的收入指引；电话会说云 RPO 约占总 RPO 的 95%，加上公司指引 OCA 不会明显增长，可以粗略把 12 个月以上的 RPO 全部视为 OCI；结果是 FY26-28 三年的 OCI 预期收入完全可以由现有 RPO 覆盖，确定性高；FY29 之后现有 RPO 只能覆盖 OCI 预期收入约 62%，两年还有约 1100 亿美元缺口，所以公司必须继续拿到大单才能完成指引，也暗示管理层对前景很乐观。
- **适用场景与注意事项**：适用于有大额长期合同或 RPO 披露的公司（云、算力租赁、企业软件、设备、工程）。归属假设必须合理并注明；RPO 可能含取消条款或客户信用风险，集中于少数客户时要叠加客户兑付能力分析。

### 8.4.4 在手订单拆分：产品 vs 服务 → 对应容量 → 覆盖产能年限 → 与管理层指引交叉验证

- **方法要点**：把在手订单拆成产品订单与服务订单，换算成对应装机容量（GW），对照产能与年度交付目标看覆盖年限，再与管理层的收入与毛利率指引交叉验证；订单、产能、指引三者一致，指引可信度就高。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取在手订单总额及产品 / 服务拆分，计算各自同比；
  2. 把产品订单换算成对应装机容量（GW）；服务订单看期限（与 PPA 一致的长周期运维，高毛利现金流）；
  3. 与产能对照：现有产能、产能扩张计划，判断订单覆盖几年产能、是否已锁定下一年度；
  4. 追踪新签订单及对应容量，与上一期在手容量比较；
  5. 与管理层指引（收入增速、毛利率）交叉验证，并关注指引是否被上调。
- **关键指标与数据来源**：在手订单金额、产品 / 服务结构、对应 GW、对年度交付的覆盖倍数、新签订单、营收与毛利率指引。
- **判断标准**：订单对年度交付 / 产能的覆盖倍数越高、覆盖年限越长，加上指引上调、新签仍超过上期末在手容量，说明能见度高；订单转化率、价格和产能爬坡仍是需要持续跟踪的风险。
- **海豚案例**：
  - 《AI 电荒突围》（2026-04-14）：BE 截至 2025 年底在手订单约 200 亿美元，创历史新高；产品订单约 60 亿美元（同比 +140%），对应约 2GW 潜在部署容量；服务订单约 140 亿美元（+46%），体现 PPA 模式下长周期运维的高毛利现金流；现有产能约 1GW，计划 2026 年底翻倍到 2GW，在手订单已完全覆盖 2026 年规划产能并部分锁定到 2027 年；管理层指引 2026 年收入增速超 50%、Non-GAAP 毛利率超 32%；订单、产能、指引三者一致，指引可信度高。
  - Bloom Energy（2026-07-20）：2025 年底在手订单约 200 亿美元（创新高）= 产品订单约 60 亿美元（同比 +150%，对应约 2GW，已覆盖 2026 年 900MW-1GW 交付目标并开始锁定 2027 年后）+ 服务订单约 140 亿美元（多为长期运维，期限与 PPA 一致 10-15 年，项目落地后形成长期稳定收入）；2026H1 新签产品订单超 80 亿美元，含 AEP 900MW 期权、Oracle 首期 1.2GW、Nebius 328MW，对应约 2.4GW，已超过 25 年底在手产品容量；指引上调：2026 年营收 34-38 亿美元，中值同比约 +80%，Non-GAAP 毛利率约 34%，均远超此前市场预期（可与上一条案例中 4 月时点的指引——收入增速超 50%、Non-GAAP 毛利率超 32%——对照，看指引如何随订单被上调）。
- **适用场景与注意事项**：适用于订单驱动型制造、设备公司与成长股。需关注订单转化率、价格和产能爬坡风险。

### 8.4.5 订单质量三维：客户多元化、标杆客户从试点到标配、老客户复购倍数

- **方法要点**：不只看订单量，还要看质量：客户是否从单一大客户扩展到多类核心玩家；标杆客户是否从试点走向标配；老客户的复购倍数是否验证了技术可行性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 客户多元化：客户类型数及结构的变化（CSP、公用事业、基础设施资本、托管服务商、Neocloud 等）；
  2. 标杆客户从试点到标配：首个小规模试点 → 扩大到数 GW 计划，并看替代方案的比例（原规划的备选方案被完全替换）；
  3. 老客户复购：框架协议行权的倍数、战略合作金额的扩张倍数；
  4. 用复购验证技术可行性。
- **关键指标与数据来源**：客户类型数、单客户规模扩张倍数、方案替代比例。
- **判断标准**：客户从 1 家扩展到多类核心玩家，标杆客户 100% 替换原方案，老客户复购倍数高，三者同时出现时订单质量最高；仅有单一客户或仅有试点订单则质量偏低。
- **海豚案例**：
  - Bloom Energy（2026-07-20）：客户结构从仅服务一家大型云客户扩展至多类核心玩家（CSP Oracle、公用事业 AEP、基础设施资本 Brookfield、托管服务商 Equinix、Neocloud Nebius 与 CoreWeave）；Oracle 2025 年 7 月签首个小规模试点，55 天交付 100MW，2026 年 4 月扩至 2.8GW 计划，其中原规划燃机 + 柴油备用方案的项目 100% 改用 SOFC，说明可完全作为大型数据中心基荷电源；AEP 从 100MW 框架协议行权到 900MW，规模 9 倍；Brookfield 合作从 50 亿增至 250 亿美元，约 8GW。
- **适用场景与注意事项**：适用于 B2B 设备与解决方案公司。区域与客户结构的迁移见 8.4.6。

### 8.4.6 用订单区域结构和客户结构的迁移证明公司角色转变

- **方法要点**：判断公司是否从“政策补充能源 / 套利工具”变成“基载主力”，用订单的区域、客户、粘性三个结构变化作为证据。
- **操作步骤 / 拆分口径 / 公式**：
  1. 区域迁移：比较早期与当期订单中“高电价州”和“低电价州”的占比，判断驱动逻辑从套利电价差转向获取基载电力；
  2. 客户结构：高优订单客户数量（从 1 家增至多家），并看深度绑定的战略客户；
  3. 粘性：工商业领域老客户增购占比；
  4. 以关键年份为分水岭，划分示范验证期与规模化期。
- **关键指标与数据来源**：高 / 低电价州订单占比、超大规模客户数、老客户复购占比、单客户订单规模。
- **判断标准**：订单区域从“高电价州套利”转向“低电价州刚需”、客户数量大幅增加、老客户复购占比高，说明公司驱动力已从补贴 / 套利切换到刚需。
- **海豚案例**：
  - 《AI 电荒突围》（2026-04-14）：2024 年超 80% 订单来自美国“高电价州”（逻辑是套利电价差）；到 2026 年超 80% 积压订单转向“低电价州”，说明数据中心选址正被迫转向能快速获取基载电力的地区，也说明 BE 的 LCOE 已有跨区域竞争力；高优订单客户从一年前的 1 家超大规模 / 新兴云厂商增至 6 家，并深度绑定 AEP（约 1GW 订单）、Brookfield（50 亿美元战略合作）、Equinix、Oracle、CoreWeave；工商业领域 2/3 订单来自老客户增购，说明技术可靠性得到认可；以 2024 年为分水岭，此前是示范验证期（中小规模，如韩国 SK）。
- **适用场景与注意事项**：适用于判断公司驱动力是否切换（从补贴 / 套利驱动到刚需驱动）。

### 8.4.7 以 GW 计的算力订单追踪，并判断“签约到落地”的转化

- **方法要点**：AI 加速器公司的大客户订单以 GW 计量，按客户累加，作为“抢单能力”的证据；同时强调订单要“落地”到实际业绩，观察新品量产爬坡、全年产品指引是否随订单上调、下季环比增量是否匹配。
- **操作步骤 / 拆分口径 / 公式**：
  1. 按客户累加订单 GW（披露的客户 + 未披露的客户另标注）；
  2. 观察新品量产爬坡进度；
  3. 检查全年产品指引是否随订单上调；
  4. 检查下季环比增量是否匹配订单节奏；
  5. 若签约多而指引不变，则预判市场会担心落地情况。
- **关键指标与数据来源**：客户订单 GW 数、全年 AI GPU 收入指引、季度环比增量。
- **判断标准**：订单 GW 数是“抢单能力”的证据，但估值能否从“故事”转为“现实”取决于量产爬坡和指引的同步上调；订单多、指引不变是背离信号。
- **海豚案例**：
  - AMD《AMD：狂抢“AI 大单”》（2026-08-05）：订单明确超过 14GW（OpenAI、Meta 各 6GW，Anthropic 2GW，微软未披露，合计 14GW 以上）；但全年 AI GPU 指引 140 亿-150 亿美元未上调，市场担心订单实际落地；MI455X 的爬坡表现是估值从“故事”转为“现实”的关键。
  - AMD《CPU“狂飙”》（2026-05-06）：已与 OpenAI、Meta、Oracle 签订数 GW 协议，MI450 量产爬坡直接影响交付。
- **适用场景与注意事项**：适合 AI 芯片、数据中心基础设施公司。GW 订单到收入的换算需要单 GW 价值量假设（见 8.4.9）。

### 8.4.8 大客户合同拆解：总额、期限、年化、算力规模，汇总 ARR 并与历史收入对比

- **方法要点**：把每份大合同拆成签约时间、合同总额、期限、年化收入、租用的算力规模或芯片数，汇总得到新增 ARR，再与上一年度整个分部的收入对比，判断业务结构的跃迁。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：年化收入 = 合同总额 ÷ 合同期（年）；新增 ARR = Σ 各合同年化收入。
  1. 逐份合同整理：签约时间、合同总额、期限、年化收入、算力规模 / 芯片数；
  2. 汇总新增 ARR；
  3. 与上一年度整个分部收入对比（并区分真正的 AI 解决方案与基础设施收入）；
  4. 判断业务结构的跃迁，并关注客户集中度与合同条款。
- **关键指标与数据来源**：合同总额、期限、年化收入、算力规模、客户集中度。
- **判断标准**：新增 ARR 相对上一年度分部收入是数倍量级，说明业务结构发生跃迁；同时客户集中度高，需叠加客户兑付能力与条款分析。
- **海豚案例**：
  - SpaceX《SpaceX：AI 烧钱不止…》（2026-06-30）：Anthropic（2026 年 5 月签，总额约 450 亿美元，到 2029 年 5 月，约 300MW，年化 150 亿美元）；Google（2026 年 6 月签，总额约 304 亿美元，约 11 万张 GPU，年化 110 亿美元）；Reflection AI（2026 年 6 月签，总额 63 亿美元，GB300，年化 18 亿美元）；三项合计 ARR 278 亿美元，对比 2025 年 AI 分部总收入 32 亿美元（真正的 AI 解决方案与基础设施收入约 13 亿美元）；算力租赁使 AI 板块成为 2026 年增速最快、收入占比最高的板块。
- **适用场景与注意事项**：适用于大合同驱动的业务（算力租赁、军工、长协）；要关注客户集中度和合同条款（是否可取消、是否按使用量计价）。

### 8.4.9 长期合同隐含单价倒推，推断芯片成本优势

- **方法要点**：用合同总额、期限与算力规模倒推隐含的单 GW 年收入，与行业公允水平比较，若明显偏低，再列解释因素并推出成本结论，并用外部独立测算交叉验证。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：隐含单 GW 年收入 = 合同总额 ÷ 合同期（年）÷ GW。
  1. 取合同总额、期限与算力规模，倒推隐含单 GW 年收入（十年 1000 亿对应 5GW，按算术折合约每 GW 每年 20 亿美元）；
  2. 与行业公允水平比较：1GW 约对应年收入略高于 100 亿美元，十年 1000 亿对应 5GW 明显偏低；
  3. 先列解释因素：算力爬坡并非 Day1 用满；客户表示不通过该云租用其他芯片算力；
  4. 推出结论：该自研芯片的综合使用成本应明显低于基于 NVIDIA GPU 的成本；
  5. 用外部独立测算交叉验证（该测算于 25 年底做出，非由合同倒推），再用性能差解释定价。
- **关键指标与数据来源**：合同金额、期限、GW、行业单 GW 年收入。
- **判断标准**：隐含单价明显低于行业水平，若无法被爬坡节奏等因素完全解释，则说明供给方的单位成本优势明显；外部测算给出同一方向（如每 GW 仅为行业均值的 60-65%），则结论更可靠。
- **海豚案例**：
  - Amazon（2026-06-24）：十年 1000 亿对应 5GW 明显偏低，推出 Trn 芯片综合使用成本应明显低于基于 NVIDIA GPU 的成本；外部独立测算交叉验证：New Carlisle 2.2GW 实际年收入折扣后约 140 亿，每 GW 仅为行业均值 60-65%；再用性能差解释定价（Trn2 约为 H200 的 60%，Trn3 略超）。
- **适用场景与注意事项**：适用于长期算力、供货合同分析；需注意爬坡曲线与合同口径。

### 8.4.10 长协（SCA）四维拆解：客户结构 / 期限 / 条款 / 财务含义

- **方法要点**：对市场“拉估值”最关心的长协，按四个维度拆解：客户结构、期限、条款、财务含义，并解读签约优势的来源。
- **操作步骤 / 拆分口径 / 公式**：
  1. 客户结构：超大型客户、中型客户的数量与覆盖终端（数据中心、消费电子、汽车），其余为中小客户；
  2. 期限：通常 5 年（2026 至 2030 年底），汽车类 3 年；
  3. 条款：照付不议，反悔属重大违约；大协议设价格上限（等于当下自然季二季度市价）和贯穿合约期的价格下限，其他协议随行就市；新一代产品（HBM4、DDR6）溢价未锁死；
  4. 财务含义：按最低价累计营收（保底）、现金押金、价格下限支撑的毛利率、固定价或上限协议占总营收比例、全部执行后 SCA 框架下营收占比；
  5. 解读签约优势的来源（如“美国产能”属性）。
- **关键指标与数据来源**：客户数量及类型；合约年限；价格上下限条款；保底收入；押金；SCA 收入占比。
- **判断标准**：价格下限是否真能执行是核心；价格下限支撑的毛利率高于历史任何周期峰值，且保底收入与押金规模可观，说明周期被“平滑”；新一代产品溢价未锁死意味着上行弹性依然保留。
- **海豚案例**：
  - 美光《美光：牛气冲天！“凄凉周期”要变“超级成长”？》（2026-06-25）：4 个超大型客户 + 3 个中型客户，其余为汽车行业中小客户，覆盖数据中心、消费电子、汽车三大终端；期限通常 5 年（2026 至 2030 年底），汽车类 3 年；照付不议，反悔属重大违约，大协议设价格上限（等于当下自然季二季度市价）和贯穿合约期的价格下限，其他协议随行就市，新一代产品（HBM4、DDR6）溢价未锁死；4 份协议按最低价累计营收约 1000 亿（每年约 200 亿保底），带来约 220 亿现金押金，价格下限支撑高于历史任何周期峰值的毛利率，固定价或上限协议约占总营收 40%，全部执行后约一半以上营收在 SCA 框架下；海豚君还解读“美国产能”属性带来签约优势。
- **适用场景与注意事项**：适用于任何周期性行业转向长约模式时的评估（锂、硅料、晶圆代工、LNG）。重点核查价格下限是否真能执行。

### 8.4.11 Backlog 约束力对比：对标长协的期限、价格区间、押金比例

- **方法要点**：找一个约束更强的参照（如美光长协），按期限、价格区间、现金押金三要素对标目标公司的 Backlog，再看递延收入 / Backlog 比，判断客户违约时是否存在约束。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：押金覆盖率 = 现金押金 ÷ 合约最低价下累计应收；递延收入 / Backlog = 递延收入 ÷ Backlog。
  1. 取参照物的三要素：规定期限、限定价格区间（避免合同额不变下被迫增量交付“贱卖”）、现金押金（押金 / 最低价下累计应收）；
  2. 看目标公司有无押金性质的递延收入，计算递延收入 / Backlog；
  3. 若极低，说明客户违约时缺乏约束；
  4. 看合同类型（固定金额 / 特定周期最低消耗）：Token 降价趋势下，可能出现“消耗同等价值需更长周期”。
- **关键指标与数据来源**：押金 / 累计应收、递延收入 / Backlog、价格条款、合同类型。
- **判断标准**：押金占累计应收比例高（如 22%）是强约束；递延收入占 Backlog 比例极低（如 1.5%）且含 C 端预收，则约束可忽略；若产品迭代落后，缺乏 SOTA 模型可能走价格战老路。
- **海豚案例**：
  - 谷歌（2026-07-27）：美光 220 亿押金达合约最低价下累计应收的 22%；谷歌 Q2 递延收入 73 亿，仅占 5140 亿 Backlog 的 1.5%，且含 Google Play C 端预收，约束可忽略；Gemini 迭代落后，若无 SOTA 模型，可能走价格战老路。
- **适用场景与注意事项**：适用于长协 / 积压订单型公司（云、存储、设备），检验订单真实性与兑现质量。

### 8.4.12 长协的“实质保护力”拆解：担保覆盖率、价格下限、覆盖出货比例、重谈风险

- **方法要点**：不只看有没有签长协，而要拆出长协的实质保护力：财务担保覆盖保底收入的比例、全周期最低合同收入与担保金额、长协覆盖未来出货的比例、现货暴跌时的重新谈判风险；并把商业模式的变化与竞争壁垒的变化分开看。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：担保覆盖率 = 财务担保金额 ÷ 全周期最低合同收入。
  1. 财务担保覆盖保底收入的比例，其余部分依赖客户信用；
  2. 全周期最低合同收入和担保金额（构成价格下限）；
  3. 长协覆盖未来各年出货的比例（量的能见度）；
  4. 现货暴跌时重新谈判的风险；
  5. 把商业模式的变化（从“短单、锁量不锁价、违约成本低”转向定金 / 预付款 + 长协）和竞争壁垒的变化分开看；
  6. 结论：长协“平滑周期而非消除周期”，价值判断的本质是供需错配能持续多久。
- **关键指标与数据来源**：担保覆盖率、最低合同收入、担保金额、长协覆盖出货比例、长协定价上限。
- **判断标准**：担保覆盖率低（如约 18%），说明其余保底收入依赖客户信用；长协只覆盖部分出货，且需要为长协保留库存，会影响可销售 bit 增速；本轮属于超级周期，竞争格局和壁垒没有本质改变。
- **海豚案例**：
  - 闪迪《AI 改不了“DNA”…》（2026-10-06）：NBM 长协财务担保只覆盖保底收入约 18%；全周期最低合同收入 939 亿美元，另有 165 亿担保；预计覆盖 FY27 约一半、FY28 约三分之二的出货；投资者日把 FY27 可销售 bit 增速从 mid-to-high teens 下调到 mid-teens，原因是为 NBM 保留库存。
- **适用场景与注意事项**：适用于签有长协 / 照付不议合同的周期品公司（存储、锂矿、LNG 等）；关键是区分“有约束力的部分”和“依赖信用的部分”。

### 8.4.13 同业长协策略对比：覆盖率、价格上下限、保证金现金属性 → 上行弹性 vs 下行保护

- **方法要点**：对比同业公司的长协策略（覆盖比例、价格上下限、保证金形式、期限），推断各自的上行弹性与下行保护，并以公司的行业定位解释差异的根源。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出各家的长协条款：锁量与否、价格带（上限 / 下限）、保证金（现金还是第三方信托托管）、覆盖比例、合约期限；
  2. 判断覆盖比例：官方无披露时参考机构推测，并结合管理层表述（如“维持在适当水平”以便市况有利时承接额外需求）；
  3. 判断价格条款：只设底价不设上限，则涨价完全传导；只设上下限，则弹性被锁定；
  4. 判断保证金的现金属性：托管于第三方信托，客户违约后才能动用，对现金流无立竿见影帮助；
  5. 概括为“少锁量、只托底、不封顶”（重向上弹性、轻向下保护）与“最愿签、最透明”（锁量、设价格带、收现金保证金并量化披露）两种风格；
  6. 解释差异根源：行业定位（HBM 龙头、良率领先自认不需保障；规模最小又要在美国大举建厂的公司借长协换资金与扩产可见性；此前 HBM 落后正在抢客户的公司愿用长协和预付款绑客户）。
- **关键指标与数据来源**：长协覆盖率、价格上下限、保证金形式（现金 / 信托）、合约期限。
- **判断标准**：若存储继续紧缺，“少锁量、只托底、不封顶”的公司上行弹性更大；反之下行保护更低；条款差异是行业定位的结果，不是随机的。
- **海豚案例**：
  - SK 海力士 / 美光 / 三星《SK 海力士：长协能熨平周期？估值到哪一步》（2026-10-09，第 3.3 节）：美光是最愿签、最透明的一家——锁量、设价格带（上限据报为 2026 年二季度市价）、收现金保证金并量化披露；海力士相对“冷淡”：覆盖比例偏低（无官方披露，UBS 推测 2027 年 DDR 出货中按固定价锁定不足 20%，管理层称比例“维持在适当水平”）、只设底价不设上限（涨价可完全传导，HBM 仍走年度合约、不在 5 年期长协内）、保证金托管于第三方信托（客户违约后才能动用）；三星此前 HBM 落后、正在抢客户，愿用长协和预付款绑客户。
- **适用场景与注意事项**：适用于同行业公司合同条款差异对业绩弹性和下行风险的比较。

### 8.4.14 识别“用自己的钱买订单”的循环融资结构

- **方法要点**：检查 Backlog 增量是否来自公司自己投资的客户（股权投资 + 订单绑定），分析其对 EPS 与订单根基的双向放大效应，并设定跟踪信号。
- **操作步骤 / 拆分口径 / 公式**：
  1. 检查 Backlog 增量来源：是否来自公司投资的客户，类比英伟达 - OpenAI 的循环融资；
  2. 分析双向放大：顺风时做高 Backlog + 投资收益增厚 EPS（双赢）；逆风时（客户 ARR 放缓、估值下调）EPS 首当其冲恶化，长期订单根基也不稳；
  3. 跟踪信号：被投客户的 ARR 增速与估值；
  4. 区分“框架协议”与“实打实”的订单（如含算力采购的框架合作）。
- **关键指标与数据来源**：对客户投资额、客户框架合同额、投资收益、客户 ARR 增速与估值。
- **判断标准**：Backlog 与投资收益都依赖同一被投客户时，风险是同向放大的；被投客户 ARR 边际放缓即风险信号，ARR 持续上飙则是对订单真实性的侧面印证。
- **海豚案例**：
  - 谷歌（2026-07-27）：Anthropic 5 年 2000 亿合作框架（含 400 亿 TPU 算力采购）“并非实打实”；4 月宣布分阶段增持 400 亿（100 亿以 3500 亿估值投入，已有 14% 股权），Q2 账面收益近 800 亿；Anthropic ARR 6-7 月边际放缓即风险。
  - 亚马逊（2026-07-31）：Anthropic ARR 持续上飙是 AWS 侧面印证信号。
- **适用场景与注意事项**：适用于 AI 产业链供应商 - 客户交叉持股情形；也适用于厂商融资、渠道压货识别。

**交叉引用**

- 用公开信息拼图推断大单客户与合同结构的方法，详见 1.5（口径辨析与信息甄别）。

**本节速查清单**

- [ ] 天量订单是否已相对化（订单 ÷ 上年营收，订单 ÷ 上期末 RPO），订单的绝对值是否被换成了相对量级
- [ ] RPO 是否按履约期限分段，并与分年收入预测 / 指引对比，覆盖率和缺口是多少，归属假设是否合理并注明
- [ ] 在手订单是否拆成产品 / 服务，对应的容量（GW）、覆盖产能的年限、与管理层指引三者是否一致
- [ ] 订单质量：客户是否多元化、标杆客户是否从试点走向标配、老客户复购倍数、订单区域与客户结构有无迁移
- [ ] 签约到落地：量产爬坡进度、全年产品指引是否随订单上调、下季环比增量是否匹配
- [ ] 大合同是否拆成年化 ARR，并核对隐含单价（单 GW 年收入）与行业水平是否一致
- [ ] 长协是否按期限、价格上下限、押金 / 担保、覆盖出货比例、重谈风险做了实质保护力拆解，并与同业条款对比
- [ ] Backlog 增量是否来自自己投资的客户（循环融资），被投客户 ARR 与估值是否出现边际放缓

## 8.5 管理层指引解读与可达成性验证

> 本节导读：本节处理“管理层说了一个数字，我们怎么用它”的问题：先把指引拆成可建模、可检验的隐含假设（逐年指引、区间指引、投资者日长期模型、历次沿革、三方对比、增量来源），再用物理量、产能、合同、可比公司等独立证据去验证它能不能达成（目标量级校验、单 GW 收入、租赁反推、三角验证、口径辨析、毛利率夹逼），最后决定指引在自己的模型和估值里占什么位置（新业务确定性分级、自有预测与指引的差额、指引偏保守时的基准设定、长期目标作为估值锚）。适用于财报后的指引解读、投资者日、长期目标发布和任何“画饼型”目标。与 8.4（RPO 覆盖率、订单可见度）、8.6（把验证后的指引落到盈利预测）、10.1（反向估值）、11.1（管理层历史兑现记录的评估）配合使用。

### 8.5.1 以指引为基准：反推隐含分项，再验证可达成性

**方法要点**：对高度不确定、难以自下而上预测的业务（如未来 5 年 AI 算力需求），最简单有效的做法是把公司指引当作基准假设，研究员的工作不是另起炉灶，而是反推指引的隐含分项、验证它能不能达成，再按验证结果在指引上做调整。

**操作步骤 / 拆分口径 / 公式**：

1. 取公司对某板块（或总量）的长期指引，写出指引期内每年的数字。
2. 用已经能自己预测的“非核心部分”（存量业务、增长停滞部分）的预测值，从总指引中减掉。
3. 剩下的就是核心分项（如 AI 与非 AI）的隐含营收路径：隐含核心分项 = 板块总指引 − 非核心部分预测值，再继续按 AI / 非 AI 拆开，算出各自的起点、终点、倍数与增速。
4. 把“看不清的大数”变成一组可以逐项验证的具体目标，然后配套 8.5.8–8.5.13 的多维验证（量级、产能、合同、毛利率）。
5. 按验证结果在指引上做调整，形成自己的中性情景。

**关键指标与数据来源**：板块营收指引、非核心部分预测值、隐含核心分项营收及增速；来源为公司财报电话会、投资者日材料与自建的存量业务预测。

**判断标准**：
- 隐含路径若要求核心分项在几年内爆发数十倍（而存量部分只是平稳或萎缩），说明指引几乎把全部增量押在新业务上，必须找到产能、订单、合同上的独立证据支撑，否则应下调。
- 推理链条：总指引 − 存量预测 → 核心分项隐含路径 → 拆出“新增最难的那一块” → 逐项找证据验证 → 验证通过的部分采纳、缺口部分打折。
- 管理层有给指引偏乐观的激励，指引只能做“起点”，不能做“终点”。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：按 F3Q26 后最新的 OCI 指引，剔除非 Core 部分后，隐含 Core OCI 需要从 26 财年 140 多亿爆发到 30 财年 1500 多亿；其中 AI 部分从不到 60 亿涨到 1200 亿（数十倍），非 AI 部分从 80 亿到 330 亿（CAGR 42%）。

**适用场景与注意事项**：适用于新兴业务、预测难度大但管理层给了长期目标的公司。要警惕管理层激励导致指引偏乐观，因此必须配套多维验证（见 8.5.8–8.5.13）；非核心部分的预测口径要和指引口径一致（是否含某板块），否则减出来的“隐含分项”会失真。

### 8.5.2 长期指引逐年拆解：总量 CAGR、分业务倍数、拐点年份与增量贡献占比

**方法要点**：当公司罕见地给出多年逐年指引时，把总量、分业务、增量三个维度同时拆开，反推出管理层对各业务的隐含假设（谁在增长、什么时候加速、谁基本不增长）。

**操作步骤 / 拆分口径 / 公式**：

1. 总量：起点年营收到终点年营收，算 N 年 CAGR。
2. 分业务倍数：重点业务从起点到终点放大多少倍（终点 ÷ 起点），并找出增长斜率明显拉高的“拐点年份”。
3. 增量贡献占比：逐年计算 单业务净增额 ÷ 总营收净增额，看增量由谁贡献。
4. 反推：若某业务贡献了总增量的 90%–100%，说明公司预期其余业务在指引期内基本不增长；把这些隐含假设写成清单。
5. 若公司后续（如分析师会）上调了指引，要把调整后的数字同步更新到沿革表里（见 8.5.5）。

**关键指标与数据来源**：指引营收（逐年）、CAGR、分业务倍数、拐点年份、净增额贡献占比；来源为公司披露的长期指引与分析师会材料。

**判断标准**：
- 总量 CAGR 与分业务倍数相互印证：总量 31% 的复合增速，若全部由一个业务支撑，该业务的倍数就是整个指引成败的关键。
- 拐点年份说明管理层把兑现压在哪一年之后，拐点越靠后，前期可验证的东西越少，越需要订单、产能的先行指标来验证。
- 某业务净增额贡献接近 100%，意味着指引是“单点押注”，其余业务被默认为零增长。

**海豚案例**：
- 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：公司给出到 FY30 的逐年指引（之后分析师会上又上调）。海豚君拆成三点：a. 总营收从 FY25 约 570 亿到 FY30 的 2250 亿，5 年 CAGR 31%；b. OCI 从约 100 亿到 1660 亿，5 年约 16 倍，增长斜率明显拉高的拐点从 FY28 开始；c. FY27–30 每年总营收净增额的 90%–100% 由 OCI 贡献，说明公司预期 SaaS 和非云业务在指引期内基本不增长。

**适用场景与注意事项**：适合公司或投资者日给出多年长期指引的场景；若指引后来被上调，注意区分“原指引”和“上调后指引”，避免混用口径。

### 8.5.3 远期区间指引取中值，拆到各业务并倒推增长的时间分布

**方法要点**：公司给出的是远期区间（如 FY31 收入 700–900 亿）时，取中值把它拆到各业务，算各业务 5 年 CAGR 和收入占比变化，再用已知的中间年份指引倒推剩余年份的增量，判断增长是均匀分布还是集中在远期后段。

**操作步骤 / 拆分口径 / 公式**：

1. 取区间中值作为总量；按公司披露的业务口径把总量拆到各业务（互联、定制 ASIC、交换与存储、通信及其他等）。
2. 对每个业务算 5 年 CAGR（可给出区间）和收入占比的起点—终点变化，识别“结构变化最大的业务”。
3. 用公司已经给出的中间年份指引（如 FY29 定制 ASIC 指引）作为锚点，倒推：中间年份到终点年份的增量 = 终点值 − 中间值；再算这两年的 CAGR。
4. 比较前后两段的增速：若后段 CAGR 仍然很高，说明增长集中在中间年份之后，前期可验证的东西少，兑现的不确定性更大。

**关键指标与数据来源**：分业务收入、CAGR、收入占比；来源为投资者日披露的区间指引和中间年份指引。

**判断标准**：
- 分业务拆分之和必须与总量中值吻合，不吻合说明口径有出入，需要回头核对。
- 中间年份到终点年份的 CAGR 仍然很高（如 55%），说明增长后置，需要更长的验证周期。
- 占比提升最快的业务就是指引的核心押注，应重点验证其订单与产能。

**海豚案例**：
- Marvell《Marvell：远期指引狂飙，究竟是「信心」还是「画饼」？》（2026-10-07）：FY31 中值约 800 亿美元 = 互联约 375 亿 + 定制 ASIC 约 300 亿 + 交换与存储约 100 亿 + 通信及其他约 25 亿；ASIC 5 年 CAGR 75%–85%，收入占比从 17% 升到 38%，互联 CAGR 60%–70%；再用 FY29 ASIC 120 亿的指引倒推，FY29 到 FY31 增量约 180 亿，两年 CAGR 仍有 55%，说明增长集中在 FY29 之后。

**适用场景与注意事项**：适用于给出远期目标的公司，用来检验增长在时间上的分布；区间取中值只是便于拆分，不代表海豚君采纳该中值，仍需配合 8.5.5 沿革和 8.5.6 三方对比判断可信度。

### 8.5.4 投资者日长期财务模型：逐项翻译为隐含量价假设（含“熨平周期”假设的识别）

**方法要点**：把投资者日给出的长期财务模型（收入增速、毛利率、费用率、利润率、FCF、capex、股东回报）逐项翻译成量和价的假设，找出指引里没明说的价格假设；对周期股，把管理层指引当作“乐观情景”，写明兑现条件，并与自己的周期判断对比算出利润差。

**操作步骤 / 拆分口径 / 公式**：

变体 A：逐项翻译成隐含假设（存储公司的长期模型）

1. 近一财年：把 bit 增长与价格走势翻译成周期位置。例如 FY27（至 27 年 6 月）bit 增长 mid-teens、全年价格逐季温和上行 → 隐含 NAND“变态涨价期”已过，进入稳步爬升期。
2. 中期财年：把“收入中高双位数增长、主要靠 bit”翻译成量价拆分。公司预期 bit 需求 CAGR 约 18% 且无价格增长，所谓增速即贴近行业约 18% 的 bit 增速。
3. 盈利：non-GAAP 毛利率约 80%、OpEx 费用率 5%、其他收支无显著贡献 → non-GAAP 经营利润率 75%。
4. 现金流：扣税金、营运资本与 capex 后，调后 FCF 率 50%；建模时 capex 强度取收入的中低个位数。
5. 股东回报：收入的 50%（公司定义的超额现金）返还股东。
6. 与行业历史对比：NAND 晴天赚钱雨天亏光、从不敢承诺股东回报，指引的“反常”本身就是重要信号。

变体 B：识别“熨平周期”假设，把指引用作乐观情景

1. 把收入、毛利率、费用、利润率指引拆回量和价：收入增速与 bit 出货增速同步，隐含单价持平；高毛利率指引的前提是 ASP 基本稳住。
2. 照指引推算出净利润路径。
3. 写明要让指引兑现必须同时满足的条件：长协托住约定部分的价格；AI 需求还要消化掉 2029 年后的新增供给，让非长协部分价格也不回落。
4. 与海豚君自己的周期判断（见 8.6.2 周期股分项预测）对比，算出两者的利润差（以百分比表示）。

**关键指标与数据来源**：bit 增长、价格、收入 CAGR、毛利率、OpEx 率、经营利润率、FCF 率、capex/收入、股东回报比例、收入增速指引、bit 增速指引、推算净利润；来源为投资者日长期模型与财报指引。

**判断标准**：
- 收入增速与 bit 增速同步 = 隐含单价持平；在周期品里这是“极度乐观”的信号，等于假设周期被熨平。
- 毛利率 80%、经营利润率 75% 的前提是 ASP 稳住，若自己的周期判断是价格回落，则指引兑现需要附加条件，应当把指引放在“乐观情景”而不是基准情景。
- 与行业历史（过去从不敢承诺股东回报）对比，指引越反常，越需要检验“这一轮到底有什么结构性变化”。

**海豚案例**：
- 闪迪《比 DRAM 还摇钱树，闪迪真有那么香？》（2026-08-17）：FY28–30 约 20% 收入 CAGR、80% 毛利率、75% 经营利润率、50% FCF 率、capex 强度 <5%，并与行业历史对比凸显指引的反常（变体 A）。
- 闪迪《AI 改不了“DNA”…》（2026-10-06）：管理层指引 FY27 ASP 逐季温和上行，FY28–FY30 收入 +15%~19%，与 bit 出货同步，海豚君认为这隐含“未来三年单价持平”的极度乐观假设；non-GAAP 毛利率约 80%，OpEx 约 5%，OPM 约 75%；按指引推算净利从 FY27 约 344 亿增到 FY30 约 508 亿，并作为海豚君自己周期预测（FY30 净利约 216 亿）的对照（变体 B）。

**适用场景与注意事项**：适用于周期股的投资者日 / 长期目标解读，核心是找出指引里没明说的价格假设；投资者日解读也适用于非周期公司，只需把“量价拆分”换成该行业的驱动公式。

### 8.5.5 把同一指标的历次指引排成沿革表

**方法要点**：把同一指标（如某业务收入、TAM）的历次指引按时间排列，看管理层是否在持续上调、节奏如何，再结合管理层的预期管理安排（如上季财报不调指引、留到投资者日一起公布）理解市场期待是怎么形成的。

**操作步骤 / 拆分口径 / 公式**：

1. 同一指标、同一口径，按发布时间排成时间表：日期 | 指引数值 | 口径变化。
2. 计算相邻两次指引的上调幅度和间隔，判断是持续上调还是一次性加码。
3. 对 TAM 类指引同时记录“目标年份”和“目标值”的变化，目标年份后移说明口径在放大而不是单纯上调。
4. 标注管理层的沟通安排（是否把调整留给特定节点），解释为什么该节点市场预期会被拉高。

**关键指标与数据来源**：历次指引的数值与日期；来源为历次财报、投资者日、电话会纪要。

**判断标准**：
- 连续上调且幅度扩大，说明管理层对需求能见度增强，同时市场预期也会被不断抬高，需要警惕“预期已先行”。
- TAM 的目标年份和数值同时变化，要核对口径是否被放大。

**海豚案例**：
- Marvell（2026-10-07）：FY29 定制 ASIC 指引从 80–100 亿（2024 年 4 月）到 100 亿（2025 年 6 月），再到 120 亿以上（2026 年 10 月）；ASIC TAM 从 2025 年 6 月给的 2028 年 554 亿美元，变为本次给的 2030 年 2350 亿美元；上季财报后未上调 ASIC 指引，管理层表示留到投资者日公布。

**适用场景与注意事项**：适用于长期指引频繁更新的成长股；要同时记录口径变化，避免把口径调整误读为需求上调。

### 8.5.6 本次指引、上次指引、市场预期的三方对比

**方法要点**：解读发布会和投资者日时，逐项列出本次指引、上次指引和市场预期三组数字，判断是超预期、符合预期还是低于预期；指引项不只看收入，还要看毛利率、EPS 和股东回报承诺。

**操作步骤 / 拆分口径 / 公式**：

1. 事前收集一致预期（没有事前预期就无法判断“超”还是“不及”）。
2. 逐项列表：收入、毛利率、EPS、股东回报等指引项，每项三列：上次指引 / 本次指引 / 市场预期。
3. 判断每一项的位置：本次 > 市场预期 → 超预期；本次 ≈ 市场预期 → 符合预期；本次 < 市场预期 → 低于预期。
4. 汇总后指出“市场真正想看到而没给到的东西”（如明确订单）。

**关键指标与数据来源**：收入、毛利率、EPS、股东回报等指引项及对应的市场预期；来源为公司发布会材料与卖方一致预期。

**判断标准**：
- 指引上调但与主流预期持平，属于“符合预期”，股价往往取决于有没有更硬的信号（订单、合同）。
- 指引项里只要有一项远超预期（如远期 EPS、远期毛利率），就是超预期的主要来源，要追问兑现路径（见 8.5.7）。

**海豚案例**：
- 英伟达（2026-03-17）：2025–2027 年数据中心累计收入 1 万亿美元（去年 GTC 给的是 2025–2026 年累计 5000 亿），市场主流预期已在 1 万亿以上，判断为符合预期，市场更想看到明确订单。
- Marvell《Marvell：远期指引狂飙，究竟是「信心」还是「画饼」？》（2026-10-07）：FY27 收入约 120 亿（维持）；FY28 从 180 亿上调到 200 亿（市场 180–190 亿）；首次给出 FY31 收入 700–900 亿（市场 470–500 亿）、毛利率 56%–59%（市场 55%–56%）、Non-GAAP EPS 超过 30 美元（市场 20 美元）；长期平均超过 50% 的自由现金流返还股东。

**适用场景与注意事项**：适用于所有指引型事件，前提是收集好一致预期；市场预期口径（财年 / 自然年）要与指引对齐。

### 8.5.7 拆出指引增量来自哪个业务，定位战略合作的兑现时点

**方法要点**：指引上调后追问“新增的钱从哪个业务来”，由此把市场期待的催化剂（如一项大合作）落到具体财年上，判断兑现是近还是远。

**操作步骤 / 拆分口径 / 公式**：

1. 把指引上调的总额拆到各业务线：Δ总量 = Σ Δ分业务。
2. 找出增量最大的业务，对照公司对它的解释（来自电话会、投资者日）。
3. 把市场期待的催化剂（如新签合作）与增量来源的业务对应：若增量来自别的业务，说明该合作还没有进入指引。
4. 看后续年份的分业务指引上调，定位合作最早体现的财年。

**关键指标与数据来源**：分业务指引变动；增量来源；来源为公司投资者日与电话会。

**判断标准**：
- 总量上调的增量来自非市场预期的业务，则市场期待的催化剂兑现更晚。
- 后续年份某业务指引大幅上调，并明确来源于新机会（如 attach 机会），才是催化剂进入指引的证据。

**海豚案例**：
- Marvell（2026-10-07）：FY28 新增的 20 亿主要来自数据中心连接类产品（互联、scale-up 光学、交换），而不是定制 ASIC，说明谷歌战略合作的贡献最早 FY29 才会体现；FY29 定制 ASIC 指引上调到 120 亿以上（FY28 的 3 倍以上），来源是 XPU attach 机会（AI 加速器配套的网络、存储、安全、推理加速等半定制产品），其中包括 8 月与谷歌的协议。

**适用场景与注意事项**：适用于多业务线、刚签下大合作的公司。

### 8.5.8 目标规模直观化与叙事量级校验

**方法要点**：对一个看起来很大的目标，先判断它的“量级”，再决定要用多大力度去验证；有两种做法：把目标和行业现有规模、竞对未来体量比（变体 A），或把管理层的自定义单位换算成行业通用物理量再对标存量（变体 B）。

**操作步骤 / 拆分口径 / 公式**：

变体 A：静态 + 动态对比（适用于营收目标）

1. 静态：目标年营收 ÷ 当前全球行业总规模，得到“相当于现在全行业的百分之几”。
2. 动态：参考市场对主要竞争对手同期营收的预期，看公司届时的行业地位（相当于第几大、相当于对手的百分之几）。
3. 综合判断目标是否“激进到需要改变行业格局”；行业口径必须对齐（仅 IaaS 还是全云）。

变体 B：物理量换算 + 存量对标（适用于愿景型目标）

1. 找转换系数，把管理层的自定义单位换成行业通用单位：新增算力（GW/年）= 运力（吨/年）× 比功率（kW/吨）。
2. 拿全球现有存量做参照，计算“年增量相当于存量的多少倍”。
3. 把时间表拆成节点（卫星、火箭、芯片厂各自的时间和规格），明确每个节点要验证什么。
4. 对转换系数本身做敏感性检验。

**关键指标与数据来源**：全球行业收入（Gartner IaaS）、竞对未来营收预期（谷歌云、AWS、Azure）；运力（吨 / 年）、比功率（kW / 吨）、新增算力（GW / 年）、全球 CSP 累计 AI 算力存量（GW）。

**判断标准**：
- 目标营收相当于当前全行业规模的相当比例，且接近头部对手的体量，说明公司要成为新的头部玩家，而不是在现有格局里增长。
- 仅年增量就相当于再造两三个全球云计算总和，说明叙事具有颠覆性，需要极强的证据才能采纳。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）（变体 A）：全球 IaaS 收入 2025 年约 2150 亿，Core OCI 30 财年营收相当于 25 年全球 IaaS 的 60% 以上；OCI 30 财年体量将接近谷歌云总营收，相当于 AWS / Azure 的 50%–55%，意味着 Oracle 将成为第四家 Hyperscaler。
- SpaceX《SpaceX：太空算力，马斯克新饼，还是真未来？》（2026-07-08）（变体 B）：管理层目标是「每年往太空运 100 万吨算力硬件」，每吨硬件 100kW，则 100 万吨 / 年 × 100kW/吨 = 100GW / 年，对比全球主要 CSP 累计部署的 AI 算力只有 30–50GW，结论是“仅年增量就相当于再造两三个全球云计算总和”；同一个表把时间表拆成节点：2028 年 AI1 卫星（翼展 70 米、平均功耗 120kW）、2028–2031 年星舰（V3 单发 100 吨）加 Terafab（2nm，远期年产 1TW 算力）、2030–2031 年每年 100 万吨；终极目标 1TW。

**适用场景与注意事项**：变体 A 适用于任何宏大长期目标的合理性初判，行业口径要对齐；变体 B 适合评估太空、核聚变、Robotaxi 车队规模等愿景型指引，前提是转换系数要靠谱，系数本身也该做敏感性检验。

### 8.5.9 用单 GW 年收入锚定营收，推算所需 GW 与产能支持的营收峰值

**方法要点**：把营收目标翻译成物理产能需求（GW），再盘点已上线和已规划的 GW，看产能能支持多大的营收峰值，与目标比较，量化缺口。

**操作步骤 / 拆分口径 / 公式**：

1. 先确定“1GW 数据中心对应的年收入”：用管理层口径，再用两个外部实例交叉验证：① 大合同的总价 ÷ 年限 ÷ GW；② 可比公司的季度年化收入 ÷ 平均上线 GW。
2. 所需上线 GW = 营收目标 ÷ 单 GW 年收入。
3. 盘点已上线 GW 与已规划 GW（拆到具体项目），相加得到产能总量。
4. 营收峰值 = （已上线 GW + 规划 GW）× 单 GW 年收入，与目标比较，得出缺口。

**关键指标与数据来源**：单 GW 年收入、合同总额 / 年限 / GW、可比公司年化收入 / 上线 GW、已上线 GW、规划 GW；来源为管理层表述、大合同披露、可比公司财报、市场统计的规划项目。

**判断标准**：
- 管理层口径与两个外部实例所得的单 GW 收入基本一致，才可作为锚；差别大时要解释为什么（GPU 代际、定价、合同结构）。
- 产能能支持的营收峰值低于目标，缺口就是需要额外获取的产能；缺口越大，指引越依赖尚未锁定的资源。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：管理层称 1GW 约对应年收入 100 亿美元；OpenAI 合同 5 年 3000 亿 / 约 6GW，即每 GW 每年 100 亿；CoreWeave 4Q25 年化收入 63 亿 / 平均上线 0.75GW ≈ 88 亿 / GW。据此 Oracle 至少需要 15GW 上线算力；26 自然年底已上线约 3.5GW，另计划 7.4GW（Abilene 扩展 0.6GW、Stargate 二期 4.8GW、其他 AI Lab 约 2GW），合计 10.9GW，对应营收峰值约 1100 亿。

**适用场景与注意事项**：适用于算力租赁、IDC、Neocloud、电力相关公司；单 GW 收入随 GPU 代际和定价变化，需要动态更新。

### 8.5.10 用已承诺的数据中心租赁费用反推已签约 GW

**方法要点**：用表外承诺（已签约的数据中心租赁总额）反推公司已签约但尚未投用的数据中心规模，与市场统计的规划 GW 互相印证，检验公司是否已经锁定足够产能去支撑营收目标。

**操作步骤 / 拆分口径 / 公式**：

1. 从财报附注取已承诺的数据中心租赁费用总额。
2. 隐含已签约 GW = 租赁承诺总额 ÷ 平均租期 ÷ 每 GW 年租金。
3. 与市场统计的计划上线 GW（见 8.5.9）比较，看是否吻合。
4. 对照营收目标所需的 GW，判断已签约规模是否足够。

**关键指标与数据来源**：已承诺数据中心租赁费用总额、平均租期、每 GW 年租金、隐含 GW；来源为财报附注（租赁承诺）与行业数据。

**判断标准**：
- 隐含已签约 GW 与市场统计的规划 GW 大体相当，则两套数据相互印证，数字可信。
- 隐含已签约 GW 小于营收目标所需 GW，说明还没有预约到足够的产能。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：截至 F3Q26，已承诺的数据中心租赁费用为 2610 亿美元，按平均 17 年租期、每 GW 年租金 20 亿计算，隐含已签约未使用的规模约 7.7GW，与计划在 26 年后上线的约 7.4GW 大体相当，说明还没有预约到足够支撑 15GW 的数据中心。

**适用场景与注意事项**：适用于采用租赁模式扩张的云 / 算力公司；租期和单 GW 租金是假设项，需要用行业数据校准。

### 8.5.11 多口径三角验证：用一致性结论量化缺口及所需新增客户

**方法要点**：把订单端（RPO）、产能端（规划 GW）、合同端（租赁承诺）三个相互独立的数据推出的营收峰值放在一起比较；如果三者指向同一水平，结论可信度就很高，再计算与指引的缺口金额，并推导填补缺口需要什么。

**操作步骤 / 拆分口径 / 公式**：

1. 订单端：用 RPO 覆盖率推出可兑现的营收峰值（RPO 按确认期限分段，与分年收入指引对比算覆盖率和缺口，详见 8.4）。
2. 产能端：用 8.5.9 的“（已上线 + 规划 GW）× 单 GW 收入”推出营收峰值。
3. 合同端：用 8.5.10 的租赁承诺反推 GW，再乘以单 GW 收入。
4. 三个峰值放在一起看是否一致；一致则取其作为中性情景，计算 缺口 = 指引目标 − 中性峰值。
5. 推导填补缺口需要什么：新增大客户、新增数据中心供应商，并换算成年化金额。

**关键指标与数据来源**：各方法推出的营收峰值、与指引的缺口；来源见 8.5.9、8.5.10 和 8.4。

**判断标准**：
- 三种独立口径指向同一区间，结论可信度高；任一口径明显偏离，要回头找原因。
- 缺口的存在不等于指引不可达，而是说明达成需要新增合作伙伴 / 供应商；以此判断“还要多少新增条件才能兑现”。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：三个数据指向的 Core OCI 收入峰值都在 1000~1100 亿左右，均表明还有年化约 400~500 亿的缺口；结论是公司需要寻找更多合作伙伴和数据中心供应商，而中性情境取约 1000 亿 OCI 营收。

**适用场景与注意事项**：通用于验证长期指引。关键是各方法的数据来源要相互独立，避免循环论证。

### 8.5.12 产能目标口径辨析：规划 vs 部署完成，建设周期反推与兑现记录打折

**方法要点**：对管理层或媒体的产能目标（数据中心、工厂、电站）先辨析口径，再用建设周期反推可行性，最后结合管理层历史兑现记录打折。

**操作步骤 / 拆分口径 / 公式**：

1. 辨析口径：“到某年的规划目标”还是“某年底必须部署完成”。后者需要集中投入，前者可以把新增投入往后续年度分摊。
2. 建设周期反推：假定建设周期 1–2 年，若要年底完成，眼下就应该看到在建项目之外还有新数据中心开工、施工队伍就位、电力合作开始；没看到则倾向规划口径。
3. 留安全垫：数据中心规划与实际落地普遍存在落差，需要给目标打折。
4. 结合管理层历史兑现记录（战略漂移、左右脑互搏的前科）对目标进一步打折（具体的管理层评估见 11.1）。
5. 无法量化的部分不过度纠结，只作定性判断。

**关键指标与数据来源**：在建项目数、新开工、电力合作公告、建设周期、管理层历史兑现。

**判断标准**：
- 在建项目之外没有新开工与电力合作 → 倾向“规划口径”，资本开支可往后年度摊薄。
- 管理层有“放空炮”的前科 → 对目标额外打折。

**海豚案例**：
- Meta（2026-07-10）：倾向 14GW 只是到 27 年的规划目标而非年底完全部署，26–27 年新增 1200 亿可继续往 28、29 年分摊；“小扎的空响炮也不止放过一次”。

**适用场景与注意事项**：所有产能、装机、算力目标类公告（数据中心、工厂、电站）。

### 8.5.13 毛利率指引的外部校验：可比公司“夹逼”与市场、指引、同行三方交叉

**方法要点**：新业务利润率不透明时，不直接采信管理层的稳态毛利率指引，而是用外部可比数据检验：用一强一弱两个可比公司“夹逼”（变体 A），或用市场推算、公司指引、同行实际三方交叉（变体 B）。

**操作步骤 / 拆分口径 / 公式**：

变体 A：可比公司“夹逼”

1. 找业务构成和成本结构相近的可比公司：一个规模和技术更弱，一个更强。
2. 看指引是否落在两者的毛利率之间。
3. 再从单位定价（单 GW 收入）和规模效应解释公司毛利率为何高于较弱的可比公司。
4. 落在区间内就认为指引大体可信。

变体 B：三方交叉验证

1. 列出市场推算（及其依据的假设，如出租率）、公司指引、同行实际毛利率。
2. 检验市场推算依据的假设（如算力出租率 60%–90%）是否合理，对照公司指引与同行实际。
3. 纵向对比：与公司自身原有业务毛利率比；横向对比：与同行比，判断新业务处于什么盈利水平。

**关键指标与数据来源**：指引毛利率、可比公司稳态毛利率、单 GW 收入（反映单位定价）、规模、出租率；来源为公司指引、同行财报与投行估算。

**判断标准**：
- 指引介于较弱与较强可比公司之间 → 大体可信；高于较弱可比公司要能用单位定价与规模效应解释。
- 市场估算明显低于公司指引时，先检验市场估算依据的假设，再看同行实际落在哪一侧。
- 纵向看，相比原有高毛利业务仍然是大幅下滑；横向看，是否避免了像同行那样在盈亏平衡线附近挣扎。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）（变体 A）：Oracle 指引 AI 算力租赁毛利率 30%~35%；CoreWeave 稳态毛利率约 25%（海豚君此前测算），Bernstein 估计微软 3Q25 AI 云毛利率约 30%~40%。Oracle 介于两者之间，所以判断指引大体准确；其每 GW 收入约 100 亿高于 CoreWeave 的 88 亿，说明 GPU 小时定价更高，再加上规模效应。
- 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）（变体 B）：市场一度认为甲骨文 AI 云毛利率不到 20%，依据是算力出租率只有 60%–90% 的假设；公司在 10 月投资人会议上指引 AI 云毛利率 30%–40%；参考 CoreWeave 约 25%–30% 的毛利率，海豚君判断公司指引大体可信。纵向对比：相比自身原有业务 70%–80% 的毛利率仍是巨大下滑；横向对比：不至于像 CoreWeave 那样挣扎在盈亏平衡线附近。

**适用场景与注意事项**：适用于新业务毛利率指引的可信度检验；可比公司口径（是否含折旧、租金）需对齐，同行要有可比性（相同的商业模式）。

### 8.5.14 新业务收入指引与 TAM 的引用及确定性分级

**方法要点**：引用管理层的新业务收入指引（起点、终点、CAGR）和 TAM，但按确定性分级对待，并以签约客户覆盖度与采购承诺评估指引的信心。

**操作步骤 / 拆分口径 / 公式**：

1. 记录新业务指引：起点年、终点年、收入、CAGR；记录公司给的 TAM（口径与年份）。
2. 按确定性分级：有收入的产品 > 有采购允诺的协议 > 只有合作开发意向和股权搭售。
3. 评估信心：签约客户覆盖度（头部 CSP 签了几家）；协议里是否有采购承诺。
4. 把分级结果映射到预测中的权重：确定性高的部分纳入中性情景，低的部分作为期权或上行情景。

**关键指标与数据来源**：新业务收入指引、CAGR、TAM、签约客户数、采购允诺；来源为公司投资者日、协议公告。

**判断标准**：
- 协议中含采购允诺，指引的可信度上升；只有合作开发意向和股权搭售的，确定性最低。
- 头部客户覆盖度越高，指引越可信；单一客户依赖则存在集中度风险。

**海豚案例**：
- 高通《抱上亚马逊大腿…》（2026-09-09）：数据中心收入从 FY27 50 亿美元增到 FY29 150 亿美元，CAGR 73%；四板块 2029 年 TAM 1 万亿美元；与亚马逊的协议含采购允诺，增加了指引的可信度。

**适用场景与注意事项**：适用于对管理层画饼型指引的可信度评估；TAM 数字属于“管理层口径的天花板”，不要直接当收入预测。

### 8.5.15 自有分业务预测与指引隐含增速的差额对比

**方法要点**：把自建的分业务预测汇总后，与公司官方指引隐含的同口径复合增速比较，明确自己比公司更乐观还是更保守、差多少个点，并说明原因；既定位预期差的方向，也检验自己有没有被指引带偏。

**操作步骤 / 拆分口径 / 公式**：

1. 汇总自己的分业务预测，算同口径的 CAGR。
2. 算公司指引隐含的同口径 CAGR。
3. 差额 = 自有预测 CAGR − 指引隐含 CAGR（单位 pct）。
4. 写明差异原因：差在哪个业务、哪个假设。

**关键指标与数据来源**：自有预测 CAGR、指引隐含 CAGR、差额（pct）。

**判断标准**：
- 差额的符号说明预期差方向：自己更保守则说明指引有“画饼”成分，更乐观则可能存在市场低估。
- 差额很小也要警惕：可能是被指引锚定，而没有独立的判断依据。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：剔除 OCI 后所有业务营收从 26 财年约 490 亿增长到 30 财年 567 亿，CAGR 3.6%，比公司指引隐含的复合增速低约 1pct。

**适用场景与注意事项**：适用于公司给出了分板块或总量长期指引的情况；需确保口径一致（是否含某板块）。

### 8.5.16 公司指引偏保守时：用市场预期或海豚君自估值作为估值输入

**方法要点**：公司指引保守、市场已经把预期拉高时，估值计算用市场预期或海豚君自己的估计（高于指引），并写明两者差距。含义是：估值反映的是已经打进股价的预期，公司如果只完成指引，反而是负面信号。

**操作步骤 / 拆分口径 / 公式**：

1. 并列三组数字：公司指引、卖方一致预期、海豚君预期。
2. 若指引长期偏保守、常态性超预期，估值输入取市场预期或海豚君预期，而不是指引。
3. 在文中写明差距（指引与所取输入的差额）。
4. 提示：公司只完成指引不是正面信号，只有超出被抬高的预期才是。

**关键指标与数据来源**：公司指引；卖方一致预期；海豚君预期。

**判断标准**：指引保守且常态性被超越 → 估值输入看市场；公司只完成指引 → 对股价偏负面。

**海豚案例**：
- 博通（2026-07-07）：市场认为 FY2027 AI 收入在 1300 亿美元以上，公司维持 1000 亿的保守指引。
- 英伟达（2026-03-17）：海豚君按 2025–27 自然年数据中心收入 1.15 万亿测算，高于公司 1 万亿的指引。

**适用场景与注意事项**：适用于指引保守、常态性超预期的公司；与 8.5.15 的差额对比配合使用。

### 8.5.17 管理层远期目标作为估值锚（第一层假设），再按不确定性决定是否采纳

**方法要点**：管理层给出 3–5 年或至 2030 年的长期目标时，先把它当作估值锚（目标收入或利润乘以稳态倍数），再按不确定性程度决定是否采纳：技术或商业模式可能被颠覆时，长期指引被判定为“意义不大”，转而用保守口径（历史利润、下一年指引）估值。

**操作步骤 / 拆分口径 / 公式**：

1. 取长期目标（收入或利润、业务占比目标）。
2. 估值锚 = 目标收入（或利润）× 稳态倍数；若是利润目标，市值 = 目标利润 × 稳态 PE。
3. 评估不确定性：技术或商业模式是否可能被颠覆？目标是否有订单、产能的独立验证（见 8.5.8–8.5.13）？
4. 不确定性高 → 判定长期指引意义有限，改用保守口径（历史利润、下一年指引）估值；不确定性低 → 作为第一层假设纳入估值。

**关键指标与数据来源**：管理层长期收入或利润目标、稳态 PE、业务占比目标。

**判断标准**：
- 长期目标越依赖未被验证的技术或业务，越应降低其在估值里的权重。
- 技术被 AI 颠覆的不确定性是不采纳长期指引的典型理由。

**海豚案例**：
- Rocket Lab《中子号或延期》（2026-08-11）：管理层称 3–5 年内 Electron 营收 5–10 亿、Neutron 10 亿，航天系统远期占比 55%–60%，2026 年 Electron 发射近 30 次，作为第一层假设。
- Salesforce《AI替代论摧枯拉朽》（2026-02-26）及《既没增长也没利润》（2026-05-28）：30 财年 GAAP 税后经营利润约 180 亿，按 15x PE 对应约 2700 亿市值、每股约 290 美元，但因 AI 颠覆不确定，认为长期指引意义有限。

**适用场景与注意事项**：适用于有长期目标的公司；需结合行业变化判断其可信度；这是估值层面的使用，更完整的估值方法与情景见第 9 章、10.2。

**本节速查清单**

- [ ] 指引是否已拆成“隐含分项”（总指引 − 非核心预测 = 核心分项），并写出了起点、终点、倍数和 CAGR？
- [ ] 增量由哪个业务贡献？是否出现某业务贡献 90%–100% 净增额、其余业务被默认零增长的单点押注？
- [ ] 区间指引是否取中值拆到各业务，并用中间年份指引倒推增长是否后置？
- [ ] 投资者日的长期模型是否翻译成了量价假设？收入增速与量增速同步是否意味着“单价持平 / 熨平周期”的假设？
- [ ] 历次指引沿革表、本次 / 上次 / 市场预期三方对比是否做了？超预期的是哪一项？
- [ ] 目标量级是否通过行业总量、竞对体量或物理量换算做过校验？
- [ ] 产能类目标是否辨析了“规划 vs 部署完成”，并用建设周期、在建项目、电力合作反推？
- [ ] 订单端、产能端、合同端是否至少有两到三个相互独立的口径做三角验证，缺口是否量化？
- [ ] 毛利率指引是否用一强一弱可比公司“夹逼”或市场 / 指引 / 同行三方交叉验证过？
- [ ] 指引偏保守时，估值输入是否改用了市场预期或自估值，并写明差距？新业务指引是否按“有收入 > 有采购允诺 > 合作意向”分级？

## 8.6 盈利预测建模与敏感性测算

> 本节导读：本节回答“怎么把一家公司的未来报表搭起来”：从最底层的驱动因子（晶圆产能、bit、ASP、GW、订单、ARR、用户、门店、同店、RevPAR、GMV、账户、生息资产）出发，经过分业务毛利率与费用率路径，拼接成集团收入、利润率和净利润，并用敏感性矩阵、利率敏感度、全年业绩情景和宏观传导链检验结果的稳健性。使用时先选对“驱动因子链”（周期品看量价、算力链看 GW、订阅看 ARR、连锁看门店 × 同店、平台看渗透率 × 变现率、券商看账户 × 资产），再补利润率与费用率路径。与 8.1（利润率与费用拆解）、8.4（订单与收入可见度）、8.5（指引验证）、第 3–5 章（收入驱动、单位经济、行业空间）、7.2（扩张路径）配合；估值层面的情景（上下限）归 10.2。每个方法都强调“假设写明、保守或激进的取向写明、可被后续数据证伪”。

### 8.6.1 存储公司分产品驱动模型：晶圆产能→bit 出货→ASP→单位成本→毛利率→毛利润，并与一致预期对比

**方法要点**：对以 bit 计价的商品型半导体，按“产品 × 价量成本”逐层搭建毛利润模型：核心产品（DRAM 中的 HBM 与 DDR）完整展开，非重点业务（NAND）直接给结果，最后汇总到集团利润并与市场一致预期比较，判断预期差。

**操作步骤 / 拆分口径 / 公式**：

1. 晶圆产能：给出多年的月产能路径（kwpm）。
2. 出货（bit，Gb）：分产品给出出货量与年增速；资源分配假设要写清（新产能优先给 HBM，则 DDR 增速被压低）。
3. 价格（ASP，偏保守）：分产品、分年度给出涨跌幅；定价机制（年度合约 vs 季度合约）决定价格假设的节奏，例如价格在上一年已谈定的产品，当年涨幅较小，次年才体现涨价。
4. 单位成本：成熟工艺但节点切换、折旧增加时，降幅有限；新品从上一代切到下一代时，单位成本先上升，成熟后才回落。
5. 毛利率 = 1 − 单位成本 / ASP；毛利润 = 出货 × (ASP − 单位成本)。
6. 汇总：各产品毛利润相加；非重点业务（占收入约 1/4 的 NAND）直接给出出货、均价与毛利润结果。
7. 折算到集团利润，与市场一致预期对比。

**关键指标与数据来源**：kwpm、bit 出货（Gb）、ASP（美元 / GB）、单位成本变化、分产品毛利率、毛利润、市场一致预期；来源为公司披露、行业价格数据与自建假设。

**判断标准**：
- 假设的保守度需要写明：ASP 偏保守，单位成本降幅有限，是为覆盖折旧与良率爬坡。
- 毛利润的结构：DRAM 毛利润七成以上来自 DDR，说明利润主要由常规品而非 HBM 贡献。
- 集团利润低于市场一致预期，说明海豚君的假设更保守，预期差向下。

**海豚案例**：
- SK 海力士《SK 海力士：长协能熨平周期？估值到哪一步》（2026-10-09）第 4.1–4.2 节：
  - 海力士 DRAM：晶圆产能 2025–28 年约 52 万 → 74 万片 / 月；
  - 出货：HBM 约 130 亿 → 310 亿 Gb（年增 30%–40%），DDR 约 780 亿 → 1350 亿 Gb（2027 年新产能优先给 HBM，DDR 仅增约 12%）；
  - 价格（偏保守）：常规 DDR 2026 年均价 +约 290%、2027 年 +约 5%、2028 年 −约 10%；HBM 2026 年 +约 10%（价格在供应充裕的 2025 年已谈定）、2027 年 +约 62%（单 GB 约 14 → 23 美元）、2028 年 +约 10%；
  - 单位成本：DDR 工艺成熟但节点切换、折旧增加使降幅有限，2027 年起每年仅降约 2%，毛利率稳定约 91%；HBM 从 3E 切到 4，单位成本 2026 / 27 年分别 +约 13% / +39%，2029 年成熟后才回落约 5%，但涨价更多，毛利率约 69% → 75%；
  - DRAM 毛利润 2026–28 年约 1630 亿 → 2575 亿美元，毛利率 86%–87%，七成以上来自 DDR；
  - NAND（占收入约 1/4）直接给结果：出货年增 16%–20%，均价 2026 年 +270%、2027 年 +30%、2028 年 −5%，毛利润约 494 亿 → 878 亿美元；
  - 集团 2028 年利润约 350 万亿韩元（低于市场一致预期 390 万亿）≈ 2590 亿美元。

**适用场景与注意事项**：适用于以 bit 计价的商品型半导体（DRAM、NAND、HBM）；定价机制（年度合约 vs 季度合约）决定价格假设节奏；非重点业务可直接给结果，不必同等精度。

### 8.6.2 周期股分项预测：ASP 路径 + bit 出货 + 单位成本 + 毛利率 + OPM + 税率 → 净利润，并与指引推算值对比

**方法要点**：对价格主导利润的周期品，自上而下按变量逐项预测，每一步写明保守 / 激进的取向，推出利润见顶年份与回落幅度，并与管理层指引推算值对比，给出百分比差异。

**操作步骤 / 拆分口径 / 公式**：

1. ASP：按供需缺口给出“温和上涨 → 见顶 → 回落”的逐年路径和同比。
2. bit 出货：按节点迁移和新厂节奏给 CAGR。
3. 单位成本：按保守假设固定（不计新节点降本，用来覆盖新产线折旧、良率爬坡、原材料涨价）。
4. 毛利率 = 1 − 单位成本 / ASP，推出见顶年份和回落幅度。
5. OPM = 毛利率 − 费用率。
6. 净利润 = 经营利润 × (1 − 税率)，按固定税率计算；与管理层指引推算值对比，给出百分比差异（对比方法见 8.5.4 变体 B）。

**关键指标与数据来源**：ASP（美元 / GB）、bit（EB）、单位成本（美元 / GB）、毛利率、OPM、税率、净利润。

**判断标准**：
- 毛利率见顶年份与 ASP 见顶年份同步，回落幅度由 ASP 跌幅决定，单位成本固定则回落更陡。
- 净利润与指引推算值的比值，就是“周期不被熨平”下的利润折扣，是周期股估值的核心输入。
- 单位成本假设要说明是保守还是激进。

**海豚案例**：
- 闪迪《AI 改不了“DNA”…》（2026-10-06）：ASP FY27 0.37（+113%）、FY28 0.38（+2%，见顶）、FY29 −20%、FY30 −40% 至 0.18（回到 2026 年水平）；bit 从 FY26 116EB 到 FY30 218EB，CAGR 约 17%；单位成本 FY27—FY30 维持约 0.051 美元 / GB；毛利率 FY28 86.6% 见顶，FY30 72%；OPM FY28 82%，FY30 65%（三年均值仍约 75%）；税率约 15%；净利 FY28 约 416 亿见顶，FY30 约 216 亿，仅为指引推算值 508 亿的 43%。

**适用场景与注意事项**：适用于价格主导利润的周期品；单位成本假设要说明保守或激进的取向。

### 8.6.3 周期回落期 ASP 底部支撑论证：合同价格下限 + 高价值客户占比抬升

**方法要点**：即便预测价格回落，也要说明底部为什么比上一轮高：用“回落后的 ASP 仍是上一轮底部的 N 倍”来表达结构性抬升，并给出支撑依据。

**操作步骤 / 拆分口径 / 公式**：

1. 长协的价格下限：全周期最低合同收入和担保金额，换算成价格底。
2. 客户结构升级：数据中心这类高价值客户的需求占比提升，抬高均价的结构性底部。
3. 表达：回落后 ASP ÷ 上一轮底部 ASP = N 倍。
4. 提示风险：避免把一次性超级周期的结构变化过度外推。

**关键指标与数据来源**：最低合同收入、担保金额、数据中心需求占比、回落期 ASP / 上一轮底部 ASP。

**判断标准**：回落后 ASP 仍显著高于上一轮底部，并且有合同下限和需求结构两个独立依据支撑，才可以说“底部抬升”；只有一个依据时要打折。

**海豚案例**：
- 闪迪《AI 改不了“DNA”…》（2026-10-06）：FY30 ASP 约 0.18 美元 / GB，仍约为 FY25（0.07）的 2.5 倍；依据 NBM 价格下限（最低合同收入 939 亿 + 165 亿担保），以及数据中心占 NAND 需求 2028 年升到 63%。

**适用场景与注意事项**：适用于判断周期股“新底部”是否抬升；要防止把一次性超级周期的结构变化过度外推。

### 8.6.4 ASP 学习曲线外推

**方法要点**：对设备制造业，用历史 ASP 的学习曲线斜率外推未来每年降价幅度，作为“收入 = 出货 × ASP”中的价格端假设。

**操作步骤 / 拆分口径 / 公式**：

1. 统计历史 ASP（起点年、终点年），计算年均降幅。
2. 结合技术路线假设：是否会切换到理论成本更低但未大规模验证的路线。
3. 设定后续年度降幅（可略低于历史），外推到预测终点年。
4. 收入 = 出货量 × ASP。

**关键指标与数据来源**：ASP（美元 / kW）、年均降幅。

**判断标准**：假设的年降幅不高于历史年均降幅，且技术路线不发生切换，属于合理外推；若技术路线切换，降价斜率会改变，应另做情景。

**海豚案例**：
- Bloom Energy（2026-07-20）Base Case：ASP 2019 年约 4668 美元 / kW → 2025 年约 3141 美元 / kW，年均降约 6%；结合技术路线假设（尚未也无需切换至理论成本更低但未大规模验证的阳极支撑），假设后续每年降约 5%，2030 年约 2423 美元 / kW。

**适用场景与注意事项**：设备制造业的学习曲线降价；技术路线切换会改变降价斜率。

### 8.6.5 成熟业务“慢性萎缩”的简洁保守假设

**方法要点**：对已没有看点的成熟业务，按“简洁有效 + 谨慎”原则，结合过往实际增速和行业趋势做线性外推，不做细致拆分，给估值提供高可见性的底座。

**操作步骤 / 拆分口径 / 公式**：

1. 识别没有看点的成熟业务（传统软件许可、硬件、咨询等）。
2. 结合过往实际增速与行业趋势（软件云端化、AI 化），假设延续此前每年同比小幅萎缩。
3. 不做细致拆分，用线性外推；假设宁可保守。
4. 为技术替代导致“断崖下滑”的可能配套负面情景。

**关键指标与数据来源**：分业务历史营收增速、预测期 CAGR。

**判断标准**：这部分的作用是提供可见性高的底座，所以假设偏保守；若技术替代加速，则需把“慢性萎缩”改为“加速下滑”做下行情景。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：软件 + 硬件 + 咨询三块“底座型”业务合计营收在 26~30 财年的 CAGR 假设为 −2%；Legacy Hosting 假设逐年低个位数下滑。

**适用场景与注意事项**：适用于占比大但增长停滞的存量业务；风险在于技术替代可能让“慢性萎缩”变成“断崖下滑”，需要配套负面情景。

### 8.6.6 出货量 × 均价反推收入，在手订单推算潜在收入

**方法要点**：硬件产品型公司没有分产品披露时，用产品价格和订单量自下而上推算收入：用价格和已知收入倒推交付量，用大客户已下订单减已交付量得到待交付订单，再在“产能到位、不考虑新增订单”的条件下算出收入下限和同比增速。

**操作步骤 / 拆分口径 / 公式**：

1. 行业调研拿到零售价和均价（ASP）。
2. 交付量 = 已知收入 ÷ 均价，倒推出历史年度交付量。
3. 待交付订单 = 大客户已下订单 − 已交付量，判断供不应求的程度，以及增速是否卡在产能上。
4. 收入下限 = （已交付 + 待交付）× 均价，在假设产能到位、且不考虑新增订单的条件下计算，并算出同比增速。

**关键指标与数据来源**：ASP 与零售价；出货量；在手订单；代工产能。

**判断标准**：待交付订单 ≫ 年度产能 → 增速卡在产能上而非需求；收入下限即为“已有订单即可兑现”的最保守值。

**海豚案例**：
- 昆仑芯（2026-01-02）：P800 零售价 8.4 万元、均价 6 万元 / 张，推出 2025 年交付约 6 万张；预估已下订单（含百度）超过 20 万张，至少 14 万张待交付；产能到位时收入至少 84 亿元，同比 +140%。
- 百度《AI 云 + 昆仑芯，百度值得一次重估吗？》（2026-09-07）：26 年 80 亿元收入约对应 15 万张 P800 为主的交付量，在手订单预估近百亿元。

**适用场景与注意事项**：适用于硬件产品型公司，关键是 ASP 和订单来源是否可靠；订单为预估值时要标注为推算。

### 8.6.7 用“每 GW 价值量 × GW 规模”把客户订单换算成分年收入

**方法要点**：以算力功率（GW）为单位，把模糊的合作新闻换成收入数字，并与此前预期对比得出调整幅度。

**操作步骤 / 拆分口径 / 公式**：

1. 确定每 GW 价值量：整机柜交付约 200 亿美元；只交付芯片（计算 + 网络）约 50–100 亿美元，交付形态不同价值量不同。
2. 取管理层披露的客户算力规模（GW 规划）及时间表。
3. 分年度收入贡献 = 当年交付 GW × 每 GW 价值量。
4. 与此前预期对比，得出上调或下调幅度。

**关键指标与数据来源**：每 GW 收入（整柜 / 芯片）；客户 GW 规划；交付形态。

**判断标准**：交付形态（整柜 vs 仅芯片）决定了每 GW 价值量，需要写明假设；对比此前预期，超出 / 低于的部分才是预期差。

**海豚案例**：
- 博通（2026-07-07）：2026 年客户算力规模超过 1GW；4 月新协议从 2027 年起新增 5GW 下一代 TPU 算力（此前为 3GW）；Anthropic 2026 / 2027 年预计贡献约 60–80 亿 / 300 亿美元，较此前预期分别下调 130 亿 / 300 亿美元。

**适用场景与注意事项**：适用于 AI 基础设施链（芯片、网络、电源、数据中心）的订单测算，前提是每 GW 的 BOM 价值量假设可靠；与 8.5.9 的“单 GW 年收入”互补（后者面向算力租赁方，前者面向设备供应方）。

### 8.6.8 增量利润测算：在运算力 × 出租比例 × 单 GW 长约价 × 边际利润率

**方法要点**：测算新业务（算力出租）对利润的边际贡献，关键是用保守的长约均价和较高的边际利润率（因为一致预期里已经包含折旧、电费等成本），得出对一致预期利润的净增幅。

**操作步骤 / 拆分口径 / 公式**：

1. 基数：在运算力（自建 + 外租）的 GW。
2. 出租比例：根据自研模型和 Agent 计划需要，假设逐年出租比例。
3. 单价：用保守的长约均价，而非即时溢价价。
4. 边际利润率：因为一致预期已经包含数据中心折旧、电费等成本，出租收入只需扣除少量销售、电费、平台支持费用，所以用较高的边际利润率，而不是公司整体利润率。
5. 增量利润 = 在运 GW × 出租比例 × 单 GW 年化租赁收入 × 边际利润率。
6. 净增幅 = 增量利润 ÷ 一致预期利润。

**关键指标与数据来源**：在运 GW、出租比例、单 GW 年化租赁收入、边际利润率、一致预期利润。

**判断标准**：区分哪些成本已在一致预期里，避免重复扣除或漏扣；结论以“净增约 X%”表达，作为增量对估值的影响。

**海豚案例**：
- Meta《算力太贵，Meta 掀桌？》（2026-07-06）：在运算力 2~3GW，27 年总储备约 10GW；假设 26、27 年分别把全部在运算力的 15% 和 20% 用于出租；单价取 Neocloud 5 年期平均合同价 100~150 亿 / GW；正常利润率 20%~40%，这里边际利润率取 70%；测算出算力出租带来约 10%~15% 的利润净增。

**适用场景与注意事项**：适用于评估新业务或新事件对 EPS 的增量；关键是区分哪些成本已经在一致预期里，避免重复扣除或漏扣；收入端的测算可与 8.6.9 并用。

### 8.6.9 算力外租收入测算：外租比例 × GW × 单 GW 年化租金，并回代缓解 Capex 压力

**方法要点**：对新出现的算力租赁业务，用简单乘法估增量收入，并把租赁收入放回 Capex / 收入比率，看投入压力缓解程度，推导资本市场含义。

**操作步骤 / 拆分口径 / 公式**：

1. 假设外租比例（如 26、27 年各拿出 30% 算力，对应 2GW、4GW）。
2. 增量收入 = 外租 GW × 裸租年化租金（100–150 亿美元 / GW），至少 200 亿、400 亿，相对原收入预期 +8%、+12%。
3. 若搭售大模型、Agent 能力，增量会更多（作为上行项）。
4. 回代：把租赁收入放回 Capex / 收入比率，看投入压力缓解的程度。
5. 推导资本市场含义：AI 从纯成本项变为有直接收入的业务后，用债务融资“豪赌 AI”来自股东的阻力会减少。

**关键指标与数据来源**：外租比例、外租 GW、单 GW 年租金、对原收入预期的增厚比例。

**判断标准**：外租收入占原收入预期的 8%–12%，说明业务有实质增厚；Capex / 收入比的缓解程度，决定了市场对“投入无回报”的担忧是否减轻。

**海豚案例**：
- Meta（2026-07-10）：假设 26、27 年各拿出 30% 算力外租（2GW、4GW）× 裸租年化租金 100–150 亿美元 / GW → 至少新增 200、400 亿收入，相对原收入预期 +8%、12%；考虑新建算力的额外投入与 30% 外租收入后，Capex 相对收入端压力有所放缓。

**适用场景与注意事项**：云 / 算力租赁类新业务；租金水平随行业供需变化，需情景化。

### 8.6.10 收入分成业务的倒推：设备数 × 单设备分成 × 12 个月

**方法要点**：新业务没有单独披露时，用公开报道的单用户分成价格乘以接入设备数乘以 12 个月，估算年收入，再算它占所在分部收入的比例，判断新业务当前体量，同时梳理合作模式。

**操作步骤 / 拆分口径 / 公式**：

1. 取公开报道的单用户分成价格（如用户额外付约 10 美元 / 月，平台方分约 5.5 美元 / 月）。
2. 年收入 = 接入设备数（年底活跃设备）× 单设备分成 × 12。
3. 占比 = 年收入 ÷ 所在分部收入，判断体量。
4. 梳理合作模式：频谱被运营商占据，平台方只是技术分包商，运营商在自家渠道卖卫星流量包，双方分成。

**关键指标与数据来源**：活跃设备数（2026Q1 为 740 万，覆盖 30 国、30 家运营商）、分成单价、C 端总收入。

**判断标准**：测算的年收入占分部收入的比例很小，说明新业务当前体量有限，不应在近期估值中给过高权重。

**海豚案例**：
- SpaceX《Space X：天空之网…》（2026-06-15）：以 T-Mobile 为例，用户额外付约 10 美元 / 月，SpaceX 分约 5.5 美元 / 月，乘以接入设备数（2025 年底约 600 万台）乘以 12 个月，估算 D2C 2025 年收入约 4 亿美元，仅占 Starlink C 端收入 72 亿美元的 5.5%。

**适用场景与注意事项**：适用于收入分成、渠道合作类新业务的规模估算；单价来自公开报道，不同运营商可能差异很大。


### 8.6.11 新业务短期增量收入情景测算 + MAU / GMV 敏感性矩阵

**方法要点**：对刚推出的新业务（如 AI 助手里的电商与订阅），用“用户规模 × 转化 × 客单 × 抽佣 / 付费率 × 月费”的乘法公式测算短期增量收入，再做不同 MAU 与 GMV 下的敏感性表，判断它对总收入的贡献量级。

**操作步骤 / 拆分口径 / 公式**：

1. 公式：
   - GMV = MAU × 电商交易用户占比 × 人均年成交额；
   - 佣金收入 = GMV × 抽佣率；
   - 订阅收入 = MAU × 付费率 × 月费 × 12。
2. 参数（来自对标案例）：
   - 明年底 3 亿 MAU；
   - 30% 电商用户；
   - 人均 500 美元（Shopify 用户年花费约 200 美元，Meta 高价值用户中和）→ 450 亿 GMV；
   - 抽佣 3%（对标 2026 年初 OpenAI 与 Shopify 合作抽佣 4%，后因转化率太低取消）→ 13.5 亿；
   - 订阅 2% 付费率 × 30 美元 / 月 → 约 22 亿；
   - 合计约 35 亿。
3. 做不同 MAU 与 GMV 组合下的敏感性表，计算占总营收的比例。
4. 明确未计入的部分（广告与 Business Agent 用量增量），交给业绩会跟踪。

**关键指标与数据来源**：MAU、电商用户占比、人均 GMV、抽佣率、付费率、月费；参数取自对标案例。

**判断标准**：对 2500 亿营收的贡献仅 0.3%–3%，说明短期增量有限，该业务的价值更多体现在“估值情绪的修复”而不是利润；未计入项（广告、Agent 用量）作为后续跟踪点。

**海豚案例**：
- Meta（2026-09-23，文章主旨“Muse 的增量价值，短期在估值情绪的修复”）：按上述参数得到约 35 亿美元增量，对 2500 亿营收贡献仅 0.3%–3%。

**适用场景与注意事项**：新业务早期收入测算；参数取自对标案例，需随披露更新；敏感性矩阵要给出区间而非单点。

### 8.6.12 分层订阅用户 × 加权 ARPU 自下而上测算 ARR，再用 P / ARR 估值

**方法要点**：对收入没有单独披露的 AI 模型业务，用公开用户数和分层定价自下而上测算 ARR，再按成长阶段给 P / ARR 倍数，并给出情景区间。

**操作步骤 / 拆分口径 / 公式**：

1. C 端①（直接订阅）：订阅用户数 × 加权 ARPU × 12。加权 ARPU = Σ（分层价格 × 占比）。
   - 190 万 SuperGrok 用户，按三层定价分布：Lite 9 美元 / 月占 50%、Standard 28 美元 / 月占 45%、Heavy 265 美元 / 月占 5%，加权 ARPU 约 30 美元 / 月，ARR 约 6.8 亿。
2. C 端②（捆绑订阅）：用户数 × 增量价值 × 12。
   - 440 万 X Premium 用户，订阅费主要买社交功能，假设 Grok 的增量价值 8 美元 / 月，ARR 约 4.2 亿。
3. C 端合计约 11 亿。
4. B 端（Business / Enterprise / API）刚起步，按占比约 10% 估约 1 亿；总 ARR 约 12 亿。
5. 估值：参考 OpenAI（同样 C 端起家），因处于增长早期，中性给 50x P / ARR，对应 600 亿；若年底 ARR 增长到 21 亿（Grok 5 发布、企业层和 API 放量），给 35–40x，对应 744–850 亿。

**关键指标与数据来源**：订阅用户数、分层价格与占比、加权 ARPU、ARR、B 端占比、P / ARR。

**判断标准**：用户分层比例是主观假设，结论应以区间表达；倍数随 ARR 增速和阶段变化而下调（ARR 增长后倍数从 50x 降至 35–40x，估值仍从 600 亿升到 744–850 亿）。

**海豚案例**：
- SpaceX《SpaceX：太空算力，马斯克新饼，还是真未来？》（2026-07-08）：Grok ARR 约 12 亿 → 600 亿（50x）；年底 21 亿 → 744–850 亿。

**适用场景与注意事项**：适合大模型、SaaS 等收入没有拆分披露的子业务；用户分层比例是主观假设，结论应以区间表达。

### 8.6.13 ARR 按月环比增速外推 + 对比公司年度目标与市场预期 + 隐含年化增速判断

**方法要点**：对未上市 AI Lab 做 ARR 预测：先甄别传闻，再按月环比增速外推全年，与公司年初目标和市场预期对比；关键不在“是否超目标”，而在“增速斜率”，因为超目标早已 priced in。

**操作步骤 / 拆分口径 / 公式**：

1. 甄别传闻：近期月数据不可得时，先判断小作文的可信度（例如传出的 Yipit 测算 795 亿被 Yipit 打假）。
2. 按与预测值相近的 20% 月环比估 7 月 ARR；8 月之后考虑竞争加剧，增速按趋势缓慢下滑至年底约 5%，逐月外推得出年底 ARR。
3. 对比公司年初制定的收入目标与市场预期年底 ARR，判断达成难度。
4. 计算隐含年化增速：若下半年月环比真降至年底 5%，则隐含年化增速约 70%，据此判断对估值弹性的影响。

**关键指标与数据来源**：ARR、月环比增速、公司年度收入目标、市场预期 ARR、隐含年化增速；来源为 Yipit、公司披露。

**判断标准**：
- 达成难度不大，但超目标早已 priced in；增速斜率（月环比）比“是否达标”更决定估值。
- 隐含年化增速降到约 70%，对上市后的估值弹性不利。

**海豚案例**：
- Anthropic《Kimi K3 时刻：中美 AI 产业链叙事要变天？》（2026-07-22）：年底 ARR 预测 1180 亿美元，对比公司年初制定的 260 亿收入目标与市场预期年底 1000 亿 ARR，判断达成难度不大；但若下半年环比真降至年底 5%，隐含年化增速约 70%，对上市后估值弹性不利。

**适用场景与注意事项**：适用于高增长订阅 / API 收入公司的预测与预期管理；月度外推对增速假设敏感，应做情景。

### 8.6.14 用下游客户 ARR 轨迹推演供应商收入增速

**方法要点**：供应商收入高度依赖少数客户时，用客户 ARR 的月度轨迹推算其对供应商的贡献，再叠加供应商非该客户的收入，得到整体增速，并与自己的模型对照。

**操作步骤 / 拆分口径 / 公式**：

1. 取客户最新 ARR（截至 5 月约 450 亿美元）与近期环比变化（3、4 月达峰后 5 月环比放缓）。
2. 保守假设后续每月环比增量平稳下降，推出年底 ARR（约 700 亿出头）。
3. 简化假设云的 AI 收入全部来自该客户；非 AI 收入增速约 16%（去年约 14.4%）。
4. 得出该客户贡献云全年收入约 19%，带动云全年增速 35% 以上（一季度约 28%），并与自身模型预估对照。

**关键指标与数据来源**：客户 ARR 与环比增量、非 AI 收入增速、AI 收入占比。

**判断标准**：自下而上测算的增速与此前自有模型的预估大体相当，说明模型稳健；若差异显著，需检验“AI 收入全部来自该客户”的简化假设。

**海豚案例**：
- Amazon（2026-06-24）：测算结果与海豚君此前模型中预估的 AWS 全年增速大体相当。

**适用场景与注意事项**：供应商收入高度依赖少数客户的场景（云 - AI Lab、芯片 - 云厂商）；简化假设（AI 收入全部来自单一客户）会高估客户贡献，需说明。

### 8.6.15 竞品对标法：用对标车型月均销量区间估算未上市新车销量

**方法要点**：对即将上市、还没有订单数据的新车，用定位最接近的竞品的月均销量区间作为参考范围，叠加现有车型稳定月销，得到全年销量的情景区间，作为汽车业务估值的输入。

**操作步骤 / 拆分口径 / 公式**：

1. 找出定位最接近的竞品，取其月均销量区间。
2. 新车销量区间 = 竞品月均销量区间 × 剩余月份数。
3. 叠加现有车型稳定月销（全年），得到全年总销量的情景区间。
4. 把全年销量的底部 / 中枢 / 上限作为汽车业务估值输入。

**关键指标与数据来源**：竞品月均销量区间、剩余月份数、现有车型月销。

**判断标准**：竞品的品牌力和渠道差异需要调整；用区间（底部价值对应的全年销量）而非单点表达。

**海豚案例**：
- 小米《又双叒原地久跪…》（2026-08-18）：澎程 N70 对标车型月均 1–3 万，N90 Max 对标车型月均 0.5–1.5 万，预估澎程未来 4 个月销量 6–18 万；叠加 SU7 + YU7 全年约 37 万，汽车业务底部价值对应全年约 43 万辆。

**适用场景与注意事项**：适用于新车型或新品类的销量预测；竞品的品牌力和渠道差异需要调整。

### 8.6.16 月度销量拆分国内 / 海外、剔除一次性因素，并用开年节奏验证管理层指引

**方法要点**：用最新累计销量检验全年判断：国内和海外分开看，识别非经营性扰动，再用海外开年节奏验证管理层全年海外指引是否可达，最终给出分区域的全年销量预测。

**操作步骤 / 拆分口径 / 公式**：

1. 分区域：国内、海外分开拆分累计销量及同比。
2. 识别非经营性扰动：春节错期、去库存、政策退坡提前透支（如购置税退坡），并剔除其影响。
3. 用海外开年节奏验证管理层全年海外指引：全年指引 ÷ 上年海外销量 = 需要提升的幅度；对照开年节奏是否可达。
4. 分区域给出全年销量预测，求和得全年总销量与同比。

**关键指标与数据来源**：月度累计总销量、国内销量、海外销量及同比；春节错期；渠道库存；管理层年度海外指引。

**判断标准**：开年两个月数据受季节性影响大，结论要随月度数据滚动修正；海外开年增速若足以覆盖指引所需的提升，则判断指引可达。

**海豚案例**：
- 比亚迪《比亚迪：“颠覆性”发布会，能“颠回”宇宙车厂吗？》（2026-03-06）：2026 年 1–2 月累计销量约 40 万辆，同比下滑约 35.8%；国内仅 20 万辆（同比下滑 59%），受购置税退坡、春节错期和主动去库存影响；海外 20.1 万辆，同比大增超 50%；管理层全年海外 150 万辆指引（2025 年约 104 万辆，提升约 45%）预计可达成；最终分区域预测：国内同比下滑约 10% 至 321 万辆，海外 150 万辆，全年 471 万辆（同比增 2.3%）。

**适用场景与注意事项**：适用于有月度销量披露的车企和消费品公司；开年两个月数据受季节性影响大，结论要随月度数据滚动修正。

### 8.6.17 季节占比倒推季度收入，并用 PE 定位判断市场定价逻辑

**方法要点**：公司只披露增速区间时，用历史季度占比还原基数，推算本季收入并做环比比较；区域增速放在渗透阶段里评价；最后用 PE 定位，判断市场定价逻辑是否有误。

**操作步骤 / 拆分口径 / 公式**：

1. 用历史季度占比（某季度收入 ÷ 全年收入）还原去年同期基数。
2. 本季收入 = 去年同期基数 × (1 + 披露的增速区间)，并与上季度做环比比较。
3. 区域增速放在对应市场所处的渗透阶段里评价，不孤立看数字高低。
4. 用 PE 定位：以全年净利润和当前市值得到 PE，判断市场定价逻辑是否有误。

**关键指标与数据来源**：增速区间、季度占比、PE。

**判断标准**：推算的季度收入环比仅小幅下降（个位数），说明增长并未“放缓”；若全年净利对应的 PE 明显低于合理区间，则判断估值被低估。

**海豚案例**：
- 泡泡玛特（2026-05-12）：推算 Q1 约 98 亿，环比仅降个位数；中国区增速 100%–105%；全年净利 160 亿对应约 12x，判断估值被低估。

**适用场景与注意事项**：适用于只披露运营数据的公司；季节占比要用与当年业务结构可比的历史年份。

### 8.6.18 开店节奏预测：行业出清红利期高扩张、规模阈值后放缓；模型打磨期 → 跑通加速期分阶段

**方法要点**：开店假设不是线性外推，而是与外部环境（行业出清红利）、规模阈值（对标龙头）或单店模型验证进度（打磨期 → 加速期）挂钩，并对加盟店作单独假设。

**操作步骤 / 拆分口径 / 公式**：

变体 A：行业出清红利期 → 规模阈值后放缓（亚朵）

1. 判断外部环境：近两年大量经营不善的单体酒店倒闭，释放出核心商圈、交通枢纽的优质物业，为头部连锁创造低成本获取物业、提升集中度的机会，整合红利短期继续释放。
2. 2026–2027 年假设较高扩张速度；门店突破 2500 家后参考华住，2028 年起开店逐步放缓，转向优化存量门店结构、提升单店效率。

变体 B：模型打磨期 → 模型跑通加速期，加盟店零增长（星巴克）

1. 2026–2027 年北美以存量门店改造和单店 ROI 修复为主，年均新开 150–200 家。
2. 2028 年新单店模型跑通后，店型向轻量化转向，开店加速至年均 400–500 家。
3. 授权 / 加盟门店集中于封闭或特定场景（Target 卖场、机场车站、大学、医院），全美渗透接近瓶颈，假设新建优质场景店与关停低效店抵消、不再增长。
4. 合成 2030 年门店总数，与当前对比。

**关键指标与数据来源**：年度新开店数、净开店数、门店总数阈值；直营新开店数、加盟净开店、门店总数。

**判断标准**：
- 规模阈值和放缓节奏可参考行业龙头的历史路径（突破某一规模后增速放缓）。
- 开店节奏应与单店模型验证进度挂钩，而非直接线性外推：模型未跑通前不放量，跑通后才加速。

**海豚案例**：
- 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：开店预测图，2026–2027 年高扩张，门店突破 2500 家后参考华住，2028 年起放缓（变体 A）。
- 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：北美 2026–2027 年年均新开 150–200 家，2028 年起加速至 400–500 家，加盟店不再增长；合成 2030 年北美门店 20049 家，较当前提升约 10%（变体 B）。

**适用场景与注意事项**：适用于连锁扩张型企业；变体 A 适合有行业出清、集中度提升逻辑的行业，变体 B 适合处于困境反转、单店模型在重新验证的公司；扩张路径本身的评估见 7.2。

### 8.6.19 分品牌门店与加盟假设：“下沉 + 加盟提速 + 同店温和修复”，按成长阶段区分弹性与确定性

**方法要点**：多品牌连锁把未来五年成长拆成按品牌的三块，共同主线是门店下沉、加盟提速、同店温和修复，区别在各品牌所处的成长阶段；对每个品牌区分“弹性”与“确定性”，并对标同业门店规模检验假设。

**操作步骤 / 拆分口径 / 公式**：

1. 主力成熟品牌（KFC）：
   - 2025 年底 12997 家，公司指引净新增中加盟占比提升至 40%–50%；
   - “肯德基小镇 mini 店”打开过去算不过账的低线点位；直营继续一二线加密；
   - 假设 2030 年 19527 家，加盟占比 15% → 25%；用华莱士近 2 万家对标验证“不算激进”；
   - 同店温和修复，关键增量是肯悦咖啡店中店。
2. 低基数品牌（必胜客）：
   - 4168 家，存量加盟占比仅 7%，净新增加盟指引 20%–30%；
   - WOW 店扩大价格带下沉；
   - 基数低弹性可能更大，但模型能否复制、品牌大众化认知能否重塑待验证，确定性不如 KFC。
3. 其他品牌（肯悦独立店、Lavazza、塔可钟、小肥羊、黄记煌）：体量小，共用中台试错成本低，跑出一个即“免费附送的第二曲线”，不逐个建模。
4. 汇总得到整体利润增速。

**关键指标与数据来源**：分品牌门店数、加盟占比、净新增加盟占比指引、同店增速。

**判断标准**：对标同业门店规模（华莱士近 2 万家）验证目标门店数“不算激进”；对低基数品牌，弹性大但需待验证，因此确定性低于成熟品牌。

**海豚案例**：
- 百胜中国《百胜中国：一只“洋鸡”，凭何在东方称王三十年？》（2026-07-02）：按上述三块建模，利润增速 CAGR 约 8%。

**适用场景与注意事项**：适用于多品牌连锁；对不同成长阶段品牌区分“弹性”与“确定性”，并对标同业门店规模检验假设。

### 8.6.20 同店增速“低基数反弹 → 回落常态 → 历史正常水平”三段路径假设

**方法要点**：困境反转公司的同店假设，先复盘下滑原因，再看修复动作，然后给出三段式路径，并用自下而上的增量测算支撑第一年的反弹，同时明确假设的激进程度。

**操作步骤 / 拆分口径 / 公式**：

1. 复盘下滑原因：高通胀下 6 美元一杯的性价比质疑、移动点单拥堵反噬体验；FY2024 同店 −1.5%、FY2025 −1.8%，客流连续七个季度承压。
2. 看修复动作：“重回星巴克”——优化点单算法、砍 30% 冗余 SKU、翻新上千家门店、增加门店人手；4Q25 北美同店在低基数下率先转正、客流拐点初现。
3. 路径假设：
   - 2026 年 +5.5%（低基数 + 体验修复 + 下午时段新品，用下午时段 +10% 拉动 2.5pct 的测算支撑）；
   - 2027 年回落至 +4.5%；
   - FY2028–2030 稳定在 +4% 左右（回到历史正常年份）。
4. 国际市场：中国出表后同店影响弱化，EMEA 约 +1–2%、亚太约 +2–3%。
5. 合成 2026–2030 年营收 CAGR 约 6.5%。

**关键指标与数据来源**：同店增速、客流、客单价、分区域同店。

**判断标准**：反弹第一年要有自下而上的增量测算支撑（如下午时段 +10% 拉动 2.5pct）；之后回落到历史正常水平，不把反弹延续成新常态。

**海豚案例**：
- 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：按上述路径预测，海豚君自称假设“比较积极”。

**适用场景与注意事项**：适用于处于困境反转的消费公司；同店假设需用自下而上的增量测算支撑，并明确假设激进程度。

### 8.6.21 RevPAR = OCC × ADR：以行业天花板约束 OCC，以产品结构升级驱动 ADR

**方法要点**：酒店业务按 RevPAR = 入住率（OCC）× 平均房价（ADR）建模，OCC 受行业天花板约束，增长主要由产品结构升级驱动 ADR。

**操作步骤 / 拆分口径 / 公式**：

1. OCC：先看公司整体、成熟门店（经营 2 年以上）与行业中高端顶尖水平；提升空间不大时，只假设随新店爬坡和品牌势能小幅提升。
2. ADR：结合管理层交流会披露的战略（持续提升中高端产品占比、新开门店结构目标），把产品结构升级映射到 ADR 路径。
3. RevPAR = OCC × ADR；结合门店数与客房规模的预测（见 8.6.18），汇总得到酒店业务营收 CAGR。

**关键指标与数据来源**：OCC（整体 / 成熟门店 / 行业顶尖）、ADR、新开门店产品结构、营收 CAGR。

**判断标准**：OCC 已接近行业天花板时，主要靠 ADR（产品结构升级）；若 OCC 假设高于行业顶尖水平则过于激进。

**海豚案例**：
- 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：OCC 亚朵整体 78%、成熟门店 83%，中高端顶尖水平 80%–85%，提升空间不大，假设小幅升到 80%；投资者交流会信息显示持续提升中高端产品占比是未来 3–5 年核心战略，2025–2028 年中高端新开门店（主品牌以上）占比从 80% 升到 95% 以上，ADR 从 446 元 / 天升到 482 元 / 天；最终酒店业务 2025–2029 年营收 CAGR 13.5%。

**适用场景与注意事项**：适合酒店、航空（客座率 × 票价）等量价拆分业务。


### 8.6.22 零售分品类 GMV 预测：按竞争格局差异化设定 CAGR 后汇总

**方法要点**：零售业务不按总量一刀切，而是按品类分别预测 GMV，每个品类的增速由其竞争格局决定（头部跟进者多的品类增速下滑，跟进者少的品类保持高增速），再加上新品类假设后汇总到零售与集团营收。

**操作步骤 / 拆分口径 / 公式**：

1. 把零售拆成核心品类，各自预测起点年、终点年 GMV 与 CAGR。
2. 增速假设与竞争分析一致：头部家纺跟进、竞争压力加大的品类，增速逐步下滑；跟进者少的品类，短期保持高增速。
3. 假设中期再造一个新品类（如 10 亿以上 GMV 的床品品类）。
4. 汇总得到零售营收 CAGR，再与酒店业务汇总得到集团总营收与 CAGR。

**关键指标与数据来源**：分品类 GMV、CAGR、新品类贡献。

**判断标准**：品类增速要与竞争分析相互一致；新品类假设单列、金额克制。

**海豚案例**：
- 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：深睡枕因头部家纺跟进、竞争压力加大，增速逐步下滑，GMV 从 2025 年 23 亿到 2029 年 41 亿，CAGR 16%；控温被跟进者少，短期保持高增速，11 亿到 32 亿，CAGR 31%；另外假设中期再造一个 10 亿以上 GMV 的床品品类；零售营收 CAGR 20%；集团总营收从 103 亿到 190 亿元，CAGR 17%。

**适用场景与注意事项**：适合多品类消费品牌，各品类增速假设要和竞争分析一致。

### 8.6.23 3P 业务预测：渗透率爬坡 × 变现率温和抬升，广告作上行期权不计入中性

**方法要点**：平台化早期公司的 3P（第三方卖家）预测拆成两条线：渗透率与变现率；成熟平台的广告变现率不计入中性预测，单列为上行期权；做悲观 / 中性 / 乐观三情景，正文只披露中性。

**操作步骤 / 拆分口径 / 公式**：

1. 渗透率线：品类扩展、本地卖家生态加密、3P 占比向亚马逊路径靠拢。
2. 变现率线（take rate）：当前处于让利换商家阶段，随卖家密度提升，佣金与增值服务提价；对标同业 take rate。
3. 3P 收入 = 3P GMV × 变现率；3P GMV = 总 GMV × 3P 渗透率。
4. 广告变现率（成熟平台占 GMV 3%–5%、近乎纯利）不计入中性预测，单列为上行期权。
5. 做悲观 / 中性 / 乐观三情景，正文只披露中性。

**关键指标与数据来源**：3P GMV、3P 渗透率、take rate、广告变现率（占 GMV）。

**判断标准**：广告搜索竞价、展示位尚未系统变现时，不宜过早计入中性；变现率提升要有对标（同业 take rate）支撑。

**海豚案例**：
- SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：当前变现率约 15%（沃尔玛 18%–20%），中性情景 3P GMV 从 390 亿提升至 714 亿美元，CAGR 16%；广告搜索竞价、展示位尚未系统变现，作上行期权。

**适用场景与注意事项**：平台化早期公司；广告变现率起点低时不宜过早计入。

### 8.6.24 1P 量价 + 3P 假设拼接集团收入、利润率与净利润路径

**方法要点**：在 3P 预测基础上叠加 1P 量价预测，汇总集团收入 CAGR；利润端按年份描述承压期与修复期，得到经营利润率从低点修复的路径及净利润 CAGR。

**操作步骤 / 拆分口径 / 公式**：

1. 1P 量价：如客单价随新兴市场扩张小幅下滑，叠加 1P 销量。
2. 集团收入 = 1P 收入 + 3P 收入，算集团收入 CAGR。
3. 利润端按年份描述：短期受关税与合规成本压制（承压期）；之后 3P 占比提升推高毛利、本地仓摊薄履约（修复期）。
4. 得到经营利润率从低点修复的路径，以及净利润及 CAGR。

**关键指标与数据来源**：集团收入及 CAGR、3P 占收入比、经营利润率路径、净利润及 CAGR。

**判断标准**：利润率修复主要来自 3P 占比提升（结构变化）；对结构占比假设高度敏感，应明确占比的起点与终点。

**海豚案例**：
- SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：收入 2026–2030 年从 458 亿增至 606 亿美元，CAGR 约 7.7%；2026–2027 年承压，2028 年起 3P 占收入比从 11% 拉高至 19%，经营利润率从 2.4% 低点修复至 2030 年 5.5%，净利润 17 亿 → 38 亿美元，CAGR 约 22%。

**适用场景与注意事项**：多业务结构变化驱动利润率的公司；对结构占比假设高度敏感。

### 8.6.25 券商 / 交易平台的驱动因子链：账户数 → DARTs → 交易收入，账户 → 生息资产 → NII

**方法要点**：短期业绩预测按驱动链展开，把“量”（账户、生息资产）与“价”（佣金率、NIM）分开假设，再合成收入、利润率与净利润。

**操作步骤 / 拆分口径 / 公式**：

1. 账户数增速：结合行业驱动（如 AI + 跨境投资）假设。
2. 交易收入：账户数 → DARTs（日均交易笔数）增速，叠加降佣趋势，得到交易收入增长中枢。
3. 净利息收入：账户 → 生息资产。新兴市场新用户人均资产较低，生息资产增速低于账户数；NIM 受阶段性加息受益（敏感度见 8.6.28）。
4. 利润率：投入期对经营利润率略有影响但可控。
5. 合成业绩增速与净利润。

**关键指标与数据来源**：账户数增速、DARTs 增速、佣金率趋势、生息资产增速、NIM、经营利润率。

**判断标准**：量与价分开：账户增长是量，佣金率下降是价；生息资产增速与账户增速不同步时要解释原因（新用户资产少）。

**海豚案例**：
- 盈透《盈透：将“极致效率”刻进 DNA 的交易扫地僧》（2026-09-22）：2027 年账户数 +25%（继续受益 AI + 跨境投资）；DARTs 增速 15%–20%；叠加降佣趋势，交易收入增长中枢约 15%；生息资产随账户增长但新兴市场新用户人均资产较低，增速低于账户数，按 15%–20%；NIM 受阶段性加息受益（加息 25bp 对总营收 +2%）；投入期对经营利润率略有影响但可控 → 2027 年业绩增速 15%–20%，税后净利润约 60 亿美元。

**适用场景与注意事项**：适用于券商 / 交易平台；关键是区分量（账户、生息资产）与价（佣金率、NIM）。

### 8.6.26 利润率路径：分业务毛利率路径 + 费用杠杆推导净利率

**方法要点**：不直接给集团毛利率，而是把业务拆成两三块分别预测毛利率（按成本结构变化或对标龙头），加权得到集团毛利率，再结合费用率的规模效应推到净利率或净利润。

**操作步骤 / 拆分口径 / 公式**：

变体 A：产品 / 服务分别预测，再加权（制造 + 服务混合模式）

1. 产品毛利率：技术降本 + 规模效应；服务毛利率：长期服务合同规模扩大，摊薄运维固定成本。
2. 分别设定终点年毛利率，加权得到整体毛利率。
3. 再考虑费用端杠杆释放，推出净利率。

变体 B：对标龙头 + 销售费用率的规模效应假设推到净利润（多业务模型）

1. 酒店业务毛利率对标华住，随轻资产加盟占比提高、成本控制和运营效率优化小幅上升；零售业务随规模效应和产品结构升级小幅上升；加权得到集团毛利率。
2. 费用：零售近两年从 0 到 1 爆发，投入大量营销（明星代言、直播带货、线上投流），假设品牌势能提升后在规模效应下销售费用率下降；管理费用率保持平稳。
3. 得到净利润及 CAGR，利润增速快于收入。

**关键指标与数据来源**：产品毛利率、服务毛利率、整体毛利率、净利率；分业务毛利率、集团毛利率、销售费用率、管理费用率、净利润 CAGR。

**判断标准**：
- 毛利率改善要有明确来源（技术降本、规模效应、合同规模扩大、加盟占比提高、产品结构升级）。
- 净利率目标属“中性偏乐观”时要明示；对标龙头的利润率要考虑商业模式差异。
- 利润增速快于收入，说明经营杠杆释放。

**海豚案例**：
- Bloom Energy（2026-07-20）（变体 A）：产品毛利率 2021 年 29% → 2025 年 35.2%（技术降本 + 规模效应），假设再升约 4pct 至 2030 年 39.3%；服务毛利率 2024 年约 −1% → 2025 年 10%（长期服务合同规模扩大、摊薄运维固定成本），假设升至 2030 年约 20.6%；加权后整体毛利率由 2025 年 29% 升至 2030 年约 35.8%；再考虑费用端杠杆释放，净利率由 2025 年 4.3% 升至 2030 年 24%（中性偏乐观）。
- Rocket Lab《Rocket Lab：SpaceX 最危险的对手？》（2026-04-10）（变体 A，同属经营杠杆论证）：随收入规模扩大毛利率提升、各项费用摊薄，海豚君认为盈利无需担心。
- 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）（变体 B）：毛利率方面，酒店业务对标华住，随轻资产加盟占比提高、成本控制和运营效率优化，从 36.4% 升到 38.4%；零售业务随规模效应和产品结构升级，从 53.4% 升到 55.4%；集团从 43.5% 升到 46.3%。费用方面，销售费用率从 14.4% 降到 12.4%，管理费用率保持平稳；最终净利润 2025–2029 年从 18.6 亿到 41.2 亿元，CAGR 22%，利润增速快于收入。

**适用场景与注意事项**：变体 A 适用于制造 + 服务混合模式公司；变体 B 适用于多业务模型的利润预测。利润率的拆解（毛利率、费用率、回报率）本身见 8.1，本节只用于预测路径。

### 8.6.27 费用率路径假设：门店运营费用率与管理费用率随经营杠杆下降

**方法要点**：利润率修复型公司把费用端分成两大项建模（门店运营费用率与管理费用率），明确每项下降的驱动因素，并检验合成的分部利润率是否超过历史高点，以检验假设激进度。

**操作步骤 / 拆分口径 / 公式**：

1. 门店运营费用率：因主动加投人工工时，2025 年处 46% 历史高位；假设随同店转正带来的经营杠杆、Green Apron 标准化运营与人效改善，从 45.9% 逐步降至 2030 年 39.8%。
2. 管理费用率：随组织精简与数字化提效，从 7% 降至 5.1%。
3. 合成：经营利润率 = 毛利率 − 费用率，得到从底部 10% 修复至 19% 的路径，利润 CAGR 约 24%。
4. 检验：隐含北美经营利润率修复至 21.6%，小幅超过下滑前水平，说明假设并不保守。

**关键指标与数据来源**：门店运营费用率、管理费用率、经营利润率、北美分部利润率。

**判断标准**：需明确隐含的分部利润率是否超过历史高点，以此判断假设激进度；费用率下降的前提是同店转正（见 8.6.20）。

**海豚案例**：
- 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：门店运营费用率 45.9% → 39.8%、管理费用率 7% → 5.1%；经营利润率从底部 10% 修复至 19%，利润 CAGR 约 24%；隐含北美经营利润率修复至 21.6%（小幅超过下滑前水平）。

**适用场景与注意事项**：适用于利润率修复逻辑的公司；需明确隐含的分部利润率是否超过历史高点，以检验假设激进度。

### 8.6.28 用管理层披露的利率敏感度测算加息对收入的影响

**方法要点**：对利息收入占比高的公司，用电话会披露的敏感度（每 25bp 对净利息收入的影响）测算加息 / 降息对收入的影响，判断绝对影响与估值情绪的放大效应。

**操作步骤 / 拆分口径 / 公式**：

1. 取管理层披露的敏感度：美元基准每升 / 降 25bp → 年度净利息收入增 / 减 0.81 亿美元；非美元（占约 1/3 敏感度）每升 / 降 25bp → 增 / 减 0.38 亿美元。
2. 设定加息路径：例如年内加息两次合计 50bp 且非美同步 → 对当年收入增长影响约 3%–4%；2027 年再温和加息 25bp → 对总营收约 +2%。
3. 判断：绝对影响不大，但估值预期可能放大利好情绪。

**关键指标与数据来源**：利率敏感度（每 25bp 对 NII 影响）、NII 占收入比（60%）。

**判断标准**：敏感度测算只回答“收入弹性有多大”，判断时要区分币种敏感度与客户存款 beta 变化；利率周期拐点时短期业绩对利率敏感度更高。

**海豚案例**：
- 盈透《盈透：将“极致效率”刻进 DNA 的交易扫地僧》（2026-09-22）：当下正处利率周期拐点，短期业绩对利率敏感度更高；按上述敏感度，加息 25bp 对总营收约 +2%。

**适用场景与注意事项**：适用于银行、券商、保险、支付等利息敏感行业；注意区分币种敏感度与客户存款 beta 变化。

### 8.6.29 自下而上全年业绩情景：规模环比假设 → 年末规模 → 利息与其他收入 → 毛利率与费用 → 经营利润 → 估值倍数

**方法要点**：市场预期滞后或波动大时，自建全年情景：用少数驱动变量（稳定币规模环比、利率）推出全年收入，加上毛利率与费用得到经营利润，再用当前市值算 EV/EBITDA，判断估值是否已透支。

**操作步骤 / 拆分口径 / 公式**：

1. 规模：假设剩余三季规模环比增速（对比去年同期 QoQ，按保守值）推出年末规模。
2. 利息收入 = 规模 × 不变利率。
3. 总收入 = 利息收入 + 其他收入（超指引上限的部分），得到总收入及增速。
4. 经营利润：按毛利率与指引费用中枢算出经调整经营利润。
5. 估值：用当前市值得到 EV / EBITDA，判断估值是否已透支。

**关键指标与数据来源**：USDC 季度环比增速假设、年末规模、利率、利息收入、其他收入、毛利率、经营费用、经调整经营利润、EV / EBITDA。

**判断标准**：假设环比增速显著低于去年同期（保守取值）后，估值倍数仍然很高，则判断估值已透支。

**海豚案例**：
- Circle《Circle：稀烂行情…》（2026-05-11）：假设剩余三季环比 5%（去年 Q2–Q3 为 12%），年末 870 亿；按 3.5% 利率，全年利息收入 28 亿；其他收入 1.7 亿；总收入 30 亿（+9%）；42% 毛利率，费用中枢 5.8 亿，经调整经营利润 6.8 亿；280 亿市值对应约 40x EV / Adj.EBITDA。

**适用场景与注意事项**：适用于收入可由少数驱动变量推导的公司（如稳定币发行商）；规模环比假设要明确保守度。

### 8.6.30 宏观冲击的传导链分析：油价 → 需求 / 成本 → 分部利润

**方法要点**：把宏观事件按传导路径分解到具体业务，再看公司实际受影响的程度（客流下滑多少、补贴金额多大），评估经营韧性。

**操作步骤 / 拆分口径 / 公式**：

1. 识别宏观事件（如中东冲突推高油价）。
2. 按传导路径分解：
   - 需求端：高油价影响出行和旅游需求，压制主题公园；
   - 成本端：园区消费品成本上升，向终端转嫁不顺畅；
   - 平台补贴：网约车平台给司机油费补助，记为收入减项，压低变现率。
3. 对每一条传导链找公司实际受影响的数字（客流、补贴额、变现率变化）。
4. 评估经营韧性：受影响幅度 vs 其他业务的对冲。

**关键指标与数据来源**：油价、园区客流、成本、补贴额、变现率。

**判断标准**：冲击已在客流、补贴等数字中体现，而收入 / 利润仍然增长，说明经营韧性强；若冲击没有体现，则需预留后续传导的空间。

**海豚案例**：
- 迪士尼《迪士尼：新官首秀不俗》（2026-05-06）：中东摩擦导致高油价，影响旅游需求和园区成本，美国本土园区客流同比 −1%，但体验收入仍增长 7%。
- Uber《Uber：业绩都在线》（2026-05-07）：美伊冲突推高油价，油费补贴约 10 亿美元，网约车变现率从 30% 跌到 26%。

**适用场景与注意事项**：适合受大宗商品或宏观影响的消费、出行公司；风险事件的识别与传导（跨公司）见 13.1。
