## 14.1 投资结论表达

> 本节导读：本节回答“研究做完之后，结论应该长成什么样”。海豚君极少给单一的买/卖评级，而是把结论拆成“资产属性定性 + 量化空间（三情景或上下行百分比）+ 需要满足的条件 + 介入价位 + 跟踪点”几个部分组合表达。写个股深度、财报点评、事件快评的结论段时使用；上游的情景估值与上下限测算见10.2，隐含预期见10.1，折溢价与估值框架切换见10.3；结论怎样落成交易动作（击球区、持仓分层、波段）见14.2；全文的标题与结构设计见14.3。

### 14.1.1 三情景每股价值 + 概率定性 + “隐含回报=折现率”入场点 + 向上期权

**方法要点**：给出悲观/中性/乐观三档每股价值及上下行空间，再对每个情景做“概率定性”（说明为什么概率高或低，而不是机械加权），最后把入场价锚定在中性价值上——股价回落到该位置时，隐含年回报恰好等于折现率，此时再入场相当于“免费搏一个向上期权”。结论用“赔率够不够”来表达，适合高不确定、分化大的博弈性标的。

**操作步骤 / 拆分口径 / 公式**：
1. 先算三档每股价值，并换算相对当前股价的上下行空间：上下行空间 = 情景每股价值 ÷ 当前股价 − 1。
2. 对每个情景写概率定性，并写出理由：
   - 悲观（只剩底座业务）：概率要论证“为什么低”。例如更可能出现的情形是主要客户在竞争中落败，而算力还能另找客户，不至于归零，所以最悲观的底座情景概率相当低。
   - 中性：概率最高。
   - 乐观：概率不低，但可见性不高（兑现路径看不清）。
3. 以中性价值为入场锚：入场价 = 中性情景每股价值；股价回落到这个位置，隐含年回报 = 折现率（案例取10%）。
4. 从该入场价看，悲观情景是下行风险，乐观情景是“几乎免费的向上期权”。
5. 用“赔率够不够”收口：当前价格若明显高于中性价值，则结论是赔率不够；回到中性价位附近入场“不算亏”。

**关键指标与数据来源**：各情景每股价值、上下行空间、各情景概率定性、隐含年回报（折现率）；估值情景来自前文的分部预测与倍数假设（如案例中非AI部分12x、AI部分乐观20x/中性16x）。

**判断标准**：
- 当前价 > 中性价值：赔率不够，不追；
- 当前价回落到中性价值：隐含年回报 ≈ 折现率，下行已被中性情景托住，向上期权“白送”；
- 概率定性必须有理由（如“客户落败≠算力归零”），否则等于主观拍脑袋；
- 推理链条：三档价值 → 概率定性（不机械加权）→ 以中性价值作为折现率意义上的入场点 → 向上期权 → 赔率结论。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：悲观情景-40%，概率相当低；中性情景约$144（较现价-17%），概率最高，股价回落到该价位时隐含年回报为10%；乐观情景约$192（+11%），概率不低但可见性不高。结论：当前赔率不够，在中性价位入场搏向上期权“不算亏”。该文估值部分以非AI部分12x、AI乐观20x、AI中性16x得到三情景每股价值，再做概率判断并给出入场点。

**适用场景与注意事项**：适用于高不确定、市场分歧大的博弈性标的（如被定性为“大号CoreWeave”的重投入算力公司）；概率定性需要给出具体理由；折现率要与自身要求回报一致并明示。

### 14.1.2 赔率对称性判断 + 关键验证点 + 介入价位（“空间 + 条件 + 价位”三段式）

**方法要点**：把各情景的上行与下行空间放在一起比赔率，判断是否对称、尾部风险偏哪边，然后点明股价继续突破所需的关键验证点，最后给出可操作的介入价位。这种“空间 + 条件 + 价位”的三段式结论在多篇个股深度里反复出现，目的是避免只给一个目标价。

**操作步骤 / 拆分口径 / 公式**：
1. 汇总各情景相对现价的上行空间、下行空间（上行%、下行%），并标出尾部风险（极度悲观情景）方向。
2. 比较赔率：上、下行大致对称且尾部风险偏下行时，定性为“估值已处合理区间、基本反映中性情景、短期安全边际有限”。
3. 写出继续上涨需要被验证的关键点（案例：市场能否相信并验证“2028年后价格不崩”）。
4. 给出操作化表达：回调到中性估值以下再介入，胜率与性价比更高；或写出“还需要看到什么”（更多大厂订单与交付、竞品推出后的回落等）。

**关键指标与数据来源**：上行空间%、下行空间%、尾部风险、中性估值价位；这些数字来自前文情景估值（如跨周期净利润×中枢PE加DCF交叉验证、P/ARR倍数、SOTP）。

**判断标准**：
- 上下行空间量级相当（如+40%~55% vs -36%~49%）→ 赔率对称，不构成强买入理由；
- 尾部风险向下 → 安全边际有限，要等回调；
- 关键验证点必须是可被后续数据检验的事项，而不是泛泛的“看基本面”；
- 好的结论段同时包含空间、条件、价位三项。

**海豚案例**：
- 闪迪《AI 改不了“DNA”，闪迪还能牛多久？》（2026-10-06）：向上约40%~55%，向下约36%~49%，赔率大致对称、尾部偏下行，结论“合理区间”；关键验证点是市场能否相信并验证2028年后价格不崩（该文供需缺口判断为2026年6%、2027年4%、2028年为分水岭；估值用跨周期净利润×中枢PE并以DCF交叉验证，设中性、悲观、极度悲观、乐观四情景）；操作表达为跌到约1632美元以下再介入。
- MiniMax《疯狂高估值背后，MiniMax 是泡沫还是摸到了未来？》（2026-03-31）：以P/ARR 40—45x得到约550亿美元、约30%空间，并反推所需增速；结论是“一年多30%的收益不算可观”，可在竞品模型推出、股价回落时考虑买入。
- 高通《抱上亚马逊大腿，高通 AI 第二曲线“稳了”？》（2026-09-09）：SOTP估值（传统业务15—18x PE + AI业务30—50x PE，对应145—200美元）；要继续上行需看到更多大厂订单和交付。

**适用场景与注意事项**：通用于个股深度的结论段；避免只给目标价，要给赔率和验证条件；验证点要能在可预见的时间窗口内被观察到（见13.2、13.3）。

### 14.1.3 设问式标题 + 分层结论 + 量化空间

**方法要点**：用设问标题把文章的核心矛盾直接抛给读者，正文最后用“分层结论”回答：先承认积极面，再指出局限，给出近端可信区间与远端成立条件，并带上估值数字、情景和交易时机；结论段尽量量化（上行/下行空间、目标价区间、安全边际）并附跟踪条件。

**操作步骤 / 拆分口径 / 公式**：

*变体 A：设问式标题——一句话点出核心矛盾*
1. 找到这篇文章最想回答的那个争议，改写成一个问句，如「值得一次重估吗」「究竟是信心还是画饼」「会危吗」「满心期待、扫兴而归」「凭什么总能抓住风口？」「笑到最后还是跨界老腊肉？」「能颠回宇宙车厂吗？」「1.5万亿AI特斯拉真的贵了吗？」「折叠屏能救场吗？」「告别概念，开启Robotaxi大时代？」。
2. 标题中的问句即是正文要回答的核心问题（与14.3的问题清单开篇对应）。

*变体 B：正文末的分层结论*
1. 先承认积极面（如管理层信心、业务确实改善）；
2. 再指出局限（如上调集中在后半段、增量信息不多）；
3. 给出近端可信区间（市场更相信哪一段）和远端需要满足的条件；
4. 带上估值数字、情景和交易时机。

*变体 C：量化空间 + 有条件的建议*
1. 结论尾部写出量化空间：上行或下行空间百分比、目标价区间、安全边际；
2. 把建议写成“有条件”的表述（回撤到某价位以下是入场点、突破需要超预期）；
3. 附上跟踪条件（如Optimus量产进展、Cybercab扩张速度、iPhone Duo需求）。

**关键指标与数据来源**：上行或下行空间%、目标价区间、安全边际、跟踪条件；估值数字来自前文DCF/PE/SOTP等。

**判断标准**：
- 好的分层结论不是“好”或“不好”，而是“好在哪、局限在哪、近端值多少、远端要什么”；
- 避免绝对化的买卖建议，用空间、性价比、入场点和跟踪条件表达；
- 推理链条：承认事实 → 指出局限 → 区分近端与远端 → 给价位/时机。

**海豚案例**：
- Marvell《Marvell：远期指引狂飙，究竟是「信心」还是「画饼」？》（2026-10-07）：承认管理层信心，但指出指引上调集中在后半段，市场更信FY29前的指引；该文DCF（14%折现/3%永续）得约4000亿，两年维度增量有限、隐含20倍PE，给20-25倍对应285-350美元，股价突破400美元需要FY31蓝图全部兑现。
- 百度《AI 云 + 昆仑芯，百度值得一次重估吗？》（2026-09-07）：中性估值390亿美元，有20%空间，建议在Q4参与反弹。
- 腾讯《偷袭珍珠港时刻！腾讯 AI 上群聊「王炸」，豆包会危吗？》（2026-01-26）：情绪偏离是机会；约17倍PE、股东回报率3%。
- 英伟达《英伟达 GTC：AI 界春晚，满心期待、扫兴而归？》（2026-03-17）：增量信息不多，隐含PE 13倍，PE再提升需要新成长曲线。
- 比亚迪《比亚迪：“颠覆性”发布会，能“颠回”宇宙车厂吗？》（2026-03-06）：净利润450-470亿元×20倍PE，合理市值9000-9400亿元，上行空间仅5%-10%，已较充分反映基本面。
- 三花《三花智控：生意不起眼，凭什么总能抓住风口？》（2026-01-02）与《三花：AI 机器人时代，笑到最后还是跨界“老腊肉”？》（2026-01-08）：A股向上空间不大、向下缺安全边际；港股考虑流动性折价后仍有40%以上空间，具备一定性价比。
- 特斯拉《从造车到造梦：1.5 万亿 AI 特斯拉真的贵了吗？》（2026-01-12）：回撤到中性价392美元以下是不错的入场点（三情景392/602/188美元）；《Cybercab 发布会：告别概念，开启 Robotaxi 大时代？》（2026-09-04）：跟踪条件为Cybercab扩张速度与Optimus量产进展。
- 苹果《苹果：存储暴涨逼提价，折叠屏能救场吗？》（2026-09-10）：30-35倍PE对应296-345美元（文中给出的假设对应32倍PE），突破需要超预期；跟踪iPhone Duo需求。

**适用场景与注意事项**：适合所有研究报告结论段与财报/发布会点评的收尾；设问要和后文的核心判断一一对应，不能沦为标题党（见14.3.6）；量化空间要与前文估值的口径一致。

### 14.1.4 条件式结论：写清“估值提升/股价突破需要什么条件”

**方法要点**：结论不只给方向，还要写清楚估值提升或股价突破需要满足哪些条件。条件式结论本身就是后续的跟踪清单，把“买不买”转成“看什么、何时看”。

**操作步骤 / 拆分口径 / 公式**：
1. 先判断当前估值已经反映了什么（中性情景、近端指引等）；
2. 列出让估值或股价再上一个台阶所需的条件：新的成长曲线、应用规模化、蓝图全部兑现、上市/产能节点、产品体验完善等；
3. 把条件写成可观测事件（里程碑、时间窗口），并与催化剂时间线（13.3）和证伪条件（13.2）对应；
4. 在结论里写成“若……则……”的句式。

**关键指标与数据来源**：催化剂事件、关键里程碑；管理层指引与路线图、行业数据。

**判断标准**：条件必须具体、可观测，且数量有限（通常1-3个）；条件满足 → 估值锚/倍数上移；不满足 → 维持中性区间。

**海豚案例**：
- 英伟达《英伟达 GTC：AI 界春晚，满心期待、扫兴而归？》（2026-03-17）：PE再提升需要AI应用更大规模、更快落地，加上新的成长曲线（Physical AI、太空算力）。
- Marvell《Marvell：远期指引狂飙，究竟是「信心」还是「画饼」？》（2026-10-07）：股价突破400美元需要2031年蓝图全部兑现。
- 百度《AI 云 + 昆仑芯，百度值得一次重估吗？》（2026-09-07）：交易时机看昆仑芯上市和产能进展。
- 腾讯《偷袭珍珠港时刻！腾讯 AI 上群聊「王炸」，豆包会危吗？》（2026-01-26）：元宝体验完善、融入微信后，基于群聊数据的AI推荐、生活助手、办公助手会是更有力的出招。

**适用场景与注意事项**：适用于所有投资结论的写法；条件式结论若不写时间窗口，容易失去可检验性。

### 14.1.5 “估值不便宜但有道理” + 赔率友好的介入区间

**方法要点**：对估值偏高但逻辑成立的好公司，结论分两层：①对当前位置定性（值得长期跟踪、可持有但估值偏高）；②给出更舒服的介入区间（具体股价区间与对应PE上限），并把该区间解释为“只为高弹性业务支付悲观到中性之间的价格”，即赔率明显更友好。

**操作步骤 / 拆分口径 / 公式**：
1. 用SOTP/反向估值把市值拆成“基本盘 + 高弹性业务”，判断当前价是否已经把高弹性业务计到中性；
2. 对当前位置定性：不便宜，但“有道理”（高估值对应的是确定性与成长期权）；
3. 反推一个区间：只付“悲观到中性之间”的价格给高弹性业务时，对应的股价区间与PE上限；
4. 把区间和情景估值挂钩，写明“回到该区间 = 赔率明显更友好”。

**关键指标与数据来源**：股价区间、对应PE阈值；分部估值（SOTP）与情景假设（见9.6、10.2）。

**判断标准**：区间必须与情景估值挂钩，而不是凭感觉定“舒服价”；好的介入区间 = 为高弹性业务只付悲观—中性价。

**海豚案例**：
- 沃尔玛《沃尔玛：老兵不老，重估路还能走多长？》（2026-06-10）：更舒服的介入区间为股价回到100-110美元、PE压到35x以下。该文SOTP：沃尔玛美国1P+门店EBIT 200亿×25x=5500亿；山姆美国26亿×25x=650亿；国际EBIT还原后66→71亿×15x=1065亿；平台业务（3P渗透率/take rate/广告/会员假设，2030稳态利润按WACC 8.2%折现）中性2355亿；市值倒算隐含平台2232亿≈中性；DCF交叉验证（OPM 4.3%→7.4%）；总结为“估值不便宜但有道理”。
- SHEIN《SHEIN：Temu 围剿，关税压制，千亿独角兽还能否“老树开新花”？》（2026-08-31）：发行价有约30%空间，12倍2028E以下分批布局（约270亿美元市值、约48港元下方，详见14.2.3）。

**适用场景与注意事项**：适用于所有个股估值结论；介入区间要和情景估值挂钩，不是“便宜了就买”。

### 14.1.6 “短期明显高、长期有机会”的双时间维度结论 + 安全垫

**方法要点**：把短中期估值（指引法）与长期估值（远期折现法）并列，结论按时间维度分开：高估值交易的是“走出扩张转型后的成长性”而不是当下；同时说明自己远期假设的激进程度，列出短期看点和风险，最后建议投资者按风险偏好预备安全垫，而非简单“买/卖”。

**操作步骤 / 拆分口径 / 公式**：
1. 短中期：用管理层指引法算当前倍数，并剔除不干净因素（如粉饰折价）后重算；
2. 长期：用远期（如2030年）盈利×合理倍数，再按要求回报折现回今天，得到长期现值区间；
3. 声明远期假设的激进程度（案例为“中性略积极”）；
4. 列出短期看点（政策红利、加息初期的债务整合需求、增发后的充足现金储备）与风险（短期溢价带来的波动）；
5. 结论：短期明显偏高、长期有机会；建议按各自风险偏好预备安全垫。

**关键指标与数据来源**：短期倍数、长期现值区间、现金储备；指引、一致预期、融资条款。

**判断标准**：短期倍数明显高于合理区间且需要靠远期假设才能消化 → “贵但有道理”须明示假设；只要远期假设不可观测，就要写安全垫。

**海豚案例**：
- SoFi《槽点多多的 SoFi，“贵” 得有理？》（2026-06-29）：结论“短期明显高、长期有机会”。该文先点出“拧巴”的矛盾——瑕疵多但估值溢价（420亿/30x EV/EBITDA→230亿）；指引法下14x/29x，打20%粉饰折价后为37x/18x；2030远期EV/EBITDA 12-15x，按15%折现得226-282亿美元；最后给出安全垫提示。

**适用场景与注意事项**：适用于高估值成长股；把结论分时间维度可避免“贵/便宜”的单一判断，但需要清楚说明假设的激进程度，否则近似为自圆其说。

### 14.1.7 “攻守兼备”的结构化表达：守 = 基本盘与股东回报底仓，攻 = 同店弹性与期权

**方法要点**：把投资逻辑结构化为“攻”与“守”两部分：守是基本盘和股东回报形成的底仓，攻是弹性与期权；随后用估值判断“攻”的部分是否已被定价，再决定买点。

**操作步骤 / 拆分口径 / 公式**：
1. 守：翻新门店与会员浮存金筑起的基本盘；每年4%-5%的回购分红底仓。
2. 攻：下午时段的同店弹性；小店业态的开店期权；轻资产化的估值期权（方向直指麦当劳重估之路）。
3. 估值判断：用盈利预测与历史PE区间估算“攻”是否已计入价格，再决定买点。
4. 在结论中写明：守的部分提供安全垫，攻的部分是否值得为之付价。

**关键指标与数据来源**：股东回报收益率、同店弹性、开店期权、历史PE区间。

**判断标准**：若估值已经把“攻”的期权计满，则“攻守兼备”并不等于“好击球区”，需要等回调到更低的倍数；“守”的底仓要可持续（回购分红来自经营性现金流）。

**海豚案例**：
- 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：守——基本盘与每年4%-5%回购分红底仓；攻——下午时段同店弹性、小店业态开店期权、轻资产化估值期权。该文盈利预测营收CAGR 6.5%、利润率10%→19%，历史PE 25-31x；2030 EPS×28x折现118美元，DCF 106.7美元，判断已计价，小结“攻守兼备但不是好击球区”，买点在25x/89美元。

**适用场景与注意事项**：适用于成熟消费龙头；与14.1.8“类债券 + 成长期权”表达同源，区别在于这里强调“攻”是否被定价。

### 14.1.8 “类债券 + 成长期权”：用股东总回报率作为债性底

**方法要点**：把估值结论表达成资产属性——用较低的前瞻PE与较高的股东总回报率构成“类债券”的底与安全垫，把下沉开店、加盟提速、品类放量等成长当作“几乎免费附送的期权”，并给出适配的资金类型。

**操作步骤 / 拆分口径 / 公式**：
1. 股东总回报率 =（现金分红 + 回购）÷ 市值，叠加FCF返还比例，得到债性底；
2. 配合前瞻PE判断估值底：案例前瞻PE约14-15x；
3. 把成长（下沉开店、加盟提速、咖啡放量等）定性为“几乎免费附送的成长期权”；
4. 给出适配资金：适合风险偏好偏低、追求稳定现金流的防御型资金，是消费板块的优质底仓；
5. 验证回报的资金来源是经营现金流而非借债。

**关键指标与数据来源**：股东总回报率（分红 + 回购 / 市值）、FCF返还比例、前瞻PE；公司资本回报计划（案例：2026年返还15亿美元，2027年起近全额返还自由现金流，现金分红+回购综合回报中枢8%-10%，股息持续上调）。

**判断标准**：股东总回报率近9%-10%、前瞻PE约14-15x → 类债券的底；成长期权不再需要为之额外付价。

**海豚案例**：
- 百胜中国《百胜中国：一只“洋鸡”，凭何在东方称王三十年？》（2026-07-02）：前瞻PE约14-15x，股东总回报率近9%-10%；该文相对估值按14x中性、DCF按WACC 10.1%/永续增速2%交叉验证，落点约49美元；类比沃尔玛、古茗、鸣鸣很忙的低成本生态，结论为防御型底仓。

**适用场景与注意事项**：适用于高股东回报的成熟公司；需验证回报资金来自经营现金流而非借债。

### 14.1.9 “生死一搏 vs 锦上添花”：战略定性 + 机会风险双向列示

**方法要点**：先用各业务增长现状推出“某项新业务对公司是不是生死攸关”，再用这个战略必然性解释管理层的冒险行为，最后对称地列示机会与风险。

**操作步骤 / 拆分口径 / 公式**：
1. 按业务拆增速，找出成熟甚至衰退的业务和唯一的增长来源；案例中除OCI外其他业务都已近零增长甚至衰退；
2. 推出战略必然性：OCI不是“做成了锦上添花、做不成也无所谓”，而是“做成了生、做不成死”；
3. 用该必然性解释管理层行为：为何在OpenAI合作上如此积极，甘愿替对方承担AI算力可能过度投入的风险；
4. 双向列示：
   - 机会：其他业务不增长也能把总收入推到31%的复合增速；RPO可能进一步增长（OpenAI与英伟达、AMD、博通签的合计26GW意向中分一杯羹，Meta、xAI也可能给新订单）；
   - 风险：OpenAI超30GW的算力意向可能被“故意过量虚报”，在手订单不一定全部兑现，可能变成坏账。

**关键指标与数据来源**：各业务增速、RPO、GW意向；公司财报业务口径重分后的收入序列。

**判断标准**：新业务是否为唯一增长来源（是则“生死一搏”）；风险与机会必须双向对称列示。

**海豚案例**：
- 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：首篇覆盖，小结a/b/c三点判断（生死一搏、大号CoreWeave、机遇与风险并存）；该文按新口径重分FY18-26收入，发现OCI是唯一增长来源，并对3000亿订单做RPO分期限覆盖率测试，订单来源拼图含OpenAI每年600亿、5年。

**适用场景与注意事项**：适合高风险转型公司；用战略动机解释管理层的冒险行为，并对称呈现风险；前提是业务增速口径要先行重分。

### 14.1.10 指出长期分水岭：从外生增长转向内生增长，并把长期风险具象成可观测行为

**方法要点**：小结先概括公司的差异化路径，再明确长期检验点——当外生增长（开店 + 爆款）触顶后，能否切换为内生增长（会员价值 + 业务协同）——并把这个切换写成可以观察的消费者行为和经营指标，成为后续跟踪方向。

**操作步骤 / 拆分口径 / 公式**：
1. 概括差异化路径：不靠烧钱补贴换规模，而是先用中高端体验壁垒建立品牌粘性，再以加盟实现高效扩张，最后通过会员体系把酒店场景流量转化为零售价值，形成正向循环；
2. 指出长期分水岭：当门店扩张触及天花板、零售单品遭遇家纺巨头正面竞争、流量红利见顶后，能否摆脱对“新店扩张 + 单品爆款”的双重依赖，转向“存量会员价值深耕 + 双业务协同”的内生增长；
3. 把行为转变写出来：消费者行为能否从“偶然住一次、买一个枕头”变成“认可睡眠体验、复购全系列”的习惯；
4. 把这些落成指标：会员复购、跨品类购买、单店效率、同店增长。

**关键指标与数据来源**：会员复购、跨品类购买、单店效率、同店增长；公司披露的会员与交叉购买数据。

**判断标准**：触顶后若能靠会员复购和跨品类购买提供增长，则“从外生转内生”成立；否则估值要回到外生增长的天花板。

**海豚案例**：
- 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：「小而美的双轮驱动标的」；该文开店空间用商圈承载法3350家与客房份额法3152家交叉验证，零售用深睡枕会员渗透法与市占率法交叉，小结落在“双轮驱动与长期分水岭”。

**适用场景与注意事项**：适合双轮或多业务驱动的成长股；把长期风险具象成可观测的行为指标，才不会变成空泛的“长期不确定”。

### 14.1.11 结论段的组装：把上述形态串成一段完整的结论

**方法要点**：一段合格的结论通常由“属性定性 → 量化空间/情景 → 条件 → 价位与时机 → 跟踪点”五个构件按需组合，不同公司取不同的组合。

**操作步骤 / 拆分口径 / 公式**：
1. 属性定性：赔率型博弈资产（14.1.1）、类债券 + 期权（14.1.8）、攻守兼备（14.1.7）、生死一搏（14.1.9）、贵但有道理（14.1.5）等；
2. 量化空间：上行/下行百分比、目标价区间、情景价值（14.1.2、14.1.3）；
3. 条件：估值上移所需条件（14.1.4）；长期分水岭（14.1.10）；
4. 价位与时机：介入区间、PE上限、击球区（14.1.5、14.2.3）、持仓分层（14.2.2）、催化剂时点（14.2.1）；
5. 时间维度：短期与长期分开写（14.1.6）；
6. 跟踪点：落到13.2的关键跟踪指标与13.3的催化剂时间线。

**关键指标与数据来源**：同上各小节。

**判断标准**：结论至少同时包含“空间 + 条件 + 价位”三项；避免只写“看好/谨慎”。

**海豚案例**：百度《AI 云 + 昆仑芯，百度值得一次重估吗？》（2026-09-07）：中性估值390亿美元（20%空间）+ 下行保护（信贷为主的融资、3年50亿美元回购）+ 催化剂时点（Q4、昆仑芯上市）；SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：发行价约30%空间 + 12倍2028E以下分批 + 反证条件。两篇的具体写法见14.2.1、14.2.3。

**适用场景与注意事项**：财报点评可以只写其中3项（空间、条件、价位），深度文则建议五项齐备；各项数字的口径要与全文估值一致。

## 14.2 交易策略、击球区与市场情绪

> 本节导读：本节回答“结论怎么落成交易动作，以及怎样读懂市场情绪和资金面”。内容分两块：一是交易建议的构件（估值空间、下行保护、催化剂时点），按持仓状态分层的建议，击球区的设计，周期股与终局不明公司的波段策略，财报点评里引用前期深度估值，叙事阶段与逆向判断；二是市场情绪与资金面（仓位拥挤、事件后股价反应、对单一数据的敏感度、巨头融资与超级IPO对增量资金的虹吸）。上游估值数字见第9、10章；结论形态见14.1；解禁、筹码类的短期窗口详见11.2；跟踪指标与催化剂时间线见13.2、13.3。

### 14.2.1 “估值空间 + 下行保护 + 催化剂时点”三要素组成交易建议

**方法要点**：交易建议不是一句“买入”，而是由三个要素拼成：①估值空间（中性估值相对当前价有多少修复空间）；②下行保护（回购、融资方式等）；③催化剂时点（结合持股时间成本，选在关键事件附近参与），并同时观察事件日的资金情绪。适用于估值低但缺乏催化剂的公司。

**操作步骤 / 拆分口径 / 公式**：
1. 估值空间 = 中性估值 ÷ 当前市值 − 1，写明中性估值的来源（见10.2）。
2. 下行保护：逐项核对回购计划、融资方式（信贷为主、不稀释股权）、融资折价与稀释率，判断下跌空间是否有限。
3. 催化剂时点：列出时间线上的关键事件（上市、产能、量产交付、财报），结合持股的时间成本，选在事件附近参与反弹，而不是在无催化剂的时段长期持有。
4. 看事件日资金情绪：利好落地当天反而下跌，说明市场在走“利好兑现”逻辑，应把参与时点后移或等待更明确的信号。

**关键指标与数据来源**：中性估值、回购规模、融资方式、事件日股价反应、催化剂时间；来源为公司公告、融资条款、前文估值模型。

**判断标准**：
- 三要素同时具备才是完整的交易建议：有空间、下跌有限、有时点；
- 利好当日不涨反跌 → “利好兑现”，说明短期情绪不配合；
- 融资以信贷为主、不稀释股权，叠加回购 → 下行保护较强。

**海豚案例**：
- 百度《AI 云 + 昆仑芯，百度值得一次重估吗？》（2026-09-07）：中性预期390亿美元，仍有20%修复空间；正式进入港股通当天反跌5%，走的是“利好兑现”；后续融资大概率以信贷为主，加上3年50亿美元回购，下跌空间有限；建议在Q4接近年底、昆仑芯上市和M100可能量产交付的时间点参与反弹。该文估值的三块支撑：传统广告零估值，聚焦AI云与昆仑芯；昆仑芯30倍PS得350亿美元，扣稀释和关联交易后百度应享136亿，母体约等于净现金（类比快手）。
- 阿里《阿里 800 亿融资：外卖补贴市场买单，AI 才真未来？》（2026-08-24）：用融资条款判断下行保护——实际为800亿港币定增，折价9%、稀释3.7%，回购只够抵消SBC；结合此前对净现金2080亿与融资顺序的预期、外卖大战2-3年检验窗口，结论是融资打出股价低点，向上弹性更高。

**适用场景与注意事项**：适用于估值偏低但缺乏催化剂的公司；注意“下行保护”要核对实际条款（折价、稀释、回购规模是否真能覆盖），不能只看“有回购”。

### 14.2.2 按持仓状态分层给出操作建议 + 跟踪信号 + 击球区

**方法要点**：结论不写单一评级，而是分投资者状态：已持有如何处理、未持有在哪个价位才考虑、没有回调时怎么办，再附一条跟踪信号。适合估值已不便宜但基本面仍好的标的。

**操作步骤 / 拆分口径 / 公式**：
1. 判断估值位置：用情景估值或周期顶PE确认当前是否“已不便宜但基本面仍好”；
2. 已持有：写清是否可以拿住及理由（如股东回馈提供基础回报）；
3. 未持有：给出入场价位或市值（如回调到约0.85万亿美元市值可考虑）；若无回调，则中短期弹性有限，可另寻机会；
4. 跟踪信号：写一个能证伪或强化判断的外生变量（如AI是否出现新的重磅应用普及——C端Agent、端侧AI等）；
5. 价位分档：股价涨超长期乐观位 → 保持冷静；靠近保守份额估值 → 关注；并把解禁等事件视为可能的“击球区”（解禁窗口详见11.2）。

**关键指标与数据来源**：入场市值/价位、催化剂、跟踪指标；情景估值与股东回报率。

**判断标准**：价位与情景估值挂钩（保守/中性/乐观）；分层建议里“已持有/未持有”的口径必须一致；跟踪信号要对应一个可观察的行业事件。

**海豚案例**：
- SK海力士《SK 海力士：长协能熨平周期？估值到哪一步》（2026-10-09）：已持有可以拿住（股东回馈提供基础回报）；未持有则回调到约0.85万亿美元市值可考虑，无回调则中短期弹性有限、可另寻机会；跟踪信号是AI是否出现新的重磅应用普及（C端Agent、端侧AI）。该文估值用2028周期峰值×历史顶PE 3-6x得到合理中性，强调供给确定/需求不确定的非对称，股东回报12%基础回报，乐观情景1.82万亿。
- 壁仞科技《壁仞：国产“英伟达”，到底“几斤几两”？》（2026-06-18）：股价涨超长期乐观位置时保持冷静，价位靠近保守份额估值时关注，并把解禁事件视为可能的“击球区”。该文估值：2030年TAM 800亿×份额三情景×15x PS×13%折现，中性185亿≈当前市值，所以等待保守价位。

**适用场景与注意事项**：研究结论写作；适合估值已不便宜、基本面仍好的标的。解禁时间表作为短期波动与击球区窗口详见11.2。

### 14.2.3 利空兑现期 + 倍数阈值 + 反证条件：三要素设计击球区

**方法要点**：区分短期交易与中期仓位，把“明牌利空的兑现期”定义为长线击球窗口，用明确的倍数阈值给出分批布局线，再写出估值进一步下探需要同时成立的反证条件并评估其概率。

**操作步骤 / 拆分口径 / 公式**：
1. 找到明牌利空及其时间表，把利空集中兑现的阶段（如报表连续利润负增长）定义为长线击球窗口；
2. 定倍数阈值：远期PE低于某值（如12倍2028E）→ 换算对应市值与股价，作为分批布局线；
3. 写反证条件：估值继续下探需要哪些条件同时成立；
4. 评估这些条件同时成立的概率，并在后续持续跟踪反证条件是否出现。

**关键指标与数据来源**：远期PE阈值、对应市值与股价、反证条件；盈利预测与关税、竞争等冲击时间表。

**判断标准**：窗口 = 利空兑现期（利空已知、报表兑现）；布局线 = 倍数阈值；继续下探的前提 = 反证条件同时成立且概率不高才敢布局；反证条件一旦出现要立即重估。

**海豚案例**：
- SHEIN《SHEIN：Temu 围剿，关税压制，千亿独角兽还能否“老树开新花”？》（2026-08-31）：2026H2-2027年欧盟关税为利空兑现期；股价被砸到12倍2028E以下（约270亿美元市值、约48港元下方）可分批布局；再往下需要“3P证伪 + 关税永久恶化”同时成立，概率不大。该文估值：3P渗透率×变现率预测、集团预测，用干净年份PE + WACC折现，并结合筹码结构与首日表现判断。

**适用场景与注意事项**：适用于有明确冲击时间表的标的；反证条件需持续跟踪，不能“一次定价永久有效”。

### 14.2.4 引用前期深度的悲观/中性估值，作为财报后的分批布局区间

**方法要点**：财报点评里不重做完整估值，而是引用前期深度报告里的悲观情景（不计远期期权，只给已变现业务保守定价）或悲观到中性的区间，作为股价回落后的布局参考，并配合催化剂清单使用。

**操作步骤 / 拆分口径 / 公式**：
1. 调出前期深度的悲观/中性估值区间（悲观 = 完全不计远期期权，只对已变现业务保守定价）；
2. 对比财报后的当前市值：股价较高点、较IPO价的回撤幅度；
3. 当市值回落到该区间（悲观或悲观—中性）时，建议逢低分批布局；
4. 附上催化剂清单，告诉读者回落后看什么事件。

**关键指标与数据来源**：前期深度报告估值区间、当前市值；财报与指引。

**判断标准**：布局区间引用的是已被检验的估值，不在点评中临时改假设；悲观情景完全不含期权 → 在该位置买入等于“期权免费”。

**海豚案例**：
- SpaceX《豪赌AI》（2026-08-05）：股价自高点跌近50%、较IPO价低约20%；当市值回落至前期深度测算的1.1-1.4万亿美元（悲观情形，完全不考虑太空数据中心期权）时可逢低分批布局。
- Rocket Lab《中子号或延期》（2026-08-11）：建议在43-101美元（悲观到中性）区间逐步介入。
- Palantir《瑕疵修复》（2026-08-04）：相对稳妥的是在“大模型鬼故事”调整中切入。

**适用场景与注意事项**：适用于已有深度覆盖的标的，作为财报点评的落点；若前期深度的关键假设已被财报改变，需先修正假设再引用。

### 14.2.5 区间博弈 / 波段操作框架（周期股与长期不确定性公司）

**方法要点**：对基本面受强周期（如楼市）或长期颠覆风险（如无人车）影响、终局看不清的公司，不做长期持有判断，而是给出区间或波段策略。

**操作步骤 / 拆分口径 / 公式**：
- 变体 A（强周期股）：在政策、情绪、股价都处于低点时买入，在政策、情绪、业绩处于相对高点时获利了结；
- 变体 B（存在颠覆风险的龙头）：在终局清晰之前，以颠覆变量的动态作为主判断依据——头部玩家有重大突破就远离，第三方追上就利好；没有大动态时，由业绩和估值主导。
- 通用：先判断信息是否足以支持“历史大底”之类的重判断，不足则降级为区间性博弈机会。

**关键指标与数据来源**：政策周期位置、市场情绪、估值位置、颠覆技术进展事件。

**判断标准**：终局不清时不押单边；买点看“政策 + 情绪 + 股价”三低；卖点看“政策 + 情绪 + 业绩”三高；颠覆变量出现重大突破即为撤退信号。

**海豚案例**：
- 贝壳《“跪太久”贝壳》（2026-05-20）：信息尚不足以支持楼市迎来历史大底的判断，把贝壳视为区间性博弈机会。
- Uber《Uber：业绩都在线》（2026-05-07）：在2027年中或无人驾驶终局路径清晰之前，Uber是有波段机会的标的；Waymo和Tesla有重大突破就远离，其他第三方技术追上头部则利好。

**适用场景与注意事项**：适合强周期股和面临技术颠覆的龙头；周期股估值方法见9.4。

### 14.2.6 叙事阶段判断：天花板极高 + 短期无法证伪的“甜蜜期”，据此决定入场点

**方法要点**：对主题叙事型公司先判断叙事处于哪个阶段，再决定入场策略：天花板极高、短期逻辑又无法证伪的“甜蜜期”，回撤到中性价位以下反而是入场点；一旦叙事进度超预期，估值锚切换，股价向乐观价位进发。

**操作步骤 / 拆分口径 / 公式**：
1. 判断阶段：叙事过去是否常延期（如AI叙事常延期交付）；当前市场空间天花板是否极高、短期是否无法证伪；兑现时点何时（如Robotaxi将在26年下半年显著影响报表，2026年是AI故事从概念走向利润兑现的开始）；
2. 设定入场点：若因业绩疲软或淡季导致股价回撤到中性价位以下，则是不错的入场点；
3. 设定锚切换条件：Optimus或Robotaxi进度超预期（监管获批、订单量产）→ 估值锚从传统汽车制造切换到AI成长 → 股价向乐观价位进发；
4. 警惕叙事再延期带来的估值锚回落。

**关键指标与数据来源**：叙事证伪节点、报表兑现时间、股价相对中性和乐观价位的位置、超预期催化（监管、订单）。

**判断标准**：甜蜜期 = 空间天花板极高 + 短期证伪不了；价位关系：392美元（中性）以下是入场点，602美元为乐观，188美元为悲观。

**海豚案例**：
- 特斯拉《从造车到造梦：1.5 万亿 AI 特斯拉真的贵了吗？》（2026-01-12）总结部分：若因25Q4业绩疲软或26Q1卖车淡季导致股价回撤到中性价位（392美元）以下，反而是不错的入场点；一旦Optimus或Robotaxi进度超预期，估值锚由传统汽车制造切换到AI成长，股价向乐观价位（602美元）进发。该文三情景市值结构：基本盘对比AI溢价的392、602、188美元。
- 特斯拉《Cybercab 发布会：告别概念，开启 Robotaxi 大时代？》（2026-09-04）：1.4万亿市值中约1万亿依赖AI兑现，Robotaxi兑现度高于Optimus；602美元对比历史回撤至300-350美元；关键观察指标为Cybercab扩张速度。
- 特斯拉《(短评)特斯拉估值里AI占比超60%》：交付下滑与股价新高背离，分部估值拆分AI 60%/硬件40%，乐观目标价602美元。

**适用场景与注意事项**：适用于高估值主题股的择时表达；要警惕叙事延期带来的估值锚回落。

### 14.2.7 格局未定的竞争中，把情绪过度偏离视为机会（逆向思维）

**方法要点**：竞争格局未定、输赢难下结论时，任何情绪的过度偏离（如市场对某家公司AI入口过度悲观）都值得关注；做法是配合“市场已打入哪些悲观预期”的拆解和基本面检查，形成逆向判断，同时写出主要风险。

**操作步骤 / 拆分口径 / 公式**：
1. 先判断竞争格局是否未定（输赢难下结论）；
2. 拆解市场已打入的悲观预期清单，并逐项做基本面检查；
3. 若悲观预期明显偏离基本面（估值水平仅反映单边情绪），则形成逆向判断“情绪偏离是机会”；
4. 同时写出主要风险（不能只写机会）。

**关键指标与数据来源**：市场情绪、估值水平、悲观预期清单。

**判断标准**：胜负未分 + 估值只反映单边悲观 → 值得关注；若悲观预期已被基本面证实，则逆向不成立。

**海豚案例**：
- 腾讯《偷袭珍珠港时刻！腾讯 AI 上群聊「王炸」，豆包会危吗？》（2026-01-26）：AI“三国杀”输赢难定，任何情绪过度偏离时都是值得关注的机会；风险是算力支撑、用户隐私保护、基础模型Agent能力的稳定性。
- 腾讯《(短评)腾讯AI太安静》：股价疲弱原因 → 多头论点 → 空头论点 → 指出共同前提并用战略动作反驳 → Q1窗口期待 → Q4业绩前瞻 → 海豚君约束判断。
- 《(短评)Gemini 4发布市场反应平淡》：解释平淡的三个原因（可看不可用、Coding细分落后、催化兑现 + 搜索侵蚀）；对比搜索量份额与收入份额；结论是不必恐慌定价，并指出情绪需要的催化。

**适用场景与注意事项**：适用于竞争胜负未分、估值反映单边情绪的时候；逆向不等于抄底，需写清风险。

### 14.2.8 解读仓位拥挤、资金行为与事件后的股价反应

**方法要点**：解释事件冲击时不只讲基本面，也分析交易结构：多头仓位拥挤时，空头预期一出现兑现迹象就引发连锁下杀；产业逻辑在高位出现分歧后，投机资金撤退，场外看多资金会先观察而不是马上接盘，因此修复需要时间。再用事件当日与次日的股价反应读出市场预期与情绪修正的程度。

**操作步骤 / 拆分口径 / 公式**：
1. 判断交易结构：多头是否拥挤（定性）、投机资金与场外资金的行为差异；
2. 记录事件当日、次日涨跌幅，以及相关标的联动（对手、供应链）；
3. 判读：涨后回吐 = 短期情绪被修正；对手股价联动 = 市场在给事件对竞争格局的影响定价；
4. 据此判断修复需要多久、反弹是否可持续。

**关键指标与数据来源**：当日/次日涨跌幅、相关标的联动、仓位拥挤程度（定性，仓位数据通常只能定性描述）。

**判断标准**：事件当日大涨、次日回吐 → 情绪被修正；一方上涨一方明显下挫 → 市场在给份额转移定价。

**海豚案例**：
- Meta《算力太贵，Meta 掀桌？》（2026-07-06）：消息后Meta当天上涨9%，第二天回落近5%，体现资金对短期算力恐慌情绪的修正；先说结论中指出情绪过猛、修复需要时间。
- Marvell《迈威尔 Marvell：“贴钱”结盟谷歌，能“撬动”博通墙角吗？》（2026-08-20）：Marvell权证消息涨10%以上，博通明显下挫，反映市场对Marvell抢夺TPU订单的定价。
- 变体——事件后异动的短评写法：腾讯《(短评)腾讯暴力反弹：微信Agent要来了》（异动描述 → 微信Agent背景（早有预期）→ 反应强烈的两大原因 → 对时间线打折 → 估值底与基本面 → 下周财报关注点）；《(短评)AppLovin盘中盘后大涨》（消息一：招聘JD显示社交平台意图；消息二：OpenAI合作传闻——来源、可行性、动机、与电话会契合度）。
- 变体——事件信号层级决定情绪反应的合理幅度：《(短评)监管转发外卖大战应尽快结束》：新闻内容 → 信号层级定性（转发而非官方表态）→ 判断原则（除非强硬叫停，竞争取决于公司意愿）→ 影响（提振情绪或加快减亏）；《(短评)美国防部CMC清单乌龙》：纳入后撤回 → 区分CMC与NS-CMIC效力 → 历史先例（小米、腾讯）→ 时间节点博弈解读 → 结论：大概率无实质影响，保持关注。
- 筹码类异动（B站CCASS持股增加等）属于股东结构与减持分析，详见11.2。

**适用场景与注意事项**：适用于事件驱动的短期判断；仓位数据只能定性描述；对异动要先分清“信息本身是否新增”和“情绪放大”两层。

### 14.2.9 从市场对单一数据的敏感度解读风险偏好，并给出仓位建议

**方法要点**：当市场对某个头部公司的单个数字（如ARR）一惊一乍，说明预期分歧大、多数资金风险偏好下降。结合即将到来的检验窗口与宏观环境，给出分散仓位、淡化集中持仓波动风险的建议，同时维持长期看好的判断。

**操作步骤 / 拆分口径 / 公式**：
1. 先还原数字本身（口径差异、预期差），判断真实冲击有多大；
2. 看市场反应的幅度（开盘跌幅、联动市场），反推风险偏好；
3. 列出后续检验窗口（三季报、招股书）与宏观环境（高利率放大波动）；
4. 结论：适当分散仓位，不改长期判断。

**关键指标与数据来源**：事件后市场跌幅、检验窗口、利率环境。

**判断标准**：数字的真实冲击小于市场反应 → “情绪乌龙”；检验窗口临近且宏观放大波动 → 建议分散。

**海豚案例**：
- 《OpenAI 收入 200 亿缺口“炸锅”：真实威力没那么大，一场情绪乌龙！》（2026-10-09）：消息导致美股和港A开盘大跌（韩、台休市，另有美国对产业链材料禁用的担忧），之后亚洲资金情绪回暖；海豚君还原口径——500亿为净收入、还原后约640亿，缺口约60亿而非200亿；总结市场对数字敏感说明风险偏好下降，财报季和招股书将带来检验，建议适当分散仓位。
- 《(短评)一个数字引发的暴跌》：存储、光模块暴跌 → 导火索数字 → 与第三方估算对比 → 合计收入加速度放缓 → 倒金字塔杠杆逻辑 → 市场追问（价格战？Token用量？）。

**适用场景与注意事项**：适用于事件快评文的结尾；前提是已做口径澄清，避免在错误数字上给仓位建议。

### 14.2.10 巨头融资与超级IPO的增量资金虹吸分析

**方法要点**：跳出个股看市场：单个巨头几百亿融资的理论稀释率很低，关键在于它吸纳的是市场增量资金。当巨头融资规模升级、叠加超级IPO，被虹吸的是AI外环的中小市值标的，并推演更深的洗牌与缩圈。

**操作步骤 / 拆分口径 / 公式**：
1. 先算稀释率：理论稀释率 = 融资额 ÷ 市值（极低），说明问题不在稀释；
2. 看规模升级：巨头融资从100-200亿升级到500-1000亿；
3. 叠加超级IPO：SpaceX估值1.8万亿、Anthropic 0.965万亿、OpenAI 0.852万亿；
4. 看集中度与总量：巨头集中度超1/3；美股总市值约70万亿（同比+10%），利率预期不利于持续吸引增量资金；
5. 推演：被虹吸的是AI外环的中小市值标的；提出“最谨慎的投资者也投降上车后，增量资金从何而来”；推演更深洗牌与缩圈（决胜圈外资产成为“血包”）以及情绪极致后的高切低再平衡。

**关键指标与数据来源**：巨头融资规模、IPO估值、美股总市值及增速、巨头市值集中度；融资细则（发行价与转股价假设、股本基数、超额配售、期权对冲）。

**判断标准**：融资规模 + IPO 估值总量相对于增量资金池的占比越大，外环资产越容易被虹吸；集中度越高、利率越不友好，缩圈风险越大。

**海豚案例**：
- Google《当所有人都在车上时…》（2026-06-02；对应事件文《谷歌再借 800 亿，行情“续杯”还是泡沫“试金石”？》的“市场层面”部分）：该文先看融资事件与资金用途（AI基建、看涨期权对冲、员工期权代缴税），推算2027年顶格Capex（OCF + 募资 + 净现金）与三部分融资的稀释率，最后落到巨头融资与超级IPO虹吸增量资金、集中度、洗牌缩圈与高切低。

**适用场景与注意事项**：判断行情持续性与风格切换，属于宏观资金面的辅助判断，不适合单独作为个股买卖依据。

**本节速查清单**
- [ ] 交易建议是否同时有估值空间、下行保护（回购/融资方式及条款）、催化剂时点三项？事件日股价反应是否检查了“利好兑现”？
- [ ] 是否按持仓状态（已持有/未持有/无回调）分层，并附一条可观察的跟踪信号？
- [ ] 击球区是否写明利空兑现期、倍数阈值（及对应市值/股价）与反证条件，并评估反证条件的概率？
- [ ] 财报点评里引用前期深度的悲观/中性估值作为布局区间时，关键假设是否仍成立？
- [ ] 周期股与终局不明公司是否改用区间/波段表达，并指明颠覆变量的监测事件？
- [ ] 主题叙事股是否判断了叙事阶段（甜蜜期或其他），入场点与估值锚切换条件是否写清？
- [ ] 逆向判断是否配了“市场已打入的悲观预期清单”和主要风险？
- [ ] 对事件后股价反应与单一数据冲击是否做了口径澄清与交易结构（仓位拥挤、资金行为）判断，仓位建议是否合理？
- [ ] 巨头融资与超级IPO是否从增量资金视角评估了对外环标的的虹吸？

## 14.3 写作结构与研究流程模板

> 本节导读：本节回答“一篇海豚式的研究文章应该怎么搭、怎么开头、怎么讲清楚”。先给出问题清单驱动的标准骨架及其各种开篇写法（反常现象、市场标签反差、首篇四问、三问式、带问题参会），再给表达技巧（生活化类比、大白话祛魅、跨公司类比、对比表），最后按文章类型（首篇认知文、估值终篇、行业技术铺垫文、事件快评、发布会点评、短评）归纳骨架与变体，并给出从立项到成文的研究流程。研究动作本身见第1至13章，结论怎么落笔见14.1，交易表达见14.2，多篇如何分工与留档见14.4。

### 14.3.1 标准骨架：开篇列问题清单 → 分节作答 → 小结 → 预告下篇

**方法要点**：海豚个股深度文与事件文共用的固定结构——先交代背景与核心判断，再列出本篇要回答的2~4个具体问题，正文逐节作答，用“小结”收束，最后预告下篇并附系列文章链接；事件文则用“先说结论”的倒金字塔。解决的是“文章散、读者不知道你要回答什么”的问题。

**操作步骤 / 拆分口径 / 公式**：
1. 开头一两段交代背景和核心判断（延续上篇结论，或承接行业文的卡点结论）；
2. 列出本篇要回答的2~4个具体问题（问题来源与设计见14.3.2）；
3. 正文按问题逐节作答，每节末尾或全文末尾用“小结”收束（小结写判断，不复述）；
4. 全文末尾预告下篇内容，并附系列文章链接（系列分工见14.4）；
5. 变体 A（系列深度文）：回顾上篇 → 列问题 → 分节作答 → 小结 → 预告；变体 B（事件文）：事件与股价反应 → “先说结论”若干点（倒金字塔）→ 分节论证 → 估值/情绪 → 文末回溯。

**关键指标与数据来源**：无（写作方法）。写作时配套的数字来自各章分析（预测、估值、测算），问题清单本身要可回答、可验证。

**判断标准**：
- 好的问题清单：数量2~4个、每个问题能在正文用一节回答、答案可被后续数据验证；
- 好的小结：给出判断（如“需求够，客户和产能不够”），而不是把前文再说一遍；
- 推理链条：背景与核心判断 → 问题清单 → 逐问作答 → 小结收束 → 预告下篇形成系列。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：开篇回顾上篇（定性为“大号CoreWeave”，属博弈性标的），列出4个问题——业务构成与增长、指引隐含的AI收入及可达成性、投入与举债影响及AI盈利、不同情境下的投资价值；正文依次为“搭积木”预测框架、可达成性三法交叉验证、小结（需求够，客户和产能不够）、利润、估值（三情景每股价值+概率判断+入场点）。
- Lumentum上篇（2026-09-24）：列2个问题——激光器为何是双重卡点、五条产品线卡位与格局；结尾预告下篇定量测算并附系列文章。中篇《Lumentum：产能告急，“全能卖水人”还有什么看家绝活？》（2026-10-05）：回顾上篇（EML是基本盘、UHP CW押注CPO），提出磷化铟晶圆产能天花板的约束，列2个问题——Scale-across为何让电信业务老树开新花、为何涉足低毛利模块；小结为“按网络拓扑层的全场景卖水人矩阵”，预告下篇估值。
- Cerebras《Cerebras：不切晶圆的芯片“怪兽”，有希望挑战英伟达？》（2026-10-09）：开篇用“整片晶圆当芯片”的反常识切入并给出核心观点（WSE拆掉“内存墙”，护城河在台积电之外），交代本篇三件事——WSE是什么、解决GPU什么问题、如何制造及难点；结尾预告下篇写经营表现和展望。
- Meta《算力太贵，Meta 掀桌？》（2026-07-06）：事件文，用“先说结论”给出4点判断（情绪过猛、修复需要时间、对Meta利大于弊、利润增量测算仅作参考），再以“买家变黄牛 / 不会主动退出战场 / 能分几杯羹”三节展开。

**适用场景与注意事项**：通用于研究报告写作；问题清单要对准市场分歧、可回答可验证，避免“列了问题却没答案”；每篇都要独立可读（系列写法见14.4.1）。

### 14.3.2 问题清单驱动：把市场担忧转化为可回答的问题

**方法要点**：深度文的问题清单不是凭空设计的，而是从“市场正在担心什么、股价为什么走成这样”转化而来；转化之后，每个一级标题对应回答一个问题，各节常采用“结论先行，再展开测算”。这套清单同时可作后续跟踪框架。

**操作步骤 / 拆分口径 / 公式**：
1. 收集问题来源：股价高位或急跌时的市场担忧、多空论点、竞争叙事、管理层的新说法；
2. 把担忧归并成2~5个问题，按“需求 / 供给 / 竞争 / 估值”或“是什么 / 凭什么 / 值多少”等层次排序；
3. 每个问题对应一个一级标题；每节“结论先行，再展开测算”；
4. 在结尾小结逐一回扣；问题清单留作后续跟踪的检查表。

*变体 A：行业类比设问 + 四个核心问题（Amazon）*：以“OpenAI崛起利好微软、Gemini带动谷歌云，那么Anthropic一枝独秀，哪家云受益”引入，再列4问——AWS的AI布局、与Anthropic合作的帮助与稳固性、自研芯片能力、大模型水平；
*变体 B：先梳理股价高位时的市场担忧，再转化为四大问题（Bloom Energy）*：担忧分需求端（AI电力需求是否只是短期脉冲）与供给端（能否兑现2030年5GW、AEP项目执行延误），转化为需求/供给/竞争/估值四大问题；
*变体 C：用一句导入锁定三问（Rocket Lab）*：“何以积累挑战巨头的能力、未来空间在哪、关键变化在哪”；
*变体 D：按时间与确定性顺序组织（海力士、闪迪、壁仞）*：问题清单明确后，正文按“历程 → 中短期 → 短期 → 长期 → 估值”或“供需缺口 / 客户与长协 / 产能业绩与估值”推进，业绩与估值可明说放到下篇。

**关键指标与数据来源**：无（结构方法）；问题的原料来自股价复盘、卖方与买方分歧、管理层电话会表述、做空报告与市场传闻。

**判断标准**：问题必须对准分歧点（市场真正在争什么），且每个问题都有可量化的答案路径；若问题只是“公司是什么”的科普，应放在首篇认知文中（14.3.14）。

**海豚案例**：
- Amazon《“AI拉胯”亚马逊：会上演逆袭大戏吗？》（2026-06-24）：行业类比设问 + 四问；结构为“一、AWS AI（三层收入结构+跨层AI口径；AI收入按业务拆分与利润率；跨云MaaS对比）→二、与AI Lab合作（MaaS竞争力两要素；Anthropic合作三阶段；合同隐含单价倒推；Anthropic收入贡献与会计口径；ARR推AWS增速；与微软-OpenAI的稳固性对比；Project Rainier拆解）及芯片（产品线时间线；Graviton实例级比较与第三方基准；Trainium纸面参数对标）→三、自研模型Nova评估→小结（AI综合实力不弱）”，并预告云厂商系列横评、附历史研究列表。
- Bloom Energy《AI电荒破局：Bloom Energy是新解药？》（2026-07-20）：回顾前作（美国结构性缺电）→三条离网电源路径定位与产能溢出逻辑→股价复盘（近30倍）→市场担忧转化为四大问题→需求端（CSP Capex、三大供给约束、交付速度、时间价值经济账、推理负载特征、系统性风险）→供给端（技术验证→产能爬坡验证；在手订单拆分与指引；订单质量；产能工序拆分；做空钪供需逐项反驳；调研真实瓶颈与出货区间）→竞争端（三类SOFC路线、75%份额、Ceres授权生态与数量级差距、防守与外部替代）→估值（三情景2030年PE折现）→结论（已定价基准情形，上下行条件）。
- Rocket Lab《Rocket Lab：SpaceX最危险的对手？》（2026-04-10）：问题导入三问；结构为业务拆解 → 能力来源（创始人Peter Beck特质→务实高效的企业文化与研发效率）→ 竞品对比（发射经验与成功率、政府供应商多样化；卫星制造）→ 市场空间（估值现状定位→政府预算拆解发射TAM→商业市场对标SpaceX→卫星市场→海外区域→星座运营）→ 市值判断（预期差排序、代际差推演、终局份额情景估值、赔率与胜率、Neutron催化剂）。
- SK海力士《海力士：超级AI加持，存储神话还能牛多久？》（2026-10-08）：提出供需缺口、客户与长协、产能业绩与估值三问；开篇交代处境（业绩大涨 vs 优势从独占到领先；价×量框架），依次为需求、供给、供需缺口、客户与长协、业绩预测与估值，结尾给结论与系列文链接（10-08版为上下合并完整稿）。
- 闪迪《AI 推理大爆发，“悲催”闪迪真有凤凰涅槃？》（2026-09-14）：提出与西数的关系、与铠侠的合作、NAND技术三问，并说明业绩与估值放到下篇。
- 壁仞科技《壁仞：国产“英伟达”，到底“几斤几两”？》（2026-06-18）：以“几斤几两”提问，按历程 → 中短期（出货为王）→ 短期（产能锁定）→ 长期（产品力）→ 估值组织。

**适用场景与注意事项**：所有个股深度报告的通用组织方式；问题清单也可直接作为后续跟踪框架（见14.4.11）。易错点：问题彼此重叠，或某一问在正文里没有答案。

### 14.3.3 三问式深度结构：是什么生意 / 凭什么 / 值多少

**方法要点**：深度文开头列三个待回答问题，全文按问题层层拆解、每个问题对应一章、最后小结回扣。三问覆盖商业模式、竞争优势、估值三个层次，是最常用的深度文骨架之一。

**操作步骤 / 拆分口径 / 公式**：
1. 问题一（是什么 / 怎么看）：画像与商业模式——钱从哪来、赚不赚钱、增长来自哪里；
2. 问题二（凭什么）：竞争优势与护城河——为什么别人学不会、能否穿越周期；
3. 问题三（值多少）：估值与击球区——什么价位算贵，什么价位是击球区；
4. 每个问题对应一章，章内按“结论先行再展开”写；最后小结回扣三问；
5. 若篇幅大，只做前两问，把“值多少”放到下篇（见14.4.3）。

**关键指标与数据来源**：无（结构方法）；三问分别对应画像数据（收入结构、利润率）、竞争力证据（同业对比、运营指标）、估值（相对估值与DCF交叉）。

**判断标准**：三个问题须覆盖商业模式、竞争优势、估值三个层次；缺了“值多少”则只是科普，缺了“凭什么”则估值缺少护城河支撑。

**海豚案例**：
- 星巴克《星巴克：“披着咖啡外衣的银行”，凭何称霸全球四十年？》（2026-07-21，上篇）：①卖咖啡还是卖空间；②凭什么把日常咖啡做成可负担的小奢侈并穿越四十年周期；③为何出让中国业务股权。结构：以“越便宜越牛”框架反例引入→三个问题→公司画像（三阶段成长史：品类定义、全球化与雀巢授权、战略重构与中国份额下滑；收入“三份钱”：直营/授权/CPG版税；门店规模与美国饱和/中国增量；毛利68% vs 营业利润率9.9%与“减重”动机；储值浮存金与负权益下的股东回报）→如何做到（供应链：产业链价值分布→采购/烘焙/物流拆解→与瑞幸对比；伙伴文化与“总部赋能+区域自主”组织）→出售中国运营权三点解读（速度、定位、风险/期权）→小结（类比亚朵、护城河边界、留问题给下篇）。
- 百胜中国《百胜中国：一只“洋鸡”，凭何在东方称王三十年？》（2026-07-02）：①是一门怎样的生意；②凭什么穿越周期、护城河在哪；③这台现金流机器值多少钱。结构：反差开篇（“无聊成熟股”标签 vs 拓店与利润率提升）→一、与母公司镜像的商业模式、收入按来源/品牌拆分、万店难度比较（客单/后厨/单店投入）、穿越周期的收入韧性（2022年-2.9% vs 海底捞-20%，价格带/时段/场景）、利润率含金量与必胜客业态差异、ROE杜邦拆分→二、护城河（供应链：集采是标配，差异在规模与本土化纵深，单环节无壁垒、物流园全链路协同 vs 塔斯汀；数字化：流量房东 vs 租户、会员占比65%、疯狂星期四、飞轮闭环）→三、投资价值（分品牌假设；相对估值14x中性+DCF WACC 10.1%/g 2%→49美元；“类债券+成长期权”）→小结（类比沃尔玛/古茗/鸣鸣很忙的低成本生态，防御型底仓）。
- SHEIN（2026-08-31）同样列明三问（是什么公司 / 小单快反壁垒 / 估值击球区），详见14.3.6。

**适用场景与注意事项**：适用于所有个股深度；问题设计应覆盖商业模式、竞争优势、估值三个层次；注意“凭什么”一问要有同业对比或量化证据，不要只给定性赞美。

### 14.3.4 结论先行、每节末加粗句收论与“灵魂发问”小标题

**方法要点**：深度文开头列3-5个核心问题，正文按问题编号逐节回答；分部深度文把关键争议写成“灵魂发问”式小标题；每节末用一句加粗句收出结论，全文最后再用一句话定性。让读者翻到任意一节都能拿走一个明确判断。

**操作步骤 / 拆分口径 / 公式**：
1. 开头列3-5个核心问题（如“可回收技术能降多少成本？”“为何急于上市？”“太空算力可行性多大？”），问题要对准市场分歧；
2. 正文按问题编号逐节回答，节内“结论先行，再展开测算”；
3. 分部深度文里把关键争议点写成“灵魂发问”：壁垒多深、领先多久、市场为何袖珍、下一代产品进度如何（小标题可用“灵魂一问：××搞得定吗？”的形式）；
4. 每节末用加粗句收出结论（如“星舰的成败直接决定公司估值上限”），必要时给一句定性评级（如对太空数据中心的散热评级“差点火候”、辐射评级“问题不大”）；
5. 全文最后用一句话定性（如“打着望远镜找不到对手的资产”）。

**关键指标与数据来源**：无（写作组织方式）；加粗句里的结论要对应前文的量化依据。

**判断标准**：加粗句必须是判断句而非描述句；“灵魂发问”要对应读者最想问的争议点；评级式收尾要与正文论证同向。

**海豚案例**：
- SpaceX四篇均以问题清单开篇：《马斯克再甩“王炸”：SpaceX 真能重塑“太空经济学”？》（2026-02-24）3问（成长史与降本、上市动机、太空算力可行性）；《从“白日梦”到“万贯金”，Space X 真那么“科幻”？》（2026-06-12）3问加3个灵魂发问（正文实为①至④：壁垒深度、领先多久、市场为何袖珍、星舰进度），结论“星舰决定估值上限”；《Space X：天空之网，要无敌了？》（2026-06-15）4问；《SpaceX：AI烧钱不止，“太空算力霸权”才是终极杀招？》（2026-06-30）5问。
- 《SpaceX：太空算力，马斯克新饼，还是真未来？》（2026-07-08）：列2个核心问题；每节给定性评级——散热“差点火候”、辐射“问题不大”，再看延迟与成本经济性，最后做SOTP（评级式收尾的写法与终篇组织见14.4.8）。

**适用场景与注意事项**：适用于所有个股深度文；问题要对准市场分歧；加粗句多了会稀释重点，建议每节只一句。

### 14.3.5 首次覆盖开篇之一：老牌转型公司的“四问”

**方法要点**：首次覆盖一家因重大事件被重估的老牌转型公司时，开篇先列四个问题——发展史 → 收入结构定关键业务 → 引爆点事件 → 重大合作得失，文章按这个顺序推进，最后用“小结：机会与风险并存”给出三个关键判断（a/b/c）。

**操作步骤 / 拆分口径 / 公式**：
1. 问题1：梳理发展史，搞清楚几十年的老店怎样变成新势力（案例：50多年的老店变云服务新势力；发展史五阶段：数据库、多元化与收购、整合、云转型失败、AI新云）；
2. 问题2：理清业务和收入构成，找出影响业绩的关键业务（按新口径重分FY18-26收入，发现OCI是唯一增长来源；新四大板块业务构成）；
3. 问题3：拆解“引爆点”事件意味着什么、来自哪里（3000亿大单相对化、FY30长期指引拆解、RPO分期限覆盖率测试、订单来源拼图：OpenAI每年600亿、5年）；
4. 问题4：重大合作的得失、动机和影响（取代微软成为OpenAI主要合作伙伴后的得失；替代微软的合作复盘；“大号CoreWeave”风险清单：客户集中、技术弱、毛利率、Capex与负债压力测试）；
5. 收尾：小结“机会与风险并存”，给出3个关键判断（a/b/c；案例为“生死一搏、大号CoreWeave、机遇与风险并存”，战略定性写法见14.1.9）。

**关键指标与数据来源**：无（结构方法）；配套的数据为业务口径重分后的收入序列、RPO、订单与GW意向、资本开支与负债。

**判断标准**：首篇先把事实与口径理清，再给结论；四问之间是递进关系（历史 → 现状 → 引爆点 → 合作得失）；小结的三点判断要与问题一一对应。

**海豚案例**：
- 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：首篇覆盖，以CoreWeave作为研究美国IaaS行业的引子之后的第二家新云；四问之后按“发展史 → OCI是唯一胜负手 → 小结三点判断”推进。

**适用场景与注意事项**：适合因重大事件被重估的老牌公司首篇覆盖；后续估值篇见14.3.15与14.4.2（Oracle后篇为《Oracle：AI 算力豪赌，赔率够了吗？》）。

### 14.3.6 “反常现象 + N个核心问题”式开篇：先抛悖论，再锁定全文主线

**方法要点**：开篇先抛出一个与常识冲突的现象或悖论，再用2-3个问题锁定全文主线，后文每个一级标题对应回答一个问题。这样让读者先接受“这里有研究价值”，再进入拆解；也是深度首篇最常见的开场。

**操作步骤 / 拆分口径 / 公式**：
1. 找悖论，常见两类：（a）行业普遍低估值/低增长 vs 标的高估值/逆势高增；（b）“利润率低于母公司但其实是好生意”这类需要换框架理解的反直觉数据；
2. 用硬数据把悖论摆出来：行业PE vs 公司PE、行业增速 vs 公司增速、分部利润率 vs 母公司利润率；
3. 提出2-3个问题锁定主线，常见三问：①这是一家怎样的公司、钱从哪来、赚不赚钱（商业模式+财务画像）；②壁垒在哪、为什么别人学不会（护城河）；③什么估值算贵、什么价位是击球区（估值与买点）；
4. 后文每个一级标题对应回答一个问题，最后必须给出答案，让悖论得到解释。

**关键指标与数据来源**：开篇常用对比数据——行业PE vs 公司PE、行业增速 vs 公司增速、分部利润率 vs 母公司利润率；来源为财报与行业数据。

**判断标准**：悖论要有数据支撑；后文必须回答，否则沦为标题党（与14.1.3的设问式标题要求一致）；“重估走到哪了、还剩多少空间”这类单一问题也可成立，但全文要围绕它展开。

**海豚案例**：
- SHEIN《SHEIN：Temu 围剿，关税压制，千亿独角兽还能否“老树开新花”？》（2026-08-31）：明确列出三问（是什么公司 / 小单快反壁垒 / 估值击球区）；开篇先写IPO发行条款与基石、一级估值“膝盖斩”复盘、“不上不行”（优先股负权益、对赌8%→12%），再提出三问。
- 亚朵《亚朵：酒店界“海底捞”凭何练就？》（2026-01-13）：以2024年行业价格战+关店潮下亚朵营收+50%、利润+70%的逆势表现开篇（逆势高增长悖论），再进入业务结构与“中高端溢价从何而来”。
- 沃尔玛《沃尔玛：“万亿零售真神”凭何练就？》（2026-04-21）：国内零售常年约10x PE vs 沃尔玛常年40x+并破万亿美元市值的悖论，宣布三部曲。
- 山姆《沃尔玛里的“Costco”：山姆养成的套路与反套路》（2026-06-09）：山姆OPM仅2.6%低于沃尔玛美国5%+，提出“不能用普通零售商框架看”，并点出会员费占利润90%的反直觉。
- 沃尔玛《沃尔玛：老兵不老，重估路还能走多长？》（2026-06-10）：以“重估走到哪了、还剩多少空间”为唯一问题；先给价值三层框架（线下地基/山姆/平台经济）与重估两条逻辑。
- Cerebras（2026-10-09）以“整片晶圆当芯片”的反常识切入，属同源写法（见14.3.1）。

**适用场景与注意事项**：适用于所有个股深度首篇；悖论要有数据，不能只是修辞；若悖论只是营销话术、后文答不出，就改用普通开篇。

### 14.3.7 “反差”开篇的两种写法：标签 vs 经营数据；标签 + 股价复盘 + 事件冲突

**方法要点**：海豚君惯用“市场叙事标签”与“实际经营数据”的反差开篇，把反差本身变成全文要回答的核心问题；争议型成长股则用“市场标签 + 股价复盘 + 事件冲突”引出对公司本质的判断。两者都把读者带入“是什么 / 凭什么 / 值多少”的结构。

**操作步骤 / 拆分口径 / 公式**：

*变体 A：标签 vs 经营数据（反差开篇）*
1. 列出市场给标的的标签（如“增长见顶的成熟股、靠回购续命的现金奶牛”）；
2. 用硬数据（门店数、利润率、人均创收、估值）证明实际情况与标签相反；
3. 把反差表述为本文要回答的核心问题，引导进入三问结构（见14.3.3）。

*变体 B：市场标签 + 股价复盘 + 事件冲突 → 公司本质 → 多空分歧（争议成长股首篇）*
1. 列市场给它贴过的标签（下一个Lending Club、成长中的数字银行、高波动金融Meme股）；
2. 复盘股价（2021年上市后多次大跌，2022年最低跌至IPO估值的60%）；
3. 引出当下事件（3月被浑水做空；CEO当天增持50万美元，加上3月初100万美元）；
4. 给出对公司本质的判断：成立15年，其中10年本质和贷款机构没有区别；只是近5年靠收购SaaS、平台型业务变现、校园贷恢复还息、《大美丽法案》给联邦校园贷设上限，才讲出性感的成长故事；
5. 点出多空分歧：能否匹配Fintech高估值 vs 中产家庭高渗透率带来的用户生命周期价值；最后交代系列安排。

**关键指标与数据来源**：变体A：市场叙事标签、关键经营数据（门店数、利润率、人均创收、估值）；变体B：股价/IPO估值比、管理层增持金额。

**判断标准**：反差需用硬数据支撑，避免只是修辞；变体B的“本质判断”要有历史事实依据（如十年做贷款机构、近五年才增加平台叙事）；多空分歧要落到一个可检验的核心问题。

**海豚案例**：
- 百胜中国（2026-07-02）：被贴上“增长见顶的成熟股、靠回购续命的现金奶牛”的标签，但实际拓店节奏未放缓、门店逼近2万家、经营利润率连续多季提升。
- 盈透《盈透：将“极致效率”刻进DNA的交易扫地僧》（2026-09-22）：IBKR几乎不打广告、界面劝退小白、下载榜进不了前十，却常年70%+经营利润率、人均创收200万美元；核心判断“牌照+技术”，随后做同行对比（Robinhood、SCHW）、技术驱动与价值判断（放弃DCF，27年净利60亿、27x前瞻PE vs SCHW 16x/HOOD 40x，配置型仓位，上沿30x）。
- SoFi《槽点多多的 SoFi，“贵”得有理？》（2026-06-29）：槽点多多（做空、粉饰、稀释）却享受估值溢价，下篇以“拧巴的表象”（瑕疵多但估值溢价高；420亿/30x EV/EBITDA→230亿）为核心问题。
- 星巴克上篇（2026-07-21）：原料成本极低却长期高价且客流不断，用“越便宜越牛”框架的反例引入。
- SoFi《被浑水盯上的 SoFi：真金科新贵 or“高科技噱头”？》（2026-06-16）：变体B完整示范——标签、股价复盘、浑水做空与CEO增持、公司本质判断、系列安排；随后分HENRY客群、成长史、信贷商业模式、技术平台SaaS，小结（Beta因素、一致预期隐含估值）引出下篇。

**适用场景与注意事项**：适用于所有深度文写作；变体B适合有争议的成长股首篇，用冲突引出核心问题；反差不能只靠形容词。

### 14.3.8 发布会点评模板：先给核心信息与海豚君点评，再附详细产品信息

**方法要点**：发布会类短文固定三段——开头几条提炼本次最值得关注的信息；紧跟点评，把产品信息翻译成对销量、ASP、毛利率、利润和估值的影响，并与市场预期比较；后半部分罗列详细参数供查阅。点评重点是投资含义，参数只作为附录。

**操作步骤 / 拆分口径 / 公式**：
1. 开头提炼若干条核心信息（如小米：SU7改款加AI大模型；比亚迪：闪充、能量密度、技术下放、基建、定价；苹果：标准版缺失、全线涨价、首发折叠屏）；
2. 点评部分：先对每条信息判断强弱（是否超预期），再翻译成财务变量——销量、ASP、毛利率、利润、估值，并给出与市场预期的比较；对缺席项、催化剂时效、政策冲击、战略转向做单独判断；
3. 估值结论尽早给出（时效性强）：用销量×单车利润或ASP/量/毛利率假设得净利润，再乘PE区间，写出上下行触发条件；
4. 后半部分罗列详细参数（三电、智驾、底盘、芯片、价格表、规格、运营进度，注意口径提示），并在文末回溯历史文章；
5. 若涉及产业链，可加一段映射标的（如苹果篇的立讯、领益、安费诺）。

**关键指标与数据来源**：发布会核心变化；定价；配置；对销量、ASP、毛利率的推论；估值；数据来源于发布会、官方参数、第三方追踪数据与历史财报。

**判断标准**：看“投资含义”而非“产品多亮眼”——定价与配置变动对ASP和毛利的影响、对销量的影响、是否超出市场预期；点评必须落到盈利与估值的结论；参数部分不进入判断。

**海豚案例**：
- 小米《小米（春季发布会）：SU7“低调”换代，MiMo限免冲榜》（2026-03-20）：a）新一代SU7中期改款，统一提价4000元，标准版配置升级最明显，推断标准版销量占比上升、均价结构性下移；b）MiMo-V2-Pro在OpenRouter匿名冲榜，识别限免红利，与MiniMax比较输出价格；之后附详细信息：SU7定价和硬件（三电、智驾、底盘、其他）、其他新品（Book Pro 14、Watch S5）、AI大模型三连发（Pro、Omni、TTS规格）、AI投入指引（当年超160亿元、三年600亿元）。
- 比亚迪《比亚迪：“颠覆性”发布会，能“颠回”宇宙车厂吗？》（2026-03-06）：核心信息5条——闪充参数对标行业5C；能量密度和续航对标宁德和主流车型；超快充下放15-20万元（回应友商800V下探）；闪充基建目标；分价格带定价（中低端增配涨价，高端激进定价）。海豚君点评：缺席项（DM-i 6.0、城市NOA下放）→催化剂时效（超充周期长）→政策冲击主力价格带→战略转向保利润→销量预测（国内-10%至321万辆；1-2月国内和海外拆分；海外150万辆指引）→国内和海外单车利润拆分→净利润450-470亿元×20倍PE，合理市值9000-9400亿元，上行5%-10%，已充分反映。
- 苹果《苹果：存储暴涨逼提价，折叠屏能救场吗？》（2026-09-10）：背景为新CEO首场发布会；三大重点——a）标准版缺失（2nm产能、存储成本转嫁难）；b）全线涨价（老机型反常涨价，存储合约价传导，手表和耳机未涨作为对照）；c）首发折叠屏iPhone Duo（规格、独立产品线、延迟发售）；d）整体思路：量承压、保毛利、推折叠屏（提价低于市场预期；iPhone 17历史对照；Duo定价卡位安卓竞品，拉动ASP）。估值：ASP、量、毛利率假设对应32倍PE，处于历史30-35倍区间即296-345美元，给出上下行触发条件；产业链映射（立讯、领益、安费诺）；最后附详细产品信息（Duo、Pro、Watch、AirPods、iOS 27）与历史文章回溯。

### 14.3.9 带着资本市场关心的问题清单去参会，按问题组织事件文

**方法要点**：参会或写事件文之前，先列出资本市场真正关心的几个问题，事后逐一回答，文章章节就按问题展开，避免流水账式复述发布内容。

**操作步骤 / 拆分口径 / 公式**：
1. 会前列清单：问题通常覆盖差异化定位、在集团内的定位、终局形态、费用投入四类；
2. 会中会后逐一取证，会后一一作答；
3. 文章章节按问题展开，另设“发布了什么”一节只做事实交代；
4. 文末用后记点出阶段性判断（如“C端AI竞争元年，下半场将相互渗透”）。

**关键指标与数据来源**：问题清单本身；回答所依据的发布会信息、公司公告、第三方数据（DAU/MAU、费用投入测算）。

**判断标准**：问题要是资本市场真正关心的（而非公司想讲的）；每个问题都有明确回答（哪怕是“暂时无法判断”并说明所需条件）。

**海豚案例**：
- 阿里《千问：AI 互联网时代，阿里要卷土重来？》（2026-01-16）：参加千问发布会前列出四问——①被豆包、DeepSeek和元宝多轮教育后，千问的差异化定位是什么；②千问在集团内的定位是什么；③AI App的终极目标会是新的流量主入口吗；④千问对比淘宝闪购，会是另一个“烧钱大户”吗。文章结构：背景（阿里C端AI动作时间线：成立事业群、AI眼镜、千问App月活过亿）→提出四个核心问题→一、发布了什么（任务助理对比生活助理，功能闭环成熟度）→二、差异化定位（与豆包、元宝对比，软件与硬件入口、封闭与开放生态，DAU差距）→三、在集团内的定位（取代夸克，接近闪购等级）→四、终局（取代还是共存、变现方式、硬件还是软件入口）→五、会不会成为烧钱大户（错位竞争、现金流约束、按All others亏损推算投入）→后记。
- 昆仑芯《昆仑芯上市加速，百度的「谷歌时刻」来了？》（2026-01-02）：用三个核心问题组织全文——1.前世今生（2011年FPGA起源、三代产品与路线图、团队、博通授权与三星代工、产能瓶颈）；2.竞争优势（先论证国产赛道的性价比和合规优势、大厂预算，再看技术层面的显存/CUDA兼容/三万卡集群/软硬一体，最后看生态层面、IDC份额和客户清单）；3.百度受益几分（融资估值对应的PS、按出货量和订单推算收入、IPO可比与情绪剔除、给10-15倍PS、按持股59.45%算价值、更新分部估值，整体提升11-21%）。

**适用场景与注意事项**：适用于所有事件解读写作；前提是有时间提前准备问题；问题清单要避免被发布会议程牵着走。

### 14.3.10 生活化类比：用一套完整的类比解释技术/架构差异

**方法要点**：对非专业读者解释复杂技术架构差异时，用一套完整的生活化类比，把各硬件部件逐一映射到类比对象，把“内存墙”这类抽象瓶颈变得直观，再引出定量测算。

**操作步骤 / 拆分口径 / 公式**：
1. 选定一个读者熟悉的场景作类比母体（图书馆、灯泡、加油站）；
2. 建立部件到对象的一一映射表（映射要完整，不能只比喻一处）；
3. 用类比把瓶颈说清楚（谁在等谁、哪条路最窄）；
4. 立刻衔接定量分析（带宽、时间、成本测算），让类比成为入口而非结论；
5. 同一系列内可换类比，但每篇内保持一套类比自洽。

**关键指标与数据来源**：无（表达技巧），配合带宽等参数；类比必须与后面的定量分析衔接。

**判断标准**：类比的每个对应关系都经得起追问（该部件在现实里确实承担这个角色）；类比之后必须有数字，否则只是修辞；失真的地方要说明。

**海豚案例**：
- Cerebras《Cerebras：不切晶圆的芯片“怪兽”，有希望挑战英伟达？》（2026-10-09）：GPU是一座图书馆，权重=百科全书，HBM=书库，HBM带宽=走廊，SM=读者；每写一个字所有读者都得把整套书翻一遍，书库到阅览室只有一条每秒过8TB的走廊；WSE则雇了90万人（WSE核心=背下一段书的人，SRAM=记忆，路由器=传题收答案）各背一小段，念一遍题目每人报出自己那段答案即可。随后进入“搬运时间 vs 计算时间”的测算。
- Lumentum上篇（2026-09-24）用“灯泡”比喻激光器；中篇（2026-10-05）用“加油站和供油车”比喻EDFA和泵浦激光器。

**适用场景与注意事项**：适用于技术壁垒型公司的深度文写作；类比必须与后面的定量分析衔接，避免失真；不要用类比替代对技术差异的量化。

### 14.3.11 大白话祛魅：把复杂业务映射成朴素的产业链类比

**方法要点**：用日常类比把高科技业务还原成朴素的经济活动，帮读者抓住价值链上哪一环是地基、哪一环是变现，之后的分部分析按这个链条展开。是分析框架的组织工具，不是装饰。

**操作步骤 / 拆分口径 / 公式**：
1. 把业务环节翻译成朴素经济活动（造火箭=造船、发射=出海、铺卫星通信网=撒网、收网络通讯费=收渔，未来还有算力费）；
2. 标出哪一环是地基（运输成本），哪一环是变现（网络订阅）；
3. 后文分部分析沿链条展开：船（运输壁垒）→网（Starlink）→新网（太空算力）；
4. 在每一环落回量化指标，类比只负责定调和导航。

**关键指标与数据来源**：无具体指标，是分析框架的组织工具；后文分环节的收入、毛利、估值数据另行给出。

**判断标准**：类比链条要与真实价值链同构，能解释“钱在哪一环赚”；规模经济的关键在地基环节（案例：船与运输成本）。

**海豚案例**：
- SpaceX《从“白日梦”到“万贯金”，Space X 真那么“科幻”？》（2026-06-12）：“造船、出海、撒网、收渔”；指出地基是“能把网运出去的运输船”，规模经济的关键在船和运输成本；其后估值跃迁复盘（2700万、2亿、120亿、305亿、8000亿、1万亿合并xAI、约2万亿）、商业飞轮与TAM扩展到28.5万亿美元（作为期权）都沿此链条展开。

**适用场景与注意事项**：适用于概念复杂、科幻感强的标的（航天、AI、生物科技），首篇深度文开篇定调尤其有用；类比不能代替量化。

### 14.3.12 跨公司 / 跨行业类比：快速传达商业模式本质

**方法要点**：用读者熟知的公司给标的“定性”，并说明类比成立的具体机制（而不是只贴标签），类比也用于给国内公司找海外原型或反向映射。

**操作步骤 / 拆分口径 / 公式**：
1. 选对标公司，列出类比维度：服务体系类比、业态类比、扩张路径类比、模式组合类比；
2. 写清成立机制（如亚朵≈海底捞：价值观驱动服务 + SOP + 员工授权 + 组织保障）；
3. 说明不成立的部分与边界；
4. 让类比服务于后文的量化比较，而非代替论证。

**关键指标与数据来源**：无固定指标，类比需落到具体机制。

**判断标准**：类比成立的机制能被数据或事实验证；类比不严谨时需注明，不能替代数据论证。

**海豚案例**：
- 亚朵《亚朵：酒店界“海底捞”凭何练就？》（2026-01-13）：亚朵≈酒店界海底捞（价值观驱动服务 + SOP + 员工授权 + 组织保障），早期零售≈“酒店版名创优品”。
- 沃尔玛《沃尔玛：“万亿零售真神”凭何练就？》（2026-04-21）：古茗自下而上扩张路径借鉴沃尔玛。
- 沃尔玛《沃尔玛：老兵“奇袭”电商，沃尔玛何以价值重估？》（2026-06-08）：零售业务像Costco、平台业务像淘宝。
- 山姆《沃尔玛里的“Costco”：山姆养成的套路与反套路》（2026-06-09）：先仓后店类似泡泡玛特开店前用机器人店探路。
- SHEIN（2026-08-31）：服装版亚马逊自营。
- 其他类比：甲骨文上篇“大号CoreWeave”（定性类比，见14.1.9）；星巴克上篇小结类比亚朵；SpaceX发射业务类比东印度公司（近乎绝对垄断）、Starlink定位为“太空垄断版电信运营商”（见14.4.8）；百胜中国小结类比沃尔玛/古茗/鸣鸣很忙的低成本生态。

**适用场景与注意事项**：所有个股写作；类比不严谨时需注明，不能替代数据论证；最好同时给出“像在哪、不像在哪”。

### 14.3.13 “海豚君在下表比较”：结构化对比表呈现模式差异

**方法要点**：关键竞争对比用表格逐项列示（定位、模式、客群、价格、权益、陈列、广告产品类型等），让读者一眼看清两家差异，再在正文提炼2-3个结论性优势与短板。

**操作步骤 / 拆分口径 / 公式**：
1. 选定要比较的对象与维度，维度要覆盖决定胜负的关键变量；
2. 逐项列示，每行一个维度；
3. 正文从表中提炼2-3个结论性优势与短板；
4. 可用图表变体：对比图（如服务峰值对比图、考核机制对比图）、竞品对比表（模型/产品发布场景）。

**关键指标与数据来源**：表格维度因比较对象而异；来源为公司披露、产品页面、第三方测评与调研。

**判断标准**：表格维度须覆盖决定胜负的关键变量（而不是任意罗列）；表后必须有结论，而不是只放表。

**海豚案例**：
- SHEIN（2026-08-31）：SHEIN vs TEMU对比表。
- 沃尔玛《沃尔玛：“万亿零售真神”凭何练就？》（2026-04-21）：Bettergoods vs Great Value思路对比表。
- 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：亚马逊与沃尔玛广告业务类型对比表、Walmart+ vs Prime对比表。
- 亚朵（2026-01-13）：亚朵 vs 华住中高端服务峰值对比图、“现长 vs 政委”考核对比图。
- 相关用法：Marvell权证篇横向对比亚马逊两份权证和英伟达可转优先股（量级、行权价、是否现金出资）以给关系性质分类；《(短评)Meta Muse发布》以竞品对比表开篇（见14.3.8）。

**适用场景与注意事项**：竞争分析写作；表格维度需覆盖决定胜负的关键变量；对比的口径要一致（同期、同口径）。

### 14.3.14 深度文骨架之一：首篇认知文（钩子 → 提问 → 画像 → 竞争力 → 小结 → 预告）

**方法要点**：首篇（或“上篇”）负责建立认知——是什么公司、钱从哪来、凭什么赚钱——不急于估值，甚至可以全篇无估值。这是海豚个股深度文里使用最多的骨架，沃尔玛、亚朵、星巴克、百胜中国、盈透、SHEIN、SoFi、三花、Lumentum等首篇都按这个顺序展开。

**操作步骤 / 拆分口径 / 公式**：
1. 开篇钩子：悖论 / 标签反差 / 事件+股价复盘 / 反常识 / 承接行业文的卡点结论（写法见14.3.6、14.3.7、14.3.19）；
2. 提出2-5个问题，宣布系列安排（见14.3.1至14.3.3）；
3. 公司画像：
   - 成长阶段：沃尔玛“乡镇折扣店 / 线下见顶 / 全渠道转型”三阶段并配营收增速曲线；星巴克“品类定义 / 全球化与雀巢授权 / 战略重构与中国份额下滑”三阶段；甲骨文五阶段；Lumentum“JDSU分拆与三轮并购、成为一体化光子平台”；
   - 业务与收入口径：星巴克收入“三份钱”（直营/授权/CPG版税）；亚朵加盟三类收入、直营收缩、零售阶段演进；百胜中国与母公司镜像商业模式、按来源/品牌拆分；SHEIN 1P/3P口径、收入=用户×频次×单均；
   - 财务画像：沃尔玛毛利率稳定（食品杂货60% vs Target）与反向定价、顶尖OPM（5% vs 国内1-3%）、高周转（14万SKU、39天）；
4. 核心竞争力：分层、可比、可量化——亚朵“重软装轻硬装预算对比 → 峰终定律服务产品化（17触点、固定/动态峰值、500元授权）→ 现长+政委双轨组织与考核 → 人房比 vs OCC/ADR/复购率量化溢价 → 正循环总结”；沃尔玛“差异化选址 → 供应链 → 自有品牌三阶段”；SHEIN“快时尚不可能三角 → Zara解法与天花板 → LATR小单快反 → 前端数据感知+后端柔性供应链三层机制 → 三大壁垒”；
5. 小结：用类比、闭环或边界收束（如类比海底捞与双业务赋能闭环；三者闭环、“最大公约数”定位；护城河边界），并留问题给下篇；
6. 预告下篇并附系列文章链接。

**关键指标与数据来源**：成长阶段划分、收入拆分、利润率与周转、同业对标数据；来源为财报、招股书、行业数据与调研。

**判断标准**：首篇的目标是“把生意讲清楚”——成长史能解释现状，口径重构能找出真实增长来源，竞争力有量化证据与同业对比；小结必须落到“质地好不好”，把“价格贵不贵”留给下篇。

### 14.3.15 深度文骨架之二：估值 / 终篇（回顾结论 → 提问 → 预测 → 验证 → 估值 → 结论）

**方法要点**：估值篇或终篇把前文的定性结论转成数字——先一句话回顾前文，提出“值多少 / 赔率够不够”的核心问题，再依次完成预测框架、可达成性验证、盈利预测、多方法估值，最后给出情景、赔率与介入价位。

**操作步骤 / 拆分口径 / 公式**：
1. 回顾前文结论（一句话或一小段），提出本篇核心问题（如“现金牛还值多少钱”“重估走到哪了”“瑕疵多但估值溢价怎么看”）；
2. 搭预测框架：分部/分产品拆分（如“搭积木”：底座业务 + OCI层层细拆 + 营收预测）；
3. 可达成性验证：用多种方法交叉检验指引或预测（如RPO覆盖率、GW算力供给与租赁承诺、客户钱包份额与终端需求；或管理层指引隐含假设识别）；
4. 利润与资本：毛利率、费用率、净利润；资本开支强度、举债与利息；
5. 估值：多方法交叉（相对估值、SOTP、跨周期净利润×中枢PE、DCF交叉验证），再给三情景或四情景；
6. 结论：赔率、介入价位、验证条件、跟踪点（见14.1、14.2）；
7. 文末附系列目录或历史回溯。

**关键指标与数据来源**：各章盈利预测与估值指标（见第8至10章）；估值篇的所有假设要可追溯到前文结论。

**判断标准**：估值篇的数字应能回扣上篇的定性判断（如中篇核查结论必须在下篇估值中有量化落点，见14.4.9）；多方法交叉验证一致才给强结论；结论段必须有“空间 + 条件 + 价位”。

### 14.3.16 深度文骨架之三：行业 / 技术铺垫文（先建立认知，再谈公司）

**方法要点**：产业链复杂、技术门槛高的标的，先写一篇行业或技术铺垫文，把“行业是什么、卡点在哪、公司凭什么”讲透，再写公司篇与估值篇。铺垫文的特点是反常识切入、机制拆解、定量对比，单篇只承担一个核心任务，并留问题给下篇。

**操作步骤 / 拆分口径 / 公式**：
1. 用反常识或核心观点切入（如整片晶圆当芯片、AI之前NAND是什么行业）；
2. 机制拆解：技术路线对比、物理结构 → 商业模式（如串联共享、批量成型 vs 1T1C）；
3. 定量对比：搬运时间 vs 计算时间、单片bit产出四因子公式、量价拆分（2019—2025年量价拆分论证“做大量≠做大收入”）；
4. 与同类行业/产品对标定性（如与钢铁/化工/航运对比，定性NAND为大宗商品）；
5. 结尾留下篇问题或预告，并附系列目录。

**关键指标与数据来源**：技术参数、行业供需数据、厂商资本开支与产能；量价拆分、四因子公式（逻辑缩放、架构缩放CBA、垂直缩放、横向缩放）等。

**判断标准**：铺垫文要让读者读完就能判断“卡点在哪、谁受益”，而不是堆砌技术名词；每个机制都要落到成本、价格或份额。

**海豚案例**：

### 14.3.17 事件快评骨架：事件与股价反应 → 先说结论 → 逐项拆解 → 影响判断 → 估值与情绪 → 文末回溯

**方法要点**：合作、融资、分拆、IPO、做空、口径争议、财报后指引等事件文，共用一个“倒金字塔”骨架：先交代事件与股价反应，再给出结论（或核心问题），然后把事实逐项拆解、判断强弱方与影响，纠正市场误读，最后落到估值、情绪和仓位，文末附历史回溯。事件文的价值在“预期差”：事件到底有没有新增信息、市场反应过没过头。

**操作步骤 / 拆分口径 / 公式**：
1. 事件与股价反应：写清事件内容、当日/次日涨跌与联动标的；
2. 先说结论（核心观点或核心问题）：用3-4点结论或把争议抽成1-2个核心问题；
3. 逐项拆解事实：条款、口径、时间表、数字来源（见12.4战略合作与交易条款拆解、12.2做空报告核查）；
4. 影响判断：判断强弱方与意图；列影响矩阵（对手、客户、公司自身）；横向对比先例并给关系性质分类；
5. 纠正误读：口径澄清（毛/净、窗口、发布时点）、信号层级定性；
6. 落到估值、情绪与仓位：priced in 判断、估值区间、继续上行的条件或介入价位（见14.1、14.2）；
7. 文末回溯历史财报点评、纪要与深度，并预告后续详细纪要或系列下篇（见14.4.11）。

*变体 A：交易条款型（合作 / 融资 / 分拆 / ADR）*：重点是条款逐项拆解与同类先例对标；
*变体 B：预期差澄清型*：重点是还原口径与第三方数据，判断真实冲击小于或大于市场反应；
*变体 C：做空与争议核查型*：把指控抽成可核查的问题，逐条用数据复现，给出“粉饰还是欺诈”的定性和估值落点；
*变体 D：战略动作解读型*：把多个动作归并成一个叙事转向，测算增量并提示信号；
*变体 E：股价异动重估型*：复盘股价事件链，用反向估值拆市场隐含预期，判断溢价是否有基本面支撑；
*变体 F：财报/指引后的整体观点型*：指引对比预期 → 分业务拆解 → 隐含估值 → 兑现条件。

**关键指标与数据来源**：事件当日/次日涨跌幅、条款数字（折价、稀释、行权价、金额）、第三方追踪数据、历史财报与纪要线索；见各变体案例。

**判断标准**：事件文是否“有增量信息”是第一判断（增量有限则点明“预期差有限”）；影响判断要给“谁受益、谁受伤、受伤多大”的矩阵而非单一方向；结论要有“已 priced in / 还差什么条件”的表述。

**海豚案例**：
- 变体 A：

### 14.3.18 短评骨架：一个问题、一组数据、一句结论

**方法要点**：“(短评)”系列把一个问题讲透即止，通常不做完整估值：以设问、反直觉观点或异动现象开头，用一两个量化锚（数据对比、成本拆解、时间量级）支撑，必要时做对比或情景，最后一句话结论并给出跟踪信号。它们既是独立的快评，也是系列文的“颗粒度部件”（见14.4.13）。

**操作步骤 / 拆分口径 / 公式**：
1. 开头三选一：设问（“为何…”）、反直觉观点（“真正会爆的是KV缓存”）、异动描述（股价异动 + 消息）；
2. 中段只放1-2条论证主线，每条配一个量化锚（如“10微秒 vs 9毫秒”“周转5-7天、整箱95%”）；
3. 需要时加对比（两种路线/两家公司/两类需求）或情景（2035年三情景成本）；
4. 末段一句话结论，并给跟踪信号或判别条件（如“判别条件”“跟踪信号清单”“催化剂与目标价”）。

*变体 A：观点 / 概念解释型*——《(短评)99%算力在空转：内存墙》（内存墙量化：10微秒 vs 9毫秒 → 短期解法：HBM升级+3D SRAM分工，含收购Groq → 中长期：存算一体 → 量产时间表）；《(短评)HBM与DDR的区别：堆与贴》（观点：颗粒无本质区别 → 堆：制程难缩、无摩尔定律、垂直堆叠层数演进 → 贴：共封装、边长受限 → 一句话总结门槛与成本来源）；《(短评)内存需求里真正会爆的是KV缓存》（存力拆为容量与速度 → 容量拆为底仓（参数）与弹性（KV缓存）→ 参数增长示例 → KV缓存被软件压住的单会话 → 会话数叠加的总量爆发 → 结论：用户数比模型大小更关键）；
*变体 B：设问—对比型*——《(短评)NAND为何不放手扩产》（设问：有5-6%缺口为何不扩 → 扩产门槛低与历史教训 → 紧平衡利润最大化 → 竞争分散下的博弈 → Capex优先DRAM → 结论：适度扩产）；《(短评)鸣鸣很忙供应链有多能省》（关键数字开篇：周转5-7天、整箱95% → 短链路 → 整箱拣选 → 数字化仓管与配送 → 结论：支撑低价策略）；《(短评)AWS 3D torus为何做不大》（设问 → 3D torus定义 → Trn2-Ultra结构 → 与谷歌的差异：回绕链路介质、OCS → 规模上限原因：无交换、铜缆、AEC长度 → 转向交换式Trn3）；
*变体 C：事件澄清 / 异动解读型*——见14.2.8的异动短评（腾讯、AppLovin、监管转发、CMC清单乌龙）与14.2.9的“一个数字引发的暴跌”；
*变体 D：发布 / 产品短评*——见14.3.8（Meta Muse、Gemini 4、Claude Haiku 5.5）；
*变体 E：总括 / 趋势型*——《(短评)Robotaxi击穿私家车成本底线》（私家车垄断的原因：省 → 网约车 vs 私家车成本对比 → 降本三杠杆：去司机/车辆BOM/运营效率 → 2035年三情景成本测算 → 特斯拉落点区间 → 里程碑：Cybercab量产）；《(短评)存力这局怎么收场》（核心变量：缺容量还是缺带宽 → 情景一卡容量 → 情景二卡带宽 → 情景三双双告急 → 现实三者并存 → 跟踪信号清单）；《(短评)AI商业化的钱从哪来》（核心追问 → 纯流量打法失效与C端困境 → B端Agent付费力：开发者调研数据 → OpenAI收入结构与倒算C端 → 广告路径受阻：CPM、门槛、广告ARR）。

**关键指标与数据来源**：每篇的量化锚——量级对比（微秒 vs 毫秒）、周转与占比、成本拆解、情景测算、供需比例；来源为公司披露、第三方数据与前序深度文。

**判断标准**：一篇短评只回答一个问题；量化锚要能一句话说清；结论要可被跟踪（判别条件、触发事件）；短评不替代估值，需要估值时仅做区间（如Muse短评的18x/25x/28x）。

**海豚案例**：见上列各变体，另见《(短评)字节阿里腾讯疯抢AI入口》（反直觉设问：流量巨无霸为何仍推独立AI入口 → 流量数据铺垫 → 原因一：交互范式不兼容 → 原因二：争夺Agent分发权，Windows/App Store类比 → 原因三：超级App先天短板，字节缺硬件 → 结论：未雨绸缪，以早期微信类比）、《(短评)Byte已老Token才是未来》（设问 → 流量价格通缩数据 → AI新基建成本 → Token作为计量筹码 → Token用量与份额数据 → 推理成本下降验证可行性 → 用户与厂商两视角 → 结论：Token与流量互补，走向刚需计价）、《(短评)美国Robotaxi三大阵营》（行业阶段判断：洗牌收敛 → 三大阵营底牌：Waymo/特斯拉/英伟达联盟 → 技术、成本、商业模式三个博弈焦点 → 短期 vs 长期胜负手 → 三种终局与份额区间）、《(短评)特斯拉估值里AI占比超60%》（交付下滑与股价新高的背离 → 分部估值拆分：AI 60%/硬件40% → 乐观情形Robotaxi估值 → FSD订阅、Optimus空间 → 催化剂与乐观目标价602美元）、《(短评)B站可转债+腾讯清仓》（具体执行：B站视角净融资拆解、腾讯视角股债转换 → 对B站影响：短空——Delta发行与借券逻辑，长多——低成本融资、解除减持压制 → 估值：PE与目标市值 → 催化剂节奏）。

**适用场景与注意事项**：适用于热点快评与知识型小文；不要把短评写成缩水版深度；系列短评之间要互相引用，形成知识矩阵（见14.4.13）。

### 14.3.19 各部分写法速查：标题、开篇入口、回顾上篇、小结、估值段、文末

**方法要点**：把海豚文章里反复出现的“局部写法”拆成可单独调用的零件——标题怎么起、开篇有哪些入口、如何回顾上篇、小结怎么收、估值段按什么顺序、文末放什么。写作时从零件库里挑组合即可。

**操作步骤 / 拆分口径 / 公式**：
1. 标题：设问式点出核心矛盾（见14.1.3）；或用类比词定性（“海底捞”“卖水人”“老腊肉”“大号CoreWeave”）；系列文标题各自独立，副线用括注区分（如“(短评)”“(纪要)”“(GTC 纪要)”）；
2. 开篇入口库（任选其一，常组合）：
   - 悖论 / 反常现象（14.3.6）与市场标签反差（14.3.7）；
   - 事件 + 股价反应（Marvell权证：MRVL涨、AVGO跌；Meta：彭博报道引发产业链下杀）；
   - 股价复盘（三花：与特斯拉合作、H股上市、机器人预期、近期A/H分歧；Bloom Energy：近30倍；SoFi：上市后多次大跌）；
   - 反常识（Cerebras：整片晶圆当芯片）；
   - 估值现状或重估背景（Lumentum：股价近10倍、英伟达入股，定价逻辑切换为供给约束型卖方市场）；
   - 个人体验（腾讯：亲测元宝派，说明复盘的目的）；
   - 行业类比设问（Amazon：OpenAI崛起利好微软、Gemini带动谷歌云，Anthropic一枝独秀哪家云受益）；
   - 承接前作（Oracle估值篇回顾上篇定性；BE篇回顾美国结构性缺电前作）；
   - 归因拆解（博通：把下跌归因为β与α）；
3. 回顾上篇：一句话回顾前文结论，让单篇独立可读（星巴克下篇：“好公司不一定等于好成长和好资产”；SoFi下篇：回顾上篇业务骨架与中篇暗伤核查并提出“拧巴的表象”；海力士10-09下篇：开头回顾上篇供需结论）；
4. 小结：判断而非复述，常见四式——a/b/c三点判断（Oracle“生死一搏、大号CoreWeave、机遇与风险并存”）；类比收束（亚朵：海底捞与双业务赋能闭环）；层次总结（沃尔玛电商篇：硬件层/用户层/变现层，Costco+淘宝类比，红利修复风险）；一句话定性（SpaceX：“打着望远镜找不到对手的资产”；“星舰决定估值上限”）；
5. 估值段顺序（细节见第9、10章）：指引隐含假设识别 → 分项预测（ASP、bit、单位成本、毛利率、OPM、净利）→ 跨周期净利润×中枢PE与DCF交叉验证 → 三/四情景 → 赔率与结论（闪迪终篇）；或相对估值 + DCF + 反向估值交叉（沃尔玛终篇）；
6. 文末：历史文章回溯（财报点评、纪要、深度、热点，见14.4.11）；系列文章目录（闪迪终篇附AI存储、CPO、组网、XPU系列）；预告下篇或后续详细纪要（英伟达快评预告《英伟达（GTC 纪要）》）；
7. 附录区：发布会等文章把详细参数放后半部分（见14.3.8）。

**关键指标与数据来源**：无（写作零件）；各零件内的数字沿用前文。

**判断标准**：标题与开篇要在前两屏就让读者知道“要回答什么问题”；小结与结论段必须有判断；回顾与预告保证每篇独立可读；估值段顺序反映“先假设后数字、先交叉验证后结论”。

**海豚案例**：见上列各零件的括注示例；另可对照14.3.1（标准骨架）、14.3.6至14.3.9（开篇与问题清单）、14.3.14至14.3.18（分类型骨架）。

**适用场景与注意事项**：适用于所有写作；零件之间要相互呼应（标题的问句在小结里要有答案；开篇的悖论在结论里要被解释）。

### 14.3.20 研究流程模板：从问题清单到结论与跟踪

**方法要点**：把海豚文章背后的研究顺序抽成一条可执行的流程：先定问题，再建认知、拆口径、做预测、交叉验证、估值，最后落结论、规划系列并留档。每一步都对应本书的章节，写作骨架只是这条流程的外显。

**操作步骤 / 拆分口径 / 公式**：
1. 立项与问题清单：判断是事件触发、行业卡点驱动，还是市场分歧驱动；先写问题清单（14.3.2、14.3.9；第1章）。先写行业文确定卡点，再选卡点龙头做个股系列（14.4.2）；
2. 认知层：成长史与关键节点（第2章）；业务架构与口径重构，找出真实增长来源（第3章；如按新口径重分FY18-26收入，发现OCI是唯一增长来源）；
3. 机制层：单位经济与成本结构（第4章）；行业空间与供需（第5章）；竞争格局与护城河（第6章）；
4. 预测层：增长归因与战略（第7章）；分部“搭积木”预测、订单与收入可见度、管理层指引可达成性验证（第8章）；
5. 估值层：选方法（第9章）、做隐含预期与情景（第10章），多方法交叉；
6. 治理与特殊情境：管理层与资本配置（第11章）、IPO/做空/分拆/合作/发布会等事件（第12章）；
7. 风险、催化剂与跟踪：证伪条件与催化剂时间线（第13章）；
8. 结论与交易表达：14.1、14.2；
9. 成文：选骨架（14.3.14至14.3.18），用零件库（14.3.19）；多篇时按14.4拆分；
10. 留档与事后检验：把本次的预期、结论与跟踪指标写入档案，下一次财报/事件回头对照（14.4.11、14.4.12）。

**关键指标与数据来源**：见各章；档案字段建议包含“核心判断 / 指引 / 关键数字 / 管理层表态 / 估值区间 / 下一次检验时点”。

**判断标准**：每一步产出一个可供下一步使用的“中间结论”（问题清单 → 口径重分后的收入序列 → 分部预测 → 交叉验证结论 → 情景估值 → 赔率与价位）；缺任何一步，结论会出现断点（例如上篇定性结论未量化进下篇估值，见14.4.9）。

**海豚案例**：
- Lumentum：前置行业文（《AI 超连接时代：AI 向“光”飞奔？》《“‘铜’牛夫人”不走！CPO：真机会 or 镜中花？》《叫板英伟达霸权，谷歌“光网”凭什么？》）先确定卡点，再对卡点龙头做上/中/下篇个股系列，下篇做业绩测算和估值（见14.4.2）。
- Oracle：首篇覆盖（四问）→ 估值篇（搭积木预测、可达成性三法验证、利润、三情景估值）→ 结论“赔率够了吗”（见14.3.5、14.3.15、14.1.1）。
- SpaceX：首篇讲前因后果 → 招股书总览与基本盘 → 分部深挖 → 竞对专篇 → 终篇估值（见14.4.7）。
- 高通：事件文回溯历次财报点评和纪要中的线索，再得出“客户指向亚马逊”的推断（见14.4.12）。

**适用场景与注意事项**：适用于任何一次从零开始的个股研究；流程是顺序建议而非僵硬规定，财报点评与短评可只走其中几步；对已有档案的标的，从第10步的档案回看开始，先检验旧判断再更新。

**本节速查清单**
- [ ] 开篇是否交代背景与核心判断，并列出2~4个可回答、可验证、对准市场分歧的问题？
- [ ] 每个问题是否对应一个一级标题，节内是否“结论先行再展开测算”，每节末是否有判断句？
- [ ] 开篇钩子（悖论、标签反差、事件复盘、反常识）是否有硬数据支撑，且后文给出了答案，而非标题党？
- [ ] 首篇是否按“画像 → 竞争力 → 小结”建立认知；估值篇是否先回顾前文结论，再依次完成预测、验证、估值、结论？
- [ ] 复杂技术或业务是否用了与定量分析衔接的类比（生活化类比、产业链类比、跨公司类比），并说明了类比的边界？
- [ ] 竞争对比是否使用了覆盖胜负关键变量的对比表，表后是否提炼了2-3条结论？
- [ ] 发布会、事件快评是否先给核心信息和投资含义（销量、ASP、毛利率、利润、估值），详细参数放在后半部分？
- [ ] 事件文是否先判断“有无增量信息”，对条款、口径、先例做了拆解与对标，并落到估值、情绪或仓位？
- [ ] 短评是否只回答一个问题、有一个量化锚、末段有可跟踪的一句话结论？
- [ ] 文末是否附历史文章回溯 / 系列目录，并预告下一篇或后续纪要？

## 14.4 系列文组织与研究跟踪档案

> 本节导读：本节回答“一家公司或一个行业太大，怎么拆成多篇；以及怎样让每次新研究都接在旧研究上”。前半部分是系列文的分工模板（上中下篇、四篇递进、行业→个股、超级标的按业务分篇、争议公司三部曲、短评矩阵），后半部分是跟踪档案方法（财报点评+电话会纪要成对发布、文末历史回溯、事件文接续纪要线索）。单篇的骨架与写法见14.3，结论表达见14.1，催化剂与跟踪指标的内容本身见13.2、13.3。

### 14.4.1 系列文通用机制：单篇单任务、开头回顾、结尾钩子、文末目录

**方法要点**：不管系列怎么分工，海豚文章普遍遵守同一套“接口规范”：每篇只承担一个核心任务、开头回顾前文结论、结尾预告或抛出下一篇的问题、文末列相关文章与系列目录。这样每篇独立可读，又能串成连续的研究矩阵。

**操作步骤 / 拆分口径 / 公式**：
1. 拆任务：先决定每篇承担的核心问题（如“是什么、空间多大”“能拿多少、值多少”），单篇只做一件事；
2. 开头回顾：用一句话或一小段回顾前文结论（如“好公司不一定等于好成长和好资产”），再提出本篇问题；
3. 结尾钩子：预告下一篇，或抛出留给下篇的具体问题（如“其他厂是否真默契不扩产、需求如何重塑、涨价还能飞多久、估值是否仍有空间”），下篇逐一回答；
4. 篇内小结：用层次总结（如“硬件层 / 用户层 / 变现层”）收束；
5. 文末目录：列出相关文章与系列目录（终篇可附“DRAM行业、存储个股、CPO互联、组网、XPU”等系列，形成“行业×个股”的研究矩阵）；
6. 自洽检查：单篇要能被独立理解，不能要求读者读完全系列；终篇靠前文结论时，要把假设来由说清。

**关键指标与数据来源**：各篇承担的问题；篇间引用关系；系列目录。

**判断标准**：每篇有清晰的单一任务；回顾与预告首尾呼应；上篇设置的悬念在下篇有答案；终篇的假设能追溯到前文。

**海豚案例**：
- 闪迪中篇《NAND 天性“多产”，闪迪凭什么守 80% 毛利率？》（2026-09-18）结尾留下“其他厂是否真默契不扩产、需求如何重塑、涨价还能飞多久、估值是否仍有空间”四问，终篇《AI 改不了“DNA”，闪迪还能牛多久？》（2026-10-06）逐一回答，并在文末附系列目录（DRAM行业、存储个股、CPO互联、组网、XPU）。
- 星巴克上篇结尾抛出“博裕能否跑到2万家、‘重回星巴克’能否修复、高端定位能守多久”，下篇开头以一句话回顾上篇结论（见14.4.3）。
- 沃尔玛四部曲每篇结尾预告下一篇、文末列系列相关文章；SpaceX系列每篇开头回链前文结论、结尾预告下一篇并列出相关文章（见14.4.4、14.4.7）。

**适用场景与注意事项**：所有系列文；单篇需自洽，避免读者必须读完全系列才能理解；终篇单读时假设的来由不够透明是系列文的固有局限，需在文中主动补足。

### 14.4.2 上 / 中 / 下篇分工：业务与技术拆解 → 剩余业务与第二曲线 → 业绩测算与估值

**方法要点**：复杂公司用系列文拆分任务——上篇做定性的商业模式和技术拆解（是什么、解决什么问题、卡在哪、壁垒在哪）；中篇补齐其余业务线和第二增长曲线，以及瓶颈约束下的成长路径；下篇（或估值篇）做分业务业绩测算和估值，给出“值多少钱”。系列文也可与行业文联动：先写行业文确定卡点，再选卡点龙头做个股系列。

**操作步骤 / 拆分口径 / 公式**：
1. 前置行业文（可选）：先写行业文确定卡点；
2. 上篇：定性拆解（商业模式、技术、壁垒、核心看点与风险）；
3. 中篇：其余业务线、第二曲线、瓶颈资源约束与成长路径；
4. 下篇/估值篇：分业务业绩测算与估值，给“值多少钱”；
5. 每篇独立可读，并在开头回顾上篇结论。

**关键指标与数据来源**：无（组织方法）。

**判断标准**：上篇定性要给出可被下篇量化的判断（如“大号CoreWeave”定性对应估值篇的博弈性标的处理）；中篇必须回答“成长从哪来、被什么约束”；下篇的估值假设能回扣前两篇。

**海豚案例**：
- Oracle：上篇定性为“大号CoreWeave”，识别核心看点与风险；《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）为估值篇。
- Cerebras：上篇（2026-10-09）写产品、技术与制造，下篇写经营表现与展望。
- Lumentum：上篇（2026-09-24）写EML和CW，中篇（2026-10-05）写电信器件、光模块、OCS，下篇做业绩测算和估值；前置行业文包括《AI 超连接时代：AI 向“光”飞奔？》《“‘铜’牛夫人”不走！CPO：真机会 or 镜中花？》《叫板英伟达霸权，谷歌“光网”凭什么？》。

**适用场景与注意事项**：适用于业务复杂、技术门槛高的深度研究；每篇都要独立可读，并在开头回顾上篇结论。

### 14.4.3 上下篇分工：上篇建立认知（定“质地”），下篇做判断（定“价格”）

**方法要点**：深度研究拆成上下两篇——上篇负责成长史、核心能力、科普和市场空间，建立“是什么、空间多大”的认知；下篇负责新业务、竞争格局、盈利预测与估值，回答“能拿多少、值多少”；事件文或财报点评在两篇之上做验证和跟踪。下篇开头用问题清单或一句话回顾衔接上篇。

**操作步骤 / 拆分口径 / 公式**：
1. 上篇：成长史复盘、核心能力归纳、产品科普、市场空间；明确把估值或新业务留到下篇；
2. 上篇结尾：抛出留给下篇的问题或悬念；
3. 下篇开头：回顾上篇结论（问题清单或一句话），提出核心问题；
4. 下篇：新业务/新下游、竞争格局、能力迁移论证、盈利预测、SOTP/DCF估值、投资结论；
5. 事件文：回引两篇深度报告的目标价或结论做验证与跟踪；
6. 中间可穿插财报点评。

*变体 A：产品科普 + 新下游（三花、特斯拉）*；*变体 B：成长性 + 盈利预测 + 估值（亚朵）*；*变体 C：质地 vs 价格，中间穿插财报点评（星巴克）*。

**关键指标与数据来源**：各篇承担的问题；篇间引用关系。

**判断标准**：上篇定“质地”（公司好不好），下篇定“价格”（资产好不好）；下篇常引用上篇的定性结论再做量化验证；“好公司不一定等于好成长和好资产”是下篇需要回答的转折。

**海豚案例**：
- 三花智控《三花智控：生意不起眼，凭什么总能抓住风口？》（2026-01-02）与《三花：AI 机器人时代，笑到最后还是跨界“老腊肉”？》（2026-01-08）：上篇负责成长史复盘、核心能力归纳、产品科普（阀、热管理）和新能源车热管理市场空间，明确把机器人和估值留到下篇；下篇负责新下游（数据中心、储能）、人形机器人布局、能力迁移论证、SOTP估值和投资结论。
- 特斯拉《Robotaxi 出行帝国，能再造特斯拉？》（上篇）讨论Robotaxi如何改变网约车苦生意的本质以及能重构多大市场；《从造车到造梦：1.5 万亿 AI 特斯拉真的贵了吗？》（2026-01-12，下篇）以三个问题开篇（竞争格局和UE、市值增量、1.5万亿是否贵了），完成全业务SOTP；之后的《Cybercab 发布会：告别概念，开启 Robotaxi 大时代？》（2026-09-04）事件文回引两篇深度报告的目标价。分工逻辑：上篇建立认知（是什么、空间多大），下篇做判断（能拿多少、值多少），事件文做验证和跟踪。
- 亚朵：上篇《亚朵：酒店界“海底捞”凭何练就？》（2026-01-13）分析差异化切入中高端、靠服务制胜的酒店业务，以及依托酒店爆发的第二曲线零售业务；下篇《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）开头承接上篇结论，回答“成长性如何、投资价值怎么看”，依次是酒店成长性（竞争力验证 → 开店空间两法测算 → 子品牌）→ 零售天花板（大单品两法测算 → 竞争）→ 盈利预测 → 分部估值 + DCF → 小结。下篇常引用上篇的定性结论再做量化验证。
- 星巴克：上篇《星巴克：“披着咖啡外衣的银行”，凭何称霸全球四十年？》（2026-07-21）主打商业模式与核心竞争力（是什么生意、凭什么高溢价、为何出售中国），结尾抛出留给下篇的问题（博裕能否跑到2万家、“重回星巴克”能否修复、高端定位能守多久）；中间穿插财报点评《星巴克：走出至暗时刻，星巴克涅槃重生？》（2026-07-30）；下篇《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）开头先用一句话回顾上篇结论（好公司不一定等于好成长和好资产），然后聚焦成长性（开店空间+同店修复）、盈利预测与估值，给出买点。

**适用场景与注意事项**：适用于业务复杂、需要大篇幅科普的深度覆盖，以及首次深度覆盖的消费公司；下篇开头用问题清单衔接上篇，是可复用的结构；上篇定“质地”，下篇定“价格”，上篇结尾设置悬念承接下篇。

### 14.4.4 多篇递进：主业护城河 → 第二曲线 → 第三增长极 → 终篇估值

**方法要点**：多业务巨头拆成多篇连续发布：首篇讲最核心基本盘的商业模式与护城河并复盘成长史；第二篇讲最影响成长性与市值的第二曲线（与最强对手全方位对比）；第三篇补齐被忽视的资产（与全球标杆对比、海外子市场）；终篇把前三篇结论组装成价值分层框架，完成SOTP + 反向估值 + DCF交叉验证。每篇结尾预告下一篇、文末列系列相关文章，篇内小结用“硬件层 / 用户层 / 变现层”等层次总结。

**操作步骤 / 拆分口径 / 公式**：
1. 首篇：基本盘商业模式、护城河、成长史（低成本生态）；
2. 第二篇：第二曲线，与最强对手全方位对比（电商 vs 亚马逊）；
3. 第三篇：被忽视的资产，与全球标杆对比并拆海外子市场（山姆 vs Costco、山姆中国）；
4. 终篇：把前三篇结论组装成价值分层框架（线下地基 / 山姆 / 平台经济），完成SOTP、反向估值、DCF交叉验证；
5. 每篇结尾预告下篇、文末列系列文章，篇内小结用层次总结。

**关键指标与数据来源**：无（组织方法）；各篇的核心数据见各篇（如OPM、费用率、渗透率、take rate）。

**判断标准**：每篇有独立论点（低成本生态 / 电商 vs 亚马逊 / 山姆 vs Costco / 估值），终篇的每个估值模块都能回扣前三篇的结论；“估值不便宜但有道理”只在终篇给出。

**海豚案例**：沃尔玛四部曲——
- 《沃尔玛：“万亿零售真神”凭何练就？》（2026-04-21）：低成本生态（结构见14.3.14）。
- 《沃尔玛：老兵“奇袭”电商，沃尔玛何以价值重估？》（2026-06-08）：电商 vs 亚马逊。结构：承接上篇 → 电商规模与份额定位（亚马逊绝对领先，沃尔玛抓未垄断市场）→ 一、亚马逊重资产死穴 vs 沃尔玛存量红利（亚马逊履约链路与最后一公里成本；90%人口10英里内；门店改造三阶段：Store Assist/空间改造/APD与时间表；三种履约方式费用率与占比）→ 二、生鲜杂货切入、高频带低频（频次数据、杂货份额、疫情渗透率跃升与持续性、全渠道用户价值）→ 三、1P到3P（1P亏损与3P终局；Marketplace卖家迁移：广告ROI、WFS vs FBA；Walmart Connect利润贡献与保守情景测算；Walmart+ vs Prime；Luminate）→ 小结（硬件层/用户层/变现层，Costco+淘宝类比，红利修复风险）→ 预告山姆与估值篇。
- 《沃尔玛里的“Costco”：山姆养成的套路与反套路》（2026-06-09）：山姆 vs Costco、山姆中国。结构：系列第三篇定位 → 一、山姆美国（OPM 2.6%的反直觉与会员费占利润90%；与Costco规模效率对比：门店、会员、单会员/SKU/坪效、年均消费；差距原因：SKU集中度、定位纯粹度；追赶路径一Member's Mark：整合、Made Without、会员共创、增量贡献；追赶路径二数字化：集团技术复用、Scan & Go漏斗与效果、电商渗透率；坪效差距收敛）→ 二、山姆中国（体量对标与本土竞品败退；爆品战略：SKU精简、年度10款爆品、场景识别、超预期公式、代工深度参与、以量换价；即时零售三层网络与线上占比；Costco决策链条对比；先仓后店）。
- 《沃尔玛：老兵不老，重估路还能走多长？》（2026-06-10）：估值（价值三层框架，SOTP + 反向估值 + DCF，结构见14.3.15与14.1.5）。

**适用场景与注意事项**：多业务巨头首次深度覆盖；单篇需自洽，避免读者必须读完全系列才能理解；终篇之前不给估值结论，避免“半截结论”。

### 14.4.5 行业 × 个股四篇：公司定位 → 行业DNA → 需求重塑 → 供需测算与估值

**方法要点**：产业链复杂、需要先建立行业认知再估值的深度覆盖，按“公司 → 行业供给本质 → 需求变化 → 定量与估值”递进。单篇只承担一个核心任务，每篇开头回顾前文结论、结尾抛出下一篇的问题作钩子，终篇文末附系列目录形成“行业×个股”的研究矩阵。

**操作步骤 / 拆分口径 / 公式**：
1. 上篇（公司定位）：公司的战略取舍与技术定位；
2. 中篇（行业DNA）：AI之前这个行业是什么行业（量价拆分）、供给为何减不掉（四因子公式）、与相近行业为何同源不同命（物理 → 商业模式）；
3. 下篇（需求重塑）：新需求逻辑如何改变行业（如让SSD成为“Token电池”）；
4. 终篇（定量与估值）：供给逐厂测算、需求自下而上测算、缺口判断，再落到公司预测和四情景估值；
5. 衔接：每篇开头回顾前文结论，结尾抛下一篇的问题作钩子；终篇文末附系列目录。

**关键指标与数据来源**：无（写作结构）；各篇数据包括量价拆分、四因子公式、供需缺口、情景估值。

**判断标准**：钩子问题必须在下一篇被回答（中篇结尾四问在终篇逐一回答）；行业篇的结论（如“大宗商品属性”“默契不扩产”）要在终篇估值中体现为周期假设。

**海豚案例**：
- 闪迪系列：上篇《AI 推理大爆发，“悲催”闪迪真有凤凰涅槃？》（2026-09-14）讲公司甩掉HDD聚焦NAND，以及技术定位（横向微缩、CBA、HBF）；中篇《NAND 天性“多产”，闪迪凭什么守 80% 毛利率？》（2026-09-18）回答AI之前NAND是什么行业（量价拆分）、供给为何减不掉（四因子公式）、NAND与DRAM为何同源不同命（物理 → 商业模式）；下篇《从绿叶到鲜花，AI推理如何为NAND“逆天改命”？》讲AI推理让SSD成为“Token电池”的需求逻辑；终篇《AI 改不了“DNA”，闪迪还能牛多久？》（2026-10-06）做供给逐厂测算、需求自下而上测算、缺口判断，再落到公司预测和四情景估值。每篇开头回顾前文结论，结尾抛出下一篇的问题作钩子；终篇文末附系列目录（DRAM行业、存储个股、CPO互联、组网、XPU）。中篇结尾留下“其他厂是否真默契不扩产、需求如何重塑、涨价还能飞多久、估值是否仍有空间”四问，终篇逐一回答。

**适用场景与注意事项**：适用于产业链复杂、需要先建立行业认知再估值的深度覆盖；单篇只承担一个核心任务；行业篇与个股篇的双向引用能形成研究矩阵（见14.4.10）。

### 14.4.6 技术 / 行业铺垫 → 公司供需 → 客户与估值，或：关系与技术 → 毛利率 → 业绩与估值

**方法要点**：大型深度研究的拆分与发布节奏——先用技术/行业文铺垫，再写公司篇（上）聚焦供需与周期拐点，（下）聚焦客户与长协、业绩测算与估值；或按“关系与技术 → 毛利率 → 业绩与估值”递进；事件快评与深度系列互补，纪要与热评穿插其间。

**操作步骤 / 拆分口径 / 公式**：
1. 铺垫文：从技术角度梳理行情逻辑（如存力接棒算力、HBM为何脱颖而出）；
2. 公司篇（上）：行业供需推演与周期拐点；
3. 公司篇（下）：与核心客户及ASIC客户合作格局、三大厂长协策略差异、业绩测算与估值性价比；
4. 发布形态：可发上下合并的完整稿，再单发下篇（下篇开头回顾上篇）；
5. 并行的事件快评（如ADR、投资者日）独立成篇；
6. 闪迪式：电话会纪要 → 热评（投资者日指引质疑）→ 上篇（西数关系、铠侠合作、NAND技术）→ 中篇（凭什么守80%毛利率）→ 下篇（AI推理如何为NAND逆天改命 / 业务进展与估值）；每篇结尾预告下篇、列历史文章回溯。

**关键指标与数据来源**：无。

**判断标准**：铺垫文提供技术判断，公司篇消化成供需与估值；快评不重复深度结论，只做增量；纪要与热评提供“管理层说了什么、市场质疑什么”的线索。

**海豚案例**：
- SK海力士：前两篇从技术角度梳理存力行情（《存力接棒算力，HBM为什么脱颖而出？》《从HBM限高到NAND加量…》），公司篇（上）聚焦DRAM/HBM行业供需推演与周期拐点，（下）解析与英伟达及ASIC客户合作格局、三大厂长协策略差异、业绩测算与估值性价比；《海力士：超级AI加持，存储神话还能牛多久？》（2026-10-08）为上下合并的完整稿，《SK 海力士：长协能熨平周期？估值到哪一步》（2026-10-09）为下篇单发，开头回顾上篇；另配合事件快评《海力士赴美，来讨一个“公道估值”？》（2026-07-10）独立成篇。
- 闪迪：《比 DRAM 还摇钱树，闪迪真有那么香？》（2026-08-17，热评）、《AI 推理大爆发，“悲催”闪迪真有凤凰涅槃？》（2026-09-14，上篇）等；电话会纪要 → 热评 → 上篇 → 中篇 → 下篇的节奏，每篇结尾预告下篇、列历史文章回溯。

**适用场景与注意事项**：大型深度研究的拆分与发布节奏；事件快评与深度系列互补；合并稿与单发稿并存时，下篇开头必须回顾上篇。

### 14.4.7 超级标的系列：行业入门 → 招股书总览与基本盘 → 各分部深挖 → 竞对专篇 → 估值

**方法要点**：围绕一个超级标的（大型IPO或复杂多业务公司）组织系列：先写行业入门式的前因后果，再用招股书总览估值跃迁与业务矩阵并深挖基本盘，随后按分部逐篇深挖（现金牛、烧钱业务），再写竞争对手专篇，估值留到最后一篇。原则是先业务后估值、先基本盘后期权。

**操作步骤 / 拆分口径 / 公式**：
1. 首篇（行业入门）：成长史、降本测算、上市动机、新叙事可行性，并预告下篇讲竞争格局；
2. 招股书篇：估值跃迁、业务矩阵、资本流向，并深挖基本盘业务；
3. 分部篇一：深挖现金牛（商业模式、D2C、对比同行、护城河）；
4. 分部篇二：深挖烧钱的新业务（资产版图、各产品线、算力租赁、太空算力）；
5. 竞争对手专篇：对手的业务、能力来源、对标与市值判断；
6. 终篇估值：留到最后，先回答最大不确定性（技术与经济可行性），再把前几篇的分业务结论串起来做SOTP（见14.4.8）；
7. 每篇开头回链前文结论，结尾预告下一篇并列出相关文章。

**关键指标与数据来源**：无（组织方法）；各篇核心数据：估值跃迁节点、TAM、分部收入与CAGR、毛利率、资本开支与融资。

**判断标准**：每个分部篇给出该业务的独立定性（垄断运力 / 太空垄断版电信运营商 / 资源密集的期权）；系列整体顺序遵循“先业务后估值、先基本盘后期权”。

**海豚案例**：SpaceX系列——

### 14.4.8 超级独角兽“一业务一篇” + 终篇SOTP汇总估值

**方法要点**：对多业务、多叙事、估值争议很大的公司（如SpaceX、特斯拉这类平台型），采用“一业务一篇”深挖，终篇先回答最大的不确定性（如太空算力的技术与经济可行性），再把前几篇的分业务结论串起来做SOTP汇总。每篇开头明确列出“本篇聚焦的N个核心问题”，正文用“灵魂一问：××搞得定吗？”这类设问做小标题，每节末给一句定性评级。

**操作步骤 / 拆分口径 / 公式**：
1. 分业务写：先分别写火箭发射、Starlink、AI业务，每篇给出业务的定性（发射：近乎绝对垄断，类比东印度公司；Starlink：太空垄断版电信运营商；AI：烧钱，太空算力是最大的期权价值）；
2. 终篇开头先引用前文结论（如“太空数据中心是估值里最大的期权价值”），再列出本篇聚焦的核心问题（案例：太空算力是科幻还是降维打击；怎么给SpaceX估值）；
3. 终篇先攻最大不确定性：按散热、辐射、延迟、成本经济性的顺序推进，每节给定性评级（散热“差点火候”、辐射“问题不大”）；
4. 终篇第三部分按业务逐个估值，每个业务先引用前文结论、再落到估值参数：火箭（EV/EBITDA折现）、Starlink（宽带/DTC/航空海事TAM加份额，EV/EBIT折现）、AI（X用P/S、Grok用P/ARR、地面算力用P/S、太空DC终局PE加时点折现）；
5. 用SOTP汇总图收尾。

**关键指标与数据来源**：分业务结论引用；SOTP汇总表（图）；太空算力的物理与经济参数（散热、辐射、延迟、TCO/LCOC平价）。

**判断标准**：终篇每一块估值都有来源于前文的假设；评级式收尾与论证一致；不确定性最大的模块（期权）单独处理，不与基本盘混算。

**海豚案例**：
- SpaceX《SpaceX：太空算力，马斯克新饼，还是真未来？》（2026-07-08）：开篇引用前文“太空数据中心是估值里最大的期权价值”，列出部署时间表并换算为GW，对比全球CSP存量，提出两个核心问题；一、散热（物理约束、四大困境、四种权衡方案，评级为差点火候）；二、辐射（临界电荷、四项方案、Google实验实证，评级为问题不大）；三、延迟（三层网络对比、过顶时间与多跳延迟、感算一体、定位异步计算；运维靠冗余）；四、成本经济性（轨道日照、Capex替代Opex、地面四层电力缓冲、TCO/LCOC平价、基准与电荒双情景的成本剪刀差和供需溢出）；估值（火箭、Starlink、AI分业务，如上）；SOTP汇总。
- 系列前三篇：《从白日梦到万贯金》（火箭发射，结论近乎绝对垄断，类比东印度公司）、《天空之网，要无敌了？》（Starlink，定位为太空垄断版电信运营商）、《AI 烧钱不止，太空算力霸权才是终极杀招？》（AI业务）。

**适用场景与注意事项**：适合多业务、多叙事、估值争议很大的公司（如SpaceX、特斯拉这类平台型）；局限在于终篇要靠前几篇的结论，单读终篇时假设的来由不够透明（见14.4.1的自洽检查）。

### 14.4.9 争议 / 做空类公司首次覆盖三部曲：业务骨架 → 做空报告逐条核查 → 空间竞争与估值

**方法要点**：对被做空、争议大的公司，用上、中、下三篇组织首次覆盖：先理解业务，再做风险折价，最后估值。核心原则是“对于有估值溢价的公司，摸清风险比算成长更重要”；中篇的核查结论必须量化进下篇估值，否则系列会断裂。

**操作步骤 / 拆分口径 / 公式**：
1. 上篇：拆业务骨架与当前增长引擎（获客、信贷重资产与轻资产、技术平台），结尾留伏笔（如“会计确认法使业绩不能横向比较，易被高估”）；
2. 中篇：顺着做空机构的逻辑逐条核查“暗伤”（坏账率表内外腾挪、公允价值计法利润虚高、股权稀释），开宗明义说明“摸清风险比算成长更重要”；
3. 下篇：开头回顾前两篇结论，提出“拧巴的表象”（瑕疵多但估值溢价高）作为核心问题；从市场空间和竞争两个角度寻找合适的估值标尺；并把中篇核查结论（如20%利润粉饰）量化进估值；
4. 顺序：先理解业务 → 再做风险折价 → 最后估值（原计划的“下篇”可因内容扩充而变成中篇）。

**关键指标与数据来源**：无（结构方法）；各篇中的核查与估值数据见14.3.17、14.3.15。

**判断标准**：中篇的结论要在下篇估值中有量化落点（如打20%粉饰折价后的估值倍数）；中篇对“粉饰 vs 欺诈”要有定性。

**海豚案例**：
- SoFi系列：上篇《被浑水盯上的 SoFi：真金科新贵 or“高科技噱头”？》（2026-06-16）讲商业模式和业务逻辑（获客、信贷重资产和轻资产、技术平台），结尾留下“会计确认法使业绩不能横向比较，易被高估”的伏笔；中篇《竟是翻版“安然”！浑水博眼球 or SoFi 真烂？》（2026-06-17，原计划的“下篇”）用梳理浑水报告的方式具体呈现缺陷，并开宗明义说“对于有估值溢价的公司，摸清风险比算成长更重要”；下篇《槽点多多的 SoFi，“贵”得有理？》（2026-06-29）开头先回顾前两篇结论，提出“拧巴的表象”（瑕疵多但估值溢价高）作为核心问题，从市场TAM和竞争两个角度给出不同预期下的价值判断，并把中篇核查结论（如20%利润粉饰）量化进估值。
- 对照：AppLovin的做空事件文单篇处理（见14.3.17变体C），与其前作浑水点评对照（见14.4.10）。

**适用场景与注意事项**：适用于有做空报告或重大争议的首次覆盖；先排雷再估值；中篇的核查结论必须在下篇估值中有量化落点，否则系列文会断裂。

### 14.4.10 系列文与历史研究的组织：行业 → 技术 → 个股、产品 → 产业链、个股 → 行业横评

**方法要点**：用系列文分工降低单篇负担，并让历史研究成为跟踪档案：行业文铺垫原理，个股文直接做落地；产品端先讨论，后端产业链另文梳理；先写个股，再横向评比同行并给出行业整体判断；事件点评引用前作对比；文末附历史研究清单便于回溯观点演变。

**操作步骤 / 拆分口径 / 公式**：
1. 行业 → 技术路线 → 个股：先写行业文论证结构性矛盾，再写技术原理文，个股文直接做落地、不再复述原理；
2. 产品端 → 产业链：先讨论产品，后端产业链变化另文梳理，本篇声明“只谈产品端”；
3. 个股 → 行业横评：单个公司篇是系列之一，后续梳理其他同行，最后给出行业整体判断与公司偏好；
4. 事件点评引用前作对比：新事件与前作（如做空点评）对照，说明火力与可信度的变化；
5. 文末附历史研究清单（深度研究、财报点评、电话会纪要），回溯观点演变；预告更新全行业数据（如算力供需缺口）。

**关键指标与数据来源**：无（组织方法）。

**判断标准**：个股篇不重复行业篇的原理；横评系列最后要落到“行业整体判断 + 公司偏好”；历史清单要分类（深度 / 财报 / 纪要 / 热点）。

**海豚案例**：
- Bloom Energy《AI电荒破局：Bloom Energy是新解药？》（2026-07-20）：承接《AI竞赛终局：电力说了算？》（论证美国缺电是AI算力爆发与电网基建长期滞后的结构性矛盾）和《AI电荒突围：谁能替代重燃？》（SOFC技术原理），本篇直接做个股落地、不再复述原理。
- Meta《Muse 爆了，Meta 的真拐点还是假高潮？》（2026-09-23）：Muse篇先讨论产品，后端产业链变化另文梳理。
- Amazon《“AI拉胯”亚马逊：会上演逆袭大戏吗？》（2026-06-24）：云厂商AI能力系列之一，后续梳理其他云公司，最后给出行业整体判断与公司偏好；附《亚马逊电商终局猜想：零售的马甲，广告的魂？》等历史列表。
- Meta《过剩外租 vs 疯狂扩建，“精分”Meta 背后是明晃晃的“阳谋”？》（2026-07-10）：Meta算力租赁篇预告更新全行业算力供需缺口，附《算力死贵，Meta掀桌》等历史点评。
- AppLovin《Applovin：空头开年又整活，这次火力如何？》（2026-01-20）：事件点评对照前作浑水点评（评估攻击力时对比前作）。

**适用场景与注意事项**：搭建长期跟踪体系与系列研究；对比前作时要用同一指标口径，避免“前后矛盾”。

### 14.4.11 季度主线：财报点评 + 电话会纪要 + 深度文，文末附历史文章回溯（自建跟踪档案）

**方法要点**：对重点覆盖公司，以每季“财报点评 + 电话会纪要”成对发布为主线，热点与事件文做补充，深度文定期重估；每篇文末附“相关文章回溯”，按财报（点评与纪要成对）、热点、深度分类，列出日期和标题，形成连续的追踪链。事件文通常在前文结论上做增量，并可预告后续详细纪要。研究方法的本质是对同一标的保持季度级和事件级的连续记录，便于检验此前判断。

**操作步骤 / 拆分口径 / 公式**：
1. 季度主线：每季财报发布后同时产出点评与纪要；
2. 补充层：热点或事件文（异动、合作、融资、发布会）做增量，深度文定期重估；
3. 文末回溯：按财报（点评与纪要成对）、热点、深度分类，倒序列出日期与标题；
4. 连接判断：事件判断与过往财报中的关键问题连起来（如ASIC进展、客户结构、上季度指引、管理层表态），检验“是否兑现或偏离”；
5. 自建档案（建议字段）：日期｜类型（财报点评 / 纪要 / 深度 / 事件 / 发布会）｜当时核心判断｜指引与关键数字｜管理层表态｜本次预期 vs 实际｜下一次检验时点。

*变体 A：季度成对 + 深度回溯（Marvell、Meta、百度、博通）*；*变体 B：事件文承接前作框架与预判（腾讯、阿里、英伟达）*；*变体 C：时间倒序的完整档案（苹果）*。

**关键指标与数据来源**：各季度财报点评标题中的核心判断（如指引、AI收入占比、XPU量产节点）；历次财报关键结论；电话会管理层表态；发布会关注点；前后变化。

**判断标准**：每个新判断都要能与档案里的旧判断对照；回溯清单是“检验用的”，不是装饰；事件文的结论质量依赖前期跟踪的积累。

**海豚案例**：
- Marvell《迈威尔 Marvell：“贴钱”结盟谷歌，能“撬动”博通墙角吗？》（2026-08-20）：文末回溯2025-03至2026-05各季度的财报点评和纪要（如FY28 165亿美元收入指引、第二家XPU在FY28量产、AWS成为Celestial AI核心客户、对Alchip挑战的回应），以及2025年1月两篇ASIC深度。
- Marvell《Marvell：远期指引狂飙，究竟是「信心」还是「画饼」？》（2026-10-07）：承接《“贴钱”结盟谷歌》和上季财报“未上调ASIC指引”，文末回溯2025年8月到2026年8月共5个季度的点评和纪要。
- Meta《算力太贵，Meta 掀桌？》（2026-07-06）：文末回溯2025-12-01的深度。
- 腾讯（2026-01-26）：引用《火拼 AI 互联网（上篇）》的框架；阿里《阿里 800 亿融资…》（2026-08-24）：承接财报解读中的资金缺口预判；英伟达《英伟达 GTC…》（2026-03-17）：快评后预告详细纪要《英伟达（GTC 纪要）》；百度、博通：文末列出财报季的点评和纪要。
- 苹果《苹果：存储暴涨逼提价，折叠屏能救场吗？》（2026-09-10）：文末历史文章回溯按时间倒序串联每季度的财报点评、电话会纪要和发布会点评（2025年8月到2026年7月共11篇），包括《苹果：硬刚涨价，硬件老大的底气还能撑多久？》《苹果（纪要）：不再坚持“净现金中性”，新 Siri 将在今年推出》等；每篇新文章都放在连续的跟踪脉络中：上季度指引是什么、管理层说过什么（如不再坚持净现金中性、新Siri与谷歌合作），本次事件是否兑现或偏离。

**适用场景与注意事项**：通用于持续覆盖，适用于所有重点覆盖标的与搭建个股跟踪体系；建议在自己的研究中维护同样的跟踪档案，记录每次的预期和结论，方便事后检验；跟踪指标与催化剂本身见13.2、13.3。

### 14.4.12 事件分析接续季度财报点评、电话会纪要、投资者大会纪要的线索

**方法要点**：对覆盖公司持续写财报点评、电话会纪要、投资者大会纪要，事件发生时回溯纪要里的管理层线索，串成推断；文末附历次研究清单，方便追溯观点演变。事件文的结论质量依赖前期跟踪的积累。

**操作步骤 / 拆分口径 / 公式**：
1. 平时：每次财报与大会后记录管理层关于客户数、产品时间表、提价/需求的表述（见14.4.11的档案字段）；
2. 事件发生时：回溯这些线索，与事件信息对接（如管理层说过定制ASIC有2个大规模客户、连接类拿到首家大规模客户，合作公布后市场就把客户指向亚马逊）；
3. 串成推断：线索 + 事件 → 对客户、时间表、需求的判断；
4. 文末附历次研究清单，说明观点演变。

**关键指标与数据来源**：季度纪要中的客户数、产品时间表、提价/需求线索。

**判断标准**：线索与事件要在时间与内容上可对接；推断要写明“线索是什么、事件补了什么”；线索不足时降低结论强度。

**海豚案例**：
- 高通《抱上亚马逊大腿，高通 AI 第二曲线“稳了”？》（2026-09-09）：文末列出2026-02-05、04-30、06-25、07-30的财报点评和纪要（如“Q3是中国安卓的底部、定制ASIC新签一家大客户”“已启动双位数幅度的产品提价”“内存短缺手机厂商缩减生产计划”）；正文用“签约到收入的时间”推断首批出货形态，结合此前管理层关于定制ASIC有2个大规模客户、连接类拿到首家大规模客户的表述，把本次合作的客户指向亚马逊（事件文结构见14.3.17变体A）。

**适用场景与注意事项**：通用于持续覆盖；事件文的结论质量依赖前期跟踪的积累；没有前期档案时，不要硬做“线索串联”。

### 14.4.13 短评矩阵：把一个大主题拆成一组“一问一答”的短评

**方法要点**：对存储、AWS组网、Robotaxi、商业航天等大主题，海豚君会连续发出一组短评，每篇只回答同一主题下的一个子问题（为何、是什么、值不值、怎么收场），合起来构成该主题的知识矩阵，既为深度文提供铺垫，也方便后续引用。

**操作步骤 / 拆分口径 / 公式**：
1. 先列主题下的子问题树：现象（价格、事件）→ 机制（供给、需求、技术）→ 约束（扩产门槛、物理限制）→ 竞争格局 → 收场情景与跟踪信号；
2. 每个子问题一篇短评，遵循14.3.18的骨架；
3. 短评之间留引用关系（如从“内存墙”到“HBM与DDR”到“存力这局怎么收场”）；
4. 最后用一篇总括型短评给出情景与跟踪信号清单。

**关键指标与数据来源**：各篇的量化锚；见下列系列。

**判断标准**：每篇一问；系列整体覆盖“现象—机制—约束—格局—收场”；总括篇给出可跟踪信号。

**海豚案例**（以下为系列成员及每篇论证主线）：
