## 7.1 增长归因与成长阶段判断

> 本节导读：本节回答“这家公司的增长到底从哪里来、是真本事还是阶段性红利、现在处在成长曲线的哪个位置”。海豚君的做法是把成长拆成“行业 Beta + 份额 Alpha”并给每块业务定角色，再用剔除一次性因素的内生增速、客户数量与新需求来源、收入下滑的多层归因去检验增长质量，最后用成熟龙头的“终局参照系”和“ARPU 下降、收入与利润上升”的组合信号定位阶段。本节要与 3.2（收入驱动公式与量价拆分）、5.2（渗透率、份额与单位价值量）、6.1（竞争格局与份额动态）配合使用，结论再落到 7.2（扩张路径）和 7.3（第二曲线）。

**方法选择速览**

| 要解决的问题 | 优先使用的方法 | 小节 |
| --- | --- | --- |

### 7.1.1 成长拆为“行业 Beta + 份额 Alpha”，并为各业务定角色

- **方法要点**：在完成 TAM 与竞争分析之后，把公司成长归纳为一句公式——成长 = 行业红利（Beta）+ 市占率提升（Alpha），再给每块业务定一个角色（主力 / 辅助 / 估值看点），让角色直接决定估值时哪些业务计入核心预测、哪些只作为情绪溢价。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：成长 = 行业红利 Beta + 市占率提升 Alpha。
  1. 先完成行业空间（第 5 章）与竞争格局（第 6 章）的分析，明确行业本身在往哪个方向走、公司的份额在哪里；
  2. 把成长归纳成上面一句话，分别回答“行业红利有多大”“份额能提多少”；
  3. 给每块业务定角色：信贷类主业 = 基本面兜底；泛金融化业务（券商、支付、加密）= 辅助市占率提升；SaaS 等科技业务 = 科技属性强，但对基本面拉动非主力，是市场资金活跃时用来拉估值的看点；
  4. 按角色决定估值口径：兜底业务和份额提升业务计入核心预测，看点业务只作为情绪溢价，不压在基本面预测上。
- **关键指标与数据来源**：分业务收入贡献、分业务增速、各业务对估值的影响方式（计入基本面还是仅作溢价）；数据来自分部披露与财报。
- **判断标准**：能清楚说出“基本面由谁兜底、叙事由谁撑起”，才算角色划分成立；如果市场给的估值高于“兜底业务 + 份额提升”所能解释的部分，多出来的部分就是对“看点业务”的溢价，需要判断该溢价是否稳定依赖于市场风险偏好。这个划分帮助区分“基本面驱动”和“叙事 / 估值驱动”的业务。
- **海豚案例**：
  - SoFi《槽点多多的 SoFi，“贵” 得有理？》（2026-06-29）：标题即为“信贷兜底，泛金融 + SaaS 讲故事的 SoFi 贵不贵？”；成长 = 个贷行业红利 Beta + 市占率提升 Alpha；信贷 = 基本面兜底，泛金融化（券商、支付、加密）= 辅助市占率提升，SaaS = 科技属性强、但对基本面拉动非主力，是市场资金活跃时拉估值的看点。
- **适用场景与注意事项**：适用于所有多业务公司，尤其是“主业稳、副业讲故事”的金融科技、平台类公司。角色定位要在 TAM 与竞争分析之后做，否则容易凭印象给业务贴标签；角色不是一成不变的，业务做大后“看点”可能升格为“辅助”甚至“主力”，需要随披露更新。

### 7.1.2 增长来源归因的自我审视：渗透率差异修复红利 vs 真正抢份额

- **方法要点**：在论证完公司优势之后，主动反问“过去的高增长里有多少只是对手长期渗透不足的品类被修复的红利，而不是贴身肉搏抢来的份额”，以此识别风险、避免把阶段性红利当作永久壁垒。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把增长按品类 / 业务拆开，找出贡献最大的增量来源；
  2. 判断该来源是“对手长期渗透不足的品类”（红利）还是“和强对手正面竞争得来的份额”；
  3. 核对分品类份额变化，以及对手在该品类的投入；
  4. 反推风险：一旦对手大举进入该品类，增长将面临硬仗，把它写进结论部分的反方论证。
- **关键指标与数据来源**：分品类份额变化、对手在该品类的投入（资本开支、补贴、商品与履约布局）。
- **判断标准**：增长主要来自“自己禀赋最厚、对手最难啃”的增量，就说明公司吃到的是阶段性结构红利；对手一旦转身重投入，红利会收窄，增长需要转为真正的份额争夺。反之，如果在对手重兵布防的品类里仍能提升份额，才是更硬的 Alpha。
- **海豚案例**：
  - 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：沃尔玛崛起本质是吃到了杂货与全渠道这块自己禀赋最厚、亚马逊最难啃的增量蛋糕；随着亚马逊大举杀入杂货，未来三年有硬仗要打。
- **适用场景与注意事项**：适用于所有高增长公司，是结论部分必备的反方论证。与 6.1（份额动态）、13.1（风险识别与传导）联动使用；需要有分品类数据才能落地，否则只能做定性提醒。

### 7.1.3 剔除大客户流失看内生增速，并给出低于机构的保守 CAGR

- **方法要点**：对有大客户集中度的 B2B / SaaS 子业务，先看报表增速，再识别一次性冲击并采用剔除口径，结合新客户上线、大客户合作、宏观敏感性和竞争烈度，给出一个明确低于部分机构预期的中长期 CAGR，并据此决定该业务在整体成长叙事中的分量。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看报表增速（技术平台收入同比 -27%）；
  2. 识别一次性冲击：大客户（Chime）迁走、战略技术自主化；
  3. 采用管理层给出的剔除口径（+12%），并与上一季度（19%）对比，判断真实放缓幅度；
  4. 结合新客户上线数（13 个）和大客户合作（前三大电信运营商）判断能否缓解；
  5. 结合宏观敏感性（客户为中小金科，预算对利率敏感）与竞争烈度；
  6. 给出中长期 CAGR 15%，明确低于部分机构 20% 的预期；
  7. 给出结论：这类叙事“已过了无脑吹的阶段”，不作为支撑成长性的关键业务。
- **关键指标与数据来源**：技术平台收入同比、剔除大客户后增速（管理层披露）、新客户数、大客户合作情况。
- **判断标准**：剔除口径增速从 19% 降到 12%，说明即便排除大客户因素，增长也在放缓；新客户虽有 13 个上线，但在客户为中小金科、预算对利率敏感的背景下，难以快速填补缺口，因此中长期取 15% 而非机构的 20%。
- **海豚案例**：
  - SoFi《槽点多多的 SoFi，“贵” 得有理？》（2026-06-29）：Galileo（对标 Affirm、Block、Marqeta、Jack Henry）1Q26 收入 -27%，剔除 Chime 后为 +12%（4Q25 为 19%），2027 年后按 15% CAGR 预估，并明确不将其作为支撑成长性的关键业务。
- **适用场景与注意事项**：适用于有大客户集中度的 B2B / SaaS 业务。需警惕管理层“剔除口径”的美化，应同时看环比趋势；剔除之后的增速只回答“内生质量”，不等于未来的总增速，总增速要把客户流失带来的基数效应一起算进去。

### 7.1.4 用客户数量口径和新需求来源作为成长性信号

- **方法要点**：核心客户的供应链多元化难以避免时，公司成长性取决于能否拓展新客户和新需求来源，因此要把“公司披露的客户数口径”和“需求结构里各类需求占比”当作成长性信号来跟踪。
- **操作步骤 / 拆分口径 / 公式**：
  1. 跟踪公司披露的客户数口径（如 XPU 客户数），关注是否长期不变；
  2. 跟踪需求结构：云厂商、政企、主权云各占多少；
  3. 关注新客户的量产时间，确认新客户何时能转成收入；
  4. 与同类龙头对比其需求增量来源（如强调政企市场与主权云）。
- **关键指标与数据来源**：ASIC / XPU 客户数；新客户量产时间；需求来源结构（云 / 政企 / 主权）；财报与电话会披露。
- **判断标准**：客户数长期不变，市场就会担心竞争挑战和成长性；新客户数或新需求来源出现增量，才会推动信心回升。
- **海豚案例**：
  - 博通（2026-07-07）：财报仍是“六个客户”的口径，引发成长性担忧；对比英伟达一直强调政企市场和主权云的需求增量。海豚君建议博通争取更多客户和订单来推动信心回升。
- **适用场景与注意事项**：适用于客户集中的 B2B 科技公司。客户数口径本身可能被公司选择性披露，要同时看单客户收入规模和多代合作情况（参见 7.3.18）。

### 7.1.5 收入下滑的三层归因：行业结构、战略收缩、改造阵痛，加竞品核心数据资产对比

- **方法要点**：对某一收入线持续下滑的业务，不下笼统结论，而是拆成三个原因逐个配证据，并用竞品核心数据资产对比解释“为什么别人能接走预算”。
- **操作步骤 / 拆分口径 / 公式**：
  1. **行业结构**：品牌广告的基因遭遇效果化围剿，宏观和地缘不确定性下广告主追求可量化 ROI，预算从曝光导向流向转化导向；再用竞品优势矩阵对比：TikTok 有用户时长，Google 搜索有购买意图，亚马逊有购买行为数据，Meta 有 AI 广告技术（Advantage+、GEM）；X 平台的全链路转化效果偏弱，资源倾斜到 Grok 又拖慢了广告算法迭代；
  2. **战略收缩**：裁员（内容审核团队）和言论尺度放宽触碰品牌安全红线，引发品牌出走；2024 年广告同比下降 26% 至 17 亿美元，2023 年确认 38 亿美元商誉及无形资产减值，作为品牌资产流失的财务证据；
  3. **改造阵痛**：2026Q1 重构 AI 广告基建（自动投放、概率归因、Grok 风控、推荐融合），当季广告同比下降约 1 亿美元（-22.6%）至 3.4 亿美元，效果待观察；
  4. 逐条标明是周期性、结构性还是一次性因素，并说明各层的证据强度。
- **关键指标与数据来源**：广告收入同比、商誉减值、季度广告收入、竞品核心数据资产（用户时长、购买意图、购买行为数据、AI 广告技术）。
- **判断标准**：三层原因里，行业结构是外部大势，战略收缩是自身决策代价，改造阵痛是正在进行的修复；只有第三层有望在后续季度改善，前两层是中长期压力，因此改造效果“待观察”而不能提前乐观。
- **海豚案例**：
  - SpaceX《SpaceX：AI 烧钱不止…》（2026-06-30）：第二部分“作为底层数据源的 X 平台，为何广告收入持续承压下滑？”，按上述三层展开，并以 2024 年广告收入 -26% 至 17 亿美元、2023 年 38 亿美元商誉及无形资产减值、2026Q1 广告收入 3.4 亿美元（-22.6%）作为证据。
- **适用场景与注意事项**：适用于广告平台收入下滑诊断。要区分周期性、结构性和一次性因素；竞品优势矩阵要落到“数据资产”这一可比维度上，而不是泛泛说对手“更强”。

### 7.1.6 以成熟龙头为“终局参照系”定位公司所处阶段

- **方法要点**：选一个已经走完全程的龙头作为终局模式，把标的放到龙头历史时间轴上对应的阶段，由此判断剩余路径与空间；同时指出不同玩家可以从相反方向趋近同一终局。
- **操作步骤 / 拆分口径 / 公式**：
  1. 选定终局参照对象（如亚马逊），明确该龙头关键指标的历史轨迹（如 3P 订单 / GMV 占比随年份的变化）；
  2. 把标的当前指标（如 3P 订单占比）对应到龙头历史上的某一年，确定所处阶段；
  3. 以龙头后续路径推演标的的剩余路径与空间；
  4. 区分玩家的出发方向：先自营建心智再开平台，还是纯平台起家；
  5. 提示环境差异，避免机械套用。
- **关键指标与数据来源**：3P 订单 / GMV 占比、对应龙头历史年份。
- **判断标准**：标的指标已经接近龙头某个阶段，说明模式迁移已走到哪一步；不同玩家的“趋近终局”路径不同（自营建心智 → 开放平台变现流量，或 1P 锚价 + 3P 盈利），需要分别判断。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：SHEIN 通过全托管 + 半托管把 3P 订单占比干到近四成，相当于亚马逊 2013-14 年阶段，走“先自营建心智（时尚）、再开放平台变现流量”的老路。
  - 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：1P 负责锚价、履约、沉淀用户，3P 是盈利核心，“亚马逊走过后，现在轮到沃尔玛”。
- **适用场景与注意事项**：适用于处于模式迁移中的公司。终局参照需考虑市场环境与竞争差异，不可机械套用；对照年份只是定位工具，不等于时间表。

### 7.1.7 “ARPU 下降、收入上升、利润上升”组合：判断从“建网期”进入“收租期”

- **方法要点**：把 ARPU、收入、毛利率、经营利润率、EBITDA 利润率放在同一张图里追踪；如果单价下降而收入和利润同步爆发，说明商业模式从“先亏钱建网”进入“低成本收租”阶段，是规模经济的典型特征。
- **操作步骤 / 拆分口径 / 公式**：
  1. 同时拉出 ARPU、收入、毛利率、经营利润及利润率、EBITDA 利润率的时间序列；
  2. 检查“量增价降”的组合：用户扩张靠降价驱动，但利润率同步上升；
  3. 对照数据判断阶段：单价越来越低、利润越来越高，标志进入低成本收租阶段。
- **关键指标与数据来源**：
  - ARPU：2023 年 99 美元 / 月，2026Q1 降至 66 美元 / 月，降幅 33%；
  - 收入：约 39 亿美元至 114 亿美元；
  - 毛利率：28% 至 48%；
  - 经营利润：4.69 亿至 44.23 亿美元，利润率 12% 至近 40%；
  - EBITDA 利润率：41.4% 至 63%。
- **判断标准**：ARPU 下降本身不是坏事，只要收入和利润率同步上升，就说明降价换来的是规模经济和固定成本摊薄；若 ARPU 下降而利润率不升，则只是在以价换量，不能判定进入收租期。
- **海豚案例**：
  - SpaceX《Space X：天空之网…》（2026-06-15）：单价越来越低、利润越来越高，标志进入低成本收租阶段。
  - SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：星链毛利润两年 CAGR 125%，分部 EBITDA 利润率 63%。
- **适用场景与注意事项**：适用于网络型基础设施和订阅业务（电信、云、SaaS）的阶段判断。要确认利润率提升来自规模效应而非会计口径调整，可与 8.1（利润率、费用与回报率拆解）配合。

### 7.1.8 增长天花板修正：隐性用户 + “跨市场团队作战”

- **方法要点**：判断成长天花板时，先修正表观数据对覆盖面的低估，再看竞争模式本身是否决定了更高的上限。
- **操作步骤 / 拆分口径 / 公式**：
  1. 找出表观指标差距（如账户数远低于对手）的成因：①对核心用户的主动筛选（筛掉钱少的年轻小白）；②介绍券商终端用户未被展示（订单需求归于统一的机构账户）；
  2. 识别竞争模式：“跨市场团队作战”——各地具本地化优势的中小券商依赖该公司打通全球市场与资产、降低底层系统投入，公司借这些通道触达全球而非仅美国用户；
  3. 与对手的路径对比：不必像 HOOD 卷产品创新，也不必像 SCHW 重资产建投顾与门店；
  4. 综合判断天花板天然更高。
- **关键指标与数据来源**：直接账户数、介绍券商渠道规模、海外用户占比。
- **判断标准**：若账户数低是“主动筛选”而非“获客能力弱”，且存在未被统计的间接终端用户，则表观数据低估了真实覆盖；渠道型打法使公司的触达范围不受单一市场限制，天花板高于对手。
- **海豚案例**：
  - 盈透《盈透：将“极致效率”刻进 DNA 的交易扫地僧》（2026-09-22）：IBKR 账户数远低于 Robinhood，但因主动筛选核心用户、介绍券商终端用户未展示，加上跨市场团队作战模式，海豚君判断中长期“天花板不低”。
- **适用场景与注意事项**：适用于有隐性 / 间接用户的平台；需注意表观指标可能低估真实覆盖，同时要验证间接渠道的规模，避免把未经验证的“隐性用户”当作确定增量。与 7.4.5（盈透的战略二选一推演）一起看。

**本节速查清单**

- [ ] 是否把成长拆成“行业 Beta + 份额 Alpha”，并给各业务定了角色（兜底 / 辅助 / 估值看点）？
- [ ] 过去的高增长有多少来自对手长期缺位的品类（红利），有多少是真抢来的份额？对手进入后会怎样？
- [ ] 子业务增速是否剔除了大客户流失等一次性因素？剔除口径与上一季度相比趋势如何？是否给了保守 CAGR？
- [ ] 客户数量口径、新客户量产时间、需求来源结构是否在变化，还是长期不变？
- [ ] 收入下滑是否拆成了行业结构 / 战略收缩 / 改造阵痛三层，每层有无财务证据？
- [ ] 是否选了终局参照系，并把标的指标对应到了龙头的历史年份？是否提示了环境差异？
- [ ] 若是网络型 / 订阅业务，ARPU、收入、毛利率、经营利润率、EBITDA 利润率是否同图追踪，利润率是否同步上升？
- [ ] 表观用户指标低于对手时，是否检查了主动筛选和隐性用户对天花板的影响？

**A. 门店扩张**

### 7.2.1 开店天花板测算：商圈承载法

- **方法要点**：开酒店的本质是抢占优质商圈的物业资源，因此用“各线城市商圈数 × 单商圈可承载门店数”来估算品牌的中期开店上限。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：门店上限 = Σ（各线城市商圈数 × 单商圈可承载门店数）。
  1. 取各线城市商圈数（美团披露的各线商圈数，约 150 / 400 / 450 / 2000 个，依次对应一线 / 新一线 / 二线 / 三线及以下）；
  2. 结合调研设定单商圈承载数：一线城市商圈平均可承载 3 家亚朵，新一线、二线、三线及以下依次递减为 2.5、2、0.5 家（三线及以下以中小商圈为主，亚朵对商圈要求高，承载能力大幅下降）；
  3. 汇总：150×3 + 400×2.5 + 450×2 + 2000×0.5 = 3350 家，即中期主品牌及以上（不含轻居）的开店上限；
  4. 与当前门店数（1761 家）比较，得到剩余空间约 90%；
  5. 不同目标客群、不同单店模型的子品牌单独测算。
- **关键指标与数据来源**：商圈数（美团）、单商圈承载数（调研）、当前门店数。
- **判断标准**：上限与当前门店数的差距就是剩余空间；上限并非“必达”，需与客房份额法（7.2.2）交叉验证，并对照管理层开店指引（7.2.5）。
- **海豚案例**：
  - 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：商圈承载法得出主品牌及以上上限 3350 家，较当前 1761 家有约 90% 空间。
- **适用场景与注意事项**：适合依赖优质点位的线下连锁（酒店、高端餐饮、品牌零售）。承载系数是主观假设，需要调研支撑，并建议做敏感性；子品牌因客群和单店模型不同要单独算，不能套用主品牌系数。

### 7.2.2 开店天花板测算：客房份额法，并与商圈法交叉验证

- **方法要点**：第二种口径从行业总量出发——行业客房总量 × 增速 × 目标份额，得到门店数，并与商圈法对照，看两个结果是否落在同一量级。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：目标客房数 = 行业客房总量 ×（1 + CAGR）^ 年数 × 目标份额；对应门店数 = 目标客房数 ÷ 单店客房数。
  1. 取行业客房总量：中国饭店协会数据显示，2025 年中高端酒店客房总数约 420 万间；
  2. 取公司客房数：亚朵（不含轻居）18.8 万间，份额 4.5%；
  3. 设定行业增速：参考弗若斯特沙利文，假设 2025-2030 年中高端客房 CAGR 6%；
  4. 设定份额提升速度：亚朵份额从 4.5% 升到 6%（每年平均 +0.3pct，比过去 5 年平均每年 +0.5pct 放缓）；
  5. 得到对应 3152 家酒店，与商圈法的 3350 家交叉验证。
- **关键指标与数据来源**：行业客房数、公司客房数、份额、行业 CAGR、历史份额提升速度。
- **判断标准**：两种互相独立的口径（3350 家 vs 3152 家）结果接近，说明开店上限的量级可信；份额提升速度要参照历史节奏做适度折减，不应简单外推。
- **海豚案例**：
  - 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：客房份额法 3152 家 vs 商圈承载法 3350 家，两者相互验证。
- **适用场景与注意事项**：适合有行业总量数据的连锁业态。份额提升速度可以参照历史节奏打折；行业 CAGR 取自第三方机构，要注明来源与口径。

### 7.2.3 开店天花板测算：按每 10 万人门店密度对标

- **方法要点**：用“每 10 万人门店数”向更高密度区域对标，测算本土门店总量天花板，再与公司自下而上的开店口径交叉验证。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：门店总量 = 目标密度（店 / 10 万人）× 总人口 ÷ 10 万；增量 = 总量 − 当前门店数。
  1. 取当前密度：北美约 5 店 / 10 万人；
  2. 情景一：向中高密度州靠拢（6.5 店 / 10 万人）→ 美国门店总量约 2.18 万家，增量约 +4900 家；
  3. 情景二：对标最高密度的加州（7.8 店 / 10 万人，理由：小店业态大幅降低了单点位成立门槛）→ 总量约 2.61 万家，增量约 +9300 家；
  4. 与公司自下而上口径交叉验证：自营再开约 5000 家至约 2.2 万家，含授权最多再开 1 万家，两者基本吻合。
- **关键指标与数据来源**：每 10 万人门店数、分州密度、总人口、公司开店目标。
- **判断标准**：自上而下（密度对标）与自下而上（公司口径）测算基本吻合时，空间结论更稳；选哪个密度作为对标上限，要说明理由（如小店业态降低点位门槛）。
- **海豚案例**：
  - 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：北美约 5 店 / 10 万人，向中高密度州靠拢增量约 +4900 家，对标加州增量约 +9300 家，与公司口径（自营再开约 5000 家、含授权最多再开 1 万家）吻合。
- **适用场景与注意事项**：适用于连锁餐饮、零售、健身、便利店等的开店天花板测算；需考虑店型变化（如小店）对密度上限的影响。算出空间后必须接 7.2.5，用管理层的实际开店节奏判断这是“短期驱动”还是“中期期权”。

### 7.2.4 开店上限 + 剩余空间 + 拓店摩擦，并把开店指引换算成门店增速

- **方法要点**：沿用深度报告里的门店上限测算，与当前门店数比较得到剩余空间，再加入开店摩擦因素判断增速放缓是否大概率，最后把次年开店指引换算成门店数增速，作为次年收入增长的主要底座。
- **操作步骤 / 拆分口径 / 公式**：
  - 公式：门店增速 = 次年新开门店指引 ÷ 当前门店数。
  1. 引用深度报告的门店上限（乐观上限 / 中性两档），与当前门店数比较，得到剩余空间；
  2. 加入开店摩擦：高线城市租金和点位竞争、拿铺到物业协调周期更长，判断门店增速放缓是否大概率；
  3. 把公司次年新开门店指引换算成门店数增速，作为次年收入增长的主要底座。
- **关键指标与数据来源**：门店上限（乐观 / 中性）、当前门店数、新开门店指引、门店增速。
- **判断标准**：当前门店数已接近乐观上限的相当比例、且向高线城市拓展面临摩擦时，门店增速放缓是大概率；指引换算出的门店增速是收入增长的“底座”，同店和新店爬坡再叠加其上。
- **海豚案例**：
  - 鸣鸣很忙（2026-04-01）：引用深度《从万店很忙到万品很忙，是陷阱还是馅饼？》，乐观上限 3.5 万家；当前约 2.2 万家，2026 年起门店增速放缓大概率；2026 年新开 5000 家的指引对应约 22% 的门店增长。
- **适用场景与注意事项**：适用于连锁扩张型公司。上限测算依赖渗透率和单店覆盖人口假设，使用时要标明是乐观上限还是中性上限。

### 7.2.5 对比理论开店空间与管理层开店指引：判断是“中期期权”而非短期驱动

- **方法要点**：测出理论空间后，必须对照管理层实际指引的节奏，把空间转化为年度收入贡献，从而识别哪些逻辑是短期驱动、哪些只是期权。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取管理层的开店指引节奏：美国直营中期（2028 年）每年仅约 400 家量级；
  2. 与理论空间对照：相对 5000-10000 家潜在空间，需十余年才能填满，说明管理层优先跑通小店模型、打磨单店回报与运营流程，而非激进抢跑；
  3. 量化对收入的贡献：每年约 400 家净开店 + 新店爬坡 + 小店单店销售额偏低 → 年度收入增量仅 1%-2%；
  4. 下结论：在公司上调开店指引之前，该业态扩张属于中期价值期权，短期难成业绩核心驱动。
- **关键指标与数据来源**：年净开店数指引、新店爬坡、单店销售额、开店对收入的贡献。
- **判断标准**：空间 ÷ 年开店数 = 填满所需年数；若需十余年、且年度收入增量仅 1%-2%，则不应在短期估值中给予大幅溢价；上调开店指引才是改变判断的催化剂。
- **海豚案例**：
  - 星巴克《星巴克：狼狈出走中国，咖啡之王靠美国能东山再起吗？》（2026-09-10）：美国直营 2028 年每年约 400 家净开店，对应年度收入增量 1%-2%，北美小店扩张在上调开店指引前只是中期价值期权。
- **适用场景与注意事项**：适用于所有“空间很大”的成长逻辑。要与 7.2.3 配合使用，先测空间、再看节奏；管理层指引也要打折验证，参见 8.5（管理层指引解读与可达成性验证）。

### 7.2.6 全球连锁门店数横向排位 + 分市场“饱和 vs 增量”定性

- **方法要点**：先把公司门店数放进全球连锁排位，建立规模直觉，再按区域拆分并定性每个市场是“存量提效”还是“增量扩张”，据此判断资本开支和经营模式的差异。
- **操作步骤 / 拆分口径 / 公式**：
  1. 全球排位：星巴克约 4 万家，与麦当劳约 4.4 万家并肩，超赛百味约 3.7 万家、肯德基逾 3 万家，仅次于蜜雪冰城约 4.7 万家；
  2. 区域拆分：美国约 1.7 万家、中国约 8 千家，合计占六成以上；
  3. 定性市场性质：美国成熟饱和、直营为主，增长转向门店体验与同店；中国是唯一具长期大规模扩张空间的增量市场，但全直营资本开支压力大；
  4. 判断资本模式：2026 年与博裕合资交割后中国业务全部转为特许经营，由合作方承担下沉拓店资金。
- **关键指标与数据来源**：全球门店数、分区域门店数、直营 / 授权结构。
- **判断标准**：成熟饱和市场的增长看同店和门店体验；增量市场的增长看开店，但要匹配资本开支能力，必要时通过特许经营 / 合资让合作方出资。
- **海豚案例**：
  - 星巴克《星巴克：“披着咖啡外衣的银行”，凭何称霸全球四十年？》（2026-07-21）：全球门店排位（约 4 万家）、美国约 1.7 万家 / 中国约 8 千家，美国饱和、中国增量，中国与博裕合资交割后转为特许经营。
- **适用场景与注意事项**：适用于连锁零售 / 餐饮；不同区域应分别判断“存量提效”还是“增量扩张”，不能用全球均值笼统判断。

### 7.2.7 开店节奏与同店表现的权衡，以及轻资产加盟比例对冲 RevPAR 波动

- **方法要点**：同店 RevPAR 承压时，放慢签约和开业、把资源用于筛选储备项目是理性选择；中长期应对低线城市供给增加、存量定价权被侵蚀，需要提高轻资产加盟比例，降低 RevPAR 波动对自身利润的影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看净开店节奏（对比去年同期）与同店 RevPAR 同时变化；
  2. 判断：同店承压时盲目开店会让新店和存量店互相蚕食，放慢开店更理性；
  3. 看加盟 / 直营结构，评估提高轻资产加盟比例对冲 RevPAR 波动的空间（参照华住）。
- **关键指标与数据来源**：净开店、同店 RevPAR、加盟 / 直营结构。
- **判断标准**：同店 RevPAR 下滑时，如果开店节奏同步放缓，说明管理层在保护存量店经营质量；若仍以高速度开店，则要警惕新店与存量店互相蚕食。
- **海豚案例**：
  - 亚朵（2026-08-21）：二季度净增 87 家，比去年同期慢；亚朵主品牌 1611 家加盟 + 13 家直营；同店 RevPAR -3.0% 时放慢开店更理性；和华住一样，只能提高轻资产加盟比例。
- **适用场景与注意事项**：适用于酒店、连锁餐饮等加盟型连锁。加盟比例提高并不会消除同店下滑，只是降低 RevPAR 波动对公司利润的传导，需结合 7.2.9 的加盟商回报判断开店意愿。

### 7.2.8 用最高密度区域的历年同店表现，检验门店加密是否必然蚕食同店

- **方法要点**：市场常担心“加密开店 → 同店下滑”，海豚君用公司门店最密、竞争最卷、渗透率最高的大本营区域的历年同店表现来检验该担忧是否成立。
- **操作步骤 / 拆分口径 / 公式**：
  1. 选出公司门店密度最高、渗透率最高的大本营区域；
  2. 拉取该区域历年同店增速，扣除极端年份（如全行业极限价格战）；
  3. 判断：若除极端年份外每年同店都在增长，说明门店密度增加带来的更多是供应链、单位配送成本和品牌心智的正向加成，真正决定同店的是产品力。
- **关键指标与数据来源**：大本营区域历年同店增速、门店密度。
- **判断标准**：密度最高的区域同店仍然持续增长（极端行业年份除外），就可以反驳“加密必然蚕食同店”的担忧；同店下滑的主因应去找产品力、价格战等因素。
- **海豚案例**：
  - 古茗《古茗：补贴退坡，茶饮界 Costco 依然稳健！》（2026-03-26）：浙江（门店最密、竞争最卷）除 2024 年（全行业极限价格战）外每一年同店都在增长。
- **适用场景与注意事项**：适用于区域加密型连锁，需要区域层面的调研数据。注意排除行业性冲击年份，且大本营区域的结论是否能外推到新进入区域要另行验证。

### 7.2.9 用加盟商投资回报 + 新签来源结构，判断子品牌扩张目标

- **方法要点**：站在加盟商的角度评估子品牌的吸引力：单店投资、回本周期、品牌溢价、运营成本，再看新签项目里“老加盟商复购”的占比，用来判断管理层扩张目标能否达成。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列优势：总投资比全季低 20-30%，面积门槛低、改造难度低、采用模块化装配，对持有小面积或不规整物业的加盟商更友好；
  2. 列劣势：品牌势能弱，在次优位置和下沉市场拿不到主品牌的 ADR 溢价，单房运营成本又略高于全季，回本周期更长；
  3. 看新签来源：调研显示轻居新签项目超过 50% 来自亚朵老加盟商复购，说明对新加盟商的吸引力有限；
  4. 结论：在单店模型明显改善之前，轻居只能作为主品牌的补充（吸引物业不达标、“退而求其次”的意向投资者）；
  5. 对照管理层目标：短期因低基数加公司支持仍能较快开店，但公司 2025-2030 年新增 800-1000 家的目标（每年约 200 家，占新增门店 50% 以上）难度较大。
- **关键指标与数据来源**：单店总投资、回本周期、ADR 溢价、单房运营成本、新签中老加盟商占比。
- **判断标准**：老加盟商复购占比高，说明对新加盟商吸引力不足、扩张更多是存量客户内部转移；单店模型（回本周期、ADR 溢价）没有明显改善前，管理层的高增速目标难以兑现。
- **海豚案例**：
  - 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：轻居新签超过 50% 来自老加盟商复购，判断 2025-2030 年新增 800-1000 家（每年约 200 家）的目标难以达成。
- **适用场景与注意事项**：适合加盟品牌扩张目标的验证。新签结构是很好的领先指标，但需要调研数据；与 4.2（投资回报、回本周期与客户经济性）互为补充。

### 7.2.10 “先仓后店”扩张逻辑：轻节点探测需求密度 → 重资产放大

- **方法要点**：对比传统的“先开店 → 积累周边用户 → 再做线上”，识别反向流程：先铺极速达和云仓，在线上建立认知与消费习惯，再用门店承接更高阶体验与更大规模销售。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别公司是否先铺极速达和云仓，作为轻节点探测区域真实需求密度；
  2. 看门店是否在需求被“养熟”后才落地，缩短门店培育周期；
  3. 判断好处：用极低成本测试区域真实需求，避免盲目开店，扩张胜率更高；
  4. 验证云仓本身的盈亏。
- **关键指标与数据来源**：云仓先行区域、门店培育周期。
- **判断标准**：若开店时周边用户已被线上养熟、新店爬坡更快，说明“先需求渗透、后重资产落地”真正降低了试错成本；若云仓本身长期亏损，则成本只是转移而非节省。
- **海豚案例**：
  - 山姆《沃尔玛里的“Costco”…》（2026-06-09）：山姆把“先供给、后验证需求”改造为“先需求渗透、后重资产落地”，类似泡泡玛特开店前用机器人店探路。
- **适用场景与注意事项**：适用于连锁零售扩张分析；需验证云仓本身的盈亏。

**B. 品类扩张**

### 7.2.11 品类扩张评估：低周转品类 vs 鲜食短保品类，看对频次、存货周转和毛利率的影响

- **方法要点**：评估社区折扣化的品类扩张时，不只看 SKU 扩张速度，而是按周转属性分组，看对购买频次、存货周转和毛利率的影响，在“频次提升”与“毛利率把控”之间权衡。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把新增品类按周转属性分组：日化、米面粮油等低周转品类，鲜食和短保品类；
  2. 看各组的实际表现：低周转品类表现不理想；鲜食和短保品类能提升购买频次和流量，但大幅提升不易；
  3. 判断：克制的品类扩张更容易掌控存货周转，从而控制毛利率；
  4. 在频次提升和毛利率把控之间权衡，而不是只看 SKU 扩张速度。
- **关键指标与数据来源**：品类结构、购买频次、存货周转天数、毛利率。
- **判断标准**：新品类若拖低整体周转、拉低毛利率，则扩张得不偿失；鲜食 + 短保能带来频次，但要承受更高的周转管理难度，整合后竞对较弱时毛利率仍有把控力。
- **海豚案例**：
  - 鸣鸣很忙（2026-04-01）：新的日化、米面粮油等低周转品类表现不理想，扩品类将集中于鲜食 + 短保；单店购买频次可能提升但大幅提升不易；整合后竞对较弱，毛利率仍有较好把控力。
- **适用场景与注意事项**：适用于零售业态扩张分析（量贩零食、折扣超市、便利店）。需与 4.3（成本结构、降本路径与经营杠杆）联动，核对存货周转与毛利变化。

### 7.2.12 新产品选择三问：需求是否刚性、壁垒能否防同质化、是否匹配自身优势

- **方法要点**：复原公司当年“为什么做某个产品”，用三个标准判断其是不是好切入点；这套标准也可以反过来检验公司今天切入的新品类。
- **操作步骤 / 拆分口径 / 公式**：
  1. **有需求**：产品是下游整机必需的部件，国内没人能做，进口价高，属于卡脖子环节，而且下游行业已经成长起来，形成硬需求；
  2. **有壁垒**：产品有一定技术和生产门槛，不容易陷入同质化价格战，符合公司战略定位；
  3. **匹配优势**：相对海外品牌，公司的优势是成本，这有利于抢份额；
  4. 三项都满足才算好的切入点；
  5. 反向检验：把同样三问用在公司今天切入的新品类（机器人执行器、数据中心液冷）上，看是否也满足需求刚性、壁垒适中、匹配自身能力。
- **关键指标与数据来源**：下游需求规模和增速；进口依赖度和进口价格；技术和生产壁垒；公司相对海外龙头的成本优势。
- **判断标准**：三问全部满足才是好切入点；缺一项（如需求尚未形成，或壁垒太低陷入价格战，或与自身优势不匹配）就要降低对该品类的预期。
- **海豚案例**：
  - 三花智控《三花智控：生意不起眼，凭什么总能抓住风口？》（2026-01-02）：1987 年开发两位三通电磁阀的考量是冰箱必需、进口贵、国内冰箱产业已有硬需求、有技术壁垒不易同质化、成本优势利于获取份额，最终打破日本企业垄断。
- **适用场景与注意事项**：适用于判断国产替代型制造企业的新品类扩张是否靠谱，前提是能讲清下游需求和竞争格局；对纯技术驱动、需求尚未形成的品类适用性较弱。

### 7.2.13 新品类成功四步拆解：赛道选择 → 品类切入点 → 产品创新 → 营销种草

- **方法要点**：把一个新品类（第二曲线）的成功拆成四个环节，每一环用第三方数据或结果数据验证，复盘其成功是否可复制。
- **操作步骤 / 拆分口径 / 公式**：
  1. **赛道**：用权威白皮书量化需求（睡眠时长、睡眠困扰比例及趋势）；
  2. **切入点**：用第三方调研找出消费者认为影响最大的单品；
  3. **产品创新**：对比行业传统产品参数，指出其未触及核心矛盾（动态适配），再说明新品的功能设计（分区承托、控温面料）；
  4. **营销**：在内容平台围绕场景与人群投放，邀请头部 KOL 形成“种草 - 拔草”的 UGC 传播；
  5. 以结果数据（上市后多久冲到品类第一）验证。
- **关键指标与数据来源**：人均睡眠时长、睡眠困扰比例、品类第一用时、KOL 投放。
- **判断标准**：赛道需求有权威数据支撑、切入点有第三方调研背书、产品对准未被满足的核心矛盾、营销形成自传播闭环，并有“品类第一用时”这类结果数据验证，才算完整的成功路径。
- **海豚案例**：
  - 亚朵《亚朵：酒店界“海底捞”…》（2026-01-13）：《2025 中国睡眠健康研究白皮书》显示人均夜间睡眠 6.9 小时、65% 人群每周 1-2 次睡眠困扰；沙利文调研显示枕头对睡眠影响最高；深睡枕 Pro 采用三区设计 + 凉感纤维与吸湿排汗层，9 个月冲到全平台品类第一；在小红书邀请李诞、papi 酱、鲁豫等做“深睡体验官”。
- **适用场景与注意事项**：适用于消费品新品类 / 大单品分析；需警惕单一爆品生命周期风险。

### 7.2.14 大单品驱动模式：识别支柱品类后集中测算，再外推品类扩张

- **方法要点**：判断零售业务属于标准的大单品驱动模式后，按帕累托原则集中测算支柱品类，其他品类用“再造一个十亿级品类”等假设外推，给出中期规模。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别支柱品类及其 GMV 占比：枕头和被子是支柱，GMV 占比超过 80%；
  2. 判断增长路径：在枕头和被子基础上向深睡床垫、床笠、睡衣等全场景睡眠产品扩展，培育更多大单品；
  3. 集中测算枕头和被子；
  4. 其他品类用“再造 1 个 10 亿级品类”或“培育 2-3 个 10 亿级单品”的假设外推；
  5. 得出中期零售 GMV 有望突破 100 亿元。
- **关键指标与数据来源**：品类 GMV 占比、单品 GMV。
- **判断标准**：支柱品类占比超过 80% 说明集中度极高，既是增长抓手，也意味着对单一品类的依赖；外推部分是假设，应与 7.2.13 的成功要素一起判断可复制性。
- **海豚案例**：
  - 亚朵《亚朵：酒店圈粉、零售提款，酒店界小清新还能笑多久？》（2026-03-04）：枕头和被子 GMV 占比超过 80%，中期零售 GMV 有望突破 100 亿元。
- **适用场景与注意事项**：适合大单品驱动的消费品牌，按帕累托原则集中测算头部品类。外推的“十亿级品类”假设为主观设定，需要标明并做情景。

### 7.2.15 以消费频次数据论证“高频品类切入”战略

- **方法要点**：面对看似“反电商”的品类（低毛利、重履约、强时效、冷链复杂），用消费频次数据揭示其战略价值——掌握最稳定、最重复、最刚需的消费触点；再用线下品类份额证明公司在该品类的统治地位，说明线上化本质是存量高信任用户的迁移，获客与信任成本极低。
- **操作步骤 / 拆分口径 / 公式**：
  1. 用第三方频次数据比较品类：杂货每周购物次数 vs 服饰家居电子等的每月次数；
  2. 说明公司在该品类线上的切入顺序与范围（如早期线上只上线生鲜食品日用）；
  3. 用线下品类市场份额证明统治地位；
  4. 说明线上化的本质是存量高信任用户的迁移；
  5. 配合高毛利品类变现。
- **关键指标与数据来源**：品类周均购物频次、品类线下市场份额。
- **判断标准**：品类频次高 + 公司线下份额高 → 线上获客与信任成本极低，是战略性切入点；但高频品类线上本身盈利难，需靠高毛利品类变现。
- **海豚案例**：
  - 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：Statista 数据显示美国消费者每周 1.6 次杂货购物，而服饰、家居、电子大多每月 1-2 次；2021 年前沃尔玛电商仅上线生鲜食品日用；沃尔玛杂货全美份额约 21%，是 Kroger、Costco 的一倍以上，亚马逊（含 Whole Foods）不到 2%；杂货长期贡献沃尔玛美国营收 60% 以上。
- **适用场景与注意事项**：适用于拥有线下高频品类优势的零售商；高频品类线上盈利难，需配合高毛利品类变现（如 7.1.6 中沃尔玛的 3P 是盈利核心）。

**C. 区域扩张**

### 7.2.16 比较不同国家的基础设施条件，判断产品在哪个市场更有价值

- **方法要点**：同一产品在不同国家的价值不同，取决于当地替代方案的成本与质量，据此判断目标市场的优先级和天花板。
- **操作步骤 / 拆分口径 / 公式**：
  1. 比较各目标国家的替代方案条件：地面宽带覆盖率、宽带价格、人口密度、基建成本；
  2. 判断产品价值：美国地广人稀、基础设施缺乏、光纤基建成本高、运营商垄断导致宽带费用高，所以卫星通讯在美国比在中国更有价值；
  3. 据此排序目标市场优先级，估计各市场天花板。
- **关键指标与数据来源**：地面宽带覆盖率、宽带价格、人口密度、基建成本。
- **判断标准**：替代方案越贵、越差、越难铺设的地区，新产品的价值越高、渗透意愿越强。
- **海豚案例**：
  - SpaceX《马斯克再甩“王炸”…》（2026-02-24）：相对于中国，卫星通讯网络在美国显得更有价值。
- **适用场景与注意事项**：适用于出海、区域扩张类公司的市场选择分析。

### 7.2.17 海外子市场体量对标与本土竞品失败归因

- **方法要点**：用多个参照物刻画区域业务体量与增速，再列出本土同类模式竞品并归纳其失败环节，提出模式成功的苛刻条件，从而引出公司“做对了什么”。
- **操作步骤 / 拆分口径 / 公式**：
  1. 用多个参照物刻画区域业务体量：占所在国集团营收比例、相当于几个本土龙头、是同类外资竞品的几倍，并给出增速；
  2. 列出本土同类模式竞品，归纳其失败环节（供应链、商品力、会员心智任一环失守）；
  3. 提出模式成功的苛刻条件：全球采购精选 + 本土爆品研发 + 大包装与即时配送矛盾的调和；
  4. 回到公司，说明其做对了什么。
- **关键指标与数据来源**：区域销售额、门店数、占集团区域营收比例、增速、竞品倍数。
- **判断标准**：区域业务以少量门店贡献大比例营收，且体量对标本土龙头和外资竞品都具优势，说明模式适配；本土竞品失败的共性（供应链、商品力、会员心智任一环失守）正是模式门槛所在。
- **海豚案例**：
  - 山姆《沃尔玛里的“Costco”…》（2026-06-09）：2025 年山姆中国销售额突破 1400 亿元，仅 63 家门店贡献沃尔玛中国 80% 以上营收，体量约等于两个大润发，是 Costco 中国的 14 倍，千亿基数上增速接近 40%；盒马 X 会员店、永辉仓储店、大润发 M 会员店等相继败退。
- **适用场景与注意事项**：适用于跨国公司区域业务；区域数据常为非正式披露，需注明来源。

**A. 评估：第二曲线是否成立**

### 7.3.1 第二曲线增速对比 + 主业拓展天花板判断

- **方法要点**：用分业务 CAGR 对比（新业务 vs 主业）识别第二曲线，并论证主业为什么无法承担扩张任务，从而说明转型的必要性。
- **操作步骤 / 拆分口径 / 公式**：
  1. 拉出新、旧业务各自的收入 CAGR 做对比；
  2. 论证主业的拓展天花板：核心能力是为某一垂直品类“长”出来的（版型、面料、产业带、算法都绑定该品类），自营拓品很难；核心市场渗透进入瓶颈；
  3. 由此说明转型 / 发展第二曲线的必要性；
  4. 同时看新业务占总体收入的比例，判断其是否已成为实质性的第二曲线。
- **关键指标与数据来源**：分业务收入 CAGR、主业用户渗透度、第二曲线占比。
- **判断标准**：新业务增速远高于主业、占比提升，而主业核心市场渗透已近瓶颈、自营拓品困难，则第二曲线成立；第二曲线需看利润贡献而非仅看增速。
- **海豚案例**：
  - SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：3P 服务收入 2023-2025 年从 8.7 亿增至 47.4 亿美元，CAGR 133%，1P 期间增速仅 9%；欧美核心市场渗透进入瓶颈，柔性供应链绑定服装难以自营拓品。
  - 亚朵《亚朵：酒店界“海底捞”…》（2026-01-13）：零售 2019 年不到 1 亿元，到 2024 年 22 亿元、占比 30%，成为第二曲线。
- **适用场景与注意事项**：适用于多业务公司；第二曲线需看利润贡献而非仅看增速，高增速低基数的业务要警惕“占比小、拉动弱”。

### 7.3.2 新业务早期评估四要素：流量场规模、收费模式、作用对象、战略价值

- **方法要点**：对新推出的业务，从四个角度做早期评估，再结合调研判断其所处阶段。
- **操作步骤 / 拆分口径 / 公式**：
  1. **流量入口规模**：与成熟流量场比较（例如 Shop App 的自然流量和 Facebook、Google、TikTok 不可比）；
  2. **收费方式**：定向折扣、成交后才收费等；
  3. **实际作用**：只能激活存量用户、提高下单频次，还是能触达新用户；
  4. **战略意义**：补上流量入口、降低外部依赖，从支付变现走向广告变现，空间可能数倍于现有规模；
  5. 结合调研判断进展阶段（绝对早期）。
- **关键指标与数据来源**：新业务流量规模、收费模式、调研进展。
- **判断标准**：规模暂时不可比、阶段处于绝对早期时，要看“方向是否正确”和“战略意义能否放大现有变现空间”，而不是用短期收入判断成败。
- **海豚案例**：
  - Shopify Campaigns（2026-08-06）：以 Shop App 为流量场，进展仍在绝对早期，但方向正确。
- **适用场景与注意事项**：任何公司的第二曲线 / 新业务评估均可使用。

### 7.3.3 新业务板块化拆解：能力来源（收购 vs 自研）、客户、收入阶段

- **方法要点**：把公司的新业务战略拆成若干板块，逐一标注能力来源、已确认大客户、收入阶段，分清哪些收入是“买来的”、哪些是真正孵化的，哪些短期就能贡献、哪些还要等。
- **操作步骤 / 拆分口径 / 公式**：
  1. 按产品拆板块；
  2. 每个板块标注三项：能力来源（收购来的还是自研）、已确认的大客户、收入阶段（已量产 / 有订单无收入 / 采样期 / 量产时间）；
  3. 汇总：哪些收入已经在、哪些只有订单、哪些仍在采样。
- **关键指标与数据来源**：板块、能力来源、大客户、产品时间表、收入状态。
- **判断标准**：能力来自收购的板块通常更早贡献收入；自研板块只有客户和订单、没有收入时，需要等量产节点；对大客户的签约覆盖面（如四大 CSP 签下几家）反映商业化进度。
- **海豚案例**：
  - 高通《抱上亚马逊大腿…》（2026-09-09）：数据中心四板块——①单一客户定制 ASIC（来自 Alphawave）；②通用客户标准 AI 加速器（自研，AI250 / HBC 2027 年中商用采样，大客户微软）；③服务器 CPU（来自 Nuvia，C1000 2028H2 量产，大客户 Meta）；④连接（光 DSP / SerDes，来自 Alphawave，已量产，1.6T 有望 2026—2027 年推出）；自研加速器只有客户和订单，还没有收入；四大 CSP 签下三家（微软、Meta、亚马逊）。
- **适用场景与注意事项**：适用于传统公司转型新赛道时的第二曲线评估；与 7.3.18（进度表）配合形成静态拆解 + 动态跟踪。

### 7.3.4 新赛道参与度三维评估：产品能力、供应链层级与直接 / 间接关系、收入体量

- **方法要点**：评估公司在新赛道到底参与多深，防止把概念当兑现。
- **操作步骤 / 拆分口径 / 公式**：
  1. **产品**：基于底层原理一致，公司能提供哪些部件（泵、阀、换热器、微通道液冷板）；
  2. **供应链环节**：目前通过特灵、大金等一二级供应商间接供应海外数据中心巨头，与终端巨头大概率缺少直接接触；
  3. **收入体量**：2024 年数据中心液冷相关收入超 10 亿元；
  4. 综合判断为“已有一定收入体量，但主要供应零部件，战略和行动都还算不上积极和领先”。
- **关键指标与数据来源**：可供应产品清单；直接客户与终端客户；相关收入体量（2024 年超 10 亿元）；占所属业务收入比例。
- **判断标准**：看三件事——产品能做什么、在产业链的第几层（直接还是间接）、已有多大收入；只有产品能力而无直接客户与明显收入，就只能认定“参与了但参与得不多”。
- **海豚案例**：
  - 三花智控《三花：AI 机器人时代…》（2026-01-08）第一部分第一节第 4 点和小结：数据中心布局评估结论为参与了但参与得不多。
- **适用场景与注意事项**：适用于判断供应链公司新业务的成色。收入数据常不单独披露，需要从管理层交流或调研获取。

### 7.3.5 用客户基础差异解释不同新赛道的布局进度，并做机会与障碍的正反论证

- **方法要点**：同样是大市场，公司在 A 赛道积极、在 B 赛道落后，直接原因往往是客户基础不同；在此基础上做机会与障碍的正反论证，判断新业务的推进优先级和胜率。
- **操作步骤 / 拆分口径 / 公式**：
  1. 解释进度差异：机器人领导者是特斯拉，双方深度绑定，切入顺畅；数据中心领导者是英伟达，双方没有合作基础，英伟达供应链又相对封闭；
  2. 列机会：①以 Google 为首的 ASIC 阵营形成独立于英伟达的新供应链，更开放，只要产品稳定安全就有机会进入；②国产算力兴起带来国内液冷需求；③研发制造能力不缺，系统级产品的壁垒更多是时间问题；
  3. 列障碍：更大的威胁来自中国大陆对手（英维克等已与英伟达、Google 建立合作，部分还是三花的客户），能分到多少存在不确定性。
- **关键指标与数据来源**：龙头客户合作基础；供应链开放度；先行竞争者的客户关系；客户与竞争对手重叠。
- **判断标准**：客户基础决定切入速度；供应链是否开放决定可进入性；先行者的客户关系和与自身客户的重叠决定分到蛋糕的概率。
- **海豚案例**：
  - 三花智控《三花：AI 机器人时代…》（2026-01-08）第四部分：解释数据中心布局为何不及机器人，指出 Google ASIC 和国产算力的机会以及英维克等先行者的竞争。
- **适用场景与注意事项**：适用于多业务公司判断新业务推进优先级和胜率。要注意客户同时是竞争对手时的关系风险。

### 7.3.6 借用海外成熟商业模式类比，拆解新业务并评估资源占用

- **方法要点**：公司推出新业务时，用海外成熟模式类比定位，拆解价值链分工、定价逻辑、选品策略和目标市场，再评估投入规模对集团利润、资金和管理精力的占用以及对股东回报的影响。
- **操作步骤 / 拆分口径 / 公式**：
  1. 类比定位：如商超自营品牌 Costco Kirkland；
  2. 拆价值链分工：设计选品、定价、推广、履约自己做，生产外包；
  3. 拆定价逻辑：成本加成，低毛利；
  4. 拆选品策略：经典大单品（对比 Shein 的小单快反）；
  5. 看目标市场；
  6. 评估投入规模（首期注资和三年计划）对集团利润、资金和管理精力的占用，以及对股东回报概率的影响。
- **关键指标与数据来源**：新业务投入金额（首期、三年）、目标市场、品类、定价逻辑。
- **判断标准**：早期投入会拖累利润，并降低分红和回购的可能；类比对象若是更成熟的模式，要说明新业务与现有业务（如 Temu）的差异与重叠，占用的资金和管理精力是否值得。
- **海豚案例**：
  - 拼多多《拼多多：“狂人”彻底变“庸人”？》（2026-03-25）：成立“新拼姆”，结合拼多多和 Temu 的供应链做自营品牌，首期现金注资 150 亿元，三年计划投入 1000 亿；早期投入会拖累利润，也降低了分红和回购的可能。
  - 拼多多《拼多多：又老又“傲慢”，彻底人人嫌》（2026-05-27）：模式类似 Costco 的 Kirkland，测试服饰、家居、户外，面向海外，成本加成定价，主打经典大单品（不同于 Shein 的小单快反），相当于 Temu 的自营版本，但占用更多资金和管理精力。
- **适用场景与注意事项**：适用于公司宣布新业务或新战略时的初步评估。

### 7.3.7 新产品切入新市场的评估：参数、定位、客户承诺、迭代规划

- **方法要点**：评估公司推出的新品类（例如 IP 公司首次自研芯片）时，按参数、定位、客户承诺、迭代规划四项列清，其中客户承诺被视为比参数更关键的验证。
- **操作步骤 / 拆分口径 / 公式**：
  1. **核心参数**：核心数、制程、TDP、芯粒设计；
  2. **定位**：相对 x86 替代，性能更强、功耗更低；明确不进入哪些市场；
  3. **客户承诺**：是否已有实际客户承诺，以及客户用途（AI 头节点或通用 CPU）；
  4. **迭代规划**：后续迭代规划（第二代产品时间）。
- **关键指标与数据来源**：产品参数、目标市场、客户承诺名单、迭代时间表。
- **判断标准**：参数只是入场券，真正的验证是客户是否已经承诺使用及用途；有清晰迭代规划才说明公司在长期投入。
- **海豚案例**：
  - ARM《ARM：“短期波动”难掩锋芒》（2026-05-07）：ARM AGI CPU 有 136 个 Neoverse V3 核心，采用台积电 3nm，TDP 低于 300W，双芯粒；Meta、OpenAI 和另外三家初创企业用作 AI 头节点，SAP、Cloudflare 等用作通用 CPU；2027 年推出第二代。
- **适用场景与注意事项**：适合公司跨入新品类时的评估。

### 7.3.8 新技术产品定位与部署形态分析：规格 → 定位 → 各形态门槛与风险 → 落地时间

- **方法要点**：评估新技术 / 新产品作为第二曲线的可行性时，先看规格，再看它在现有层级结构中的位置，然后按不同部署形态分别评估门槛与风险，最后判断落地时间。
- **操作步骤 / 拆分口径 / 公式**：
  1. **规格**：HBF（高带宽闪存）由 SK 海力士与闪迪在 FMS 2026 联合披露规范：8-Hi 与 16-Hi 两种堆叠、容量上限 512GB，一代目标约 1.6TB/s、微秒级延迟、容量为 HBM 的 8-16 倍，介于 HBM 与 NVMe SSD（7-14GB/s）之间；
  2. **原理**：HBM 快在“距离短、接口宽”、紧贴 GPU，HBF 把这套封装级接口用于 NAND；
  3. **局限与定位**：随机读延迟约 10us（HBM 为 10-100ns），差 100-1000 倍 → 不会替代 HBM，是 HBM 与 SSD 之间的新层级，适合权重和大上下文可预取、并行度高的密集推理；
  4. **四种部署形态逐一评估**：
     - ①替代型（纯 HBF，容量最大化但对 NAND 写入寿命最敏感，每个 token 的 KV 直接写 NAND）；
     - ②缓存型（HBM 退到前端做缓存，写入约束仍在）；
     - ③增配型（HBF + HBM 混搭，权重放 HBF、KV 留 HBM，门槛最低，最可能是第一代落地形态）；
     - ④解耦型（HBF 独立成池存放 decode 阶段权重与 KV，谷歌、Meta、海力士、Tenstorrent 推动）；
  5. **进度**：首颗 HBF die 已流片，首批推理样品预计 CY27 交付。
- **关键指标与数据来源**：带宽、容量、延迟、写入寿命（P/E 循环）、样品与量产时间、生态联盟成员。
- **判断标准**：看新技术在层级中的位置（补充层而非替代层）、各部署形态对关键约束（如写入寿命）的敏感度，以及生态推动者与时间表；门槛最低的形态最可能先落地。
- **海豚案例**：
  - 闪迪《AI 推理大爆发，“悲催” 闪迪真有凤凰涅槃？》（2026-09-14）第四节 d)：HBF 规格、定位、四种部署形态与进度。
  - 闪迪《比 DRAM 还摇钱树，闪迪真有那么香？》（2026-08-17）：HBF 用富余产能承接。
- **适用场景与注意事项**：评估新技术 / 第二曲线的可行性与时间表；按部署形态区分落地概率，不要把“最终形态”的想象力直接记入近期业绩。

### 7.3.9 技术复用型新业务：多路线竞争格局 + 壁垒性质判断

- **方法要点**：分析新业务时先找技术同源性，再列出所有竞争技术路线并用硬性条件筛选已落地路线，最后判断壁垒究竟来自基础原理还是先发与工程验证。
- **操作步骤 / 拆分口径 / 公式**：
  1. **找技术同源性**：新产品是否复用公司在老业务中验证多年的技术（例如 OCS 的 MEMS 微镜与 WSS 二十年的光路调度技术同源）；
  2. **列全竞争技术路线**；
  3. **用硬性条件筛选**：规模（端口数）和现网验证；
  4. **判断壁垒性质**：是基础原理层面的，还是先发与量产、集群工程验证层面的。
- **关键指标与数据来源**：技术同源性、竞争路线数量、端口规模、现网验证情况。
- **判断标准**：同时满足“数百端口规模 + 超大规模 AI 集群现网验证”的路线才是已落地路线；若壁垒来自先发和规模化验证而非原理，则优势会随时间被追赶，需要持续观察竞争者验证进度。
- **海豚案例**：
  - Lumentum《Lumentum：产能告急，“全能卖水人”还有什么看家绝活？》（2026-10-05）：OCS 有五条路线——Lumentum 3D-MEMS、Coherent LCOS、Polatis 压电陶瓷、iPronics 硅光、Telescent 机械臂换纤；同时满足“数百端口规模 + 超大规模 AI 集群现网验证”的只有 MEMS，且已通过谷歌 TPU 集群验证；Lumentum 的优势来自先发和规模化现网验证，原理层面壁垒不高。
- **适用场景与注意事项**：适用于平台型公司拓展相邻业务的评估。与 6.3（技术路线、产品力与竞争力诊断）互为补充。

### 7.3.10 跟踪新市场产品的渗透排名，评估第二增长曲线的大小

- **方法要点**：主业增速见顶后，收入端的想象力来自新市场扩张；通过新市场产品的 DAU / MAU 排名和与头部平台的差距，加上市场规模评估，判断它对估值的贡献。
- **操作步骤 / 拆分口径 / 公式**：
  1. 跟踪新市场产品的 DAU、MAU 排名，以及与头部平台的差距；
  2. 评估新市场本身的规模；
  3. 判断对估值的贡献——市场规模小则贡献有限。
- **关键指标与数据来源**：新市场 DAU / MAU 排名、与头部平台的差距、市场规模。
- **判断标准**：排名靠前不等于贡献大，要和市场规模一起看；市场扩张到一定程度之前，保持业绩的最快办法仍可能是主业自我瘦身（降本增效）。
- **海豚案例**：
  - Boss 直聘（2026-05-20）：香港平台 OfferToday 日活已是香港主流招聘平台第一，月活第二，离头部平台 JobsDB 一步之遥；但“香港市场毕竟小”，市场扩张到一定程度之前，公司保持业绩的最快办法还是自我瘦身。
- **适用场景与注意事项**：适用于寻找第二增长曲线的成熟公司。

### 7.3.11 新业务按三层口径估年化收入，对标行业龙头体量，判断能否单独贡献估值

- **方法要点**：对藏在集团内部的新业务（如自研芯片）按三层口径估算规模，与行业龙头比较，判断是否具备单独估值条件，并量化对集团的协同。
- **操作步骤 / 拆分口径 / 公式**：
  1. 估算三层口径：对外销售的年化收入、含内部使用的年化规模、承诺订单金额；
  2. 与行业龙头（英伟达）比较体量，判断是否已具备单独估值的条件；
  3. 量化对集团的协同：少买外部芯片省下的 Capex，以及能效比带来的经营利润率几个 pct 的优势。
- **关键指标与数据来源**：新业务年化收入；内部使用规模；承诺订单；对标公司收入。
- **判断标准**：含内部使用的规模接近龙头体量一定比例（如 1/5）时，具备单独估值的条件；对外销售口径只反映商业化进度，含自用口径才反映真实规模，承诺订单反映未来可见度。
- **海豚案例**：
  - 亚马逊（2026-04-30）：芯片销售年化收入 200 亿，含内部使用为 500 亿，Trainium 承诺订单 2250 亿；ASIC（含 GPU 和 CPU）业务含自用已接近英伟达体量的 1/5，有望单独贡献估值；Trainium 每年可省数百亿 Capex。
- **适用场景与注意事项**：有内部孵化业务的科技巨头（自研芯片、TPU 等）。估值层面的处理见 9.6（SOTP 分部估值）。

### 7.3.12 用龙头业务结构对标第二曲线空间（卫星星座运营）

- **方法要点**：判断硬件公司向服务运营延伸的第二曲线时，先论证自身平台是否具备进入能力，再用龙头的业务结构对标空间。
- **操作步骤 / 拆分口径 / 公式**：
  1. 看平台特征：Flatellite 平台极致标准化（模块化、统一接口）+ 极致扁平化（多颗卫星像扑克牌一样堆叠在整流罩内，大幅提升单次发射卫星数、摊薄发射成本）；
  2. 对比同类堆叠式平台的成熟度：仅 SpaceX 成熟应用，Blue Origin 的 Kuiper、中国蓝箭航天及千帆星座仍处初期 → 具备搭建自有星座、与 Starlink 竞争的能力；
  3. 空间对标：Starlink 约占 SpaceX 收入 6-7 成，因此卫星运营有望成为公司未来占比最高的业务。
- **关键指标与数据来源**：单次发射卫星数、平台成熟度、龙头业务结构。
- **判断标准**：平台能力 + 同类成熟度对比说明“能不能做”，龙头业务结构说明“做成了有多大”；公司目前尚未布局星座运营，因此只是空间判断，需要后续进度验证。
- **海豚案例**：
  - Rocket Lab（2026-04-10）：公司 2025 年 2 月发布 Flatellite，目前尚未布局星座运营。
- **适用场景与注意事项**：判断硬件公司向服务运营延伸的空间。

### 7.3.13 论证现有产品成本已逼近物理下限，下一代产品是唯一出路

- **方法要点**：先论证现有产品优化到了极致、剩余成本是刚性的，再说明进一步量级降本和解锁更高价值业态必须依赖新架构，由此把新产品定位为“现金牛与远期期权之间唯一的桥梁”，并点明它决定估值上限。
- **操作步骤 / 拆分口径 / 公式**：
  1. 论证现有产品已近物理下限：二子级不可回收、推进剂、翻修等成本刚性；
  2. 量化现有成本：边际成本约 1500 万美元、入轨成本约 700-1000 美元 / kg；
  3. 对照目标成本：低于 200 美元 / kg；
  4. 论证必须靠新架构（完全复用）才能达成；
  5. 定位新产品：连接现金牛与远期期权的唯一桥梁，其成败决定估值上限。
- **关键指标与数据来源**：现有产品边际成本（约 1500 万美元）、入轨成本（约 700-1000 美元 / kg）、目标成本（低于 200 美元 / kg）。
- **判断标准**：旧产品降本空间越小、新架构的降本幅度越大（量级级别），新产品对估值上限越关键；同时必须配合研发进度判断，防止只讲故事。
- **海豚案例**：
  - SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：猎鹰 9 号复用已到极致，入轨成本要从约 700-1000 美元 / kg 降到 200 美元 / kg 以下，必须靠 Starship 的完全复用架构；星舰的成败决定 SpaceX 能否打开下一个十万亿美元级市场，是整个公司估值上限的决定性因素。
- **适用场景与注意事项**：适用于判断老产品天花板和新产品必要性；要防止只讲故事、不看研发进度（接 7.3.22、7.3.23）。

### 7.3.14 识别共同瓶颈资源，推导两条增长路径

- **方法要点**：当公司多条产品线竞争同一稀缺资源时，成长上限由这项资源决定；要最大化业绩弹性只有两条路。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别共同瓶颈资源（如同一片磷化铟晶圆产能）；
  2. 判断各产品线对瓶颈资源的占用；
  3. 推导两条路径：①提升单位瓶颈资源的产值——优先生产更高价值的产品，最大化单张晶圆的收入和利润；②开辟不消耗瓶颈资源的新业务曲线，从根本上摆脱天花板；
  4. 用这个框架评估各业务（模块、OCS）的战略意义。
- **关键指标与数据来源**：单位晶圆收入 / 利润、各产品对瓶颈资源的占用、不占用瓶颈资源的业务占比。
- **判断标准**：看公司是否向高价值产品倾斜（如 200G EML、UHP CW），以及不消耗瓶颈资源的业务（如 OCS）占比是否提升。
- **海豚案例**：
  - Lumentum《Lumentum：产能告急，“全能卖水人”还有什么看家绝活？》（2026-10-05）：EML、CW、DCI 相干器件底层都在竞争同一块紧缺的磷化铟晶圆产能，因此要看公司是否转向高价值芯片（200G EML、UHP CW）以及 OCS 等不消耗磷化铟的业务。
- **适用场景与注意事项**：适用于产能受限的制造型公司（晶圆、封装、化合物半导体、稀缺原料）。与 5.3（需求驱动、供给约束与供需缺口）联动。

### 7.3.15 用技术代际迭代时间表 + 最新出货增速判断第二增长曲线

- **方法要点**：结合第三方机构的技术代际路线图，判断单颗器件价值量何时跃升；再用最新季度关键器件的出货同比增速，确认需求是否已启动；两者共同支持“传统板块走出第二增长曲线”的结论。
- **操作步骤 / 拆分口径 / 公式**：
  1. 取第三方机构技术代际时间表（每一代速率的规范发布、送样、规模上量期）；
  2. 判断单颗器件价值量何时跃升；
  3. 取最新季度关键器件出货同比增速，确认需求启动；
  4. 两者共同支持第二增长曲线判断。
- **关键指标与数据来源**：技术代际时间表（400ZR → 800ZR → 1.6T ZR）、规范发布 / 送样 / 放量时间、器件出货同比。
- **判断标准**：路线图给“什么时候价值量跃升”，出货增速给“需求是否已启动”，两者同向才支持结论；单有路线图则可能延期。
- **海豚案例**：
  - Lumentum《Lumentum：产能告急，“全能卖水人”还有什么看家绝活？》（2026-10-05）：据 Cignal AI，2026~2027 年为 800ZR 规模上量期，1.6T ZR 规范 2026 年 9 月发布，预计 2027 年送样、2028 年放量，单颗光源价值量第二次跃升；最新季度泵浦激光器出货同比增长超过 80%，窄线宽可调激光器同比增长 130%。
- **适用场景与注意事项**：适用于产品迭代驱动的通信与半导体公司。路线图可能延期，需持续跟踪。

### 7.3.16 小体量高弹性业务：识别爆发的触发条件

- **方法要点**：对当前收入很小但被视为未来最大增量的业务，先如实给出现有规模和占比，再明确爆发的单一触发条件，把跟踪重点放在这个条件上，避免现阶段过度外推。
- **操作步骤 / 拆分口径 / 公式**：
  1. 如实给出业务当前规模与占比；
  2. 说明收入来源阶段（样片 / 初级需求）；
  3. 明确爆发的单一触发条件（如新架构落地速度）；
  4. 把跟踪重点放在触发条件上，并预告后续定量测算。
- **关键指标与数据来源**：业务当前收入、占比、收入来源阶段（样片 / 初级需求）、触发条件进度。
- **判断标准**：触发条件未兑现前，不把当前增速外推；触发条件（如 CPO 交换机出货）必须可观测。
- **海豚案例**：
  - Lumentum《从光互联老炮到“全能卖水人”，Lumentum 凭什么？》（2026-09-24）：CW 激光器年收入约 0.5 亿美元，仅占总营收 2%，主要来自硅光初级需求和 CPO 样片；真正的爆发取决于 NPO / CPO 落地速度，从可插拔走向 CPO 时需求将指数增长，下篇定量测算。
- **适用场景与注意事项**：适用于期权型新业务（第二曲线）的处理。触发条件需要可观测。

### 7.3.17 新业务“体内 + 体外”双轨布局分析与长期收入占比目标

- **方法要点**：拆解公司在新赛道的布局方式——体内做通用部件，体外通过关联公司布局整机，并关注管理层给出的长期收入结构目标。
- **操作步骤 / 拆分口径 / 公式**：
  1. 体内：通用部件（传感器、微电机）；
  2. 体外：通过关联公司（创始人投资的灵巧手公司）布局整机；
  3. 看未来体内能否给体外供应部件或代工；
  4. 记录管理层的长期收入结构目标。
- **关键指标与数据来源**：体内新业务收入、关联方交易、管理层收入结构目标。
- **判断标准**：体内部件是否成为体外整机的供应方，决定关联布局能否转化为上市公司收入；关联交易需判断定价公允与利益冲突。
- **海豚案例**：
  - 禾赛（2026-05-19、2026-08-19）：体内推出“物理 AI 之眼”（全集成传感器）和“物理 AI 的肌肉”（微电机），目标 5 年内与激光雷达收入五五开；体外是创始人投资的 Sharpa，Sharpa 已被英伟达 GR00T 平台采用，禾赛未来可以供应微电机或代工整手。
- **适用场景与注意事项**：适用于创始人有体外布局的科技公司。需要关注关联交易和利益冲突，参见 11.1（管理层、组织与人才）。

**B. 跟踪：新业务进展与里程碑**

### 7.3.18 第二曲线进度表：产品路线图 + 已确认客户 + 收入目标 + 竞争定位

- **方法要点**：新业务还没贡献收入时，建立一张进度表，持续记录产品、客户、收入目标和竞争定位；海豚君强调更应落在相对近期的表现，远期目标只作参考。
- **操作步骤 / 拆分口径 / 公式**：
  1. 产品代际和量产 / 送样时间；
  2. 技术差异化（与主流方案对比）；
  3. 已确认客户及是否多代合作；
  4. 单客户收入规模；
  5. 管理层收入目标（近期年份与远期年份分开）；
  6. TAM；
  7. 评估竞争地位，看份额是否足以威胁现有龙头；
  8. 以近期表现为主，远期目标只作参考。
- **关键指标与数据来源**：量产 / 送样时点、客户数及单客户收入、近 / 远期收入目标、TAM、市场份额。
- **判断标准**：近期可核验的节点（量产、首批出货、客户数）比远期目标更重要；份额低的细分（如 AI PC）难以威胁龙头，不应夸大其意义。
- **海豚案例**：
  - 高通（2026-04-30）：AI200（2026 量产，高内存容量 + 低 TCO，面向推理）、AI250（2027 量产，近内存计算，有效带宽提升 10 倍以上），预计 2027 年起贡献 50-70 亿美元年收入；与超大规模客户合作，2026 年 12 月季度首批出货；AI PC Snapdragon X2 NPU 85 TOPS，但份额低，难威胁英特尔 / AMD。
  - 高通（2026-07-30）：投资者日四大产品线——AI 加速器（LPDDR5X 替代 HBM，微软多代合作，AI300 有效带宽是 AI200 的 54 倍）、商用 CPU Dragonfly C1000（Meta）、定制硅（2 家超大规模客户 FY27 各贡献 10 亿 +，能力来自收购 Alphawave、Ventana）、连接（800G / 1.6T 光模块）；TAM 1 万亿美元，FY29 目标 150 亿、FY27 目标 50 亿。
- **适用场景与注意事项**：转型期公司、新业务仍在投入期的公司。管理层的远期收入目标和 TAM 宣传口径常偏乐观，要与近期出货节点对照。

### 7.3.19 新业务四维跟踪：产品、产业链定位、客户验证进展、产能和组织投入

- **方法要点**：对尚未量产的新业务（如人形机器人），按四个固定维度跟踪，便于每期对比。
- **操作步骤 / 拆分口径 / 公式**：
  1. **产品**：做什么——机电执行器，集电机、减速器或丝杠、传感器、编码器、控制器于一体的总成，即机器人关节；目前主攻身体关节而非灵巧手；
  2. **产业链定位**：总成提供商还是零部件商——定位总成，类似汽车热管理中的 Tier1，同时自研丝杠、合作谐波减速器；
  3. **客户进展**：靠产业链调研获取——旋转执行器已通过头部客户多轮技术验证并小批量供货，线性执行器在开发，26 年定点量产确定性强；
  4. **产能和组织**：资本开支和工厂——2024 年 1 月公告杭州 38 亿元研发生产基地，泰国工厂为量产做好准备，墨西哥与绿地谐波合资；以及 2025 年 10 月成立机器人事业部。
- **关键指标与数据来源**：产品形态；定位层级；客户验证阶段（技术验证、小批量、定点、量产）；资本开支金额；海外工厂；组织架构调整。
- **判断标准**：客户验证阶段（技术验证 → 小批量 → 定点 → 量产）逐级推进、产能与组织投入同步到位，说明新业务从概念向收入推进；若只有产品、没有客户验证与产能，仍属概念。
- **海豚案例**：
  - 三花智控《三花：AI 机器人时代…》（2026-01-08）第二部分：从产品、产业链定位、客户合作进展、产能准备四方面梳理人形机器人布局。
- **适用场景与注意事项**：适用于有第二、第三曲线但尚无收入的公司。客户进展多依赖产业链调研，可信度需要交叉验证。

### 7.3.20 智驾、Robotaxi、人形机器人的里程碑时间表：作为 AI 期权价值的验证清单

- **方法要点**：每季更新 AI 相关业务的里程碑清单，并标出解锁的外部资金；估值上把这些业务作为不计入保守估值的期权，兑现后再触发 P/S 重估。
- **操作步骤 / 拆分口径 / 公式**：
  1. 硬件：自研芯片算力、量产上车；
  2. 软件：大模型版本、关键性能指标；
  3. Robotaxi：测试许可、示范运营、专属车型、商业模式；
  4. 机器人：自由度、量产时间、月产能目标、首批场景；
  5. 标出解锁的外部资金（如 Robotaxi 测试解锁 Uber 股权资金）；
  6. 估值处理：不计入保守估值，兑现后再触发 P/S 重估。
- **关键指标与数据来源**：芯片算力、上车比例、模型迭代指标、运营城市和时间、量产时间和月产能。
- **判断标准**：里程碑按期兑现才触发重估；未兑现前仅作为期权观察。
- **海豚案例**：
  - Rivian（2026-02-13、05-01）：RAP1 单芯片 800 TOPS，双芯片；26H2 点到点智驾，旧金山、迈阿密 Robotaxi 测试解锁 Uber 2.5 亿；2027 年 L3，2028 年 L4。
  - 小鹏（2026-03-20、05-28、08-24）：图灵芯片 750 TOPS 全系量产；VLA 2.0 于 3 月发布（推理效率提升 32 倍、误差降低 33%），8 月升级，端侧向 20B 参数推进；Robotaxi Q3 在广州载客示范，2027 年推经济型专属车；Iron 有 82 个自由度，年底量产，月产能超 1000 台。
- **适用场景与注意事项**：适合有 AI 或机器人故事的车企和科技公司。期权估值处理见 9.7。

### 7.3.21 用“演示 → 生产 → 实际付费载客运营”的里程碑链判断是否告别概念

- **方法要点**：把新业务进展按里程碑链定位，跨过最后一环（实际付费运营）才算从概念展示走到商业化；同时列出产品定义和商业定位。
- **操作步骤 / 拆分口径 / 公式**：
  1. 概念演示；
  2. 生产：周产爬坡至 500-600 台、库存充足；
  3. 实际载客运营：奥斯汀 45 辆 Cybercab 完成注册，发布会后开启无安全员付费载客；
  4. 产品定义：双座、无方向盘和踏板、HW4 纯视觉 8 摄像头、48kWh 电池、400V、整备质量 1412kg、风阻 0.19、主打城市短途高频接单；
  5. 商业定位：同时面向自营车队和商业客户，不对个人消费者售卖，暂未公布进入中国时间表。
- **关键指标与数据来源**：所处里程碑阶段；周产能；注册车辆数；是否无安全员；是否收费；运营城市。
- **判断标准**：每个阶段对应不同的估值折价；是否无安全员、是否收费是区分“演示”和“商业运营”的关键。
- **海豚案例**：
  - 特斯拉《Cybercab 发布会：告别概念，开启 Robotaxi 大时代？》（2026-09-04）：特斯拉跨过演示、生产、实际载客运营这条链。
- **适用场景与注意事项**：适用于自动驾驶、机器人、新药等有清晰商业化阶段的业务。

### 7.3.22 把关键产品拆成子里程碑分别判断时间点，并与下游需求时间表对齐

- **方法要点**：把下一代“杀手级产品”的成熟拆开，分别判断每个子里程碑的时间点，再列出管理层时间指引和市场部署计划，并与下游需求时间表对齐，检查逻辑是否一致。
- **操作步骤 / 拆分口径 / 公式**：
  1. 拆子里程碑：一级回收和二级回收分开判断——一级技术路线已基本走通，预计第 13 或 14 次试飞重返成功；二级是完全复用的最后难关，热防护、再入控制、着陆精度还要多轮迭代；
  2. 列管理层时间指引；
  3. 列市场部署计划：先发自家 V3 卫星，5-6 次飞行验证后约 2027 年中开放外部商业发射；
  4. 与下游需求时间表对齐：2028 年起部署轨道 AI 卫星。
- **关键指标与数据来源**：试飞次数和完成度（第 12 次试飞完成超过 95% 的主要目标）、单次载荷（约 60 颗 V3 卫星、新增超过 60Tbps）、飞行验证次数、商业化时间。
- **判断标准**：子里程碑之间的时间是否能满足下游需求时间表；管理层时间指引常常偏乐观，要打折。
- **海豚案例**：
  - SpaceX《从“白日梦”到“万贯金”…》（2026-06-12）：2026 年 5 月 23 日第 12 次试飞（V3 首飞），验证猛禽 3、热防护、在轨释放 20 颗模拟 V3 卫星，一级坠海；马斯克目标 2026 年实现完全复用、2026 年下半年运送轨道载荷。
- **适用场景与注意事项**：适用于产品周期驱动的公司（新车型、新药、新芯片）；管理层时间指引常常偏乐观，要打折。

### 7.3.23 按行业标准测试流程拆解研发里程碑，并对延期做根因分析

- **方法要点**：把研发进度放进行业标准流程，逐项对照公司披露进度，并对已发生的延期做根因分析。
- **操作步骤 / 拆分口径 / 公式**：
  1. 把研发流程拆成：分系统测试（发动机试车、结构静力 / 动力测试、电气综合测试）→ 环境模拟（振动、声学、热真空）→ 总装后测试 → 发射演练 → 正式发射；
  2. 标出最关键三项：发动机试车、结构测试、总装后全箭匹配与状态测试；
  3. 逐项对照公司披露进度：Archimedes 多次试车、结构测试大部分完成、发射台基本完工；
  4. 对延期做根因分析：2026 年 1 月一级贮箱静水压测试破裂，源于供应商手工铺层工艺缺陷 → 全面转为公司已成熟掌握的 AFP 工艺；首飞由 2026 年二季度推迟至四季度。
- **关键指标与数据来源**：各测试节点完成度、延期原因、首飞时间。
- **判断标准**：关键三项是否完成决定首飞可信度；延期根因若已被工艺改进解决，对后续风险是缓解，否则要继续折价。
- **海豚案例**：
  - Rocket Lab（2026-04-10）：Neutron 工作进度表——按标准测试流程逐项对照，并分析一级贮箱破裂的根因与改进。
- **适用场景与注意事项**：火箭、航空、新药、芯片等长研发周期产品的进度跟踪。与 7.3.24 配合：本方法偏“进度拆解 + 根因”，后者偏“历次延期与股价”。

### 7.3.24 记录关键项目的延期历史和工程节点，并用期权折现解释股价

- **方法要点**：对估值依赖单一关键项目的公司，记录该项目的历次延期时间表、失败原因与工艺改进、当前硬件进度，评估剩余时间窗口和延期风险；逻辑是每次延期都会折现期权价值、导致股价回撤。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列首飞时间表的历次变更及延期次数；
  2. 记录失败原因与工艺改进：手工铺层改为自动纤维铺放（AFP）；
  3. 记录当前硬件进度：热试车次数、总装集成；
  4. 评估剩余时间窗口和延期风险；
  5. 解释股价：每次延期折现期权价值 → 股价回撤。
- **关键指标与数据来源**：首飞时间表、延期次数、测试节点（热试车次数、静水压测试）、剩余时间窗口。
- **判断标准**：距离目标日期的剩余窗口越窄、工程节点越没跑完，延期风险越高；延期会压低期权的折现价值。
- **海豚案例**：
  - Rocket Lab《中子号或延期》（2026-08-11）：Neutron 首飞已从 2025Q4 推到 2026Q1，再到 2026Q4；2026 年 1 月一级贮箱静水压测试破裂，根源为第三方手工铺层，此后转为内部 AFP；Archimedes 完成 400+ 次热试车；距年底约 4.5 个月，窗口收窄，存在延期风险。
- **适用场景与注意事项**：适用于航天、创新药、新车型、芯片流片等单一里程碑驱动估值的公司。

### 7.3.25 远期业务的产业链高频进度跟踪：产线调试、周产目标、供应商催货、份额

- **方法要点**：对股价主要由想象力业务驱动的公司，在财报点评中单独跟踪产业链进度，把这些作为“情绪修复与估值重估”的催化剂。
- **操作步骤 / 拆分口径 / 公式**：
  1. 客户新一代产品是否定稿；
  2. 产线到场和调试；
  3. 工程样机周下线量；
  4. 供应商收到的周交付提升要求；
  5. 未来周产目标（月度和年底）；
  6. 公司在核心部件中的份额、单台价值量；
  7. 海外工厂交付情况。
- **关键指标与数据来源**：周产量、周交付量、份额、单台价值量、PPA 落地。
- **判断标准**：供应商被要求把周交付提升到数倍、周产目标逐月上调，说明量产确认度提高；这些高频指标是估值重估的催化剂。
- **海豚案例**：
  - 三花（2026-08-27）：Optimus 最新代设计定稿，26H2 开始量产爬坡；7 月半自动产线每周下线 100-200 台工程样机；执行器当前周交付百余台，供应商被要求提升到数倍；9 月周产目标 1000 台，年底 2000-2500 台；执行器单台约 5 万元以上；三花在 14 个旋转关节总成中占约 50-70% 份额，墨西哥工厂已批量交付。
- **适用场景与注意事项**：适合机器人、AI 硬件等处于量产前夜的产业链公司。数据多来自产业链调研，可靠性需要交叉验证。

### 7.3.26 特斯拉式 AI 业务里程碑验证：传统业务估值不足市值 1/3 时，逐季检验里程碑是否按期兑现

- **方法要点**：当传统业务（汽车）估值不足市值 1/3 时，每季财报的核心就是检验 AI 业务里程碑是否按期，同时用 capex 和现金测算投入能否持续。
- **操作步骤 / 拆分口径 / 公式**：
  1. 每季检验：量产时间、产能、车队规模、无人监督比例；
  2. 与竞对（如 Waymo）比较；
  3. 用 capex 和现金测算投入能否持续。
- **关键指标与数据来源**：产品时间表、产能、车队规模、无人监督比例、capex。
- **判断标准**：电话会未给出关键产品进度、车队规模远小于竞对时，判断股价承压；capex 指引上调则对现金消耗形成压力。
- **海豚案例**：
  - 特斯拉《1Q26》（2026-04-23）：Optimus V3 推迟到年中；Robotaxi 年底覆盖约十个州；capex 指引上调至 >250 亿。

**A. 公司战略**

### 7.4.1 公司战略动作解读：杠铃策略、让利换量、新市场扩张、超级入口

- **方法要点**：把管理层战略动作逐条解读成对增长和利润率的含义，进而判断公司处于“投入抢份额、稳增长”还是“收获利润”的阶段，调整后续利润率提升幅度的预期。
- **操作步骤 / 拆分口径 / 公式**：
  1. **杠铃策略**：高端产品贡献利润、抗风险，低价产品下沉拉新；
  2. **让利换量**：成本节省让利给用户以刺激订单（稳利润、抢份额）；
  3. **成熟市场 vs 新市场**：成熟市场靠广告和规模效率释放利润，新市场激进扩张（直接与对手竞争）会压制利润率；
  4. **跨界合作与超级入口**：跨界合作（与 OTA 合作导流）和 AI Agent，构建超级入口；
  5. 汇总判断：公司处于“投入抢份额、稳增长”的阶段，据此调整对后续利润率提升幅度的预期。
- **关键指标与数据来源**：产品结构、新进入市场数量、合作伙伴、利润率趋势。
- **判断标准**：新市场进入越多、让利越多，利润率短期越受压；成熟市场的广告与规模效率是利润来源；综合起来决定利润率的节奏。
- **海豚案例**：
  - Uber《Uber：业绩都在线》（2026-05-07）：网约车继续杠铃策略，并把保费下降的利益让渡给用户；外卖新进入欧洲七国，与 DoorDash 竞争；与 Expedia 合作提供酒店预订；今年整体是投入抢份额、稳增长的状态。
- **适用场景与注意事项**：适合需要判断投入周期的平台公司。

### 7.4.2 利润换增长战略的验证链：投入 → 下单频次 / 订单提速 → 订单密度 → 履约成本摊薄 → 经营杠杆

- **方法要点**：对主动牺牲利润换增长的平台（降低免邮门槛、自建物流、当日达、切入外卖），用一条因果链验证投入是否有效，并认识到物流产能增速高于业务量增速期间利润率会下滑。
- **操作步骤 / 拆分口径 / 公式**：
  1. 投入后订单量和人均下单频次是否加速；
  2. 品类渗透（商超、生鲜、药品）带来的 TAM 扩张；
  3. 订单密度上升后，履约成本摊薄，后续释放经营杠杆；
  4. 同时指出：物流产能增速高于业务量增速期间利润率会下滑，逐利资金会暂时离开（亚马逊历史上多次如此），抄底还是避开取决于投资期限。
- **关键指标与数据来源**：订单增速、人均下单频次、履约成本、物流产能、利润率。
- **判断标准**：订单与频次加速是投入有效的第一信号；若订单没有加速而利润率已下滑，则投入无效；投入期的利润率下滑可接受，但要看订单密度能否带来履约成本摊薄。
- **海豚案例**：
  - MercadoLibre（2026-02-25）：降低免邮门槛、提升履约时效后，订单加速、频次提升，验证更好的履约能带动渗透和粘性；信用卡度过 12-18 个月发展期后进入 NIMAL 盈亏平衡，信贷利润将释放。
  - Sea（2026-03-03）：Shopee 降低免邮门槛、东南亚六国部分实现当日达和即时达，在印尼、泰国等 4 个市场切入餐饮外卖，份额第二（仅次于 Grab）。
- **适用场景与注意事项**：适用于电商和本地生活平台的投入期分析。

### 7.4.3 多元化扩张的“添头”判断：重运营新业务稀释效率，核心景气仍是主变量

- **方法要点**：评估公司跨界扩张时，承认其带来增量用户与收入，但指出新业务多为重运营行业、公司作为挑战者要对抗已有龙头，管理与经营效率会分散下降；结论把多元化定位为“添头”，投资主变量仍是核心行业景气。
- **操作步骤 / 拆分口径 / 公式**：
  1. 列出跨界扩张方向（外卖配送、租车 / 接送机、旅游活动、酒店供给）；
  2. 承认增量用户与收入；
  3. 判断新业务是否为重运营、是否需要对抗已有龙头；
  4. 判断多元化对管理和经营效率的分散；
  5. 定位为“添头”，投资主变量仍是核心行业景气。
- **关键指标与数据来源**：新业务收入占比、营销费用增速、核心业务景气指标。
- **判断标准**：新业务收入占比小且重运营，则对估值影响有限；核心业务景气决定投资结论，公司因此适合作为趋势性 / 周期性机会选项。
- **海豚案例**：
  - Airbnb（2026-08-07）：管理层强调从住宿预订转为综合平台，海豚君认为多元化是“添头”，世界杯后需观察新利好接力。
- **适用场景与注意事项**：平台公司拓品类 / 拓赛道的战略评估。

### 7.4.4 战略转向动因三问：为何从差异化走向正面竞争

- **方法要点**：当公司从差异化策略转向与龙头正面竞争时，回答“为什么现在做”，从市场、能力、客户三个角度论证战略合理性。
- **操作步骤 / 拆分口径 / 公式**：
  1. **市场**：原细分市场太小，尤其对商业客户成本无优势；
  2. **能力**：前期火箭与卫星制造积累的能力和资源足以支撑布局中型火箭；
  3. **客户**：客户结构决定不必正面硬刚——美国军方和政府不会容忍发射市场被一家垄断，Falcon 9 当前没有竞品，只要做出来客户自然会敞开大门。
- **关键指标与数据来源**：细分市场规模、能力积累、客户采购偏好。
- **判断标准**：三问都有答案，转向才合理；其中客户结构（采购方偏好与反垄断诉求）是判断“正面竞争是否真的是正面硬刚”的关键。
- **海豚案例**：
  - Rocket Lab（2026-04-10）：Neutron 于 2021 年公布，对标 Falcon 9。
- **适用场景与注意事项**：挑战者进入龙头主战场的战略合理性评估。

### 7.4.5 中长期战略二选一推演（加投入降利润率 vs 守现状降天花板），再看管理层实际选择

- **方法要点**：把公司未来路径推演为两种选择并写清各自代价，然后用近一年电话会表述与实际动作判断管理层真实选择，并推出对收入与利润率的含义。
- **操作步骤 / 拆分口径 / 公式**：
  1. **路径 A**：增加投入做终端产品创新、品牌营销甚至延伸到财富管理 / 支付信贷 → 代价是高利润率被削弱；
  2. **路径 B**：保持现状、越来越依赖国际化经纪通道，在非美市场靠美股牌照优势保持高效增长 → 代价是增长天花板降低；
  3. 用近一年电话会表述与实际动作判断管理层很可能“双脚并行”：开拓巴西、台湾、阿联酋、斯洛文尼亚、韩国等新市场；在 Crypto（上线各地、增加品种、稳定币入金）与 AI（交易工具、AI 资讯、研究梳理、客服、投顾机器人）加速创新；
  4. 结论：收入 / 账户高增可持续，但近 80% 的极致利润率必然被削弱。
- **关键指标与数据来源**：新进入国家数、新产品上线、经营利润率趋势。
- **判断标准**：每条路径对收入和利润率的影响不同，推演框架要明确这一点；管理层若同时走两条路，则增长和利润率的组合要同时修正。
- **海豚案例**：
  - 盈透《盈透：将“极致效率”刻进 DNA 的交易扫地僧》（2026-09-22）：上述二选一推演，并判断管理层“双脚并行”，近 80% 的极致利润率必然被削弱。
- **适用场景与注意事项**：适用于处于战略拐点的高利润率公司。同一篇文章的天花板修正方法见 7.1.8。

### 7.4.6 透过短期资本操作识别战略重心的转折点

- **方法要点**：透过短期预期差和资本操作，识别公司战略重心的转折信号（分部口径调整、某块业务亏损触底、资本投向变化），再依据行业格局判断转向是否合理，并评价过去的资源配置是否错配。
- **操作步骤 / 拆分口径 / 公式**：
  1. 观察信号：分部口径调整、分部亏损趋势、资本投向；
  2. 依据行业格局判断转向是否合理：原有战场已是多强互耗、再投入也只能勉强守边界时，转向新战场就有道理；
  3. 评价过去的资源配置是否错配。
- **关键指标与数据来源**：分部口径调整；分部亏损趋势；资本投向。
- **判断标准**：口径调整 → 亏损触底 → 投资加码这一序列出现，意味着重心转向；原战场“只要大体稳住、提供弹药”即可，新战场成为主叙事。
- **海豚案例**：
  - 阿里（2026-08-24）：从调整业绩口径，到电商亏损触底，再到 AI 投资加获利，阿里从“全栈 AI + 一站消费”双重心基本转向 All in 全栈 AI，电商只要大体稳住、提供弹药；电商战场已是多强互耗格局；此前投外卖是资源错配，这次投 AI 是迟来的纠偏。
- **适用场景与注意事项**：适用于判断多业务集团的战略转向。

### 7.4.7 把战略动作与内部经营问题挂钩，分析动机

- **方法要点**：把公司的战略动作放进近期经营背景里理解，找出动机，并与此前的反向信号对照，看战略是否一致。
- **操作步骤 / 拆分口径 / 公式**：
  1. 梳理经营背景：技术竞赛落后（新模型与第一梯队的差距再次拉大）、员工士气下降、战略和组织架构频繁调整导致团队迷茫；
  2. 解读动作：短期看不到 AI 体验和商业化突破，出租算力可以直接产生 AI 变现收入，缓解市场对高 Capex ROI 的质疑和对次年利润、现金流恶化的担忧；
  3. 与此前的反向信号对照（刚上调 Capex、被供应商限制算力、刚锁定长期算力），说明战略并非一致。
- **关键指标与数据来源**：模型能力排名、组织调整、Capex 指引、ROI 质疑。
- **判断标准**：战略动作若与内部短板相互印证，说明动机更可能是缓解压力而非主动布局；与此前动作互相矛盾，则说明战略缺乏一致性。
- **海豚案例**：
  - Meta《算力太贵，Meta 掀桌？》（2026-07-06）：Q1 财报刚把 2026 年 Capex 中位数上调 100 亿到 1350 亿，Google 刚限制对 Meta 的算力供给，Meta 6 月刚与 Crusoe 锁定 1.6GW 长期算力；4 月发布的 Muse Spark 当时缩小了与 Tier 1 的差距，现在又被甩出头部；扎克伯格在股东大会提到很多客户来高价租算力。
- **适用场景与注意事项**：适用于解读大公司的非常规战略动作。动机分析偏定性，需要结合后续行动验证。

### 7.4.8 战略定位“纯粹度”对比：长期单一路线 vs 混合逻辑导致心智模糊

- **方法要点**：比较两家公司战略是否长期单一坚定，判断为什么同一模式在不同公司结果不同。
- **操作步骤 / 拆分口径 / 公式**：
  1. 一方：坚守纯粹模型（精简 SKU、重仓自有品牌、压缩冗余），形成“低价 — 高周转 — 更大规模 — 更低价格”闭环与“家庭大宗采购主场”心智；
  2. 另一方：背靠母公司未割裂大卖场逻辑（扩 SKU、照顾长尾），导致供应链打法、商品结构与用户心智不够极致，沦为“补充消费渠道”；
  3. 用钱包份额等数据支撑定性判断。
- **关键指标与数据来源**：SKU 趋势、会员年均消费、用户心智定位。
- **判断标准**：定位越纯粹，闭环越强、会员年均消费越高；混合逻辑会使消费频次与集中度偏弱。
- **海豚案例**：
  - 山姆《沃尔玛里的“Costco”…》（2026-06-09）：Costco 定位纯粹、会员年均消费 3300 美元；山姆美国定位模糊、年均消费约 1900 美元、消费频次与集中度偏弱。
- **适用场景与注意事项**：母子公司 / 多业态公司；定性判断需用钱包份额等数据支撑。

### 7.4.9 把管理层的终极构想与当前现实对照（Everything App vs “美国版微博”）

- **方法要点**：先复述管理层的终极构想，再用现实数据对照，并用一个比喻概括愿景与现实之间的差距。
- **操作步骤 / 拆分口径 / 公式**：
  1. 复述愿景：把 X 打造成融合 AI、支付、通信、内容、商业的万物应用，用 Grok 贯穿形成“数据、模型、变现、用户”的自强化闭环，从单一广告变成多元变现；
  2. 对照现实：突发事件中仍是舆论中心，但日常商业流量和用户粘性被竞品系统性蚕食，市场份额持续承压；
  3. 用比喻概括：“美国版微博”。
- **关键指标与数据来源**：变现结构、用户粘性、市场份额。
- **判断标准**：愿景中的每个环节（支付、通信、商业、变现多元化）是否有现实数据支持；若现实仍停留在“舆论中心”，说明愿景尚未兑现。
- **海豚案例**：
  - SpaceX《SpaceX：AI 烧钱不止…》（2026-06-30）：X 平台陷入“美国版微博”的窘境。
- **适用场景与注意事项**：适用于管理层叙事宏大的公司，防止被愿景带偏。

### 7.4.10 “地面演练到太空复制”：把短期业务解读为长期战略的工程能力积累

- **方法要点**：把短期业务视为长期战略的必修课，看各业务之间的能力传承，而不只是看短期财务回报。
- **操作步骤 / 拆分口径 / 公式**：
  1. 识别短期业务：地面 GW 级集群，Colossus II 于 2026 年 1 月投运，计划年内 1.5GW，2026 年底至 2027 年冲击 2GW、约 55.5 万张 GPU；
  2. 识别长期战略：太空算力；
  3. 解读能力传承：通过运营地面集群，跑通超大供电、极限散热、数万节点网络拓扑的全链条工程体系，对应马斯克“在地球驾驭 GW 级集群，才能在太空复制”的逻辑。
- **关键指标与数据来源**：地面集群 GW 规模与时间表、GPU 数量。
- **判断标准**：若短期业务确实积累了长期战略所需的工程能力（供电、散热、网络拓扑），则可视为“双轨战略”——短期地面基石，长期太空算力。
- **海豚案例**：
  - SpaceX《SpaceX：AI 烧钱不止…》（2026-06-30）：双轨战略，短期地面基石，长期太空算力。
- **适用场景与注意事项**：适用于判断长期战略与短期业务之间的协同。

### 7.4.11 存量资产改造分阶段拆解 + 落地时间表，判断红利释放节奏

- **方法要点**：按时间顺序拆改造阶段，每阶段写覆盖进度与预计完成时间，据此判断各层红利在何时释放，并与对手重资产模式比较资本开支与试错成本。
- **操作步骤 / 拆分口径 / 公式**：
  1. **软件层**：店内拣货数字调度，不改物理空间、边际成本低，把效率拉到约“80 分”；
  2. **空间层**：增设自提与配送暂存区、加宽通道优化货架，线上线下流量互不干扰；
  3. **自动化层**：后仓微型自动化履约中心；
  4. 每阶段写覆盖进度与预计完成时间；
  5. 与对手每建一个 FC 需数亿美元的重资产模式比较资本开支与试错成本。
- **关键指标与数据来源**：系统覆盖门店比例、改造完成比例与时间、自动化部署时间。
- **判断标准**：软件层已基本落地、空间层与自动化层按时间表推进，则红利逐层释放；用存量资产改造替代重资产新建，资本开支和试错成本更低。
- **海豚案例**：
  - 沃尔玛《沃尔玛：老兵“奇袭”电商…》（2026-06-08）：2022 年推出 Store Assist，已基本全覆盖；门店空间改造预计 2027 年底完成约 70% 主力门店；2023 年押注 APD 后仓自动化，2025 年交由 Symbotic 联合开发，规模化部署至少要到 2027-2029 年，判断自动化红利在未来 3-5 年逐步释放。
- **适用场景与注意事项**：处于转型期的公司；时间表来自公司交流，需持续跟踪进度偏差。

### 7.4.12 按全栈五层（芯片 / 系统 / 模型 / 工具 / 生态）判断公司从硬件商转型为基础设施商

- **方法要点**：把公司在发布会上的布局按分层框架梳理，判断其战略定位，并结合新增长曲线框架（物理 AI）看长期空间。
- **操作步骤 / 拆分口径 / 公式**：
  1. **芯片层**：Vera CPU、Rubin GPU、Orin / Thor；
  2. **硬件系统层**：Vera Rubin 超级计算机、DGX Cloud；
  3. **模型层**：NeMoTron、Cosmos 等开源基础模型 + 垂直领域模型；
  4. **工具层**：NeMo 系列库、蓝图构建框架；
  5. **生态层**：联合 Palantir、西门子等；
  6. 结论：英伟达正从 GPU 厂商转型为 AI 全栈基础设施提供商；
  7. 用物理 AI 框架判断新增长曲线：发展阶段为感知 AI → 生成式 AI → AI 智能体 → 物理 AI；技术原理为合成数据、三台计算机协同、Cosmos 与 GR00T 模型；落地场景为自动驾驶 Alpamayo、与西门子的工业制造、机器人、Earth 2 天气预测。
- **关键指标与数据来源**：各层产品与合作伙伴、物理 AI 落地场景、出货时间（Rubin 2026 年下半年出货）。
- **判断标准**：看每一层是否有产品、有合作伙伴、有时间表；全栈布局最终要落到各层的收入贡献去验证。
- **海豚案例**：
  - 英伟达《老黄解锁 Rubin，AI 存储又添“一把火”》（2026-01-07）：CES 2026 布局按五层梳理，得出“从 GPU 厂商转型为 AI 全栈基础设施提供商”，并用物理 AI 框架判断新增长曲线。
- **适用场景与注意事项**：适用于平台型科技公司的战略定位分析。全栈布局最终要落到各层的收入贡献去验证（参见 7.3.11 的新业务规模口径）。

### 7.4.13 自研 ASIC 战略意图判断：自用降本 vs 对外商业化

- **方法要点**：判断大厂自研芯片的定位——自用降本还是对外商业化，从设计分工、用途、产能约束入手，再追踪配套供应链长协和量产进度，判断其对总算力目标的贡献。
- **操作步骤 / 拆分口径 / 公式**：
  1. 设计分工：Broadcom 负责协同设计和物理落地，TSMC 代工；
  2. 用途：训练 + 推理，但预计主要推理；
  3. 产能约束：台积电产能份额不足以支撑做芯片生意；
  4. 结论：自用为主，本质是降低推理成本、减少被少数供应商（NVIDIA）裹挟；
  5. 追踪配套供应链长协（三星、闪迪存储模块，住友电工光纤）和量产进度（9 月量产、测试未发现大 bug），判断其对总算力目标的贡献。
- **关键指标与数据来源**：量产时间、代工产能份额、供应链长协、推理成本。
- **判断标准**：代工产能份额不足、主要用于推理，则为自用降本；最终体现为云业务利润率释放。
- **海豚案例**：
  - Meta（2026-07-10）：第四代 MTIA 芯片 Iris 是 14GW 总算力的重要组成。
  - Amazon《“AI 拉胯”亚马逊：会上演逆袭大戏吗？》（2026-06-24）：自研芯片核心原因是降低外部依赖、软硬一体提高能效 / 成本比，最终体现为云业务利润率释放。
- **适用场景与注意事项**：大厂自研芯片评估；也可反推对 NVIDIA、Broadcom 等供应商的影响。

### 7.4.14 “可交付优先于竞争力”的决策逻辑及代价拆解

- **方法要点**：解释看似落后的技术选择，用“可交付”而非“竞争力”作为决策首要考虑，并拆解这一选择在两头的代价与出路。
- **操作步骤 / 拆分口径 / 公式**：
  1. 解释选择：AWS 选 PCIe 是图省事、求快速上市——协议跟现成标准走，又省掉自研交换芯片的时间；既摆脱英伟达溢价，又尽快向锚定客户 Anthropic 交付；
  2. 拆代价①等升级、节奏落后：PCIe 约三年一代，NVLink 约两年一代，只能被动跟随；
  3. 拆代价②堆通道、成本变高：背板铜缆、连接器、Retimer 用量增加，拉高功耗与成本；
  4. 看下一代：若仍用 PCIe 7，已无法靠换调制方式翻倍，只能硬提频率，板材与 Retimer 压力成倍上升；
  5. 看出路：交换芯片换成 UALink 时协议顺势切换；或转向 NVLink Fusion（AWS 已宣布 Trn4 支持）。
- **关键指标与数据来源**：协议迭代周期、Retimer / 铜缆用量、功耗、客户交付时间。
- **判断标准**：快速交付换来客户锁定，但技术节奏被动、成本抬升；出路取决于协议生态的演进。
- **海豚案例**：
  - 亚马逊 AWS《（短评）AWS 为何还要选 PCIe》（2026-10-13）：“可交付优先于竞争力”的决策逻辑与两头代价。
- **适用场景与注意事项**：适用于自研芯片厂商的路线选择分析。

**B. 产品战略**

### 7.4.15 判断新入口与旧入口的关系：内部蚕食还是试验田

- **方法要点**：新产品和公司原有超级 App 功能重叠时，判断它是在内部侵蚀旧入口，还是旧入口的试验田。
- **操作步骤 / 拆分口径 / 公式**：
  1. 判断是否避免了在旧入口直接加新功能可能引起的用户反感；
  2. 能否通过小体量产品观察用户反馈，决定深度融合的节奏；
  3. 小体量下算力成本和团队压力是否更小；
  4. 给出路径预期：最终融入旧入口，或两款产品并存的“两步走”。
- **关键指标与数据来源**：用户体量；功能重叠度；用户反馈。
- **判断标准**：若新产品用户体量小、能提供反馈、成本压力低，则更像试验田；功能重叠本身不必然构成蚕食。
- **海豚案例**：
  - 腾讯（2026-01-26）：海豚君认为元宝是微信 AI 的“试验田”，体验完善后最终会融入微信；也不排除像 QQ 和微信那样两款产品并存的“两步走”。
- **适用场景与注意事项**：适用于有多个 App 的平台公司。

### 7.4.16 新产品的战略必要性与行业资源流向分析

- **方法要点**：分析一个产品方向为何被押注，从行业、公司、管理层三个层面各给出证据，判断该产品在公司内部的战略地位与持续投入意愿。
- **操作步骤 / 拆分口径 / 公式**：
  1. **行业层面**：2B Agent 付费流水风生水起，泛生活类 2C Agent 商业模式未突破，大厂悄悄把资源转向 C 端工作流场景，泛生活 2C 被放慢；
  2. **公司层面**：Meta 本身缺少生产力场景，若任由新的十亿级入口（ChatGPT）抢夺用户注意力，对自身社交生态是长期打击，因而“不得不押注”；
  3. **管理层一致性**：“人人一个 AI 助理”在业绩会上至少讲了两年，产品是内部资源优先级最高的核心项目。
- **关键指标与数据来源**：管理层表述持续时间、资源优先级、行业商业化进展。
- **判断标准**：行业资源流向、公司战略必要性、管理层表述一致性三者互相印证，说明该产品是长期押注；管理层表述的持续时间是判断一致性的重要信号。
- **海豚案例**：
  - Meta《Muse 爆了，Meta 的真拐点还是假高潮？》（2026-09-23）“Muse 的火并不意外”一节。
- **适用场景与注意事项**：判断新产品的战略地位与持续投入意愿。

### 7.4.17 产品定位认知差 + 竞品多维对比表

- **方法要点**：从用户认知层面比较新产品与竞品的定位差，检查底层支撑，再选同类竞品沿多个维度做对比表，作差异化的定性比较。
- **操作步骤 / 拆分口径 / 公式**：
  1. 比较认知：ChatGPT 虽能做任务（配合 Codex 可执行长任务），但多数用户在非工作场景习惯把它当聊天机器人；Muse 从设计到宣发都定位为主动任务型生活助理（以可完成的任务举例介绍），实现“认知改写”；
  2. 检查底层支撑：直接用公开的 Muse Spark 模型，未做专调或参数精简；
  3. 选同类竞品（初创公司 Instinct、Grok bot、Openclaw 类平台），沿隐私审慎程度、授权范围、场景（生活 vs 工作流）、上线状态等维度做对比表；
  4. 读表：Instinct 授权大胆但风控不全，Grok bot 偏工作流、与 Openclaw 差异不显著。
- **关键指标与数据来源**：交互形式、宣发定位、底层模型、授权范围、风控措施、接入应用、上线状态。
- **判断标准**：差异化是否真正落在用户认知与场景上，而不只是技术参数；竞品对比维度要覆盖风控与授权这类产品化关键点。
- **海豚案例**：
  - Meta（2026-09-23）：Muse vs Instinct（2 月发布、邀请测试、一级估值大涨）vs Grok bot（8 月推出，可接入 Gmail、Notion、Figma 等）对比。
- **适用场景与注意事项**：AI 应用与消费产品的差异化定性比较。

### 7.4.18 产品组合决策归因：产能约束 + 成本转嫁能力（按客群价格敏感度）

- **方法要点**：解释为什么公司只发高端机型、标准版延期，推理链为：上游成本冲击加产能约束，使公司优先保障转嫁能力强、毛利高的产品，推迟价格敏感产品。
- **操作步骤 / 拆分口径 / 公式**：
  1. 产能约束：2nm 量产初期产能紧张，苹果把产能优先分给高端机型；
  2. 成本转嫁：存储成本大幅上涨（市场预估手机端存储价格同比上涨 100% 以上），标准版用户价格敏感，更难转嫁成本；
  3. 推理：上游成本冲击 + 产能约束 → 优先保障转嫁能力强、毛利高的产品，推迟价格敏感产品。
- **关键指标与数据来源**：先进制程产能；存储价格同比；各产品线客群价格敏感度；产品线毛利率。
- **判断标准**：产品线客群价格敏感度越高、毛利越低，越容易在产能与成本双重约束下被推迟。
- **海豚案例**：
  - 苹果《苹果：存储暴涨逼提价，折叠屏能救场吗？》（2026-09-10）：标准版 iPhone 18 推迟到春季发布的两个原因（2nm 产能优先分给高端机型；存储成本大涨且标准版用户价格敏感，难转嫁）。
- **适用场景与注意事项**：适用于消费电子、汽车等受上游成本和产能约束的产品组合分析。
