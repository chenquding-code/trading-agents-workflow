## 13.1 风险识别与传导分析

> 本节导读：本节回答“这家公司最可能在哪里出问题、问题会怎样一步步传导到业绩与估值”。做法是先给风险定性（工程执行风险还是需求风险、短期事件还是长期结构性风险），再把风险写成可观察的传导链和跟踪线，最后借助偏离情景、可比公司映射和跨市场剧本推演给风险定概率、定量级。适用于首次搭建风险清单、财报与事件点评的风险段落、以及为估值折价或中枢下移找依据；大客户集中与客户自研风险见6.7，竞争威胁见6.8，政策事件的影响推演见12.6，风险落成证伪条件与跟踪指标见13.2，落到估值上下限见10.2。

**风险类型速选表**（先判断属于哪一类，再选方法）：

| 你面对的风险 | 优先使用的方法 |
|---|---|
| 新产品/新平台量产或首飞前的不确定性 | 13.1.1 工程执行风险 vs 需求风险 |

| 高利润率靠行业纪律或默契维持 | 13.1.5 定价权脆弱前提与跟踪线 |
| 大宗商品敞口、囤货/存货生意 | 13.1.6 零对冲囤货＝单边做多原材料 |

| 已研究过同类商业模式的标的 | 13.1.12 可比公司映射风险清单 |

### 13.1.1 区分工程执行风险与需求风险，定位核心不确定性

**方法要点**：对新产品或新平台量产前的公司，先判断关键项目的风险性质——到底是“有没有人买”（需求风险），还是“能不能按时做出来”（工程执行风险）——从而锁定核心不确定性，并预判股价的驱动方式。

**操作步骤 / 拆分口径**：

1. 需求端检验：看是否已有实质订单（预售订单数），客户类型是否分散在商业与国防等不同来源，需求是否有真金白银的承诺。
2. 供给端拆解：把项目从当下到量产/首飞之间的工程路径拆成节点，圈出风险最集中的高风险节点（如整级测试、首次加注点火、发动机与航电集成）。
3. 定性：需求清晰、执行不确定时，结论是“需要证明能不能按时飞，而非有没有人买”；若订单本身不实，则风险性质转为需求风险，要回到行业空间与客户结构去验证（见第5章、6.7）。
4. 推断股价驱动：风险主要在执行端时，股价主要受延期类新闻驱动，管理层在电话会上披露的延迟风险会使短期股价承压。
5. 把高风险节点转成跟踪表，逐一设置“按时/延期”的观察点（跟踪表写法见13.2.4）。

**关键指标与数据来源**：预售订单数；客户结构（商业/国防）；高风险工程节点及其预计时间。来源为公司订单披露、业绩会/电话会管理层关于进度与延迟风险的表述。

**判断标准**：
- 需求端：已有多笔订单、商业与国防客户都有订单 → 需求风险低。
- 供给端：节点集中、环环相扣且每个节点都可能延期 → 执行风险高。
- 需求清晰＋执行不确定 → 结论为“证明能不能按时飞”，投资上看“节点是否按时落地”，而不是“行业有没有空间”；电话会透露延期风险 → 短期股价承压。

**海豚案例**：
- Rocket Lab《中子号或延期》（2026-08-11）：已提前拿下5次Neutron发射订单，商业和国防客户均有订单，需求端不是问题；核心风险落在整级测试、完整加注后的首次点火、发动机与航电系统集成这些执行节点；电话会透露的延迟风险，海豚君预计会使短期股价承压。

**适用场景与注意事项**：适用于新产品或新平台量产前的公司（火箭、新车型、新芯片、新产线等）。注意“有订单”不等于“需求无风险”，要同时看订单的客户类型与可撤销性；节点要拆到可观察的颗粒度，否则无法形成跟踪抓手。

### 13.1.2 外部压力清单：资本开支扩张、竞争、政府订单/政治风险、监管

**方法要点**：对业务多元、受政府与监管影响大的公司，系统地列出外部压力的“清单”，每一项配具体事件，并评估对盈利预期的影响，避免只讲故事不讲压力。

**操作步骤 / 拆分口径**：

1. 压力一：核心现金流业务面临下一代巨额资本开支（要把单位造价、下一代造价量级列出来）。
2. 压力二：各细分业务的具体竞争者（按业务线分别写，而不是笼统写“竞争激烈”）。
3. 压力三：政府客户的不稳定性和政治因素（创始人与政府领导人冲突、合同被开放给竞对）。
4. 压力四：监管审查（如FAA）。
5. 每项都配具体事件，评估对盈利预期的影响，指出哪项预期可能偏乐观（例如V2盈利预期可能偏乐观）。

**关键指标与数据来源**：V1.5与V2卫星造价、竞争者进展、政府合同事件、监管审批进度。来源为公司披露、政府与监管机构动向及竞争对手公开进展。

**判断标准**：某项压力同时具备“有具体事件佐证”和“能量化到盈利预期”两个条件，才进入风险清单的核心位置；造价量级跳升、合同可被撤销或开放给竞对、监管审查持续严格，都视为对盈利预期的下行压力。

**海豚案例**：
- SpaceX《马斯克再甩“王炸”…》（2026-02-24）：资本开支方面，V1.5卫星造价15亿美元，V2可能飙升到600亿美元以上；竞争方面，全球互联业务受贝索斯和中国挑战，D2D（直连手机）受AST SpaceMobile挑战；政府与政治方面，特朗普威胁终止合同，NASA向Blue Origin重新开放月球着陆器合同；监管方面，FAA持续严格审查。据此评估V2盈利预期可能偏乐观。

**适用场景与注意事项**：适用于依赖政府、受强监管的公司。清单要每项配事件、不堆形容词；政治类风险具有突发性，宜配合13.2的跟踪清单持续更新。

### 13.1.3 风险传导链：工艺路线→良率/能效→出货能力

**方法要点**：把“芯片能不能卖出去”的风险拆成一条供应链传导链：谁在供货→用什么工艺→良率与能效如何→最终能出多少货，从而找到短期最关键的风险节点。

**操作步骤 / 拆分口径**：

1. 找供应来源：确认主要代工厂，以及对方的排产优先级是否面向该公司（先进产能大头是否愿意分配产能）。
2. 看工艺路线：二供代工厂的先进制程处于什么阶段（投产初期、产能需爬坡）、通过什么路径实现（DUV多重曝光，而非EUV）。
3. 推导良率与能效：工艺路线相对落后、产线爬坡初期 → 芯片良率与能效相对偏低。
4. 推导出货能力：良率与能效偏低 → 拖累出货能力，是短期最关键风险点。
5. 新品发布后复核：新品补足产品短板后，把关键矛盾重新写成“新产线爬坡的良率”，避免因产品力改善而误以为供给风险消失。

**关键指标与数据来源**：代工厂良率、产能爬坡进度、工艺路线（DUV多重曝光/EUV）。来源为代工厂产能与工艺披露、公司招股书与产品发布信息。

**判断标准**：传导链上任一环节“弱”，则下一环节都要打折——排产优先级不面向本公司 → 供应依赖二供；二供产线处于爬坡期且工艺路径靠多重曝光 → 良率能效偏低 → 出货能力受限。短期以“供给兑现”而非“产品性能”为核心矛盾。

**海豚案例**：
- 壁仞科技《壁仞：国产“英伟达”，到底“几斤几两”？》（2026-06-18，第3、4节）：中芯国际（先进产能大头）排产优先级不面向壁仞，主要供应来自华虹；华虹先进制程处于投产初期、产能需爬坡，且通过DUV多重曝光而非EUV实现，芯片良率与能效相对偏低，拖累出货能力，是短期最关键风险点；新品BR20X补足产品短板后，关键矛盾同样是“新产线爬坡的良率”。

**适用场景与注意事项**：适用于依赖新产线/二供代工厂的芯片设计公司。要点是把“工艺路线”这一技术事实翻译成“良率/能效”再到“出货量”的财务含义；产能来源切换的节奏风险见13.1.4。

### 13.1.4 把代工与产能切换视为放量的最大不确定因素

**方法要点**：对需求旺盛但供给受限的芯片公司，把“产能来自哪里、能否稳定拿到”当作业绩兑现的核心变量，而不是只数在手订单。

**操作步骤 / 拆分口径**：

1. 跟踪新产品的流片和量产节点（只流片、仅供客户测试，与真正量产出货差距很大）。
2. 跟踪代工合作框架何时到期，评估到期后是否必须切换（含制裁风险）。
3. 评估切换成本：切换代工还需要配合修改芯片架构，同样需要时间，规划可能延期。
4. 把在手订单与产能对照：订单充足但兑现受产能限制，兑现节奏要打折。
5. 估值衔接：在以PS和可比市值为主的估值体系下，产能不确定性会压低上市后的估值。

**关键指标与数据来源**：流片和量产时间；代工合同期限；在手订单；产能。来源为公司公告、招股书、管理层披露与产业链信息。

**判断标准**：合作框架即将到期且切换为必选项 → 风险高；新品仅处于流片测试或设计阶段 → 放量时点靠后；在手订单大但产能受限 → 业绩兑现看产能而非订单。

**海豚案例**：
- 百度（2026-09-07）：M100只流片供客户测试，M300还在设计中、计划明年下半年出货；明年与三星的合作框架到期，切到国产代工已是必选项；在手订单预估近百亿元，但兑现受产能限制。
- 昆仑芯（2026-01-02）：P800交付节奏受三星产能限制。

**适用场景与注意事项**：适用于需求旺盛但供应受限的半导体公司。与13.1.3的区别在于：13.1.3看已有供应链的工艺—良率—出货传导，本方法看“供应来源本身是否稳定、能否切换”。

### 13.1.5 识别定价权依赖的脆弱前提，并设跟踪线

**方法要点**：高利润率或紧平衡的背后往往靠某个具体前提（如寡头默契）维持；找出这个前提、以及会打破它的变量，写成跟踪线，让风险从“泛泛担忧”变成“可跟踪的问题”。

**操作步骤 / 拆分口径**：

1. 写出当前紧平衡/高定价所依赖的具体前提。例如NAND的紧平衡靠寡头之间的默契：闪迪主动把行业bit增速目标压在约15%，而不是历史上30%以上。
2. 找出会打破前提的变量，设两条跟踪线：①供给端——其他原厂（尤其中国厂商）会不会打破默契、在NAND上扩产；②需求端——AI对NAND的拉动能持续多久。
3. 把跟踪线落成可量化的工作：逐厂的CapEx与Fab动工/投产时间表（供给），自下而上的AI需求测算（需求）。
4. 用“达摩克利斯之剑随时可能落下”表达：当下未必兑现，但前提脆弱，需要持续盯。

**关键指标与数据来源**：行业bit增速目标、各厂CapEx与Fab动工/投产节点、AI需求测算。来源为各原厂资本开支与产能披露、行业需求测算。

**判断标准**：若行业bit增速目标被突破（回到历史30%以上）、或有玩家新增产能不再遵守默契，则定价权前提被证伪；若AI需求拉动力衰减，则需求端前提被证伪。两条线之一被证伪，高利润率的持续性就要重估（跟踪线的证伪表达见13.2.1）。

**海豚案例**：
- 闪迪《NAND 天性“多产”…》（2026-09-18）：文末提出“供给端是否打破默契、需求端AI持续性”两个问题，留给下篇解答；终篇把这两条线落成逐厂Fab时间表和需求自下而上测算。

**适用场景与注意事项**：适用于所有靠行业纪律维持高利润率的寡头行业（如存储、部分化工、航运联盟）。注意要把前提说“具体”（具体到数值目标或具体玩家），否则无法设置跟踪线。

### 13.1.6 零对冲囤货＝单边做多原材料：上行期双收益，下行期减值＋周转变慢，估值永久折价

**方法要点**：对不使用金融对冲、仅靠提前囤货作天然对冲的公司，识别其商业模式本质是“单边做多原材料”，由此得出盈利不确定性极强、估值永久带折价的判断，与品牌力关系不大。

**操作步骤 / 拆分口径**：

1. 核查对冲政策：是否使用期货、黄金租赁等金融对冲；若只有提前囤货，则定性为单边做多原材料。
2. 拆上行周期：库存增值＋提价，双收益。
3. 拆下行周期：失去库存收益，并面临存货减值、周转变慢、消费者杀跌观望。
4. 得出估值含义：盈利不确定性极强，只要不对冲，估值永远带折价；投资定位为“跟随金价区间的交易机会”，不是靠品牌力的长期复利。
5. 对高位加仓的动作定性：高位配股加仓囤金被视为“豪赌”。

**关键指标与数据来源**：金价、存货、周转率、对冲政策。来源为公司财报（存货、周转、减值）、融资与配股公告、金价走势。

**判断标准**：上行期“赌对了”不代表模式稳健；真正的检验是下行周期的压力测试——存货减值幅度、周转天数变化、终端需求是否杀跌观望。未经下行周期检验的盈利，不能给高确定性估值。

**海豚案例**：
- 老铺黄金（2026-03-23）：2025年10月高位配股囤货后金价又涨30%以上，“又赌对了”；但仍视作豪赌式的单边做多。
- 老铺黄金（2026-08-25）：金价从5599美元跌至4000美元（-29%）的首个长期下行周期中，公司未通过压力测试。

**适用场景与注意事项**：适用于大宗商品敞口大的消费/制造公司。区分“品牌带来的提价能力”与“库存增值带来的账面收益”，不要把后者当作品牌力的证明。

### 13.1.7 品牌舆情冲击评估：身份认同型品牌的心智损伤更难修复

**方法要点**：对靠社群文化与身份认同支撑溢价的品牌，评估社媒负面舆情对到店客流和线上访问的直接拖累，区分短期舆情与中期竞争恶化，并用月度GMV衡量冲击的深度与衰减速度。

**操作步骤 / 拆分口径**：

1. 识别舆情类型：创始人公开批评、化学物质（PFAS）调查、营销触发民族情绪等持续的负面扩散。
2. 传导到经营：负面扩散 → 到店客流、线上访问下降 → 销售拖累。
3. 评估修复难度：身份认同型品牌的心智损伤，比供应链、库存问题更难修复。
4. 用月度GMV同比量化冲击深度与衰减速度（逐月看降幅是否收窄）。
5. 区分“舆情本身”和“中期竞争恶化”：判断真正的长期风险是不是舆情之外的结构性变量（如新竞争者进入）。

**关键指标与数据来源**：月度GMV同比、到店客流、线上访问量。来源为电商平台月度GMV数据、客流与流量数据、公司披露。

**判断标准**：舆情冲击的GMV降幅在后续月份逐步收窄，说明冲击在衰减；若降幅持续、或叠加竞争者进入，则从短期舆情转为中期竞争恶化，风险等级上升。

**海豚案例**：
- Lululemon（2026-06-05）：创始人公开批评管理层、PFAS风波，对线下客流和线上访问造成直接拖累。
- Lululemon（2026-09-04）：5月30日长城瑜伽节太极鼓事件引发民族情绪，天猫淘宝GMV在5、6、7月分别为-54%、-45%、-39%（降幅逐月收窄）；海豚君更担心Alo进入中国带来的中期竞争恶化，而非舆情本身。

**适用场景与注意事项**：适用于高端消费品牌、生活方式品牌。要用数据衡量衰减速度，不能只凭印象判断“影响有限”；同时避免把舆情当作唯一风险，忽略中期竞争格局变化（竞争格局见6.1）。

### 13.1.8 评估政治立场与舆论对国际化天花板的影响

**方法要点**：对“美国优先”或与国防部深度捆绑的公司，评估本土保护主义与舆论事件对海外企业客户签单意愿的影响，据此判断国际化的天花板，并对国际业务回暖保持“谨慎乐观”。

**操作步骤 / 拆分口径**：

1. 识别公司的政治定位：本土保护主义倾向、与国防部的深度捆绑等。
2. 追踪舆论事件：如海外媒体围剿某项政府合同。
3. 评估传导：即使单个合同占比很小（<1%），舆论也可能形成更多合作阻碍，限制国际化天花板。
4. 验证国际业务：持续跟踪国际商业收入增速与环比、国际客户数等合同数据，检验回暖是否延续成趋势。
5. 表达为“谨慎乐观”，而不是外推单季回暖。

**关键指标与数据来源**：国际商业收入增速与环比、国际客户数、舆论事件与合同规模。来源为公司财报与业绩会、媒体对合同的报道。

**判断标准**：国际业务单季回暖但下季环比持平，未延续成趋势 → 不能据此上调国际化预期；舆论事件持续发酵并波及客户签单意愿 → 天花板下移。

**海豚案例**：
- Palantir《瑕疵修复》（2026-08-04）：英国媒体围剿NHS合同（6000-6500万美元，占今年收入不到1%），可能限制国际化天花板；Q1国际商业意外回暖（+26%、客户+9家），Q2环比持平，未延续成趋势；此前《软件末日论汹涌》（2026-05-05）已提示谨慎。

**适用场景与注意事项**：适用于政治敏感行业（军工软件、数据、AI）的出海公司。小合同的舆论风险容易被低估，要区分“收入影响小”与“对天花板的影响大”。

### 13.1.9 结构性风险对估值中枢的压制：AI替代＋人口结构

**方法要点**：把短期催化与中长期结构性风险分开；长期风险用可观测的数据持续跟踪，结论落在“估值中枢相对下移”，并提醒越往后拖压力越明显。

**操作步骤 / 拆分口径**：

1. 区分两类问题：短期催化（财报、事件）与中长期结构性风险（技术替代、人口结构）。
2. 为结构性风险找可观测的替代指标：AI教育平台的用户时长（如豆包学）、出生人口下滑进入学龄、AI颠覆论的产品渗透。
3. 持续跟踪这些数据，判断压力是否在兑现。
4. 把结论落到估值：结构性风险不影响某一季的业绩，但会使估值中枢相对下移，而且越往后拖压力越明显。

**关键指标与数据来源**：在线教育平台用户时长、出生人口、AI产品渗透。来源为第三方平台时长数据、国家人口统计、AI产品公开数据。

**判断标准**：AI产品已在目标用户中占据一席之地、人口下滑已进入公司核心客群所在的学龄阶段 → 结构性压力开始兑现；战略转向叠加AI颠覆论 → 长期估值中枢必然受压。

**海豚案例**：
- 新东方（2026-01-28）：在线教育平台时长显示豆包学等AI教育平台已占一席之地；2020年后的出生人口下滑开始进入学龄。
- 新东方（2026-04-22）：AI和青年人口萎缩这“两座大山”可能令估值中枢下移。
- 多邻国（2026-05-05）：AI颠覆论叠加战略转向，长期估值中枢必然受压。

**适用场景与注意事项**：适用于教育、内容等易被AI替代的行业。结论要写成“估值中枢相对下移”而非“业绩立刻下滑”，避免把长期风险与短期业绩混为一谈；估值折价的定价落点见10.3。

### 13.1.10 反向审视“极致效率”的机会成本：UI、营销、新品类后来者

**方法要点**：在肯定公司核心优势之后，反向列出该经营风格的代价与盲区——每个护城河都要配套分析它的机会成本。

**操作步骤 / 拆分口径**：

1. 先肯定核心优势（此处为“极致效率”），再反向问：这种风格会牺牲什么？
2. 检查终端产品门槛：是否因忽视UI而把新用户挡在门外（如2022年才推出小白友好的GlobalTrader，此前TWS/IBKR Mobile复杂，与Robinhood的傻瓜界面对比，将散户挡在门外）。
3. 检查营销与品牌：营销投放欠缺导致本土散户品牌认知弱。
4. 检查对新兴需求的反应速度：Crypto 2021年9月仅4种资产，三年无动作，2025年才扩容，而Crypto已是Robinhood增长的重要驱动。
5. 用第三方数据佐证：Sensor Tower显示2025年美国/全球金融投资类应用下载TOP10无IBKR。

**关键指标与数据来源**：App下载排名（Sensor Tower）、新品类上线时间与资产数量、营销费用率。来源为第三方应用榜单与公司披露。

**判断标准**：新品类滞后上线、下载榜缺席、营销投放不足，三者叠加，即可判断公司“错失部分零售经纪市场先机”。

**海豚案例**：
- 盈透《盈透：将“极致效率”刻进 DNA 的交易扫地僧》（2026-09-22）：反向列出UI门槛、营销缺位、新品类滞后三项代价，并用Sensor Tower下载榜佐证，判断IBKR错失部分零售经纪市场先机。

**适用场景与注意事项**：适用于任何以单一优势见长的公司。该方法的价值在于避免“只夸不防”，可与护城河论证章节（6.4、6.5）配合使用。

### 13.1.11 列出偏离情景，用客户结构判断概率，得出“不对称保守”

**方法要点**：对基础假设分别列出负面与乐观两种偏离情景，再用业务的客户结构等底层事实判断哪种概率更高，最后对预期取“不对称保守”的立场。

**操作步骤 / 拆分口径**：

1. 定基础假设（如老业务增速预期）。
2. 列两种偏离：乐观情景（例如新业务带动老业务的交叉销售）与负面情景（例如AI快速替代传统软件，导致断崖下滑）。
3. 用底层事实判断概率：乐观情景依赖交叉销售，而新业务客户集中于少数巨头和AI Lab，而非广大常规企业，交叉销售可能性小；负面情景短期概率不大，但AI迭代极快，无法排除。
4. 比较概率：负面概率高于乐观概率。
5. 表达立场：对老业务增长预期“宁可悲观保守也不宜乐观”，即不对称保守。

**关键指标与数据来源**：客户集中度/客户类型结构、技术替代速度。来源为公司客户披露、合同结构、技术迭代进展。

**判断标准**：乐观情景所需的前提（交叉销售）是否被客户结构所支持；负面情景是否有技术迭代速度的支撑。乐观前提缺乏支撑而负面无法排除 → 假设取保守。

**海豚案例**：
- Oracle《Oracle：AI 算力豪赌，赔率够了吗？》（2026-04-27）：难以想象OpenAI因为租用Oracle算力就去采用其SaaS或数据库，因此否定交叉销售；AI替代传统软件的风险不可排除，因此对底座业务取保守假设。

**适用场景与注意事项**：适用于判断协同效应、交叉销售、技术替代的场景。概率判断偏定性，需要随新证据更新；落成情景估值的做法见10.2。

### 13.1.12 可比公司映射：用已研究标的的风险清单逐项套用（“大号CoreWeave”）

**方法要点**：把新研究的公司映射到之前研究过、商业模式相似的公司，把后者的风险清单逐项套用，提高风险识别的效率，并得出统一的定位判断。

**操作步骤 / 拆分口径**：

1. 选对标：找商业模式本质相似、已有风险清单的标的（甲骨文↔AI新云CoreWeave）。
2. 逐项套用风险清单并量化：
   - a. 客户集中度：来自OpenAI的合同约3000亿，占总RPO约58%，不如CoreWeave严重但问题存在。
   - b. 技术能力不强、议价权低：算力租赁多是BareMetal模式，附加值低，难以靠软件附加服务提高利润率；Cloud 1.0失败、AI浪潮前IaaS不温不火都是佐证。
   - c. AI云利润率低。
   - d. 高额Capex和负债压力。
3. 差异修正：标出对标对象与本公司在体量、多元化程度上的不同，下调或上调风险程度。
4. 给出定位结论：本质定位相似，都是“绑在OpenAI大船上干苦活的供应链型公司”。

**关键指标与数据来源**：客户RPO占比、服务模式（BareMetal占比）、毛利率、Capex、负债。来源为公司财报、RPO披露与对标公司研究。

**判断标准**：对标清单中的每一项在本公司都有证据对应，才确认风险成立；差异项（体量、多元化）决定风险是“同等严重”还是“相对较轻”。

**海豚案例**：
- 甲骨文《捡剩饭、傍大款！甲骨文拿命博生存？》（2026-01-22）：OpenAI占RPO约58%（约3000亿）；对标CoreWeave，逐项检查客户集中、议价权、AI云利润率、Capex与负债，得出“大号CoreWeave”的定位。

**适用场景与注意事项**：适合同一商业模式下的多家公司，复用风险清单能提高研究效率。要注意体量和多元化程度的差异，不能机械照搬。

### 13.1.13 “已发生市场剧本→未发生市场”：政策冲击的类比推演

**方法要点**：当同类政策在一个市场已落地并有数据可观测、而在另一个市场即将落地时，用前者的冲击路径推演后者，锁定利润承压的时间窗口，作为后文估值“坑底年份”和击球窗口的依据。

**操作步骤 / 拆分口径**：

1. 确认“已发生市场”有可观测的数据（提价、需求压制、占比下滑、利润承压的路径）。
2. 确认“未发生市场”的政策生效时间与征税方式（定额/比例）。
3. 引用管理层招股书原话佐证影响量级。
4. 把前者的冲击路径平移到后者，推演利润承压的起止时间，以及冲击全年化的年份。
5. 以此锁定估值上的“坑底年份”与击球窗口（估值使用见第10章）。

**关键指标与数据来源**：新政策生效时间、征税方式（定额/比例）、管理层对影响量级的表述。来源为政策文件、招股书与已发生市场的公司数据。

**判断标准**：管理层表述的影响量级与已发生市场相比如何（“大致符合或超出”）→ 决定推演的强度；政策生效时间 → 决定冲击窗口。

**海豚案例**：
- SHEIN《SHEIN：Temu 围剿…》（2026-08-31）：欧盟自2026年7月取消150欧元以下包裹免税，并按品类征约3欧元定额关税；管理层称欧洲影响“可能大致符合或超出美国”；海豚君推断美国2025年的剧本将在2026H2-2027年于欧洲重演，2027年冲击全年化。

**适用场景与注意事项**：适用于多市场经营且面临相似监管的公司；需注意两个市场的需求弹性、竞争格局不同，推演应保留差异修正。政策事件本身的影响推演方法见12.6。

**本节速查清单**

- [ ] 是否先把风险定性：工程执行风险 vs 需求风险，短期事件 vs 长期结构性风险？
- [ ] 每项外部压力（资本开支、竞争、政府/政治、监管）是否配有具体事件与对盈利预期的影响？
- [ ] 供给受限的公司，是否写清“供应来源→工艺/良率→出货”的传导链和代工合同到期、切换节点？
- [ ] 高利润率/紧平衡依赖的脆弱前提是否写成了具体的跟踪线（供给端、需求端各一条）？
- [ ] 商业模式层面：是否核查对冲政策、存货减值与周转压力，是否已在下行周期做过压力测试？
- [ ] 品牌/舆情风险是否用月度GMV等数据量化了深度和衰减速度，并区分了舆情与中期竞争恶化？
- [ ] 长期结构性风险（AI替代、人口）是否用可观测数据跟踪，并落到“估值中枢下移”？
- [ ] 对核心优势是否做了反向审视（机会成本与盲区）？
- [ ] 乐观/负面偏离情景是否用客户结构等底层事实判断了概率，并据此取不对称保守假设？
- [ ] 能否用已研究标的的风险清单或已发生市场的政策剧本做对标，并标注差异？

## 13.2 证伪条件与关键跟踪指标

> 本节导读：本节回答“如果我看错了，会在什么地方先出现信号”。做法是为每个核心逻辑写出反向情形或唯一的系统性风险，在事件点评后锁定一个可高频观测的关键指标并映射双向股价情景，区分“估值修复”与“基本面反转”，最后把下一步可验证的信号与催化剂列成跟踪清单。适用于每篇研究的结论段、事件点评的收尾，以及个股长期跟踪体系的搭建；核心驱动因素的主次排序见1.1，新业务里程碑的跟踪见7.3，催化剂的识别与时间线见13.3，风险的来源与传导见13.1。

### 13.2.1 写明核心逻辑的证伪条件与“唯一系统性风险”

**方法要点**：每个核心逻辑点都写出反向情形或“唯一的系统性风险”，让读者知道“看错时会发生什么”，结论段采用对称表达。

**操作步骤 / 拆分口径**：

1. 对每一个核心逻辑点，问一个问题：什么情形出现，这个逻辑就不成立？
2. 找出该逻辑的“唯一系统性风险”（一旦发生会同时击穿订单、估值等多个环节的外生变量）。
3. 结论段使用“向上取决于……；反之若……则……”的对称表达，同时写正反两面。
4. 对规划类目标（如算力目标）写明“规划与实际落地存在落差”，并在预测中留安全垫。
5. 把证伪条件对应到可观测变量（CSP Capex、AI ROI、电网排队变化、FCF），便于后续跟踪。

**关键指标与数据来源**：CSP Capex、AI ROI、电网排队变化、FCF。来源为云厂商财报与Capex指引、电力/并网排队数据、公司现金流披露。

**判断标准**：
- Bloom Energy（BE）：宏观深度衰退，或AI应用迟迟无法盈利（ROI为负），导致CSP大幅削减Capex → 时间溢价的紧迫性消失，订单转化与估值逻辑遭到直接反噬。
- Meta：短期现金流持续恶化 → 阻碍估值上探。
- Meta算力目标：数据中心规划与实际落地存在落差 → 需要留安全垫。

**海豚案例**：
- Bloom Energy（2026-07-20）：把“宏观深度衰退/AI ROI为负导致CSP削减Capex”写为核心逻辑的证伪条件。
- Meta（2026-09-23）、Meta（2026-07-10）：对估值写“现金流持续恶化会阻碍估值上探”，对算力目标写“规划与落地存在落差，需留安全垫”。

**适用场景与注意事项**：适用于所有投资结论的表达。证伪条件要写成具体情形与具体变量，不要写成“若宏观恶化”这类无法落地的泛泛之词。

### 13.2.2 锁定单一关键观察指标，映射双向股价情景，并参照历史回撤

**方法要点**：事件（如发布会）之后，明确最关键的那一个观察指标，把它的“快/慢”分别映射为上行与下行股价情景，用历史上同类不及预期的回撤幅度作为下行参照，并回链深度报告的目标价。

**操作步骤 / 拆分口径**：

1. 选择单一关键指标：与核心逻辑兑现最直接相关、且可高频观测（例如Cybercab的扩张速度/车队规模）。
2. 写上行情景：若扩张超预期（例如从45辆快速扩到数百、数千辆）→ 兑现概率显著提升 → 股价可能涨向乐观价位（2万亿美元，602美元/股）。
3. 写下行情景：若扩张显著低于预期（车队迟迟爬不到数百辆级别）→ 市场信心再受挫 → 历史可能重演。
4. 用历史同类不及预期的回撤幅度作为下行参照：此前因Robotaxi进度不及预期，股价从420美元跌到300-350美元。
5. 回链深度报告的目标价，保持跟踪与长期框架一致。

**关键指标与数据来源**：Cybercab车队规模和爬坡速度；乐观目标价；历史回撤区间（420美元到300-350美元）。来源为公司发布会与运营披露、深度报告目标价、历史股价。

**判断标准**：快速由45辆扩到数百、数千辆 → 上行；迟迟爬不到数百辆 → 下行，且下行幅度可参照420美元→300-350美元的历史回撤。

**海豚案例**：
- 特斯拉《Cybercab 发布会：告别概念，开启 Robotaxi 大时代？》（2026-09-04）：以扩张速度为关键指标，上行指向2万亿美元（602美元/股）、下行参照420美元跌至300-350美元的历史回撤；并回引《从造车到造梦…》《Robotaxi 出行帝国，能再造特斯拉？》的目标价与框架。

**适用场景与注意事项**：适用于事件后给出明确跟踪抓手。关键指标要可高频观测；单一指标不能替代全面跟踪，但能让读者聚焦。

### 13.2.3 明确基本面反转的跟踪条件，区分估值修复与基本面反转

**方法要点**：事件点评的结论区分两个层次：短期估值和情绪修复可以发生，但基本面彻底反转需要特定条件；把条件明确为可跟踪的指标，并给出时间判断。

**操作步骤 / 拆分口径**：

1. 区分层次：估值与情绪修复（短期可发生） vs 基本面彻底反转（需要条件）。
2. 把反转条件列成可跟踪指标：内部大模型迭代、与Tier 1的差距、AI产品体验、Agent商业化，以及组织和战略的稳定性。
3. 逐项给出观察口径：大模型能力排名/迭代、Meta AI体验、Business Agents和AI机器人的规模应用、组织调整频率。
4. 给出时间判断（如今年内很难出现基本面彻底反转）。
5. 写成跟踪清单，收在事件点评的结尾。

**关键指标与数据来源**：大模型能力排名/迭代、Meta AI体验、Business Agents和AI机器人的规模应用、组织调整频率。

**判断标准**：反转拐点要看内部大模型与产品的实质进展；组织架构与战略频繁变动 → 基本面彻底反转很难在短期内出现；单纯的算力、成本事件只能带来估值/情绪修复。

**海豚案例**：
- Meta《算力太贵，Meta 掀桌？》（2026-07-06）：反转拐点仍要看内部大模型和Meta AI的进展；内部组织架构和战略频繁变动，使基本面彻底反转很难在今年内出现。

**适用场景与注意事项**：适用于所有事件点评的收尾，可写成跟踪清单。要让读者清楚“短期修复”与“长期反转”是两个不同的判断，避免把反弹当反转。

### 13.2.4 设置可验证的观察信号与催化剂（跟踪清单）

**方法要点**：每篇研究都给出下一步可观察、可验证的信号，用以检验判断，把“看好/看空”转成“接下来看什么”。

**操作步骤 / 拆分口径**：

1. 为每个核心判断指定下一个观察点：财报中的指引变化、管理层口吻、项目进度、竞品订单、关键时间点。
2. 按公司写出具体信号：
   - Meta：月底Q2财报是否继续上调当年Capex，业绩会谈及14GW部署时的口吻是否激进。
   - Muse：用户渗透、付费率与订阅涨价，是否被倒逼自建电商，业绩会上广告与Business Agent用量进展。
   - Amazon：Project Rainier建设节奏（合作关系风向标）、Trn4流片时间。
   - BE：Ceres在AIDC的订单、燃机扩产节奏、阳极支撑量产、电堆还原工序改造进度。
   - Rocket Lab：Neutron四季度能否按时首飞。
   - AppLovin：Pixel安装数据与Q4财报。
3. 每项信号要“可观察、可验证”，并标明时点，用于下一次复盘。

**关键指标与数据来源**：Capex指引、管理层表述、项目进度、竞品订单、首飞时间。

**判断标准**：信号按预期出现 → 逻辑强化；与预期相反 → 触发复核或下调；管理层口吻（激进/克制）也是信号的一部分。

**海豚案例**：
- Meta（2026-07-10、2026-09-23）：跟踪Q2财报是否继续上调当年Capex、14GW部署的表述口吻，以及Muse的用户渗透、付费率与订阅涨价、是否被倒逼自建电商、业绩会上广告与Business Agent用量进展。
- Amazon（2026-06-24）：Project Rainier建设节奏（合作关系风向标）、Trn4流片时间。
- Bloom Energy（2026-07-20）：Ceres在AIDC的订单、燃机扩产节奏、阳极支撑量产、电堆还原工序改造进度。
- Rocket Lab（2026-04-10）：Neutron四季度能否按时首飞。
- AppLovin（2026-01-20）：Pixel安装数据与Q4财报。

**适用场景与注意事项**：用于个股跟踪体系的搭建。信号要具体到数据或事件，且设置时点，才能在下一期复盘时核对；本清单与13.3的催化剂时间线互相印证。

## 13.3 催化剂识别与时间线

> 本节导读：本节回答“什么事件会在什么时候推动股价、哪些只是一次性噪音”。做法是先把催化剂分类并标出下一个关键节点，再甄别它们是一次性、阶段性还是长期的，判断从发布到进入报表需要多久，最后看业绩之外的叙事能否托底，并对指数纳入这类资金流事件做情景化的时间处理。适用于事件驱动型标的、业绩一般时的股价判断、市场情绪转向时的叙事评估；与13.2的跟踪清单配合，形成“催化剂时间线＋验证信号”；“公司战略vs市场偏好”错配框架对股价拐点的两类催化详见1.3，解禁时间表见11.2，政策事件的影响推演见12.6。

### 13.3.1 事件驱动型股价：催化剂分类清单

**方法要点**：对靠事件催化而非业绩兑现定价的公司，把催化剂分成固定的几类，逐一列出并标出下一个关键节点，避免遗漏驱动因素。

**操作步骤 / 拆分口径**：

1. 分四类列出催化剂：
   - 产品或技术里程碑；
   - 订单（ARR）；
   - 创始人beta（关联公司与政府合同）；
   - 宏观（降息预期）。
2. 每类写出已发生的事件与下一个关键节点。
3. 把股价近期涨跌归因到这四类，区分哪些是自身里程碑、哪些是创始人或宏观的外部贡献。
4. 用节点清单作为跟踪表，随事件推进更新。

**关键指标与数据来源**：里程碑事件、ARR、国防合同、宏观利率。来源为公司披露、政府合同公告、宏观数据（如非农）。

**判断标准**：此类股价逻辑类似特斯拉，取决于里程碑兑现（如星舰复用、V3卫星、Grok 5、算力订单）；里程碑密集且持续兑现 → 催化剂强；仅靠宏观或创始人beta → 持续性弱。

**海豚案例**：
- SpaceX（2026-10-07）：较8月低点反弹约60%；归因于星舰第14飞入轨、第15飞尝试捕获上级（产品技术里程碑），五家客户算力ARR 545亿（订单），马斯克被任命为国防部计划联合负责人（创始人beta），非农不及预期（宏观）。
- SpaceX《2Q26速读》（2026-08-05）：股价逻辑类似特斯拉，取决于星舰复用、V3卫星、Grok 5、算力订单等里程碑。

**适用场景与注意事项**：适用于马斯克系、远期叙事驱动的股票。分类清单要“标出下一个关键节点”，而不是只总结已发生的事件。

### 13.3.2 催化剂/新功能的“阶段性 vs 长期”甄别（含品牌心智冲突分析）

**方法要点**：把市场提出的潜在利好逐条分类，识别哪些是一次性事件、阶段性提振、长期利好，并对长期利好做反面论证，尤其检验它与品牌心智是否冲突。

**操作步骤 / 拆分口径**：

1. 把市场提出的潜在利好列出，逐条分为三类：
   - 一次性事件（如世界杯）；
   - 阶段性提振（体验没有根本提升的功能，如先定后付，对增速+2~3pct）；
   - 可能的长期利好（如增加酒店供给加广告变现）。
2. 对长期利好做反面论证：会不会冲击“品牌即品类”的心智？流量怎么分配？公平分配就失去特色，优先分配又让新供给失去意义。
3. 用国内电商的类比辅助说明（流量分配与生态结构的矛盾）。
4. 参考管理层态度（是否克制）作为辅助证据。
5. 对新功能的增速贡献用pct量化，判断其是否足以改变趋势。

**关键指标与数据来源**：新功能对增速的提振pct、管理层态度。来源为业绩会、功能上线适用范围与效果披露。

**判断标准**：体验没有根本提升的功能 → 阶段性；与品牌心智冲突、且流量分配两难的“长期利好” → 持怀疑态度；一次性事件不应进入趋势性预测。

**海豚案例**：
- Airbnb（2026-02-13）：先定后付（RNPL）在适用地区提振间夜增速2~3pct，海豚君认为是阶段性的；26年美加墨世界杯是一次性催化剂；增加酒店供给会冲击“品牌即品类”的心智，Airbnb的真正差异在于几乎没有酒店，管理层态度也克制，所以海豚君持怀疑态度。

**适用场景与注意事项**：适用于平台公司、消费品牌在市场情绪转向时的叙事评估。要警惕把阶段性功能当成长期增长引擎；长期利好也要问“代价是什么”。

### 13.3.3 催化剂时效性判断：技术更新多久能转化为销量

**方法要点**：对每项利好判断“从发布到影响报表”需要多长时间，只有短期能兑现的才算销量催化，长周期项只算长期竞争力。

**操作步骤 / 拆分口径**：

1. 列出每项利好及其发布时间：超充网络铺设、DM-i 6.0发布、Robotaxi投产等。
2. 估算转化周期：超充网络铺设需要较长周期，短期难以改变消费者购车决策；DM-i 6.0预计下半年发布，晚于当前插混销售窗口；Robotaxi预计2026年下半年才对报表产生显著影响（Cybercab 2026年4月投产）。
3. 与当年销量/业绩对照：只有短期能兑现的才计入销量催化。
4. 长周期项只记为长期竞争力，不进入当年预测的乐观调整。

**关键指标与数据来源**：技术或产品发布时间；量产或铺设周期；对当年销量的贡献。来源为发布会与公司披露、量产与基础设施建设进度。

**判断标准**：发布时间晚于当前销售窗口，或铺设周期长 → 不形成当年销量催化；产品只是“更新”而非“质变” → 短期不足以形成质变的销量催化。

**海豚案例**：
- 比亚迪《比亚迪：“颠覆性”发布会，能“颠回”宇宙车厂吗？》（2026-03-06）：认为电池与快充更新短期不足以形成质变的销量催化。
- 特斯拉《从造车到造梦：1.5 万亿 AI 特斯拉真的贵了吗？》（2026-01-12）：Robotaxi业务预计26年下半年才显著影响报表。

**适用场景与注意事项**：适用于事件驱动交易判断。时效判断要与市场的交易周期匹配——若市场交易的是远期叙事，长周期项仍可能影响股价，但不应混入当年盈利预测。

### 13.3.4 判断业绩之外的叙事和催化剂能否为股价托底

**方法要点**：业绩一般时，判断股价有没有叙事托底（新车周期、新业务上市、回购、新模型、机器人等）；对高估值成长股，看叙事有没有被验证。

**操作步骤 / 拆分口径**：

1. 先承认业绩一般，再列出业绩之外的叙事和催化剂：新车周期、新业务上市、回购、新模型、机器人等。
2. 把它们放进催化剂时间表，标明发生时点。
3. 判断这些叙事能否对冲业绩的不及预期，从而为股价托底。
4. 对高估值成长股，进一步检验叙事有没有被验证（被验证才能支撑估值）。

**关键指标与数据来源**：催化剂时间表。

**判断标准**：存在年内可兑现的叙事（上市、入通、新品发布、新模型）或回购 → 股价有托底；叙事全部处于远期且未被验证、估值又高 → 托底不足。

**海豚案例**：
- 百度（2026-02-26）：股价调整已久，加上回购托底，以及昆仑芯上市、入通等年内叙事。
- 理想（2026-03-12）：Q2新款L9上市，传闻上半年人形机器人亮相。
- Meta（2026-01-29）：Q1新模型Avocado、Mango，Threads商业化，可能宣布更多Opex优化。
- 小米（2026-03-24）：寄望后续新车和大模型。
- 三花（2026-03-23）：更值得关注机器人和数据中心等新业务。
- 中芯（2026-02-10）：追赶台积电等第一梯队带来额外期待。
- 苹果（2026-01-30）：与谷歌Gemini合作、Siri升级。

**适用场景与注意事项**：普遍适用，尤其是财报前后的短期点评。叙事不能替代业绩：托底只能缓冲，需要用13.3.3的时效性判断过滤“看起来很远”的叙事。

### 13.3.5 指数纳入与被动资金到账时间的情景化处理

**方法要点**：对新上市、二次上市、市值跨档的标的，列出可纳入的指数与对应被动资金量，并按指数规则对纳入时点做情景区分，承认最大单一流入的到账时间存在不确定性。

**操作步骤 / 拆分口径**：

1. 列出可纳入的指数及各自对应的被动资金规模估算。
2. 核对指数编制规则（尤其IPO快速纳入条款），区分情景：
   - 若按IPO待遇处理，最早2026年9月纳入；
   - 若不按IPO待遇，则延至2027年9月。
3. 识别单一最大流入（约38亿美元）及其时间不确定性（约一年）。
4. 用时间线图表呈现各指数事件，作为股价催化剂的跟踪清单。
5. 随规则核对结果与公司公告更新情景。

**关键指标与数据来源**：指数编制规则（IPO快速纳入条款）、被动资金规模估算、纳入日期。来源为各指数公司的编制规则与公告。

**判断标准**：被动资金到账是“确定会发生、但时点不确定”的催化剂；最大单一流入时点相差一年，对短期股价节奏影响大，应以情景而非单点呈现。

**海豚案例**：
- SK海力士《海力士赴美，来讨一个“公道估值”？》（2026-07-10，补充信息“指数及被动资金时间线”）：38亿美元单一最大流入的时点不确定约一年（IPO待遇下最早2026年9月，否则延至2027年9月）。

**适用场景与注意事项**：适用于新上市、二次上市、市值跨档等标的的资金流催化剂分析；需逐一核对指数规则。

**本节速查清单**

- [ ] 事件驱动型标的，是否按“产品/技术里程碑、订单（ARR）、创始人beta、宏观”四类列出催化剂并标出下一个关键节点？
- [ ] 每条潜在利好是否分清了一次性、阶段性、长期，并量化了对增速的提振（pct）？
- [ ] 对长期利好是否做了反面论证（是否冲击品牌心智、流量如何分配）？
