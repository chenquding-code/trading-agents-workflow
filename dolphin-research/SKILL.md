# 海豚投研研究方法论

三套框架，全部提炼自海豚投研 2026-01-01 至 2026-10-19 的中文原文：长文 367 篇、火线速读与短评 284 条。共 3419 条方法，每条都带海豚的原文案例和数字。

| 框架 | 回答什么 | 规模 | 附录A 卡片 |
|---|---|---|---|
| `财报` | 这次财报怎么读、预期差在哪、指引隐含什么、股价为什么这么走 | 17 章 · 108 节 · 1287 法 | 106 家公司的财报追踪卡（每季必看指标、预期基准、估值方法） |
| `个股` | 这家公司怎么做深度：生意、单位经济、空间、护城河、预测、估值、治理、结论 | 15 章 · 78 节 · 992 法 | 88 张公司研究卡 |
| `行业` | 这个赛道怎么研究：产业链、需求、供给、价格周期、技术路线、竞争、标的映射、宏观数据 | 17 章 · 78 节 · 702 法 | 86 张行业/赛道卡 |

编号规则：`9.2` 是节，`9.2.3` 是方法（章.节.条）。每个方法都有同样几个字段：**方法要点 / 操作步骤与公式 / 关键指标与数据来源 / 判断标准 / 海豚案例 / 适用场景与注意事项**。每节末尾有一份「本节速查清单」。

## 怎么读：不要整份打开正文

正文单个文件 50–500 KB，整份读进来会挤掉上下文。所有内容都用脚本按编号取：

```bash
D=<本 skill 目录>/scripts/dolphin.py      # 例如 ~/.claude/skills/dolphin-research/scripts/dolphin.py

python3 $D card CoreWeave                 # 先查卡片：三套框架里所有标题含 CoreWeave 的卡
python3 $D overview 财报 SOP              # 该模式的标准流程（00_总览 里的现成工具）
python3 $D toc 财报 9                     # 第 9 章的节与方法标题
python3 $D show 财报 9.2 --brief          # 一节的方法要点 + 速查清单（约 10 KB，选方法用）
python3 $D show 财报 9.2.2                # 单个方法全文（照着做）
python3 $D search 隐含 Q4                 # 不知道在哪一节时按关键词找（多词取交集）
python3 $D checklist 个股 10.1            # 做完一节后对照速查清单
python3 $D source 台积电 -f 财报          # 海豚原文出处：日期、类型、标题、链接
```

框架名也可以写成 `earnings / stock / industry` 或 `e / s / i`。不带参数运行 `overview <框架>`，会列出 00_总览 的各个部分。

## 第一步：选框架

| 手头的任务 | 主框架 | 常配合 |
|---|---|---|
| 财报前预期表、业绩前瞻 | 财报 第 1 章 | 财报 11.3（估值水位与业绩门槛）、14.1（高频数据） |
| 财报发布后的火线速读 | 财报 第 2、9 章 | 财报 17.2.1（速读三段式） |
| 完整财报点评 | 财报 第 3–14 章 + 对应行业节 15.x/16.x | 财报 17.1（点评骨架） |
| 首次覆盖、个股深度 | 个股（全流程） | 行业（先定赛道主线）、财报卡（季度 KPI） |
| 估值、目标价、击球区 | 个股 第 9、10、14 章 | 财报 第 12 章（财报后的估值更新） |
| 股价大涨大跌归因 | 财报 第 11 章 | 个股 2.3（股价复盘）、10.3（定价锚切换） |
| 行业、赛道、产业链研究 | 行业（全流程） | 行业 11（从行业到标的） |
| 突发事件、传闻、新品发布 | 行业 第 12 章 / 个股 第 12 章 | 行业 17.2.7（事件快评骨架） |
| 月度宏观高频（社零等）、市场策略 | 行业 第 14、15 章 | — |

研究某个行业里的具体公司，顺序一般是：先用`行业`定主线、空间和格局，再用`个股`做深度，之后每季用`财报`跟踪。

## 第二步：先查卡片

```bash
python3 $D card <公司名或代码>            # 命中 3 张以内直接打印全文；命中更多先列清单
python3 $D card --list -f 财报            # 列出某框架的全部卡片
```

- **财报卡**：每季核心问题及其演变、必看指标清单（口径与看法）、预期基准与好坏判定、估值方法、来源文章。做财报前预期表时，就按「必看指标清单」逐项建表。
- **个股卡 / 行业卡**：研究主线、分析框架与关键判断、估值框架、追踪指标、相关卡片。

卡片是 2026-10 之前的状态。拿来当研究的起点和指标清单用，数字要用最新披露更新。没有现成卡片时，就找同类公司的卡片，复用它的主线和估值框架（个股 A1 步就是这么做的）。

## 第三步：按模式走流程

下面是三套标准流程的压缩版。完整版（每步对应哪些方法、哪些必做、哪些视情况做）用 `overview` 取。

### A. 财报（`overview 财报 SOP`）

| 阶段 | 要做的事 | 主要小节 |
|---|---|---|
| 财报前 T-7~T-1 | 翻卡片和上季遗留的验证清单。搭多层预期基准：彭博、头部大行、买方、公司指引。锁定决定股价的那一个核心指标。还原买方真实预期是怎么一路漂移上来的，标出哪些已经是「明牌」。按业务线推演当季，做基数和日历校准。确认估值水位和业绩门槛，填好追踪表 | 1.1、1.2、1.3、1.5、3.3、3.4、11.3、14.1；`overview 财报 追踪表` |
| 速读 30 分钟 | 先定口径（名义 vs 不变汇率、一次性项），再逐项对标 beat/miss。读指引：按上限、中值、下限判定，倒算隐含值，问清市场在为哪一年定价。做预期差归因，检验超预期的含金量。一句话定性，初判股价反应，列 2–5 个电话会问题 | 4.1、4.4、4.5、2.2、9.1、9.2、9.3、2.3、2.4、2.1、11.2；成文用 17.2.1 和 `overview 财报 一页纸` |
| 电话会后 | 增量信息分级。按季排序措辞、记录「没说什么」。用新信息更新指引倒算和股价归因 | 2.5、9.5、9.8、9.2、11.1 |
| 完整点评 T+1~T+3 | 边际变化 → 口径清洗 → 收入与前瞻指标 → 行业指标体系 → 毛利率与费用 → Capex、现金流与资产负债表 → 外部验证 → 股价解释 → 预测与估值 → 观点 → 成文 | 3→4→5/6→15/16→7/8→10→14→11→12→13→17.1 |
| 季度复盘 | 回测上季判断，更新指引台账和管理层风格档案，滚动估值基准年份 | 13.3、9.6、9.4.7、12.6 |

行业专属指标：`overview 财报 按行业查指标`，给出 21 个行业各自最核心的 3–6 个追踪指标，以及对应的公司卡片。多数行业节有一条「速读框架」，比如 15.1.24、15.6.26、16.1.38，拿到财报可以先读它。

### B. 个股深度（`overview 个股 标准流程`）

九个阶段：**A 立项**（1：用增量找决定性板块，给标的定性，分清已定价与边际增量）→ **B 来路**（2：成长阶段、股价复盘）→ **C 生意**（3、4：收入写成因子乘积，在最小经营单元上算清单位经济）→ **D 空间与对手**（5、6：TAM 双路线，护城河落到具体环节，再做逆境检验）→ **E 增长与战略**（7：Beta/Alpha 拆分、第二曲线进度表）→ **F 预测**（8：驱动因子链、订单相对化、指引反推、三情景底稿）→ **G 定价**（9、10：先选尺子再算倍数，做反向估值和情景估值）→ **H 治理与特殊情境**（11、12）→ **I 结论与跟踪**（13、14：证伪条件、催化剂、「空间 + 条件 + 价位」）。

辅助工具：
- `overview 个股 40 问`：立项问卷，能答的写一句结论，答不了的就是下一步要补的研究
- `overview 个股 按公司类型`：11 类公司（AI 硬件、周期股、平台互联网、消费连锁、亏损早期、金融科技、IPO、被做空、困境反转、转型、能源设备）各自先翻哪里
- `overview 个股 估值方法速查表`：第 9、10 章全部估值方法一览

### C. 行业研究（`overview 行业 标准流程`）

十七步，从立项到跟踪：主线与瓶颈 → 赛道定性（爆发型还是替代型、新需求还是存量替代、结构性还是周期性）→ 规划证据 → 产业链拆到可数的物理单元 → 利润分配 → 需求公式（写出放大项和抵消项）→ 有效供给与瓶颈 → 供需、价格二阶导与周期位置 → 技术路线 → 空间与渗透率 → 竞争格局与追赶 → 商业模式与单位经济 → 政策地缘 → 标的映射（先做可投资性过滤）→ 验证（±10% 弹性测试）→ 跟踪信号 → 成稿。

辅助工具：`overview 行业 立项清单`（38 问）、`overview 行业 按行业类型`（8 类赛道）、`overview 行业 数据源速查表`。赛道专属原理见第 16 章（存储、AI 网络、电力、机器人、车与智驾、商业航天等）。宏观月度数据按 14.1→14.2→14.3 走，美股/中概策略按 15.1→15.4 走。

## 第四步：取方法并照做

1. 用 `show <框架> <节> --brief` 看一节有哪些方法，挑出适用的 2–5 条
2. 用 `show <框架> <方法号>` 读全文，照「操作步骤与公式」算，按「判断标准」解读读数
3. 「海豚案例」是校准用的参照：看海豚在同类公司上取的口径、阈值和结论形态，不是现成的答案
4. 一节做完，跑一遍 `checklist <框架> <节>` 查漏
5. 现成方法不够用，可以组合、迁移、换分母，衍生出新方法：`overview <框架> 衍生`

## 海豚的核心判断习惯

三套框架各有 19–20 条「核心心法」（`overview <框架> 心法`）。下面这几条贯穿全部，写结论前逐条过一遍：

1. **每个数字旁边写明「和谁比」。** 拥挤的龙头股，真实门槛是上调后的买方预期，彭博一致预期不算数（财报 1.1）。
2. **先找决定股价的那一个变量。** 已知的后置，未知的前置。用增量而不是存量找「唯一胜负手」（财报 1.3、13.2；个股 1.1）。
3. **三维定性：绝对表现、预期差、边际趋势，再点明哪一维决定股价**（财报 2.1）。
4. **先去噪再解读。** 汇率、并表、一次性、基数、日历逐项排查；拐点比幅度重要（财报 3、4 章）。
5. **指引要倒算成可比数字。** 全年减已实现，利润指引除以收入指引，再按管理层的指引风格修正（财报 9.2、9.4）。
6. **反向估值：先问价格里已经隐含了什么。** 答案要落到「和我们判断的差距」，不能只说贵或便宜（个股 10.1；行业心法 10）。
7. **估值只写假设显性化的区间。** 三情景并列、写清赔率，给击球区，不追单一目标价（财报 12；个股 10.2、14.1）。
8. **事实、推算、推测分开标注。** 外部数据取保守一端。公司停止披露关键指标，按负面信号处理（财报 4.6、14.4）。
9. **观点必须可证伪。** 结尾列「变量 + 阈值 + 时点」的验证清单，下一季开篇先回顾上期观点（财报 13.3；个股 13.2）。

## 硬规则

1. **方法是海豚的，数据要自己取。** 海豚案例里的数字、阈值和判断都是原文当时的口径。用到新公司或新时期，必须用最新披露重新取数、重新校准，不许把案例数字当成现在的数据。
2. **数字要有来源和日期。** 拿不到就写「未获取」，不估算，也不用记忆里的旧值。推算出来的数要写明公式，并标「推算」。
3. **引用海豚过去的观点，要给出《标题》和长桥原文发布日期**（用 `source` 查）。不许编造「海豚君认为」。框架本身只是方法工具箱，不含任何投资结论。
4. **时间边界。** 框架和卡片覆盖 2026-01-01 至 2026-10-19，之后发生的事要另外取数。
5. **底稿里标方法编号**（例如「隐含 Q4 按财报 9.2.2 倒算」），方便复核。对外成稿默认不堆编号，用户要求时才保留。
6. **成稿骨架照海豚的模板来。** 财报点评用 17.1，速读用 17.2.1，个股深度用 14.3，行业文用 17.2。小标题写成陈述句结论，不写名词短语。
7. **画图**：如果环境里有 `dolphin-charter` skill，所有图表都按它的规范出图（英文图内文字、「Sources: …, Dolphin Research」、水印、品牌色）。
