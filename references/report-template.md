# 报告结构（v2 · 定价导向）

对外只交付 `report.md` / `report.html`。11 个角色的原文留在 `1_analysts/`…`5_portfolio/`，是审计留痕，不进交付物。

## 为什么改

v1 把 11 份原文按图顺序拼成一份文档，读者要自己提炼三件事：市场在定价什么、共识是什么、我们差在哪。v2 把这三件事做成正文骨架，其余压缩成支撑。

**技术面从"一个平级分析师"降为"附录 A 的执行参考"。** 对 3 个月以上的判断，趋势线和 MACD 提供的信息量远低于盈利质量与折现率。

## report.md 结构

```markdown
# <ticker> · <公司名>

## 结论
- 评级 / 12 个月目标价 / 现价 / 预期回报
- 三句话：① 市场在交易什么（不是基本面）② 共识已经算什么了 ③ 我们的差异在哪
- 一句话操作建议

## 多空辩论
三行三列的表格，每格一句话，不许写成段落：

| | 多方 | 空方 |
|---|---|---|
| **核心逻辑** | 一句话：最硬的做多理由，带数字 | 一句话：最硬的做空理由，带数字 |
| **这个逻辑的最大风险** | 一句话：什么会打掉做多逻辑 | 一句话：什么会打掉做空逻辑 |
| **何时验证** | 一句话：哪个数据点、什么时候 | 同 |

作用：让读者在 15 秒内看到双方的胜负手在哪，以及赌的是什么事件。

## 1. 市场现在在交易什么
### 1.1 <陈述句结论：这轮涨跌里多少来自倍数、多少来自盈利>
表格：日期 / 收盘 / 市值 / PS / 事件。正文只放证据，不复述标题。
### 1.2 <陈述句结论：市场在说什么，不是在说什么>
用两个反证支撑（IV 水位、空头持仓、成交量分布）。
### 1.3 <陈述句结论：三个锚的具体数值>
三个数：PS / EV-FCF / FCF 收益率，各自和五年分位、无风险利率对照。

## 2. 价格里已经包含了什么
### 2.1 <陈述句结论：隐含 10 年 FCF 复合增速是 X%>
给 9%/10%/11%/12% 折现率各一个值。
### 2.2 <陈述句结论：增速只要 Y% 而非 X%，合理 EV 就低 Z%>
增速 20/25/30/33/35% 对应 EV 与当前 EV 的差。让读者自己判断"这个增速合不合理"。
### 2.3 <陈述句结论：共识目标价=现价，却把 EPS 上修了 N%>
forward PE 反推 EPS vs 公司指引。**若目标价≈现价但 EPS 在增长 → 共识在算倍数收缩。**

## 3. 卖方共识的拆解
### 3.1 <陈述句结论：N 买 N 持 N 卖，目标价 X 等于现价>
给两个口径，不一致就指出来。
### 3.2 <陈述句结论：N 次上调 N 次下调，且发生在股价跌 N% 那周>
### 3.3 <陈述句结论：共识的 N 个假设，每一个都能被质疑>
表格：假设 / 共识怎么想 / 依据薄弱在哪

## 4. 我们与共识的差异（核心章节）
5 条以内，每条标题就是那句差异本身（"X 不是 A，是 B"），正文固定四段：

> **共识认为**：……
> **数据说**：……
> **差异量级**：……（能算就算，算不出就写"无法量化"）
> **验证节点**：……（哪个数据点、什么时候）

最后一句：这几条差异合起来，评级应该是几档。

## 5. 基本面：这门生意现在的位置
### 5.1 <陈述句结论：增速在做什么，但什么已经停滞>
### 5.2 <陈述句结论：哪个数字是真的，哪个是假象>
### 5.3 <陈述句结论：资本配置在做什么，股东回报是多少>
### 5.4 <陈述句结论：这个倍数买的是什么 alpha>
### 5.5 <陈述句结论：内部人做了什么，在什么价位>

## 6. 估值：<陈述句结论：加权目标价 X，分布是正偏还是负偏>
表格：情景 / 假设 / 倍数 / 价位 / 回报 / 概率。末尾给概率加权目标价和预期回报。
概率必须能说出理由，不能均分。

## 7. 验证节点：<陈述句结论：哪个数字定生死>
表格：日期 / 事件 / 验证哪条差异 / 触发什么动作。

## 8. 什么会推翻我们：<陈述句结论：共 N 条可观测条件>
3–4 条，可观测、可执行（价格条件或数据条件），每条注明"上调到几档"。

## 附录 A：执行参考（<关键价位与止损>）
只留：现价、关键支撑阻力、ATR 与止损距离、量能状态。**不解释趋势、不做方向判断。**

## 附录 B：数据缺口与口径（<N 项未获取>）
`未获取` 项清单、口径差异（GAAP/Non-GAAP、TTM/单季）、第三方数据取数日。
```

## 写作约束

- **所有小标题必须是陈述句结论，不许用名词短语。** 写"这轮 -18.5% 全来自倍数"，不写"最近一次重定价的分解"；写"增速只要 25% 而非 33%，合理 EV 就低 45%"，不写"敏感度分析"。读者只看标题就该知道每节说什么。
- **标题下不复述标题。** 标题给结论，正文只放证据和推理。
- **多空辩论用表格，不用段落。** 每格一句话，四格之内讲完。
- **不出现"XX 分析师认为"**。观点以"共识 / 数据 / 我们认为"三种主语出现。
- **同一件事只讲一次**。辩论里的重复论点在正文合并，不按轮次复述。
- **每个数字带口径**。GAAP 还是 Non-GAAP、TTM 还是单季、取数日。
- **结论先行**。每节第一段就是结论，后面才是支撑。不要"下面我们来看"这种过渡句。
- **不写免责长文**。末尾一行足够。

## 评级解析

终裁文件第一行必须是 `**Rating**: X`。解析口径：

1. 取正文第一行（跳过 `#` 标题行），匹配 `rating` + `:`/`-` + 五档之一
2. 第一行没匹配上，找全文所有 `Rating: X`，**全部一致**才算数
3. 多个不同评级且未标明哪个是终裁 → `REVIEW`
4. "Rating Scale / Rating Options" 是量表说明，跳过

`REVIEW` 不是 Hold，是要人工复核的信号，交付时必须明确告诉用户。
