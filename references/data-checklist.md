# 取数清单

按市场分。**先确认标的的交易所后缀，再选对应清单**——用错后缀会拿到完全不相干的公司数据。

|---|---|---|---|
| 美股 | 无 | `NVDA`、`SPY` | ETF 同样适用 |

## 一、技术面（所有市场通用）

必需：近 6 个月日线 OHLCV（至少 130 个交易日，200 日均线需要 200 个）。

| 数据 | 来源优先级 |
|---|---|
| 日线行情 | 交易所官网 / 东方财富 / 同花顺 / Yahoo Finance / Stooq |
| 复权处理 | A股必须用**前复权**，否则除权日会出现假跳空 |
| 成交额 | 用于量能判断，A股看成交额不看成交量（价格差异太大） |

指标自己算，不要让数据源给现成值（各家参数口径不同）。ATR 用 14 日，RSI 用 14 日，MACD 用 12/26/9。

## 二、基本面

### 美股
- 10-K / 10-Q（SEC EDGAR，原始文件最可靠）
- 财报电话会纪要（管理层指引原文）
- Form 4（内部人交易）、13F（机构持仓）

### A股
- 定期报告（巨潮资讯网 cninfo 为原始披露源）
- 业绩预告 / 业绩快报（比正式财报早，注意区分）
- 投资者关系活动记录表（调研纪要，信息密度高）
- 龙虎榜、大宗交易、股东增减持公告

### 港股
- 港交所披露易（HKEXnews）公告原文
- 中期/年度报告
- 南向资金持股变化

### 关键提醒
- **TTM 与单季不要混用**，每个数字注明口径
- A股「扣非净利润」比净利润更能反映主业
- 港股注意「股东应占溢利」与「净利润」的差异
- 加密无财报，基本面改为：链上活跃地址、交易所净流入、代币解锁时间表、协议收入

## 三、卖方共识（报告第 3 节的原料，必取）

报告的价值一半来自"与共识的差异"，所以共识必须先拿到硬数字，不能写"分析师普遍看好"。

| 数据 | 用途 | 来源 |
|---|---|---|
| 评级分布（买/持/卖各几家） | 判断一致性是否到极值 | MarketBeat、StockAnalysis、富途、TipRanks、Zacks |
| 目标价：均值 / 最高 / 最低 | 判断上行空间；最高最低差反映分歧度 | 同上，**至少取两家口径** |
| 目标价时间序列（1 年前 / 3 个月前 / 1 个月前 / 现在） | 判断共识在往哪个方向修 | MarketBeat 分析师动作表 |
| 近 30–90 天评级动作（上调/下调/首次覆盖，带日期与机构） | 识别"追价式上调" | MarketBeat、Benzinga |
| forward PE 与 NTM EPS 共识 | 反推共识的盈利假设 | S&P（经 StockAnalysis）、Yahoo、Zacks |
| 营收/EPS 共识（本财年与下一财年） | 与公司指引对照 | 同上 |

**必须做的三个对照**：
1. **共识目标价 vs 现价** —— 若已等于或低于现价，说明共识没有上行空间，这比评级分布更重要
2. **共识 EPS vs 公司指引** —— 共识高于指引 = 共识预期 beat；再结合目标价不动，可推出共识隐含倍数收缩
3. **不同聚合器的均价差** —— 差 10% 以上说明"共识"本身不稳，报告里必须指出

**注意**：量化模型评级（如 Zacks Rank）与人类分析师评级要分开计，混在一起会高估空方代表性。

## 四、新闻宏观

| 类型 | 来源 |
|---|---|
| 公司事件 | 交易所公告（原始）、公司官网投资者关系页 |
| 行业政策 | 部委官网、行业协会 |
| 宏观数据 | 统计局、央行、FRED（美）、Trading Economics |
| 市场隐含预期 | CME FedWatch（利率）、Polymarket（事件概率） |
| 卖方观点 | 研报摘要（注意：这是观点不是事实，必须标注） |

## 五、情绪面

| 市场 | 散户社区 | 资金面代理 |
|---|---|---|
| 美股 | StockTwits、Reddit（r/wallstreetbets、r/stocks） | 期权 Put/Call、做空比例、ETF 流向 |
| A股 | 雪球、东方财富股吧 | 融资余额、北向资金、成交额分位 |
| 港股 | 雪球、AAStocks | 南向资金、沽空比例 |
| 加密 | X/Twitter、Telegram | 资金费率、未平仓合约、交易所净流入 |

**数据可得性警告**：社区数据多为近期快照，历史日期拿不到当时的讨论。做历史日期分析时，情绪面只能标注"数据不可得"，不要用今天的情绪冒充那天的。

## 取数失败时怎么办

按这个顺序降级，**不要跳过**：

1. 换来源（同一数据一般有 3 个以上公开源）
2. 降精度（日线拿不到用周线，但要在报告里注明）
3. 标注 `未获取`，并在报告里写清"因此哪部分结论无法支撑"

绝不允许：用估算值、用记忆中的旧值、用其他公司的数据替代、把"没查到"写成"没有"。
